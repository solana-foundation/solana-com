# Builder App Agent Guide

Use this app for the BLDR event site at `solana.com/builder`.

- Workspace: `apps/builder`
- Package: `solana-com-builder`
- Default dev port: `3007`
- Public route ownership: proxied behind `/builder`, assets under
  `/builder-assets`

Read [`CLAUDE.md`](./CLAUDE.md) for structure, palettes, fonts and the launch
checklist.
