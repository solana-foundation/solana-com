Solana 速成课程是一门轻量级课程，旨在帮助你以最快的方式从入门到构建一个可运行的应用程序。更多课程内容将在编辑完成后陆续添加。

## 课程内容概览

- Solana 开发者路线图
- 本地开发环境搭建
- 快速完成首次构建与部署流程

## 如何使用本课程

- 按顺序观看各章节内容。
- 使用配套页面查看笔记和延伸链接。
- 当你希望深入学习完整的四模块路径时，可返回完整训练营继续学习。
