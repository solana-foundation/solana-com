程序模式是训练营从设置和入门阶段转向可复用 Solana 程序设计的环节。

## 课程内容

- 有状态程序设计
- 托管与权限模式
- 代币铸造与兑换机制
- 上线前的安全审查习惯

## 如何使用本课程

- 先观看本集视频。
- 使用配套页面记录笔记和检查点。
- 在进入下一课之前完成每一节课，因为这些概念是相互递进的。
