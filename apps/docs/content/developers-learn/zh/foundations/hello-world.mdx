## 项目目标

构建一个最简化的 Hello World 风格的 Solana 项目并成功执行。

## 里程碑

1. 初始化项目结构。
2. 实现最小可用指令。
3. 执行指令并检查结果。
4. 验证预期的状态变更。

## 复用快速入门中的内容：读取账户状态

在进入更大型项目之前，请复用
[`/docs/intro/quick-start/reading-from-network`](/docs/intro/quick-start/reading-from-network) 中完全相同的账户读取工作流。

使用该教程的结果来验证以下基础知识：

- 钱包账户的 `executable` 为 `false`。
- 钱包账户的 `owner` 为 System Program。
- `lamports` 反映已充值的余额。
- 没有自定义数据的系统钱包，其 `space` 为 `0`。

## 验证

- 程序运行时无错误。
- 交易确认成功。
- 预期输出/状态在日志或账户数据中可见。
