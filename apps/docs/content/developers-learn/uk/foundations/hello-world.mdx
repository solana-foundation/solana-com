## Мета проєкту

Створити мінімальний проєкт Solana у стилі hello-world та успішно його виконати.

## Етапи

1. Ініціалізувати структуру проєкту.
2. Реалізувати найменшу корисну інструкцію.
3. Виконати інструкцію та перевірити результат.
4. Підтвердити очікувані зміни стану.

## Повторне використання з швидкого старту: читання стану акаунта

Перед переходом до більших проєктів повторно використайте точний робочий процес читання акаунта з
[`/docs/intro/quick-start/reading-from-network`](/docs/intro/quick-start/reading-from-network).

Використайте результат цього покрокового керівництва для перевірки таких основ:

- `executable` має значення `false` для акаунтів гаманців.
- `owner` — це System Program для акаунтів гаманців.
- `lamports` відображає поповнений баланс.
- `space` дорівнює `0` для системних гаманців без користувацьких даних.

## Перевірка

- Програма виконується без помилок під час виконання.
- Підтвердження транзакції пройшло успішно.
- Очікуваний вивід/стан відображається у журналах або даних акаунта.
