## Мета уроку

Налаштуйте чистіший конвеєр подій, щоб пристрій або застосунок реагував на активність у Solana без постійного ручного опитування.

## Контрольні точки

- Визначте, які події вебхуків важливі для вашого процесу.
- Зверніть увагу на те, як сервіс-одержувач повинен перевіряти та обробляти їх.
- Вирішіть, що має відбуватися, коли доставка вебхуку не вдається або затримується.
