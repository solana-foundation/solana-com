Прискорений курс Solana — це легший курс, розроблений для найшвидшого шляху від
ознайомлення до працюючого застосунку. Нові уроки можуть бути додані сюди після
завершення редагування.

## Що ви вивчите

- Дорожня карта розробника Solana
- Налаштоване локальне середовище розробки
- Швидкий перший цикл збірки та деплою

## Як користуватися цим курсом

- Дивіться епізоди по порядку.
- Використовуйте супровідні сторінки для нотаток і посилань для подальшого вивчення.
- Поверніться до повного буткемпу, коли захочете пройти глибший чотиримодульний шлях.
