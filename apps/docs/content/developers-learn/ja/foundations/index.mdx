基礎編では、より大規模な
プロダクトやプロトコルの構築に進む前に必要な背景知識からブートキャンプを始めます。

## 学習内容

- ブートキャンプの構成と、これらの補助ガイドの活用方法
- Solana のメンタルモデルを理解する
- ローカル開発ツールチェーンをセットアップする
- `create-solana-dapp` から始める
- ブロックチェーンで重要な詳細を検証しながら、AI を活用して構築する

## このトラックの使い方

- まず各エピソードを視聴します。
- メモ、チェックポイント、リンクには補助ページを活用します。
- 次のトラックに進む前に、レッスンをローカルで完了済みにします。
