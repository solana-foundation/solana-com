## プロジェクトの目標

スワップルール、流動性、価格設定の前提条件がプロトコルの動作にどのような影響を与えるかを学びます。

## チェックポイント

- 常に成立すべきプールの不変条件を特定する。
- ユーザー入力から残高更新までのスワップパスをトレースする。
- 手数料とスリッページがコードとUIの両方でどのように表示されるかを確認する。
