「プログラムパターン」では、ブートキャンプがセットアップとオリエンテーションから、再利用可能なSolanaプログラム設計へと移行します。

## 学習内容

- ステートフルなプログラム設計
- エスクローと権限パターン
- トークンのミントとスワップの仕組み
- リリース前のセキュリティレビューの習慣

## このトラックの使い方

- まずエピソードを視聴してください。
- コンパニオンページを使用して、メモやチェックポイントを記録してください。
- 概念は互いに積み上げられているため、次のレッスンに進む前に各レッスンを必ず完了してください。
