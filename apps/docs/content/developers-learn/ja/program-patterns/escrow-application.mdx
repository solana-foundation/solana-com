---
title: エスクローアプリケーション
description:
  Implement an escrow flow with explicit state transitions, authorities, and
  release conditions.
---

## プロジェクトの目標

明確な所有権とリリースルールを持つエスクローのインタラクションをモデル化する。

## チェックポイント

- コードを書く前に、すべてのエスクロー状態遷移をリストアップする。
- 作成、承認、キャンセル、決済アクションの権限モデルを検証する。
- 各ステップのPDA導出と署名者の要件を確認する。
