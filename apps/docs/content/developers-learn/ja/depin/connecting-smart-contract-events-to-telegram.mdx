---
title: スマートコントラクトイベントをTelegramに接続する
description:
  Route smart contract events into Telegram so operators or devices can react in
  real time.
---

## レッスンの目標

スマートコントラクトのアクティビティをアプリ外でも活用できる通知ブリッジを構築する。

## チェックポイント

- Telegramメッセージを生成すべきイベントを特定する。
- 各メッセージが実用的であるために必要なコンテキストを決定する。
- レート制限、配信の失敗、およびオペレーターのノイズについて検討する。
