  Link the device to Solana so it can read chain data and participate in onchain
  flows.
---

## レッスンの目標

Raspberry PiをデータおよびトランザクションフローにつなぎこみSolanaに接続された実際のデバイスにします。

## チェックポイント

- PiがSolanaネットワークおよび必要なサービスに到達できることを確認する。
- デバイスが消費しているデータまたはイベントを理解する。
- デバイスの信頼性が最も重要となる箇所を把握する。
