「出荷と本番運用」では、ブートキャンプで構築したものを、実際のリリース計画に近い形へと発展させます。

## 学習内容

- 読み取りモデルとインデックス設計
- 本番環境チェックリストとモニタリング
- リリース前の運用準備

## このトラックの活用方法

- まずエピソードを視聴してください。
- これまで見落としがちだった運用上の前提条件を洗い出しましょう。
- 学んだ内容を、自分のプロジェクト向けのリリースチェックリストに落とし込みましょう。
