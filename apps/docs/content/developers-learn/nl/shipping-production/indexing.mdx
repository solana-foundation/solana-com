  Add indexing so product surfaces can query and present onchain data reliably.

## Lesdoel

Ontwerp de leeslaag die ruwe onchain-data omzet in iets wat producten snel en betrouwbaar kunnen gebruiken.

## Controlepunten

- Bepaal welke weergaven vanuit geïndexeerde data moeten worden aangeboden.
- Beslis hoe actualiteit en consistentie moeten worden beheerd.
- Noem de foutscenario's die de gebruikersinterface van een product misleidend zouden maken.
