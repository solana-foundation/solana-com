  Move from fundamentals into reusable onchain patterns for state, escrow, token

Programmapatronen is waar de bootcamp verschuift van installatie en oriëntatie naar
herhaalbaar Solana-programmaontwerp.

## Wat Je Gaat Leren

- Ontwerp van stateful programma's
- Escrow- en autoriteitspatronen
- Token mint- en swapprincipes
- Beveiligingsreview gewoonten voor het uitrollen

## Hoe Gebruik Je Dit Traject

- Bekijk eerst de aflevering.
- Gebruik de begeleidende pagina om notities en controlepunten bij te houden.
- Rond elke les af voordat je doorgaat naar de volgende, omdat de concepten voortbouwen op
  elkaar.
