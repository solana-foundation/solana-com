  behavior.

## Projectdoel

Leer hoe swapregels, liquiditeit en prijsaannames het gedrag van het protocol beïnvloeden.

## Controlepunten

- Identificeer de pool-invarianten die altijd van toepassing moeten zijn.
- Volg het swappad van gebruikersinvoer tot bijgewerkte saldi.
- Controleer hoe kosten en slippage zichtbaar worden gemaakt in zowel de code als de gebruikersinterface.
