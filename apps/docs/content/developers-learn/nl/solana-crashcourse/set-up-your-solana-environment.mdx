## Lesdoel

Zorg voor een betrouwbare lokale omgeving zodat je van het kijken van video's kunt overstappen naar het daadwerkelijk bouwen op Solana.

## Controlepunten

- Installeer de kern-CLI en ondersteunende ontwikkeltools.
- Bevestig dat je machine de verwachte lokale workflow kan uitvoeren.
- Noteer eventuele installatieproblemen die je moet oplossen voordat je verdergaat.
