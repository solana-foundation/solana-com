## Tujuan proyek

Hubungkan mekanisme transfer pribadi ke alur aplikasi yang menghadap pengguna.

## Pos pemeriksaan

- Cantumkan tindakan pengguna dan operasi onchain di baliknya.
- Catat di mana asumsi privasi berpengaruh pada alur UI dan backend.
- Verifikasi bagaimana Anda akan menjelaskan kondisi kegagalan kepada pengguna.
