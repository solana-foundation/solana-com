---
title: Aplikasi Escrow
description:
  Implement an escrow flow with explicit state transitions, authorities, and
  release conditions.
---

## Tujuan proyek

Modelkan interaksi escrow dengan aturan kepemilikan dan pelepasan yang jelas.

## Pos pemeriksaan

- Daftarkan setiap transisi status escrow sebelum menulis kode.
- Verifikasi model otoritas untuk tindakan buat, terima, batalkan, dan selesaikan.
- Konfirmasi derivasi PDA dan ekspektasi penanda tangan untuk setiap langkah.
