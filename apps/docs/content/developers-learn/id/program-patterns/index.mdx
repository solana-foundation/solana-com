title: Pola Program
description:
  Move from fundamentals into reusable onchain patterns for state, escrow, token
  flows, swaps, and security review.
---

Pola Program adalah bagian di mana bootcamp beralih dari pengaturan dan orientasi ke
desain program Solana yang dapat diulang.

## Apa yang Akan Dibahas

- Desain program stateful
- Pola escrow dan otoritas
- Mekanisme mint dan swap token
- Kebiasaan tinjauan keamanan sebelum diluncurkan

## Cara Menggunakan Track Ini

- Tonton episode terlebih dahulu.
- Gunakan halaman pendamping untuk mencatat dan menandai checkpoint.
- Selesaikan setiap pelajaran sebelum beralih ke pelajaran berikutnya karena konsep-konsepnya saling
  berkaitan.
