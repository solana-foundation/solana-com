  A hardware-focused course for builders connecting Raspberry Pi projects, AI

DePIN est un cours autonome destiné aux développeurs qui souhaitent connecter du matériel, des automatisations et des événements onchain. Il commence par la configuration du Raspberry Pi, puis aborde les flux de périphériques connectés à Solana, les webhooks et les modèles de notification dans le monde réel.

## Ce que vous allez apprendre

- Configuration du Raspberry Pi et provisionnement sans interface graphique
- Flux matériels connectés à Solana
- Webhooks, surveillance des transactions et automatisations pilotées par les événements
- Idées de produits comme les appareils connectés et les alertes Telegram

## Comment utiliser ce cours

- Regardez les épisodes dans l'ordre si vous débutez avec la configuration matérielle.
- Utilisez les pages complémentaires pour noter les informations sur l'appareil, le réseau et les webhooks.
- Revenez aux leçons individuelles ultérieurement lorsque vous avez besoin d'une référence pour un projet.
