  Move from fundamentals into reusable onchain patterns for state, escrow, token
  flows, swaps, and security review.

Les Modèles de programmes marquent le moment où le bootcamp passe de la configuration et de l'orientation à la conception répétable de programmes Solana.

## Ce que vous allez apprendre

- Conception de programmes avec état
- Modèles d'entiercement et d'autorité
- Mécanique de création et d'échange de tokens
- Bonnes pratiques de revue de sécurité avant le déploiement

## Comment utiliser cette piste

- Regardez d'abord l'épisode.
- Utilisez la page complémentaire pour prendre des notes et valider les points de contrôle.
- Terminez chaque leçon avant de passer à la suivante, car les concepts s'appuient les uns sur les autres.
