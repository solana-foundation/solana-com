## Objectif du projet

Créer un projet Solana minimal de type hello-world et l'exécuter avec succès.

## Étapes clés

1. Initialiser la structure du projet.
2. Implémenter l'instruction utile la plus simple.
3. Exécuter l'instruction et inspecter le résultat.
4. Vérifier les changements d'état attendus.

## Réutilisation depuis le démarrage rapide : lecture de l'état d'un compte

Avant de passer à des projets plus importants, réutilisez le workflow exact de lecture de compte depuis
[`/docs/intro/quick-start/reading-from-network`](/docs/intro/quick-start/reading-from-network).

Utilisez le résultat de cette procédure pour valider ces principes fondamentaux :

- `executable` est `false` pour les comptes portefeuille.
- `owner` est le System Program pour les comptes portefeuille.
- `lamports` reflète le solde financé.
- `space` est `0` pour les portefeuilles système sans données personnalisées.

## Vérification

- Le programme s'exécute sans erreurs d'exécution.
- La confirmation de la transaction est réussie.
- La sortie/l'état attendu est visible dans les journaux ou les données du compte.
