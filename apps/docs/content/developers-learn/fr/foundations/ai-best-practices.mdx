  Use AI effectively while keeping correctness, safety, and reproducibility in
  blockchain workflows.
---

## Pratiques essentielles

- Traitez le résultat de l'IA comme une ébauche, pas comme une source de vérité.
- Validez manuellement toutes les contraintes de compte et les vérifications d'autorité.
- Reproduisez les chemins de code générés avec des tests avant la mise en production.
- Conservez les invites et les sorties dans un système de contrôle de version pour la révision en équipe.

## Flux de travail pratique

1. Demandez à l'IA une modification de code ciblée et testable.
2. Exécutez les vérifications statiques et les tests.
3. Comparez la logique générée avec la documentation du protocole.
4. Itérez en intégrant des cas d'échec explicites.
