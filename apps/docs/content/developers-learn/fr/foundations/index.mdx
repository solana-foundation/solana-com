Fondamentaux ouvre le bootcamp avec le contexte dont vous avez besoin avant les constructions de produits et de protocoles plus importantes.

## Ce que vous allez couvrir

- La structure du bootcamp et comment utiliser ces guides d'accompagnement
- Comprendre le modèle mental de Solana
- Configurer la chaîne d'outils de développement locale
- Démarrer depuis `create-solana-dapp`
- Construire avec l'IA tout en vérifiant les détails critiques de la blockchain

## Comment utiliser cette piste

- Regardez d'abord chaque épisode.
- Utilisez la page d'accompagnement pour les notes, les points de contrôle et les liens.
- Marquez une leçon comme terminée localement avant de passer à la piste suivante.
