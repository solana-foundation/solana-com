title: Applicazione Escrow
description:
  Implement an escrow flow with explicit state transitions, authorities, and
  release conditions.
---

## Obiettivo del progetto

Modellare un'interazione escrow con regole chiare di proprietà e rilascio.

## Checkpoint

- Elenca tutte le transizioni di stato dell'escrow prima di scrivere il codice.
- Verifica il modello di autorità per le azioni di creazione, accettazione, annullamento e liquidazione.
- Conferma le derivazioni PDA e le aspettative del firmatario per ogni passaggio.
