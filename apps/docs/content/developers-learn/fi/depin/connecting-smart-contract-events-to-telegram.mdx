---
title: Älysopimustapahtumien yhdistäminen Telegramiin
description:
  Route smart contract events into Telegram so operators or devices can react in
  real time.
---

## Oppitunnin tavoite

Rakenna ilmoitussilta, joka tekee älysopimusaktiviteetista hyödyllistä sovelluksen ulkopuolella.

## Tarkistuspisteet

- Tunnista, mitkä tapahtumat pitäisi tuottaa Telegram-viestejä.
- Päätä, mitä kontekstia kukin viesti tarvitsee ollakseen toimintakelpoinen.
- Mieti nopeusrajoituksia, toimitusvirheitä ja operaattorimelua.
