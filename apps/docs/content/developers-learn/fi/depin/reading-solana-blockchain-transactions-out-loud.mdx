---
title: Solana-lohkoketjun transaktioiden lukeminen ääneen
description:
  Turn live transaction data into a hardware-driven output flow that speaks
  updates aloud.
---

## Oppitunnin tavoite

Tutustu leikkisään mutta konkreettiseen esimerkkiin lohkoketjuaktiviteetin muuntamisesta fyysiseksi tai kuultavaksi tulosteeksi.

## Tarkistuspisteet

- Tunnista, mitkä transaktiodatasta ovat hyödyllisimpiä nostaa esiin.
- Päätä, miten laite muuntaa datan puheeksi.
- Mieti, miten käsittelisit meluisan tai toistuvan tapahtuman.
