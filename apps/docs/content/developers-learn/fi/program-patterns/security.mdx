## Katsauksen tavoite

Muuta bootcamp-mallit, joita olet jo käyttänyt, toistettavaksi tietoturvatarkistuslistaksi.

## Tarkistuspisteet

- Tarkista tilirajaukset ja allekirjoittajaolettamukset.
- Etsi puuttuvia valtuutustarkistuksia ja odottamattomia tilasiirtymiä.
- Tallenna vähintään yksi invariantti, jonka haluat testien valvovan jatkossa.
