  Start with the bootcamp structure, learn the Solana mental model, set up the

Perusteet-osio avaa bootcampin tarjoamalla tarvittavan kontekstin ennen laajempia
tuote- ja protokollarakennuksia.

## Mitä käydään läpi

- Bootcampin rakenne ja näiden oppaisiin tutustuminen
- Solana-ajattelumallin ymmärtäminen
- Paikallisen kehitysympäristön käyttöönotto
- Aloittaminen `create-solana-dapp`-komennolla
- Rakentaminen tekoälyn avulla samalla kun varmennetaan lohkoketjun kriittiset tiedot

## Kuinka käyttää tätä polkua

- Katso jokainen jakso ensin.
- Käytä oheissivua muistiinpanoihin, tarkistuspisteisiin ja linkkeihin.
- Merkitse oppitunti paikallisesti valmiiksi ennen seuraavalle polulle siirtymistä.
