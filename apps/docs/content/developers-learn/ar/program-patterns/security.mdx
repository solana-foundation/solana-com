## هدف المراجعة

حوّل أنماط معسكر التدريب التي استخدمتها بالفعل إلى قائمة تحقق أمنية قابلة للتكرار.

## نقاط التحقق

- راجع قيود الحساب وافتراضات الموقّع.
- ابحث عن فحوصات الصلاحية المفقودة وانتقالات الحالة غير المتوقعة.
- التقط ثابتًا واحدًا على الأقل تريد أن تفرضه الاختبارات فيما بعد.
