## هدف المشروع

نمذجة تفاعل الضمان مع قواعد واضحة للملكية والإفراج.

## نقاط التحقق

- قم بإدراج كل انتقالات حالة الضمان قبل كتابة الكود.
- تحقق من نموذج الصلاحية لإجراءات الإنشاء والقبول والإلغاء والتسوية.
- تأكد من اشتقاقات PDA وتوقعات الموقّع لكل خطوة.
