## هدف المشروع

بناء تدفق تصويت يجعل تغييرات الحالة سهلة الفهم والتتبع.

## نقاط التفتيش

- تحديد حالة الاقتراح والتصويت بوضوح.
- تحديد الحسابات التي تحتاج إلى أن تكون قابلة للتعديل وسبب ذلك.
- اختبار المسار الصحيح ومحاولات التصويت المكررة أو غير الصالحة.
