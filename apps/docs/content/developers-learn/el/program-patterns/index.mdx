  Move from fundamentals into reusable onchain patterns for state, escrow, token
  flows, swaps, and security review.

Τα Πρότυπα Προγράμματος είναι το σημείο όπου το bootcamp μεταβαίνει από τη ρύθμιση και τον προσανατολισμό στον
επαναλαμβανόμενο σχεδιασμό προγραμμάτων Solana.

## Τι Θα Καλύψετε

- Σχεδιασμός προγράμματος με κατάσταση
- Πρότυπα escrow και εξουσιοδότησης
- Μηχανισμοί δημιουργίας και ανταλλαγής token
- Συνήθειες ελέγχου ασφαλείας πριν από την κυκλοφορία

## Πώς Να Χρησιμοποιήσετε Αυτό το Track

- Παρακολουθήστε πρώτα το επεισόδιο.
- Χρησιμοποιήστε τη συνοδευτική σελίδα για να καταγράψετε σημειώσεις και σημεία ελέγχου.
- Ολοκληρώστε κάθε μάθημα πριν προχωρήσετε στο επόμενο, καθώς οι έννοιες βασίζονται
  η μία στην άλλη.
