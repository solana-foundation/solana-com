## Στόχος έργου

Κατανοήστε πώς η δημιουργία token, η εξουσία κοπής και οι κανόνες μεταφοράς διαμορφώνουν τη συμπεριφορά του προϊόντος.

## Σημεία ελέγχου

- Καταγράψτε ποιος ελέγχει την κοπή και ποιος μπορεί να εναλλάξει αυτή την εξουσία.
- Επιβεβαιώστε πώς πρέπει να επικυρώνονται τα υπόλοιπα, η προσφορά και τα μεταδεδομένα.
- Δοκιμάστε τόσο τις κανονικές ροές κοπής όσο και τις οριακές περιπτώσεις εξουσίας.
