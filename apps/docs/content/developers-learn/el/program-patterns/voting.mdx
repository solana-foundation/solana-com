## Στόχος του έργου

Δημιουργήστε μια ροή ψηφοφορίας που κάνει τις αλλαγές κατάστασης εύκολες στην κατανόηση.

## Σημεία ελέγχου

- Ορίστε με σαφήνεια την πρόταση και την κατάσταση ψηφοφορίας.
- Προσδιορίστε ποιοι λογαριασμοί πρέπει να είναι μεταβλητοί και γιατί.
- Δοκιμάστε τόσο την κανονική διαδρομή όσο και τις διπλές ή μη έγκυρες απόπειρες ψήφου.
