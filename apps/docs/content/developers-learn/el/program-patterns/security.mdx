## Στόχος ανασκόπησης

Μετατρέψτε τα πρότυπα του bootcamp που έχετε ήδη χρησιμοποιήσει σε μια επαναλαμβανόμενη λίστα ελέγχου ασφαλείας.

## Σημεία ελέγχου

- Ελέγξτε τους περιορισμούς λογαριασμού και τις παραδοχές υπογράφοντα.
- Αναζητήστε ελλείποντες ελέγχους εξουσιοδότησης και απροσδόκητες μεταβάσεις κατάστασης.
- Καταγράψτε τουλάχιστον ένα αμετάβλητο που θέλετε οι δοκιμές να επιβάλλουν στο εξής.
