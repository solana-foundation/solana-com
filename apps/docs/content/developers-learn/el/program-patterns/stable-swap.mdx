## Στόχος έργου

Μάθετε πώς οι κανόνες ανταλλαγής, η ρευστότητα και οι παραδοχές τιμολόγησης επηρεάζουν τη συμπεριφορά του πρωτοκόλλου.

## Σημεία ελέγχου

- Εντοπίστε τις αναλλοίωτες ποσότητες της δεξαμενής που πρέπει να ισχύουν πάντα.
- Ακολουθήστε τη διαδρομή ανταλλαγής από την είσοδο του χρήστη έως τα ενημερωμένα υπόλοιπα.
- Επαληθεύστε πώς τα τέλη και η ολίσθηση τιμής αποτυπώνονται τόσο στον κώδικα όσο και στο περιβάλλον χρήστη.
