## Στόχος έργου

Μοντελοποίηση μιας αλληλεπίδρασης θεματοφυλακής με σαφείς κανόνες ιδιοκτησίας και αποδέσμευσης.

## Σημεία ελέγχου

- Καταγράψτε κάθε μετάβαση κατάστασης θεματοφυλακής πριν γράψετε κώδικα.
- Επαληθεύστε το μοντέλο εξουσιοδότησης για τις ενέργειες δημιουργίας, αποδοχής, ακύρωσης και διακανονισμού.
- Επιβεβαιώστε τις παραγωγές PDA και τις προσδοκίες υπογράφοντος για κάθε βήμα.
