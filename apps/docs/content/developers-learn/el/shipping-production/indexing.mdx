## Στόχος μαθήματος

Σχεδιάστε το επίπεδο ανάγνωσης που μετατρέπει τα ακατέργαστα δεδομένα onchain σε κάτι που τα προϊόντα μπορούν
να χρησιμοποιούν γρήγορα και αξιόπιστα.

## Σημεία ελέγχου

- Προσδιορίστε ποιες προβολές θα πρέπει να εξυπηρετούνται από ευρετηριασμένα δεδομένα.
- Αποφασίστε πώς θα πρέπει να διαχειρίζεται η επικαιρότητα και η συνέπεια.
- Απαριθμήστε τις αποτυχίες που θα μπορούσαν να κάνουν το UI ενός προϊόντος παραπλανητικό.
