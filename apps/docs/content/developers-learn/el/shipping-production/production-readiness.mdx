## Στόχος μαθήματος

Μετατρέψτε τα μαθήματα από το bootcamp σε μια συγκεκριμένη λίστα ελέγχου εκκίνησης.

## Σημεία ελέγχου

- Επανεξετάστε τις προσδοκίες για ανάπτυξη, επαναφορά και παρακολούθηση.
- Επιβεβαιώστε ποιοι έλεγχοι ασφαλείας πρέπει να αποκλείουν μια κυκλοφορία.
- Ορίστε τι πρέπει να τεκμηριωθεί πριν παραδοθεί το έργο σε μια ομάδα.
