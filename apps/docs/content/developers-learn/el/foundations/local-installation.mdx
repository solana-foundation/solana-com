## Τι θα δημιουργήσετε

Ένα τοπικό περιβάλλον ανάπτυξης με όλα τα απαραίτητα εργαλεία για την εκτέλεση παραδειγμάτων και
την ανάπτυξη στο devnet.

## Λίστα ελέγχου ρύθμισης

- Εγκαταστήστε το Rust και το Solana CLI.
- Εγκαταστήστε το Node.js και τον διαχειριστή πακέτων σας.
- Επιβεβαιώστε τις εκδόσεις CLI και τη ρύθμιση του πορτοφολιού.
- Εκτελέστε μια βασική εντολή για να επαληθεύσετε το περιβάλλον σας.

## Κριτήρια ολοκλήρωσης

Μπορείτε να εκτελείτε εντολές εργαλείων τοπικά χωρίς σφάλματα περιβάλλοντος.
