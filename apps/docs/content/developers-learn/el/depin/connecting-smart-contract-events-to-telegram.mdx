## Στόχος μαθήματος

Δημιουργήστε μια γέφυρα ειδοποιήσεων που κάνει τη δραστηριότητα του έξυπνου συμβολαίου χρήσιμη εκτός
της ίδιας της εφαρμογής.

## Σημεία ελέγχου

- Προσδιορίστε ποια συμβάντα πρέπει να δημιουργούν μηνύματα Telegram.
- Αποφασίστε τι πλαίσιο χρειάζεται κάθε μήνυμα για να είναι εφαρμόσιμο.
- Σκεφτείτε τα όρια ρυθμού, τις αποτυχίες παράδοσης και τον θόρυβο του χειριστή.
