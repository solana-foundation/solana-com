## Στόχος μαθήματος

Συνδέστε τη συσκευή στο διαδίκτυο γρήγορα, ώστε να μπορεί να διαχειριστεί εξ αποστάσεως και να προετοιμαστεί για τα μαθήματα που ακολουθούν και σχετίζονται με το Solana.

## Σημεία ελέγχου

- Ρυθμίστε το Pi χωρίς να χρειαστείτε οθόνη και πληκτρολόγιο.
- Επαληθεύστε ότι η συσκευή συνδέεται επιτυχώς στο δίκτυό σας.
- Καταγράψτε τα στοιχεία σύνδεσης που θα χρειαστείτε αργότερα.
