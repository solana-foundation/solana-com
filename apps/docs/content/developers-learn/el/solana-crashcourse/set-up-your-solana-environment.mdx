## Στόχος μαθήματος

Δημιουργήστε ένα αξιόπιστο τοπικό περιβάλλον ώστε να μπορείτε να περάσετε από την παρακολούθηση βίντεο στην
πραγματική ανάπτυξη στο Solana.

## Σημεία ελέγχου

- Εγκαταστήστε το βασικό CLI και τα υποστηρικτικά εργαλεία ανάπτυξης.
- Επιβεβαιώστε ότι το μηχάνημά σας μπορεί να εκτελέσει την αναμενόμενη τοπική ροή εργασίας.
- Εντοπίστε τυχόν προβλήματα εγκατάστασης που χρειάζεται να διορθώσετε πριν συνεχίσετε.
