## Στόχος μαθήματος

Κατανοήστε τα βασικά στάδια της πορείας ενός προγραμματιστή Solana, ώστε να γνωρίζετε τι να
μάθετε πρώτα και τι μπορεί να περιμένει για αργότερα.

## Σημεία ελέγχου

- Εντοπίστε τα βασικά θέματα που χρειάζεστε πριν ξεκινήσετε να κατασκευάζετε.
- Σημειώστε ποια εργαλεία και πλαίσια εμφανίζονται αργότερα στον οδικό χάρτη.
- Αποφασίστε ποιο βαθύτερο μονοπάτι θέλετε να ακολουθήσετε μετά από αυτό το εντατικό μάθημα.
