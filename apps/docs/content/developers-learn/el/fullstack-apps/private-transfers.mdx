## Στόχος έργου

Σύνδεση μηχανισμών ιδιωτικής μεταφοράς με μια ροή εφαρμογής προσανατολισμένη στον χρήστη.

## Σημεία ελέγχου

- Καταγράψτε τις ενέργειες του χρήστη και τις αντίστοιχες λειτουργίες στο blockchain.
- Σημειώστε πού έχουν σημασία οι παραδοχές απορρήτου στη ροή UI και backend.
- Επαληθεύστε πώς θα εξηγείτε τις καταστάσεις αποτυχίας στους χρήστες.
