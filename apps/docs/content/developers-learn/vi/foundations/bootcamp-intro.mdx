## Bài học này bao gồm những gì

- Cách cấu trúc bootcamp bốn track
- Mục đích của từng trang companion
- Cách di chuyển giữa video, ghi chú, code và các checkpoint

## Trước khi bạn tiếp tục

- Đánh dấu trang repo bootcamp và thanh bên bài học.
- Quyết định cách bạn sẽ theo dõi ghi chú, thay đổi code và câu hỏi.
- Lên kế hoạch hoàn thành các bài học theo thứ tự để các track sau có thể xây dựng trên nền tảng của các track trước.
