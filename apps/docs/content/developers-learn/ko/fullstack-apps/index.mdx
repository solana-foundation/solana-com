풀스택 애플리케이션은 프로토콜 패턴에서 사용자 대면 제품으로 나아갑니다.

## 학습 내용

- 온체인 액션을 위한 애플리케이션 UX
- 제품 중심의 통합 패턴
- 동일한 부트캠프 스택을 기반으로 한 수직적 사용 사례
- 클라이언트와 프로그램 레이어 전반에 걸친 엔드투엔드 추론

## 이 트랙 활용 방법

- 먼저 에피소드를 시청하세요.
- 프로그램 동작과 제품 표면 모두에 대해 메모를 남기세요.
- 각 빌드를 이전 트랙의 패턴과 비교하세요.
