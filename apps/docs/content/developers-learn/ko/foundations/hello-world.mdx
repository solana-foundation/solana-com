## 프로젝트 목표

최소한의 hello-world 스타일 Solana 프로젝트를 구성하고 성공적으로 실행합니다.

## 마일스톤

1. 프로젝트 구조를 초기화합니다.
2. 가장 작은 유용한 명령어를 구현합니다.
3. 명령어를 실행하고 결과를 확인합니다.
4. 예상된 상태 변경 사항을 검증합니다.

## 빠른 시작에서 재사용: 계정 상태 읽기

더 큰 프로젝트로 넘어가기 전에, 
[`/docs/intro/quick-start/reading-from-network`](/docs/intro/quick-start/reading-from-network)의 정확한 계정 읽기 워크플로를 재사용하세요.

해당 연습의 결과를 사용하여 다음 기본 사항을 검증하세요:

- 지갑 계정의 경우 `executable`은 `false`입니다.
- 지갑 계정의 경우 `owner`는 System Program입니다.
- `lamports`는 충전된 잔액을 반영합니다.
- 커스텀 데이터가 없는 시스템 지갑의 경우 `space`는 `0`입니다.

## 검증

- 프로그램이 런타임 오류 없이 실행됩니다.
- 트랜잭션 확인이 성공적으로 완료됩니다.
- 예상 출력/상태가 로그 또는 계정 데이터에서 확인됩니다.
