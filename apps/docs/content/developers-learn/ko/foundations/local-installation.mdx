## 빌드할 내용

예제 실행 및 devnet 배포에 필요한 모든 도구를 갖춘 로컬 개발자 환경입니다.

## 설정 체크리스트

- Rust와 Solana CLI를 설치합니다.
- Node.js와 패키지 매니저를 설치합니다.
- CLI 버전과 지갑 구성을 확인합니다.
- 기본 명령어를 실행하여 환경을 검증합니다.

## 완료 기준

환경 오류 없이 로컬에서 툴링 명령어를 실행할 수 있습니다.
