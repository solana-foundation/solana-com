## 학습 내용

- 애플리케이션 개발자가 사용하는 핵심 블록체인 기본 요소
- Solana에서 계정, 트랜잭션, 프로그램 실행이 어떻게 다른지 이해합니다.
- 처리량, 수수료, 병렬 실행이 제품 설계에 중요한 이유

## 빌드 체크리스트

- 첫 번째 앱의 상태 모델을 일반 언어로 정의합니다.
- 어떤 데이터를 온체인에 저장하고 어떤 데이터를 오프체인에 저장할지 파악합니다.
- 나중에 validator할 성능 가정과 보안 가정을 각각 하나씩 작성합니다.
