## 레슨 목표

원시 온체인 데이터를 제품이 빠르고 안정적으로 활용할 수 있는 형태로 변환하는 읽기 레이어를 설계합니다.

## 체크포인트

- 인덱싱된 데이터에서 제공해야 할 뷰를 식별합니다.
- 데이터 최신성과 일관성을 처리하는 방법을 결정합니다.
- 제품 UI를 오해하게 만들 수 있는 장애 유형을 나열합니다.
