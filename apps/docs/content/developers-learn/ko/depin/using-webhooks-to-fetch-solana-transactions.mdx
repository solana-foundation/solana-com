## 학습 목표

기기나 앱이 지속적인 수동 폴링 없이 Solana 활동에 반응할 수 있도록 더 효율적인 이벤트 파이프라인을 설정합니다.

## 체크포인트

- 워크플로우에 중요한 웹훅 이벤트가 무엇인지 파악합니다.
- 수신 서비스가 이벤트를 어떻게 validator하고 처리해야 하는지 확인합니다.
- 웹훅 전송이 실패하거나 지연될 경우 어떻게 처리할지 결정합니다.
