## 학습 목표

이후 이어지는 Solana 연동 강의를 위해 기기를 원격으로 관리할 수 있도록 빠르게 네트워크에 연결합니다.

## 체크포인트

- 모니터와 키보드 없이 Pi를 구성합니다.
- 기기가 네트워크에 성공적으로 연결되었는지 확인합니다.
- 이후 필요한 연결 정보를 기록해 둡니다.
