## 학습 목표

스마트 컨트랙트 활동을 앱 외부에서도 유용하게 활용할 수 있는 알림 브리지를 구축합니다.

## 체크포인트

- Telegram 메시지를 생성해야 할 이벤트를 식별합니다.
- 각 메시지가 실행 가능하려면 어떤 컨텍스트가 필요한지 결정합니다.
- 속도 제한, 전송 실패, 운영자 노이즈에 대해 고려합니다.
