프로그램 패턴은 부트캠프가 설정 및 오리엔테이션에서 반복 가능한 Solana 프로그램 설계로 전환되는 단계입니다.

## 학습 내용

- 상태 기반 프로그램 설계
- 에스크로 및 권한 패턴
- 토큰 발행 및 스왑 메커니즘
- 배포 전 보안 검토 습관

## 이 트랙 활용 방법

- 먼저 에피소드를 시청하세요.
- 보조 페이지를 활용하여 노트와 체크포인트를 기록하세요.
- 개념들이 서로 연결되어 있으므로, 다음 레슨으로 넘어가기 전에 각 레슨을 완료하세요.
