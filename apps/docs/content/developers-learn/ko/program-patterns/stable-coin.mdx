## 프로젝트 목표

토큰 생성, 발행 권한, 전송 규칙이 제품 동작에 어떤 영향을 미치는지 이해합니다.

## 체크포인트

- 발행을 제어하는 주체와 해당 권한을 교체할 수 있는 주체를 기록합니다.
- 잔액, 공급량, 메타데이터의 유효성 검사 방법을 확인합니다.
- 일반적인 발행 흐름과 권한 엣지 케이스를 모두 테스트합니다.
