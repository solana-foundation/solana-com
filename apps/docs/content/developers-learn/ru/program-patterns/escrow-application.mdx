## Цель проекта

Смоделируйте эскроу-взаимодействие с чёткими правилами владения и высвобождения средств.

## Контрольные точки

- Перечислите все переходы состояний эскроу перед написанием кода.
- Проверьте модель полномочий для действий создания, принятия, отмены и урегулирования.
- Подтвердите вывод PDA и ожидания подписантов для каждого шага.
