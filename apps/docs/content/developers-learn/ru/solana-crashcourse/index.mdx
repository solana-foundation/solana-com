Экспресс-курс по Solana — это облегчённый курс, созданный для максимально быстрого пути от
знакомства с платформой до работающего приложения. По мере завершения редактирования сюда могут добавляться новые уроки.

## Что вы изучите

- Дорожная карта разработчика Solana
- Настройка рабочей локальной среды разработки
- Быстрый первый цикл сборки и деплоя

## Как использовать этот курс

- Смотрите эпизоды по порядку.
- Используйте сопроводительные страницы для заметок и дополнительных ссылок.
- Возвращайтесь к полному буткемпу, когда захотите пройти более углублённый четырёхмодульный путь.
