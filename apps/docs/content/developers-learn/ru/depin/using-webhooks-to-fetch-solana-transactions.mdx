## Цель урока

Настройте более чистый конвейер событий, чтобы устройство или приложение реагировало на активность в Solana без постоянного ручного опроса.

## Контрольные точки

- Определите, какие события вебхука важны для вашего процесса.
- Обратите внимание на то, как принимающий сервис должен проверять и обрабатывать их.
- Решите, что должно происходить при сбое или задержке доставки вебхука.
