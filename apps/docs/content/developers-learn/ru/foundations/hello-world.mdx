## Цель проекта

Создать минимальный проект Solana в стиле hello-world и успешно его запустить.

## Этапы

1. Инициализировать структуру проекта.
2. Реализовать минимальную полезную инструкцию.
3. Выполнить инструкцию и проверить результат.
4. Убедиться в ожидаемых изменениях состояния.

## Повторное использование из быстрого старта: чтение состояния аккаунта

Перед переходом к более крупным проектам повторно используйте процесс чтения аккаунта из
[`/docs/intro/quick-start/reading-from-network`](/docs/intro/quick-start/reading-from-network).

Используйте результат этого руководства для проверки следующих основ:

- `executable` равно `false` для аккаунтов кошельков.
- `owner` — это System Program для аккаунтов кошельков.
- `lamports` отражает пополненный баланс.
- `space` равно `0` для системных кошельков без пользовательских данных.

## Проверка

- Программа выполняется без ошибок времени выполнения.
- Подтверждение транзакции прошло успешно.
- Ожидаемый вывод/состояние отображается в логах или данных аккаунта.
