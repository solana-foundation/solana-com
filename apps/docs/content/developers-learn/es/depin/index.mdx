---
title: DePIN
description:
  A hardware-focused course for builders connecting Raspberry Pi projects, AI
  workflows, and Solana data to real-world devices.
---

DePIN es un curso independiente para desarrolladores que desean conectar hardware, automatización y eventos onchain. Comienza con la configuración de Raspberry Pi, luego avanza hacia flujos de dispositivos conectados a Solana, webhooks y patrones de notificación del mundo real.

## Qué Aprenderás

- Configuración de Raspberry Pi y aprovisionamiento headless
- Flujos de hardware conectados a Solana
- Webhooks, monitoreo de transacciones y automatizaciones basadas en eventos
- Ideas de productos como dispositivos conectados y alertas de Telegram

## Cómo Usar Este Curso

- Mira los episodios en orden si eres nuevo en la configuración de hardware.
- Usa las páginas complementarias para registrar notas sobre dispositivos, redes y webhooks.
- Vuelve a lecciones individuales más adelante cuando necesites una referencia para un proyecto.
