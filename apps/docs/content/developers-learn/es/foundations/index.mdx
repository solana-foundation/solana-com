Fundamentos abre el bootcamp con el contexto que necesitas antes de las construcciones más amplias de producto y protocolo.

## Qué Aprenderás

- Cómo está estructurado el bootcamp y cómo usar estas guías complementarias
- Comprender el modelo mental de Solana
- Configurar la cadena de herramientas local para desarrolladores
- Comenzar desde `create-solana-dapp`
- Desarrollar con IA mientras se verifican los detalles críticos de la blockchain

## Cómo Usar Esta Ruta

- Mira cada episodio primero.
- Usa la página complementaria para notas, puntos de control y enlaces.
- Marca una lección como completada localmente antes de pasar a la siguiente ruta.
