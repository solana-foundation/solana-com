El Curso Intensivo de Solana es un curso más ligero diseñado para el camino más rápido desde la orientación hasta una aplicación funcional. Se pueden agregar más lecciones aquí a medida que terminen la edición.

## Lo Que Aprenderás

- La hoja de ruta del desarrollador de Solana
- Un entorno de desarrollo local funcional
- Un flujo rápido de primera compilación e implementación

## Cómo Usar Este Curso

- Mira los episodios en orden.
- Usa las páginas complementarias para notas y enlaces de seguimiento.
- Regresa al bootcamp completo cuando quieras la ruta más profunda de cuatro módulos.
