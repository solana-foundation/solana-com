## Projektziel

Modellieren Sie eine Escrow-Interaktion mit klaren Eigentümerschafts- und Freigaberegeln.

## Meilensteine

- Listen Sie alle Escrow-Zustandsübergänge auf, bevor Sie mit dem Programmieren beginnen.
- Überprüfen Sie das Berechtigungsmodell für die Aktionen Erstellen, Akzeptieren, Abbrechen und Abwickeln.
- Bestätigen Sie die PDA-Ableitungen und Signer-Erwartungen für jeden Schritt.
