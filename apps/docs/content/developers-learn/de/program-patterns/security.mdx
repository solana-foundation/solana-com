## Überprüfungsziel

Wandeln Sie die Bootcamp-Muster, die Sie bereits verwendet haben, in eine wiederholbare Sicherheits-Checkliste um.

## Prüfpunkte

- Konten-Einschränkungen und Signer-Annahmen überprüfen.
- Nach fehlenden Berechtigungsprüfungen und unerwarteten Zustandsübergängen suchen.
- Mindestens eine Invariante erfassen, die Tests künftig durchsetzen sollen.
