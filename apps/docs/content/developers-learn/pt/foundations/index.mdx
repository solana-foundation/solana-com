Fundamentos abre o bootcamp com o contexto necessário antes das construções maiores de produto e protocolo.

## O Que Você Vai Aprender

- Como o bootcamp é estruturado e como usar estes guias complementares
- Entender o modelo mental do Solana
- Configurar a cadeia de ferramentas de desenvolvimento local
- Começar a partir do `create-solana-dapp`
- Desenvolver com IA enquanto verifica detalhes críticos da blockchain

## Como Usar Esta Trilha

- Assista a cada episódio primeiro.
- Use a página complementar para anotações, pontos de verificação e links.
- Marque uma lição como concluída localmente antes de passar para a próxima trilha.
