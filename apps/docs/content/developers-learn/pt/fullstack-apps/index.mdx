Aplicações Fullstack avança dos padrões de protocolo para produtos voltados ao utilizador.

## O Que Você Vai Aprender

- UX de aplicações em torno de ações onchain
- Padrões de integração voltados ao produto
- Casos de uso verticais construídos sobre o mesmo stack do bootcamp
- Raciocínio de ponta a ponta entre as camadas de cliente e programa

## Como Utilizar Esta Trilha

- Assista ao episódio primeiro.
- Tome notas tanto sobre o comportamento do programa quanto sobre a superfície do produto.
- Compare cada build com os padrões da trilha anterior.
