## Objetivo do projeto

Conectar a mecânica de transferências privadas a um fluxo de aplicação voltado para o usuário.

## Pontos de verificação

- Liste as ações do usuário e as operações onchain por trás delas.
- Observe onde as premissas de privacidade importam no fluxo de UI e backend.
- Verifique como você explicará os estados de falha aos usuários.
