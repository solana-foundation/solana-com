Padrões de Programa é onde o bootcamp deixa de ser configuração e orientação para se tornar design repetível de programas Solana.

## O Que Você Vai Aprender

- Design de programas com estado
- Padrões de escrow e autoridade
- Mecânicas de mint e swap de tokens
- Hábitos de revisão de segurança antes do lançamento

## Como Usar Esta Trilha

- Assista ao episódio primeiro.
- Use a página complementar para registrar notas e checkpoints.
- Conclua cada lição antes de passar para a próxima, pois os conceitos se constroem
  uns sobre os outros.
