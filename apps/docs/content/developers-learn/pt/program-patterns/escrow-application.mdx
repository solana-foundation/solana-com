## Objetivo do projeto

Modelar uma interação de escrow com regras claras de propriedade e liberação.

## Pontos de verificação

- Liste todas as transições de estado do escrow antes de escrever o código.
- Verifique o modelo de autoridade para as ações de criação, aceitação, cancelamento e liquidação.
- Confirme as derivações de PDA e as expectativas do signatário para cada etapa.
