  A hardware-focused course for builders connecting Raspberry Pi projects, AI
  workflows, and Solana data to real-world devices.

DePIN é um curso independente para desenvolvedores que desejam conectar hardware,
automação e eventos onchain. Começa com a configuração do Raspberry Pi, depois avança
para fluxos de dispositivos conectados à Solana, webhooks e padrões de notificação do mundo real.

## O Que Você Vai Aprender

- Configuração do Raspberry Pi e provisionamento headless
- Fluxos de hardware conectados à Solana
- Webhooks, monitoramento de transações e automações orientadas a eventos
- Ideias de produtos como dispositivos conectados e alertas no Telegram

## Como Usar Este Curso

- Assista aos episódios em sequência se você é novo na configuração de hardware.
- Use as páginas complementares para registrar anotações sobre dispositivos, redes e webhooks.
- Volte a lições individuais posteriormente quando precisar de uma referência para um projeto.
