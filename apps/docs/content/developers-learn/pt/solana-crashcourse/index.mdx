O Curso Intensivo de Solana é um curso mais leve, desenvolvido para o caminho mais rápido desde a orientação até um aplicativo funcional. Mais lições podem ser adicionadas aqui à medida que a edição for concluída.

## O Que Você Vai Aprender

- O roteiro do desenvolvedor Solana
- Um ambiente de desenvolvimento local funcional
- Um fluxo rápido de primeira compilação e implantação

## Como Usar Este Curso

- Assista aos episódios em ordem.
- Use as páginas complementares para anotações e links de acompanhamento.
- Volte ao bootcamp completo quando quiser o caminho mais aprofundado, com quatro módulos.
