## Objetivo da aula

Projete a camada de leitura que transforma dados brutos onchain em algo que os produtos possam
usar de forma rápida e confiável.

## Pontos de verificação

- Identifique quais visualizações devem ser servidas a partir de dados indexados.
- Decida como a atualização e a consistência devem ser gerenciadas.
- Liste os modos de falha que tornariam a interface de um produto enganosa.
