The Solana Cookbook is a developer resource that provides examples and
references for building applications on Solana. Each example and reference will
focus on specific aspects of Solana development while providing additional
details and usage examples.

The Python examples use `solana` 0.41 and its async client (`AsyncClient`),
which needs Python 3.11 or later. Install the tested versions:

```bash Terminal
pip install solana==0.41.0 solders==0.29.0
```

The Rust examples use the 2.x Solana crates. Most need these dependencies in
`Cargo.toml` (tested with Rust 1.89 and 1.98):

```toml Cargo.toml
[dependencies]
anyhow = "1"
tokio = { version = "1", features = ["full"] }
solana-client = "2"
solana-commitment-config = "2"
solana-sdk = "2"
solana-system-interface = "1"
```

Token examples also need `spl-token-interface = "1"` or
`spl-token-2022-interface = "1"`. Add any other crate an example's `use` lines
name; for `bincode`, use version 1.
