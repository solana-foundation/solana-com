Keeping accounts alive on Solana incurs a data storage cost called
[rent](/developers/docs/core/rent). For the calculation, you need to
consider the amount of data you intend to store in the account. Rent can be
reclaimed in full if the account is closed.

<Note>
  The recorded output comes from a local Surfpool network, which still uses the
  older rate of 6,960 lamports per byte. Mainnet and devnet use 5,080 lamports
  per byte as of October 2026, so they return a lower value. See
  [rent](/developers/docs/core/rent).
</Note>
