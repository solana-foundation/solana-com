One way to generate a Keypair is through the use of a Mnemonic. Mnemonics are
generally used to make the user experience within wallets better than a Keypair
file by using a list of readable words (instead of a shorter string of random
numbers and letters).

<GenerateMnemonicMnemonic />

Each call returns a new random 12-word phrase. Anyone who has the phrase can
derive every keypair from it, so keep it secret, and never use a phrase you
found in an example, a tutorial, or a screenshot for a real wallet.
