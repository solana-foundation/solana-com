To add metadata (name, symbol, image) to a standard SPL Token, you need to use
the
[Metaplex Token Metadata Program](https://developers.metaplex.com/token-metadata).
This creates a metadata account that is linked to your token mint via a Program
Derived Address (PDA).

<Info>
  This guide covers metadata for standard SPL Tokens (Token Program) and is also
  applicable for Token-2022. If you want to use the Metadata Extension for
  Token-2022, see the [Metadata Extension
  guide](/developers/docs/tokens/extensions/metadata).
</Info>

The Kit examples use the Metaplex Token Metadata client. Install it together
with `@solana-program/token`, which the client loads but doesn't declare as a
dependency:

```shell
npm install @solana/kit @solana/kit-plugin-rpc @solana/kit-plugin-signer @metaplex-foundation/mpl-token-metadata-kit @solana-program/token
```

<Note>
  `@metaplex-foundation/mpl-token-metadata-kit` 0.0.3 is built on Kit 6. It
  runs with Kit 8, but TypeScript reports the RPC types as incompatible until
  you resolve it onto your Kit version in `package.json`, then delete
  `node_modules` and `package-lock.json` and run `npm install` again:

  ```json
  "overrides": {
    "@metaplex-foundation/mpl-token-metadata-kit": {
      "@solana/kit": "$@solana/kit",
      "@solana/program-client-core": "^8.6.0"
    }
  }
  ```
</Note>
