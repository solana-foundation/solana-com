Every token account has information on the token such as the owner, mint,
amount(balance).

<Note>
  This example reads a PYUSD token account that exists only on mainnet. Run it
  against a Surfpool local network that forks mainnet
  (`surfpool start --network mainnet` fetches the account on demand), or point
  the RPC URL at a mainnet endpoint.
</Note>
