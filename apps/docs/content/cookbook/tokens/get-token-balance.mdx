The token account holds the token balance, which can be retrieved with a single
RPC call.

<Note>
  This example reads a token account that exists only on mainnet. Run it
  against a Surfpool local network that forks mainnet
  (`surfpool start --network mainnet` fetches the account on demand), or point
  the RPC URL at a mainnet endpoint.
</Note>

<Info>
  A token account can only hold one kind of mint. When you specify a token
  account, you also specify its mint.
</Info>
