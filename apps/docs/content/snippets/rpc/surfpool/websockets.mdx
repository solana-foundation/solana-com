Real-time WebSocket subscriptions for monitoring blockchain state changes. Connect to `ws://127.0.0.1:8900` when running Surfnet. Surfnet implements `accountSubscribe`, `logsSubscribe`, `programSubscribe`, `signatureSubscribe` and `slotSubscribe`; `blockSubscribe`, `voteSubscribe` and `slotUpdatesSubscribe` are listed for completeness but are not supported. In every notification the payload is wrapped in `params.result`, next to the `subscription` id.
