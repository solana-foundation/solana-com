Administrative controls for managing the Surfnet instance and its plugins. These come from the Agave validator admin RPC, and Surfnet implements only `exit`, `listPlugins`, `startTime`, `loadPlugin`, `reloadPlugin` and `unloadPlugin`. The other Agave admin methods (for example `setIdentity` or `setLogFilter`) return `-32601 Method not found` on Surfnet and are not listed.

## exit

Immediately shuts down the RPC server.

**This stops the Surfnet process immediately and cannot be undone.** Don't run this sample against a Surfnet you want to keep.

**Result**

<ResponseField name="result" type="null">
  exit - Immediately shuts down the RPC server
</ResponseField>

```bash Request
curl http://127.0.0.1:8899 -s -X POST \
  -H "Content-Type: application/json" \
  -d '
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "exit",
    "params": []
  }
'
```

```json Response
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": null
}
```
