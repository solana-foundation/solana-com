  Avvia un agente con Pay e completa un pagamento x402 V2 su un'API sandbox locale senza spostare fondi reali.
---

Usa [Pay](https://pay.sh) per eseguire un'API x402 V2 e fornire a Claude Code un
client HTTP in grado di gestire i pagamenti. L'API, il wallet del pagatore e il regolamento utilizzano tutti la
sandbox di Solana, quindi questa guida passo passo non richiede un account né fondi reali.

Ti servono un terminale, Pay e Claude Code installati.

## 1. Installa Pay

Su macOS, installa il binario precompilato:

```bash
brew install pay
pay --version
```

Su altre piattaforme, installa il pacchetto npm:

```bash
npm install --global @solana/pay
pay --version
```

## 2. Avvia un'API sandbox x402

Crea `x402-demo.yaml`:

```yaml filename=x402-demo.yaml
name: x402-demo
subdomain: x402-demo
title: "x402 Demo"
description: "Minimal x402 V2 sandbox endpoint."
category: devtools
version: v1
routing:
  type: respond
operator:
  currencies:
    usd: ["USDC"]
  network: "localnet"
  fee_payer: true
endpoints:
  - method: GET
    path: "report"
    description: "Return a sandbox report."
    metering:
      schemes: [x402-exact]
      dimensions:
        - direction: usage
          unit: requests
          scale: 1
          tiers:
            - price_usd: 0.001
```

Avvia l'API e lasciala in esecuzione:

```bash
pay --sandbox server start x402-demo.yaml --bind 127.0.0.1:1402
```

Lo schema `x402-exact` rende questo un endpoint esclusivamente x402. La modalità sandbox crea
e finanzia automaticamente account temporanei per operatore e pagatore.

## 3. Avvia l'agente con Pay

In un altro terminale, avvia Claude Code in modalità sandbox:

```bash
pay --sandbox claude
```

Pay collega i propri strumenti MCP locali alla sessione dell'agente. L'agente non
riceve alcuna chiave privata.

## 4. Effettua una richiesta x402

Incolla questo prompt nell'agente:

```text
Use Pay to make exactly one sandbox x402 API request to
http://127.0.0.1:1402/report.

Before paying, show me the amount and ask for approval. Then return the API
result and payment receipt. Do not make any other paid requests.
```

La richiesta segue un ciclo completo di pagamento x402 V2:

1. L'API restituisce `402 Payment Required` con una richiesta `PAYMENT-REQUIRED`.
2. Pay convalida i requisiti x402 e mostra i termini di pagamento.
3. Dopo l'approvazione, il wallet sandbox firma e Pay ripete la richiesta con
   `PAYMENT-SIGNATURE`.
4. L'API restituisce il risultato con una ricevuta `PAYMENT-RESPONSE`.

Non viene spostato alcun fondo reale. Rifiutando l'approvazione, la richiesta si interrompe.

Continua con [x402 su Solana](/docs/payments/agentic-payments/x402) per creare un
client e un resource server x402 V2, oppure
[diventa un facilitator x402](/docs/tools/x402-facilitator).
