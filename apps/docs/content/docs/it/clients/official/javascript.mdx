## Solana Kit

`@solana/kit` è il TypeScript SDK consigliato per sviluppare su Solana. Puoi
assemblare un client a partire da plugin componibili, aggiungere i binding React
quando necessario e integrare i client di programma generati per i programmi
on-chain che intendi chiamare.

| Pacchetto                   | Descrizione                                  | GitHub                                                                                 |
| ------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------- |
| @solana/kit               | SDK principale: RPC, transazioni, codec, signer | [Sorgente](https://github.com/anza-xyz/kit)                                              |
| @solana/react             | Binding React: `ClientProvider` e hook   | [Sorgente](https://github.com/anza-xyz/kit/tree/main/packages/react)                     |
| @solana/kit-plugin-rpc    | Connessione RPC e invio di transazioni         | [Sorgente](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-rpc)    |
| @solana/kit-plugin-signer | Plugin per fee payer, identità e signer      | [Sorgente](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-signer) |
| @solana/kit-plugin-wallet | Connessione Wallet Standard e hook React     | [Sorgente](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-wallet) |

## Solana Web3.js v3

`@solana/web3.js` v3 è la versione consigliata di web3.js. Ricostruisce la
classica API basata su classi — `Connection`, `Keypair`, `Transaction`, `PublicKey` —
sulle componenti interne di `@solana/kit`, quindi funziona con le primitive di Kit e con i
client dei programmi indicati sopra. Usala se stai aggiornando un'app web3.js esistente o
preferisci l'API basata su classi.

La maggior parte dei metodi che nell'SDK legacy erano sincroni, come
`Keypair.generate()` e `transaction.sign()`, ora sono asincroni.

```bash
npm install @solana/web3.js@3
```

| Pacchetto         | Descrizione | GitHub                                                        |
| --------------- | ----------- | ------------------------------------------------------------- |
| @solana/web3.js | SDK principale    | [Sorgente](https://github.com/solana-foundation/solana-web3.js) |

`@solana/spl-token` dipende da `@solana/web3.js` (legacy) e non funziona con
la v3. Usa invece `@solana-program/token` o `@solana-program/token-2022`: le relative
istruzioni generate e i piani di istruzioni funzionano direttamente con
`Transaction.add()` della v3.

- [Guida alla migrazione da web3.js v1 a v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
- [Guida alla migrazione di spl-token](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-spl-token-migration.md)

## Solana Web3.js (legacy)

`@solana/web3.js` (legacy, `1.x`) è l'SDK TypeScript originale per Solana. È
in modalità di manutenzione e riceve solo correzioni critiche. I codebase esistenti possono
[passare a web3.js v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
oppure [migrare a Kit](/docs/frontend/web3-compat).
