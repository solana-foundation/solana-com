L'interfaccia a riga di comando `spl-token` crea e gestisce mint, token
account, autorità, trasferimenti ed estensioni di Token-2022.

Questo riferimento segue
[`spl-token-cli` v5.6.1](https://github.com/solana-program/token-2022/releases/tag/cli%40v5.6.1),
la versione inclusa in Agave v4.2.1. Esegui `spl-token --version` e usa
`<command> --help` per vedere le opzioni esatte disponibili nella versione installata.

<Callout type="warn">
  La creazione di mint, i trasferimenti, le modifiche delle autorità, i burn, i freeze e la chiusura degli account
  inviano transazioni. Prima di eseguire un comando, verifica cluster, token program, firmatario e
  indirizzi. Le modifiche su Mainnet usano asset reali.
</Callout>

## Installazione e guida

Il bundle di release della CLI di Agave include `spl-token`. Se non è installato, usa
il crate Rust pubblicato:

```shell
cargo install spl-token-cli --version 5.6.1
spl-token --version
```

Consulta la guida a livello globale o di singolo comando:

```shell
spl-token --help
spl-token create-token --help
spl-token transfer --help
```

## Opzioni globali

Inserisci le opzioni globali prima del comando.

| Opzione                                       | Scopo                                                                   |
| -------------------------------------------- | ------------------------------------------------------------------------- |
| `-u, --url <URL_OR_MONIKER>`                 | Seleziona un URL RPC oppure `mainnet-beta`, `testnet`, `devnet` o `localhost`. |
| `-C, --config <PATH>`                        | Usa un file di configurazione della Solana CLI diverso.                            |
| `--fee-payer <KEYPAIR>`                      | Seleziona l'account che paga le commissioni di transazione.                            |
| `-p, --program-id <ADDRESS>`                 | Usa un ID di Token Program esplicito.                                         |
| `--program-2022`                             | Usa Token-2022 (`TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb`).           |
| `--output <FORMAT>`                          | Restituisce `json` o `json-compact` dove supportato.                          |
| `--with-compute-unit-limit <UNITS>`          | Imposta il limite di compute unit della transazione.                                   |
| `--with-compute-unit-price <MICRO_LAMPORTS>` | Imposta il prezzo di priorità per compute unit.                                  |
| `-v, --verbose`                              | Mostra output aggiuntivo.                                                   |
| `-V, --version`                              | Stampa la versione installata della CLI.                                          |

Il programma predefinito è il Token Program originale. Usa `--program-2022` per un
mint o un account Token-2022, anche in lettura. Un comando fallisce se il programma
selezionato non è il proprietario dell'indirizzo fornito.

## Creare e usare un token

I comandi stampano gli indirizzi creati. Salva l'indirizzo del mint restituito da
`create-token` per i comandi successivi.

```shell
# Create a six-decimal mint under the original Token Program.
spl-token --url devnet create-token --decimals 6

# Create the default signer's associated token account for the mint.
spl-token --url devnet create-account <MINT_ADDRESS>

# Mint 100 tokens to that associated token account.
spl-token --url devnet mint <MINT_ADDRESS> 100

# Read supply, balance, and complete mint or account details.
spl-token --url devnet supply <MINT_ADDRESS>
spl-token --url devnet balance <MINT_ADDRESS>
spl-token --url devnet display <MINT_OR_TOKEN_ACCOUNT_ADDRESS>

# Transfer tokens to a wallet and create its associated account if needed.
spl-token --url devnet transfer \
  <MINT_ADDRESS> \
  10 \
  <RECIPIENT_WALLET_ADDRESS> \
  --fund-recipient
```

Gli importi sono importi di token in formato UI, adattati ai decimali del mint. Comandi come
`transfer`, `burn` e `unwrap-sol` accettano `ALL` dove indicato nella loro guida.

## Creare un mint Token-2022

Le estensioni allocano uno stato aggiuntivo del mint o dell'account e di norma devono essere scelte al momento
della creazione del mint. Questo esempio crea un mint a sei decimali con supporto
per i metadati incorporati:

```shell
spl-token --program-2022 create-token \
  --decimals 6 \
  --enable-metadata

spl-token --program-2022 initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  EXAMPLE \
  https://example.com/token.json
```

Le opzioni di estensione più comuni di `create-token` includono:

- `--enable-close`
- `--enable-confidential-transfers auto|manual`
- `--enable-freeze`
- `--enable-group` e `--enable-member`
- `--enable-metadata`
- `--enable-non-transferable`
- `--enable-pause`
- `--enable-permanent-delegate`
- `--enable-permissioned-burn`
- `--enable-transfer-hook` oppure `--transfer-hook <PROGRAM_ID>`
- `--interest-rate <BASIS_POINTS>`
- `--transfer-fee-basis-points <BASIS_POINTS>` con
  `--transfer-fee-maximum-fee <AMOUNT>`
- `--ui-amount-multiplier <MULTIPLIER>`

Combina solo le estensioni che il programma Token-2022 consente di usare insieme. Consulta la
[guida alle estensioni di Token-2022](/docs/tokens/extensions) pertinente prima di creare
una configurazione del mint irreversibile.

## Gestire autorità e delegati

```shell
# Change the mint authority.
spl-token authorize <MINT_ADDRESS> mint <NEW_AUTHORITY_ADDRESS>

# Permanently remove the mint authority.
spl-token authorize <MINT_ADDRESS> mint --disable

# Let a delegate spend up to 25 tokens from one token account.
spl-token approve \
  <TOKEN_ACCOUNT_ADDRESS> \
  25 \
  <DELEGATE_ADDRESS>

# Remove the current delegate.
spl-token revoke <TOKEN_ACCOUNT_ADDRESS>
```

`authorize` supporta i tipi di autorità mint, freeze, owner, close e quelli specifici
delle estensioni. Rimuovere un'autorità con `--disable` è permanente se nessun altro
meccanismo del programma può ripristinarla.

## Freeze, burn e chiusura

```shell
spl-token freeze <TOKEN_ACCOUNT_ADDRESS>
spl-token thaw <TOKEN_ACCOUNT_ADDRESS>

spl-token burn <TOKEN_ACCOUNT_ADDRESS> 5

# A token account must normally have a zero token balance before closing.
spl-token close --address <TOKEN_ACCOUNT_ADDRESS>
```

`burn` riduce sia il saldo dell'account sia la supply totale. `close` restituisce i
lamport rimanenti dell'account al destinatario configurato; non recupera i token
bruciati.

## Wrap e unwrap di SOL

```shell
# Create or fund the owner's wrapped SOL token account.
spl-token wrap 1

# Unwrap part of the wrapped SOL balance.
spl-token unwrap-sol 0.25

# Close the wrapped SOL account and return its full lamport balance.
spl-token unwrap
```

Usa `sync-native` dopo aver trasferito lamport direttamente in un token account di SOL wrapped,
in modo che il relativo importo di token corrisponda ai lamport sottostanti.

## Firma multisig

Crea un multisig M-of-N del Token Program con fino a 11 membri:

```shell
spl-token create-multisig \
  2 \
  <MEMBER_1_ADDRESS> \
  <MEMBER_2_ADDRESS> \
  <MEMBER_3_ADDRESS>
```

Per una transazione controllata da quel multisig, passa l'indirizzo del multisig come
autorità pertinente e fornisci i keypair dei membri tramite valori
`--multisig-signer` ripetuti. Controlla la guida del comando di destinazione, perché il flag
dell'autorità principale varia in base all'operazione.

## Saldi riservati

I comandi per i saldi riservati richiedono un mint Token-2022 configurato per i
trasferimenti riservati e un account destinatario configurato.

```shell
spl-token --program-2022 configure-confidential-transfer-account \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 deposit-confidential-tokens \
  <MINT_ADDRESS> \
  10 \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 apply-pending-balance \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 withdraw-confidential-tokens \
  <MINT_ADDRESS> \
  5 \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 transfer \
  <MINT_ADDRESS> \
  1 \
  <RECIPIENT_ADDRESS> \
  --confidential
```

Per `configure-confidential-transfer-account` e `apply-pending-balance`, passa
`--address <TOKEN_ACCOUNT_ADDRESS>` oppure un `<MINT_ADDRESS>` posizionale, non
entrambi. La forma posizionale usa l'associated token account del proprietario. Deposito e
prelievo richiedono sempre il mint e accettano `--address` per sostituire quell'account
predefinito.

Usa `enable-confidential-credits`, `disable-confidential-credits`,
`enable-non-confidential-credits` e `disable-non-confidential-credits` per
controllare quali depositi accetta l'account. Queste impostazioni influiscono sulla privacy
dell'account e sulla compatibilità dei pagamenti; ispeziona l'account prima di modificarle.

## Firma strutturata e offline

Usa l'output strutturato anziché analizzare il testo visualizzato:

```shell
spl-token accounts --output json
spl-token display <MINT_ADDRESS> --output json-compact
```

I comandi che producono transazioni di solito supportano `--sign-only`, `--blockhash`,
`--signer <PUBKEY=SIGNATURE>`, `--nonce` e `--nonce-authority`. Gli input
offline esatti dipendono dal comando, dai decimali del mint e dalla configurazione delle autorità,
quindi genera il messaggio non firmato seguendo le istruzioni `--help` di quel comando e
verifica ogni indirizzo prima di raccogliere le firme.
