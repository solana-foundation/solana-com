---
title: "Quickstart: creare un token con la CLI"
description:
  Create a token, open a token account, mint supply, and transfer tokens using
  the SPL Token CLI on devnet.
---

Questo quickstart illustra il ciclo di vita completo di un token tramite la CLI _sh`spl-token`_. Creerai un mint, un account in grado di contenere il token, coniai 100 token e ne trasferirai alcuni a un altro wallet.

Usa [Solana Playground](https://beta.solpg.io/) per eseguire i comandi nel tuo browser, oppure installa la CLI in locale con `cargo install spl-token-cli`. Gli indirizzi nel tuo output saranno diversi dagli esempi seguenti.

## 1. Connettiti alla devnet

Crea o connetti un wallet in Solana Playground, poi seleziona la devnet e richiedi SOL per i depositi degli account e le commissioni di transazione:

```terminal
$ solana config set --url devnet
$ solana airdrop 2
```

Usa i token devnet solo per i test. Non hanno alcun valore finanziario.

## 2. Crea un token

Crea il mint account che identifica il tuo token:

```terminal
$ spl-token create-token
```

Copia l'indirizzo del token dall'output. Questo è il mint address che utilizzerai nei comandi successivi. Un nuovo mint parte con una supply pari a zero.

```terminal
$ spl-token supply <MINT_ADDRESS>
```

## 3. Crea un token account

Il tuo wallet ha bisogno di un token account per questo mint prima di poter detenere un saldo:

```terminal
$ spl-token create-account <MINT_ADDRESS>
```

Questo crea il tuo [associated token account](/docs/tokens#associated-token-account), il cui indirizzo è derivato dal tuo wallet e dal mint.

## 4. Conia token

Conia 100 token nel tuo associated token account:

```terminal
$ spl-token mint <MINT_ADDRESS> 100
$ spl-token balance <MINT_ADDRESS>
```

La mint authority deve firmare questa operazione. Il minting aumenta sia il saldo del tuo token account che la supply totale registrata dal mint.

## 5. Trasferisci token

Invia 10 token a un altro wallet sulla devnet. L'opzione _sh`--fund-recipient`_ crea l'associated token account del destinatario se non esiste:

```terminal
$ spl-token transfer <MINT_ADDRESS> 10 <RECIPIENT_WALLET_ADDRESS> --fund-recipient
```

Il trasferimento modifica i saldi nei token account del mittente e del destinatario; non modifica la supply totale del mint.

## Opzionale: aggiungere metadati Token-2022

Per memorizzare un nome, un simbolo e un URI direttamente su un nuovo mint Token-2022, crealo con l'estensione dei metadati abilitata:

```terminal
$ spl-token create-token \
  --program-id TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb \
  --enable-metadata
```

Poi usa il nuovo mint address stampato da quel comando:

```terminal
$ spl-token initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  "EXAMPLE" \
  "https://example.com/token.json"
```

L'URI deve restituire un documento JSON pubblico di metadati. Consulta [Token-2022 metadata](/docs/tokens/extensions/metadata) per il modello di account e gli esempi di codice.
