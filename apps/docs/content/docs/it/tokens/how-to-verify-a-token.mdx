# Come verificare un token e farlo apparire su Solana Explorer

Una domanda comune da parte dei creatori di token è: _"Perché il mio token non appare quando lo cerco su Solana Explorer e come faccio a farlo verificare?"_

La risposta breve: Solana Explorer non esegue un proprio processo di verifica centralizzato. Al contrario, **aggrega diversi provider di verifica indipendenti**. Se il tuo token viene verificato tramite **anche solo uno** di questi provider, apparirà nei risultati di ricerca di Explorer e mostrerà le informazioni di verifica.

Questa guida illustra ciascun provider, cosa significa (e cosa non significa) "verificato", e come far verificare il tuo token.

## Cosa significa "verificato" (e cosa non significa)

La verifica conferma che un token è il **token canonico / corretto** per un determinato nome, simbolo e indirizzo mint. Aiuta gli utenti a evitare token falsificati e duplicati, poiché chiunque può coniare un token con qualsiasi nome su Solana.

La verifica **non** è un'approvazione di un progetto, e **non** è una garanzia del valore, della sicurezza o della legittimità di un token. Fai sempre le tue ricerche.

## I provider di verifica alla base di Solana Explorer

Solana Explorer controlla i seguenti verificatori indipendenti. Essere riconosciuto da uno qualsiasi di essi (RugCheck è automatico; gli altri richiedono un'azione) fa apparire il tuo token nella ricerca di Explorer.

### 1. RugCheck (automatico)

[RugCheck](https://rugcheck.xyz) esegue un'analisi automatizzata on-chain e traccia automaticamente i token. Poiché è automatico, in genere non è necessario inviare nulla — RugCheck valuta i segnali di rischio on-chain (autorità di mint/freeze, distribuzione dei holder, liquidità, ecc.) e traccia il token autonomamente.

È prevista una gestione speciale per alcune stablecoin, in cui i progetti possono contattare direttamente il team di RugCheck per un trattamento appropriato.

Esempio di pagina token:
[`rugcheck.xyz/tokens/<mint>`](https://rugcheck.xyz/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 2. Jupiter

[Jupiter](https://jup.ag) mantiene una lista di token verificati (VRFD) ampiamente integrata nell'ecosistema Solana — DEX, wallet e screener. Un token verificato riceve un segno di spunta verde sui prodotti Jupiter e sulle piattaforme partner.

Per ottenere la verifica, invia il tuo token per la revisione:

- Invia su [verified.jup.ag/tokens](https://verified.jup.ag/tokens)
- Chiunque può inviare un token (non solo il team del progetto)
- Puoi facoltativamente collegare l'account X del progetto per associare l'indirizzo mint del token a un account specifico
- Jupiter esegue una revisione olistica (liquidità, conformità agli standard dei metadati e altri segnali) invece di controllare una singola metrica

Esempio di pagina token:
[`jup.ag/tokens/<mint>`](https://jup.ag/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 3. CoinGecko

La verifica su [CoinGecko](https://www.coingecko.com) elenca il tuo token con i dati di mercato. Quando verifichi con CoinGecko, assicurati di includere l'**indirizzo mint** del token (nel modulo di CoinGecko questo campo è etichettato come "contract address") in modo che le integrazioni downstream possano risolvere correttamente i prezzi.

Segui la guida ufficiale di CoinGecko per la listing/aggiornamento:

- [Guida alla verifica per le richieste di listing e aggiornamento su CoinGecko](https://support.coingecko.com/hc/en-us/articles/23725417857817-Verification-Guide-for-Listing-Update-Requests-on-CoinGecko)

Esempio di pagina coin:
[`coingecko.com/en/coins/<token>`](https://www.coingecko.com/en/coins/usdc)

### 4. Solflare

[Solflare](https://solflare.com) è un validator indipendente nel framework di verifica di Solana Explorer. In pratica, i suoi criteri di listing dei token si sovrappongono ampiamente a quelli di Jupiter, poiché la lista di swap in-app di Solflare è alimentata dall'aggregatore Jupiter. Affinché un nuovo token appaia, in genere deve:

- Essere un token valido sulla blockchain Solana con metadati conformi allo standard Metaplex Token Metadata
- Avere liquidità sufficiente (un valore minimo in USD del token disponibile per il trading)
- Mantenere l'impatto sul prezzo entro limiti accettabili per gli swap tipici

Per via di questa sovrapposizione, i token che completano la verifica Jupiter sono spesso già idonei su Solflare senza una sottomissione separata — quindi di solito non è necessario considerare Solflare come un passaggio manuale aggiuntivo. Una volta soddisfatti i criteri, i token di solito appaiono entro pochi minuti. Consulta:

- [Non riesco a trovare un token su Solflare](https://help.solflare.com/en/articles/9260147-i-cannot-find-a-token-in-solflare)

Esempio di pagina token:
[`solflare.com/prices/<name>/<mint>`](https://www.solflare.com/prices/usd-coin/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/)

### 5. Bluprynt (KYC avanzato)

[Bluprynt](https://app.bluprynt.com/register/account) offre un percorso di verifica avanzato con un protocollo KYC. Si tratta di un processo più rigoroso, basato sull'identità, adatto ai progetti che desiderano un segnale di verifica più solido.

- Registrati tramite il
  [modulo di onboarding Bluprynt per Solana Explorer](https://app.bluprynt.com/register/account)

Esempio di pagina asset verificato:
[`verified.bluprynt.com/verified-assets/<mint>/solana`](https://verified.bluprynt.com/verified-assets/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/solana)

## Come funziona nel complesso

- **RugCheck** avviene automaticamente tramite analisi on-chain — nessuna sottomissione necessaria.
- **Jupiter, CoinGecko, Solflare e Bluprynt** richiedono ciascuno di inviare / completare il rispettivo processo.
- Non appena il tuo token viene verificato da **almeno uno** di questi provider, apparirà nella ricerca di **Solana Explorer** e mostrerà i dettagli di verifica.

Se il tuo token non appare ancora nella ricerca di Explorer, il percorso più rapido è solitamente inviare la richiesta di verifica a Jupiter e/o completare una listing su CoinGecko, poiché entrambi sono ampiamente integrati nell'ecosistema.

## Prerequisiti che favoriscono il successo della verifica

Indipendentemente dal provider, questi fondamentali on-chain aumentano notevolmente le probabilità di successo della verifica:

- **Metadati validi**: il tuo token deve avere metadati on-chain conformi allo standard Metaplex Token Metadata (nome, simbolo, URI del logo).
- **Liquidità**: fornisci liquidità sufficiente su un DEX supportato in modo che il token possa essere scambiato e valutato.
- **Indirizzo mint corretto**: ogni volta che invii una richiesta a un provider, utilizza sempre l'**indirizzo mint** del tuo token (etichettato come "contract address" in alcuni moduli dei provider).

## Riepilogo

Solana Explorer aggrega più verificatori indipendenti — **RugCheck** (automatico), **Jupiter**, **CoinGecko**, **Solflare** e **Bluprynt** (KYC). La verifica tramite uno qualsiasi di essi rende il tuo token individuabile nella ricerca di Explorer. La verifica conferma l'identità canonica del token; non è un'approvazione, quindi gli utenti dovrebbero sempre fare le proprie ricerche.
