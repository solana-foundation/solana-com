title: BlockMint

  Rimuove un mint precedentemente consentito dall'istanza, impedendo nuovi depositi per quel mint
---

Rimuove un mint precedentemente consentito dall'istanza, impedendo nuovi depositi per
quel mint. I depositi esistenti non sono interessati.

## Account

| Account                          | Scrivibile | Firmatario | Descrizione                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | Pagatore delle commissioni                                    |
| `admin`                          |          | ✓      | Amministratore dell'istanza                               |
| `instance`                       |          |        | PDA dell'istanza                                 |
| `mint`                           |          |        | Mint del token SPL da bloccare                      |
| `allowed_mint`                   | ✓        |        | PDA AllowedMint (chiuso da questa istruzione) |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | PDA dell'autorità degli eventi                          |
| `private_channel_escrow_program` |          |        | Programma Escrow                               |

Questa istruzione non accetta parametri.

## Note importanti

- Chiude il PDA `allowed_mint`: le nuove chiamate `Deposit` per questo mint falliranno
  con `InvalidAllowedMint`
- I saldi dei canali esistenti per questo mint non sono interessati
- Emette un evento tramite CPI `EmitEvent`
