Questa sezione è il riferimento alle istruzioni on-chain. La maggior parte degli sviluppatori richiama queste istruzioni tramite i client TypeScript generati; questo riferimento è necessario solo se si sta costruendo strumenti per operatori, scrivendo integrazioni personalizzate o eseguendo il debug di errori a livello di istruzione.

**Escrow Program** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) - gestisce depositi, provisioning degli operatori e liquidazione su Mainnet:

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) -
  inizializza il PDA dell'istanza escrow
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) - aggiunge
  un mint di token SPL alla whitelist
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) - rimuove un
  mint dalla allowlist
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) -
  effettua il provisioning di un operatore
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) -
  revoca un operatore
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) -
  trasferisce i diritti di amministratore
- [Deposit](/docs/tools/private-channels/instructions/deposit) - sposta token SPL
  nell'escrow
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) -
  l'operatore liquida un prelievo su Mainnet
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) -
  l'operatore ruota lo Sparse Merkle Tree

**Withdraw Program** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) - opera sulla rete del canale privato:

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) -
  brucia il saldo lato canale per avviare un prelievo

## Codici di Errore

**Withdraw Program - `PrivateChannelEscrowProgramError`**

| Codice                                         | Messaggio                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | Autorità evento non valida fornita                 |
| `InvalidAta`                                 | ATA non valido fornito                             |
| `InvalidMint`                                | Mint non valido fornito                            |
| `InvalidInstanceId`                          | ID istanza non valido o non conforme alle regole    |
| `InvalidInstance`                            | Istanza non valida fornita                        |
| `InvalidAdmin`                               | Amministratore non valido fornito                           |
| `TransferHookNotAllowed`                     | Estensione transfer hook non consentita              |
| `InvalidOperatorPda`                         | PDA operatore non valido fornito                    |
| `InvalidTokenAccount`                        | token account non valido fornito                   |
| `InvalidEscrowBalance`                       | Saldo escrow non valido                           |
| `InvalidAllowedMint`                         | Mint consentito non valido                             |
| `InvalidSmtProof`                            | Prova SMT non valida fornita                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | Nonce transazione non valido per l'indice albero corrente |
| `UnexpectedTreeIndex`                        | Indice albero corrente imprevisto per il reset della radice SMT |

**Withdraw Program - `PrivateChannelWithdrawProgramError`**

| Codice          | Messaggio                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | Mint non valido fornito                       |
| `ZeroAmount`  | L'importo del prelievo deve essere maggiore di zero |
