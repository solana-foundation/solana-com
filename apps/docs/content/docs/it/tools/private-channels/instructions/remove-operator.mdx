---
title: RemoveOperator
description: Revoca un operatore chiudendo il relativo PDA dell'operatore
---

Revoca un operatore chiudendo il relativo PDA `Operator`. Il wallet revocato non potrà
più chiamare `ReleaseFunds` o `ResetSmtRoot`.

## Account

| Account                          | Scrivibile | Firmatario | Descrizione                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | Pagatore delle commissioni                                 |
| `admin`                          |          | ✓      | Admin dell'istanza                            |
| `instance`                       |          |        | PDA dell'istanza                              |
| `operator`                       |          |        | Wallet dell'operatore da revocare                 |
| `operator_pda`                   | ✓        |        | PDA dell'operatore (chiuso da questa istruzione) |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | PDA dell'autorità degli eventi                       |
| `private_channel_escrow_program` |          |        | Programma di escrow                            |

Questa istruzione non richiede parametri.

## Note importanti

- Chiude il `operator_pda`; il wallet revocato non potrà più chiamare
  `ReleaseFunds` o `ResetSmtRoot`
- Qualsiasi transazione dell'operatore in corso fallirà con `InvalidOperatorPda` dopo
  questa chiamata
- Emette un evento tramite CPI `EmitEvent`
