---
title: Prelievo di Fondi
description:
  Brucia i token lato canale per avviare un prelievo verso l'escrow della mainnet Solana
---

Brucia il saldo di token lato canale di un utente sul Withdraw Program per segnalare un
prelievo in sospeso; un operatore deve successivamente chiamare `ReleaseFunds` sull'Escrow
Program per completare il settlement.

## Account

| Account                    | Scrivibile | Firmatario | Descrizione                                |
| -------------------------- | -------- | ------ | ------------------------------------------ |
| `user`                     |          | ✓      | Proprietario del token che avvia il prelievo      |
| `mint`                     | ✓        |        | Mint del token SPL (bruciato contro)            |
| `token_account`            | ✓        |        | token account lato canale dell'utente (sorgente) |
| `token_program`            |          |        | Token Program SPL                          |
| `associated_token_program` |          |        | Associated Token Program                   |

## Parametri

| Parametro     | Tipo             | Descrizione                                                          |
| ------------- | ---------------- | -------------------------------------------------------------------- |
| `amount`      | `u64`            | Quantità di token da prelevare, nell'unità più piccola del token           |
| `destination` | `Option<Pubkey>` | Wallet di destinazione sulla Mainnet; se `None`, viene utilizzato il wallet del firmatario |

## Valore Restituito

Restituisce un `TransactionBuilder` che può essere utilizzato per costruire e inviare la
transazione.

## Esempio

```typescript
import { getWithdrawFundsInstruction } from "../private-channel-withdraw-program/clients/typescript/src/generated";

const withdrawIx = getWithdrawFundsInstruction({
  user: userSigner,
  mint: mintAddress,
  tokenAccount: channelTokenAccount,
  tokenProgram: TOKEN_PROGRAM_ID,
  associatedTokenProgram: ASSOCIATED_TOKEN_PROGRAM_ID,
  amount: 1_000_000n,
  destination: null // null = release to signer's Mainnet wallet
});
```

## Note Importanti

- Questa istruzione si trova sul **Withdraw Program**
  (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi` devnet), non sull'Escrow
  Program
- Bruciare i token lato canale **non** rilascia automaticamente i fondi sulla
  Mainnet; un operatore deve successivamente chiamare `ReleaseFunds` sull'Escrow
  Program con una prova di esclusione SMT valida
- L'errore `ZeroAmount` viene generato se `amount` è 0
- Se `destination` è `None`, la chiamata `ReleaseFunds` dell'operatore rilascerà
  i fondi al wallet del firmatario

Per il riferimento completo ai codici di errore di entrambi i programmi, consulta
[Istruzioni -> Codici di Errore](/docs/tools/private-channels/instructions#error-codes).
