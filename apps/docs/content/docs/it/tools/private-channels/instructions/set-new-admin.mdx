Trasferisce i diritti di amministratore a un nuovo wallet.

## Account

| Account                          | Scrivibile | Firmatario | Descrizione                        |
| -------------------------------- | -------- | ------ | ---------------------------------- |
| `payer`                          | ✓        | ✓      | Pagatore delle commissioni                          |
| `current_admin`                  |          | ✓      | Amministratore attuale (deve firmare)          |
| `instance`                       | ✓        |        | PDA dell'istanza (campo admin aggiornato) |
| `new_admin`                      |          | ✓      | Wallet che riceve i diritti di amministratore     |
| `event_authority`                |          |        | PDA dell'autorità degli eventi                |
| `private_channel_escrow_program` |          |        | Programma Escrow                     |

Questa istruzione non richiede parametri.

## Note importanti

- **Irreversibile in un solo passaggio**: l'amministratore attuale non può rivendicare nuovamente il ruolo
  senza che il nuovo amministratore chiami di nuovo `SetNewAdmin`
- Verifica l'indirizzo di destinazione prima di procedere; non è possibile annullare l'operazione
- Emette un evento tramite CPI `EmitEvent`
