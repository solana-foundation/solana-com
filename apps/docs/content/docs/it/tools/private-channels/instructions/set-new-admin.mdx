Trasferisce i diritti di amministratore a un nuovo wallet.

## Account

| Account                          | Scrivibile | Firmatario | Descrizione                        |
| -------------------------------- | -------- | ------ | ---------------------------------- |
| `payer`                          | ✓        | ✓      | Pagante delle commissioni                          |
| `current_admin`                  |          | ✓      | Admin attuale (deve firmare)          |
| `instance`                       | ✓        |        | PDA dell'istanza (campo admin aggiornato) |
| `new_admin`                      |          | ✓      | Wallet che riceve i diritti di amministratore     |
| `event_authority`                |          |        | PDA dell'autorità eventi                |
| `private_channel_escrow_program` |          |        | Programma Escrow                     |

Questa istruzione non prevede parametri.

## Note Importanti

- **Irreversibile in un solo passaggio**: l'admin attuale non può recuperare il ruolo
  senza che il nuovo admin chiami nuovamente `SetNewAdmin`
- Verifica l'indirizzo di destinazione prima di chiamare; non è possibile annullare l'operazione
- Emette un evento tramite `EmitEvent` CPI
