Autorizza un mint di token SPL sull'istanza e crea l'associated
token account dell'escrow per quel mint. I depositi per questo mint diventano possibili dopo questa
chiamata.

## Account

| Account                          | Scrivibile | Firmatario | Descrizione                                                                   |
| -------------------------------- | -------- | ------ | ----------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Pagatore delle commissioni                                                                     |
| `admin`                          |          | ✓      | Admin dell'istanza                                                                |
| `instance`                       |          |        | PDA dell'istanza                                                                  |
| `mint`                           |          |        | Mint di token SPL da autorizzare                                                       |
| `allowed_mint`                   | ✓        |        | PDA AllowedMint (creato da questa istruzione)                                 |
| `instance_ata`                   | ✓        |        | Associated token account dell'escrow per questo mint (creato da questa istruzione) |
| `system_program`                 |          |        | System Program                                                                |
| `token_program`                  |          |        | SPL Token Program                                                             |
| `associated_token_program`       |          |        | Associated Token Program                                                      |
| `event_authority`                |          |        | PDA dell'autorità degli eventi                                                           |
| `private_channel_escrow_program` |          |        | Programma Escrow                                                                |

## Parametri

| Parametro | Tipo | Descrizione                                                                                   |
| --------- | ---- | --------------------------------------------------------------------------------------------- |
| `bump`    | `u8` | Bump seed per il PDA `allowed_mint`. Facoltativo: il client `Async` lo deriva automaticamente se omesso |

> L'IDL contiene un argomento `discriminator: u8` (valore `1`) che viene impostato automaticamente
> dal client generato e non deve essere passato manualmente.

## Note Importanti

- Usa `getAllowMintInstructionAsync`; deriva automaticamente `bump`, `allowed_mint`,
  e `instance_ata` quando non vengono forniti. Passa il tuo `bump` solo se
  lo hai già calcolato tramite
  `Pubkey::find_program_address(&[b"allowed_mint", instance_pda, mint], &PROGRAM_ID)`
- Crea anche `instance_ata`, l'ATA dell'escrow per questo mint
- I mint con un'estensione transfer hook sono esplicitamente bloccati: tentare di
  autorizzare tale mint genera l'errore `TransferHookNotAllowed`
- Emette un evento tramite CPI `EmitEvent`
