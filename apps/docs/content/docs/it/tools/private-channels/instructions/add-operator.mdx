---
title: AddOperator
description: Provisiona un nuovo operatore creando il suo Operator PDA
---

Provisiona un nuovo operatore creando il suo PDA `Operator`. Dopo questa chiamata, il
wallet `operator` può chiamare `ReleaseFunds` e `ResetSmtRoot`.

## Account

| Account                          | Scrivibile | Firmatario | Descrizione                                                         |
| -------------------------------- | -------- | ------ | ------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Pagatore delle commissioni                                                           |
| `admin`                          |          | ✓      | Admin dell'istanza                                                      |
| `instance`                       |          |        | PDA dell'istanza                                                        |
| `operator`                       |          |        | Wallet dell'operatore da provisionare                                        |
| `operator_pda`                   | ✓        |        | Operator PDA - derivato automaticamente da `["operator", instance, operator]` |
| `system_program`                 |          |        | System Program                                                      |
| `event_authority`                |          |        | PDA dell'autorità degli eventi                                                 |
| `private_channel_escrow_program` |          |        | Programma Escrow                                                      |

## Parametri

| Parametro | Tipo | Descrizione                                                                               |
| --------- | ---- | ----------------------------------------------------------------------------------------- |
| `bump`    | `u8` | bump seed per l'`operator_pda`. Opzionale: il client `Async` lo deriva automaticamente se omesso |

> L'IDL contiene un argomento `discriminator: u8` (valore `3`) impostato automaticamente
> dal client generato e non deve essere passato manualmente.

## Note importanti

- Usa `getAddOperatorInstructionAsync`; deriva automaticamente `bump` e
  `operator_pda` quando non vengono forniti. Esiste anche una variante sincrona
  `getAddOperatorInstruction` nel caso in cui tu abbia già calcolato `bump`
  autonomamente
- Dopo questa chiamata, il wallet `operator` può chiamare `ReleaseFunds` e
  `ResetSmtRoot`
- Emette un evento tramite CPI `EmitEvent`
