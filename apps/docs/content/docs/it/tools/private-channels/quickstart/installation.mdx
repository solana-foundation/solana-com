## Prerequisiti

- Rust 1.91+
- Solana CLI 3.1.13 (Agave):
  `sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.13/install)"`
- Node.js 24.7.0+
- pnpm 10.15.1+: `npm install -g pnpm@10.15.1`

## Clona il Repository

```bash
git clone https://github.com/solana-foundation/solana-private-channels.git
cd solana-private-channels
```

## Genera i Client TypeScript

I client TypeScript **non** sono pubblicati su npm. Devono essere generati
dall'IDL utilizzando Codama.

```bash
# Escrow program client
cd private-channel-escrow-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..

# Withdraw program client
cd private-channel-withdraw-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..
```

I client generati si trovano in:

- `private-channel-escrow-program/clients/typescript/src/generated/`
- `private-channel-withdraw-program/clients/typescript/src/generated/`

Importa da questi percorsi locali nella tua applicazione; non esiste alcun
pacchetto `@private-channels/client` su npm. Gli esempi di codice in questa sezione utilizzano un
percorso relativo (`../private-channel-escrow-program/...`) che presuppone che il tuo codice
si trovi accanto al repository clonato; adattalo in base al percorso da cui importi
effettivamente nel tuo progetto.
