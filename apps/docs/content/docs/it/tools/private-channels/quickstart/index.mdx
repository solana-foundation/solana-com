Questo avvio rapido illustra l'intero flusso di Private Channels sulla devnet di Solana:
configura l'ambiente client, deposita token SPL nell'escrow, invia un
trasferimento off-chain tra due wallet e preleva i fondi nel tuo wallet
Solana.

Al termine comprenderai l'intero ciclo deposito -> trasferimento off-chain ->
prelievo e avrai codice TypeScript funzionante per ogni passaggio.

<Callout type="info">
  Questo avvio rapido presuppone che un'istanza di Private Channels sia già distribuita e
  in esecuzione sulla devnet con il tuo mint nella allowlist. Se devi prima distribuirne una,
  la [guida per gli Operatori](/docs/tools/private-channels/operators) copre
  la configurazione completa; prevedi 30-60 minuti per la build Docker iniziale.
</Callout>

## Passaggi

1. **[Installazione](/docs/tools/private-channels/quickstart/installation)** -
   clona il repository e genera i client TypeScript (5 minuti)
2. **[Deposita Token](/docs/tools/private-channels/quickstart/deposit)** -
   deposita token SPL nell'escrow; attendi ~15 secondi affinché l'indicizzatore
   accrediti il saldo del tuo canale
3. **[Invia un Trasferimento](/docs/tools/private-channels/quickstart/transfer)** -
   invia un trasferimento off-chain tramite il gateway; si conferma in meno di un secondo,
   senza mai toccare la Mainnet
4. **[Preleva Fondi](/docs/tools/private-channels/quickstart/withdraw)** - brucia
   il tuo saldo lato canale; l'operatore accredita i fondi nel tuo wallet Mainnet
   entro pochi secondi
