## Utilizzare Solana MCP

Il modo più efficace per sfruttare l'IA nello sviluppo su Solana è tramite il
[Solana Developer MCP](https://mcp.solana.com/) (Model Context Protocol). Questa
integrazione porta le conoscenze specializzate su Solana direttamente nel tuo IDE, fornendo
ai tuoi agenti accesso alla documentazione Solana aggiornata e rendendo lo sviluppo
più rapido ed efficiente.

## Cos'è Solana MCP?

Solana MCP è un assistente IA specializzato che si integra direttamente negli
IDE con supporto AI come Cursor e Windsurf. Quando poni domande specifiche su Solana,
interroga automaticamente il server MCP per fornire informazioni accurate e
aggiornate provenienti da:

- La [documentazione di Solana](/docs)
- La [documentazione del framework Anchor](https://www.anchor-lang.com/docs)
- Gli
  [esempi di programma](https://github.com/solana-developers/program-examples) di Solana
- Domande e risposte di
  [Solana Stack Exchange](https://solana.stackexchange.com/)

## Esempi di utilizzo

Puoi usare MCP per:

- Informarti sui concetti di Solana
- Eseguire il debug degli errori dei programmi
- Ottenere raccomandazioni sulle best practice
- Imparare da esempi di esperti
- Sviluppare più velocemente con l'aiuto di un esperto

## Configurare Solana MCP

Trova una guida dettagliata alla configurazione e all'avvio sul
[sito web di Solana MCP](https://mcp.solana.com/).

## Preferisci usare una skill?

Se preferisci usare una skill, installa la skill ufficiale di Solana con:

```bash
npx skills add https://github.com/solana-foundation/solana-dev-skill
```

Esplora altri workflow riutilizzabili nella [libreria Solana Agent Skills](/skills).
