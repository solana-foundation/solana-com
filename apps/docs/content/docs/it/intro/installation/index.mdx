Configura un ambiente di sviluppo Solana locale con l'installer automatico. Installa Rust, la Solana CLI, Anchor CLI, Surfpool CLI, Node.js e Yarn su
macOS, Linux o Windows tramite WSL.

<Callout type="info" title="Windows richiede WSL">
  In Windows PowerShell, esegui `wsl --install`, riavvia Windows se richiesto, quindi
  esegui i comandi di installazione riportati di seguito nel terminale Ubuntu. Consulta la [guida all'installazione
  manuale](/docs/intro/installation/dependencies) per la configurazione
  completa di WSL.
</Callout>

## Installazione rapida

1. Esegui l'installer in un terminale macOS, Linux o WSL:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
```

Puoi
[consultare il codice sorgente dell'installer](https://github.com/solana-developers/solana-install/blob/main/install.sh)
prima di eseguirlo. L'installer rileva i gestori di pacchetti Linux supportati e
installa automaticamente le relative dipendenze di sistema.

2. Riavvia il terminale in modo che i nuovi comandi siano disponibili nel tuo `PATH`.

3. Verifica ogni strumento:

```terminal
$ rustc --version
$ solana --version
$ anchor --version
$ surfpool --version
$ node --version
$ yarn --version
```

Un'installazione riuscita restituisce un output di questo tipo (i numeri di versione cambiano con il
rilascio dei nuovi strumenti):

```txt title="Example output"
Installed Versions:
Rust: rustc x.y.z (...)
Solana CLI: solana-cli x.y.z (..., client:Agave)
Anchor CLI: anchor-cli x.y.z
Surfpool CLI: surfpool x.y.z
Node.js: vx.y.z
Yarn: x.y.z
```

<Callout type="warn" title="Installer non riuscito o comando mancante">
  Segui la [guida all'installazione manuale](/docs/intro/installation/dependencies)
  per installare o risolvere i problemi di ogni dipendenza singolarmente.
</Callout>
