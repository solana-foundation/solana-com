Installa ogni dipendenza separatamente quando hai bisogno di una versione specifica o quando l'[installazione rapida](/docs/intro/installation) non si completa correttamente.
Segui le sezioni in ordine per un nuovo ambiente, oppure vai direttamente allo strumento
che devi installare o di cui devi risolvere i problemi.

## Prerequisiti

<Accordions>
<Accordion title="Windows">

Per sviluppare programmi Solana su Windows **devi** usare
[Windows Subsystem for Linux](https://learn.microsoft.com/en-us/windows/wsl/install)
(WSL). Dopo aver installato WSL, tutte le altre dipendenze verranno installate
tramite il terminale Linux.

Per installare WSL, esegui il seguente comando in Windows PowerShell:

```terminal
$ wsl --install
```

Il processo di installazione ti chiederà di creare un account utente
predefinito.

![Installazione WSL](/assets/docs/intro/installation/wsl-install.png)

Per impostazione predefinita, WSL installa Ubuntu. Puoi aprire un terminale
Linux cercando "Ubuntu" nella barra di ricerca.

![WSL Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-search.png)

Se il tuo terminale Ubuntu appare come nell'immagine qui sotto, potresti
riscontrare un problema in cui `ctrl + v` (scorciatoia da tastiera per
incollare) non funziona nel terminale.

![Terminale Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-terminal-1.png)

Se riscontri questo problema, apri Windows Terminal cercando "Terminal" nella
barra di ricerca.

![Windows Terminal](/assets/docs/intro/installation/wsl-windows-terminal.png)

Successivamente, chiudi Windows Terminal e riapri un terminale Linux cercando
Ubuntu di nuovo. Il terminale dovrebbe ora apparire come nell'immagine qui
sotto, dove `ctrl + v` (scorciatoia da tastiera per incollare) funziona.

![Terminale Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-terminal-2.png)

Se usi VS Code,
l'[estensione WSL](https://code.visualstudio.com/docs/remote/wsl-tutorial) ti
consente di usare WSL e VS Code insieme.

![Configurazione WSL in VS Code](/assets/docs/intro/installation/wsl-vscode.png)

Vedrai quanto segue nella barra di stato di VS Code:

![WSL: Ubuntu](/assets/docs/intro/installation/wsl-vscode-ubuntu.png)

Una volta configurato WSL, sei pronto per:

- Completare l'[installazione rapida](/docs/intro/installation) utilizzando il
  terminale Ubuntu (Linux)
- Installare [Rust](#install-rust), la [Solana CLI](#install-solana-cli) e la
  [Anchor CLI](#install-anchor-cli) individualmente, come descritto di seguito

<Tabs items={[".deb", ".rpm"]}>
<Tab value=".deb" >
Su Debian o su una distribuzione derivata da Debian, come Ubuntu o Mint:

1. Aggiorna gli elenchi dei pacchetti per assicurarti che tutti i pacchetti
   siano aggiornati:

```terminal
$ sudo apt-get update
```

2. Installa le seguenti dipendenze:

```terminal
$ sudo apt-get install -y \
    build-essential \
    pkg-config \
    libudev-dev llvm libclang-dev \
    protobuf-compiler libssl-dev
```

<Callout>
Se riscontri il seguente errore durante l'installazione di `protobuf-compiler`, esegui
`sudo apt-get update` prima di riprovare a eseguire il comando di installazione.

```
Package protobuf-compiler is not available, but is referred to by another package.
This may mean that the package is missing, has been obsoleted, or
is only available from another source
```

</Callout>

  </Tab>

    <Tab value=".rpm" >
    Su una distribuzione basata su RPM, come Fedora o Red Hat Enterprise Linux:

Aggiorna i pacchetti installati:

```terminal
$ sudo dnf upgrade --refresh
```

Installa le dipendenze di sviluppo:

```terminal
$ sudo dnf group install c-development development-tools \
&& sudo dnf install pkg-config openssl-devel
```

### Installa Rust

Gli sviluppatori creano programmi Solana utilizzando il linguaggio di
programmazione [Rust](https://www.rust-lang.org/).

1. Installa Rust utilizzando [rustup](https://www.rust-lang.org/tools/install)
   inserendo il seguente comando nel tuo terminale:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
```

Dopo un'installazione riuscita vedrai il seguente messaggio:

<Accordions>
<Accordion title="Messaggio di installazione Rust riuscita">

```
Rust is installed now. Great!

To get started you may need to restart your current shell.
This would reload your PATH environment variable to include
Cargo's bin directory ($HOME/.cargo/bin).

To configure your current shell, you need to source
the corresponding env file under $HOME/.cargo.

This is usually done by running one of the following (note the leading DOT):
. "$HOME/.cargo/env"            # For sh/bash/zsh/ash/dash/pdksh
source "$HOME/.cargo/env.fish"  # For fish
```

</Accordion>
</Accordions>

2. Ricarica la variabile d'ambiente PATH per includere la directory bin di
   [Cargo](https://github.com/rust-lang/cargo):

```terminal
$ . "$HOME/.cargo/env"
```

3. Verifica che l'installazione sia andata a buon fine.

```terminal
$ rustc --version
```

Il comando stampa la versione di Rust installata, ad esempio:

```
rustc x.y.z (...)
```

</Step>
<Step>

### Installa Solana CLI

La Solana CLI fornisce tutti gli strumenti necessari per costruire e distribuire
programmi Solana.

1. Installa la suite di strumenti Solana CLI utilizzando il comando di
   installazione ufficiale:

```terminal
$ sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

<Callout>
  Puoi sostituire `stable` con un tag di rilascio specifico di Agave oppure con il canale di rilascio `beta`
  o `edge`.
</Callout>

2. Rendi la Solana CLI disponibile nel terminale corrente.

L'installer aggiorna la configurazione della shell e stampa il comando necessario
per aggiornare la sessione corrente. Il comando è in genere:

```terminal
$ export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"
```

Se `solana` risulta ancora non disponibile, riavvia il terminale. Per verificare quale file
di configurazione della shell è stato aggiornato dall'installer, controlla la shell in uso:

```terminal
$ echo $SHELL
```

- Se l'output contiene `/bash`, riavvia il terminale oppure esegui
  `source ~/.bashrc`.
- Se l'output contiene `/zsh`, riavvia il terminale oppure esegui `source ~/.zshrc`.

3. Verifica che l'installazione sia riuscita:

```terminal
$ solana --version
```

Il comando stampa la versione installata della Solana CLI, ad esempio:

```
solana-cli x.y.z (..., client:Agave)
```

<Callout>

Puoi vedere tutte le versioni disponibili nel
[repository GitHub di Agave](https://github.com/anza-xyz/agave/releases). Agave è
il client validator di [Anza](https://www.anza.xyz/), precedentemente noto come
client validator di Solana Labs.

</Callout>

4. Per aggiornare la Solana CLI in seguito, esegui:

```terminal
$ agave-install update
```

</Step>

### Installa la CLI di Anchor

[Anchor](https://www.anchor-lang.com/) è un framework per lo sviluppo di
programmi Solana. Il framework Anchor sfrutta le macro Rust per semplificare il
processo di scrittura dei programmi Solana.

#### Prerequisiti

Node.js e un gestore di pacchetti JavaScript sono necessari solo quando selezioni un
template di test TypeScript, come Mocha o Jest. Il template di test LiteSVM predefinito
viene eseguito in Rust e non richiede strumenti Node.js.

<Accordions>
<Accordion title="Installazione di Node">

1. Installa Node usando
   [Node Version Manager (nvm)](https://github.com/nvm-sh/nvm) eseguendo il
   seguente comando:

```terminal
$ curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```

2. Riavvia il terminale e verifica che il comando `nvm` venga eseguito correttamente:

```terminal
$ command -v nvm
```

3. Usa `nvm` per installare Node:

```terminal
$ nvm install --lts
```

4. Verifica che l'installazione sia riuscita controllando la versione di Node:

```terminal
$ node --version
```

Il comando stampa la versione di Node.js installata, ad esempio:

```
vx.y.z
```

</Accordion>
<Accordion title="Installazione di Yarn">

1. Installa Yarn:

```terminal
$ npm install --global yarn
```

2. Verifica che l'installazione sia riuscita controllando la versione di Yarn:

```terminal
$ yarn --version
```

Il comando stampa la versione di Yarn installata, ad esempio:

```
x.y.z
```

</Accordion>
</Accordions>

#### Installazione

Puoi installare la CLI e gli strumenti di Anchor in due modi:

- Anchor Version Manager (AVM) — metodo di installazione consigliato
- Senza AVM — installa direttamente da GitHub

<Tabs groupId="anchor" items={["AVM", "Without AVM"]}>
<Tab value="AVM">

Anchor Version Manager (AVM) ti consente di installare e gestire diverse
versioni di Anchor sul tuo sistema e di aggiornare facilmente le versioni di
Anchor in futuro. Per installare Anchor utilizzando AVM, segui i passaggi
seguenti:

1. Installa AVM con il seguente comando:

```terminal
$ curl -sSfL https://raw.githubusercontent.com/otter-sec/anchor/master/avm/install | sh
```

2.  Conferma che AVM sia stato installato correttamente:

```terminal
$ avm --version
```

3. Installa la CLI di Anchor utilizzando AVM:

Per installare l'ultima versione:

```terminal
$ avm install latest
$ avm use latest
```

Per installare una versione specifica, specifica il numero di versione:

```terminal
$ avm install 1.1.2
$ avm use 1.1.2
```

<Callout type="warn">

Durante l'installazione di Anchor CLI su Linux o WSL, potresti incontrare questo errore:

```
error: could not exec the linker cc = note: Permission denied (os error 13)
```

Se visualizzi questo messaggio di errore, segui i passaggi seguenti:

1. Installa le dipendenze elencate nella sezione
   [Linux](/docs/intro/installation/dependencies) in cima a questa
   pagina.
2. Riprova a installare Anchor CLI.

</Callout>

4. Verifica che l'installazione sia riuscita, controllando la versione della CLI
   di Anchor:

```terminal
$ anchor --version
```

Il comando stampa la versione attiva di Anchor CLI, ad esempio:

```
anchor-cli 1.1.2
```

<Callout type="info">

Esegui `avm use` per selezionare la versione di Anchor CLI per il tuo sistema.

- Se hai installato l'ultima versione, esegui `avm use latest`.
- Se hai installato la versione `1.1.2`, esegui `avm use 1.1.2`.

</Callout>

</Tab>

<Tab value="Without AVM">

1. Installa una versione specifica di Anchor CLI con il seguente comando:

```terminal
$ cargo install --git https://github.com/solana-foundation/anchor --tag v1.1.2 anchor-cli --locked
```

2. Verifica che l'installazione sia riuscita controllando la versione di Anchor CLI:

```terminal
$ anchor --version
```

Il comando stampa la versione di Anchor CLI installata, ad esempio:

```
anchor-cli 1.1.2
```

</Tab>

### Installa Surfpool CLI

[Surfpool](/docs/tools/surfpool) è uno strumento per lo sviluppo locale e un sostituto
migliorato di `solana-test-validator`.

1. Installa Surfpool con il seguente comando:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://run.surfpool.run/ | bash
```

2. Verifica che l'installazione sia riuscita controllando la versione di
   Surfpool CLI:

```terminal
$ surfpool --version
```

Il comando stampa la versione di Surfpool CLI installata, ad esempio:

```
surfpool x.y.z
```

</Step>
