Η ενιαία παγκόσμια κατάσταση του Solana, οι χρόνοι block ~400ms και τα τέλη κάτω από ένα σεντ το καθιστούν την
κατ' εξοχήν πλατφόρμα για onchain χρηματοοικονομικά και DeFi: κάθε πρόγραμμα - DEX, αγορές δανεισμού,
oracles, perps - είναι συνθέσιμο μέσα σε μία ενιαία ατομική συναλλαγή. Αυτή η ενότητα
αποτελεί το επίπεδο ροής εργασίας για την ανάπτυξη χρηματοοικονομικών εφαρμογών· συνδέεται με τις
[Βασικές Έννοιες](/docs/core/transactions) και το
[cookbook](/developers/cookbook) για τους υποκείμενους μηχανισμούς.
