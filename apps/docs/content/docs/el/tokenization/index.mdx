Το Solana είναι σχεδιασμένο εξ αρχής για την έκδοση και λειτουργία tokenized περιουσιακών στοιχείων σε κλίμακα:
οριστικοποίηση σε κλάσματα δευτερολέπτου, προμήθειες κάτω από $0.001, και ένα πρότυπο token με εγγενείς
ελέγχους συμμόρφωσης - περιορισμοί μεταφοράς, δυνατότητα παύσης, εμπιστευτικές
μεταφορές και μόνιμοι εκπρόσωποι - που σε άλλες αλυσίδες απαιτούν προσαρμοσμένα έξυπνα
συμβόλαια.

## Πώς συνδέονται όλα μαζί

Τα tokenized περιουσιακά στοιχεία στο Solana βασίζονται στο [Token-2022 program](/docs/tokens)
και στις [επεκτάσεις](/docs/tokens/extensions) του - τα ίδια primitives που τεκμηριώνονται
στα βασικά έγγραφα. Αυτή η ενότητα είναι προσανατολισμένη στις ροές εργασίας: κάθε σελίδα παρουσιάζει μια
εργασία από την αρχή ως το τέλος και παραπέμπει στην αναφορά της υποκείμενης επέκτασης όταν χρειάζεστε την πλήρη επιφάνεια API.
