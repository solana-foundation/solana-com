# Πώς να επαληθεύσετε ένα token και να εμφανιστεί στο Solana Explorer

Ένα συνηθισμένο ερώτημα από δημιουργούς token είναι: _«Γιατί το token μου δεν εμφανίζεται όταν
το αναζητώ στο Solana Explorer και πώς μπορώ να το επαληθεύσω;»_

Η σύντομη απάντηση: το Solana Explorer δεν διαθέτει δική του ενιαία διαδικασία επαλήθευσης.
Αντίθετα, **συγκεντρώνει αρκετούς ανεξάρτητους παρόχους επαλήθευσης**.
Εάν το token σας επαληθευτεί από **έναν** από αυτούς τους παρόχους, θα
εμφανιστεί στα αποτελέσματα αναζήτησης του Explorer και θα εμφανίσει πληροφορίες επαλήθευσης.

Αυτός ο οδηγός εξηγεί κάθε πάροχο, τι σημαίνει (και τι δεν σημαίνει) «επαληθευμένο», και
πώς να επαληθεύσετε το token σας.

## Τι σημαίνει «επαληθευμένο» (και τι δεν σημαίνει)

Η επαλήθευση επιβεβαιώνει ότι ένα token είναι το **κανονικό / σωστό token** για ένα
συγκεκριμένο όνομα, σύμβολο και διεύθυνση mint. Βοηθά τους χρήστες να αποφύγουν μιμητές και
duplicate tokens, καθώς ο καθένας μπορεί να δημιουργήσει ένα token με οποιοδήποτε όνομα στο Solana.

Η επαλήθευση **δεν** αποτελεί έγκριση ενός έργου και **δεν** είναι
εγγύηση για την αξία, την ασφάλεια ή τη νομιμότητα ενός token. Κάντε πάντα τη δική σας
έρευνα.

## Οι πάροχοι επαλήθευσης πίσω από το Solana Explorer

Το Solana Explorer ελέγχει τους παρακάτω ανεξάρτητους παρόχους επαλήθευσης. Η καταγραφή από
οποιονδήποτε από αυτούς (το RugCheck είναι αυτόματο· οι υπόλοιποι απαιτούν ενέργεια) κάνει το token
σας να εμφανίζεται στην αναζήτηση του Explorer.

### 1. RugCheck (αυτόματο)

Το [RugCheck](https://rugcheck.xyz) εκτελεί αυτοματοποιημένη ανάλυση on-chain και
παρακολουθεί αυτόματα τα tokens. Επειδή είναι αυτόματο, συνήθως δεν χρειάζεται να υποβάλετε τίποτα — το RugCheck αξιολογεί σήματα κινδύνου on-chain (εξουσία mint/freeze,
κατανομή κατόχων, ρευστότητα, κ.λπ.) και παρακολουθεί το token από μόνο του.

Υπάρχει ειδική αντιμετώπιση για ορισμένα stablecoins, όπου τα έργα μπορούν να επικοινωνήσουν
άμεσα με την ομάδα RugCheck για κατάλληλη μεταχείριση.

Παράδειγμα σελίδας token:
[`rugcheck.xyz/tokens/<mint>`](https://rugcheck.xyz/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 2. Jupiter

Το [Jupiter](https://jup.ag) διατηρεί μια επαληθευμένη λίστα token (VRFD) που είναι ευρέως
ενσωματωμένη σε ολόκληρο το οικοσύστημα Solana — DEXes, πορτοφόλια και screeners. Ένα
επαληθευμένο token λαμβάνει πράσινο σήμα ελέγχου στα προϊόντα Jupiter και στις πλατφόρμες συνεργατών.

Για να επαληθευτείτε, υποβάλετε το token σας για αξιολόγηση:

- Υποβάλετε στο [verified.jup.ag/tokens](https://verified.jup.ag/tokens)
- Οποιοσδήποτε μπορεί να υποβάλει ένα token (όχι μόνο η ομάδα του έργου)
- Μπορείτε προαιρετικά να συνδέσετε τον λογαριασμό X του έργου για να συνδέσετε τη διεύθυνση mint του token
  με έναν συγκεκριμένο λογαριασμό
- Το Jupiter διεξάγει μια ολιστική αξιολόγηση (ρευστότητα, συμμόρφωση με πρότυπα μεταδεδομένων και
  άλλα σήματα) αντί να ελέγχει έναν μόνο δείκτη

Παράδειγμα σελίδας token:
[`jup.ag/tokens/<mint>`](https://jup.ag/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 3. CoinGecko

Η επαλήθευση από το [CoinGecko](https://www.coingecko.com) καταχωρεί το token σας με δεδομένα αγοράς.
Όταν επαληθεύετε με το CoinGecko, φροντίστε να συμπεριλάβετε τη **διεύθυνση mint** του token
(η φόρμα του CoinGecko την αποκαλεί «contract address») ώστε οι downstream
ενσωματώσεις να μπορούν να επιλύουν σωστά τις τιμές.

Ακολουθήστε τον επίσημο οδηγό καταχώρισης/ενημέρωσης του CoinGecko:

- [Οδηγός επαλήθευσης για αιτήματα καταχώρισης & ενημέρωσης στο CoinGecko](https://support.coingecko.com/hc/en-us/articles/23725417857817-Verification-Guide-for-Listing-Update-Requests-on-CoinGecko)

Παράδειγμα σελίδας νομίσματος:
[`coingecko.com/en/coins/<token>`](https://www.coingecko.com/en/coins/usdc)

### 4. Solflare

Το [Solflare](https://solflare.com) είναι ένας ανεξάρτητος validator στο πλαίσιο επαλήθευσης του Solana
Explorer. Στην πράξη, τα κριτήριά του για καταχώριση token επικαλύπτονται σε μεγάλο βαθμό με αυτά του Jupiter, επειδή η εσωτερική λίστα swap του Solflare τροφοδοτείται
από τον aggregator του Jupiter. Για να εμφανιστεί ένα νέο token, συνήθως πρέπει να:

- Είναι ένα έγκυρο token στο blockchain Solana με μεταδεδομένα που ακολουθούν
  το πρότυπο Metaplex Token Metadata
- Διαθέτει επαρκή ρευστότητα (ελάχιστη αξία USD του token διαθέσιμη για
  συναλλαγές)
- Διατηρεί την επίπτωση τιμής εντός αποδεκτών ορίων για τυπικές ανταλλαγές

Λόγω αυτής της επικάλυψης, τα tokens που ολοκληρώνουν την επαλήθευση Jupiter είναι συχνά
ήδη επιλέξιμα στο Solflare χωρίς χωριστή υποβολή — οπότε συνήθως δεν χρειάζεται να αντιμετωπίζετε το Solflare ως επιπλέον χειροκίνητο βήμα. Μόλις πληρούνται τα κριτήρια,
τα tokens εμφανίζονται συνήθως μέσα σε λίγα λεπτά. Δείτε:

- [Δεν μπορώ να βρω ένα token στο Solflare](https://help.solflare.com/en/articles/9260147-i-cannot-find-a-token-in-solflare)

Παράδειγμα σελίδας token:
[`solflare.com/prices/<name>/<mint>`](https://www.solflare.com/prices/usd-coin/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/)

### 5. Bluprynt (ενισχυμένο KYC)

Το [Bluprynt](https://app.bluprynt.com/register/account) προσφέρει μια ενισχυμένη
διαδρομή επαλήθευσης με πρωτόκολλο KYC. Πρόκειται για μια πιο αυστηρή, βασισμένη σε ταυτότητα
διαδικασία κατάλληλη για έργα που επιθυμούν ισχυρότερο σήμα επαλήθευσης.

- Εγγραφείτε μέσω της
  [διαδικασίας onboarding Bluprynt για το Solana Explorer](https://app.bluprynt.com/register/account)

Παράδειγμα σελίδας επαληθευμένου asset:
[`verified.bluprynt.com/verified-assets/<mint>/solana`](https://verified.bluprynt.com/verified-assets/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/solana)

## Πώς συνδυάζονται όλα μαζί

- Το **RugCheck** γίνεται αυτόματα μέσω ανάλυσης on-chain — δεν απαιτείται υποβολή.
- Το **Jupiter, CoinGecko, Solflare και Bluprynt** απαιτούν το καθένα να υποβάλετε /
  να ολοκληρώσετε την αντίστοιχη διαδικασία τους.
- Μόλις το token σας επαληθευτεί από **τουλάχιστον έναν** από αυτούς τους παρόχους, θα
  εμφανιστεί στην αναζήτηση του **Solana Explorer** και θα εμφανίσει λεπτομέρειες επαλήθευσης.

Εάν το token σας δεν εμφανίζεται ακόμη στην αναζήτηση του Explorer, η γρηγορότερη διαδρομή είναι
συνήθως η υποβολή για επαλήθευση Jupiter και/ή η ολοκλήρωση καταχώρισης στο CoinGecko,
καθώς και τα δύο είναι ευρέως ενσωματωμένα σε ολόκληρο το οικοσύστημα.

## Προαπαιτούμενα που βοηθούν την επαλήθευση να πετύχει

Ανεξάρτητα από τον πάροχο, αυτά τα βασικά on-chain στοιχεία καθιστούν την επαλήθευση πολύ
πιο πιθανό να επιτύχει:

- **Έγκυρα μεταδεδομένα**: το token σας θα πρέπει να έχει on-chain μεταδεδομένα που ακολουθούν το
  πρότυπο Metaplex Token Metadata (όνομα, σύμβολο, URI λογότυπου).
- **Ρευστότητα**: παρέχετε επαρκή ρευστότητα σε ένα υποστηριζόμενο DEX ώστε το token να μπορεί να
  διαπραγματεύεται και να αξιολογείται.
- **Σωστή διεύθυνση mint**: κάθε φορά που υποβάλλετε σε έναν πάροχο, χρησιμοποιείτε πάντα τη
  **διεύθυνση mint** του token σας (αποκαλείται «contract address» σε ορισμένες φόρμες παρόχων).

## Σύνοψη

Το Solana Explorer συγκεντρώνει πολλούς ανεξάρτητους παρόχους επαλήθευσης — **RugCheck**
(αυτόματο), **Jupiter**, **CoinGecko**, **Solflare** και **Bluprynt** (KYC).
Η επαλήθευση από οποιονδήποτε από αυτούς καθιστά το token σας ανιχνεύσιμο στην αναζήτηση του Explorer.
Η επαλήθευση επιβεβαιώνει την κανονική ταυτότητα του token· δεν αποτελεί
έγκριση, οπότε οι χρήστες θα πρέπει πάντα να κάνουν τη δική τους έρευνα.
