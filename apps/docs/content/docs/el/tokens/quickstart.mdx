---
title: "Quickstart: δημιουργία token με το CLI"
description:
  Create a token, open a token account, mint supply, and transfer tokens using
  the SPL Token CLI on devnet.
---

Αυτό το quickstart παρουσιάζει τον πλήρη κύκλο ζωής ενός token με το
_sh`spl-token`_ CLI. Θα δημιουργήσετε ένα mint, έναν λογαριασμό που μπορεί να διατηρεί το
token, θα κόψετε 100 tokens και θα μεταφέρετε μερικά σε άλλο πορτοφόλι.

Χρησιμοποιήστε το [Solana Playground](https://beta.solpg.io/) για να εκτελέσετε τις εντολές στο
πρόγραμμα περιήγησής σας, ή εγκαταστήστε το CLI τοπικά με `cargo install spl-token-cli`. Οι
διευθύνσεις στην έξοδό σας θα διαφέρουν από τα παρακάτω παραδείγματα.

## 1. Σύνδεση στο devnet

Δημιουργήστε ή συνδέστε ένα πορτοφόλι στο Solana Playground, έπειτα επιλέξτε devnet και ζητήστε
SOL για καταθέσεις λογαριασμού και χρεώσεις συναλλαγών:

```terminal
$ solana config set --url devnet
$ solana airdrop 2
```

Χρησιμοποιείτε tokens devnet μόνο για δοκιμές. Δεν έχουν οικονομική αξία.

## 2. Δημιουργία token

Δημιουργήστε το mint account που προσδιορίζει το token σας:

```terminal
$ spl-token create-token
```

Αντιγράψτε τη διεύθυνση του token από την έξοδο. Αυτή είναι η διεύθυνση mint που θα χρησιμοποιήσετε στις
υπόλοιπες εντολές. Ένα νέο mint ξεκινά με προσφορά μηδέν.

```terminal
$ spl-token supply <MINT_ADDRESS>
```

## 3. Δημιουργία token account

Το πορτοφόλι σας χρειάζεται ένα token account για αυτό το mint πριν μπορέσει να διατηρεί υπόλοιπο:

```terminal
$ spl-token create-account <MINT_ADDRESS>
```

Αυτό δημιουργεί το
[associated token account](/docs/tokens#associated-token-account) σας, του οποίου η διεύθυνση
προκύπτει από το πορτοφόλι σας και το mint.

## 4. Κοπή tokens

Κόψτε 100 tokens στο associated token account σας:

```terminal
$ spl-token mint <MINT_ADDRESS> 100
$ spl-token balance <MINT_ADDRESS>
```

Η αρχή mint πρέπει να υπογράψει αυτή την ενέργεια. Η κοπή αυξάνει τόσο το υπόλοιπο του token account σας όσο και τη συνολική προσφορά που καταγράφεται από το mint.

## 5. Μεταφορά tokens

Στείλτε 10 tokens σε άλλο πορτοφόλι devnet. Η επιλογή _sh`--fund-recipient`_
δημιουργεί το associated token account του παραλήπτη εάν δεν υπάρχει:

```terminal
$ spl-token transfer <MINT_ADDRESS> 10 <RECIPIENT_WALLET_ADDRESS> --fund-recipient
```

Η μεταφορά αλλάζει τα υπόλοιπα στα token accounts αποστολέα και παραλήπτη· δεν
αλλάζει τη συνολική προσφορά του mint.

## Προαιρετικό: προσθήκη μεταδεδομένων Token-2022

Για να αποθηκεύσετε όνομα, σύμβολο και URI απευθείας σε ένα νέο mint Token-2022, δημιουργήστε το
με ενεργοποιημένη την επέκταση μεταδεδομένων:

```terminal
$ spl-token create-token \
  --program-id TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb \
  --enable-metadata
```

Στη συνέχεια χρησιμοποιήστε τη νέα διεύθυνση mint που εκτυπώνεται από εκείνη την εντολή:

```terminal
$ spl-token initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  "EXAMPLE" \
  "https://example.com/token.json"
```

Το URI θα πρέπει να επιστρέφει ένα δημόσιο έγγραφο μεταδεδομένων JSON. Δείτε
[Token-2022 metadata](/docs/tokens/extensions/metadata) για το μοντέλο λογαριασμού
και παραδείγματα κώδικα.
