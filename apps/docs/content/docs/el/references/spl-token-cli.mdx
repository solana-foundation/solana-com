Η διεπαφή γραμμής εντολών `spl-token` δημιουργεί και διαχειρίζεται mints, token
accounts, αρχές ελέγχου, μεταφορές και επεκτάσεις Token-2022.

Η παρούσα αναφορά ακολουθεί το
[`spl-token-cli` v5.6.1](https://github.com/solana-program/token-2022/releases/tag/cli%40v5.6.1),
την έκδοση που συνοδεύει το Agave v4.2.1. Εκτελέστε `spl-token --version` και χρησιμοποιήστε
`<command> --help` για τις ακριβείς επιλογές που είναι διαθέσιμες στην εγκατεστημένη σας έκδοση.

<Callout type="warn">
  Η δημιουργία mint, οι μεταφορές, οι αλλαγές αρχών ελέγχου, οι καύσεις, οι παγώσεις και το κλείσιμο
  λογαριασμών υποβάλλουν συναλλαγές. Επιβεβαιώστε το cluster, το Token Program, τον υπογράφοντα και
  τις διευθύνσεις πριν εκτελέσετε μια εντολή. Οι αλλαγές στο Mainnet αφορούν πραγματικά περιουσιακά στοιχεία.
</Callout>

## Εγκατάσταση και λήψη βοήθειας

Το πακέτο έκδοσης του Agave CLI περιλαμβάνει το `spl-token`. Εάν δεν είναι εγκατεστημένο,
χρησιμοποιήστε το δημοσιευμένο Rust crate:

```shell
cargo install spl-token-cli --version 5.6.1
spl-token --version
```

Δείτε τη βοήθεια σε επίπεδο ρίζας ή εντολής:

```shell
spl-token --help
spl-token create-token --help
spl-token transfer --help
```

## Καθολικές επιλογές

Τοποθετήστε τις καθολικές επιλογές πριν από την εντολή.

| Επιλογή                                       | Σκοπός                                                                   |
| -------------------------------------------- | ------------------------------------------------------------------------- |
| `-u, --url <URL_OR_MONIKER>`                 | Επιλέξτε ένα RPC URL ή `mainnet-beta`, `testnet`, `devnet` ή `localhost`. |
| `-C, --config <PATH>`                        | Χρησιμοποιήστε διαφορετικό αρχείο διαμόρφωσης του Solana CLI.                            |
| `--fee-payer <KEYPAIR>`                      | Επιλέξτε τον λογαριασμό που πληρώνει τα τέλη συναλλαγής.                            |
| `-p, --program-id <ADDRESS>`                 | Χρησιμοποιήστε ρητά ένα Token Program ID.                                         |
| `--program-2022`                             | Χρησιμοποιήστε το Token-2022 (`TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb`).           |
| `--output <FORMAT>`                          | Επιστρέφει `json` ή `json-compact` όπου υποστηρίζεται.                          |
| `--with-compute-unit-limit <UNITS>`          | Ορίστε το όριο compute units της συναλλαγής.                                   |
| `--with-compute-unit-price <MICRO_LAMPORTS>` | Ορίστε την τιμή προτεραιότητας ανά compute unit.                                  |
| `-v, --verbose`                              | Εμφάνιση πρόσθετης εξόδου.                                                   |
| `-V, --version`                              | Εκτύπωση της εγκατεστημένης έκδοσης του CLI.                                          |

Το προεπιλεγμένο πρόγραμμα είναι το αρχικό Token Program. Χρησιμοποιήστε `--program-2022` για ένα
mint ή λογαριασμό Token-2022, ακόμη και κατά την ανάγνωσή του. Μια εντολή αποτυγχάνει εάν το
επιλεγμένο πρόγραμμα δεν είναι ιδιοκτήτης της παρεχόμενης διεύθυνσης.

## Δημιουργία και χρήση ενός token

Οι εντολές εκτυπώνουν τις διευθύνσεις που δημιουργήθηκαν. Αποθηκεύστε τη διεύθυνση του mint που
επιστρέφει το `create-token` για τις επόμενες εντολές.

```shell
# Create a six-decimal mint under the original Token Program.
spl-token --url devnet create-token --decimals 6

# Create the default signer's associated token account for the mint.
spl-token --url devnet create-account <MINT_ADDRESS>

# Mint 100 tokens to that associated token account.
spl-token --url devnet mint <MINT_ADDRESS> 100

# Read supply, balance, and complete mint or account details.
spl-token --url devnet supply <MINT_ADDRESS>
spl-token --url devnet balance <MINT_ADDRESS>
spl-token --url devnet display <MINT_OR_TOKEN_ACCOUNT_ADDRESS>

# Transfer tokens to a wallet and create its associated account if needed.
spl-token --url devnet transfer \
  <MINT_ADDRESS> \
  10 \
  <RECIPIENT_WALLET_ADDRESS> \
  --fund-recipient
```

Τα ποσά είναι ποσά token σε μορφή UI, προσαρμοσμένα στα δεκαδικά ψηφία του mint. Εντολές όπως οι
`transfer`, `burn` και `unwrap-sol` δέχονται το `ALL` όπου αναφέρεται στη βοήθειά τους.

## Δημιουργία mint Token-2022

Οι επεκτάσεις δεσμεύουν επιπλέον κατάσταση mint ή λογαριασμού και συνήθως πρέπει να επιλεγούν όταν
δημιουργείται το mint. Αυτό το παράδειγμα δημιουργεί ένα mint έξι δεκαδικών ψηφίων με υποστήριξη
ενσωματωμένων μεταδεδομένων:

```shell
spl-token --program-2022 create-token \
  --decimals 6 \
  --enable-metadata

spl-token --program-2022 initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  EXAMPLE \
  https://example.com/token.json
```

Συνηθισμένες επιλογές επεκτάσεων του `create-token` περιλαμβάνουν:

- `--enable-close`
- `--enable-confidential-transfers auto|manual`
- `--enable-freeze`
- `--enable-group` και `--enable-member`
- `--enable-metadata`
- `--enable-non-transferable`
- `--enable-pause`
- `--enable-permanent-delegate`
- `--enable-permissioned-burn`
- `--enable-transfer-hook` ή `--transfer-hook <PROGRAM_ID>`
- `--interest-rate <BASIS_POINTS>`
- `--transfer-fee-basis-points <BASIS_POINTS>` με
  `--transfer-fee-maximum-fee <AMOUNT>`
- `--ui-amount-multiplier <MULTIPLIER>`

Συνδυάζετε μόνο επεκτάσεις που το πρόγραμμα Token-2022 επιτρέπει να χρησιμοποιούνται μαζί. Ανατρέξτε στον
σχετικό [οδηγό επεκτάσεων Token-2022](/docs/tokens/extensions) πριν δημιουργήσετε
μια μη αναστρέψιμη διαμόρφωση mint.

## Διαχείριση αρχών ελέγχου και delegates

```shell
# Change the mint authority.
spl-token authorize <MINT_ADDRESS> mint <NEW_AUTHORITY_ADDRESS>

# Permanently remove the mint authority.
spl-token authorize <MINT_ADDRESS> mint --disable

# Let a delegate spend up to 25 tokens from one token account.
spl-token approve \
  <TOKEN_ACCOUNT_ADDRESS> \
  25 \
  <DELEGATE_ADDRESS>

# Remove the current delegate.
spl-token revoke <TOKEN_ACCOUNT_ADDRESS>
```

Το `authorize` υποστηρίζει τύπους αρχών ελέγχου mint, freeze, owner, close, καθώς και τύπους ειδικούς για
επεκτάσεις. Η αφαίρεση μιας αρχής ελέγχου με `--disable` είναι μόνιμη όταν κανένας
άλλος μηχανισμός προγράμματος δεν μπορεί να την επαναφέρει.

## Πάγωμα, καύση και κλείσιμο

```shell
spl-token freeze <TOKEN_ACCOUNT_ADDRESS>
spl-token thaw <TOKEN_ACCOUNT_ADDRESS>

spl-token burn <TOKEN_ACCOUNT_ADDRESS> 5

# A token account must normally have a zero token balance before closing.
spl-token close --address <TOKEN_ACCOUNT_ADDRESS>
```

Το `burn` μειώνει τόσο το υπόλοιπο του λογαριασμού όσο και τη συνολική προσφορά. Το `close` επιστρέφει τα
υπολειπόμενα lamports του λογαριασμού στον ρυθμισμένο παραλήπτη· δεν ανακτά
τα tokens που έχουν καεί.

## Wrap και unwrap SOL

```shell
# Create or fund the owner's wrapped SOL token account.
spl-token wrap 1

# Unwrap part of the wrapped SOL balance.
spl-token unwrap-sol 0.25

# Close the wrapped SOL account and return its full lamport balance.
spl-token unwrap
```

Χρησιμοποιήστε το `sync-native` μετά τη μεταφορά lamports απευθείας σε ένα wrapped SOL token
account, ώστε το ποσό token του να συμφωνεί με τα υποκείμενα lamports.

## Υπογραφή multisig

Δημιουργήστε ένα multisig M-of-N του Token Program με έως 11 μέλη:

```shell
spl-token create-multisig \
  2 \
  <MEMBER_1_ADDRESS> \
  <MEMBER_2_ADDRESS> \
  <MEMBER_3_ADDRESS>
```

Για μια συναλλαγή που ελέγχεται από αυτό το multisig, περάστε τη διεύθυνση του multisig ως τη
σχετική αρχή ελέγχου και παρέχετε τα keypairs των μελών μέσω επαναλαμβανόμενων τιμών
`--multisig-signer`. Ελέγξτε τη βοήθεια της εντολής-στόχου, επειδή η κύρια σημαία
αρχής ελέγχου διαφέρει ανά λειτουργία.

## Εμπιστευτικά υπόλοιπα

Οι εντολές εμπιστευτικών υπολοίπων απαιτούν ένα mint Token-2022 ρυθμισμένο για
εμπιστευτικές μεταφορές και έναν ρυθμισμένο λογαριασμό παραλήπτη.

```shell
spl-token --program-2022 configure-confidential-transfer-account \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 deposit-confidential-tokens \
  <MINT_ADDRESS> \
  10 \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 apply-pending-balance \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 withdraw-confidential-tokens \
  <MINT_ADDRESS> \
  5 \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 transfer \
  <MINT_ADDRESS> \
  1 \
  <RECIPIENT_ADDRESS> \
  --confidential
```

Για τα `configure-confidential-transfer-account` και `apply-pending-balance`, περάστε
είτε `--address <TOKEN_ACCOUNT_ADDRESS>` είτε ένα θεσιακό `<MINT_ADDRESS>`, όχι
και τα δύο. Η θεσιακή μορφή χρησιμοποιεί το associated token account του ιδιοκτήτη. Η κατάθεση και η
ανάληψη λαμβάνουν πάντα το mint και δέχονται το `--address` για να παρακάμψουν αυτόν τον
προεπιλεγμένο λογαριασμό.

Χρησιμοποιήστε τα `enable-confidential-credits`, `disable-confidential-credits`,
`enable-non-confidential-credits` και `disable-non-confidential-credits` για να
ελέγξετε ποιες καταθέσεις δέχεται ο λογαριασμός. Αυτές οι ρυθμίσεις επηρεάζουν το απόρρητο
του λογαριασμού και τη συμβατότητα πληρωμών· επιθεωρήστε τον λογαριασμό πριν τις αλλάξετε.

## Δομημένη και offline υπογραφή

Χρησιμοποιήστε δομημένη έξοδο αντί για ανάλυση του κειμένου εμφάνισης:

```shell
spl-token accounts --output json
spl-token display <MINT_ADDRESS> --output json-compact
```

Οι εντολές που παράγουν συναλλαγές συνήθως υποστηρίζουν τα `--sign-only`, `--blockhash`,
`--signer <PUBKEY=SIGNATURE>`, `--nonce` και `--nonce-authority`. Οι ακριβείς
είσοδοι offline εξαρτώνται από την εντολή, τα δεκαδικά ψηφία του mint και τη διάταξη των αρχών ελέγχου,
οπότε δημιουργήστε το μη υπογεγραμμένο μήνυμα ακολουθώντας τις οδηγίες `--help` της εντολής και
επαληθεύστε κάθε διεύθυνση πριν συλλέξετε υπογραφές.
