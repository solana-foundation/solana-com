---
title: Προγραμματισμός staking
---

Για να μεγιστοποιηθεί η κατανομή των stakes, η αποκέντρωση και η αντίσταση στη
λογοκρισία στο δίκτυο Solana, το staking μπορεί να πραγματοποιηθεί
προγραμματιστικά. Η ομάδα και η κοινότητα έχουν αναπτύξει αρκετά onchain και
offchain προγράμματα για να διευκολύνουν τη διαχείριση των stakes.

### Πρόγραμμα ανάθεσης του Solana Foundation

Το
[Πρόγραμμα ανάθεσης του Solana Foundation](https://solana.org/delegation-program)
είναι σχεδιασμένο να εξυπηρετεί τις ανάγκες του δικτύου στοχεύοντας στους
ακόλουθους στόχους:

1. Μεγιστοποίηση της αποκέντρωσης, αξιοπιστίας και απόδοσης του Solana
2. Μεγιστοποίηση του αριθμού των validators που έχουν διαφορετικές πηγές stake
3. Διατήρηση ενός μεγάλου και αντιπροσωπευτικού testnet

### Stake Pools

Αυτό το onchain πρόγραμμα συγκεντρώνει SOL για να γίνει staking από έναν διαχειριστή, επιτρέποντας στους κατόχους SOL
να κάνουν staking και να κερδίζουν ανταμοιβές χωρίς να διαχειρίζονται οι ίδιοι τα stakes. Οι χρήστες καταθέτουν SOL με αντάλλαγμα
τokens SPL (παράγωγα staking) που αντιπροσωπεύουν τη συμμετοχή τους στο
stake pool. Ο διαχειριστής του pool κάνει staking στα SOL που έχουν κατατεθεί σύμφωνα με τη
στρατηγική του, ενδεχομένως χρησιμοποιώντας μια παραλλαγή ενός bot αυτόματης ανάθεσης (auto-delegation) όπως περιγράφεται παραπάνω.
Καθώς τα stakes κερδίζουν ανταμοιβές, το pool και τα pool tokens αυξάνονται ανάλογα σε αξία.
Τέλος, οι κάτοχοι pool tokens μπορούν να στείλουν tokens SPL πίσω στο stake pool για να εξαργυρώσουν
SOL, συμμετέχοντας έτσι στην αποκέντρωση με πολύ λιγότερη προσπάθεια.
Περισσότερες πληροφορίες μπορείτε να βρείτε στην
[τεκμηρίωση του Stake Pool](https://www.solana-program.com/docs/stake-pool).
