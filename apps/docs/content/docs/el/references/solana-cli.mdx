Η διεπαφή γραμμής εντολών `solana` ρυθμίζει τη σύνδεση με ένα cluster, διαβάζει
την κατάσταση του δικτύου, στέλνει SOL, διαχειρίζεται durable nonces, αναπτύσσει προγράμματα και λειτουργεί
λογαριασμούς stake και ψήφου.

Η παρούσα αναφορά ακολουθεί το
[Agave v4.2.1](https://github.com/anza-xyz/agave/releases/tag/v4.2.1). Εκτελέστε
`solana --version` για να ελέγξετε την εγκατεστημένη έκδοση και χρησιμοποιήστε `--help` για τις ακριβείς
επιλογές που διατίθενται σε αυτήν την έκδοση.

<Callout type="warn">
  Οι εντολές που δημιουργούν, μεταφέρουν, εξουσιοδοτούν, αποσύρουν ή αναπτύσσουν υποβάλλουν
  συναλλαγές. Επιβεβαιώστε το ρυθμισμένο cluster και τον signer πριν τις εκτελέσετε.
  Τα tokens στα Devnet και Testnet δεν έχουν αξία· οι εντολές στο Mainnet χρησιμοποιούν πραγματικά SOL.
</Callout>

## Δομή εντολών

```text
solana [GLOBAL_OPTIONS] <COMMAND> [COMMAND_OPTIONS]
```

Λάβετε βοήθεια σε οποιοδήποτε επίπεδο:

```shell
solana --help
solana transfer --help
solana address-lookup-table extend --help
```

## Καθολικές επιλογές

Οι καθολικές επιλογές μπορούν να τοποθετηθούν πριν από την εντολή. Η βοήθεια της κάθε εντολής επαναλαμβάνει
τις επιλογές που ισχύουν για αυτήν.

| Επιλογή                          | Σκοπός                                                                        |
| ------------------------------- | ------------------------------------------------------------------------------ |
| `-u, --url <URL_OR_MONIKER>`    | Επιλέξτε ένα RPC URL ή `mainnet-beta`, `testnet`, `devnet` ή `localhost`.      |
| `--ws <URL>`                    | Αντικατάσταση του endpoint WebSocket.                                               |
| `-k, --keypair <KEYPAIR>`       | Επιλέξτε ένα αρχείο keypair, `ASK`, stdin (`-`) ή ένα υποστηριζόμενο URL signer.          |
| `-C, --config <FILEPATH>`       | Χρήση διαφορετικού αρχείου ρυθμίσεων του CLI.                                        |
| `--commitment <LEVEL>`          | Ανάγνωση με commitment `processed`, `confirmed` ή `finalized`.                   |
| `--output <FORMAT>`             | Επιστροφή `json` ή `json-compact` όπου υποστηρίζεται.                               |
| `--skip-preflight`              | Αποστολή χωρίς προσομοίωση RPC. Χρησιμοποιήστε το μόνο εφόσον κατανοείτε τον συμβιβασμό σε περίπτωση αποτυχίας. |
| `--use-tpu-client`              | Αποστολή συναλλαγών μέσω του πελάτη TPU.                                      |
| `--no-address-labels`           | Εκτύπωση διευθύνσεων χωρίς τοπικές ετικέτες.                                          |
| `--skip-seed-phrase-validation` | Επιτρέπει φράση ανάκτησης εκτός της αγγλικής λίστας BIP39.                       |
| `-v, --verbose`                 | Εμφάνιση πρόσθετης εξόδου της εντολής.                                                |
| `-V, --version`                 | Εκτύπωση της εγκατεστημένης έκδοσης του CLI.                                               |

## Ρύθμιση του CLI

```shell
# Inspect the effective configuration.
solana config get

# Use Devnet and a specific signer by default.
solana config set --url devnet
solana config set --keypair ./devnet-keypair.json

# Override defaults for one command.
solana --url mainnet-beta --keypair usb://ledger address
```

Οι ρυθμίσεις περιλαμβάνουν ένα RPC URL, ένα URL WebSocket, τον προεπιλεγμένο signer και
το commitment. Μια επιλογή γραμμής εντολών υπερισχύει της αποθηκευμένης τιμής για τη συγκεκριμένη εκτέλεση.

## Συνήθεις ροές εργασίας λογαριασμών και συναλλαγών

```shell
# Print the default signer's address and balance.
solana address
solana balance

# Read an account as JSON.
solana account <ACCOUNT_ADDRESS> --output json

# Request Devnet SOL.
solana airdrop 1 --url devnet

# Send SOL and then confirm the returned signature.
solana transfer <RECIPIENT_ADDRESS> 0.1 --allow-unfunded-recipient
solana confirm <TRANSACTION_SIGNATURE>

# Inspect recent activity and stream logs mentioning an address.
solana transaction-history <ADDRESS> --limit 20
solana logs <ADDRESS>
```

Η `transfer` δέχεται από προεπιλογή SOL. Χρησιμοποιήστε το `ALL` ως ποσό για να μεταφέρετε το διαθέσιμο
υπόλοιπο μετά τα τέλη. Για παραδείγματα με tokens, δείτε τον
[οδηγό γρήγορης εκκίνησης για tokens](/docs/tokens/quickstart).

## Ροές εργασίας προγραμμάτων

```shell
# Deploy or upgrade an SBF program.
solana program deploy ./target/deploy/my_program.so

# Inspect the deployed program and list programs controlled by the signer.
solana program show <PROGRAM_ID>
solana program show --programs

# Close a program buffer and recover its lamports.
solana program close <BUFFER_ADDRESS>
```

Περάστε `--program-id <KEYPAIR_OR_ADDRESS>` όταν μια ανάπτυξη πρέπει να χρησιμοποιήσει ένα γνωστό
program ID. Το `--final` καθιστά μια νέα ανάπτυξη αμετάβλητη· διαβάστε προσεκτικά τη βοήθειά του
πριν το χρησιμοποιήσετε, επειδή η upgrade authority δεν μπορεί να αποκατασταθεί.

## Ροές εργασίας durable nonce

```shell
solana-keygen new --outfile nonce-account.json
solana create-nonce-account nonce-account.json 0.1
solana nonce nonce-account.json
solana new-nonce nonce-account.json
solana withdraw-from-nonce-account nonce-account.json <RECIPIENT_ADDRESS> ALL
```

Χρησιμοποιήστε την `authorize-nonce-account` για να αλλάξετε την nonce authority και την `nonce-account`
για να ελέγξετε την πλήρη κατάσταση του λογαριασμού. Οι συναλλαγές που χρησιμοποιούν nonce δέχονται επίσης
τα `--nonce` και `--nonce-authority` στις εντολές που τα υποστηρίζουν.

## Ροές εργασίας stake

```shell
solana-keygen new --outfile stake-account.json
solana create-stake-account stake-account.json 1
solana delegate-stake stake-account.json <VOTE_ACCOUNT_ADDRESS>
solana stake-account stake-account.json

solana deactivate-stake stake-account.json
solana withdraw-stake stake-account.json <RECIPIENT_ADDRESS> ALL
```

Η απενεργοποίηση ολοκληρώνεται στο όριο ενός epoch και μπορεί να διαρκέσει περισσότερα από ένα epoch.
Χρησιμοποιήστε τις `stakes`, `validators`, `stake-history` και `stake-minimum-delegation` για να
επιθεωρήσετε την κατάσταση του cluster και των αναθέσεων πριν υποβάλετε αλλαγές.

## Βοηθητικά εργαλεία διευθύνσεων

```shell
# Derive a PDA from typed seeds.
solana find-program-derived-address \
  <PROGRAM_ID> \
  string:profile \
  pubkey:<OWNER_ADDRESS>

# Create and extend an address lookup table.
solana address-lookup-table create
solana address-lookup-table extend \
  <LOOKUP_TABLE_ADDRESS> \
  --addresses <ADDRESS_1>,<ADDRESS_2>
```

Τα PDA seeds χρησιμοποιούν τη μορφή `PREFIX:VALUE`. Τα υποστηριζόμενα προθέματα περιλαμβάνουν `string`, `pubkey`,
`hex`, `u8` και κωδικοποιήσεις ακεραίων σταθερού πλάτους, με ή χωρίς πρόσημο, όπως το
`u64le`.

## Μηνύματα εκτός αλυσίδας και συμπλήρωση εντολών στο shell

```shell
solana sign-offchain-message "terms accepted"
solana verify-offchain-signature \
  "terms accepted" \
  <SIGNATURE> \
  --signer <SIGNER_ADDRESS>

# Print a completion script for the current shell.
solana completion --shell zsh
```

## Έξοδος για σενάρια

Χρησιμοποιήστε `--output json` ή `--output json-compact` όπου υποστηρίζεται, αντί να
αναλύετε την έξοδο που προορίζεται για ανθρώπους:

```shell
solana epoch-info --output json
solana account <ACCOUNT_ADDRESS> --output json-compact
solana validators --output json > validators.json
```

Δεν υποστηρίζουν όλες οι εντολές δομημένη έξοδο. Ελέγξτε τη βοήθεια της εντολής πριν
βασιστείτε σε αυτήν σε αυτοματισμούς και αντιμετωπίστε τη μη μηδενική κατάσταση εξόδου ως αποτυχία.
