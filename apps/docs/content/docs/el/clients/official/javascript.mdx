## Solana Kit

`@solana/kit` είναι το συνιστώμενο TypeScript SDK για ανάπτυξη στο Solana.
Συναρμολογείτε έναν client από συνθέσιμα plugins, προσθέτετε React bindings όταν
τα χρειάζεστε, και ενσωματώνετε παραγόμενους program clients για τα on-chain
programs που καλείτε.

| Package                   | Περιγραφή                                  | GitHub                                                                                 |
| ------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------- |
| @solana/kit               | Core SDK: RPC, transactions, codecs, signers | [Πηγή](https://github.com/anza-xyz/kit)                                              |
| @solana/react             | React bindings: `ClientProvider` και hooks   | [Πηγή](https://github.com/anza-xyz/kit/tree/main/packages/react)                     |
| @solana/kit-plugin-rpc    | Σύνδεση RPC + αποστολή συναλλαγών         | [Πηγή](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-rpc)    |
| @solana/kit-plugin-signer | Plugins για fee payer, identity και signer      | [Πηγή](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-signer) |
| @solana/kit-plugin-wallet | Σύνδεση Wallet Standard + React hooks     | [Πηγή](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-wallet) |

## Solana Web3.js v3

Το `@solana/web3.js` v3 είναι η προτεινόμενη έκδοση του web3.js. Ανακατασκευάζει
το κλασικό API που βασίζεται σε κλάσεις — `Connection`, `Keypair`, `Transaction`, `PublicKey` —
πάνω στα εσωτερικά του `@solana/kit`, ώστε να λειτουργεί με τα βασικά στοιχεία του Kit και
τους παραπάνω πελάτες προγραμμάτων (program clients). Χρησιμοποιήστε το εάν αναβαθμίζετε μια υπάρχουσα εφαρμογή web3.js ή
προτιμάτε το API που βασίζεται σε κλάσεις.

Οι περισσότερες μέθοδοι που ήταν σύγχρονες στο παλαιό SDK, όπως οι
`Keypair.generate()` και `transaction.sign()`, είναι πλέον ασύγχρονες.

```bash
npm install @solana/web3.js@3
```

| Package         | Περιγραφή | GitHub                                                        |
| --------------- | ----------- | ------------------------------------------------------------- |
| @solana/web3.js | Βασικό SDK    | [Πηγή](https://github.com/solana-foundation/solana-web3.js) |

Το `@solana/spl-token` εξαρτάται από το `@solana/web3.js` (legacy) και δεν λειτουργεί
στο v3. Χρησιμοποιήστε αντί αυτού το `@solana-program/token` ή το `@solana-program/token-2022`· οι
παραγόμενες εντολές και τα σχέδια εντολών (instruction plans) τους λειτουργούν απευθείας με το
`Transaction.add()` του v3.

- [Οδηγός μετάβασης από web3.js v1 σε v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
- [Οδηγός μετάβασης του spl-token](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-spl-token-migration.md)

## Solana Web3.js (legacy)

Το `@solana/web3.js` (legacy, `1.x`) είναι το αρχικό SDK TypeScript για το Solana. Βρίσκεται
σε λειτουργία συντήρησης και λαμβάνει μόνο κρίσιμες διορθώσεις. Οι υπάρχουσες βάσεις κώδικα μπορούν να
[αναβαθμιστούν στο web3.js v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
ή να [μεταβούν στο Kit](/docs/frontend/web3-compat).
