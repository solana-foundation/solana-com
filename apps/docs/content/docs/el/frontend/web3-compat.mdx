title: Μετάβαση στο Kit
description:
  Πώς οι έννοιες του @solana/web3.js και του wallet-adapter αντιστοιχίζονται στο @solana/kit.
---

Αν προέρχεστε από το `@solana/web3.js` (legacy), το `@solana/wallet-adapter-*`
ή τα παλαιότερα πακέτα του framework-kit (`@solana/client`, `@solana/react-hooks`,
`@solana/web3-compat`), σας ενθαρρύνουμε να μεταβείτε στα plugins του `@solana/kit` ή
στο `@solana/web3.js` v3 (ή νεότερο).

Αυτή η σελίδα αντιστοιχίζει τις έννοιες που ήδη γνωρίζετε με τα ισοδύναμά τους στο Kit.

## Αντιστοίχιση εννοιών

| web3.js (legacy) / wallet-adapter      | Kit                                                                  |
| -------------------------------------- | -------------------------------------------------------------------- |
| `new Connection(url)`                  | `createSolanaRpc(url)`, ή `.use(solanaRpc({ rpcUrl }))` σε ένα client |
| `PublicKey`                            | `Address` — μετατροπή string με `address("...")`                    |
| `Keypair`                              | `generateKeyPairSigner()` ή τα plugins `@solana/kit-plugin-signer` |
| `SystemProgram.transfer(...)`          | `getTransferSolInstruction(...)` από το `@solana-program/system`       |
| `LAMPORTS_PER_SOL` math                | `lamports(...)` από το `@solana/kit`                                   |
| `Transaction` / `VersionedTransaction` | Μηνύματα συναλλαγών που δομούνται και συσκευάζονται από τον transaction planner     |
| `sendAndConfirmTransaction(...)`       | `client.sendTransaction([...])` (ο planner υπογράφει, αποστέλλει και επιβεβαιώνει) |
| `@solana/wallet-adapter-*`             | `@solana/kit-plugin-wallet` + ανακάλυψη μέσω Wallet Standard              |

Το web3.js v3 διατηρεί τα παραπάνω ονόματα που βασίζονται σε κλάσεις — `Connection`, `Keypair`,
`Transaction`, `PublicKey` — ως λεπτά wrappers πάνω από τα εσωτερικά στοιχεία του Kit, επομένως η στήλη
Kit περιγράφει επίσης τι κάνουν αυτές οι κλάσεις στο παρασκήνιο στο v3.

## Έρχεστε από το web3.js;

Αν συντηρείτε μια μεγάλη βάση κώδικα με `@solana/web3.js` (legacy) και μια πλήρης επανεγγραφή
σε Kit δεν είναι πρακτική, το web3.js v3 αποτελεί τη γέφυρα. Εγκαταστήστε το με
`@solana/web3.js@3`. Αναδομεί το κλασικό API που βασίζεται σε κλάσεις — `Connection`,
`Keypair`, `Transaction`, `PublicKey` — πάνω στα εσωτερικά στοιχεία του `@solana/kit`.
Επειδή βασίζεται στο Kit, η διαλειτουργικότητα είναι στενή: το `PublicKey` είναι ο κύριος τύπος
διεύθυνσης και η μέθοδος `.toBase58()` επιστρέφει το branded string `Address` του Kit, ενώ ένα v3
`Keypair` υλοποιεί το `KeyPairSigner` του Kit, οπότε μπορείτε να το περάσετε απευθείας σε APIs, plugins
και clients του Kit που έχουν δημιουργηθεί με το Codama.

<Callout type="warn" title="Συναλλαγές v1 και web3.js (legacy)">
  Αν στέλνετε συναλλαγές v1 με το web3.js, πρέπει να χρησιμοποιήσετε την έκδοση v3 ή νεότερη.
</Callout>

Για την ίδια τη μετάβαση, δείτε τον επίσημο
[οδηγό μετάβασης από web3.js v1 σε v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md).

## Πορτοφόλια

Το Kit δεν χρησιμοποιεί wallet-adapter. Το `@solana/kit-plugin-wallet`
ανακαλύπτει πορτοφόλια Wallet Standard και τα εκθέτει μέσω του `client.wallet`
και των [React hooks](/docs/frontend/react-hooks). Τα σύγχρονα πορτοφόλια
(Phantom, Solflare, Backpack και άλλα) διαφημίζουν τον εαυτό τους μέσω του
Wallet Standard, οπότε δεν απαιτείται πακέτο προσαρμογέα ανά πορτοφόλι.

Μπορείτε επίσης να χρησιμοποιήσετε προκατασκευασμένα εργαλεία όπως το
[@solana/connector](https://www.npmjs.com/package/@solana/connector), το οποίο
χρησιμοποιεί απευθείας τα primitives του Kit για σύνδεση με πορτοφόλια.

<Callout type="info" title="Χρησιμοποιείτε ακόμα wallet-adapter;">
  Αν διαχειρίζεστε μια εφαρμογή που έχει κατασκευαστεί στο
  `@solana/wallet-adapter-*` και δεν είστε έτοιμοι να μεταβείτε, το [αποθετήριο
  wallet-adapter ](https://github.com/anza-xyz/wallet-adapter) παραμένει η
  αναφορά για αυτό το stack. Για οτιδήποτε νέο, προτιμήστε το plugin πορτοφολιού
  του Kit.
</Callout>
