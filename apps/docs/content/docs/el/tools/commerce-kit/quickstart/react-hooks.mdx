<Callout type="warn" title="Το Commerce Kit δεν συντηρείται πλέον">
  Τα πακέτα του Commerce Kit δεν λαμβάνουν πλέον ενημερώσεις ή διορθώσεις. Για νέες
  ενσωματώσεις πληρωμών, χρησιμοποιήστε το [Solana Pay](/docs/tools/solana-pay).
</Callout>

Το πακέτο `@solana-commerce/sdk` παρέχει React hooks για τη δημιουργία προσαρμοσμένων
εμπειριών πληρωμής στο Solana. Τα hooks αυτά προσφέρουν πλήρη έλεγχο των μεταφορών SOL και
SPL token, με ενσωματωμένη διαχείριση κατάστασης, αυτόματη λογική επανάληψης, χειρισμό
σφαλμάτων και βοηθητικά εργαλεία διεπαφής.

Στο παρασκήνιο, το SDK χρησιμοποιεί το [TanStack Query](https://tanstack.com/query) για
την προσωρινή αποθήκευση (caching) και τη διαχείριση κατάστασης, το [@solana/kit](https://github.com/anza-xyz/kit) για
τα βασικά δομικά στοιχεία του Solana, και ενσωματώνεται απρόσκοπτα με το `@solana-commerce/connector`
για τη σύνδεση πορτοφολιού.

## Εγκατάσταση

```bash
pnpm add @solana-commerce/sdk
```

## Ρύθμιση του Provider

### `ArcProvider`

Ο `ArcProvider` είναι ο βασικός provider που αρχικοποιεί τον πελάτη Solana RPC,
διαχειρίζεται τη ρύθμιση του δικτύου και παρέχει συνδεσιμότητα με το blockchain σε όλα τα
hooks. Πρέπει να περιβάλλει κάθε component που χρησιμοποιεί hooks του SDK.

#### Props

- **`config`** (`ArcWebClientConfig`) - Αντικείμενο ρύθμισης για τον πελάτη Arc
- **`children`** (`ReactNode`) - Θυγατρικά components που θα έχουν πρόσβαση στα
  hooks
- **`queryClient`** (`QueryClient`, προαιρετικό) - Προσαρμοσμένος πελάτης TanStack Query. Αν
  δεν δοθεί, δημιουργείται εσωτερικά μια προεπιλεγμένη παρουσία.

#### `ArcWebClientConfig`

Ρύθμιση για τον πελάτη Arc που ελέγχει τη συνδεσιμότητα RPC και τα επίπεδα
επιβεβαίωσης (commitment).

##### Απαιτούμενα πεδία

Ο provider ενσωματώνεται αυτόματα με το `@solana-commerce/connector` μέσω
του hook `useConnectorClient`, επομένως δεν χρειάζεται ρητή ρύθμιση του connector
όταν χρησιμοποιείται εντός ενός `ConnectorProvider`.

##### Προαιρετικά πεδία

- **`network`** (`'mainnet' | 'devnet' | 'testnet'`) - Το δίκτυο Solana στο οποίο θα γίνει σύνδεση.
  Προεπιλογή: `'mainnet'`.

- **`rpcUrl`** (`string`) - Προσαρμοσμένο URL endpoint RPC. Αν δεν δοθεί, χρησιμοποιεί
  δημόσια endpoints για το επιλεγμένο δίκτυο.

- **`commitment`** (`'processed' | 'confirmed' | 'finalized'`) - Επίπεδο
  επιβεβαίωσης συναλλαγής. Προεπιλογή: `'confirmed'`.

- **`debug`** (`boolean`) - Ενεργοποιεί αναλυτική καταγραφή στην κονσόλα για εντοπισμό σφαλμάτων.
  Προεπιλογή: `false`.

- **`autoConnect`** (`boolean`) - Συνδέεται αυτόματα στο πορτοφόλι όταν το
  component γίνεται mount. Προεπιλογή: `true`.

- **`storage`** (`Storage`) - Προσαρμοσμένος προσαρμογέας αποθήκευσης για τη διατήρηση των προτιμήσεων
  πορτοφολιού. Πρέπει να υλοποιεί:
  - `getItem(key: string): string | null`
  - `setItem(key: string, value: string): void`
  - `removeItem(key: string): void`

  Προεπιλογή: `window.localStorage` όταν είναι διαθέσιμο (μόνο σε πρόγραμμα περιήγησης). Χρησιμοποιήστε το για
  React Native (`AsyncStorage`) ή για προσαρμοσμένη αποθήκευση ασφαλή για SSR.

#### Ενσωμάτωση με το `ConnectorProvider`

Ο provider ενσωματώνεται με το `ConnectorProvider` από το
`@solana-commerce/connector`. Περιβάλλετε πάντα την εφαρμογή σας με το `ConnectorProvider`
πριν από τον `ArcProvider`:

```tsx
import { ConnectorProvider } from "@solana-commerce/connector";
import { ArcProvider } from "@solana-commerce/sdk";

function App() {
  return (
    <ConnectorProvider config={{ autoConnect: true }}>
      <ArcProvider config={{ network: "mainnet", commitment: "confirmed" }}>
        <YourApp />
      </ArcProvider>
    </ConnectorProvider>
  );
}
```

## Βασικά Hooks

### `useTransferSOL`

Hook για τη μεταφορά SOL με αυτόματη λογική επανάληψης, διαχείριση κατάστασης και βοηθητικές
συναρτήσεις διεπαφής. Βασίζεται στο TanStack Query για caching και αποδοχή μοναδικών αιτημάτων (deduplication).

#### Υπογραφή

```typescript
function useTransferSOL(
  initialToInput?: string,
  initialAmountInput?: string
): UseTransferSOLReturn;
```

#### Παράμετροι

- **`initialToInput`** (`string`, προαιρετικό) - Αρχική τιμή για το πεδίο διεύθυνσης
  παραλήπτη. Χρήσιμο για την προσυμπλήρωση φορμών.
- **`initialAmountInput`** (`string`, προαιρετικό) - Αρχική τιμή για το πεδίο ποσού
  σε SOL. Χρήσιμο για την προσυμπλήρωση φορμών.

#### Τιμή επιστροφής

```typescript
interface UseTransferSOLReturn {
  // Core transfer function
  transferSOL: (options: TransferSOLOptions) => Promise<TransferSOLResult>;

  // State
  isLoading: boolean;
  error: Error | null;
  data: TransferSOLResult | null;
  reset: () => void;

  // UI Helpers
  toInput: string;
  amountInput: string;
  setToInput: (value: string) => void;
  setAmountInput: (value: string) => void;
  handleToInputChange: (event: React.ChangeEvent<HTMLInputElement>) => void;
  handleAmountInputChange: (event: React.ChangeEvent<HTMLInputElement>) => void;
  handleSubmit: (event?: {
    preventDefault?: () => void;
  }) => Promise<TransferSOLResult | undefined>;
  transferFromInputs: () => Promise<TransferSOLResult | undefined>;
}
```

##### Βασική συνάρτηση

- **`transferSOL`** - Ξεκινά μια μεταφορά SOL. Επιστρέφει ένα promise που επιλύεται
  όταν η συναλλαγή επιβεβαιωθεί στο blockchain.

##### Ιδιότητες κατάστασης

- **`isLoading`** (`boolean`) - `true` ενώ η συναλλαγή βρίσκεται σε επεξεργασία
  (υπογραφή, υποβολή, επιβεβαίωση). Χρησιμοποιήστε το για ενδείξεις φόρτωσης και καταστάσεις
  κουμπιών.

- **`error`** (`Error | null`) - Αντικείμενο σφάλματος αν η συναλλαγή απέτυχε σε οποιοδήποτε
  στάδιο. `null` όταν δεν υπάρχει σφάλμα. Τα σφάλματα περιλαμβάνουν απορρίψεις από το πορτοφόλι, ανεπαρκές
  υπόλοιπο, αστοχίες δικτύου κ.λπ.

- **`data`** (`TransferSOLResult | null`) - Αντικείμενο αποτελέσματος όταν η συναλλαγή
  ολοκληρωθεί με επιτυχία. Περιέχει την υπογραφή, τις διευθύνσεις, τα ποσά και μεταδεδομένα του blockchain.
  `null` πριν από την πρώτη επιτυχημένη μεταφορά.

- **`reset`** (`() => void`) - Επαναφέρει την κατάσταση της mutation, καθαρίζοντας τα `error` και
  `data`. Χρήσιμο για ροές επανάληψης ή για επαναφορά φορμών μετά την ολοκλήρωση.

##### Βοηθητικές ιδιότητες και μέθοδοι διεπαφής

Το hook παρέχει ενσωματωμένη διαχείριση κατάστασης για τα πεδία φόρμας:

- **`toInput`** / **`setToInput`** - Ελεγχόμενη κατάσταση για το πεδίο διεύθυνσης
  παραλήπτη

- **`amountInput`** / **`setAmountInput`** - Ελεγχόμενη κατάσταση για το πεδίο
  ποσού (σε SOL, όχι σε lamports)

- **`handleToInputChange`** - Προδεσμευμένος χειριστής onChange για το πεδίο παραλήπτη:
  `<input onChange={handleToInputChange} />`

- **`handleAmountInputChange`** - Προδεσμευμένος χειριστής onChange για το πεδίο ποσού:
  `<input onChange={handleAmountInputChange} />`

- **`transferFromInputs`** - Μέθοδος διευκόλυνσης που μεταφέρει SOL χρησιμοποιώντας τις
  τρέχουσες τιμές `toInput` και `amountInput`. Μετατρέπει αυτόματα το ποσό από
  SOL σε lamports.

- **`handleSubmit`** - Χειριστής υποβολής φόρμας που καλεί το `transferFromInputs()`
  και αποτρέπει την προεπιλεγμένη συμπεριφορά της φόρμας. Χρησιμοποιήστε το με `<form onSubmit={handleSubmit}>`.

#### Επιλογές

```typescript
interface TransferSOLOptions {
  to: string | Address; // Recipient wallet address
  amount: bigint; // Amount in lamports (1 SOL = 1,000,000,000 lamports)
  from?: string | Address; // Optional sender address (defaults to connected wallet)
}
```

- **`to`** (απαιτείται) - Διεύθυνση Solana του παραλήπτη. Μπορεί να είναι συμβολοσειρά (string) ή τύπος `Address`
  από το `@solana/kit`.

- **`amount`** (απαιτείται) - Ποσό μεταφοράς σε **lamports** (όχι SOL). Πρέπει να είναι
  `bigint`. Χρησιμοποιήστε `BigInt()` ή γραφή literal: `1_000_000_000n` = 1 SOL.

- **`from`** (προαιρετικό) - Διεύθυνση αποστολέα. Αν δεν δοθεί, χρησιμοποιείται η διεύθυνση του
  συνδεδεμένου πορτοφολιού. Απαιτείται μόνο σε προχωρημένες περιπτώσεις χρήσης (π.χ. υπογραφή για
  διαφορετικό λογαριασμό).

#### Αποτέλεσμα

Το αποτέλεσμα περιλαμβάνει μεταδεδομένα συναλλαγής, όπως λεπτομέρειες της μεταφοράς και την
υπογραφή της συναλλαγής:

```typescript
interface TransferSOLResult {
  signature: string; // Transaction signature (base58)
  amount: bigint; // Amount transferred in lamports
  from: Address; // Sender address
  to: Address; // Recipient address
  blockTime?: number; // Unix timestamp when transaction was processed
  slot?: number; // Slot number where transaction was confirmed
}
```

#### Εσωτερική αρχιτεκτονική

**Transaction Builder:** Το hook χρησιμοποιεί έναν κοινό transaction builder που:

- Ανακτά νέα blockhash για κάθε συναλλαγή
- Δημιουργεί βελτιστοποιημένα μηνύματα συναλλαγής με ελάχιστες χρεώσεις
- Υπογράφει τις συναλλαγές χρησιμοποιώντας το συνδεδεμένο πορτοφόλι
- Υποβάλλει και επιβεβαιώνει τις συναλλαγές σε μία ενιαία ροή

**Ακύρωση cache:** Μετά από επιτυχή μεταφορά, το hook ακυρώνει αυτόματα
τις cache του TanStack Query για:

- Το υπόλοιπο του αποστολέα (διεύθυνση `from`)
- Το υπόλοιπο του παραλήπτη (διεύθυνση `to`)

Έτσι διασφαλίζεται ότι τυχόν components που εμφανίζουν υπόλοιπα (π.χ. μέσω του `useArcClient`)
ανακτούν ξανά και ενημερώνονται αυτόματα, χωρίς χειροκίνητη παρέμβαση.

**Ακριβής μετατροπή ποσού:** Όταν χρησιμοποιείται το `transferFromInputs()`, το ποσό
μετατρέπεται από SOL σε lamports με αριθμητική βασισμένη σε συμβολοσειρές, ώστε να αποφεύγονται
σφάλματα ακρίβειας κινητής υποδιαστολής. Η μετατροπή:

- Επικυρώνει τη μορφή της εισόδου (απορρίπτει αρνητικούς και μη έγκυρους αριθμούς)
- Υποστηρίζει έως και 9 δεκαδικά ψηφία (1 lamport = 0.000000001 SOL)
- Περικόπτει ή συμπληρώνει τα κλασματικά μέρη όπως χρειάζεται
- Εγείρει περιγραφικά σφάλματα για μη έγκυρες εισόδους

### `useTransferToken`

Όπως το `useTransferSOL`, αυτό το hook χρησιμοποιείται για τη μεταφορά SPL tokens. Εκτός από τον χειρισμό
των μεταφορών, το hook χειρίζεται επίσης την αυτόματη δημιουργία associated token
account (ATA) όταν χρειάζεται.

#### Υπογραφή

```typescript
function useTransferToken(
  initialMintInput?: string,
  initialToInput?: string,
  initialAmountInput?: string
): UseTransferTokenReturn;
```

#### Παράμετροι

- **`initialMintInput`** (`string`, προαιρετικό) - Αρχική διεύθυνση mint του token.
  Χρήσιμο για μεταφορές σταθερού token.
- **`initialToInput`** (`string`, προαιρετικό) - Αρχική διεύθυνση παραλήπτη.
- **`initialAmountInput`** (`string`, προαιρετικό) - Αρχικό ποσό στις βασικές
  μονάδες του token (λαμβάνοντας υπόψη τα δεκαδικά ψηφία).

#### Τιμή επιστροφής

```typescript
interface UseTransferTokenReturn {
  // Core transfer function
  transferToken: (
    options: TransferTokenOptions
  ) => Promise<TransferTokenResult>;

  // State
  isLoading: boolean;
  error: Error | null;
  data: TransferTokenResult | null;
  reset: () => void;

  // UI Helpers
  mintInput: string;
  toInput: string;
  amountInput: string;
  setMintInput: (value: string) => void;
  setToInput: (value: string) => void;
  setAmountInput: (value: string) => void;
  handleMintInputChange: (event: React.ChangeEvent<HTMLInputElement>) => void;
  handleToInputChange: (event: React.ChangeEvent<HTMLInputElement>) => void;
  handleAmountInputChange: (event: React.ChangeEvent<HTMLInputElement>) => void;
  handleSubmit: (event?: {
    preventDefault?: () => void;
  }) => Promise<TransferTokenResult | undefined>;
  transferFromInputs: () => Promise<TransferTokenResult | undefined>;
}
```

Η τιμή επιστροφής είναι παρόμοια με του `useTransferSOL`, αλλά περιλαμβάνει μια επιπλέον
κατάσταση `mintInput` για την επιλογή token.

#### Επιλογές

```typescript
interface TransferTokenOptions {
  mint: string | Address; // Token mint address
  to: string | Address; // Recipient wallet address
  amount: bigint; // Amount in token's smallest unit
  from?: string | Address; // Optional sender (defaults to connected wallet)
  createAccountIfNeeded?: boolean; // Auto-create recipient's ATA (default: true)
  retryConfig?: TransferRetryConfig; // Optional retry configuration
}
```

##### Απαιτούμενα πεδία

- **`mint`** - Διεύθυνση mint του SPL token. Για παράδειγμα:
  - USDC: `'EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v'`
  - USDT: `'Es9vMFrzaCERmJfrF4H2FYD4KCoNkY11McCe8BenwNYB'`

- **`to`** - Διεύθυνση πορτοφολιού του παραλήπτη (όχι το token account του). Το hook
  εξάγει αυτόματα τον σωστό associated token account.

- **`amount`** - Ποσό μεταφοράς στη **μικρότερη μονάδα** του token. Πρέπει να λαμβάνει υπόψη
  τα δεκαδικά ψηφία του token:
  - USDC (6 δεκαδικά): `1_000_000n` = 1 USDC
  - Wrapped SOL tokens (9 δεκαδικά): `1_000_000_000n` = 1 token

##### Προαιρετικά πεδία

- **`from`** - Διεύθυνση πορτοφολιού του αποστολέα. Από προεπιλογή, το συνδεδεμένο πορτοφόλι.

- **`createAccountIfNeeded`** (προεπιλογή: `true`) - Αν ο παραλήπτης δεν διαθέτει
  token account για αυτό το mint, δημιουργείται αυτόματα στο πλαίσιο της
  συναλλαγής. Όταν είναι `false`, η μεταφορά θα αποτύχει αν ο λογαριασμός του παραλήπτη
  δεν υπάρχει.

  _Σημείωση:_ Η δημιουργία ενός token account κοστίζει ~0.00203 SOL. Το ποσό αυτό το καταβάλλει ο
  αποστολέας.

- **`retryConfig`** - Ρύθμιση για αυτόματη επανάληψη σε περίπτωση λήξης του blockhash.
  Δείτε [Ρύθμιση επανάληψης](#retry-configuration).

#### Αποτέλεσμα

Το αποτέλεσμα περιλαμβάνει μεταδεδομένα συναλλαγής, όπως λεπτομέρειες της μεταφοράς και την
υπογραφή της συναλλαγής:

```typescript
interface TransferTokenResult {
  signature: string; // Transaction signature
  mint: Address; // Token mint address
  amount: bigint; // Amount transferred
  from: Address; // Sender wallet address
  to: Address; // Recipient wallet address
  fromTokenAccount: Address; // Sender's token account
  toTokenAccount: Address; // Recipient's token account
  createdAccount?: boolean; // Whether recipient's ATA was created
  blockTime?: number; // Transaction timestamp
  slot?: number; // Block slot number
}
```

#### Ρύθμιση επανάληψης

Το hook περιλαμβάνει προηγμένη λογική επανάληψης για τον χειρισμό της λήξης του blockhash,
η οποία συμβαίνει συχνά σε περιόδους congestion του δικτύου.

```typescript
interface TransferRetryConfig {
  maxAttempts?: number; // Max retry attempts (default: 3)
  baseDelay?: number; // Base delay in ms (default: 1000)
  backoffMultiplier?: number; // Backoff multiplier (default: 1)
}
```

- **`maxAttempts`** - Μέγιστος αριθμός προσπαθειών συναλλαγής. Κάθε προσπάθεια
  ανακτά ένα νέο blockhash. Προεπιλογή: `3`.

- **`baseDelay`** - Καθυστέρηση σε χιλιοστά του δευτερολέπτου πριν από την πρώτη επανάληψη. Προεπιλογή:
  `1000` (1 δευτερόλεπτο).

- **`backoffMultiplier`** - Πολλαπλασιαστής εκθετικού backoff. Κάθε επανάληψη περιμένει
  `baseDelay * (backoffMultiplier ^ attemptNumber)` χιλιοστά του δευτερολέπτου.
  - `1` = γραμμικό backoff (1s, 1s, 1s)
  - `1.5` = εκθετικό backoff (1s, 1.5s, 2.25s)
  - `2` = επιθετικό εκθετικό (1s, 2s, 4s)

**Πώς λειτουργεί η επανάληψη:**

1. **Πρώτη προσπάθεια:** Η συναλλαγή δημιουργείται με το τρέχον blockhash και υποβάλλεται
2. **Λήξη του blockhash:** Αν το blockhash παλιώσει πριν από την επιβεβαίωση,
   το Solana απορρίπτει τη συναλλαγή
3. **Αυτόματη επανάληψη:** Το hook εντοπίζει τη λήξη, ανακτά νέο blockhash,
   ξαναδημιουργεί τη συναλλαγή και την υποβάλλει εκ νέου
4. **Εκθετικό backoff:** Κάθε επανάληψη περιμένει περισσότερο, ώστε να αποφεύγεται το congestion του δικτύου
5. **Τελική αποτυχία:** Μετά τα `maxAttempts`, εγείρεται το `BlockhashExpirationError`
   με πληροφορίες πλαισίου

**Πότε δεν ενεργοποιείται η επανάληψη:**

- Σφάλματα που δεν σχετίζονται με το blockhash (ανεπαρκή κεφάλαια, μη έγκυροι λογαριασμοί κ.λπ.) εγείρονται
  αμέσως χωρίς επανάληψη
- Μόνο τα σφάλματα λήξης του blockhash ενεργοποιούν τον μηχανισμό επανάληψης

#### Εσωτερική αρχιτεκτονική

**Διαχείριση ATA:**

- Εξάγει τους associated token account με ντετερμινιστικό τρόπο χρησιμοποιώντας το
  `findAssociatedTokenPda` (_Σημείωση: προς το παρόν υποστηρίζεται μόνο το Token Program_)
- Ελέγχει αν ο αποστολέας διαθέτει token account (αποτυγχάνει γρήγορα αν ο αποστολέας δεν κατέχει το
  token)
- Ελέγχει αν ο παραλήπτης διαθέτει token account (το δημιουργεί αν χρειάζεται και
  `createAccountIfNeeded: true`)
- Οι έλεγχοι λογαριασμών εκτελούνται μόνο στην πρώτη προσπάθεια, ώστε να αποφεύγονται περιττές κλήσεις RPC
  κατά τις επαναλήψεις

**Ακύρωση cache:** Μετά από επιτυχία, ακυρώνει τις cache του TanStack Query για:

- Υπόλοιπο token του αποστολέα για αυτό το mint
- Υπόλοιπο token του παραλήπτη για αυτό το mint
- Σχετικά δεδομένα λογαριασμού

Έτσι, όλα τα στοιχεία διεπαφής που εμφανίζουν υπόλοιπα παραμένουν αυτόματα συγχρονισμένα.

### `useArcClient`

Hook για πρόσβαση στον υποκείμενο πελάτη Solana RPC, στην κατάσταση του πορτοφολιού και στη διαμόρφωση
δικτύου. Πρόκειται για hook χαμηλότερου επιπέδου, για προχωρημένες περιπτώσεις χρήσης που απαιτούν
άμεση πρόσβαση σε RPC.

#### Υπογραφή

```typescript
function useArcClient(): ArcClientSnapshot;
```

#### Τιμή επιστροφής

```typescript
interface ArcClientSnapshot {
  // Wallet State
  wallet: {
    address: Address | null;
    signer: TransactionSigner | null;
  };

  // Network Configuration
  network: {
    cluster: "mainnet" | "devnet" | "testnet";
    rpcUrl: string;
  };

  // Client Configuration
  config: ArcWebClientConfig;

  // Actions
  select: (walletName: string) => Promise<void>;
  disconnect: () => Promise<void>;
  selectAccount: (accountAddress: Address) => Promise<void>;
}
```

##### Κατάσταση

Το `ArcClientSnapshot` επεκτείνει το `ArcWebClient`, το οποίο παρέχει πρόσβαση σε:

- κατάσταση πορτοφολιού (διεύθυνση, υπογράφων, διαθέσιμα πορτοφόλια, λειτουργίες και κατάσταση πορτοφολιού)
- διαμόρφωση δικτύου (endpoint RPC, cluster Solana)

#### Περιπτώσεις χρήσης

**Άμεσα ερωτήματα RPC:**

```tsx
import { useArcClient } from "@solana-commerce/sdk";
import { getSharedRpc } from "@solana-commerce/sdk/core/rpc-manager";
import { address } from "@solana/kit";

function AccountBalance() {
  const { network, wallet } = useArcClient();
  const [balance, setBalance] = useState<bigint | null>(null);

  useEffect(() => {
    if (!wallet.address) return;

    const rpc = getSharedRpc(network.rpcUrl);

    async function fetchBalance() {
      const result = await rpc.getBalance(wallet.address).send();
      setBalance(result);
    }

    fetchBalance();
  }, [wallet.address, network.rpcUrl]);

  if (!wallet.address) return <div>Connect wallet to see balance</div>;

  return <div>Balance: {(Number(balance) / 1e9).toFixed(4)} SOL</div>;
}
```

**Στοιχεία με επίγνωση δικτύου:**

```tsx
function NetworkIndicator() {
  const { network } = useArcClient();

  return (
    <div>
      <span>Network: {network.cluster}</span>
      {network.canAirdrop && <button onClick={handleAirdrop}>Airdrop</button>}
    </div>
  );
}
```

**Εμφάνιση υπό όρους με βάση το πορτοφόλι:**

```tsx
function SendButton() {
  const { wallet } = useArcClient();
  const { transferSOL, isLoading } = useTransferSOL();

  if (!wallet.address) {
    return <div>Connect wallet to send SOL</div>;
  }

  return (
    <button
      onClick={() =>
        transferSOL({
          to: "recipient-address",
          amount: BigInt(1_000_000_000)
        })
      }
      disabled={isLoading}
    >
      {isLoading ? "Sending..." : "Send 1 SOL"}
    </button>
  );
}
```
