---

Αυτός ο οδηγός γρήγορης εκκίνησης περιγράφει βήμα προς βήμα τη ροή των Private Channels στο Solana devnet:
ρυθμίστε το περιβάλλον του client, καταθέστε SPL tokens στο escrow, στείλτε μια
off-chain μεταφορά μεταξύ δύο wallets και αναλάβετε κεφάλαια πίσω στο Solana
wallet σας.

Στο τέλος θα κατανοείτε πλήρως τον κύκλο κατάθεση -> off-chain μεταφορά ->
ανάληψη και θα διαθέτετε λειτουργικό κώδικα TypeScript για κάθε βήμα.

<Callout type="info">
  Αυτός ο οδηγός γρήγορης εκκίνησης προϋποθέτει ότι ένα instance Private Channels έχει ήδη αναπτυχθεί και
  εκτελείται στο devnet με το mint σας στη λίστα επιτρεπόμενων. Αν χρειαστεί να το αναπτύξετε πρώτα,
  ο [Οδηγός Operators](/docs/tools/private-channels/operators) καλύπτει
  την πλήρη εγκατάσταση· υπολογίστε 30-60 λεπτά για την αρχική κατασκευή Docker.
</Callout>

## Βήματα

1. **[Εγκατάσταση](/docs/tools/private-channels/quickstart/installation)** -
   κλωνοποιήστε το αποθετήριο και δημιουργήστε τα TypeScript clients (5 λεπτά)
2. **[Κατάθεση Tokens](/docs/tools/private-channels/quickstart/deposit)** -
   καταθέστε SPL tokens στο escrow· αφήστε ~15 δευτερόλεπτα για να
   πιστωθεί το υπόλοιπο του καναλιού σας από τον indexer
3. **[Αποστολή Μεταφοράς](/docs/tools/private-channels/quickstart/transfer)** -
   στείλτε μια off-chain μεταφορά μέσω του gateway· επιβεβαιώνεται σε λιγότερο από ένα δευτερόλεπτο,
   χωρίς καμία επαφή με το Mainnet
4. **[Ανάληψη Κεφαλαίων](/docs/tools/private-channels/quickstart/withdraw)** - κάψτε
   το υπόλοιπο από την πλευρά του καναλιού σας· ο operator διακανονίζει τα κεφάλαια στο Mainnet wallet σας
   μέσα σε λίγα δευτερόλεπτα
