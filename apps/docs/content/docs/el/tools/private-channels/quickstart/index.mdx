---

Αυτός ο οδηγός γρήγορης εκκίνησης παρουσιάζει ολόκληρη τη ροή των Private Channels στο Solana devnet:
ρύθμιση του περιβάλλοντος πελάτη, κατάθεση SPL tokens στο escrow, αποστολή
εκτός αλυσίδας μεταφοράς μεταξύ δύο πορτοφολιών και ανάληψη κεφαλαίων πίσω στο Solana
πορτοφόλι σας.

Στο τέλος θα κατανοείτε πλήρως τον κύκλο κατάθεση -> μεταφορά εκτός αλυσίδας ->
ανάληψη και θα διαθέτετε λειτουργικό κώδικα TypeScript για κάθε βήμα.

<Callout type="info">
  Αυτός ο οδηγός γρήγορης εκκίνησης προϋποθέτει ότι ένα στιγμιότυπο Private Channels είναι ήδη αναπτυγμένο και
  εκτελείται στο devnet με το mint σας στη λίστα επιτρεπόμενων. Εάν χρειαστεί να αναπτύξετε πρώτα ένα,
  ο [οδηγός Operators](/docs/tools/private-channels/operators) καλύπτει
  την πλήρη εγκατάσταση· αναμένετε 30-60 λεπτά για την αρχική κατασκευή Docker.
</Callout>

## Βήματα

1. **[Εγκατάσταση](/docs/tools/private-channels/quickstart/installation)** -
   κλωνοποιήστε το αποθετήριο και δημιουργήστε τα TypeScript clients (5 λεπτά)
2. **[Κατάθεση Tokens](/docs/tools/private-channels/quickstart/deposit)** -
   καταθέστε SPL tokens στο escrow· αφήστε ~15 δευτερόλεπτα για να
   πιστωθεί το υπόλοιπο του καναλιού σας από τον indexer
3. **[Αποστολή Μεταφοράς](/docs/tools/private-channels/quickstart/transfer)** -
   στείλτε μια εκτός αλυσίδας μεταφορά μέσω του gateway· επιβεβαιώνεται σε λιγότερο από ένα δευτερόλεπτο,
   χωρίς ποτέ να αγγίζει το Mainnet
4. **[Ανάληψη Κεφαλαίων](/docs/tools/private-channels/quickstart/withdraw)** - εξαργυρώστε
   το υπόλοιπο από την πλευρά του καναλιού σας· ο operator διακανονίζει τα κεφάλαια στο Mainnet πορτοφόλι σας
   μέσα σε λίγα δευτερόλεπτα
