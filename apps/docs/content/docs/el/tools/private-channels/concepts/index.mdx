---
title: Έννοιες
description: Βασικές έννοιες πίσω από το πρωτόκολλο Private Channels
---

Αυτές οι σελίδες εξηγούν πώς λειτουργεί το Private Channels εσωτερικά. Οι developers
που ενσωματώνουν μια υπάρχουσα instance θα πρέπει να διαβάσουν πρώτα το **Channel Lifecycle**.
Οι operators και όσοι δημιουργούν εργαλεία για operators θα πρέπει επίσης να διαβάσουν
την αναφορά **Sparse Merkle Tree**.

- **[Channel Lifecycle](/docs/tools/private-channels/concepts/channels)** -
  συμμετέχοντες, ρόλοι και η ροή από κατάθεση έως ανάληψη
- **[Sparse Merkle Tree](/docs/tools/private-channels/concepts/smt)** - πώς
  τα αποδεικτικά ανάληψης επαληθεύονται on-chain για την αποτροπή διπλής δαπάνης
- **[Authentication & Roles](/docs/tools/private-channels/concepts/auth)** - JWT
  αυθεντικοποίηση, RBAC και επαλήθευση πορτοφολιού
