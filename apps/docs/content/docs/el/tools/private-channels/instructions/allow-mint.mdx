  Επιτρέπει ένα SPL token mint στην παρουσία και δημιουργεί το escrow ATA για αυτό το mint

Επιτρέπει ένα SPL token mint στην παρουσία και δημιουργεί το associated
token account του escrow για αυτό το mint. Οι καταθέσεις για αυτό το mint καθίστανται δυνατές μετά από
αυτή την κλήση.

## Λογαριασμοί

| Λογαριασμός                          | Εγγράψιμος | Υπογράφων | Περιγραφή                                                                   |
| -------------------------------- | -------- | ------ | ----------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Πληρωτής τελών                                                                     |
| `admin`                          |          | ✓      | Διαχειριστής παρουσίας                                                                |
| `instance`                       |          |        | PDA παρουσίας                                                                  |
| `mint`                           |          |        | SPL token mint προς επιτροπή                                                       |
| `allowed_mint`                   | ✓        |        | AllowedMint PDA (δημιουργείται από αυτή την εντολή)                                 |
| `instance_ata`                   | ✓        |        | Associated token account του escrow για αυτό το mint (δημιουργείται από αυτή την εντολή) |
| `system_program`                 |          |        | System Program                                                                |
| `token_program`                  |          |        | SPL Token Program                                                             |
| `associated_token_program`       |          |        | Associated Token Program                                                      |
| `event_authority`                |          |        | PDA αρχής συμβάντων                                                           |
| `private_channel_escrow_program` |          |        | Πρόγραμμα Escrow                                                                |

## Παράμετροι

| Παράμετρος | Τύπος | Περιγραφή                                                                                   |
| --------- | ---- | --------------------------------------------------------------------------------------------- |
| `bump`    | `u8` | Bump seed για το `allowed_mint` PDA. Προαιρετικό: ο `Async` client το παράγει αυτόματα αν παραλειφθεί |

> Το IDL περιέχει ένα όρισμα `discriminator: u8` (τιμή `1`) που ορίζεται αυτόματα
> από τον παραγόμενο client και δεν πρέπει να περνιέται χειροκίνητα.

## Σημαντικές Σημειώσεις

- Χρησιμοποιήστε το `getAllowMintInstructionAsync`· παράγει αυτόματα τα `bump`, `allowed_mint`,
  και `instance_ata` όταν δεν παρέχονται. Περνάτε το δικό σας `bump` μόνο αν
  το έχετε ήδη υπολογίσει μέσω
  `Pubkey::find_program_address(&[b"allowed_mint", instance_pda, mint], &PROGRAM_ID)`
- Δημιουργεί επίσης το `instance_ata`, το ATA του escrow για αυτό το mint
- Τα mints με επέκταση transfer hook αποκλείονται ρητά: η προσπάθεια να επιτραπεί ένα τέτοιο mint εκπέμπει `TransferHookNotAllowed`
- Εκπέμπει ένα συμβάν μέσω `EmitEvent` CPI
