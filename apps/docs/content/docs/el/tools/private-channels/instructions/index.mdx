  Αναφορά εντολών on-chain για τα προγράμματα Escrow και Withdraw των Private Channels
---

Αυτή η ενότητα αποτελεί την αναφορά εντολών on-chain. Οι περισσότεροι προγραμματιστές καλούν αυτές τις
εντολές μέσω των παραγόμενων TypeScript clients· χρειάζεστε αυτό μόνο αν
δημιουργείτε εργαλεία operator, γράφετε προσαρμοσμένες ενσωματώσεις ή εντοπίζετε
σφάλματα σε επίπεδο εντολών.

**Πρόγραμμα Escrow** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) - διαχειρίζεται
καταθέσεις, παροχή operator και διακανονισμό Mainnet:

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) -
  αρχικοποίηση του PDA της escrow παρουσίας
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) - προσθήκη
  ενός SPL token mint στη λευκή λίστα
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) - αφαίρεση
  ενός mint από τη λίστα επιτρεπόμενων
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) -
  παροχή operator
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) -
  ανάκληση operator
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) -
  μεταφορά δικαιωμάτων διαχειριστή
- [Deposit](/docs/tools/private-channels/instructions/deposit) - μεταφορά SPL tokens
  στο escrow
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) -
  ο operator διακανονίζει μια ανάληψη στο Mainnet
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) -
  ο operator εναλλάσσει τη ρίζα του Sparse Merkle Tree

**Πρόγραμμα Withdraw** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) - εκτελείται στο
δίκτυο private channel:

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) -
  κάψιμο υπολοίπου πλευράς channel για έναρξη ανάληψης

## Κωδικοί Σφάλματος

**Πρόγραμμα Escrow - `PrivateChannelEscrowProgramError`**

| Κωδικός                                         | Μήνυμα                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | Μη έγκυρη αρχή συμβάντος                 |
| `InvalidAta`                                 | Μη έγκυρο ATA                             |
| `InvalidMint`                                | Μη έγκυρο mint                            |
| `InvalidInstanceId`                          | Μη έγκυρο ID παρουσίας ή δεν τηρεί τους κανόνες    |
| `InvalidInstance`                            | Μη έγκυρη παρουσία                        |
| `InvalidAdmin`                               | Μη έγκυρος διαχειριστής                           |
| `TransferHookNotAllowed`                     | Η επέκταση transfer hook δεν επιτρέπεται              |
| `InvalidOperatorPda`                         | Μη έγκυρο PDA operator                    |
| `InvalidTokenAccount`                        | Μη έγκυρο token account                   |
| `InvalidEscrowBalance`                       | Μη έγκυρο υπόλοιπο escrow                           |
| `InvalidAllowedMint`                         | Μη έγκυρο επιτρεπόμενο mint                             |
| `InvalidSmtProof`                            | Μη έγκυρη απόδειξη SMT                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | Μη έγκυρο nonce συναλλαγής για τον τρέχοντα δείκτη δέντρου |
| `UnexpectedTreeIndex`                        | Μη αναμενόμενος τρέχων δείκτης δέντρου για επαναφορά ρίζας SMT |

**Πρόγραμμα Withdraw - `PrivateChannelWithdrawProgramError`**

| Κωδικός          | Μήνυμα                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | Μη έγκυρο mint                       |
| `ZeroAmount`  | Το ποσό ανάληψης πρέπει να είναι μεγαλύτερο από μηδέν |
