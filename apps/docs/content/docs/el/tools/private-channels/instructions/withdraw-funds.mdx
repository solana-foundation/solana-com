---
title: Ανάληψη Κεφαλαίων
description:
  Κάνει burn τα token της πλευράς του καναλιού για να ξεκινήσει μια ανάληψη πίσω στο escrow του Solana mainnet
---

Κάνει burn το υπόλοιπο token ενός χρήστη στην πλευρά του καναλιού μέσω του Withdraw Program για να σηματοδοτήσει μια
εκκρεμή ανάληψη· ένας operator πρέπει στη συνέχεια να καλέσει το `ReleaseFunds` στο
Escrow Program για να ολοκληρωθεί ο διακανονισμός.

## Λογαριασμοί

| Λογαριασμός                    | Εγγράψιμος | Υπογράφων | Περιγραφή                                |
| -------------------------- | -------- | ------ | ------------------------------------------ |
| `user`                     |          | ✓      | Ο κάτοχος token που ξεκινά την ανάληψη      |
| `mint`                     | ✓        |        | SPL token mint (στο οποίο γίνεται burn)            |
| `token_account`            | ✓        |        | token account του χρήστη στην πλευρά του καναλιού (πηγή) |
| `token_program`            |          |        | SPL Token Program                          |
| `associated_token_program` |          |        | Associated Token Program                   |

## Παράμετροι

| Παράμετρος     | Τύπος             | Περιγραφή                                                          |
| ------------- | ---------------- | -------------------------------------------------------------------- |
| `amount`      | `u64`            | Ποσό token προς ανάληψη, στη μικρότερη μονάδα του token           |
| `destination` | `Option<Pubkey>` | Το πορτοφόλι προορισμού στο Mainnet· αν είναι `None`, προεπιλέγεται το πορτοφόλι του υπογράφοντος |

## Επιστρεφόμενη Τιμή

Επιστρέφει ένα `TransactionBuilder` που μπορεί να χρησιμοποιηθεί για να δημιουργηθεί και να αποσταλεί η
συναλλαγή.

## Παράδειγμα

```typescript
import { getWithdrawFundsInstruction } from "../private-channel-withdraw-program/clients/typescript/src/generated";

const withdrawIx = getWithdrawFundsInstruction({
  user: userSigner,
  mint: mintAddress,
  tokenAccount: channelTokenAccount,
  tokenProgram: TOKEN_PROGRAM_ID,
  associatedTokenProgram: ASSOCIATED_TOKEN_PROGRAM_ID,
  amount: 1_000_000n,
  destination: null // null = release to signer's Mainnet wallet
});
```

## Σημαντικές Σημειώσεις

- Αυτή η εντολή βρίσκεται στο **Withdraw Program**
  (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi` devnet), όχι στο Escrow
  Program
- Το burn token στην πλευρά του καναλιού **δεν** αποδεσμεύει αυτόματα κεφάλαια στο
  Mainnet· ένας operator πρέπει στη συνέχεια να καλέσει το `ReleaseFunds` στο Escrow
  Program με έγκυρη απόδειξη εξαίρεσης SMT
- Το σφάλμα `ZeroAmount` εκτοξεύεται αν το `amount` είναι 0
- Αν το `destination` είναι `None`, η κλήση `ReleaseFunds` του operator θα αποδεσμεύσει
  κεφάλαια στο πορτοφόλι του υπογράφοντος

Για την πλήρη αναφορά κωδικών σφάλματος και για τα δύο προγράμματα, δείτε
[Instructions -> Error Codes](/docs/tools/private-channels/instructions#error-codes).
