Μεταφέρει δικαιώματα διαχειριστή σε νέο πορτοφόλι.

## Λογαριασμοί

| Λογαριασμός                          | Εγγράψιμο | Υπογράφων | Περιγραφή                        |
| -------------------------------- | -------- | ------ | ---------------------------------- |
| `payer`                          | ✓        | ✓      | Πληρωτής τελών                          |
| `current_admin`                  |          | ✓      | Τρέχων διαχειριστής (απαιτείται υπογραφή)          |
| `instance`                       | ✓        |        | Instance PDA (το πεδίο διαχειριστή ενημερώνεται) |
| `new_admin`                      |          | ✓      | Πορτοφόλι που λαμβάνει δικαιώματα διαχειριστή     |
| `event_authority`                |          |        | PDA αρχής συμβάντων                |
| `private_channel_escrow_program` |          |        | Πρόγραμμα Escrow                     |

Αυτή η εντολή δεν δέχεται παραμέτρους.

## Σημαντικές Σημειώσεις

- **Μη αναστρέψιμο σε ένα βήμα**: ο τρέχων διαχειριστής δεν μπορεί να διεκδικήσει εκ νέου τον ρόλο
  χωρίς ο νέος διαχειριστής να καλέσει ξανά το `SetNewAdmin`
- Επαληθεύστε τη διεύθυνση προορισμού πριν την κλήση· δεν υπάρχει δυνατότητα αναίρεσης
- Εκπέμπει ένα συμβάν μέσω `EmitEvent` CPI
