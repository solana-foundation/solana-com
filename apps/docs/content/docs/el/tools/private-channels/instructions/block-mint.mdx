Αφαιρεί ένα προηγουμένως επιτρεπόμενο mint από την παρουσία, αποτρέποντας νέες καταθέσεις για
αυτό το mint. Οι υπάρχουσες καταθέσεις δεν επηρεάζονται.

## Λογαριασμοί

| Λογαριασμός                          | Εγγράψιμο | Υπογράφων | Περιγραφή                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | Πληρωτής τελών                                    |
| `admin`                          |          | ✓      | Διαχειριστής παρουσίας                               |
| `instance`                       |          |        | PDA παρουσίας                                 |
| `mint`                           |          |        | SPL token mint προς αποκλεισμό                      |
| `allowed_mint`                   | ✓        |        | AllowedMint PDA (κλείνει με αυτή την εντολή) |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | PDA αρχής συμβάντων                          |
| `private_channel_escrow_program` |          |        | Πρόγραμμα Escrow                               |

Αυτή η εντολή δεν δέχεται παραμέτρους.

## Σημαντικές Σημειώσεις

- Κλείνει το `allowed_mint` PDA: νέες κλήσεις `Deposit` για αυτό το mint θα αποτύχουν
  με `InvalidAllowedMint`
- Τα υπάρχοντα υπόλοιπα καναλιού για αυτό το mint δεν επηρεάζονται
- Εκπέμπει ένα συμβάν μέσω `EmitEvent` CPI
