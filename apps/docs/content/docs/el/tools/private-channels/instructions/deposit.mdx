---
title: Κατάθεση
description:
  Μεταφέρει SPL tokens από το πορτοφόλι ενός χρήστη στο escrow του Private Channels
---

Μεταφέρει SPL tokens από το associated token account ενός χρήστη στο
associated token account του escrow, πιστώνοντας το υπόλοιπο καναλιού του χρήστη που πραγματοποιεί την κατάθεση (ή το υπόλοιπο ενός προαιρετικού παραλήπτη).

## Λογαριασμοί

| Λογαριασμός                          | Εγγράψιμος | Υπογράφων | Περιγραφή                                          |
| -------------------------------- | -------- | ------ | ---------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Πληρωτής τελών για τη συναλλαγή                        |
| `user`                           |          | ✓      | Κάτοχος token που πραγματοποιεί την κατάθεση                       |
| `instance`                       |          |        | PDA παρουσίας escrow                                  |
| `mint`                           |          |        | SPL token mint                                       |
| `allowed_mint`                   |          |        | PDA που επαληθεύει ότι το mint επιτρέπεται σε αυτή την παρουσία |
| `user_ata`                       | ✓        |        | Associated token account χρήστη (πηγή)             |
| `instance_ata`                   | ✓        |        | Associated token account του escrow (προορισμός)      |
| `system_program`                 |          |        | System Program                                       |
| `token_program`                  |          |        | SPL Token Program                                    |
| `associated_token_program`       |          |        | Associated Token Program                             |
| `event_authority`                |          |        | PDA αρχής συμβάντων για CPI `EmitEvent`              |
| `private_channel_escrow_program` |          |        | Πρόγραμμα Escrow (αυτο-αναφορά για CPI)              |

## Παράμετροι

| Παράμετρος   | Τύπος             | Περιγραφή                                                                           |
| ----------- | ---------------- | ------------------------------------------------------------------------------------- |
| `amount`    | `u64`            | Ποσό tokens προς κατάθεση, στη μικρότερη μονάδα του token                             |
| `recipient` | `Option<Pubkey>` | Προαιρετικός on-chain παραλήπτης· εάν είναι `None`, πιστώνει το υπόλοιπο καναλιού του χρήστη που καταθέτει |

## Επιστρεφόμενη Τιμή

Επιστρέφει ένα `TransactionBuilder` που μπορεί να χρησιμοποιηθεί για τη δημιουργία και αποστολή της συναλλαγής.

## Παράδειγμα

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

// allowedMint and instanceAta are auto-derived from mint and instance
const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n,
  recipient: null
});
```

## Σημαντικές Σημειώσεις

- Program ID: `9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`
- Για mints Token-2022, περάστε ρητά `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS`,
  καθώς η προεπιλογή είναι το τυπικό SPL Token Program
- Το PDA `allowed_mint` πρέπει να υπάρχει (δημιουργείται από το `AllowMint`)· η κατάθεση με μη καταχωρημένο mint εκπέμπει `InvalidAllowedMint`
- Όταν το `recipient` είναι `None`, πιστώνεται το υπόλοιπο καναλιού του χρήστη που καταθέτει· όταν παρέχεται, πιστώνεται αντίθετα το υπόλοιπο του καθορισμένου πορτοφολιού
- Τόσο ο `payer` όσο και ο `user` πρέπει να υπογράψουν τη συναλλαγή
- Το `instance_ata` πρέπει να υπάρχει ήδη (δημιουργείται από το `AllowMint` για αυτό το mint)
