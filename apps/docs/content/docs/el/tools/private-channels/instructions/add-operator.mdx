title: AddOperator
description: Προσθέτει έναν νέο χειριστή δημιουργώντας το Operator PDA του
---

Προσθέτει έναν νέο χειριστή δημιουργώντας το `Operator` PDA του. Μετά από αυτή την κλήση, το
πορτοφόλι `operator` μπορεί να καλέσει τις `ReleaseFunds` και `ResetSmtRoot`.

## Λογαριασμοί

| Λογαριασμός                          | Εγγράψιμο | Υπογράφων | Περιγραφή                                                         |
| -------------------------------- | -------- | ------ | ------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Πληρωτής τελών                                                           |
| `admin`                          |          | ✓      | Διαχειριστής instance                                                      |
| `instance`                       |          |        | Instance PDA                                                        |
| `operator`                       |          |        | Πορτοφόλι χειριστή προς προσθήκη                                        |
| `operator_pda`                   | ✓        |        | Operator PDA - αυτόματη παραγωγή από `["operator", instance, operator]` |
| `system_program`                 |          |        | System Program                                                      |
| `event_authority`                |          |        | PDA εξουσιοδότησης συμβάντων                                                 |
| `private_channel_escrow_program` |          |        | Escrow Program                                                      |

## Παράμετροι

| Παράμετρος | Τύπος | Περιγραφή                                                                               |
| --------- | ---- | ----------------------------------------------------------------------------------------- |
| `bump`    | `u8` | Bump seed για το `operator_pda`. Προαιρετικό: ο `Async` client το παράγει αυτόματα αν παραληφθεί |

> Το IDL περιέχει ένα όρισμα `discriminator: u8` (τιμή `3`) που ορίζεται αυτόματα
> από τον παραγόμενο client και δεν πρέπει να περνιέται χειροκίνητα.

## Σημαντικές Σημειώσεις

- Χρησιμοποιήστε το `getAddOperatorInstructionAsync`· παράγει αυτόματα τα `bump` και
  `operator_pda` όταν δεν παρέχονται. Υπάρχει επίσης μια σύγχρονη
  παραλλαγή `getAddOperatorInstruction` αν έχετε ήδη υπολογίσει το `bump`
  μόνοι σας
- Μετά από αυτή την κλήση, το πορτοφόλι `operator` μπορεί να καλέσει τις `ReleaseFunds` και
  `ResetSmtRoot`
- Εκπέμπει ένα συμβάν μέσω `EmitEvent` CPI
