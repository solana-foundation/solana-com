---
title: RemoveOperator
description: Ανακαλεί έναν χειριστή κλείνοντας το PDA του Χειριστή
---

Ανακαλεί έναν χειριστή κλείνοντας το `Operator` PDA του. Το ανακληθέν πορτοφόλι δεν μπορεί πλέον
να καλέσει `ReleaseFunds` ή `ResetSmtRoot`.

## Λογαριασμοί

| Λογαριασμός                          | Εγγράψιμο | Υπογράφων | Περιγραφή                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | Πληρωτής τελών                                 |
| `admin`                          |          | ✓      | Διαχειριστής στιγμιότυπου                            |
| `instance`                       |          |        | PDA στιγμιότυπου                              |
| `operator`                       |          |        | Πορτοφόλι χειριστή προς ανάκληση                 |
| `operator_pda`                   | ✓        |        | PDA Χειριστή (κλείνεται από αυτή την εντολή) |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | PDA αρχής συμβάντων                       |
| `private_channel_escrow_program` |          |        | Πρόγραμμα Escrow                            |

Αυτή η εντολή δεν δέχεται παραμέτρους.

## Σημαντικές Σημειώσεις

- Κλείνει το `operator_pda`· το ανακληθέν πορτοφόλι δεν μπορεί πλέον να καλέσει
  `ReleaseFunds` ή `ResetSmtRoot`
- Τυχόν εκκρεμείς συναλλαγές χειριστή θα αποτύχουν με `InvalidOperatorPda` μετά
  από αυτή την κλήση
- Εκπέμπει ένα συμβάν μέσω `EmitEvent` CPI
