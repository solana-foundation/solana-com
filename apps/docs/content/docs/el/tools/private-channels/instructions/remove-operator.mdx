---
title: RemoveOperator
description: Ανακαλεί έναν operator κλείνοντας το Operator PDA του
---

Ανακαλεί έναν operator κλείνοντας το `Operator` PDA του. Το ανακληθέν wallet δεν
μπορεί πλέον να καλέσει `ReleaseFunds` ή `ResetSmtRoot`.

## Λογαριασμοί

| Λογαριασμός                          | Εγγράψιμο | Υπογράφων | Περιγραφή                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | Πληρωτής τελών                                 |
| `admin`                          |          | ✓      | Διαχειριστής instance                            |
| `instance`                       |          |        | Instance PDA                              |
| `operator`                       |          |        | Wallet operator προς ανάκληση                 |
| `operator_pda`                   | ✓        |        | Operator PDA (κλείνει με αυτή την εντολή) |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | PDA αρχής συμβάντων                       |
| `private_channel_escrow_program` |          |        | Πρόγραμμα Escrow                            |

Αυτή η εντολή δεν δέχεται παραμέτρους.

## Σημαντικές Σημειώσεις

- Κλείνει το `operator_pda`· το ανακληθέν wallet δεν μπορεί πλέον να καλέσει
  `ReleaseFunds` ή `ResetSmtRoot`
- Τυχόν εκκρεμείς συναλλαγές operator θα αποτύχουν με `InvalidOperatorPda` μετά
  από αυτή την κλήση
- Εκπέμπει ένα συμβάν μέσω `EmitEvent` CPI
