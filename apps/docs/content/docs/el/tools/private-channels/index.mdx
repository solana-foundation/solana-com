<Callout type="warning">
  Τα Ιδιωτικά Κανάλια δεν έχουν υποβληθεί σε έλεγχο ασφαλείας και δεν συνιστώνται για
  χρήση σε παραγωγικό περιβάλλον με πραγματικά κεφάλαια χωρίς διεξοδική αξιολόγηση ασφαλείας.
</Callout>

**Τα Ιδιωτικά Κανάλια αποτελούν ένα επιχειρησιακό επίπεδο για αγορές κεφαλαίου στο διαδίκτυο επί του
Solana.** Παρέχει ένα διαμορφώσιμο επίπεδο εφαρμογής για ιδιωτικές, άμεσες, μηδενικής χρέωσης
μεταφορές εντός καναλιών πληρωμών: οι χρήστες καταθέτουν SPL tokens σε ένα on-chain
πρόγραμμα θεματοφυλακής, πραγματοποιούν συναλλαγές off-chain μέσω πύλης και διακανονίζουν στο Mainnet
μέσω απόδειξης Sparse Merkle Tree, προσφέροντας στους προγραμματιστές εφαρμογών άμεσες, μηδενικής χρέωσης, ιδιωτικές
μεταφορές χωρίς να εγκαταλείπουν το οικοσύστημα του Solana.

### Γιατί Ιδιωτικά Κανάλια;

- **Άμεσες μεταφορές**: off-chain απόδοση που υπερβαίνει το εγγενές TPS του Solana·
  οι μεταφορές επιβεβαιώνονται όταν τις επεξεργάζεται ο sequencer, όχι όταν επιβεβαιωθεί ένα block
- **Μηδενικές χρεώσεις ανά μεταφορά**: καμία χρέωση gas στις μεμονωμένες μεταφορές καναλιού· οι χρήστες
  πληρώνουν μόνο για on-chain καταθέσεις και αναλήψεις
- **Απόρρητο**: οι μεταφορές μεταξύ συμμετεχόντων του καναλιού δεν καταγράφονται στο Solana
  Mainnet
- **Ελεγχόμενη πρόσβαση**: το RBAC με πιστοποίηση JWT σάς επιτρέπει να ελέγχετε ποιος μπορεί
  να αποστέλλει και να λαμβάνει
- **Διακανονισμός στο Mainnet**: τα κεφάλαια είναι πάντα εξαγοράσιμα στο Solana μέσω απόδειξης αποκλεισμού
  Sparse Merkle Tree, την οποία επιβάλλει το πρόγραμμα θεματοφυλακής on-chain

Δείτε την **[Επισκόπηση](/docs/tools/private-channels/overview)** για την πλήρη
αρχιτεκτονική, το διάγραμμα ροής δεδομένων και το μοντέλο ασφαλείας.

## Γρήγορη Εκκίνηση

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n, // 1 USDC
  recipient: null
});
// send via your preferred Solana client
```

Τα TypeScript clients δημιουργούνται από το IDL· βλέπε Εγκατάσταση. Για εκδόσεις Token-2022,
περάστε ρητά `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS`, καθώς η προεπιλογή είναι το τυπικό SPL Token Program.

**[Πλήρης Οδηγός Γρήγορης Εκκίνησης](/docs/tools/private-channels/quickstart/installation)** -
ρύθμιση περιβάλλοντος και δημιουργία client

**[Επισκόπηση](/docs/tools/private-channels/overview)** - αρχιτεκτονική και ροή
δεδομένων

## Περιπτώσεις Χρήσης

- **Θεσμικές διμερείς πληρωμές** - τράπεζες και ιδρύματα που χρειάζονται
  μεγάλου όγκου, ιδιωτικές ροές USDC χωρίς κάθε μεταφορά να εμφανίζεται on-chain
- **Μεταφορές υψηλής συχνότητας στο επίπεδο εφαρμογής** - εφαρμογές gaming, loyalty και καταναλωτών
  που χρειάζονται μεταφορές υποδευτερολέπτου, μηδενικής χρέωσης σε κλίμακα πέρα από το εγγενές TPS του Solana
- **Ροές token με διαφύλαξη απορρήτου** - κάθε περίπτωση χρήσης όπου το απόρρητο αντισυμβαλλομένου και
  ποσού αποτελεί απαίτηση του προϊόντος

**[Πότε να χρησιμοποιείτε εγγενείς μεταφορές SPL](/docs/tools/private-channels/concepts/channels#when-to-use-private-channels)**
