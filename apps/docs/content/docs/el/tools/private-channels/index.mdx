<Callout type="warning">
  Τα Ιδιωτικά Κανάλια δεν έχουν υποβληθεί σε έλεγχο ασφαλείας και δεν συνιστώνται για
  χρήση σε παραγωγικό περιβάλλον με πραγματικά κεφάλαια χωρίς διεξοδικό έλεγχο ασφαλείας.
</Callout>

**Τα Ιδιωτικά Κανάλια αποτελούν ένα επιχειρησιακό επίπεδο για αγορές διαδικτυακού κεφαλαίου στο
Solana.** Παρέχει ένα διαμορφώσιμο επίπεδο εφαρμογών για ιδιωτικές, άμεσες, μηδενικής χρέωσης
μεταφορές εντός καναλιών πληρωμών: οι χρήστες καταθέτουν SPL tokens σε ένα on-chain
πρόγραμμα θεματοφυλακής, συναλλάσσονται off-chain μέσω gateway και διακανονίζουν πίσω στο Mainnet
μέσω απόδειξης Sparse Merkle Tree, παρέχοντας στους προγραμματιστές εφαρμογών άμεσες, μηδενικής χρέωσης, ιδιωτικές
μεταφορές χωρίς να εγκαταλείπουν το οικοσύστημα του Solana.

### Γιατί Ιδιωτικά Κανάλια;

- **Άμεσες μεταφορές**: off-chain ρυθμαπόδοση πέραν του εγγενούς TPS του Solana·
  οι μεταφορές επιβεβαιώνονται όταν τις επεξεργάζεται ο sequencer, όχι όταν επιβεβαιώνεται ένα block
- **Μηδενικές χρεώσεις ανά μεταφορά**: κανένα κόστος gas στις μεμονωμένες μεταφορές καναλιού· οι χρήστες
  πληρώνουν μόνο για on-chain καταθέσεις και αναλήψεις
- **Απόρρητο**: οι μεταφορές μεταξύ συμμετεχόντων στο κανάλι δεν καταγράφονται στο Solana
  Mainnet
- **Ελεγχόμενη πρόσβαση**: το RBAC με αυθεντικοποίηση JWT σάς επιτρέπει να ελέγχετε ποιος μπορεί
  να αποστέλλει και να λαμβάνει
- **Διακανονισμός στο Mainnet**: τα κεφάλαια είναι πάντα εξαγοράσιμα στο Solana μέσω απόδειξης αποκλεισμού
  Sparse Merkle Tree, την οποία το πρόγραμμα θεματοφυλακής επιβάλλει on-chain

Δείτε την **[Επισκόπηση](/docs/tools/private-channels/overview)** για την πλήρη
αρχιτεκτονική, το διάγραμμα ροής δεδομένων και το μοντέλο ασφαλείας.

## Γρήγορη Εκκίνηση

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n, // 1 USDC
  recipient: null
});
// send via your preferred Solana client
```

Τα TypeScript clients δημιουργούνται από το IDL· βλ. Εγκατάσταση. Για Token-2022
mints, περάστε ρητά `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS`, καθώς
επιλέγεται από προεπιλογή το τυπικό SPL Token Program.

**[Πλήρης Γρήγορη Εκκίνηση](/docs/tools/private-channels/quickstart/installation)** -
ρύθμιση περιβάλλοντος και δημιουργία client

**[Επισκόπηση](/docs/tools/private-channels/overview)** - αρχιτεκτονική και ροή
δεδομένων

## Περιπτώσεις Χρήσης

- **Θεσμικές διμερείς πληρωμές** - τράπεζες και ιδρύματα που χρειάζονται
  μεγάλου όγκου, ιδιωτικές ροές USDC χωρίς κάθε μεταφορά να εμφανίζεται on-chain
- **Μεταφορές εφαρμογών υψηλής συχνότητας** - gaming, loyalty και καταναλωτικές εφαρμογές
  που χρειάζονται μεταφορές υπο-δευτερολέπτου, μηδενικής χρέωσης σε κλίμακα πέραν του εγγενούς TPS του Solana
- **Ροές token με διαφύλαξη απορρήτου** - κάθε περίπτωση χρήσης όπου το απόρρητο
  αντισυμβαλλομένου και ποσού αποτελεί απαίτηση προϊόντος

**[Πότε να χρησιμοποιείτε εγγενείς μεταφορές SPL](/docs/tools/private-channels/concepts/channels#when-to-use-private-channels)**
