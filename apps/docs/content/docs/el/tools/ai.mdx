# Εργασία με LLMs και πράκτορες στο Solana

Πριν εμβαθύνουμε σε συγκεκριμένα εργαλεία, ας κατανοήσουμε τα βασικά στοιχεία στο stack
ανάπτυξης AI:

## Κατανόηση του AI Stack

1. **Μεγάλα Γλωσσικά Μοντέλα (LLMs)**
   - Τα θεμελιώδη μοντέλα AI (όπως GPT-4, Claude ή Llama)
   - Επεξεργάζονται και παράγουν φυσική γλώσσα
   - Παρέχουν ακατέργαστη νοημοσύνη και δυνατότητες συλλογισμού
   - Παραδείγματα: GPT-4 της OpenAI, Claude της Anthropic, Llama της Meta

2. **Πλαίσια πρακτόρων (όπως το Eliza)**
   - Χτίζονται πάνω σε LLMs για τη δημιουργία αυτόνομων πρακτόρων
   - Διαχειρίζονται τις προσωπικότητες και τις συμπεριφορές των πρακτόρων
   - Χειρίζονται τη μνήμη και το context
   - Παρέχουν ενσωμάτωση σε πολλαπλές πλατφόρμες
   - Παραδείγματα: Eliza, LangChain, AutoGPT, Vercel AI

3. **Domain-Specific Agent Kits (όπως το Solana Agent Kit)**
   - Χτίζονται για συγκεκριμένες περιπτώσεις χρήσης (π.χ. λειτουργίες blockchain)
   - Παρέχουν προκατασκευασμένα εργαλεία και ενσωματώσεις
   - Αποκρύπτουν την τεχνική πολυπλοκότητα
   - Έτοιμες προς χρήση λειτουργίες blockchain
   - Παραδείγματα: Solana Agent Kit, GOAT Toolkit

Σκεφτείτε το ως εξής:

- Τα LLMs είναι ο «εγκέφαλος» που μπορεί να κατανοεί και να παράγει γλώσσα
- Τα πλαίσια πρακτόρων είναι το «λειτουργικό σύστημα» που διαχειρίζεται τη συμπεριφορά του AI
- Τα domain-specific kits είναι οι «εφαρμογές» που δίνουν στο AI συγκεκριμένες δυνατότητες

# Δημιουργία AI πρακτόρων για το Solana

Αυτός ο οδηγός θα σας δείξει πώς να:

- Δημιουργήσετε έναν βασικό AI πράκτορα χρησιμοποιώντας το Solana Agent Kit της SendAI
- Δημιουργήσετε ένα Twitter bot με το Eliza Framework
- Κατανοήσετε τις επιλογές ενσωμάτωσης on-chain AI
- Επιλογές για το πώς να δημιουργήσετε προηγμένα trading bots

## Εισαγωγή στους AI πράκτορες στο Solana

Οι AI πράκτορες στο Solana είναι αυτόνομα προγράμματα που μπορούν να αλληλεπιδρούν με το
blockchain χρησιμοποιώντας επεξεργασία φυσικής γλώσσας και μηχανική μάθηση. Μπορούν να:

- Εκτελούν συναλλαγές
- Παρακολουθούν τη δραστηριότητα του blockchain
- Αλληλεπιδρούν με smart contracts
- Παρέχουν υποστήριξη στους χρήστες
- Αυτοματοποιούν σύνθετες ροές εργασίας

## Διαθέσιμα πλαίσια

Υπάρχουν διαθέσιμα αρκετά πλαίσια για τη δημιουργία AI πρακτόρων στο Solana:

1. **Solana Agent Kit της SendAI**

- Μια συλλογή εργαλείων για τη δημιουργία πρακτόρων στο Solana
- Συμβατό με Eliza, Langchain και Vercel AI SDK
- Ενσωματωμένα εργαλεία και βοηθητικά utilities για το Solana
- Δυνατότητες επεξεργασίας φυσικής γλώσσας
- [Solana Agent Kit](https://github.com/sendaifun/solana-agent-kit)
- [Τεκμηρίωση](https://docs.solanaagentkit.xyz/)

2. **Eliza Framework**

- Συνδυάζει datalayer, LLM και πράκτορες και διαθέτει ειδικό plugin για το Solana
- Επεκτάσιμη αρχιτεκτονική πρακτόρων
- Εύκολη ενσωμάτωση με υπάρχοντα έργα και μπορεί να χρησιμοποιηθεί, για παράδειγμα, για
  Twitter (X), Telegram ή Discord bots
- [Αποθετήριο GitHub](https://github.com/elizaOS/eliza)

3. **GOAT Toolkit**

- Ολοκληρωμένο toolkit ανάπτυξης
- Συμβατότητα μεταξύ αλυσίδων
- [Αποθετήριο GitHub](https://github.com/goat-sdk/goat)

4. **Rig Framework**

- Εγγενής υλοποίηση σε Rust
- Κατάλληλο για trading bots υψηλής απόδοσης
- Μπορεί να συνδυαστεί με το toolkit Listen.rs για ενσωμάτωση στο Solana, παρακολούθηση συναλλαγών
  και αποστολή συναλλαγών χρησιμοποιώντας, για παράδειγμα, Jito bundles
- [Αποθετήριο GitHub](https://github.com/0xPlaygrounds/rig)
- [Αποθετήριο Listen.rs](https://github.com/piotrostr/listen)

Αν δημιουργείτε ένα πλαίσιο AI, μπορείτε ελεύθερα να ανοίξετε ένα PR για να προσθέσετε το πλαίσιο σας
στη λίστα

### Δημιουργία του script του πράκτορα

Δημιουργήστε ένα νέο αρχείο με όνομα `agent.ts` με το ακόλουθο περιεχόμενο:

```typescript filename=agent.ts
import { SolanaAgentKit, createSolanaTools } from "solana-agent-kit";
import { HumanMessage } from "@langchain/core/messages";
import { ChatOpenAI } from "@langchain/openai";
import { createReactAgent } from "@langchain/langgraph/prebuilt";
import { MemorySaver } from "@langchain/langgraph";
import * as dotenv from "dotenv";
import bs58 from "bs58";
import * as readline from "readline";

dotenv.config();

async function initializeAgent() {
  const llm = new ChatOpenAI({
    modelName: "gpt-4-turbo-preview",
    temperature: 0.7
  });

  // Convert array string to actual array, then to Uint8Array, then to base58
  const privateKeyArray = JSON.parse(process.env.SOLANA_PRIVATE_KEY!);
  const privateKeyUint8 = new Uint8Array(privateKeyArray);
  const privateKeyBase58 = bs58.encode(privateKeyUint8);

  const solanaKit = new SolanaAgentKit(privateKeyBase58, process.env.RPC_URL!, {
    OPENAI_API_KEY: process.env.OPENAI_API_KEY!
  });

  const tools = createSolanaTools(solanaKit);
  const memory = new MemorySaver();

  return createReactAgent({
    llm,
    tools,
    checkpointSaver: memory
  });
}

async function runInteractiveChat() {
  const agent = await initializeAgent();
  const config = { configurable: { thread_id: "Solana Agent Kit!" } };
  const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout
  });

  // Clear console and start chat with a small delay
  setTimeout(() => {
    console.clear(); // Clear any initialization messages
    console.log("Chat with Solana Agent (type 'exit' to quit)");
    console.log("--------------------------------------------");
    askQuestion();
  }, 100);

  const askQuestion = () => {
    rl.question("You: ", async (input) => {
      if (input.toLowerCase() === "exit") {
        rl.close();
        return;
      }

      const stream = await agent.stream(
        {
          messages: [new HumanMessage(input)]
        },
        config
      );

      process.stdout.write("Agent: ");
      for await (const chunk of stream) {
        if ("agent" in chunk) {
          process.stdout.write(chunk.agent.messages[0].content);
        } else if ("tools" in chunk) {
          process.stdout.write(chunk.tools.messages[0].content);
        }
      }
      console.log("\n--------------------------------------------");

      askQuestion(); // Continue the conversation
    });
  };
}

runInteractiveChat().catch(console.error);
```

## Δημιουργία με το Eliza Framework

Το [ElizaOS](https://github.com/elizaOS/eliza) (παλαιότερα γνωστό ως Ai16z) είναι ένα
πλαίσιο AI. Αυτό σημαίνει ότι συνδυάζει πολλαπλές εφαρμογές σε μία και
οργανώνει τις αλληλεπιδράσεις τους. Συνδυάζει:

1. Διαφορετικά LLMs για την κατανόηση του χρήστη
2. Blockchain πράκτορες με διαφορετικές ενέργειες (όπως, για παράδειγμα, mint ενός NFT)
3. Επίπεδα δεδομένων για την αποθήκευση της κατάστασης των χαρακτήρων μεταξύ ενεργειών, χρησιμοποιώντας για παράδειγμα
   Redis, PostgreSQL DB ή τοπική αποθήκευση
4. Διαφορετικούς clients όπως X, Telegram, Discord κ.λπ.

Παίρνει όλα αυτά τα στοιχεία και τα συνδυάζει με τρόπο που σας επιτρέπει να δημιουργήσετε έναν
«Character» που μπορεί να αλληλεπιδρά με χρήστες ή αυτόνομα. Αυτοί οι Characters
ορίζονται σε ένα αρχείο JSON, το οποίο καθορίζει ποιες ενέργειες μπορεί να εκτελέσει, ποιο LLM
πρέπει να χρησιμοποιήσει και διάφορα prompts που ορίζουν τη συμπεριφορά του χαρακτήρα.

### Δημιουργία ρύθμισης χαρακτήρα

Για να δημιουργήσουμε έναν νέο χαρακτήρα, πρέπει να δημιουργήσουμε ένα αρχείο character.json. Μπορείτε να βρείτε
τους προκαθορισμένους χαρακτήρες στον φάκελο characters του έργου Eliza. Για να δημιουργήσετε έναν
νέο χαρακτήρα, μπορείτε να αντιγράψετε και να αλλάξετε έναν από τους ήδη υπάρχοντες χαρακτήρες ή
μπορείτε να χρησιμοποιήσετε τη
[λειτουργία composer στο Cursor](https://docs.cursor.com/composer/overview) και να του πείτε
τι είδους χαρακτήρα θέλετε να δημιουργήσετε.

```json filename=characters/sol.character.json
{
    "name": "Sol",
    "clients": ["twitter"],
    "modelProvider": "openai",
    "settings": {
        "voice": {
            "model": "en_US-neural"
        },
        ...
```

Το σημαντικό μέρος εδώ είναι οι clients και το modelProvider. Στην περίπτωσή μας
θέλουμε να χρησιμοποιήσουμε το twitter ως client και το openai ως πάροχο μοντέλου, επειδή αυτό
είναι και για το οποίο ρυθμίσαμε τα secrets μας στο αρχείο `.env`.

### Εκτέλεση του πράκτορα

Τώρα που η ρύθμιση έχει ολοκληρωθεί, μπορούμε να εκτελέσουμε τον χαρακτήρα μας:

```bash
pnpm start --character="characters/sol.character.json"
```

Αυτό θα ξεκινήσει τον πράκτορα και μπορείτε τώρα να αλληλεπιδράσετε μαζί του στο twitter. Ο
χαρακτήρας θα αρχίσει αυτόματα να δημοσιεύει tweets κάθε λίγες ώρες και όταν
αλληλεπιδρούμε μαζί του θα μπορεί να εκτελεί ενέργειες Solana, όπως για παράδειγμα minting NFTs.

Εδώ μπορείτε να δείτε τον
[χαρακτήρα σε δράση](https://x.com/solanadevhelper/status/1882222232656847143).

Μπορείτε επίσης να αλληλεπιδράσετε με τον χαρακτήρα τοπικά χρησιμοποιώντας την ακόλουθη εντολή:
Ίσως χρειαστεί να ελευθερώσετε τη θύρα 3000 και να ξεκινήσετε τον χαρακτήρα σας με το flag `--host`.

```bash
pnpm start --character="characters/sol.character.json" --host
pnpm start:client
```

Αν ο client σας δεν συνδέεται, βεβαιωθείτε ότι εκτελείτε τον πράκτορά σας με το flag `--host`
και ότι η θύρα 3000 δεν χρησιμοποιείται όταν ξεκινάτε τον client.

Για περισσότερες πληροφορίες ακολουθήστε την
[επίσημη τεκμηρίωση του eliza](https://elizaos.github.io/eliza/docs/quickstart/)

</Steps>

Αποποίηση ευθυνών: Η ενσωμάτωση και οι ενέργειες Solana δεν είναι ακόμη τέλειες, αλλά βρίσκονται
σε συνεχή ανάπτυξη και εξελίσσονται γρήγορα. Θα υπάρξει σύντομα άμεση ενσωμάτωση

## Ενσωμάτωση πράκτορα σε on-chain πρόγραμμα

Αν θέλετε να χρησιμοποιήσετε την απάντηση ενός agent σε ένα πρόγραμμα Solana, πρέπει να χρησιμοποιήσετε ένα
oracle που γράφει τα δεδομένα απόκρισης σε έναν λογαριασμό που μπορεί να διαβάσει το πρόγραμμά σας.
Μπορείτε να βρείτε ένα παράδειγμα LLM που θα μεταφέρει tokens σε οποιονδήποτε χρήστη
απαντά σωστά σε ερωτήσεις εδώ:

[Αλληλεπίδραση LLM με πρόγραμμα on-chain](https://github.com/GabrielePicco/super-smart-contracts)

Αυτό είναι ένα παράδειγμα ενός on-chain προγράμματος που ενσωματώνεται με ένα LLM (AI) oracle
για τη δημιουργία ενός διαδραστικού agent διανομής tokens με το όνομα "Mar1o".

### Βασικά Χαρακτηριστικά

1. **Αλληλεπίδραση με AI Agent**
   - Οι χρήστες μπορούν να συνομιλούν με τον Mar1o για να προσπαθήσουν να κερδίσουν tokens
   - Ο agent αξιολογεί τις γνώσεις Solana του χρήστη για να αποφασίσει τα ποσά tokens
   - Οι αποκρίσεις είναι σε μορφή JSON με κείμενο απάντησης και ποσό tokens

2. **Διαχείριση Tokens**
   - Δημιουργεί MAR1O tokens με μεταδεδομένα
   - Μπορεί να κόψει μεταξύ 0-10.000 tokens βάσει της απόκρισης AI
   - Χρησιμοποιεί PDAs για τη διαχείριση tokens

### Επεξήγηση ροής προγράμματος

Δείτε πώς λειτουργεί αυτό το πρόγραμμα:

```rust
// Initialize the AI agent with personality
const AGENT_DESC: &str = "You are an AI agent called Mar1o which can dispense MAR1O tokens...";

// User interaction flow:
// 1. User sends message to agent
// 2. Oracle processes with LLM
// 3. Agent responds with JSON containing reply and amount
// 4. If amount > 0, tokens are minted to user

// Example response:
{
    "reply": "Great answer! Here's a reward.",
    "amount": 1000
}
```

Αυτό δείχνει πώς να συνδυάσετε τις δυνατότητες AI με τη μηχανική on-chain tokens για
τη δημιουργία διαδραστικών εμπειριών blockchain. Εδώ είναι ένα
[live παράδειγμα](https://mar1o.xyz/) όπου μπορείτε να προσπαθήσετε να πείσετε τον Agent να
σας μεταφέρει μερικά tokens.

## Προηγμένοι Rust agents για αλγοριθμικό trading

Αν θέλετε να γράψετε τους agents σας σε Rust, μπορείτε να χρησιμοποιήσετε το
[Rig framework](https://github.com/0xPlaygrounds/rig) και τη
[βιβλιοθήκη Listen.rs](https://github.com/piotrostr/listen).

Αυτά τα δύο λειτουργούν πολύ καλά μαζί. Ενώ το Rig framework σάς παρέχει έναν εύκολο τρόπο
σύνδεσης με LLMs, το toolkit Listen.rs σάς προσφέρει την ενσωμάτωση Solana,
συμπεριλαμβανομένης της παρακολούθησης συναλλαγών και της αποστολής συναλλαγών με χρήση Jito bundles
για παράδειγμα.

## Βέλτιστες Πρακτικές

- Να γνωρίζετε ότι ο agent σας διαθέτει ιδιωτικό κλειδί και επομένως μπορεί να έχει πρόσβαση στα κεφάλαια του
  πορτοφολιού σας. Αν κάποιος μπορεί να συνομιλεί με τον agent σας και αυτός διαθέτει ενέργεια μεταφοράς,
  οι χρήστες μπορούν πιθανώς να τον παρακινήσουν να μεταφέρει τα κεφάλαιά σας.
- Χρησιμοποιείτε πληρωμένα [RPC endpoints](https://solana.com/rpc). Τα δημόσια endpoints
  συνήθως υπόκεινται σε rate limiting
- Παρακολουθείτε τις δραστηριότητες του agent και βεβαιωθείτε ότι δεν εκτελεί κακόβουλες ενέργειες
  ή δεν εξαπατάται από χρήστες που αλληλεπιδρούν μαζί του
- Εφαρμόστε priority fees και επαναλήψεις συναλλαγών στις ενέργειες του agent σας, ώστε
  να εκτελούνται επιτυχώς και όταν υπάρχει συμφόρηση στο δίκτυο
- Αν είναι δυνατόν, δοκιμάστε πρώτα στο devnet πριν αναπτύξετε στο mainnet. Οι περισσότεροι agents
  δέχονται απλώς το RPC url ως είσοδο και μπορείτε να χρησιμοποιήσετε ένα devnet μέχρι να είστε
  έτοιμοι για το mainnet. Ωστόσο, δεν είναι δυνατό να εκτελεστούν όλες οι ενέργειες στο devnet.
- Όταν γράφετε τις δικές σας ενέργειες, προσθέστε integration tests για αυτές, ώστε τα
  frameworks να μπορούν να παρακολουθούν ποιες ενέργειες αποτυγχάνουν λόγω αλλαγών σε προγράμματα ή
  APIs

## Συμπέρασμα

Οι AI agents στο Solana ανοίγουν νέες δυνατότητες για αυτοματισμό και αλληλεπίδραση
με το blockchain. Αν και δεν είναι όλες οι ενσωματώσεις τέλειες ακόμη, αναπτύσσονται
γρήγορα και προσφέρουν πολλές ευκαιρίες για συνεισφορές, ενώ είναι εξαιρετικά
ευέλικτες ως προς την προσθήκη δικών σας ενσωματώσεων.
