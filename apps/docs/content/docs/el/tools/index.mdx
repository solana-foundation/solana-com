## Εργαλεία

<Cards>
  <Card title="Kora" href="/docs/tools/kora">
    Δημιουργήστε ροές συναλλαγών χωρίς gas και με πληρωμή σε token με έναν
    paymaster Kora.
  </Card>
  <Card title="Keychain" href="/docs/tools/keychain">
    Χρησιμοποιήστε μια ενοποιημένη διεπαφή υπογραφής σε τοπικά κλειδιά, KMS, HSM
    και backends πορτοφολιών.
  </Card>
  <Card title="Commerce Kit" href="/docs/tools/commerce-kit">
    Προσθέστε στοιχεία πληρωμής Solana και ροές εμπορίου στην εφαρμογή σας.
  </Card>
  <Card title="Solana Pay" href="/docs/tools/solana-pay">
    Υλοποιήστε ροές μεταφοράς και αιτημάτων συναλλαγών του Solana Pay.
  </Card>
  <Card title="Attestations" href="/docs/tools/attestations">
    Δημιουργήστε διαπιστευτήρια, σχήματα και attestations για δεδομένα εκτός
    αλυσίδας συνδεδεμένα με λογαριασμούς εντός αλυσίδας.
  </Card>
  <Card title="Private Channels" href="/docs/tools/private-channels">
    Εξετάστε υλικό προϊόντος ιδιωτικών καναλιών και πόρους ενσωμάτωσης.
  </Card>
  <Card title="Surfpool" href="/docs/tools/surfpool">
    Αντικατάσταση drop-in του solana-test-validator για τοπική ανάπτυξη, δοκιμές
    και αναπτύξεις Infrastructure-as-Code.
  </Card>
  <Card title="LiteSVM" href="/docs/tools/litesvm">
    Δοκιμάστε προγράμματα Solana σε μια γρήγορη ενδο-διεργασιακή VM, χωρίς
    validator, σε Rust και TypeScript.
  </Card>
  <Card title="Actions και Blinks" href="/docs/tools/actions">
    Μετατρέψτε οποιαδήποτε συναλλαγή Solana σε έναν κοινοποιήσιμο σύνδεσμο πλούσιο σε μεταδεδομένα.
  </Card>
  <Card title="Εργαλεία AI" href="/docs/tools/ai">
    Χρησιμοποιήστε βοηθούς κωδικοποίησης AI και πλαίσια agents με το Solana.
  </Card>
</Cards>
