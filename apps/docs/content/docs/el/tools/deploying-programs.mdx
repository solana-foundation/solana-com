---

Αν αναπτύσσετε ένα προσαρμοσμένο πρόγραμμα Solana ως μέρος της υποδομής
πληρωμών σας, υπάρχουν πρόσθετα ζητήματα που πρέπει να λάβετε υπόψη.

## Πριν από την ανάπτυξη

- **Έκδοση Solana CLI:** Βεβαιωθείτε ότι χρησιμοποιείτε την τελευταία έκδοση του
  [Solana CLI](https://solana.com/docs/intro/installation).
- **Keypair προγράμματος:** Το πρόγραμμά σας θα έχει διαφορετική διεύθυνση στο
  mainnet από ό,τι στο devnet (εκτός αν επαναχρησιμοποιείτε το ίδιο keypair).
  Ενημερώστε όλες τις αναφορές στη διαμόρφωση της εφαρμογής σας. Αποθηκεύστε το
  keypair του προγράμματός σας σε ασφαλές σημείο (σημειώστε ότι η εκτέλεση της
  εντολής `cargo clean` πιθανότατα θα διαγράψει το keypair του προγράμματός σας).
- **Αρχικοποίηση λογαριασμών:** Αν το πρόγραμμά σας απαιτεί λογαριασμούς
  διαχειριστή, PDAs ή άλλους λογαριασμούς κατάστασης, βεβαιωθείτε ότι αυτοί
  δημιουργούνται στο mainnet πριν οι χρήστες αλληλεπιδράσουν με την εφαρμογή
  σας. Το ίδιο ισχύει για τυχόν Associated Token Accounts (ATAs) που χρειάζεται
  το πρόγραμμά σας.

## Διαδικασία ανάπτυξης

- **Λογαριασμοί buffer:** Τα μεγάλα προγράμματα αναπτύσσονται μέσω λογαριασμών
  buffer. Η εντολή `solana program deploy` το χειρίζεται αυτόματα, αλλά να
  έχετε υπόψη ότι η ανάπτυξη δεν είναι ατομική—αν διακοπεί, ίσως χρειαστεί να
  ανακτήσετε ή να κλείσετε λογαριασμούς buffer.
- **Αρχή αναβάθμισης:** Δημιουργήστε ένα
  [multisig](https://docs.squads.so/main/basics/what-is-a-multisig) και ορίστε
  το ως την
  [αρχή αναβάθμισης του προγράμματος Solana σας](https://docs.squads.so/main/navigating-your-squad/developers-assets/programs).
- **Rent:** Βεβαιωθείτε ότι το πορτοφόλι ανάπτυξής σας διαθέτει αρκετά SOL για
  να καλύψει τα ελάχιστα ποσά απαλλαγής από rent για όλα τα program accounts.
- **Επαλήθευση:** [Επαληθεύστε](https://solana.com/docs/programs/verified-builds)
  το πρόγραμμά σας, ώστε να διασφαλίσετε ότι το εκτελέσιμο πρόγραμμα που
  αναπτύσσετε στο δίκτυο της Solana αντιστοιχεί στον πηγαίο κώδικα του
  αποθετηρίου σας
