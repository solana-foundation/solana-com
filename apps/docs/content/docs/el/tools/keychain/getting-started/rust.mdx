## Εγκατάσταση

Προσθέστε το `solana-keychain` στο `Cargo.toml` σας με μόνο τα backends που
χρειάζεστε:

```toml title="Cargo.toml"
[dependencies]
# Memory signer only (default, Solana SDK 2.x)
solana-keychain = "2.0"

# Or specify backends explicitly (pick exactly one SDK feature)
solana-keychain = { version = "2.0", default-features = false, features = ["vault", "aws_kms", "sdk-v2"] }

# All remote backends on the Solana 4.x SDK line
solana-keychain = { version = "2.0", default-features = false, features = ["all", "sdk-v4"] }
```

Κάνετε αναβάθμιση από την έκδοση 1.x; Δείτε τον
[οδηγό μετάβασης στην έκδοση 2.0](https://github.com/solana-foundation/solana-keychain/blob/main/docs/MIGRATING_V2.md).

### Σημαίες Χαρακτηριστικών

| Χαρακτηριστικό        | Περιγραφή                                                           |
| -------------- | --------------------------------------------------------------------- |
| `memory`       | Τοπική υπογραφή keypair (προεπιλογή)                                       |
| `vault`        | Μηχανή HashiCorp Vault Transit                                        |
| `aws_kms`      | AWS KMS με Ed25519                                                  |
| `gcp_kms`      | GCP Cloud KMS με Ed25519                                            |
| `privy`        | Ενσωματωμένα πορτοφόλια Privy                                                |
| `turnkey`      | Turnkey API                                                           |
| `fireblocks`   | Fireblocks MPC                                                        |
| `cdp`          | Coinbase Developer Platform                                           |
| `crossmint`    | Διαχειριζόμενα πορτοφόλια Crossmint                                             |
| `dfns`         | Υποδομή πορτοφολιών Dfns                                            |
| `openfort`     | Ενσωματωμένα πορτοφόλια Openfort                                             |
| `para`         | Πορτοφόλια Para MPC                                                      |
| `utila`        | Φύλαξη Utila MPC                                                     |
| `fordefi`      | Θεματοφυλακή Fordefi MPC                                                   |
| `ledger`       | Πορτοφόλι υλικού Ledger μέσω USB-HID (μόνο για Rust, προαιρετικό, δεν περιλαμβάνεται στο `all`) |
| `all`          | Ενεργοποίηση όλων των backend εκτός από το `ledger`                                  |
| `sdk-v2`       | Solana SDK 2.x (προεπιλογή)                                              |
| `sdk-v3`       | Solana SDK 3.x                                                        |
| `sdk-v4`       | Solana SDK 4.x (απαιτείται για συναλλαγές v1)                         |
| `unsafe-debug` | Καταγράφει πλήρεις απαντήσεις σφάλματος του παρόχου· μην το ενεργοποιείτε ποτέ στο περιβάλλον παραγωγής        |

Πρέπει να είναι ενεργοποιημένο ακριβώς ένα από τα `sdk-v2`, `sdk-v3` και `sdk-v4`.

## Βασική Χρήση

Όλοι οι signers υλοποιούν το βασικό
[trait `SolanaSigner`](https://github.com/solana-foundation/solana-keychain/blob/main/rust/src/traits.rs)
(`pubkey`, `sign_message`, `is_available`). Κάθε backend υλοποιεί επίσης ακριβώς
ένα trait δυνατοτήτων:

- `TransactionSigner`: υπογράφει τη συναλλαγή σας όπως έχει δοθεί.
- `ModifyingSigner`: ο πάροχος τροποποιεί τη συναλλαγή και στη συνέχεια την υπογράφει.
- `SendingSigner`: ο πάροχος την υπογράφει και την αποστέλλει στο δίκτυο.

```rust
use solana_keychain::{SignerError, SolanaSigner, TransactionSigner};
use solana_sdk::transaction::VersionedTransaction;

async fn sign_transaction(
    signer: &impl TransactionSigner,
    tx: &mut VersionedTransaction,
) -> Result<(), SignerError> {
    // Get the signer's public key
    let pubkey = signer.pubkey();
    println!("Signing with: {}", pubkey);

    // Check availability (useful for remote signers)
    if !signer.is_available().await {
        return Err(SignerError::NotAvailable("Signer offline".into()));
    }

    // Sign the transaction: returns Complete or Partial
    let result = signer.sign_transaction(tx).await?;
    let (base64_tx, signature) = result.into_signed_transaction();
    println!("Signature: {}", signature);

    Ok(())
}
```

Μετατρέψτε μια παλαιού τύπου (legacy) `Transaction` με `.into()`. Οι συναλλαγές legacy και v0 λειτουργούν
με κάθε δυνατότητα SDK· οι συναλλαγές v1 απαιτούν `sdk-v4`.

### Δυνατότητες Signer

| Backend                              | Trait δυνατοτήτων    | `sign_message`                  |
| ------------------------------------ | ------------------- | ------------------------------- |
| Crossmint                            | `SendingSigner`     | Δεν υποστηρίζεται                   |
| Fordefi native auto                  | `SendingSigner`     | Ναι                             |
| Fordefi native manual                | `ModifyingSigner`   | Ναι                             |
| Utila                                | `TransactionSigner` | Δεν υποστηρίζεται                   |
| CDP                                  | `TransactionSigner` | Μόνο payloads UTF-8             |
| Ledger                               | `TransactionSigner` | Ναι, μέσω off-chain envelope |
| Όλα τα υπόλοιπα (συμπ. Fordefi black box) | `TransactionSigner` | Ναι                             |

Οι κατασκευαστές `Signer::from_*` εκτελούν το `init()` για εσάς. Αν δημιουργήσετε
άμεσα τους τύπους signer Privy, Fireblocks, Dfns, Crossmint, Para, Openfort ή Utila,
καλέστε `init().await` πριν από τη χρήση.

## Διαμόρφωση Backend

### Memory Signer

Για ανάπτυξη και δοκιμή με τοπικά keypairs:

```rust
use solana_keychain::Signer;

// From base58 private key
let signer = Signer::from_memory("base58_private_key")?;

// From JSON keypair file path
let signer = Signer::from_memory_file("/path/to/keypair.json")?;

// From byte array string
let signer = Signer::from_memory("[1,2,3,...]")?;
```

### HashiCorp Vault

Για αυτο-φιλοξενούμενο HSM με μηχανή Transit:

```rust
use solana_keychain::Signer;

let signer = Signer::from_vault(
    "https://vault.example.com:8200".to_string(), // Vault address
    "hvs.xxxxx".to_string(),                      // Vault token
    "my-solana-key".to_string(),                  // Key name in Transit
    "base58_public_key".to_string(),              // Expected public key
    None,                                         // Default HTTP timeouts
)?;
```

### AWS KMS

Για υπογραφή βασισμένη σε cloud με κλειδιά AWS KMS Ed25519:

```rust
use solana_keychain::Signer;

let signer = Signer::from_aws_kms(
    "alias/my-solana-key".to_string(),   // KMS key ID or alias
    "base58_public_key".to_string(),     // Expected public key
    Some("us-east-1".to_string()),       // Region (optional)
).await?;
```

### Privy

Για υπογραφή με ενσωματωμένο πορτοφόλι:

```rust
use solana_keychain::Signer;

let signer = Signer::from_privy(

```

### Turnkey

Για μη-κηδεμονική υπογραφή:

```rust

let signer = Signer::from_turnkey(

    "base58_public_key".to_string(),// Expected public key

```

### Fireblocks

Για θεσμική υπογραφή MPC:

```rust
use solana_keychain::{Signer, FireblocksSignerConfig};

let config = FireblocksSignerConfig {
    api_key: "api_key".to_string(),
    private_key_pem: "-----BEGIN RSA PRIVATE KEY-----\n...".to_string(),
    vault_account_id: "0".to_string(),
    asset_id: Some("SOL".to_string()), // None defaults to "SOL"; "SOL_TEST" for devnet
    api_base_url: None,
    poll_interval_ms: None,
    max_poll_attempts: None,
    use_program_call: None, // Some(true) signs via PROGRAM_CALL (sign-only, legacy/v0, hot wallet)
    http_client_config: None,
};

let signer = Signer::from_fireblocks(config).await?;
```

### GCP KMS

Για cloud-native υπογραφή με κλειδιά GCP Cloud KMS Ed25519:

```rust
use solana_keychain::Signer;

let signer = Signer::from_gcp_kms(
    "projects/my-project/locations/us-east1/keyRings/my-ring/cryptoKeys/my-key/cryptoKeyVersions/1".to_string(),
    "base58_public_key".to_string(),
).await?;
```

### CDP (Coinbase Developer Platform)

Για υπογραφή με διαχειριζόμενο πορτοφόλι Coinbase:

```rust
use solana_keychain::{Signer, CdpSignerConfig, CDP_NETWORK_MAINNET};

let signer = Signer::from_cdp(CdpSignerConfig {
    api_key_id: "api_key_id".to_string(),           // CDP API key ID
    api_key_secret: "api_key_secret".to_string(),   // CDP API private key (base64 Ed25519)
    wallet_secret: "wallet_secret".to_string(),     // CDP wallet secret (base64 PKCS#8 DER)
    address: "base58_address".to_string(),          // Solana account address
    network: Some(CDP_NETWORK_MAINNET.to_string()), // Required to sign transactions with address lookup tables
    api_base_url: None,
    http_client_config: None,                       // Default HTTP timeouts
})?;
```

Το `sign_message` του CDP δέχεται μόνο payloads UTF-8.

### Crossmint

Το Crossmint υποστηρίζει μόνο αποστολή: το API του εκτελεί κάθε εγκεκριμένη συναλλαγή
στην πλευρά του διακομιστή, επομένως δεν υπάρχει διαδρομή μόνο υπογραφής και το `sign_message` αποτυγχάνει. Καλέστε
το `sign_and_send_transaction`, το οποίο αφήνει τη συναλλαγή σας αμετάβλητη και επιστρέφει
την υπογραφή της συναλλαγής που εγγράφηκε στο δίκτυο. Η συναλλαγή αυτή μπορεί να διαφέρει από
τη δική σας, αν το Crossmint χορηγεί το κόστος gas.

```rust
use solana_keychain::{Signer, CrossmintSignerConfig};

let config = CrossmintSignerConfig {
    api_key: "api_key".to_string(),
    wallet_locator: "wallet_locator".to_string(),
    signer_secret: None,
    signer: None,
    api_base_url: None,
    poll_interval_ms: None,
    max_poll_attempts: None,
};

let signer = Signer::from_crossmint(config).await?;

let signature = signer
    .as_sending_signer()
    .expect("Crossmint is a sending signer")
    .sign_and_send_transaction(&tx)
    .await?;
```

### Fordefi

Για υπογραφή με φύλαξη MPC του Fordefi. Τα αιτήματα API πιστοποιούνται με υπογραφή αιτήματος ECDSA
P-256. Δώστε ακριβώς ένα από τα `private_key_pem` ή
`request_signer` (ένα `Arc<dyn FordefiRequestSigner>`, που χρησιμοποιείται για να παραμένει το κλειδί σε
KMS/HSM).

Το Fordefi διατίθεται σε τρεις τύπους signer, που καθορίζονται κατά τη δημιουργία από τα `chain` και
`push_mode`:

| `chain`    | `push_mode`      | Τύπος                        | Δυνατότητα          | Συμπεριφορά                                                           |
| ---------- | ---------------- | --------------------------- | ------------------- | ------------------------------------------------------------------ |
| `None`     | οποιοδήποτε              | `FordefiBlackBoxSigner`     | `TransactionSigner` | Υπογράφει ακατέργαστα bytes· εσείς αποστέλλετε τη συναλλαγή                                     |
| `Some(..)` | `None` ή `Auto` | `FordefiNativeAutoSigner`   | `SendingSigner`     | Το Fordefi μπορεί να τροποποιήσει το blockhash και τα τέλη, υπογράφει και αποστέλλει   |
| `Some(..)` | `Manual`         | `FordefiNativeManualSigner` | `ModifyingSigner`   | Το Fordefi τροποποιεί και υπογράφει· εσείς αποστέλλετε τη συναλλαγή που επιστρέφεται |

Η native manual λειτουργία αντικαθιστά τη συναλλαγή σας με αυτήν που υπέγραψε το Fordefi.
Συνεχίστε από αυτήν, ποτέ από εκείνη που δημιουργήσατε εσείς. Πρέπει να εκτελεστεί πριν από οποιονδήποτε άλλο
απαιτούμενο signer.

```rust
use solana_keychain::{
    Signer, FordefiSignerConfig, FordefiPushMode, SolanaChainUniqueId, FordefiSolanaFee,
    FordefiPriorityLevel,
};

let config = FordefiSignerConfig {
    access_token: "api_token".to_string(),
    vault_id: "vault_uuid".to_string(),
    private_key_pem: Some(std::fs::read_to_string("./secret/private.pem")?),
    request_signer: None,                           // Or Some(Arc::new(your_kms_signer))
    public_key: "base58_public_key".to_string(),    // Solana vault address
    chain: Some(SolanaChainUniqueId::SolanaDevnet), // None for black box mode
    fee: Some(FordefiSolanaFee::Priority {
        priority_level: FordefiPriorityLevel::Medium,
    }),
    push_mode: Some(FordefiPushMode::Auto),         // Manual: sign without broadcasting
    api_base_url: None,       // Default: https://api.fordefi.com
    poll_interval_ms: None,   // Default: 2000
    max_poll_attempts: None,  // Default: 50
    http_client_config: None, // Default HTTP timeouts
};

let signer = Signer::from_fordefi(config).await?;
```

### Ledger

Για υπογραφή με πορτοφόλι υλικού μέσω USB-HID (μόνο για Rust). Απαιτεί τη δυνατότητα `ledger`,
μια ξεκλείδωτη συσκευή με την εφαρμογή Solana και, σε Linux, τους κανόνες udev της Ledger.
Το Ledger δεν καλύπτεται από τον τρέχοντα έλεγχο ασφαλείας (audit)· δείτε την
[κατάσταση των audit](https://github.com/solana-foundation/solana-keychain/blob/main/audits/AUDIT_STATUS.md).

```rust
use solana_keychain::{LedgerConfig, Signer};

let signer = Signer::from_ledger(LedgerConfig {
    confirm_pubkey_on_device: true,
    ..LedgerConfig::default()
})
.await?;
```

Το `sign_message` υπογράφει ένα off-chain envelope που περιβάλλει το payload σας, όχι τα ακατέργαστα
bytes· ανακατασκευάστε το με `solana_keychain::ledger::ledger_offchain_envelope` για
επαλήθευση. Ορίστε `auto_open_app: false` για χρήση χωρίς επίβλεψη. Αν απορριφθεί το μήνυμα επιβεβαίωσης στη
συσκευή, επιστρέφεται `SignerError::UserRejected`.

## Ενοποιημένο Enum Υπογραφέα

Χρησιμοποιήστε το enum `Signer` για να επιλέξετε backends κατά το runtime:

```rust
use solana_keychain::{Signer, SolanaSigner, SignerError};

async fn get_signer(backend: &str) -> Result<Signer, SignerError> {
    match backend {
        "memory" => Signer::from_memory("base58_key"),
        "vault" => Signer::from_vault(/* ... */),
        "kms" => Signer::from_aws_kms(/* ... */).await,
        _ => Err(SignerError::ConfigError("Unknown backend".into())),
    }
}

// Use it generically
let signer = get_signer("kms").await?;
let pubkey = signer.pubkey();
```

Το `Signer` υλοποιεί μόνο το `SolanaSigner`. Αποκτήστε πρόσβαση σε μια δυνατότητα μέσω
`as_transaction_signer()`, `as_modifying_signer()` ή `as_sending_signer()`,
τα οποία επιστρέφουν `None` όταν το backend δεν διαθέτει αυτή τη μορφή:

```rust
if let Some(transaction_signer) = signer.as_transaction_signer() {
    let result = transaction_signer.sign_transaction(&mut tx).await?;
}
```

Ή αφήστε το `sign_and_send` να δρομολογήσει ανάλογα με το backend. Το crate δεν διαθέτει πελάτη RPC, οπότε
εσείς παρέχετε την αποστολή· για backend που αποστέλλει το ίδιο, το closure δεν καλείται ποτέ:

```rust
let signature = signer
    .sign_and_send(&mut tx, |encoded| async move { broadcast(encoded).await })
    .await?;
```

## Διαχείριση σφαλμάτων

Το `SignerError::BroadcastUnconfirmed { provider_tx_id, idempotency_key, transaction_signature, .. }`
(από το Crossmint, το Fordefi native auto ή ένα closure `sign_and_send` που αποτυγχάνει)
σημαίνει ότι η συναλλαγή μπορεί να έχει εγγραφεί στο δίκτυο. Μην επαναλάβετε τυφλά την προσπάθεια: συμφωνήστε πρώτα
το `provider_tx_id` ή το `transaction_signature`, ή στείλτε ξανά μόνο τη
συναλλαγή με πανομοιότυπα bytes. Τα εξαντλητικά `match` στο `SignerError` χρειάζονται αυτόν τον κλάδο.
Δείτε το
[μοντέλο ασφαλείας](https://github.com/solana-foundation/solana-keychain/blob/main/docs/SECURITY_MODEL.md)
για το τι εγγυάται κάθε μορφή υπογραφής.
