**Το Solana Keychain παρέχει μια ενιαία διεπαφή για την υπογραφή συναλλαγών Solana
σε πολλαπλά backends διαχείρισης κλειδιών.** Αναπτύξτε τοπικά με ένα κλειδί
στη μνήμη και στη συνέχεια μεταβείτε σε διαχείριση κλειδιών επιπέδου επιχείρησης, cloud HSM ή υπηρεσίες
διαχειριζόμενων πορτοφολιών στην παραγωγή, χωρίς να ξαναγράψετε τον κώδικα υπογραφής σας.

### Γιατί το Keychain;

- **Ενιαία διεπαφή**: Μία βασική διεπαφή `SolanaSigner` για όλα τα backends,
  συν μία δυνατότητα ανά backend: υπογραφή, αναδιατύπωση και υπογραφή ή υπογραφή και αποστολή
- **Εναλλαγή backends**: Αλλάξτε παρόχους διαχείρισης κλειδιών μέσω ρυθμίσεων· τα
  σημεία κλήσης αλλάζουν μόνο όταν το νέο backend έχει διαφορετική δυνατότητα (εγγενείς λειτουργίες Crossmint
  και Fordefi)
- **Πληρώνετε μόνο για ό,τι χρησιμοποιείτε**: Τα feature flags του Rust, τα πακέτα npm ανά backend, τα extras της Python
  και τα modules Go ανά backend περιλαμβάνουν μόνο τα backends που χρειάζεστε
- **Με έλεγχο ασφαλείας**: Τα Rust, TypeScript, Python και Go έχουν ελεγχθεί από την
  [OtterSec](https://osec.io) (το προαιρετικό backend Ledger ήταν εκτός πεδίου)· ένας
  προηγούμενος έλεγχος από την [Accretion](https://accretion.xyz) κάλυψε τα Rust και TypeScript.
  Δείτε
  [την κατάσταση των ελέγχων](https://github.com/solana-foundation/solana-keychain/blob/main/audits/AUDIT_STATUS.md).

### Αρχιτεκτονική

- **Γλώσσες**: Rust, TypeScript, Python και Go, με ισοδυναμία χαρακτηριστικών (το backend Ledger
  είναι διαθέσιμο μόνο για Rust)
- **Διεπαφή**: Βασική διεπαφή `SolanaSigner` (`pubkey`, `sign_message`, `is_available`)
  συν ακριβώς μία δυνατότητα ανά backend: `TransactionSigner`,
  `ModifyingSigner` ή `SendingSigner`
- **Backends**: Memory, Vault, AWS KMS, GCP KMS, Privy, Turnkey, Fireblocks,
  CDP, Crossmint, Dfns, Openfort, Para, Utila, Fordefi, Ledger (μόνο Rust,
  προαιρετικό, χωρίς έλεγχο ασφαλείας)
- **Συμβατότητα**: `@solana/kit` και `@solana/signers` 8.1+ (TypeScript) |
  `solana-sdk` 2.x, 3.x ή 4.x μέσω των features `sdk-v2` / `sdk-v3` / `sdk-v4`
  (Rust· οι συναλλαγές v1 απαιτούν `sdk-v4`) | `solders` (Python) | `solana-go` v2
  (Go)

### Υποστηριζόμενα Συστήματα

Τα backends καλύπτουν την τοπική ανάπτυξη, αυτο-φιλοξενούμενη και cloud
διαχείριση κλειδιών, καθώς και διαχειριζόμενες ή MPC υπηρεσίες πορτοφολιών.
Δείτε [Επιλογή backend](/docs/tools/keychain/choosing-a-backend) για σύγκριση
μοντέλων φύλαξης και επιλογή του κατάλληλου.

| HashiCorp Vault | Αυτο-φιλοξενούμενη διαχείριση κλειδιών          | ✓    | ✓          | ✓      | ✓   |
| AWS KMS         | Cloud-native (AWS)                  | ✓    | ✓          | ✓      | ✓   |

## Γρήγορη Εκκίνηση

### Rust

Εγκαταστήστε το Rust crate:

```bash
cargo add solana-keychain
```

Βασική χρήση:

```rust
use solana_keychain::{Signer, SolanaSigner};

// Create a signer from any backend
let signer = Signer::from_memory("base58_private_key")?;
let pubkey = signer.pubkey();

// Transaction signing is a capability; `tx` is a VersionedTransaction
if let Some(tx_signer) = signer.as_transaction_signer() {
    let result = tx_signer.sign_transaction(&mut tx).await?;
}

// Or let the umbrella route any backend shape and supply the RPC hop yourself
let signature = signer
    .sign_and_send(&mut tx, |encoded| async move { broadcast(encoded).await })
    .await?;
```

- [Οδηγός Rust](/docs/tools/keychain/getting-started/rust) - Πλήρης εγκατάσταση
  και διαμόρφωση backend
- [Crates.io](https://crates.io/crates/solana-keychain) - Rust crate

### TypeScript

Εγκαταστήστε το πακέτο TypeScript:

```bash
pnpm add @solana/keychain
```

Βασική χρήση:

```typescript
import { createKeychainSigner } from "@solana/keychain";
import { signTransactionWithSigners } from "@solana/signers";

// Create any signer via the unified factory
const signer = await createKeychainSigner({
  backend: "vault",
  vaultAddr: "https://vault.example.com:8200",
  vaultToken: "hvs.xxxxx",
  keyName: "my-solana-key",
  publicKey: "base58_public_key"
});

// Sign an already-compiled transaction
const signedTx = await signTransactionWithSigners(
  [signer],
  compiledTransaction
);
```

- [Οδηγός TypeScript](/docs/tools/keychain/getting-started/typescript) -
  `@solana/keychain` πακέτα
- [Πακέτο npm](https://www.npmjs.com/package/@solana/keychain) - πακέτο npm

Για να εγκαταστήσετε έναν signer του Keychain σε έναν client [Kit](https://github.com/anza-xyz/kit)
ως `payer` ή `identity`, χρησιμοποιήστε το `@solana/keychain-kit-plugin` (οι εγγενείς λειτουργίες Crossmint και
Fordefi εξαιρούνται, καθώς αναδιατυπώνουν τις συναλλαγές).

### Python

Εγκαταστήστε το πακέτο (τα βαρύτερα backends διατίθενται ως extras, για παράδειγμα
`solana-keychain[aws-kms]`):

```bash
pip install solana-keychain
```

Βασική χρήση:

```python
import os

from solana_keychain import VaultSignerConfig, create_vault_signer

signer = await create_vault_signer(
    VaultSignerConfig(
        api_base_url="https://vault.example.com:8200",
        token=os.environ["VAULT_TOKEN"],
        key_name="my-solana-key",
        public_key="base58_public_key",
    )
)

# tx is a solders VersionedTransaction
result = await signer.sign_transaction(tx)
```

- [Οδηγός Python](/docs/tools/keychain/getting-started/python) - Πλήρης
  εγκατάσταση, extras και ρύθμιση backends
- [PyPI](https://pypi.org/project/solana-keychain/) - Πακέτο Python

### Go

Κάθε backend είναι ένα ξεχωριστό module Go, ώστε να κατεβάζετε μόνο τα backends που εισάγετε:

```bash
go get github.com/solana-foundation/solana-keychain/go/signers/vault/v2@latest
```

Βασική χρήση:

```go
import "github.com/solana-foundation/solana-keychain/go/signers/vault/v2"

signer, err := vault.New(vault.Config{
	VaultAddr: "https://vault.example.com:8200",
	Token:     os.Getenv("VAULT_TOKEN"),
	KeyName:   "my-solana-key",
	Pubkey:    "base58_public_key",
})
if err != nil {
	return err
}

// tx is a *solana.Transaction from solana-go v2
res, err := signer.SignTransaction(ctx, tx)
```

- [Οδηγός Go](/docs/tools/keychain/getting-started/go) - Modules, δυνατότητες
  και ρύθμιση backends
- [pkg.go.dev](https://pkg.go.dev/github.com/solana-foundation/solana-keychain/go/core/v2) -
  Τεκμηρίωση Go
