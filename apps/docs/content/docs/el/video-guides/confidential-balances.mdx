Τα Εμπιστευτικά υπόλοιπα είναι μια επέκταση του Token-2022 που διατηρεί κρυπτογραφημένα τα ποσά μεταφοράς και
τα υπόλοιπα στο Solana, ενώ οι διευθύνσεις των token account παραμένουν δημόσιες.
Αυτό το βίντεο εξηγεί πώς λειτουργεί και γιατί είναι σημαντικό για τη μισθοδοσία, τις συναλλαγές και
τις καθημερινές πληρωμές. Συνδυάστε το με τον
[οδηγό για τα Εμπιστευτικά υπόλοιπα](/docs/tokens/extensions/confidential-transfer).
