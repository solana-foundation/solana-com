Επτά έννοιες αποτελούν τη βάση της ανάπτυξης στο Solana. Ξεκινήστε με τους Λογαριασμούς
και τα Προγράμματα, έπειτα παρακολουθήστε πώς οι Εντολές γίνονται Συναλλαγές. Τα PDAs, τα CPIs και
τα Τέλη βασίζονται σε αυτό το μοντέλο εκτέλεσης.

  alt="Solana core concepts, ordered from accounts and programs through instructions and transactions, with PDAs, CPIs, and fees"
/>

<Cards>
  <Card title="Λογαριασμοί" href="/docs/core/accounts">
    Το Solana αποθηκεύει όλη την κατάσταση σε λογαριασμούς, ένα κατάστιχο κλειδιού-τιμής με κλειδί διευθύνσεων 32 byte.
    Κάθε λογαριασμός έχει πέντε πεδία: lamports, data, owner, executable
    και rent_epoch.
  </Card>
  <Card title="Προγράμματα" href="/docs/core/programs">
    Τα έξυπνα συμβόλαια του Solana, μεταγλωττισμένα σε sBPF. Τα προγράμματα είναι χωρίς κατάσταση και όλη
    η μεταβλητή κατάσταση βρίσκεται σε ξεχωριστούς λογαριασμούς δεδομένων που μεταβιβάζονται μέσω εντολών.
  </Card>
  <Card title="Εντολές" href="/docs/core/instructions">
    Ένα αίτημα εκτέλεσης ενός προγράμματος, που περιέχει ένα αναγνωριστικό προγράμματος, λίστα λογαριασμών
    και αδιαφανή bytes δεδομένων. Πολλαπλές εντολές συνθέτονται σε μία μόνο
    συναλλαγή.
  </Card>
  <Card title="Συναλλαγές" href="/docs/core/transactions">
    Η ατομική μονάδα εκτέλεσης στο Solana. Περιέχει υπογραφές και ένα μήνυμα
    (διευθύνσεις λογαριασμών, πρόσφατο blockhash και μεταγλωττισμένες εντολές). Μέγιστο 1232
    bytes, ή 4096 με τη μορφή v1.
  </Card>
  <Card title="Τέλη" href="/docs/core/fees">
    Βασικό τέλος 5.000 lamports ανά υπογραφή, συν προαιρετικό τέλος προτεραιότητας
    βάσει των ζητούμενων μονάδων υπολογισμού. Μέγιστο 1,4 εκατ. μονάδες υπολογισμού ανά συναλλαγή.
  </Card>
  <Card title="Program Derived Addresses (PDAs)" href="/docs/core/pda">
    Ντετερμινιστικές διευθύνσεις που προκύπτουν από ένα αναγνωριστικό προγράμματος και seeds. Μόνο το κατέχον
    πρόγραμμα μπορεί να υπογράψει εκ μέρους ενός PDA μέσω του invoke_signed.
  </Card>
  <Card title="Cross-Program Invocations (CPIs)" href="/docs/core/cpi">
    Ένα πρόγραμμα καλεί ένα άλλο μέσω invoke ή invoke_signed. Τα προνόμια υπογράφοντα και εγγράψιμου
    επεκτείνονται στον καλούμενο. Μέγιστο βάθος στοίβας εντολών 5 (κορυφαίο επίπεδο
    συν CPIs).
  </Card>
</Cards>
