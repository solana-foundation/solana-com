## Έκδοση και διαχείριση περιουσιακών στοιχείων

Εάν δημιουργείτε το περιουσιακό στοιχείο αντί να ενσωματώνετε ένα που ήδη υπάρχει,
συνεχίστε στο [Έκδοση & Τoκενοποίηση](/docs/tokenization). Καλύπτει τη δημιουργία token,
ελέγχους πρόσβασης, διακανονισμό παράδοσης έναντι πληρωμής και λειτουργίες αμοιβαίων κεφαλαίων.
