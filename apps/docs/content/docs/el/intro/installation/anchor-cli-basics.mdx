Αυτή η ενότητα παρέχει μερικές κοινές εντολές και παραδείγματα για να σας
βοηθήσει να ξεκινήσετε τη χρήση του
[Anchor CLI](https://www.anchor-lang.com/docs).

<Steps>
<Step>

### Αρχικοποίηση του έργου

Δημιουργήστε ένα νέο έργο Anchor εκτελώντας την εντολή που εμφανίζεται παρακάτω. Θα δημιουργηθεί
ένας νέος κατάλογος με το όνομα του έργου και θα χρησιμοποιηθεί για την αρχικοποίηση ενός νέου έργου
Anchor.

```terminal
$ anchor init <project-name>
```

Για παράδειγμα, η παρακάτω εντολή θα δημιουργήσει ένα έργο με όνομα `my-project`. Ο
κατάλογος `my-project` θα περιέχει ένα αρθρωτό πρόγραμμα Rust και ένα πρότυπο δοκιμών
Rust που χρησιμοποιεί το LiteSVM.

```terminal
$ anchor init my-project
```

Για να δημιουργήσετε αντί αυτού ένα πρότυπο δοκιμών TypeScript, επιλέξτε ρητά ένα. Για
παράδειγμα, χρησιμοποιήστε το πρότυπο Mocha:

```terminal
$ anchor init my-project --test-template mocha
```

Τα πρότυπα δοκιμών TypeScript απαιτούν Node.js και έναν διαχειριστή πακέτων JavaScript.

Στη συνέχεια, μεταβείτε στον κατάλογο του έργου:

```terminal
$ cd <project-name>
```

Δείτε τη
[δομή αρχείων του έργου](https://www.anchor-lang.com/docs/quickstart/local#project-file-structure) του Anchor.

</Step>
<Step>

### Κατασκευή του προγράμματος

Για να κατασκευάσετε το έργο σας, εκτελέστε την ακόλουθη εντολή:

```terminal
$ anchor build
```

Μπορείτε να βρείτε το μεταγλωττισμένο πρόγραμμα στον κατάλογο `/target/deploy`.

<Callout type="warn" title="Αποτυχία εγκατάστασης των platform tools">
  Αν η δημιουργία (build) αναφέρει μη έγκυρο κατάλογο platform-tools, εγκαταστήστε ξανά τα
  εργαλεία δημιουργίας SBF και επαναλάβετε τη δημιουργία:

```terminal
$ cargo build-sbf --force-tools-install
$ anchor build
```

</Callout>

</Step>
<Step>

### Ανάπτυξη του προγράμματος

Για να αναπτύξετε το έργο σας, εκτελέστε την ακόλουθη εντολή:

```terminal
$ anchor deploy
```

Αυτή η εντολή αναπτύσσει το πρόγραμμά σας στο `cluster` που καθορίζεται στο
αρχείο [`Anchor.toml`](https://www.anchor-lang.com/docs/references/anchor-toml).

</Step>
<Step>

### Δοκιμή του προγράμματος

Για να δοκιμάσετε το έργο σας, εκτελέστε την ακόλουθη εντολή:

```terminal
$ anchor test
```

Αυτή η εντολή δημιουργεί, αναπτύσσει και εκτελεί τις δοκιμές για το έργο σας.

<Callout>
  Όταν χρησιμοποιείτε το cluster `localnet`, το Anchor ξεκινά αυτόματα έναν
  τοπικό validator, αναπτύσσει το πρόγραμμα, εκτελεί τις δοκιμές και στη
  συνέχεια σταματά τον validator.
</Callout>

<Callout type="warn" title="Σφάλματα του εκτελεστή δοκιμών JavaScript">

Αν επιλέξατε πρότυπο δοκιμών JavaScript ή TypeScript, κάποιο από τα
παρακάτω σφάλματα μπορεί να υποδεικνύει ότι το Node.js ή ο ρυθμισμένος διαχειριστής πακέτων
δεν είναι εγκατεστημένος:

```
Permission denied (os error 13)
```

```
No such file or directory (os error 2)
```

</Callout>

</Step>
</Steps>
