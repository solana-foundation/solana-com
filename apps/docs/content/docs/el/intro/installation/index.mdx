Ρυθμίστε ένα τοπικό περιβάλλον ανάπτυξης Solana με το αυτοματοποιημένο πρόγραμμα εγκατάστασης. Εγκαθιστά
τα Rust, Solana CLI, Anchor CLI, Surfpool CLI, Node.js και Yarn σε
macOS, Linux ή Windows μέσω WSL.

<Callout type="info" title="Τα Windows απαιτούν WSL">
  Στο Windows PowerShell, εκτελέστε `wsl --install`, επανεκκινήστε τα Windows εφόσον σας ζητηθεί και στη συνέχεια
  εκτελέστε τις παρακάτω εντολές εγκατάστασης στο τερματικό του Ubuntu. Δείτε τον [εγχειρίδιο
  οδηγό χειροκίνητης εγκατάστασης](/docs/intro/installation/dependencies) για την πλήρη
  ρύθμιση του WSL.
</Callout>

## Γρήγορη εγκατάσταση

1. Εκτελέστε το πρόγραμμα εγκατάστασης σε ένα τερματικό macOS, Linux ή WSL:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
```

Μπορείτε να
[ελέγξετε τον πηγαίο κώδικα του προγράμματος εγκατάστασης](https://github.com/solana-developers/solana-install/blob/main/install.sh)
πριν το εκτελέσετε. Το πρόγραμμα εγκατάστασης εντοπίζει τους υποστηριζόμενους διαχειριστές πακέτων Linux και
εγκαθιστά αυτόματα τις εξαρτήσεις συστήματός τους.

2. Επανεκκινήστε το τερματικό σας, ώστε οι νέες εντολές να είναι διαθέσιμες στο `PATH` σας.

3. Επαληθεύστε κάθε εργαλείο:

```terminal
$ rustc --version
$ solana --version
$ anchor --version
$ surfpool --version
$ node --version
$ yarn --version
```

Μια επιτυχημένη εγκατάσταση επιστρέφει έξοδο με την εξής μορφή (οι αριθμοί έκδοσης αλλάζουν καθώς
κυκλοφορούν νέες εκδόσεις των εργαλείων):

```txt title="Example output"
Installed Versions:
Rust: rustc x.y.z (...)
Solana CLI: solana-cli x.y.z (..., client:Agave)
Anchor CLI: anchor-cli x.y.z
Surfpool CLI: surfpool x.y.z
Node.js: vx.y.z
Yarn: x.y.z
```

<Callout type="warn" title="Η εγκατάσταση απέτυχε ή λείπει μια εντολή">
  Ακολουθήστε τον [οδηγό χειροκίνητης εγκατάστασης](/docs/intro/installation/dependencies)
  για να εγκαταστήσετε ή να αντιμετωπίσετε προβλήματα σε κάθε εξάρτηση ξεχωριστά.
</Callout>
