Εγκαταστήστε κάθε εξάρτηση ξεχωριστά όταν χρειάζεστε μια συγκεκριμένη έκδοση ή όταν η
[γρήγορη εγκατάσταση](/docs/intro/installation) δεν ολοκληρώνεται με επιτυχία.
Ακολουθήστε τις ενότητες με τη σειρά για ένα νέο περιβάλλον ή μεταβείτε απευθείας στο εργαλείο
που θέλετε να εγκαταστήσετε ή του οποίου τα προβλήματα θέλετε να επιλύσετε.

## Προαπαιτούμενα

<Accordions>
<Accordion title="Windows">

Για να αναπτύξετε προγράμματα Solana σε Windows **πρέπει** να χρησιμοποιήσετε το
[Windows Subsystem for Linux](https://learn.microsoft.com/en-us/windows/wsl/install)
(WSL). Μετά την εγκατάσταση του WSL, όλες οι άλλες εξαρτήσεις θα εγκατασταθούν
μέσω του τερματικού Linux.

Για να εγκαταστήσετε το WSL, εκτελέστε την ακόλουθη εντολή στο Windows
PowerShell:

```terminal
$ wsl --install
```

Η διαδικασία εγκατάστασης θα σας ζητήσει να δημιουργήσετε έναν προεπιλεγμένο
λογαριασμό χρήστη.

![Εγκατάσταση WSL](/assets/docs/intro/installation/wsl-install.png)

Από προεπιλογή, το WSL εγκαθιστά το Ubuntu. Μπορείτε να ανοίξετε ένα τερματικό
Linux αναζητώντας "Ubuntu" στη γραμμή αναζήτησης.

![WSL Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-search.png)

Αν το τερματικό Ubuntu σας μοιάζει με την παρακάτω εικόνα, ενδέχεται να
αντιμετωπίσετε πρόβλημα όπου το `ctrl + v` (συντόμευση πληκτρολογίου
επικόλλησης) δεν λειτουργεί στο τερματικό.

![Τερματικό Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-terminal-1.png)

Αν αντιμετωπίσετε αυτό το πρόβλημα, ανοίξτε το Windows Terminal αναζητώντας
"Terminal" στη γραμμή αναζήτησης.

![Windows Terminal](/assets/docs/intro/installation/wsl-windows-terminal.png)

Στη συνέχεια, κλείστε το Windows Terminal και ανοίξτε ξανά ένα τερματικό Linux
αναζητώντας το Ubuntu ξανά. Το τερματικό θα πρέπει τώρα να μοιάζει με την
παρακάτω εικόνα, όπου το `ctrl + v` (συντόμευση πληκτρολογίου επικόλλησης)
λειτουργεί.

![Τερματικό Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-terminal-2.png)

Αν χρησιμοποιείτε το VS Code, η
[επέκταση WSL](https://code.visualstudio.com/docs/remote/wsl-tutorial) σας
επιτρέπει να χρησιμοποιείτε το WSL και το VS Code μαζί.

![Ρύθμιση WSL στο VS Code](/assets/docs/intro/installation/wsl-vscode.png)

Θα δείτε τα ακόλουθα στη γραμμή κατάστασης του VS Code:

![WSL: Ubuntu](/assets/docs/intro/installation/wsl-vscode-ubuntu.png)

Αφού ρυθμίσετε το WSL, είστε έτοιμοι είτε να:

- Ολοκληρώσετε τη [γρήγορη εγκατάσταση](/docs/intro/installation)
  χρησιμοποιώντας το τερματικό Ubuntu (Linux)
- Εγκαταστήσετε τη [Rust](#install-rust), το [Solana CLI](#install-solana-cli)
  και το [Anchor CLI](#install-anchor-cli) ξεχωριστά, όπως περιγράφεται παρακάτω

</Accordion>

Σε Debian ή σε διανομή που βασίζεται στο Debian, όπως το Ubuntu ή το Mint:

1. Ενημερώστε τις λίστες πακέτων για να βεβαιωθείτε ότι όλα τα πακέτα είναι
   ενημερωμένα:

```terminal
$ sudo apt-get update
```

2. Εγκαταστήστε τις ακόλουθες εξαρτήσεις:

```terminal
$ sudo apt-get install -y \
    build-essential \
    pkg-config \
    libudev-dev llvm libclang-dev \
    protobuf-compiler libssl-dev
```

<Callout>
Αν συναντήσετε το ακόλουθο σφάλμα κατά την εγκατάσταση του `protobuf-compiler`, εκτελέστε
την εντολή `sudo apt-get update` πριν επαναλάβετε την εντολή εγκατάστασης.

```
Package protobuf-compiler is not available, but is referred to by another package.
This may mean that the package is missing, has been obsoleted, or
is only available from another source
```

</Callout>

Εγκαταστήστε τις εξαρτήσεις ανάπτυξης:

```terminal
$ sudo dnf group install c-development development-tools \

```

### Εγκατάσταση Rust

Οι προγραμματιστές δημιουργούν προγράμματα Solana χρησιμοποιώντας τη γλώσσα
προγραμματισμού [Rust](https://www.rust-lang.org/).

1. Εγκαταστήστε το Rust χρησιμοποιώντας το
   [rustup](https://www.rust-lang.org/tools/install) εισάγοντας την ακόλουθη
   εντολή στο τερματικό σας:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
```

Μετά από μια επιτυχημένη εγκατάσταση θα δείτε το ακόλουθο μήνυμα:

<Accordions>
<Accordion title="Μήνυμα επιτυχούς εγκατάστασης Rust">

```
Rust is installed now. Great!

To get started you may need to restart your current shell.
This would reload your PATH environment variable to include
Cargo's bin directory ($HOME/.cargo/bin).

To configure your current shell, you need to source
the corresponding env file under $HOME/.cargo.

This is usually done by running one of the following (note the leading DOT):
. "$HOME/.cargo/env"            # For sh/bash/zsh/ash/dash/pdksh
source "$HOME/.cargo/env.fish"  # For fish
```

</Accordion>
</Accordions>

2. Επαναφορτώστε τη μεταβλητή περιβάλλοντος PATH για να συμπεριλάβετε τον
   κατάλογο bin του [Cargo](https://github.com/rust-lang/cargo):

```terminal
$ . "$HOME/.cargo/env"
```

3. Επαληθεύστε ότι η εγκατάσταση ήταν επιτυχής.

```terminal
$ rustc --version
```

Η εντολή εμφανίζει την εγκατεστημένη έκδοση της Rust, για παράδειγμα:

```
rustc x.y.z (...)
```

</Step>

### Εγκατάσταση Solana CLI

Το Solana CLI παρέχει όλα τα εργαλεία που απαιτούνται για τη δημιουργία και την
ανάπτυξη προγραμμάτων Solana.

1. Εγκαταστήστε τη σουίτα εργαλείων Solana CLI χρησιμοποιώντας την επίσημη
   εντολή εγκατάστασης:

```terminal
$ sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

<Callout>
  Μπορείτε να αντικαταστήσετε το `stable` με ένα συγκεκριμένο tag έκδοσης του Agave ή με το κανάλι εκδόσεων `beta`
  ή `edge`.
</Callout>

2. Κάντε το Solana CLI διαθέσιμο στο τρέχον τερματικό σας.

Το πρόγραμμα εγκατάστασης ενημερώνει τη διαμόρφωση του shell σας και εμφανίζει την εντολή που απαιτείται
για την ενημέρωση της τρέχουσας συνεδρίας. Η εντολή είναι συνήθως:

```terminal
$ export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"
```

Αν το `solana` εξακολουθεί να μην είναι διαθέσιμο, επανεκκινήστε το τερματικό σας. Για να επιβεβαιώσετε ποιο αρχείο
διαμόρφωσης του shell ενημέρωσε το πρόγραμμα εγκατάστασης, ελέγξτε το τρέχον shell σας:

```terminal
$ echo $SHELL
```

- Αν η έξοδος περιέχει `/bash`, επανεκκινήστε το τερματικό ή εκτελέστε
  `source ~/.bashrc`.
- Αν η έξοδος περιέχει `/zsh`, επανεκκινήστε το τερματικό ή εκτελέστε `source ~/.zshrc`.

3. Επαληθεύστε ότι η εγκατάσταση ολοκληρώθηκε με επιτυχία:

```terminal
$ solana --version
```

Η εντολή εμφανίζει την εγκατεστημένη έκδοση του Solana CLI, για παράδειγμα:

```
solana-cli x.y.z (..., client:Agave)
```

<Callout>

Μπορείτε να δείτε όλες τις διαθέσιμες εκδόσεις στο
[αποθετήριο Agave στο GitHub](https://github.com/anza-xyz/agave/releases). Το Agave είναι
το validator client της [Anza](https://www.anza.xyz/), γνωστό παλαιότερα ως
validator client της Solana Labs.

</Callout>

4. Για να ενημερώσετε αργότερα το Solana CLI, εκτελέστε:

```terminal
$ agave-install update
```

</Step>

### Εγκατάσταση Anchor CLI

Το [Anchor](https://www.anchor-lang.com/) είναι ένα πλαίσιο ανάπτυξης
προγραμμάτων Solana. Το πλαίσιο Anchor αξιοποιεί τις μακροεντολές Rust για να
απλοποιήσει τη διαδικασία συγγραφής προγραμμάτων Solana.

#### Προαπαιτούμενα

Το Node.js και ένας διαχειριστής πακέτων JavaScript απαιτούνται μόνο όταν επιλέγετε ένα
πρότυπο δοκιμών TypeScript, όπως το Mocha ή το Jest. Το προεπιλεγμένο πρότυπο δοκιμών LiteSVM
εκτελείται σε Rust και δεν απαιτεί εργαλεία Node.js.

<Accordions>
<Accordion title="Εγκατάσταση Node">

1. Εγκαταστήστε το Node χρησιμοποιώντας το
   [Node Version Manager (nvm)](https://github.com/nvm-sh/nvm) εκτελώντας την
   ακόλουθη εντολή:

```terminal
$ curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```

2. Επανεκκινήστε το τερματικό σας και επιβεβαιώστε ότι η εντολή `nvm` εκτελείται με επιτυχία:

```terminal
$ command -v nvm
```

3. Χρησιμοποιήστε το `nvm` για να εγκαταστήσετε το Node:

```terminal
$ nvm install --lts
```

4. Επαληθεύστε ότι η εγκατάσταση ολοκληρώθηκε με επιτυχία, ελέγχοντας την έκδοση του Node:

```terminal
$ node --version
```

Η εντολή εμφανίζει την εγκατεστημένη έκδοση του Node.js, για παράδειγμα:

```
vx.y.z
```

</Accordion>
<Accordion title="Εγκατάσταση Yarn">

1. Εγκαταστήστε το Yarn:

```terminal
$ npm install --global yarn
```

2. Επαληθεύστε ότι η εγκατάσταση ολοκληρώθηκε με επιτυχία, ελέγχοντας την έκδοση του Yarn:

```terminal
$ yarn --version
```

Η εντολή εμφανίζει την εγκατεστημένη έκδοση του Yarn, για παράδειγμα:

```
x.y.z
```

</Accordion>
</Accordions>

#### Εγκατάσταση

Μπορείτε να εγκαταστήσετε το Anchor CLI και τα εργαλεία με δύο τρόπους:

- Anchor Version Manager (AVM) — Συνιστώμενη μέθοδος εγκατάστασης
- Χωρίς AVM — Εγκατάσταση απευθείας από το GitHub

<Tabs groupId="anchor" items={["AVM", "Without AVM"]}>
<Tab value="AVM">

Το Anchor Version Manager (AVM) σας επιτρέπει να εγκαταστήσετε και να
διαχειριστείτε διαφορετικές εκδόσεις του Anchor στο σύστημά σας και να
ενημερώνετε εύκολα τις εκδόσεις του Anchor στο μέλλον. Για να εγκαταστήσετε το
Anchor χρησιμοποιώντας το AVM, ακολουθήστε τα παρακάτω βήματα:

1. Εγκαταστήστε το AVM με την ακόλουθη εντολή:

```terminal
$ curl -sSfL https://raw.githubusercontent.com/otter-sec/anchor/master/avm/install | sh
```

2.  Επιβεβαιώστε ότι το AVM εγκαταστάθηκε με επιτυχία:

```terminal
$ avm --version
```

3. Εγκαταστήστε το Anchor CLI χρησιμοποιώντας το AVM:

Για να εγκαταστήσετε την πιο πρόσφατη έκδοση:

```terminal
$ avm install latest
$ avm use latest
```

Για να εγκαταστήσετε μια συγκεκριμένη έκδοση, καθορίστε τον αριθμό έκδοσης:

```terminal
$ avm install 1.1.2
$ avm use 1.1.2
```

<Callout type="warn">

Κατά την εγκατάσταση του Anchor CLI σε Linux ή WSL, ενδέχεται να αντιμετωπίσετε αυτό το σφάλμα:

```
error: could not exec the linker cc = note: Permission denied (os error 13)
```

Αν δείτε αυτό το μήνυμα σφάλματος, ακολουθήστε τα παρακάτω βήματα:

1. Εγκαταστήστε τις εξαρτήσεις που αναφέρονται στην ενότητα
   [Linux](/docs/intro/installation/dependencies) στην κορυφή αυτής της
   σελίδας.
2. Δοκιμάστε ξανά την εγκατάσταση του Anchor CLI.

</Callout>

4. Επαληθεύστε ότι η εγκατάσταση ολοκληρώθηκε με επιτυχία, ελέγχοντας την έκδοση
   του Anchor CLI:

```terminal
$ anchor --version
```

Η εντολή εμφανίζει την ενεργή έκδοση του Anchor CLI, για παράδειγμα:

```
anchor-cli 1.1.2
```

<Callout type="info">

Εκτελέστε `avm use` για να επιλέξετε την έκδοση του Anchor CLI για το σύστημά σας.

- Αν εγκαταστήσατε την τελευταία έκδοση, εκτελέστε `avm use latest`.
- Αν εγκαταστήσατε την έκδοση `1.1.2`, εκτελέστε `avm use 1.1.2`.

</Callout>

</Tab>

Η εντολή εμφανίζει την εγκατεστημένη έκδοση του Anchor CLI, για παράδειγμα:

### Εγκατάσταση του Surfpool CLI

Το [Surfpool](/docs/tools/surfpool) είναι ένα εργαλείο για τοπική ανάπτυξη και βελτιωμένη
αντικατάσταση του `solana-test-validator`.

1. Εγκαταστήστε το Surfpool με την ακόλουθη εντολή:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://run.surfpool.run/ | bash
```

2. Επαληθεύστε ότι η εγκατάσταση ολοκληρώθηκε με επιτυχία, ελέγχοντας την έκδοση του Surfpool CLI:

```terminal
$ surfpool --version
```

Η εντολή εμφανίζει την εγκατεστημένη έκδοση του Surfpool CLI, για παράδειγμα:

```
surfpool x.y.z
```
