Θα καταλήξετε με ένα στοιχείο React που εμφανίζει έναν κωδικό QR του Solana Pay για μια πληρωμή σε USDC, περιμένει να ολοκληρωθεί η πληρωμή και ελέγχει ότι ταιριάζει με αυτό που ζητήσατε. Χρειάζεστε Node.js 20+, μια εφαρμογή React ή Next.js (ένα νέο `create-next-app` είναι εντάξει) και ένα πορτοφόλι κινητού ρυθμισμένο στο devnet. Χρηματοδοτήστε το με devnet USDC από το [faucet.circle.com](https://faucet.circle.com) και με devnet SOL από το [faucet.solana.com](https://faucet.solana.com) για να καλύψετε τα τέλη συναλλαγών.

<Callout type="caution">
  Το `@solana/pay` βρίσκεται αυτή τη στιγμή σε beta. Τα API ενδέχεται να αλλάξουν πριν από την σταθερή έκδοση.
</Callout>

## 1. Εγκαταστήστε το Solana Pay

```bash
pnpm add @solana/pay@beta @solana/kit
```

## 2. Προσθέστε τον κωδικό QR πληρωμής

Το στοιχείο δημιουργεί μια μοναδική αναφορά για την παραγγελία, την κωδικοποιεί σε ένα URL [αιτήματος μεταφοράς](/docs/tools/solana-pay/quickstart/transfer-requests) και εμφανίζει το URL ως κωδικό QR. Στη συνέχεια παρακολουθεί για μια συναλλαγή που περιλαμβάνει την αναφορά και επικυρώνει τον παραλήπτη, το ποσό και το token πριν επισημάνει την παραγγελία ως πληρωμένη. Ορίστε το `MERCHANT_WALLET` σε μια διεύθυνση που ελέγχετε:

```tsx
"use client";

import { useEffect, useRef, useState } from "react";
import {
  address,
  createSolanaRpc,
  createSolanaRpcSubscriptions,
  generateKeyPair,
  getAddressFromPublicKey
} from "@solana/kit";
import {
  createQR,
  encodeURL,
  validateTransfer,
  watchReference
} from "@solana/pay";

const MERCHANT_WALLET = address("your-wallet-address");
const USDC_DEVNET = address("4zMMC9srt5Ri5X14GAgXhaHii3GnPAEERYPJgZJDncDU");
const AMOUNT = 1;

const rpc = createSolanaRpc("https://api.devnet.solana.com");
const rpcSubscriptions = createSolanaRpcSubscriptions(
  "wss://api.devnet.solana.com"
);

export function Checkout() {
  const qrRef = useRef<HTMLDivElement>(null);
  const [signature, setSignature] = useState<string | null>(null);

  useEffect(() => {
    const abortController = new AbortController();

    async function startPayment() {
      const keyPair = await generateKeyPair();
      const reference = await getAddressFromPublicKey(keyPair.publicKey);

      const url = encodeURL({
        recipient: MERCHANT_WALLET,
        amount: AMOUNT,
        splToken: USDC_DEVNET,
        reference,
        label: "My Store",
        message: "Order #1001"
      });

      if (abortController.signal.aborted) return;

      if (qrRef.current) {
        qrRef.current.innerHTML = "";
        createQR(url, 300).append(qrRef.current);
      }

      const result = await watchReference(rpcSubscriptions, reference, {
        abortSignal: abortController.signal
      });
      if (result.err) throw new Error("Payment transaction failed");

      await validateTransfer(rpc, result.signature, {
        recipient: MERCHANT_WALLET,
        amount: AMOUNT,
        splToken: USDC_DEVNET,
        reference
      });
      setSignature(result.signature);
    }

    startPayment().catch((error) => {
      if (!abortController.signal.aborted) console.error(error);
    });

    return () => abortController.abort();
  }, []);

  if (signature) return <p>Payment confirmed: {signature}</p>;
  return <div ref={qrRef} />;
}
```

Το `amount` είναι σε μονάδες token, οπότε το `1` ζητά 1 USDC. Παραλείψτε το `splToken` για να ζητήσετε SOL.

## 3. Λάβετε μια πληρωμή

Εκτελέστε την εφαρμογή σας, σαρώστε τον κωδικό QR με το πορτοφόλι σας και εγκρίνετε την πληρωμή. Μόλις η συναλλαγή επιβεβαιωθεί και περάσει την επικύρωση, το στοιχείο εμφανίζει την υπογραφή της συναλλαγής. Αυτή η υπογραφή είναι η απόδειξή σας: αναζητήστε την με το [getTransaction](/docs/rpc/http/gettransaction) ή σε οποιονδήποτε explorer.

<Callout type="warn">
  Η επικύρωση στο πρόγραμμα περιήγησης είναι εντάξει για ένα demo. Προτού εκπληρώσετε πραγματικές παραγγελίες, επικυρώστε τις πληρωμές στον διακομιστή σας. Δείτε [επαλήθευση πληρωμών](/docs/payments/accept-payments/verification-tools).
</Callout>
