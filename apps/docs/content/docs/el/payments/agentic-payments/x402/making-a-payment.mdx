Χρησιμοποιήστε το [Pay](https://pay.sh) για να εκτελέσετε ένα API x402 V2 και να δώσετε στο Claude Code έναν
HTTP client με υποστήριξη πληρωμών. Το API, το πορτοφόλι του πληρωτή και η εκκαθάριση χρησιμοποιούν όλα το
sandbox της Solana, επομένως αυτός ο οδηγός δεν απαιτεί λογαριασμό ή πραγματικά κεφάλαια.

Χρειάζεστε ένα τερματικό, το Pay και εγκατεστημένο το Claude Code.

## 1. Εγκατάσταση του Pay

Στο macOS, εγκαταστήστε το προμεταγλωττισμένο εκτελέσιμο αρχείο:

```bash
brew install pay
pay --version
```

Σε άλλες πλατφόρμες, εγκαταστήστε το πακέτο npm:

```bash
npm install --global @solana/pay
pay --version
```

## 2. Εκκίνηση ενός API sandbox x402

Δημιουργήστε το `x402-demo.yaml`:

```yaml filename=x402-demo.yaml
name: x402-demo
subdomain: x402-demo
title: "x402 Demo"
description: "Minimal x402 V2 sandbox endpoint."
category: devtools
version: v1
routing:
  type: respond
operator:
  currencies:
    usd: ["USDC"]
  network: "localnet"
  fee_payer: true
endpoints:
  - method: GET
    path: "report"
    description: "Return a sandbox report."
    metering:
      schemes: [x402-exact]
      dimensions:
        - direction: usage
          unit: requests
          scale: 1
          tiers:
            - price_usd: 0.001
```

Εκκινήστε το API και αφήστε το σε λειτουργία:

```bash
pay --sandbox server start x402-demo.yaml --bind 127.0.0.1:1402
```

Το σχήμα `x402-exact` καθιστά αυτό το endpoint αποκλειστικά x402. Η λειτουργία sandbox δημιουργεί
και χρηματοδοτεί αυτόματα προσωρινούς λογαριασμούς operator και πληρωτή.

## 3. Εκκίνηση του agent με το Pay

Σε ένα άλλο τερματικό, εκκινήστε το Claude Code σε λειτουργία sandbox:

```bash
pay --sandbox claude
```

Το Pay συνδέει τα τοπικά εργαλεία MCP του στη συνεδρία του agent. Ο agent δεν
λαμβάνει ιδιωτικό κλειδί.

## 4. Υποβολή ενός αιτήματος x402

Επικολλήστε αυτό το prompt στον agent:

```text
Use Pay to make exactly one sandbox x402 API request to
http://127.0.0.1:1402/report.

Before paying, show me the amount and ask for approval. Then return the API
result and payment receipt. Do not make any other paid requests.
```

Το αίτημα ακολουθεί έναν πλήρη κύκλο πληρωμής x402 V2:

1. Το API επιστρέφει `402 Payment Required` με μια πρόκληση `PAYMENT-REQUIRED`.
2. Το Pay επικυρώνει τις απαιτήσεις x402 και εμφανίζει τους όρους πληρωμής.
3. Μετά την έγκριση, το πορτοφόλι sandbox υπογράφει και το Pay επαναλαμβάνει το αίτημα με
   `PAYMENT-SIGNATURE`.
4. Το API επιστρέφει το αποτέλεσμα μαζί με μια απόδειξη `PAYMENT-RESPONSE`.

Δεν μετακινούνται πραγματικά κεφάλαια. Η απόρριψη της έγκρισης σταματά το αίτημα.

Συνεχίστε με το [x402 στη Solana](/docs/payments/agentic-payments/x402) για να δημιουργήσετε έναν
πελάτη και έναν διακομιστή πόρων x402 V2, ή
[γίνετε facilitator x402](/docs/tools/x402-facilitator).
