`solana` komut satırı arayüzü, cluster bağlantısını yapılandırır, ağ durumunu okur,
SOL gönderir, kalıcı nonce'ları yönetir, programları dağıtır ve stake ile vote
hesaplarını işletir.

Bu başvuru kılavuzu
[Agave v4.2.1](https://github.com/anza-xyz/agave/releases/tag/v4.2.1) sürümünü temel alır. Yüklü sürümü kontrol etmek için
`solana --version` komutunu çalıştırın; ilgili sürümde kullanılabilen seçenekleri
tam olarak görmek için `--help` kullanın.

<Callout type="warn">
  Oluşturan, transfer eden, yetkilendiren, çeken veya dağıtan komutlar işlem
  gönderir. Bunları çalıştırmadan önce yapılandırılmış cluster'ı ve imzalayanı doğrulayın.
  Devnet ve Testnet token'larının hiçbir değeri yoktur; Mainnet komutları gerçek SOL kullanır.
</Callout>

## Komut yapısı

```text
solana [GLOBAL_OPTIONS] <COMMAND> [COMMAND_OPTIONS]
```

Her düzeyde yardım alın:

```shell
solana --help
solana transfer --help
solana address-lookup-table extend --help
```

## Genel seçenekler

Genel seçenekler komutun önüne yerleştirilebilir. Komuta özgü yardım, o komut için
geçerli olan seçenekleri tekrar listeler.

| Seçenek                          | Amaç                                                                        |
| ------------------------------- | ------------------------------------------------------------------------------ |
| `-u, --url <URL_OR_MONIKER>`    | Bir RPC URL'si veya `mainnet-beta`, `testnet`, `devnet` ya da `localhost` seçer.      |
| `--ws <URL>`                    | WebSocket uç noktasını geçersiz kılar.                                               |
| `-k, --keypair <KEYPAIR>`       | Bir keypair dosyası, `ASK`, stdin (`-`) veya desteklenen bir imzalayıcı URL'si seçer.          |
| `-C, --config <FILEPATH>`       | Farklı bir CLI yapılandırma dosyası kullanır.                                        |
| `--commitment <LEVEL>`          | `processed`, `confirmed` veya `finalized` commitment düzeyinde okur.                   |
| `--output <FORMAT>`             | Desteklenen yerlerde `json` veya `json-compact` döndürür.                               |
| `--skip-preflight`              | RPC simülasyonu olmadan gönderir. Yalnızca başarısızlık risklerinin bilindiği durumlarda kullanın. |
| `--use-tpu-client`              | İşlemleri TPU istemcisi üzerinden gönderir.                                      |
| `--no-address-labels`           | Adresleri yerel etiketler olmadan yazdırır.                                          |
| `--skip-seed-phrase-validation` | BIP39 İngilizce listesi dışındaki bir kurtarma ifadesine izin verir.                       |
| `-v, --verbose`                 | Ek komut çıktısı gösterir.                                                |
| `-V, --version`                 | Yüklü CLI sürümünü yazdırır.                                               |

## CLI'ı yapılandırma

```shell
# Inspect the effective configuration.
solana config get

# Use Devnet and a specific signer by default.
solana config set --url devnet
solana config set --keypair ./devnet-keypair.json

# Override defaults for one command.
solana --url mainnet-beta --keypair usb://ledger address
```

Yapılandırma; bir RPC URL'si, WebSocket URL'si, varsayılan imzalayıcı ve
commitment içerir. Bir komut satırı seçeneği, ilgili çağrı için kayıtlı değeri geçersiz kılar.

## Yaygın hesap ve işlem iş akışları

```shell
# Print the default signer's address and balance.
solana address
solana balance

# Read an account as JSON.
solana account <ACCOUNT_ADDRESS> --output json

# Request Devnet SOL.
solana airdrop 1 --url devnet

# Send SOL and then confirm the returned signature.
solana transfer <RECIPIENT_ADDRESS> 0.1 --allow-unfunded-recipient
solana confirm <TRANSACTION_SIGNATURE>

# Inspect recent activity and stream logs mentioning an address.
solana transaction-history <ADDRESS> --limit 20
solana logs <ADDRESS>
```

`transfer` varsayılan olarak SOL kabul eder. Ücretlerden sonra kullanılabilir bakiyenin
tamamını taşımak için tutar olarak `ALL` kullanın. Token örnekleri için
[token hızlı başlangıç kılavuzuna](/docs/tokens/quickstart) bakın.

## Program iş akışları

```shell
# Deploy or upgrade an SBF program.
solana program deploy ./target/deploy/my_program.so

# Inspect the deployed program and list programs controlled by the signer.
solana program show <PROGRAM_ID>
solana program show --programs

# Close a program buffer and recover its lamports.
solana program close <BUFFER_ADDRESS>
```

Bir dağıtımın bilinen bir program ID'sini kullanması gerektiğinde
`--program-id <KEYPAIR_OR_ADDRESS>` parametresini geçin. `--final`, yeni bir dağıtımı
değiştirilemez hale getirir; yükseltme yetkisi geri alınamayacağından kullanmadan önce
yardım metnini dikkatle okuyun.

## Kalıcı nonce iş akışları

```shell
solana-keygen new --outfile nonce-account.json
solana create-nonce-account nonce-account.json 0.1
solana nonce nonce-account.json
solana new-nonce nonce-account.json
solana withdraw-from-nonce-account nonce-account.json <RECIPIENT_ADDRESS> ALL
```

Nonce yetkilisini değiştirmek için `authorize-nonce-account`, hesabın tüm durumunu
incelemek için `nonce-account` kullanın. Nonce kullanan işlemler, desteklenen komutlarda
ayrıca `--nonce` ve `--nonce-authority` seçeneklerini kabul eder.

## Stake iş akışları

```shell
solana-keygen new --outfile stake-account.json
solana create-stake-account stake-account.json 1
solana delegate-stake stake-account.json <VOTE_ACCOUNT_ADDRESS>
solana stake-account stake-account.json

solana deactivate-stake stake-account.json
solana withdraw-stake stake-account.json <RECIPIENT_ADDRESS> ALL
```

Devre dışı bırakma işlemi bir epoch sınırında tamamlanır ve birden fazla epoch sürebilir.
Değişiklikleri göndermeden önce cluster ve delegasyon durumunu incelemek için `stakes`,
`validators`, `stake-history` ve `stake-minimum-delegation` komutlarını kullanın.

## Adres yardımcı araçları

```shell
# Derive a PDA from typed seeds.
solana find-program-derived-address \
  <PROGRAM_ID> \
  string:profile \
  pubkey:<OWNER_ADDRESS>

# Create and extend an address lookup table.
solana address-lookup-table create
solana address-lookup-table extend \
  <LOOKUP_TABLE_ADDRESS> \
  --addresses <ADDRESS_1>,<ADDRESS_2>
```

PDA seed'leri `PREFIX:VALUE` biçimini kullanır. Desteklenen önekler arasında `string`, `pubkey`,
`hex`, `u8` ve `u64le` gibi sabit genişlikli işaretli veya işaretsiz tamsayı
kodlamaları yer alır.

## Zincir dışı mesajlar ve kabuk tamamlama

```shell
solana sign-offchain-message "terms accepted"
solana verify-offchain-signature \
  "terms accepted" \
  <SIGNATURE> \
  --signer <SIGNER_ADDRESS>

# Print a completion script for the current shell.
solana completion --shell zsh
```

## Betik çıktısı

İnsan tarafından okunabilir çıktıyı ayrıştırmak yerine, desteklenen yerlerde
`--output json` veya `--output json-compact` kullanın:

```shell
solana epoch-info --output json
solana account <ACCOUNT_ADDRESS> --output json-compact
solana validators --output json > validators.json
```

Her komut yapılandırılmış çıktıyı desteklemez. Otomasyonda buna güvenmeden önce
komutun yardım metnini kontrol edin ve sıfırdan farklı çıkış durumunu başarısızlık olarak değerlendirin.
