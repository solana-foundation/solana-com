`spl-token` komut satırı arayüzü; mint'leri, token
hesaplarını, yetkileri, transferleri ve Token-2022 uzantılarını oluşturur ve yönetir.

Bu referans, Agave v4.2.1 ile birlikte gelen
[`spl-token-cli` v5.6.1](https://github.com/solana-program/token-2022/releases/tag/cli%40v5.6.1) sürümünü temel alır.
`spl-token --version` komutunu çalıştırın ve yüklü sürümünüzde kullanılabilen seçenekler için
`<command> --help` komutunu kullanın.

<Callout type="warn">
  Mint oluşturma, transferler, yetki değişiklikleri, yakma, dondurma ve hesap
  kapatma işlemleri birer işlem gönderir. Bir komutu çalıştırmadan önce cluster'ı, Token Program'ı, imzalayanı ve
  adresleri doğrulayın. Mainnet üzerindeki değişiklikler gerçek varlıkları etkiler.
</Callout>

## Kurulum ve yardım alma

Agave CLI sürüm paketi `spl-token` aracını içerir. Kurulu değilse yayımlanmış
Rust crate'ini kullanın:

```shell
cargo install spl-token-cli --version 5.6.1
spl-token --version
```

Yardımı kök düzeyinde veya komut düzeyinde görüntüleyin:

```shell
spl-token --help
spl-token create-token --help
spl-token transfer --help
```

## Genel seçenekler

Genel seçenekleri komuttan önce yazın.

| Seçenek                                       | Amaç                                                                   |
| -------------------------------------------- | ------------------------------------------------------------------------- |
| `-u, --url <URL_OR_MONIKER>`                 | Bir RPC URL'si veya `mainnet-beta`, `testnet`, `devnet` ya da `localhost` seçin. |
| `-C, --config <PATH>`                        | Farklı bir Solana CLI yapılandırma dosyası kullanın.                            |
| `--fee-payer <KEYPAIR>`                      | İşlem ücretlerini ödeyecek hesabı seçin.                            |
| `-p, --program-id <ADDRESS>`                 | Açık bir Token Program ID'si kullanın.                                         |
| `--program-2022`                             | Token-2022'yi kullanın (`TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb`).           |
| `--output <FORMAT>`                          | Desteklendiği yerlerde `json` veya `json-compact` biçiminde çıktı döndürün.                          |
| `--with-compute-unit-limit <UNITS>`          | İşlemin compute unit limitini belirleyin.                                   |
| `--with-compute-unit-price <MICRO_LAMPORTS>` | Compute unit başına öncelik fiyatını belirleyin.                                  |
| `-v, --verbose`                              | Ek çıktı gösterin.                                                   |
| `-V, --version`                              | Yüklü CLI sürümünü yazdırın.                                          |

Varsayılan program, orijinal Token Program'dır. Bir Token-2022 mint'i veya hesabı için,
onu okurken de dahil olmak üzere, `--program-2022` kullanın. Seçilen program
verilen adrese sahip değilse komut başarısız olur.

## Token oluşturma ve kullanma

Komutlar, oluşturulan adresleri yazdırır. Sonraki komutlar için
`create-token` tarafından döndürülen mint adresini kaydedin.

```shell
# Create a six-decimal mint under the original Token Program.
spl-token --url devnet create-token --decimals 6

# Create the default signer's associated token account for the mint.
spl-token --url devnet create-account <MINT_ADDRESS>

# Mint 100 tokens to that associated token account.
spl-token --url devnet mint <MINT_ADDRESS> 100

# Read supply, balance, and complete mint or account details.
spl-token --url devnet supply <MINT_ADDRESS>
spl-token --url devnet balance <MINT_ADDRESS>
spl-token --url devnet display <MINT_OR_TOKEN_ACCOUNT_ADDRESS>

# Transfer tokens to a wallet and create its associated account if needed.
spl-token --url devnet transfer \
  <MINT_ADDRESS> \
  10 \
  <RECIPIENT_WALLET_ADDRESS> \
  --fund-recipient
```

Tutarlar, mint'in ondalık basamaklarına göre ayarlanmış arayüz (UI) token tutarlarıdır. `transfer`,
`burn` ve `unwrap-sol` gibi komutlar, yardım çıktılarında belirtilen yerlerde `ALL` değerini kabul eder.

## Token-2022 mint'i oluşturma

Uzantılar ek mint veya hesap durumu için alan ayırır ve genellikle mint
oluşturulurken seçilmelidir. Bu örnek, gömülü metadata desteğine sahip altı
ondalık basamaklı bir mint oluşturur:

```shell
spl-token --program-2022 create-token \
  --decimals 6 \
  --enable-metadata

spl-token --program-2022 initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  EXAMPLE \
  https://example.com/token.json
```

Yaygın `create-token` uzantı seçenekleri şunlardır:

- `--enable-close`
- `--enable-confidential-transfers auto|manual`
- `--enable-freeze`
- `--enable-group` ve `--enable-member`
- `--enable-metadata`
- `--enable-non-transferable`
- `--enable-pause`
- `--enable-permanent-delegate`
- `--enable-permissioned-burn`
- `--enable-transfer-hook` veya `--transfer-hook <PROGRAM_ID>`
- `--interest-rate <BASIS_POINTS>`
- `--transfer-fee-basis-points <BASIS_POINTS>` ile birlikte
  `--transfer-fee-maximum-fee <AMOUNT>`
- `--ui-amount-multiplier <MULTIPLIER>`

Yalnızca Token-2022 programının birlikte kullanılmasına izin verdiği uzantıları birleştirin. Geri döndürülemez bir mint yapılandırması oluşturmadan önce
ilgili [Token-2022 uzantı kılavuzunu](/docs/tokens/extensions) inceleyin.

## Yetkileri ve delegeleri yönetme

```shell
# Change the mint authority.
spl-token authorize <MINT_ADDRESS> mint <NEW_AUTHORITY_ADDRESS>

# Permanently remove the mint authority.
spl-token authorize <MINT_ADDRESS> mint --disable

# Let a delegate spend up to 25 tokens from one token account.
spl-token approve \
  <TOKEN_ACCOUNT_ADDRESS> \
  25 \
  <DELEGATE_ADDRESS>

# Remove the current delegate.
spl-token revoke <TOKEN_ACCOUNT_ADDRESS>
```

`authorize`; mint, freeze, owner, close ve uzantıya özgü
yetki türlerini destekler. Başka hiçbir program mekanizması bir yetkiyi geri getiremiyorsa, `--disable` ile yetkiyi kaldırmak kalıcıdır.

## Dondurma, yakma ve kapatma

```shell
spl-token freeze <TOKEN_ACCOUNT_ADDRESS>
spl-token thaw <TOKEN_ACCOUNT_ADDRESS>

spl-token burn <TOKEN_ACCOUNT_ADDRESS> 5

# A token account must normally have a zero token balance before closing.
spl-token close --address <TOKEN_ACCOUNT_ADDRESS>
```

`burn`, hem hesap bakiyesini hem de toplam arzı azaltır. `close`, hesapta kalan
lamport'ları yapılandırılmış alıcıya iade eder; yakılan token'ları geri getirmez.

## SOL'u wrap ve unwrap etme

```shell
# Create or fund the owner's wrapped SOL token account.
spl-token wrap 1

# Unwrap part of the wrapped SOL balance.
spl-token unwrap-sol 0.25

# Close the wrapped SOL account and return its full lamport balance.
spl-token unwrap
```

Lamport'ları doğrudan wrapped SOL token account'una aktardıktan sonra, token tutarının
alttaki lamport'larla eşleşmesi için `sync-native` kullanın.

## Multisig imzalama

En fazla 11 üyeli, M-of-N bir Token Program multisig'i oluşturun:

```shell
spl-token create-multisig \
  2 \
  <MEMBER_1_ADDRESS> \
  <MEMBER_2_ADDRESS> \
  <MEMBER_3_ADDRESS>
```

Bu multisig tarafından kontrol edilen bir işlem için multisig adresini ilgili
yetki olarak verin ve üye keypair'lerini tekrarlanan
`--multisig-signer` değerleriyle sağlayın. Birincil yetki bayrağı işleme göre değiştiği için
hedef komutun yardımını kontrol edin.

## Gizli bakiyeler

Gizli bakiye komutları, gizli transferler için yapılandırılmış bir Token-2022 mint'i
ve yapılandırılmış bir alıcı hesabı gerektirir.

```shell
spl-token --program-2022 configure-confidential-transfer-account \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 deposit-confidential-tokens \
  <MINT_ADDRESS> \
  10 \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 apply-pending-balance \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 withdraw-confidential-tokens \
  <MINT_ADDRESS> \
  5 \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 transfer \
  <MINT_ADDRESS> \
  1 \
  <RECIPIENT_ADDRESS> \
  --confidential
```

`configure-confidential-transfer-account` ve `apply-pending-balance` için ya
`--address <TOKEN_ACCOUNT_ADDRESS>` ya da konumsal bir `<MINT_ADDRESS>` verin, ikisini birden
vermeyin. Konumsal biçim, sahibin associated token account'unu kullanır. Para yatırma ve
çekme işlemleri her zaman mint'i alır ve bu varsayılan hesabı değiştirmek için `--address` kabul eder.

Hesabın hangi para yatırma işlemlerini kabul edeceğini kontrol etmek için `enable-confidential-credits`, `disable-confidential-credits`,
`enable-non-confidential-credits` ve `disable-non-confidential-credits` komutlarını kullanın. Bu ayarlar hesap
gizliliğini ve ödeme uyumluluğunu etkiler; değiştirmeden önce hesabı inceleyin.

## Yapılandırılmış ve çevrimdışı imzalama

Görüntü metnini ayrıştırmak yerine yapılandırılmış çıktı kullanın:

```shell
spl-token accounts --output json
spl-token display <MINT_ADDRESS> --output json-compact
```

İşlem üreten komutlar genellikle `--sign-only`, `--blockhash`,
`--signer <PUBKEY=SIGNATURE>`, `--nonce` ve `--nonce-authority` seçeneklerini destekler. Tam
çevrimdışı girdiler komuta, mint ondalık basamaklarına ve yetki düzenine bağlıdır;
bu yüzden imzasız mesajı ilgili komutun `--help` yönergelerine göre oluşturun ve
imzaları toplamadan önce her adresi doğrulayın.
