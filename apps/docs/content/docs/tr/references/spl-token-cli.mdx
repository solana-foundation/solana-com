`spl-token` komut satırı arayüzü; mint'leri, token account'ları, yetkilileri,
transferleri ve Token-2022 uzantılarını oluşturur ve yönetir.

Bu referans, Agave v4.2.1 ile birlikte gelen
[`spl-token-cli` v5.6.1](https://github.com/solana-program/token-2022/releases/tag/cli%40v5.6.1) sürümünü temel alır. Kurulu sürümünüzde kullanılabilen
tam seçenekleri görmek için `spl-token --version` komutunu çalıştırın ve
`<command> --help` kullanın.

<Callout type="warn">
  Mint oluşturma, transferler, yetki değişiklikleri, yakma (burn), dondurma ve
  account kapatma işlemleri transaction gönderir. Bir komutu çalıştırmadan önce cluster'ı,
  Token Program'ı, imzalayanı ve adresleri doğrulayın. Mainnet üzerindeki değişiklikler
  gerçek varlıkları etkiler.
</Callout>

## Kurulum ve yardım alma

Agave CLI sürüm paketi `spl-token` içerir. Kurulu değilse yayımlanmış
Rust crate'ini kullanın:

```shell
cargo install spl-token-cli --version 5.6.1
spl-token --version
```

Yardımı kök düzeyde veya komut düzeyinde görüntüleyin:

```shell
spl-token --help
spl-token create-token --help
spl-token transfer --help
```

## Genel seçenekler

Genel seçenekleri komuttan önce yazın.

| Seçenek                                       | Amaç                                                                   |
| -------------------------------------------- | ------------------------------------------------------------------------- |
| `-u, --url <URL_OR_MONIKER>`                 | Bir RPC URL'si veya `mainnet-beta`, `testnet`, `devnet` ya da `localhost` seçin. |
| `-C, --config <PATH>`                        | Farklı bir Solana CLI yapılandırma dosyası kullanın.                            |
| `--fee-payer <KEYPAIR>`                      | Transaction ücretlerini ödeyecek account'u seçin.                            |
| `-p, --program-id <ADDRESS>`                 | Açıkça belirtilen bir Token Program ID'si kullanın.                                         |
| `--program-2022`                             | Token-2022 kullanın (`TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb`).           |
| `--output <FORMAT>`                          | Desteklenen yerlerde `json` veya `json-compact` biçiminde çıktı döndürür.                          |
| `--with-compute-unit-limit <UNITS>`          | Transaction compute unit sınırını belirleyin.                                   |
| `--with-compute-unit-price <MICRO_LAMPORTS>` | Compute unit başına öncelik ücretini belirleyin.                                  |
| `-v, --verbose`                              | Ek çıktı gösterir.                                                   |
| `-V, --version`                              | Kurulu CLI sürümünü yazdırır.                                          |

Varsayılan program, orijinal Token Program'dır. Bir Token-2022 mint'i veya
account'u için, okurken de dahil olmak üzere, `--program-2022` kullanın. Seçilen
program verilen adrese sahip değilse komut başarısız olur.

## Token oluşturma ve kullanma

Komutlar oluşturulan adresleri yazdırır. Sonraki komutlar için `create-token`
tarafından döndürülen mint adresini kaydedin.

```shell
# Create a six-decimal mint under the original Token Program.
spl-token --url devnet create-token --decimals 6

# Create the default signer's associated token account for the mint.
spl-token --url devnet create-account <MINT_ADDRESS>

# Mint 100 tokens to that associated token account.
spl-token --url devnet mint <MINT_ADDRESS> 100

# Read supply, balance, and complete mint or account details.
spl-token --url devnet supply <MINT_ADDRESS>
spl-token --url devnet balance <MINT_ADDRESS>
spl-token --url devnet display <MINT_OR_TOKEN_ACCOUNT_ADDRESS>

# Transfer tokens to a wallet and create its associated account if needed.
spl-token --url devnet transfer \
  <MINT_ADDRESS> \
  10 \
  <RECIPIENT_WALLET_ADDRESS> \
  --fund-recipient
```

Tutarlar, mint'in ondalık basamaklarına göre ayarlanmış UI token tutarlarıdır.
`transfer`, `burn` ve `unwrap-sol` gibi komutlar, yardım çıktılarında gösterilen
yerlerde `ALL` değerini kabul eder.

## Token-2022 mint'i oluşturma

Uzantılar ek mint veya account durumu ayırır ve genellikle mint oluşturulurken
seçilmelidir. Bu örnek, gömülü metadata desteğine sahip altı ondalık basamaklı
bir mint oluşturur:

```shell
spl-token --program-2022 create-token \
  --decimals 6 \
  --enable-metadata

spl-token --program-2022 initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  EXAMPLE \
  https://example.com/token.json
```

Yaygın `create-token` uzantı seçenekleri şunlardır:

- `--enable-close`
- `--enable-confidential-transfers auto|manual`
- `--enable-freeze`
- `--enable-group` ve `--enable-member`
- `--enable-metadata`
- `--enable-non-transferable`
- `--enable-pause`
- `--enable-permanent-delegate`
- `--enable-permissioned-burn`
- `--enable-transfer-hook` veya `--transfer-hook <PROGRAM_ID>`
- `--interest-rate <BASIS_POINTS>`
- `--transfer-fee-basis-points <BASIS_POINTS>` ile birlikte
  `--transfer-fee-maximum-fee <AMOUNT>`
- `--ui-amount-multiplier <MULTIPLIER>`

Yalnızca Token-2022 programının birlikte kullanılmasına izin verdiği uzantıları
birleştirin. Geri alınamaz bir mint yapılandırması oluşturmadan önce ilgili
[Token-2022 uzantı kılavuzunu](/docs/tokens/extensions) inceleyin.

## Yetkilileri ve delegate'leri yönetme

```shell
# Change the mint authority.
spl-token authorize <MINT_ADDRESS> mint <NEW_AUTHORITY_ADDRESS>

# Permanently remove the mint authority.
spl-token authorize <MINT_ADDRESS> mint --disable

# Let a delegate spend up to 25 tokens from one token account.
spl-token approve \
  <TOKEN_ACCOUNT_ADDRESS> \
  25 \
  <DELEGATE_ADDRESS>

# Remove the current delegate.
spl-token revoke <TOKEN_ACCOUNT_ADDRESS>
```

`authorize`; mint, freeze, owner, close ve uzantıya özgü yetki türlerini
destekler. `--disable` ile bir yetkiyi kaldırmak, başka hiçbir program mekanizması
onu geri getiremiyorsa kalıcıdır.

## Dondurma, yakma ve kapatma

```shell
spl-token freeze <TOKEN_ACCOUNT_ADDRESS>
spl-token thaw <TOKEN_ACCOUNT_ADDRESS>

spl-token burn <TOKEN_ACCOUNT_ADDRESS> 5

# A token account must normally have a zero token balance before closing.
spl-token close --address <TOKEN_ACCOUNT_ADDRESS>
```

`burn` hem account bakiyesini hem de toplam arzı azaltır. `close`, account'taki
kalan lamport'ları yapılandırılmış alıcıya iade eder; yakılan token'ları geri
getirmez.

## SOL wrap ve unwrap işlemleri

```shell
# Create or fund the owner's wrapped SOL token account.
spl-token wrap 1

# Unwrap part of the wrapped SOL balance.
spl-token unwrap-sol 0.25

# Close the wrapped SOL account and return its full lamport balance.
spl-token unwrap
```

Lamport'ları doğrudan wrapped SOL token account'una aktardıktan sonra, token
tutarının alttaki lamport'larla eşleşmesi için `sync-native` kullanın.

## Multisig ile imzalama

En fazla 11 üyeli bir M-of-N Token Program multisig'i oluşturun:

```shell
spl-token create-multisig \
  2 \
  <MEMBER_1_ADDRESS> \
  <MEMBER_2_ADDRESS> \
  <MEMBER_3_ADDRESS>
```

Bu multisig tarafından kontrol edilen bir transaction için multisig adresini
ilgili yetkili olarak verin ve üye keypair'lerini tekrarlanan
`--multisig-signer` değerleriyle sağlayın. Birincil yetkili bayrağı işleme göre
değiştiği için hedef komutun yardımını kontrol edin.

## Gizli bakiyeler

Gizli bakiye komutları, gizli transferler için yapılandırılmış bir Token-2022
mint'i ve yapılandırılmış bir alıcı account gerektirir.

```shell
spl-token --program-2022 configure-confidential-transfer-account \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 deposit-confidential-tokens \
  <MINT_ADDRESS> \
  10 \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 apply-pending-balance \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 withdraw-confidential-tokens \
  <MINT_ADDRESS> \
  5 \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 transfer \
  <MINT_ADDRESS> \
  1 \
  <RECIPIENT_ADDRESS> \
  --confidential
```

`configure-confidential-transfer-account` ve `apply-pending-balance` için
`--address <TOKEN_ACCOUNT_ADDRESS>` veya konumsal `<MINT_ADDRESS>` değerinden
yalnızca birini verin, ikisini birden değil. Konumsal biçim, sahibin associated
token account'unu kullanır. Yatırma ve çekme işlemleri her zaman mint'i alır ve
varsayılan account'u geçersiz kılmak için `--address` kabul eder.

Account'un hangi yatırmaları kabul edeceğini kontrol etmek için
`enable-confidential-credits`, `disable-confidential-credits`,
`enable-non-confidential-credits` ve `disable-non-confidential-credits`
komutlarını kullanın. Bu ayarlar account gizliliğini ve ödeme uyumluluğunu
etkiler; değiştirmeden önce account'u inceleyin.

## Yapılandırılmış ve çevrimdışı imzalama

Görüntü metnini ayrıştırmak yerine yapılandırılmış çıktıyı kullanın:

```shell
spl-token accounts --output json
spl-token display <MINT_ADDRESS> --output json-compact
```

Transaction üreten komutlar genellikle `--sign-only`, `--blockhash`,
`--signer <PUBKEY=SIGNATURE>`, `--nonce` ve `--nonce-authority` seçeneklerini
destekler. Gereken çevrimdışı girdiler komuta, mint ondalık basamaklarına ve
yetki düzenine bağlıdır; bu nedenle imzasız mesajı ilgili komutun `--help`
talimatlarına göre oluşturun ve imzaları toplamadan önce her adresi doğrulayın.
