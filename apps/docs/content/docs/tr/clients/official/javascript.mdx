## Solana Kit

`@solana/kit`, Solana üzerinde geliştirme yapmak için önerilen TypeScript
SDK'sıdır. Birleştirilebilir eklentilerden bir istemci oluşturursunuz, ihtiyaç
duyduğunuzda React bağlamalarını eklersiniz ve çağırdığınız zincir üstü
programlar için oluşturulmuş program istemcilerini dahil edersiniz.

| Paket                   | Açıklama                                  | GitHub                                                                                 |
| ------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------- |
| @solana/kit               | Çekirdek SDK: RPC, işlemler, codec'ler, imzalayanlar | [Kaynak](https://github.com/anza-xyz/kit)                                              |
| @solana/react             | React bağlamaları: `ClientProvider` ve hook'lar   | [Kaynak](https://github.com/anza-xyz/kit/tree/main/packages/react)                     |
| @solana/kit-plugin-rpc    | RPC bağlantısı + işlem gönderimi         | [Kaynak](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-rpc)    |
| @solana/kit-plugin-signer | Ücret ödeyen, kimlik ve imzalayan eklentileri      | [Kaynak](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-signer) |
| @solana/kit-plugin-wallet | Wallet Standard bağlantısı + React hook'ları     | [Kaynak](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-wallet) |

## Solana Web3.js v3

`@solana/web3.js` v3, web3.js'in önerilen sürümüdür. Klasik sınıf tabanlı API'yi (`Connection`, `Keypair`, `Transaction`, `PublicKey`) `@solana/kit` altyapısı üzerinde yeniden oluşturur; bu sayede Kit primitifleri ve yukarıdaki program istemcileriyle birlikte çalışır. Mevcut bir web3.js uygulamasını yükseltiyorsanız veya sınıf tabanlı API'yi tercih ediyorsanız bu sürümü kullanın.

Eski SDK'da senkron olan `Keypair.generate()` ve `transaction.sign()` gibi çoğu metot artık asenkrondur.

```bash
npm install @solana/web3.js@3
```

| Paket         | Açıklama | GitHub                                                        |
| --------------- | ----------- | ------------------------------------------------------------- |
| @solana/web3.js | Temel SDK    | [Kaynak](https://github.com/solana-foundation/solana-web3.js) |

`@solana/spl-token`, `@solana/web3.js` (legacy) paketine bağımlıdır ve v3 üzerinde çalışmaz. Bunun yerine `@solana-program/token` veya `@solana-program/token-2022` kullanın; bunların oluşturulmuş talimatları ve talimat planları v3'ün `Transaction.add()` metodu ile doğrudan çalışır.

- [web3.js v1 → v3 geçiş rehberi](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
- [spl-token geçiş rehberi](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-spl-token-migration.md)

## Solana Web3.js (legacy)

`@solana/web3.js` (legacy, `1.x`), Solana için geliştirilen orijinal TypeScript SDK'sıdır. Bakım modundadır ve yalnızca kritik düzeltmeler alır. Mevcut kod tabanları [web3.js v3'e yükseltebilir](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md) veya [Kit'e geçiş yapabilir](/docs/frontend/web3-compat).
