---
title: "Hızlı Başlangıç: CLI ile token oluşturma"
description:
  Create a token, open a token account, mint supply, and transfer tokens using
  the SPL Token CLI on devnet.
---

Bu hızlı başlangıç kılavuzu, _sh`spl-token`_ CLI ile eksiksiz token yaşam döngüsünü adım adım açıklar. Bir mint oluşturacak, token tutabilecek bir hesap açacak, 100 token basacak ve bir kısmını başka bir cüzdana aktaracaksınız.

Komutları tarayıcınızda çalıştırmak için [Solana Playground](https://beta.solpg.io/)'u kullanın ya da CLI'yi yerel olarak `cargo install spl-token-cli` komutuyla yükleyin. Çıktınızdaki adresler aşağıdaki örneklerden farklı olacaktır.

## 1. Devnet'e bağlanın

Solana Playground'da bir cüzdan oluşturun veya mevcut cüzdanınızı bağlayın, ardından devnet'i seçip hesap yatırımları ve işlem ücretleri için SOL talep edin:

```terminal
$ solana config set --url devnet
$ solana airdrop 2
```

Devnet tokenlarını yalnızca test amacıyla kullanın. Bunların herhangi bir finansal değeri yoktur.

## 2. Token oluşturun

Tokenınızı tanımlayan mint account'u oluşturun:

```terminal
$ spl-token create-token
```

Çıktıdan token adresini kopyalayın. Bu, kalan komutlarda kullanacağınız mint adresidir. Yeni bir mint, sıfır arz ile başlar.

```terminal
$ spl-token supply <MINT_ADDRESS>
```

## 3. Token account oluşturun

Cüzdanınızın bakiye tutabilmesi için bu mint'e ait bir token account'a ihtiyacı vardır:

```terminal
$ spl-token create-account <MINT_ADDRESS>
```

Bu işlem, adresi cüzdanınızdan ve mint'ten türetilen [associated token account](/docs/tokens#associated-token-account)'unuzu oluşturur.

## 4. Token basın

associated token account'unuza 100 token basın:

```terminal
$ spl-token mint <MINT_ADDRESS> 100
$ spl-token balance <MINT_ADDRESS>
```

Bu işlemi mint yetkilisinin imzalaması gerekir. Token basma işlemi hem token account bakiyenizi hem de mint tarafından kaydedilen toplam arzı artırır.

## 5. Token aktarın

Başka bir devnet cüzdanına 10 token gönderin. _sh`--fund-recipient`_ seçeneği, alıcının associated token account'u mevcut değilse oluşturur:

```terminal
$ spl-token transfer <MINT_ADDRESS> 10 <RECIPIENT_WALLET_ADDRESS> --fund-recipient
```

Aktarım işlemi, gönderici ve alıcı token account bakiyelerini değiştirir; mint'in toplam arzını etkilemez.

## İsteğe bağlı: Token-2022 meta verisi ekleme

Yeni bir Token-2022 mint'ine doğrudan ad, sembol ve URI depolamak için mint'i metadata uzantısı etkinleştirilmiş şekilde oluşturun:

```terminal
$ spl-token create-token \
  --program-id TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb \
  --enable-metadata
```

Ardından bu komutun yazdırdığı yeni mint adresini kullanın:

```terminal
$ spl-token initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  "EXAMPLE" \
  "https://example.com/token.json"
```

URI, herkese açık bir JSON meta veri belgesi döndürmelidir. Hesap modeli ve kod örnekleri için [Token-2022 metadata](/docs/tokens/extensions/metadata) sayfasına bakın.
