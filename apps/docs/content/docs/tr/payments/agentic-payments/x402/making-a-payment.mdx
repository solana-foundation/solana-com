Bir x402 V2 API'sini çalıştırmak ve Claude Code'a ödeme farkındalığına sahip bir HTTP istemcisi kazandırmak için [Pay](https://pay.sh) kullanın. API, ödeme yapan cüzdan ve takas işlemlerinin tümü Solana sandbox ortamını kullanır; bu nedenle bu adım adım rehber hesap veya gerçek fon gerektirmez.

Bir terminale, Pay'e ve kurulu Claude Code'a ihtiyacınız var.

## 1. Pay'i Kurun

macOS'ta önceden derlenmiş ikili dosyayı kurun:

```bash
brew install pay
pay --version
```

Diğer platformlarda npm paketini kurun:

```bash
npm install --global @solana/pay
pay --version
```

## 2. Bir x402 sandbox API'si başlatın

`x402-demo.yaml` dosyasını oluşturun:

```yaml filename=x402-demo.yaml
name: x402-demo
subdomain: x402-demo
title: "x402 Demo"
description: "Minimal x402 V2 sandbox endpoint."
category: devtools
version: v1
routing:
  type: respond
operator:
  currencies:
    usd: ["USDC"]
  network: "localnet"
  fee_payer: true
endpoints:
  - method: GET
    path: "report"
    description: "Return a sandbox report."
    metering:
      schemes: [x402-exact]
      dimensions:
        - direction: usage
          unit: requests
          scale: 1
          tiers:
            - price_usd: 0.001
```

API'yi başlatın ve çalışır durumda bırakın:

```bash
pay --sandbox server start x402-demo.yaml --bind 127.0.0.1:1402
```

`x402-exact` şeması, bunu yalnızca x402 destekli bir uç noktaya dönüştürür. Sandbox modu, geçici operatör ve ödeme yapan hesapları otomatik olarak oluşturur ve fonlar.

## 3. Ajanı Pay ile başlatın

Başka bir terminalde Claude Code'u sandbox modunda başlatın:

```bash
pay --sandbox claude
```

Pay, yerel MCP araçlarını ajan oturumuna ekler. Ajan özel anahtar almaz.

## 4. Bir x402 isteği yapın

Bu istemi ajana yapıştırın:

```text
Use Pay to make exactly one sandbox x402 API request to
http://127.0.0.1:1402/report.

Before paying, show me the amount and ask for approval. Then return the API
result and payment receipt. Do not make any other paid requests.
```

İstek, eksiksiz bir x402 V2 ödeme döngüsünü izler:

1. API, `PAYMENT-REQUIRED` meydan okuması (challenge) ile birlikte `402 Payment Required` yanıtını döndürür.
2. Pay, x402 gereksinimlerini doğrular ve ödeme koşullarını görüntüler.
3. Onaydan sonra sandbox cüzdanı imzalar ve Pay isteği `PAYMENT-SIGNATURE` ile yeniden dener.
4. API, sonucu `PAYMENT-RESPONSE` makbuzuyla birlikte döndürür.

Hiçbir gerçek fon hareket etmez. Onayı reddetmek isteği durdurur.

Bir x402 V2 istemcisi ve kaynak sunucusu oluşturmak için [Solana'da x402](/docs/payments/agentic-payments/x402) bölümüyle devam edin ya da [x402 facilitator'ı olun](/docs/tools/x402-facilitator).
