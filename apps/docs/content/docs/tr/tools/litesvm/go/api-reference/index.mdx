## Hızlı Referans

### Handle Kurulumu

```go
import (
    litesvm "github.com/LiteSVM/litesvm-go"
    solana "github.com/gagliardetto/solana-go"
)

svm, err := litesvm.New()
if err != nil {
    // handle error
}
defer svm.Close()
```

### Hesap Yönetimi

| Metot                                                                       | Açıklama                                          |
| ---------------------------------------------------------------------------- | ---------------------------------------------------- |
| `Airdrop(pubkey, lamports) error`                                            | Bir hesabı fonla                                      |
| `Balance(pubkey) (uint64, bool, error)`                                      | SOL bakiyesi; bool hesabın mevcut olup olmadığını bildirir |
| `GetAccount(pubkey) *Account`                                                | Hesap handle'ını al (yoksa nil)          |
| `SetAccount(pubkey, *Account) error`                                         | Hesap durumunu doğrudan kaydet                         |
| `MinimumBalanceForRentExemption(dataLen int) (uint64, error)`                | rent muafiyeti için gereken minimum bakiyeyi hesapla                          |
| `NewAccount(lamports, data, owner, executable, rentEpoch) (*Account, error)` | SetAccount için bir Account handle'ı oluştur               |

### Program Yönetimi

| Metot                                                   | Açıklama                             |
| -------------------------------------------------------- | --------------------------------------- |
| `AddProgram(programID, bytes) error`                     | Programı byte dizisinden yükle                 |
| `AddProgramFromFile(programID, path) error`              | Programı `.so` dosyasından yükle            |
| `AddProgramWithLoader(programID, bytes, loaderID) error` | Belirli bir loader altında yükle (gelişmiş) |

### İşlemler

| Metot                                                                        | Açıklama                                                                     |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| `SendLegacyTransaction(txBytes) (*TxOutcome, error)`                          | Legacy işlem çalıştır                                                    |
| `SendVersionedTransaction(txBytes) (*TxOutcome, error)`                       | v0+ işlem çalıştır                                                       |
| `SimulateLegacyTransaction(txBytes) (*TxOutcome, error)`                      | Durum değişikliği olmadan simüle et                                                  |
| `SimulateVersionedTransaction(txBytes) (*TxOutcome, error)`                   | Durum değişikliği olmadan v0+ simüle et                                              |
| `LatestBlockhash() (solana.Hash, error)`                                      | Güncel blockhash                                                               |
| `ExpireBlockhash() error`                                                     | Yeni bir blockhash'e geç                                                      |
| `GetTransaction(signature) *TxOutcome`                                        | Geçmişte işlemi ara (yoksa nil)                                  |
| `litesvm.BuildTransferTx(payerSeed, to, lamports, blockhash) ([]byte, error)` | `solana-go` bağımlılığı olmadan imzalı legacy transfer oluşturan test yardımcısı |

### Yapılandırma

| Metot                                         | Açıklama                                             |
| ---------------------------------------------- | ------------------------------------------------------- |
| `SetSigverify(bool) error`                     | İmza doğrulamayı etkinleştir / devre dışı bırak                 |
| `Sigverify() (bool, error)`                    | Mevcut ayarı oku                                |
| `SetBlockhashCheck(bool) error`                | Blockhash doğrulamayı etkinleştir / devre dışı bırak                   |
| `SetTransactionHistory(int) error`             | Bellek içi tx geçmişinin kapasitesi (0 devre dışı bırakır)           |
| `SetLogBytesLimit(int) error`                  | İşlem başına log byte sınırı (negatif = sınırsız)              |
| `SetLamports(uint64) error`                    | Yeni airdrop havuzu hesapları için varsayılan lamport değeri          |
| `SetSysvars() error`                           | Sysvar'ları varsayılanlara sıfırla                               |
| `SetBuiltins() error`                          | Yerleşik programları yeniden yükle                                |
| `SetDefaultPrograms() error`                   | SPL Token, Memo vb. yeniden yükle                            |
| `SetPrecompiles() error`                       | ed25519 / secp256k1 ön derlemelerini etkinleştir                  |
| `WithNativeMints() error`                      | Wrapped-SOL mint'i seed ile başlat                                   |
| `SetFeatureSet(*FeatureSet) error`             | Bir özellik kapısı seti kur                              |
| `SetComputeBudget(ComputeBudget) error`        | Hesaplama bütçesi uygula                                  |
| `ComputeBudget() (ComputeBudget, bool, error)` | Mevcut bütçeyi oku (bool "açıkça ayarlandı" bilgisini verir) |

### Zaman ve Sysvar'lar

| Metot                                       | Açıklama                          |
| -------------------------------------------- | ------------------------------------ |
| `WarpToSlot(slot uint64) error`              | Belirli bir slot'a atla              |
| `Clock() (Clock, error)`                     | Clock sysvar'ını oku                |
| `SetClock(Clock) error`                      | Clock sysvar'ının üzerine yaz           |
| `Rent() (Rent, error)`                       | Rent sysvar'ını oku                 |
| `SetRent(Rent) error`                        | Rent sysvar'ının üzerine yaz            |
| `EpochSchedule() (EpochSchedule, error)`     | EpochSchedule sysvar'ını oku        |
| `SetEpochSchedule(EpochSchedule) error`      | EpochSchedule sysvar'ının üzerine yaz   |
| `EpochRewards() (EpochRewards, error)`       | EpochRewards sysvar'ını oku         |
| `SetEpochRewards(EpochRewards) error`        | EpochRewards sysvar'ının üzerine yaz    |
| `LastRestartSlot() (uint64, error)`          | Son yeniden başlatma slot'unu oku               |
| `SetLastRestartSlot(uint64) error`           | Son yeniden başlatma slot'unu ayarla                |
| `SlotHashes() ([]SlotHash, error)`           | SlotHashes sysvar'ını oku           |
| `SetSlotHashes([]SlotHash) error`            | SlotHashes sysvar'ının üzerine yaz      |
| `SlotHistory() (*SlotHistory, error)`        | SlotHistory sysvar'ını oku (handle) |
| `SetSlotHistory(*SlotHistory) error`         | SlotHistory sysvar'ının üzerine yaz     |
| `StakeHistory() ([]StakeHistoryItem, error)` | StakeHistory sysvar'ını oku         |
| `SetStakeHistory([]StakeHistoryItem) error`  | StakeHistory sysvar'ının üzerine yaz    |
