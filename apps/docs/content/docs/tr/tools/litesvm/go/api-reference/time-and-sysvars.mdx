Zamanı manipüle etmek ve sistem değişkenlerine erişmek için yöntemler. Her sysvar
alıcısının eşleşen bir ayarlayıcısı vardır; struct'lar Solana
kaynağının sade Go yansımalarıdır.

## Saat Manipülasyonu

### WarpToSlot

```go
func (s *LiteSVM) WarpToSlot(slot uint64) error
```

İç saati belirli bir slot'a ilerlet.

```go
before, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("current slot: %d", before.Slot)

if err := svm.WarpToSlot(10_000_000); err != nil {
    t.Fatal(err)
}

after, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("new slot:     %d", after.Slot)
```

### Clock

```go
type Clock struct {
    Slot                uint64
    EpochStartTimestamp int64
    Epoch               uint64
    LeaderScheduleEpoch uint64
    UnixTimestamp       int64
}

func (s *LiteSVM) Clock() (Clock, error)
```

Clock sysvar'ını oku.

```go
c, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("slot=%d epoch=%d unix=%d", c.Slot, c.Epoch, c.UnixTimestamp)
```

### SetClock

```go
func (s *LiteSVM) SetClock(c Clock) error
```

Clock sysvar'ının üzerine yaz. `WarpToSlot`'un güncellemediği `Epoch` veya
`UnixTimestamp` üzerinde kontrol sahibi olmanız gerektiğinde okuyun,
alanları değiştirin ve geri yazın.

```go
c, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
c.Slot = 1_000
c.Epoch = 10
c.UnixTimestamp = 1_735_689_600
if err := svm.SetClock(c); err != nil {
    t.Fatal(err)
}
```

<Callout type="info">
  `WarpToSlot` yalnızca `Slot`'u günceller. Programınız Clock sysvar'ından
  `Epoch` veya `UnixTimestamp` okuyorsa `SetClock` kullanın.
</Callout>

## Epoch Rewards

```go
type EpochRewards struct {
    DistributionStartingBlockHeight uint64
    NumPartitions                   uint64
    ParentBlockhash                 solana.Hash
    TotalPointsLo                   uint64 // low 64 bits of the u128 total_points
    TotalPointsHi                   uint64 // high 64 bits
    TotalRewards                    uint64
    DistributedRewards              uint64
    Active                          bool
}

func (s *LiteSVM) EpochRewards() (EpochRewards, error)
func (s *LiteSVM) SetEpochRewards(e EpochRewards) error
```

`total_points`, Solana tarafında bir `u128`'dir; `litesvm-go` her iki yarıyı da
açıkça ortaya çıkarır, böylece Go çağırıcıları bir u128 kütüphanesine ihtiyaç duymaz.
64 bite sığan değerler için `TotalPointsHi` `0`, `TotalPointsLo` ise değerin kendisidir.

### SlotHistory

`SlotHistory` yaklaşık 128 KB'lık bir bitvec'tir; `litesvm-go` bunu bir dilim
yerine bir tanıtıcı olarak sunar.

```go
sh, err := litesvm.NewSlotHistory()
if err != nil {
    t.Fatal(err)
}
defer sh.Close()

sh.Add(42)

switch sh.Check(42) {
case litesvm.SlotHistoryFound:
    // ...
case litesvm.SlotHistoryNotFound:
    // ...
case litesvm.SlotHistoryTooOld:
    // ...
case litesvm.SlotHistoryFuture:
    // ...
}

if err := svm.SetSlotHistory(sh); err != nil {
    t.Fatal(err)
}
```

| Yöntem                                           | Açıklama                                |
| ------------------------------------------------ | ------------------------------------------ |
| `litesvm.NewSlotHistory() (*SlotHistory, error)` | Boş tanıtıcı                               |
| `sh.Add(slot uint64)`                            | Bir slot kaydet                              |
| `sh.Check(slot uint64) SlotHistoryCheck`         | `Future` / `TooOld` / `Found` / `NotFound` |
| `sh.Oldest() uint64`                             | İzlenen en eski slot                        |
| `sh.Newest() uint64`                             | İzlenen en yeni slot                        |
| `sh.NextSlot() uint64`                           | Kaydedilecek sonraki slot                        |
| `sh.SetNextSlot(slot uint64) error`              | Sonraki slot işaretçisini geçersiz kıl              |
| `sh.Close()`                                     | Tanıtıcıyı serbest bırak                         |
| `svm.SlotHistory() (*SlotHistory, error)`        | Yeni bir tanıtıcıya oku                   |
| `svm.SetSlotHistory(*SlotHistory) error`         | SVM'ye yükle                         |

## Zamana Bağlı Mantığı Test Etme

Sade slot tabanlı ilerleme için `WarpToSlot`, tam kontrol için `SetClock` kullanın:

```go
func TestTimeLockedVault(t *testing.T) {
    svm, err := litesvm.New()
    if err != nil {
        t.Fatal(err)
    }
    defer svm.Close()

    const unlockSlot = uint64(10_000)

    // Setup: create the time-locked account ...

    // Test 1: Try to withdraw before unlock (should fail)
    before, err := svm.Clock()
    if err != nil {
        t.Fatal(err)
    }
    t.Logf("current slot: %d", before.Slot)
    // ... attempt withdrawal, expect failure ...

    // Warp time forward past unlock slot
    if err := svm.WarpToSlot(unlockSlot + 1); err != nil {
        t.Fatal(err)
    }

    // Test 2: Try to withdraw after unlock (should succeed)
    after, err := svm.Clock()
    if err != nil {
        t.Fatal(err)
    }
    t.Logf("new slot: %d", after.Slot)
    // ... attempt withdrawal, expect success ...
}
```
