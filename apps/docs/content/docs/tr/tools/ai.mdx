# Solana'da LLM'ler ve Ajanslarla Çalışmak

Belirli araçlara geçmeden önce, yapay zeka
geliştirme yığınındaki temel bileşenleri anlayalım:

## Yapay Zeka Yığınını Anlamak

1. **Büyük Dil Modelleri (LLM'ler)**
   - Temel yapay zeka modelleri (GPT-4, Claude veya Llama gibi)
   - Doğal dili işler ve üretir
   - Ham zeka ve akıl yürütme yetenekleri sağlar
   - Örnekler: OpenAI'nin GPT-4'ü, Anthropic'in Claude'u, Meta'nın Llama'sı

2. **Ajan Çerçeveleri (Eliza gibi)**
   - Otonom ajanlar oluşturmak için LLM'lerin üzerine inşa edilmiştir
   - Ajan kişiliklerini ve davranışlarını yönetir
   - Bellek ve bağlamı yönetir
   - Çok platformlu entegrasyon sağlar
   - Örnekler: Eliza, LangChain, AutoGPT, Vercel AI

3. **Alana Özgü Ajan Kitleri (Solana Agent Kit gibi)**
   - Belirli kullanım durumları için oluşturulmuştur (ör. blockchain işlemleri)
   - Önceden hazırlanmış araçlar ve entegrasyonlar sağlar
   - Teknik karmaşıklığı soyutlar
   - Kullanıma hazır blockchain fonksiyonları
   - Örnekler: Solana Agent Kit, GOAT Toolkit

Şöyle düşünün:

- LLM'ler, dili anlayabilen ve üretebilen "beyin"dir
- Ajan çerçeveleri, yapay zekanın davranışını yöneten "işletim sistemi"dir
- Alana özgü kitler ise yapay zekaya belirli yetenekler kazandıran "uygulamalar"dır

# Solana için Yapay Zeka Ajanları Oluşturma

Bu kılavuz size şunları gösterecek:

- SendAI'nin Solana Agent Kit'ini kullanarak temel bir yapay zeka ajanı oluşturun
- Eliza Framework ile bir Twitter botu oluşturun

- Gelişmiş alım satım botları oluşturma seçenekleri

## Solana'da Yapay Zeka Ajanlarına Giriş

Solana'daki yapay zeka ajanları, doğal dil işleme ve makine öğrenimi kullanarak
blockchain ile etkileşime girebilen otonom programlardır. Şunları yapabilirler:

- İşlem gerçekleştirme
- Blockchain etkinliğini izleme
- Akıllı sözleşmelerle etkileşim kurma
- Kullanıcı yardımı sağlama
- Karmaşık iş akışlarını otomatikleştirme

## Mevcut Çerçeveler

Solana'da yapay zeka ajanları oluşturmak için birkaç çerçeve mevcuttur:

1. **SendAI'nin Solana Agent Kit'i**

- Solana üzerinde ajanlar oluşturmak için araç koleksiyonu
- Eliza, Langchain ve Vercel AI SDK ile uyumlu
- Yerleşik Solana araçları ve yardımcı programları
- Doğal dil işleme yetenekleri
- [Solana Agent Kit](https://github.com/sendaifun/solana-agent-kit)
- [Dokümantasyon](https://docs.solanaagentkit.xyz/)

2. **Eliza Framework**

- Veri katmanı, LLM ve ajanları birleştirir ve özel bir Solana eklentisine sahiptir
- Genişletilebilir ajan mimarisi
- Mevcut projelerle kolay entegrasyon; örneğin Twitter (X), Telegram veya
  Discord botları için kullanılabilir
- [GitHub Deposu](https://github.com/elizaOS/eliza)

3. **GOAT Toolkit**

- Kapsamlı geliştirme araç seti
- Zincirler arası uyumluluk
- [GitHub Deposu](https://github.com/goat-sdk/goat)

4. **Rig Framework**

- Yerel Rust uygulaması
- Yüksek performanslı alım satım botları için idealdir
- Solana entegrasyonu, işlem izleme ve örneğin Jito paketleri kullanarak
  işlem gönderimi için Listen.rs araç setiyle birleştirilebilir
- [GitHub Deposu](https://github.com/0xPlaygrounds/rig)
- [Listen.rs Deposu](https://github.com/piotrostr/listen)

Bir yapay zeka çerçevesi geliştiriyorsanız, çerçevenizi listeye eklemek için bir PR açmaktan çekinmeyin

### Ajan scriptini oluşturun

Aşağıdaki içerikle `agent.ts` adında yeni bir dosya oluşturun:

```typescript filename=agent.ts
import { SolanaAgentKit, createSolanaTools } from "solana-agent-kit";
import { HumanMessage } from "@langchain/core/messages";
import { ChatOpenAI } from "@langchain/openai";
import { createReactAgent } from "@langchain/langgraph/prebuilt";
import { MemorySaver } from "@langchain/langgraph";
import * as dotenv from "dotenv";
import bs58 from "bs58";
import * as readline from "readline";

dotenv.config();

async function initializeAgent() {
  const llm = new ChatOpenAI({
    modelName: "gpt-4-turbo-preview",
    temperature: 0.7
  });

  // Convert array string to actual array, then to Uint8Array, then to base58
  const privateKeyArray = JSON.parse(process.env.SOLANA_PRIVATE_KEY!);
  const privateKeyUint8 = new Uint8Array(privateKeyArray);
  const privateKeyBase58 = bs58.encode(privateKeyUint8);

  const solanaKit = new SolanaAgentKit(privateKeyBase58, process.env.RPC_URL!, {
    OPENAI_API_KEY: process.env.OPENAI_API_KEY!
  });

  const tools = createSolanaTools(solanaKit);
  const memory = new MemorySaver();

  return createReactAgent({
    llm,
    tools,
    checkpointSaver: memory
  });
}

async function runInteractiveChat() {
  const agent = await initializeAgent();
  const config = { configurable: { thread_id: "Solana Agent Kit!" } };
  const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout
  });

  // Clear console and start chat with a small delay
  setTimeout(() => {
    console.clear(); // Clear any initialization messages
    console.log("Chat with Solana Agent (type 'exit' to quit)");
    console.log("--------------------------------------------");
    askQuestion();
  }, 100);

  const askQuestion = () => {
    rl.question("You: ", async (input) => {
      if (input.toLowerCase() === "exit") {
        rl.close();
        return;
      }

      const stream = await agent.stream(
        {
          messages: [new HumanMessage(input)]
        },
        config
      );

      process.stdout.write("Agent: ");
      for await (const chunk of stream) {
        if ("agent" in chunk) {
          process.stdout.write(chunk.agent.messages[0].content);
        } else if ("tools" in chunk) {
          process.stdout.write(chunk.tools.messages[0].content);
        }
      }
      console.log("\n--------------------------------------------");

      askQuestion(); // Continue the conversation
    });
  };
}

runInteractiveChat().catch(console.error);
```

</Step>

## Eliza Framework ile Geliştirme

[ElizaOS](https://github.com/elizaOS/eliza) (eski adıyla Ai16z), bir
yapay zeka çerçevesidir. Yani birden fazla uygulamayı tek çatı altında birleştirir ve
bunların etkileşimlerini düzenler. Şunları bir araya getirir:

1. Kullanıcıyı anlamak için farklı LLM'ler
2. Farklı eylemlerle blockchain ajanları (örneğin NFT mint etme gibi)
3. Karakterlerin durumunu eylemler arasında saklamak için örneğin
   Redis, PostgreSQL DB veya yerel depolama kullanan veri katmanları
4. X, Telegram, Discord gibi farklı istemciler vb.

Tüm bunları, kullanıcılarla etkileşime girebilen veya otonom hareket edebilen bir
"Karakter" oluşturmanıza olanak tanıyacak şekilde bir araya getirir. Bu Karakterler,
hangi eylemleri gerçekleştirebileceğini, hangi LLM'yi kullanması gerektiğini ve
karekterin davranışını tanımlayan çeşitli istemleri belirleyen bir JSON dosyasında tanımlanır.

## Zincir üstü program ajan entegrasyonu

Bir ajanın yanıtını bir Solana programı içinde kullanmak istiyorsanız, yanıt verilerini programınızın okuyabileceği bir hesaba yazan bir
oracle kullanmanız gerekir.
Soruları doğru cevaplayan herhangi bir kullanıcıya token transfer edecek bir LLM örneğini burada bulabilirsiniz:

[Zincir üstü program LLM etkileşimi](https://github.com/GabrielePicco/super-smart-contracts)

Bu, interaktif bir token dağıtım ajanı olan "Mar1o" adlı ajan oluşturmak için bir LLM (AI) oracle'ı ile entegre olan zincir üstü bir program örneğidir.

### Temel Özellikler

1. **AI Ajan Etkileşimi**
   - Kullanıcılar token kazanmak için Mar1o ile sohbet edebilir
   - Ajan, token miktarına karar vermek için kullanıcının Solana bilgisini değerlendirir
   - Yanıtlar, yanıt metni ve token miktarı içeren JSON formatındadır

2. **Token Yönetimi**
   - Meta verilerle birlikte MAR1O token'ları oluşturur
   - AI yanıtına göre 0-10.000 arasında token basabilir
   - Token yönetimi için PDA'ları kullanır

### Program akışı açıklandı

Bu programın nasıl çalıştığı aşağıda açıklanmaktadır:

```rust
// Initialize the AI agent with personality
const AGENT_DESC: &str = "You are an AI agent called Mar1o which can dispense MAR1O tokens...";

// User interaction flow:
// 1. User sends message to agent
// 2. Oracle processes with LLM
// 3. Agent responds with JSON containing reply and amount
// 4. If amount > 0, tokens are minted to user

// Example response:
{
    "reply": "Great answer! Here's a reward.",
    "amount": 1000
}
```

Bu, interaktif blok zinciri deneyimleri oluşturmak için AI yeteneklerinin zincir üstü token mekanikleriyle nasıl birleştirileceğini göstermektedir. Ajanı token transfer etmesi için ikna etmeyi deneyebileceğiniz
[canlı bir örnek](https://mar1o.xyz/) burada mevcuttur.

## Algoritmik ticaret için gelişmiş Rust ajanları

Ajanlarınızı Rust ile yazmak istiyorsanız
[Rig framework](https://github.com/0xPlaygrounds/rig)'ünü ve
[Listen.rs](https://github.com/piotrostr/listen) kütüphanesini kullanabilirsiniz.

Bu ikisi birlikte güzel çalışır. Rig framework LLM'lere bağlanmak için kolay bir yol sunarken, Listen.rs araç seti; işlem izleme ve örneğin Jito bundle'ları kullanarak işlem gönderme gibi özellikler dahil olmak üzere Solana entegrasyonunu sağlar.

## En İyi Uygulamalar

- Ajanınızın bir özel anahtara sahip olduğunu ve dolayısıyla cüzdanınızdaki fonlara erişebildiğini bilin. Birisi ajanınızla sohbet edebiliyorsa ve ajanın örneğin bir transfer eylemi varsa, kullanıcılar büyük olasılıkla fonlarınızı kendilerine transfer ettirmesini sağlayabilir.
- Ücretli [RPC uç noktaları](https://solana.com/rpc) kullanın. Genel uç noktalar
  genellikle hız sınırlamasına tabi tutulur
- Ajan aktivitelerini izleyin ve kötü amaçlı bir şey yapmadıklarından veya kullanıcıların etkileşimleriyle buna kandırılmadıklarından emin olun
- Ajan eylemlerinize öncelik ücretleri ve işlem yeniden denemeleri ekleyin; böylece ağda yoğunluk olduğunda da işlemler gerçekleşebilsin
- Mümkünse mainnet'e dağıtmadan önce devnet üzerinde test edin. Çoğu ajan, RPC url'sini girdi olarak alır ve mainnet'e hazır olana kadar devnet url'si kullanabilirsiniz. Ancak tüm eylemler devnet'te mümkün olmayabilir.
- Kendi eylemlerinizi yazarken bunlar için entegrasyon testleri ekleyin; böylece framework'ler, değişen programlar veya API'ler nedeniyle hangi eylemlerin başarısız olduğunu takip edebilsin

## Sonuç

Solana üzerindeki AI ajanları, blok zinciriyle otomasyon ve etkileşim için yeni olanaklar sunmaktadır. Tüm entegrasyonlar henüz mükemmel olmasa da hızla gelişmekte, katkı için bol fırsat sunmakta ve kendi entegrasyonlarınızı eklemek açısından son derece esnektir.
