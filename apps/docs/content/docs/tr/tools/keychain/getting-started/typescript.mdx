## Kurulum

Şemsiye paketi veya gerektiğinde bireysel imzalayıcıları kurun:

```shell
# Umbrella package (includes all signers)
pnpm add @solana/keychain

# Or install individual packages
pnpm add @solana/keychain-core        # Core interfaces (required for custom signers)
pnpm add @solana/keychain-memory      # Local keypair signer
pnpm add @solana/keychain-vault       # HashiCorp Vault
pnpm add @solana/keychain-aws-kms     # AWS KMS
pnpm add @solana/keychain-gcp-kms     # GCP KMS
pnpm add @solana/keychain-privy       # Privy
pnpm add @solana/keychain-turnkey     # Turnkey
pnpm add @solana/keychain-fireblocks  # Fireblocks
pnpm add @solana/keychain-cdp         # Coinbase Developer Platform
pnpm add @solana/keychain-crossmint   # Crossmint
pnpm add @solana/keychain-dfns        # Dfns
pnpm add @solana/keychain-openfort    # Openfort
pnpm add @solana/keychain-para        # Para
pnpm add @solana/keychain-utila       # Utila
pnpm add @solana/keychain-fordefi     # Fordefi

# Kit client plugins (keychainSigner / keychainPayer / keychainIdentity)
pnpm add @solana/keychain-kit-plugin
```

`@solana/kit` 8.1 veya üzeri gerekir. v1 işlemleri
(`createTransactionMessage({ version: 1 })`) desteklenir; yalnızca `useProgramCall: true` ile Fireblocks bunun dışındadır ve yalnızca legacy ile v0 işlemleri kabul eder.

## Temel Kullanım

### Birleşik Fabrika (Birden fazla imzalayıcıyı desteklemek isteyen uygulamalar için önerilir)

Herhangi bir arka uç oluşturmak için ayrımlaştırılmış yapılandırmayla
`createKeychainSigner` kullanın:

```typescript
import { createKeychainSigner } from "@solana/keychain";
import { signTransactionWithSigners } from "@solana/signers"; // requires @solana/signers >= 8.1

const signer = await createKeychainSigner({
  backend: "privy",
  appId: "your-app-id",
  appSecret: "your-app-secret",
  walletId: "your-wallet-id"
});

// Sign an already-compiled transaction
const signedTx = await signTransactionWithSigners(
  [signer],
  compiledTransaction
);
```

Veya daha küçük bir bağımlılık ayak izi için bireysel bir imzalayıcı paketi
kurun:

```typescript
import { createPrivySigner } from "@solana/keychain-privy";

const signer = await createPrivySigner({
  appId: "your-app-id",
  appSecret: "your-app-secret",
  walletId: "your-wallet-id"
});
```

### İşlem Mesajlarıyla Kullanımı

Crossmint ve Fordefi native modu dışındaki her backend, bir Kit `TransactionPartialSigner` olan ve aşağıdaki `@solana/signers` kısmi imzalayıcı (partial-signer) yardımcılarıyla çalışan bir `SolanaTransactionSigner` döndürür. Yönetilen yayın (managed-broadcast) yapan backend'ler [İmzalayıcı Yetenekleri](#signer-capabilities) bölümünde ele alınmıştır.

```typescript
import type { SolanaTransactionSigner } from "@solana/keychain-core";
import { signTransactionMessageWithSigners } from "@solana/signers";
import {
  createTransactionMessage,
  setTransactionMessageFeePayerSigner,
  pipe
} from "@solana/kit";

async function signWithKeychain(signer: SolanaTransactionSigner) {
  // Check availability (useful for remote signers)
  if (!(await signer.isAvailable())) {
    throw new Error("Signer offline");
  }

  // Use with @solana/kit transaction builder
  const transaction = pipe(
    createTransactionMessage({ version: 0 }),
    (tx) => setTransactionMessageFeePayerSigner(signer, tx)
    // ... set a lifetime and add instructions
  );

  // Sign with the standard signers API
  const signedTx = await signTransactionMessageWithSigners(transaction);
  return signedTx;
}
```

### Herhangi Bir İmzalayıcıyla İmzalama ve Gönderme

`@solana/keychain-core` içindeki `signAndSendTransaction`, imzalayıcının türü ne olursa olsun bir işlemi zincire ulaştırır. Gönderen (sending) imzalayıcılar işlemi kendi sağlayıcıları üzerinden yayınlar; diğer tüm türler sizin ilettiğiniz `sendTransaction` işlevini kullanır (core paketinin RPC bağımlılığı yoktur):

```typescript
import { signAndSendTransaction } from "@solana/keychain-core";

const signature = await signAndSendTransaction(signer, transaction, {
  sendTransaction: (tx) =>
    sendAndConfirmTransaction(tx, { commitment: "confirmed" })
});
```

### Kit İstemcisiyle Kullanım (keychainSigner eklentisi)

`@solana/keychain-kit-plugin`, bir keychain imzalayıcıyı doğrudan bir
[Kit istemcisine](https://github.com/anza-xyz/kit) yükler ve onu `payer` ile
`identity` olarak bağlayarak yukarıda gösterilen manuel `pipe` kurulumunu
atlamanızı sağlar:

```typescript
import { createClient } from "@solana/kit";
import { keychainSigner } from "@solana/keychain-kit-plugin";

const client = await createClient().use(
  keychainSigner({
    backend: "privy",
    appId: process.env.PRIVY_APP_ID!,
    appSecret: process.env.PRIVY_APP_SECRET!,
    walletId: process.env.PRIVY_WALLET_ID!
  })
);

client.payer; // SolanaTransactionSigner, also a Kit TransactionPartialSigner
client.identity; // same signer instance
```

Eklenti, Crossmint ve Fordefi native modu (`chain` ayarlı) dışında, `createKeychainSigner` ile aynı backend etiketli yapılandırmayı kabul eder. Bu backend'ler işlemi sunucu tarafında yeniden yazdığından istemci `payer` veya `identity` olarak görev yapamaz; eklenti bunları hem derleme zamanında hem de çalışma zamanında reddeder. Yalnızca yönlendirildiği backend pakete dahil edilir (backend paketleri dinamik `import()` ile yüklenir).

Yalnızca tek bir rol ayarlamak ve tek bir istemcide birden fazla arka ucu
birleştirmek için `keychainPayer` veya `keychainIdentity` kullanın:

```typescript
import { createClient } from "@solana/kit";
import { keychainIdentity, keychainPayer } from "@solana/keychain-kit-plugin";

const client = await createClient()
  .use(
    keychainPayer({
      backend: "memory",
      privateKeyPath: `${process.env.HOME}/.config/solana/id.json`
    })
  )
  .use(keychainIdentity({ backend: "turnkey", ...turnkeyConfig }));
```

Zaten bir `SolanaTransactionSigner` nesneniz mi var? Bu geçerli bir Kit `TransactionPartialSigner` olduğundan, bunun yerine [`@solana/kit-plugin-signer`](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-signer) ile kurabilirsiniz (`pnpm add @solana/kit-plugin-signer`):

```typescript
import { createClient } from "@solana/kit";
import { signer } from "@solana/kit-plugin-signer";
import { createKeychainSigner } from "@solana/keychain";

const mySigner = await createKeychainSigner({
  backend: "vault",
  ...vaultConfig
});
const client = createClient().use(signer(mySigner));
```

### İptal ve Onaylanmamış Yayınlar

`signTransactions`, `modifyAndSignTransactions`, `signAndSendTransactions` ve `signMessages` işlevlerinin tümü ikinci bağımsız değişken olarak `{ abortSignal }` kabul eder. İptal etmek beklemeyi durdurur; sağlayıcının kabul ettiği işi geri almaz.

Crossmint ve Fordefi native auto modunda bir hata, hiçbir şeyin zincire ulaşmadığı anlamına gelmez. Sağlayıcı işlemi kabul etmiş olabilirse hata kodu `SignerErrorCode.BROADCAST_UNCONFIRMED` (`"SIGNER_BROADCAST_UNCONFIRMED"`) olur. Oluşturma isteği kabul edildiğinde `context.providerTransactionId` ayarlanır; `context.idempotencyKey` ise mesajdan türetilen anahtarı taşır. Bayt düzeyinde aynı işlemi yeniden göndermek güvenlidir; yeniden oluşturulmuş bir işlem (örneğin yeni bir blockhash ile) yeni bir transfer sayılır. `@solana/keychain-core` içindeki `providerMayHaveAccepted(error)` ve `providerStatus(error)` hatayı sınıflandırmaya yardımcı olur. Yeniden denemeden önce sağlayıcıyla mutabakat sağlayın.

### Fordefi

Fordefi'nin, oluşturma sırasında `chain` ve `pushMode` ile belirlenen üç imzalama modu vardır. Her mod tam olarak bir işlem yöntemi sunar ve üçü de mesajları imzalar:

| Mod          | Yapılandırma                                      | Tür                        | Yöntem                        |
| ------------- | ------------------------------------------- | --------------------------- | ----------------------------- |
| Kara kutu     | `chain` ayarsız                               | `FordefiBlackBoxSigner`     | `signTransactions()`          |
| Native auto   | `chain` ayarlı, `pushMode` belirtilmemiş veya `"auto"` | `FordefiNativeSigner`       | `signAndSendTransactions()`   |
| Native manual | `chain` ayarlı, `pushMode: "manual"`           | `FordefiNativeManualSigner` | `modifyAndSignTransactions()` |

API istekleri ECDSA P-256 istek imzasıyla doğrulanır: imzalama anahtarını `privateKeyPem` olarak sağlayın veya bir `requestSigner` ileterek anahtarı KMS/HSM içinde tutun.

**Native auto modu** (zincir üzeri kullanım için önerilir): `chain` ayarlayın; Fordefi işlemi kendisi imzalar ve yayınlar. Fordefi imzalamadan önce blockhash'i veya ücretleri değiştirebileceğinden, imzalayıcı bir Kit `TransactionSendingSigner` olur: yukarıda gösterilen kısmi imzalayıcı akışını değil, `signAndSendTransactionMessageWithSigners` ile kullanın. Native auto modu yalnızca gerekli tek imzalayıcısı vault olan imzasız bir işlemi kabul eder ve `@solana/keychain-kit-plugin` ile kullanılamaz.

```typescript
import { createFordefiSigner } from "@solana/keychain-fordefi";
import { signAndSendTransactionMessageWithSigners } from "@solana/signers";
import { readFileSync } from "node:fs";

const signer = await createFordefiSigner({
  accessToken: process.env.FORDEFI_ACCESS_TOKEN!,
  vaultId: process.env.FORDEFI_VAULT_ID!,
  publicKey: process.env.FORDEFI_PUBLIC_KEY!, // Solana vault address (base58)
  privateKeyPem: readFileSync("./secret/private.pem", "utf8"),
  chain: "solana_devnet", // or "solana_mainnet"
  fee: { type: "custom", priority_fee: "1000" } // optional
});

const signature =
  await signAndSendTransactionMessageWithSigners(transactionMessage);
```

**Native manual modu**: `chain` ve `pushMode: "manual"` ayarlayın. Fordefi mesajı yeniden yazar (güncel blockhash, Compute Budget ücret talimatları) ve imzalar, ancak yayınlamaz. `modifyAndSignTransactions()`, Fordefi'nin imzaladığı işlemi döndürür; bu işlem sizin gönderdiğinizin yerini alır: her zaman döndürülen işlemle devam edin. Fordefi ücret ödeyen (fee payer) olmalı ve gerekli diğer imzalayıcılardan önce imzalamalıdır. Yeniden yazım için fark (diff) üretilmez, bu yüzden yayınlamadan önce sonucu inceleyin.

```typescript
import { createFordefiSigner } from "@solana/keychain-fordefi";
import { readFileSync } from "node:fs";

const signer = await createFordefiSigner({
  accessToken: process.env.FORDEFI_ACCESS_TOKEN!,
  vaultId: process.env.FORDEFI_VAULT_ID!,
  publicKey: process.env.FORDEFI_PUBLIC_KEY!,
  privateKeyPem: readFileSync("./secret/private.pem", "utf8"),
  chain: "solana_devnet",
  pushMode: "manual"
});

const [signedTransaction] = await signer.modifyAndSignTransactions([
  transaction
]);
```

**Kara kutu modu**: `chain` parametresini atlayın. Fordefi ham baytları imzalar ve yayınlamaz; işlemi kendiniz oluşturup gönderirsiniz. Bunu bir Fordefi kara kutu kasasıyla kullanın.

```typescript
import { createFordefiSigner } from "@solana/keychain-fordefi";
import { readFileSync } from "node:fs";

const signer = await createFordefiSigner({
  accessToken: process.env.FORDEFI_ACCESS_TOKEN!,
  vaultId: process.env.FORDEFI_BB_VAULT_ID!,
  publicKey: process.env.FORDEFI_BB_PUBLIC_KEY!,
  privateKeyPem: readFileSync("./secret/private.pem", "utf8")
});
```

## İmzalayıcı Yetenekleri

`@solana/keychain-core`, her Kit imzalayıcı türü için bir arayüz tanımlar. Her biri, eşleşen `@solana/signers` arayüzüne `isAvailable(): Promise<boolean>` ekler:

- `SolanaTransactionSigner` (Kit `TransactionPartialSigner`): sahibi olduğunuz bir işlem için imzalar döndürür.
- `SolanaModifyingSigner` (Kit `TransactionModifyingSigner`): işlemi yeniden yazar, imzalar ve yayınlamadan yeni işlemi döndürür.
- `SolanaSendingSigner` (Kit `TransactionSendingSigner`): sağlayıcısı üzerinden imzalar ve yayınlar.
- `SolanaMessageSigner` (Kit `MessagePartialSigner`): zincir dışı mesajları imzalar. Bu, işlem türlerinden ayrıdır.

`SolanaSigner`, üç işlem türünün birleşimidir (union). Her fabrika işlevinin dönüş türü, ilgili backend'in tam türünü belirtir. Yapılandırma yalnızca çalışma zamanında biliniyorsa `isSolanaTransactionSigner`, `isSolanaModifyingSigner`, `isSolanaSendingSigner` veya `isSolanaMessageSigner` ile daraltın. `signerCapabilities(signer)` dördünü birden bildirir.

| Backend                                                                                                     | Tür                                           |
| ----------------------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| memory, vault, aws-kms, gcp-kms, privy, turnkey, fireblocks, cdp, dfns, para, openfort, fordefi (kara kutu) | `SolanaTransactionSigner & SolanaMessageSigner` |
| utila                                                                                                       | `SolanaTransactionSigner` (mesaj imzalama yok)  |
| fordefi (native manual)                                                                                     | `SolanaModifyingSigner & SolanaMessageSigner`   |
| fordefi (native auto)                                                                                       | `SolanaSendingSigner & SolanaMessageSigner`     |
| crossmint                                                                                                   | `SolanaSendingSigner` (mesaj imzalama yok)      |

```typescript
import {
  isSolanaSendingSigner,
  isSolanaTransactionSigner
} from "@solana/keychain-core";

if (isSolanaSendingSigner(signer)) {
  await signer.signAndSendTransactions([transaction]);
} else if (isSolanaTransactionSigner(signer)) {
  await signer.signTransactions([transaction]);
}
```

## Özel İmzalayıcılar Oluşturma

Backend'inizin desteklediği yetenek arayüzlerini uygulayın:

```typescript
import type {
  SolanaMessageSigner,
  SolanaTransactionSigner
} from "@solana/keychain-core";
import type { Address } from "@solana/addresses";
import type {
  MessagePartialSignerConfig,
  SignableMessage,
  TransactionPartialSignerConfig
} from "@solana/signers";
import type { Transaction } from "@solana/transactions";

class MyCustomSigner implements SolanaTransactionSigner, SolanaMessageSigner {
  constructor(readonly address: Address) {}

  async isAvailable(): Promise<boolean> {
    return await myBackend.healthCheck();
  }

  async signMessages(
    messages: readonly SignableMessage[],
    config?: MessagePartialSignerConfig
  ) {
    return await myBackend.signMessages(messages, config?.abortSignal);
  }

  async signTransactions(
    transactions: readonly Transaction[],
    config?: TransactionPartialSignerConfig
  ) {
    return await myBackend.signTransactions(transactions, config?.abortSignal);
  }
}
```

Yalnızca backend'inizin desteklediklerini uygulayın. Kit, imzalayıcıları hangi yöntemlere sahip olduklarına göre sınıflandırır; bu yüzden yalnızca hata fırlatan bir yöntemi asla eklemeyin.

Ek anahtar yönetimi hizmetlerini entegre etmek için
[İmzalayıcı Ekleme rehberine](/docs/tools/keychain/adding-signers) bakın.
