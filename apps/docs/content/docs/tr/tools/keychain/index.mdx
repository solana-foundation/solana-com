**Solana Keychain, birden fazla anahtar yönetimi arka ucu üzerinden Solana işlemlerini imzalamak için birleşik bir arayüz sunar.** Yerelde bellek içi bir anahtarla geliştirin, ardından imzalama kodunuzu yeniden yazmadan üretimde kurumsal anahtar yönetimine, bulut HSM'lerine veya yönetilen cüzdan hizmetlerine geçin.

### Neden Keychain?

- **Tek Arayüz**: Tüm arka uçlarda tek bir `SolanaSigner` temel arayüzü ve her arka uç için bir yetenek: imzalama, yeniden yazıp imzalama veya imzalayıp yayınlama
- **Arka Uçları Değiştirin**: Anahtar yönetimi sağlayıcılarını yapılandırma üzerinden değiştirin; çağrı noktaları yalnızca yeni arka ucun farklı bir yeteneği olduğunda değişir (Crossmint ve Fordefi yerel modları)
- **Yalnızca kullandığınız kadar ödeyin**: Rust özellik bayrakları, arka uç başına npm paketleri, Python ek paketleri (extras) ve arka uç başına Go modülleri yalnızca ihtiyacınız olan arka uçları içerir
- **Denetlenmiş**: Rust, TypeScript, Python ve Go, [OtterSec](https://osec.io) tarafından denetlenmiştir (isteğe bağlı Ledger arka ucu kapsam dışındaydı); daha önceki bir [Accretion](https://accretion.xyz) denetimi Rust ve TypeScript'i kapsıyordu.
  Bkz.
  [denetim durumu](https://github.com/solana-foundation/solana-keychain/blob/main/audits/AUDIT_STATUS.md).

### Mimari

- **Diller**: Rust, TypeScript, Python ve Go, eşit düzeyde (Ledger arka ucu yalnızca Rust'ta bulunur)
- **Arayüz**: `SolanaSigner` temeli (`pubkey`, `sign_message`, `is_available`) ve her arka uç için tam olarak bir yetenek: `TransactionSigner`, `ModifyingSigner` veya `SendingSigner`
- **Arka Uçlar**: Memory, Vault, AWS KMS, GCP KMS, Privy, Turnkey, Fireblocks, CDP, Crossmint, Dfns, Openfort, Para, Utila, Fordefi, Ledger (yalnızca Rust, isteğe bağlı, denetlenmemiş)
- **Uyumluluk**: `@solana/kit` ve `@solana/signers` 8.1+ (TypeScript) | `sdk-v2` / `sdk-v3` / `sdk-v4` özellikleri üzerinden `solana-sdk` 2.x, 3.x veya 4.x (Rust; v1 işlemleri için `sdk-v4` gerekir) | `solders` (Python) | `solana-go` v2 (Go)

### Desteklenen Altyapılar

Arka uçlar yerel geliştirme, kendi kendine barındırılan ve bulut tabanlı anahtar
yönetimi ile yönetilen veya MPC cüzdan hizmetlerini kapsamaktadır. Velayet
modellerini karşılaştırmak ve en uygun olanı seçmek için
[Arka uç seçimi](/docs/tools/keychain/choosing-a-backend) sayfasına bakın.

## Hızlı Başlangıç

### Rust

Rust crate'ini yükleyin:

```bash
cargo add solana-keychain
```

Temel kullanım:

```rust
use solana_keychain::{Signer, SolanaSigner};

// Create a signer from any backend
let signer = Signer::from_memory("base58_private_key")?;
let pubkey = signer.pubkey();

// Transaction signing is a capability; `tx` is a VersionedTransaction
if let Some(tx_signer) = signer.as_transaction_signer() {
    let result = tx_signer.sign_transaction(&mut tx).await?;
}

// Or let the umbrella route any backend shape and supply the RPC hop yourself
let signature = signer
    .sign_and_send(&mut tx, |encoded| async move { broadcast(encoded).await })
    .await?;
```

- [Rust Kılavuzu](/docs/tools/keychain/getting-started/rust) - Tam kurulum ve
  arka uç yapılandırması
- [Crates.io](https://crates.io/crates/solana-keychain) - Rust crate

### TypeScript

TypeScript paketini yükleyin:

```bash
pnpm add @solana/keychain
```

Temel kullanım:

```typescript
import { createKeychainSigner } from "@solana/keychain";
import { signTransactionWithSigners } from "@solana/signers";

// Create any signer via the unified factory
const signer = await createKeychainSigner({
  backend: "vault",
  vaultAddr: "https://vault.example.com:8200",
  vaultToken: "hvs.xxxxx",
  keyName: "my-solana-key",
  publicKey: "base58_public_key"
});

// Sign an already-compiled transaction
const signedTx = await signTransactionWithSigners(
  [signer],
  compiledTransaction
);
```

- [TypeScript Kılavuzu](/docs/tools/keychain/getting-started/typescript) -
  `@solana/keychain` paketleri
- [npm Paketi](https://www.npmjs.com/package/@solana/keychain) - npm paketi

Bir Keychain imzalayıcısını bir [Kit](https://github.com/anza-xyz/kit) istemcisine `payer` veya `identity` olarak kurmak için `@solana/keychain-kit-plugin` kullanın (Crossmint ve Fordefi yerel modları, işlemleri yeniden yazdıkları için hariç tutulmuştur).

### Python

Paketi yükleyin (daha ağır arka uçlar ek paket (extras) olarak sunulur, örneğin `solana-keychain[aws-kms]`):

```bash
pip install solana-keychain
```

Temel kullanım:

```python
import os

from solana_keychain import VaultSignerConfig, create_vault_signer

signer = await create_vault_signer(
    VaultSignerConfig(
        api_base_url="https://vault.example.com:8200",
        token=os.environ["VAULT_TOKEN"],
        key_name="my-solana-key",
        public_key="base58_public_key",
    )
)

# tx is a solders VersionedTransaction
result = await signer.sign_transaction(tx)
```

- [Python Kılavuzu](/docs/tools/keychain/getting-started/python) - Tam kurulum, ek paketler (extras) ve arka uç yapılandırması
- [PyPI](https://pypi.org/project/solana-keychain/) - Python paketi

### Go

Her arka uç kendi Go modülüdür, bu nedenle yalnızca içe aktardığınız arka uçları çekersiniz:

```bash
go get github.com/solana-foundation/solana-keychain/go/signers/vault/v2@latest
```

Temel kullanım:

```go
import "github.com/solana-foundation/solana-keychain/go/signers/vault/v2"

signer, err := vault.New(vault.Config{
	VaultAddr: "https://vault.example.com:8200",
	Token:     os.Getenv("VAULT_TOKEN"),
	KeyName:   "my-solana-key",
	Pubkey:    "base58_public_key",
})
if err != nil {
	return err
}

// tx is a *solana.Transaction from solana-go v2
res, err := signer.SignTransaction(ctx, tx)
```

- [Go Kılavuzu](/docs/tools/keychain/getting-started/go) - Modüller, yetenekler ve arka uç yapılandırması
- [pkg.go.dev](https://pkg.go.dev/github.com/solana-foundation/solana-keychain/go/core/v2) - Go referansı
