## Ön Koşullar

- Rust 1.91+
- Solana CLI 3.1.13 (Agave):
  `sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.13/install)"`
- Node.js 24.7.0+
- pnpm 10.15.1+: `npm install -g pnpm@10.15.1`

## Depoyu Klonlayın

```bash
git clone https://github.com/solana-foundation/solana-private-channels.git
cd solana-private-channels
```

## TypeScript İstemcilerini Oluşturun

TypeScript istemcileri npm'de yayımlanmamaktadır. Codama kullanılarak
IDL'den oluşturulmaları gerekmektedir.

```bash
# Escrow program client
cd private-channel-escrow-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..

# Withdraw program client
cd private-channel-withdraw-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..
```

Oluşturulan istemciler şu konuma yerleştirilir:

- `private-channel-escrow-program/clients/typescript/src/generated/`
- `private-channel-withdraw-program/clients/typescript/src/generated/`

Bu yerel yollardan uygulamanıza içe aktarın; npm'de
`@private-channels/client` paketi bulunmamaktadır. Bu bölümdeki kod örnekleri,
kodunuzun klonlanan depoyla aynı dizinde bulunduğunu varsayan göreli bir yol
(`../private-channel-escrow-program/...`) kullanmaktadır; kendi projenizde
gerçekte içe aktardığınız konuma göre ayarlayın.
