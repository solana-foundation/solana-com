---
title: AddOperator
description: Operator PDA'sını oluşturarak yeni bir operatör sağlar
---

Yeni bir operatörü `Operator` PDA'sını oluşturarak sağlar. Bu çağrının ardından
`operator` cüzdanı `ReleaseFunds` ve `ResetSmtRoot` fonksiyonlarını çağırabilir.

## Hesaplar

| Hesap                          | Yazılabilir | İmzalayan | Açıklama                                                         |
| -------------------------------- | -------- | ------ | ------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Ücret ödeyen                                                           |
| `admin`                          |          | ✓      | Instance yöneticisi                                                      |
| `instance`                       |          |        | Instance PDA                                                        |
| `operator`                       |          |        | Sağlanacak operatör cüzdanı                                        |
| `operator_pda`                   | ✓        |        | Operator PDA - `["operator", instance, operator]` ifadesinden otomatik türetilir |
| `system_program`                 |          |        | System Program                                                      |
| `event_authority`                |          |        | Etkinlik yetkisi PDA                                                 |
| `private_channel_escrow_program` |          |        | Escrow Programı                                                      |

## Parametreler

| Parametre | Tür | Açıklama                                                                               |
| --------- | ---- | ----------------------------------------------------------------------------------------- |
| `bump`    | `u8` | `operator_pda` için bump seed. İsteğe bağlı: `Async` istemcisi belirtilmezse otomatik türetir |

> IDL, otomatik olarak ayarlanan bir `discriminator: u8` argümanı (değer `3`) içerir
> ve oluşturulan istemci tarafından otomatik ayarlanır; manuel olarak geçirilmemelidir.

## Önemli Notlar

- `getAddOperatorInstructionAsync` kullanın; `bump` ve `operator_pda` sağlanmadığında
  bunları otomatik olarak türetir. Eğer `bump` değerini kendiniz hesapladıysanız
  eşzamanlı `getAddOperatorInstruction` varyantı da mevcuttur
- Bu çağrının ardından `operator` cüzdanı `ReleaseFunds` ve
  `ResetSmtRoot` fonksiyonlarını çağırabilir
- `EmitEvent` CPI aracılığıyla bir etkinlik yayar
