---
title: CreateInstance
description: Private Channels escrow'unu sabitleyen Instance PDA'sını oluşturur
---

Escrow'u sabitleyen `Instance` PDA'sını oluşturur. Diğer tüm işlemlerden önce
çağrılmalıdır.

## PDA seed'leri

```
instance        -> ["instance", instance_seed: Pubkey]
allowed_mint    -> ["allowed_mint", instance_pda: Pubkey, mint: Pubkey]
operator        -> ["operator", instance_pda: Pubkey, operator: Pubkey]
event_authority -> ["event_authority"]
```

## Hesaplar

| Hesap                          | Yazılabilir | İmzalayan | Açıklama                                                                 |
| -------------------------------- | -------- | ------ | --------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Ücret ödeyici ve rent ödeyici                                                    |
| `admin`                          |          | ✓      | Instance'ın ilk yöneticisi                                               |
| `instance_seed`                  |          | ✓      | Yalnızca PDA türetimi için kullanılan tek seferlik keypair; pubkey'i seed olur |
| `instance`                       | ✓        |        | Instance PDA (`["instance", instance_seed.pubkey]`'den türetilir)            |
| `system_program`                 |          |        | System Program                                                              |
| `event_authority`                |          |        | Olay yetkisi PDA'sı                                                         |
| `private_channel_escrow_program` |          |        | Escrow Programı                                                              |

## Parametreler

| Parametre | Tür | Açıklama                                                                             |
| --------- | ---- | --------------------------------------------------------------------------------------- |
| `bump`    | `u8` | Instance PDA'sı için bump seed. İsteğe bağlı: belirtilmezse `Async` istemcisi otomatik olarak türetir |

> IDL, otomatik olarak ayarlanan bir `discriminator: u8` bağımsız değişkeni (değer `0`) içerir
> ve oluşturulan istemci tarafından otomatik olarak atanır; manuel olarak geçirilmemelidir.

## Önemli Notlar

- `instance_seed`, yalnızca `Instance` PDA'sını türetmek için kullanılan tek seferlik bir keypair'dır.
  pubkey'i seed olur; keypair'ın kendisi saklanmaz veya yeniden kullanılmaz.
- `getCreateInstanceInstructionAsync` kullanın; `instance_seed` sağlanmadığında `bump` ve `instance`'ı
  otomatik olarak türetir. Kendi `bump` değerinizi yalnızca
  `Pubkey::find_program_address(&[b"instance", instance_seed_pubkey.as_ref()], &PROGRAM_ID)` aracılığıyla
  önceden hesapladıysanız geçirin
- `EmitEvent` CPI aracılığıyla bir olay yayar
