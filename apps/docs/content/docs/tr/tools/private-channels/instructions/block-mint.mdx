Daha önce izin verilmiş bir mint'i örnekten kaldırır ve o mint için yeni
yatırmaları engeller. Mevcut yatırmalar etkilenmez.

## Hesaplar

| Hesap                          | Yazılabilir | İmzalayan | Açıklama                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | Ücret ödeyici                                    |
| `admin`                          |          | ✓      | Örnek yöneticisi                               |
| `instance`                       |          |        | Örnek PDA                                 |
| `mint`                           |          |        | Engellenecek SPL token mint'i                      |
| `allowed_mint`                   | ✓        |        | AllowedMint PDA (bu talimat tarafından kapatılır) |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | Olay yetkisi PDA                          |
| `private_channel_escrow_program` |          |        | Emanet Programı                               |

Bu talimat herhangi bir parametre almaz.

## Önemli Notlar

- `allowed_mint` PDA'sını kapatır: bu mint için yeni `Deposit` çağrıları
  `InvalidAllowedMint` hatasıyla başarısız olur
- Bu mint için mevcut kanal bakiyeleri etkilenmez
- `EmitEvent` CPI aracılığıyla bir olay yayar
