  Private Channels Escrow ve Withdraw programları için zincir üstü talimat referansı

Bu bölüm, zincir üstü talimat referansıdır. Geliştiricilerin çoğu bu talimatları oluşturulan TypeScript istemcileri aracılığıyla çağırır; buna yalnızca operatör araçları geliştiriyorsanız, özel entegrasyonlar yazıyorsanız veya talimat düzeyindeki hataları ayıklıyorsanız ihtiyaç duyarsınız.

**Escrow Programı** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) - yatırımları, operatör sağlamayı ve Mainnet uzlaşmasını yönetir:

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) -
  escrow instance PDA'sını başlatır
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) - bir
  SPL token mint'ini beyaz listeye ekler
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) - bir
  mint'i izin listesinden kaldırır
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) -
  bir operatör sağlar
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) -
  bir operatörün yetkisini iptal eder
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) -
  yönetici haklarını devreder
- [Deposit](/docs/tools/private-channels/instructions/deposit) - SPL tokenları
  escrow'a taşır
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) -
  operatör bir çekimi Mainnet'e uzlaştırır
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) -
  operatör Sparse Merkle Tree'yi döndürür

**Withdraw Programı** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) - özel kanal ağında çalışır:

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) -
  bir çekimi başlatmak için kanal tarafındaki bakiyeyi yakar

## Hata Kodları

**Escrow Programı - `PrivateChannelEscrowProgramError`**

| Kod                                         | Mesaj                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | Geçersiz olay yetkisi sağlandı                 |
| `InvalidAta`                                 | Geçersiz ATA sağlandı                             |
| `InvalidMint`                                | Geçersiz mint sağlandı                            |
| `InvalidInstanceId`                          | Instance ID geçersiz veya kurallara uymuyor    |
| `InvalidInstance`                            | Geçersiz instance sağlandı                        |
| `InvalidAdmin`                               | Geçersiz yönetici sağlandı                           |
| `TransferHookNotAllowed`                     | Transfer hook uzantısına izin verilmiyor              |
| `InvalidOperatorPda`                         | Geçersiz operatör PDA'sı sağlandı                    |
| `InvalidTokenAccount`                        | Geçersiz token account sağlandı                   |
| `InvalidEscrowBalance`                       | Geçersiz escrow bakiyesi                           |
| `InvalidAllowedMint`                         | Geçersiz izinli mint                             |
| `InvalidSmtProof`                            | Geçersiz SMT kanıtı sağlandı                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | Mevcut ağaç indeksi için geçersiz işlem nonce'u |
| `UnexpectedTreeIndex`                        | SMT kök sıfırlama için beklenmeyen mevcut ağaç indeksi |

**Withdraw Programı - `PrivateChannelWithdrawProgramError`**

| Kod          | Mesaj                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | Geçersiz mint sağlandı                       |
| `ZeroAmount`  | Çekim miktarı sıfırdan büyük olmalıdır |
