Yönetici haklarını yeni bir cüzdana aktarır.

## Hesaplar

| Hesap                          | Yazılabilir | İmzalayan | Açıklama                        |
| -------------------------------- | -------- | ------ | ---------------------------------- |
| `payer`                          | ✓        | ✓      | Ücret ödeyici                          |
| `current_admin`                  |          | ✓      | Mevcut yönetici (imzalaması gerekir)          |
| `instance`                       | ✓        |        | Instance PDA (yönetici alanı güncellendi) |
| `new_admin`                      |          | ✓      | Yönetici haklarını alacak cüzdan     |
| `event_authority`                |          |        | Etkinlik yetkisi PDA                |
| `private_channel_escrow_program` |          |        | Escrow Programı                     |

Bu talimat herhangi bir parametre almaz.

## Önemli Notlar

- **Tek adımda geri alınamaz**: mevcut yönetici, yeni yönetici `SetNewAdmin` komutunu tekrar çağırmadan rolü geri alamaz
- Çağrı yapmadan önce hedef adresi doğrulayın; geri alma işlemi mümkün değildir
- `EmitEvent` CPI aracılığıyla bir etkinlik yayar
