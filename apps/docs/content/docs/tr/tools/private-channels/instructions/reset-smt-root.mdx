---
title: SMT Kökünü Sıfırla
description:
  Seyrek Merkle Ağacını döndürerek yeni bir ağaç epoch'u için çekilme kökünü sıfırlar
---

Yalnızca operatöre ait talimat; `Instance.current_tree_index` değerini artırarak
Seyrek Merkle Ağacını döndürür ve çekilme kökünü sıfırlar, böylece 65.536 çekilmelik
yeni bir epoch'a olanak tanır.

<Callout type="info">
  Emanet programı bu Seyrek Merkle Ağacı tasarımından zincir üstü bir nonce bitmap'ine
  (upstream'de takip edilmektedir) geçiş yapmaktadır; bu durumda talimat
  `RotateBitmap` adını alacaktır. Bu sayfa mevcut emanet programını doğru şekilde
  yansıtmaktadır ve söz konusu değişiklik uygulandığında güncellenecektir.
</Callout>

## Hesaplar

| Hesap                          | Yazılabilir | İmzalayan | Açıklama                                            |
| -------------------------------- | -------- | ------ | ------------------------------------------------------ |
| `payer`                          | ✓        | ✓      | Ücret ödeyici                                              |
| `operator`                       |          | ✓      | Operatör imzalayıcı                                        |
| `instance`                       | ✓        |        | Emanet instance PDA'sı (`current_tree_index` artırıldı) |
| `operator_pda`                   |          |        | İmzalayanın sağlandığını kanıtlayan Operatör PDA'sı         |
| `event_authority`                |          |        | `EmitEvent` CPI için olay yetkilisi PDA'sı                |
| `private_channel_escrow_program` |          |        | Emanet Programı (CPI için öz-referans)                |

## Parametreler

| Parametre                     | Tür  | Açıklama                                                              |
| ----------------------------- | ----- | ------------------------------------------------------------------------ |
| `expected_current_tree_index` | `u64` | Tekrar oynatma koruması; `Instance.current_tree_index` ile eşleşmesi gerekir, aksi takdirde çağrı başarısız olur |

## Dönüş Değeri

İşlemi oluşturmak ve göndermek için kullanılabilecek bir `TransactionBuilder` döndürür.

## Örnek

```typescript
import { getResetSmtRootInstruction } from "../private-channel-escrow-program/clients/typescript/src/generated";

const resetIx = getResetSmtRootInstruction({
  payer: operatorPayerSigner,
  operator: operatorSigner,
  instance: instancePda,
  operatorPda: operatorPdaAddress,
  eventAuthority: eventAuthorityPda,
  privateChannelEscrowProgram: ESCROW_PROGRAM_ID,
  expectedCurrentTreeIndex: currentTreeIndex // u64
});
```

## Önemli Notlar

- Yalnızca operatör: geçerli bir `operator_pda` gerektirir; aksi takdirde `InvalidOperatorPda` hatası fırlatır
- `expected_current_tree_index`, çağrı anında `Instance.current_tree_index` ile eşit olmalıdır; eski bir değer `UnexpectedTreeIndex` hatasını fırlatır ve halihazırda gerçekleşmiş bir sıfırlamanın tekrar oynatılmasına karşı koruma sağlar
- `Instance.current_tree_index` değerini artırır; önceki ağaç epoch'unda geçerli olan nonce'lar döndürme işleminin ardından geçersiz hale gelir
- `operator-private-channel` servisi, `transaction_nonce % 65536 == 0` (ve `nonce > 0`) koşulu sağlandığında bunu otomatik olarak çağırır; bu durum yeni bir epoch'un başladığına işaret eder ve normal işlem koşullarında manuel olarak çağrılmasına gerek yoktur
- Döndürme işleminin ardından çekilme kökü boş ağaca sıfırlanır; böylece yeni çekilmeler temiz bir SMT üzerinden başlar
- `EmitEvent` CPI aracılığıyla bir olay yayımlar
