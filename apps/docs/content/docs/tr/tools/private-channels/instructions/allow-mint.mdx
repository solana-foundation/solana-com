  Örnekte bir SPL token mint'ine izin verir ve o mint için escrow ATA'sını oluşturur

Örnekte bir SPL token mint'ine izin verir ve o mint için escrow'un associated
token account'ını oluşturur. Bu çağrının ardından söz konusu mint için
yatırma işlemleri mümkün hale gelir.

## Hesaplar

| Hesap                          | Yazılabilir | İmzalayan | Açıklama                                                                   |
| -------------------------------- | -------- | ------ | ----------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Ücret ödeyen                                                                     |
| `admin`                          |          | ✓      | Örnek yöneticisi                                                                |
| `instance`                       |          |        | Örnek PDA                                                                  |
| `mint`                           |          |        | İzin verilecek SPL token mint'i                                                       |
| `allowed_mint`                   | ✓        |        | AllowedMint PDA (bu talimat tarafından oluşturulur)                                 |
| `instance_ata`                   | ✓        |        | Bu mint için escrow'un associated token account'ı (bu talimat tarafından oluşturulur) |
| `system_program`                 |          |        | System Program                                                                |
| `token_program`                  |          |        | SPL Token Program                                                             |
| `associated_token_program`       |          |        | Associated Token Program                                                      |
| `event_authority`                |          |        | Etkinlik yetkilisi PDA                                                           |
| `private_channel_escrow_program` |          |        | Escrow Programı                                                                |

## Parametreler

| Parametre | Tür | Açıklama                                                                                   |
| --------- | ---- | --------------------------------------------------------------------------------------------- |
| `bump`    | `u8` | `allowed_mint` PDA için bump seed. İsteğe bağlı: `Async` istemcisi belirtilmezse otomatik olarak türetir |

> IDL, otomatik olarak ayarlanan bir `discriminator: u8` argümanı (değer `1`) içerir
> ve oluşturulan istemci tarafından otomatik ayarlanır; manuel olarak iletilmemelidir.

## Önemli Notlar

- `getAllowMintInstructionAsync` kullanın; `bump`, `allowed_mint` ve `instance_ata` sağlanmadığında bunları otomatik olarak türetir. Kendi `bump` değerinizi yalnızca
  `Pubkey::find_program_address(&[b"allowed_mint", instance_pda, mint], &PROGRAM_ID)` aracılığıyla
  önceden hesapladıysanız iletin
- Bu mint için escrow'un ATA'sı olan `instance_ata`'yı da oluşturur
- Transfer hook uzantısına sahip mint'ler açıkça engellenir: böyle bir mint'e izin vermeye çalışmak `TransferHookNotAllowed` hatası fırlatır
- `EmitEvent` CPI aracılığıyla bir etkinlik yayar
