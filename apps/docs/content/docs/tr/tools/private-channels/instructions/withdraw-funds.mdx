---
title: Para Çekme
description:
  Solana mainnet escrow'una geri çekim başlatmak için kanal tarafındaki token'ları yakar
---

Bekleyen bir çekimi bildirmek amacıyla Withdraw Program üzerinde kullanıcının kanal tarafındaki token bakiyesini yakar; ardından bir operatörün uzlaşmayı tamamlamak için Escrow Program üzerinde `ReleaseFunds` fonksiyonunu çağırması gerekir.

## Hesaplar

| Hesap                    | Yazılabilir | İmzalayan | Açıklama                                |
| -------------------------- | -------- | ------ | ------------------------------------------ |
| `user`                     |          | ✓      | Çekimi başlatan token sahibi      |
| `mint`                     | ✓        |        | SPL token mint'i (yakma hedefi)            |
| `token_account`            | ✓        |        | Kullanıcının kanal tarafındaki token account'u (kaynak) |
| `token_program`            |          |        | SPL Token Program                          |
| `associated_token_program` |          |        | Associated Token Program                   |

## Parametreler

| Parametre     | Tür             | Açıklama                                                          |
| ------------- | ---------------- | -------------------------------------------------------------------- |
| `amount`      | `u64`            | Çekilecek token miktarı, token'ın en küçük birimi cinsinden           |
| `destination` | `Option<Pubkey>` | Mainnet'teki hedef cüzdan; `None` ise varsayılan olarak imzalayanın cüzdanı kullanılır |

## Dönüş Değeri

İşlemi oluşturmak ve göndermek için kullanılabilecek bir `TransactionBuilder` döndürür.

## Örnek

```typescript
import { getWithdrawFundsInstruction } from "../private-channel-withdraw-program/clients/typescript/src/generated";

const withdrawIx = getWithdrawFundsInstruction({
  user: userSigner,
  mint: mintAddress,
  tokenAccount: channelTokenAccount,
  tokenProgram: TOKEN_PROGRAM_ID,
  associatedTokenProgram: ASSOCIATED_TOKEN_PROGRAM_ID,
  amount: 1_000_000n,
  destination: null // null = release to signer's Mainnet wallet
});
```

## Önemli Notlar

- Bu talimat, Escrow Program'da değil, **Withdraw Program**'da (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi` devnet) yer almaktadır
- Kanal tarafında token yakmak, Mainnet'teki fonları **otomatik olarak** serbest bırakmaz; bir operatörün geçerli bir SMT hariç tutma kanıtıyla birlikte Escrow Program üzerinde `ReleaseFunds` fonksiyonunu çağırması gerekir
- `amount` 0 ise `ZeroAmount` hatası fırlatılır
- `destination` değeri `None` ise operatörün `ReleaseFunds` çağrısı fonları imzalayanın cüzdanına serbest bırakır

Her iki program için tam hata kodu referansı için bkz.
[Talimatlar -> Hata Kodları](/docs/tools/private-channels/instructions#error-codes).
