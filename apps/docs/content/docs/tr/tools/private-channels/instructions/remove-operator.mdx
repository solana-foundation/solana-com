---
title: RemoveOperator
description: Operatör PDA'sını kapatarak bir operatörün yetkisini iptal eder
---

Bir operatörün `Operator` PDA'sını kapatarak yetkisini iptal eder. Yetkisi iptal edilen cüzdan artık `ReleaseFunds` veya `ResetSmtRoot` fonksiyonlarını çağıramaz.

## Hesaplar

| Hesap                          | Yazılabilir | İmzacı | Açıklama                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | Ücret ödeyici                                 |
| `admin`                          |          | ✓      | Örnek yöneticisi                            |
| `instance`                       |          |        | Örnek PDA                              |
| `operator`                       |          |        | Yetkisi iptal edilecek operatör cüzdanı                 |
| `operator_pda`                   | ✓        |        | Operatör PDA'sı (bu talimat tarafından kapatılır) |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | Etkinlik yetki PDA'sı                       |
| `private_channel_escrow_program` |          |        | Emanet Programı                            |

Bu talimat herhangi bir parametre almaz.

## Önemli Notlar

- `operator_pda`'yı kapatır; yetkisi iptal edilen cüzdan artık
  `ReleaseFunds` veya `ResetSmtRoot` fonksiyonlarını çağıramaz
- Bu çağrıdan sonra, işlemde olan operatör işlemleri `InvalidOperatorPda` hatasıyla
  başarısız olacaktır
- `EmitEvent` CPI aracılığıyla bir etkinlik yayınlar
