---
title: RemoveOperator
description: Operatör PDA'sını kapatarak bir operatörün yetkisini iptal eder
---

Operatörün `Operator` PDA'sını kapatarak yetkisini iptal eder. Yetkisi iptal edilen cüzdan artık `ReleaseFunds` veya `ResetSmtRoot` çağrısı yapamaz.

## Hesaplar

| Hesap                          | Yazılabilir | İmzalayan | Açıklama                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | Ücret ödeyici                                 |
| `admin`                          |          | ✓      | Örnek yöneticisi                            |
| `instance`                       |          |        | Örnek PDA                              |
| `operator`                       |          |        | Yetkisi iptal edilecek operatör cüzdanı                 |
| `operator_pda`                   | ✓        |        | Operatör PDA'sı (bu talimat tarafından kapatılır) |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | Etkinlik yetkisi PDA                       |
| `private_channel_escrow_program` |          |        | Emanet Programı                            |

Bu talimat herhangi bir parametre almaz.

## Önemli Notlar

- `operator_pda`'yı kapatır; yetkisi iptal edilen cüzdan artık
  `ReleaseFunds` veya `ResetSmtRoot` çağrısı yapamaz
- Bu çağrının ardından işlem hâlindeki operatör işlemleri `InvalidOperatorPda` hatasıyla başarısız olur
- `EmitEvent` CPI aracılığıyla bir olay yayar
