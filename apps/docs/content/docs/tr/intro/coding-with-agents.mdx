## Solana MCP Kullanımı

Solana geliştirme için yapay zekadan yararlanmanın en güçlü yolu,
[Solana Developer MCP](https://mcp.solana.com/) (Model Context Protocol) aracılığıyladır. Bu
entegrasyon, uzmanlaşmış Solana bilgisini doğrudan IDE'nize taşıyarak
ajanlarınıza güncel Solana belgelerine erişim sağlar ve geliştirme sürecini
daha hızlı ve verimli hale getirir.

## Solana MCP Nedir?

Solana MCP, Cursor ve Windsurf gibi yapay zeka destekli IDE'lere doğrudan
entegre olan uzmanlaşmış bir yapay zeka asistanıdır. Solana'ya özgü sorular
sorduğunuzda, doğru ve güncel bilgiler sunmak için MCP sunucusunu otomatik
olarak sorgular:

- [Solana belgeleri](/docs)
- [Anchor Framework belgeleri](https://www.anchor-lang.com/docs)
- Solana
  [Program Örnekleri](https://github.com/solana-developers/program-examples)
- [Solana Stack Exchange](https://solana.stackexchange.com/) soru ve
  cevapları

## Örnek kullanım senaryoları

MCP'yi şunlar için kullanabilirsiniz:

- Solana kavramları hakkında soru sorma
- Program hatalarını ayıklama
- En iyi uygulama önerileri alma
- Uzman örneklerinden öğrenme
- Bir uzmanın yardımıyla daha hızlı geliştirme yapma

## Solana MCP Kurulumu

Ayrıntılı kurulum ve başlangıç kılavuzunu
[Solana MCP web sitesinde](https://mcp.solana.com/) bulabilirsiniz.

## Bir beceri kullanmayı mı tercih edersiniz?

Bir beceri kullanmayı tercih ediyorsanız, resmi Solana becerisini şununla yükleyin:

```bash
npx skills add https://github.com/solana-foundation/solana-dev-skill
```

[Solana Agent Skills kütüphanesinde](/skills) daha fazla yeniden kullanılabilir iş akışına göz atın.
