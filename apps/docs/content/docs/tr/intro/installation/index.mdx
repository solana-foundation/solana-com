Otomatik yükleyici ile yerel bir Solana geliştirme ortamı kurun. macOS, Linux veya WSL üzerinden Windows'ta Rust, Solana CLI, Anchor CLI, Surfpool CLI, Node.js ve Yarn'ı yükler.

<Callout type="info" title="Windows için WSL gereklidir">
  Windows PowerShell'de `wsl --install` komutunu çalıştırın, istenirse Windows'u yeniden başlatın, ardından aşağıdaki kurulum komutlarını Ubuntu terminalinde çalıştırın. WSL kurulumunun tamamı için [manuel kurulum kılavuzuna](/docs/intro/installation/dependencies) bakın.
</Callout>

## Hızlı kurulum

1. Yükleyiciyi macOS, Linux veya WSL terminalinde çalıştırın:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
```

Yükleyiciyi çalıştırmadan önce [kaynak kodunu inceleyebilirsiniz](https://github.com/solana-developers/solana-install/blob/main/install.sh). Yükleyici, desteklenen Linux paket yöneticilerini algılar ve sistem bağımlılıklarını otomatik olarak yükler.

2. Yeni komutların `PATH` değişkeninizde kullanılabilir olması için terminalinizi yeniden başlatın.

3. Tüm araçları doğrulayın:

```terminal
$ rustc --version
$ solana --version
$ anchor --version
$ surfpool --version
$ node --version
$ yarn --version
```

Başarılı bir kurulum, şu biçimde bir çıktı döndürür (sürüm numaraları, araçların yeni sürümleri yayımlandıkça değişir):

```txt title="Example output"
Installed Versions:
Rust: rustc x.y.z (...)
Solana CLI: solana-cli x.y.z (..., client:Agave)
Anchor CLI: anchor-cli x.y.z
Surfpool CLI: surfpool x.y.z
Node.js: vx.y.z
Yarn: x.y.z
```

<Callout type="warn" title="Yükleyici başarısız oldu veya bir komut bulunamıyor">
  Her bir bağımlılığı ayrı ayrı yüklemek veya sorunlarını gidermek için [manuel kurulum kılavuzunu](/docs/intro/installation/dependencies) izleyin.
</Callout>
