`CreateDvp`, bir işlemin koşullarını kaydeder ve tarafların fonlayacağı iki emanet
hesabını oluşturur. Hiçbir token taşımaz. Herkes gönderebilir; dolayısıyla kayıt
bir karşı taraftan, takas yetkilisinin operatöründen ya da üçüncü bir taraftan
gelebilir ve diğer tüm katılımcılar, saklanan koşullara göre hareket etmeden önce
bunları doğrular (bkz. [bacakları fonlama](/docs/defi/dvp-program/fund-the-legs)).

Kod parçacıkları, ilgili hesapların ve imzalayanların görünür olması için
yer tutucu adreslerle birlikte doğrudan üretilmiş istemciyi kullanır. Programın
mainnet-beta ile aynı adreste dağıtıldığı devnet'i hedefler.

## Kurulum

2 Ekim 2026 itibarıyla DvP istemcileri için yayımlanmış bir paket yoktur. İkisi de
depodaki programın IDL'inden üretilir ve kaynaktan kullanılır.

Bu sayfalar, TypeScript'te `@solana/kit` 8 ve Rust'ta `solana-*` 2.x crate'leri
ile `df9919e` commit'ine göre yazılmıştır.

Her adım sayfasındaki kod parçacıkları birbirinin devamıdır: her sayfa, önceki
sayfalarda tanımlanan istemciyi, imzalayanları ve adresleri kullanır. `payerSigner`,
`userASigner`, `userBSigner` ve `authoritySigner`, sırasıyla rent'i ödeyen hesap,
iki taraf ve takas yetkilisi için `TransactionSigner` nesneleridir; örneğin
`createKeyPairSignerFromBytes` ile elde edilebilirler. Rust kod parçacıkları
talimatları oluşturur; imzalama ve göndermeyi çağıran tarafa bırakır.

## Adresleri türetme

İşlem kaydı; takas yetkilisi, iki taraf, iki mint ve bir nonce üzerinden türetilen
bir program-derived address'tir. Her emanet hesabı, kaydın mint'lerden biri için
associated token account'udur. Her iki türetme de ağ erişimi gerektirmez.

Her işlem için rastgele bir 64 bit nonce kullanın. Oluşturma izin gerektirmediği
için tahmin edilebilir bir nonce, üçüncü bir tarafın işlemin kullanacağı adresi
işgal etmesine yol açabilir. TypeScript'te nonce'u ve tutarları `bigint` olarak
geçirin; üretilen istemci `number` değerini reddeder.

Çalıştırmadan önce her `..._HERE` yer tutucusunu gerçek bir adresle değiştirin.
`address()` base58'i doğrular ve yer tutucuda hata fırlatır; `pubkey!` ise
derlenmez.

<Tabs items={["TypeScript", "Rust"]}>
  <Tab value="TypeScript">
    ```ts
    import { address, createClient } from "@solana/kit";
    import { solanaRpc } from "@solana/kit-plugin-rpc";
    import { signer } from "@solana/kit-plugin-signer";
    import { TOKEN_2022_PROGRAM_ADDRESS } from "@solana-program/token-2022";
    import { findSwapDvpEscrowAta, findSwapDvpPda } from "./dvp";

    const client = createClient()
      .use(signer(payerSigner))
      .use(
        solanaRpc({
          rpcUrl: "https://api.devnet.solana.com",
          rpcSubscriptionsUrl: "wss://api.devnet.solana.com",
        }),
      );

    const settlementAuthority = address("SETTLEMENT_AUTHORITY_ADDRESS_HERE");
    const userA = address("ASSET_LEG_PARTY_ADDRESS_HERE");
    const userB = address("CASH_LEG_PARTY_ADDRESS_HERE");
    const mintA = address("ASSET_MINT_ADDRESS_HERE");
    const mintB = address("CASH_MINT_ADDRESS_HERE");
    const tokenProgramA = TOKEN_2022_PROGRAM_ADDRESS;
    const tokenProgramB = TOKEN_2022_PROGRAM_ADDRESS;

    // A fresh random nonce per trade, as a bigint.
    const nonce = new DataView(
      crypto.getRandomValues(new Uint8Array(8)).buffer,
    ).getBigUint64(0);

    const [swapDvp] = await findSwapDvpPda({
      settlementAuthority,
      userA,
      userB,
      mintA,
      mintB,
      nonce,
    });
    const [escrowA] = await findSwapDvpEscrowAta({
      swapDvp,
      mint: mintA,
      tokenProgram: tokenProgramA,
    });
    const [escrowB] = await findSwapDvpEscrowAta({
      swapDvp,
      mint: mintB,
      tokenProgram: tokenProgramB,
    });
    ```

  </Tab>

## Koşulları kaydetme

`CreateDvp`; temel birimlerle iki tutarı, bir son kullanma zamanını, nonce'u ve
dört isteğe bağlı alanı alır: en fazla 64 baytlık opak bir referans, her taraf
için bir takas hedefi ve en erken takas zamanı (bkz. Notlar). Hedef, o tarafın
gelirlerinin takas sırasında ulaştığı yerdir; örneğin bir saklayıcının para
yatırma cüzdanı. Varsayılan olarak tarafın kendi adresidir ve kayıt oluştuktan
sonra değiştirilemez. İadeler ve geri alımlar, emanet hesabını kim fonlamış olursa
olsun, her zaman tarafın o bacağın mint'i için kendi token account'una gider;
hiçbir zaman hedefe gitmez.

Ödeyen hesap; kayıt, nonce tombstone'u ve iki emanet hesabı için rent'i karşılar.
Kapatma sırasında bu rent, ödeyen hesaba geri dönmez; kapatma talimatını imzalayan
hesaba gider. Tombstone hiçbir zaman kapatılmaz, bu nedenle her işlem küçük bir
kalıcı bakiye bırakır. Ödeyen hesabın SOL bütçesini planlarken rent tutarlarını
sabit kodlamak yerine `getMinimumBalanceForRentExemption` RPC yöntemiyle türetin.

<Tabs items={["TypeScript", "Rust"]}>
  <Tab value="TypeScript">
    ```ts
    import { getCreateDvpInstruction } from "./dvp";

    const nowSeconds = BigInt(Math.floor(Date.now() / 1000));

    const createInstruction = getCreateDvpInstruction({
      payer: payerSigner,
      swapDvp,
      nonceTombstone: (
        await getProgramDerivedAddress({
          programAddress: DVP_SWAP_PROGRAM_PROGRAM_ADDRESS,
          seeds: ["nonce", getAddressEncoder().encode(swapDvp)],
        })
      )[0],
      settlementAuthority,
      userA,
      userB,
      mintA,
      mintB,
      dvpAtaA: escrowA,
      dvpAtaB: escrowB,
      tokenProgramA,
      tokenProgramB,
      amountA: 1_000_000_000n, // 1,000 units of a 6-decimal asset
      amountB: 998_500_000n, // 998.50 units of a 6-decimal cash token
      expiryTimestamp: nowSeconds + 60n * 60n * 24n, // one day
      nonce,
      refString: "ORDER-2026-10-02-0001",
      userASettlementDestination: null, // defaults to userA
      userBSettlementDestination: null, // defaults to userB
      earliestSettlementTimestamp: null,
    });

    const { context } = await client.sendTransaction([createInstruction]);
    console.log("Trade record:", swapDvp, "signature:", context.signature);
    ```

TypeScript kod parçacığı için `@solana/kit` içinden `getProgramDerivedAddress` ve
`getAddressEncoder` ile istemciden `DVP_SWAP_PROGRAM_PROGRAM_ADDRESS` kapsamda
olmalıdır. Rust builder'ı System Program ve Associated Token Program'ı varsayılan
değerlerinde bırakır.

## Notlar

- **Son kullanma zamanı.** Son kullanma zamanını yalnızca Settle kontrol eder.
  Reclaim, Cancel ve Reject bu süreden sonra da çalışır; süre dolduktan sonra
  gelen bir para yatırma işlemi ise ilgili bacağın tarafınca geri alınabilir.
  Son kullanma zamanı, oluşturmadan en fazla bir yıl sonrası olabilir.
- **Zaman, ağ zamanıdır.** Program, duvar saatinden farklı olabilen (zaman zaman
  onlarca saniye) ve ileri sıçrayabilen zincir üstü saati okur. Son kullanma
  zamanı ile planlanan takas zamanı arasında pay bırakın, fonlamayı veya takası
  her iki sınıra yakın yapmaktan kaçının ve bir son tarihi saniyesine kadar
  uygulatmak için son kullanma zamanına güvenmeyin. Programın README dosyası,
  yaklaşık bir dakikalık sapma payı öngörülmesini önerir.
- **En erken takas.** İsteğe bağlıdır. Ayarlanırsa Settle bu zamandan önce
  reddedilir ve son kullanma zamanından sonra olamaz.
- **Oluşturma zamanı kontrolleri.** Bir taraf System Program'a ait bir hesap
  değilse (bu, SPL Token multisig'ini dışarıda bırakır) Create, `PartyNotSignerCapable`
  ile başarısız olur; ayrıca `SettlementDestinationIsSwapDvp`, `SelfDvp`,
  `SameMint`, `ZeroAmount`, `SettlementAuthorityIsParty` veya `ExpiryNotInFuture`
  hatalarıyla da başarısız olabilir. Tam liste [hatalar tablosunda](/docs/defi/dvp-program#errors)
  yer alır.
