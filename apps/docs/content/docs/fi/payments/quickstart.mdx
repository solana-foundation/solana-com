Tuloksena saat React-komponentin, joka näyttää Solana Pay -QR-koodin USDC-maksua varten, odottaa maksun saapumista ja tarkistaa, että se vastaa pyytämääsi maksua. Tarvitset Node.js 20+:n, React- tai Next.js-sovelluksen (tuore `create-next-app` käy hyvin) sekä devnetiin asetetun mobiililompakon. Lataa lompakkoon devnet-USDC-tokeneita osoitteesta [faucet.circle.com](https://faucet.circle.com) ja devnet-SOL-tokeneita osoitteesta [faucet.solana.com](https://faucet.solana.com) transaktiomaksujen kattamiseksi.

<Callout type="caution">
  `@solana/pay` on tällä hetkellä beta-vaiheessa. API-rajapinnat saattavat muuttua ennen vakaata julkaisua.
</Callout>

## 1. Asenna Solana Pay

```bash
pnpm add @solana/pay@beta @solana/kit
```

## 2. Lisää maksun QR-koodi

Komponentti luo tilaukselle yksilöllisen viitteen, koodaa sen [siirtopyynnön](/docs/tools/solana-pay/quickstart/transfer-requests) URL-osoitteeseen ja renderöi URL-osoitteen QR-koodiksi. Sen jälkeen se seuraa transaktiota, joka sisältää viitteen, ja tarkistaa vastaanottajan, summan ja tokenin ennen kuin merkitsee tilauksen maksetuksi. Aseta `MERCHANT_WALLET` osoitteeseen, jota hallitset:

```tsx
"use client";

import { useEffect, useRef, useState } from "react";
import {
  address,
  createSolanaRpc,
  createSolanaRpcSubscriptions,
  generateKeyPair,
  getAddressFromPublicKey
} from "@solana/kit";
import {
  createQR,
  encodeURL,
  validateTransfer,
  watchReference
} from "@solana/pay";

const MERCHANT_WALLET = address("your-wallet-address");
const USDC_DEVNET = address("4zMMC9srt5Ri5X14GAgXhaHii3GnPAEERYPJgZJDncDU");
const AMOUNT = 1;

const rpc = createSolanaRpc("https://api.devnet.solana.com");
const rpcSubscriptions = createSolanaRpcSubscriptions(
  "wss://api.devnet.solana.com"
);

export function Checkout() {
  const qrRef = useRef<HTMLDivElement>(null);
  const [signature, setSignature] = useState<string | null>(null);

  useEffect(() => {
    const abortController = new AbortController();

    async function startPayment() {
      const keyPair = await generateKeyPair();
      const reference = await getAddressFromPublicKey(keyPair.publicKey);

      const url = encodeURL({
        recipient: MERCHANT_WALLET,
        amount: AMOUNT,
        splToken: USDC_DEVNET,
        reference,
        label: "My Store",
        message: "Order #1001"
      });

      if (abortController.signal.aborted) return;

      if (qrRef.current) {
        qrRef.current.innerHTML = "";
        createQR(url, 300).append(qrRef.current);
      }

      const result = await watchReference(rpcSubscriptions, reference, {
        abortSignal: abortController.signal
      });
      if (result.err) throw new Error("Payment transaction failed");

      await validateTransfer(rpc, result.signature, {
        recipient: MERCHANT_WALLET,
        amount: AMOUNT,
        splToken: USDC_DEVNET,
        reference
      });
      setSignature(result.signature);
    }

    startPayment().catch((error) => {
      if (!abortController.signal.aborted) console.error(error);
    });

    return () => abortController.abort();
  }, []);

  if (signature) return <p>Payment confirmed: {signature}</p>;
  return <div ref={qrRef} />;
}
```

`amount` ilmoitetaan token-yksiköissä, joten `1` pyytää 1 USDC:tä. Jätä `splToken` pois, jos haluat pyytää SOL-tokeneita.

## 3. Vastaanota maksu

Käynnistä sovelluksesi, skannaa QR-koodi lompakollasi ja hyväksy maksu. Kun transaktio vahvistuu ja läpäisee tarkistuksen, komponentti näyttää transaktion allekirjoituksen. Tämä allekirjoitus on kuittisi: hae se komennolla [getTransaction](/docs/rpc/http/gettransaction) tai missä tahansa lohkoketjuselaimessa.

<Callout type="warn">
  Selaimessa tehtävä tarkistus riittää demoon. Ennen kuin toteutat oikeita tilauksia, vahvista maksut palvelimellasi. Katso [maksujen vahvistaminen](/docs/payments/accept-payments/verification-tools).
</Callout>
