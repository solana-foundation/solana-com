Agenttimaksujen avulla ohjelmisto voi selvittää hinnan, valtuuttaa maksun ja vastaanottaa
resurssin samassa HTTP-työnkulussa. Agentti voi maksaa datakyselystä, mallin
päättelystä tai työkalukutsusta ilman, että sen tarvitsee ensin luoda laskutustiliä tai kopioida
API-avainta.

## Yleinen maksuvirta

MPP ja x402 käyttävät eri otsakkeita ja tietomalleja, mutta niiden perustason HTTP-kulku on
samankaltainen:

```mermaid title="Agentic HTTP Payment Flow"
sequenceDiagram
    participant Agent
    participant Payer as Payment-aware client
    participant API as Resource server
    participant Solana
    Agent->>Payer: Request a paid resource
    Payer->>API: HTTP request
    API-->>Payer: 402 Payment Required + terms
    Note over Payer: Check price, asset, recipient, and policy
    Payer->>Payer: Ask the wallet to authorize and sign
    Payer->>API: Retry with payment authorization
    API->>Solana: Verify and settle, directly or through a facilitator
    Solana-->>API: Confirmed transaction
    API-->>Payer: Resource + payment receipt
    Payer-->>Agent: Return the result
```

## MPP ja x402

Molemmat protokollat voivat selvittää stablecoin-maksuja Solanassa. Valitse protokolla
maksumallin ja palvelusi tarvitseman yhteentoimivuuden perusteella, älä pelkästään yhteisen `402`-
tilakoodin perusteella.

|                         | MPP                                                               | x402                                                                     |
| ----------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Haaste               | `WWW-Authenticate: Payment`                                       | `PAYMENT-REQUIRED`                                                       |
| Asiakkaan valtuutus    | `Authorization: Payment`                                          | `PAYMENT-SIGNATURE`                                                      |
| Kuitti                 | `Payment-Receipt`                                                 | `PAYMENT-RESPONSE`                                                       |
| Solana-maksumallit   | Kertaluonteinen `charge`-veloitus ja ylärajalliset, mitatut `session`-aikomukset           | Skeemat, kuten `exact` ja `upto`; tuki vaihtelee verkon ja asiakasohjelman mukaan |
| Selvitysarkkitehtuuri | Palvelimen suorittama validointi tai valinnainen välittäjä tai yhdyskäytävä                | Resurssipalvelin paikallisella varmennuksella tai facilitator                 |
| Hyvä lähtökohta     | API-rajapinnat, jotka tarvitsevat HTTP-todennuksen semantiikkaa tai toistuvaa mittausta | Pyyntökohtaisesti maksettavat resurssit ja olemassa olevat x402-asiakasohjelmat                      |

MPP on **Machine Payments Protocol**. Älä sekoita sitä **Model
Context Protocoliin (MCP)**. MCP tarjoaa agenteille työkaluja ja resursseja; MPP tai x402
voi edellyttää maksua, kun agentti kutsuu jotakin näistä työkaluista.

<Callout type="info">
  Palvelu voi mainostaa useampaa kuin yhtä protokollaa. Asiakas valitsee tukemansa
  maksuvaihtoehdon ja käyttää sitten vastaavia haaste-, valtuutus- ja
  kuittiotsakkeita koko vuorovaikutuksen ajan.
</Callout>
