Käytä [Payta](https://pay.sh) x402 V2 -rajapinnan ajamiseen ja anna Claude Codelle
maksutietoinen HTTP-asiakas. Rajapinta, maksajan lompakko ja maksun selvitys käyttävät
kaikki Solanan sandbox-ympäristöä, joten tämä läpikäynti ei vaadi tiliä eikä oikeita varoja.

Tarvitset päätteen sekä asennetut Payn ja Claude Coden.

## 1. Asenna Pay

Asenna macOS:llä valmiiksi käännetty binääritiedosto:

```bash
brew install pay
pay --version
```

Muilla alustoilla asenna npm-paketti:

```bash
npm install --global @solana/pay
pay --version
```

## 2. Käynnistä x402-sandbox-rajapinta

Luo tiedosto `x402-demo.yaml`:

```yaml filename=x402-demo.yaml
name: x402-demo
subdomain: x402-demo
title: "x402 Demo"
description: "Minimal x402 V2 sandbox endpoint."
category: devtools
version: v1
routing:
  type: respond
operator:
  currencies:
    usd: ["USDC"]
  network: "localnet"
  fee_payer: true
endpoints:
  - method: GET
    path: "report"
    description: "Return a sandbox report."
    metering:
      schemes: [x402-exact]
      dimensions:
        - direction: usage
          unit: requests
          scale: 1
          tiers:
            - price_usd: 0.001
```

Käynnistä rajapinta ja jätä se käyntiin:

```bash
pay --sandbox server start x402-demo.yaml --bind 127.0.0.1:1402
```

`x402-exact`-skeema tekee tästä pelkän x402-päätepisteen. Sandbox-tila luo
ja rahoittaa väliaikaiset operaattorin ja maksajan tilit automaattisesti.

## 3. Käynnistä agentti Payn avulla

Käynnistä toisessa päätteessä Claude Code sandbox-tilassa:

```bash
pay --sandbox claude
```

Pay liittää paikalliset MCP-työkalunsa agentin istuntoon. Agentti ei
saa yksityistä avainta.

## 4. Tee yksi x402-pyyntö

Liitä tämä kehote agentille:

```text
Use Pay to make exactly one sandbox x402 API request to
http://127.0.0.1:1402/report.

Before paying, show me the amount and ask for approval. Then return the API
result and payment receipt. Do not make any other paid requests.
```

Pyyntö noudattaa yhtä täydellistä x402 V2 -maksusilmukkaa:

1. Rajapinta palauttaa vastauksen `402 Payment Required` sekä `PAYMENT-REQUIRED`-haasteen.
2. Pay validoi x402-vaatimukset ja näyttää maksuehdot.
3. Hyväksynnän jälkeen sandbox-lompakko allekirjoittaa maksun, ja Pay yrittää pyyntöä uudelleen
   otsikolla `PAYMENT-SIGNATURE`.
4. Rajapinta palauttaa tuloksen sekä `PAYMENT-RESPONSE`-kuitin.

Oikeita varoja ei siirry. Hyväksynnän hylkääminen pysäyttää pyynnön.

Jatka lukemalla [x402 Solanassa](/docs/payments/agentic-payments/x402) ja rakenna
x402 V2 -asiakas ja resurssipalvelin tai
[ryhdy x402-facilitatoriksi](/docs/tools/x402-facilitator).
