## Pikaviite

### Kahvan alustus

```go
import (
    litesvm "github.com/LiteSVM/litesvm-go"
    solana "github.com/gagliardetto/solana-go"
)

svm, err := litesvm.New()
if err != nil {
    // handle error
}
defer svm.Close()
```

### Tilinhallinta

| Metodi                                                                       | Kuvaus                                          |
| ---------------------------------------------------------------------------- | ---------------------------------------------------- |
| `Airdrop(pubkey, lamports) error`                                            | Rahoita tili                                      |
| `Balance(pubkey) (uint64, bool, error)`                                      | SOL-saldo; bool ilmoittaa, onko tili olemassa |
| `GetAccount(pubkey) *Account`                                                | Hae tilikahva (nil, jos puuttuu)          |
| `SetAccount(pubkey, *Account) error`                                         | Tallenna tilin tila suoraan                         |
| `MinimumBalanceForRentExemption(dataLen int) (uint64, error)`                | Laske rent-vapautuksen vähimmäissaldo                          |
| `NewAccount(lamports, data, owner, executable, rentEpoch) (*Account, error)` | Rakenna Account-kahva SetAccountia varten               |

### Ohjelmien hallinta

| Metodi                                                   | Kuvaus                             |
| -------------------------------------------------------- | --------------------------------------- |
| `AddProgram(programID, bytes) error`                     | Lataa ohjelma tavuista                 |
| `AddProgramFromFile(programID, path) error`              | Lataa ohjelma `.so`-tiedostosta            |
| `AddProgramWithLoader(programID, bytes, loaderID) error` | Lataa tietyllä loaderilla (edistynyt) |

### Transaktiot

| Metodi                                                                        | Kuvaus                                                                     |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| `SendLegacyTransaction(txBytes) (*TxOutcome, error)`                          | Suorita legacy-transaktio                                                    |
| `SendVersionedTransaction(txBytes) (*TxOutcome, error)`                       | Suorita v0+-transaktio                                                       |
| `SimulateLegacyTransaction(txBytes) (*TxOutcome, error)`                      | Simuloi ilman tilamuutoksia                                                  |
| `SimulateVersionedTransaction(txBytes) (*TxOutcome, error)`                   | Simuloi v0+ ilman tilamuutoksia                                              |
| `LatestBlockhash() (solana.Hash, error)`                                      | Nykyinen lohkohajautusarvo                                                               |
| `ExpireBlockhash() error`                                                     | Siirry uuteen lohkohajautusarvoon                                                      |
| `GetTransaction(signature) *TxOutcome`                                        | Hae transaktio historiasta (nil, jos puuttuu)                                  |
| `litesvm.BuildTransferTx(payerSeed, to, lamports, blockhash) ([]byte, error)` | Testiapu­funktio, joka rakentaa allekirjoitetun legacy-siirron ilman `solana-go`-riippuvuutta |

### Konfigurointi

| Metodi                                         | Kuvaus                                             |
| ---------------------------------------------- | ------------------------------------------------------- |
| `SetSigverify(bool) error`                     | Ota allekirjoitusten tarkistus käyttöön / poista käytöstä                 |
| `Sigverify() (bool, error)`                    | Lue nykyinen asetus                                |
| `SetBlockhashCheck(bool) error`                | Ota lohkohajautusarvon validointi käyttöön / poista käytöstä                   |
| `SetTransactionHistory(int) error`             | Muistissa pidettävän tx-historian kapasiteetti (0 poistaa käytöstä)           |
| `SetLogBytesLimit(int) error`                  | Lokitavujen enimmäismäärä per transaktio (negatiivinen = rajoittamaton)              |
| `SetLamports(uint64) error`                    | Oletusarvoinen lamport-määrä uusille airdrop-pool-tileille          |
| `SetSysvars() error`                           | Palauta sysvars oletusarvoihin                               |
| `SetBuiltins() error`                          | Lataa sisäänrakennetut ohjelmat uudelleen                                |
| `SetDefaultPrograms() error`                   | Lataa SPL Token, Memo jne. uudelleen                            |
| `SetPrecompiles() error`                       | Ota ed25519 / secp256k1-esikäänteet käyttöön                  |
| `WithNativeMints() error`                      | Alusta wrapped-SOL-mint (seed)                                   |
| `SetFeatureSet(*FeatureSet) error`             | Asenna feature gate -joukko                              |
| `SetComputeBudget(ComputeBudget) error`        | Käytä laskentabudjettia                                  |
| `ComputeBudget() (ComputeBudget, bool, error)` | Lue nykyinen budjetti (bool ilmoittaa "asetettu eksplisiittisesti") |

| -------------------------------------------- | ------------------------------------ |
| `WarpToSlot(slot uint64) error`              | Hyppää tiettyyn slot-kohtaan              |

| `Rent() (Rent, error)`                       | Lue Rent-sysvar                 |

| `EpochSchedule() (EpochSchedule, error)`     | Lue EpochSchedule-sysvar        |
| `SetEpochSchedule(EpochSchedule) error`      | Korvaa EpochSchedule-sysvar   |
| `EpochRewards() (EpochRewards, error)`       | Lue EpochRewards-sysvar         |
| `SetEpochRewards(EpochRewards) error`        | Korvaa EpochRewards-sysvar    |
| `LastRestartSlot() (uint64, error)`          | Lue last-restart-slot               |
| `SetLastRestartSlot(uint64) error`           | Aseta last-restart-slot                |
| `SlotHashes() ([]SlotHash, error)`           | Lue SlotHashes-sysvar           |
| `SetSlotHashes([]SlotHash) error`            | Korvaa SlotHashes-sysvar      |
| `SlotHistory() (*SlotHistory, error)`        | Lue SlotHistory-sysvar (kahva) |
| `SetSlotHistory(*SlotHistory) error`         | Korvaa SlotHistory-sysvar     |
| `StakeHistory() ([]StakeHistoryItem, error)` | Lue StakeHistory-sysvar         |
| `SetStakeHistory([]StakeHistoryItem) error`  | Korvaa StakeHistory-sysvar    |
