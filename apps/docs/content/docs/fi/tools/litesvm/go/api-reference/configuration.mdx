Jokainen setter vastaa Rust-tyypin `LiteSVM` vastaavaa builder-metodia.
Kutsut tulevat voimaan välittömästi ja palauttavat `error`-arvon.

## Tyypillinen testiasetukset

```go
svm, err := litesvm.New()
if err != nil {
    t.Fatal(err)
}
defer svm.Close()

// Each setter returns an error. The calls below are infallible in practice,
// so the docs use _ = ... for brevity; check the error in production code.
_ = svm.SetSigverify(false)        // skip signature verification (faster)
_ = svm.SetBlockhashCheck(false)   // skip blockhash validation (simpler)
_ = svm.SetSysvars()               // reset Clock, Rent, etc. to defaults
_ = svm.SetBuiltins()              // reload built-in programs
_ = svm.SetTransactionHistory(100) // keep the last 100 transactions
```

## Allekirjoitus ja lohkohash

### SetSigverify

```go
func (s *LiteSVM) SetSigverify(enabled bool) error
```

Ota transaktioiden allekirjoitusvarmistus käyttöön tai poista se käytöstä.

```go
if err := svm.SetSigverify(false); err != nil { // accept unsigned / badly-signed txs
    t.Fatal(err)
}
if err := svm.SetSigverify(true); err != nil {  // restore production-like behavior
    t.Fatal(err)
}
```

<Callout type="info">
  Allekirjoitusvarmistuksen poistaminen käytöstä nopeuttaa testejä, mutta tekee niistä vähemmän realistisia.
</Callout>

### Sigverify

```go
func (s *LiteSVM) Sigverify() (bool, error)
```

Lue nykyinen asetus.

### SetBlockhashCheck

```go
func (s *LiteSVM) SetBlockhashCheck(enabled bool) error
```

Ota käyttöön tai poista käytöstä lähetettyjen transaktioiden viimeisimmän lohkohashin tarkistus.

```go
if err := svm.SetBlockhashCheck(false); err != nil { // accept any blockhash
    t.Fatal(err)
}
```

## Ohjelmat ja sysvars-muuttujat

### SetSysvars

```go
func (s *LiteSVM) SetSysvars() error
```

Alusta sisäänrakennetut sysvars-muuttujat (Clock, Rent, EpochSchedule, ...) uudelleen
oletusarvoihinsa.

### SetBuiltins

```go
func (s *LiteSVM) SetBuiltins() error
```

Lataa oletusjoukko sisäänrakennettuja ohjelmia.

### SetDefaultPrograms

```go
func (s *LiteSVM) SetDefaultPrograms() error
```

Lataa vakio-SPL-ohjelmat (System Program, SPL Token, Memo, ...).

### SetPrecompiles

```go
func (s *LiteSVM) SetPrecompiles() error
```

Ota käyttöön ed25519 / secp256k1 esikäännetyt ohjelmat.

### WithNativeMints

```go
func (s *LiteSVM) WithNativeMints() error
```

Alusta SPL Token / Token-2022 natiivimint-tilit (kääritty SOL). Ei tee mitään, jos
vastaavaa ohjelmaa ei ole ladattu; kutsu ensin `SetDefaultPrograms`, jos haluat
molemmata.

## Resurssirajoitukset

### SetLamports

```go
func (s *LiteSVM) SetLamports(lamports uint64) error
```

Aseta sisäisen airdrop-pool-tilin oletusarvoinen lamport-saldo.

```go
if err := svm.SetLamports(1 << 40); err != nil { // ~1.1 trillion lamports (~1,100 SOL)
    t.Fatal(err)
}
```

### SetLogBytesLimit

```go
func (s *LiteSVM) SetLogBytesLimit(limit int) error
```

Rajoita transaktiota kohden kaapattuja kokonaislogtavuja. Anna negatiivinen arvo
poistaaksesi rajoituksen.

```go
if err := svm.SetLogBytesLimit(10_000); err != nil { // 10 KB cap
    t.Fatal(err)
}
if err := svm.SetLogBytesLimit(-1); err != nil {     // unlimited
    t.Fatal(err)
}
```

### SetTransactionHistory

```go
func (s *LiteSVM) SetTransactionHistory(capacity int) error
```

Aseta muistissa olevan transaktiohistorian kapasiteetti. Anna `0` poistaaksesi deduplikoinnin
ja salliaksesi identtisten transaktioiden toistamisen.

```go
if err := svm.SetTransactionHistory(100); err != nil { // cap at 100 entries
    t.Fatal(err)
}
if err := svm.SetTransactionHistory(0); err != nil {   // disable dedup entirely
    t.Fatal(err)
}
```

## Laskentabudjetti

```go
type ComputeBudget struct {
    // See litesvm-go/litesvm.go for the full field list.
    // usize fields are normalized to uint64; HeapSize stays uint32.
    ComputeUnitLimit uint64
    HeapSize         uint32
    // ...
}
```

### ComputeBudget

```go
func (s *LiteSVM) ComputeBudget() (ComputeBudget, bool, error)
```

Lue nykyinen laskentabudjetti. Toinen palautusarvo kertoo, onko budjetti
asetettu eksplisiittisesti; jos `false`, struct sisältää oletusarvot,
joita käytetään.

```go
budget, set, err := svm.ComputeBudget()
if err != nil {
    t.Fatal(err)
}
if !set {
    budget.ComputeUnitLimit = 1_400_000
}
if err := svm.SetComputeBudget(budget); err != nil {
    t.Fatal(err)
}
```

### SetComputeBudget

```go
func (s *LiteSVM) SetComputeBudget(b ComputeBudget) error
```

Asenna laskentabudjetti myöhempiä transaktioita varten.

## Ominaisuusjoukot

`FeatureSet` on läpinäkymätön kahva – luo se, muokkaa sitä `Activate` /
`Deactivate`-metodeilla, ja asenna se sitten `SetFeatureSet`-metodilla. Sulje luomasi kahvat.

```go
// Start with all features off, then activate what you care about.
fs, err := litesvm.NewFeatureSet()
if err != nil {
    t.Fatal(err)
}
defer fs.Close()
if err := fs.Activate(featureID, 0); err != nil {
    t.Fatal(err)
}

// Or start from "everything enabled" and flip specific features off.
fs2, err := litesvm.NewFeatureSetAllEnabled()
if err != nil {
    t.Fatal(err)
}
defer fs2.Close()
if err := fs2.Deactivate(featureID); err != nil {
    t.Fatal(err)
}

if err := svm.SetFeatureSet(fs); err != nil {
    t.Fatal(err)
}
```

| Metodi                                                   | Kuvaus                       |
| -------------------------------------------------------- | --------------------------------- |
| `litesvm.NewFeatureSet() (*FeatureSet, error)`           | Tyhjä joukko (kaikki ominaisuudet inaktiivisia) |
| `litesvm.NewFeatureSetAllEnabled() (*FeatureSet, error)` | Kaikki ominaisuudet aktiivisia               |
| `fs.Activate(featureID, slot) error`                     | Merkitse ominaisuus aktiiviseksi slot-kohdassa       |
| `fs.Deactivate(featureID) error`                         | Merkitse ominaisuus inaktiiviseksi             |
| `fs.IsActive(featureID) bool`                            | Aktiivisuuden tarkistus                      |
| `fs.ActivatedSlot(featureID) (uint64, bool)`             | Slot, jossa ominaisuus aktivoitiin   |
| `fs.ActiveCount() int`                                   | Aktiivisten ominaisuuksien määrä              |
| `fs.InactiveCount() int`                                 | Inaktiivisten ominaisuuksien määrä            |
| `fs.ActiveFeatures() []solana.PublicKey`                 | Listaa aktiivisten ominaisuuksien tunnisteet           |
| `fs.InactiveFeatures() []solana.PublicKey`               | Listaa inaktiivisten ominaisuuksien tunnisteet         |
| `fs.Close()`                                             | Vapauta kahva                |
| `svm.SetFeatureSet(*FeatureSet) error`                   | Asenna SVM:ään                |

<Callout type="info">
  Käytä ominaisuuden porttausta testataksesi, miten ohjelmat toimivat tietyn Solana-version alla
  – aktivoi kohdejulkaisusi mukana toimitetut ominaisuudet ja
  poista käytöstä myöhemmin lisätyt.
</Callout>
