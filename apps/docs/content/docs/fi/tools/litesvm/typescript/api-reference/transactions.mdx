Menetelmiä transaktioiden lähettämiseen, simulointiin ja hallintaan.

## sendTransaction

```typescript
sendTransaction(tx: Transaction): TransactionMetadata | FailedTransactionMetadata
```

Suorita transaktio. Palauttaa metatiedot onnistumisen yhteydessä tai virhetiedot epäonnistumisen yhteydessä.

```typescript
const result = client.svm.sendTransaction(signedTx);

// Check for errors
if ("err" in result && result.err()) {
  console.error("Transaction failed:", result.err());
  return;
}

// Access result properties (note: these are getter functions)
console.log("Signature:", result.signature());
console.log("Compute units:", result.computeUnitsConsumed());
console.log("Logs:", result.logs());
```

<Callout type="warn">
  Transaktion tuloksen ominaisuudet kuten `err()`, `computeUnitsConsumed()`,
  `logs()` ja `signature()` ovat **getter-funktioita**, eivät ominaisuuksia. Kutsu
  niitä aina sulkujen kanssa.
</Callout>

### TransactionMetadata-metodit

| Metodi                   | Palauttaa                 | Kuvaus                 |
| ------------------------ | ----------------------- | --------------------------- |
| `signature()`            | `Uint8Array`            | Transaktion allekirjoitustavut |
| `computeUnitsConsumed()` | `bigint`                | Käytetyt laskentayksiköt          |
| `logs()`                 | `string[]`              | Ohjelmalokitiedot                |
| `innerInstructions()`    | `InnerInstruction[]`    | Sisäiset (CPI) ohjeet    |
| `returnData()`           | `TransactionReturnData` | Ohjelmien palauttama data   |
| `prettyLogs()`           | `string`                | Muotoillut lokitiedot väreineen  |

## simulateTransaction

```typescript
simulateTransaction(tx: Transaction): SimulatedTransactionInfo | FailedTransactionMetadata
```

Simuloi transaktio muuttamatta tilaa.

```typescript
const simResult = client.svm.simulateTransaction(signedTx);

if ("err" in simResult && simResult.err()) {
  console.error("Simulation failed:", simResult.err());
  return;
}

// Use .meta() to get TransactionMetadata
const meta = simResult.meta();
console.log("Would use", meta.computeUnitsConsumed(), "compute units");
console.log("Logs:", meta.logs());

// Get post-execution account states
const postAccounts = simResult.postAccounts();
console.log("Post-state accounts:", postAccounts);
```

<Callout type="info">
  Simulointi ei muuta tilaa. Käytä sitä transaktioiden tarkistamiseen ennen lähettämistä.
</Callout>

## Lohkotiivisteen hallinta

### latestBlockhash

```typescript
latestBlockhash(): Blockhash
```

Hae nykyinen lohkotiiviste.

```typescript
const blockhash = client.svm.latestBlockhash();
console.log("Blockhash:", blockhash);
```

### getLatestBlockhash (client.rpc:n kautta)

Hae lohkotiiviste elinikätietoineen transaktioiden manuaalista rakentamista varten.
Käytä RPC-apuria, sillä se palauttaa sekä `blockhash`- että `lastValidBlockHeight`-arvon.

```typescript
import {
  createTransactionMessage,
  setTransactionMessageLifetimeUsingBlockhash
} from "@solana/kit";

const { value: blockhashLifetime } = await client.rpc
  .getLatestBlockhash()
  .send();

const tx = setTransactionMessageLifetimeUsingBlockhash(
  blockhashLifetime,
  createTransactionMessage({ version: 0 })
);
```

<Callout type="info">
  Kun käytät ohjelmalaajennnuksia kuten `systemProgram()` tai `tokenProgram()`, sinun
  ei tarvitse koskaan hakea lohkotiivistettä itse — `client.sendTransaction()` (ja
  ohjeketjujen `.sendTransaction()`-apuri) hoitavat sen puolestasi.
</Callout>

### expireBlockhash

```typescript
expireBlockhash(): LiteSVM
```

Siirry uuteen lohkotiivisteeseen. Hyödyllinen lohkotiivisteen vanhenemistilanteiden testaamiseen.

```typescript
const oldBlockhash = client.svm.latestBlockhash();
client.svm.expireBlockhash();
const newBlockhash = client.svm.latestBlockhash();

console.log("Old:", oldBlockhash);
console.log("New:", newBlockhash);
// Blockhashes will be different
```

## Transaktiohistoria

Ota transaktiohistoria käyttöön hakeaksesi transaktioita lähettämisen jälkeen:

```typescript
// Enable history storage (stores last N transactions)
client.svm.withTransactionHistory(100n);

// Send a transaction
const result = client.svm.sendTransaction(signedTx);

// Later, retrieve it by signature (base58 string)
// Note: getTransaction expects a base58-encoded signature string
```
