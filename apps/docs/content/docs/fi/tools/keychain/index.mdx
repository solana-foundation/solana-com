**Solana Keychain tarjoaa yhtenäisen rajapinnan Solana-transaktioiden allekirjoittamiseen
usean avainhallintataustajärjestelmän välillä.** Kehitä paikallisesti muistinvaraisella
avaimella ja siirry tuotannossa yritystason avainhallintaan, pilvipohjaisiin HSM-moduuleihin tai hallinnoituihin lompakko-
palveluihin ilman, että allekirjoituskoodiasi tarvitsee kirjoittaa uudelleen.

### Miksi Keychain?

- **Yksi rajapinta**: Yksi `SolanaSigner`-perusrajapinta kaikille taustajärjestelmille,
  sekä yksi ominaisuus kutakin taustajärjestelmää kohden: allekirjoitus, uudelleenkirjoitus ja allekirjoitus tai allekirjoitus ja lähetys
- **Vaihda taustajärjestelmää**: Vaihda avainhallintapalvelun tarjoajaa konfiguraation kautta; kutsukohtia
  tarvitsee muuttaa vain, jos uudella taustajärjestelmällä on eri ominaisuus (Crossmintin
  ja Fordefin natiilitilat)
- **Maksa vain käyttämästäsi**: Rustin feature-liput, taustajärjestelmäkohtaiset npm-paketit, Pythonin
  extras-lisäosat ja taustajärjestelmäkohtaiset Go-moduulit sisältävät vain tarvitsemasi taustajärjestelmät
- **Auditoitu**: Rust, TypeScript, Python ja Go auditoinut
  [OtterSec](https://osec.io) (valinnainen Ledger-taustajärjestelmä jäi auditoinnin ulkopuolelle); aiempi
  [Accretion](https://accretion.xyz)-auditointi kattoi Rustin ja TypeScriptin.
  Katso
  [auditoinnin tila](https://github.com/solana-foundation/solana-keychain/blob/main/audits/AUDIT_STATUS.md).

### Arkkitehtuuri

- **Kielet**: Rust, TypeScript, Python ja Go, yhtäläisin ominaisuuksin (Ledger-taustajärjestelmä
  on vain Rustille)
- **Rajapinta**: `SolanaSigner`-perusrajapinta (`pubkey`, `sign_message`, `is_available`)
  sekä täsmälleen yksi ominaisuus kutakin taustajärjestelmää kohden: `TransactionSigner`,
  `ModifyingSigner` tai `SendingSigner`
- **Taustajärjestelmät**: Memory, Vault, AWS KMS, GCP KMS, Privy, Turnkey, Fireblocks,
  CDP, Crossmint, Dfns, Openfort, Para, Utila, Fordefi, Ledger (vain Rust,
  valinnainen, auditoimaton)
- **Yhteensopivuus**: `@solana/kit` ja `@solana/signers` 8.1+ (TypeScript) |
  `solana-sdk` 2.x, 3.x tai 4.x `sdk-v2` / `sdk-v3` / `sdk-v4` -ominaisuuksien kautta
  (Rust; v1-transaktiot vaativat `sdk-v4`:n) | `solders` (Python) | `solana-go` v2
  (Go)

### Tuetut järjestelmät

Taustajärjestelmät kattavat paikallisen kehityksen, itse isännöidyn ja
pilvipalvelupohjaisen avaintenhallinnan sekä hallinnoidut tai
MPC-lompakkopalvelut. Katso
[Taustajärjestelmän valinta](/docs/tools/keychain/choosing-a-backend)
vertaillaksesi säilytysratkaisuja ja valitaksesi oikean vaihtoehdon.

## Pikaopas

### Rust

Asenna Rust-paketti:

```bash
cargo add solana-keychain
```

Peruskäyttö:

```rust
use solana_keychain::{Signer, SolanaSigner};

// Create a signer from any backend
let signer = Signer::from_memory("base58_private_key")?;
let pubkey = signer.pubkey();

// Transaction signing is a capability; `tx` is a VersionedTransaction
if let Some(tx_signer) = signer.as_transaction_signer() {
    let result = tx_signer.sign_transaction(&mut tx).await?;
}

// Or let the umbrella route any backend shape and supply the RPC hop yourself
let signature = signer
    .sign_and_send(&mut tx, |encoded| async move { broadcast(encoded).await })
    .await?;
```

- [Rust-opas](/docs/tools/keychain/getting-started/rust) - Täydellinen asennus
  ja taustapalvelun konfigurointi
- [Crates.io](https://crates.io/crates/solana-keychain) - Rust-paketti

### TypeScript

Asenna TypeScript-paketti:

```bash
pnpm add @solana/keychain
```

Peruskäyttö:

```typescript
import { createKeychainSigner } from "@solana/keychain";
import { signTransactionWithSigners } from "@solana/signers";

// Create any signer via the unified factory
const signer = await createKeychainSigner({
  backend: "vault",
  vaultAddr: "https://vault.example.com:8200",
  vaultToken: "hvs.xxxxx",
  keyName: "my-solana-key",
  publicKey: "base58_public_key"
});

// Sign an already-compiled transaction
const signedTx = await signTransactionWithSigners(
  [signer],
  compiledTransaction
);
```

- [TypeScript-opas](/docs/tools/keychain/getting-started/typescript) -
  `@solana/keychain` paketit
- [npm-paketti](https://www.npmjs.com/package/@solana/keychain) - npm-paketti

Jos haluat asentaa Keychain-allekirjoittajan [Kit](https://github.com/anza-xyz/kit)-asiakkaaseen
sen `payer`- tai `identity`-arvoksi, käytä pakettia `@solana/keychain-kit-plugin` (Crossmintin ja
Fordefin natiilitilat on suljettu pois, koska ne kirjoittavat transaktiot uudelleen).

### Python

Asenna paketti (raskaammat taustajärjestelmät toimitetaan lisäosina, esimerkiksi
`solana-keychain[aws-kms]`):

```bash
pip install solana-keychain
```

Peruskäyttö:

```python
import os

from solana_keychain import VaultSignerConfig, create_vault_signer

signer = await create_vault_signer(
    VaultSignerConfig(
        api_base_url="https://vault.example.com:8200",
        token=os.environ["VAULT_TOKEN"],
        key_name="my-solana-key",
        public_key="base58_public_key",
    )
)

# tx is a solders VersionedTransaction
result = await signer.sign_transaction(tx)
```

- [Python-opas](/docs/tools/keychain/getting-started/python) – Täydellinen
  asennus, lisäosat ja taustajärjestelmien konfigurointi
- [PyPI](https://pypi.org/project/solana-keychain/) – Python-paketti

### Go

Jokainen taustajärjestelmä on oma Go-moduulinsa, joten haet vain ne taustajärjestelmät, jotka tuot:

```bash
go get github.com/solana-foundation/solana-keychain/go/signers/vault/v2@latest
```

Peruskäyttö:

```go
import "github.com/solana-foundation/solana-keychain/go/signers/vault/v2"

signer, err := vault.New(vault.Config{
	VaultAddr: "https://vault.example.com:8200",
	Token:     os.Getenv("VAULT_TOKEN"),
	KeyName:   "my-solana-key",
	Pubkey:    "base58_public_key",
})
if err != nil {
	return err
}

// tx is a *solana.Transaction from solana-go v2
res, err := signer.SignTransaction(ctx, tx)
```

- [Go-opas](/docs/tools/keychain/getting-started/go) – Moduulit, ominaisuudet
  ja taustajärjestelmien konfigurointi
- [pkg.go.dev](https://pkg.go.dev/github.com/solana-foundation/solana-keychain/go/core/v2) –
  Go-viite
