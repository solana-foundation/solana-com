## Asennus

Lisää `solana-keychain` `Cargo.toml`-tiedostoosi vain tarvitsemasi backendit:

```toml title="Cargo.toml"
[dependencies]
# Memory signer only (default, Solana SDK 2.x)
solana-keychain = "2.0"

# Or specify backends explicitly (pick exactly one SDK feature)
solana-keychain = { version = "2.0", default-features = false, features = ["vault", "aws_kms", "sdk-v2"] }

# All remote backends on the Solana 4.x SDK line
solana-keychain = { version = "2.0", default-features = false, features = ["all", "sdk-v4"] }
```

Päivitätkö versiosta 1.x? Katso
[siirtymisopas versioon 2.0](https://github.com/solana-foundation/solana-keychain/blob/main/docs/MIGRATING_V2.md).

### Ominaisuusliput

| Ominaisuus        | Kuvaus                                                           |
| -------------- | --------------------------------------------------------------------- |
| `memory`       | Paikallinen keypair-allekirjoitus (oletus)                                       |
| `vault`        | HashiCorp Vault Transit -moottori                                        |
| `aws_kms`      | AWS KMS Ed25519:llä                                                  |
| `gcp_kms`      | GCP Cloud KMS Ed25519:llä                                            |
| `privy`        | Privy upotetut lompakot                                                |
| `turnkey`      | Turnkey API                                                           |
| `fireblocks`   | Fireblocks MPC                                                        |
| `cdp`          | Coinbase Developer Platform                                           |
| `crossmint`    | Crossmint hallinnoidut lompakot                                             |
| `dfns`         | Dfns lompakkoinfrastruktuuri                                            |
| `openfort`     | Openfort upotetut lompakot                                             |
| `para`         | Para MPC -lompakot                                                      |
| `utila`        | Utila MPC -säilytys                                                     |
| `fordefi`      | Fordefi MPC-säilytys                                                   |
| `ledger`       | Ledger-laitteistolompakko USB-HID:n kautta (vain Rust, valinnainen, ei sisälly `all`-ominaisuuteen) |
| `all`          | Ota käyttöön kaikki taustajärjestelmät paitsi `ledger`                                  |
| `sdk-v2`       | Solana SDK 2.x (oletus)                                              |
| `sdk-v3`       | Solana SDK 3.x                                                        |
| `sdk-v4`       | Solana SDK 4.x (vaaditaan v1-transaktioille)                         |
| `unsafe-debug` | Kirjaa palveluntarjoajan täydet virhevastaukset lokiin; älä koskaan ota käyttöön tuotannossa        |

Täsmälleen yksi ominaisuuksista `sdk-v2`, `sdk-v3` ja `sdk-v4` on otettava käyttöön.

## Peruskäyttö

Kaikki allekirjoittajat toteuttavat perustyypin
[`SolanaSigner`-trait](https://github.com/solana-foundation/solana-keychain/blob/main/rust/src/traits.rs)
(`pubkey`, `sign_message`, `is_available`). Lisäksi jokainen taustajärjestelmä toteuttaa täsmälleen
yhden kyvykkyys-traitin:

- `TransactionSigner`: allekirjoittaa transaktiosi sellaisenaan.
- `ModifyingSigner`: palveluntarjoaja muokkaa transaktiota ja allekirjoittaa sen sitten.
- `SendingSigner`: palveluntarjoaja allekirjoittaa ja lähettää sen verkkoon.

```rust
use solana_keychain::{SignerError, SolanaSigner, TransactionSigner};
use solana_sdk::transaction::VersionedTransaction;

async fn sign_transaction(
    signer: &impl TransactionSigner,
    tx: &mut VersionedTransaction,
) -> Result<(), SignerError> {
    // Get the signer's public key
    let pubkey = signer.pubkey();
    println!("Signing with: {}", pubkey);

    // Check availability (useful for remote signers)
    if !signer.is_available().await {
        return Err(SignerError::NotAvailable("Signer offline".into()));
    }

    // Sign the transaction: returns Complete or Partial
    let result = signer.sign_transaction(tx).await?;
    let (base64_tx, signature) = result.into_signed_transaction();
    println!("Signature: {}", signature);

    Ok(())
}
```

Muunna perinteinen `Transaction` komennolla `.into()`. Perinteiset ja v0-transaktiot toimivat
kaikilla SDK-ominaisuuksilla; v1-transaktiot vaativat `sdk-v4`:n.

### Allekirjoittajien kyvykkyydet

| Taustajärjestelmä                              | Kyvykkyys-trait    | `sign_message`                  |
| ------------------------------------ | ------------------- | ------------------------------- |
| Crossmint                            | `SendingSigner`     | Ei tuettu                   |
| Fordefi natiivi automaattinen                  | `SendingSigner`     | Kyllä                             |
| Fordefi natiivi manuaalinen                | `ModifyingSigner`   | Kyllä                             |
| Utila                                | `TransactionSigner` | Ei tuettu                   |
| CDP                                  | `TransactionSigner` | Vain UTF-8-sisällöt             |
| Ledger                               | `TransactionSigner` | Kyllä, ketjun ulkopuolisen kirjekuoren kautta |
| Kaikki muut (mukaan lukien Fordefi black box) | `TransactionSigner` | Kyllä                             |

`Signer::from_*`-konstruktorit suorittavat `init()`-kutsun puolestasi. Jos luot
Privy-, Fireblocks-, Dfns-, Crossmint-, Para-, Openfort- tai Utila-allekirjoittajatyypit
suoraan, kutsu `init().await` ennen käyttöä.

## Backend-konfiguraatio

### Muistiallekirjoittaja

Kehitykseen ja testaukseen paikallisilla keypair-avaimilla:

```rust
use solana_keychain::Signer;

// From base58 private key
let signer = Signer::from_memory("base58_private_key")?;

// From JSON keypair file path
let signer = Signer::from_memory_file("/path/to/keypair.json")?;

// From byte array string
let signer = Signer::from_memory("[1,2,3,...]")?;
```

### HashiCorp Vault

Itse hallinnoidulle HSM:lle Transit-moottorilla:

```rust
use solana_keychain::Signer;

let signer = Signer::from_vault(
    "https://vault.example.com:8200".to_string(), // Vault address
    "hvs.xxxxx".to_string(),                      // Vault token
    "my-solana-key".to_string(),                  // Key name in Transit
    "base58_public_key".to_string(),              // Expected public key
    None,                                         // Default HTTP timeouts
)?;
```

### AWS KMS

Pilvinatiiviin allekirjoitukseen AWS KMS Ed25519 -avaimilla:

```rust
use solana_keychain::Signer;

let signer = Signer::from_aws_kms(
    "alias/my-solana-key".to_string(),   // KMS key ID or alias
    "base58_public_key".to_string(),     // Expected public key
    Some("us-east-1".to_string()),       // Region (optional)
).await?;
```

### Privy

Upotetun lompakon allekirjoitukseen:

```rust
use solana_keychain::Signer;

let signer = Signer::from_privy(
    "app_id".to_string(),      // Privy app ID
    "app_secret".to_string(),  // Privy app secret
    "wallet_id".to_string(),   // Wallet ID
    None,                      // Default HTTP timeouts
).await?;
```

### Turnkey

Ei-kustodiaaliseen allekirjoitukseen:

```rust
use solana_keychain::Signer;

let signer = Signer::from_turnkey(
    "api_public_key".to_string(),   // Turnkey API public key
    "api_private_key".to_string(),  // Turnkey API private key
    "org_id".to_string(),           // Organization ID
    "private_key_id".to_string(),   // Private key ID in Turnkey
    "base58_public_key".to_string(),// Expected public key
    None,                           // Default HTTP timeouts
)?;
```

### Fireblocks

Institutionaaliseen MPC-allekirjoitukseen:

```rust
use solana_keychain::{Signer, FireblocksSignerConfig};

let config = FireblocksSignerConfig {
    api_key: "api_key".to_string(),
    private_key_pem: "-----BEGIN RSA PRIVATE KEY-----\n...".to_string(),
    vault_account_id: "0".to_string(),
    asset_id: Some("SOL".to_string()), // None defaults to "SOL"; "SOL_TEST" for devnet
    api_base_url: None,
    poll_interval_ms: None,
    max_poll_attempts: None,
    use_program_call: None, // Some(true) signs via PROGRAM_CALL (sign-only, legacy/v0, hot wallet)
    http_client_config: None,
};

let signer = Signer::from_fireblocks(config).await?;
```

### GCP KMS

Pilvinatiiviin allekirjoitukseen GCP Cloud KMS Ed25519-avaimilla:

```rust
use solana_keychain::Signer;

let signer = Signer::from_gcp_kms(
    "projects/my-project/locations/us-east1/keyRings/my-ring/cryptoKeys/my-key/cryptoKeyVersions/1".to_string(),
    "base58_public_key".to_string(),
).await?;
```

### CDP (Coinbase Developer Platform)

Coinbasen hallinnoimaan lompakkoallekirjoitukseen:

```rust
use solana_keychain::{Signer, CdpSignerConfig, CDP_NETWORK_MAINNET};

let signer = Signer::from_cdp(CdpSignerConfig {
    api_key_id: "api_key_id".to_string(),           // CDP API key ID
    api_key_secret: "api_key_secret".to_string(),   // CDP API private key (base64 Ed25519)
    wallet_secret: "wallet_secret".to_string(),     // CDP wallet secret (base64 PKCS#8 DER)
    address: "base58_address".to_string(),          // Solana account address
    network: Some(CDP_NETWORK_MAINNET.to_string()), // Required to sign transactions with address lookup tables
    api_base_url: None,
    http_client_config: None,                       // Default HTTP timeouts
})?;
```

CDP:n `sign_message` hyväksyy vain UTF-8-sisältöjä.

### Crossmint

Crossmint on vain lähettävä: sen API suorittaa jokaisen hyväksytyn transaktion
palvelinpuolella, joten pelkkää allekirjoitusta varten ei ole omaa polkua, ja `sign_message` epäonnistuu. Kutsu
`sign_and_send_transaction`, joka jättää transaktiosi koskemattomaksi ja palauttaa
perille päätyneen transaktion allekirjoituksen. Kyseinen transaktio voi poiketa
omastasi, jos Crossmint sponsoroi gas-maksut.

```rust
use solana_keychain::{Signer, CrossmintSignerConfig};

let config = CrossmintSignerConfig {
    api_key: "api_key".to_string(),
    wallet_locator: "wallet_locator".to_string(),
    signer_secret: None,
    signer: None,
    api_base_url: None,
    poll_interval_ms: None,
    max_poll_attempts: None,
};

let signer = Signer::from_crossmint(config).await?;

let signature = signer
    .as_sending_signer()
    .expect("Crossmint is a sending signer")
    .sign_and_send_transaction(&tx)
    .await?;
```

### Fordefi

Fordefin MPC-säilytyksen allekirjoitusta varten. API-pyynnöt todennetaan ECDSA
P-256 -pyyntöallekirjoituksella. Anna täsmälleen yksi seuraavista: `private_key_pem` tai
`request_signer` (`Arc<dyn FordefiRequestSigner>`, jolla avain pidetään
KMS:ssä tai HSM:ssä).

Fordefi on saatavilla kolmena allekirjoittajatyyppinä, jotka määräytyvät luonnin yhteydessä arvoilla `chain` ja
`push_mode`:

| `chain`    | `push_mode`      | Tyyppi                        | Kyvykkyys          | Toiminta                                                           |
| ---------- | ---------------- | --------------------------- | ------------------- | ------------------------------------------------------------------ |
| `None`     | mikä tahansa              | `FordefiBlackBoxSigner`     | `TransactionSigner` | Allekirjoittaa raakatavut; lähetät itse                                     |
| `Some(..)` | `None` tai `Auto` | `FordefiNativeAutoSigner`   | `SendingSigner`     | Fordefi voi muokata blockhashia ja palkkioita, allekirjoittaa ja lähettää   |
| `Some(..)` | `Manual`         | `FordefiNativeManualSigner` | `ModifyingSigner`   | Fordefi muokkaa ja allekirjoittaa; lähetät palautetun transaktion itse |

Natiivi manuaalitila korvaa transaktiosi Fordefin allekirjoittamalla versiolla.
Jatka siitä, älä koskaan itse rakentamastasi. Sen on suoritettava ennen muita
vaadittuja allekirjoittajia.

```rust
use solana_keychain::{
    Signer, FordefiSignerConfig, FordefiPushMode, SolanaChainUniqueId, FordefiSolanaFee,
    FordefiPriorityLevel,
};

let config = FordefiSignerConfig {
    access_token: "api_token".to_string(),
    vault_id: "vault_uuid".to_string(),
    private_key_pem: Some(std::fs::read_to_string("./secret/private.pem")?),
    request_signer: None,                           // Or Some(Arc::new(your_kms_signer))
    public_key: "base58_public_key".to_string(),    // Solana vault address
    chain: Some(SolanaChainUniqueId::SolanaDevnet), // None for black box mode
    fee: Some(FordefiSolanaFee::Priority {
        priority_level: FordefiPriorityLevel::Medium,
    }),
    push_mode: Some(FordefiPushMode::Auto),         // Manual: sign without broadcasting
    api_base_url: None,       // Default: https://api.fordefi.com
    poll_interval_ms: None,   // Default: 2000
    max_poll_attempts: None,  // Default: 50
    http_client_config: None, // Default HTTP timeouts
};

let signer = Signer::from_fordefi(config).await?;
```

### Ledger

Laitteistolompakon allekirjoitusta varten USB-HID:n kautta (vain Rust). Vaatii `ledger`-
ominaisuuden, avatun laitteen, jossa on Solana-sovellus, ja Linuxissa Ledgerin udev-
säännöt. Ledger ei kuulu nykyiseen auditointiin; katso
[auditoinnin tila](https://github.com/solana-foundation/solana-keychain/blob/main/audits/AUDIT_STATUS.md).

```rust
use solana_keychain::{LedgerConfig, Signer};

let signer = Signer::from_ledger(LedgerConfig {
    confirm_pubkey_on_device: true,
    ..LedgerConfig::default()
})
.await?;
```

`sign_message` allekirjoittaa ketjun ulkopuolisen kirjekuoren, joka kääri sisältösi sisäänsä, ei raakatavuja;
rakenna se uudelleen funktiolla `solana_keychain::ledger::ledger_offchain_envelope`
tarkistusta varten. Aseta `auto_open_app: false` valvomatonta käyttöä varten. Laitteella hylätty
kehote palauttaa `SignerError::UserRejected`.

## Yhdistetty Signer Enum

Käytä `Signer`-enumia valitaksesi backendit ajonaikaisesti:

```rust
use solana_keychain::{Signer, SolanaSigner, SignerError};

async fn get_signer(backend: &str) -> Result<Signer, SignerError> {
    match backend {
        "memory" => Signer::from_memory("base58_key"),
        "vault" => Signer::from_vault(/* ... */),
        "kms" => Signer::from_aws_kms(/* ... */).await,
        _ => Err(SignerError::ConfigError("Unknown backend".into())),
    }
}

// Use it generically
let signer = get_signer("kms").await?;
let pubkey = signer.pubkey();
```

`Signer` toteuttaa vain `SolanaSigner`-traitin. Pääset kyvykkyyteen käsiksi metodeilla
`as_transaction_signer()`, `as_modifying_signer()` tai `as_sending_signer()`,
jotka palauttavat `None`, jos taustajärjestelmältä puuttuu kyseinen muoto:

```rust
if let Some(transaction_signer) = signer.as_transaction_signer() {
    let result = transaction_signer.sign_transaction(&mut tx).await?;
}
```

Tai anna `sign_and_send`-funktion reitittää taustajärjestelmän mukaan. Kirjasto ei sisällä RPC-asiakasta, joten
lähetyksen toteutat itse; lähettävällä taustajärjestelmällä sulkeumaa ei kutsuta koskaan:

```rust
let signature = signer
    .sign_and_send(&mut tx, |encoded| async move { broadcast(encoded).await })
    .await?;
```

## Virheidenkäsittely

`SignerError::BroadcastUnconfirmed { provider_tx_id, idempotency_key, transaction_signature, .. }`
(Crossmintilta, Fordefi native autolta tai epäonnistuneesta `sign_and_send`-sulkeumasta)
tarkoittaa, että transaktio on voinut päätyä perille. Älä yritä uudelleen sokkona: täsmäytä ensin
`provider_tx_id` tai `transaction_signature`, tai lähetä uudelleen vain
tavu tavulta identtinen transaktio. Tyhjentävät `match`-lausekkeet `SignerError`-tyypille tarvitsevat tämän haaran.
Katso
[tietoturvamalli](https://github.com/solana-foundation/solana-keychain/blob/main/docs/SECURITY_MODEL.md)
siitä, mitä kukin allekirjoitustapa takaa.
