Poistaa aiemmin sallitun mintin instanssista, estäen uudet talletukset kyseiselle
mintille. Olemassa olevat talletukset eivät muutu.

## Tilit

| Tili                          | Kirjoitettava | Allekirjoittaja | Kuvaus                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | Maksun maksaja                                    |
| `admin`                          |          | ✓      | Instanssin ylläpitäjä                               |
| `instance`                       |          |        | Instanssin PDA                                 |
| `mint`                           |          |        | Estettävä SPL-token-mint                      |
| `allowed_mint`                   | ✓        |        | AllowedMint PDA (suljetaan tällä ohjeella) |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | Tapahtumavaltuutuksen PDA                          |
| `private_channel_escrow_program` |          |        | Escrow-ohjelma                               |

Tämä ohje ei ota parametreja.

## Tärkeät huomiot

- Sulkee `allowed_mint` PDA:n: uudet `Deposit`-kutsut tälle mintille epäonnistuvat
  virheellä `InvalidAllowedMint`
- Olemassa olevat kanavan saldot tälle mintille eivät muutu
- Lähettää tapahtuman `EmitEvent` CPI:n kautta
