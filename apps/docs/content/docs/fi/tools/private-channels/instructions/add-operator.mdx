---
title: AddOperator
description: Valmistelee uuden operaattorin luomalla heidän Operator PDA:nsa
---

Valmistelee uuden operaattorin luomalla heidän `Operator` PDA:nsa. Tämän kutsun jälkeen
`operator`-lompakko voi kutsua `ReleaseFunds`- ja `ResetSmtRoot`-toimintoja.

## Tilit

| Tili                          | Kirjoitettava | Allekirjoittaja | Kuvaus                                                         |
| -------------------------------- | -------- | ------ | ------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Maksun maksaja                                                           |
| `admin`                          |          | ✓      | Instanssin ylläpitäjä                                                      |
| `instance`                       |          |        | Instanssin PDA                                                        |
| `operator`                       |          |        | Valmisteltava operaattorilompakko                                        |
| `operator_pda`                   | ✓        |        | Operaattorin PDA – johdetaan automaattisesti kohteesta `["operator", instance, operator]` |
| `system_program`                 |          |        | System Program                                                      |
| `event_authority`                |          |        | Tapahtumavaltuuden PDA                                                 |
| `private_channel_escrow_program` |          |        | Escrow-ohjelma                                                      |

## Parametrit

| Parametri | Tyyppi | Kuvaus                                                                               |
| --------- | ---- | ----------------------------------------------------------------------------------------- |
| `bump`    | `u8` | Bump seed `operator_pda`:lle. Valinnainen: `Async`-asiakas johtaa sen automaattisesti, jos sitä ei anneta |

> IDL sisältää `discriminator: u8` -argumentin (arvo `3`), joka asetetaan automaattisesti
> generoidun asiakkaan toimesta eikä sitä tule antaa manuaalisesti.

## Tärkeät huomiot

- Käytä `getAddOperatorInstructionAsync`-funktiota; se johtaa automaattisesti `bump`- ja
  `operator_pda`-arvot, kun niitä ei ole annettu. Synkroninen
  `getAddOperatorInstruction`-variantti on myös saatavilla, jos olet jo laskenut `bump`-arvon
  itse
- Tämän kutsun jälkeen `operator`-lompakko voi kutsua `ReleaseFunds`- ja
  `ResetSmtRoot`-toimintoja
- Lähettää tapahtuman `EmitEvent` CPI:n kautta
