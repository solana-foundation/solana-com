---
title: Nollaa SMT-juuri
description:
  Kiertää Sparse Merkle Tree -rakenteen nollaten nostojuuren uutta puuepookkia varten
---

Vain operaattorille tarkoitettu ohje, joka kiertää Sparse Merkle Tree -rakenteen kasvattamalla
`Instance.current_tree_index`-arvoa ja nollaamalla nostojuuren, mahdollistaen uuden
65 536 noston epookin.

<Callout type="info">
  Escrow-ohjelma siirtyy tästä Sparse Merkle Tree -suunnittelusta
  ketjussa olevaan nonce-bittikartastoon (seurataan ylävirrassa), jolloin tästä ohjeesta tulee
  `RotateBitmap`. Tämä sivu on ajan tasalla nykyisen escrow-ohjelman osalta ja
  se päivitetään, kun kyseinen muutos otetaan käyttöön.
</Callout>

## Tilit

| Tili                          | Kirjoitettava | Allekirjoittaja | Kuvaus                                            |
| -------------------------------- | -------- | ------ | ------------------------------------------------------ |
| `payer`                          | ✓        | ✓      | Maksun maksaja                                              |
| `operator`                       |          | ✓      | Operaattorin allekirjoittaja                                        |
| `instance`                       | ✓        |        | Escrow-instanssin PDA (`current_tree_index` kasvatettu) |
| `operator_pda`                   |          |        | Operaattorin PDA, joka todistaa allekirjoittajan olevan käyttöönotettu         |
| `event_authority`                |          |        | Tapahtuman authority-PDA `EmitEvent`-CPI:tä varten                |
| `private_channel_escrow_program` |          |        | Escrow-ohjelma (viittaus itseen CPI:tä varten)                |

## Parametrit

| Parametri                     | Tyyppi  | Kuvaus                                                              |
| ----------------------------- | ----- | ------------------------------------------------------------------------ |
| `expected_current_tree_index` | `u64` | Toistohyökkäyssuoja; täytyy vastata `Instance.current_tree_index`-arvoa tai kutsu epäonnistuu |

## Paluuarvo

Palauttaa `TransactionBuilder`-olion, jota voidaan käyttää transaktion rakentamiseen ja lähettämiseen.

## Esimerkki

```typescript
import { getResetSmtRootInstruction } from "../private-channel-escrow-program/clients/typescript/src/generated";

const resetIx = getResetSmtRootInstruction({
  payer: operatorPayerSigner,
  operator: operatorSigner,
  instance: instancePda,
  operatorPda: operatorPdaAddress,
  eventAuthority: eventAuthorityPda,
  privateChannelEscrowProgram: ESCROW_PROGRAM_ID,
  expectedCurrentTreeIndex: currentTreeIndex // u64
});
```

## Tärkeät huomiot

- Vain operaattorille: vaatii kelvollisen `operator_pda`-arvon; heittää `InvalidOperatorPda`-virheen
  muussa tapauksessa
- `expected_current_tree_index`-arvon täytyy vastata `Instance.current_tree_index`-arvoa kutsuhetkellä;
  vanhentunut arvo heittää `UnexpectedTreeIndex`-virheen, suojaten jo suoritetun
  nollauksen toistamiselta
- Kasvattaa `Instance.current_tree_index`-arvoa; edellisessä puuepookissa kelvolliset noncet
  mitätöidään kierron jälkeen
- `operator-private-channel`-palvelu kutsuu tätä automaattisesti, kun
  `transaction_nonce % 65536 == 0` (ja `nonce > 0`), merkiten uuden epookin alkua;
  sitä ei pitäisi tarvita kutsua manuaalisesti normaalin toiminnan aikana
- Kierron jälkeen nostojuuri nollautuu tyhjään puuhun, joten uudet
  nostot alkavat tuoreesta SMT:stä
- Lähettää tapahtuman `EmitEvent`-CPI:n kautta
