Tämä osio on ketjunsisäisten ohjeiden viiteopas. Useimmat kehittäjät kutsuvat näitä
ohjeita generoitujen TypeScript-asiakaskirjastojen kautta; tarvitset tätä vain, jos
rakennat operaattorityökaluja, kirjoitat mukautettuja integraatioita tai debuggaat
ohjetason virheitä.

**Escrow-ohjelma** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) – hallinnoi
talletuksia, operaattorien provisiointia ja Mainnet-selvitystä:

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) –
  alusta escrow-instanssin PDA
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) – lisää
  SPL-token mint sallittujen listalle
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) – poista
  mint sallittujen listalta
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) –
  provisioi operaattori
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) –
  peruuta operaattorin oikeudet
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) –
  siirrä järjestelmänvalvojan oikeudet
- [Deposit](/docs/tools/private-channels/instructions/deposit) – siirrä SPL-tokenit
  escrow'hun
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) –
  operaattori selvittää noston Mainnetiin
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) –
  operaattori kierrättää Sparse Merkle Tree -juuren

**Withdraw-ohjelma** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) – toimii
yksityiskanavaverkossa:

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) –
  polta kanavan puolen saldo noston käynnistämiseksi

## Virhekoodit

**Escrow-ohjelma – `PrivateChannelEscrowProgramError`**

| Koodi                                         | Viesti                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | Virheellinen tapahtuma-auktoriteetti annettu                 |
| `InvalidAta`                                 | Virheellinen ATA annettu                             |
| `InvalidMint`                                | Virheellinen mint annettu                            |
| `InvalidInstanceId`                          | Instanssin tunnus on virheellinen tai ei noudata sääntöjä    |
| `InvalidInstance`                            | Virheellinen instanssi annettu                        |
| `InvalidAdmin`                               | Virheellinen järjestelmänvalvoja annettu                           |
| `TransferHookNotAllowed`                     | Transfer hook -laajennus ei ole sallittu              |
| `InvalidOperatorPda`                         | Virheellinen operaattorin PDA annettu                    |
| `InvalidTokenAccount`                        | Virheellinen token account annettu                   |
| `InvalidEscrowBalance`                       | Virheellinen escrow-saldo                           |
| `InvalidAllowedMint`                         | Virheellinen sallittu mint                             |
| `InvalidSmtProof`                            | Virheellinen SMT-todiste annettu                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | Virheellinen transaktiononce nykyiselle puuindeksille |
| `UnexpectedTreeIndex`                        | Odottamaton nykyinen puuindeksi SMT-juuren nollauksessa |

**Withdraw-ohjelma – `PrivateChannelWithdrawProgramError`**

| Koodi          | Viesti                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | Virheellinen mint annettu                       |
| `ZeroAmount`  | Nostettavan summan on oltava suurempi kuin nolla |
