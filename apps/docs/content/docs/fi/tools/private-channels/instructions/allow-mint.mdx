title: AllowMint

  Sallii SPL-tokenin mintin instanssissa ja luo kyseisen mintin escrow-ATA:n
---

Sallii SPL-tokenin mintin instanssissa ja luo escrow'n associated
token account kyseiselle mintille. Talletukset tälle mintille tulevat mahdollisiksi tämän
kutsun jälkeen.

## Tilit

| Tili                          | Kirjoitettava | Allekirjoittaja | Kuvaus                                                                   |
| -------------------------------- | -------- | ------ | ----------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Maksun maksaja                                                                     |
| `admin`                          |          | ✓      | Instanssin ylläpitäjä                                                                |
| `instance`                       |          |        | Instanssin PDA                                                                  |
| `mint`                           |          |        | Sallittava SPL-tokenin mint                                                       |
| `allowed_mint`                   | ✓        |        | AllowedMint PDA (luodaan tällä ohjeella)                                 |
| `instance_ata`                   | ✓        |        | Escrow'n associated token account tälle mintille (luodaan tällä ohjeella) |
| `system_program`                 |          |        | System Program                                                                |
| `token_program`                  |          |        | SPL Token Program                                                             |
| `associated_token_program`       |          |        | Associated Token Program                                                      |
| `event_authority`                |          |        | Tapahtumavaltuuden PDA                                                           |
| `private_channel_escrow_program` |          |        | Escrow-ohjelma                                                                |

## Parametrit

| Parametri | Tyyppi | Kuvaus                                                                                   |
| --------- | ---- | --------------------------------------------------------------------------------------------- |
| `bump`    | `u8` | Bump seed `allowed_mint`-PDA:lle. Valinnainen: `Async`-asiakas johtaa sen automaattisesti, jos se jätetään pois |

> IDL sisältää `discriminator: u8` -argumentin (arvo `1`), joka asetetaan automaattisesti
> generoidun asiakkaan toimesta eikä sitä tule antaa manuaalisesti.

## Tärkeät huomiot

- Käytä `getAllowMintInstructionAsync`-funktiota; se johtaa automaattisesti `bump`-, `allowed_mint`-
  ja `instance_ata`-arvot, kun niitä ei ole annettu. Anna oma `bump` vain, jos
  olet jo laskenut sen käyttäen
  `Pubkey::find_program_address(&[b"allowed_mint", instance_pda, mint], &PROGRAM_ID)`
- Luo myös `instance_ata`:n, joka on escrow'n ATA tälle mintille
- Mintit, joilla on transfer hook -laajennus, on nimenomaisesti estetty: tällaisen mintin
  salliminen aiheuttaa `TransferHookNotAllowed`-virheen
- Lähettää tapahtuman `EmitEvent`-CPI:n kautta
