Siirtää järjestelmänvalvojan oikeudet uuteen lompakkoon.

## Tilit

| Tili                          | Kirjoitettava | Allekirjoittaja | Kuvaus                        |
| -------------------------------- | -------- | ------ | ---------------------------------- |
| `payer`                          | ✓        | ✓      | Maksun maksaja                          |
| `current_admin`                  |          | ✓      | Nykyinen järjestelmänvalvoja (on allekirjoitettava)          |
| `instance`                       | ✓        |        | Instanssi PDA (järjestelmänvalvojakenttä päivitetty) |
| `new_admin`                      |          | ✓      | Lompakko, joka vastaanottaa järjestelmänvalvojan oikeudet     |
| `event_authority`                |          |        | Tapahtumavaltuuden PDA                |
| `private_channel_escrow_program` |          |        | Escrow-ohjelma                     |

Tämä käsky ei ota parametreja.

## Tärkeät huomiot

- **Peruuttamaton yhdessä vaiheessa**: nykyinen järjestelmänvalvoja ei voi palauttaa roolia
  ilman, että uusi järjestelmänvalvoja kutsuu `SetNewAdmin`-komentoa uudelleen
- Tarkista kohdeosoite ennen kutsumista; peruuttaminen ei ole mahdollista
- Lähettää tapahtuman `EmitEvent` CPI:n kautta
