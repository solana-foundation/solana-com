---
title: RemoveOperator
description: Peruuttaa operaattorin sulkemalla heidän Operator PDA:nsa
---

Peruuttaa operaattorin sulkemalla heidän `Operator` PDA:nsa. Peruutettu lompakko ei enää
voi kutsua `ReleaseFunds`- tai `ResetSmtRoot`-toimintoja.

## Tilit

| Tili                          | Kirjoitettava | Allekirjoittaja | Kuvaus                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | Maksun maksaja                                 |
| `admin`                          |          | ✓      | Instanssin ylläpitäjä                            |
| `instance`                       |          |        | Instanssin PDA                              |
| `operator`                       |          |        | Peruutettava operaattorin lompakko                 |
| `operator_pda`                   | ✓        |        | Operaattorin PDA (suljetaan tällä ohjeella) |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | Tapahtuman valtuuden PDA                       |
| `private_channel_escrow_program` |          |        | Escrow-ohjelma                            |

Tämä ohje ei ota parametreja.

## Tärkeät huomiot

- Sulkee `operator_pda`:n; peruutettu lompakko ei enää voi kutsua
  `ReleaseFunds`- tai `ResetSmtRoot`-toimintoja
- Kaikki käynnissä olevat operaattorin transaktiot epäonnistuvat `InvalidOperatorPda`-virheellä
  tämän kutsun jälkeen
- Lähettää tapahtuman `EmitEvent` CPI:n kautta
