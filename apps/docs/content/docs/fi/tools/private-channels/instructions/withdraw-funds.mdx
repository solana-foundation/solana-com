---
title: Nosta varoja
description:
  Polttaa kanavan puoleisia tokeneita käynnistääkseen noston takaisin Solana mainnet -escrow'hun
---

Polttaa käyttäjän kanavan puoleisen tokenisaldon Withdraw Program -ohjelmassa merkitsemään
odottavan noston; operaattorin täytyy tämän jälkeen kutsua `ReleaseFunds`-funktiota
Escrow Program -ohjelmassa selvityksen viimeistelemiseksi.

## Tilit

| Tili                    | Kirjoitettava | Allekirjoittaja | Kuvaus                                |
| -------------------------- | -------- | ------ | ------------------------------------------ |
| `user`                     |          | ✓      | Noston käynnistävä tokenin omistaja      |
| `mint`                     | ✓        |        | SPL-tokenin mint (poltettava)            |
| `token_account`            | ✓        |        | Käyttäjän kanavan puoleinen token account (lähde) |
| `token_program`            |          |        | SPL Token Program                          |
| `associated_token_program` |          |        | Associated Token Program                   |

## Parametrit

| Parametri     | Tyyppi             | Kuvaus                                                          |
| ------------- | ---------------- | -------------------------------------------------------------------- |
| `amount`      | `u64`            | Nostettavien tokenien määrä tokenin pienimmässä yksikössä           |
| `destination` | `Option<Pubkey>` | Kohdelompakko Mainnetissä; jos `None`, käytetään oletuksena allekirjoittajan lompakkoa |

## Palautusarvo

Palauttaa `TransactionBuilder`-olion, jota voidaan käyttää transaktion rakentamiseen ja lähettämiseen.

## Esimerkki

```typescript
import { getWithdrawFundsInstruction } from "../private-channel-withdraw-program/clients/typescript/src/generated";

const withdrawIx = getWithdrawFundsInstruction({
  user: userSigner,
  mint: mintAddress,
  tokenAccount: channelTokenAccount,
  tokenProgram: TOKEN_PROGRAM_ID,
  associatedTokenProgram: ASSOCIATED_TOKEN_PROGRAM_ID,
  amount: 1_000_000n,
  destination: null // null = release to signer's Mainnet wallet
});
```

## Tärkeät huomiot

- Tämä instruktio on **Withdraw Program** -ohjelmassa
  (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi` devnet), ei Escrow
  Program -ohjelmassa
- Tokenien polttaminen kanavan puolella **ei** automaattisesti vapauta varoja
  Mainnetissä; operaattorin täytyy tämän jälkeen kutsua `ReleaseFunds`-funktiota Escrow
  Program -ohjelmassa käyttäen voimassa olevaa SMT-poissulkemistodistetta
- `ZeroAmount`-virhe heitetään, jos `amount` on 0
- Jos `destination` on `None`, operaattorin `ReleaseFunds`-kutsu vapauttaa
  varat allekirjoittajan lompakkoon

Täydellinen virhekoodeista molemmille ohjelmille löytyy täältä:
[Instruktiot -> Virhekoodit](/docs/tools/private-channels/instructions#error-codes).
