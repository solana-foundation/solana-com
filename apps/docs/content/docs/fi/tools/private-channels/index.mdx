<Callout type="warning">
  Private Channelsia ei ole tietoturva-auditoitu, eikä sitä suositella
  tuotantokäyttöön oikeilla varoilla ilman perusteellista tietoturvatarkastusta.
</Callout>

**Private Channels on yritystason kerros internet-pääomamarkkinoille
Solanassa.** Se tarjoaa konfiguroitavan sovelluskerroksen yksityisille, välittömille ja maksuttomille
siirroille maksukanavien sisällä: käyttäjät tallettavat SPL-tokeneita ketjussa olevaan
eskrow-ohjelmaan, tekevät transaktioita ketjun ulkopuolella yhdyskäytävän kautta ja selvittävät
Mainnetiin takaisin Sparse Merkle Tree -todisteen avulla, antaen sovellusten kehittäjille välittömät, maksuttomat ja yksityiset
siirrot poistumatta Solana-ekosysteemistä.

### Miksi Private Channels?

- **Välittömät siirrot**: ketjun ulkopuolinen suorituskyky ylittää Solanan natiivi-TPS:n;
  siirrot vahvistuvat, kun sekvensseri käsittelee ne, ei silloin kun lohko vahvistuu
- **Ei siirtokohtaisia maksuja**: ei kaasukustannuksia yksittäisistä kanavasiirroista; käyttäjät
  maksavat vain ketjussa tapahtuvista talletuksista ja nostoista
- **Yksityisyys**: kanavaosallistujien väliset siirrot eivät tallennu Solana
  Mainnetiin
- **Rajattu pääsy**: RBAC JWT-autentikoinnilla antaa sinulle hallinnan siitä, kuka voi
  lähettää ja vastaanottaa
- **Mainnet-selvitys**: varat ovat aina lunastettavissa Solanaan Sparse
  Merkle Tree -poissulkutodisteen avulla, jonka eskrow-ohjelma valvoo ketjussa

Katso **[Yleiskatsaus](/docs/tools/private-channels/overview)** koko
arkkitehtuurin, tietovirtakaavion ja tietoturvamallin osalta.

## Pika-aloitus

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n, // 1 USDC
  recipient: null
});
// send via your preferred Solana client
```

TypeScript-asiakasohjelmat generoidaan IDL:stä; katso Asennus. Token-2022
-minttejä varten anna `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS` eksplisiittisesti, koska
se käyttää oletuksena tavallista SPL Token Program -ohjelmaa.

## Käyttötapaukset

- **Institutionaaliset kahdenvälisedot maksut** – pankit ja instituutiot, jotka tarvitsevat
  suuren volyymin yksityisiä USDC-virtoja ilman, että jokainen siirto näkyy ketjussa
- **Tiheäfrekvenssisiset sovelluskerroksen siirrot** – pelit, kanta-asiakasohjelmat ja kuluttajasovellukset,
  jotka tarvitsevat alle sekunnin, maksuttomia siirtoja skaalassa yli natiivin Solana-TPS:n
- **Yksityisyyttä suojaavat token-virrat** – kaikki käyttötapaukset, joissa vastapuolen ja
  summan yksityisyys on tuotevaatimus

**[Milloin käyttää natiiveja SPL-siirtoja sen sijaan](/docs/tools/private-channels/concepts/channels#when-to-use-private-channels)**
