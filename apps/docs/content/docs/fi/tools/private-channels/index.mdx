**Private Channels on yritystason sovelluskerros internet-pääomamarkkinoille
Solanassa.** Se tarjoaa konfiguroitavan sovelluskerroksen yksityisiä, välittömiä ja
maksuttomia siirtoja varten maksukanavien sisällä: käyttäjät tallettavat SPL-tokeneita
on-chain-escrow-ohjelmaan, tekevät transaktioita off-chain gatewayn kautta ja selvittävät
takaisin Mainnetiin Sparse Merkle Tree -todisteen avulla – antaen sovelluskehittäjille
välittömät, maksuttomat ja yksityiset siirrot poistumatta Solana-ekosysteemistä.

### Miksi Private Channels?

- **Välittömät siirrot**: off-chain-suorituskyky ylittää Solanan natiivin TPS:n;
  siirrot vahvistuvat, kun sekvenseri käsittelee ne, ei kun lohko vahvistuu
- **Ei siirtokohtaisia maksuja**: ei kaasukustannuksia yksittäisistä kanavasiirroista;
  käyttäjät maksavat vain on-chain-talletuksista ja -nostoista
- **Yksityisyys**: kanavaosallistujien väliset siirrot eivät tallennu Solana
  Mainnetiin
- **Rajoitettu pääsy**: RBAC JWT-autentikoinnilla antaa sinulle hallinnan siitä,
  kuka voi lähettää ja vastaanottaa
- **Mainnet-selvitys**: varat ovat aina lunastettavissa Solanaan Sparse
  Merkle Tree -poissulkemistodisteen avulla, jonka escrow-ohjelma valvoo on-chain

Katso **[Yleiskatsaus](/docs/tools/private-channels/overview)** saadaksesi koko
arkkitehtuurin, datavirran kaavion ja tietoturvamallin.

## Pikaopas

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n, // 1 USDC
  recipient: null
});
// send via your preferred Solana client
```

TypeScript-asiakasohjelmat generoidaan IDL:stä; katso Asennus. Token-2022
-minteille välitä `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS` eksplisiittisesti, sillä
oletusarvona käytetään tavanomaista SPL Token Program -ohjelmaa.

## Käyttötapaukset

- **Institutionaaliset kahdenkeskiset maksut** – pankit ja laitokset, jotka tarvitsevat
  suuren volyymin yksityisiä USDC-virtoja ilman, että jokainen siirto näkyy on-chain
- **Taajuuskaupan sovelluskerroksen siirrot** – pelit, kanta-asiakasohjelmat ja
  kuluttajasovellukset, jotka tarvitsevat alle sekunnin maksuttomia siirtoja
  suuressa mittakaavassa Solanan natiivin TPS:n ylittämiseksi
- **Yksityisyyttä suojaavat token-virrat** – kaikki käyttötapaukset, joissa
  vastapuolen ja summan yksityisyys on tuotevaatimus

**[Milloin käyttää natiiveja SPL-siirtoja sen sijaan](/docs/tools/private-channels/concepts/channels#when-to-use-private-channels)**
