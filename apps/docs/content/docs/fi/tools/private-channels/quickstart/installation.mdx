## Edellytykset

- Rust 1.91+
- Solana CLI 3.1.13 (Agave):
  `sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.13/install)"`
- Node.js 24.7.0+
- pnpm 10.15.1+: `npm install -g pnpm@10.15.1`

## Kloonaa repositorio

```bash
git clone https://github.com/solana-foundation/solana-private-channels.git
cd solana-private-channels
```

## Luo TypeScript-asiakasohjelmat

TypeScript-asiakasohjelmia **ei** julkaista npm:ään. Ne on luotava
IDL:stä Codaman avulla.

```bash
# Escrow program client
cd private-channel-escrow-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..

# Withdraw program client
cd private-channel-withdraw-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..
```

Luodut asiakasohjelmat sijoitetaan hakemistoon:

- `private-channel-escrow-program/clients/typescript/src/generated/`
- `private-channel-withdraw-program/clients/typescript/src/generated/`

Tuo sovelluksessasi näistä paikallisista poluista; npm:ssä ei ole
`@private-channels/client`-pakettia. Tämän osion koodiesimerkit käyttävät
suhteellista polkua (`../private-channel-escrow-program/...`), joka olettaa koodisi
sijaitsevat kloonatun repositorion rinnalla; muuta se vastaamaan todellista
tuontipaikkaasi omassa projektissasi.
