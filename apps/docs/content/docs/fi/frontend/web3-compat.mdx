Jos siirryt käyttämään `@solana/web3.js`-kirjastoa (legacy), `@solana/wallet-adapter-*`-paketteja
tai aiempia framework-kit-paketteja (`@solana/client`, `@solana/react-hooks`,
`@solana/web3-compat`), suosittelemme siirtymistä `@solana/kit`-liitännäisiin tai
`@solana/web3.js` v3:een (tai uudempaan).

Tämä sivu yhdistää jo tuntemasi käsitteet niiden Kit-vastineisiin.

## Käsitteiden vastaavuudet

| web3.js (legacy) / wallet-adapter      | Kit                                                                  |
| -------------------------------------- | -------------------------------------------------------------------- |
| `new Connection(url)`                  | `createSolanaRpc(url)`, tai `.use(solanaRpc({ rpcUrl }))` asiakkaalla |
| `PublicKey`                            | `Address` — muunna merkkijono `address("...")`:lla                    |
| `Keypair`                              | `generateKeyPairSigner()` tai `@solana/kit-plugin-signer`-laajennukset |
| `SystemProgram.transfer(...)`          | `getTransferSolInstruction(...)` paketista `@solana-program/system`       |
| `LAMPORTS_PER_SOL`-laskenta                | `lamports(...)` paketista `@solana/kit`                                   |
| `Transaction` / `VersionedTransaction` | Tapahtumaviestit, jotka transaktiosuunnittelija rakentaa ja pakkaa     |
| `sendAndConfirmTransaction(...)`       | `client.sendTransaction([...])` (suunnittelija allekirjoittaa, lähettää ja vahvistaa) |
| `@solana/wallet-adapter-*`             | `@solana/kit-plugin-wallet` + Wallet Standard -löytäminen              |

web3.js v3 säilyttää yllä olevat luokkapohjaiset nimet — `Connection`, `Keypair`,
`Transaction`, `PublicKey` — ohuina kääreinä Kitin sisäisten osien päällä, joten Kit-
sarake kuvaa myös sen, mitä nämä luokat tekevät v3:ssa konepellin alla.

## Tulitko web3.js:stä?

Jos ylläpidät laajaa `@solana/web3.js`-koodikantaa (legacy) etkä voi käytännössä kirjoittaa sitä kokonaan uudelleen
Kitille, web3.js v3 toimii siltana. Asenna se komennolla
`@solana/web3.js@3`. Se rakentaa perinteisen luokkapohjaisen API:n — `Connection`,
`Keypair`, `Transaction`, `PublicKey` — `@solana/kit`-kirjaston sisäisten osien päälle.
Koska se perustuu Kitiin, yhteentoimivuus on saumatonta: `PublicKey` on ensisijainen osoitetyyppi,
ja sen `.toBase58()` palauttaa Kitin brändätyn `Address`-merkkijonon, ja v3:n
`Keypair` toteuttaa Kitin `KeyPairSigner`-rajapinnan, joten voit välittää sen suoraan Kitin
API-rajapinnoille, liitännäisille ja Codama-generoiduille asiakkaille.

<Callout type="warn" title="v1-transaktiot ja web3.js (legacy)">
  Jos lähetät v1-transaktioita web3.js:llä, sinun on käytettävä versiota v3 tai uudempaa.
</Callout>

Itse migraatiosta löydät lisätietoja virallisesta
[web3.js v1 → v3 -migraatio-oppaasta](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md).

## Lompakot

Kit ei käytä wallet-adapteria. `@solana/kit-plugin-wallet` tunnistaa Wallet
Standard -lompakot ja tarjoaa ne käytettäväksi `client.wallet`:n ja
[React-koukkujen](/docs/frontend/react-hooks) kautta. Modernit lompakot
(Phantom, Solflare, Backpack ja muut) ilmoittavat itsensä Wallet Standardin
kautta, joten erillistä lompakohtaista adapteripaketia ei tarvita.

Voit myös käyttää valmiita työkaluja, kuten
[@solana/connector](https://www.npmjs.com/package/@solana/connector), joka
hyödyntää Kitin primitiivejä suoraan lompakoihin yhdistämiseen.

<Callout type="info" title="Käytätkö vielä wallet-adapteria?">
  Jos ylläpidät `@solana/wallet-adapter-*`:lle rakennettua sovellusta etkä ole
  valmis siirtymään uuteen,
  [wallet-adapter-repositorio](https://github.com/anza-xyz/wallet-adapter) on
  edelleen kyseisen pinon viitteellinen toteutus. Kaikkea uutta varten
  suosittelemme Kitin lompakon liitännäistä.
</Callout>
