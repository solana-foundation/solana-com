## Solana MCP:n käyttäminen

Tehokkain tapa hyödyntää tekoälyä Solana-kehityksessä on
[Solana Developer MCP](https://mcp.solana.com/) (Model Context Protocol) -integraation kautta. Tämä
integraatio tuo erikoistuneen Solana-osaamisen suoraan IDE:hen, antaen
agenteillesi pääsyn ajantasaiseen Solana-dokumentaatioon ja tehden kehityksestä
nopeampaa ja tehokkaampaa.

## Mikä on Solana MCP?

Solana MCP on erikoistunut tekoälyavustaja, joka integroituu suoraan
tekoälyä tukeviin IDE-ympäristöihin, kuten Cursoriin ja Windsurfiin. Kun esität Solanaan liittyviä
kysymyksiä, se kyselee automaattisesti MCP-palvelimelta tarjotakseen tarkkoja,
ajantasaisia tietoja seuraavista lähteistä:

- [Solana-dokumentaatio](/docs)
- [Anchor Framework -dokumentaatio](https://www.anchor-lang.com/docs)
- Solana
  [-ohjelmaesimerkit](https://github.com/solana-developers/program-examples)
- [Solana Stack Exchange](https://solana.stackexchange.com/) -kysymykset ja
  vastaukset

## Esimerkkikäyttötapauksia

Voit käyttää MCP:tä:

- Solana-käsitteiden selvittämiseen
- Ohjelmavirheiden debuggaamiseen
- Parhaiden käytäntöjen suositusten saamiseen
- Oppimiseen asiantuntijaesimerkkien avulla
- Nopeampaan kehitykseen asiantuntija-avun tuella

## Solana MCP:n käyttöönotto

Löydät yksityiskohtaisen asennusoppaan ja aloitusohjeistuksen
[Solana MCP -verkkosivustolta](https://mcp.solana.com/).

## Haluatko mieluummin käyttää taitoa?

Jos haluat mieluummin käyttää taitoa, asenna virallinen Solana-taito komennolla:

```bash
npx skills add https://github.com/solana-foundation/solana-dev-skill
```

Selaa lisää uudelleenkäytettäviä työnkulkuja [Solana Agent Skills -kirjastossa](/skills).
