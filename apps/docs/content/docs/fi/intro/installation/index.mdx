Määritä paikallinen Solana-kehitysympäristö automaattisella asennusohjelmalla. Se
asentaa Rustin, Solana CLI:n, Anchor CLI:n, Surfpool CLI:n, Node.js:n ja Yarnin
macOS-, Linux- tai Windows-järjestelmään WSL:n kautta.

<Callout type="info" title="Windows edellyttää WSL:ää">
  Suorita Windows PowerShellissä komento `wsl --install`, käynnistä Windows tarvittaessa uudelleen ja suorita sitten
  alla olevat asennuskomennot Ubuntu-päätteessä. Katso täydelliset
  WSL-asetukset [manuaalisesta asennusoppaasta](/docs/intro/installation/dependencies).
</Callout>

## Pikaasennus

1. Suorita asennusohjelma macOS-, Linux- tai WSL-päätteessä:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
```

Voit
[tarkistaa asennusohjelman lähdekoodin](https://github.com/solana-developers/solana-install/blob/main/install.sh)
ennen sen suorittamista. Asennusohjelma tunnistaa tuetut Linuxin paketinhallinnat ja
asentaa niiden järjestelmäriippuvuudet automaattisesti.

2. Käynnistä pääte uudelleen, jotta uudet komennot ovat käytettävissä `PATH`-ympäristömuuttujassa.

3. Varmista jokainen työkalu:

```terminal
$ rustc --version
$ solana --version
$ anchor --version
$ surfpool --version
$ node --version
$ yarn --version
```

Onnistunut asennus palauttaa tulosteen tässä muodossa (versionumerot muuttuvat, kun
työkaluja julkaistaan):

```txt title="Example output"
Installed Versions:
Rust: rustc x.y.z (...)
Solana CLI: solana-cli x.y.z (..., client:Agave)
Anchor CLI: anchor-cli x.y.z
Surfpool CLI: surfpool x.y.z
Node.js: vx.y.z
Yarn: x.y.z
```

<Callout type="warn" title="Asennus epäonnistui tai komento puuttuu">
  Seuraa [manuaalista asennusopasta](/docs/intro/installation/dependencies)
  asentaaksesi tai vianmääritykseen kunkin riippuvuuden erikseen.
</Callout>
