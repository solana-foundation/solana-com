`spl-token`-komentorivikäyttöliittymällä voit luoda ja hallita mintejä, token account -tilejä, valtuuksia,
siirtoja ja Token-2022-laajennuksia.

Tämä viiteopas noudattaa versiota
[`spl-token-cli` v5.6.1](https://github.com/solana-program/token-2022/releases/tag/cli%40v5.6.1),
joka sisältyy Agave v4.2.1 -pakettiin. Suorita `spl-token --version` ja käytä
`<command> --help` nähdäksesi asennetussa versiossasi käytettävissä olevat tarkat valinnat.

<Callout type="warn">
  Mintin luonti, siirrot, valtuuksien muutokset, polttamiset, jäädytykset ja tilin
  sulkeminen lähettävät transaktioita. Tarkista klusteri, Token Program, allekirjoittaja ja
  osoitteet ennen komennon suorittamista. Mainnet-muutokset käyttävät oikeita varoja.
</Callout>

## Asennus ja ohjeiden haku

Agave CLI -julkaisupaketti sisältää `spl-token`-työkalun. Jos sitä ei ole asennettu, käytä
julkaistua Rust-pakettia (crate):

```shell
cargo install spl-token-cli --version 5.6.1
spl-token --version
```

Tarkastele ohjetta juuritasolla tai komentotasolla:

```shell
spl-token --help
spl-token create-token --help
spl-token transfer --help
```

## Globaalit valinnat

Sijoita globaalit valinnat ennen komentoa.

| Valinta                                       | Tarkoitus                                                                   |
| -------------------------------------------- | ------------------------------------------------------------------------- |
| `-u, --url <URL_OR_MONIKER>`                 | Valitse RPC-URL tai `mainnet-beta`, `testnet`, `devnet` tai `localhost`. |
| `-C, --config <PATH>`                        | Käytä toista Solana CLI:n asetustiedostoa.                            |
| `--fee-payer <KEYPAIR>`                      | Valitse tili, joka maksaa transaktiomaksut.                            |
| `-p, --program-id <ADDRESS>`                 | Käytä nimenomaisesti annettua Token Program ID:tä.                                         |
| `--program-2022`                             | Käytä Token-2022:ta (`TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb`).           |
| `--output <FORMAT>`                          | Palauta `json` tai `json-compact` niissä komennoissa, jotka tukevat sitä.                          |
| `--with-compute-unit-limit <UNITS>`          | Aseta transaktion laskentayksikkörajoitus.                                   |
| `--with-compute-unit-price <MICRO_LAMPORTS>` | Aseta laskentayksikköä kohti maksettava prioriteettihinta.                                  |
| `-v, --verbose`                              | Näytä lisätulosteet.                                                   |
| `-V, --version`                              | Tulosta asennetun CLI:n versio.                                          |

Oletusohjelma on alkuperäinen Token Program. Käytä `--program-2022`-valintaa
Token-2022-mintille tai -tilille, myös sitä luettaessa. Komento epäonnistuu, jos
valittu ohjelma ei omista annettua osoitetta.

## Luo ja käytä tokenia

Komennot tulostavat luodut osoitteet. Tallenna `create-token`-komennon palauttama
mint-osoite seuraavia komentoja varten.

```shell
# Create a six-decimal mint under the original Token Program.
spl-token --url devnet create-token --decimals 6

# Create the default signer's associated token account for the mint.
spl-token --url devnet create-account <MINT_ADDRESS>

# Mint 100 tokens to that associated token account.
spl-token --url devnet mint <MINT_ADDRESS> 100

# Read supply, balance, and complete mint or account details.
spl-token --url devnet supply <MINT_ADDRESS>
spl-token --url devnet balance <MINT_ADDRESS>
spl-token --url devnet display <MINT_OR_TOKEN_ACCOUNT_ADDRESS>

# Transfer tokens to a wallet and create its associated account if needed.
spl-token --url devnet transfer \
  <MINT_ADDRESS> \
  10 \
  <RECIPIENT_WALLET_ADDRESS> \
  --fund-recipient
```

Määrät ovat käyttöliittymän token-määriä, jotka on säädetty mintin desimaalien mukaan. Komennot, kuten
`transfer`, `burn` ja `unwrap-sol`, hyväksyvät arvon `ALL`, kun se mainitaan niiden ohjeessa.

## Luo Token-2022-mint

Laajennukset lisäävät mintin tai tilin tilatietoja, ja ne on yleensä valittava mintin
luontihetkellä. Tämä esimerkki luo kuuden desimaalin mintin, jossa on sisäänrakennettu
metadatatuki:

```shell
spl-token --program-2022 create-token \
  --decimals 6 \
  --enable-metadata

spl-token --program-2022 initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  EXAMPLE \
  https://example.com/token.json
```

Yleisiä `create-token`-komennon laajennusvalintoja ovat:

- `--enable-close`
- `--enable-confidential-transfers auto|manual`
- `--enable-freeze`
- `--enable-group` ja `--enable-member`
- `--enable-metadata`
- `--enable-non-transferable`
- `--enable-pause`
- `--enable-permanent-delegate`
- `--enable-permissioned-burn`
- `--enable-transfer-hook` tai `--transfer-hook <PROGRAM_ID>`
- `--interest-rate <BASIS_POINTS>`
- `--transfer-fee-basis-points <BASIS_POINTS>` yhdessä valinnan
  `--transfer-fee-maximum-fee <AMOUNT>` kanssa
- `--ui-amount-multiplier <MULTIPLIER>`

Yhdistä vain sellaisia laajennuksia, joita Token-2022-ohjelma sallii yhdessä. Tutustu
asianomaiseen [Token-2022-laajennusoppaaseen](/docs/tokens/extensions) ennen kuin
luot peruuttamattoman mint-konfiguraation.

## Hallitse valtuuksia ja delegaatteja

```shell
# Change the mint authority.
spl-token authorize <MINT_ADDRESS> mint <NEW_AUTHORITY_ADDRESS>

# Permanently remove the mint authority.
spl-token authorize <MINT_ADDRESS> mint --disable

# Let a delegate spend up to 25 tokens from one token account.
spl-token approve \
  <TOKEN_ACCOUNT_ADDRESS> \
  25 \
  <DELEGATE_ADDRESS>

# Remove the current delegate.
spl-token revoke <TOKEN_ACCOUNT_ADDRESS>
```

`authorize` tukee mint-, freeze-, owner- ja close-valtuuksia sekä laajennuskohtaisia
valtuustyyppejä. Valtuuden poistaminen `--disable`-valinnalla on pysyvää, jos mikään
muu ohjelman mekanismi ei voi palauttaa sitä.

## Jäädytä, polta ja sulje

```shell
spl-token freeze <TOKEN_ACCOUNT_ADDRESS>
spl-token thaw <TOKEN_ACCOUNT_ADDRESS>

spl-token burn <TOKEN_ACCOUNT_ADDRESS> 5

# A token account must normally have a zero token balance before closing.
spl-token close --address <TOKEN_ACCOUNT_ADDRESS>
```

`burn` pienentää sekä tilin saldoa että kokonaistarjontaa. `close` palauttaa
tilin jäljellä olevat lamports määritetylle vastaanottajalle; se ei palauta
poltettuja tokeneita.

## Kääri ja pura SOL

```shell
# Create or fund the owner's wrapped SOL token account.
spl-token wrap 1

# Unwrap part of the wrapped SOL balance.
spl-token unwrap-sol 0.25

# Close the wrapped SOL account and return its full lamport balance.
spl-token unwrap
```

Käytä `sync-native`-komentoa, kun olet siirtänyt lamports suoraan käärittyyn SOL token
account -tiliin, jotta sen token-määrä vastaa taustalla olevia lamports.

## Multisig-allekirjoitus

Luo M-of-N Token Program -multisig, jossa on enintään 11 jäsentä:

```shell
spl-token create-multisig \
  2 \
  <MEMBER_1_ADDRESS> \
  <MEMBER_2_ADDRESS> \
  <MEMBER_3_ADDRESS>
```

Kun transaktiota ohjaa kyseinen multisig, anna multisig-osoite asianomaisena
valtuutena ja anna jäsenten keypair-parit toistetuilla
`--multisig-signer`-arvoilla. Tarkista kohdekomennon ohje, sillä sen ensisijaisen
valtuuden lippu vaihtelee toiminnon mukaan.

## Luottamukselliset saldot

Luottamuksellisten saldojen komennot vaativat luottamuksellisia siirtoja varten
määritetyn Token-2022-mintin ja määritetyn vastaanottajatilin.

```shell
spl-token --program-2022 configure-confidential-transfer-account \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 deposit-confidential-tokens \
  <MINT_ADDRESS> \
  10 \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 apply-pending-balance \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 withdraw-confidential-tokens \
  <MINT_ADDRESS> \
  5 \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 transfer \
  <MINT_ADDRESS> \
  1 \
  <RECIPIENT_ADDRESS> \
  --confidential
```

Komennoille `configure-confidential-transfer-account` ja `apply-pending-balance` anna
joko `--address <TOKEN_ACCOUNT_ADDRESS>` tai paikkaan sidottu `<MINT_ADDRESS>`, ei
molempia. Paikkaan sidottu muoto käyttää omistajan associated token account -tiliä. Talletus ja
nosto vaativat aina mintin ja hyväksyvät `--address`-valinnan kyseisen oletustilin
korvaamiseksi.

Käytä komentoja `enable-confidential-credits`, `disable-confidential-credits`,
`enable-non-confidential-credits` ja `disable-non-confidential-credits` hallitaksesi,
mitä talletuksia tili hyväksyy. Nämä asetukset vaikuttavat tilin
yksityisyyteen ja maksujen yhteensopivuuteen; tarkista tili ennen niiden muuttamista.

## Rakenteinen ja offline-allekirjoitus

Käytä rakenteista tulostetta näytettävän tekstin jäsentämisen sijaan:

```shell
spl-token accounts --output json
spl-token display <MINT_ADDRESS> --output json-compact
```

Transaktioita tuottavat komennot tukevat yleensä valintoja `--sign-only`, `--blockhash`,
`--signer <PUBKEY=SIGNATURE>`, `--nonce` ja `--nonce-authority`. Tarkat
offline-syötteet riippuvat komennosta, mintin desimaaleista ja valtuusjärjestelystä,
joten luo allekirjoittamaton viesti kyseisen komennon `--help`-ohjeiden mukaan ja
tarkista jokainen osoite ennen allekirjoitusten keräämistä.
