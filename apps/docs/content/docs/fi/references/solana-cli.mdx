`solana`-komentoriviliittymä määrittää klusteriyhteyden, lukee
verkon tilaa, lähettää SOL-tokeneita, hallitsee pysyviä nonceja, ottaa ohjelmia käyttöön ja ylläpitää
stake- ja vote-tilejä.

Tämä viite noudattaa versiota
[Agave v4.2.1](https://github.com/anza-xyz/agave/releases/tag/v4.2.1). Tarkista asennettu julkaisu komennolla
`solana --version` ja katso kyseisen version tarkat käytettävissä olevat
valinnat `--help`-valinnalla.

<Callout type="warn">
  Komennot, jotka luovat, siirtävät, valtuuttavat, nostavat tai ottavat käyttöön, lähettävät
  transaktioita. Vahvista määritetty klusteri ja allekirjoittaja ennen niiden suorittamista.
  Devnetin ja Testnetin tokeneilla ei ole arvoa; Mainnet-komennot käyttävät oikeita SOL-tokeneita.
</Callout>

## Komentojen rakenne

```text
solana [GLOBAL_OPTIONS] <COMMAND> [COMMAND_OPTIONS]
```

Hae ohje miltä tahansa tasolta:

```shell
solana --help
solana transfer --help
solana address-lookup-table extend --help
```

## Yleiset valinnat

Yleiset valinnat voi sijoittaa ennen komentoa. Komentokohtainen ohje toistaa
kyseiseen komentoon sovellettavat valinnat.

| Valinta                          | Tarkoitus                                                                        |
| ------------------------------- | ------------------------------------------------------------------------------ |
| `-u, --url <URL_OR_MONIKER>`    | Valitse RPC-URL tai `mainnet-beta`, `testnet`, `devnet` tai `localhost`.      |
| `--ws <URL>`                    | Ohita WebSocket-päätepiste.                                               |
| `-k, --keypair <KEYPAIR>`       | Valitse keypair-tiedosto, `ASK`, stdin (`-`) tai tuettu allekirjoittajan URL.          |
| `-C, --config <FILEPATH>`       | Käytä toista CLI-määritystiedostoa.                                        |
| `--commitment <LEVEL>`          | Lue `processed`-, `confirmed`- tai `finalized`-vahvistustasolla.                   |
| `--output <FORMAT>`             | Palauta `json` tai `json-compact`, kun se on tuettu.                               |
| `--skip-preflight`              | Lähetä ilman RPC-simulaatiota. Käytä vain, jos virhetilanteen kompromissi ymmärretään. |
| `--use-tpu-client`              | Lähetä transaktiot TPU-asiakkaan kautta.                                      |
| `--no-address-labels`           | Tulosta osoitteet ilman paikallisia nimikkeitä.                                          |
| `--skip-seed-phrase-validation` | Salli palautuslause, joka ei kuulu BIP39:n englanninkieliseen sanalistaan.                       |
| `-v, --verbose`                 | Näytä komennon lisätulosteet.                                                |
| `-V, --version`                 | Tulosta asennetun CLI:n versio.                                               |

## CLI:n määrittäminen

```shell
# Inspect the effective configuration.
solana config get

# Use Devnet and a specific signer by default.
solana config set --url devnet
solana config set --keypair ./devnet-keypair.json

# Override defaults for one command.
solana --url mainnet-beta --keypair usb://ledger address
```

Määritys sisältää RPC-URL-osoitteen, WebSocket-URL-osoitteen, oletusallekirjoittajan ja
vahvistustason. Komentoriviltä annettu valinta ohittaa tallennetun arvon kyseisen suorituskerran ajaksi.

## Yleiset tili- ja transaktiotyönkulut

```shell
# Print the default signer's address and balance.
solana address
solana balance

# Read an account as JSON.
solana account <ACCOUNT_ADDRESS> --output json

# Request Devnet SOL.
solana airdrop 1 --url devnet

# Send SOL and then confirm the returned signature.
solana transfer <RECIPIENT_ADDRESS> 0.1 --allow-unfunded-recipient
solana confirm <TRANSACTION_SIGNATURE>

# Inspect recent activity and stream logs mentioning an address.
solana transaction-history <ADDRESS> --limit 20
solana logs <ADDRESS>
```

`transfer` siirtää oletuksena SOL-tokeneita. Käytä summana arvoa `ALL`, jos haluat siirtää
käytettävissä olevan saldon kulujen jälkeen. Tokenesimerkkejä löydät
[tokenien pikaoppaasta](/docs/tokens/quickstart).

## Ohjelmien työnkulut

```shell
# Deploy or upgrade an SBF program.
solana program deploy ./target/deploy/my_program.so

# Inspect the deployed program and list programs controlled by the signer.
solana program show <PROGRAM_ID>
solana program show --programs

# Close a program buffer and recover its lamports.
solana program close <BUFFER_ADDRESS>
```

Anna `--program-id <KEYPAIR_OR_ADDRESS>`, kun käyttöönoton on käytettävä tiettyä
ohjelmatunnusta. `--final` tekee uudesta käyttöönotosta muuttumattoman; lue sen ohje huolellisesti
ennen käyttöä, koska päivitysvaltuutta ei voi palauttaa.

## Pysyvän noncen työnkulut

```shell
solana-keygen new --outfile nonce-account.json
solana create-nonce-account nonce-account.json 0.1
solana nonce nonce-account.json
solana new-nonce nonce-account.json
solana withdraw-from-nonce-account nonce-account.json <RECIPIENT_ADDRESS> ALL
```

Käytä komentoa `authorize-nonce-account` nonce-valtuutetun vaihtamiseen ja komentoa `nonce-account`
tilin koko tilan tarkasteluun. Noncea käyttävät transaktiot hyväksyvät tuetuissa komennoissa myös
`--nonce` ja `--nonce-authority`.

## Stake-työnkulut

```shell
solana-keygen new --outfile stake-account.json
solana create-stake-account stake-account.json 1
solana delegate-stake stake-account.json <VOTE_ACCOUNT_ADDRESS>
solana stake-account stake-account.json

solana deactivate-stake stake-account.json
solana withdraw-stake stake-account.json <RECIPIENT_ADDRESS> ALL
```

Deaktivointi päättyy epoch-rajalla ja voi kestää yli yhden epoch-jakson.
Käytä komentoja `stakes`, `validators`, `stake-history` ja `stake-minimum-delegation`
klusterin ja delegoinnin tilan tarkasteluun ennen muutosten lähettämistä.

## Osoiteapuohjelmat

```shell
# Derive a PDA from typed seeds.
solana find-program-derived-address \
  <PROGRAM_ID> \
  string:profile \
  pubkey:<OWNER_ADDRESS>

# Create and extend an address lookup table.
solana address-lookup-table create
solana address-lookup-table extend \
  <LOOKUP_TABLE_ADDRESS> \
  --addresses <ADDRESS_1>,<ADDRESS_2>
```

PDA-seed-arvot käyttävät muotoa `PREFIX:VALUE`. Tuettuja etuliitteitä ovat `string`, `pubkey`,
`hex`, `u8` sekä kiinteänlevyiset etumerkilliset tai etumerkittömät kokonaislukukoodaukset, kuten
`u64le`.

## Ketjun ulkopuoliset viestit ja shell-täydennys

```shell
solana sign-offchain-message "terms accepted"
solana verify-offchain-signature \
  "terms accepted" \
  <SIGNATURE> \
  --signer <SIGNER_ADDRESS>

# Print a completion script for the current shell.
solana completion --shell zsh
```

## Skriptien tuloste

Käytä valintoja `--output json` tai `--output json-compact`, kun ne ovat tuettuja,
ihmisluettavan tulosteen jäsentämisen sijaan:

```shell
solana epoch-info --output json
solana account <ACCOUNT_ADDRESS> --output json-compact
solana validators --output json > validators.json
```

Kaikki komennot eivät tue jäsenneltyä tulostetta. Tarkista komennon ohje, ennen kuin
turvaudut siihen automaatiossa, ja käsittele nollasta poikkeava poistumiskoodi virheenä.
