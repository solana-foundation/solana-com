# Kuinka vahvistaa token ja saada se näkymään Solana Explorerissa

Tokenin luojilta kuullaan usein kysymys: _"Miksi tokenini ei näy, kun
etsin sitä Solana Explorerista, ja miten saan sen vahvistettua?"_

Lyhyt vastaus: Solana Explorer ei ylläpidä omaa yhtä vahvistusprosessia. Sen sijaan se **kokoaa yhteen useita itsenäisiä vahvistuspalveluntarjoajia**.
Jos tokenisi vahvistetaan **jonkin yhden** näistä palveluntarjoajista kautta, se
ilmestyy Explorerin hakutuloksiin ja näyttää vahvistustiedot.

Tämä opas selittää jokaisen palveluntarjoajan, mitä "vahvistettu" tarkoittaa (ja mitä se ei tarkoita), sekä
miten saat tokenisi vahvistettua.

## Mitä "vahvistettu" tarkoittaa (ja mitä se ei tarkoita)

Vahvistus vahvistaa, että token on **kanoninen / oikea token** tietylle
nimelle, symbolille ja mint-osoitteelle. Se auttaa käyttäjiä välttämään tekijänoikeusloukkauksia ja
duplikaattitokeneita, sillä kuka tahansa voi luoda tokenin millä tahansa nimellä Solanassa.

Vahvistus **ei** ole projektin suositus, eikä se ole **takuu**
tokenin arvosta, turvallisuudesta tai laillisuudesta. Tee aina oma tutkimuksesi.

## Solana Explorerin taustalla olevat vahvistuspalveluntarjoajat

Solana Explorer tarkistaa seuraavat itsenäiset vahvistajat. Kun jokin niistä poimii tokenisi
(RugCheck on automaattinen; muut vaativat toimenpiteitä), tokenisi
ilmestyy Explorer-hakuun.

### 1. RugCheck (automaattinen)

[RugCheck](https://rugcheck.xyz) suorittaa automaattisen ketjuanalyysin ja
seuraa tokeneita automaattisesti. Koska se on automaattinen, sinun ei yleensä tarvitse
lähettää mitään — RugCheck arvioi ketjun riskisignaalit (mint/freeze-
valtuutus, haltijajakauma, likviditeetti jne.) ja seuraa tokenia itsenäisesti.

Tietyillä stablecoineilla on erityiskäsittely, jossa projektit voivat ottaa
suoraan yhteyttä RugCheck-tiimiin asianmukaista käsittelyä varten.

Esimerkki token-sivusta:
[`rugcheck.xyz/tokens/<mint>`](https://rugcheck.xyz/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 2. Jupiter

[Jupiter](https://jup.ag) ylläpitää vahvistettua tokenlistausta (VRFD), joka on laajasti
integroitu koko Solana-ekosysteemiin — DEX-pörsseihin, lompakkoihin ja screenereihin. Vahvistettu token saa vihreän valintamerkin Jupiterin tuotteissa ja kumppanialustoilla.

Vahvistusta varten lähetä tokenisi tarkistettavaksi:

- Lähetä osoitteessa [verified.jup.ag/tokens](https://verified.jup.ag/tokens)
- Kuka tahansa voi lähettää tokenin (ei vain projektitiimi)
- Voit halutessasi yhdistää projektin X-tilin linkittääksesi tokenin mint-
  osoitteen tiettyyn tiliin
- Jupiter tekee kokonaisvaltaisen arvioinnin (likviditeetti, metatietostandardien noudattaminen ja
  muut signaalit) yhden yksittäisen mittarin tarkistamisen sijaan

Esimerkki token-sivusta:
[`jup.ag/tokens/<mint>`](https://jup.ag/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 3. CoinGecko

[CoinGecko](https://www.coingecko.com)-vahvistus listaa tokenisi markkinatietojen kera. Kun vahvistat CoinGekon kautta, muista sisällyttää tokenin **mint-osoite**
(CoinGekon lomakkeessa tämä on merkitty "contract address") jotta jatkointegraaatiot voivat ratkaista hinnat oikein.

Noudata virallista CoinGecko-listaus-/päivitysopasta:

- [Vahvistusopas CoinGekon listaus- ja päivityspyyntöihin](https://support.coingecko.com/hc/en-us/articles/23725417857817-Verification-Guide-for-Listing-Update-Requests-on-CoinGecko)

Esimerkki kolikko-sivusta:
[`coingecko.com/en/coins/<token>`](https://www.coingecko.com/en/coins/usdc)

### 4. Solflare

[Solflare](https://solflare.com) on itsenäinen validator Solana Explorerin vahvistuskehyksessä. Käytännössä sen tokenlistauskriteereillä on paljon yhteistä Jupiterin kanssa, koska Solflaren sovelluksen vaihtolistaus perustuu Jupiter-aggregaattoriin. Uuden tokenin näkyminen edellyttää tyypillisesti, että se:

- On kelvollinen token Solana-lohkoketjussa ja sillä on metatiedot, jotka noudattavat
  Metaplex Token Metadata -standardia
- Sillä on riittävä likviditeetti (vähimmäis-USD-arvo tokenista saatavilla
  kaupankäyntiä varten)
- Pitää hintavaikutuksen hyväksyttävissä rajoissa tyypillisissä vaihdoissa

Tämän päällekkäisyyden vuoksi Jupiter-vahvistuksen suorittaneet tokenit ovat usein
jo kelpoisia Solflaressa ilman erillistä lähetystä — joten sinun ei yleensä tarvitse
käsitellä Solflarea ylimääräisenä manuaalisena vaiheena. Kun kriteerit täyttyvät,
tokenit ilmestyvät yleensä muutamassa minuutissa. Katso:

- [En löydä tokenia Solflaressa](https://help.solflare.com/en/articles/9260147-i-cannot-find-a-token-in-solflare)

Esimerkki token-sivusta:
[`solflare.com/prices/<name>/<mint>`](https://www.solflare.com/prices/usd-coin/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/)

### 5. Bluprynt (laajennettu KYC)

[Bluprynt](https://app.bluprynt.com/register/account) tarjoaa laajennetun
vahvistuspolun KYC-protokollalla. Tämä on tiukempi, henkilöllisyyteen perustuva
prosessi, joka sopii projekteille, jotka haluavat vahvemman vahvistussignaalin.

- Rekisteröidy
  [Bluprynt-käyttöönoton kautta Solana Explorerille](https://app.bluprynt.com/register/account)

Esimerkki vahvistetun omaisuuserän sivusta:
[`verified.bluprynt.com/verified-assets/<mint>/solana`](https://verified.bluprynt.com/verified-assets/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/solana)

## Kuinka kaikki toimii yhdessä

- **RugCheck** toimii automaattisesti ketjuanalyysin kautta — lähetystä
  ei tarvita.
- **Jupiter, CoinGecko, Solflare ja Bluprynt** edellyttävät kukin, että lähetät /
  suoritat niiden oman prosessin.
- Heti kun tokenisi on vahvistettu **vähintään yhden** näistä palveluntarjoajista toimesta, se
  ilmestyy **Solana Explorer** -hakuun ja näyttää vahvistustiedot.

Jos tokenisi ei vielä näy Explorer-haussa, nopein tie on
yleensä lähettää se Jupiter-vahvistukseen ja/tai suorittaa CoinGecko-listaus,
sillä molemmat ovat laajasti integroituja ekosysteemiin.

## Edellytykset, jotka auttavat vahvistuksen onnistumisessa

Palveluntarjoajasta riippumatta nämä ketjun perustavanlaatuiset seikat tekevät vahvistuksen onnistumisesta
paljon todennäköisempää:

- **Kelvolliset metatiedot**: tokenillasi tulisi olla ketjumetatiedot, jotka noudattavat
  Metaplex Token Metadata -standardia (nimi, symboli, logo-URI).
- **Likviditeetti**: tarjoa riittävästi likviditeettiä tuetulla DEX-pörssissä, jotta tokenia voidaan
  käydä kauppaa ja arvioida.
- **Oikea mint-osoite**: aina kun lähetät tietoja palveluntarjoajalle, käytä aina tokenisi
  **mint-osoitetta** (joissakin palveluntarjoajan lomakkeissa merkitty "contract address").

## Yhteenveto

Solana Explorer kokoaa yhteen useita itsenäisiä vahvistajia — **RugCheck**
(automaattinen), **Jupiter**, **CoinGecko**, **Solflare** ja **Bluprynt** (KYC).
Vahvistus minkä tahansa niistä kautta tekee tokenistasi löydettävän Explorer-
haussa. Vahvistus vahvistaa kanonisen token-identiteetin; se ei ole
suositus, joten käyttäjien tulee aina tehdä oma tutkimuksensa.
