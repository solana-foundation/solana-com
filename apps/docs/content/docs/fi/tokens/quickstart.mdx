---
title: "Pikaopas: luo token CLI:llä"
description:
  Create a token, open a token account, mint supply, and transfer tokens using
  the SPL Token CLI on devnet.
---

Tämä pikaopas käy läpi tokenin koko elinkaaren _sh`spl-token`_-CLI:llä. Luot mint account -tilin, luot tilin joka voi säilyttää tokenia, lyöt 100 tokenia ja siirrät osan toiseen lompakkoon.

Käytä [Solana Playground](https://beta.solpg.io/) -ympäristöä komentojen suorittamiseen selaimessasi tai asenna CLI paikallisesti komennolla `cargo install spl-token-cli`. Osoitteet tulosteessasi poikkeavat alla olevista esimerkeistä.

## 1. Yhdistä devnetiin

Luo tai yhdistä lompakko Solana Playgroundissa, valitse sitten devnet ja pyydä SOL tilitalletuksia ja transaktiomaksuja varten:

```terminal
$ solana config set --url devnet
$ solana airdrop 2
```

Käytä devnet-tokeneita vain testaukseen. Niillä ei ole taloudellista arvoa.

## 2. Luo token

Luo mint account, joka tunnistaa tokenisi:

```terminal
$ spl-token create-token
```

Kopioi token-osoite tulosteesta. Tämä on mint-osoite, jota käytät jäljellä olevissa komennoissa. Uuden mintin tarjonta on aluksi nolla.

```terminal
$ spl-token supply <MINT_ADDRESS>
```

## 3. Luo token account

Lompakkosi tarvitsee token account -tilin tätä minttiä varten ennen kuin se voi pitää saldoa:

```terminal
$ spl-token create-account <MINT_ADDRESS>
```

Tämä luo sinulle associated token account -tilin, jonka osoite johdetaan lompakostasi ja mintistä.

## 4. Lyö tokeneita

Lyö 100 tokenia associated token account -tiliisi:

```terminal
$ spl-token mint <MINT_ADDRESS> 100
$ spl-token balance <MINT_ADDRESS>
```

Mint-auktoriteetin täytyy allekirjoittaa tämä operaatio. Lyöminen kasvattaa sekä token account -tilisi saldoa että mintin kirjaamaa kokonaistarjontaa.

## 5. Siirrä tokeneita

Lähetä 10 tokenia toiselle devnet-lompakolle. _sh`--fund-recipient`_-optio luo vastaanottajan associated token account -tilin, jos sitä ei ole olemassa:

```terminal
$ spl-token transfer <MINT_ADDRESS> 10 <RECIPIENT_WALLET_ADDRESS> --fund-recipient
```

Siirto muuttaa lähettäjän ja vastaanottajan token account -tilien saldoja; se ei muuta mintin kokonaistarjontaa.

## Valinnainen: lisää Token-2022-metatiedot

Jos haluat tallentaa nimen, symbolin ja URI:n suoraan uuteen Token-2022-minttiin, luo se metatietolaajennuksen ollessa käytössä:

```terminal
$ spl-token create-token \
  --program-id TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb \
  --enable-metadata
```

Käytä sitten kyseisen komennon tulostamaa uutta mint-osoitetta:

```terminal
$ spl-token initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  "EXAMPLE" \
  "https://example.com/token.json"
```

URI:n tulisi palauttaa julkinen JSON-metatietodokumentti. Katso [Token-2022-metatiedot](/docs/tokens/extensions/metadata) tilin mallin ja koodiesimerkkien osalta.
