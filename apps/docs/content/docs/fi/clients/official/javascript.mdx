## Solana Kit

`@solana/kit` on suositeltu TypeScript SDK Solana-kehitykseen. Voit koota
asiakkaan koostettavista liitännäisistä, lisätä React-sidokset tarvittaessa ja
ottaa käyttöön generoidut ohjelma-asiakkaat kutsuttaville ketjussa oleville
ohjelmille.

| @solana/kit               | Ydin-SDK: RPC, transaktiot, koodekit, allekirjoittajat | [Lähde](https://github.com/anza-xyz/kit)                                              |
| @solana/react             | React-sidokset: `ClientProvider` ja hookit   | [Lähde](https://github.com/anza-xyz/kit/tree/main/packages/react)                     |
| @solana/kit-plugin-rpc    | RPC-yhteys ja transaktioiden lähetys         | [Lähde](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-rpc)    |

## Solana Web3.js v3

`@solana/web3.js` v3 on suositeltu web3.js-versio. Se rakentaa klassisen
luokkapohjaisen API:n — `Connection`, `Keypair`, `Transaction`, `PublicKey` —
`@solana/kit`in sisäisten osien päälle, joten se toimii Kitin primitiivien ja
yllä olevien ohjelmaklienttien kanssa. Käytä sitä, jos päivität olemassa olevaa
web3.js-sovellusta tai pidät luokkapohjaisesta API:sta.

Useimmat menetelmät, jotka olivat vanhassa SDK:ssa synkronisia, kuten
`Keypair.generate()` ja `transaction.sign()`, ovat nyt asynkronisia.

```bash
npm install @solana/web3.js@3
```

| Paketti         | Kuvaus | GitHub                                                        |
| --------------- | ----------- | ------------------------------------------------------------- |
| @solana/web3.js | Ydinkirjasto    | [Lähde](https://github.com/solana-foundation/solana-web3.js) |

`@solana/spl-token` riippuu paketista `@solana/web3.js` (vanha) eikä toimi
v3:n kanssa. Käytä sen sijaan pakettia `@solana-program/token` tai
`@solana-program/token-2022`; niiden generoidut instruktiot ja
instruktiosuunnitelmat toimivat suoraan v3:n `Transaction.add()`-metodin kanssa.

- [web3.js v1 → v3 -siirtymäopas](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
- [spl-token-siirtymäopas](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-spl-token-migration.md)

## Solana Web3.js (vanha)

`@solana/web3.js` (vanha, `1.x`) on Solanan alkuperäinen TypeScript-SDK. Se
on ylläpitotilassa ja saa vain kriittisiä korjauksia. Olemassa olevat koodikannat voivat
[päivittää web3.js v3:een](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
tai [siirtyä käyttämään Kitiä](/docs/frontend/web3-compat).
