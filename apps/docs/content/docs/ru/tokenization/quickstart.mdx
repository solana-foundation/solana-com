## Подключение к devnet

Замените URL-адреса RPC на devnet и пополните счёт плательщика через [фосет](/developers/cookbook/development/airdrops-and-faucets):

```ts
solanaRpc({
  rpcUrl: "https://api.devnet.solana.com",
  rpcSubscriptionsUrl: "wss://api.devnet.solana.com"
});
```

Всё остальное остаётся без изменений. Перед использованием той же конфигурации в mainnet спланируйте управление полномочиями, операции по соблюдению требований и мониторинг актива.
