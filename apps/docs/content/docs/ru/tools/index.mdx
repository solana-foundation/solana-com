## Инструменты

<Cards>
  <Card title="Kora" href="/docs/tools/kora">
    Создавайте транзакционные потоки без комиссий и с оплатой токенами с помощью
    paymaster Kora.
  </Card>
  <Card title="Keychain" href="/docs/tools/keychain">
    Используйте единый интерфейс подписания для локальных ключей, KMS, HSM и
    бэкендов кошельков.
  </Card>
  <Card title="Commerce Kit" href="/docs/tools/commerce-kit">
    Добавляйте платёжные компоненты Solana и коммерческие потоки в своё
    приложение.
  </Card>
  <Card title="Solana Pay" href="/docs/tools/solana-pay">
    Реализуйте потоки переводов и запросов транзакций через Solana Pay.
  </Card>
  <Card title="Attestations" href="/docs/tools/attestations">
    Создавайте учётные данные, схемы и аттестации для внецепочечных данных,
    связанных с онцепочечными аккаунтами.
  </Card>
  <Card title="Private Channels" href="/docs/tools/private-channels">
    Ознакомьтесь с материалами по продукту приватных каналов и ресурсами для
    интеграции.
  </Card>
  <Card title="Surfpool" href="/docs/tools/surfpool">
    Замена solana-test-validator для локальной разработки, тестирования и
    развёртывания в рамках Infrastructure-as-Code.
  </Card>
  <Card title="LiteSVM" href="/docs/tools/litesvm">
    Тестируйте программы Solana в быстрой внутрипроцессной виртуальной машине
    без validator, на Rust и TypeScript.
  </Card>
  <Card title="Actions и Blinks" href="/docs/tools/actions">
    Превратите любую транзакцию Solana в общедоступную ссылку с метаданными.
  </Card>
  <Card title="Инструменты ИИ" href="/docs/tools/ai">
    Используйте ИИ-ассистенты для написания кода и агентные фреймворки вместе с Solana.
  </Card>
</Cards>
