## Сервисы

Запуск экземпляра Private Channels предполагает наличие следующих сервисов
Docker Compose:

| Контейнер                                  | Роль                                                                    |
| ------------------------------------------ | ----------------------------------------------------------------------- |
| `private-channel-postgres-primary`         | База данных состояния узла записи (PostgreSQL 16)                               |
| `private-channel-postgres-replica`         | База данных состояния узла чтения (потоковая реплика)                            |
| `private-channel-postgres-indexer`         | База данных индексатора и оператора                                           |
| `private-channel-write-node`               | Принимает и выполняет транзакции (порт 8900, только loopback)           |
| `private-channel-read-node`                | Обрабатывает RPC-запросы на чтение (порт 8901, только loopback)                     |
| `private-channel-gateway`                  | Маршрутизирует запросы между узлами записи и чтения; применяет RBAC (порт 8899) |
| `private-channel-indexer-solana`           | Отслеживает события `Deposit` в Solana через Yellowstone gRPC                |
| `private-channel-indexer-private-channel`  | Отслеживает события `Burn` в канале через RPC-опрос                   |
| `private-channel-operator-solana`          | Выпускает токены канала при подтверждении депозитов                        |
| `private-channel-operator-private-channel` | Вызывает `ReleaseFunds` в Mainnet при подтверждении выводов          |
| `private-channel-auth`                     | Опциональный сервис JWT/RBAC (профиль Docker: `auth`)                      |

Контейнеры наблюдаемости (`prometheus`, `grafana`, `cadvisor`) также
включены.

## Шлюз

Для настройки Docker Compose в devnet предусмотрены разумные значения по умолчанию. Переопределяйте их только
при запуске шлюза вне Docker или при развёртывании в production.

| Переменная окружения                         | По умолчанию                                                             | Обязательно            | Описание                                        |
| ------------------------------- | ------------------------------------------------------------------- | ------------------- | -------------------------------------------------- |
| `GATEWAY_PORT`                  | `8899` (devnet)                                                     | Нет                  | Порт прослушивания                                        |
| `GATEWAY_WRITE_URL`             | `http://write-node:8900` (значение из env-файла devnet; нет встроенного значения по умолчанию) | **Да**             | URL узла записи — запросы `sendTransaction` направляются сюда     |
| `GATEWAY_READ_URL`              | `http://read-node:8901` (значение из env-файла devnet; нет встроенного значения по умолчанию)  | **Да**             | URL узла чтения — все остальные RPC-методы направляются сюда   |
| `GATEWAY_CORS_ALLOWED_ORIGIN`   | `*`                                                                 | Нет                  | Значение заголовка `Access-Control-Allow-Origin`         |
| `JWT_SECRET`                    | -                                                                   | Нет                  | Включает RBAC; должен совпадать с `JWT_SECRET` сервиса аутентификации |
| `AUTH_DATABASE_URL`             | -                                                                   | Если задан `JWT_SECRET` | База данных аутентификации для проверки владения кошельком                |
| `AUTH_DATABASE_MAX_CONNECTIONS` | `10`                                                                | Нет                  | Размер пула подключений к базе данных аутентификации                       |
| `METRICS_PORT`                  | `9101`                                                              | Нет                  | Порт метрик Prometheus                            |
| `RUST_LOG`                      | `info`                                                              | Нет                  | Уровень логирования                                          |

> `GATEWAY_WRITE_URL` и `GATEWAY_READ_URL` используют имена сервисов Docker Compose
> (`write-node`, `read-node`) при запуске внутри Docker. Используйте эквиваленты
> с `localhost` только при запуске бинарного файла шлюза непосредственно вне Docker.
>
> Встроенное значение по умолчанию для `GATEWAY_PORT` в бинарном файле шлюза равно `8898`.
> `.env.example` и `.env.devnet` оба устанавливают его в `8899`, что и используется
> в настройке Docker Compose (`versions.env` содержит только привязки версий инструментов и образов,
> но не порты сервисов). Значение по умолчанию `8898` применяется только при
> запуске бинарного файла напрямую без env-файла.

<Callout type="warning">
  `GATEWAY_CORS_ALLOWED_ORIGIN` по умолчанию равен `*`, что разрешает любому источнику обращаться
  к шлюзу из браузера. Ограничьте это значение фактическим источником вашего приложения
  перед любым развёртыванием в production.
</Callout>

## Узел записи и узел чтения

Полный справочник по конфигурации узла записи и узла чтения находится в
[`docs/CONFIG.md`](https://github.com/solana-foundation/solana-private-channels/blob/main/docs/CONFIG.md)
в репозитории.

## Сервис аутентификации

| Переменная окружения                         | Обязательно            | Описание                                                                                                                  |
| ------------------------------- | ------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `JWT_SECRET`                    | **Да**             | Секрет подписи HS256; должен совпадать с `JWT_SECRET` шлюза                                                                  |
| `AUTH_PORT`                     | Нет (по умолчанию `8903`) | Порт прослушивания                                                                                                                  |
| `AUTH_DATABASE_URL`             | **Да**             | Строка подключения PostgreSQL для базы данных аутентификации                                                                           |
| `CORS_ALLOWED_ORIGIN`           | Нет (по умолчанию `*`)    | Значение заголовка `Access-Control-Allow-Origin` для этого сервиса (независимо от `GATEWAY_CORS_ALLOWED_ORIGIN` самого шлюза) |
| `AUTH_DATABASE_MAX_CONNECTIONS` | Нет (по умолчанию `10`)   | Размер пула подключений к базе данных аутентификации                                                                                                 |

## Справочник портов сервисов

| Сервис          | Порт хоста  | Привязка                                                                           |
| ---------------- | ---------- | --------------------------------------------------------------------------------- |
| Шлюз          | 8899       | Все интерфейсы                                                                    |
| Узел записи       | 8900       | Только loopback                                                                     |
| Узел чтения        | 8901       | Только loopback                                                                     |
| Стример         | 8902       | Только внутренний (`expose`, не публикуется на хост); не входит в devnet-стек |
| Сервис аутентификации     | 8903       | Все интерфейсы                                                                    |
| Метрики оператора | 9102, 9103 | Все интерфейсы                                                                    |
| Grafana          | 37429      | Все интерфейсы                                                                    |
| Prometheus       | 9090       | Все интерфейсы                                                                    |
| cAdvisor         | 8080       | Все интерфейсы                                                                    |

> **Примечание по безопасности:** Порты узлов записи и чтения привязаны только к loopback
> (`127.0.0.1`). Шлюз, сервис аутентификации, метрики оператора, Grafana,
> Prometheus и cAdvisor опубликованы на всех сетевых интерфейсах в
> настройке devnet Docker Compose. Защитите их брандмауэром на уровне хоста или сети для
> любого использования, выходящего за рамки локальной разработки; RBAC распространяется только на JSON-RPC-методы
> самого шлюза, но не на эти другие сервисы. Стример является исключением: это
> неаутентифицированный внутренний поток, который Docker никогда не публикует на хост.
