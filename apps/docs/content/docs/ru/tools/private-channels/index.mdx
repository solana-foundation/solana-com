  Private Channels не прошёл аудит безопасности и не рекомендуется для
  использования в продакшене с реальными средствами без тщательной проверки безопасности.
</Callout>

**Private Channels — это корпоративный уровень для интернет-рынков капитала на
Solana.** Он предоставляет настраиваемый прикладной уровень для приватных, мгновенных, бесплатных
переводов внутри платёжных каналов: пользователи вносят SPL-токены в программу эскроу на блокчейне,
проводят транзакции вне сети через шлюз и производят расчёты обратно в Mainnet
через доказательство Sparse Merkle Tree, предоставляя разработчикам приложений мгновенные, бесплатные, приватные
переводы без выхода из экосистемы Solana.

### Почему Private Channels?

- **Мгновенные переводы**: внецепочечная пропускная способность, превышающая нативный TPS Solana;
  переводы подтверждаются в момент обработки секвенсором, а не при подтверждении блока
- **Нулевые комиссии за переводы**: никаких затрат на газ при отдельных переводах в канале;
  пользователи платят только за внесение средств и вывод на блокчейн
- **Конфиденциальность**: переводы между участниками канала не регистрируются в
  Solana Mainnet
- **Разграниченный доступ**: RBAC с JWT-аутентификацией позволяет контролировать, кто может
  отправлять и получать средства
- **Расчёт в Mainnet**: средства всегда можно вывести в Solana через доказательство исключения
  Sparse Merkle Tree, которое программа эскроу принудительно применяет на блокчейне

См. **[Обзор](/docs/tools/private-channels/overview)** — полная
архитектура, диаграмма потока данных и модель безопасности.

## Быстрый старт

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n, // 1 USDC
  recipient: null
});
// send via your preferred Solana client
```

TypeScript-клиенты генерируются из IDL; см. раздел «Установка». Для минтов Token-2022
передайте `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS` явно, поскольку по умолчанию
используется стандартный SPL Token Program.

**[Полное руководство по быстрому старту](/docs/tools/private-channels/quickstart/installation)** —
настройка окружения и генерация клиентов

## Сценарии использования

- **Институциональные двусторонние платежи** — банки и организации, которым необходимы
  высокообъёмные, приватные потоки USDC без отображения каждого перевода на блокчейне
- **Высокочастотные переводы на прикладном уровне** — игровые, программы лояльности и потребительские приложения,
  которым требуются субсекундные, бесплатные переводы в масштабе, превышающем нативный TPS Solana
- **Конфиденциальные потоки токенов** — любой сценарий, где конфиденциальность контрагента и
  суммы является требованием продукта

**[Когда использовать нативные SPL-переводы вместо этого](/docs/tools/private-channels/concepts/channels#when-to-use-private-channels)**
