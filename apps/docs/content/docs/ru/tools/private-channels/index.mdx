<Callout type="warning">
  Приватные каналы не прошли аудит безопасности и не рекомендуются для
  использования в продакшене с реальными средствами без тщательной проверки безопасности.
</Callout>

**Приватные каналы — это корпоративный уровень для интернет-рынков капитала на
Solana.** Он предоставляет настраиваемый уровень приложений для приватных, мгновенных и бесплатных
переводов внутри платёжных каналов: пользователи вносят SPL-токены в программу эскроу на блокчейне,
совершают транзакции вне блокчейна через шлюз и возвращаются в Mainnet
через доказательство разреженного дерева Меркла, предоставляя разработчикам приложений мгновенные, бесплатные и приватные
переводы без выхода из экосистемы Solana.

### Почему Приватные каналы?

- **Мгновенные переводы**: внецепочечная пропускная способность, превышающая нативный TPS Solana;
  переводы подтверждаются в момент обработки секвенсором, а не при подтверждении блока
- **Нулевые комиссии за перевод**: никаких затрат на газ при отдельных переводах внутри канала; пользователи
  платят только за внесение и вывод средств в блокчейне
- **Приватность**: переводы между участниками канала не записываются в
  Solana Mainnet
- **Управление доступом**: RBAC с JWT-аутентификацией позволяет контролировать, кто может
  отправлять и получать средства
- **Расчёты в Mainnet**: средства всегда можно вывести в Solana через доказательство исключения
  разреженного дерева Меркла, которое программа эскроу проверяет в блокчейне

Смотрите **[Обзор](/docs/tools/private-channels/overview)** для ознакомления с полной
архитектурой, диаграммой потока данных и моделью безопасности.

## Быстрый старт

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n, // 1 USDC
  recipient: null
});
// send via your preferred Solana client
```

TypeScript-клиенты генерируются из IDL; см. раздел «Установка». Для минтов Token-2022
передайте `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS` явно, поскольку по умолчанию
используется стандартный SPL Token Program.

настройка среды и генерация клиента

## Сценарии использования

- **Институциональные двусторонние платежи** — банки и организации, которым необходимы
  высокообъёмные приватные потоки USDC без отображения каждой транзакции в блокчейне
- **Высокочастотные переводы на уровне приложений** — игры, программы лояльности и потребительские приложения,
  которым нужны мгновенные бесплатные переводы в масштабе, превышающем нативный TPS Solana
- **Приватные потоки токенов** — любые сценарии, где конфиденциальность контрагента и
  суммы является обязательным требованием к продукту

**[Когда вместо этого использовать нативные SPL-переводы](/docs/tools/private-channels/concepts/channels#when-to-use-private-channels)**
