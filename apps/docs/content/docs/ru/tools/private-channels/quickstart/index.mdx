В этом руководстве по быстрому старту описан полный процесс работы с Private Channels в Solana devnet:
настройка клиентской среды, пополнение эскроу токенами SPL, выполнение
офф-чейн перевода между двумя кошельками и вывод средств обратно в ваш кошелёк
Solana.

К концу руководства вы поймёте полный цикл: пополнение → офф-чейн перевод →
вывод средств — и получите готовый TypeScript-код для каждого шага.

<Callout type="info">
  В этом руководстве предполагается, что экземпляр Private Channels уже развёрнут и
  работает в devnet с вашим минтом в списке разрешённых. Если вам сначала нужно выполнить развёртывание,
  обратитесь к [руководству для операторов](/docs/tools/private-channels/operators) — оно охватывает
  полную настройку; рассчитывайте на 30–60 минут для первоначальной сборки Docker.
</Callout>

## Шаги

1. **[Установка](/docs/tools/private-channels/quickstart/installation)** —
   клонируйте репозиторий и сгенерируйте TypeScript-клиенты (5 минут)
2. **[Пополнение токенов](/docs/tools/private-channels/quickstart/deposit)** —
   внесите токены SPL в эскроу; дождитесь ~15 секунд, пока индексатор
   зачислит баланс на ваш канал
3. **[Отправка перевода](/docs/tools/private-channels/quickstart/transfer)** —
   отправьте офф-чейн перевод через шлюз; подтверждение занимает менее секунды,
   Mainnet не задействован
4. **[Вывод средств](/docs/tools/private-channels/quickstart/withdraw)** — сожгите
   баланс на стороне канала; оператор переводит средства на ваш кошелёк Mainnet
   в течение нескольких секунд
