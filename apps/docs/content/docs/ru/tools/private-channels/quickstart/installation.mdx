## Предварительные требования

- Rust 1.91+
- Solana CLI 3.1.13 (Agave):
  `sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.13/install)"`
- Node.js 24.7.0+
- pnpm 10.15.1+: `npm install -g pnpm@10.15.1`

## Клонирование репозитория

```bash
git clone https://github.com/solana-foundation/solana-private-channels.git
cd solana-private-channels
```

## Генерация TypeScript-клиентов

TypeScript-клиенты **не** публикуются в npm. Их необходимо сгенерировать из
IDL с помощью Codama.

```bash
# Escrow program client
cd private-channel-escrow-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..

# Withdraw program client
cd private-channel-withdraw-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..
```

Сгенерированные клиенты размещаются в:

- `private-channel-escrow-program/clients/typescript/src/generated/`
- `private-channel-withdraw-program/clients/typescript/src/generated/`

Импортируйте из этих локальных путей в своём приложении; пакет
`@private-channels/client` в npm отсутствует. Примеры кода в этом разделе используют
относительный путь (`../private-channel-escrow-program/...`), предполагая, что ваш код
находится рядом с клонированным репозиторием; скорректируйте путь в соответствии с тем,
откуда вы фактически импортируете в своём проекте.
