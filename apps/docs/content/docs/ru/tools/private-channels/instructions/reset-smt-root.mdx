---
title: Сброс корня SMT
description:
  Выполняет ротацию разреженного дерева Меркла, сбрасывая корень вывода средств для нового epoch дерева
---

Инструкция только для оператора, которая выполняет ротацию разреженного дерева Меркла путём увеличения
`Instance.current_tree_index` и сброса корня вывода средств, что позволяет обработать новый
epoch из 65 536 выводов.

<Callout type="info">
  Программа эскроу мигрирует с данной архитектуры разреженного дерева Меркла на
  побитовую карту нонсов на блокчейне (отслеживается в вышестоящем репозитории), где эта инструкция станет
  `RotateBitmap`. Данная страница соответствует текущей программе эскроу и
  будет обновлена после внедрения этого изменения.
</Callout>

## Аккаунты

| Аккаунт                          | Записываемый | Подписант | Описание                                            |
| -------------------------------- | -------- | ------ | ------------------------------------------------------ |
| `payer`                          | ✓        | ✓      | Плательщик комиссии                                              |
| `operator`                       |          | ✓      | Подписант-оператор                                        |
| `instance`                       | ✓        |        | PDA экземпляра эскроу (увеличивает `current_tree_index`) |
| `operator_pda`                   |          |        | PDA оператора, подтверждающий, что подписант активирован         |
| `event_authority`                |          |        | PDA авторитета событий для CPI `EmitEvent`                |
| `private_channel_escrow_program` |          |        | Программа эскроу (самоссылка для CPI)                |

## Параметры

| Параметр                     | Тип  | Описание                                                              |
| ----------------------------- | ----- | ------------------------------------------------------------------------ |
| `expected_current_tree_index` | `u64` | Защита от повторного воспроизведения; должно совпадать с `Instance.current_tree_index`, иначе вызов завершится ошибкой |

## Возвращаемое значение

Возвращает `TransactionBuilder`, который можно использовать для построения и отправки
транзакции.

## Пример

```typescript
import { getResetSmtRootInstruction } from "../private-channel-escrow-program/clients/typescript/src/generated";

const resetIx = getResetSmtRootInstruction({
  payer: operatorPayerSigner,
  operator: operatorSigner,
  instance: instancePda,
  operatorPda: operatorPdaAddress,
  eventAuthority: eventAuthorityPda,
  privateChannelEscrowProgram: ESCROW_PROGRAM_ID,
  expectedCurrentTreeIndex: currentTreeIndex // u64
});
```

## Важные замечания

- Только для оператора: требуется действительный `operator_pda`; в противном случае выбрасывается `InvalidOperatorPda`
- `expected_current_tree_index` должен быть равен `Instance.current_tree_index` на момент вызова; устаревшее значение вызывает `UnexpectedTreeIndex`, защищая от повторного применения уже выполненного сброса
- Увеличивает `Instance.current_tree_index`; нонсы, действительные в предыдущем epoch дерева, аннулируются после ротации
- Сервис `operator-private-channel` вызывает эту инструкцию автоматически при
  `transaction_nonce % 65536 == 0` (и `nonce > 0`), сигнализируя о начале
  нового epoch; в штатном режиме ручной вызов не требуется
- После ротации корень вывода средств сбрасывается до пустого дерева, и новые
выводы начинаются с чистого SMT
- Генерирует событие через CPI `EmitEvent`
