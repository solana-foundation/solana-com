---
title: AddOperator
description: Создаёт нового оператора путём формирования его Operator PDA
---

Создаёт нового оператора путём формирования его `Operator` PDA. После этого вызова
кошелёк `operator` может вызывать `ReleaseFunds` и `ResetSmtRoot`.

## Аккаунты

| Аккаунт                          | Записываемый | Подписант | Описание                                                         |
| -------------------------------- | -------- | ------ | ------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Плательщик комиссии                                                           |
| `admin`                          |          | ✓      | Администратор инстанса                                                      |
| `instance`                       |          |        | Instance PDA                                                        |
| `operator`                       |          |        | Кошелёк оператора для подготовки                                        |
| `operator_pda`                   | ✓        |        | Operator PDA — автоматически выводится из `["operator", instance, operator]` |
| `system_program`                 |          |        | System Program                                                      |
| `event_authority`                |          |        | PDA полномочий событий                                                 |
| `private_channel_escrow_program` |          |        | Escrow Program                                                      |

## Параметры

| Параметр | Тип | Описание                                                                               |
| --------- | ---- | ----------------------------------------------------------------------------------------- |
| `bump`    | `u8` | bump seed для `operator_pda`. Необязательный: клиент `Async` автоматически выводит его, если не указан |

> IDL содержит аргумент `discriminator: u8` (значение `3`), который автоматически устанавливается
> сгенерированным клиентом и не должен передаваться вручную.

## Важные замечания

- Используйте `getAddOperatorInstructionAsync`: он автоматически выводит `bump` и
  `operator_pda`, если они не указаны. Также существует синхронный вариант
  `getAddOperatorInstruction`, если вы уже вычислили `bump`
  самостоятельно
- После этого вызова кошелёк `operator` может вызывать `ReleaseFunds` и
  `ResetSmtRoot`
- Генерирует событие через `EmitEvent` CPI
