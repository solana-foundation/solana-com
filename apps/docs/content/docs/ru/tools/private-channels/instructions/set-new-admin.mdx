Передаёт права администратора новому кошельку.

## Аккаунты

| Аккаунт                          | Записываемый | Подписант | Описание                        |
| -------------------------------- | -------- | ------ | ---------------------------------- |
| `payer`                          | ✓        | ✓      | Плательщик комиссии                          |
| `current_admin`                  |          | ✓      | Текущий администратор (должен подписать)          |
| `instance`                       | ✓        |        | Instance PDA (поле администратора обновлено) |
| `new_admin`                      |          | ✓      | Кошелёк, получающий права администратора     |
| `event_authority`                |          |        | PDA авторизации событий                |
| `private_channel_escrow_program` |          |        | Программа эскроу                     |

Эта инструкция не принимает параметров.

## Важные замечания

- **Необратимо за один шаг**: текущий администратор не может вернуть себе роль
  без повторного вызова `SetNewAdmin` новым администратором
- Проверьте целевой адрес перед вызовом; отмена невозможна
- Генерирует событие через `EmitEvent` CPI
