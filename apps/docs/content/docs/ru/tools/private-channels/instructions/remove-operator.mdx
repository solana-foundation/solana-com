---
title: RemoveOperator
description: Отзывает оператора, закрывая его Operator PDA
---

Отзывает оператора, закрывая его `Operator` PDA. Отозванный кошелёк больше не
может вызывать `ReleaseFunds` или `ResetSmtRoot`.

## Аккаунты

| Аккаунт                          | Записываемый | Подписант | Описание                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | Плательщик комиссии                                 |
| `admin`                          |          | ✓      | Администратор инстанса                            |
| `instance`                       |          |        | Instance PDA                              |
| `operator`                       |          |        | Кошелёк оператора для отзыва                 |
| `operator_pda`                   | ✓        |        | Operator PDA (закрывается данной инструкцией) |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | PDA авторизации событий                       |
| `private_channel_escrow_program` |          |        | Программа эскроу                            |

Эта инструкция не принимает параметров.

## Важные замечания

- Закрывает `operator_pda`; отозванный кошелёк больше не может вызывать
  `ReleaseFunds` или `ResetSmtRoot`
- Все транзакции оператора, находящиеся в обработке, завершатся ошибкой `InvalidOperatorPda` после
  данного вызова
- Генерирует событие через `EmitEvent` CPI
