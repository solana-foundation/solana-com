Удаляет ранее разрешённый минт из экземпляра, запрещая новые депозиты для
этого минта. Существующие депозиты не затрагиваются.

## Аккаунты

| Аккаунт                          | Записываемый | Подписант | Описание                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | Плательщик комиссии                                    |
| `admin`                          |          | ✓      | Администратор экземпляра                               |
| `instance`                       |          |        | PDA экземпляра                                 |
| `mint`                           |          |        | Минт SPL-токена для блокировки                      |
| `allowed_mint`                   | ✓        |        | PDA AllowedMint (закрывается этой инструкцией) |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | PDA авторитета событий                          |
| `private_channel_escrow_program` |          |        | Программа эскроу                               |

Эта инструкция не принимает параметров.

## Важные замечания

- Закрывает PDA `allowed_mint`: последующие вызовы `Deposit` для этого минта завершатся ошибкой
  `InvalidAllowedMint`
- Существующие балансы каналов для этого минта не затрагиваются
- Генерирует событие через CPI `EmitEvent`
