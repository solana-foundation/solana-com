Создаёт `Instance` PDA, который закрепляет эскроу. Должен быть вызван до любой
другой операции.

## Seeds для PDA

```
instance        -> ["instance", instance_seed: Pubkey]
allowed_mint    -> ["allowed_mint", instance_pda: Pubkey, mint: Pubkey]
operator        -> ["operator", instance_pda: Pubkey, operator: Pubkey]
event_authority -> ["event_authority"]
```

## Аккаунты

| Аккаунт                          | Записываемый | Подписант | Описание                                                                 |
| -------------------------------- | -------- | ------ | --------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Плательщик комиссий и rent                                                    |
| `admin`                          |          | ✓      | Начальный администратор инстанса                                               |
| `instance_seed`                  |          | ✓      | Одноразовый keypair, используемый только для деривации PDA; его pubkey становится seed |
| `instance`                       | ✓        |        | Instance PDA (выведен из `["instance", instance_seed.pubkey]`)            |
| `system_program`                 |          |        | System Program                                                              |
| `event_authority`                |          |        | PDA авторизации событий                                                         |
| `private_channel_escrow_program` |          |        | Программа эскроу                                                              |

## Параметры

| Параметр | Тип | Описание                                                                             |
| --------- | ---- | --------------------------------------------------------------------------------------- |
| `bump`    | `u8` | bump seed для Instance PDA. Необязательный: клиент `Async` автоматически выводит его, если не указан |

> IDL содержит аргумент `discriminator: u8` (значение `0`), который автоматически устанавливается
> сгенерированным клиентом и не должен передаваться вручную.

## Важные замечания

- `instance_seed` — одноразовый keypair, используемый только для деривации `Instance`
  PDA. Его pubkey становится seed; сам keypair не сохраняется и не переиспользуется.
- Используйте `getCreateInstanceInstructionAsync`; он автоматически выводит `bump` и `instance`
  из `instance_seed`, если они не указаны. Передавайте собственный `bump` только в том случае,
  если вы уже вычислили его через
  `Pubkey::find_program_address(&[b"instance", instance_seed_pubkey.as_ref()], &PROGRAM_ID)`
- Генерирует событие через `EmitEvent` CPI
