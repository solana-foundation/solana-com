Этот раздел является справочником on-chain инструкций. Большинство разработчиков вызывают эти
инструкции через сгенерированные TypeScript-клиенты; этот справочник нужен только при
создании операторного инструментария, написании пользовательских интеграций или отладке
ошибок на уровне инструкций.

**Escrow Program** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) — управляет
депозитами, подготовкой операторов и расчётами в Mainnet:

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) —
  инициализация PDA экземпляра эскроу
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) — добавление
  SPL-токена в белый список
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) — удаление
  токена из белого списка
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) —
  добавление оператора
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) —
  отзыв оператора
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) —
  передача прав администратора
- [Deposit](/docs/tools/private-channels/instructions/deposit) — перевод SPL-токенов
  в эскроу
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) —
  оператор выполняет расчёт по выводу средств в Mainnet
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) —
  оператор обновляет корень Sparse Merkle Tree

**Withdraw Program** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) — работает в
сети приватных каналов:

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) —
  сжигание баланса на стороне канала для инициации вывода средств

## Коды ошибок

**Escrow Program — `PrivateChannelEscrowProgramError`**

| Код                                         | Сообщение                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | Указан недопустимый источник события                 |
| `InvalidAta`                                 | Указан недопустимый ATA                             |
| `InvalidMint`                                | Указан недопустимый токен                            |
| `InvalidInstanceId`                          | Идентификатор экземпляра недействителен или не соответствует правилам    |
| `InvalidInstance`                            | Указан недопустимый экземпляр                        |
| `InvalidAdmin`                               | Указан недопустимый администратор                           |
| `TransferHookNotAllowed`                     | Расширение transfer hook не разрешено              |
| `InvalidOperatorPda`                         | Указан недопустимый PDA оператора                    |
| `InvalidTokenAccount`                        | Указан недопустимый token account                   |
| `InvalidEscrowBalance`                       | Недопустимый баланс эскроу                           |
| `InvalidAllowedMint`                         | Недопустимый разрешённый токен                             |
| `InvalidSmtProof`                            | Указано недопустимое SMT-доказательство                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | Недопустимый nonce транзакции для текущего индекса дерева |
| `UnexpectedTreeIndex`                        | Неожиданный текущий индекс дерева при сбросе корня SMT |

**Withdraw Program — `PrivateChannelWithdrawProgramError`**

| Код          | Сообщение                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | Указан недопустимый токен                       |
| `ZeroAmount`  | Сумма вывода должна быть больше нуля |
