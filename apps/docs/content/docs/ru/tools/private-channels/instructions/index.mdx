Этот раздел является справочником по on-chain инструкциям. Большинство разработчиков вызывают эти инструкции через сгенерированные TypeScript-клиенты; этот раздел понадобится вам только если вы создаёте операторные инструменты, пишете пользовательские интеграции или отлаживаете ошибки на уровне инструкций.

**Escrow Program** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) — управляет депозитами, подготовкой операторов и расчётами в Mainnet:

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) —
  инициализировать PDA экземпляра escrow
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) — добавить
  SPL token mint в белый список
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) — удалить
  mint из белого списка
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) —
  подготовить оператора
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) —
  отозвать оператора
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) —
  передать права администратора
- [Deposit](/docs/tools/private-channels/instructions/deposit) — переместить SPL-токены
  в escrow
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) —
  оператор выполняет расчёт вывода средств в Mainnet
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) —
  оператор выполняет ротацию корня Sparse Merkle Tree

**Withdraw Program** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) — работает в
сети приватных каналов:

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) —
  сжечь баланс на стороне канала для инициирования вывода средств

## Коды ошибок

**Escrow Program — `PrivateChannelEscrowProgramError`**

| Код                                         | Сообщение                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | Указан недопустимый authority события                 |
| `InvalidAta`                                 | Указан недопустимый ATA                             |
| `InvalidMint`                                | Указан недопустимый mint                            |
| `InvalidInstanceId`                          | Недопустимый ID экземпляра или нарушение правил    |
| `InvalidInstance`                            | Указан недопустимый экземпляр                        |
| `InvalidAdmin`                               | Указан недопустимый администратор                           |
| `TransferHookNotAllowed`                     | Расширение transfer hook не разрешено              |
| `InvalidOperatorPda`                         | Указан недопустимый PDA оператора                    |
| `InvalidTokenAccount`                        | Указан недопустимый token account                   |
| `InvalidEscrowBalance`                       | Недопустимый баланс escrow                           |
| `InvalidAllowedMint`                         | Недопустимый разрешённый mint                             |
| `InvalidSmtProof`                            | Указано недопустимое доказательство SMT                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | Недопустимый nonce транзакции для текущего индекса дерева |
| `UnexpectedTreeIndex`                        | Неожиданный текущий индекс дерева при сбросе корня SMT |

**Withdraw Program — `PrivateChannelWithdrawProgramError`**

| Код          | Сообщение                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | Указан недопустимый mint                       |
| `ZeroAmount`  | Сумма вывода должна быть больше нуля |
