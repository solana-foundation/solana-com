---
title: Депозит
description:
  Переводит SPL-токены из кошелька пользователя в эскроу Private Channels
---

Переводит SPL-токены из associated token account пользователя в associated token account эскроу, начисляя баланс канала пользователю, осуществляющему депозит (или указанному получателю).

## Аккаунты

| Аккаунт                          | Записываемый | Подписант | Описание                                          |
| -------------------------------- | -------- | ------ | ---------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Плательщик комиссии за транзакцию                        |
| `user`                           |          | ✓      | Владелец токенов, осуществляющий депозит                       |
| `instance`                       |          |        | PDA экземпляра эскроу                                  |
| `mint`                           |          |        | Минт SPL-токена                                       |
| `allowed_mint`                   |          |        | PDA, подтверждающий, что минт разрешён для данного экземпляра |
| `user_ata`                       | ✓        |        | Associated token account пользователя (источник)             |
| `instance_ata`                   | ✓        |        | Associated token account эскроу (назначение)      |
| `system_program`                 |          |        | System Program                                       |
| `token_program`                  |          |        | SPL Token Program                                    |
| `associated_token_program`       |          |        | Associated Token Program                             |
| `event_authority`                |          |        | PDA авторитета событий для CPI `EmitEvent`              |
| `private_channel_escrow_program` |          |        | Программа эскроу (самоссылка для CPI)              |

## Параметры

| Параметр   | Тип             | Описание                                                                           |
| ----------- | ---------------- | ------------------------------------------------------------------------------------- |
| `amount`    | `u64`            | Количество токенов для депозита в минимальных единицах токена                             |
| `recipient` | `Option<Pubkey>` | Необязательный получатель на блокчейне; если `None`, баланс канала начисляется пользователю, осуществляющему депозит |

## Возвращаемое значение

Возвращает `TransactionBuilder`, который можно использовать для построения и отправки транзакции.

## Пример

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

// allowedMint and instanceAta are auto-derived from mint and instance
const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n,
  recipient: null
});
```

## Важные примечания

- ID программы: `9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`
- Для минтов Token-2022 необходимо явно указать `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS`, так как по умолчанию используется стандартный SPL Token Program
- PDA `allowed_mint` должен существовать (создаётся через `AllowMint`); попытка депозита с незарегистрированным минтом вызовет ошибку `InvalidAllowedMint`
- Если `recipient` равен `None`, баланс канала начисляется пользователю, осуществляющему депозит; если указан — баланс начисляется указанному кошельку
- Транзакцию должны подписать как `payer`, так и `user`
- `instance_ata` должен уже существовать (создаётся через `AllowMint` для данного минта)
