# Работа с LLM и агентами на Solana

Прежде чем перейти к конкретным инструментам, давайте разберёмся в ключевых компонентах стека разработки ИИ:

## Понимание стека ИИ

1. **Большие языковые модели (LLM)**
   - Базовые модели ИИ (такие как GPT-4, Claude или Llama)
   - Обрабатывают и генерируют естественный язык
   - Обеспечивают базовый интеллект и возможности рассуждения
   - Примеры: GPT-4 от OpenAI, Claude от Anthropic, Llama от Meta

2. **Фреймворки агентов (например, Eliza)**
   - Построены поверх LLM для создания автономных агентов
   - Управляют личностями и поведением агентов
   - Управляют памятью и контекстом
   - Обеспечивают интеграцию с несколькими платформами
   - Примеры: Eliza, LangChain, AutoGPT, Vercel AI

3. **Специализированные наборы инструментов для агентов (например, Solana Agent Kit)**
   - Созданы для конкретных сценариев использования (например, операций с блокчейном)
   - Предоставляют готовые инструменты и интеграции
   - Скрывают техническую сложность
   - Готовые к использованию функции блокчейна
   - Примеры: Solana Agent Kit, GOAT Toolkit

Это можно представить так:

- LLM — это «мозг», который понимает и генерирует язык
- Фреймворки агентов — это «операционная система», управляющая поведением ИИ
- Специализированные наборы инструментов — это «приложения», наделяющие ИИ конкретными возможностями

# Создание ИИ-агентов для Solana

В этом руководстве вы узнаете, как:

- Создать базового ИИ-агента с помощью Solana Agent Kit от SendAI
- Создать Twitter-бота с помощью Eliza Framework
- Разобраться в вариантах интеграции ИИ в блокчейн
- Варианты создания продвинутых торговых ботов

## Введение в ИИ-агентов на Solana

ИИ-агенты на Solana — это автономные программы, которые могут взаимодействовать с
блокчейном с использованием обработки естественного языка и машинного обучения. Они могут:

- Выполнять транзакции
- Отслеживать активность блокчейна
- Взаимодействовать со смарт-контрактами
- Оказывать помощь пользователям
- Автоматизировать сложные рабочие процессы

## Доступные фреймворки

Для создания ИИ-агентов на Solana доступно несколько фреймворков:

1. **Solana Agent Kit от SendAI**

- Набор инструментов для создания агентов на Solana
- Совместим с Eliza, Langchain и Vercel AI SDK
- Встроенные инструменты и утилиты для Solana
- Возможности обработки естественного языка
- [Solana Agent Kit](https://github.com/sendaifun/solana-agent-kit)
- [Документация](https://docs.solanaagentkit.xyz/)

2. **Eliza Framework**

- Объединяет уровень данных, LLM и агентов, имеет специальный плагин для Solana
- Расширяемая архитектура агентов
- Простая интеграция с существующими проектами; может использоваться, например, для
  ботов в Twitter (X), Telegram или Discord
- [Репозиторий GitHub](https://github.com/elizaOS/eliza)

3. **GOAT Toolkit**

- Комплексный набор инструментов для разработки
- Совместимость с несколькими блокчейнами
- [Репозиторий GitHub](https://github.com/goat-sdk/goat)

4. **Rig Framework**

- Нативная реализация на Rust
- Подходит для высокопроизводительных торговых ботов
- Можно комбинировать с набором инструментов Listen.rs для интеграции с Solana, мониторинга транзакций
  и отправки транзакций, например, с использованием Jito bundles
- [Репозиторий GitHub](https://github.com/0xPlaygrounds/rig)
- [Репозиторий Listen.rs](https://github.com/piotrostr/listen)

Если вы разрабатываете ИИ-фреймворк, не стесняйтесь открыть PR, чтобы добавить его в список

### Создание скрипта агента

Создайте новый файл `agent.ts` со следующим содержимым:

```typescript filename=agent.ts
import { SolanaAgentKit, createSolanaTools } from "solana-agent-kit";
import { HumanMessage } from "@langchain/core/messages";
import { ChatOpenAI } from "@langchain/openai";
import { createReactAgent } from "@langchain/langgraph/prebuilt";
import { MemorySaver } from "@langchain/langgraph";
import * as dotenv from "dotenv";
import bs58 from "bs58";
import * as readline from "readline";

dotenv.config();

async function initializeAgent() {
  const llm = new ChatOpenAI({
    modelName: "gpt-4-turbo-preview",
    temperature: 0.7
  });

  // Convert array string to actual array, then to Uint8Array, then to base58
  const privateKeyArray = JSON.parse(process.env.SOLANA_PRIVATE_KEY!);
  const privateKeyUint8 = new Uint8Array(privateKeyArray);
  const privateKeyBase58 = bs58.encode(privateKeyUint8);

  const solanaKit = new SolanaAgentKit(privateKeyBase58, process.env.RPC_URL!, {
    OPENAI_API_KEY: process.env.OPENAI_API_KEY!
  });

  const tools = createSolanaTools(solanaKit);
  const memory = new MemorySaver();

  return createReactAgent({
    llm,
    tools,
    checkpointSaver: memory
  });
}

async function runInteractiveChat() {
  const agent = await initializeAgent();
  const config = { configurable: { thread_id: "Solana Agent Kit!" } };
  const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout
  });

  // Clear console and start chat with a small delay
  setTimeout(() => {
    console.clear(); // Clear any initialization messages
    console.log("Chat with Solana Agent (type 'exit' to quit)");
    console.log("--------------------------------------------");
    askQuestion();
  }, 100);

  const askQuestion = () => {
    rl.question("You: ", async (input) => {
      if (input.toLowerCase() === "exit") {
        rl.close();
        return;
      }

      const stream = await agent.stream(
        {
          messages: [new HumanMessage(input)]
        },
        config
      );

      process.stdout.write("Agent: ");
      for await (const chunk of stream) {
        if ("agent" in chunk) {
          process.stdout.write(chunk.agent.messages[0].content);
        } else if ("tools" in chunk) {
          process.stdout.write(chunk.tools.messages[0].content);
        }
      }
      console.log("\n--------------------------------------------");

      askQuestion(); // Continue the conversation
    });
  };
}

runInteractiveChat().catch(console.error);
```

</Step>

## Разработка с Eliza Framework

[ElizaOS](https://github.com/elizaOS/eliza) (ранее известный как Ai16z) — это
фреймворк ИИ. Это означает, что он объединяет несколько приложений в одно и
организует их взаимодействие. Он включает:

1. Различные LLM для понимания пользователя
2. Агенты блокчейна с различными действиями (например, минт NFT)
3. Уровни данных для хранения состояния персонажей между действиями, например,
   с использованием Redis, PostgreSQL DB или локального хранилища
4. Различные клиенты: X, Telegram, Discord и т. д.

Всё это объединяется таким образом, что вы можете создать «Персонажа», который взаимодействует с пользователями или действует автономно. Эти персонажи
определяются в JSON-файле, который задаёт доступные действия, используемую LLM
и различные промпты, определяющие поведение персонажа.

### Кодирование приватного ключа (при необходимости)

Если ваш приватный ключ в шестнадцатеричном формате, вы можете закодировать его в base58
с помощью следующего JS-фрагмента:

```ts filename=encode58.ts
const bs58 = require('bs58');
console.log(bs58.encode(new Uint8Array([213,29,143,...])));
```

И запустить его командой

```bash
npx tsx encode58.ts
```

### Создание конфигурации персонажа

Чтобы создать нового персонажа, необходимо создать файл character.json. Готовые персонажи
находятся в папке characters проекта Eliza. Для создания нового персонажа вы можете
скопировать и изменить одного из уже существующих персонажей или воспользоваться
[функцией composer в Cursor](https://docs.cursor.com/composer/overview) и описать,
какого персонажа вы хотите создать.

```json filename=characters/sol.character.json
{
    "name": "Sol",
    "clients": ["twitter"],
    "modelProvider": "openai",
    "settings": {
        "voice": {
            "model": "en_US-neural"
        },
        ...
```

Важная часть здесь — это clients и modelProvider. В нашем случае мы хотим использовать
twitter в качестве клиента и openai в качестве провайдера модели, поскольку именно для них
мы задали секреты в файле `.env`.

### Запуск агента

После завершения настройки мы можем запустить нашего персонажа:

```bash
pnpm start --character="characters/sol.character.json"
```

Это запустит агента, и теперь вы можете взаимодействовать с ним в Twitter. Персонаж
будет автоматически публиковать твиты каждые несколько часов, а при взаимодействии с ним
сможет выполнять действия в Solana, например минтить NFT.

Здесь вы можете увидеть
[персонажа в действии](https://x.com/solanadevhelper/status/1882222232656847143).

Вы также можете взаимодействовать с персонажем локально с помощью следующей команды.
Возможно, вам потребуется освободить порт 3000 и запустить персонажа с флагом `--host`.

```bash
pnpm start --character="characters/sol.character.json" --host
pnpm start:client
```

Если клиент не подключается, убедитесь, что агент запущен с флагом `--host`
и что порт 3000 не занят при запуске клиента.

Для получения дополнительной информации обратитесь к
[официальной документации Eliza](https://elizaos.github.io/eliza/docs/quickstart/)

</Steps>

SendAI Agent Kit в Eliza.

## Использование GOAT Toolkit

[GOAT](https://github.com/goat-sdk/goat) — это, подобно Solana Agent Kit,
набор множества различных инструментов для блокчейна, поддерживающий различные
действия в Solana и других блокчейнах. Его также можно интегрировать, например, во фреймворк Eliza;
он поддерживает множество различных кошельков, фреймворков и блокчейнов. В данном
[примере](https://github.com/goat-sdk/goat/tree/main/typescript/examples/by-use-case/solana-purchase-on-amazon)
показано, как использовать [Crossmint](https://www.crossmint.com/) прямо в
[редакторе кода Windsurf](https://codeium.com/windsurf) для покупки товаров на Amazon.
Также доступно
[демонстрационное видео](https://x.com/windsurf_ai/status/1903118960633188485).

## Интеграция агентов с программами в блокчейне

Если вы хотите использовать ответ агента внутри программы Solana, вам необходимо использовать оракул, который записывает данные ответа в аккаунт, доступный для чтения вашей программой.
Пример LLM, который будет переводить токены любому пользователю, правильно ответившему на вопросы, можно найти здесь:

[Взаимодействие onchain-программы с LLM](https://github.com/GabrielePicco/super-smart-contracts)

Это пример onchain-программы, которая интегрируется с оракулом LLM (ИИ) для создания интерактивного агента по раздаче токенов под названием «Mar1o».

### Ключевые возможности

1. **Взаимодействие с ИИ-агентом**
   - Пользователи могут общаться с Mar1o, чтобы попытаться заработать токены
   - Агент оценивает знания пользователя о Solana и определяет количество токенов
   - Ответы представлены в формате JSON с текстом ответа и количеством токенов

2. **Управление токенами**
   - Создаёт токены MAR1O с метаданными
   - Может выпускать от 0 до 10 000 токенов на основе ответа ИИ
   - Использует PDA для управления токенами

## Продвинутые Rust-агенты для алгоритмической торговли

Если вы хотите писать своих агентов на Rust, вы можете использовать
[фреймворк Rig](https://github.com/0xPlaygrounds/rig) и библиотеку
[Listen.rs](https://github.com/piotrostr/listen).

Эти два инструмента хорошо работают вместе. Фреймворк Rig предоставляет удобный способ подключения к LLM, а набор инструментов Listen.rs обеспечивает интеграцию с Solana, включая мониторинг транзакций и их отправку с использованием Jito bundles.

## Рекомендации

- Помните, что ваш агент имеет приватный ключ и, следовательно, может получить доступ к средствам в вашем кошельке. Если кто-то сможет общаться с вашим агентом, и у того есть действие перевода, пользователи, вероятно, смогут убедить его перевести им ваши средства.
- Используйте платные [RPC-эндпоинты](https://solana.com/rpc). Публичные эндпоинты, как правило, имеют ограничения по частоте запросов
- Отслеживайте действия агента и убедитесь, что он не совершает ничего вредоносного и не поддаётся на манипуляции со стороны взаимодействующих с ним пользователей
- Реализуйте приоритетные комиссии и повторные попытки отправки транзакций для действий вашего агента, чтобы они выполнялись даже при перегрузке сети
- По возможности сначала тестируйте в devnet, прежде чем развёртывать в mainnet. Большинство агентов принимают RPC URL в качестве входных данных, и вы можете использовать devnet-адрес до готовности к mainnet. Однако не все действия могут быть доступны в devnet.
- При написании собственных действий добавляйте интеграционные тесты, чтобы фреймворки могли отслеживать, какие действия завершаются ошибкой из-за изменений в программах или API

## Заключение

ИИ-агенты на Solana открывают новые возможности для автоматизации и взаимодействия с блокчейном. Хотя не все интеграции ещё идеальны, они развиваются стремительно, предоставляют широкие возможности для вклада в экосистему и отличаются высокой гибкостью в плане добавления собственных интеграций.
