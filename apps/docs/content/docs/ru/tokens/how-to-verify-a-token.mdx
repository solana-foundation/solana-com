# Как верифицировать токен и сделать его видимым в Solana Explorer

Создатели токенов часто задают вопрос: _«Почему мой токен не отображается при
поиске в Solana Explorer и как пройти верификацию?»_

Короткий ответ: у Solana Explorer нет собственного единого процесса верификации.
Вместо этого он **агрегирует данные от нескольких независимых провайдеров верификации**.
Если ваш токен будет верифицирован хотя бы **одним** из них, он появится
в результатах поиска Explorer и будет отображать сведения о верификации.

В этом руководстве описывается каждый провайдер, что «верифицировано» означает
(и что не означает), а также как верифицировать свой токен.

## Что означает «верифицировано» (и что не означает)

Верификация подтверждает, что токен является **каноническим / правильным токеном**
для конкретного названия, символа и mint-адреса. Это помогает пользователям
избежать подделок и дублирующих токенов, поскольку любой желающий может выпустить
токен с любым именем в сети Solana.

Верификация **не** является одобрением проекта и **не** гарантирует ценность,
безопасность или легитимность токена. Всегда проводите собственное исследование.

## Провайдеры верификации, используемые Solana Explorer

Solana Explorer обращается к следующим независимым провайдерам верификации. Как только
ваш токен будет принят хотя бы одним из них (RugCheck работает автоматически;
остальные требуют активных действий), он появится в поиске Explorer.

### 1. RugCheck (автоматически)

[RugCheck](https://rugcheck.xyz) выполняет автоматизированный анализ данных в блокчейне
и отслеживает токены в автоматическом режиме. Поскольку процесс автоматический,
вам, как правило, не нужно ничего отправлять — RugCheck самостоятельно оценивает
on-chain сигналы риска (полномочия mint/freeze, распределение держателей,
ликвидность и т. д.) и начинает отслеживать токен.

Для некоторых стейблкоинов предусмотрена особая обработка: проекты могут
напрямую связаться с командой RugCheck для получения соответствующего статуса.

Пример страницы токена:
[`rugcheck.xyz/tokens/<mint>`](https://rugcheck.xyz/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 2. Jupiter

[Jupiter](https://jup.ag) ведёт верифицированный список токенов (VRFD), широко
интегрированный по всей экосистеме Solana — DEX-биржами, кошельками и скринерами.
Верифицированный токен получает зелёную галочку во всех продуктах Jupiter
и на партнёрских платформах.

Для верификации отправьте токен на проверку:

- Подайте заявку на [verified.jup.ag/tokens](https://verified.jup.ag/tokens)
- Подать заявку может любой желающий (не только команда проекта)
- По желанию можно привязать X-аккаунт проекта, чтобы связать mint-адрес токена
  с конкретным аккаунтом
- Jupiter проводит комплексную проверку (ликвидность, соответствие стандартам
  метаданных и другие сигналы), а не анализирует один отдельный показатель

Пример страницы токена:
[`jup.ag/tokens/<mint>`](https://jup.ag/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 3. CoinGecko

Верификация в [CoinGecko](https://www.coingecko.com) размещает ваш токен вместе с рыночными
данными. При верификации через CoinGecko обязательно укажите **mint-адрес** токена
(в форме CoinGecko это поле называется «contract address»), чтобы сторонние
интеграции могли корректно подтягивать цены.

Следуйте официальному руководству CoinGecko по листингу и обновлению:

- [Руководство по верификации для запросов на листинг и обновление на CoinGecko](https://support.coingecko.com/hc/en-us/articles/23725417857817-Verification-Guide-for-Listing-Update-Requests-on-CoinGecko)

Пример страницы монеты:
[`coingecko.com/en/coins/<token>`](https://www.coingecko.com/en/coins/usdc)

### 4. Solflare

[Solflare](https://solflare.com) является независимым validator в системе верификации
Solana Explorer. На практике критерии листинга токенов Solflare во многом
пересекаются с критериями Jupiter, поскольку список токенов для свопа внутри
приложения Solflare построен на агрегаторе Jupiter. Чтобы новый токен появился
в системе, как правило, необходимо:

- Быть действительным токеном в блокчейне Solana с метаданными, соответствующими
  стандарту Metaplex Token Metadata
- Обеспечить достаточную ликвидность (минимальный объём токена в USD, доступный
  для торговли)
- Удерживать ценовое влияние в допустимых пределах для стандартных свопов

Из-за этого пересечения токены, прошедшие верификацию в Jupiter, зачастую уже
соответствуют требованиям Solflare без отдельной заявки — как правило, вам не нужно
рассматривать Solflare как дополнительный ручной шаг. После выполнения критериев
токены обычно появляются в течение нескольких минут. Подробнее:

- [Не могу найти токен в Solflare](https://help.solflare.com/en/articles/9260147-i-cannot-find-a-token-in-solflare)

Пример страницы токена:
[`solflare.com/prices/<name>/<mint>`](https://www.solflare.com/prices/usd-coin/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/)

### 5. Bluprynt (расширенная KYC-верификация)

[Bluprynt](https://app.bluprynt.com/register/account) предлагает расширенный
путь верификации с KYC-протоколом. Это более строгий процесс с подтверждением
личности, подходящий для проектов, которым требуется более весомый сигнал верификации.

- Зарегистрируйтесь через
  [онбординг Bluprynt для Solana Explorer](https://app.bluprynt.com/register/account)

Пример страницы верифицированного актива:
[`verified.bluprynt.com/verified-assets/<mint>/solana`](https://verified.bluprynt.com/verified-assets/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/solana)

## Как всё это работает вместе

- **RugCheck** работает автоматически на основе on-chain анализа — никаких заявок
  не требуется.
- **Jupiter, CoinGecko, Solflare и Bluprynt** — каждый из них требует самостоятельно
  подать заявку или пройти соответствующий процесс.
- Как только ваш токен будет верифицирован **хотя бы одним** из этих провайдеров,
  он появится в поиске **Solana Explorer** и будет отображать сведения о верификации.

Если ваш токен ещё не отображается в поиске Explorer, самый быстрый путь — как
правило, подать заявку на верификацию в Jupiter и/или пройти листинг на CoinGecko,
поскольку оба сервиса широко интегрированы по всей экосистеме.

## Предварительные условия, повышающие шансы на успешную верификацию

Независимо от выбранного провайдера, следующие on-chain основы значительно
повышают вероятность успешной верификации:

- **Корректные метаданные**: у токена должны быть on-chain метаданные, соответствующие
  стандарту Metaplex Token Metadata (название, символ, URI логотипа).
- **Ликвидность**: обеспечьте достаточную ликвидность на поддерживаемой DEX-бирже,
  чтобы токен можно было торговать и оценивать.
- **Правильный mint-адрес**: при подаче заявки любому провайдеру всегда используйте
  **mint-адрес** вашего токена (в некоторых формах провайдеров он называется «contract address»).

## Итоги

Solana Explorer агрегирует данные от нескольких независимых провайдеров верификации — **RugCheck**
(автоматически), **Jupiter**, **CoinGecko**, **Solflare** и **Bluprynt** (KYC).
Верификация через любого из них делает ваш токен доступным для поиска в Explorer.
Верификация подтверждает каноническую идентичность токена; это не является одобрением,
поэтому пользователям всегда следует проводить собственное исследование.
