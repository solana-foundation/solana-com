---
title: "Быстрый старт: создание токена с помощью CLI"
description:
  Create a token, open a token account, mint supply, and transfer tokens using
  the SPL Token CLI on devnet.
---

Это руководство по быстрому старту охватывает полный жизненный цикл токена с использованием CLI _sh`spl-token`_. Вы создадите mint, создадите аккаунт для хранения токена, выпустите 100 токенов и переведёте часть из них в другой кошелёк.

Используйте [Solana Playground](https://beta.solpg.io/), чтобы выполнять команды прямо в браузере, или установите CLI локально с помощью `cargo install spl-token-cli`. Адреса в вашем выводе будут отличаться от приведённых ниже примеров.

## 1. Подключение к devnet

Создайте или подключите кошелёк в Solana Playground, затем выберите devnet и запросите SOL для пополнения аккаунта и оплаты комиссий за транзакции:

```terminal
$ solana config set --url devnet
$ solana airdrop 2
```

Используйте токены devnet только для тестирования. Они не имеют финансовой ценности.

## 2. Создание токена

Создайте mint account, который идентифицирует ваш токен:

```terminal
$ spl-token create-token
```

Скопируйте адрес токена из вывода. Это mint-адрес, который вы будете использовать в последующих командах. Новый mint начинается с нулевым объёмом предложения.

```terminal
$ spl-token supply <MINT_ADDRESS>
```

## 3. Создание token account

Вашему кошельку нужен token account для данного mint, прежде чем он сможет хранить баланс:

```terminal
$ spl-token create-account <MINT_ADDRESS>
```

Это создаёт ваш [associated token account](/docs/tokens#associated-token-account), адрес которого формируется на основе вашего кошелька и mint.

## 4. Выпуск токенов

Выпустите 100 токенов на ваш associated token account:

```terminal
$ spl-token mint <MINT_ADDRESS> 100
$ spl-token balance <MINT_ADDRESS>
```

Mint-authority должна подписать эту операцию. Выпуск токенов увеличивает как баланс вашего token account, так и общий объём предложения, зафиксированный mint.

## 5. Перевод токенов

Отправьте 10 токенов на другой кошелёк в devnet. Опция _sh`--fund-recipient`_ создаёт associated token account получателя, если он ещё не существует:

```terminal
$ spl-token transfer <MINT_ADDRESS> 10 <RECIPIENT_WALLET_ADDRESS> --fund-recipient
```

Перевод изменяет балансы в token accounts отправителя и получателя; общий объём предложения mint при этом не изменяется.

## Дополнительно: добавление метаданных Token-2022

Чтобы сохранить имя, символ и URI непосредственно в новом mint Token-2022, создайте его с включённым расширением метаданных:

```terminal
$ spl-token create-token \
  --program-id TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb \
  --enable-metadata
```

Затем используйте новый mint-адрес, выведенный этой командой:

```terminal
$ spl-token initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  "EXAMPLE" \
  "https://example.com/token.json"
```

URI должен возвращать публичный JSON-документ с метаданными. Смотрите [Token-2022 metadata](/docs/tokens/extensions/metadata) для ознакомления с моделью аккаунта и примерами кода.
