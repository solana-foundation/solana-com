Настройте локальную среду разработки Solana с помощью автоматического установщика. Он
устанавливает Rust, Solana CLI, Anchor CLI, Surfpool CLI, Node.js и Yarn в
macOS, Linux или Windows через WSL.

<Callout type="info" title="Для Windows требуется WSL">
  В Windows PowerShell выполните `wsl --install`, при необходимости перезагрузите Windows, затем
  выполните приведённые ниже команды установки в терминале Ubuntu. Полную настройку
  WSL см. в [руководстве по ручной установке](/docs/intro/installation/dependencies).
</Callout>

## Быстрая установка

1. Запустите установщик в терминале macOS, Linux или WSL:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
```

Вы можете
[просмотреть исходный код установщика](https://github.com/solana-developers/solana-install/blob/main/install.sh)
перед его запуском. Установщик определяет поддерживаемые менеджеры пакетов Linux и
автоматически устанавливает системные зависимости.

2. Перезапустите терминал, чтобы новые команды стали доступны в `PATH`.

3. Проверьте каждый инструмент:

```terminal
$ rustc --version
$ solana --version
$ anchor --version
$ surfpool --version
$ node --version
$ yarn --version
```

При успешной установке вывод будет иметь следующий вид (номера версий меняются по мере
выхода новых версий инструментов):

```txt title="Example output"
Installed Versions:
Rust: rustc x.y.z (...)
Solana CLI: solana-cli x.y.z (..., client:Agave)
Anchor CLI: anchor-cli x.y.z
Surfpool CLI: surfpool x.y.z
Node.js: vx.y.z
Yarn: x.y.z
```

<Callout type="warn" title="Установщик завершился с ошибкой или команда отсутствует">
  Следуйте [руководству по ручной установке](/docs/intro/installation/dependencies),
  чтобы установить каждую зависимость по отдельности или устранить связанные с ней неполадки.
</Callout>
