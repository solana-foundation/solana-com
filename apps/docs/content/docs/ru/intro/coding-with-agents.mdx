## Использование Solana MCP

Наиболее эффективный способ использовать ИИ для разработки на Solana — это
[Solana Developer MCP](https://mcp.solana.com/) (Model Context Protocol). Данная
интеграция привносит специализированные знания о Solana непосредственно в вашу IDE, предоставляя
вашим агентам доступ к актуальной документации Solana и делая разработку
быстрее и эффективнее.

## Что такое Solana MCP?

Solana MCP — это специализированный ИИ-ассистент, который интегрируется непосредственно в
IDE с поддержкой ИИ, такие как Cursor и Windsurf. Когда вы задаёте вопросы,
связанные с Solana, он автоматически обращается к серверу MCP для предоставления точной
и актуальной информации из:

- [Документации Solana](/docs)
- [Документации фреймворка Anchor](https://www.anchor-lang.com/docs)
- [Примеров программ](https://github.com/solana-developers/program-examples) Solana
- Вопросов и ответов [Solana Stack Exchange](https://solana.stackexchange.com/)

## Примеры использования

Вы можете использовать MCP для:

- Изучения концепций Solana
- Отладки ошибок программ
- Получения рекомендаций по лучшим практикам
- Обучения на примерах экспертов
- Ускорения разработки с помощью эксперта

## Настройка Solana MCP

Подробное руководство по настройке и началу работы можно найти на
[сайте Solana MCP](https://mcp.solana.com/).

## Предпочитаете использовать навык?

Если вы предпочитаете использовать навык, установите официальный навык Solana с помощью:

```bash
npx skills add https://github.com/solana-foundation/solana-dev-skill
```

Просматривайте больше готовых рабочих процессов в [библиотеке навыков Solana Agent](/skills).
