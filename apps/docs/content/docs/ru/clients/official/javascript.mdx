## Solana Kit

`@solana/kit` — рекомендуемый TypeScript SDK для разработки на Solana. Вы
собираете клиент из компонуемых плагинов, добавляете React-биндинги по мере
необходимости и подключаете сгенерированные программные клиенты для вызываемых
on-chain программ.

| Пакет                   | Описание                                  | GitHub                                                                                 |
| ------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------- |
| @solana/kit               | Основной SDK: RPC, транзакции, кодеки, подписанты | [Исходный код](https://github.com/anza-xyz/kit)                                              |
| @solana/react             | React-биндинги: `ClientProvider` и хуки   | [Исходный код](https://github.com/anza-xyz/kit/tree/main/packages/react)                     |
| @solana/kit-plugin-rpc    | RPC-подключение + отправка транзакций         | [Исходный код](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-rpc)    |
| @solana/kit-plugin-signer | Плагины для плательщика комиссий, идентификации и подписи      | [Исходный код](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-signer) |
| @solana/kit-plugin-wallet | Подключение Wallet Standard + React-хуки     | [Исходный код](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-wallet) |

## Solana Web3.js v3

`@solana/web3.js` v3 — рекомендуемая версия web3.js. Она заново реализует
классический API на основе классов — `Connection`, `Keypair`, `Transaction`, `PublicKey` —
поверх внутренних компонентов `@solana/kit`, поэтому работает с примитивами Kit и
с клиентами программ, описанными выше. Используйте её, если вы обновляете существующее приложение на web3.js или
предпочитаете API на основе классов.

Большинство методов, которые в прежнем SDK были синхронными, например
`Keypair.generate()` и `transaction.sign()`, теперь асинхронные.

```bash
npm install @solana/web3.js@3
```

| Пакет         | Описание | GitHub                                                        |
| --------------- | ----------- | ------------------------------------------------------------- |
| @solana/web3.js | Основной SDK    | [Исходный код](https://github.com/solana-foundation/solana-web3.js) |

`@solana/spl-token` зависит от `@solana/web3.js` (legacy) и не работает на
v3. Вместо него используйте `@solana-program/token` или `@solana-program/token-2022`; их
сгенерированные инструкции и планы инструкций напрямую работают с
`Transaction.add()` из v3.

- [Руководство по миграции с web3.js v1 на v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
- [Руководство по миграции spl-token](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-spl-token-migration.md)

## Solana Web3.js (устаревшая версия)

`@solana/web3.js` (legacy, `1.x`) — исходный SDK на TypeScript для Solana. Он
находится в режиме поддержки и получает только критические исправления. Существующие кодовые базы можно
[обновить до web3.js v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
или [перенести на Kit](/docs/frontend/web3-compat).
