Используйте [Pay](https://pay.sh), чтобы запустить API x402 V2 и предоставить Claude Code
HTTP-клиент с поддержкой платежей. API, кошелёк плательщика и расчёты используют
песочницу Solana, поэтому для этого руководства не требуется аккаунт или реальные средства.

Вам понадобятся терминал, Pay и установленный Claude Code.

## 1. Установите Pay

В macOS установите готовый бинарный файл:

```bash
brew install pay
pay --version
```

На других платформах установите npm-пакет:

```bash
npm install --global @solana/pay
pay --version
```

## 2. Запустите sandbox API x402

Создайте файл `x402-demo.yaml`:

```yaml filename=x402-demo.yaml
name: x402-demo
subdomain: x402-demo
title: "x402 Demo"
description: "Minimal x402 V2 sandbox endpoint."
category: devtools
version: v1
routing:
  type: respond
operator:
  currencies:
    usd: ["USDC"]
  network: "localnet"
  fee_payer: true
endpoints:
  - method: GET
    path: "report"
    description: "Return a sandbox report."
    metering:
      schemes: [x402-exact]
      dimensions:
        - direction: usage
          unit: requests
          scale: 1
          tiers:
            - price_usd: 0.001
```

Запустите API и оставьте его работающим:

```bash
pay --sandbox server start x402-demo.yaml --bind 127.0.0.1:1402
```

Схема `x402-exact` делает эту конечную точку доступной только для x402. Режим песочницы
автоматически создаёт и пополняет временные аккаунты оператора и плательщика.

## 3. Запустите агента с помощью Pay

В другом терминале запустите Claude Code в режиме песочницы:

```bash
pay --sandbox claude
```

Pay подключает свои локальные MCP-инструменты к сессии агента. Агент не
получает закрытый ключ.

## 4. Выполните один запрос x402

Вставьте этот промпт в агент:

```text
Use Pay to make exactly one sandbox x402 API request to
http://127.0.0.1:1402/report.

Before paying, show me the amount and ask for approval. Then return the API
result and payment receipt. Do not make any other paid requests.
```

Запрос проходит один полный цикл платежа x402 V2:

1. API возвращает `402 Payment Required` с запросом `PAYMENT-REQUIRED`.
2. Pay проверяет требования x402 и отображает условия платежа.
3. После подтверждения кошелёк песочницы подписывает транзакцию, а Pay повторяет запрос
   с `PAYMENT-SIGNATURE`.
4. API возвращает результат вместе с квитанцией `PAYMENT-RESPONSE`.

Реальные средства не перемещаются. Отклонение подтверждения останавливает запрос.

Продолжите с [x402 в Solana](/docs/payments/agentic-payments/x402), чтобы создать
клиент и сервер ресурсов x402 V2, или
[станьте фасилитатором x402](/docs/tools/x402-facilitator).
