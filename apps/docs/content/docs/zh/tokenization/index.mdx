Solana 专为大规模发行和运营代币化资产而生：亚秒级最终确认、低于 $0.001 的手续费，以及原生支持合规控制的代币标准——包括转账限制、暂停功能、隐私转账和永久委托——而这些功能在其他链上均需自定义智能合约才能实现。

## 整体架构解析

Solana 上的代币化资产基于 [Token-2022 program](/docs/tokens) 及其 [扩展功能](/docs/tokens/extensions) 构建——与核心文档中记录的基础原语相同。本节以工作流为导向：每个页面从头到尾介绍一项具体任务，并在需要完整 API 参考时链接至对应的扩展功能文档。
