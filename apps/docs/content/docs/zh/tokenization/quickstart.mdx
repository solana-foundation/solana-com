## 连接到开发网

将 RPC URL 替换为开发网地址，并从[水龙头](/developers/cookbook/development/airdrops-and-faucets)为付款方账户充值：

```ts
solanaRpc({
  rpcUrl: "https://api.devnet.solana.com",
  rpcSubscriptionsUrl: "wss://api.devnet.solana.com"
});
```

其余配置保持不变。在主网上使用相同配置之前，请规划好资产的权限管理、合规操作和监控方案。
