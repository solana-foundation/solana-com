---
title: "快速入门：使用 CLI 创建代币"
description:
  Create a token, open a token account, mint supply, and transfer tokens using
  the SPL Token CLI on devnet.
---

本快速入门将通过 _sh`spl-token`_ CLI 完整演示代币的生命周期。您将创建一个 mint，创建一个可持有该代币的账户，铸造 100 个代币，并将部分代币转移到另一个钱包。

使用 [Solana Playground](https://beta.solpg.io/) 在浏览器中运行命令，或通过 `cargo install spl-token-cli` 在本地安装 CLI。您的输出中显示的地址将与以下示例不同。

## 1. 连接到开发网络（devnet）

在 Solana Playground 中创建或连接钱包，然后选择 devnet 并申请 SOL 用于账户押金和交易费：

```terminal
$ solana config set --url devnet
$ solana airdrop 2
```

devnet 代币仅供测试使用，不具备任何实际财务价值。

## 2. 创建代币

创建用于标识您代币的 mint account：

```terminal
$ spl-token create-token
```

从输出中复制代币地址，这就是您在后续命令中将用到的 mint 地址。新建的 mint 初始供应量为零。

```terminal
$ spl-token supply <MINT_ADDRESS>
```

## 3. 创建 token account

在持有余额之前，您的钱包需要为该 mint 创建一个 token account：

```terminal
$ spl-token create-account <MINT_ADDRESS>
```

这将创建您的 [associated token account](/docs/tokens#associated-token-account)，其地址由您的钱包和 mint 共同派生。

## 4. 铸造代币

将 100 个代币铸造到您的 associated token account：

```terminal
$ spl-token mint <MINT_ADDRESS> 100
$ spl-token balance <MINT_ADDRESS>
```

此操作需要铸造权限方签名。铸造操作将同时增加您的 token account 余额和 mint 记录的总供应量。

## 5. 转移代币

向另一个 devnet 钱包发送 10 个代币。_sh`--fund-recipient`_ 选项将在接收方的 associated token account 不存在时自动创建它：

```terminal
$ spl-token transfer <MINT_ADDRESS> 10 <RECIPIENT_WALLET_ADDRESS> --fund-recipient
```

转移操作将改变发送方和接收方 token account 中的余额，但不会改变 mint 的总供应量。

## 可选：添加 Token-2022 元数据

如需在新的 Token-2022 mint 上直接存储名称、符号和 URI，请在启用元数据扩展的情况下创建它：

```terminal
$ spl-token create-token \
  --program-id TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb \
  --enable-metadata
```

然后使用该命令输出的新 mint 地址：

```terminal
$ spl-token initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  "EXAMPLE" \
  "https://example.com/token.json"
```

URI 应返回一个公开的 JSON 元数据文档。账户模型和代码示例请参阅 [Token-2022 metadata](/docs/tokens/extensions/metadata)。
