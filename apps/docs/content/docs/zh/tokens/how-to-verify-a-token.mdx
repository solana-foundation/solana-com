# 如何验证代币并使其显示在 Solana Explorer 中

代币创建者常见的问题是：_"为什么我在 Solana Explorer 上搜索时找不到我的代币，如何才能通过验证？"_

简而言之：Solana Explorer 并不运行其自有的单一验证流程，而是**聚合了多个独立的验证提供商**。只要你的代币通过了其中**任意一个**提供商的验证，它就会出现在 Explorer 的搜索结果中并显示验证信息。

本指南将介绍每个提供商、"已验证"的含义（以及不代表什么），以及如何让你的代币通过验证。

## "已验证"的含义（以及不代表什么）

验证确认某个代币是特定名称、符号和铸造地址所对应的**权威/正确代币**。由于任何人都可以在 Solana 上以任意名称铸造代币，验证有助于用户避免冒充者和重复代币。

验证**并非**对项目的背书，也**不是**对代币价值、安全性或合法性的保证。请务必自行进行研究。

## Solana Explorer 背后的验证提供商

Solana Explorer 会检查以下独立验证方。只要被其中任意一个收录（RugCheck 为自动收录；其他需要主动操作），你的代币就会出现在 Explorer 搜索中。

### 1. RugCheck（自动）

[RugCheck](https://rugcheck.xyz) 执行自动化的链上分析并自动追踪代币。由于该流程是自动进行的，你通常无需提交任何内容——RugCheck 会自行评估链上风险信号（铸造/冻结权限、持有者分布、流动性等）并自动追踪该代币。

对于某些稳定币，项目方可以直接联系 RugCheck 团队以获得相应处理。

代币页面示例：
[`rugcheck.xyz/tokens/<mint>`](https://rugcheck.xyz/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 2. Jupiter

[Jupiter](https://jup.ag) 维护着一份已验证代币列表（VRFD），该列表在 Solana 生态系统中被广泛集成——包括 DEX、钱包和行情工具。已验证的代币将在 Jupiter 产品及合作伙伴平台上显示绿色对勾标识。

如需获得验证，请提交你的代币进行审核：

- 在 [verified.jup.ag/tokens](https://verified.jup.ag/tokens) 提交
- 任何人均可提交代币（不限于项目团队）
- 你可以选择关联项目的 X 账户，将代币的铸造地址与特定账户绑定
- Jupiter 会进行综合审核（流动性、元数据标准合规性及其他信号），而非仅检查单一指标

代币页面示例：
[`jup.ag/tokens/<mint>`](https://jup.ag/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 3. CoinGecko

[CoinGecko](https://www.coingecko.com) 验证会将你的代币连同市场数据一并列出。在向 CoinGecko 提交验证时，请务必填写代币的**铸造地址**（CoinGecko 表单中将其标记为"合约地址"），以便下游集成能够正确解析价格。

请参阅 CoinGecko 官方上币/更新指南：

- [CoinGecko 上币与更新申请的验证指南](https://support.coingecko.com/hc/en-us/articles/23725417857817-Verification-Guide-for-Listing-Update-Requests-on-CoinGecko)

代币页面示例：
[`coingecko.com/en/coins/<token>`](https://www.coingecko.com/en/coins/usdc)

### 4. Solflare

[Solflare](https://solflare.com) 是 Solana Explorer 验证框架中的一个独立 validator。实际上，其代币上币标准与 Jupiter 的高度重合，因为 Solflare 应用内的兑换列表由 Jupiter 聚合器提供支持。新代币若要出现，通常需要满足以下条件：

- 是 Solana 区块链上的有效代币，且元数据符合 Metaplex Token Metadata 标准
- 具备足够的流动性（可供交易的代币需达到一定的最低 USD 价值）
- 在典型兑换场景下，价格影响维持在可接受范围内

由于存在上述重叠，完成 Jupiter 验证的代币通常无需单独提交即可满足 Solflare 的上币条件——因此一般无需将 Solflare 视为额外的手动步骤。满足条件后，代币通常会在几分钟内出现。请参阅：

- [我在 Solflare 中找不到某个代币](https://help.solflare.com/en/articles/9260147-i-cannot-find-a-token-in-solflare)

代币页面示例：
[`solflare.com/prices/<name>/<mint>`](https://www.solflare.com/prices/usd-coin/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/)

### 5. Bluprynt（增强 KYC）

[Bluprynt](https://app.bluprynt.com/register/account) 提供一条包含 KYC 协议的增强验证路径。这是一个更为严格的身份认证流程，适合希望获得更强验证信号的项目。

- 通过
  [Bluprynt Solana Explorer 入驻流程](https://app.bluprynt.com/register/account)进行注册

已验证资产页面示例：
[`verified.bluprynt.com/verified-assets/<mint>/solana`](https://verified.bluprynt.com/verified-assets/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/solana)

## 整体流程概览

- **RugCheck** 通过链上分析自动完成——无需提交。
- **Jupiter、CoinGecko、Solflare 和 Bluprynt** 各自要求你提交信息或完成其对应的流程。
- 一旦你的代币通过**至少一个**提供商的验证，它就会出现在 **Solana Explorer** 搜索结果中并显示验证详情。

如果你的代币尚未出现在 Explorer 搜索结果中，最快的方式通常是提交 Jupiter 验证和/或完成 CoinGecko 上币，因为两者在整个生态系统中均被广泛集成。

## 有助于验证成功的前提条件

无论选择哪个提供商，以下链上基础条件都能显著提升验证成功的可能性：

- **有效的元数据**：你的代币应具备遵循 Metaplex Token Metadata 标准的链上元数据（名称、符号、Logo URI）。
- **流动性**：在支持的 DEX 上提供足够的流动性，以便代币可被交易和评估。
- **正确的铸造地址**：向任何提供商提交时，请始终使用你代币的**铸造地址**（在部分提供商的表单中标记为"合约地址"）。

## 总结

Solana Explorer 聚合了多个独立验证方——**RugCheck**（自动）、**Jupiter**、**CoinGecko**、**Solflare** 和 **Bluprynt**（KYC）。通过其中任意一个验证，你的代币即可在 Explorer 搜索中被发现。验证确认的是代币的权威身份；这并非背书，因此用户应始终自行进行研究。
