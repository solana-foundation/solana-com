Solana 的单一全局状态、约 400 毫秒的出块时间和不足一分钱的手续费，使其成为链上金融与 DeFi 的核心阵地：每个程序——DEX、借贷市场、预言机、永续合约——均可在单个原子交易中进行组合。本节是构建金融应用程序的工作流层，并向下链接至 [核心概念](/docs/core/transactions) 和 [开发手册](/developers/cookbook)，以了解底层机制。
