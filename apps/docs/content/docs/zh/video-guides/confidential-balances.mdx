Confidential Balances 是 Token-2022 的一项扩展功能,可在 Solana 上对转账金额和余额进行加密,而 token account 地址仍保持公开。本视频将介绍其工作原理,以及它对工资发放、交易和日常支付的意义。建议搭配 [Confidential Balances 指南](/docs/tokens/extensions/confidential-transfer)一起阅读。
