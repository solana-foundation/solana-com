本节提供了一些常用命令和示例，帮助您开始使用
[Anchor CLI](https://www.anchor-lang.com/docs)。

<Steps>
<Step>

### 初始化项目

运行下面所示的命令来创建一个新的 Anchor 项目。该命令会创建一个以项目名称命名的新目录,并使用它来初始化新的 Anchor 项目。

```terminal
$ anchor init <project-name>
```

例如,下面的命令将创建一个名为 `my-project` 的项目。`my-project` 目录中将包含一个模块化的 Rust 程序,以及一个使用 LiteSVM 的 Rust 测试模板。

```terminal
$ anchor init my-project
```

如需改为生成 TypeScript 测试模板,请明确指定一个模板。例如,使用 Mocha 模板:

```terminal
$ anchor init my-project --test-template mocha
```

TypeScript 测试模板需要 Node.js 和 JavaScript 包管理器。

然后进入项目目录:

```terminal
$ cd <project-name>
```

请参阅 Anchor 的[项目文件结构](https://www.anchor-lang.com/docs/quickstart/local#project-file-structure)。

</Step>
<Step>

### 构建程序

要构建您的项目，请运行以下命令：

```terminal
$ anchor build
```

编译后的程序可以在 `/target/deploy` 目录中找到。

<Callout type="warn" title="平台工具安装失败">
  如果构建时提示平台工具目录无效,请重新安装 SBF 构建工具,然后重试构建:

```terminal
$ cargo build-sbf --force-tools-install
$ anchor build
```

</Callout>

</Step>
<Step>

### 部署程序

要部署您的项目，请运行以下命令：

```terminal
$ anchor deploy
```

此命令会将您的程序部署到
[`Anchor.toml`](https://www.anchor-lang.com/docs/references/anchor-toml)
文件中指定的 `cluster`。

</Step>
<Step>

### 测试程序

要测试您的项目，请运行以下命令：

```terminal
$ anchor test
```

此命令会构建、部署并运行您的项目测试。

<Callout>
  当使用 `localnet` 集群时，Anchor 会自动启动本地
  validator，部署程序，运行测试，然后停止 validator。
</Callout>

<Callout type="warn" title="JavaScript 测试运行器错误">

如果您选择了 JavaScript 或 TypeScript 测试模板,以下任一错误都可能表示未安装 Node.js 或所配置的包管理器:

```
Permission denied (os error 13)
```

```
No such file or directory (os error 2)
```

</Callout>

</Step>
</Steps>
