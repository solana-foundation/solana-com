如果你需要安装特定版本，或者[快速安装](/docs/intro/installation)未能成功完成，请单独安装每个依赖项。
对于全新的环境，请按顺序阅读各部分；你也可以直接跳转到需要安装或排查问题的工具。

## 前置条件

<Accordions>
<Accordion title="Windows">

在 Windows 上开发 Solana 程序时，**必须**使用
[Windows Subsystem for Linux](https://learn.microsoft.com/en-us/windows/wsl/install)（WSL）。安装 WSL 后，其他依赖项都将在 Linux 终端中安装。

要安装 WSL，请在 Windows PowerShell 中运行以下命令：

```terminal
$ wsl --install
```

安装过程中会提示你创建一个默认用户账户。

![WSL 安装](/assets/docs/intro/installation/wsl-install.png)

默认情况下，WSL 会安装 Ubuntu。你可以在搜索栏中输入“Ubuntu”来打开 Linux 终端。

![WSL Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-search.png)

如果你的 Ubuntu 终端界面如下图所示，可能会遇到
`ctrl + v`（粘贴快捷键）在终端中无法使用的问题。

![Ubuntu 终端](/assets/docs/intro/installation/wsl-ubuntu-terminal-1.png)

如果遇到此问题，请在搜索栏中输入“Terminal”打开 Windows Terminal。

![Windows Terminal](/assets/docs/intro/installation/wsl-windows-terminal.png)

接下来，关闭 Windows
Terminal，然后再次在搜索栏中输入 Ubuntu 打开 Linux 终端。此时终端应如下图所示，`ctrl + v`（粘贴快捷键）可以正常使用。

![Ubuntu 终端](/assets/docs/intro/installation/wsl-ubuntu-terminal-2.png)

如果你使用 VS
Code，[WSL 扩展](https://code.visualstudio.com/docs/remote/wsl-tutorial)可以让你在 WSL 和 VS
Code 间协同开发。

![在 VS Code 中设置 WSL](/assets/docs/intro/installation/wsl-vscode.png)

您将在 VS Code 状态栏中看到如下内容：

![WSL：Ubuntu](/assets/docs/intro/installation/wsl-vscode-ubuntu.png)

完成 WSL 设置后，您可以选择：

- 使用 Ubuntu（Linux）终端完成[快速安装](/docs/intro/installation)
- 按下方说明分别安装 [Rust](#install-rust)、[Solana CLI](#install-solana-cli) 和
  [Anchor CLI](#install-anchor-cli)

</Accordion>
<Accordion title="Linux">

<Tabs items={[".deb", ".rpm"]}>
<Tab value=".deb" >
在 Debian 或基于 Debian 的发行版（如 Ubuntu 或 Mint）上：

1. 更新软件包列表，确保所有软件包都是最新的：

```terminal
$ sudo apt-get update
```

2. 安装以下依赖项：

```terminal
$ sudo apt-get install -y \
    build-essential \
    pkg-config \
    libudev-dev llvm libclang-dev \
    protobuf-compiler libssl-dev
```

<Callout>
如果在安装 `protobuf-compiler` 时遇到以下错误，请先运行
`sudo apt-get update`，然后再重试安装命令。

```
Package protobuf-compiler is not available, but is referred to by another package.
This may mean that the package is missing, has been obsoleted, or
is only available from another source
```

</Callout>

  </Tab>

    <Tab value=".rpm" >
    在基于 RPM 的发行版（如 Fedora 或 Red Hat Enterprise Linux）上：

更新已安装的软件包：

```terminal
$ sudo dnf upgrade --refresh
```

安装开发依赖项：

```terminal
$ sudo dnf group install c-development development-tools \
&& sudo dnf install pkg-config openssl-devel
```

### 安装 Rust

开发者使用 [Rust](https://www.rust-lang.org/) 编程语言开发 Solana 程序。

1. 通过在终端中输入以下命令，使用
   [rustup](https://www.rust-lang.org/tools/install) 安装 Rust：

```terminal
$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
```

安装成功后，您将看到以下信息：

<Accordions>
<Accordion title="Rust 安装成功提示">

```
Rust is installed now. Great!

To get started you may need to restart your current shell.
This would reload your PATH environment variable to include
Cargo's bin directory ($HOME/.cargo/bin).

To configure your current shell, you need to source
the corresponding env file under $HOME/.cargo.

This is usually done by running one of the following (note the leading DOT):
. "$HOME/.cargo/env"            # For sh/bash/zsh/ash/dash/pdksh
source "$HOME/.cargo/env.fish"  # For fish
```

</Accordion>
</Accordions>

2. 重新加载您的 PATH 环境变量，将 [Cargo](https://github.com/rust-lang/cargo)
   的 bin 目录加入其中：

```terminal
$ . "$HOME/.cargo/env"
```

3. 验证安装是否成功。

```terminal
$ rustc --version
```

该命令会输出已安装的 Rust 版本，例如：

```
rustc x.y.z (...)
```

</Step>
<Step>

### 安装 Solana CLI

Solana CLI 提供了构建和部署 Solana 程序所需的全部工具。

1. 使用官方安装命令安装 Solana CLI 工具集：

```terminal
$ sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

<Callout>
  你可以将 `stable` 替换为特定的 Agave 发布标签，或者替换为 `beta`
  或 `edge` 发布通道。
</Callout>

2. 让当前终端可以使用 Solana CLI。

安装程序会更新你的 shell 配置，并输出更新当前会话所需的命令。该命令通常是：

```terminal
$ export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"
```

如果仍然无法使用 `solana`，请重启终端。要确认安装程序更新了哪个 shell
配置文件，请检查当前使用的 shell：

```terminal
$ echo $SHELL
```

- 如果输出包含 `/bash`，请重启终端或运行
  `source ~/.bashrc`。
- 如果输出包含 `/zsh`，请重启终端或运行 `source ~/.zshrc`。

3. 验证安装是否成功：

```terminal
$ solana --version
```

该命令会输出已安装的 Solana CLI 版本，例如：

```
solana-cli x.y.z (..., client:Agave)
```

<Callout>

你可以在 [Agave GitHub 仓库](https://github.com/anza-xyz/agave/releases)中查看所有可用版本。Agave 是
[Anza](https://www.anza.xyz/) 开发的 validator 客户端，前身为
Solana Labs validator 客户端。

</Callout>

4. 如需日后更新 Solana CLI，请运行：

```terminal
$ agave-install update
```

</Step>
<Step>

### 安装 Anchor CLI

[Anchor](https://www.anchor-lang.com/)
是一个用于开发 Solana 程序的框架。Anchor 框架利用 Rust 宏，简化了编写 Solana 程序的流程。

#### 前置条件

只有在选择 Mocha 或 Jest 等 TypeScript 测试模板时，才需要 Node.js 和 JavaScript 包管理器。默认的 LiteSVM 测试模板基于 Rust 运行，不需要 Node.js 工具。

<Accordions>
<Accordion title="Node 安装">

1. 运行以下命令，使用
   [Node 版本管理器（nvm）](https://github.com/nvm-sh/nvm)安装 Node：

```terminal
$ curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```

2. 重启终端，并确认 `nvm` 命令可以成功运行：

```terminal
$ command -v nvm
```

3. 使用 `nvm` 安装 Node：

```terminal
$ nvm install --lts
```

4. 通过检查 Node 版本来验证安装是否成功：

```terminal
$ node --version
```

该命令会输出已安装的 Node.js 版本，例如：

```
vx.y.z
```

</Accordion>
<Accordion title="Yarn 安装">

1. 安装 Yarn：

```terminal
$ npm install --global yarn
```

2. 通过检查 Yarn 版本来验证安装是否成功：

```terminal
$ yarn --version
```

该命令会输出已安装的 Yarn 版本，例如：

```
x.y.z
```

</Accordion>
</Accordions>

#### 安装

您可以通过两种方式安装 Anchor CLI 和相关工具：

- Anchor Version Manager (AVM) — 推荐的安装方式
- 不使用 AVM — 直接从 GitHub 安装

<Tabs groupId="anchor" items={["AVM", "Without AVM"]}>
<Tab value="AVM">

Anchor 版本管理器（AVM）可以让你在系统上安装和管理不同的 Anchor 版本，并且未来可以轻松更新 Anchor 版本。要使用 AVM 安装 Anchor，请按照以下步骤操作：

1. 使用以下命令安装 AVM：

```terminal
$ curl -sSfL https://raw.githubusercontent.com/otter-sec/anchor/master/avm/install | sh
```

2.  确认 AVM 是否安装成功：

```terminal
$ avm --version
```

3. 使用 AVM 安装 Anchor CLI：

要安装最新版本：

```terminal
$ avm install latest
$ avm use latest
```

要安装指定版本，请指定版本号：

```terminal
$ avm install 1.1.2
$ avm use 1.1.2
```

<Callout type="warn">

在 Linux 或 WSL 上安装 Anchor CLI 时，您可能会遇到以下错误：

```
error: could not exec the linker cc = note: Permission denied (os error 13)
```

如果您看到此错误信息，请按照以下步骤操作：

1. 安装本页顶部 [Linux](/docs/intro/installation/dependencies) 部分中列出的依赖项。
2. 重试安装 Anchor CLI。

</Callout>

4. 验证安装是否成功，检查 Anchor CLI 的版本：

```terminal
$ anchor --version
```

该命令会输出当前生效的 Anchor CLI 版本，例如：

```
anchor-cli 1.1.2
```

<Callout type="info">

运行 `avm use` 为你的系统选择 Anchor CLI 版本。

- 如果你安装的是最新版本，请运行 `avm use latest`。
- 如果你安装的是 `1.1.2` 版本，请运行 `avm use 1.1.2`。

</Callout>

</Tab>

<Tab value="Without AVM">

1. 使用以下命令安装特定版本的 Anchor CLI：

```terminal
$ cargo install --git https://github.com/solana-foundation/anchor --tag v1.1.2 anchor-cli --locked
```

2. 通过检查 Anchor CLI 版本来验证安装是否成功：

```terminal
$ anchor --version
```

该命令会输出已安装的 Anchor CLI 版本，例如：

```
anchor-cli 1.1.2
```

</Tab>
</Tabs>

### 安装 Surfpool CLI

[Surfpool](/docs/tools/surfpool) 是一款本地开发工具，是 `solana-test-validator` 的改进替代品。

1. 使用以下命令安装 Surfpool：

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://run.surfpool.run/ | bash
```

2. 通过检查 Surfpool CLI 版本来验证安装是否成功：

```terminal
$ surfpool --version
```

该命令会输出已安装的 Surfpool CLI 版本，例如：

```
surfpool x.y.z
```

</Step>
