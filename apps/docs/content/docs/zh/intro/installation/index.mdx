使用自动安装程序搭建本地 Solana 开发环境。它会在 macOS、Linux 或通过 WSL 的 Windows 上安装 Rust、Solana CLI、Anchor CLI、Surfpool CLI、Node.js 和 Yarn。

<Callout type="info" title="Windows 需要 WSL">
  在 Windows PowerShell 中运行 `wsl --install`,如有提示请重启 Windows,然后在 Ubuntu 终端中运行下面的安装命令。完整的 WSL 设置请参阅[手动安装指南](/docs/intro/installation/dependencies)。
</Callout>

## 快速安装

1. 在 macOS、Linux 或 WSL 终端中运行安装程序:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
```

运行前,您可以[查看安装程序源代码](https://github.com/solana-developers/solana-install/blob/main/install.sh)。该安装程序会检测受支持的 Linux 包管理器,并自动安装其系统依赖项。

2. 重启终端,以便新命令在您的 `PATH` 中可用。

3. 验证所有工具:

```terminal
$ rustc --version
$ solana --version
$ anchor --version
$ surfpool --version
$ node --version
$ yarn --version
```

安装成功后,将返回如下形式的输出(版本号会随工具发布而变化):

```txt title="Example output"
Installed Versions:
Rust: rustc x.y.z (...)
Solana CLI: solana-cli x.y.z (..., client:Agave)
Anchor CLI: anchor-cli x.y.z
Surfpool CLI: surfpool x.y.z
Node.js: vx.y.z
Yarn: x.y.z
```

<Callout type="warn" title="安装程序失败或缺少命令">
  请按照[手动安装指南](/docs/intro/installation/dependencies)逐个安装依赖项或排查问题。
</Callout>
