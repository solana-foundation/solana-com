## 使用 Solana MCP

利用 AI 进行 Solana 开发的最强大方式是通过
[Solana 开发者 MCP](https://mcp.solana.com/)（模型上下文协议）。该
集成将专业的 Solana 知识直接引入您的 IDE，使
您的智能体能够访问最新的 Solana 文档，从而让开发
更快速、更高效。

## 什么是 Solana MCP？

Solana MCP 是一款专业的 AI 助手，可直接集成到
Cursor 和 Windsurf 等支持 AI 的 IDE 中。当您提出 Solana 相关
问题时，它会自动查询 MCP 服务器，从以下来源提供准确、
最新的信息：

- [Solana 文档](/docs)
- [Anchor 框架文档](https://www.anchor-lang.com/docs)
- Solana
  [程序示例](https://github.com/solana-developers/program-examples)
- [Solana Stack Exchange](https://solana.stackexchange.com/) 问题与
  解答

## 使用场景示例

您可以使用 MCP 来：

- 了解 Solana 相关概念
- 调试程序错误
- 获取最佳实践建议
- 从专家示例中学习
- 借助专家的帮助加快开发速度

## 设置 Solana MCP

请在 [Solana MCP 官网](https://mcp.solana.com/) 上查阅详细的设置和入门指南。

## 更倾向于使用技能？

如果您更倾向于使用技能，请通过以下方式安装官方 Solana 技能：

```bash
npx skills add https://github.com/solana-foundation/solana-dev-skill
```

在 [Solana Agent 技能库](/skills) 中浏览更多可复用的工作流。
