## 时钟语义

<Callout
  type="warn"
  title="时间戳以毫秒为单位，而时钟报告的是秒"
>
  `surfnet_timeTravel` 的 `absoluteTimestamp` 以**毫秒**为单位，类似于 JavaScript 的 `Date.now()`，但程序读取的 `Clock` 系统变量报告的是**秒**。将时钟返回的值直接传入作弊码会落在 1970 年代初——由于时钟只能向前移动，该调用会被拒绝而非忽略。请先乘以 1000。
</Callout>

有关时钟作弊码的 SDK 级等效项，请参阅
[时间旅行](/docs/tools/surfpool/sdk/time-travel)。
