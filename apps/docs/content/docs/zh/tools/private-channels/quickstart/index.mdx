本快速入门将引导您完成Solana开发网上的完整Private Channels流程：
配置客户端环境、将SPL代币存入托管账户、在两个钱包之间发送
链下转账，以及将资金提回您的Solana钱包。

完成后，您将理解完整的存款 -> 链下转账 ->
提款流程，并获得每个步骤对应的可运行TypeScript代码。

<Callout type="info">
  本快速入门假设Private Channels实例已部署并
  在开发网上运行，且您的铸币地址已加入白名单。如果您需要先进行部署，
  [运营商指南](/docs/tools/private-channels/operators)涵盖了
  完整的配置流程；初始Docker构建预计需要30至60分钟。
</Callout>

## 步骤

1. **[安装](/docs/tools/private-channels/quickstart/installation)** -
   克隆代码仓库并生成TypeScript客户端（5分钟）
2. **[存入代币](/docs/tools/private-channels/quickstart/deposit)** -
   将SPL代币存入托管账户；请等待约15秒，待索引器
   更新您的通道余额
3. **[发送转账](/docs/tools/private-channels/quickstart/transfer)** -
   通过网关发送链下转账；确认时间不足一秒，
   且不会触及主网
4. **[提取资金](/docs/tools/private-channels/quickstart/withdraw)** - 销毁
   您的通道侧余额；运营商将在数秒内将资金结算至您的主网钱包
