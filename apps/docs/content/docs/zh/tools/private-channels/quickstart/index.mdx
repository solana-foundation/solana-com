本快速入门将引导您完整体验 Solana devnet 上的 Private Channels 流程：
搭建客户端环境，将 SPL 代币存入托管账户，在两个钱包之间发送
链下转账，并将资金提回您的 Solana 钱包。

完成后，您将理解完整的存款 -> 链下转账 ->
提款周期，并获得每个步骤可运行的 TypeScript 代码。

<Callout type="info">
  本快速入门假设 Private Channels 实例已部署并
  在 devnet 上运行，且您的 mint 已列入白名单。如果您需要先进行部署，
  [运营商指南](/docs/tools/private-channels/operators) 涵盖了
  完整的配置流程；初始 Docker 构建预计需要 30-60 分钟。
</Callout>

## 步骤

1. **[安装](/docs/tools/private-channels/quickstart/installation)** -
   克隆代码仓库并生成 TypeScript 客户端（5 分钟）
2. **[存入代币](/docs/tools/private-channels/quickstart/deposit)** -
   将 SPL 代币存入托管账户；索引器需约 15 秒
   将余额计入您的通道
3. **[发送转账](/docs/tools/private-channels/quickstart/transfer)** -
   通过网关发送链下转账；确认时间不足一秒，
   无需经过主网
4. **[提取资金](/docs/tools/private-channels/quickstart/withdraw)** - 销毁
   您的通道端余额；运营商将在数秒内将资金结算至您的主网钱包
