  Private Channels 尚未经过安全审计，在未经全面安全审查的情况下，不建议将其用于涉及真实资金的生产环境。
</Callout>

**Private Channels 是 Solana 上互联网资本市场的企业层。** 它为支付通道内的私密、即时、零手续费转账提供可配置的应用层：用户将 SPL 代币存入链上托管程序，通过网关进行链下交易，并通过稀疏默克尔树证明结算回主网，让应用开发者在不离开 Solana 生态的前提下实现即时、零手续费的私密转账。

### 为什么选择 Private Channels？

- **即时转账**：链下吞吐量突破 Solana 原生 TPS 限制；转账在排序器处理时即可确认，无需等待区块确认
- **零转账手续费**：通道内单笔转账无 gas 费用；用户仅需为链上充值和提现支付费用
- **隐私保护**：通道参与方之间的转账不会记录在 Solana 主网上
- **权限访问控制**：基于 JWT 认证的 RBAC 机制，让您精确管控发送方与接收方的访问权限
- **主网结算**：资金始终可通过稀疏默克尔树排除证明兑回 Solana，托管程序在链上强制执行该证明

请参阅 **[概览](/docs/tools/private-channels/overview)** 了解完整架构、数据流图及安全模型。

## 快速开始

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n, // 1 USDC
  recipient: null
});
// send via your preferred Solana client
```

TypeScript 客户端由 IDL 生成，详见安装说明。对于 Token-2022 铸币，请显式传入 `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS`，因为默认值为标准 SPL Token Program。

## 使用场景

- **机构双边支付** — 银行和机构需要大量、私密的 USDC 资金流转，同时不希望每笔转账都上链可查
- **高频应用层转账** — 游戏、积分及消费类应用需要亚秒级、零手续费的大规模转账，超越 Solana 原生 TPS
- **隐私保护型代币流转** — 任何将交易对手方及金额隐私作为产品需求的使用场景
