从实例中移除先前已允许的铸币，阻止该铸币的新存款。
现有存款不受影响。

## 账户

| 账户                          | 可写 | 签名者 | 描述                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | 手续费支付方                                    |
| `admin`                          |          | ✓      | 实例管理员                               |
| `instance`                       |          |        | 实例 PDA                                 |
| `mint`                           |          |        | 待屏蔽的 SPL 代币铸币                      |
| `allowed_mint`                   | ✓        |        | AllowedMint PDA（由本指令关闭） |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | 事件授权 PDA                          |
| `private_channel_escrow_program` |          |        | 托管程序                               |

本指令不接受任何参数。

## 重要说明

- 关闭 `allowed_mint` PDA：针对该铸币的新 `Deposit` 调用将失败，
  错误为 `InvalidAllowedMint`
- 该铸币的现有频道余额不受影响
- 通过 `EmitEvent` CPI 发出事件
