---
title: SetNewAdmin
description: 将管理员权限转移至新钱包
---

将管理员权限转移至新钱包。

## 账户

| 账户                          | 可写 | 签名者 | 描述                        |
| -------------------------------- | -------- | ------ | ---------------------------------- |
| `payer`                          | ✓        | ✓      | 手续费支付方                          |
| `current_admin`                  |          | ✓      | 当前管理员（必须签名）          |
| `instance`                       | ✓        |        | 实例 PDA（管理员字段已更新） |
| `new_admin`                      |          | ✓      | 接收管理员权限的钱包     |
| `event_authority`                |          |        | 事件权限 PDA                |
| `private_channel_escrow_program` |          |        | 托管程序                     |

此指令不需要任何参数。

## 重要说明

- **不可一步撤销**：当前管理员无法收回该角色，
  除非新管理员再次调用 `SetNewAdmin`
- 调用前请验证目标地址；操作不可撤销
- 通过 `EmitEvent` CPI 触发事件
