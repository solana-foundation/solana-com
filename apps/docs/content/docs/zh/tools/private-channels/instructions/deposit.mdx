---
title: 存款
description:
  将 SPL 代币从用户钱包转入 Private Channels 托管账户
---

将 SPL 代币从用户的 associated token account 转入托管账户的
associated token account，为存款用户的频道余额（或可选收款人的余额）记账。

## 账户

| 账户                          | 可写 | 签名者 | 描述                                          |
| -------------------------------- | -------- | ------ | ---------------------------------------------------- |
| `payer`                          | ✓        | ✓      | 交易的费用支付方                        |
| `user`                           |          | ✓      | 发起存款的代币持有者                       |
| `instance`                       |          |        | 托管实例 PDA                                  |
| `mint`                           |          |        | SPL 代币铸造账户                                       |
| `allowed_mint`                   |          |        | 验证该铸造账户在此实例中是否被允许的 PDA |
| `user_ata`                       | ✓        |        | 用户的 associated token account（来源）             |
| `instance_ata`                   | ✓        |        | 托管账户的 associated token account（目标）      |
| `system_program`                 |          |        | System Program                                       |
| `token_program`                  |          |        | SPL Token Program                                    |
| `associated_token_program`       |          |        | Associated Token Program                             |
| `event_authority`                |          |        | `EmitEvent` CPI 的事件权限 PDA              |
| `private_channel_escrow_program` |          |        | 托管程序（CPI 自引用）              |

## 参数

| 参数   | 类型             | 描述                                                                           |
| ----------- | ---------------- | ------------------------------------------------------------------------------------- |
| `amount`    | `u64`            | 存款代币数量，以代币最小单位计                             |
| `recipient` | `Option<Pubkey>` | 可选的链上收款人；若为 `None`，则为存款用户的频道余额记账 |

## 返回值

返回一个 `TransactionBuilder`，可用于构建并发送交易。

## 示例

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

// allowedMint and instanceAta are auto-derived from mint and instance
const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n,
  recipient: null
});
```

## 重要说明

- 程序 ID：`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`
- 对于 Token-2022 铸造账户，请显式传入 `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS`，
  因为默认值为标准 SPL Token Program
- `allowed_mint` PDA 必须已存在（由 `AllowMint` 创建）；存入
  未登记的铸造账户将抛出 `InvalidAllowedMint` 错误
- 当 `recipient` 为 `None` 时，存款记入存款用户的频道余额；
  若提供了收款人，则记入指定钱包的余额
- `payer` 和 `user` 均须对交易签名
- `instance_ata` 必须已存在（由 `AllowMint` 为该铸造账户创建）
