---
title: RemoveOperator
description: 通过关闭操作员 PDA 来撤销操作员
---

通过关闭 `Operator` PDA 来撤销操作员。被撤销的钱包将无法再调用 `ReleaseFunds` 或 `ResetSmtRoot`。

## 账户

| 账户                          | 可写 | 签名者 | 描述                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | 费用支付方                                 |
| `admin`                          |          | ✓      | 实例管理员                            |
| `instance`                       |          |        | 实例 PDA                              |
| `operator`                       |          |        | 待撤销的操作员钱包                 |
| `operator_pda`                   | ✓        |        | 操作员 PDA（由本指令关闭） |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | 事件权限 PDA                       |
| `private_channel_escrow_program` |          |        | 托管程序                            |

此指令不接受任何参数。

## 重要说明

- 关闭 `operator_pda`；被撤销的钱包将无法再调用
  `ReleaseFunds` 或 `ResetSmtRoot`
- 在此调用之后，所有进行中的操作员交易将因 `InvalidOperatorPda` 而失败
- 通过 `EmitEvent` CPI 触发事件
