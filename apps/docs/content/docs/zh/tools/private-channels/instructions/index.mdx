本节为链上指令参考。大多数开发者通过生成的 TypeScript 客户端调用这些指令；仅当您构建运营商工具、编写自定义集成或调试指令级错误时，才需要直接参阅本节。

**托管程序** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) - 管理存款、运营商配置及主网结算：

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) -
  初始化托管实例 PDA
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) - 将
  SPL 代币 mint 加入白名单
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) - 从
  白名单中移除一个 mint
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) -
  配置运营商
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) -
  撤销运营商
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) -
  转移管理员权限
- [Deposit](/docs/tools/private-channels/instructions/deposit) - 将 SPL 代币
  转入托管
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) -
  运营商将提款结算至主网
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) -
  运营商轮换稀疏默克尔树

**提款程序** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) - 运行于
私有通道网络：

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) -
  销毁通道侧余额以发起提款

## 错误代码

**托管程序 - `PrivateChannelEscrowProgramError`**

| 代码                                         | 消息                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | 提供的事件权限无效                 |
| `InvalidAta`                                 | 提供的 ATA 无效                             |
| `InvalidMint`                                | 提供的 mint 无效                            |
| `InvalidInstanceId`                          | 实例 ID 无效或不符合规则    |
| `InvalidInstance`                            | 提供的实例无效                        |
| `InvalidAdmin`                               | 提供的管理员无效                           |
| `TransferHookNotAllowed`                     | 不允许使用转账钩子扩展              |
| `InvalidOperatorPda`                         | 提供的运营商 PDA 无效                    |
| `InvalidTokenAccount`                        | 提供的 token account 无效                   |
| `InvalidEscrowBalance`                       | 托管余额无效                           |
| `InvalidAllowedMint`                         | 允许的 mint 无效                             |
| `InvalidSmtProof`                            | 提供的 SMT 证明无效                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | 当前树索引的交易 nonce 无效 |
| `UnexpectedTreeIndex`                        | SMT 根重置时当前树索引不符合预期 |

**提款程序 - `PrivateChannelWithdrawProgramError`**

| 代码          | 消息                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | 提供的 mint 无效                       |
| `ZeroAmount`  | 提款金额必须大于零 |
