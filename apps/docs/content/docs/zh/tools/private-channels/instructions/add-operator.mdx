---
title: AddOperator
description: 通过创建操作员 PDA 来配置新操作员
---

通过创建 `Operator` PDA 来配置新操作员。此调用完成后，
`operator` 钱包可以调用 `ReleaseFunds` 和 `ResetSmtRoot`。

## 账户

| 账户                          | 可写 | 签名者 | 描述                                                         |
| -------------------------------- | -------- | ------ | ------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | 手续费支付方                                                           |
| `admin`                          |          | ✓      | 实例管理员                                                      |
| `instance`                       |          |        | 实例 PDA                                                        |
| `operator`                       |          |        | 待配置的操作员钱包                                        |
| `operator_pda`                   | ✓        |        | 操作员 PDA - 自动从 `["operator", instance, operator]` 派生 |
| `system_program`                 |          |        | System Program                                                      |
| `event_authority`                |          |        | 事件权限 PDA                                                 |
| `private_channel_escrow_program` |          |        | 托管程序                                                      |

## 参数

| 参数 | 类型 | 描述                                                                               |
| --------- | ---- | ----------------------------------------------------------------------------------------- |
| `bump`    | `u8` | `operator_pda` 的 bump seed。可选：若省略，`Async` 客户端将自动派生 |

> IDL 包含一个 `discriminator: u8` 参数（值为 `3`），由生成的客户端自动设置，
> 不应手动传入。

## 注意事项

- 建议使用 `getAddOperatorInstructionAsync`；在未提供 `bump` 和
  `operator_pda` 时，它会自动派生这两个值。如果您已自行计算 `bump`，
  也可以使用同步版本 `getAddOperatorInstruction`
- 此调用完成后，`operator` 钱包可以调用 `ReleaseFunds` 和
  `ResetSmtRoot`
- 通过 `EmitEvent` CPI 触发事件
