  参与者、角色以及从存款到提款的流程
- **[稀疏默克尔树](/docs/tools/private-channels/concepts/smt)** - 如何
  在链上验证提款证明以防止双重支付
- **[身份验证与角色](/docs/tools/private-channels/concepts/auth)** - JWT
  身份验证、RBAC 与钱包验证
