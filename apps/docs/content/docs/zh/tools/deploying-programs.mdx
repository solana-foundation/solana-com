title: 部署程序
description: 在主网上部署程序的最佳实践
---

如果您要将自定义 Solana 程序作为支付基础设施的一部分进行部署,还需要考虑以下额外事项。

## 部署前

- **Solana CLI 版本:** 请确保您使用的是最新版本的
  [Solana CLI](https://solana.com/docs/intro/installation)。
- **程序 keypair:** 您的程序在主网上的地址将与开发网(devnet)不同(除非您重复使用同一个 keypair)。请更新应用配置中的所有相关引用。请将程序 keypair 存放在安全的位置(注意:运行 `cargo clean` 很可能会删除您的程序 keypair)。
- **初始化账户:** 如果您的程序需要管理员账户、PDA 或其他状态账户,请确保在用户与您的应用交互之前,先在主网上创建这些账户。程序所需的任何 Associated Token Account(ATA)也是如此。

## 部署流程

- **缓冲账户(Buffer accounts):** 大型程序通过缓冲账户进行部署。`solana program deploy` 命令会自动处理这一过程,但请注意,部署并非原子操作——如果中途被中断,您可能需要恢复或关闭缓冲账户。
- **升级权限:** 创建一个
  [多签(multisig)](https://docs.squads.so/main/basics/what-is-a-multisig),并将其指定为
  [您的 Solana 程序的升级权限](https://docs.squads.so/main/navigating-your-squad/developers-assets/programs)。
- **租金:** 请确保您的部署钱包中有足够的 SOL,以支付所有程序账户的免租金最低余额。
- **验证:** [验证](https://solana.com/docs/programs/verified-builds)
  您的程序,以确保您部署到 Solana 网络上的可执行程序与代码仓库中的源代码一致
