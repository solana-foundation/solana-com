---
title: 生产环境准备
description: 从 devnet 测试到主网部署
---

在本地构建并在 devnet 上测试是开始使用 Solana 支付的好方法。然而，当你准备部署到主网时，需要注意主网的一些细节。devnet 可以容忍错误，而主网则不行。本指南将介绍关键差异，帮助你的用户获得流畅的体验。

| Devnet                          | Mainnet                                                                               |
| ------------------------------- | ------------------------------------------------------------------------------------- |
| 可以通过水龙头免费获取 SOL           | [获取真实 SOL](https://solana.com/ecosystem/explore?categories=exchange) 用于支付手续费 |
| 区块空间竞争小 | 优先费很重要                                                                  |
| 交易容易确认        | 交易配置至关重要                                                 |
| 公共 RPC 可用              | 生产环境需使用专用 RPC                                                               |
| Devnet 密钥对和代币铸造       | 主网需使用不同的密钥和代币铸造——请更新你的配置                                     |

## 上线检查清单

- [ ] [准备您的程序 ELF 文件](/docs/tools/deployment-assets#preparing-your-elf-file)
- [ ] [准备您的程序地址](/docs/tools/deployment-assets#preparing-your-program-address)
- [ ] 已获取主网 SOL 用于手续费和 rent
- [ ] 已配置生产环境 RPC（非公共端点）
- [ ] 已配置备用 RPC 端点
- [ ] 已实现动态定价的优先费用
- [ ] 重试逻辑可处理区块哈希过期问题
- [ ] 确认级别与使用场景相匹配
- [ ] 所有常见错误均已妥善处理
- [ ] 已配置无 Gas 模式（如适用）
- [ ] 已验证主网代币地址（非开发网铸币账户）
- [ ] 发送前已验证收款地址（钱包 vs token account vs 铸币账户 vs 程序）
- [ ] 所有密钥已安全备份
- [ ] 已审查密钥管理方案（前端不存储密钥）
- [ ] 交易监控与告警已启用
- [ ] 已按预期负载完成压力测试
