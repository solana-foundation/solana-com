Solana 专为支付场景而设计，具备多项理想特性，包括原生费用抽象、低于一美分的手续费、内嵌备注、稳定可预期的费用以及快速确认时间。2025 年，Solana 处理了超过 [**1 万亿美元**](https://app.artemisanalytics.com/asset/solana?from=assets) 的稳定币交易量。本指南将帮助您针对多种使用场景构建高级支付系统，包括汇款、国库优化、全球批量付款、跨境支付、商户收款、发票管理等。

还不熟悉 Solana 上的余额和所有权机制？请先阅读 [核心概念](/docs/core)，再查阅 [资产](/docs/tokens)，了解支付流程中使用的代币账户和稳定币。

## 为什么选择 Solana

- **即时结算**。资金在约 400 毫秒内完成确认。无需 T+2，无需手动批处理，无需对账等待。
- **低于一美分的手续费**。每笔交易中位费用约为 $0.001。将多笔支付批量打包至单笔交易，进一步提升支付效率并降低成本。
- **本地费用市场**。专为支付设计的独立费用市场，确保您的支付流程不受其他网络活动的影响。
- **并行执行**。并行处理交易，进一步提升您的支付吞吐量。
- **熟悉的用户体验**。通过赞助或抽象化网络费用，让用户无需持有 SOL 即可直接以稳定币支付。
- **可编程性**。构建内置合规功能的自定义支付应用（对账备注、黑名单、自动税务核算等）。
