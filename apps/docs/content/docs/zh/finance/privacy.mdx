Solana 上的隐私保护是一套应用层工具，而非单一的网络模式。正确的解决方案取决于您的产品需要隐藏什么、谁有权查看，以及运营机构需要多大程度的控制权。

<Callout type="info" title="隐私有明确的边界">
  在不同的模型中，"私有"的含义并不相同。在选择集成方案之前，请明确您需要的是金额保密、参与者匿名、策略控制、私有执行还是审计访问权限。
</Callout>

## 三种解决方案对比

| 解决方案              | 最佳适用场景                                         | 隐私边界                                                                       |
| --------------------- | ------------------------------------------------ | -------------------------------------------------------------------------------------- |
| 机密余额 | 机密 Token-2022 余额与转账   | 金额和余额为私有；账户和交易参与方仍为公开 |
| Solana Privacy Rings  | 可编程的链上隐私与自定义策略 | 默认和自定义 Ring 决定资产、金额和参与者是否私有  |
| 私有通道      | 机构运营的私有执行环境           | 通道活动和数据访问仅限于机构控制的范围内       |

## 机密余额

<DocsDiagram
  src="/assets/docs/finance/privacy/confidential-balances.svg"
  alt="Confidential Balances diagram showing public sender and recipient accounts, encrypted balances and transfer amount, optional auditor access, and network verification of a zero-knowledge proof"
/>

机密余额是 Token-2022 的一个扩展功能，用于加密代币余额和转账金额，同时继续使用公开的 Solana 账户。

- **私有：** 代币余额和机密转账金额。
- **公开：** 铸币厂、token account、账户所有者及交易参与方。
- **审计模型：** 铸币厂可配置一个可选的 ElGamal 审计员密钥，用于解密转账金额。该密钥不会暴露账户的完整余额，也不授予转移代币的权限。
- **执行：** Token Extensions Program 更新加密状态，而 ZK ElGamal Proof Program 在 Solana 上验证转账证明。

[了解机密余额的工作原理](/docs/tokens/extensions/confidential-transfer)、
[规划集成方案](/docs/tokens/extensions/confidential-transfer/integration-guide)，
或
[配置发行方控制](/docs/tokens/extensions/confidential-transfer/issuer-guide)。

## Solana Privacy Rings

<DocsDiagram
  src="/assets/docs/finance/privacy/solana-privacy-protocol.svg"
  alt="Solana Privacy Rings diagram showing a permissionless Default Ring, a policy-controlled Custom Ring, private cross-ring transfers, and optional policy-defined auditor access"
/>

Solana Privacy Rings(Helius 文档中称为 **Solana Rings**)通过 API 提供链上加密余额和可编程隐私功能,目前处于测试阶段。

- **默认 Ring：** 无需许可且保密。资产和金额为私有，而发送方和接收方保持公开。
- **自定义 Rings:** 支持可配置策略、合规控制和审计方可见性的 Solana 程序。隐私可配置为保密模式(加密资产和金额)或匿名模式(加密资产、金额、发送方和接收方)。
- **可编程隐私:** 在 Solana 程序中利用私有托管构建兑换、质押、收益和借贷应用。
- **原生 Solana 性能:** 隐私转账在 Solana 上原生执行,无需排序器或侧链。余额由用户自行托管。转账可在不同 Rings 之间流转,并在一笔交易中完成结算。

[阅读 Solana Privacy Rings 文档](https://www.helius.dev/docs/privacy/)或[试用演示](https://helius.dev/privacy/demo)。

## 私有通道

<DocsDiagram
  src="/assets/docs/finance/privacy/private-channels.svg"
  alt="Private Channels diagram showing a private channel inside an institution-controlled perimeter, hidden from external observers, with optional institution-granted auditor visibility and movement to and from Solana mainnet"
/>

私有通道是面向机构的私有执行基础设施，适用于在交易隐私之外还需要运营控制权的场景。

- **通道内部：** 转账为私有、即时且无固定的单笔交易费用。
- **机构控制：** 运营方定义参与资格、访问控制、排序规则、频率限制、合规要求和数据可见性。
- **审计模型：** 外部观察者无法查看通道活动，而机构可根据其政策向审计员授予所需的可见权限。
- **与主网的关系：** 资产通过 Solana 主网进出通道，而通道内部的执行过程保持私有。

[探索私有通道](/docs/tools/private-channels)或
[查看产品页面](https://launch.solana.com/products/private-channels)。
