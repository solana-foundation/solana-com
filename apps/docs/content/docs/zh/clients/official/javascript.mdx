## Solana Kit

`@solana/kit` 是在 Solana 上构建应用的推荐 TypeScript
SDK。您可以通过组合式插件来组装客户端，在需要时添加 React 绑定，并引入生成的程序客户端来调用链上程序。

| 包                   | 描述                                  | GitHub                                                                                 |
| ------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------- |
| @solana/kit               | 核心 SDK：RPC、交易、编解码器、签名者 | [源码](https://github.com/anza-xyz/kit)                                              |
| @solana/react             | React 绑定：`ClientProvider` 及相关 Hooks   | [源码](https://github.com/anza-xyz/kit/tree/main/packages/react)                     |
| @solana/kit-plugin-rpc    | RPC 连接 + 交易发送         | [源码](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-rpc)    |
| @solana/kit-plugin-signer | 付费账户、身份标识与签名者插件      | [源码](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-signer) |
| @solana/kit-plugin-wallet | Wallet Standard 连接 + React Hooks     | [源码](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-wallet) |

## Solana Web3.js v3

`@solana/web3.js` v3 是推荐使用的 web3.js 版本。它基于 `@solana/kit` 的底层实现,重新构建了经典的基于类的 API——`Connection`、`Keypair`、`Transaction`、`PublicKey`——因此可以与 Kit 基础组件以及上述程序客户端配合使用。如果您要升级现有的 web3.js 应用,或更偏好基于类的 API,请使用此版本。

旧版 SDK 中大多数同步方法,例如 `Keypair.generate()` 和 `transaction.sign()`,现在均已改为异步。

```bash
npm install @solana/web3.js@3
```

| 包         | 描述 | GitHub                                                        |
| --------------- | ----------- | ------------------------------------------------------------- |
| @solana/web3.js | 核心 SDK    | [源码](https://github.com/solana-foundation/solana-web3.js) |

`@solana/spl-token` 依赖于 `@solana/web3.js`(旧版),无法在 v3 上运行。请改用 `@solana-program/token` 或 `@solana-program/token-2022`;它们生成的指令和指令计划可直接与 v3 的 `Transaction.add()` 配合使用。

- [web3.js v1 → v3 迁移指南](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
- [spl-token 迁移指南](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-spl-token-migration.md)

## Solana Web3.js(旧版)

`@solana/web3.js`(旧版,`1.x`)是 Solana 最初的 TypeScript SDK,目前处于维护模式,仅提供关键修复。现有代码库可以[升级到 web3.js v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md),或[迁移到 Kit](/docs/frontend/web3-compat)。
