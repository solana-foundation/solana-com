## 程序 Crate

- [示例:构建 Solana 程序](/docs/programs/rust)

| Crate          | 描述            | 文档                                   | GitHub                                                               |
| -------------- | ---------------------- | -------------------------------------- | -------------------------------------------------------------------- |
| solana-program | 构建链上程序 | [查看](https://docs.rs/solana-program) | [源码](https://github.com/anza-xyz/solana-sdk/tree/master/program) |

Pinocchio 是一个零依赖库,用于在 Rust 中创建 Solana 程序,可替代 `solana-program` 来编写链上程序。

| Crate     | 描述                      | 文档                              | GitHub                                          |
| --------- | -------------------------------- | --------------------------------- | ----------------------------------------------- |
| pinocchio | 零依赖链上程序 | [查看](https://docs.rs/pinocchio) | [源码](https://github.com/anza-xyz/pinocchio) |

<Callout type="warn">
  Pinocchio 仍在开发中,近期很可能会有破坏性变更。
</Callout>

## 签名与密钥管理

适用于跨多种密钥管理后端的生产环境后端签名:

| Crate           | 描述                                                                                                                                         | 文档                                              | GitHub                                                         |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- | -------------------------------------------------------------- |
| solana-keychain | 统一签名:Memory、Vault、Privy、Turnkey、AWS KMS、Fireblocks、GCP KMS、CDP、Para、Dfns、Crossmint、Openfort、Utila、Fordefi、Ledger(可选启用) | [Crate](https://crates.io/crates/solana-keychain) | [源码](https://github.com/solana-foundation/solana-keychain) |

使用功能标志(feature flags)仅包含您所需的后端。有关设置和托管模型的指导,请参阅 [Keychain 文档](/docs/tools/keychain)和 [选择后端](/docs/tools/keychain/choosing-a-backend)。
