`spl-token` 命令行界面可用于创建和管理 mint、token account、权限、转账以及 Token-2022 扩展。

本参考文档对应 [`spl-token-cli` v5.6.1](https://github.com/solana-program/token-2022/releases/tag/cli%40v5.6.1),即 Agave v4.2.1 附带的版本。请运行 `spl-token --version`,并使用 `<command> --help` 查看已安装版本中可用的确切选项。

<Callout type="warn">
  创建 mint、转账、变更权限、销毁、冻结和关闭账户都会提交交易。运行命令前,请确认集群、Token Program、签名者和地址。主网上的更改会使用真实资产。
</Callout>

## 安装与获取帮助

Agave CLI 发行包中包含 `spl-token`。如果尚未安装,请使用已发布的 Rust crate:

```shell
cargo install spl-token-cli --version 5.6.1
spl-token --version
```

在根级别或命令级别查看帮助:

```shell
spl-token --help
spl-token create-token --help
spl-token transfer --help
```

## 全局选项

请将全局选项放在命令之前。

| 选项                                       | 用途                                                                   |
| -------------------------------------------- | ------------------------------------------------------------------------- |
| `-u, --url <URL_OR_MONIKER>`                 | 选择 RPC URL,或 `mainnet-beta`、`testnet`、`devnet`、`localhost`。 |
| `-C, --config <PATH>`                        | 使用其他 Solana CLI 配置文件。                            |
| `--fee-payer <KEYPAIR>`                      | 选择支付交易费用的账户。                            |
| `-p, --program-id <ADDRESS>`                 | 使用明确指定的 Token Program ID。                                         |
| `--program-2022`                             | 使用 Token-2022(`TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb`)。           |
| `--output <FORMAT>`                          | 在支持的命令中返回 `json` 或 `json-compact` 格式。                          |
| `--with-compute-unit-limit <UNITS>`          | 设置交易的计算单元上限。                                   |
| `--with-compute-unit-price <MICRO_LAMPORTS>` | 设置每个计算单元的优先费价格。                                  |
| `-v, --verbose`                              | 显示更多输出。                                                   |
| `-V, --version`                              | 打印已安装的 CLI 版本。                                          |

默认程序为原始的 Token Program。对于 Token-2022 的 mint 或账户,请使用 `--program-2022`,读取时也同样如此。如果所选程序并不拥有所提供的地址,命令将失败。

## 创建并使用代币

这些命令会打印所创建的地址。请保存 `create-token` 返回的 mint 地址,以便用于后续命令。

```shell
# Create a six-decimal mint under the original Token Program.
spl-token --url devnet create-token --decimals 6

# Create the default signer's associated token account for the mint.
spl-token --url devnet create-account <MINT_ADDRESS>

# Mint 100 tokens to that associated token account.
spl-token --url devnet mint <MINT_ADDRESS> 100

# Read supply, balance, and complete mint or account details.
spl-token --url devnet supply <MINT_ADDRESS>
spl-token --url devnet balance <MINT_ADDRESS>
spl-token --url devnet display <MINT_OR_TOKEN_ACCOUNT_ADDRESS>

# Transfer tokens to a wallet and create its associated account if needed.
spl-token --url devnet transfer \
  <MINT_ADDRESS> \
  10 \
  <RECIPIENT_WALLET_ADDRESS> \
  --fund-recipient
```

金额为 UI 代币数量,已按 mint 的小数位数进行调整。`transfer`、`burn` 和 `unwrap-sol` 等命令在其帮助中标明的位置接受 `ALL`。

## 创建 Token-2022 mint

扩展会分配额外的 mint 或账户状态,通常必须在创建 mint 时选定。以下示例创建一个 6 位小数、支持内嵌元数据的 mint:

```shell
spl-token --program-2022 create-token \
  --decimals 6 \
  --enable-metadata

spl-token --program-2022 initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  EXAMPLE \
  https://example.com/token.json
```

常见的 `create-token` 扩展选项包括:

- `--enable-close`
- `--enable-confidential-transfers auto|manual`
- `--enable-freeze`
- `--enable-group` 和 `--enable-member`
- `--enable-metadata`
- `--enable-non-transferable`
- `--enable-pause`
- `--enable-permanent-delegate`
- `--enable-permissioned-burn`
- `--enable-transfer-hook` 或 `--transfer-hook <PROGRAM_ID>`
- `--interest-rate <BASIS_POINTS>`
- `--transfer-fee-basis-points <BASIS_POINTS>` 搭配 `--transfer-fee-maximum-fee <AMOUNT>`
- `--ui-amount-multiplier <MULTIPLIER>`

仅可组合使用 Token-2022 程序允许同时启用的扩展。在创建不可逆的 mint 配置之前,请先查阅相关的 [Token-2022 扩展指南](/docs/tokens/extensions)。

## 管理权限与委托

```shell
# Change the mint authority.
spl-token authorize <MINT_ADDRESS> mint <NEW_AUTHORITY_ADDRESS>

# Permanently remove the mint authority.
spl-token authorize <MINT_ADDRESS> mint --disable

# Let a delegate spend up to 25 tokens from one token account.
spl-token approve \
  <TOKEN_ACCOUNT_ADDRESS> \
  25 \
  <DELEGATE_ADDRESS>

# Remove the current delegate.
spl-token revoke <TOKEN_ACCOUNT_ADDRESS>
```

`authorize` 支持 mint、冻结、所有者、关闭以及特定扩展的权限类型。如果没有其他程序机制可以恢复,使用 `--disable` 移除权限将是永久性的。

## 冻结、销毁与关闭

```shell
spl-token freeze <TOKEN_ACCOUNT_ADDRESS>
spl-token thaw <TOKEN_ACCOUNT_ADDRESS>

spl-token burn <TOKEN_ACCOUNT_ADDRESS> 5

# A token account must normally have a zero token balance before closing.
spl-token close --address <TOKEN_ACCOUNT_ADDRESS>
```

`burn` 会同时减少账户余额和总供应量。`close` 会将账户剩余的 lamport 返还给已配置的接收方;它不会找回已销毁的代币。

## 包装与解包 SOL

```shell
# Create or fund the owner's wrapped SOL token account.
spl-token wrap 1

# Unwrap part of the wrapped SOL balance.
spl-token unwrap-sol 0.25

# Close the wrapped SOL account and return its full lamport balance.
spl-token unwrap
```

在将 lamport 直接转入 wrapped SOL token account 之后,请使用 `sync-native`,使其代币数量与底层 lamport 保持一致。

## 多签签名

创建最多包含 11 个成员的 M-of-N Token Program 多签:

```shell
spl-token create-multisig \
  2 \
  <MEMBER_1_ADDRESS> \
  <MEMBER_2_ADDRESS> \
  <MEMBER_3_ADDRESS>
```

对于由该多签控制的交易,请将多签地址作为相应的权限传入,并通过重复的 `--multisig-signer` 值提供成员 keypair。请查看目标命令的帮助,因为其主要权限标志因操作而异。

## 机密余额

机密余额命令需要为机密转账配置的 Token-2022 mint,以及已配置的接收账户。

```shell
spl-token --program-2022 configure-confidential-transfer-account \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 deposit-confidential-tokens \
  <MINT_ADDRESS> \
  10 \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 apply-pending-balance \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 withdraw-confidential-tokens \
  <MINT_ADDRESS> \
  5 \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 transfer \
  <MINT_ADDRESS> \
  1 \
  <RECIPIENT_ADDRESS> \
  --confidential
```

对于 `configure-confidential-transfer-account` 和 `apply-pending-balance`,请传入 `--address <TOKEN_ACCOUNT_ADDRESS>` 或位置参数 `<MINT_ADDRESS>`,二者不可同时使用。使用位置参数时,将采用所有者的 associated token account。存款和取款始终需要提供 mint,并可通过 `--address` 覆盖该默认账户。

使用 `enable-confidential-credits`、`disable-confidential-credits`、`enable-non-confidential-credits` 和 `disable-non-confidential-credits` 来控制账户接受哪些存入。这些设置会影响账户隐私和支付兼容性;更改前请先检查该账户。

## 结构化与离线签名

请使用结构化输出,而不要解析显示文本:

```shell
spl-token accounts --output json
spl-token display <MINT_ADDRESS> --output json-compact
```

生成交易的命令通常支持 `--sign-only`、`--blockhash`、`--signer <PUBKEY=SIGNATURE>`、`--nonce` 和 `--nonce-authority`。具体的离线输入取决于命令、mint 小数位数和权限安排,因此请按照该命令的 `--help` 说明生成未签名消息,并在收集签名之前核实每一个地址。
