استخدم [Pay](https://pay.sh) لتشغيل واجهة API متوافقة مع x402 V2 ولمنح Claude Code عميل HTTP
يدعم الدفع. تستخدم واجهة API والمحفظة الدافعة والتسوية جميعها
بيئة سولانا التجريبية، لذا لا يتطلب هذا الدليل حسابًا أو أموالًا حقيقية.

تحتاج إلى طرفية (terminal) وPay وتثبيت Claude Code.

## 1. تثبيت Pay

على macOS، ثبّت الملف التنفيذي المُجهَّز مسبقًا:

```bash
brew install pay
pay --version
```

على المنصات الأخرى، ثبّت حزمة npm:

```bash
npm install --global @solana/pay
pay --version
```

## 2. تشغيل واجهة API تجريبية لـ x402

أنشئ الملف `x402-demo.yaml`:

```yaml filename=x402-demo.yaml
name: x402-demo
subdomain: x402-demo
title: "x402 Demo"
description: "Minimal x402 V2 sandbox endpoint."
category: devtools
version: v1
routing:
  type: respond
operator:
  currencies:
    usd: ["USDC"]
  network: "localnet"
  fee_payer: true
endpoints:
  - method: GET
    path: "report"
    description: "Return a sandbox report."
    metering:
      schemes: [x402-exact]
      dimensions:
        - direction: usage
          unit: requests
          scale: 1
          tiers:
            - price_usd: 0.001
```

شغّل واجهة API واتركها قيد التشغيل:

```bash
pay --sandbox server start x402-demo.yaml --bind 127.0.0.1:1402
```

يجعل المخطط `x402-exact` هذه النقطة الطرفية مخصصة لـ x402 فقط. ينشئ الوضع التجريبي
حسابات مؤقتة للمشغّل والدافع ويموّلها تلقائيًا.

## 3. تشغيل الوكيل باستخدام Pay

في طرفية أخرى، شغّل Claude Code في الوضع التجريبي:

```bash
pay --sandbox claude
```

يربط Pay أدوات MCP المحلية الخاصة به بجلسة الوكيل. ولا يتلقى الوكيل
مفتاحًا خاصًا.

## 4. إرسال طلب x402 واحد

الصق هذه الموجّه (prompt) في الوكيل:

```text
Use Pay to make exactly one sandbox x402 API request to
http://127.0.0.1:1402/report.

Before paying, show me the amount and ask for approval. Then return the API
result and payment receipt. Do not make any other paid requests.
```

يتبع الطلب حلقة دفع كاملة واحدة وفق x402 V2:

1. تعيد واجهة API الاستجابة `402 Payment Required` مع تحدٍّ `PAYMENT-REQUIRED`.
2. يتحقق Pay من متطلبات x402 ويعرض شروط الدفع.
3. بعد الموافقة، توقّع المحفظة التجريبية ويعيد Pay إرسال الطلب مع
   `PAYMENT-SIGNATURE`.
4. تعيد واجهة API النتيجة مع إيصال `PAYMENT-RESPONSE`.

لا تُحرَّك أي أموال حقيقية. يؤدي رفض الموافقة إلى إيقاف الطلب.

تابع مع [x402 على سولانا](/docs/payments/agentic-payments/x402) لبناء
عميل وخادم موارد وفق x402 V2، أو
[كن مُيسِّر x402 (facilitator)](/docs/tools/x402-facilitator).
