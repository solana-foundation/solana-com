## سولانا Kit

`@solana/kit` هو SDK TypeScript الموصى به للبناء على سولانا. يمكنك تجميع عميل من
إضافات قابلة للتركيب، وإضافة روابط React عند الحاجة إليها، واستيراد عملاء
البرامج المُولَّدة للبرامج على السلسلة التي تستدعيها.

| الحزمة                   | الوصف                                  | GitHub                                                                                 |
| ------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------- |
| @solana/kit               | SDK الأساسي: RPC، والمعاملات، وبرامج الترميز، والموقِّعون | [المصدر](https://github.com/anza-xyz/kit)                                              |
| @solana/react             | روابط React: `ClientProvider` والخطافات   | [المصدر](https://github.com/anza-xyz/kit/tree/main/packages/react)                     |
| @solana/kit-plugin-rpc    | اتصال RPC وإرسال المعاملات         | [المصدر](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-rpc)    |
| @solana/kit-plugin-signer | إضافات دافع الرسوم والهوية والتوقيع      | [المصدر](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-signer) |
| @solana/kit-plugin-wallet | اتصال Wallet Standard وخطافات React     | [المصدر](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-wallet) |

## سولانا Web3.js v3

`@solana/web3.js` v3 هو الإصدار الموصى به من web3.js. يعيد بناء واجهة API الكلاسيكية القائمة على الفئات — `Connection` و`Keypair` و`Transaction` و`PublicKey` —
فوق البنية الداخلية لـ `@solana/kit`، ولذلك يعمل مع العناصر الأساسية في Kit
وعملاء البرامج المذكورين أعلاه. استخدمه إذا كنت تقوم بترقية تطبيق web3.js حالي أو
تفضّل واجهة API القائمة على الفئات.

معظم الدوال التي كانت متزامنة في مكتبة SDK القديمة، مثل
`Keypair.generate()` و`transaction.sign()`، أصبحت الآن غير متزامنة (async).

```bash
npm install @solana/web3.js@3
```

| الحزمة         | الوصف | GitHub                                                        |
| --------------- | ----------- | ------------------------------------------------------------- |
| @solana/web3.js | حزمة SDK الأساسية    | [المصدر](https://github.com/solana-foundation/solana-web3.js) |

تعتمد `@solana/spl-token` على `@solana/web3.js` (القديمة) ولا تعمل على
الإصدار v3. استخدم `@solana-program/token` أو `@solana-program/token-2022` بدلًا منها؛ فالتعليمات
وخطط التعليمات المولَّدة فيهما تعمل مباشرةً مع
`Transaction.add()` في الإصدار v3.

- [دليل الانتقال من web3.js v1 إلى v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
- [دليل الانتقال من spl-token](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-spl-token-migration.md)

## سولانا Web3.js (القديمة)

`@solana/web3.js` (القديمة، `1.x`) هي مكتبة TypeScript SDK الأصلية لسولانا. وهي
في وضع الصيانة ولا تتلقى سوى الإصلاحات الحرجة. يمكن لقواعد الأكواد الحالية
[الترقية إلى web3.js v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
أو [الانتقال إلى Kit](/docs/frontend/web3-compat).
