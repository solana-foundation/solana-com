تتيح واجهة سطر الأوامر `spl-token` إنشاء وإدارة mints وحسابات الرموز
والسلطات وعمليات التحويل وإضافات Token-2022.

يتبع هذا المرجع
[`spl-token-cli` v5.6.1](https://github.com/solana-program/token-2022/releases/tag/cli%40v5.6.1)،
وهو الإصدار المضمَّن مع Agave v4.2.1. شغّل `spl-token --version` واستخدم
`<command> --help` للاطلاع على الخيارات المتاحة تحديدًا في الإصدار المثبّت لديك.

<Callout type="warn">
  تُرسل عمليات إنشاء mint والتحويلات وتغييرات السلطة وعمليات الحرق والتجميد
  وإغلاق الحسابات معاملات إلى الشبكة. تأكد من الكلاستر وToken Program والموقّع
  والعناوين قبل تشغيل أي أمر. التغييرات على Mainnet تستخدم أصولًا حقيقية.
</Callout>

## التثبيت والحصول على المساعدة

تتضمن حزمة إصدار Agave CLI الأداة `spl-token`. إذا لم تكن مثبّتة، فاستخدم
حزمة Rust المنشورة:

```shell
cargo install spl-token-cli --version 5.6.1
spl-token --version
```

اطّلع على المساعدة على مستوى الجذر أو على مستوى الأمر:

```shell
spl-token --help
spl-token create-token --help
spl-token transfer --help
```

## الخيارات العامة

ضع الخيارات العامة قبل الأمر.

| الخيار                                       | الغرض                                                                   |
| -------------------------------------------- | ------------------------------------------------------------------------- |
| `-u, --url <URL_OR_MONIKER>`                 | حدّد عنوان RPC أو `mainnet-beta` أو `testnet` أو `devnet` أو `localhost`. |
| `-C, --config <PATH>`                        | استخدم ملف إعدادات مختلفًا لواجهة سطر أوامر سولانا.                            |
| `--fee-payer <KEYPAIR>`                      | حدّد الحساب الذي يدفع رسوم المعاملات.                            |
| `-p, --program-id <ADDRESS>`                 | استخدم معرّف Token Program صريحًا.                                         |
| `--program-2022`                             | استخدم Token-2022 (`TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb`).           |
| `--output <FORMAT>`                          | أعِد النتيجة بصيغة `json` أو `json-compact` حيثما كان ذلك مدعومًا.                          |
| `--with-compute-unit-limit <UNITS>`          | حدّد الحد الأقصى لوحدات الحوسبة للمعاملة.                                   |
| `--with-compute-unit-price <MICRO_LAMPORTS>` | حدّد سعر الأولوية لكل وحدة حوسبة.                                  |
| `-v, --verbose`                              | اعرض مخرجات إضافية.                                                   |
| `-V, --version`                              | اطبع إصدار واجهة سطر الأوامر المثبّت.                                          |

البرنامج الافتراضي هو Token Program الأصلي. استخدم `--program-2022` مع mint أو حساب من Token-2022، بما في ذلك عند قراءته. يفشل الأمر إذا لم يكن البرنامج المحدد هو المالك للعنوان المقدَّم.

## إنشاء رمز واستخدامه

تطبع الأوامر العناوين التي أنشأتها. احفظ عنوان mint الذي يعيده الأمر
`create-token` لاستخدامه في الأوامر التالية.

```shell
# Create a six-decimal mint under the original Token Program.
spl-token --url devnet create-token --decimals 6

# Create the default signer's associated token account for the mint.
spl-token --url devnet create-account <MINT_ADDRESS>

# Mint 100 tokens to that associated token account.
spl-token --url devnet mint <MINT_ADDRESS> 100

# Read supply, balance, and complete mint or account details.
spl-token --url devnet supply <MINT_ADDRESS>
spl-token --url devnet balance <MINT_ADDRESS>
spl-token --url devnet display <MINT_OR_TOKEN_ACCOUNT_ADDRESS>

# Transfer tokens to a wallet and create its associated account if needed.
spl-token --url devnet transfer \
  <MINT_ADDRESS> \
  10 \
  <RECIPIENT_WALLET_ADDRESS> \
  --fund-recipient
```

المبالغ هي مبالغ الرموز كما تظهر في الواجهة، معدَّلة وفق عدد منازل mint العشرية. تقبل أوامر مثل
`transfer` و`burn` و`unwrap-sol` القيمة `ALL` حيثما يُذكر ذلك في مساعدتها.

## إنشاء mint من Token-2022

تخصّص الإضافات حالة إضافية للـ mint أو الحساب، وغالبًا ما يجب اختيارها عند إنشاء
الـ mint. ينشئ هذا المثال mint بست منازل عشرية مع دعم
البيانات الوصفية المضمَّنة:

```shell
spl-token --program-2022 create-token \
  --decimals 6 \
  --enable-metadata

spl-token --program-2022 initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  EXAMPLE \
  https://example.com/token.json
```

تشمل خيارات الإضافات الشائعة للأمر `create-token` ما يلي:

- `--enable-close`
- `--enable-confidential-transfers auto|manual`
- `--enable-freeze`
- `--enable-group` و`--enable-member`
- `--enable-metadata`
- `--enable-non-transferable`
- `--enable-pause`
- `--enable-permanent-delegate`
- `--enable-permissioned-burn`
- `--enable-transfer-hook` أو `--transfer-hook <PROGRAM_ID>`
- `--interest-rate <BASIS_POINTS>`
- `--transfer-fee-basis-points <BASIS_POINTS>` مع
  `--transfer-fee-maximum-fee <AMOUNT>`
- `--ui-amount-multiplier <MULTIPLIER>`

لا تجمع إلا الإضافات التي يسمح برنامج Token-2022 باستخدامها معًا. راجع
[دليل إضافات Token-2022](/docs/tokens/extensions) ذي الصلة قبل إنشاء
إعداد mint لا يمكن التراجع عنه.

## إدارة السلطات والمفوَّضين

```shell
# Change the mint authority.
spl-token authorize <MINT_ADDRESS> mint <NEW_AUTHORITY_ADDRESS>

# Permanently remove the mint authority.
spl-token authorize <MINT_ADDRESS> mint --disable

# Let a delegate spend up to 25 tokens from one token account.
spl-token approve \
  <TOKEN_ACCOUNT_ADDRESS> \
  25 \
  <DELEGATE_ADDRESS>

# Remove the current delegate.
spl-token revoke <TOKEN_ACCOUNT_ADDRESS>
```

يدعم `authorize` أنواع السلطات الخاصة بـ mint والتجميد والمالك والإغلاق
والإضافات. إزالة سلطة باستخدام `--disable` إجراء دائم إذا لم تكن هناك
آلية أخرى في البرنامج تستطيع استعادتها.

## التجميد والحرق والإغلاق

```shell
spl-token freeze <TOKEN_ACCOUNT_ADDRESS>
spl-token thaw <TOKEN_ACCOUNT_ADDRESS>

spl-token burn <TOKEN_ACCOUNT_ADDRESS> 5

# A token account must normally have a zero token balance before closing.
spl-token close --address <TOKEN_ACCOUNT_ADDRESS>
```

يقلّل `burn` كلًّا من رصيد الحساب والإمداد الكلي. أما `close` فيعيد
ما تبقى من lamports في الحساب إلى المستلم المحدد في الإعدادات؛ ولا يسترد
الرموز المحروقة.

## تغليف SOL وفك تغليفه

```shell
# Create or fund the owner's wrapped SOL token account.
spl-token wrap 1

# Unwrap part of the wrapped SOL balance.
spl-token unwrap-sol 0.25

# Close the wrapped SOL account and return its full lamport balance.
spl-token unwrap
```

استخدم `sync-native` بعد تحويل lamports مباشرةً إلى token account يحتوي على SOL مغلَّف
حتى يتطابق مبلغ الرمز فيه مع lamports الأساسية.

## التوقيع المتعدد (Multisig)

أنشئ multisig من نوع M-of-N في Token Program يضم حتى 11 عضوًا:

```shell
spl-token create-multisig \
  2 \
  <MEMBER_1_ADDRESS> \
  <MEMBER_2_ADDRESS> \
  <MEMBER_3_ADDRESS>
```

بالنسبة إلى معاملة يتحكم فيها هذا الـ multisig، مرِّر عنوان الـ multisig بوصفه
السلطة المعنية، وقدّم keypair الأعضاء عبر تكرار القيم
`--multisig-signer`. راجع مساعدة الأمر المستهدف لأن خيار
السلطة الأساسي يختلف باختلاف العملية.

## الأرصدة السرية

تتطلب أوامر الأرصدة السرية وجود mint من Token-2022 مُعدّ
للتحويلات السرية وحساب مستلم مُعدّ لذلك.

```shell
spl-token --program-2022 configure-confidential-transfer-account \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 deposit-confidential-tokens \
  <MINT_ADDRESS> \
  10 \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 apply-pending-balance \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 withdraw-confidential-tokens \
  <MINT_ADDRESS> \
  5 \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 transfer \
  <MINT_ADDRESS> \
  1 \
  <RECIPIENT_ADDRESS> \
  --confidential
```

بالنسبة إلى `configure-confidential-transfer-account` و`apply-pending-balance`، مرِّر
إما `--address <TOKEN_ACCOUNT_ADDRESS>` أو `<MINT_ADDRESS>` موضعيًا، وليس
كليهما. يستخدم الشكل الموضعي associated token account الخاص بالمالك. يأخذ الإيداع
والسحب دائمًا عنوان mint ويقبلان `--address` لتجاوز ذلك الحساب
الافتراضي.

استخدم `enable-confidential-credits` و`disable-confidential-credits`
و`enable-non-confidential-credits` و`disable-non-confidential-credits` للتحكم
في الإيداعات التي يقبلها الحساب. تؤثر هذه الإعدادات في خصوصية
الحساب وتوافق الدفعات؛ افحص الحساب قبل تغييرها.

## الفهرس الكامل للأوامر

يتضمن الفهرس التالي كل أمر من المستوى الأعلى في `spl-token-cli` v5.6.1.

| الأمر                                   | الوصف                                                                   |
| ----------------------------------------- | ----------------------------------------------------------------------------- |
| `accounts`                                | اعرض token accounts المملوكة لمحفظة، مع إمكانية التصفية حسب mint.           |
| `address`                                 | اطبع عنوان المحفظة المحددة أو عنوان associated token account الخاص بها.            |
| `apply-pending-balance`                   | انقل الرموز السرية المعلّقة إلى الرصيد السري المتاح.     |
| `approve`                                 | اعتمد مفوَّضًا وحدّ إنفاق لـ token account.                |
| `authorize`                               | غيّر أو عطّل سلطة mint أو الحساب أو إحدى الإضافات.                    |
| `balance`                                 | اعرض رصيد token account.                                                 |
| `bench`                                   | شغّل أوامر قياس الأداء للرموز.                                              |
| `burn`                                    | أتلِف رموزًا من حساب وقلّل إمداد mint.                        |
| `close`                                   | أغلق token account مؤهلًا واسترد lamports الخاصة به.                     |
| `close-mint`                              | أغلق mint من Token-2022 مُعدّ بإضافة close-mint.             |
| `configure-confidential-transfer-account` | هيّئ حسابًا لاستخدام التحويلات السرية.                           |
| `create-account`                          | أنشئ token account مرتبطًا (associated) أو مساعدًا.                              |
| `create-multisig`                         | أنشئ multisig من نوع M-of-N في Token Program.                                      |

| `enable-non-confidential-credits`         | اقبل التحويلات غير السرية الواردة إلى حساب سري.        |
| `enable-required-transfer-memos`          | اشترط تضمين مذكرات (memos) في التحويلات الواردة.                                  |

## التوقيع المنظَّم والتوقيع دون اتصال

استخدم المخرجات المنظَّمة بدلًا من تحليل النص المعروض:

```shell
spl-token accounts --output json
spl-token display <MINT_ADDRESS> --output json-compact
```

تدعم الأوامر المنتجة للمعاملات عادةً الخيارات `--sign-only` و`--blockhash`
و`--signer <PUBKEY=SIGNATURE>` و`--nonce` و`--nonce-authority`. تعتمد مدخلات
التوقيع دون اتصال الدقيقة على الأمر والمنازل العشرية لـ mint وترتيبات السلطة،
لذا أنشئ الرسالة غير الموقَّعة وفق تعليمات `--help` الخاصة بذلك الأمر
وتحقق من كل عنوان قبل جمع التوقيعات.
