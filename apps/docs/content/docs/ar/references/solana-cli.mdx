تقوم واجهة سطر الأوامر `solana` بإعداد الاتصال بالـ cluster، وقراءة حالة الشبكة، وإرسال SOL، وإدارة durable nonces، ونشر البرامج، وتشغيل حسابات الستيك والتصويت.

يتبع هذا المرجع [Agave v4.2.1](https://github.com/anza-xyz/agave/releases/tag/v4.2.1). شغّل
`solana --version` للتحقق من الإصدار المثبّت، واستخدم `--help` لمعرفة الخيارات المتاحة بدقة في ذلك الإصدار.

<Callout type="warn">
  الأوامر التي تنشئ أو تحوّل أو تفوّض أو تسحب أو تنشر ترسل معاملات. تأكد من الـ cluster والموقّع المضبوطين قبل تشغيلها. رموز Devnet وTestnet لا قيمة لها، أما أوامر Mainnet فتستخدم SOL حقيقية.
</Callout>

## بنية الأوامر

```text
solana [GLOBAL_OPTIONS] <COMMAND> [COMMAND_OPTIONS]
```

احصل على المساعدة على أي مستوى:

```shell
solana --help
solana transfer --help
solana address-lookup-table extend --help
```

## الخيارات العامة

يمكن وضع الخيارات العامة قبل الأمر. تكرر مساعدة الأمر الخاصة الخيارات التي تنطبق على ذلك الأمر.

| الخيار                          | الغرض                                                                        |
| ------------------------------- | ------------------------------------------------------------------------------ |
| `-u, --url <URL_OR_MONIKER>`    | حدّد عنوان RPC URL أو أحد الأسماء: `mainnet-beta` أو `testnet` أو `devnet` أو `localhost`.      |
| `--ws <URL>`                    | تجاوز نقطة نهاية WebSocket.                                               |
| `-k, --keypair <KEYPAIR>`       | حدّد ملف keypair، أو `ASK`، أو الإدخال القياسي (`-`)، أو عنوان URL لموقّع مدعوم.          |
| `-C, --config <FILEPATH>`       | استخدم ملف إعدادات CLI مختلفًا.                                        |
| `--commitment <LEVEL>`          | اقرأ عند مستوى التأكيد `processed` أو `confirmed` أو `finalized`.                   |
| `--output <FORMAT>`             | أعد `json` أو `json-compact` حيث يكون ذلك مدعومًا.                               |
| `--skip-preflight`              | أرسل دون محاكاة RPC. استخدمه فقط عند فهم مخاطر الفشل المترتبة على ذلك. |
| `--use-tpu-client`              | أرسل المعاملات عبر عميل TPU.                                      |
| `--no-address-labels`           | اطبع العناوين دون التسميات المحلية.                                          |
| `--skip-seed-phrase-validation` | اسمح بعبارة استرداد خارج قائمة BIP39 الإنجليزية.                       |
| `-v, --verbose`                 | اعرض مخرجات إضافية للأمر.                                                |
| `-V, --version`                 | اطبع إصدار CLI المثبّت.                                               |

## إعداد CLI

```shell
# Inspect the effective configuration.
solana config get

# Use Devnet and a specific signer by default.
solana config set --url devnet
solana config set --keypair ./devnet-keypair.json

# Override defaults for one command.
solana --url mainnet-beta --keypair usb://ledger address
```

يحتوي الإعداد على RPC URL وWebSocket URL والموقّع الافتراضي ومستوى التأكيد (commitment). أي خيار في سطر الأوامر يتجاوز القيمة المحفوظة لذلك التنفيذ فقط.

## مسارات عمل شائعة للحسابات والمعاملات

```shell
# Print the default signer's address and balance.
solana address
solana balance

# Read an account as JSON.
solana account <ACCOUNT_ADDRESS> --output json

# Request Devnet SOL.
solana airdrop 1 --url devnet

# Send SOL and then confirm the returned signature.
solana transfer <RECIPIENT_ADDRESS> 0.1 --allow-unfunded-recipient
solana confirm <TRANSACTION_SIGNATURE>

# Inspect recent activity and stream logs mentioning an address.
solana transaction-history <ADDRESS> --limit 20
solana logs <ADDRESS>
```

يقبل `transfer` عملة SOL افتراضيًا. استخدم `ALL` كمبلغ لنقل الرصيد المتاح بعد الرسوم. لأمثلة الرموز، راجع
[البدء السريع للرموز](/docs/tokens/quickstart).

## مسارات عمل البرامج

```shell
# Deploy or upgrade an SBF program.
solana program deploy ./target/deploy/my_program.so

# Inspect the deployed program and list programs controlled by the signer.
solana program show <PROGRAM_ID>
solana program show --programs

# Close a program buffer and recover its lamports.
solana program close <BUFFER_ADDRESS>
```

مرّر `--program-id <KEYPAIR_OR_ADDRESS>` عندما يجب أن يستخدم النشر معرّف برنامج معروفًا. يجعل `--final` النشر الجديد غير قابل للتعديل؛ اقرأ مساعدته بعناية قبل استخدامه لأنه لا يمكن استعادة صلاحية الترقية.

## مسارات عمل durable nonce

```shell
solana-keygen new --outfile nonce-account.json
solana create-nonce-account nonce-account.json 0.1
solana nonce nonce-account.json
solana new-nonce nonce-account.json
solana withdraw-from-nonce-account nonce-account.json <RECIPIENT_ADDRESS> ALL
```

استخدم `authorize-nonce-account` لتغيير صلاحية nonce، و`nonce-account` لفحص الحالة الكاملة للحساب. كما تقبل المعاملات التي تستخدم nonce الخيارين `--nonce` و`--nonce-authority` في الأوامر المدعومة.

## مسارات عمل الستيك

```shell
solana-keygen new --outfile stake-account.json
solana create-stake-account stake-account.json 1
solana delegate-stake stake-account.json <VOTE_ACCOUNT_ADDRESS>
solana stake-account stake-account.json

solana deactivate-stake stake-account.json
solana withdraw-stake stake-account.json <RECIPIENT_ADDRESS> ALL
```

يكتمل إلغاء التفعيل عند حدود epoch وقد يستغرق أكثر من epoch واحد. استخدم `stakes` و`validators` و`stake-history` و`stake-minimum-delegation` لفحص حالة الـ cluster والتفويض قبل إرسال التغييرات.

## أدوات العناوين

```shell
# Derive a PDA from typed seeds.
solana find-program-derived-address \
  <PROGRAM_ID> \
  string:profile \
  pubkey:<OWNER_ADDRESS>

# Create and extend an address lookup table.
solana address-lookup-table create
solana address-lookup-table extend \
  <LOOKUP_TABLE_ADDRESS> \
  --addresses <ADDRESS_1>,<ADDRESS_2>
```

تستخدم قيم seed الخاصة بـ PDA الصيغة `PREFIX:VALUE`. تشمل البادئات المدعومة `string` و`pubkey` و`hex` و`u8` وترميزات الأعداد الصحيحة ذات العرض الثابت، سواء كانت موقّعة أو غير موقّعة، مثل `u64le`.

## الرسائل خارج السلسلة وإكمال الصدفة

```shell
solana sign-offchain-message "terms accepted"
solana verify-offchain-signature \
  "terms accepted" \
  <SIGNATURE> \
  --signer <SIGNER_ADDRESS>

# Print a completion script for the current shell.
solana completion --shell zsh
```

| `address-lookup-table`              | أنشئ جداول البحث عن العناوين ووسّعها وجمّدها وعطّلها وأغلقها وافحصها.     |

| `alpenglow-genesis-info`            | اقرأ معلومات عن شهادة genesis الخاصة بـ Alpenglow.                         |

| `block`                             | اجلب كتلة مؤكدة حسب slot.                                                  |

## مخرجات السكربتات

استخدم `--output json` أو `--output json-compact` حيث يكون ذلك مدعومًا بدلًا من تحليل المخرجات المقروءة للبشر:

```shell
solana epoch-info --output json
solana account <ACCOUNT_ADDRESS> --output json-compact
solana validators --output json > validators.json
```

لا يدعم كل أمر المخرجات المهيكلة. راجع مساعدة الأمر قبل الاعتماد عليها في الأتمتة، وعامل رمز الخروج غير الصفري على أنه فشل.
