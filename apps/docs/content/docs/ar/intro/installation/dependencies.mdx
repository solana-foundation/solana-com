ثبّت كل تبعية على حدة عندما تحتاج إلى إصدار محدد أو عندما لا يكتمل
[التثبيت السريع](/docs/intro/installation) بنجاح.
اتبع الأقسام بالترتيب لإعداد بيئة جديدة، أو انتقل مباشرة إلى الأداة
التي تحتاج إلى تثبيتها أو إصلاح مشكلاتها.

## المتطلبات الأساسية

<Accordions>
<Accordion title="Windows">

لتطوير برامج سولانا على Windows **يجب** عليك استخدام
[نظام Windows الفرعي لـ Linux](https://learn.microsoft.com/en-us/windows/wsl/install)
(WSL). بعد تثبيت WSL، سيتم تثبيت جميع التبعيات الأخرى من خلال طرفية Linux.

لتثبيت WSL، قم بتشغيل الأمر التالي في Windows PowerShell:

```terminal
$ wsl --install
```

ستطالبك عملية التثبيت بإنشاء حساب مستخدم افتراضي.

![تثبيت WSL](/assets/docs/intro/installation/wsl-install.png)

بشكل افتراضي، يقوم WSL بتثبيت Ubuntu. يمكنك فتح طرفية Linux عن طريق البحث عن
"Ubuntu" في شريط البحث.

![WSL Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-search.png)

إذا كانت طرفية Ubuntu الخاصة بك تبدو مثل الصورة أدناه، فقد تواجه مشكلة حيث لا
يعمل `ctrl + v` (اختصار لوحة المفاتيح للصق) في الطرفية.

![طرفية Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-terminal-1.png)

إذا واجهت هذه المشكلة، افتح Windows Terminal عن طريق البحث عن "Terminal" في شريط
البحث.

![Windows Terminal](/assets/docs/intro/installation/wsl-windows-terminal.png)

بعد ذلك، أغلق Windows Terminal وأعد فتح طرفية Linux عن طريق البحث عن Ubuntu مرة
أخرى. يجب أن تبدو الطرفية الآن مثل الصورة أدناه، حيث يعمل `ctrl + v` (اختصار
لوحة المفاتيح للصق).

![طرفية Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-terminal-2.png)

إذا كنت تستخدم VS Code، فإن
[إضافة WSL](https://code.visualstudio.com/docs/remote/wsl-tutorial) تمكنك من
استخدام WSL وVS Code معاً.

![إعداد WSL في VS Code](/assets/docs/intro/installation/wsl-vscode.png)

سترى ما يلي في شريط الحالة في VS Code:

![WSL: Ubuntu](/assets/docs/intro/installation/wsl-vscode-ubuntu.png)

بمجرد إعداد WSL، ستكون جاهزًا إما:

- إكمال [التثبيت السريع](/docs/intro/installation) باستخدام طرفية Ubuntu (Linux)
- تثبيت [Rust](#install-rust) و[Solana CLI](#install-solana-cli) و
  [Anchor CLI](#install-anchor-cli) بشكل فردي، كما هو موضح أدناه

</Accordion>
<Accordion title="Linux">

<Tabs items={[".deb", ".rpm"]}>
<Tab value=".deb" >
على توزيعة Debian أو أي توزيعة مشتقة منها مثل Ubuntu أو Mint:

1. قم بتحديث قوائم الحزم للتأكد من أن جميع الحزم محدثة:

```terminal
$ sudo apt-get update
```

2. قم بتثبيت التبعيات التالية:

```terminal
$ sudo apt-get install -y \
    build-essential \
    pkg-config \
    libudev-dev llvm libclang-dev \
    protobuf-compiler libssl-dev
```

<Callout>
إذا ظهر الخطأ التالي عند تثبيت `protobuf-compiler`، فشغّل
`sudo apt-get update` قبل إعادة محاولة أمر التثبيت.

```
Package protobuf-compiler is not available, but is referred to by another package.
This may mean that the package is missing, has been obsoleted, or
is only available from another source
```

</Callout>

  </Tab>

    <Tab value=".rpm" >

حدّث الحزم المثبّتة:

```terminal
$ sudo dnf upgrade --refresh
```

ثبّت تبعيات التطوير:

```terminal
$ sudo dnf group install c-development development-tools \
&& sudo dnf install pkg-config openssl-devel
```

### تثبيت Rust

يقوم المطورون ببناء برامج سولانا باستخدام لغة البرمجة
[Rust](https://www.rust-lang.org/).

1. قم بتثبيت Rust باستخدام [rustup](https://www.rust-lang.org/tools/install) عن
   طريق إدخال الأمر التالي في الطرفية الخاصة بك:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
```

بعد التثبيت الناجح سترى الرسالة التالية:

<Accordions>
<Accordion title="رسالة تثبيت Rust الناجح">

```
Rust is installed now. Great!

To get started you may need to restart your current shell.
This would reload your PATH environment variable to include
Cargo's bin directory ($HOME/.cargo/bin).

To configure your current shell, you need to source
the corresponding env file under $HOME/.cargo.

This is usually done by running one of the following (note the leading DOT):
. "$HOME/.cargo/env"            # For sh/bash/zsh/ash/dash/pdksh
source "$HOME/.cargo/env.fish"  # For fish
```

</Accordion>
</Accordions>

2. أعد تحميل متغير بيئة PATH الخاص بك لتضمين دليل bin الخاص بـ
   [Cargo](https://github.com/rust-lang/cargo):

```terminal
$ . "$HOME/.cargo/env"
```

3. تحقق من نجاح التثبيت.

```terminal
$ rustc --version
```

يعرض الأمر إصدار Rust المثبّت، على سبيل المثال:

```
rustc x.y.z (...)
```

</Step>
<Step>

### تثبيت Solana CLI

توفر Solana CLI جميع الأدوات المطلوبة لبناء ونشر برامج سولانا.

1. قم بتثبيت مجموعة أدوات Solana CLI باستخدام أمر التثبيت الرسمي:

```terminal
$ sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

<Callout>
  يمكنك استبدال `stable` بوسم إصدار Agave محدد أو بقناة الإصدار `beta`
  أو `edge`.
</Callout>

2. اجعل سولانا CLI متاحًا في الطرفية الحالية.

يحدّث المثبّت إعدادات الصدفة (shell) لديك ويعرض الأمر المطلوب
لتحديث الجلسة الحالية. وعادةً ما يكون الأمر:

```terminal
$ export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"
```

إذا ظل الأمر `solana` غير متاح، فأعد تشغيل الطرفية. للتأكد من ملف إعدادات
الصدفة الذي حدّثه المثبّت، تحقق من الصدفة الحالية:

```terminal
$ echo $SHELL
```

- إذا كان الناتج يحتوي على `/bash`، فأعد تشغيل الطرفية أو شغّل
  `source ~/.bashrc`.
- إذا كان الناتج يحتوي على `/zsh`، فأعد تشغيل الطرفية أو شغّل `source ~/.zshrc`.

3. تحقق من نجاح التثبيت:

```terminal
$ solana --version
```

يعرض الأمر إصدار سولانا CLI المثبّت، على سبيل المثال:

```
solana-cli x.y.z (..., client:Agave)
```

<Callout>

يمكنك عرض جميع الإصدارات المتاحة في
[مستودع Agave على GitHub](https://github.com/anza-xyz/agave/releases). Agave هو
عميل validator من [Anza](https://www.anza.xyz/)، المعروف سابقًا باسم
عميل validator من سولانا لابس.

</Callout>

4. لتحديث سولانا CLI لاحقًا، شغّل:

```terminal
$ agave-install update
```

</Step>

### تثبيت واجهة سطر أوامر Anchor

[Anchor](https://www.anchor-lang.com/) هو إطار عمل لتطوير برامج سولانا. يستفيد
إطار عمل Anchor من وحدات ماكرو Rust لتبسيط عملية كتابة برامج سولانا.

#### المتطلبات الأساسية

يلزم Node.js ومدير حزم JavaScript فقط عند اختيار قالب اختبار
TypeScript مثل Mocha أو Jest. يعمل قالب اختبار LiteSVM الافتراضي
باستخدام Rust ولا يتطلب أدوات Node.js.

<Accordions>
<Accordion title="تثبيت Node">

1. ثبّت Node باستخدام
   [Node Version Manager (nvm)](https://github.com/nvm-sh/nvm) عبر تشغيل
   الأمر التالي:

```terminal
$ curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```

2. أعد تشغيل الطرفية وتأكد من أن الأمر `nvm` يعمل بنجاح:

```terminal
$ command -v nvm
```

3. استخدم `nvm` لتثبيت Node:

```terminal
$ nvm install --lts
```

4. تحقق من نجاح التثبيت عبر التحقق من إصدار Node:

```terminal
$ node --version
```

يعرض الأمر إصدار Node.js المثبّت، على سبيل المثال:

```
vx.y.z
```

</Accordion>
<Accordion title="تثبيت Yarn">

1. ثبّت Yarn:

```terminal
$ npm install --global yarn
```

2. تحقق من نجاح التثبيت عبر التحقق من إصدار Yarn:

```terminal
$ yarn --version
```

يعرض الأمر إصدار Yarn المثبّت، على سبيل المثال:

```
x.y.z
```

</Accordion>
</Accordions>

#### التثبيت

يمكنك تثبيت Anchor CLI والأدوات بطريقتين:

- Anchor Version Manager (AVM) — طريقة التثبيت الموصى بها
- بدون AVM — التثبيت مباشرة من GitHub

<Tabs groupId="anchor" items={["AVM", "Without AVM"]}>
<Tab value="AVM">

يتيح لك مدير إصدارات Anchor (AVM) تثبيت وإدارة إصدارات Anchor المختلفة على نظامك
وتحديث إصدارات Anchor بسهولة في المستقبل. لتثبيت Anchor باستخدام AVM، اتبع
الخطوات أدناه:

1. قم بتثبيت AVM باستخدام الأمر التالي:

```terminal
$ curl -sSfL https://raw.githubusercontent.com/otter-sec/anchor/master/avm/install | sh
```

2.  تأكد من نجاح تثبيت AVM:

```terminal
$ avm --version
```

3. قم بتثبيت واجهة سطر أوامر Anchor باستخدام AVM:

لتثبيت أحدث إصدار:

```terminal
$ avm install latest
$ avm use latest
```

لتثبيت إصدار محدد، حدد رقم الإصدار:

```terminal
$ avm install 1.1.2
$ avm use 1.1.2
```

<Callout type="warn">

عند تثبيت Anchor CLI على Linux أو WSL، قد تواجه هذا الخطأ:

```
error: could not exec the linker cc = note: Permission denied (os error 13)
```

إذا ظهرت لك رسالة الخطأ هذه، اتبع الخطوات التالية:

1. ثبِّت التبعيات المدرجة في قسم
   [Linux](/docs/intro/installation/dependencies) في أعلى هذه
   الصفحة.
2. أعد محاولة تثبيت Anchor CLI.

</Callout>

4. تحقق من نجاح التثبيت، من خلال التحقق من إصدار واجهة سطر أوامر Anchor:

```terminal
$ anchor --version
```

يعرض الأمر إصدار Anchor CLI النشط، على سبيل المثال:

```
anchor-cli 1.1.2
```

<Callout type="info">

شغّل `avm use` لاختيار إصدار Anchor CLI لنظامك.

- إذا ثبّتت أحدث إصدار، فشغّل `avm use latest`.
- إذا ثبّتت الإصدار `1.1.2`، فشغّل `avm use 1.1.2`.

</Callout>

</Tab>

<Tab value="Without AVM">

1. ثبّت إصدارًا محددًا من Anchor CLI باستخدام الأمر التالي:

```terminal
$ cargo install --git https://github.com/solana-foundation/anchor --tag v1.1.2 anchor-cli --locked
```

2. تحقق من نجاح التثبيت عبر التحقق من إصدار Anchor CLI:

```terminal
$ anchor --version
```

يعرض الأمر إصدار Anchor CLI المثبّت، على سبيل المثال:

```
anchor-cli 1.1.2
```

</Tab>
</Tabs>

### تثبيت Surfpool CLI

[Surfpool](/docs/tools/surfpool) هي أداة للتطوير المحلي وبديل محسّن
لـ `solana-test-validator`.

1. ثبّت Surfpool باستخدام الأمر التالي:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://run.surfpool.run/ | bash
```

2. تحقق من نجاح التثبيت عبر التحقق من إصدار
   Surfpool CLI:

```terminal
$ surfpool --version
```

يعرض الأمر إصدار Surfpool CLI المثبّت، على سبيل المثال:

```
surfpool x.y.z
```
