قم بإعداد بيئة تطوير سولانا محلية باستخدام المثبّت الآلي. يثبّت هذا المثبّت Rust وأداة Solana CLI وأداة Anchor CLI وأداة Surfpool CLI وNode.js وYarn على macOS أو Linux أو Windows عبر WSL.

<Callout type="info" title="يتطلب Windows وجود WSL">
  في Windows PowerShell، شغّل الأمر `wsl --install`، ثم أعد تشغيل Windows إذا طُلب منك ذلك، وبعدها نفّذ أوامر التثبيت الواردة أدناه في طرفية Ubuntu. راجع [دليل التثبيت اليدوي](/docs/intro/installation/dependencies) للاطلاع على إعداد WSL كاملاً.
</Callout>

## التثبيت السريع

1. شغّل المثبّت في طرفية macOS أو Linux أو WSL:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
```

يمكنك [مراجعة المصدر البرمجي للمثبّت](https://github.com/solana-developers/solana-install/blob/main/install.sh) قبل تشغيله. يكتشف المثبّت مديري الحزم المدعومين في Linux ويثبّت تبعيات النظام الخاصة بهم تلقائيًا.

2. أعد تشغيل الطرفية لتصبح الأوامر الجديدة متاحة في `PATH` الخاص بك.

3. تحقق من كل أداة:

```terminal
$ rustc --version
$ solana --version
$ anchor --version
$ surfpool --version
$ node --version
$ yarn --version
```

يعرض التثبيت الناجح مخرجات بالشكل التالي (تتغير أرقام الإصدارات مع صدور الأدوات):

```txt title="Example output"
Installed Versions:
Rust: rustc x.y.z (...)
Solana CLI: solana-cli x.y.z (..., client:Agave)
Anchor CLI: anchor-cli x.y.z
Surfpool CLI: surfpool x.y.z
Node.js: vx.y.z
Yarn: x.y.z
```

<Callout type="warn" title="فشل المثبّت أو هناك أمر مفقود">
  اتبع [دليل التثبيت اليدوي](/docs/intro/installation/dependencies) لتثبيت كل تبعية على حدة أو لاستكشاف أخطائها وإصلاحها.
</Callout>
