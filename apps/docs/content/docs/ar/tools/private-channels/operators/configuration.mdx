## الخدمات

يعني تشغيل نسخة من القنوات الخاصة امتلاك خدمات Docker Compose
التالية:

| الحاوية                                  | الدور                                                                    |
| ------------------------------------------ | ----------------------------------------------------------------------- |
| `private-channel-postgres-primary`         | قاعدة بيانات حالة عقدة الكتابة (PostgreSQL 16)                               |
| `private-channel-postgres-replica`         | قاعدة بيانات حالة عقدة القراءة (نسخة متدفقة)                            |
| `private-channel-postgres-indexer`         | قاعدة بيانات المفهرس والمشغّل                                           |
| `private-channel-write-node`               | يستقبل المعاملات وينفّذها (المنفذ 8900، حلقة العودة فقط)           |
| `private-channel-read-node`                | يعالج استعلامات القراءة عبر RPC (المنفذ 8901، حلقة العودة فقط)                     |
| `private-channel-gateway`                  | يوجّه الطلبات بين عقدتي الكتابة والقراءة؛ يفرض RBAC (المنفذ 8899) |
| `private-channel-indexer-solana`           | يراقب سولانا بحثاً عن أحداث `Deposit` عبر Yellowstone gRPC                |
| `private-channel-indexer-private-channel`  | يراقب القناة بحثاً عن أحداث `Burn` عبر استطلاع RPC                   |
| `private-channel-operator-solana`          | يصدر رموز القناة عند تأكيد الإيداعات                        |
| `private-channel-operator-private-channel` | يستدعي `ReleaseFunds` على الشبكة الرئيسية عند تأكيد عمليات السحب          |
| `private-channel-auth`                     | خدمة JWT/RBAC اختيارية (ملف تعريف Docker: `auth`)                      |

تم تضمين حاويات المراقبة (`prometheus`، `grafana`، `cadvisor`) أيضاً.

## البوابة

تمتلك هذه الإعدادات قيماً افتراضية مناسبة لإعداد Docker Compose الخاص بشبكة التطوير. لا تتجاوزها إلا
عند تشغيل البوابة خارج Docker أو النشر في بيئة الإنتاج.

| متغير البيئة                         | الافتراضي                                                             | مطلوب            | الوصف                                        |
| ------------------------------- | ------------------------------------------------------------------- | ------------------- | -------------------------------------------------- |
| `GATEWAY_PORT`                  | `8899` (devnet)                                                     | لا                  | منفذ الاستماع                                        |
| `GATEWAY_WRITE_URL`             | `http://write-node:8900` (قيمة ملف بيئة devnet؛ لا يوجد افتراضي مدمج) | **نعم**             | عنوان URL لعقدة الكتابة - تُوجَّه طلبات `sendTransaction` هنا     |
| `GATEWAY_READ_URL`              | `http://read-node:8901` (قيمة ملف بيئة devnet؛ لا يوجد افتراضي مدمج)  | **نعم**             | عنوان URL لعقدة القراءة - تُوجَّه جميع طرق RPC الأخرى هنا   |
| `GATEWAY_CORS_ALLOWED_ORIGIN`   | `*`                                                                 | لا                  | قيمة رأس `Access-Control-Allow-Origin`         |
| `JWT_SECRET`                    | -                                                                   | لا                  | يُفعّل RBAC؛ يجب أن يطابق `JWT_SECRET` لخدمة المصادقة |
| `AUTH_DATABASE_URL`             | -                                                                   | إذا تم تعيين `JWT_SECRET` | قاعدة بيانات المصادقة للتحقق من ملكية المحفظة                |
| `AUTH_DATABASE_MAX_CONNECTIONS` | `10`                                                                | لا                  | حجم تجمّع اتصالات قاعدة بيانات المصادقة                       |
| `METRICS_PORT`                  | `9101`                                                              | لا                  | منفذ مقاييس Prometheus                            |
| `RUST_LOG`                      | `info`                                                              | لا                  | مستوى السجل                                          |

> يستخدم `GATEWAY_WRITE_URL` و`GATEWAY_READ_URL` أسماء مضيفي خدمة Docker Compose
> (`write-node`، `read-node`) عند التشغيل داخل Docker. استخدم مكافئات `localhost`
> فقط عند تشغيل الملف الثنائي للبوابة مباشرةً خارج Docker.
>
> القيمة الافتراضية المدمجة للملف الثنائي للبوابة لـ`GATEWAY_PORT` هي `8898`.
> يضبط كل من `.env.example` و`.env.devnet` القيمة على `8899`، وهي ما يستخدمه
> إعداد Docker Compose فعلياً (يحتوي `versions.env` فقط على تثبيتات إصدارات سلسلة الأدوات
> والصور، وليس منافذ الخدمة). تنطبق القيمة الافتراضية `8898` فقط إذا
> قمت بتشغيل الملف الثنائي مباشرةً دون ملف بيئة.

<Callout type="warning">
  يأخذ `GATEWAY_CORS_ALLOWED_ORIGIN` القيمة الافتراضية `*`، مما يسمح لأي مصدر بالاتصال
  بالبوابة من المتصفح. قيّد هذا بالمصدر الفعلي لتطبيقك
  قبل أي نشر في بيئة الإنتاج.
</Callout>

## عقدة الكتابة وعقدة القراءة

يوجد مرجع الإعدادات الكامل لعقدة الكتابة وعقدة القراءة في
[`docs/CONFIG.md`](https://github.com/solana-foundation/solana-private-channels/blob/main/docs/CONFIG.md)
في المستودع.

## خدمة المصادقة

| متغير البيئة                         | مطلوب            | الوصف                                                                                                                  |
| ------------------------------- | ------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `JWT_SECRET`                    | **نعم**             | سر التوقيع HS256؛ يجب أن يطابق `JWT_SECRET` للبوابة                                                                  |
| `AUTH_PORT`                     | لا (الافتراضي `8903`) | منفذ الاستماع                                                                                                                  |
| `AUTH_DATABASE_URL`             | **نعم**             | سلسلة اتصال PostgreSQL لقاعدة بيانات المصادقة                                                                           |
| `CORS_ALLOWED_ORIGIN`           | لا (الافتراضي `*`)    | قيمة رأس `Access-Control-Allow-Origin` لهذه الخدمة (مستقلة عن `GATEWAY_CORS_ALLOWED_ORIGIN` الخاصة بالبوابة) |
| `AUTH_DATABASE_MAX_CONNECTIONS` | لا (الافتراضي `10`)   | حجم تجمّع اتصالات قاعدة بيانات المصادقة                                                                                                 |

## مرجع منافذ الخدمة

| الخدمة          | منفذ المضيف  | الربط                                                                           |
| ---------------- | ---------- | --------------------------------------------------------------------------------- |
| البوابة          | 8899       | جميع الواجهات                                                                    |
| عقدة الكتابة       | 8900       | حلقة العودة فقط                                                                     |
| عقدة القراءة        | 8901       | حلقة العودة فقط                                                                     |
| المتدفق         | 8902       | داخلي فقط (`expose`، غير منشور للمضيف)؛ ليس جزءاً من مجموعة devnet |
| خدمة المصادقة     | 8903       | جميع الواجهات                                                                    |
| مقاييس المشغّل | 9102، 9103 | جميع الواجهات                                                                    |
| Grafana          | 37429      | جميع الواجهات                                                                    |
| Prometheus       | 9090       | جميع الواجهات                                                                    |
| cAdvisor         | 8080       | جميع الواجهات                                                                    |

> **ملاحظة أمنية:** منافذ عقدة الكتابة وعقدة القراءة مرتبطة بحلقة العودة
> (`127.0.0.1`) فقط. البوابة وخدمة المصادقة ومقاييس المشغّل وGrafana
> وPrometheus وcAdvisor كلها منشورة على كل واجهة شبكة في
> إعداد Docker Compose الخاص بشبكة التطوير. قم بتأمينها بجدار الحماية على مستوى المضيف أو الشبكة
> لأي بيئة تتجاوز التطوير المحلي؛ لا يغطي RBAC سوى طرق JSON-RPC
> الخاصة بالبوابة، وليس هذه الخدمات الأخرى. المتدفق هو الاستثناء: إنه
> تغذية داخلية غير مصادق عليها لا ينشرها Docker أبداً للمضيف.
