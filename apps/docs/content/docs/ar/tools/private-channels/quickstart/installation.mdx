## المتطلبات الأساسية

- Rust 1.91+
- سولانا CLI 3.1.13 (Agave):
  `sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.13/install)"`
- Node.js 24.7.0+
- pnpm 10.15.1+: `npm install -g pnpm@10.15.1`

## استنساخ المستودع

```bash
git clone https://github.com/solana-foundation/solana-private-channels.git
cd solana-private-channels
```

## إنشاء عملاء TypeScript

عملاء TypeScript **غير** منشورين على npm. يجب إنشاؤهم من
ملف IDL باستخدام Codama.

```bash
# Escrow program client
cd private-channel-escrow-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..

# Withdraw program client
cd private-channel-withdraw-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..
```

توضع العملاء المُنشؤون في:

- `private-channel-escrow-program/clients/typescript/src/generated/`
- `private-channel-withdraw-program/clients/typescript/src/generated/`

استورد من هذه المسارات المحلية في تطبيقك؛ لا توجد
حزمة `@private-channels/client` على npm. تستخدم أمثلة الكود في هذا القسم
مساراً نسبياً (`../private-channel-escrow-program/...`) يفترض أن الكود الخاص بك
يقع بجانب المستودع المُستنسخ؛ عدّله ليتوافق مع المكان الذي تستورد منه فعلياً في مشروعك.
