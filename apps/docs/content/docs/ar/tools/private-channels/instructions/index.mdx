title: التعليمات

  مرجع تعليمات السلسلة لبرنامجَي الضمان والسحب في القنوات الخاصة
---

يُعدّ هذا القسم مرجعًا للتعليمات على السلسلة. يستدعي معظم المطورين هذه التعليمات عبر عملاء TypeScript المُولَّدة تلقائيًا؛ ولن تحتاج إلى هذا القسم إلا إذا كنت تبني أدوات تشغيل، أو تكتب تكاملات مخصصة، أو تُصحّح أخطاء على مستوى التعليمات.

**برنامج الضمان** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) - يُدير
الإيداعات، وتوفير المشغّلين، وتسوية الشبكة الرئيسية:

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) -
  تهيئة PDA لنسخة الضمان
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) - إدراج
  عنوان إصدار رمز SPL في القائمة البيضاء
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) - إزالة
  عنوان إصدار من القائمة البيضاء
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) -
  تسجيل مشغّل جديد
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) -
  إلغاء صلاحيات مشغّل
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) -
  نقل صلاحيات المسؤول
- [Deposit](/docs/tools/private-channels/instructions/deposit) - نقل رموز SPL
  إلى الضمان
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) -
  يُسوّي المشغّل طلب سحب إلى الشبكة الرئيسية
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) -
  يُدوّر المشغّل جذر شجرة ميركل المتفرقة

**برنامج السحب** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) - يعمل على
شبكة القناة الخاصة:

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) -
  حرق الرصيد على جانب القناة لبدء عملية السحب

## رموز الأخطاء

**برنامج الضمان - `PrivateChannelEscrowProgramError`**

| الرمز                                         | الرسالة                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | صلاحية الحدث المُقدَّمة غير صالحة                 |
| `InvalidAta`                                 | ATA المُقدَّم غير صالح                             |
| `InvalidMint`                                | عنوان الإصدار المُقدَّم غير صالح                            |
| `InvalidInstanceId`                          | معرّف النسخة غير صالح أو لا يستوفي القواعد المطلوبة    |
| `InvalidInstance`                            | النسخة المُقدَّمة غير صالحة                        |
| `InvalidAdmin`                               | المسؤول المُقدَّم غير صالح                           |
| `TransferHookNotAllowed`                     | امتداد خطاف النقل غير مسموح به              |
| `InvalidOperatorPda`                         | PDA المشغّل المُقدَّم غير صالح                    |
| `InvalidTokenAccount`                        | token account المُقدَّم غير صالح                   |
| `InvalidEscrowBalance`                       | رصيد الضمان غير صالح                           |
| `InvalidAllowedMint`                         | عنوان الإصدار المسموح به غير صالح                             |
| `InvalidSmtProof`                            | إثبات SMT المُقدَّم غير صالح                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | رقم Nonce الخاص بالمعاملة غير صالح لمؤشر الشجرة الحالي |
| `UnexpectedTreeIndex`                        | مؤشر الشجرة الحالي غير متوقع لإعادة تعيين جذر SMT |

**برنامج السحب - `PrivateChannelWithdrawProgramError`**

| الرمز          | الرسالة                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | عنوان الإصدار المُقدَّم غير صالح                       |
| `ZeroAmount`  | يجب أن يكون مبلغ السحب أكبر من الصفر |
