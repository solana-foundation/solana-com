---
title: إيداع
description:
  تحويل رموز SPL من محفظة المستخدم إلى ضمان القنوات الخاصة
---

تحوّل رموز SPL من associated token account الخاص بالمستخدم إلى
associated token account الخاص بالضمان، مع إضافة الرصيد إلى رصيد قناة المستخدم المودِع (أو رصيد المستلم الاختياري).

## الحسابات

| الحساب                          | قابل للكتابة | موقِّع | الوصف                                          |
| -------------------------------- | -------- | ------ | ---------------------------------------------------- |
| `payer`                          | ✓        | ✓      | دافع رسوم المعاملة                        |
| `user`                           |          | ✓      | مالك الرمز الذي يُجري الإيداع                       |
| `instance`                       |          |        | PDA نسخة الضمان                                  |
| `mint`                           |          |        | مصدر رمز SPL                                       |
| `allowed_mint`                   |          |        | PDA للتحقق من أن المصدر مسموح به في هذه النسخة |
| `user_ata`                       | ✓        |        | associated token account الخاص بالمستخدم (المصدر)             |
| `instance_ata`                   | ✓        |        | associated token account الخاص بالضمان (الوجهة)      |
| `system_program`                 |          |        | System Program                                       |
| `token_program`                  |          |        | SPL Token Program                                    |
| `associated_token_program`       |          |        | Associated Token Program                             |
| `event_authority`                |          |        | PDA صلاحية الحدث لـ CPI الخاص بـ `EmitEvent`              |
| `private_channel_escrow_program` |          |        | برنامج الضمان (مرجع ذاتي لـ CPI)              |

## المعاملات

| المعامل   | النوع             | الوصف                                                                           |
| ----------- | ---------------- | ------------------------------------------------------------------------------------- |
| `amount`    | `u64`            | كمية الرموز المراد إيداعها، بأصغر وحدة للرمز                             |
| `recipient` | `Option<Pubkey>` | مستلم اختياري على السلسلة؛ في حال كانت القيمة `None`، يُضاف الرصيد إلى رصيد قناة المستخدم المودِع |

## القيم المُعادة

يُعيد `TransactionBuilder` يمكن استخدامه لبناء المعاملة وإرسالها.

## مثال

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

// allowedMint and instanceAta are auto-derived from mint and instance
const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n,
  recipient: null
});
```

## ملاحظات مهمة

- معرّف البرنامج: `9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`
- بالنسبة لمصادر Token-2022، يجب تمرير `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS`
  صراحةً، إذ يُعيَّن افتراضيًا إلى SPL Token Program القياسي
- يجب أن يكون PDA الخاص بـ `allowed_mint` موجودًا (تم إنشاؤه بواسطة `AllowMint`)؛ إيداع مصدر غير مدرج يُطلق الخطأ `InvalidAllowedMint`
- عندما تكون قيمة `recipient` هي `None`، يُضاف الرصيد إلى رصيد قناة المستخدم المودِع؛ وعند تحديده، يُضاف الرصيد إلى رصيد المحفظة المحددة بدلًا من ذلك
- يجب أن يوقّع كلٌّ من `payer` و`user` على المعاملة
- يجب أن يكون `instance_ata` موجودًا مسبقًا (تم إنشاؤه بواسطة `AllowMint` لهذا المصدر)
