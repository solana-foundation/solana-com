يزيل سك عملة مسموحاً به مسبقاً من المثيل، مما يمنع الإيداعات الجديدة
لذلك السك. الإيداعات الحالية غير متأثرة.

## الحسابات

| الحساب                          | قابل للكتابة | موقِّع | الوصف                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | دافع الرسوم                                    |
| `admin`                          |          | ✓      | مسؤول المثيل                               |
| `instance`                       |          |        | PDA الخاص بالمثيل                                 |
| `mint`                           |          |        | سك رمز SPL المراد حظره                      |
| `allowed_mint`                   | ✓        |        | AllowedMint PDA (مغلق بواسطة هذه التعليمة) |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | PDA سلطة الأحداث                          |
| `private_channel_escrow_program` |          |        | برنامج الضمان                               |

هذه التعليمة لا تأخذ أي معاملات.

## ملاحظات مهمة

- يُغلق `allowed_mint` PDA: ستفشل استدعاءات `Deposit` الجديدة لهذا السك
  مع `InvalidAllowedMint`
- أرصدة القناة الحالية لهذا السك غير متأثرة
- يُصدر حدثاً عبر `EmitEvent` CPI
