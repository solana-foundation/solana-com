يزيل mint مسموحاً به سابقاً من النسخة، مما يمنع الإيداعات الجديدة
لذلك الـ mint. الإيداعات الحالية غير متأثرة.

## الحسابات

| الحساب                          | قابل للكتابة | موقِّع | الوصف                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | دافع الرسوم                                    |
| `admin`                          |          | ✓      | مسؤول النسخة                               |
| `instance`                       |          |        | عنوان PDA للنسخة                                 |
| `mint`                           |          |        | عنوان mint لرمز SPL المراد حظره                      |
| `allowed_mint`                   | ✓        |        | عنوان PDA الخاص بـ AllowedMint (يُغلق بواسطة هذه التعليمة) |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | عنوان PDA لسلطة الأحداث                          |
| `private_channel_escrow_program` |          |        | برنامج الضمان                               |

هذه التعليمة لا تأخذ أي معاملات.

## ملاحظات مهمة

- يُغلق عنوان PDA الخاص بـ `allowed_mint`: ستفشل استدعاءات `Deposit` الجديدة لهذا الـ mint
  بخطأ `InvalidAllowedMint`
- أرصدة القنوات الحالية لهذا الـ mint غير متأثرة
- يُصدر حدثاً عبر `EmitEvent` CPI
