title: RemoveOperator
description: يلغي صلاحيات المشغّل عن طريق إغلاق PDA الخاص به
---

يلغي صلاحيات المشغّل عن طريق إغلاق `Operator` PDA الخاص به. لن يتمكن المحفظة الملغاة من استدعاء `ReleaseFunds` أو `ResetSmtRoot` بعد الآن.

## الحسابات

| الحساب                          | قابل للكتابة | موقِّع | الوصف                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | دافع الرسوم                                 |
| `admin`                          |          | ✓      | مدير النسخة                            |
| `instance`                       |          |        | PDA النسخة                              |
| `operator`                       |          |        | محفظة المشغّل المراد إلغاء صلاحياتها                 |
| `operator_pda`                   | ✓        |        | PDA المشغّل (يُغلق بواسطة هذه التعليمة) |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | PDA سلطة الأحداث                       |
| `private_channel_escrow_program` |          |        | برنامج الضمان                            |

لا تأخذ هذه التعليمة أي معاملات.

## ملاحظات مهمة

- يُغلق `operator_pda`؛ ولن تتمكن المحفظة الملغاة من استدعاء
  `ReleaseFunds` أو `ResetSmtRoot` بعد الآن
- ستفشل أي معاملات مشغّل قيد التنفيذ بخطأ `InvalidOperatorPda` بعد
  هذا الاستدعاء
- يُصدر حدثاً عبر `EmitEvent` CPI
