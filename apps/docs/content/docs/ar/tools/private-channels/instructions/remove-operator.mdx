title: RemoveOperator

---

يلغي صلاحيات مشغّل عن طريق إغلاق حساب `Operator` PDA الخاص به. لن يتمكن المحفظة الملغاة صلاحياتها من استدعاء `ReleaseFunds` أو `ResetSmtRoot` بعد الآن.

## الحسابات

| الحساب                          | قابل للكتابة | موقِّع | الوصف                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | دافع الرسوم                                 |
| `admin`                          |          | ✓      | مدير النسخة                            |
| `instance`                       |          |        | حساب PDA للنسخة                              |
| `operator`                       |          |        | محفظة المشغّل المراد إلغاء صلاحياتها                 |
| `operator_pda`                   | ✓        |        | حساب PDA للمشغّل (يُغلق بواسطة هذه التعليمة) |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | حساب PDA لسلطة الأحداث                       |
| `private_channel_escrow_program` |          |        | برنامج الضمان                            |

لا تأخذ هذه التعليمة أي معاملات.

## ملاحظات مهمة

- يُغلق حساب `operator_pda`؛ ولن تتمكن المحفظة الملغاة صلاحياتها من استدعاء
  `ReleaseFunds` أو `ResetSmtRoot` بعد الآن
- ستفشل أي معاملات مشغّل قيد التنفيذ مع الخطأ `InvalidOperatorPda` بعد
  هذا الاستدعاء
- يُصدر حدثاً عبر استدعاء CPI لـ `EmitEvent`
