يسمح بسك رمز SPL على النسخة ويُنشئ الـ associated token account الخاص بالضامن
لذلك السك. تصبح الإيداعات لهذا السك ممكنةً بعد هذا
الاستدعاء.

## الحسابات

| الحساب                          | قابل للكتابة | موقِّع | الوصف                                                                   |
| -------------------------------- | -------- | ------ | ----------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | دافع الرسوم                                                                     |
| `admin`                          |          | ✓      | مدير النسخة                                                                |
| `instance`                       |          |        | PDA الخاص بالنسخة                                                                  |
| `mint`                           |          |        | سك رمز SPL المراد السماح به                                                       |
| `allowed_mint`                   | ✓        |        | PDA الخاص بـ AllowedMint (يُنشأ بواسطة هذه التعليمة)                                 |
| `instance_ata`                   | ✓        |        | associated token account الخاص بالضامن لهذا السك (يُنشأ بواسطة هذه التعليمة) |
| `system_program`                 |          |        | System Program                                                                |
| `token_program`                  |          |        | برنامج SPL Token                                                             |
| `associated_token_program`       |          |        | Associated Token Program                                                      |
| `event_authority`                |          |        | PDA الخاص بسلطة الأحداث                                                           |
| `private_channel_escrow_program` |          |        | برنامج الضمان                                                                |

## المعاملات

| المعامل | النوع | الوصف                                                                                   |
| --------- | ---- | --------------------------------------------------------------------------------------------- |
| `bump`    | `u8` | bump seed الخاص بـ PDA الخاص بـ `allowed_mint`. اختياري: يشتقه العميل `Async` تلقائيًا إذا لم يُذكر |

> يحتوي IDL على وسيطة `discriminator: u8` (القيمة `1`) يتم ضبطها تلقائيًا
> بواسطة العميل المُولَّد ولا ينبغي تمريرها يدويًا.

## ملاحظات مهمة

- استخدم `getAllowMintInstructionAsync`؛ إذ يشتق تلقائيًا `bump` و`allowed_mint`
  و`instance_ata` عند عدم توفيرها. مرِّر `bump` الخاص بك فقط إذا
  حسبته مسبقًا عبر
  `Pubkey::find_program_address(&[b"allowed_mint", instance_pda, mint], &PROGRAM_ID)`
- يُنشئ أيضًا `instance_ata`، وهو الـ ATA الخاص بالضامن لهذا السك
- تُحجب السكوك التي تحتوي على امتداد transfer hook صراحةً: تؤدي محاولة
  السماح بمثل هذا السك إلى رمي الخطأ `TransferHookNotAllowed`
- يُصدر حدثًا عبر CPI الخاص بـ `EmitEvent`
