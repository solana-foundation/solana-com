يُنشئ مشغّلاً جديداً عبر إنشاء `Operator` PDA الخاص به. بعد هذا الاستدعاء، يمكن
لمحفظة `operator` استدعاء `ReleaseFunds` و`ResetSmtRoot`.

## الحسابات

| الحساب                          | قابل للكتابة | موقِّع | الوصف                                                         |
| -------------------------------- | -------- | ------ | ------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | دافع الرسوم                                                           |
| `admin`                          |          | ✓      | مسؤول النسخة                                                      |
| `instance`                       |          |        | PDA النسخة                                                        |
| `operator`                       |          |        | محفظة المشغّل المراد توفيرها                                        |
| `operator_pda`                   | ✓        |        | PDA المشغّل - مشتقّ تلقائياً من `["operator", instance, operator]` |
| `system_program`                 |          |        | System Program                                                      |
| `event_authority`                |          |        | PDA صلاحية الأحداث                                                 |
| `private_channel_escrow_program` |          |        | برنامج الضمان                                                      |

## المعاملات

| المعامل | النوع | الوصف                                                                               |
| --------- | ---- | ----------------------------------------------------------------------------------------- |
| `bump`    | `u8` | bump seed لـ`operator_pda`. اختياري: يشتقّه عميل `Async` تلقائياً إذا لم يُحدَّد |

> يحتوي IDL على وسيطة `discriminator: u8` (القيمة `3`) يتم ضبطها تلقائياً
> بواسطة العميل المُولَّد ولا ينبغي تمريرها يدوياً.

## ملاحظات مهمة

- استخدم `getAddOperatorInstructionAsync`؛ إذ يشتقّ `bump` و
  `operator_pda` تلقائياً عند عدم تقديمهما. كما يتوفّر متغيّر متزامن
  `getAddOperatorInstruction` في حال حسبت `bump`
  بنفسك مسبقاً
- بعد هذا الاستدعاء، يمكن لمحفظة `operator` استدعاء `ReleaseFunds` و
  `ResetSmtRoot`
- يُصدر حدثاً عبر `EmitEvent` CPI
