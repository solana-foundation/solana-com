ينشئ `Instance` PDA الذي يربط الضمان. يجب استدعاؤه قبل أي
عملية أخرى.

## بذور PDA

```
instance        -> ["instance", instance_seed: Pubkey]
allowed_mint    -> ["allowed_mint", instance_pda: Pubkey, mint: Pubkey]
operator        -> ["operator", instance_pda: Pubkey, operator: Pubkey]
event_authority -> ["event_authority"]
```

## الحسابات

| الحساب                          | قابل للكتابة | موقِّع | الوصف                                                                 |
| -------------------------------- | -------- | ------ | --------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | دافع الرسوم ودافع rent                                                    |
| `admin`                          |          | ✓      | المسؤول الأولي للـ instance                                               |
| `instance_seed`                  |          | ✓      | keypair مؤقت يُستخدم فقط لاشتقاق PDA؛ يصبح pubkey الخاص به هو seed |
| `instance`                       | ✓        |        | Instance PDA (مشتق من `["instance", instance_seed.pubkey]`)            |
| `system_program`                 |          |        | System Program                                                              |
| `event_authority`                |          |        | PDA سلطة الأحداث                                                         |
| `private_channel_escrow_program` |          |        | برنامج الضمان                                                              |

## المعاملات

| المعامل | النوع | الوصف                                                                             |
| --------- | ---- | --------------------------------------------------------------------------------------- |
| `bump`    | `u8` | bump seed لـ instance PDA. اختياري: يشتقه عميل `Async` تلقائيًا إذا لم يُحدَّد |

> يحتوي IDL على وسيطة `discriminator: u8` (القيمة `0`) يتم ضبطها تلقائيًا
> بواسطة العميل المُولَّد ولا يجب تمريرها يدويًا.

## ملاحظات مهمة

- `instance_seed` هو keypair مؤقت، يُستخدم فقط لاشتقاق `Instance`
  PDA. يصبح pubkey الخاص به هو seed؛ ولا يتم تخزين keypair نفسه أو إعادة استخدامه.
- استخدم `getCreateInstanceInstructionAsync`؛ إذ يشتق تلقائيًا `bump` و`instance`
  من `instance_seed` عند عدم توفيرهما. مرِّر `bump` الخاص بك فقط إذا
  حسبته مسبقًا عبر
  `Pubkey::find_program_address(&[b"instance", instance_seed_pubkey.as_ref()], &PROGRAM_ID)`
- يُصدر حدثًا عبر `EmitEvent` CPI
