نقل صلاحيات المسؤول إلى محفظة جديدة.

## الحسابات

| الحساب                          | قابل للكتابة | موقِّع | الوصف                        |
| -------------------------------- | -------- | ------ | ---------------------------------- |
| `payer`                          | ✓        | ✓      | دافع الرسوم                          |
| `current_admin`                  |          | ✓      | المسؤول الحالي (يجب أن يوقّع)          |
| `instance`                       | ✓        |        | PDA الخاصة بالمثيل (يتم تحديث حقل المسؤول) |
| `new_admin`                      |          | ✓      | المحفظة التي ستستلم صلاحيات المسؤول     |
| `event_authority`                |          |        | PDA سلطة الأحداث                |
| `private_channel_escrow_program` |          |        | برنامج الضمان                     |

هذا التعليمات لا يأخذ أي معاملات.

## ملاحظات مهمة

- **لا يمكن التراجع عنه في خطوة واحدة**: لا يستطيع المسؤول الحالي استعادة الدور
  دون أن يستدعي المسؤول الجديد `SetNewAdmin` مرة أخرى
- تحقق من العنوان المستهدف قبل الاستدعاء؛ لا يوجد خيار للتراجع
- يُصدر حدثاً عبر `EmitEvent` CPI
