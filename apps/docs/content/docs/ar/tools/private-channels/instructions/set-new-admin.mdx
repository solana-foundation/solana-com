تحويل صلاحيات المسؤول إلى محفظة جديدة.

## الحسابات

| الحساب                          | قابل للكتابة | موقِّع | الوصف                        |
| -------------------------------- | -------- | ------ | ---------------------------------- |
| `payer`                          | ✓        | ✓      | دافع الرسوم                          |
| `current_admin`                  |          | ✓      | المسؤول الحالي (يجب أن يوقّع)          |
| `instance`                       | ✓        |        | حساب PDA للنسخة (يتم تحديث حقل المسؤول) |
| `new_admin`                      |          | ✓      | المحفظة التي ستستلم صلاحيات المسؤول     |
| `event_authority`                |          |        | حساب PDA لسلطة الأحداث                |
| `private_channel_escrow_program` |          |        | برنامج الضمان                     |

لا تأخذ هذه التعليمة أي معاملات.

## ملاحظات مهمة

- **لا رجعة فيه في خطوة واحدة**: لا يستطيع المسؤول الحالي استعادة الدور
  دون أن يقوم المسؤول الجديد باستدعاء `SetNewAdmin` مرة أخرى
- تحقق من العنوان المستهدف قبل الاستدعاء؛ لا توجد إمكانية للتراجع
- يُصدر حدثاً عبر استدعاء `EmitEvent` CPI
