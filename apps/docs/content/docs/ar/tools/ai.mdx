# العمل مع نماذج اللغة الكبيرة والوكلاء على سولانا

قبل التعمق في الأدوات المحددة، دعنا نفهم المكونات الرئيسية في مجموعة أدوات تطوير الذكاء الاصطناعي:

## فهم مجموعة أدوات الذكاء الاصطناعي

1. **نماذج اللغة الكبيرة (LLMs)**
   - النماذج الأساسية للذكاء الاصطناعي (مثل GPT-4 وClaude وLlama)
   - معالجة اللغة الطبيعية وتوليدها
   - توفير قدرات الذكاء الخام والاستدلال
   - أمثلة: GPT-4 من OpenAI، وClaude من Anthropic، وLlama من Meta

2. **أطر عمل الوكلاء (مثل Eliza)**
   - مبنية فوق نماذج اللغة الكبيرة لإنشاء وكلاء مستقلين
   - إدارة شخصيات الوكلاء وسلوكياتهم
   - معالجة الذاكرة والسياق
   - توفير تكامل متعدد المنصات
   - أمثلة: Eliza وLangChain وAutoGPT وVercel AI

3. **مجموعات أدوات الوكلاء المتخصصة (مثل Solana Agent Kit)**
   - مصممة لحالات استخدام محددة (مثل عمليات البلوك تشين)
   - توفير أدوات وتكاملات جاهزة مسبقاً
   - تجريد التعقيد التقني
   - وظائف بلوك تشين جاهزة للاستخدام
   - أمثلة: Solana Agent Kit وGOAT Toolkit

فكّر في الأمر هكذا:

- نماذج اللغة الكبيرة هي "الدماغ" الذي يمكنه فهم اللغة وتوليدها
- أطر عمل الوكلاء هي "نظام التشغيل" الذي يدير سلوك الذكاء الاصطناعي
- المجموعات المتخصصة هي "التطبيقات" التي تمنح الذكاء الاصطناعي قدرات محددة

# بناء وكلاء الذكاء الاصطناعي لسولانا

سيوضح لك هذا الدليل كيفية:

- بناء وكيل ذكاء اصطناعي أساسي باستخدام Solana Agent Kit من SendAI
- إنشاء بوت تويتر باستخدام إطار عمل Eliza
- فهم خيارات تكامل الذكاء الاصطناعي على السلسلة
- خيارات لبناء بوتات تداول متقدمة

## مقدمة إلى وكلاء الذكاء الاصطناعي على سولانا

وكلاء الذكاء الاصطناعي على سولانا هم برامج مستقلة يمكنها التفاعل مع
البلوك تشين باستخدام معالجة اللغة الطبيعية والتعلم الآلي. يمكنها:

- تنفيذ المعاملات
- مراقبة نشاط البلوك تشين
- التفاعل مع العقود الذكية
- تقديم المساعدة للمستخدمين
- أتمتة سير العمل المعقد

## الأطر المتاحة

تتوفر عدة أطر عمل لبناء وكلاء الذكاء الاصطناعي على سولانا:

1. **Solana Agent Kit من SendAI**

- مجموعة من الأدوات لبناء الوكلاء على سولانا
- متوافق مع Eliza وLangchain وVercel AI SDK
- أدوات ومرافق سولانا مدمجة
- إمكانيات معالجة اللغة الطبيعية
- [Solana Agent Kit](https://github.com/sendaifun/solana-agent-kit)
- [التوثيق](https://docs.solanaagentkit.xyz/)

2. **إطار عمل Eliza**

- يجمع بين طبقة البيانات ونماذج اللغة الكبيرة والوكلاء، ويتضمن مكوناً إضافياً مخصصاً لسولانا
- بنية وكيل قابلة للتوسيع
- تكامل سهل مع المشاريع الموجودة ويمكن استخدامه على سبيل المثال لبوتات
  تويتر (X) وتيليغرام وديسكورد
- [مستودع GitHub](https://github.com/elizaOS/eliza)

3. **GOAT Toolkit**

- مجموعة أدوات تطوير شاملة
- توافق متعدد السلاسل
- [مستودع GitHub](https://github.com/goat-sdk/goat)

4. **إطار عمل Rig**

- تطبيق Rust أصلي
- مناسب لبوتات التداول عالية الأداء
- يمكن دمجه مع مجموعة أدوات Listen.rs لتكامل سولانا ومراقبة المعاملات
  وإرسال المعاملات باستخدام حزم Jito على سبيل المثال
- [مستودع GitHub](https://github.com/0xPlaygrounds/rig)
- [مستودع Listen.rs](https://github.com/piotrostr/listen)

إذا كنت تبني إطار عمل ذكاء اصطناعي، فلا تتردد في فتح طلب سحب (PR) لإضافة إطار عملك إلى القائمة

<Step>
### إنشاء سكريبت الوكيل

أنشئ ملفاً جديداً باسم `agent.ts` بالمحتوى التالي:

```typescript filename=agent.ts
import { SolanaAgentKit, createSolanaTools } from "solana-agent-kit";
import { HumanMessage } from "@langchain/core/messages";
import { ChatOpenAI } from "@langchain/openai";
import { createReactAgent } from "@langchain/langgraph/prebuilt";
import { MemorySaver } from "@langchain/langgraph";
import * as dotenv from "dotenv";
import bs58 from "bs58";
import * as readline from "readline";

dotenv.config();

async function initializeAgent() {
  const llm = new ChatOpenAI({
    modelName: "gpt-4-turbo-preview",
    temperature: 0.7
  });

  // Convert array string to actual array, then to Uint8Array, then to base58
  const privateKeyArray = JSON.parse(process.env.SOLANA_PRIVATE_KEY!);
  const privateKeyUint8 = new Uint8Array(privateKeyArray);
  const privateKeyBase58 = bs58.encode(privateKeyUint8);

  const solanaKit = new SolanaAgentKit(privateKeyBase58, process.env.RPC_URL!, {
    OPENAI_API_KEY: process.env.OPENAI_API_KEY!
  });

  const tools = createSolanaTools(solanaKit);
  const memory = new MemorySaver();

  return createReactAgent({
    llm,
    tools,
    checkpointSaver: memory
  });
}

async function runInteractiveChat() {
  const agent = await initializeAgent();
  const config = { configurable: { thread_id: "Solana Agent Kit!" } };
  const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout
  });

  // Clear console and start chat with a small delay
  setTimeout(() => {
    console.clear(); // Clear any initialization messages
    console.log("Chat with Solana Agent (type 'exit' to quit)");
    console.log("--------------------------------------------");
    askQuestion();
  }, 100);

  const askQuestion = () => {
    rl.question("You: ", async (input) => {
      if (input.toLowerCase() === "exit") {
        rl.close();
        return;
      }

      const stream = await agent.stream(
        {
          messages: [new HumanMessage(input)]
        },
        config
      );

      process.stdout.write("Agent: ");
      for await (const chunk of stream) {
        if ("agent" in chunk) {
          process.stdout.write(chunk.agent.messages[0].content);
        } else if ("tools" in chunk) {
          process.stdout.write(chunk.tools.messages[0].content);
        }
      }
      console.log("\n--------------------------------------------");

      askQuestion(); // Continue the conversation
    });
  };
}

runInteractiveChat().catch(console.error);
```

</Step>

## البناء باستخدام إطار عمل Eliza

[ElizaOS](https://github.com/elizaOS/eliza) (المعروف سابقاً بـ Ai16z) هو
إطار عمل للذكاء الاصطناعي. وهذا يعني أنه يجمع تطبيقات متعددة في واحدة و
ينظم تفاعلاتها. ويجمع:

1. نماذج LLM مختلفة لفهم المستخدم
2. وكلاء البلوك تشين بإجراءات مختلفة (مثل سك NFT على سبيل المثال)
3. طبقات البيانات لتخزين حالة الشخصيات بين الإجراءات باستخدام على سبيل المثال
   Redis أو PostgreSQL DB أو التخزين المحلي
4. عملاء مختلفون مثل X وتيليغرام وديسكورد وغيرها.

يأخذ كل هذه الأشياء ويضعها معاً بطريقة تمكّنك من إنشاء
"شخصية" يمكنها التفاعل مع المستخدمين أو بشكل مستقل. هذه الشخصيات
معرّفة في ملف JSON، يحدد الإجراءات التي يمكنها تنفيذها، ونموذج اللغة الكبيرة الذي
يجب استخدامه، والمطالبات المختلفة التي تحدد سلوك الشخصية.

### إنشاء تهيئة الشخصية

لإنشاء شخصية جديدة نحتاج إلى إنشاء ملف character.json. يمكنك العثور على
الشخصيات المحددة مسبقاً في مجلد characters في مشروع Eliza. لإنشاء
شخصية جديدة يمكنك نسخ وتعديل إحدى الشخصيات الموجودة، أو
yمكنك استخدام
[ميزة composer في Cursor](https://docs.cursor.com/composer/overview) وإخباره
بنوع الشخصية التي تريد إنشاءها.

```json filename=characters/sol.character.json
{
    "name": "Sol",
    "clients": ["twitter"],
    "modelProvider": "openai",
    "settings": {
        "voice": {
            "model": "en_US-neural"
        },
        ...
```

الجزء المهم هنا هو clients وmodelProvider. في حالتنا
نريد استخدام twitter كعميل وopenai كمزود للنموذج لأن هذا
ما حددنا له أسرارنا في ملف `.env`.

### تشغيل الوكيل

الآن بعد اكتمال التهيئة يمكننا تشغيل شخصيتنا:

```bash
pnpm start --character="characters/sol.character.json"
```

سيبدأ هذا الوكيل ويمكنك الآن التفاعل معه على تويتر. ستبدأ
الشخصية تلقائياً في نشر تغريدات كل بضع ساعات، وعند التفاعل معها ستكون قادرة على تنفيذ إجراءات سولانا مثل سك NFTs
على سبيل المثال.

يمكنك هنا مشاهدة
[الشخصية أثناء العمل](https://x.com/solanadevhelper/status/1882222232656847143).

يمكنك أيضاً التفاعل مع الشخصية محلياً باستخدام الأمر التالي:
قد تحتاج إلى تحرير المنفذ 3000 وبدء تشغيل شخصيتك مع علم `--host`.

```bash
pnpm start --character="characters/sol.character.json" --host
pnpm start:client
```

إذا لم يتصل العميل الخاص بك، تأكد من تشغيل وكيلك مع علم `--host`
وأن المنفذ 3000 غير مستخدم عند بدء تشغيل العميل.

لمزيد من المعلومات اتبع
[وثائق eliza الرسمية](https://elizaos.github.io/eliza/docs/quickstart/)

## استخدام GOAT Toolkit

[GOAT](https://github.com/goat-sdk/goat) مشابه لـ Solana Agent Kit وهو
مجموعة من أدوات البلوك تشين المتنوعة التي تدعم أيضاً إجراءات سولانا المختلفة وسلاسل أخرى. ويمكن دمجه أيضاً في إطار عمل Eliza
على سبيل المثال ويدعم العديد من المحافظ وأطر العمل والبلوك تشين المختلفة. يوضح هذا
[المثال](https://github.com/goat-sdk/goat/tree/main/typescript/examples/by-use-case/solana-purchase-on-amazon)
كيف يمكنك استخدام [Crossmint](https://www.crossmint.com/) مباشرة في
[محرر كود Windsurf](https://codeium.com/windsurf) لشراء منتجات من Amazon.
يتوفر أيضاً
[فيديو توضيحي](https://x.com/windsurf_ai/status/1903118960633188485).

## تكامل وكيل البرنامج على السلسلة

إذا أردت استخدام رد وكيل الذكاء الاصطناعي داخل برنامج سولانا، فأنت بحاجة إلى استخدام
أوراكل يكتب بيانات الرد في حساب يمكن لبرنامجك قراءته.
يمكنك إيجاد مثال على نموذج لغوي كبير (LLM) يقوم بتحويل الرموز إلى أي مستخدم يجيب
على الأسئلة بشكل صحيح هنا:

[تفاعل برنامج اللسلسة مع نماذج اللغة الكبيرة](https://github.com/GabrielePicco/super-smart-contracts)

هذا مثال على برنامج على السلسلة يتكامل مع أوراكل نموذج لغوي كبير (LLM/ذكاء اصطناعي)
لإنشاء وكيل تفاعلي لتوزيع الرموز يُسمى "Mar1o".

### الميزات الرئيسية

1. **تفاعل وكيل الذكاء الاصطناعي**
   - يمكن للمستخدمين التحدث مع Mar1o لمحاولة كسب الرموز
   - يقيّم الوكيل معرفة المستخدم بسولانا لتحديد كميات الرموز
   - تكون الردود بتنسيق JSON تتضمن نص الرد وكمية الرموز

2. **إدارة الرموز**
   - إنشاء رموز MAR1O مع البيانات الوصفية
   - يمكن سك ما بين 0 و10,000 رمز بناءً على استجابة الذكاء الاصطناعي
   - يستخدم PDAs لإدارة الرموز

### شرح تدفق البرنامج

إليك كيفية عمل هذا البرنامج:

```rust
// Initialize the AI agent with personality
const AGENT_DESC: &str = "You are an AI agent called Mar1o which can dispense MAR1O tokens...";

// User interaction flow:
// 1. User sends message to agent
// 2. Oracle processes with LLM
// 3. Agent responds with JSON containing reply and amount
// 4. If amount > 0, tokens are minted to user

// Example response:
{
    "reply": "Great answer! Here's a reward.",
    "amount": 1000
}
```

يوضح هذا كيفية الجمع بين قدرات الذكاء الاصطناعي وآليات الرموز على السلسلة لإنشاء
تجارب بلوكشين تفاعلية. إليك
[مثال حي](https://mar1o.xyz/) حيث يمكنك محاولة إقناع الوكيل
بتحويل بعض الرموز إليك.

## وكلاء Rust المتقدمون للتداول الخوارزمي

إذا أردت كتابة وكلائك بلغة Rust، يمكنك استخدام
[إطار عمل Rig](https://github.com/0xPlaygrounds/rig) و
مكتبة [Listen.rs](https://github.com/piotrostr/listen).

يتكامل هذان الإطاران بشكل جيد معاً. فبينما يمنحك إطار عمل Rig طريقة سهلة للاتصال
بنماذج اللغة الكبيرة، توفر لك مجموعة أدوات Listen.rs تكامل سولانا
بما في ذلك مراقبة المعاملات وإرسالها باستخدام حزم Jito على سبيل المثال.

## أفضل الممارسات

- تذكر أن وكيلك يمتلك مفتاحاً خاصاً وبالتالي يمكنه الوصول إلى الأموال في
  محفظتك. إذا كان بإمكان أحدهم التحدث مع وكيلك وكان يمتلك إجراء تحويل
  مثلاً، فمن المحتمل أن يتمكن المستخدمون من جعله يحوّل أموالك إليهم.
- استخدم [نقاط نهاية RPC](https://solana.com/rpc) مدفوعة. عادةً ما تخضع نقاط النهاية العامة
  لقيود معدل الاستخدام
- راقب أنشطة الوكيل وتأكد من أنه لا يقوم بأي إجراءات ضارة
  أو أن يُخدع للقيام بها من قِبل المستخدمين الذين يتفاعلون معه
- نفّذ رسوم الأولوية وإعادة محاولات المعاملات في إجراءات وكيلك حتى
  تصل أيضاً عند وجود ازدحام على الشبكة
- إن أمكن، اختبر على شبكة devnet أولاً قبل النشر على mainnet. معظم الوكلاء
  يأخذون عنوان URL الخاص بـ RPC كمدخل ويمكنك استخدام شبكة devnet حتى تكون
  جاهزاً للـ mainnet. غير أنه قد لا تكون جميع الإجراءات ممكنة على devnet.
- عند كتابة إجراءاتك الخاصة، أضف اختبارات تكاملية لها حتى تتمكن
  الأطر من مراقبة الإجراءات الفاشلة بسبب تغييرات في البرامج أو
  واجهات API

## الخاتمة

تفتح وكلاء الذكاء الاصطناعي على سولانا آفاقاً جديدة للأتمتة والتفاعل
مع البلوكشين. وعلى الرغم من أن بعض التكاملات لم تكتمل بعد، إلا أنها
تتطور بسرعة وتوفر فرصاً كبيرة للمساهمة وتتميز بمرونة عالية في إضافة تكاملاتك الخاصة.
