## الأدوات

<Cards>
  <Card title="Kora" href="/docs/tools/kora">
    قم ببناء تدفقات المعاملات بدون رسوم غاز والمدفوعة بالرمز المميز باستخدام

  </Card>
  <Card title="Keychain" href="/docs/tools/keychain">
    استخدم واجهة توقيع موحدة عبر المفاتيح المحلية وKMS وHSM وخلفيات المحفظة.
  </Card>
  <Card title="Commerce Kit" href="/docs/tools/commerce-kit">
    أضف مكونات الدفع عبر سولانا وتدفقات التجارة إلى تطبيقك.
  </Card>
  <Card title="Solana Pay" href="/docs/tools/solana-pay">
    نفّذ تدفقات طلبات التحويل والمعاملات عبر سولانا Pay.
  </Card>
  <Card title="Attestations" href="/docs/tools/attestations">
    أنشئ بيانات الاعتماد والمخططات والتصديقات للبيانات خارج السلسلة المرتبطة
    بالحسابات على السلسلة.
  </Card>
  <Card title="Private Channels" href="/docs/tools/private-channels">
    راجع مواد منتج القنوات الخاصة وموارد التكامل.
  </Card>
  <Card title="Surfpool" href="/docs/tools/surfpool">
    بديل جاهز للاستخدام عن solana-test-validator للتطوير المحلي والاختبار ونشر
    البنية التحتية كتعليمات برمجية.
  </Card>
  <Card title="LiteSVM" href="/docs/tools/litesvm">
    اختبر برامج سولانا في آلة افتراضية سريعة داخل العملية، بدون validator،
    بلغتَي Rust وTypeScript.
  </Card>
  <Card title="الإجراءات والروابط التفاعلية" href="/docs/tools/actions">
    حوّل أي معاملة على سولانا إلى رابط قابل للمشاركة غني بالبيانات الوصفية.

  <Card title="أدوات الذكاء الاصطناعي" href="/docs/tools/ai">
