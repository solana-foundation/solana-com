  Create a token, open a token account, mint supply, and transfer tokens using
  the SPL Token CLI on devnet.
---

يستعرض هذا الدليل السريع دورة حياة الرمز المميز الكاملة باستخدام واجهة سطر الأوامر
_sh`spl-token`_. ستقوم بإنشاء mint account، وإنشاء حساب يمكنه الاحتفاظ بالرمز المميز، وسك 100 رمز مميز، ونقل بعضها إلى محفظة أخرى.

استخدم [سولانا Playground](https://beta.solpg.io/) لتشغيل الأوامر في
متصفحك، أو ثبّت واجهة سطر الأوامر محلياً باستخدام `cargo install spl-token-cli`. ستختلف
العناوين في مخرجاتك عن الأمثلة الواردة أدناه.

## 1. الاتصال بـ devnet

أنشئ محفظة أو اتصل بمحفظة موجودة في سولانا Playground، ثم اختر devnet واطلب
SOL لإيداعات الحسابات ورسوم المعاملات:

```terminal
$ solana config set --url devnet
$ solana airdrop 2
```

استخدم رموز devnet للاختبار فقط. ليس لها أي قيمة مالية.

## 2. إنشاء رمز مميز

أنشئ mint account الذي يُعرّف رمزك المميز:

```terminal
$ spl-token create-token
```

انسخ عنوان الرمز المميز من المخرجات. هذا هو عنوان mint الذي ستستخدمه في
الأوامر المتبقية. يبدأ كل mint جديد بإمداد صفري.

```terminal
$ spl-token supply <MINT_ADDRESS>
```

## 3. إنشاء token account

تحتاج محفظتك إلى token account لهذا الـ mint قبل أن تتمكن من الاحتفاظ برصيد:

```terminal
$ spl-token create-account <MINT_ADDRESS>
```

يؤدي هذا إلى إنشاء
[associated token account](/docs/tokens#associated-token-account) الخاص بك، الذي يُشتق عنوانه
من محفظتك والـ mint.

## 4. سك الرموز المميزة

اسك 100 رمز مميز في associated token account الخاص بك:

```terminal
$ spl-token mint <MINT_ADDRESS> 100
$ spl-token balance <MINT_ADDRESS>
```

يجب أن توقّع سلطة الـ mint على هذه العملية. يزيد السك من رصيد token account الخاص بك ومن إجمالي الإمداد المسجّل في الـ mint.

## 5. نقل الرموز المميزة

أرسل 10 رموز مميزة إلى محفظة devnet أخرى. يقوم الخيار _sh`--fund-recipient`_
بإنشاء associated token account الخاص بالمستلم إذا لم يكن موجوداً:

```terminal
$ spl-token transfer <MINT_ADDRESS> 10 <RECIPIENT_WALLET_ADDRESS> --fund-recipient
```

يُغيّر النقل الأرصدة في token account الخاص بالمرسل والمستلم؛ ولا
يُغيّر إجمالي إمداد الـ mint.

## اختياري: إضافة بيانات وصفية لـ Token-2022

لتخزين اسم ورمز وURI مباشرةً على mint جديد من نوع Token-2022، أنشئه
مع تمكين امتداد البيانات الوصفية:

```terminal
$ spl-token create-token \
  --program-id TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb \
  --enable-metadata
```

ثم استخدم عنوان الـ mint الجديد الذي طبعه ذلك الأمر:

```terminal
$ spl-token initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  "EXAMPLE" \
  "https://example.com/token.json"
```

يجب أن يُعيد الـ URI مستند بيانات وصفية JSON عاماً. راجع
[بيانات Token-2022 الوصفية](/docs/tokens/extensions/metadata) للاطلاع على نموذج الحساب
وأمثلة الكود.
