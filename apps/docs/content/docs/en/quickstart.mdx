Get a feel for how Solana works, no experience needed. In five short steps on
devnet, Solana's free test network, you create a wallet and send test dollars
(USDC), then create an asset, like a share or a currency, send it to someone,
and freeze their account.

## Follow along locally

<Tabs>
  <Tab title="Start with an agent">
    ```bash Terminal
    npx add-mcp https://mcp.solana.com/mcp -n solana-mcp -g -y
    ```

    Ask your agent to follow this Quickstart with you.
  </Tab>
  <Tab title="Follow along manually">
    One command installs Rust, the Solana CLI, Anchor CLI, Surfpool CLI,
    Node.js, and Yarn:

    <div className="sol-os-tabs">
      <Tabs>
        <Tab title="macOS">
          Run the installer in Terminal:

          ```bash Terminal
          curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
          ```
        </Tab>
        <Tab title="Linux">
          Run the installer in your terminal. It also installs system
          dependencies through your package manager.

          ```bash Terminal
          curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
          ```
        </Tab>
        <Tab title="Windows">
          The tools run in Linux on Windows (WSL).

          1. In Windows PowerShell, install WSL, then restart Windows if
             prompted:

             ```powershell PowerShell
             wsl --install
             ```

          2. Open the **Ubuntu** terminal and run the installer there:

             ```bash Terminal
             curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
             ```

          See [Install dependencies](/developers/docs/intro/installation/dependencies)
          for the complete WSL setup.
        </Tab>
      </Tabs>
    </div>

    You can [review the installer
    source](https://github.com/solana-developers/solana-install/blob/main/install.sh)
    before running it. Then restart your terminal so the new commands are on
    your `PATH`, and check every tool:

    ```bash Terminal
    rustc --version
    solana --version
    anchor --version
    surfpool --version
    node --version
    yarn --version
    ```

    Expected output (your version numbers may differ):

    ```txt title="Example output"
    Installed Versions:
    Rust: rustc x.y.z (...)
    Solana CLI: solana-cli x.y.z (..., client:Agave)
    Anchor CLI: anchor-cli x.y.z
    Surfpool CLI: surfpool x.y.z
    Node.js: vx.y.z
    Yarn: x.y.z
    ```

    <Warning>
      **Installer failed or a command is missing?** Install or troubleshoot
      each tool on its own with [Install dependencies](/developers/docs/intro/installation/dependencies).
    </Warning>

    [Then continue to step 1 →](/developers/docs/quickstart/check-balance)
  </Tab>
</Tabs>

## What you'll do

The code is TypeScript with [`@solana/kit`](/developers/docs/clients/official/javascript)
and its plugins. Each step is one short file you run with `npx tsx`. A **CLI** tab does the
same with the Solana CLI and `spl-token`.
