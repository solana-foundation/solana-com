## What the code does

`createAsset(issuer)` builds one transaction with these instructions, in order:

1. **Create the mint account** (`getCreateAccountInstruction`). It is funded
   for the final size including metadata, but allocated without the metadata,
   which is written after the mint is initialized.
2. **Configure the extensions** that must be set before the mint is initialized
   (`getPreInitializeInstructionsForMintExtensions`).
3. **Initialize the mint** (`getInitializeMintInstruction`) with 6 decimals. The
   issuer is both the mint authority, who can issue more LSF, and the freeze
   authority, who approves and freezes holders.
4. **Write the metadata** (`getPostInitializeInstructionsForMintExtensions`).

Each extension sets one rule:

- [`MetadataPointer` and `TokenMetadata`](/developers/docs/tokens/extensions/metadata):
  the name (Lisbon Solar Fund), symbol (LSF), a URI for offchain details, and
  an extra `isin` field, stored on the mint itself.
- [`PausableConfig`](/developers/docs/tokens/extensions/pausable): the issuer can
  pause and resume every transfer, mint, and burn.
- [`PermanentDelegate`](/developers/docs/tokens/extensions/permanent-delegate): the
  issuer can move or burn tokens in any account without the holder's signature.
- [`DefaultAccountState`](/developers/docs/tokens/extensions/default-state) set to
  `Frozen`: every new token account starts frozen, so nobody can receive LSF
  until the issuer approves them.

The `send` helper it imports from `./config` builds, signs, sends, and confirms
the transaction. You'll see it in the next step.
