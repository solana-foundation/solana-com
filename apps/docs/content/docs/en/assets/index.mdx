move them, and [markets](/developers/docs/defi) price and trade them.

## Tokenization

Solana's Token-2022 program has compliance controls built in: transfer
restrictions, pausing, confidential transfers, and permanent delegates, with no
custom contract. These pages cover regulated and real-world assets: who may
hold them, how holders are verified, how they settle, and how funds are
priced.

### Issuance tools

| Tool                                                       | What it does                                                                                                         |
| ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| [Mosaic](https://github.com/solana-foundation/mosaic)      | The Solana Foundation's open-source issuance toolkit: an SDK and templates for gated Token-2022 mints; pre-1.0       |
| [Token ACL](/developers/docs/tokenization/token-acl)       | Shared programs for delegated freeze authority and permissionless thaw against a gate, with a reference allow/block list gate |
| [Attestations](/developers/docs/tools/attestations)        | Onchain credentials bound to an address; the schema determines what is published                                     |
| [Solana Developer Platform](https://platform.solana.com)   | An API and dashboard for token issuance and payments on Solana                                                       |
