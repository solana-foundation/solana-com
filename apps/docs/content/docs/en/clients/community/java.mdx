There's a [Java SDK](https://sava.software/welcome) built by
[Sava Engineering](https://sava.engineering/) that supports most functions to
interact with Solana. If you're using Anchor for your Solana programs, you will
be able to use [anchor-src-gen](https://github.com/sava-software/anchor-src-gen)
with your idl to produce a Java compatible client.

## Installation

Sava is published to Maven Central and needs JDK 25 or later. Add `sava-core`
and `sava-rpc`, replacing `25.13.3` with the
[latest release](https://central.sonatype.com/artifact/software.sava/sava-core)
if there's a newer one. Maven and Gradle fetch its dependencies, including
`software.sava:json-iterator`, from Maven Central, so no extra repository or
access token is needed.

### Maven

```xml pom.xml
<properties>
    <maven.compiler.release>25</maven.compiler.release>
</properties>

<dependencies>
    <dependency>
        <groupId>software.sava</groupId>
        <artifactId>sava-core</artifactId>
        <version>25.13.3</version>
    </dependency>
    <dependency>
        <groupId>software.sava</groupId>
        <artifactId>sava-rpc</artifactId>
        <version>25.13.3</version>
    </dependency>
</dependencies>
```

### Gradle

```groovy build.gradle
repositories {
  mavenCentral()
}

java {
  toolchain {
    languageVersion = JavaLanguageVersion.of(25)
  }
}

dependencies {
  implementation "software.sava:sava-core:25.13.3"
  implementation "software.sava:sava-rpc:25.13.3"
}
```
