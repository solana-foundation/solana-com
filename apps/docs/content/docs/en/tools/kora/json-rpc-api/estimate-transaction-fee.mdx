---
title: estimateTransactionFee
description:
  Estimates the transaction fee in both lamports and the specified token.
---

## JSON-RPC Request

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "estimateTransactionFee",
  "params": {
    "transaction": "base64EncodedTransaction",
    "fee_token": "EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"
  }
}
```

## Parameters

| Parameter     | Type    | Required | Description |
| ------------- | ------- | -------- | ----------- |
| `transaction` | string  | Yes      | Base64-encoded transaction to price |
| `fee_token`   | string  | Yes (SDK) | Mint of the token to price the fee in. The server accepts a request without it and returns `fee_in_token: null`, but the TypeScript SDK requires it |
| `signer_key`  | string  | No       | Public key of the Kora signer to use. It must be one of the node's signers. Defaults to the signer pool's selection strategy |
| `sig_verify`  | boolean | No       | Verify signatures during Kora's simulation. Defaults to `false`. With `true`, a transaction that still needs Kora's signature fails with `Transaction did not pass signature verification` |

Pass the same `signer_key` to related calls (for example
`estimateTransactionFee` and `signTransaction`) so one signer handles the whole
flow. See
[Specifying a Signer](/developers/docs/tools/kora/operators/signers#specifying-a-signer-client-side).

## JSON-RPC Response

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "fee_in_lamports": 5000,
    "fee_in_token": 1000000,
    "payment_address": "3Z1Ef7YaxK8oUMoi6exf7wYZjZKWJJsrzJXSt1c3qrDE",
    "signer_pubkey": "3Z1Ef7YaxK8oUMoi6exf7wYZjZKWJJsrzJXSt1c3qrDE"
  }
}
```

## cURL Example

```bash
curl -X POST http://localhost:8080 \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"estimateTransactionFee","params":{"transaction":"base64EncodedTransaction","fee_token":"EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"}}'
```

## TypeScript SDK

```typescript
const fees = await client.estimateTransactionFee({
  transaction: "base64EncodedTransaction",
  fee_token: "EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v" // USDC
});
console.log("Fee in lamports:", fees.fee_in_lamports);
console.log("Fee in USDC:", fees.fee_in_token);
```
