---
title: signTransaction
description:
  Signs a transaction with the Kora fee payer if the transaction includes
  necessary payment to the fee payer without broadcasting it.
---

## JSON-RPC Request

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "signTransaction",
  "params": {
    "transaction": "base64EncodedTransaction"
  }
}
```

## JSON-RPC Response

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "signature": "base58Signature",
    "signed_transaction": "base64EncodedTransaction",
    "signer_pubkey": "3Z1Ef7YaxK8oUMoi6exf7wYZjZKWJJsrzJXSt1c3qrDE"
  }
}
```

## cURL Example

```bash
curl -X POST http://localhost:8080 \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"signTransaction","params":{"transaction":"base64EncodedTransaction"}}'
```

## TypeScript SDK

```typescript
const result = await client.signTransaction({
  transaction: "base64EncodedTransaction",
});
console.log("Signature:", result.signature);
console.log("Signed tx:", result.signed_transaction);
```

## Errors

Under the default margin pricing, the transaction must include a payment
instruction to the Kora payment address. Without it, the method returns a
`-32000` error:

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "error": {
    "code": -32000,
    "message": "Invalid transaction: Insufficient token payment. Required 11055 lamports"
  }
}
```

Use [`estimateTransactionFee`](/developers/docs/tools/kora/json-rpc-api/estimate-transaction-fee)
or `getPaymentInstruction` to compute the required payment and append it before
calling `signTransaction`.
