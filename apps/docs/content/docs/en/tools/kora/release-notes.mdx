## Kora v2.2.0-beta.8

_2026-07-29_ |
[GitHub Release](https://github.com/solana-foundation/kora/releases/tag/v2.2.0-beta.8)
| `cargo install kora-cli@2.2.0-beta.8 --locked`

Pre-release with security hardening and stricter configuration checks.

- Requires `simulate_bundle_url` in `[kora.bundle.jito]` when bundles are
  enabled
- Rejects unknown keys in `kora.toml`, and accepts `[validation.token2022]` as
  an alias for `[validation.token_2022]`
- Applies the `--api-key` and `--hmac-secret` flags of `kora rpc start`
- Enforces usage limit rules atomically across concurrent requests
- Exits with status 1 when config validation fails
- Hardens transaction validation and fee payer accounting
- Adds signer pool health monitoring with automatic failover, and retries and
  timeouts for remote signers
- Published Docker images as `ghcr.io/solana-foundation/kora:v2.2.0-beta.8` and
  `ghcr.io/solana-foundation/kora:beta`

See [Beta Documentation](/developers/docs/tools/kora/beta) for details.

## Kora TypeScript SDK v0.2.0

_2026-03-09_ |
[GitHub Release](https://github.com/solana-foundation/kora/releases/tag/ts-sdk-v0.2.0)
| `npm install @solana/kora@0.2.0`

Kit client plugin architecture for composable gasless transactions.

- Added `createKitKoraClient()` with Kit plugin composition (planner, executor,
  payer plugins)
- Enables composability with Kit program plugins like `tokenProgram()`
- Added Token-2022 support via `tokenProgramId` config option
- Added compute budget instruction support with simulation-based CU estimation
- Added missing `signature` field to `signAndSendTransaction` response
- Returns `NoopSigner` from `getPaymentInstruction` for Kit v6 signer
  deduplication
- Bumped `@solana/kit` peer dependency to `^6.1.0`

See [Kit Client Guide](/developers/docs/tools/kora/guides/kit-client).

## Kora v2.0.0

_2025-11-24_ |
[GitHub Release](https://github.com/solana-foundation/kora/releases/tag/v2.0.0)
| `cargo install kora-cli@2.0.0`

Major release with new architecture.

- Introduced a new architecture for the Kora node
- Published TypeScript SDK `@solana/kora` v0.1.0
- Migrated to Solana SDK v3.0.x and updated all dependencies
- Replaced custom Kora Signer with solana-signers crate
- Removed `sign_transaction_if_paid` and `get_all_signers` methods
- Changed response types: removed signatures from `signAndSendTransaction` and
  `signTransaction`
- Enhanced devex, security, and performance
