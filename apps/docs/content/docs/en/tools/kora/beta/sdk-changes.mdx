The `@solana/kora` 0.3.0-beta releases add bundle methods for the v2.2.0-beta
server and move to Kit 7. Install the beta SDK:

```bash
npm install @solana/kora@beta
```

This installs `@solana/kora` 0.3.0-beta.3, which requires `@solana/kit` 7 and
its matching plugins (`@solana/kit-plugin-rpc`, `@solana/kit-plugin-signer`,
and `@solana/kit-plugin-instruction-plan`). npm installs them as peer
dependencies. The stable `@solana/kora` 0.2.x stays on Kit 6.

## Kit Client Entry Point

`createKitKoraClient`, the client the
[Kit Client guide](/developers/docs/tools/kora/guides/kit-client) recommends for
0.2.x, is no longer exported from `@solana/kora`. From 0.3.0-beta.2 it lives in
the `@solana/kora/kit` entry point and is deprecated in favour of the `kora()`
Kit plugin from the same entry point. The main `@solana/kora` entry point exports
`KoraClient`, `koraPlugin`, `KoraError`, and `KoraErrorCode`.

The `kora()` plugin reads the user's signer from `identity()` in
`@solana/kit-plugin-signer` and sets Kora as the fee payer:

```typescript
import { address, createClient } from "@solana/kit";
import { identity } from "@solana/kit-plugin-signer";
import { kora } from "@solana/kora/kit";

const client = await createClient()
  .use(identity(userSigner)) // TransactionSigner that authorizes the fee payment
  .use(
    kora({
      endpoint: "http://localhost:8080", // Kora RPC endpoint
      rpcUrl: "http://127.0.0.1:8899", // Solana RPC for CU estimation
      feeToken: address("EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"), // USDC mint
    }),
  );
```

The resulting client composes with Kit program plugins such as `tokenProgram()`
the same way as the 0.2.x Kit client. Existing code can keep calling
`createKitKoraClient` by importing it from `@solana/kora/kit`.

## Bundle Methods

The SDK now supports all bundle operations:

```typescript
// Estimate bundle fees
const estimate = await client.estimateBundleFee({
  transactions: [base64Tx1, base64Tx2],
  fee_token: "EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"
});

// Sign a bundle without submitting
const { signed_transactions } = await client.signBundle({
  transactions: [base64Tx1, base64Tx2, base64Tx3],
  signer_key: koraSignerAddress
});

// Sign and submit a bundle to Jito
const { bundle_uuid } = await client.signAndSendBundle({
  transactions: [base64Tx1, base64Tx2, base64Tx3],
  signer_key: koraSignerAddress
});
```

const { version } = await client.getVersion();
