_Available on GitHub:
[`v2.2.0-beta.8`](https://github.com/solana-foundation/kora/releases/tag/v2.2.0-beta.8)_

Kora v2.2.0-beta introduces Jito bundle support, new RPC methods, Docker images,
enhanced security features, and SDK improvements.

> **This is a pre-release.** These pages describe `v2.2.0-beta.8`, the latest
> beta. Features arrived in different betas (see
> [Configuration](/developers/docs/tools/kora/beta/configuration) for the first
> beta of each option) and may change before stable release. For stable
> documentation, see the [main Kora docs](/developers/docs/tools/kora).

## Highlights

### Jito Bundle Support

Submit up to 5 transactions atomically via Jito's block engine. New RPC methods:

- [`signBundle`](/developers/docs/tools/kora/beta/bundle-methods#signbundle) — Sign a
  bundle without broadcasting
- [`signAndSendBundle`](/developers/docs/tools/kora/beta/bundle-methods#signandsendbundle)
  — Sign and submit to Jito
- [`estimateBundleFee`](/developers/docs/tools/kora/beta/bundle-methods#estimatebundlefee)
  — Estimate total bundle fees

See the [Jito Bundle Guide](/developers/docs/tools/kora/beta/jito-guide) for a full
walkthrough.

### Docker Images

Official multi-platform images (amd64/arm64) published to GitHub Container
Registry. See [Installation](/developers/docs/tools/kora/beta/installation).

### Transaction Plugins

A new plugin system allows Kora to validate transaction shapes during signing
flows. The first built-in plugin, `gas_swap`, enforces strict rules for gasless
token-for-SOL swap transactions. Plugins are configured in `kora.toml` and run
automatically during `signTransaction`, `signAndSendTransaction`, `signBundle`,
and `signAndSendBundle`.

See
[Configuration — Transaction Plugins](/developers/docs/tools/kora/beta/configuration#transaction-plugins).

### New Configuration Options

- **Transaction Plugins** for transaction shape validation (`gas_swap`)
- **reCAPTCHA v3** bot protection for signing endpoints
- **Lighthouse** fee payer drainage protection
- **Usage limit rules** that replace the stable `max_transactions` limit
  (breaking change)
- **Bundle configuration** for Jito integration

See [Configuration](/developers/docs/tools/kora/beta/configuration).

### SDK Changes

- `@solana/kora` 0.3.0-beta.3 requires `@solana/kit` 7, and the Kit client
  moved to the `@solana/kora/kit` entry point
- Bundle method support (`signBundle`, `signAndSendBundle`, `estimateBundleFee`)

See [SDK Changes](/developers/docs/tools/kora/beta/sdk-changes).

### Additional RPC Methods

- [`getVersion`](/developers/docs/tools/kora/beta/bundle-methods#getversion) — Retrieve
  server version information

## Install

```bash
cargo install kora-cli@2.2.0-beta.8 --locked
```

Or via Docker:

```bash
docker pull ghcr.io/solana-foundation/kora:v2.2.0-beta.8
```
