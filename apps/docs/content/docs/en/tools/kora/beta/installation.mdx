## Cargo

Install the beta release directly from crates.io:

```bash
cargo install kora-cli@2.2.0-beta.8 --locked
```

`--locked` builds with the dependency versions the release was published with,
including the matching `kora-lib`. Without it, Cargo can pick a newer
pre-release of `kora-lib` than the CLI version you asked for (for example,
`kora-cli@2.2.0-beta.7` resolves `kora-lib` `2.2.0-beta.8`).

## Docker

Official multi-platform Docker images (amd64/arm64) are published to GitHub
Container Registry:

```bash
# Pull the latest beta release
docker pull ghcr.io/solana-foundation/kora:beta

# Pull a specific beta version
docker pull ghcr.io/solana-foundation/kora:v2.2.0-beta.8
```

Available tags:

- `latest` — Latest stable release
- `beta` — Latest pre-release version
- `v<version>` — Specific version (e.g., `v2.2.0-beta.8`)

### Docker Compose

To include Redis for caching and usage limit support, see the
[Docker Compose file with Redis](https://github.com/solana-foundation/kora/blob/v2.2.0-beta.8/docker-compose.yml).
For a custom image, start `FROM ghcr.io/solana-foundation/kora:v2.2.0-beta.8`
and copy in your configuration files, as the
[Railway guide](/developers/docs/tools/kora/operators/deployment/railway#step-1-prepare-deployment-files)
does for the stable image. The repository's sample Dockerfile installs Kora with
`cargo install` on `rust:1.88`, which no longer builds.

### Running with Docker

```bash
docker run -d \
  -p 8080:8080 \
  -v $(pwd)/kora.toml:/app/kora.toml \
  -v $(pwd)/signers.toml:/app/signers.toml \
  -e RPC_URL=<SOLANA_RPC_URL> \
  -e KORA_PRIVATE_KEY="your-private-key" \
  ghcr.io/solana-foundation/kora:v2.2.0-beta.8 \
  kora --config /app/kora.toml rpc start --signers-config /app/signers.toml
```

The image has no entrypoint and its default command is `kora`, so the arguments
you pass must start with `kora`. The CLI reads the Solana RPC endpoint from the
`RPC_URL` environment variable. Without `-e RPC_URL=...`, Kora uses
`http://127.0.0.1:8899`, which inside the container is the container itself, so
every method that needs the RPC (for example `getBlockhash`) fails with
`-32093` `error sending request for url (http://127.0.0.1:8899/)`. Replace
`<SOLANA_RPC_URL>` with your Solana RPC endpoint.

## TypeScript SDK

The beta SDK is available on npm:

```bash
npm install @solana/kora@beta
```

See [SDK Changes](/developers/docs/tools/kora/beta/sdk-changes) for new APIs.

## Verify Installation

```bash
kora --version
```
