## ripemd160

`ripemd160` computes the Ripemd160 hash of a value.

### Inputs

| Name    | Type                    | Description                   |
| ------- | ----------------------- | ----------------------------- |
| `value` | buffer \| array[buffer] | The hex-encoded value to hash |

### Output

| Name    | Type   | Description       |
| ------- | ------ | ----------------- |
| `value` | string | The hashed result |

```hcl
output "hashed_data" {
    value = ripemd160(encode_hex("hello, world"))
}
// > hashed_data: 0xa3201f82fca034e46d10cd7b27e174976e241da2
```


## keccak256

`std::keccak256` computes the keccak256 hash of a value.

### Inputs

| Name    | Type   | Description              |
| ------- | ------ | ------------------------ |
| `value` | string | The string value to hash |

### Output

| Name    | Type   | Description       |
| ------- | ------ | ----------------- |
| `value` | string | The hashed result |

```hcl
output "hashed_data" {
    value = keccak256("hello, world")
}
// > hashed_data: 0x29bf7021020ea89dbd91ef52022b5a654b55ed418c9e7aba71ef3b43a51669f2
```
