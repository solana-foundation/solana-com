---
title: Configuration
description: Builder methods for configuring LiteSVM in TypeScript
---

LiteSVM uses a builder pattern for configuration. All methods return `LiteSVM`
for chaining.

## Typical Test Setup

```typescript
import { createClient, generateKeyPairSigner } from "@solana/kit";
import { litesvm } from "@solana/kit-plugin-litesvm";
import { signer } from "@solana/kit-plugin-signer";

const mySigner = await generateKeyPairSigner();
const client = createClient().use(signer(mySigner)).use(litesvm());

client.svm
  .withSigverify(false) // Skip signature verification (faster)
  .withBlockhashCheck(false) // Skip blockhash validation (simpler)
  .withTransactionHistory(100n); // Store last 100 transactions
```

A `litesvm()` client already has the sysvars, the builtin programs, the
precompiles, and the default programs loaded, so a typical setup only changes
the checks it needs.

## Signature & Blockhash

### withSigverify

```typescript
withSigverify(sigverify: boolean): LiteSVM
```

Enable or disable signature verification.

```typescript
// Disable for faster tests (default is enabled)
client.svm.withSigverify(false);

// Enable for production-like testing
client.svm.withSigverify(true);
```

<Info>
  Disabling signature verification makes tests faster but less realistic.
</Info>

### withBlockhashCheck

```typescript
withBlockhashCheck(check: boolean): LiteSVM
```

Enable or disable blockhash expiration checking.

```typescript
// Disable for simpler tests
client.svm.withBlockhashCheck(false);
```

## Programs & Sysvars

These methods load programs and sysvars into the VM. A `litesvm()` client
already has all of them, so you need them only to reset a client or to set up
a bare `LiteSVM.default()` instance from the `litesvm` package.

### withSysvars

```typescript
withSysvars(): LiteSVM
```

Reset Clock, Rent, EpochSchedule, and the other sysvars to their defaults.
Sysvars are already available on a new client, so you only need this to undo
changes. Calling it after `setClock` or `warpToSlot` discards your clock.

```typescript
client.svm.setClock(myClock);
client.svm.withSysvars(); // the clock is back to its default
```

### withBuiltins

```typescript
withBuiltins(): LiteSVM
```

Add the runtime's builtin programs: the System Program, the BPF loaders, Vote,
and Compute Budget.

```typescript
client.svm.withBuiltins();
```

### withPrecompiles

```typescript
withPrecompiles(): LiteSVM
```

Add the signature-verification precompiles: ed25519, secp256k1, and secp256r1.

```typescript
client.svm.withPrecompiles();
```

### withDefaultPrograms

```typescript
withDefaultPrograms(): LiteSVM
```

Add the default programs: Token, Token-2022, Associated Token Account, Memo,
Stake, and Address Lookup Table.

```typescript
client.svm.withDefaultPrograms();
```

## Resource Limits

### withLamports

```typescript
withLamports(lamports: bigint): LiteSVM
```

Set the balance of the internal faucet account that `airdrop()` draws from.
Airdrops larger than this balance fail.

```typescript
client.svm.withLamports(1_000_000_000n); // the faucet holds 1 SOL
```

### withLogBytesLimit

```typescript
withLogBytesLimit(limit?: bigint): LiteSVM
```

Set the log output byte limit.

```typescript
client.svm.withLogBytesLimit(10000n);
```

### withTransactionHistory

```typescript
withTransactionHistory(capacity: bigint): LiteSVM
```

Enable transaction history storage.

```typescript
// Store last 100 transactions
client.svm.withTransactionHistory(100n);
```

## Feature Sets

### withFeatureSet

```typescript
withFeatureSet(featureSet: FeatureSet): LiteSVM
```

Configure the feature set for testing specific Solana versions.
