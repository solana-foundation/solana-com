<Note>
Both repositories' READMEs say to run `anchor build && cargo test`. With
current Anchor and Solana CLI releases, run these steps instead:

```bash
anchor keys sync
anchor build --arch v0
# Anchor Escrow only: its tests read the IDL from idls/
cp target/idl/anchor_escrow.json idls/
cargo test
```

`anchor keys sync` sets the program ID to your local deploy keypair, which the
tests load, so the program doesn't fail with `DeclaredProgramIdMismatch`.
`--arch v0` builds an SBPF v0 program, which the LiteSVM versions these
repositories use can load. With Anchor 1.1.x, use the build commands in the
[anchor-litesvm Quick Start](/developers/docs/tools/litesvm/additional-crates/testing-with-anchor-litesvm#installation)
instead.
</Note>
