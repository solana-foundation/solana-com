**Commerce Kit is a collection of tools for building commerce experiences on
Solana.** From drop-in payment buttons to headless primitives, Commerce Kit
provides everything you need to accept crypto payments.

<Danger>
  Commerce Kit is currently in beta. APIs may change before the stable release.
</Danger>

## Why Commerce Kit?

- **Drop-in Components**: Pre-built PaymentButton with wallet connection, token
  selection, and transaction handling
- **Framework Agnostic**: Use headless primitives in any JavaScript framework
- **Solana Pay**: Full Solana Pay support with QR code generation
- **Type-Safe**: Complete TypeScript support across all packages
- **Wallet Standard**: Compatible with all Wallet Standard wallets (Phantom,
  Solflare, Backpack, etc.)

## Quick Start

The fastest way to get started is with the `PaymentButton` component:

```tsx
import { PaymentButton } from "@solana-commerce/kit";

function App() {
  return (
    <PaymentButton
      config={{
        merchant: {
          name: "My Store",
          wallet: "your-solana-wallet-address"
        },
        mode: "buyNow"
      }}
      paymentConfig={{
        products: [{ id: "1", name: "Product", price: 10, quantity: 1 }]
      }}
      onPaymentSuccess={(signature) => {
        console.log("Payment successful:", signature);
      }}
    />
  );
}
```

Replace `your-solana-wallet-address` with a valid Solana address. The `buyNow`
and `cart` modes need `paymentConfig.products`; without it the button renders an
"Invalid Pricing" error card.

<Warning>
  `onPaymentSuccess` runs in the browser, so it is not proof of payment: anything
  in the browser can be faked. Send the signature to your server and check the
  payment there before you ship an order. See
  [Confirm payments from your backend](/developers/docs/payments/checkout/backend).
</Warning>

## Installation

Choose the Commerce Kit packages you need:

```bash
# Unified Commerce Meta Package
npm install @solana-commerce/kit

# Drop-in payment button (most common)
npm install @solana-commerce/react

# Wallet connection only
npm install @solana-commerce/connector

# Headless commerce primitives
npm install @solana-commerce/headless

# Solana Pay QR codes
npm install @solana-commerce/solana-pay

# React hooks for custom UIs
npm install @solana-commerce/sdk
```
