## Prerequisites

These are the versions commit `c9e2240` pins:

- Rust 1.91.0 (`rust-toolchain.toml`)
- Solana CLI 3.1.13 (Agave, `versions.env`):
  `sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.13/install)"`
- Node.js 24 (the version the repository's Dockerfile installs)
- pnpm 10.15.1 (the repository's `packageManager` field pins it):
  `npm install -g pnpm@10.15.1`

## Clone the Repository

```bash
git clone https://github.com/solana-foundation/solana-private-channels.git
cd solana-private-channels
git checkout c9e2240
```

## Generate TypeScript Clients

The TypeScript clients are **not** published to npm. They must be generated from
the IDL using Codama.

```bash
# Escrow program client
cd private-channel-escrow-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..

# Withdraw program client
cd private-channel-withdraw-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..
```

Generated clients land in:

- `private-channel-escrow-program/clients/typescript/src/generated/`
- `private-channel-withdraw-program/clients/typescript/src/generated/`

Import from these local paths in your application; there is no
`@private-channels/client` package on npm.

## Set Up Your Project

The code samples import `@solana/kit` and `@solana-program/token` from your own
project, and the generated clients through a relative path
(`../private-channel-escrow-program/...`). Create the project in a folder at the
root of the cloned repository so those paths resolve:

```bash
mkdir app && cd app
npm init -y
npm pkg set type=module
npm install @solana/kit @solana-program/token
npm install --save-dev tsx
```

Save a sample as a `.ts` file in `app` and run it with `npx tsx <file>.ts`. The
generated clients are TypeScript with extensionless imports, so plain `node`
can't load them. `type=module` lets the samples use top-level `await`. The
generated clients sit in a CommonJS package, so Node.js can't see the names that
`generated/index.ts` re-exports: the samples import each instruction from its
own file, such as `generated/instructions/deposit`. A bundler such as Vite also
accepts the shorter `generated` path.

## Connect to Devnet

```bash
solana config set --url devnet
solana address
```

Fund that address with devnet SOL from the
[Solana Faucet](https://faucet.solana.com/) (`solana airdrop` no longer works on
devnet), then check the balance:

```bash
solana balance
```
