Blocks a previously allowed mint on the instance, preventing new deposits for
that mint. Existing deposits are unaffected.

<Info>
  The account table and notes below describe solana-private-channels commit
  `c9e2240`, the source of the program deployed to devnet. On upstream `main`
  (as of commit `acdbb4b`), `BlockMint` sets the `block_deposits` and
  `block_withdrawals` gates on the `AllowedMint` PDA and doesn't close it.
</Info>

## Accounts

| Account                          | Writable | Signer | Description                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | Fee payer                                    |
| `admin`                          |          | ✓      | Instance admin                               |
| `instance`                       |          |        | Instance PDA                                 |
| `mint`                           |          |        | SPL token mint to block                      |
| `allowed_mint`                   | ✓        |        | AllowedMint PDA (closed by this instruction) |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | Event authority PDA                          |
| `private_channel_escrow_program` |          |        | Escrow Program                               |

This instruction takes no parameters.

## Important Notes

- Closes the `allowed_mint` PDA: new `Deposit` calls for this mint will fail
  with `InvalidAllowedMint`
- Existing channel balances for this mint are unaffected, but `ReleaseFunds`
  also reads the `allowed_mint` PDA, so withdrawals of this mint can't settle
  until `AllowMint` recreates it
- Emits an event via `EmitEvent` CPI
