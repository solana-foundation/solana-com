Solana's token standard carries controls used in regulated issuance - transfer
restrictions, pausability, confidential transfers, and permanent delegates - as
extensions enforced by the Token-2022 program. For confirmation times and fees,
see [settlement and finality](/docs/tokenization/settlement/finality) and
[production readiness](/docs/tools/production-readiness).

Mint accounts, token accounts, and every extension are documented in
[Assets](/docs/tokens). If you are new to Solana's account model, start with
[Core Concepts](/docs/core).

## The sequence

Whatever the asset, an issuance moves through the same decisions in roughly this
order.

1. **[Design the token](/docs/tokenization/design)** - whether the mint is your
   register of record or an off-chain register governs, which token program to
   issue on, which controls the asset needs, and who holds each authority. The
   extension set is fixed at creation.
2. **[Choose where it runs](/docs/tokenization/design/deployment-options)** -
   transparent mainnet, Confidential Balances, Solana Privacy Rings, or Private
   Channels, and what each changes for composability.
3. **[Evidence compliance](/docs/tokenization/compliance)** - a KYC or sanctions
   check recorded without personal data onchain, and which issuer controls still
   work with Confidential Balances.
4. **[Gate the holders](/docs/tokenization/compliance/token-acl)** - enforcing
   allowlists and blocklists with Token ACL.
5. **[Integrate custody](/docs/tokenization/custody)** - how the asset meets a
   custodian and a transfer agent, and what a vault needs from the token before
   it can hold it.
6. **[Choose the cash leg](/docs/tokenization/settlement/cash-leg)** - which
   cash instrument settles against the asset, and how that choice and the
   controls on the mint constrain each other.
7. **[Settle it](/docs/tokenization/settlement)** - exchanging the asset against
   payment in a single transaction, with the
   [DvP program](/docs/tokenization/settlement/dvp-program) or without one, and
   [which commitment level](/docs/tokenization/settlement/finality) a system of
   record should record.
8. **[Operate it](/docs/tokenization/tutorials)** - build a gated, operable
   mint, then take the custodian and vault sides of it.
