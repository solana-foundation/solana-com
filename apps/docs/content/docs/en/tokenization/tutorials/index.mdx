These tutorials build one token and then look at it from three sides. Start with
the issuing chain, which produces a gated Token-2022 mint on devnet. Work
through the three issuing tutorials in order. The custodian and vault tutorials
build on them, so run those after the issuing chain. Everything here is devnet.

## Before you start

The setup - Solana CLI, Node.js 24 or later, a funded devnet keypair, and the
Mosaic CLI - is in
[the issuing tutorials](/docs/tokenization/tutorials/issuing#before-you-start),
and the whole section assumes you have run it.

The custodian and vault tutorials add `spl-token`. The Anza release install from
the issuing tutorials includes it; if it is missing, run
`cargo install spl-token-cli`.

Both continue from
[gate the holders](/docs/tokenization/tutorials/issuing/gate-the-holders) and
expect `$MINT` exported with a working allowlist.
