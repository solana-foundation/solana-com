These tutorials build one token and then look at it from three sides. Start
with issuing, which produces a Token-2022 mint whose accounts start frozen and
whose holders are gated by an onchain allowlist. The custodian and vault
tutorials continue with that mint, so run them after the issuing tutorial.

Each step shows the same operation in four implementations (an optional
recovery step is shown for the Mosaic SDK only), so pick one and follow it
throughout:

- **Mosaic SDK**: [Mosaic](https://github.com/solana-foundation/mosaic) is the
  Solana Foundation's open-source issuance toolkit. Its SDK builds each
  transaction from a template.
- **Kit**: the same instructions built with
  [`@solana/kit`](/developers/docs/frontend/client), the Token-2022 client, and
  the Token ACL program clients.
- **Web3.js v3**: the Kit instructions sent with `@solana/web3.js` v3's
  `Connection` and `Transaction`.
- **Rust**: one binary per step, with the Token ACL instructions built by hand.
