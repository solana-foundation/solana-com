<Callout type="info" title="Summary">

These tutorials build one token and then look at it from three sides. Start with
the issuing chain, which produces a gated Token-2022 mint on devnet. The
custodian and vault tutorials continue from it, so run them after, not instead.
Everything here is devnet.

</Callout>

## One token, three roles

**[Issuing a token](/docs/tokenization/tutorials/issuing)** is a chain of three
tutorials that build the mint: create it with the controls a tokenized security
needs, gate who may hold it with an onchain allowlist, then exercise the powers
an issuer runs day to day. Work through them in order - each one depends on the
state the previous one left behind.

**[Enabling settlement as a custodian](/docs/tokenization/tutorials/custodian)**
takes the other side. You are being onboarded to hold that asset for a client,
and the tutorial covers what your systems should do and what they will see when
the issuer exercises a control you do not control.

**[Deploying a vault](/docs/tokenization/tutorials/vault)** takes the
asset-manager side: proving the gate applies to a vault, getting every account
it touches onto the allowlist, and confirming what a pause does to it.

## Before you start

The setup - Solana CLI, a funded devnet keypair, and the Mosaic CLI - is in
[the issuing tutorials](/docs/tokenization/tutorials/issuing#before-you-start),
and the whole section assumes you have run it.

The custodian and vault tutorials add `spl-token`, which ships separately from
the Solana CLI.

Both continue from
[gate the holders](/docs/tokenization/tutorials/issuing/gate-the-holders) and
expect `$MINT` exported with a working allowlist, so they are not standalone
entry points.

<Callout type="warn">

These use [Mosaic](https://github.com/solana-foundation/mosaic), which is
pre-1.0. Check the repository for the current command surface before adapting
anything here beyond devnet, and pin a version in any pipeline that depends on
it.

</Callout>

## The other implementation path

The [Solana Developer Platform](https://platform.solana.com) offers one
integrated API and dashboard across issuance, custody, payments, and compliance,
with policies and audit trails built in. Use it when you want a single surface
over all of those concerns.

These tutorials take the direct path instead: they build against Token-2022 and
Token ACL so you can see, inspect, and customize each operation, and hold your
own keys and upgrade cadence. The two are complementary - neither is a stepping
stone to the other. Check the platform's own documentation for current network
availability.
