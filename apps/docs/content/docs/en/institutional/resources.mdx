## Issuance tooling

| Tool                                                                                          | What it is                                                                                                                                             | When to use it                                                                                                                  |
| --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| [Mosaic](https://github.com/solana-foundation/mosaic)                                         | The Solana Foundation's open-source issuance toolkit. CLI, SDK, and dashboard, with templates for stablecoins, tokenized securities, and arcade tokens | Issuing a token with a control surface. This is the path the [issuance tutorials](/docs/institutional/tutorials/issuing) follow |
| [Token ACL](/docs/tokenization/token-acl)                                                     | Shared programs for delegated freeze authority and permissionless thaw against a pluggable gate                                                        | Gating who may hold your token without a per-transfer hook                                                                      |
| [Attestations](/docs/tools/attestations)                                                      | Onchain credentials bound to an address, without publishing the underlying data                                                                        | Binding an onboarding decision to a wallet                                                                                      |
| [Solana Kit](https://www.solanakit.com/)                                                      | The current TypeScript client library                                                                                                                  | Building against the programs directly rather than through a toolkit                                                            |
| [Solana Enterprise Training](https://github.com/solana-foundation/solana-enterprise-training) | Open-source enterprise curriculum from the Foundation                                                                                                  | Bringing an engineering or operations team up to speed                                                                          |

Mosaic is pre-1.0. Pin a version in any pipeline that depends on it, and check
the repository for the current command surface before adapting the tutorials.

### Moving fast versus building to operate

To explore quickly before committing engineering effort, the
[Solana developer platform](https://launch.solana.com) provides hosted,
templated infrastructure and is the quickest of these paths to a working
prototype.

It suits evaluation work and teams whose main constraint is time. These pages
assume a different setting: an institution running its own infrastructure,
holding its own keys, and accountable for the availability of its own settlement
path. In that setting the toolkit and library paths above are usually the better
fit, since they avoid a hosted dependency inside a production settlement flow.

## Live network data

Network figures change. Take current values from these sources rather than from
documentation, press coverage, or vendor material, which can be out of date.

| Source                                                                                     | What it gives you                                             |
| ------------------------------------------------------------------------------------------ | ------------------------------------------------------------- |
| [status.solana.com](https://status.solana.com)                                             | Current cluster status and incident history                   |
| [Solana news](https://solana.com/news)                                                     | Post-mortems for network incidents, written first-party       |
| [validators.app](https://www.validators.app)                                               | Validator set, stake distribution, and concentration measures |
| [solana.com/200ms](https://solana.com/200ms)                                               | Live slot times and the staged slot-time reduction rollout    |
| [solana.com/data](https://solana.com/data)                                                 | Network activity, transaction counts, and fees                |
| [Solana Explorer](https://explorer.solana.com)                                             | Individual transactions, accounts, and mints                  |
| [Solana upgrades](/upgrades)                                                               | Protocol changes in progress                                  |
| [Improvement documents](https://github.com/solana-foundation/solana-improvement-documents) | Proposed and accepted protocol changes                        |

<Callout type="warn">

For the activation state of a protocol change, the authoritative source is the
feature gate account on the cluster itself. Published status fields can lag the
chain by days. Where a change matters to your systems - as staged slot time
reductions do - verify against the gate rather than against a status page.

</Callout>

## Infrastructure

For RPC access, see [solana.com/rpc](https://solana.com/rpc) for the current set
of providers. This documentation does not recommend individual providers.

If you are running your own nodes, [exchange integration](/docs/defi/exchange)
covers node setup, offline account management, and withdrawal validation. It is
written for exchanges and is the closest equivalent in these docs to a custodian
operations guide - see
[custody integration](/docs/institutional/custody-and-vaults/custody-integration).

For signing and key custody backends, see
[signing in production](/docs/core/transactions/signing-in-production) and
[Keychain](/docs/tools/keychain).

## Training and support

[Solana Enterprise Training](https://github.com/solana-foundation/solana-enterprise-training)
is the Foundation's open-source curriculum for engineering and operations teams
at enterprises and regulated institutions. It covers this material in more
depth, and is a good next step after the
[issuance tutorials](/docs/institutional/tutorials/issuing).

For technical questions,
[Solana Stack Exchange](https://solana.stackexchange.com/) is the searchable
archive. For questions specific to a regulated issuance, such as control design,
authority layout, or documenting a settlement property for a supervisor, contact
Solana Foundation directly.
