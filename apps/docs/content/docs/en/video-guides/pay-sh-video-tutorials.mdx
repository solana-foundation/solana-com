## What You'll Learn

This 12-part series takes you from installing Pay.sh to running your own paid
API gateway:

- **Get set up fast** — install the CLI and wrap the tools you already use.
- **Pay for services** — discover paid APIs and call them, including Claude and
  text-to-speech, straight from the command line.
- **Run your own gateway** — set up a paid gateway and price endpoints per call,
  by token, or in tiers.
- **Go to production** — handle subscriptions, split payments, and accounts,
  then deploy and publish to the public catalog.

Follow the chapters in order — each one builds on the last. Pair the series with
the [written Pay.sh guide](/docs/payments/pay-sh) for the full command
reference.
