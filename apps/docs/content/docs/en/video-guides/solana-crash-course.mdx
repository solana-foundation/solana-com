## What You'll Learn

This 11-part series takes you from zero to shipping real Solana programs:

- **Get set up fast** — install your environment and deploy a working app in
  five minutes.
- **Understand the mental model** — how transactions, the account model, and
  PDAs actually work.
- **Build real programs** — a voting program, on-chain data storage, and a token
  escrow.
- **Work with tokens** — a stablecoin built with token extensions, and a stable
  swap AMM powered by oracles.

Follow the chapters in order — each one builds on the last. By the end, you'll
have written, tested, and deployed several real Anchor programs, and understand
the primitives that power most production Solana apps.
