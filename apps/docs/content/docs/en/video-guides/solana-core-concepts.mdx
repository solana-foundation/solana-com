## What You'll Learn

This 3-part whiteboard series explains the ideas behind how Solana works, with
no code required:

- **Follow a transaction** — what happens from signature to validator execution.
- **See how apps fit together** — how frontends, RPCs, and onchain programs form
  one call stack.
- **Understand PDAs** — what program derived addresses are, why programs need
  them, and how they're derived.

Follow the chapters in order — each one builds on the last. Watch the
[full playlist on YouTube](https://youtube.com/playlist?list=PLODGyuKNdFks) and
pair it with the written [Core Concepts](/docs/core) docs.
