Solana transactions are public by default — anyone can see account balances and
transfer amounts on an explorer. Confidential Balances is a Token-2022 extension
that changes that for token transfers: the transfer amount and resulting balance
stay encrypted, while the token account addresses involved remain public. This
video walks through how it works and why it matters for use cases like payroll,
trading, and everyday payments where amounts shouldn't be public.
