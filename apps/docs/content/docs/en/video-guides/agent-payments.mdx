## What You'll Learn

This 4-part series covers both sides of the machine economy — charging for an
API and paying for one as an agent:

- **Monetize an API** — charge per request using HTTP 402 payments.
- **Pay as an agent** — how AI agents pay for things with Pay.sh and its
  integrations.
- **Understand the problem** — why credit cards don't work for agents and what
  does.
- **Learn x402 on Solana** — how the x402 protocol lets agents pay directly
  onchain.

Follow the chapters in order — each one builds on the last. Watch the
[full playlist on YouTube](https://youtube.com/playlist?list=PLKP2QWkPitAE) and
pair it with the
[written Agentic Payments guide](/docs/payments/agentic-payments) for the full
details.
