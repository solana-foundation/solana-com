## What Is DePIN?

DePIN (Decentralized Physical Infrastructure Networks) uses onchain incentives
to coordinate real-world hardware — wireless hotspots, sensors, GPUs, mapping
cameras — instead of a single company owning and operating it all. Anyone can
run a device, contribute it to the network, and earn onchain rewards for the
data or resources it provides.

Solana's low fees and fast finality make it a natural settlement layer for
DePIN: networks can pay out micro-rewards per device or per interaction without
the transaction cost eating into the reward. The builds below are small,
self-contained projects that connect a physical device to a Solana program using
the same primitives — accounts, PDAs, and token transfers — production DePIN
networks rely on.
