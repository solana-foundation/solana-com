Tokens are digital assets that represent ownership of anything from dollars to
fund shares. On Solana they're called SPL (Solana Program Library) tokens.

This page covers how tokens are represented. For code, see
[Token basics](/developers/docs/tokens/basics).

## Key Points

- **Token programs** hold all the instruction logic for tokens, fungible and
  non-fungible.
- A **mint account** represents one token and stores its supply, decimals, and
  authorities.
- A **token account** holds one owner's balance of one mint.
- An **associated token account** is a token account at an address derived from
  the owner and the mint.

## Token Programs

Solana has two token programs:

Every mint and token account is a
[data account](/developers/docs/core/accounts/account-types#data-accounts) owned by a
token program.


### Mint Account

A token is identified by the address of its
[mint account](https://github.com/solana-program/token/blob/6d18ff73b1dd30703a30b1ca941cb0f1d18c2b2a/program/src/state.rs#L16-L30),
which stores:

- **Supply**: Total supply of the token
- **Decimals**: Decimal precision of the token
- **Mint authority**: The account authorized to create new units of the token,
  increasing the supply
- **Freeze authority**: The account authorized to freeze tokens in a Token
  Account, preventing them from being transferred or burned

The mint authority is set when the mint is initialized, and doesn't have to be
the account that created or paid for the mint.

The full details stored on each Mint Account include the following:

```rust title="Mint Account State"
pub struct Mint {
    /// Optional authority used to mint new tokens. The mint authority may only
    /// be provided during mint creation. If no mint authority is present
    /// then the mint has a fixed supply and no further tokens may be
    /// minted.
    pub mint_authority: COption<Pubkey>,
    /// Total supply of tokens.
    pub supply: u64,
    /// Number of base 10 digits to the right of the decimal place.
    pub decimals: u8,
    /// Is `true` if this structure has been initialized
    pub is_initialized: bool,
    /// Optional authority to freeze token accounts.
    pub freeze_authority: COption<Pubkey>,
}
```

For example, see the
[USDC mint account](https://explorer.solana.com/address/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)
in Solana Explorer.

### Token Account

A [token account](https://github.com/solana-program/token/blob/6d18ff73b1dd30703a30b1ca941cb0f1d18c2b2a/program/src/state.rs#L87-L108)
tracks one owner's balance of one token. It stores:

- **Mint**: The token the Token Account holds units of
- **Owner**: The account authorized to transfer tokens from the Token Account
- **Amount**: Number of the tokens the Token Account currently holds

The full details stored on each Token Account include the following:

```rust title="Token Account State"
pub struct Account {
    /// The mint associated with this account
    pub mint: Pubkey,
    /// The owner of this account.
    pub owner: Pubkey,
    /// The amount of tokens this account holds.
    pub amount: u64,
    /// If `delegate` is `Some` then `delegated_amount` represents
    /// the amount authorized by the delegate
    pub delegate: COption<Pubkey>,
    /// The account's state
    pub state: AccountState,
    /// If is_native.is_some, this is a native token, and the value logs the
    /// rent-exempt reserve. An Account is required to be rent-exempt, so
    /// the value is used by the Processor to ensure that wrapped SOL
    /// accounts do not drop below this threshold.
    pub is_native: COption<u64>,
    /// The amount delegated
    pub delegated_amount: u64,
    /// Optional authority to close the account.
    pub close_authority: COption<Pubkey>,
}
```

A wallet needs a token account, with itself as owner, for each mint it holds. A
wallet can own several token accounts for the same mint, but each token account
has one owner and one mint.

<Info>

A token account's `owner` field names who controls the balance. That's
different from the account's program owner, which is always the token
program.

</Info>

### Associated Token Account

An associated token account (ATA) is the "default" token account for an owner
and a mint. It's an ordinary token account at an address derived from the
owner's address and the mint's address, so anyone can find it.

Creating an ATA requires a refundable minimum balance for its account storage.
The instruction's payer funds that balance even when another wallet owns the
ATA. See
[ATA cost and payer](/developers/docs/tokens/basics/create-token-account#cost-and-payer)
for current costs and Token-2022 sizing differences.

The ATA address is a [program-derived address (PDA)](/developers/docs/core/pda):
derived deterministically from fixed inputs.
