---
title: "Quickstart: create a token with the CLI"
description:
  Create a token, open a token account, mint supply, and transfer tokens using
  the SPL Token CLI on devnet.
---

This quickstart walks through the complete token lifecycle with the
`spl-token` CLI. You will create a mint, create an account that can hold the
token, mint 100 tokens, and transfer some to another wallet.

Use [Solana Playground](https://beta.solpg.io/) to run the commands in your
browser, or run them locally. The `spl-token` CLI ships with the
[Solana CLI](/developers/docs/intro/installation/dependencies#install-solana-cli),
so a local Solana CLI install already includes it. To install `spl-token` on
its own, run `cargo install spl-token-cli --locked`. The addresses in your
output will differ from the examples below.

## 1. Connect to devnet

Point the CLI at devnet:

```bash Terminal
solana config set --url devnet
```

In Playground, connect the Playground wallet when the terminal asks. Locally,
create a keypair if you don't have one. The CLI uses
`~/.config/solana/id.json` as your wallet: it pays the fees and signs every
command on this page.

```bash Terminal
solana-keygen new
```

Next, get devnet SOL for account deposits and transaction fees. The devnet RPC
faucet is closed, so `solana airdrop` fails on devnet. Instead, print your
wallet address:

```bash Terminal
solana address
```

Paste the address into the [Solana Faucet](https://faucet.solana.com), request
devnet SOL, then check your balance with `solana balance`. For other faucets,
see [Airdrops and faucets](/developers/cookbook/development/airdrops-and-faucets).

To skip the faucet, run the quickstart against a local validator instead: start
`solana-test-validator` in a second terminal, run
`solana config set --url localhost`, and fund your wallet with
`solana airdrop 2`, which still works there.

Use devnet tokens only for testing. They have no financial value.

## 2. Create a token

Create the mint account that identifies your token:

```bash Terminal
spl-token create-token
```

Copy the token address from the output. This is the mint address you will use in
the remaining commands. A new mint starts with a supply of zero.

```bash Terminal
spl-token supply <MINT_ADDRESS>
```

## 3. Create a token account

Your wallet needs a token account for this mint before it can hold a balance:

```bash Terminal
spl-token create-account <MINT_ADDRESS>
```

This creates your
[associated token account](/developers/docs/tokens#associated-token-account), whose address
is derived from your wallet and the mint.

## 4. Mint tokens

Mint 100 tokens into your associated token account:

```bash Terminal
spl-token mint <MINT_ADDRESS> 100
spl-token balance <MINT_ADDRESS>
```

The mint authority must sign this operation. Minting increases both your token
account balance and the total supply recorded by the mint.

## 5. Transfer tokens

Send 10 tokens to another devnet wallet. The `--fund-recipient` option
creates the recipient's associated token account if it does not exist. If the
recipient wallet holds no SOL, also pass `--allow-unfunded-recipient`, or the
CLI refuses to send:

```bash Terminal
spl-token transfer <MINT_ADDRESS> 10 <RECIPIENT_WALLET_ADDRESS> --fund-recipient --allow-unfunded-recipient
```

The transfer changes the balances in the sender and recipient token accounts; it
does not change the mint's total supply.

## Optional: add Token-2022 metadata

To store a name, symbol, and URI directly on a new Token-2022 mint, create it
with the metadata extension enabled. Run this section with the local
`spl-token` CLI: the version in Solana Playground doesn't support
`--enable-metadata` or `initialize-metadata`.

```bash Terminal
spl-token create-token \
  --program-id TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb \
  --enable-metadata
```

Then use the new mint address printed by that command:

```bash Terminal
spl-token initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  "EXAMPLE" \
  "https://example.com/token.json"
```

The URI should return a public JSON metadata document. See
[Token-2022 metadata](/developers/docs/tokens/extensions/metadata) for the account model
and code examples.
