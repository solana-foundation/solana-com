[Production readiness](/docs/finance/production-readiness) carries the full
mainnet checklist: RPC, transaction landing, priority fees, compute budgeting,
confirmation levels, key custody, monitoring, and program deployment. This page
covers what is specific to payment flows.

## Paying fees on the user's behalf

Users expect to pay in stablecoins, not to acquire SOL for network fees. See
[fee abstraction](/docs/payments/send-payments/payment-processing/fee-abstraction)
for the implementation, and
[gasless transactions](/docs/finance/production-readiness#gasless-transactions)
for where it sits in the wider checklist.

`INSUFFICIENT_FUNDS_FOR_FEE` is the error this prevents. Treat it as
non-retryable without either funding the fee payer or routing the transaction
through a relayer.

## Verifying a payer or payee address

Transfers are irreversible, and a recipient address can be a wallet, a token
account, a mint, or a program - each needing different handling. See
[verify address](/docs/payments/send-payments/verify-address) for the decision
tree and reference code, and
[verify addresses](/docs/finance/production-readiness#verify-addresses) for the
mint and program address tables.

## Watching payments land
