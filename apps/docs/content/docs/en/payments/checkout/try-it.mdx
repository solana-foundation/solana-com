## What just happened

Step 1 is the customer's side. The order and the approval became a
transaction:

- **`amount: 1000000n`.** USDC has 6 decimals, so 1 USDC is 1,000,000 base
  units. Code always works in base units.
- **`storeOwner`.** The shop's wallet. The USDC goes to the shop's USDC account
  for that wallet.
- **`reference`.** A fresh address created for this order and attached to the
  transfer. The shop uses it to tell which order a payment is for.
- **`signature`.** The transaction's ID, which `payStore` returns once the
  network has confirmed the transfer. The checkout hands it to the shop's
  server.

The network fee for this transfer was 5,000 lamports (0.000005 SOL), paid by
the customer's wallet. [Go live](/developers/docs/payments/checkout/go-live) shows how
your app can pay it instead.

The money has moved, but the order isn't paid until the shop checks. Step 2 is
the shop's side: its server looks the transaction up by its signature and
returns `{ paid: true }` only if it succeeded, carries the order's reference,
and moved exactly 1 USDC of the USDC mint into the shop's account. The shop
goes by the network's record, not the customer's word.
