---
title: "Quickstart: Get an agent to pay for an API request"
description:
  Launch an agent with Pay and make one wallet-approved sandbox API request
  without moving real funds.
---

Use [Pay](https://pay.sh) to give Codex or Claude a payment-aware HTTP client.
The agent can discover a `402 Payment Required` challenge and retry the request
with payment proof, while the wallet keeps signing and approval outside the
agent process.

This walkthrough follows the official
[Pay agent quickstart](https://pay.sh/docs/get-started/agent-quickstart) and
uses an ephemeral sandbox wallet. You need a terminal, Pay, and either Codex or
Claude Code installed.

## 1. Install Pay

On macOS, install the prebuilt binary:

```bash
brew install pay
pay --version
```

On other platforms, install the npm package:

```bash
npm install --global @solana/pay
pay --version
```

You do not need to run `pay setup` or fund an account for this example. Sandbox
mode creates and funds a temporary local account automatically.

## 2. Launch the agent with Pay

Start your installed agent in sandbox mode:

```bash
pay --sandbox codex
```

Or use Claude Code:

```bash
pay --sandbox claude
```

Pay attaches its local MCP tools and payment-safety instructions to the agent
session. The agent does not receive a private key.

## 3. Ask the agent to make one request

Paste this prompt into the agent:

```text
Use Pay to make exactly one sandbox API request to
https://debugger.pay.sh/mpp/quote/AAPL.

Before paying, show me the amount and ask for approval. Then return the stock
quote and payment receipt. Do not make any other paid requests.
```

The request follows one complete payment loop:

1. The API returns `402 Payment Required` with an MPP challenge.
2. Pay validates the challenge and displays the payment terms for approval.
3. The sandbox wallet signs, and Pay retries the same request with an
   `Authorization: Payment` credential.
4. The API returns the quote and a `Payment-Receipt` header.

No real funds move. Rejecting the approval stops the request.

<Callout type="info">
  The debugger endpoint and command flow are maintained by pay.sh. See the [Pay
  client quickstart](https://pay.sh/docs/get-started/client-quickstart) for the
  equivalent one-line `pay --sandbox curl` request.
</Callout>

## Before using real funds

- Set a maximum amount for one request and a cumulative budget for the agent.
- Allowlist the services, networks, assets, and recipients the agent may use.
- Keep signing behind a constrained wallet interface; never put a private key in
  the prompt, tool output, or agent environment.
- Require approval for unexpected prices, new providers, and multi-call plans.
- Retain the payment receipt with the API result for reconciliation.
