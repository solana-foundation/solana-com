The
[Solana Program Examples](https://github.com/solana-foundation/program-examples)
repository on GitHub offers several subfolders, each containing code examples to
help developers learn and experiment with Solana blockchain development.

You can find the examples in the `solana-foundation/program-examples` together
with README files that explain you how to run the different examples. Most
examples are self-contained and available in one or more of
[Anchor](https://www.anchor-lang.com/docs/installation),
[Pinocchio](https://github.com/anza-xyz/pinocchio), and native Rust. A few of
the basics are also written in sBPF assembly (ASM).

Within the repo you will find the following subfolder, each with assorted
example programs within them:

- [Basics](#basics)
- [Tokens](#tokens)
- [Token Extensions (Token 2022)](#token-extensions-token-2022)
- [Compression](#compression)
- [Cryptography](#cryptography)
- [Oracles](#oracles)
- [Games](#games)

There are also [ecosystem program examples](#ecosystem-solana-program-examples)

## Basics

Contains a series of examples that demonstrate the foundational steps for
building Solana programs. These examples are designed to help developers
understand the core concepts of Solana programming.

| Example Name                                                                                                                  | Description                                                                                                             | Language                       |
| ----------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------ |
| [Account Data](https://github.com/solana-foundation/program-examples/tree/main/basics/account-data)                           | Saving an address with name, house number, street and city in an account.                                               | Native, Anchor, Pinocchio      |
| [Checking Accounts](https://github.com/solana-foundation/program-examples/tree/main/basics/checking-accounts)                 | Security lessons that shows how to do account checks                                                                    | Native, Anchor, Pinocchio, ASM |
| [Close Account](https://github.com/solana-foundation/program-examples/tree/main/basics/close-account)                         | Show you how to close accounts to get its rent back.                                                                    | Native, Anchor, Pinocchio      |
| [Counter](https://github.com/solana-foundation/program-examples/tree/main/basics/counter)                                     | A simple counter program in all the different architectures.                                                            | Native, Anchor, Pinocchio      |
| [Create Account](https://github.com/solana-foundation/program-examples/tree/main/basics/create-account)                       | How to create a system account within a program.                                                                        | Native, Anchor, Pinocchio, ASM |
| [Cross Program Invocation](https://github.com/solana-foundation/program-examples/tree/main/basics/cross-program-invocation)   | Using a hand and lever analogy this shows you how to call another program from within a program.                        | Native, Anchor, Pinocchio      |
| [Favorites](https://github.com/solana-foundation/program-examples/tree/main/basics/favorites)                                 | Save and update per-user state, ensuring users can only update their own information.                                   | Native, Anchor, Pinocchio      |
| [hello solana](https://github.com/solana-foundation/program-examples/tree/main/basics/hello-solana)                           | Hello world example which just prints hello world in the transaction logs.                                              | Native, Anchor, Pinocchio, ASM |
| [Pda Rent payer](https://github.com/solana-foundation/program-examples/tree/main/basics/pda-rent-payer)                       | Shows you how you can use the lamports from a PDA to pay for a new account.                                             | Native, Anchor, Pinocchio      |
| [Processing Instructions](https://github.com/solana-foundation/program-examples/tree/main/basics/processing-instructions)     | Shows you how to handle instruction data string and u32.                                                                | Native, Anchor, Pinocchio      |
| [Program Derived Addresses](https://github.com/solana-foundation/program-examples/tree/main/basics/program-derived-addresses) | Shows how to use seeds to refer to a PDA and save data in it.                                                           | Native, Anchor, Pinocchio      |
| [Realloc](https://github.com/solana-foundation/program-examples/tree/main/basics/realloc)                                     | Shows how to resize an existing account within the [runtime limits](/docs/core/accounts/modification-rules#data-rules). | Native, Anchor, Pinocchio      |
| [Repository Layout](https://github.com/solana-foundation/program-examples/tree/main/basics/repository-layout)                 | Recommendations on how to structure your program layout.                                                                | Native, Anchor, Pinocchio      |
| [Transfer SOL](https://github.com/solana-foundation/program-examples/tree/main/basics/transfer-sol)                           | Different methods of transferring SOL for system accounts and PDAs.                                                     | Native, Anchor, Pinocchio, ASM |

## Tokens

Most tokens on Solana use the Solana Program Library (SPL) token standard. Here
you can find many examples on how to mint, transfer, burn tokens and even how to
interact with them in programs.

| Example Name                                                                                                                            | Description                                                                                                              | Language                  |
| --------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------- |
| [Create Token](https://github.com/solana-foundation/program-examples/tree/main/tokens/create-token)                                     | How to create a token and add metaplex metadata to it.                                                                   | Anchor, Native, Pinocchio |
| [NFT Operations](https://github.com/solana-foundation/program-examples/tree/main/tokens/nft-operations)                                 | Create an NFT collection, mint NFTs, and verify NFTs as part of a collection using Metaplex Token Metadata.              | Anchor, Pinocchio         |
| [PDA Mint Authority](https://github.com/solana-foundation/program-examples/tree/main/tokens/pda-mint-authority)                         | Shows you how to change the mint authority of a mint, to mint tokens from within a program.                              | Anchor, Native, Pinocchio |
| [Transfer Tokens](https://github.com/solana-foundation/program-examples/tree/main/tokens/transfer-tokens)                               | Shows how to transfer SPL token using CPIs into the token program.                                                       | Anchor, Native, Pinocchio |
| [Escrow](https://github.com/solana-foundation/program-examples/tree/main/tokens/escrow)                                                 | Lets two users swap tokens with each other through an escrow program.                                                    | Anchor, Native, Pinocchio |
| [Token Fundraiser](https://github.com/solana-foundation/program-examples/tree/main/tokens/token-fundraiser)                             | Create a fundraiser with a target mint and amount, and let contributors deposit tokens until the goal is reached.        | Anchor                    |
| [Merkle Tree Token Claimer](https://github.com/solana-foundation/program-examples/tree/main/tokens/merkle-tree-token-claimer)           | Fund a vault once, publish a Merkle root of a balance snapshot, and let each holder claim their allocation with a proof. | Anchor                    |
| [Token Swap](https://github.com/solana-foundation/program-examples/tree/main/tokens/token-swap)                                         | Extensive example that shows you how to build an AMM (automated market maker) pool for SPL tokens.                       | Anchor                    |
| [External Delegate Token Master](https://github.com/solana-foundation/program-examples/tree/main/tokens/external-delegate-token-master) | Control token transfers using an external secp256k1 delegate signature.                                                  | Anchor                    |
| [Token-2022](https://github.com/solana-foundation/program-examples/tree/main/tokens/token-2022)                                         | See Token 2022 (Token extensions).                                                                                       | Anchor, Native, Pinocchio |

## Token Extensions (Token 2022)

Token 2022 is a new standard for tokens on Solana. It is a more flexible and
lets you add 16 different extensions to a token mint to add more functionality
to it. A full list of the extensions can be found in the
[Getting Started Guide](/docs/tokens/extensions)

| Example Name                                                                                                                     | Description                                                                                                          | Language                  |
| -------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------- |
| [Basics](https://github.com/solana-foundation/program-examples/tree/main/tokens/token-2022/basics)                               | How to create a token, mint and transfer it.                                                                         | Anchor                    |
| [CPI Guard](https://github.com/solana-foundation/program-examples/tree/main/tokens/token-2022/cpi-guard)                         | Prevents certain token actions from happening inside a CPI.                                                          | Anchor                    |
| [Default account state](https://github.com/solana-foundation/program-examples/tree/main/tokens/token-2022/default-account-state) | This extension lets you create token accounts with a certain state, for example frozen.                              | Anchor, Native, Pinocchio |
| [Group](https://github.com/solana-foundation/program-examples/tree/main/tokens/token-2022/group)                                 | Create tokens that belong to larger groups of tokens using the Group Pointer extension.                              | Anchor                    |
| [Immutable Owner](https://github.com/solana-foundation/program-examples/tree/main/tokens/token-2022/immutable-owner)             | Create token accounts whose owner cannot be changed.                                                                 | Anchor, Pinocchio         |
| [Interest Bearing](https://github.com/solana-foundation/program-examples/tree/main/tokens/token-2022/interest-bearing)           | Create tokens that show an interest calculation on their amount.                                                     | Anchor, Pinocchio         |
| [Memo Transfer](https://github.com/solana-foundation/program-examples/tree/main/tokens/token-2022/memo-transfer)                 | Create tokens where transfers must have a memo describing the transaction attached.                                  | Anchor                    |
| [Metadata](https://github.com/solana-foundation/program-examples/tree/main/tokens/token-2022/metadata)                           | Store the token metadata inside the mint itself, without an additional program.                                      | Anchor                    |
| [Mint Close Authority](https://github.com/solana-foundation/program-examples/tree/main/tokens/token-2022/mint-close-authority)   | With the old token program it was not possible to close a mint. Now it is.                                           | Anchor, Native, Pinocchio |
| [Multiple Extensions](https://github.com/solana-foundation/program-examples/tree/main/tokens/token-2022/multiple-extensions)     | Shows you how you can add multiple extensions to a single mint                                                       | Native, Pinocchio         |
| [NFT Metadata pointer](https://github.com/solana-foundation/program-examples/tree/main/tokens/token-2022/nft-meta-data-pointer)  | It is possible to use the metadata extension to create NFTs and add dynamic on chain metadata.                       | Anchor                    |
| [Not Transferable](https://github.com/solana-foundation/program-examples/tree/main/tokens/token-2022/non-transferable)           | Useful for example for achievements, referral programs or any soul bound tokens.                                     | Anchor, Native, Pinocchio |
| [Permanent Delegate](https://github.com/solana-foundation/program-examples/tree/main/tokens/token-2022/permanent-delegate)       | Create tokens that remain under the control of an account, even when transferred elsewhere.                          | Anchor, Pinocchio         |
| [Transfer fee](https://github.com/solana-foundation/program-examples/tree/main/tokens/token-2022/transfer-fee)                   | Every transfer of the tokens hold some tokens back in the token account which can then be collected.                 | Anchor, Native, Pinocchio |
| [Transfer Hook](https://github.com/solana-foundation/program-examples/tree/main/tokens/token-2022/transfer-hook)                 | Several examples to add additional functionality to your token using a CPI from the token program into your program. | Anchor, Pinocchio         |

## Cryptography

One stateless program per curve, wrapping the raw cryptographic syscalls. These
run in LiteSVM today but only work on public clusters once their feature gates
activate.

| Example Name                                                                                        | Description                                                                                                      | Language  |
| --------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | --------- |
| [BN254](https://github.com/solana-foundation/program-examples/tree/main/cryptography/bn254)         | Add and scalar-multiply G2 points and verify aggregate BLS signatures with the `sol_alt_bn128_group_op` syscall. | Pinocchio |
| [BLS12-381](https://github.com/solana-foundation/program-examples/tree/main/cryptography/bls12-381) | Add, subtract, and scalar-multiply BLS12-381 G1 and G2 points with the `sol_curve_group_op` syscall.             | Pinocchio |

## Ecosystem Solana program examples

Third parties often maintain their own libraries of example Solana programs.
These are maintained by the providers rather than by Solana Foundation.

- [Quicknode's Solana Program Examples](https://github.com/quicknode/solana-program-examples)
  provides additional programs, particularly for financial software, for both
  newer Anchor versions and the Quasar framework.
