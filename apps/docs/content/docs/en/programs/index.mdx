Most apps never write a program. Payments, tokenized assets, and markets run on
<span className="sol-chip" data-concept="program"><Tooltip headline="Programs" tip="Programs are code deployed to the network that owns and updates accounts. Most apps call existing programs, such as the Token program, rather than writing their own." cta="Learn more" href="/developers/docs/core/programs">programs</Tooltip><span className="nojs-only"> ([Programs](/developers/docs/core/programs): Programs are code deployed to the network that owns and updates accounts. Most apps call existing programs, such as the Token program, rather than writing their own.)</span></span> that already
exist on the network, such as the Token program. Write your own when you need
rules or state that no existing program provides: code that runs on Solana,
owns its
<span className="sol-chip" data-concept="account"><Tooltip headline="Accounts" tip="Everything on Solana (balances, tokens, programs, app data) lives in accounts: records at an address, each with an owner that is allowed to change it." cta="Learn more" href="/developers/docs/core/accounts">accounts</Tooltip><span className="nojs-only"> ([Accounts](/developers/docs/core/accounts): Everything on Solana (balances, tokens, programs, app data) lives in accounts: records at an address, each with an owner that is allowed to change it.)</span></span> and can be
called by anyone.
