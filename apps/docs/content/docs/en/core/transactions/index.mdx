## In short

<ConceptShort />

<ConceptUsedIn />

A transaction holds one or more [instructions](/developers/docs/core/instructions), the
signatures that authorize them, and a recent blockhash. Its instructions run
together: if any fails, the whole transaction fails and every change is
reverted.

## Signatures

<SignatureShort />

Each required signer approves the whole transaction, and the network verifies
every signature before it runs any instruction. See
[Wallets & signatures](/developers/docs/core/wallets) for how keys and signing work.

<SignatureUsedIn />

## Key facts

- **Atomic execution**: All instructions succeed or all revert. Fees are still
  charged on failure.
- **Size limit**: 1,232 bytes maximum, derived from the IPv6 minimum MTU (1,280
  bytes) minus 48 bytes for network headers. The
  [v1 format](/developers/docs/core/transactions/versioned-transactions#v1-format) raises
  this to 4,096 bytes.
- **Signatures**: Each signer provides one 64-byte Ed25519 signature.
- **Blockhash expiry**: A transaction's recent blockhash is valid for 150 blocks, about 30 seconds at 200ms slots.
