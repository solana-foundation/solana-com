## In short

The network stores all state in one key-value store: each key is a 32-byte
address, and each value is an account.

## Key facts

- **Structure**: Every account has the same five fields: lamports, data, owner,
  executable, rent_epoch.
- **Address**: Each account has a unique 32-byte address, either an Ed25519
  public key or a [PDA](/developers/docs/core/pda).
- **Ownership**: Only the account's owner program can modify its data or debit
  lamports. Any program can credit lamports to any writable account.
- **Storage**: Every account holds a refundable minimum lamport balance,
  proportional to its data size, to stay onchain.
