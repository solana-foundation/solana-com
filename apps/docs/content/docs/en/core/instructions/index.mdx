An instruction asks one [program](/developers/docs/core/programs) to run one of its
handlers. It names the program, the accounts it needs, and a byte array of data
the program interprets (usually a discriminator that picks the handler, then
serialized arguments). To change state, you add one or more instructions to a
[transaction](/developers/docs/core/transactions) and send it.

## Key facts

- **Single program**: Each instruction targets exactly one program via
  `program_id`.
- **Account metadata**: The `accounts` array has an `AccountMeta` for every
  account the instruction reads or writes.
- **Opaque data**: The `data` field is a byte array whose format is defined by
  the target program.
