## In short

<ConceptShort />

<ConceptUsedIn />

Every [transaction](/developers/docs/core/transactions) pays a fee in SOL, in two parts:
a **base fee** that pays validators to verify signatures, and an optional
**prioritization fee** that makes the current leader more likely to schedule
your transaction ahead of others.

## Key facts

- **Base fee**: per-signature, split 50% burned / 50% to the validator.
- **Prioritization fee**:
  `ceil(compute_unit_price * compute_unit_limit / 1,000,000)` lamports. 100% to
  the validator. In the
  [v1 format](/developers/docs/core/transactions/versioned-transactions#v1-format) the fee
  is an absolute lamport total set in the message config instead.
