This page is a single reference for all runtime constants mentioned across the
core concept pages. Each constant links to its source definition in the
[agave](https://github.com/anza-xyz/agave/tree/v4.2.1) validator client or
[solana-sdk](https://github.com/anza-xyz/solana-sdk).

## Transactions

| Constant                       | Value       | Description                                                                                                                                                                                                                                                                                                              | Source                                                                                                                       |
| ------------------------------ | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| `PACKET_DATA_SIZE`             | 1,232 bytes | Maximum transaction size (IPv6 MTU minus headers)                                                                                                                                                                                                                                                                        | [`PACKET_DATA_SIZE`](https://github.com/anza-xyz/solana-sdk/blob/packet%40v4.3.0/packet/src/lib.rs#L37-L42)                  |
| `MAX_ACCOUNTS_PER_TRANSACTION` | 256         | Hard ceiling from `u8` index encoding. The enforced runtime limit is [64](https://github.com/anza-xyz/agave/blob/v4.2.1/runtime/src/bank.rs#L3621-L3629) (128 when [`increase_tx_account_lock_limit`](https://github.com/anza-xyz/agave/blob/v4.2.1/feature-set/src/lib.rs#L875-L877) is activated, currently inactive). | [`MAX_ACCOUNTS_PER_TRANSACTION`](https://github.com/anza-xyz/agave/blob/v4.2.1/transaction-context/src/lib.rs#L14)           |
| `MAX_PROCESSING_AGE`           | 150 slots   | Blockhash expiry window                                                                                                                                                                                                                                                                                                  | [`MAX_PROCESSING_AGE`](https://github.com/anza-xyz/solana-sdk/blob/clock%40v3.2.0/clock/src/lib.rs#L99-L101)                 |
| `MAX_RECENT_BLOCKHASHES`       | 300 entries | BlockhashQueue size                                                                                                                                                                                                                                                                                                      | [`MAX_RECENT_BLOCKHASHES`](https://github.com/anza-xyz/solana-sdk/blob/clock%40v3.2.0/clock/src/lib.rs#L93-L96)              |
| `MAX_SIGNATURES_PER_PACKET`    | 12          | Maximum signatures per transaction packet                                                                                                                                                                                                                                                                                | [`MAX_SIGNATURES_PER_PACKET`](https://github.com/anza-xyz/agave/blob/v4.2.1/transaction-view/src/signature_frame.rs#L12-L19) |

The upcoming
[v1 transaction format](/docs/core/transactions/versioned-transactions#v1-message-format)
raises the maximum transaction size to 4,096 bytes. `PACKET_DATA_SIZE` still
describes the MTU-derived packet payload; a v1 transaction larger than that is
split across multiple QUIC frames. The signature and account-lock limits above
are unchanged.
