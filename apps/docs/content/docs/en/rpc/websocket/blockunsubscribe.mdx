---
title: blockUnsubscribe
description: Cancel a blockSubscribe websocket subscription.
type: reference
---

Cancel an existing [blockSubscribe](/developers/docs/rpc/websocket/blocksubscribe)
subscription.

<Info>
  **Source**

  [`block_unsubscribe`](https://github.com/anza-xyz/agave/blob/v3.1.8/rpc/src/rpc_pubsub.rs#L575)
</Info>

<Warning>
  This method is only available when block subscriptions are enabled on the
  validator.
</Warning>

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "blockUnsubscribe",
    "params": [0]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="subscription id" type="integer" required>
  Subscription id returned by `blockSubscribe`.
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  Returns `true` if the subscription was removed. Returns an error if the
  subscription id is unknown.
</ResponseField>
