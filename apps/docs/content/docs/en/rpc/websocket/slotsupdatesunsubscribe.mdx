---

Cancel an existing
[slotsUpdatesSubscribe](/developers/docs/rpc/websocket/slotsupdatessubscribe) subscription.

<Info>
  **Source**

  [`slots_updates_unsubscribe`](https://github.com/anza-xyz/agave/blob/v3.1.8/rpc/src/rpc_pubsub.rs#L541)
</Info>

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "slotsUpdatesUnsubscribe",
    "params": [0]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="subscription id" type="integer" required>
  Subscription id returned by `slotsUpdatesSubscribe`.
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  Returns `true` if the subscription was removed. Returns an error if the
  subscription id is unknown.
</ResponseField>
