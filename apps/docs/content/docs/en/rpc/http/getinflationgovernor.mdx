## Parameters

<ParamField body="config" type="object">
  Configuration object.

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string" default="finalized">
      Values: `processed`, `confirmed`, `finalized`

      Solana RPC uses the following commitment levels:

      | Value       | Description                                                                                                                                                                               |
      | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
      | `processed` | Return data from the highest slot this node has processed. This is the newest view, but the block can still be skipped.                                                                   |
      | `confirmed` | Return data from the same slot as `finalized`. Kept for compatibility and planned for removal in a later release.                                                                         |
      | `finalized` | Return data from the highest slot with a finalization certificate, from votes by 80% of stake in one round or 60% of stake in each of two rounds. This is the strongest commitment level. |
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="object">
  The result field will be a JSON object with the following fields:

  <Expandable title="properties" defaultOpen>
    <ResponseField name="foundation" type="f64">
      Percentage of total inflation allocated to the foundation
    </ResponseField>

    <ResponseField name="foundationTerm" type="f64">
      Duration of foundation pool inflation in years
    </ResponseField>

    <ResponseField name="initial" type="f64">
      Initial inflation percentage from time 0
    </ResponseField>

    <ResponseField name="taper" type="f64">
      Rate per year at which inflation is lowered. (Rate reduction is derived using
      the target slot time in genesis config)
    </ResponseField>

    <ResponseField name="terminal" type="f64">
      Terminal inflation percentage
    </ResponseField>
  </Expandable>
</ResponseField>
