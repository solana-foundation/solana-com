---
title: getClusterNodes
description: >-
  Returns network endpoints, shred version, feature set, and software version
  for known cluster nodes.
type: reference
---

<Info>
  **Source**

  [`get_cluster_nodes`](https://github.com/anza-xyz/agave/blob/v3.1.8/rpc/src/rpc.rs#L3634)
</Info>

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getClusterNodes"
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let nodes = await rpc.getClusterNodes().send();

  console.log(nodes);
  ```

  ```ts web3.js
  import { Connection, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let nodes = await connection.getClusterNodes();

  console.log(nodes);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let nodes = client.get_cluster_nodes().await?;

      println!("{:#?}", nodes);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

None

## Result

<ResponseField name="result" type="array">
  The result field will be an array of JSON objects, each with the following sub
  fields:

  <Expandable title="properties" defaultOpen>
    <ResponseField name="featureSet" type="u32 | null">
      First 4 bytes of the node's FeatureSet identifier
    </ResponseField>

    <ResponseField name="gossip" type="string | null">
      Gossip network address for the node
    </ResponseField>

    <ResponseField name="pubkey" type="string">
      Node public key, as base-58 encoded string
    </ResponseField>

    <ResponseField name="pubsub" type="string | null">
      WebSocket PubSub network address for the node, or `null` if the PubSub service
      is not enabled
    </ResponseField>

    <ResponseField name="rpc" type="string | null">
      JSON RPC network address for the node, or `null` if the JSON RPC service is not
      enabled
    </ResponseField>

    <ResponseField name="serveRepair" type="string | null">
      Serve repair UDP network address for the node
    </ResponseField>

    <ResponseField name="shredVersion" type="u16 | null">
      The shred version the node has been configured to use
    </ResponseField>

    <ResponseField name="tpu" type="string | null">
      TPU UDP network address for the node
    </ResponseField>

    <ResponseField name="tpuForwards" type="string | null">
      TPU forwards UDP network address for the node
    </ResponseField>

    <ResponseField name="tpuForwardsQuic" type="string | null">
      TPU forwards QUIC network address for the node
    </ResponseField>

    <ResponseField name="tpuQuic" type="string | null">
      TPU QUIC network address for the node
    </ResponseField>

    <ResponseField name="tpuVote" type="string | null">
      TPU vote UDP network address for the node
    </ResponseField>

    <ResponseField name="tvu" type="string | null">
      TVU UDP network address for the node
    </ResponseField>

    <ResponseField name="version" type="string | null">
      The software version of the node, or `null` if the version information is not
      available
    </ResponseField>
  </Expandable>
</ResponseField>
