---

<Info>
  **Source**

  [`get_identity`](https://github.com/anza-xyz/agave/blob/v3.1.8/rpc/src/rpc.rs#L2820)
</Info>

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getIdentity"
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let identity = await rpc.getIdentity().send();

  console.log(identity);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let identity = client.get_identity().await?;

      println!("{:#?}", identity);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

None

## Result

<ResponseField name="result" type="object">
  The result field will be a JSON object with the following fields:

  <Expandable title="properties" defaultOpen>
    <ResponseField name="identity" type="string">
      The identity pubkey of the current node (as a base-58 encoded string)
    </ResponseField>
  </Expandable>
</ResponseField>
