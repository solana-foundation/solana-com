---
title: getInflationRate
description: >-
  Returns the current epoch's effective inflation rates.
type: reference
---

<Info>
  **Source**

  [`get_inflation_rate`](https://github.com/anza-xyz/agave/blob/v3.1.8/rpc/src/rpc.rs#L897)
</Info>

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getInflationRate"
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let inflationRate = await rpc.getInflationRate().send();

  console.log(inflationRate);
  ```

  ```ts web3.js
  import { Connection, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let inflationRate = await connection.getInflationRate();

  console.log(inflationRate);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let inflation_rate = client.get_inflation_rate().await?;

      println!("{:#?}", inflation_rate);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

None

## Result

<ResponseField name="result" type="object">
  The result field will be a JSON object with the following fields:

  <Expandable title="properties" defaultOpen>
    <ResponseField name="total" type="f64">
      Total inflation
    </ResponseField>

    <ResponseField name="validator" type="f64">
      Inflation allocated to validators
    </ResponseField>

    <ResponseField name="foundation" type="f64">
      Inflation allocated to the foundation
    </ResponseField>

    <ResponseField name="epoch" type="u64">
      Epoch for which these values are valid
    </ResponseField>
  </Expandable>
</ResponseField>
