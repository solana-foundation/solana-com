---
title: getInflationReward
description: >-
  Returns the inflation reward credited to each supplied address for an epoch.
  Depending on the supplied address, this may be a staking reward or a voting
  reward.
type: reference
---

## Parameters

<ParamField body="addresses" type="array" required>
  An array of addresses to query, as base-58 encoded strings
</ParamField>

<ParamField body="config" type="object">
  Configuration object containing the following fields:

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string" default="finalized">
      Values: `processed`, `confirmed`, `finalized`

      Solana RPC uses the following commitment levels:

      | Value       | Description                                                                                                                                                                               |
      | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
      | `processed` | Return data from the highest slot this node has processed. This is the newest view, but the block can still be skipped.                                                                   |
      | `confirmed` | Return data from the same slot as `finalized`. Kept for compatibility and planned for removal in a later release.                                                                         |
      | `finalized` | Return data from the highest slot with a finalization certificate, from votes by 80% of stake in one round or 60% of stake in each of two rounds. This is the strongest commitment level. |
    </ParamField>

    <ParamField body="epoch" type="u64">
      An epoch for which the reward occurs. If omitted, the previous epoch will be
      used
    </ParamField>

    <ParamField body="minContextSlot" type="number">
      The minimum slot that the request can be evaluated at

      ```json Example
      { "minContextSlot": 341197000 }
      ```
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="array">
  The result field will be a JSON array whose elements are either reward objects
  or `null` when no reward data is available for the corresponding input address:

  <Expandable title="properties" defaultOpen>
    <ResponseField name="epoch" type="u64">
      Epoch for which reward occurred
    </ResponseField>

    <ResponseField name="effectiveSlot" type="u64">
      The slot in which the rewards are effective
    </ResponseField>

    <ResponseField name="amount" type="u64">
      Reward amount in lamports
    </ResponseField>

    <ResponseField name="postBalance" type="u64">
      Post balance of the account in lamports
    </ResponseField>

    <ResponseField name="commission" type="u8 | null">
      Vote account commission when the reward was credited
    </ResponseField>
  </Expandable>
</ResponseField>
