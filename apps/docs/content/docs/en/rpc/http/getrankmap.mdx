Returns the validator rank map used to interpret Alpenglow certificate bitmaps
for the epoch containing `slot`. Pass the certificate's slot to select its map.

The node serves the epoch stakes it currently retains. This is not a historical
archive: `value` is `null` if the requested epoch is unavailable or has no
eligible BLS validators. The response's `context.slot` is the bank used to
answer the request, which can differ from the supplied slot.

<Callout type="warn">
  Added for Agave v4.5 in
  [anza-xyz/agave#15654](https://github.com/anza-xyz/agave/pull/15654). Nodes
  without this method return `Method not found` (`-32601`).
</Callout>

```rs !!request title="Rust"
use solana_rpc_client::nonblocking::rpc_client::RpcClient;
use solana_rpc_client_api::{client_error::Error, config::RpcRankMapConfig};

async fn show_ranks(client: &RpcClient) -> Result<(), Error> {
    let certificate_slot = 432000;
    let response = client.get_rank_map(certificate_slot).await?;
    if let Some(rank_map) = response.value {
        for validator in rank_map.validators {
            println!("rank {}: {}", validator.rank, validator.node_pubkey);
        }
    }

    let response = client
        .get_rank_map_with_config(
            certificate_slot,
            RpcRankMapConfig {
                identity: Some("67omRD8GkXTi8daWceprtQABkDeEm3SZYHUCrthQGB9D".to_string()),
                ..RpcRankMapConfig::default()
            },
        )
        .await?;
    println!("{response:?}");
    Ok(())
}
```

### !params

#### !! slot

!type u64  
!required

Required slot used to select the epoch. The slot does not need to contain a
produced block. It does not set a minimum context slot.

#### !! config

!type object

All configuration fields are optional. Omitting the config or passing `{}`
returns the full map using finalized commitment.

##### !! commitment

!type string  
!values processed confirmed finalized  
!default finalized

Commitment of the bank whose retained epoch stakes are queried. Processed or
confirmed banks can return different maps on different forks.

##### !! minContextSlot

!type u64

Minimum slot of the bank answering the request. If that bank is below the
minimum, the method returns `MinContextSlotNotReached` (`-32016`), even if the
requested epoch is unavailable. Omit this field to enforce no minimum.

##### !! identity

!type string

Validator identity as a base-58 encoded public key. Limits `validators` to that
identity, preserving its original rank and the full map's `totalStake`. An
unknown identity returns an empty `validators` array when the map exists. An
invalid public key returns `Invalid params` (`-32602`).

!type object

A response with `context` and `value` fields:

- `context.slot`: slot of the bank used to answer the request.
- `context.apiVersion`: optional RPC API version string.
- `value`: rank map object, or `null` if the epoch is unavailable or has no
  eligible BLS validators.

When present, the map contains:

- `epoch: <u64>`: epoch in which the ranks are effective.
- `totalStake: <u64>`: positive total stake in the full rank map, in lamports.
- `validators: <array>`: entries ordered by rank, each containing:
  - `rank: <u16>`: zero-based index in Alpenglow certificate bitmaps.
  - `votePubkey: <string>`: base-58 vote account address.
  - `nodePubkey: <string>`: base-58 validator identity.
  - `blsPubkeyCompressed: <string>`: base-58 compressed BLS public key.
  - `stake: <u64>`: positive stake assigned to this rank, in lamports.
