## Parameters

<ParamField body="start slot" type="u64" required>
  First slot in the requested range. Use a recent slot, such as the result of
  [`getSlot`](/developers/docs/rpc/http/getslot): a node keeps leader schedules
  for only ten epochs (the next epoch, the current epoch, and the eight before
  it), so a start slot outside that range returns `Invalid slot range: leader
  schedule for epoch <epoch> is unavailable` (`-32602`). The cURL example's fixed
  slot goes out of range once the cluster is nine epochs past it (two to three
  weeks); this command reads the current slot first:

  ```bash Example
  SLOT=$(curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","id":1,"method":"getSlot"}' | jq .result)

  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","id":1,"method":"getSlotLeaders","params":['"$SLOT"',10]}'
  ```
</ParamField>

<ParamField body="limit" type="u64" required>
  Number of consecutive slots to return. Allowed range: `1` to `5,000`.
</ParamField>

## Result

<ResponseField name="result" type="array">
  Array of validator identity Pubkeys, as base-58 encoded strings, in slot order.
</ResponseField>
