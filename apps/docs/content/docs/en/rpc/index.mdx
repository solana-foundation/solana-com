## Cluster Endpoints

The endpoint you call decides which cluster you read from and send to.

| Cluster | Public RPC endpoint              | Description                                                                                       |
| ------- | -------------------------------- | ------------------------------------------------------------------------------------------------- |
| Mainnet | `https://api.mainnet.solana.com` | Production network using real SOL.                                                                |
| Devnet  | `https://api.devnet.solana.com`  | Developer testing network. Use the [Solana Faucet](https://faucet.solana.com/) to get Devnet SOL. |
| Testnet | `https://api.testnet.solana.com` | Validator testing network.                                                                        |

<Info>
  Public endpoints are shared and rate-limited, and aren't meant for production.
  They return `429` when you exceed rate limits and `403` when traffic is
  blocked. For production, [choose an RPC provider](/developers/docs/rpc/providers).
</Info>

For local development, Surfpool and `solana-test-validator` use these default
localhost endpoints:

| Interface | Endpoint                |
| --------- | ----------------------- |
| HTTP RPC  | `http://localhost:8899` |
| WebSocket | `ws://localhost:8900`   |

## Configuring State Commitment

Many methods and subscriptions accept a `commitment` parameter: how final a
block must be before the node returns data or sends a notification.

| Commitment  | Description                                                                                                                |
| ----------- | -------------------------------------------------------------------------------------------------------------------------- |
| `processed` | The node's most recent processed block. This is the newest view, but the block can still be skipped.                       |
| `confirmed` | The same block as `finalized`. Kept for compatibility and planned for removal in a later release.                          |
| `finalized` | A block with a finalization certificate: votes from 80% of stake in one round, or from 60% of stake in each of two rounds. |

`confirmed` and `finalized` return the same data, roughly 150 milliseconds
after a block is produced on mainnet; prefer `finalized` in new code. See
[settlement and finality](/developers/docs/defi/finality).

If a method or subscription accepts `commitment` and you omit it, the default is
typically `finalized`.
