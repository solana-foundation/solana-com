Tooling for issuing assets, moving them, and operating the result. For tooling
specific to payment flows - Commerce Kit and pay.sh - see
[payments developer tools](/docs/payments/developer-tools). For agent frameworks
and AI-assisted development, see [AI development](/docs/finance/ai-development).

## Issuance and controls

| Tool                      | Description                                                                                                                    | Links                                                                                           |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| Mosaic                    | The Solana Foundation's open-source issuance toolkit - CLI, SDK, and templates for gated mints; pre-1.0 at the time of writing | [GitHub](https://github.com/solana-foundation/mosaic)                                           |
| Token ACL                 | Shared programs for delegated freeze authority and permissionless thaw against a pluggable gate                                | [Docs](/docs/tokenization/token-acl) • [GitHub](https://github.com/solana-foundation/token-acl) |
| ABL Gate Program          | Reference allow/block list gate for Token ACL                                                                                  | [GitHub](https://github.com/solana-foundation/token-acl-gate)                                   |
| Attestations              | Onchain credentials bound to an address; the schema determines what is published                                               | [Docs](/docs/tools/attestations)                                                                |
| Solana Developer Platform | An API and dashboard for token issuance and payments on Solana; access through platform.solana.com                             | [platform.solana.com](https://platform.solana.com)                                              |

## Security programs

| Program                                                                   | Description                                                                                                                                                                    | Links                                                                                                                    |
| ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| STRIDE (Solana Trust, Resilience and Infrastructure for DeFi Enterprises) | Security assessments of Solana protocols across eight pillars, with findings published; run by Asymmetric Research with the Solana Foundation, per the April 2026 announcement | [stride.asymmetric.re](https://stride.asymmetric.re) • [Announcement](https://solana.com/news/solana-ecosystem-security) |
| SIRN (Solana Incident Response Network)                                   | A network of security firms that coordinates response to active security incidents; members are listed in the April 2026 announcement                                          | [Announcement](https://solana.com/news/solana-ecosystem-security)                                                        |

A STRIDE assessment covers a protocol rather than an issuer's mint, so it is
relevant to the venues an asset composes with, where those venues have been
assessed.
