Set up a local Solana development environment with the automated installer. It
installs Rust, the Solana CLI, Anchor CLI, Surfpool CLI, Node.js, and Yarn on
macOS, Linux, or Windows through WSL.

<Callout type="info" title="Windows requires WSL">
  In Windows PowerShell, run `wsl --install`, restart Windows if prompted, then
  run the installation commands below in the Ubuntu terminal. See the [manual
  installation guide](/docs/intro/installation/dependencies) for the complete
  WSL setup.
</Callout>

## Quick installation

1. Run the installer in a macOS, Linux, or WSL terminal:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
```

You can
[review the installer source](https://github.com/solana-developers/solana-install/blob/main/install.sh)
before running it. The installer detects supported Linux package managers and
installs their system dependencies automatically.

2. Restart your terminal so the new commands are available on your `PATH`.

3. Verify every tool:

```terminal
$ rustc --version
$ solana --version
$ anchor --version
$ surfpool --version
$ node --version
$ yarn --version
```

A successful installation returns output in this form (version numbers change as
tools are released):

```txt title="Example output"
Installed Versions:
Rust: rustc x.y.z (...)
Solana CLI: solana-cli x.y.z (..., client:Agave)
Anchor CLI: anchor-cli x.y.z
Surfpool CLI: surfpool x.y.z
Node.js: vx.y.z
Yarn: x.y.z
```

<Callout type="warn" title="Installer failed or a command is missing">
  Follow the [manual installation guide](/docs/intro/installation/dependencies)
  to install or troubleshoot each dependency individually.
</Callout>
