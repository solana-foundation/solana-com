Coding agents such as Claude Code, Codex, and Cursor often learn Solana from
out-of-date training data. The Solana MCP server lets your agent look up
current docs while it works, and the Solana skill teaches it current APIs and
conventions.

To build an AI agent that holds a wallet and transacts onchain, see
[Build onchain AI agents](/developers/docs/tools/ai) instead.

## Add the Solana MCP server

Run this in your project folder:

```bash Terminal
npx add-mcp https://mcp.solana.com/mcp -n solana-mcp -g -y
```

add-mcp detects the coding agents you use and adds the server to each one.

To set up one agent yourself, use its tab:

<Tabs>
  <Tab title="Claude Code">
    ```bash Terminal
    claude mcp add --transport http solana-mcp https://mcp.solana.com/mcp
    ```

    Run `/mcp` in Claude Code to check that `solana-mcp` is connected.
  </Tab>
  <Tab title="Codex">
    ```bash Terminal
    codex mcp add solana-mcp --url https://mcp.solana.com/mcp
    ```

    Run `codex mcp list` to check that `solana-mcp` is listed.
  </Tab>
  <Tab title="Cursor">
    Add this to `~/.cursor/mcp.json` for every project, or to
    `.cursor/mcp.json` for one project:

    ```json mcp.json
    {
      "mcpServers": {
        "solanaMcp": {
          "url": "https://mcp.solana.com/mcp"
        }
      }
    }
    ```
  </Tab>
  <Tab title="VS Code">
    In the Command Palette, run **MCP: Open User Configuration**, then add:

    ```json mcp.json
    {
      "servers": {
        "solanaMcp": {
          "type": "http",
          "url": "https://mcp.solana.com/mcp"
        }
      }
    }
    ```
  </Tab>
  <Tab title="Windsurf">
    Add this to `~/.codeium/windsurf/mcp_config.json`:

    ```json mcp_config.json
    {
      "mcpServers": {
        "solanaMcp": {
          "serverUrl": "https://mcp.solana.com/mcp"
        }
      }
    }
    ```
  </Tab>
</Tabs>

The server needs no API key. It searches the Solana docs, the Anchor docs, and
other Solana sources, and checks Anchor and Pinocchio program code for security
issues. The [Solana MCP site](https://mcp.solana.com/) lists every tool and has
project instructions you can add to `AGENTS.md` or `CLAUDE.md`.

## Install the Solana skill

```bash Terminal
npx skills add https://github.com/solana-foundation/solana-dev-skill
```

The skill installs into your project, where most coding agents pick it up.
Browse more workflows in the [Solana skills library](https://solana.com/skills).

## Try it

Ask your agent a Solana question or give it a task. A good first one is "Follow
the Solana Quickstart with me": the [Quickstart](/developers/docs/quickstart) sends test
dollars, creates an asset, sends it to someone, and freezes their account, on
devnet.
