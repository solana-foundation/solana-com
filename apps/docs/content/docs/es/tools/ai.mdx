# Trabajando con LLMs y Agentes en Solana

Antes de profundizar en herramientas específicas, entendamos los componentes clave del stack de desarrollo de IA:

## Entendiendo el Stack de IA

1. **Modelos de Lenguaje Grandes (LLMs)**
   - Los modelos de IA fundamentales (como GPT-4, Claude o Llama)
   - Procesan y generan lenguaje natural
   - Proporcionan inteligencia bruta y capacidades de razonamiento
   - Ejemplos: GPT-4 de OpenAI, Claude de Anthropic, Llama de Meta

2. **Frameworks de Agentes (como Eliza)**
   - Construidos sobre LLMs para crear agentes autónomos
   - Gestionan las personalidades y comportamientos de los agentes
   - Administran la memoria y el contexto
   - Ofrecen integración multiplataforma
   - Ejemplos: Eliza, LangChain, AutoGPT, Vercel AI

3. **Kits de Agentes Especializados (como Solana Agent Kit)**
   - Diseñados para casos de uso específicos (p. ej., operaciones en blockchain)
   - Ofrecen herramientas e integraciones preconfiguradas
   - Abstraen la complejidad técnica
   - Funciones blockchain listas para usar
   - Ejemplos: Solana Agent Kit, GOAT Toolkit

Piénsalo así:

- Los LLMs son el "cerebro" que puede entender y generar lenguaje
- Los frameworks de agentes son el "sistema operativo" que gestiona el comportamiento de la IA
- Los kits especializados son las "aplicaciones" que otorgan capacidades específicas a la IA

# Construyendo Agentes de IA para Solana

Esta guía te mostrará cómo:

- Construir un agente de IA básico usando el Solana Agent Kit de SendAI
- Crear un bot de Twitter con el Framework Eliza
- Entender las opciones de integración de IA onchain
- Opciones para construir bots de trading avanzados

## Introducción a los Agentes de IA en Solana

Los agentes de IA en Solana son programas autónomos que pueden interactuar con la
blockchain mediante procesamiento de lenguaje natural y aprendizaje automático. Pueden:

- Ejecutar transacciones
- Monitorear la actividad de la blockchain
- Interactuar con contratos inteligentes
- Brindar asistencia al usuario
- Automatizar flujos de trabajo complejos

## Frameworks Disponibles

Hay varios frameworks disponibles para construir agentes de IA en Solana:

1. **Solana Agent Kit de SendAI**

- Una colección de herramientas para construir agentes en Solana
- Compatible con Eliza, Langchain y Vercel AI SDK
- Herramientas y utilidades de Solana integradas
- Capacidades de procesamiento de lenguaje natural
- [Solana Agent Kit](https://github.com/sendaifun/solana-agent-kit)
- [Documentación](https://docs.solanaagentkit.xyz/)

2. **Framework Eliza**

- Combina capa de datos, LLM y agentes, y cuenta con un plugin dedicado a Solana
- Arquitectura de agentes extensible
- Fácil integración con proyectos existentes y puede usarse, por ejemplo, para
  bots de Twitter (X), Telegram o Discord
- [Repositorio de GitHub](https://github.com/elizaOS/eliza)

3. **GOAT Toolkit**

- Kit de desarrollo integral
- Compatibilidad entre cadenas
- [Repositorio de GitHub](https://github.com/goat-sdk/goat)

4. **Framework Rig**

- Implementación nativa en Rust
- Ideal para bots de trading de alto rendimiento
- Puede combinarse con el toolkit Listen.rs para integración con Solana, monitoreo de transacciones
  y envío de transacciones usando bundles de Jito, por ejemplo
- [Repositorio de GitHub](https://github.com/0xPlaygrounds/rig)
- [Repositorio de Listen.rs](https://github.com/piotrostr/listen)

Si estás desarrollando un framework de IA, no dudes en abrir un PR para añadir tu framework a la lista

<Step>
### Crear el script del agente

Crea un nuevo archivo llamado `agent.ts` con el siguiente contenido:

```typescript filename=agent.ts
import { SolanaAgentKit, createSolanaTools } from "solana-agent-kit";
import { HumanMessage } from "@langchain/core/messages";
import { ChatOpenAI } from "@langchain/openai";
import { createReactAgent } from "@langchain/langgraph/prebuilt";
import { MemorySaver } from "@langchain/langgraph";
import * as dotenv from "dotenv";
import bs58 from "bs58";
import * as readline from "readline";

dotenv.config();

async function initializeAgent() {
  const llm = new ChatOpenAI({
    modelName: "gpt-4-turbo-preview",
    temperature: 0.7
  });

  // Convert array string to actual array, then to Uint8Array, then to base58
  const privateKeyArray = JSON.parse(process.env.SOLANA_PRIVATE_KEY!);
  const privateKeyUint8 = new Uint8Array(privateKeyArray);
  const privateKeyBase58 = bs58.encode(privateKeyUint8);

  const solanaKit = new SolanaAgentKit(privateKeyBase58, process.env.RPC_URL!, {
    OPENAI_API_KEY: process.env.OPENAI_API_KEY!
  });

  const tools = createSolanaTools(solanaKit);
  const memory = new MemorySaver();

  return createReactAgent({
    llm,
    tools,
    checkpointSaver: memory
  });
}

async function runInteractiveChat() {
  const agent = await initializeAgent();
  const config = { configurable: { thread_id: "Solana Agent Kit!" } };
  const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout
  });

  // Clear console and start chat with a small delay
  setTimeout(() => {
    console.clear(); // Clear any initialization messages
    console.log("Chat with Solana Agent (type 'exit' to quit)");
    console.log("--------------------------------------------");
    askQuestion();
  }, 100);

  const askQuestion = () => {
    rl.question("You: ", async (input) => {
      if (input.toLowerCase() === "exit") {
        rl.close();
        return;
      }

      const stream = await agent.stream(
        {
          messages: [new HumanMessage(input)]
        },
        config
      );

      process.stdout.write("Agent: ");
      for await (const chunk of stream) {
        if ("agent" in chunk) {
          process.stdout.write(chunk.agent.messages[0].content);
        } else if ("tools" in chunk) {
          process.stdout.write(chunk.tools.messages[0].content);
        }
      }
      console.log("\n--------------------------------------------");

      askQuestion(); // Continue the conversation
    });
  };
}

runInteractiveChat().catch(console.error);
```

</Step>

## Construyendo con el Framework Eliza

[ElizaOS](https://github.com/elizaOS/eliza) (anteriormente conocido como Ai16z) es un
framework de IA. Esto significa que combina múltiples aplicaciones en una sola y
organiza sus interacciones. Combina:

1. Diferentes LLMs para entender al usuario
2. Agentes de blockchain con diferentes acciones (como acuñar un NFT, por ejemplo)
3. Capas de datos para almacenar el estado de los personajes entre acciones usando, por ejemplo,
   Redis, PostgreSQL o almacenamiento local
4. Diferentes clientes como X, Telegram, Discord, etc.

Toma todas estas cosas y las une de tal manera que puedes crear un
"Personaje" que puede interactuar con usuarios de forma autónoma. Estos Personajes se
definen en un archivo JSON, que especifica qué acciones puede realizar, qué LLM debe
usar y los distintos prompts que definen el comportamiento del personaje.

### Construyendo un bot de Twitter (X) que pueda acuñar NFTs bajo demanda

Lo que construiremos ahora es un asistente de desarrollo de Solana que pueda ayudar

### Codificar la clave privada (si es necesario)

Si tienes tu clave privada en formato hexadecimal, puedes codificarla en base58
usando el siguiente fragmento de JS:

```ts filename=encode58.ts
const bs58 = require('bs58');
console.log(bs58.encode(new Uint8Array([213,29,143,...])));
```

Y ejecútalo con

```bash
npx tsx encode58.ts
```

### Crear la configuración del personaje

Para crear un nuevo personaje necesitamos crear un archivo character.json. Puedes encontrar
los personajes predefinidos en la carpeta characters del proyecto Eliza. Para crear un
nuevo personaje puedes copiar y modificar uno de los personajes ya existentes, o bien
puedes usar la
[función composer de Cursor](https://docs.cursor.com/composer/overview) y decirle
qué tipo de personaje deseas crear.

```json filename=characters/sol.character.json
{
    "name": "Sol",
    "clients": ["twitter"],
    "modelProvider": "openai",
    "settings": {
        "voice": {
            "model": "en_US-neural"
        },
        ...
```

La parte importante aquí son los clientes y el modelProvider. En nuestro caso queremos
usar Twitter como cliente y OpenAI como proveedor de modelo, ya que es para lo que
también configuramos nuestros secretos en el archivo `.env`.

### Ejecutar el agente

Ahora que la configuración está lista, podemos ejecutar nuestro personaje:

```bash
pnpm start --character="characters/sol.character.json"
```

Esto iniciará el agente y podrás interactuar con él en Twitter. El
personaje comenzará automáticamente a publicar tweets cada pocas horas y cuando
interactuemos con él, podrá realizar acciones de Solana como acuñar NFTs,
por ejemplo.

Aquí puedes ver el
[personaje en acción](https://x.com/solanadevhelper/status/1882222232656847143).

También puedes interactuar con el personaje localmente usando el siguiente comando:
Es posible que necesites liberar el puerto 3000 e iniciar tu personaje con el flag `--host`.

```bash
pnpm start --character="characters/sol.character.json" --host
pnpm start:client
```

Si tu cliente no se conecta, asegúrate de ejecutar tu agente con el flag `--host`
y de que el puerto 3000 no esté en uso cuando inicies el cliente.

Para más información, consulta la
[documentación oficial de Eliza](https://elizaos.github.io/eliza/docs/quickstart/)

## Usando GOAT Toolkit

[GOAT](https://github.com/goat-sdk/goat) es, de manera similar al Solana Agent Kit, una
colección de diversas herramientas de blockchain que también admite diferentes
acciones de Solana y otras cadenas. También puede integrarse en el framework Eliza,
por ejemplo, y es compatible con muchas billeteras, frameworks y blockchains diferentes. Este
[ejemplo](https://github.com/goat-sdk/goat/tree/main/typescript/examples/by-use-case/solana-purchase-on-amazon)

[video de demostración](https://x.com/windsurf_ai/status/1903118960633188485) disponible.

## Integración de agentes en programas onchain

Si deseas utilizar la respuesta de un agente dentro de un programa de Solana, necesitas usar un
oráculo que escriba los datos de respuesta en una cuenta que tu programa pueda leer.
Puedes encontrar un ejemplo de un LLM que transferirá tokens a cualquier usuario que
responda correctamente las preguntas aquí:

[Interacción de LLM con programas en cadena](https://github.com/GabrielePicco/super-smart-contracts)

Este es un ejemplo de un programa onchain que se integra con un oráculo LLM (IA)
para crear un agente interactivo dispensador de tokens llamado "Mar1o".

### Características principales

1. **Interacción con el agente de IA**
   - Los usuarios pueden chatear con Mar1o para intentar ganar tokens
   - El agente evalúa el conocimiento de Solana del usuario para decidir las cantidades de tokens
   - Las respuestas están en formato JSON con texto de respuesta y cantidad de tokens

2. **Gestión de tokens**
   - Crea tokens MAR1O con metadatos
   - Puede acuñar entre 0 y 10.000 tokens según la respuesta de la IA
   - Utiliza PDAs para la gestión de tokens

### Flujo del programa explicado

Así es como funciona este programa:

```rust
// Initialize the AI agent with personality
const AGENT_DESC: &str = "You are an AI agent called Mar1o which can dispense MAR1O tokens...";

// User interaction flow:
// 1. User sends message to agent
// 2. Oracle processes with LLM
// 3. Agent responds with JSON containing reply and amount
// 4. If amount > 0, tokens are minted to user

// Example response:
{
    "reply": "Great answer! Here's a reward.",
    "amount": 1000
}
```

Esto demuestra cómo combinar las capacidades de la IA con la mecánica de tokens onchain para
crear experiencias interactivas en blockchain. Aquí hay un
[ejemplo en vivo](https://mar1o.xyz/) donde puedes intentar convencer al Agente para que
te transfiera algunos tokens.

## Agentes avanzados en Rust para trading algorítmico

Si deseas escribir tus agentes en Rust, puedes utilizar el
[framework Rig](https://github.com/0xPlaygrounds/rig) y la
biblioteca [Listen.rs](https://github.com/piotrostr/listen).

Estos dos funcionan muy bien juntos. Mientras que el framework Rig te ofrece una forma sencilla de
conectarte a LLMs, el kit de herramientas Listen.rs te proporciona la integración con Solana,
incluyendo el monitoreo de transacciones y el envío de transacciones mediante bundles de Jito,
por ejemplo.

## Buenas prácticas

- Ten en cuenta que tu agente tiene una clave privada y, por lo tanto, puede acceder a los fondos de tu
  billetera. Si alguien puede chatear con tu agente y este tiene una acción de transferencia,
  por ejemplo, los usuarios probablemente puedan lograr que les transfiera tus fondos.
- Utiliza [endpoints RPC](https://solana.com/rpc) de pago. Los endpoints públicos
  suelen tener limitaciones de velocidad
- Supervisa las actividades del agente y asegúrate de que no estén realizando ninguna acción maliciosa
  ni sean engañados por los usuarios que interactúan con ellos
- Implementa comisiones de prioridad y reintentos de transacciones en las acciones de tu agente para que
  también se procesen cuando haya congestión en la red
- Si es posible, prueba primero en devnet antes de desplegar en mainnet. La mayoría de los agentes
  simplemente toman la URL del RPC como entrada y puedes usar una de devnet hasta que estés
  listo para mainnet. Sin embargo, es posible que no todas las acciones sean posibles en devnet.
- Al escribir tus propias acciones, añade pruebas de integración para ellas de modo que los
  frameworks puedan monitorear qué acciones están fallando debido a cambios en programas o
  APIs

Los agentes de IA en Solana abren nuevas posibilidades para la automatización e interacción
con la blockchain. Si bien no todas las integraciones son perfectas aún, se desarrollan
rápidamente y ofrecen muchas oportunidades de contribución, siendo muy
flexibles para añadir tus propias integraciones.
