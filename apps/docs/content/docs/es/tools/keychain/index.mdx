**Solana Keychain ofrece una interfaz unificada para firmar transacciones de Solana
en múltiples backends de gestión de claves.** Desarrolla en local con una clave
en memoria y luego pasa a la gestión de claves empresarial, HSM en la nube o servicios
de billeteras gestionadas en producción, sin reescribir tu código de firma.

### ¿Por qué Keychain?

- **Interfaz única**: Una interfaz base `SolanaSigner` para todos los backends,
  más una capacidad por backend: firmar, reescribir y firmar, o firmar y transmitir
- **Cambia de backend**: Cambia de proveedor de gestión de claves mediante configuración; los
  puntos de llamada solo cambian cuando el nuevo backend tiene una capacidad distinta (modos nativos de Crossmint
  y Fordefi)
- **Paga solo por lo que usas**: Los feature flags de Rust, los paquetes npm por backend, los extras de Python
  y los módulos de Go por backend incluyen únicamente los backends que necesitas
- **Auditado**: Rust, TypeScript, Python y Go auditados por
  [OtterSec](https://osec.io) (el backend opcional de Ledger quedó fuera del alcance); una
  auditoría anterior de [Accretion](https://accretion.xyz) cubrió Rust y TypeScript.
  Consulta el
  [estado de las auditorías](https://github.com/solana-foundation/solana-keychain/blob/main/audits/AUDIT_STATUS.md).

### Arquitectura

- **Lenguajes**: Rust, TypeScript, Python y Go, con paridad (el backend de Ledger
  es exclusivo de Rust)
- **Interfaz**: base `SolanaSigner` (`pubkey`, `sign_message`, `is_available`)
  más exactamente una capacidad por backend: `TransactionSigner`,
  `ModifyingSigner` o `SendingSigner`
- **Backends**: Memory, Vault, AWS KMS, GCP KMS, Privy, Turnkey, Fireblocks,
  CDP, Crossmint, Dfns, Openfort, Para, Utila, Fordefi, Ledger (solo Rust,
  opcional, sin auditar)
- **Compatibilidad**: `@solana/kit` y `@solana/signers` 8.1+ (TypeScript) |
  `solana-sdk` 2.x, 3.x o 4.x mediante las features `sdk-v2` / `sdk-v3` / `sdk-v4`
  (Rust; las transacciones v1 requieren `sdk-v4`) | `solders` (Python) | `solana-go` v2
  (Go)

### Backends Soportados

Los backends abarcan el desarrollo local, la gestión de claves autohospedada y
en la nube, y servicios de billetera gestionados o MPC. Consulta
[Cómo elegir un backend](/docs/tools/keychain/choosing-a-backend) para comparar
los modelos de custodia y elegir el más adecuado.

| Backend         | Caso de uso                            | Rust | TypeScript | Python | Go  |

| Memory          | Desarrollo, pruebas                | ✓    | ✓          | ✓      | ✓   |
| HashiCorp Vault | Gestión de claves autohospedada          | ✓    | ✓          | ✓      | ✓   |
| AWS KMS         | Nativo en la nube (AWS)                  | ✓    | ✓          | ✓      | ✓   |
| GCP KMS         | Nativo en la nube (GCP)                  | ✓    | ✓          | ✓      | ✓   |
| Privy           | Billeteras integradas                    | ✓    | ✓          | ✓      | ✓   |
| Turnkey         | Gestión de claves sin custodia        | ✓    | ✓          | ✓      | ✓   |
| Fireblocks      | Custodia institucional               | ✓    | ✓          | ✓      | ✓   |
| CDP             | Coinbase Developer Platform         | ✓    | ✓          | ✓      | ✓   |
| Crossmint       | Billeteras gestionadas Crossmint           | ✓    | ✓          | ✓      | ✓   |

## Inicio rápido

### Rust

Instala el crate de Rust:

```bash
cargo add solana-keychain
```

Uso básico:

```rust
use solana_keychain::{Signer, SolanaSigner};

// Create a signer from any backend
let signer = Signer::from_memory("base58_private_key")?;
let pubkey = signer.pubkey();

// Transaction signing is a capability; `tx` is a VersionedTransaction
if let Some(tx_signer) = signer.as_transaction_signer() {
    let result = tx_signer.sign_transaction(&mut tx).await?;
}

// Or let the umbrella route any backend shape and supply the RPC hop yourself
let signature = signer
    .sign_and_send(&mut tx, |encoded| async move { broadcast(encoded).await })
    .await?;
```

- [Guía de Rust](/docs/tools/keychain/getting-started/rust) - Instalación
  completa y configuración del backend
- [Crates.io](https://crates.io/crates/solana-keychain) - Crate de Rust

### TypeScript

Instala el paquete de TypeScript:

```bash
pnpm add @solana/keychain
```

Uso básico:

```typescript
import { createKeychainSigner } from "@solana/keychain";
import { signTransactionWithSigners } from "@solana/signers";

// Create any signer via the unified factory
const signer = await createKeychainSigner({
  backend: "vault",
  vaultAddr: "https://vault.example.com:8200",
  vaultToken: "hvs.xxxxx",
  keyName: "my-solana-key",
  publicKey: "base58_public_key"
});

// Sign an already-compiled transaction
const signedTx = await signTransactionWithSigners(
  [signer],
  compiledTransaction
);
```

- [Guía de TypeScript](/docs/tools/keychain/getting-started/typescript) -
  Paquetes `@solana/keychain`
- [Paquete npm](https://www.npmjs.com/package/@solana/keychain) - Paquete npm

Para instalar un firmante de Keychain en un cliente de [Kit](https://github.com/anza-xyz/kit)
como su `payer` o `identity`, usa `@solana/keychain-kit-plugin` (los modos nativos de Crossmint y
Fordefi quedan excluidos, ya que reescriben las transacciones).

### Python

Instala el paquete (los backends más pesados se distribuyen como extras, por ejemplo
`solana-keychain[aws-kms]`):

```bash
pip install solana-keychain
```

Uso básico:

```python
import os

from solana_keychain import VaultSignerConfig, create_vault_signer

signer = await create_vault_signer(
    VaultSignerConfig(
        api_base_url="https://vault.example.com:8200",
        token=os.environ["VAULT_TOKEN"],
        key_name="my-solana-key",
        public_key="base58_public_key",
    )
)

# tx is a solders VersionedTransaction
result = await signer.sign_transaction(tx)
```

- [Guía de Python](/docs/tools/keychain/getting-started/python) - Instalación
  completa, extras y configuración de backends
- [PyPI](https://pypi.org/project/solana-keychain/) - Paquete de Python

### Go

Cada backend es su propio módulo de Go, por lo que solo descargas los backends que importas:

```bash
go get github.com/solana-foundation/solana-keychain/go/signers/vault/v2@latest
```

Uso básico:

```go
import "github.com/solana-foundation/solana-keychain/go/signers/vault/v2"

signer, err := vault.New(vault.Config{
	VaultAddr: "https://vault.example.com:8200",
	Token:     os.Getenv("VAULT_TOKEN"),
	KeyName:   "my-solana-key",
	Pubkey:    "base58_public_key",
})
if err != nil {
	return err
}

// tx is a *solana.Transaction from solana-go v2
res, err := signer.SignTransaction(ctx, tx)
```

- [Guía de Go](/docs/tools/keychain/getting-started/go) - Módulos, capacidades
  y configuración de backends
- [pkg.go.dev](https://pkg.go.dev/github.com/solana-foundation/solana-keychain/go/core/v2) -
  Referencia de Go
