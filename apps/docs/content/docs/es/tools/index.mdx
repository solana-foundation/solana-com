## Herramientas

<Cards>
  <Card title="Kora" href="/docs/tools/kora">
    Crea flujos de transacciones sin gas y con pago en tokens usando un
    paymaster de Kora.
  </Card>
  <Card title="Keychain" href="/docs/tools/keychain">
    Usa una interfaz de firma unificada compatible con claves locales, KMS, HSM
    y backends de billetera.
  </Card>
  <Card title="Commerce Kit" href="/docs/tools/commerce-kit">
    Agrega componentes de pago de Solana y flujos de comercio a tu aplicación.
  </Card>
  <Card title="Solana Pay" href="/docs/tools/solana-pay">
    Implementa flujos de solicitudes de transferencia y transacciones con Solana
    Pay.
  </Card>
  <Card title="Attestations" href="/docs/tools/attestations">
    Crea credenciales, esquemas y attestations para datos offchain vinculados a
    cuentas onchain.
  </Card>
  <Card title="Private Channels" href="/docs/tools/private-channels">
    Consulta materiales de producto e recursos de integración de canales
    privados.
  </Card>
  <Card title="Surfpool" href="/docs/tools/surfpool">
    Reemplazo directo de solana-test-validator para desarrollo local, pruebas e
    implementaciones de Infraestructura como Código.
  </Card>
  <Card title="LiteSVM" href="/docs/tools/litesvm">
    Prueba programas de Solana en una VM en proceso rápida, sin un validator, en
    Rust y TypeScript.
  </Card>
  <Card title="Actions y Blinks" href="/docs/tools/actions">
    Convierte cualquier transacción de Solana en un enlace compartible y enriquecido con metadatos.
  </Card>
  <Card title="Herramientas de IA" href="/docs/tools/ai">
    Usa asistentes de programación con IA y frameworks de agentes con Solana.
  </Card>
</Cards>
