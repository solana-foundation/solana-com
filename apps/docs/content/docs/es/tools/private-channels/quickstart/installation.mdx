## Requisitos previos

- Rust 1.91+
- Solana CLI 3.1.13 (Agave):
  `sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.13/install)"`
- Node.js 24.7.0+
- pnpm 10.15.1+: `npm install -g pnpm@10.15.1`

## Clonar el repositorio

```bash
git clone https://github.com/solana-foundation/solana-private-channels.git
cd solana-private-channels
```

## Generar clientes TypeScript

Los clientes TypeScript **no** están publicados en npm. Deben generarse a partir
del IDL usando Codama.

```bash
# Escrow program client
cd private-channel-escrow-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..

# Withdraw program client
cd private-channel-withdraw-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..
```

Los clientes generados se ubican en:

- `private-channel-escrow-program/clients/typescript/src/generated/`
- `private-channel-withdraw-program/clients/typescript/src/generated/`

Importa desde estas rutas locales en tu aplicación; no existe ningún
paquete `@private-channels/client` en npm. Los ejemplos de código de esta sección usan una
ruta relativa (`../private-channel-escrow-program/...`) que asume que tu código
se encuentra junto al repositorio clonado; ajústala según la ubicación real
desde donde importas en tu propio proyecto.
