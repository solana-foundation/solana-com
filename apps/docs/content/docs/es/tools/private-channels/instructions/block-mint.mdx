title: BlockMint
description:
  Elimina un mint previamente permitido de la instancia, impidiendo nuevos depósitos para ese mint
---

Elimina un mint previamente permitido de la instancia, impidiendo nuevos depósitos para
ese mint. Los depósitos existentes no se ven afectados.

## Cuentas

| Cuenta                          | Escritura | Firmante | Descripción                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | Pagador de tarifas                                    |
| `admin`                          |          | ✓      | Administrador de instancia                               |
| `instance`                       |          |        | PDA de instancia                                 |
| `mint`                           |          |        | Mint de token SPL a bloquear                      |
| `allowed_mint`                   | ✓        |        | PDA AllowedMint (cerrada por esta instrucción) |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | PDA de autoridad de eventos                          |
| `private_channel_escrow_program` |          |        | Programa de custodia                               |

Esta instrucción no acepta parámetros.

## Notas importantes

- Cierra el PDA `allowed_mint`: las nuevas llamadas a `Deposit` para este mint fallarán
  con `InvalidAllowedMint`
- Los saldos de canal existentes para este mint no se ven afectados
- Emite un evento mediante CPI `EmitEvent`
