---
title: AddOperator
description: Aprovisiona un nuevo operador creando su PDA de operador
---

Aprovisiona un nuevo operador creando su PDA `Operator`. Después de esta llamada, la
billetera `operator` puede llamar a `ReleaseFunds` y `ResetSmtRoot`.

## Cuentas

| Cuenta                          | Modificable | Firmante | Descripción                                                         |
| -------------------------------- | -------- | ------ | ------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Pagador de tarifas                                                           |
| `admin`                          |          | ✓      | Administrador de instancia                                                      |
| `instance`                       |          |        | PDA de instancia                                                        |
| `operator`                       |          |        | Billetera del operador a aprovisionar                                        |
| `operator_pda`                   | ✓        |        | PDA del operador - derivado automáticamente de `["operator", instance, operator]` |
| `system_program`                 |          |        | System Program                                                      |
| `event_authority`                |          |        | PDA de autoridad de eventos                                                 |
| `private_channel_escrow_program` |          |        | Programa de custodia                                                      |

## Parámetros

| Parámetro | Tipo | Descripción                                                                               |
| --------- | ---- | ----------------------------------------------------------------------------------------- |
| `bump`    | `u8` | bump seed para el `operator_pda`. Opcional: el cliente `Async` lo deriva automáticamente si se omite |

> El IDL contiene un argumento `discriminator: u8` (valor `3`) que se establece automáticamente
> por el cliente generado y no debe pasarse manualmente.

## Notas importantes

- Usa `getAddOperatorInstructionAsync`; deriva automáticamente `bump` y
  `operator_pda` cuando no se proporcionan. También existe una variante síncrona
  `getAddOperatorInstruction` si ya calculaste `bump`
  por tu cuenta
- Después de esta llamada, la billetera `operator` puede llamar a `ReleaseFunds` y
  `ResetSmtRoot`
- Emite un evento a través de CPI `EmitEvent`
