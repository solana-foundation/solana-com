---
title: RemoveOperator
description: Revoca un operador cerrando su PDA de operador
---

Revoca un operador cerrando su PDA de `Operator`. La billetera revocada ya no
puede llamar a `ReleaseFunds` ni a `ResetSmtRoot`.

## Cuentas

| Cuenta                          | Modificable | Firmante | Descripción                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | Pagador de comisiones                                 |
| `admin`                          |          | ✓      | Administrador de instancia                            |
| `instance`                       |          |        | PDA de instancia                              |
| `operator`                       |          |        | Billetera de operador a revocar                 |
| `operator_pda`                   | ✓        |        | PDA de operador (cerrada por esta instrucción) |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | PDA de autoridad de eventos                       |
| `private_channel_escrow_program` |          |        | Programa de custodia                            |

Esta instrucción no recibe parámetros.

## Notas importantes

- Cierra el `operator_pda`; la billetera revocada ya no puede llamar a
  `ReleaseFunds` ni a `ResetSmtRoot`
- Cualquier transacción de operador en curso fallará con `InvalidOperatorPda` después de
  esta llamada
- Emite un evento mediante CPI de `EmitEvent`
