Esta sección es la referencia de instrucciones on-chain. La mayoría de los desarrolladores invocan estas
instrucciones a través de los clientes TypeScript generados; solo necesitas esto si estás
construyendo herramientas para operadores, escribiendo integraciones personalizadas o depurando
errores a nivel de instrucción.

**Programa Escrow** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) - gestiona
depósitos, aprovisionamiento de operadores y liquidación en Mainnet:

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) -
  inicializa el PDA de la instancia escrow
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) - añade
  un mint de token SPL a la lista blanca
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) - elimina un
  mint de la lista de permitidos
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) -
  aprovisiona un operador
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) -
  revoca un operador
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) -
  transfiere los derechos de administrador
- [Deposit](/docs/tools/private-channels/instructions/deposit) - mueve tokens SPL
  al escrow
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) -
  el operador liquida un retiro a Mainnet
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) -
  el operador rota el Sparse Merkle Tree

**Programa Withdraw** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) - se ejecuta en
la red de canales privados:

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) -
  quema el saldo del lado del canal para iniciar un retiro

## Códigos de Error

**Programa Escrow - `PrivateChannelEscrowProgramError`**

| Código                                         | Mensaje                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | Autoridad de evento no válida proporcionada                 |
| `InvalidAta`                                 | ATA no válida proporcionada                             |
| `InvalidMint`                                | Mint no válido proporcionado                            |
| `InvalidInstanceId`                          | ID de instancia no válido o no cumple las reglas    |
| `InvalidInstance`                            | Instancia no válida proporcionada                        |
| `InvalidAdmin`                               | Administrador no válido proporcionado                           |
| `TransferHookNotAllowed`                     | Extensión de transfer hook no permitida              |
| `InvalidOperatorPda`                         | PDA de operador no válido proporcionado                    |
| `InvalidTokenAccount`                        | token account no válido proporcionado                   |
| `InvalidEscrowBalance`                       | Saldo de escrow no válido                           |
| `InvalidAllowedMint`                         | Mint permitido no válido                             |
| `InvalidSmtProof`                            | Prueba SMT no válida proporcionada                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | Nonce de transacción no válido para el índice de árbol actual |
| `UnexpectedTreeIndex`                        | Índice de árbol actual inesperado para el restablecimiento de raíz SMT |

**Programa Withdraw - `PrivateChannelWithdrawProgramError`**

| Código          | Mensaje                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | Mint no válido proporcionado                       |
| `ZeroAmount`  | El monto del retiro debe ser mayor que cero |
