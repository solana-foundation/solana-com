Transfiere los derechos de administrador a una nueva billetera.

## Cuentas

| Cuenta                          | Modificable | Firmante | Descripción                        |
| -------------------------------- | -------- | ------ | ---------------------------------- |
| `payer`                          | ✓        | ✓      | Pagador de tarifas                          |
| `current_admin`                  |          | ✓      | Administrador actual (debe firmar)          |
| `instance`                       | ✓        |        | PDA de instancia (campo de administrador actualizado) |
| `new_admin`                      |          | ✓      | Billetera que recibirá los derechos de administrador     |
| `event_authority`                |          |        | PDA de autoridad de eventos                |
| `private_channel_escrow_program` |          |        | Programa de custodia                     |

Esta instrucción no requiere parámetros.

## Notas importantes

- **Irreversible en un solo paso**: el administrador actual no puede recuperar el rol
  sin que el nuevo administrador vuelva a llamar a `SetNewAdmin`
- Verifica la dirección de destino antes de llamar; no hay opción de deshacer
- Emite un evento mediante CPI `EmitEvent`
