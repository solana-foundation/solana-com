title: Conceptos
description: Conceptos fundamentales del protocolo de Canales Privados
---

Estas páginas explican cómo funciona Private Channels internamente. Los desarrolladores
que integren con una instancia existente deben leer primero **Channel Lifecycle**.
Los operadores y cualquier persona que desarrolle herramientas de operación también deben leer la
referencia del **Sparse Merkle Tree**.

- **[Channel Lifecycle](/docs/tools/private-channels/concepts/channels)** -
  participantes, roles y el flujo desde el depósito hasta el retiro
- **[Sparse Merkle Tree](/docs/tools/private-channels/concepts/smt)** - cómo
  se verifican las pruebas de retiro en cadena para prevenir el doble gasto
- **[Authentication & Roles](/docs/tools/private-channels/concepts/auth)** - autenticación
  JWT, RBAC y verificación de billetera
