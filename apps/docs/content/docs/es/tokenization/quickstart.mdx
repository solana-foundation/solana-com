## Apuntarlo a devnet

Cambia las URLs de RPC por las de devnet y financia el pagador desde un [faucet](/developers/cookbook/development/airdrops-and-faucets):

```ts
solanaRpc({
  rpcUrl: "https://api.devnet.solana.com",
  rpcSubscriptionsUrl: "wss://api.devnet.solana.com"
});
```

Todo lo demás permanece igual. Antes de usar la misma configuración en mainnet, planifica la gestión de autoridades, las operaciones de cumplimiento normativo y el monitoreo del activo.
