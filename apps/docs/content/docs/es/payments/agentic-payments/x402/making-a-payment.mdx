---
title: Cómo realizar un pago x402
seoTitle: Realiza un pago x402 en sandbox en Solana
description:
  Lanza un agente con Pay y completa un pago x402 V2 contra una API sandbox local sin mover fondos reales.
---

Usa [Pay](https://pay.sh) para ejecutar una API x402 V2 y dotar a Claude Code de un
cliente HTTP compatible con pagos. La API, la billetera del pagador y la liquidación utilizan todas la
sandbox de Solana, por lo que este tutorial no requiere una cuenta ni fondos reales.

Necesitas una terminal, Pay y Claude Code instalados.

## 1. Instala Pay

En macOS, instala el binario precompilado:

```bash
brew install pay
pay --version
```

En otras plataformas, instala el paquete de npm:

```bash
npm install --global @solana/pay
pay --version
```

## 2. Inicia una API sandbox x402

Crea `x402-demo.yaml`:

```yaml filename=x402-demo.yaml
name: x402-demo
subdomain: x402-demo
title: "x402 Demo"
description: "Minimal x402 V2 sandbox endpoint."
category: devtools
version: v1
routing:
  type: respond
operator:
  currencies:
    usd: ["USDC"]
  network: "localnet"
  fee_payer: true
endpoints:
  - method: GET
    path: "report"
    description: "Return a sandbox report."
    metering:
      schemes: [x402-exact]
      dimensions:
        - direction: usage
          unit: requests
          scale: 1
          tiers:
            - price_usd: 0.001
```

Inicia la API y déjala en ejecución:

```bash
pay --sandbox server start x402-demo.yaml --bind 127.0.0.1:1402
```

El esquema `x402-exact` hace que este sea un endpoint exclusivo de x402. El modo sandbox crea
y fondea automáticamente cuentas temporales de operador y pagador.

## 3. Lanza el agente con Pay

En otra terminal, inicia Claude Code en modo sandbox:

```bash
pay --sandbox claude
```

Pay conecta sus herramientas MCP locales a la sesión del agente. El agente no
recibe ninguna clave privada.

## 4. Realiza una solicitud x402

Pega este prompt en el agente:

```text
Use Pay to make exactly one sandbox x402 API request to
http://127.0.0.1:1402/report.

Before paying, show me the amount and ask for approval. Then return the API
result and payment receipt. Do not make any other paid requests.
```

La solicitud sigue un ciclo completo de pago x402 V2:

1. La API devuelve `402 Payment Required` con un desafío `PAYMENT-REQUIRED`.
2. Pay valida los requisitos de x402 y muestra las condiciones del pago.
3. Tras la aprobación, la billetera sandbox firma y Pay reintenta la solicitud con
   `PAYMENT-SIGNATURE`.
4. La API devuelve el resultado con un recibo `PAYMENT-RESPONSE`.

No se mueven fondos reales. Si rechazas la aprobación, la solicitud se detiene.

Continúa con [x402 en Solana](/docs/payments/agentic-payments/x402) para crear un
cliente y un servidor de recursos x402 V2, o
[conviértete en facilitador de x402](/docs/tools/x402-facilitator).
