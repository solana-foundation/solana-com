---
title: "Inicio rápido: crear un token con la CLI"
description:
  Create a token, open a token account, mint supply, and transfer tokens using
  the SPL Token CLI on devnet.
---

Este inicio rápido recorre el ciclo de vida completo de un token con la CLI
_sh`spl-token`_. Crearás un mint, una cuenta que pueda almacenar el token,
acuñarás 100 tokens y transferirás algunos a otra billetera.

Usa [Solana Playground](https://beta.solpg.io/) para ejecutar los comandos en tu
navegador, o instala la CLI localmente con `cargo install spl-token-cli`. Las
direcciones en tu salida serán distintas a los ejemplos mostrados a continuación.

## 1. Conectarse a devnet

Crea o conecta una billetera en Solana Playground, luego selecciona devnet y solicita
SOL para depósitos en cuentas y tarifas de transacción:

```terminal
$ solana config set --url devnet
$ solana airdrop 2
```

Usa tokens de devnet solo para pruebas. No tienen valor financiero.

## 2. Crear un token

Crea el mint account que identifica tu token:

```terminal
$ spl-token create-token
```

Copia la dirección del token desde la salida. Esta es la dirección del mint que usarás en
los comandos restantes. Un nuevo mint comienza con un suministro de cero.

```terminal
$ spl-token supply <MINT_ADDRESS>
```

## 3. Crear un token account

Tu billetera necesita un token account para este mint antes de poder mantener un saldo:

```terminal
$ spl-token create-account <MINT_ADDRESS>
```

Esto crea tu
[associated token account](/docs/tokens#associated-token-account), cuya dirección
se deriva de tu billetera y del mint.

## 4. Acuñar tokens

Acuña 100 tokens en tu associated token account:

```terminal
$ spl-token mint <MINT_ADDRESS> 100
$ spl-token balance <MINT_ADDRESS>
```

La autoridad de acuñación debe firmar esta operación. Acuñar tokens aumenta tanto el
saldo de tu token account como el suministro total registrado por el mint.

## 5. Transferir tokens

Envía 10 tokens a otra billetera de devnet. La opción _sh`--fund-recipient`_
crea el associated token account del destinatario si no existe:

```terminal
$ spl-token transfer <MINT_ADDRESS> 10 <RECIPIENT_WALLET_ADDRESS> --fund-recipient
```

La transferencia modifica los saldos en los token accounts del emisor y el destinatario;
no cambia el suministro total del mint.

## Opcional: agregar metadatos de Token-2022

Para almacenar un nombre, símbolo y URI directamente en un nuevo mint de Token-2022, créalo
con la extensión de metadatos habilitada:

```terminal
$ spl-token create-token \
  --program-id TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb \
  --enable-metadata
```

Luego usa la nueva dirección del mint impresa por ese comando:

```terminal
$ spl-token initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  "EXAMPLE" \
  "https://example.com/token.json"
```

El URI debe devolver un documento de metadatos JSON público. Consulta
[Token-2022 metadata](/docs/tokens/extensions/metadata) para conocer el modelo de cuenta
y ejemplos de código.
