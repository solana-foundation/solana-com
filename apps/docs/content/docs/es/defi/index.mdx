El estado global único de Solana, tiempos de bloque de ~400 ms y comisiones de menos de un centavo la convierten en el
hogardel financiamiento onchain y DeFi: cada programa — DEXs, mercados de préstamos,
oráculos, perpetuos — es componible dentro de una única transacción atómica. Esta sección
es la capa de flujo de trabajo para construir aplicaciones financieras; enlaza hacia
[Conceptos Fundamentales](/docs/core/transactions) y el
[cookbook](/developers/cookbook) para los mecanismos subyacentes.
