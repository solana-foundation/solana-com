## Solana Kit

`@solana/kit` es el SDK de TypeScript recomendado para desarrollar en Solana.
Puedes ensamblar un cliente a partir de plugins componibles, agregar enlaces de
React cuando los necesites e incorporar clientes de programa generados para los
programas en cadena que invoques.

| Paquete                   | Descripción                                  | GitHub                                                                                 |
| ------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------- |
| @solana/kit               | SDK principal: RPC, transacciones, codecs, firmantes | [Fuente](https://github.com/anza-xyz/kit)                                              |
| @solana/react             | Enlaces de React: `ClientProvider` y hooks   | [Fuente](https://github.com/anza-xyz/kit/tree/main/packages/react)                     |
| @solana/kit-plugin-rpc    | Conexión RPC + envío de transacciones         | [Fuente](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-rpc)    |
| @solana/kit-plugin-signer | Plugins de pagador de tarifas, identidad y firmante      | [Fuente](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-signer) |
| @solana/kit-plugin-wallet | Conexión Wallet Standard + hooks de React     | [Fuente](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-wallet) |

## Solana Web3.js v3

`@solana/web3.js` v3 es la versión recomendada de web3.js. Reconstruye la
API clásica basada en clases — `Connection`, `Keypair`, `Transaction`, `PublicKey` —
sobre los componentes internos de `@solana/kit`, por lo que funciona con las primitivas de Kit y los
clientes de programa anteriores. Úsala si estás actualizando una aplicación existente de web3.js o
prefieres la API basada en clases.

La mayoría de los métodos que eran síncronos en el SDK heredado, como
`Keypair.generate()` y `transaction.sign()`, ahora son asíncronos.

```bash
npm install @solana/web3.js@3
```

| Paquete         | Descripción | GitHub                                                        |
| --------------- | ----------- | ------------------------------------------------------------- |
| @solana/web3.js | SDK principal    | [Fuente](https://github.com/solana-foundation/solana-web3.js) |

`@solana/spl-token` depende de `@solana/web3.js` (heredado) y no funciona con
la v3. Usa `@solana-program/token` o `@solana-program/token-2022` en su lugar; sus
instrucciones generadas y planes de instrucciones funcionan directamente con
`Transaction.add()` de la v3.

- [Guía de migración de web3.js v1 → v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
- [Guía de migración de spl-token](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-spl-token-migration.md)

## Solana Web3.js (heredado)

`@solana/web3.js` (heredado, `1.x`) es el SDK original de TypeScript para Solana. Está
en modo de mantenimiento y solo recibe correcciones críticas. Las bases de código existentes pueden
[actualizarse a web3.js v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
o [migrar a Kit](/docs/frontend/web3-compat).
