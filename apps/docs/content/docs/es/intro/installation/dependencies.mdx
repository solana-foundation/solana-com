Instala cada dependencia por separado cuando necesites una versión específica o cuando la
[instalación rápida](/docs/intro/installation) no se complete correctamente.
Sigue las secciones en orden si configuras un entorno nuevo, o ve directamente a la herramienta
que necesitas instalar o cuyos problemas quieres solucionar.

## Requisitos previos

<Accordions>
<Accordion title="Windows">

Para desarrollar programas de Solana en Windows **debes** usar
[Windows Subsystem for Linux](https://learn.microsoft.com/en-us/windows/wsl/install)
(WSL). Después de instalar WSL, todas las demás dependencias se instalarán a
través de la terminal de Linux.

Para instalar WSL, ejecuta el siguiente comando en Windows PowerShell:

```terminal
$ wsl --install
```

El proceso de instalación te pedirá que crees una cuenta de usuario
predeterminada.

![Instalación de WSL](/assets/docs/intro/installation/wsl-install.png)

Por defecto, WSL instala Ubuntu. Puedes abrir una terminal de Linux buscando
"Ubuntu" en la barra de búsqueda.

![WSL Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-search.png)

Si tu terminal de Ubuntu se ve como la imagen a continuación, es posible que
encuentres un problema donde `ctrl + v` (atajo de teclado para pegar) no
funciona en la terminal.

![Terminal de Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-terminal-1.png)

Si encuentras este problema, abre Windows Terminal buscando "Terminal" en la
barra de búsqueda.

![Windows Terminal](/assets/docs/intro/installation/wsl-windows-terminal.png)

A continuación, cierra Windows Terminal y vuelve a abrir una terminal de Linux
buscando Ubuntu nuevamente. La terminal ahora debería verse como la imagen a
continuación, donde `ctrl + v` (atajo de teclado para pegar) funciona.

![Terminal de Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-terminal-2.png)

Si usas VS Code, la
[extensión WSL](https://code.visualstudio.com/docs/remote/wsl-tutorial) te
permite usar WSL y VS Code juntos.

![Configuración de WSL en VS Code](/assets/docs/intro/installation/wsl-vscode.png)

Verás lo siguiente en la barra de estado de VS Code:

![WSL: Ubuntu](/assets/docs/intro/installation/wsl-vscode-ubuntu.png)

Una vez que tengas WSL configurado, estás listo para:

- Completar la [instalación rápida](/docs/intro/installation) usando la terminal
  de Ubuntu (Linux)
- Instalar [Rust](#install-rust), el [CLI de Solana](#install-solana-cli) y el
  [CLI de Anchor](#install-anchor-cli) individualmente, como se describe a
  continuación

<Tabs items={[".deb", ".rpm"]}>
<Tab value=".deb" >
En Debian o en una distribución derivada de Debian, como Ubuntu o Mint:

1. Actualiza las listas de paquetes para asegurar que todos los paquetes estén
   actualizados:

```terminal
$ sudo apt-get update
```

2. Instala las siguientes dependencias:

```terminal
$ sudo apt-get install -y \
    build-essential \
    pkg-config \
    libudev-dev llvm libclang-dev \
    protobuf-compiler libssl-dev
```

<Callout>
Si encuentras el siguiente error al instalar `protobuf-compiler`, ejecuta
`sudo apt-get update` antes de volver a intentar el comando de instalación.

```
Package protobuf-compiler is not available, but is referred to by another package.
This may mean that the package is missing, has been obsoleted, or
is only available from another source
```

</Callout>

  </Tab>

    <Tab value=".rpm" >
    En una distribución basada en RPM, como Fedora o Red Hat Enterprise Linux:

Actualiza los paquetes instalados:

```terminal
$ sudo dnf upgrade --refresh
```

Instala las dependencias de desarrollo:

```terminal
$ sudo dnf group install c-development development-tools \
&& sudo dnf install pkg-config openssl-devel
```

### Instalar Rust

Los desarrolladores crean programas de Solana usando el lenguaje de programación
[Rust](https://www.rust-lang.org/).

1. Instala Rust usando [rustup](https://www.rust-lang.org/tools/install)
   ingresando el siguiente comando en tu terminal:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
```

Después de una instalación exitosa verás el siguiente mensaje:

<Accordions>
<Accordion title="Mensaje de instalación exitosa de Rust">

```
Rust is installed now. Great!

To get started you may need to restart your current shell.
This would reload your PATH environment variable to include
Cargo's bin directory ($HOME/.cargo/bin).

To configure your current shell, you need to source
the corresponding env file under $HOME/.cargo.

This is usually done by running one of the following (note the leading DOT):
. "$HOME/.cargo/env"            # For sh/bash/zsh/ash/dash/pdksh
source "$HOME/.cargo/env.fish"  # For fish
```

</Accordion>
</Accordions>

2. Recarga tu variable de entorno PATH para incluir el directorio bin de
   [Cargo](https://github.com/rust-lang/cargo):

```terminal
$ . "$HOME/.cargo/env"
```

3. Verifica que la instalación fue exitosa.

```terminal
$ rustc --version
```

El comando muestra la versión de Rust instalada, por ejemplo:

```
rustc x.y.z (...)
```

</Step>

### Instalar Solana CLI

El Solana CLI proporciona todas las herramientas necesarias para construir y
desplegar programas de Solana.

1. Instala el conjunto de herramientas de Solana CLI usando el comando de
   instalación oficial:

```terminal
$ sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

<Callout>
  Puedes reemplazar `stable` por una etiqueta de versión específica de Agave o por el canal de versiones `beta`
  o `edge`.
</Callout>

2. Haz que la CLI de Solana esté disponible en tu terminal actual.

El instalador actualiza la configuración de tu shell y muestra el comando necesario
para actualizar la sesión actual. Normalmente, el comando es:

```terminal
$ export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"
```

Si `solana` sigue sin estar disponible, reinicia tu terminal. Para confirmar qué archivo de configuración
del shell actualizó el instalador, comprueba tu shell actual:

```terminal
$ echo $SHELL
```

- Si la salida contiene `/bash`, reinicia la terminal o ejecuta
  `source ~/.bashrc`.
- Si la salida contiene `/zsh`, reinicia la terminal o ejecuta `source ~/.zshrc`.

3. Verifica que la instalación se haya completado correctamente:

```terminal
$ solana --version
```

El comando muestra la versión de la CLI de Solana instalada, por ejemplo:

```
solana-cli x.y.z (..., client:Agave)
```

<Callout>

Puedes ver todas las versiones disponibles en el
[repositorio de Agave en GitHub](https://github.com/anza-xyz/agave/releases). Agave es
el cliente validator de [Anza](https://www.anza.xyz/), anteriormente conocido como
cliente validator de Solana Labs.

</Callout>

4. Para actualizar la CLI de Solana más adelante, ejecuta:

```terminal
$ agave-install update
```

</Step>

### Instalar Anchor CLI

[Anchor](https://www.anchor-lang.com/) es un framework para desarrollar
programas de Solana. El framework Anchor aprovecha las macros de Rust para
simplificar el proceso de escribir programas de Solana.

#### Requisitos previos

Node.js y un gestor de paquetes de JavaScript solo son necesarios cuando seleccionas una
plantilla de pruebas de TypeScript, como Mocha o Jest. La plantilla de pruebas predeterminada de LiteSVM
se ejecuta en Rust y no requiere herramientas de Node.js.

<Accordions>
<Accordion title="Instalación de Node">

1. Instala Node con
   [Node Version Manager (nvm)](https://github.com/nvm-sh/nvm) ejecutando el
   siguiente comando:

```terminal
$ curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```

2. Reinicia tu terminal y confirma que el comando `nvm` se ejecuta correctamente:

```terminal
$ command -v nvm
```

3. Usa `nvm` para instalar Node:

```terminal
$ nvm install --lts
```

4. Verifica que la instalación se haya completado correctamente comprobando la versión de Node:

```terminal
$ node --version
```

El comando muestra la versión de Node.js instalada, por ejemplo:

```
vx.y.z
```

</Accordion>
<Accordion title="Instalación de Yarn">

1. Instala Yarn:

```terminal
$ npm install --global yarn
```

2. Verifica que la instalación se haya completado correctamente comprobando la versión de Yarn:

```terminal
$ yarn --version
```

El comando muestra la versión de Yarn instalada, por ejemplo:

```
x.y.z
```

</Accordion>
</Accordions>

#### Instalación

Puedes instalar la CLI y las herramientas de Anchor de dos maneras:

- Anchor Version Manager (AVM) — Método de instalación recomendado
- Sin AVM — Instalar directamente desde GitHub

<Tabs groupId="anchor" items={["AVM", "Without AVM"]}>
<Tab value="AVM">

El Anchor Version Manager (AVM) te permite instalar y gestionar diferentes
versiones de Anchor en tu sistema y actualizar fácilmente las versiones de
Anchor en el futuro. Para instalar Anchor usando AVM, sigue los pasos a
continuación:

1. Instala AVM con el siguiente comando:

```terminal
$ curl -sSfL https://raw.githubusercontent.com/otter-sec/anchor/master/avm/install | sh
```

2.  Confirma que AVM se instaló correctamente:

```terminal
$ avm --version
```

3. Instala Anchor CLI usando AVM:

Para instalar la última versión:

```terminal
$ avm install latest
$ avm use latest
```

Para instalar una versión específica, especifica el número de versión:

```terminal
$ avm install 1.1.2
$ avm use 1.1.2
```

<Callout type="warn">

Al instalar el Anchor CLI en Linux o WSL, es posible que encuentres este error:

```
error: could not exec the linker cc = note: Permission denied (os error 13)
```

Si ves este mensaje de error, sigue estos pasos:

1. Instala las dependencias indicadas en la sección
   [Linux](/docs/intro/installation/dependencies) en la parte superior de esta
   página.
2. Vuelve a intentar instalar el Anchor CLI.

</Callout>

4. Verifica que la instalación se realizó correctamente, comprobando la versión
   de Anchor CLI:

```terminal
$ anchor --version
```

El comando muestra la versión activa de Anchor CLI, por ejemplo:

```
anchor-cli 1.1.2
```

<Callout type="info">

Ejecuta `avm use` para seleccionar la versión de Anchor CLI para tu sistema.

- Si instalaste la última versión, ejecuta `avm use latest`.
- Si instalaste la versión `1.1.2`, ejecuta `avm use 1.1.2`.

</Callout>

</Tab>

<Tab value="Without AVM">

1. Instala una versión específica de Anchor CLI con el siguiente comando:

```terminal
$ cargo install --git https://github.com/solana-foundation/anchor --tag v1.1.2 anchor-cli --locked
```

2. Verifica que la instalación se haya completado correctamente comprobando la versión de Anchor CLI:

```terminal
$ anchor --version
```

El comando muestra la versión de Anchor CLI instalada, por ejemplo:

```
anchor-cli 1.1.2
```

</Tab>

### Instalar Surfpool CLI

[Surfpool](/docs/tools/surfpool) es una herramienta para el desarrollo local y un
reemplazo mejorado de `solana-test-validator`.

1. Instala Surfpool con el siguiente comando:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://run.surfpool.run/ | bash
```

2. Verifica que la instalación se haya completado correctamente comprobando la versión de Surfpool CLI:

```terminal
$ surfpool --version
```

El comando muestra la versión de Surfpool CLI instalada, por ejemplo:

```
surfpool x.y.z
```

</Step>
