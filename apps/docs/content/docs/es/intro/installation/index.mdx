Configura un entorno de desarrollo local de Solana con el instalador automatizado. Instala
Rust, la CLI de Solana, Anchor CLI, Surfpool CLI, Node.js y Yarn en
macOS, Linux o Windows mediante WSL.

<Callout type="info" title="Windows requiere WSL">
  En Windows PowerShell, ejecuta `wsl --install`, reinicia Windows si se te solicita y luego
  ejecuta los comandos de instalación que aparecen a continuación en la terminal de Ubuntu. Consulta la [guía de
  instalación manual](/docs/intro/installation/dependencies) para ver la
  configuración completa de WSL.
</Callout>

## Instalación rápida

1. Ejecuta el instalador en una terminal de macOS, Linux o WSL:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
```

Puedes
[revisar el código fuente del instalador](https://github.com/solana-developers/solana-install/blob/main/install.sh)
antes de ejecutarlo. El instalador detecta los gestores de paquetes de Linux compatibles e
instala automáticamente sus dependencias del sistema.

2. Reinicia la terminal para que los nuevos comandos estén disponibles en tu `PATH`.

3. Verifica todas las herramientas:

```terminal
$ rustc --version
$ solana --version
$ anchor --version
$ surfpool --version
$ node --version
$ yarn --version
```

Una instalación correcta devuelve una salida con este formato (los números de versión cambian a medida que
se lanzan nuevas versiones de las herramientas):

```txt title="Example output"
Installed Versions:
Rust: rustc x.y.z (...)
Solana CLI: solana-cli x.y.z (..., client:Agave)
Anchor CLI: anchor-cli x.y.z
Surfpool CLI: surfpool x.y.z
Node.js: vx.y.z
Yarn: x.y.z
```

<Callout type="warn" title="El instalador falló o falta un comando">
  Sigue la [guía de instalación manual](/docs/intro/installation/dependencies)
  para instalar cada dependencia o solucionar sus problemas de forma individual.
</Callout>
