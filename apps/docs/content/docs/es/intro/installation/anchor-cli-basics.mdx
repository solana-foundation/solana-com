Esta sección proporciona algunos comandos y ejemplos comunes para ayudarte a
comenzar a usar el [Anchor CLI](https://www.anchor-lang.com/docs).

<Steps>
<Step>

### Inicializar el proyecto

Crea un nuevo proyecto de Anchor ejecutando el comando que se muestra a continuación. Se creará un
nuevo directorio con el nombre del proyecto y se usará para inicializar un nuevo proyecto de
Anchor.

```terminal
$ anchor init <project-name>
```

Por ejemplo, el siguiente comando creará un proyecto llamado `my-project`. El
directorio `my-project` contendrá un programa modular en Rust y una plantilla de pruebas en Rust
que utiliza LiteSVM.

```terminal
$ anchor init my-project
```

Para generar en su lugar una plantilla de pruebas en TypeScript, elígela de forma explícita. Por
ejemplo, usa la plantilla de Mocha:

```terminal
$ anchor init my-project --test-template mocha
```

Las plantillas de pruebas en TypeScript requieren Node.js y un gestor de paquetes de JavaScript.

A continuación, navega al directorio del proyecto:

```terminal
$ cd <project-name>
```

Consulta la
[estructura de archivos del proyecto](https://www.anchor-lang.com/docs/quickstart/local#project-file-structure) de Anchor.

</Step>
<Step>

### Compilar el programa

Para compilar tu proyecto, ejecuta el siguiente comando:

```terminal
$ anchor build
```

Puedes encontrar el programa compilado en el directorio `/target/deploy`.

<Callout type="warn" title="Error al instalar las herramientas de la plataforma">
  Si la compilación informa de un directorio de platform-tools no válido, reinstala las herramientas de
  compilación de SBF y vuelve a intentar la compilación:

```terminal
$ cargo build-sbf --force-tools-install
$ anchor build
```

</Callout>

</Step>
<Step>

### Despliega el programa

Para desplegar tu proyecto, ejecuta el siguiente comando:

```terminal
$ anchor deploy
```

Este comando despliega tu programa en el `cluster` especificado en el archivo
[`Anchor.toml`](https://www.anchor-lang.com/docs/references/anchor-toml).

</Step>
<Step>

### Prueba el programa

Para probar tu proyecto, ejecuta el siguiente comando:

```terminal
$ anchor test
```

Este comando compila, despliega y ejecuta las pruebas de tu proyecto.

<Callout>
  Al usar el clúster `localnet`, Anchor inicia automáticamente un validador
  local, despliega el programa, ejecuta las pruebas y luego detiene el
  validador.
</Callout>

<Callout type="warn" title="Errores del ejecutor de pruebas de JavaScript">

Si seleccionaste una plantilla de pruebas de JavaScript o TypeScript, cualquiera de los
siguientes errores puede indicar que Node.js o el gestor de paquetes configurado no
está instalado:

```
Permission denied (os error 13)
```

```
No such file or directory (os error 2)
```

</Callout>

</Step>
</Steps>
