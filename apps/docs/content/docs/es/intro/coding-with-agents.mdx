## Usando Solana MCP

La forma más poderosa de aprovechar la IA para el desarrollo en Solana es a través del
[Solana Developer MCP](https://mcp.solana.com/) (Model Context Protocol). Esta
integración incorpora conocimiento especializado de Solana directamente en tu IDE, dando
a tus agentes acceso a documentación actualizada de Solana y haciendo el desarrollo
más rápido y eficiente.

## ¿Qué es Solana MCP?

Solana MCP es un asistente de IA especializado que se integra directamente en
IDEs con soporte de IA como Cursor y Windsurf. Cuando haces preguntas específicas
sobre Solana, consulta automáticamente el servidor MCP para proporcionar información
precisa y actualizada desde:

- La [documentación de Solana](/docs)
- La [documentación del Anchor Framework](https://www.anchor-lang.com/docs)
- [Ejemplos de Programas](https://github.com/solana-developers/program-examples) de Solana
- Preguntas y respuestas de [Solana Stack Exchange](https://solana.stackexchange.com/)

## Casos de uso de ejemplo

Puedes usar MCP para:

- Preguntar sobre conceptos de Solana
- Depurar errores de programas
- Obtener recomendaciones de mejores prácticas
- Aprender de ejemplos de expertos
- Desarrollar más rápido con la ayuda de un experto

## Configurar Solana MCP

Encuentra una guía detallada de configuración e introducción en el
[sitio web de Solana MCP](https://mcp.solana.com/).

## ¿Prefieres usar una skill?

Si prefieres usar una skill, instala la skill oficial de Solana con:

```bash
npx skills add https://github.com/solana-foundation/solana-dev-skill
```

Explora más flujos de trabajo reutilizables en la [biblioteca de Solana Agent Skills](/skills).
