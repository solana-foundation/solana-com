Giao diện dòng lệnh `solana` cho phép cấu hình kết nối cluster, đọc trạng thái
mạng, gửi SOL, quản lý durable nonce, triển khai chương trình, và vận hành
các tài khoản stake và vote.

Tài liệu tham khảo này dựa trên
[Agave v4.2.1](https://github.com/anza-xyz/agave/releases/tag/v4.2.1). Chạy
`solana --version` để kiểm tra bản phát hành đã cài đặt và dùng `--help` để xem
chính xác các tùy chọn khả dụng trong phiên bản đó.

<Callout type="warn">
  Các lệnh tạo, chuyển, ủy quyền, rút hoặc triển khai sẽ gửi giao dịch.
  Hãy xác nhận cluster và signer đã cấu hình trước khi chạy.
  Token trên Devnet và Testnet không có giá trị; các lệnh trên Mainnet dùng SOL thật.
</Callout>

## Cấu trúc lệnh

```text
solana [GLOBAL_OPTIONS] <COMMAND> [COMMAND_OPTIONS]
```

Xem trợ giúp ở bất kỳ cấp độ nào:

```shell
solana --help
solana transfer --help
solana address-lookup-table extend --help
```

## Tùy chọn chung

Các tùy chọn chung có thể đặt trước lệnh. Phần trợ giúp riêng của từng lệnh sẽ nhắc lại
các tùy chọn áp dụng cho lệnh đó.

| Tùy chọn                          | Mục đích                                                                        |
| ------------------------------- | ------------------------------------------------------------------------------ |
| `-u, --url <URL_OR_MONIKER>`    | Chọn một URL RPC hoặc `mainnet-beta`, `testnet`, `devnet`, hay `localhost`.      |
| `--ws <URL>`                    | Ghi đè endpoint WebSocket.                                               |
| `-k, --keypair <KEYPAIR>`       | Chọn một tệp keypair, `ASK`, stdin (`-`), hoặc một URL signer được hỗ trợ.          |
| `-C, --config <FILEPATH>`       | Dùng một tệp cấu hình CLI khác.                                        |
| `--commitment <LEVEL>`          | Đọc dữ liệu ở mức commitment `processed`, `confirmed`, hoặc `finalized`.                   |
| `--output <FORMAT>`             | Trả về `json` hoặc `json-compact` ở những lệnh có hỗ trợ.                               |
| `--skip-preflight`              | Gửi mà không mô phỏng qua RPC. Chỉ dùng khi đã hiểu rõ sự đánh đổi về rủi ro thất bại. |
| `--use-tpu-client`              | Gửi giao dịch thông qua TPU client.                                      |
| `--no-address-labels`           | In địa chỉ mà không kèm nhãn cục bộ.                                          |
| `--skip-seed-phrase-validation` | Cho phép dùng cụm từ khôi phục nằm ngoài danh sách tiếng Anh của BIP39.                       |
| `-v, --verbose`                 | Hiển thị thêm thông tin đầu ra của lệnh.                                                |
| `-V, --version`                 | In phiên bản CLI đã cài đặt.                                               |

## Cấu hình CLI

```shell
# Inspect the effective configuration.
solana config get

# Use Devnet and a specific signer by default.
solana config set --url devnet
solana config set --keypair ./devnet-keypair.json

# Override defaults for one command.
solana --url mainnet-beta --keypair usb://ledger address
```

Cấu hình bao gồm URL RPC, URL WebSocket, signer mặc định và
commitment. Một tùy chọn dòng lệnh sẽ ghi đè giá trị đã lưu cho lần gọi đó.

## Quy trình tài khoản và giao dịch thông dụng

```shell
# Print the default signer's address and balance.
solana address
solana balance

# Read an account as JSON.
solana account <ACCOUNT_ADDRESS> --output json

# Request Devnet SOL.
solana airdrop 1 --url devnet

# Send SOL and then confirm the returned signature.
solana transfer <RECIPIENT_ADDRESS> 0.1 --allow-unfunded-recipient
solana confirm <TRANSACTION_SIGNATURE>

# Inspect recent activity and stream logs mentioning an address.
solana transaction-history <ADDRESS> --limit 20
solana logs <ADDRESS>
```

`transfer` mặc định chuyển SOL. Dùng `ALL` làm số lượng để chuyển toàn bộ số dư
khả dụng sau khi trừ phí. Với các ví dụ về token, xem
[hướng dẫn nhanh về token](/docs/tokens/quickstart).

## Quy trình làm việc với chương trình

```shell
# Deploy or upgrade an SBF program.
solana program deploy ./target/deploy/my_program.so

# Inspect the deployed program and list programs controlled by the signer.
solana program show <PROGRAM_ID>
solana program show --programs

# Close a program buffer and recover its lamports.
solana program close <BUFFER_ADDRESS>
```

Truyền `--program-id <KEYPAIR_OR_ADDRESS>` khi một lần triển khai phải dùng
program ID đã biết. `--final` khiến bản triển khai mới trở nên bất biến; hãy đọc kỹ phần trợ giúp
trước khi dùng vì không thể khôi phục lại upgrade authority.

## Quy trình làm việc với durable nonce

```shell
solana-keygen new --outfile nonce-account.json
solana create-nonce-account nonce-account.json 0.1
solana nonce nonce-account.json
solana new-nonce nonce-account.json
solana withdraw-from-nonce-account nonce-account.json <RECIPIENT_ADDRESS> ALL
```

Dùng `authorize-nonce-account` để thay đổi nonce authority và `nonce-account`
để xem toàn bộ trạng thái tài khoản. Các giao dịch dùng nonce cũng chấp nhận
`--nonce` và `--nonce-authority` ở những lệnh được hỗ trợ.

## Quy trình làm việc với stake

```shell
solana-keygen new --outfile stake-account.json
solana create-stake-account stake-account.json 1
solana delegate-stake stake-account.json <VOTE_ACCOUNT_ADDRESS>
solana stake-account stake-account.json

solana deactivate-stake stake-account.json
solana withdraw-stake stake-account.json <RECIPIENT_ADDRESS> ALL
```

Việc hủy kích hoạt hoàn tất tại ranh giới epoch và có thể mất hơn một epoch.
Dùng `stakes`, `validators`, `stake-history` và `stake-minimum-delegation` để
kiểm tra trạng thái cluster và ủy thác trước khi gửi các thay đổi.

## Tiện ích địa chỉ

```shell
# Derive a PDA from typed seeds.
solana find-program-derived-address \
  <PROGRAM_ID> \
  string:profile \
  pubkey:<OWNER_ADDRESS>

# Create and extend an address lookup table.
solana address-lookup-table create
solana address-lookup-table extend \
  <LOOKUP_TABLE_ADDRESS> \
  --addresses <ADDRESS_1>,<ADDRESS_2>
```

Các seed của PDA dùng định dạng `PREFIX:VALUE`. Các tiền tố được hỗ trợ gồm `string`, `pubkey`,
`hex`, `u8`, và các kiểu mã hóa số nguyên có dấu hoặc không dấu với độ rộng cố định như
`u64le`.

## Thông điệp off-chain và tự động hoàn thành lệnh trong shell

```shell
solana sign-offchain-message "terms accepted"
solana verify-offchain-signature \
  "terms accepted" \
  <SIGNATURE> \
  --signer <SIGNER_ADDRESS>

# Print a completion script for the current shell.
solana completion --shell zsh
```

## Danh mục lệnh đầy đủ

Danh mục sau đây bao gồm mọi lệnh cấp cao nhất trong Agave v4.2.1. Các lệnh
như `program`, `config`, `feature` và `address-lookup-table` chứa
các lệnh lồng bên trong; hãy chạy `<command> --help` để liệt kê chúng.

| Lệnh                             | Mô tả                                                                       |
| ----------------------------------- | --------------------------------------------------------------------------------- |
| `account`                           | Hiển thị lamport, chủ sở hữu, dữ liệu và trạng thái thực thi của một tài khoản.                    |
| `address`                           | In khóa công khai của signer đã chọn.                                           |
| `address-lookup-table`              | Tạo, mở rộng, đóng băng, hủy kích hoạt, đóng và kiểm tra các bảng tra cứu địa chỉ.     |
| `airdrop`                           | Yêu cầu SOL từ faucet của cluster.                                                |
| `alpenglow-genesis-info`            | Đọc thông tin về chứng chỉ genesis của Alpenglow.                         |
| `authorize-nonce-account`           | Gán authority cho tài khoản durable nonce.                                         |
| `balance`                           | Hiển thị số dư SOL của một tài khoản.                                                    |
| `block`                             | Lấy một block đã xác nhận theo slot.                                                  |
| `block-height`                      | Hiển thị chiều cao block hiện tại.                                                    |
| `block-production`                  | Hiển thị lượng block do leader tạo ra trong một khoảng slot.                                    |

## Đầu ra cho tập lệnh

Hãy dùng `--output json` hoặc `--output json-compact` ở những lệnh có hỗ trợ thay vì
phân tích cú pháp đầu ra dành cho người đọc:

```shell
solana epoch-info --output json
solana account <ACCOUNT_ADDRESS> --output json-compact
solana validators --output json > validators.json
```

Không phải lệnh nào cũng hỗ trợ đầu ra có cấu trúc. Hãy kiểm tra phần trợ giúp của lệnh trước khi
phụ thuộc vào nó trong tự động hóa, và coi mã thoát khác không là thất bại.
