# Làm việc với LLM và Tác nhân trên Solana

Trước khi đi sâu vào các công cụ cụ thể, hãy cùng tìm hiểu các thành phần chính trong
ngăn xếp phát triển AI:

## Tìm hiểu về Ngăn xếp AI

1. **Mô hình Ngôn ngữ Lớn (LLM)**
   - Các mô hình AI nền tảng (như GPT-4, Claude hoặc Llama)
   - Xử lý và tạo ra ngôn ngữ tự nhiên
   - Cung cấp khả năng trí tuệ và suy luận thuần túy
   - Ví dụ: GPT-4 của OpenAI, Claude của Anthropic, Llama của Meta

2. **Các Framework Tác nhân (như Eliza)**
   - Được xây dựng trên nền tảng LLM để tạo ra các tác nhân tự chủ
   - Quản lý tính cách và hành vi của tác nhân
   - Xử lý bộ nhớ và ngữ cảnh
   - Cung cấp tích hợp đa nền tảng
   - Ví dụ: Eliza, LangChain, AutoGPT, Vercel AI

3. **Bộ công cụ Tác nhân Chuyên biệt (như Solana Agent Kit)**
   - Được xây dựng cho các trường hợp sử dụng cụ thể (ví dụ: các thao tác blockchain)
   - Cung cấp các công cụ và tích hợp dựng sẵn
   - Giảm thiểu sự phức tạp kỹ thuật
   - Các hàm blockchain sẵn sàng sử dụng
   - Ví dụ: Solana Agent Kit, GOAT Toolkit

Hãy nghĩ về nó theo cách này:

- LLM là "bộ não" có thể hiểu và tạo ra ngôn ngữ
- Các framework tác nhân là "hệ điều hành" quản lý hành vi của AI
- Các bộ công cụ chuyên biệt là "ứng dụng" cung cấp cho AI các khả năng cụ thể

# Xây dựng Tác nhân AI cho Solana

Hướng dẫn này sẽ chỉ cho bạn cách:

- Xây dựng một tác nhân AI cơ bản sử dụng Solana Agent Kit của SendAI
- Tạo một bot Twitter với Eliza Framework
- Tìm hiểu các tùy chọn tích hợp AI onchain
- Các tùy chọn để xây dựng bot giao dịch nâng cao

## Giới thiệu về Tác nhân AI trên Solana

Các tác nhân AI trên Solana là các chương trình tự chủ có thể tương tác với
blockchain bằng cách sử dụng xử lý ngôn ngữ tự nhiên và học máy. Chúng có thể:

- Thực thi các giao dịch
- Theo dõi hoạt động blockchain
- Tương tác với hợp đồng thông minh
- Hỗ trợ người dùng
- Tự động hóa các quy trình làm việc phức tạp

## Các Framework Hiện có

Có một số framework để xây dựng tác nhân AI trên Solana:

1. **Solana Agent Kit của SendAI**

- Một bộ sưu tập công cụ để xây dựng tác nhân trên Solana
- Tương thích với Eliza, Langchain và Vercel AI SDK
- Các công cụ và tiện ích Solana tích hợp sẵn
- Khả năng xử lý ngôn ngữ tự nhiên
- [Solana Agent Kit](https://github.com/sendaifun/solana-agent-kit)
- [Tài liệu](https://docs.solanaagentkit.xyz/)

2. **Eliza Framework**

- Kết hợp lớp dữ liệu, llm và tác nhân, đồng thời có một plugin Solana chuyên dụng
- Kiến trúc tác nhân có thể mở rộng
- Dễ dàng tích hợp với các dự án hiện có và có thể được sử dụng ví dụ cho
  các bot Twitter (X), telegram hoặc discord
- [Kho lưu trữ GitHub](https://github.com/elizaOS/eliza)

3. **GOAT Toolkit**

- Bộ công cụ phát triển toàn diện
- Tương thích đa chuỗi
- [Kho lưu trữ GitHub](https://github.com/goat-sdk/goat)

4. **Rig Framework**

- Triển khai Rust gốc
- Phù hợp cho các bot giao dịch hiệu suất cao
- Có thể kết hợp với bộ công cụ Listen.rs để tích hợp Solana, theo dõi giao dịch
  và gửi giao dịch bằng các bundle Jito chẳng hạn
- [Kho lưu trữ GitHub](https://github.com/0xPlaygrounds/rig)
- [Kho lưu trữ Listen.rs](https://github.com/piotrostr/listen)

Nếu bạn đang xây dựng một framework AI, hãy thoải mái mở một PR để thêm framework của bạn
vào danh sách

<Step>
### Tạo script tác nhân

Tạo một file mới có tên `agent.ts` với nội dung sau:

```typescript filename=agent.ts
import { SolanaAgentKit, createSolanaTools } from "solana-agent-kit";
import { HumanMessage } from "@langchain/core/messages";
import { ChatOpenAI } from "@langchain/openai";
import { createReactAgent } from "@langchain/langgraph/prebuilt";
import { MemorySaver } from "@langchain/langgraph";
import * as dotenv from "dotenv";
import bs58 from "bs58";
import * as readline from "readline";

dotenv.config();

async function initializeAgent() {
  const llm = new ChatOpenAI({
    modelName: "gpt-4-turbo-preview",
    temperature: 0.7
  });

  // Convert array string to actual array, then to Uint8Array, then to base58
  const privateKeyArray = JSON.parse(process.env.SOLANA_PRIVATE_KEY!);
  const privateKeyUint8 = new Uint8Array(privateKeyArray);
  const privateKeyBase58 = bs58.encode(privateKeyUint8);

  const solanaKit = new SolanaAgentKit(privateKeyBase58, process.env.RPC_URL!, {
    OPENAI_API_KEY: process.env.OPENAI_API_KEY!
  });

  const tools = createSolanaTools(solanaKit);
  const memory = new MemorySaver();

  return createReactAgent({
    llm,
    tools,
    checkpointSaver: memory
  });
}

async function runInteractiveChat() {
  const agent = await initializeAgent();
  const config = { configurable: { thread_id: "Solana Agent Kit!" } };
  const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout
  });

  // Clear console and start chat with a small delay
  setTimeout(() => {
    console.clear(); // Clear any initialization messages
    console.log("Chat with Solana Agent (type 'exit' to quit)");
    console.log("--------------------------------------------");
    askQuestion();
  }, 100);

  const askQuestion = () => {
    rl.question("You: ", async (input) => {
      if (input.toLowerCase() === "exit") {
        rl.close();
        return;
      }

      const stream = await agent.stream(
        {
          messages: [new HumanMessage(input)]
        },
        config
      );

      process.stdout.write("Agent: ");
      for await (const chunk of stream) {
        if ("agent" in chunk) {
          process.stdout.write(chunk.agent.messages[0].content);
        } else if ("tools" in chunk) {
          process.stdout.write(chunk.tools.messages[0].content);
        }
      }
      console.log("\n--------------------------------------------");

      askQuestion(); // Continue the conversation
    });
  };
}

runInteractiveChat().catch(console.error);
```

</Step>

## Xây dựng với Eliza Framework

[ElizaOS](https://github.com/elizaOS/eliza) (trước đây được gọi là Ai16z) là một
framework AI. Điều đó có nghĩa là nó kết hợp nhiều ứng dụng thành một và
tổ chức các tương tác của chúng. Nó kết hợp:

1. Nhiều LLM khác nhau để hiểu người dùng
2. Các tác nhân blockchain với các hành động khác nhau (ví dụ như đúc NFT)
3. Các lớp dữ liệu để lưu trữ trạng thái của nhân vật giữa các hành động bằng cách sử dụng ví dụ
   Redis, PostgreSQL DB hoặc bộ nhớ cục bộ
4. Các client khác nhau như X, telegram, discord, v.v.

Nó tập hợp tất cả những thứ này lại với nhau theo cách cho phép bạn tạo ra một
"Nhân vật" có thể tương tác với người dùng hoặc hoạt động tự chủ. Các Nhân vật này được
định nghĩa trong một file JSON, xác định các hành động nó có thể thực hiện, LLM nào nó
nên sử dụng và các prompt khác nhau định nghĩa hành vi của nhân vật.

Nếu bạn có khóa riêng tư ở định dạng hex, bạn có thể mã hóa base58 khóa riêng tư
của mình bằng đoạn js sau:

```ts filename=encode58.ts
const bs58 = require('bs58');
console.log(bs58.encode(new Uint8Array([213,29,143,...])));
```

Và chạy nó bằng

```bash
npx tsx encode58.ts
```

### Tạo cấu hình nhân vật

Để tạo một nhân vật mới, chúng ta cần tạo một file character.json. Bạn có thể tìm thấy
các nhân vật có sẵn trong thư mục characters của dự án Eliza. Để tạo một
nhân vật mới, bạn có thể sao chép và thay đổi một trong những nhân vật đã có sẵn hoặc
bạn có thể sử dụng
[tính năng composer trong Cursor](https://docs.cursor.com/composer/overview) và cho nó biết
bạn muốn tạo loại nhân vật nào.

```json filename=characters/sol.character.json
{
    "name": "Sol",
    "clients": ["twitter"],
    "modelProvider": "openai",
    "settings": {
        "voice": {
            "model": "en_US-neural"
        },
        ...
```

Phần quan trọng ở đây là clients và modelProvider. Trong trường hợp của chúng ta
chúng ta muốn sử dụng twitter làm client và openai làm nhà cung cấp mô hình vì đây là
những gì chúng ta cũng đã thiết lập secrets trong file `.env`.

### Chạy tác nhân

Bây giờ khi cấu hình đã hoàn tất, chúng ta có thể chạy nhân vật của mình:

```bash
pnpm start --character="characters/sol.character.json"
```

Điều này sẽ khởi động tác nhân và bây giờ bạn có thể tương tác với nó trên twitter. Nhân vật
sẽ tự động bắt đầu đăng tweet vài giờ một lần và khi chúng ta
tương tác với nó, nó sẽ có thể thực hiện các hành động solana như đúc NFT
chẳng hạn.

Ở đây bạn có thể xem
[nhân vật đang hoạt động](https://x.com/solanadevhelper/status/1882222232656847143).

Bạn cũng có thể tương tác với nhân vật cục bộ bằng lệnh sau:
Bạn có thể cần giải phóng cổng 3000 và khởi động nhân vật của bạn với cờ `--host`.

```bash
pnpm start --character="characters/sol.character.json" --host
pnpm start:client
```

Nếu client của bạn không kết nối được, hãy đảm bảo bạn chạy tác nhân với cờ `--host`
và cổng 3000 của bạn không bị sử dụng khi bạn khởi động client.

Để biết thêm thông tin, hãy theo dõi
[tài liệu eliza chính thức](https://elizaos.github.io/eliza/docs/quickstart/)

</Steps>

## Tích hợp tác nhân chương trình onchain

Nếu bạn muốn sử dụng phản hồi của agent trong một chương trình Solana, bạn cần dùng một
oracle ghi dữ liệu phản hồi vào một tài khoản mà chương trình của bạn có thể đọc.
Bạn có thể tìm thấy ví dụ về một LLM sẽ chuyển token cho bất kỳ người dùng nào
trả lời đúng câu hỏi tại đây:

[Tương tác LLM với chương trình trên chuỗi](https://github.com/GabrielePicco/super-smart-contracts)

Đây là ví dụ về một chương trình onchain tích hợp với oracle LLM (AI)
để tạo ra một agent phân phối token tương tác có tên là "Mar1o".

### Tính năng chính

1. **Tương tác với AI Agent**
   - Người dùng có thể trò chuyện với Mar1o để cố gắng kiếm token
   - Agent đánh giá kiến thức Solana của người dùng để quyết định số lượng token
   - Phản hồi ở định dạng JSON với nội dung trả lời và số lượng token

2. **Quản lý Token**
   - Tạo token MAR1O kèm metadata
   - Có thể đúc từ 0 đến 10.000 token dựa trên phản hồi của AI
   - Sử dụng PDA để quản lý token

### Giải thích luồng hoạt động của chương trình

Đây là cách chương trình này hoạt động:

```rust
// Initialize the AI agent with personality
const AGENT_DESC: &str = "You are an AI agent called Mar1o which can dispense MAR1O tokens...";

// User interaction flow:
// 1. User sends message to agent
// 2. Oracle processes with LLM
// 3. Agent responds with JSON containing reply and amount
// 4. If amount > 0, tokens are minted to user

// Example response:
{
    "reply": "Great answer! Here's a reward.",
    "amount": 1000
}
```

Đây minh họa cách kết hợp khả năng AI với cơ chế token onchain để
tạo ra các trải nghiệm blockchain tương tác. Đây là
[ví dụ trực tiếp](https://mar1o.xyz/) nơi bạn có thể thử thuyết phục Agent
chuyển cho bạn một số token.

## Agent Rust nâng cao cho giao dịch thuật toán

Nếu bạn muốn viết các agent của mình bằng Rust, bạn có thể sử dụng
[framework Rig](https://github.com/0xPlaygrounds/rig) và thư viện
[Listen.rs](https://github.com/piotrostr/listen).

Hai công cụ này hoạt động rất tốt khi kết hợp với nhau. Trong khi framework Rig cung cấp cho bạn cách dễ dàng để
kết nối với các LLM, bộ công cụ Listen.rs cung cấp tích hợp Solana
bao gồm giám sát giao dịch và gửi giao dịch sử dụng Jito bundles
chẳng hạn.

## Các thực hành tốt nhất

- Hãy lưu ý rằng agent của bạn có khóa riêng và do đó có thể truy cập các quỹ trong
  ví của bạn. Nếu ai đó có thể trò chuyện với agent của bạn và nó có hành động chuyển tiền
  chẳng hạn, người dùng có thể khiến nó chuyển quỹ của bạn cho họ.
- Sử dụng [RPC endpoint](https://solana.com/rpc) trả phí. Các endpoint công khai
  thường bị giới hạn tốc độ
- Giám sát hoạt động của agent và đảm bảo chúng không thực hiện bất kỳ hành động độc hại nào
  hoặc bị người dùng tương tác lừa vào việc đó
- Triển khai phí ưu tiên và thử lại giao dịch cho các hành động của agent để
  chúng cũng được thực thi khi mạng bị tắc nghẽn
- Nếu có thể, hãy thử nghiệm trên devnet trước khi triển khai lên mainnet. Hầu hết các agent
  chỉ nhận URL RPC làm đầu vào và bạn có thể dùng URL devnet cho đến khi bạn
  sẵn sàng cho mainnet. Tuy nhiên, không phải tất cả các hành động đều có thể thực hiện trên devnet.
- Khi viết các hành động của riêng bạn, hãy thêm các bài kiểm tra tích hợp cho chúng để
  các framework có thể theo dõi những hành động nào đang thất bại do chương trình hoặc
  API đã thay đổi

## Kết luận

Các AI agent trên Solana mở ra những khả năng mới cho tự động hóa và tương tác
với blockchain. Mặc dù chưa phải tất cả các tích hợp đều hoàn hảo, chúng đang
được phát triển nhanh chóng và mang lại nhiều cơ hội đóng góp, đồng thời rất
linh hoạt trong việc thêm các tích hợp của riêng bạn.
