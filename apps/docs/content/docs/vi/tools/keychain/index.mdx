**Solana Keychain cung cấp một giao diện thống nhất để ký các giao dịch Solana
trên nhiều backend quản lý khóa.** Phát triển cục bộ với khóa lưu trong bộ nhớ,
sau đó chuyển sang quản lý khóa doanh nghiệp, HSM trên đám mây hoặc dịch vụ ví
được quản lý trong môi trường production mà không cần viết lại mã ký của bạn.

### Tại sao nên dùng Keychain?

- **Một giao diện duy nhất**: Một giao diện cơ sở `SolanaSigner` cho mọi backend,
  cộng với một khả năng (capability) cho mỗi backend: ký, viết lại và ký, hoặc ký và phát sóng
- **Hoán đổi backend**: Thay đổi nhà cung cấp quản lý khóa thông qua cấu hình; các
  điểm gọi chỉ thay đổi khi backend mới có capability khác (chế độ native của Crossmint
  và Fordefi)
- **Chỉ trả cho những gì bạn dùng**: Các feature flag của Rust, gói npm riêng cho từng backend, extras của Python
  và module Go riêng cho từng backend chỉ bao gồm những backend bạn cần
- **Đã được kiểm toán**: Rust, TypeScript, Python và Go đã được
  [OtterSec](https://osec.io) kiểm toán (backend Ledger tùy chọn nằm ngoài phạm vi); một
  cuộc kiểm toán trước đó của [Accretion](https://accretion.xyz) đã bao quát Rust và TypeScript.
  Xem
  [trạng thái kiểm toán](https://github.com/solana-foundation/solana-keychain/blob/main/audits/AUDIT_STATUS.md).

### Kiến trúc

- **Ngôn ngữ**: Rust, TypeScript, Python và Go, với tính năng tương đương (backend Ledger
  chỉ có trên Rust)
- **Giao diện**: Giao diện cơ sở `SolanaSigner` (`pubkey`, `sign_message`, `is_available`)
  cộng với đúng một capability cho mỗi backend: `TransactionSigner`,
  `ModifyingSigner` hoặc `SendingSigner`
- **Backend**: Memory, Vault, AWS KMS, GCP KMS, Privy, Turnkey, Fireblocks,
  CDP, Crossmint, Dfns, Openfort, Para, Utila, Fordefi, Ledger (chỉ Rust,
  tùy chọn, chưa được kiểm toán)
- **Khả năng tương thích**: `@solana/kit` và `@solana/signers` 8.1+ (TypeScript) |
  `solana-sdk` 2.x, 3.x hoặc 4.x thông qua các feature `sdk-v2` / `sdk-v3` / `sdk-v4`
  (Rust; giao dịch v1 cần `sdk-v4`) | `solders` (Python) | `solana-go` v2
  (Go)

### Các Backend được hỗ trợ

Các backend bao gồm môi trường phát triển cục bộ, quản lý khóa tự lưu trữ và
trên đám mây, cũng như các dịch vụ ví được quản lý hoặc MPC. Xem
[Chọn backend](/docs/tools/keychain/choosing-a-backend) để so sánh các mô hình
lưu ký và chọn mô hình phù hợp.

| Backend         | Trường hợp sử dụng                            | Rust | TypeScript | Python | Go  |
| --------------- | ----------------------------------- | ---- | ---------- | ------ | --- |
| Memory          | Phát triển, kiểm thử                | ✓    | ✓          | ✓      | ✓   |
| HashiCorp Vault | Quản lý khóa tự lưu trữ          | ✓    | ✓          | ✓      | ✓   |
| AWS KMS         | Cloud-native (AWS)                  | ✓    | ✓          | ✓      | ✓   |
| GCP KMS         | Cloud-native (GCP)                  | ✓    | ✓          | ✓      | ✓   |
| Privy           | Ví nhúng                    | ✓    | ✓          | ✓      | ✓   |
| Turnkey         | Quản lý khóa không lưu ký        | ✓    | ✓          | ✓      | ✓   |
| Fireblocks      | Lưu ký tổ chức               | ✓    | ✓          | ✓      | ✓   |
| CDP             | Coinbase Developer Platform         | ✓    | ✓          | ✓      | ✓   |
| Crossmint       | Ví được quản lý bởi Crossmint           | ✓    | ✓          | ✓      | ✓   |
| Dfns            | Hạ tầng ví Dfns          | ✓    | ✓          | ✓      | ✓   |
| Openfort        | Ví backend Openfort            | ✓    | ✓          | ✓      | ✓   |
| Para            | Ví MPC Para                    | ✓    | ✓          | ✓      | ✓   |
| Utila           | Lưu ký MPC Utila                   | ✓    | ✓          | ✓      | ✓   |
| Fordefi         | Fordefi MPC custody                 | ✓    | ✓          | ✓      | ✓   |
| Ledger          | Ví phần cứng (tùy chọn, chưa được kiểm toán) | ✓    |            |        |     |

## Bắt Đầu Nhanh

### Rust

Cài đặt Rust crate:

```bash
cargo add solana-keychain
```

Cách sử dụng cơ bản:

```rust
use solana_keychain::{Signer, SolanaSigner};

// Create a signer from any backend
let signer = Signer::from_memory("base58_private_key")?;
let pubkey = signer.pubkey();

// Transaction signing is a capability; `tx` is a VersionedTransaction
if let Some(tx_signer) = signer.as_transaction_signer() {
    let result = tx_signer.sign_transaction(&mut tx).await?;
}

// Or let the umbrella route any backend shape and supply the RPC hop yourself
let signature = signer
    .sign_and_send(&mut tx, |encoded| async move { broadcast(encoded).await })
    .await?;
```

- [Hướng Dẫn Rust](/docs/tools/keychain/getting-started/rust) - Cài đặt đầy đủ
  và cấu hình backend
- [Crates.io](https://crates.io/crates/solana-keychain) - Rust crate

### TypeScript

Cài đặt gói TypeScript:

```bash
pnpm add @solana/keychain
```

Cách sử dụng cơ bản:

```typescript
import { createKeychainSigner } from "@solana/keychain";
import { signTransactionWithSigners } from "@solana/signers";

// Create any signer via the unified factory
const signer = await createKeychainSigner({
  backend: "vault",
  vaultAddr: "https://vault.example.com:8200",
  vaultToken: "hvs.xxxxx",
  keyName: "my-solana-key",
  publicKey: "base58_public_key"
});

// Sign an already-compiled transaction
const signedTx = await signTransactionWithSigners(
  [signer],
  compiledTransaction
);
```

- [Hướng Dẫn TypeScript](/docs/tools/keychain/getting-started/typescript) - Các
  gói `@solana/keychain`
- [Gói npm](https://www.npmjs.com/package/@solana/keychain) - gói npm

Để cài đặt một signer Keychain trên client [Kit](https://github.com/anza-xyz/kit)
làm `payer` hoặc `identity`, hãy dùng `@solana/keychain-kit-plugin` (chế độ native của Crossmint và
Fordefi bị loại trừ vì chúng viết lại giao dịch).

### Python

Cài đặt gói (các backend nặng hơn được cung cấp dưới dạng extras, ví dụ
`solana-keychain[aws-kms]`):

```bash
pip install solana-keychain
```

Cách sử dụng cơ bản:

```python
import os

from solana_keychain import VaultSignerConfig, create_vault_signer

signer = await create_vault_signer(
    VaultSignerConfig(
        api_base_url="https://vault.example.com:8200",
        token=os.environ["VAULT_TOKEN"],
        key_name="my-solana-key",
        public_key="base58_public_key",
    )
)

# tx is a solders VersionedTransaction
result = await signer.sign_transaction(tx)
```

- [Hướng dẫn Python](/docs/tools/keychain/getting-started/python) - Cài đặt đầy đủ,
  extras và cấu hình backend
- [PyPI](https://pypi.org/project/solana-keychain/) - Gói Python

### Go

Mỗi backend là một module Go riêng, nên bạn chỉ kéo về những backend mà bạn import:

```bash
go get github.com/solana-foundation/solana-keychain/go/signers/vault/v2@latest
```

Cách sử dụng cơ bản:

```go
import "github.com/solana-foundation/solana-keychain/go/signers/vault/v2"

signer, err := vault.New(vault.Config{
	VaultAddr: "https://vault.example.com:8200",
	Token:     os.Getenv("VAULT_TOKEN"),
	KeyName:   "my-solana-key",
	Pubkey:    "base58_public_key",
})
if err != nil {
	return err
}

// tx is a *solana.Transaction from solana-go v2
res, err := signer.SignTransaction(ctx, tx)
```

- [Hướng dẫn Go](/docs/tools/keychain/getting-started/go) - Module, capability
  và cấu hình backend
- [pkg.go.dev](https://pkg.go.dev/github.com/solana-foundation/solana-keychain/go/core/v2) -
  Tài liệu tham khảo Go
