## Tham khảo nhanh

### Khởi tạo handle

```go
import (
    litesvm "github.com/LiteSVM/litesvm-go"
    solana "github.com/gagliardetto/solana-go"
)

svm, err := litesvm.New()
if err != nil {
    // handle error
}
defer svm.Close()
```

### Quản lý tài khoản

| Phương thức                                                                       | Mô tả                                          |
| ---------------------------------------------------------------------------- | ---------------------------------------------------- |
| `Airdrop(pubkey, lamports) error`                                            | Nạp tiền cho một tài khoản                                      |
| `Balance(pubkey) (uint64, bool, error)`                                      | Số dư SOL; bool cho biết tài khoản có tồn tại hay không |
| `GetAccount(pubkey) *Account`                                                | Lấy handle tài khoản (nil nếu không tìm thấy)          |
| `SetAccount(pubkey, *Account) error`                                         | Lưu trạng thái tài khoản trực tiếp                         |
| `MinimumBalanceForRentExemption(dataLen int) (uint64, error)`                | Tính toán số dư tối thiểu miễn rent                          |
| `NewAccount(lamports, data, owner, executable, rentEpoch) (*Account, error)` | Tạo handle Account cho SetAccount               |

### Quản lý chương trình

| Phương thức                                                   | Mô tả                             |
| -------------------------------------------------------- | --------------------------------------- |
| `AddProgram(programID, bytes) error`                     | Tải chương trình từ bytes                 |
| `AddProgramFromFile(programID, path) error`              | Tải chương trình từ tệp `.so`            |
| `AddProgramWithLoader(programID, bytes, loaderID) error` | Tải với loader cụ thể (nâng cao) |

### Giao dịch

| Phương thức                                                                        | Mô tả                                                                     |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| `SendLegacyTransaction(txBytes) (*TxOutcome, error)`                          | Thực thi giao dịch legacy                                                    |
| `SendVersionedTransaction(txBytes) (*TxOutcome, error)`                       | Thực thi giao dịch v0+                                                       |
| `SimulateLegacyTransaction(txBytes) (*TxOutcome, error)`                      | Mô phỏng mà không thay đổi trạng thái                                                  |
| `SimulateVersionedTransaction(txBytes) (*TxOutcome, error)`                   | Mô phỏng v0+ mà không thay đổi trạng thái                                              |
| `LatestBlockhash() (solana.Hash, error)`                                      | Blockhash hiện tại                                                               |
| `ExpireBlockhash() error`                                                     | Chuyển sang blockhash mới                                                      |
| `GetTransaction(signature) *TxOutcome`                                        | Tra cứu giao dịch trong lịch sử (nil nếu không có)                                  |
| `litesvm.BuildTransferTx(payerSeed, to, lamports, blockhash) ([]byte, error)` | Hàm trợ giúp kiểm thử tạo giao dịch chuyển legacy đã ký mà không cần import `solana-go` |

### Cấu hình

| Phương thức                                         | Mô tả                                             |
| ---------------------------------------------- | ------------------------------------------------------- |
| `SetSigverify(bool) error`                     | Bật / tắt xác minh chữ ký                 |
| `Sigverify() (bool, error)`                    | Đọc cài đặt hiện tại                                |
| `SetBlockhashCheck(bool) error`                | Bật / tắt xác thực blockhash                   |
| `SetTransactionHistory(int) error`             | Dung lượng lịch sử giao dịch trong bộ nhớ (0 để tắt)           |
| `SetLogBytesLimit(int) error`                  | Giới hạn byte log mỗi giao dịch (âm = không giới hạn)              |
| `SetLamports(uint64) error`                    | Số lamport mặc định cho các tài khoản airdrop-pool mới          |
| `SetSysvars() error`                           | Đặt lại sysvar về mặc định                               |
| `SetBuiltins() error`                          | Tải lại các chương trình tích hợp sẵn                                |
| `SetDefaultPrograms() error`                   | Tải lại SPL Token, Memo, v.v.                            |
| `SetPrecompiles() error`                       | Bật precompile ed25519 / secp256k1                  |
| `WithNativeMints() error`                      | Seed mint wrapped-SOL                                   |
| `SetFeatureSet(*FeatureSet) error`             | Cài đặt bộ feature gate                              |
| `SetComputeBudget(ComputeBudget) error`        | Áp dụng ngân sách tính toán                                  |
| `ComputeBudget() (ComputeBudget, bool, error)` | Đọc ngân sách hiện tại (bool cho biết "đã đặt rõ ràng") |

### Thời gian và Sysvar

| Phương thức                                       | Mô tả                          |
| -------------------------------------------- | ------------------------------------ |
| `WarpToSlot(slot uint64) error`              | Nhảy đến một slot cụ thể              |
| `Clock() (Clock, error)`                     | Đọc sysvar Clock                |
| `SetClock(Clock) error`                      | Ghi đè sysvar Clock           |
| `Rent() (Rent, error)`                       | Đọc sysvar Rent                 |
| `SetRent(Rent) error`                        | Ghi đè sysvar Rent            |
| `EpochSchedule() (EpochSchedule, error)`     | Đọc sysvar EpochSchedule        |
| `SetEpochSchedule(EpochSchedule) error`      | Ghi đè sysvar EpochSchedule   |
| `EpochRewards() (EpochRewards, error)`       | Đọc sysvar EpochRewards         |
| `SetEpochRewards(EpochRewards) error`        | Ghi đè sysvar EpochRewards    |
| `LastRestartSlot() (uint64, error)`          | Đọc last-restart-slot               |
| `SetLastRestartSlot(uint64) error`           | Đặt last-restart-slot                |
| `SlotHashes() ([]SlotHash, error)`           | Đọc sysvar SlotHashes           |
| `SetSlotHashes([]SlotHash) error`            | Ghi đè sysvar SlotHashes      |
| `SlotHistory() (*SlotHistory, error)`        | Đọc sysvar SlotHistory (handle) |
| `SetSlotHistory(*SlotHistory) error`         | Ghi đè sysvar SlotHistory     |
| `StakeHistory() ([]StakeHistoryItem, error)` | Đọc sysvar StakeHistory         |
| `SetStakeHistory([]StakeHistoryItem) error`  | Ghi đè sysvar StakeHistory    |

### Tiện ích

| Phương thức                     | Mô tả                                                    |
| -------------------------- | -------------------------------------------------------------- |
| `litesvm.Version() string` | Chuỗi phiên bản được báo cáo bởi crate Rust `litesvm` bên dưới |
