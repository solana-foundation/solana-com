title: AllowMint
description:
  Cho phép một SPL token mint trên instance và tạo escrow ATA cho mint đó
---

Cho phép một SPL token mint trên instance và tạo associated
token account của escrow cho mint đó. Các khoản nạp tiền cho mint này sẽ khả dụng sau lệnh
gọi này.

## Tài khoản

| Tài khoản                          | Có thể ghi | Người ký | Mô tả                                                                   |
| -------------------------------- | -------- | ------ | ----------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Người trả phí                                                                     |
| `admin`                          |          | ✓      | Quản trị viên instance                                                                |
| `instance`                       |          |        | PDA của instance                                                                  |
| `mint`                           |          |        | SPL token mint cần cho phép                                                       |
| `allowed_mint`                   | ✓        |        | PDA AllowedMint (được tạo bởi lệnh này)                                 |
| `instance_ata`                   | ✓        |        | Associated token account của escrow cho mint này (được tạo bởi lệnh này) |
| `system_program`                 |          |        | System Program                                                                |
| `token_program`                  |          |        | SPL Token Program                                                             |
| `associated_token_program`       |          |        | Associated Token Program                                                      |
| `event_authority`                |          |        | PDA quyền hạn sự kiện                                                           |
| `private_channel_escrow_program` |          |        | Chương trình Escrow                                                                |

## Tham số

| Tham số | Kiểu | Mô tả                                                                                   |
| --------- | ---- | --------------------------------------------------------------------------------------------- |
| `bump`    | `u8` | Bump seed cho PDA `allowed_mint`. Tùy chọn: client `Async` tự suy ra nếu bị bỏ qua |

> IDL chứa một đối số `discriminator: u8` (giá trị `1`) được tự động đặt
> bởi client được tạo ra và không nên truyền vào thủ công.

## Lưu ý quan trọng

- Sử dụng `getAllowMintInstructionAsync`; nó tự suy ra `bump`, `allowed_mint`,
  và `instance_ata` khi chúng không được cung cấp. Chỉ truyền `bump` của riêng bạn nếu
  bạn đã tính toán nó thông qua
  `Pubkey::find_program_address(&[b"allowed_mint", instance_pda, mint], &PROGRAM_ID)`
- Cũng tạo `instance_ata`, ATA của escrow cho mint này
- Các mint có phần mở rộng transfer hook bị chặn rõ ràng: việc cố gắng
  cho phép một mint như vậy sẽ ném lỗi `TransferHookNotAllowed`
- Phát ra một sự kiện thông qua CPI `EmitEvent`
