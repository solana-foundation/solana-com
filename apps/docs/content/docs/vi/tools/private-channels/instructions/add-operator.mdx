title: AddOperator
description: Cấp phép một operator mới bằng cách tạo Operator PDA của họ
---

Cấp phép một operator mới bằng cách tạo `Operator` PDA của họ. Sau lệnh gọi này,
ví `operator` có thể gọi `ReleaseFunds` và `ResetSmtRoot`.

## Tài khoản

| Tài khoản                          | Có thể ghi | Người ký | Mô tả                                                         |
| -------------------------------- | -------- | ------ | ------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Người trả phí                                                           |
| `admin`                          |          | ✓      | Quản trị viên instance                                                      |
| `instance`                       |          |        | Instance PDA                                                        |
| `operator`                       |          |        | Ví operator cần cấp phép                                        |
| `operator_pda`                   | ✓        |        | Operator PDA - tự động suy ra từ `["operator", instance, operator]` |
| `system_program`                 |          |        | System Program                                                      |
| `event_authority`                |          |        | PDA quyền hạn sự kiện                                                 |
| `private_channel_escrow_program` |          |        | Chương trình Escrow                                                      |

## Tham số

| Tham số | Kiểu | Mô tả                                                                               |
| --------- | ---- | ----------------------------------------------------------------------------------------- |
| `bump`    | `u8` | Bump seed cho `operator_pda`. Tùy chọn: client `Async` tự động suy ra nếu bị bỏ qua |

> IDL chứa đối số `discriminator: u8` (giá trị `3`) được tự động đặt
> bởi client được tạo ra và không nên truyền thủ công.

## Lưu ý quan trọng

- Sử dụng `getAddOperatorInstructionAsync`; nó tự động suy ra `bump` và
  `operator_pda` khi chúng không được cung cấp. Biến thể đồng bộ
  `getAddOperatorInstruction` cũng tồn tại nếu bạn đã tự tính toán `bump`
- Sau lệnh gọi này, ví `operator` có thể gọi `ReleaseFunds` và
  `ResetSmtRoot`
- Phát ra một sự kiện thông qua CPI `EmitEvent`
