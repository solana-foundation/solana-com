---

Phần này là tài liệu tham khảo lệnh on-chain. Hầu hết các nhà phát triển gọi các lệnh này thông qua các client TypeScript được tạo tự động; bạn chỉ cần phần này nếu bạn đang xây dựng công cụ vận hành, viết tích hợp tùy chỉnh, hoặc gỡ lỗi các lỗi ở cấp độ lệnh.

**Chương trình Escrow** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) - quản lý
các khoản tiền gửi, cung cấp operator, và thanh toán Mainnet:

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) -
  khởi tạo PDA của phiên bản escrow
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) - đưa vào
  danh sách trắng một SPL token mint
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) - xóa một
  mint khỏi danh sách cho phép
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) -
  cung cấp một operator
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) -
  thu hồi quyền của một operator
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) -
  chuyển quyền quản trị
- [Deposit](/docs/tools/private-channels/instructions/deposit) - chuyển SPL token
  vào escrow
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) -
  operator thanh toán một lệnh rút tiền lên Mainnet
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) -
  operator xoay vòng Sparse Merkle Tree

**Chương trình Rút tiền** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) - chạy trên
mạng kênh riêng tư:

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) -
  đốt số dư phía kênh để khởi tạo lệnh rút tiền

## Mã lỗi

**Chương trình Escrow - `PrivateChannelEscrowProgramError`**

| Mã                                         | Thông báo                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | Quyền sự kiện không hợp lệ được cung cấp                 |
| `InvalidAta`                                 | ATA không hợp lệ được cung cấp                             |
| `InvalidMint`                                | Mint không hợp lệ được cung cấp                            |
| `InvalidInstanceId`                          | ID phiên bản không hợp lệ hoặc không tuân thủ các quy tắc    |
| `InvalidInstance`                            | Phiên bản không hợp lệ được cung cấp                        |
| `InvalidAdmin`                               | Quản trị viên không hợp lệ được cung cấp                           |
| `TransferHookNotAllowed`                     | Phần mở rộng transfer hook không được phép              |
| `InvalidOperatorPda`                         | Operator PDA không hợp lệ được cung cấp                    |
| `InvalidTokenAccount`                        | token account không hợp lệ được cung cấp                   |
| `InvalidEscrowBalance`                       | Số dư escrow không hợp lệ                           |
| `InvalidAllowedMint`                         | Mint được phép không hợp lệ                             |
| `InvalidSmtProof`                            | Bằng chứng SMT không hợp lệ được cung cấp                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | Nonce giao dịch không hợp lệ cho chỉ mục cây hiện tại |
| `UnexpectedTreeIndex`                        | Chỉ mục cây hiện tại không mong đợi khi đặt lại SMT root |

**Chương trình Rút tiền - `PrivateChannelWithdrawProgramError`**

| Mã          | Thông báo                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | Mint không hợp lệ được cung cấp                       |
| `ZeroAmount`  | Số tiền rút phải lớn hơn 0 |
