Chuyển quyền quản trị cho một ví mới.

## Tài khoản

| Tài khoản                          | Có thể ghi | Người ký | Mô tả                        |
| -------------------------------- | -------- | ------ | ---------------------------------- |
| `payer`                          | ✓        | ✓      | Người trả phí                          |
| `current_admin`                  |          | ✓      | Quản trị viên hiện tại (phải ký)          |
| `instance`                       | ✓        |        | Instance PDA (trường admin đã được cập nhật) |
| `new_admin`                      |          | ✓      | Ví nhận quyền quản trị     |
| `event_authority`                |          |        | Event authority PDA                |
| `private_channel_escrow_program` |          |        | Chương trình Escrow                     |

Lệnh này không có tham số nào.

## Lưu ý quan trọng

- **Không thể hoàn tác trong một bước**: quản trị viên hiện tại không thể lấy lại vai trò
  mà không cần quản trị viên mới gọi lại `SetNewAdmin`
- Hãy xác minh địa chỉ đích trước khi gọi; không có chức năng hoàn tác
- Phát ra một sự kiện thông qua `EmitEvent` CPI
