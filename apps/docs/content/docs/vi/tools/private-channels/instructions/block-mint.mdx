Xóa một mint đã được cho phép trước đó khỏi instance, ngăn chặn các khoản nạp mới cho
mint đó. Các khoản nạp hiện có không bị ảnh hưởng.

## Tài khoản

| Tài khoản                          | Có thể ghi | Người ký | Mô tả                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | Người trả phí                                    |
| `admin`                          |          | ✓      | Quản trị viên instance                               |
| `instance`                       |          |        | PDA của instance                                 |
| `mint`                           |          |        | Mint token SPL cần chặn                      |
| `allowed_mint`                   | ✓        |        | PDA AllowedMint (bị đóng bởi lệnh này) |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | PDA quyền sự kiện                          |
| `private_channel_escrow_program` |          |        | Chương trình Escrow                               |

Lệnh này không nhận tham số nào.

## Lưu ý quan trọng

- Đóng PDA `allowed_mint`: các lệnh gọi `Deposit` mới cho mint này sẽ thất bại
  với lỗi `InvalidAllowedMint`
- Số dư kênh hiện có cho mint này không bị ảnh hưởng
- Phát ra sự kiện thông qua CPI `EmitEvent`
