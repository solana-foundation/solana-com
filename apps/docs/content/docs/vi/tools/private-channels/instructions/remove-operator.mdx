Thu hồi quyền của một operator bằng cách đóng `Operator` PDA của họ. Ví đã bị thu hồi sẽ không còn có thể gọi `ReleaseFunds` hoặc `ResetSmtRoot`.

## Tài khoản

| Tài khoản                          | Có thể ghi | Người ký | Mô tả                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | Người trả phí                                 |
| `admin`                          |          | ✓      | Quản trị viên instance                            |
| `instance`                       |          |        | PDA của instance                              |
| `operator`                       |          |        | Ví operator cần thu hồi                 |
| `operator_pda`                   | ✓        |        | PDA của operator (được đóng bởi lệnh này) |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | PDA quyền hạn sự kiện                       |
| `private_channel_escrow_program` |          |        | Chương trình Escrow                            |

Lệnh này không nhận tham số nào.

## Lưu ý quan trọng

- Đóng `operator_pda`; ví đã bị thu hồi sẽ không còn có thể gọi
  `ReleaseFunds` hoặc `ResetSmtRoot`
- Mọi giao dịch operator đang xử lý sẽ thất bại với lỗi `InvalidOperatorPda` sau
  lệnh gọi này
- Phát ra một sự kiện thông qua CPI `EmitEvent`
