Thiết lập môi trường phát triển Solana cục bộ bằng trình cài đặt tự động. Trình cài đặt này
cài đặt Rust, Solana CLI, Anchor CLI, Surfpool CLI, Node.js và Yarn trên
macOS, Linux hoặc Windows thông qua WSL.

<Callout type="info" title="Windows yêu cầu WSL">
  Trong Windows PowerShell, chạy `wsl --install`, khởi động lại Windows nếu được yêu cầu, sau đó
  chạy các lệnh cài đặt bên dưới trong terminal Ubuntu. Xem [hướng dẫn cài đặt
  thủ công](/docs/intro/installation/dependencies) để biết cách thiết lập
  WSL đầy đủ.
</Callout>

## Cài đặt nhanh

1. Chạy trình cài đặt trong terminal macOS, Linux hoặc WSL:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
```

Bạn có thể
[xem lại mã nguồn của trình cài đặt](https://github.com/solana-developers/solana-install/blob/main/install.sh)
trước khi chạy. Trình cài đặt sẽ phát hiện các trình quản lý gói Linux được hỗ trợ và
tự động cài đặt các phụ thuộc hệ thống của chúng.

2. Khởi động lại terminal để các lệnh mới khả dụng trong `PATH` của bạn.

3. Xác minh từng công cụ:

```terminal
$ rustc --version
$ solana --version
$ anchor --version
$ surfpool --version
$ node --version
$ yarn --version
```

Cài đặt thành công sẽ trả về kết quả có dạng sau (số phiên bản thay đổi khi
các công cụ được phát hành):

```txt title="Example output"
Installed Versions:
Rust: rustc x.y.z (...)
Solana CLI: solana-cli x.y.z (..., client:Agave)
Anchor CLI: anchor-cli x.y.z
Surfpool CLI: surfpool x.y.z
Node.js: vx.y.z
Yarn: x.y.z
```

<Callout type="warn" title="Trình cài đặt thất bại hoặc thiếu lệnh">
  Hãy làm theo [hướng dẫn cài đặt thủ công](/docs/intro/installation/dependencies)
  để cài đặt hoặc khắc phục sự cố từng phụ thuộc riêng lẻ.
</Callout>
