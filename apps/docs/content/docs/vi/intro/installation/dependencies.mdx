Hãy cài đặt riêng từng phần phụ thuộc khi bạn cần một phiên bản cụ thể hoặc khi
[cài đặt nhanh](/docs/intro/installation) không hoàn tất thành công.
Hãy làm theo các phần theo thứ tự nếu bạn đang thiết lập môi trường mới, hoặc chuyển thẳng đến công cụ
bạn cần cài đặt hoặc khắc phục sự cố.

## Điều kiện tiên quyết

<Accordions>
<Accordion title="Windows">

Để phát triển các chương trình Solana trên Windows, bạn **phải** sử dụng
[Windows Subsystem for Linux](https://learn.microsoft.com/en-us/windows/wsl/install)
(WSL). Sau khi cài đặt WSL, tất cả các phụ thuộc khác sẽ được cài đặt thông qua
terminal Linux.

Để cài đặt WSL, chạy lệnh sau trong Windows PowerShell:

```terminal
$ wsl --install
```

Quá trình cài đặt sẽ yêu cầu bạn tạo tài khoản người dùng mặc định.

![Cài đặt WSL](/assets/docs/intro/installation/wsl-install.png)

Theo mặc định, WSL cài đặt Ubuntu. Bạn có thể mở terminal Linux bằng cách tìm
kiếm "Ubuntu" trong thanh tìm kiếm.

![WSL Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-search.png)

Nếu terminal Ubuntu của bạn trông giống như hình ảnh bên dưới, bạn có thể gặp sự
cố khi `ctrl + v` (phím tắt dán) không hoạt động trong terminal.

![Terminal Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-terminal-1.png)

Nếu bạn gặp sự cố này, hãy mở Windows Terminal bằng cách tìm kiếm "Terminal"
trong thanh tìm kiếm.

![Windows Terminal](/assets/docs/intro/installation/wsl-windows-terminal.png)

Tiếp theo, đóng Windows Terminal và mở lại terminal Linux bằng cách tìm kiếm
Ubuntu một lần nữa. Terminal bây giờ sẽ trông giống như hình ảnh bên dưới, trong
đó `ctrl + v` (phím tắt dán) hoạt động.

![Terminal Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-terminal-2.png)

Nếu bạn sử dụng VS Code,
[tiện ích mở rộng WSL](https://code.visualstudio.com/docs/remote/wsl-tutorial)
cho phép bạn sử dụng WSL và VS Code cùng nhau.

![Thiết lập WSL trong VS Code](/assets/docs/intro/installation/wsl-vscode.png)

Bạn sẽ thấy nội dung sau trong thanh trạng thái của VS Code:

![WSL: Ubuntu](/assets/docs/intro/installation/wsl-vscode-ubuntu.png)

Sau khi đã thiết lập WSL, bạn đã sẵn sàng để:

- Hoàn thành [cài đặt nhanh](/docs/intro/installation) bằng terminal Ubuntu
  (Linux)
- Cài đặt [Rust](#install-rust), [Solana CLI](#install-solana-cli), và
  [Anchor CLI](#install-anchor-cli) riêng lẻ, như mô tả bên dưới

</Accordion>
<Accordion title="Linux">

<Tabs items={[".deb", ".rpm"]}>
<Tab value=".deb" >
Trên Debian hoặc bản phân phối dựa trên Debian như Ubuntu hoặc Mint:

1. Cập nhật danh sách gói để đảm bảo tất cả các gói đều được cập nhật:

```terminal
$ sudo apt-get update
```

2. Cài đặt các phụ thuộc sau:

```terminal
$ sudo apt-get install -y \
    build-essential \
    pkg-config \
    libudev-dev llvm libclang-dev \
    protobuf-compiler libssl-dev
```

<Callout>
Nếu bạn gặp lỗi sau khi cài đặt `protobuf-compiler`, hãy chạy
`sudo apt-get update` trước khi thử lại lệnh cài đặt.

```
Package protobuf-compiler is not available, but is referred to by another package.
This may mean that the package is missing, has been obsoleted, or
is only available from another source
```

</Callout>

  </Tab>

    <Tab value=".rpm" >
    Trên bản phân phối dựa trên RPM như Fedora hoặc Red Hat Enterprise Linux:

Cập nhật các gói đã cài đặt:

```terminal
$ sudo dnf upgrade --refresh
```

Cài đặt các phần phụ thuộc phục vụ phát triển:

```terminal
$ sudo dnf group install c-development development-tools \
&& sudo dnf install pkg-config openssl-devel
```

  </Tab>
</Tabs>

### Cài đặt Rust

Các nhà phát triển xây dựng chương trình Solana bằng ngôn ngữ lập trình
[Rust](https://www.rust-lang.org/).

1. Cài đặt Rust bằng [rustup](https://www.rust-lang.org/tools/install) bằng cách
   nhập lệnh sau vào terminal của bạn:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
```

Sau khi cài đặt thành công, bạn sẽ thấy thông báo sau:

<Accordions>
<Accordion title="Thông báo cài đặt Rust thành công">

```
Rust is installed now. Great!

To get started you may need to restart your current shell.
This would reload your PATH environment variable to include
Cargo's bin directory ($HOME/.cargo/bin).

To configure your current shell, you need to source
the corresponding env file under $HOME/.cargo.

This is usually done by running one of the following (note the leading DOT):
. "$HOME/.cargo/env"            # For sh/bash/zsh/ash/dash/pdksh
source "$HOME/.cargo/env.fish"  # For fish
```

</Accordion>
</Accordions>

2. Tải lại biến môi trường PATH của bạn để bao gồm thư mục bin của
   [Cargo](https://github.com/rust-lang/cargo):

```terminal
$ . "$HOME/.cargo/env"
```

3. Xác minh rằng quá trình cài đặt đã thành công.

```terminal
$ rustc --version
```

Lệnh này in ra phiên bản Rust đã cài đặt, ví dụ:

```
rustc x.y.z (...)
```

</Step>
<Step>

### Cài đặt Solana CLI

Solana CLI cung cấp tất cả các công cụ cần thiết để xây dựng và triển khai các
chương trình Solana.

1. Cài đặt bộ công cụ Solana CLI bằng cách sử dụng lệnh cài đặt chính thức:

```terminal
$ sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

<Callout>
  Bạn có thể thay `stable` bằng một thẻ phát hành Agave cụ thể hoặc bằng kênh phát hành `beta`
  hoặc `edge`.
</Callout>

2. Làm cho Solana CLI khả dụng trong terminal hiện tại của bạn.

Trình cài đặt sẽ cập nhật cấu hình shell của bạn và in ra lệnh cần thiết
để cập nhật phiên làm việc hiện tại. Lệnh thường là:

```terminal
$ export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"
```

Nếu `solana` vẫn chưa khả dụng, hãy khởi động lại terminal. Để xác nhận trình cài đặt đã cập nhật
tệp cấu hình shell nào, hãy kiểm tra shell hiện tại của bạn:

```terminal
$ echo $SHELL
```

- Nếu kết quả đầu ra chứa `/bash`, hãy khởi động lại terminal hoặc chạy
  `source ~/.bashrc`.
- Nếu kết quả đầu ra chứa `/zsh`, hãy khởi động lại terminal hoặc chạy `source ~/.zshrc`.

3. Xác minh rằng quá trình cài đặt đã thành công:

```terminal
$ solana --version
```

Lệnh này in ra phiên bản Solana CLI đã cài đặt, ví dụ:

```
solana-cli x.y.z (..., client:Agave)
```

<Callout>

Bạn có thể xem tất cả các phiên bản khả dụng trên
[kho GitHub của Agave](https://github.com/anza-xyz/agave/releases). Agave là
validator client của [Anza](https://www.anza.xyz/), trước đây được gọi là
Solana Labs validator client.

</Callout>

4. Để cập nhật Solana CLI sau này, hãy chạy:

```terminal
$ agave-install update
```

</Step>

### Cài đặt Anchor CLI

[Anchor](https://www.anchor-lang.com/) là một framework để phát triển các chương
trình Solana. Framework Anchor tận dụng các macro của Rust để đơn giản hóa quá
trình viết các chương trình Solana.

#### Điều kiện tiên quyết

Node.js và trình quản lý gói JavaScript chỉ cần thiết khi bạn chọn một
mẫu kiểm thử TypeScript như Mocha hoặc Jest. Mẫu kiểm thử LiteSVM mặc định
chạy bằng Rust và không yêu cầu các công cụ Node.js.

<Accordions>
<Accordion title="Cài đặt Node">

1. Cài đặt Node bằng
   [Node Version Manager (nvm)](https://github.com/nvm-sh/nvm) bằng cách chạy
   lệnh sau:

```terminal
$ curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```

2. Khởi động lại terminal và xác nhận lệnh `nvm` chạy thành công:

```terminal
$ command -v nvm
```

3. Dùng `nvm` để cài đặt Node:

```terminal
$ nvm install --lts
```

4. Xác minh quá trình cài đặt đã thành công bằng cách kiểm tra phiên bản Node:

```terminal
$ node --version
```

Lệnh này in ra phiên bản Node.js đã cài đặt, ví dụ:

```
vx.y.z
```

</Accordion>
<Accordion title="Cài đặt Yarn">

1. Cài đặt Yarn:

```terminal
$ npm install --global yarn
```

2. Xác minh quá trình cài đặt đã thành công bằng cách kiểm tra phiên bản Yarn:

```terminal
$ yarn --version
```

Lệnh này in ra phiên bản Yarn đã cài đặt, ví dụ:

```
x.y.z
```

</Accordion>
</Accordions>

#### Cài đặt

Bạn có thể cài đặt Anchor CLI và các công cụ theo hai cách:

- Anchor Version Manager (AVM) — Phương pháp cài đặt được khuyến nghị
- Không dùng AVM — Cài đặt trực tiếp từ GitHub

<Tabs groupId="anchor" items={["AVM", "Without AVM"]}>
<Tab value="AVM">

Anchor Version Manager (AVM) cho phép bạn cài đặt và quản lý các phiên bản
Anchor khác nhau trên hệ thống của bạn và dễ dàng cập nhật phiên bản Anchor
trong tương lai. Để cài đặt Anchor bằng AVM, hãy làm theo các bước dưới đây:

1. Cài đặt AVM bằng lệnh sau:

```terminal
$ curl -sSfL https://raw.githubusercontent.com/otter-sec/anchor/master/avm/install | sh
```

2.  Xác nhận rằng AVM đã được cài đặt thành công:

```terminal
$ avm --version
```

3. Cài đặt Anchor CLI bằng AVM:

Để cài đặt phiên bản mới nhất:

```terminal
$ avm install latest
$ avm use latest
```

Để cài đặt một phiên bản cụ thể, hãy chỉ định số phiên bản:

```terminal
$ avm install 1.1.2
$ avm use 1.1.2
```

<Callout type="warn">

Khi cài đặt Anchor CLI trên Linux hoặc WSL, bạn có thể gặp lỗi sau:

```
error: could not exec the linker cc = note: Permission denied (os error 13)
```

Nếu bạn thấy thông báo lỗi này, hãy làm theo các bước sau:

1. Cài đặt các gói phụ thuộc được liệt kê trong phần
   [Linux](/docs/intro/installation/dependencies) ở đầu trang
   này.
2. Thử cài đặt lại Anchor CLI.

</Callout>

4. Xác minh rằng việc cài đặt đã thành công bằng cách kiểm tra phiên bản Anchor
   CLI:

```terminal
$ anchor --version
```

Lệnh này in ra phiên bản Anchor CLI đang được sử dụng, ví dụ:

```
anchor-cli 1.1.2
```

<Callout type="info">

Chạy `avm use` để chọn phiên bản Anchor CLI cho hệ thống của bạn.

- Nếu bạn đã cài đặt phiên bản mới nhất, hãy chạy `avm use latest`.
- Nếu bạn đã cài đặt phiên bản `1.1.2`, hãy chạy `avm use 1.1.2`.

</Callout>

</Tab>

<Tab value="Without AVM">

1. Cài đặt một phiên bản cụ thể của Anchor CLI bằng lệnh sau:

```terminal
$ cargo install --git https://github.com/solana-foundation/anchor --tag v1.1.2 anchor-cli --locked
```

2. Xác minh quá trình cài đặt đã thành công bằng cách kiểm tra phiên bản Anchor CLI:

```terminal
$ anchor --version
```

Lệnh này in ra phiên bản Anchor CLI đã cài đặt, ví dụ:

```
anchor-cli 1.1.2
```

</Tab>

### Cài đặt Surfpool CLI

[Surfpool](/docs/tools/surfpool) là một công cụ dành cho phát triển cục bộ và là giải pháp
thay thế được cải tiến cho `solana-test-validator`.

1. Cài đặt Surfpool bằng lệnh sau:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://run.surfpool.run/ | bash
```

2. Xác minh quá trình cài đặt đã thành công bằng cách kiểm tra phiên bản
   Surfpool CLI:

```terminal
$ surfpool --version
```

Lệnh này in ra phiên bản Surfpool CLI đã cài đặt, ví dụ:

```
surfpool x.y.z
```

</Step>
