title: Cơ bản về Anchor CLI
seoTitle: Các lệnh cơ bản để bắt đầu với Anchor CLI
description:
  Phần này hướng dẫn một số lệnh Anchor CLI phổ biến để giúp bạn bắt đầu.
---

Phần này cung cấp một số lệnh và ví dụ phổ biến để giúp bạn bắt đầu sử dụng
[Anchor CLI](https://www.anchor-lang.com/docs).

<Steps>
<Step>

### Khởi tạo dự án

Tạo một dự án Anchor mới bằng cách chạy lệnh bên dưới. Lệnh này sẽ tạo một
thư mục mới với tên dự án và dùng thư mục đó để khởi tạo một dự án Anchor
mới.

```terminal
$ anchor init <project-name>
```

Ví dụ, lệnh bên dưới sẽ tạo một dự án có tên `my-project`. Thư mục
`my-project` sẽ chứa một chương trình Rust dạng mô-đun và một mẫu kiểm thử Rust
sử dụng LiteSVM.

```terminal
$ anchor init my-project
```

Để tạo mẫu kiểm thử TypeScript thay thế, hãy chọn một mẫu một cách tường minh. Ví
dụ, sử dụng mẫu Mocha:

```terminal
$ anchor init my-project --test-template mocha
```

Các mẫu kiểm thử TypeScript yêu cầu Node.js và một trình quản lý gói JavaScript.

Sau đó, di chuyển đến thư mục dự án:

```terminal
$ cd <project-name>
```

Xem [cấu trúc tệp dự án](https://www.anchor-lang.com/docs/quickstart/local#project-file-structure) của Anchor.

</Step>
<Step>

### Build chương trình

Để build dự án của bạn, chạy lệnh sau:

```terminal
$ anchor build
```

Bạn có thể tìm thấy chương trình đã được biên dịch trong thư mục
`/target/deploy`.

<Callout type="warn" title="Cài đặt platform tools không thành công">
  Nếu quá trình build báo thư mục platform-tools không hợp lệ, hãy cài đặt lại các công cụ
  build SBF, sau đó thử build lại:

```terminal
$ cargo build-sbf --force-tools-install
$ anchor build
```

</Callout>

</Step>
<Step>

### Triển khai chương trình

Để triển khai dự án của bạn, hãy chạy lệnh sau:

```terminal
$ anchor deploy
```

Lệnh này triển khai chương trình của bạn đến `cluster` được chỉ định trong file
[`Anchor.toml`](https://www.anchor-lang.com/docs/references/anchor-toml).

</Step>
<Step>

### Kiểm thử chương trình

Để kiểm thử dự án của bạn, hãy chạy lệnh sau:

```terminal
$ anchor test
```

Lệnh này biên dịch, triển khai và chạy các bài kiểm thử cho dự án của bạn.

<Callout>
  Khi sử dụng cluster `localnet`, Anchor tự động khởi động một validator cục bộ,
  triển khai chương trình, chạy kiểm thử, sau đó dừng validator.
</Callout>

<Callout type="warn" title="Lỗi trình chạy kiểm thử JavaScript">

Nếu bạn đã chọn mẫu kiểm thử JavaScript hoặc TypeScript, một trong các
lỗi sau có thể cho biết Node.js hoặc trình quản lý gói đã cấu hình chưa
được cài đặt:

```
Permission denied (os error 13)
```

```
No such file or directory (os error 2)
```

</Callout>

</Step>
</Steps>
