## Sử dụng Solana MCP

Cách mạnh mẽ nhất để tận dụng AI trong phát triển Solana là thông qua
[Solana Developer MCP](https://mcp.solana.com/) (Model Context Protocol). Tích hợp này
đưa kiến thức chuyên sâu về Solana trực tiếp vào IDE của bạn, cung cấp cho
các tác nhân AI quyền truy cập vào tài liệu Solana cập nhật, giúp quá trình
phát triển nhanh hơn và hiệu quả hơn.

## Solana MCP là gì?

Solana MCP là một trợ lý AI chuyên biệt tích hợp trực tiếp vào
các IDE hỗ trợ AI như Cursor và Windsurf. Khi bạn đặt câu hỏi liên quan đến
Solana, nó tự động truy vấn máy chủ MCP để cung cấp thông tin chính xác,
cập nhật từ:

- [Tài liệu Solana](/docs)
- [Tài liệu Anchor Framework](https://www.anchor-lang.com/docs)
- [Ví dụ chương trình](https://github.com/solana-developers/program-examples) Solana
- Câu hỏi và câu trả lời trên [Solana Stack Exchange](https://solana.stackexchange.com/)

## Ví dụ về các trường hợp sử dụng

Bạn có thể sử dụng MCP để:

- Hỏi về các khái niệm Solana
- Gỡ lỗi chương trình
- Nhận các khuyến nghị về thực tiễn tốt nhất
- Học hỏi từ các ví dụ của chuyên gia
- Phát triển nhanh hơn với sự hỗ trợ của chuyên gia

## Thiết lập Solana MCP

Tìm hướng dẫn thiết lập chi tiết và bắt đầu sử dụng trên
[trang web Solana MCP](https://mcp.solana.com/).

## Bạn muốn sử dụng một kỹ năng?

Nếu bạn muốn sử dụng một kỹ năng, hãy cài đặt kỹ năng Solana chính thức bằng:

```bash
npx skills add https://github.com/solana-foundation/solana-dev-skill
```

Khám phá thêm các quy trình làm việc có thể tái sử dụng trong [thư viện Solana Agent Skills](/skills).
