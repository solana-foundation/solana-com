---
title: "Quickstart: tạo token bằng CLI"
description:
  Create a token, open a token account, mint supply, and transfer tokens using
  the SPL Token CLI on devnet.
---

Quickstart này hướng dẫn toàn bộ vòng đời của token bằng CLI
_sh`spl-token`_. Bạn sẽ tạo một mint, tạo một account có thể lưu trữ
token, mint 100 token và chuyển một số token sang ví khác.

Sử dụng [Solana Playground](https://beta.solpg.io/) để chạy các lệnh trên
trình duyệt của bạn, hoặc cài đặt CLI cục bộ với `cargo install spl-token-cli`. Các
địa chỉ trong đầu ra của bạn sẽ khác với các ví dụ bên dưới.

## 1. Kết nối với devnet

Tạo hoặc kết nối ví trong Solana Playground, sau đó chọn devnet và yêu cầu
SOL để nạp tiền vào account và thanh toán phí giao dịch:

```terminal
$ solana config set --url devnet
$ solana airdrop 2
```

Chỉ sử dụng token devnet cho mục đích kiểm thử. Chúng không có giá trị tài chính.

## 2. Tạo token

Tạo mint account để xác định token của bạn:

```terminal
$ spl-token create-token
```

Sao chép địa chỉ token từ đầu ra. Đây là địa chỉ mint bạn sẽ dùng trong
các lệnh còn lại. Một mint mới bắt đầu với nguồn cung bằng không.

```terminal
$ spl-token supply <MINT_ADDRESS>
```

## 3. Tạo token account

Ví của bạn cần một token account cho mint này trước khi có thể lưu số dư:

```terminal
$ spl-token create-account <MINT_ADDRESS>
```

Thao tác này tạo
[associated token account](/docs/tokens#associated-token-account) của bạn, có địa chỉ
được suy ra từ ví và mint của bạn.

## 4. Mint token

Mint 100 token vào associated token account của bạn:

```terminal
$ spl-token mint <MINT_ADDRESS> 100
$ spl-token balance <MINT_ADDRESS>
```

Mint authority phải ký xác nhận thao tác này. Việc mint sẽ tăng cả số dư
token account của bạn lẫn tổng nguồn cung được ghi lại bởi mint.

## 5. Chuyển token

Gửi 10 token đến một ví devnet khác. Tùy chọn _sh`--fund-recipient`_
sẽ tạo associated token account của người nhận nếu nó chưa tồn tại:

```terminal
$ spl-token transfer <MINT_ADDRESS> 10 <RECIPIENT_WALLET_ADDRESS> --fund-recipient
```

Việc chuyển token thay đổi số dư trong token account của người gửi và người nhận; nó
không thay đổi tổng nguồn cung của mint.

## Tùy chọn: thêm metadata Token-2022

Để lưu trữ tên, ký hiệu và URI trực tiếp trên một mint Token-2022 mới, hãy tạo nó
với tính năng mở rộng metadata được bật:

```terminal
$ spl-token create-token \
  --program-id TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb \
  --enable-metadata
```

Sau đó sử dụng địa chỉ mint mới được in ra bởi lệnh đó:

```terminal
$ spl-token initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  "EXAMPLE" \
  "https://example.com/token.json"
```

URI phải trả về một tài liệu JSON metadata công khai. Xem
[Token-2022 metadata](/docs/tokens/extensions/metadata) để biết mô hình account
và các ví dụ mã.
