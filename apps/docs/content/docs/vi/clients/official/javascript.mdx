## Solana Kit

`@solana/kit` là TypeScript SDK được khuyến nghị để xây dựng trên Solana. Bạn
tập hợp một client từ các plugin có thể kết hợp, thêm các liên kết React khi
cần, và tích hợp các program client được tạo sẵn cho các on-chain program mà bạn
gọi.

| Package                   | Mô tả                                  | GitHub                                                                                 |
| ------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------- |
| @solana/kit               | SDK cốt lõi: RPC, giao dịch, codec, signer | [Mã nguồn](https://github.com/anza-xyz/kit)                                              |
| @solana/react             | Liên kết React: `ClientProvider` và các hook   | [Mã nguồn](https://github.com/anza-xyz/kit/tree/main/packages/react)                     |
| @solana/kit-plugin-rpc    | Kết nối RPC + gửi giao dịch         | [Mã nguồn](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-rpc)    |
| @solana/kit-plugin-signer | Plugin fee payer, identity và signer      | [Mã nguồn](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-signer) |
| @solana/kit-plugin-wallet | Kết nối Wallet Standard + React hook     | [Mã nguồn](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-wallet) |

## Solana Web3.js v3

`@solana/web3.js` v3 là phiên bản web3.js được khuyến nghị. Phiên bản này xây dựng lại
API dựa trên lớp (class) cổ điển — `Connection`, `Keypair`, `Transaction`, `PublicKey` —
trên nền tảng nội bộ của `@solana/kit`, nên có thể hoạt động với các primitive của Kit và các
program client nêu trên. Hãy dùng nếu bạn đang nâng cấp một ứng dụng web3.js hiện có hoặc
ưu tiên API dựa trên lớp.

Hầu hết các phương thức vốn đồng bộ trong SDK cũ, chẳng hạn như
`Keypair.generate()` và `transaction.sign()`, giờ đây đều là bất đồng bộ (async).

```bash
npm install @solana/web3.js@3
```

| Package         | Mô tả | GitHub                                                        |
| --------------- | ----------- | ------------------------------------------------------------- |
| @solana/web3.js | SDK cốt lõi    | [Mã nguồn](https://github.com/solana-foundation/solana-web3.js) |

`@solana/spl-token` phụ thuộc vào `@solana/web3.js` (legacy) và không chạy trên
v3. Hãy dùng `@solana-program/token` hoặc `@solana-program/token-2022` thay thế; các
instruction được tạo sinh và instruction plan của chúng hoạt động trực tiếp với
`Transaction.add()` của v3.

- [Hướng dẫn di chuyển từ web3.js v1 → v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
- [Hướng dẫn di chuyển spl-token](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-spl-token-migration.md)

## Solana Web3.js (legacy)

`@solana/web3.js` (legacy, `1.x`) là SDK TypeScript gốc dành cho Solana. SDK này
đang ở chế độ bảo trì và chỉ nhận các bản sửa lỗi quan trọng. Các codebase hiện có có thể
[nâng cấp lên web3.js v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
hoặc [di chuyển sang Kit](/docs/frontend/web3-compat).
