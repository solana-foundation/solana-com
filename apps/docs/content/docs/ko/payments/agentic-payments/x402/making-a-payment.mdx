[Pay](https://pay.sh)를 사용해 x402 V2 API를 실행하고 Claude Code에 결제 인식 HTTP 클라이언트를 제공하세요. API, 결제자 지갑, 정산 모두 Solana 샌드박스를 사용하므로 이 안내를 따라 하는 데 계정이나 실제 자금이 필요하지 않습니다.

터미널, Pay, Claude Code가 설치되어 있어야 합니다.

## 1. Pay 설치

macOS에서는 사전 빌드된 바이너리를 설치합니다:

```bash
brew install pay
pay --version
```

다른 플랫폼에서는 npm 패키지를 설치합니다:

```bash
npm install --global @solana/pay
pay --version
```

## 2. x402 샌드박스 API 시작

`x402-demo.yaml`을 생성합니다:

```yaml filename=x402-demo.yaml
name: x402-demo
subdomain: x402-demo
title: "x402 Demo"
description: "Minimal x402 V2 sandbox endpoint."
category: devtools
version: v1
routing:
  type: respond
operator:
  currencies:
    usd: ["USDC"]
  network: "localnet"
  fee_payer: true
endpoints:
  - method: GET
    path: "report"
    description: "Return a sandbox report."
    metering:
      schemes: [x402-exact]
      dimensions:
        - direction: usage
          unit: requests
          scale: 1
          tiers:
            - price_usd: 0.001
```

API를 시작하고 계속 실행 상태로 둡니다:

```bash
pay --sandbox server start x402-demo.yaml --bind 127.0.0.1:1402
```

`x402-exact` 스킴은 이 엔드포인트를 x402 전용으로 만듭니다. 샌드박스 모드에서는 임시 운영자 계정과 결제자 계정이 자동으로 생성되고 자금이 충전됩니다.

## 3. Pay로 에이전트 실행

다른 터미널에서 샌드박스 모드로 Claude Code를 시작합니다:

```bash
pay --sandbox claude
```

Pay는 로컬 MCP 도구를 에이전트 세션에 연결합니다. 에이전트는 개인 키를 받지 않습니다.

## 4. x402 요청 한 번 보내기

에이전트에 다음 프롬프트를 붙여넣으세요:

```text
Use Pay to make exactly one sandbox x402 API request to
http://127.0.0.1:1402/report.

Before paying, show me the amount and ask for approval. Then return the API
result and payment receipt. Do not make any other paid requests.
```

이 요청은 하나의 완전한 x402 V2 결제 루프를 따릅니다:

1. API가 `PAYMENT-REQUIRED` 챌린지와 함께 `402 Payment Required`를 반환합니다.
2. Pay가 x402 요구 사항을 검증하고 결제 조건을 표시합니다.
3. 승인 후 샌드박스 지갑이 서명하고, Pay가 `PAYMENT-SIGNATURE`와 함께 요청을 다시 시도합니다.
4. API가 `PAYMENT-RESPONSE` 영수증과 함께 결과를 반환합니다.

실제 자금은 이동하지 않습니다. 승인을 거부하면 요청이 중단됩니다.

[Solana의 x402](/docs/payments/agentic-payments/x402)에서 계속 진행하여 x402 V2 클라이언트와 리소스 서버를 구축하거나, [x402 퍼실리테이터가 되어](/docs/tools/x402-facilitator) 보세요.
