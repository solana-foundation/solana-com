최종적으로 USDC 결제를 위한 Solana Pay QR 코드를 표시하고, 결제가 반영될 때까지 대기하며, 요청한 내용과 일치하는지 확인하는 React 컴포넌트가 만들어집니다. Node.js 20 이상, React 또는 Next.js 앱(새로 생성한 `create-next-app`도 가능), 그리고 devnet으로 설정된 모바일 지갑이 필요합니다. [faucet.circle.com](https://faucet.circle.com)에서 devnet USDC를, [faucet.solana.com](https://faucet.solana.com)에서 devnet SOL을 받아 지갑에 충전하면 트랜잭션 수수료를 충당할 수 있습니다.

<Callout type="caution">
  `@solana/pay`는 현재 베타 버전입니다. 안정적인 릴리스 전에 API가 변경될 수 있습니다.
</Callout>

## 1. Solana Pay 설치

```bash
pnpm add @solana/pay@beta @solana/kit
```

## 2. 결제 QR 코드 추가

이 컴포넌트는 주문별 고유 reference를 생성하여 [전송 요청](/docs/tools/solana-pay/quickstart/transfer-requests) URL로 인코딩하고, 해당 URL을 QR 코드로 렌더링합니다. 그런 다음 reference가 포함된 트랜잭션을 감시하다가, 수신자, 금액, 토큰을 검증한 후 주문을 결제 완료로 표시합니다. `MERCHANT_WALLET`을 직접 관리하는 주소로 설정하세요:

```tsx
"use client";

import { useEffect, useRef, useState } from "react";
import {
  address,
  createSolanaRpc,
  createSolanaRpcSubscriptions,
  generateKeyPair,
  getAddressFromPublicKey
} from "@solana/kit";
import {
  createQR,
  encodeURL,
  validateTransfer,
  watchReference
} from "@solana/pay";

const MERCHANT_WALLET = address("your-wallet-address");
const USDC_DEVNET = address("4zMMC9srt5Ri5X14GAgXhaHii3GnPAEERYPJgZJDncDU");
const AMOUNT = 1;

const rpc = createSolanaRpc("https://api.devnet.solana.com");
const rpcSubscriptions = createSolanaRpcSubscriptions(
  "wss://api.devnet.solana.com"
);

export function Checkout() {
  const qrRef = useRef<HTMLDivElement>(null);
  const [signature, setSignature] = useState<string | null>(null);

  useEffect(() => {
    const abortController = new AbortController();

    async function startPayment() {
      const keyPair = await generateKeyPair();
      const reference = await getAddressFromPublicKey(keyPair.publicKey);

      const url = encodeURL({
        recipient: MERCHANT_WALLET,
        amount: AMOUNT,
        splToken: USDC_DEVNET,
        reference,
        label: "My Store",
        message: "Order #1001"
      });

      if (abortController.signal.aborted) return;

      if (qrRef.current) {
        qrRef.current.innerHTML = "";
        createQR(url, 300).append(qrRef.current);
      }

      const result = await watchReference(rpcSubscriptions, reference, {
        abortSignal: abortController.signal
      });
      if (result.err) throw new Error("Payment transaction failed");

      await validateTransfer(rpc, result.signature, {
        recipient: MERCHANT_WALLET,
        amount: AMOUNT,
        splToken: USDC_DEVNET,
        reference
      });
      setSignature(result.signature);
    }

    startPayment().catch((error) => {
      if (!abortController.signal.aborted) console.error(error);
    });

    return () => abortController.abort();
  }, []);

  if (signature) return <p>Payment confirmed: {signature}</p>;
  return <div ref={qrRef} />;
}
```

`amount`는 토큰 단위이므로 `1`은 1 USDC를 요청합니다. SOL을 대신 요청하려면 `splToken`을 생략하세요.

## 3. 결제 받기

앱을 실행하고 지갑으로 QR 코드를 스캔한 다음 결제를 승인하세요. 트랜잭션이 확정되고 검증을 통과하면 컴포넌트에 트랜잭션 서명이 표시됩니다. 이 서명이 영수증 역할을 하며, [getTransaction](/docs/rpc/http/gettransaction) 또는 아무 익스플로러에서나 조회할 수 있습니다.

<Callout type="warn">
  브라우저에서의 검증은 데모용으로는 충분합니다. 실제 주문을 처리하기 전에 서버에서 결제를 검증하세요. [결제 검증](/docs/payments/accept-payments/verification-tools)을 참고하세요.
</Callout>
