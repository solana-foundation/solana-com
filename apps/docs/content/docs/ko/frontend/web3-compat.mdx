---

`@solana/web3.js`(레거시), `@solana/wallet-adapter-*` 또는 이전 framework-kit 패키지(`@solana/client`, `@solana/react-hooks`, `@solana/web3-compat`)를 사용하고 계신다면, `@solana/kit` 플러그인 또는 `@solana/web3.js` v3(또는 그 이상)로 마이그레이션하시기를 권장합니다.

이 페이지에서는 이미 익숙한 개념을 Kit의 대응 요소와 매핑하여 보여줍니다.

## 개념 매핑

| web3.js (레거시) / wallet-adapter      | Kit                                                                  |
| -------------------------------------- | -------------------------------------------------------------------- |
| `new Connection(url)`                  | `createSolanaRpc(url)`, 또는 클라이언트에서 `.use(solanaRpc({ rpcUrl }))` |
| `PublicKey`                            | `Address` — `address("...")`로 문자열 변환                    |
| `Keypair`                              | `generateKeyPairSigner()` 또는 `@solana/kit-plugin-signer` 플러그인 |
| `SystemProgram.transfer(...)`          | `@solana-program/system`의 `getTransferSolInstruction(...)`       |
| `LAMPORTS_PER_SOL` 수학 연산                | `@solana/kit`의 `lamports(...)`                                   |
| `Transaction` / `VersionedTransaction` | 트랜잭션 플래너가 빌드 및 패킹하는 트랜잭션 메시지     |
| `sendAndConfirmTransaction(...)`       | `client.sendTransaction([...])` (플래너가 서명, 전송 및 확인) |
| `@solana/wallet-adapter-*`             | `@solana/kit-plugin-wallet` + Wallet Standard 검색              |

web3.js v3는 위에 나열된 클래스 기반 이름인 `Connection`, `Keypair`, `Transaction`, `PublicKey`를 Kit 내부 구현 위에 얹은 얇은 래퍼로 유지합니다. 따라서 Kit 열은 v3에서 해당 클래스들이 내부적으로 수행하는 작업도 함께 설명합니다.

## web3.js에서 오셨나요?

대규모 `@solana/web3.js`(레거시) 코드베이스를 유지 관리하고 있고 Kit으로의 전면 재작성이 현실적이지 않다면, web3.js v3가 그 가교 역할을 합니다. `@solana/web3.js@3`으로 설치하세요. 이 버전은 `Connection`, `Keypair`, `Transaction`, `PublicKey` 등 기존의 클래스 기반 API를 `@solana/kit` 내부 구현 위에서 다시 구성합니다. Kit을 기반으로 하기 때문에 상호 운용성이 뛰어납니다. `PublicKey`가 기본 주소 타입이며 `.toBase58()`은 Kit의 브랜드 타입 `Address` 문자열을 반환하고, v3 `Keypair`는 Kit의 `KeyPairSigner`를 구현하므로 Kit API, 플러그인, Codama로 생성된 클라이언트에 바로 전달할 수 있습니다.

<Callout type="warn" title="v1 트랜잭션과 web3.js(레거시)">
  web3.js로 v1 트랜잭션을 전송하는 경우 v3 이상을 사용해야 합니다.
</Callout>

마이그레이션 방법은 공식 [web3.js v1 → v3 마이그레이션 가이드](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)를 참고하세요.

## 지갑

Kit은 wallet-adapter를 사용하지 않습니다. `@solana/kit-plugin-wallet`는 Wallet
Standard 지갑을 검색하고 `client.wallet` 및
[React 훅](/docs/frontend/react-hooks)을 통해 노출합니다. 최신 지갑(Phantom,
Solflare, Backpack 등)은 Wallet Standard를 통해 자신을 알리므로 지갑별 어댑터
패키지가 필요하지 않습니다.

[@solana/connector](https://www.npmjs.com/package/@solana/connector)와 같은 사전
빌드된 도구를 사용할 수도 있습니다. 이 도구는 Kit 기본 요소를 직접 사용하여
지갑에 연결합니다.

<Callout type="info" title="아직 wallet-adapter를 사용 중이신가요?">
  `@solana/wallet-adapter-*` 기반으로 구축된 앱을 유지 관리 중이며 아직
  마이그레이션할 준비가 되지 않은 경우, [wallet-adapter
  저장소](https://github.com/anza-xyz/wallet-adapter)가 해당 스택의 참조 자료로
  유지됩니다. 새로운 프로젝트에는 Kit 지갑 플러그인을 사용하는 것을 권장합니다.
</Callout>
