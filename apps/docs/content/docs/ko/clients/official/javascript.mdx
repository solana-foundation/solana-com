## Solana Kit

`@solana/kit`는 Solana 위에서 개발하기 위한 공식 권장 TypeScript SDK입니다.
컴포저블 플러그인으로 클라이언트를 조립하고, 필요할 때 React 바인딩을 추가하며,
호출하는 온체인 프로그램에 맞는 생성된 프로그램 클라이언트를 가져올 수 있습니다.

| 패키지                   | 설명                                  | GitHub                                                                                 |
| ------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------- |
| @solana/kit               | 핵심 SDK: RPC, 트랜잭션, 코덱, 서명자 | [소스](https://github.com/anza-xyz/kit)                                              |
| @solana/react             | React 바인딩: `ClientProvider` 및 훅   | [소스](https://github.com/anza-xyz/kit/tree/main/packages/react)                     |
| @solana/kit-plugin-rpc    | RPC 연결 + 트랜잭션 전송         | [소스](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-rpc)    |
| @solana/kit-plugin-signer | 수수료 납부자, 신원, 서명자 플러그인      | [소스](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-signer) |
| @solana/kit-plugin-wallet | Wallet Standard 연결 + React 훅     | [소스](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-wallet) |

## Solana Web3.js v3

`@solana/web3.js` v3는 web3.js의 권장 버전입니다. 기존의 클래스 기반 API인
`Connection`, `Keypair`, `Transaction`, `PublicKey`를 `@solana/kit` 내부 구조
위에서 다시 구현했기 때문에 Kit 기본 요소 및 위에 나열된 프로그램 클라이언트와
함께 사용할 수 있습니다. 기존 web3.js 앱을 업그레이드하거나 클래스 기반 API를
선호한다면 이 버전을 사용하세요.

`Keypair.generate()`, `transaction.sign()`처럼 레거시 SDK에서 동기식이던 대부분의
메서드가 이제 비동기식입니다.

```bash
npm install @solana/web3.js@3
```

| 패키지         | 설명 | GitHub                                                        |
| --------------- | ----------- | ------------------------------------------------------------- |
| @solana/web3.js | 핵심 SDK    | [소스](https://github.com/solana-foundation/solana-web3.js) |

`@solana/spl-token`은 `@solana/web3.js`(레거시)에 의존하므로 v3에서는 실행되지
않습니다. 대신 `@solana-program/token` 또는 `@solana-program/token-2022`를
사용하세요. 이 패키지에서 생성된 instruction과 instruction plan은 v3의
`Transaction.add()`에서 바로 사용할 수 있습니다.

- [web3.js v1 → v3 마이그레이션 가이드](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
- [spl-token 마이그레이션 가이드](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-spl-token-migration.md)

## Solana Web3.js (레거시)

`@solana/web3.js`(레거시, `1.x`)는 Solana의 오리지널 TypeScript SDK입니다. 현재
유지보수 모드이며 중요한 수정 사항만 제공됩니다. 기존 코드베이스는
[web3.js v3로 업그레이드](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)하거나
[Kit로 마이그레이션](/docs/frontend/web3-compat)할 수 있습니다.
