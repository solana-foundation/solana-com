`solana` 명령줄 인터페이스는 클러스터 연결을 구성하고, 네트워크 상태를 조회하며,
SOL을 전송하고, durable nonce를 관리하고, 프로그램을 배포하며,
스테이크 및 투표 계정을 운영합니다.

이 레퍼런스는
[Agave v4.2.1](https://github.com/anza-xyz/agave/releases/tag/v4.2.1)을 기준으로 합니다. 설치된 릴리스를 확인하려면
`solana --version`을 실행하고, 해당 버전에서 사용할 수 있는 정확한 옵션은 `--help`로 확인하세요.

<Callout type="warn">
  생성, 전송, 권한 부여, 인출 또는 배포를 수행하는 명령은 트랜잭션을 제출합니다.
  실행하기 전에 설정된 클러스터와 서명자를 확인하세요.
  Devnet 및 Testnet 토큰은 가치가 없으며, Mainnet 명령은 실제 SOL을 사용합니다.
</Callout>

## 명령 구조

```text
solana [GLOBAL_OPTIONS] <COMMAND> [COMMAND_OPTIONS]
```

모든 수준에서 도움말을 확인하세요:

```shell
solana --help
solana transfer --help
solana address-lookup-table extend --help
```

## 전역 옵션

전역 옵션은 명령 앞에 둘 수 있습니다. 명령별 도움말에는 해당 명령에 적용되는
옵션이 다시 나와 있습니다.

| 옵션                          | 용도                                                                        |
| ------------------------------- | ------------------------------------------------------------------------------ |
| `-u, --url <URL_OR_MONIKER>`    | RPC URL 또는 `mainnet-beta`, `testnet`, `devnet`, `localhost` 중 하나를 선택합니다.      |
| `--ws <URL>`                    | WebSocket 엔드포인트를 재정의합니다.                                               |
| `-k, --keypair <KEYPAIR>`       | keypair 파일, `ASK`, 표준 입력(`-`) 또는 지원되는 서명자 URL을 선택합니다.          |
| `-C, --config <FILEPATH>`       | 다른 CLI 설정 파일을 사용합니다.                                        |
| `--commitment <LEVEL>`          | `processed`, `confirmed` 또는 `finalized` 커밋먼트 수준으로 조회합니다.                   |
| `--output <FORMAT>`             | 지원되는 경우 `json` 또는 `json-compact`를 반환합니다.                               |
| `--skip-preflight`              | RPC 시뮬레이션 없이 전송합니다. 실패 시의 트레이드오프를 이해하는 경우에만 사용하세요. |
| `--use-tpu-client`              | TPU 클라이언트를 통해 트랜잭션을 전송합니다.                                      |
| `--no-address-labels`           | 로컬 레이블 없이 주소를 출력합니다.                                          |
| `--skip-seed-phrase-validation` | BIP39 영어 단어 목록에 없는 복구 문구를 허용합니다.                       |
| `-v, --verbose`                 | 추가 명령 출력을 표시합니다.                                                |
| `-V, --version`                 | 설치된 CLI 버전을 출력합니다.                                               |

## CLI 설정

```shell
# Inspect the effective configuration.
solana config get

# Use Devnet and a specific signer by default.
solana config set --url devnet
solana config set --keypair ./devnet-keypair.json

# Override defaults for one command.
solana --url mainnet-beta --keypair usb://ledger address
```

설정에는 RPC URL, WebSocket URL, 기본 서명자, 커밋먼트가 포함됩니다.
명령줄 옵션은 해당 실행에 한해 저장된 값을 재정의합니다.

## 일반적인 계정 및 트랜잭션 워크플로

```shell
# Print the default signer's address and balance.
solana address
solana balance

# Read an account as JSON.
solana account <ACCOUNT_ADDRESS> --output json

# Request Devnet SOL.
solana airdrop 1 --url devnet

# Send SOL and then confirm the returned signature.
solana transfer <RECIPIENT_ADDRESS> 0.1 --allow-unfunded-recipient
solana confirm <TRANSACTION_SIGNATURE>

# Inspect recent activity and stream logs mentioning an address.
solana transaction-history <ADDRESS> --limit 20
solana logs <ADDRESS>
```

`transfer`는 기본적으로 SOL을 전송합니다. 금액으로 `ALL`을 사용하면 수수료를 제외한
사용 가능한 잔액 전체를 이동합니다. 토큰 예제는
[토큰 퀵스타트](/docs/tokens/quickstart)를 참조하세요.

## 프로그램 워크플로

```shell
# Deploy or upgrade an SBF program.
solana program deploy ./target/deploy/my_program.so

# Inspect the deployed program and list programs controlled by the signer.
solana program show <PROGRAM_ID>
solana program show --programs

# Close a program buffer and recover its lamports.
solana program close <BUFFER_ADDRESS>
```

배포 시 알려진 프로그램 ID를 사용해야 한다면 `--program-id <KEYPAIR_OR_ADDRESS>`를
전달하세요. `--final`은 새 배포를 변경 불가능하게 만듭니다. 업그레이드 권한은 복원할 수 없으므로
사용하기 전에 도움말을 주의 깊게 읽으세요.

## Durable nonce 워크플로

```shell
solana-keygen new --outfile nonce-account.json
solana create-nonce-account nonce-account.json 0.1
solana nonce nonce-account.json
solana new-nonce nonce-account.json
solana withdraw-from-nonce-account nonce-account.json <RECIPIENT_ADDRESS> ALL
```

nonce 권한을 변경하려면 `authorize-nonce-account`를, 전체 계정 상태를 확인하려면
`nonce-account`를 사용하세요. nonce를 사용하는 트랜잭션은 지원되는 명령에서
`--nonce` 및 `--nonce-authority`도 허용합니다.

## 스테이크 워크플로

```shell
solana-keygen new --outfile stake-account.json
solana create-stake-account stake-account.json 1
solana delegate-stake stake-account.json <VOTE_ACCOUNT_ADDRESS>
solana stake-account stake-account.json

solana deactivate-stake stake-account.json
solana withdraw-stake stake-account.json <RECIPIENT_ADDRESS> ALL
```

비활성화는 epoch 경계에서 완료되며 둘 이상의 epoch가 걸릴 수 있습니다.
변경 사항을 제출하기 전에 `stakes`, `validators`, `stake-history`, `stake-minimum-delegation`으로
클러스터 및 위임 상태를 확인하세요.

## 주소 유틸리티

```shell
# Derive a PDA from typed seeds.
solana find-program-derived-address \
  <PROGRAM_ID> \
  string:profile \
  pubkey:<OWNER_ADDRESS>

# Create and extend an address lookup table.
solana address-lookup-table create
solana address-lookup-table extend \
  <LOOKUP_TABLE_ADDRESS> \
  --addresses <ADDRESS_1>,<ADDRESS_2>
```

PDA seed는 `PREFIX:VALUE` 형식을 사용합니다. 지원되는 접두사에는 `string`, `pubkey`,
`hex`, `u8`, 그리고 `u64le`와 같은 고정 너비 부호 있는 또는 부호 없는 정수 인코딩이 있습니다.

## 오프체인 메시지 및 셸 자동 완성

```shell
solana sign-offchain-message "terms accepted"
solana verify-offchain-signature \
  "terms accepted" \
  <SIGNATURE> \
  --signer <SIGNER_ADDRESS>

# Print a completion script for the current shell.
solana completion --shell zsh
```

## 스크립트 출력

사람이 읽는 출력을 파싱하는 대신, 지원되는 경우
`--output json` 또는 `--output json-compact`를 사용하세요:

```shell
solana epoch-info --output json
solana account <ACCOUNT_ADDRESS> --output json-compact
solana validators --output json > validators.json
```

모든 명령이 구조화된 출력을 지원하는 것은 아닙니다. 자동화에 의존하기 전에 해당 명령의 도움말을
확인하고, 0이 아닌 종료 상태는 실패로 처리하세요.
