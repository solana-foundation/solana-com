자동 설치 프로그램으로 로컬 Solana 개발 환경을 설정하세요. macOS, Linux 또는
Windows(WSL 사용)에서 Rust, Solana CLI, Anchor CLI, Surfpool CLI, Node.js, Yarn을
설치합니다.

<Callout type="info" title="Windows에서는 WSL이 필요합니다">
  Windows PowerShell에서 `wsl --install`을 실행하고, 안내가 표시되면 Windows를 다시 시작한 다음
  Ubuntu 터미널에서 아래 설치 명령어를 실행하세요. 전체 WSL 설정 방법은 [수동
  설치 가이드](/docs/intro/installation/dependencies)를 참고하세요.
</Callout>

## 빠른 설치

1. macOS, Linux 또는 WSL 터미널에서 설치 프로그램을 실행하세요.

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
```

실행하기 전에
[설치 프로그램 소스](https://github.com/solana-developers/solana-install/blob/main/install.sh)를
검토할 수 있습니다. 설치 프로그램은 지원되는 Linux 패키지 관리자를 감지하여
시스템 종속성을 자동으로 설치합니다.

2. 새 명령어를 `PATH`에서 사용할 수 있도록 터미널을 다시 시작하세요.

3. 모든 도구를 확인하세요.

```terminal
$ rustc --version
$ solana --version
$ anchor --version
$ surfpool --version
$ node --version
$ yarn --version
```

설치가 성공하면 다음과 같은 형식으로 출력됩니다(버전 번호는 도구가 릴리스될 때마다
변경됩니다).

```txt title="Example output"
Installed Versions:
Rust: rustc x.y.z (...)
Solana CLI: solana-cli x.y.z (..., client:Agave)
Anchor CLI: anchor-cli x.y.z
Surfpool CLI: surfpool x.y.z
Node.js: vx.y.z
Yarn: x.y.z
```

<Callout type="warn" title="설치 프로그램이 실패했거나 명령어를 찾을 수 없는 경우">
  [수동 설치 가이드](/docs/intro/installation/dependencies)를 따라
  각 종속성을 개별적으로 설치하거나 문제를 해결하세요.
</Callout>
