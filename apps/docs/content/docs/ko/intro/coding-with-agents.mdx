## Solana MCP 사용하기

Solana 개발에 AI를 활용하는 가장 강력한 방법은
[Solana Developer MCP](https://mcp.solana.com/)(Model Context Protocol)를 통하는 것입니다. 이
통합은 전문화된 Solana 지식을 IDE에 직접 제공하여
에이전트가 최신 Solana 문서에 접근할 수 있게 하고
개발을 더 빠르고 효율적으로 만들어 줍니다.

## Solana MCP란 무엇인가요?

Solana MCP는 Cursor 및 Windsurf와 같은 AI 지원 IDE에 직접
통합되는 특화된 AI 어시스턴트입니다. Solana 관련
질문을 하면 MCP 서버를 자동으로 조회하여 다음 출처에서
정확하고 최신의 정보를 제공합니다:

- [Solana 문서](/docs)
- [Anchor 프레임워크 문서](https://www.anchor-lang.com/docs)
- Solana
  [프로그램 예제](https://github.com/solana-developers/program-examples)
- [Solana Stack Exchange](https://solana.stackexchange.com/) 질문 및
  답변

## 사용 사례 예시

MCP를 활용하여 다음과 같은 작업을 할 수 있습니다:

- Solana 개념 질문하기
- 프로그램 오류 디버깅
- 모범 사례 권장 사항 받기
- 전문가 예제로 학습하기
- 전문가의 도움으로 더 빠르게 개발하기

## Solana MCP 설정하기

[Solana MCP 웹사이트](https://mcp.solana.com/)에서
자세한 설정 및 시작 가이드를 확인하세요.

## 스킬 사용을 선호하시나요?

스킬을 사용하고 싶다면 다음 명령어로 공식 Solana 스킬을 설치하세요:

```bash
npx skills add https://github.com/solana-foundation/solana-dev-skill
```

[Solana Agent Skills 라이브러리](/skills)에서 더 많은 재사용 가능한 워크플로를 살펴보세요.
