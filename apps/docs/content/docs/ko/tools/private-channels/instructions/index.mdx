이 섹션은 온체인 명령어 레퍼런스입니다. 대부분의 개발자는 생성된 TypeScript 클라이언트를 통해 이러한 명령어를 호출합니다. 오퍼레이터 툴링을 구축하거나, 커스텀 통합을 작성하거나, 명령어 수준의 오류를 디버깅하는 경우에만 이 내용이 필요합니다.

**에스크로 프로그램** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) - 예치, 오퍼레이터 프로비저닝, 메인넷 정산을 관리합니다:

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) -
  에스크로 인스턴스 PDA 초기화
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) - SPL 토큰
  민트 허용 목록 등록
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) - 허용
  목록에서 민트 제거
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) -
  오퍼레이터 프로비저닝
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) -
  오퍼레이터 권한 취소
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) -
  관리자 권한 이전
- [Deposit](/docs/tools/private-channels/instructions/deposit) - SPL 토큰을
  에스크로로 이동
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) -
  오퍼레이터가 메인넷으로의 출금을 정산
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) -
  오퍼레이터가 Sparse Merkle Tree를 교체

**출금 프로그램** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) - 프라이빗 채널 네트워크에서 실행됩니다:

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) -
  출금을 시작하기 위해 채널 측 잔액 소각

## 오류 코드

**에스크로 프로그램 - `PrivateChannelEscrowProgramError`**

| 코드                                         | 메시지                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | 유효하지 않은 이벤트 권한이 제공됨                 |
| `InvalidAta`                                 | 유효하지 않은 ATA가 제공됨                             |
| `InvalidMint`                                | 유효하지 않은 민트가 제공됨                            |
| `InvalidInstanceId`                          | 인스턴스 ID가 유효하지 않거나 규칙을 준수하지 않음    |
| `InvalidInstance`                            | 유효하지 않은 인스턴스가 제공됨                        |
| `InvalidAdmin`                               | 유효하지 않은 관리자가 제공됨                           |
| `TransferHookNotAllowed`                     | 전송 훅 확장이 허용되지 않음              |
| `InvalidOperatorPda`                         | 유효하지 않은 오퍼레이터 PDA가 제공됨                    |
| `InvalidTokenAccount`                        | 유효하지 않은 token account가 제공됨                   |
| `InvalidEscrowBalance`                       | 유효하지 않은 에스크로 잔액                           |
| `InvalidAllowedMint`                         | 유효하지 않은 허용 민트                             |
| `InvalidSmtProof`                            | 유효하지 않은 SMT 증명이 제공됨                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | 현재 트리 인덱스에 대한 트랜잭션 논스가 유효하지 않음 |
| `UnexpectedTreeIndex`                        | SMT 루트 재설정을 위한 현재 트리 인덱스가 예상과 다름 |

**출금 프로그램 - `PrivateChannelWithdrawProgramError`**

| 코드          | 메시지                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | 유효하지 않은 민트가 제공됨                       |
| `ZeroAmount`  | 출금 금액은 0보다 커야 합니다 |
