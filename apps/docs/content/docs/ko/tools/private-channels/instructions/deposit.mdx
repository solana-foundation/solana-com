---
title: 입금
description:
  사용자의 지갑에서 Private Channels 에스크로로 SPL 토큰을 전송합니다
---

사용자의 associated token account에서 에스크로의
associated token account로 SPL 토큰을 전송하며, 입금한 사용자의 채널 잔액(또는
선택적 수신자의 잔액)을 증가시킵니다.

## 계정

| 계정                          | 쓰기 가능 | 서명자 | 설명                                          |
| -------------------------------- | -------- | ------ | ---------------------------------------------------- |
| `payer`                          | ✓        | ✓      | 트랜잭션 수수료 납부자                        |
| `user`                           |          | ✓      | 입금을 수행하는 토큰 소유자                       |
| `instance`                       |          |        | 에스크로 인스턴스 PDA                                  |
| `mint`                           |          |        | SPL 토큰 민트                                       |
| `allowed_mint`                   |          |        | 해당 인스턴스에서 민트가 허용되었는지 검증하는 PDA |
| `user_ata`                       | ✓        |        | 사용자의 associated token account (출처)             |
| `instance_ata`                   | ✓        |        | 에스크로의 associated token account (목적지)      |
| `system_program`                 |          |        | System Program                                       |
| `token_program`                  |          |        | SPL Token Program                                    |
| `associated_token_program`       |          |        | Associated Token Program                             |
| `event_authority`                |          |        | `EmitEvent` CPI를 위한 이벤트 권한 PDA              |
| `private_channel_escrow_program` |          |        | 에스크로 프로그램 (CPI용 자기 참조)              |

## 파라미터

| 파라미터   | 타입             | 설명                                                                           |
| ----------- | ---------------- | ------------------------------------------------------------------------------------- |
| `amount`    | `u64`            | 입금할 토큰 수량 (토큰의 최소 단위 기준)                             |
| `recipient` | `Option<Pubkey>` | 선택적 온체인 수신자. `None`인 경우 입금한 사용자의 채널 잔액을 증가시킵니다 |

## 반환값

`TransactionBuilder`를 반환하며, 이를 사용하여 트랜잭션을
빌드하고 전송할 수 있습니다.

## 예시

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

// allowedMint and instanceAta are auto-derived from mint and instance
const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n,
  recipient: null
});
```

## 중요 참고 사항

- 프로그램 ID: `9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`
- Token-2022 민트의 경우, 기본값이 표준 SPL Token Program으로 설정되어 있으므로
  `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS`를 명시적으로 전달해야 합니다
- `allowed_mint` PDA가 존재해야 합니다 (`AllowMint`로 생성됨). 등록되지 않은
  민트를 입금하면 `InvalidAllowedMint` 오류가 발생합니다
- `recipient`가 `None`인 경우 입금한 사용자의 채널 잔액이 증가하며,
  값이 제공된 경우 지정된 지갑의 잔액이 대신 증가합니다
- `payer`와 `user` 모두 트랜잭션에 서명해야 합니다
- `instance_ata`는 이미 존재해야 합니다 (해당 민트에 대해 `AllowMint`로 생성됨)
