`Operator` PDA를 생성하여 새 오퍼레이터를 프로비저닝합니다. 이 호출 이후,
`operator` 지갑은 `ReleaseFunds` 및 `ResetSmtRoot`를 호출할 수 있습니다.

## 계정

| 계정                          | 쓰기 가능 | 서명자 | 설명                                                         |
| -------------------------------- | -------- | ------ | ------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | 수수료 납부자                                                           |
| `admin`                          |          | ✓      | 인스턴스 관리자                                                      |
| `instance`                       |          |        | 인스턴스 PDA                                                        |
| `operator`                       |          |        | 프로비저닝할 오퍼레이터 지갑                                        |
| `operator_pda`                   | ✓        |        | 오퍼레이터 PDA - `["operator", instance, operator]`에서 자동 파생됨 |
| `system_program`                 |          |        | System Program                                                      |
| `event_authority`                |          |        | 이벤트 권한 PDA                                                 |
| `private_channel_escrow_program` |          |        | 에스크로 프로그램                                                      |

## 매개변수

| 매개변수 | 타입 | 설명                                                                               |
| --------- | ---- | ----------------------------------------------------------------------------------------- |
| `bump`    | `u8` | `operator_pda`의 bump seed. 선택 사항: 생략 시 `Async` 클라이언트가 자동으로 파생합니다 |

> IDL에는 `discriminator: u8` 인수(값 `3`)가 포함되어 있으며, 이는 생성된 클라이언트에 의해 자동으로 설정되므로
> 수동으로 전달하지 않아야 합니다.

## 중요 사항

- `getAddOperatorInstructionAsync`를 사용하세요. `bump` 및
  `operator_pda`가 제공되지 않은 경우 자동으로 파생합니다. 이미 `bump`를
  직접 계산한 경우에는 동기 방식의
  `getAddOperatorInstruction` 변형도 사용할 수 있습니다
- 이 호출 이후, `operator` 지갑은 `ReleaseFunds` 및
  `ResetSmtRoot`를 호출할 수 있습니다
- `EmitEvent` CPI를 통해 이벤트를 발생시킵니다
