인스턴스에서 이전에 허용된 민트를 제거하여 해당 민트에 대한 새로운 입금을 차단합니다.
기존 입금은 영향을 받지 않습니다.

## 계정

| 계정                          | 쓰기 가능 | 서명자 | 설명                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | 수수료 납부자                                    |
| `admin`                          |          | ✓      | 인스턴스 관리자                               |
| `instance`                       |          |        | 인스턴스 PDA                                 |
| `mint`                           |          |        | 차단할 SPL 토큰 민트                      |
| `allowed_mint`                   | ✓        |        | AllowedMint PDA (이 명령어에 의해 종료됨) |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | 이벤트 권한 PDA                          |
| `private_channel_escrow_program` |          |        | 에스크로 프로그램                               |

이 명령어는 매개변수를 사용하지 않습니다.

## 중요 사항

- `allowed_mint` PDA를 종료합니다: 이 민트에 대한 새로운 `Deposit` 호출은
  `InvalidAllowedMint` 오류와 함께 실패합니다
- 이 민트에 대한 기존 채널 잔액은 영향을 받지 않습니다
- `EmitEvent` CPI를 통해 이벤트를 발생시킵니다
