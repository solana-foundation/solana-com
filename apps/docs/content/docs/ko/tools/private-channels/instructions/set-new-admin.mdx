새 지갑으로 관리자 권한을 이전합니다.

## 계정

| 계정                          | 쓰기 가능 | 서명자 | 설명                        |
| -------------------------------- | -------- | ------ | ---------------------------------- |
| `payer`                          | ✓        | ✓      | 수수료 납부자                          |
| `current_admin`                  |          | ✓      | 현재 관리자 (서명 필요)          |
| `instance`                       | ✓        |        | 인스턴스 PDA (관리자 필드 업데이트됨) |
| `new_admin`                      |          | ✓      | 관리자 권한을 받을 지갑     |
| `event_authority`                |          |        | 이벤트 권한 PDA                |
| `private_channel_escrow_program` |          |        | 에스크로 프로그램                     |

이 명령어는 매개변수를 사용하지 않습니다.

## 중요 사항

- **되돌릴 수 없는 단일 단계**: 현재 관리자는 새 관리자가 다시 `SetNewAdmin`을 호출하지 않는 한 역할을 되찾을 수 없습니다
- 호출 전 대상 주소를 반드시 확인하세요. 실행 취소 기능은 없습니다
- `EmitEvent` CPI를 통해 이벤트를 발생시킵니다
