---
title: RemoveOperator
description: Operator PDA를 닫아 운영자 권한을 취소합니다
---

`Operator` PDA를 닫아 운영자 권한을 취소합니다. 권한이 취소된 지갑은 더 이상
`ReleaseFunds` 또는 `ResetSmtRoot`를 호출할 수 없습니다.

## 계정

| 계정                          | 쓰기 가능 | 서명자 | 설명                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | 수수료 납부자                                 |
| `admin`                          |          | ✓      | 인스턴스 관리자                            |
| `instance`                       |          |        | 인스턴스 PDA                              |
| `operator`                       |          |        | 취소할 운영자 지갑                 |
| `operator_pda`                   | ✓        |        | 운영자 PDA (이 명령어에 의해 닫힘) |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | 이벤트 권한 PDA                       |
| `private_channel_escrow_program` |          |        | 에스크로 프로그램                            |

이 명령어는 매개변수를 사용하지 않습니다.

## 중요 사항

- `operator_pda`를 닫습니다. 권한이 취소된 지갑은 더 이상
  `ReleaseFunds` 또는 `ResetSmtRoot`를 호출할 수 없습니다
- 진행 중인 운영자 트랜잭션은 이 호출 이후
  `InvalidOperatorPda` 오류와 함께 실패합니다
- `EmitEvent` CPI를 통해 이벤트를 발생시킵니다
