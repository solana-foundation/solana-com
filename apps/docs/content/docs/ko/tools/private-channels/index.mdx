<Callout type="warning">
  프라이빗 채널은 보안 감사를 받지 않았으며, 충분한 보안 검토 없이 실제 자금이 포함된 프로덕션 환경에서의 사용은 권장하지 않습니다.
</Callout>

**프라이빗 채널은 Solana 기반 인터넷 자본 시장을 위한 엔터프라이즈 레이어입니다.** 결제 채널 내에서 프라이빗·즉각·무수수료 전송을 위한 구성 가능한 앱 레이어를 제공합니다. 사용자는 SPL 토큰을 온체인 에스크로 프로그램에 예치하고, 게이트웨이를 통해 오프체인으로 거래하며, Sparse Merkle Tree 증명을 통해 메인넷으로 정산합니다. 이를 통해 앱 개발자는 Solana 생태계를 벗어나지 않고도 즉각적이고 무수수료인 프라이빗 전송을 활용할 수 있습니다.

### 프라이빗 채널을 사용하는 이유

- **즉각적인 전송**: Solana 기본 TPS를 초과하는 오프체인 처리량; 전송은 블록이 확정될 때가 아닌 시퀀서가 처리하는 즉시 확인됩니다
- **전송당 수수료 없음**: 개별 채널 전송에 가스 비용 없음; 사용자는 온체인 입출금에 대해서만 비용을 지불합니다
- **프라이버시**: 채널 참여자 간의 전송은 Solana 메인넷에 기록되지 않습니다
- **허가된 접근**: JWT 인증을 통한 RBAC로 송수신 가능한 사용자를 제어할 수 있습니다
- **메인넷 정산**: 자금은 Sparse Merkle Tree 배제 증명을 통해 언제든지 Solana로 인출 가능하며, 에스크로 프로그램이 이를 온체인에서 강제합니다

전체 아키텍처, 데이터 흐름 다이어그램 및 보안 모델은 **[개요](/docs/tools/private-channels/overview)**를 참조하세요.

## 빠른 시작

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n, // 1 USDC
  recipient: null
});
// send via your preferred Solana client
```

TypeScript 클라이언트는 IDL에서 생성됩니다. 설치 안내를 참조하세요. Token-2022 민트의 경우, 기본값이 표준 SPL Token Program으로 설정되어 있으므로 `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS`를 명시적으로 전달해야 합니다.

## 활용 사례

- **기관 간 양자 결제** - 모든 전송이 온체인에 노출되지 않고 대규모 프라이빗 USDC 흐름이 필요한 은행 및 기관
- **고빈도 앱 레이어 전송** - 네이티브 Solana TPS를 초과하는 대규모에서 1초 미만의 무수수료 전송이 필요한 게임, 로열티, 소비자 앱
- **프라이버시 보호 토큰 흐름** - 거래 상대방 및 금액 프라이버시가 제품 요구 사항인 모든 활용 사례

**[네이티브 SPL 전송을 대신 사용해야 하는 경우](/docs/tools/private-channels/concepts/channels#when-to-use-private-channels)**
