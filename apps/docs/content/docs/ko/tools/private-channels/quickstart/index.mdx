이 빠른 시작 가이드는 Solana devnet에서 Private Channels의 전체 흐름을 안내합니다:
클라이언트 환경 설정, 에스크로에 SPL 토큰 입금, 두 지갑 간 오프체인 전송,
그리고 Solana 지갑으로 자금 출금까지 다룹니다.

이 가이드를 마치면 입금 -> 오프체인 전송 -> 출금의 전체 사이클을 이해하고
각 단계에 대한 TypeScript 코드를 직접 실행해 볼 수 있습니다.

<Callout type="info">
  이 빠른 시작 가이드는 Private Channels 인스턴스가 이미 배포되어
  devnet에서 실행 중이며, 해당 민트가 허용 목록에 등록되어 있다고 가정합니다. 먼저 배포가
  필요하다면 [운영자 가이드](/docs/tools/private-channels/operators)에서
  전체 설정 과정을 확인하세요. 초기 Docker 빌드에는 30~60분이 소요될 수 있습니다.
</Callout>

## 단계

1. **[설치](/docs/tools/private-channels/quickstart/installation)** -
   저장소를 클론하고 TypeScript 클라이언트를 생성합니다 (5분)
2. **[토큰 입금](/docs/tools/private-channels/quickstart/deposit)** -
   에스크로에 SPL 토큰을 입금합니다. 인덱서가 채널 잔액을 반영하는 데 약 15초가 소요됩니다
3. **[전송 보내기](/docs/tools/private-channels/quickstart/transfer)** -
   게이트웨이를 통해 오프체인 전송을 보냅니다. 1초 이내에 확인되며
   메인넷에는 전혀 영향을 주지 않습니다
4. **[자금 출금](/docs/tools/private-channels/quickstart/withdraw)** - 채널 측
   잔액을 소각하면 운영자가 몇 초 이내에 메인넷 지갑으로 자금을 정산합니다
