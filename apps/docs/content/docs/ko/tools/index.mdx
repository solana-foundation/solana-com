## 도구

<Cards>
  <Card title="Kora" href="/docs/tools/kora">
    Kora 페이마스터로 가스비 없는 트랜잭션과 토큰 결제 트랜잭션 플로우를
    구축하세요.
  </Card>
  <Card title="Keychain" href="/docs/tools/keychain">
    로컬 키, KMS, HSM, 지갑 백엔드에서 통합 서명 인터페이스를 사용하세요.
  </Card>
  <Card title="Commerce Kit" href="/docs/tools/commerce-kit">
    앱에 Solana 결제 컴포넌트와 커머스 플로우를 추가하세요.
  </Card>
  <Card title="Solana Pay" href="/docs/tools/solana-pay">
    Solana Pay 전송 및 트랜잭션 요청 플로우를 구현하세요.
  </Card>
  <Card title="Attestations" href="/docs/tools/attestations">
    온체인 계정에 연결된 오프체인 데이터에 대한 자격 증명, 스키마,
    어테스테이션을 생성하세요.
  </Card>
  <Card title="Private Channels" href="/docs/tools/private-channels">
    프라이빗 채널 제품 자료 및 통합 리소스를 검토하세요.
  </Card>
  <Card title="Surfpool" href="/docs/tools/surfpool">
    로컬 개발, 테스트, 코드형 인프라(IaC) 배포를 위한 solana-test-validator 대체
    솔루션입니다.
  </Card>
  <Card title="LiteSVM" href="/docs/tools/litesvm">
    validator 없이 Rust 및 TypeScript 환경에서 빠른 인프로세스 VM으로 Solana
    프로그램을 테스트하세요.
  </Card>
  <Card title="액션 및 블링크" href="/docs/tools/actions">
    Solana 트랜잭션을 공유 가능하고 메타데이터가 풍부한 링크로 변환하세요.
  </Card>
  <Card title="AI 도구" href="/docs/tools/ai">
    Solana와 함께 AI 코딩 어시스턴트 및 에이전트 프레임워크를 활용하세요.
  </Card>
</Cards>
