**Solana Keychain은 여러 키 관리 백엔드에 걸쳐 Solana 트랜잭션에 서명할 수 있는 통합 인터페이스를 제공합니다.** 로컬에서는 인메모리 키로 개발하고, 프로덕션에서는 서명 코드를 다시 작성하지 않고도 엔터프라이즈 키 관리, 클라우드 HSM 또는 관리형 월렛 서비스로 전환할 수 있습니다.

### Keychain을 사용해야 하는 이유는?

- **단일 인터페이스**: 모든 백엔드에서 하나의 `SolanaSigner` 기본 인터페이스를 사용하며,
  백엔드별로 서명, 재작성 후 서명, 서명 후 브로드캐스트 중 하나의 기능을 제공합니다
- **백엔드 교체**: 설정만으로 키 관리 제공업체를 변경할 수 있으며, 호출
  부분은 새 백엔드의 기능이 다른 경우(Crossmint 및 Fordefi 네이티브 모드)에만 변경하면 됩니다
- **사용하는 만큼만 포함**: Rust 기능 플래그, 백엔드별 npm 패키지, Python
  extras, 백엔드별 Go 모듈을 통해 필요한 백엔드만 포함할 수 있습니다
- **감사 완료**: Rust, TypeScript, Python, Go는
  [OtterSec](https://osec.io)의 감사를 받았습니다(옵트인 방식의 Ledger 백엔드는 범위에서 제외). 이전에
  [Accretion](https://accretion.xyz)이 Rust와 TypeScript를 감사한 바 있습니다.
  자세한 내용은
  [감사 현황](https://github.com/solana-foundation/solana-keychain/blob/main/audits/AUDIT_STATUS.md)을 참고하세요.

### 아키텍처

- **언어**: Rust, TypeScript, Python, Go를 동등하게 지원합니다(Ledger 백엔드는
  Rust 전용)
- **인터페이스**: `SolanaSigner` 기본 인터페이스(`pubkey`, `sign_message`, `is_available`)와
  백엔드별로 정확히 하나의 기능(`TransactionSigner`,
  `ModifyingSigner` 또는 `SendingSigner`)을 제공합니다
- **백엔드**: Memory, Vault, AWS KMS, GCP KMS, Privy, Turnkey, Fireblocks,
  CDP, Crossmint, Dfns, Openfort, Para, Utila, Fordefi, Ledger(Rust 전용,
  옵트인, 감사 미실시)
- **호환성**: `@solana/kit` 및 `@solana/signers` 8.1 이상(TypeScript) |
  `sdk-v2` / `sdk-v3` / `sdk-v4` 기능을 통한 `solana-sdk` 2.x, 3.x 또는 4.x
  (Rust, v1 트랜잭션은 `sdk-v4` 필요) | `solders`(Python) | `solana-go` v2
  (Go)

### 지원되는 백엔드

백엔드는 로컬 개발, 자체 호스팅 및 클라우드 키 관리, 매니지드 또는 MPC 지갑
서비스를 아우릅니다. 커스터디 모델을 비교하고 적합한 백엔드를 선택하려면
[백엔드 선택하기](/docs/tools/keychain/choosing-a-backend)를 참고하세요.

| 백엔드         | 사용 사례                            | Rust | TypeScript | Python | Go  |
| --------------- | ----------------------------------- | ---- | ---------- | ------ | --- |
| Memory          | 개발, 테스트                | ✓    | ✓          | ✓      | ✓   |
| HashiCorp Vault | 자체 호스팅 키 관리          | ✓    | ✓          | ✓      | ✓   |
| AWS KMS         | 클라우드 네이티브 (AWS)                  | ✓    | ✓          | ✓      | ✓   |
| GCP KMS         | 클라우드 네이티브 (GCP)                  | ✓    | ✓          | ✓      | ✓   |
| Privy           | 임베디드 지갑                    | ✓    | ✓          | ✓      | ✓   |
| Turnkey         | 비수탁형 키 관리        | ✓    | ✓          | ✓      | ✓   |
| Fireblocks      | 기관 수탁               | ✓    | ✓          | ✓      | ✓   |
| CDP             | Coinbase 개발자 플랫폼         | ✓    | ✓          | ✓      | ✓   |
| Crossmint       | Crossmint 매니지드 지갑           | ✓    | ✓          | ✓      | ✓   |
| Dfns            | Dfns 지갑 인프라          | ✓    | ✓          | ✓      | ✓   |
| Openfort        | Openfort 백엔드 지갑            | ✓    | ✓          | ✓      | ✓   |
| Para            | Para MPC 지갑                    | ✓    | ✓          | ✓      | ✓   |

| Fordefi         | Fordefi MPC 커스터디                 | ✓    | ✓          | ✓      | ✓   |
| Ledger          | 하드웨어 월렛(옵트인, 감사 미실시) | ✓    |            |        |     |

## 빠른 시작

### Rust

Rust 크레이트를 설치하세요:

```bash
cargo add solana-keychain
```

기본 사용법:

```rust
use solana_keychain::{Signer, SolanaSigner};

// Create a signer from any backend
let signer = Signer::from_memory("base58_private_key")?;
let pubkey = signer.pubkey();

// Transaction signing is a capability; `tx` is a VersionedTransaction
if let Some(tx_signer) = signer.as_transaction_signer() {
    let result = tx_signer.sign_transaction(&mut tx).await?;
}

// Or let the umbrella route any backend shape and supply the RPC hop yourself
let signature = signer
    .sign_and_send(&mut tx, |encoded| async move { broadcast(encoded).await })
    .await?;
```

- [Rust 가이드](/docs/tools/keychain/getting-started/rust) - 전체 설치 및 백엔드
  구성
- [Crates.io](https://crates.io/crates/solana-keychain) - Rust 크레이트

### TypeScript

TypeScript 패키지를 설치하세요:

```bash
pnpm add @solana/keychain
```

기본 사용법:

```typescript
import { createKeychainSigner } from "@solana/keychain";
import { signTransactionWithSigners } from "@solana/signers";

// Create any signer via the unified factory
const signer = await createKeychainSigner({
  backend: "vault",
  vaultAddr: "https://vault.example.com:8200",
  vaultToken: "hvs.xxxxx",
  keyName: "my-solana-key",
  publicKey: "base58_public_key"
});

// Sign an already-compiled transaction
const signedTx = await signTransactionWithSigners(
  [signer],
  compiledTransaction
);
```

- [TypeScript 가이드](/docs/tools/keychain/getting-started/typescript) -
  `@solana/keychain` 패키지
- [npm 패키지](https://www.npmjs.com/package/@solana/keychain) - npm 패키지

[Kit](https://github.com/anza-xyz/kit) 클라이언트에 Keychain 서명자를 `payer` 또는 `identity`로 설치하려면
`@solana/keychain-kit-plugin`을 사용하세요(Crossmint 및 Fordefi 네이티브 모드는 트랜잭션을 재작성하므로 제외됩니다).

### Python

패키지를 설치하세요(무거운 백엔드는 extras로 제공되며, 예: `solana-keychain[aws-kms]`):

```bash
pip install solana-keychain
```

기본 사용법:

```python
import os

from solana_keychain import VaultSignerConfig, create_vault_signer

signer = await create_vault_signer(
    VaultSignerConfig(
        api_base_url="https://vault.example.com:8200",
        token=os.environ["VAULT_TOKEN"],
        key_name="my-solana-key",
        public_key="base58_public_key",
    )
)

# tx is a solders VersionedTransaction
result = await signer.sign_transaction(tx)
```

- [Python 가이드](/docs/tools/keychain/getting-started/python) - 전체
  설치, extras 및 백엔드 설정
- [PyPI](https://pypi.org/project/solana-keychain/) - Python 패키지

### Go

각 백엔드는 독립된 Go 모듈이므로, 가져오는(import) 백엔드만 받게 됩니다:

```bash
go get github.com/solana-foundation/solana-keychain/go/signers/vault/v2@latest
```

기본 사용법:

```go
import "github.com/solana-foundation/solana-keychain/go/signers/vault/v2"

signer, err := vault.New(vault.Config{
	VaultAddr: "https://vault.example.com:8200",
	Token:     os.Getenv("VAULT_TOKEN"),
	KeyName:   "my-solana-key",
	Pubkey:    "base58_public_key",
})
if err != nil {
	return err
}

// tx is a *solana.Transaction from solana-go v2
res, err := signer.SignTransaction(ctx, tx)
```

- [Go 가이드](/docs/tools/keychain/getting-started/go) - 모듈, 기능 및
  백엔드 설정
- [pkg.go.dev](https://pkg.go.dev/github.com/solana-foundation/solana-keychain/go/core/v2) -
  Go 레퍼런스
