## 클록 시맨틱스

<Callout
  type="warn"
  title="타임스탬프는 밀리초 단위이며, 클록은 초 단위로 보고합니다"
>
  `surfnet_timeTravel`의 `absoluteTimestamp`는 JavaScript의 `Date.now()`처럼 **밀리초** 단위입니다. 그러나 프로그램이 읽는 `Clock` sysvar는 **초** 단위로 보고합니다. 클록에서 읽은 값을 그대로 치트코드에 다시 전달하면 1970년대 초로 이동하게 되며, 클록은 앞으로만 이동하기 때문에 해당 호출은 무시되지 않고 거부됩니다. 먼저 1000을 곱하세요.
</Callout>

클록 치트코드의 SDK 수준 동등 항목은 [타임 트래블](/docs/tools/surfpool/sdk/time-travel)을 참조하세요.
