---
title: 프로그램 배포
description: 메인넷에서 프로그램을 배포하기 위한 모범 사례
---

결제 인프라의 일부로 커스텀 Solana 프로그램을 배포하는 경우, 추가로 고려해야 할 사항이 있습니다.

## 배포 전 준비

- **Solana CLI 버전:** 최신 버전의 [Solana CLI](https://solana.com/docs/intro/installation)를 사용하고 있는지 확인하세요.
- **프로그램 keypair:** 프로그램은 메인넷과 devnet에서 서로 다른 주소를 갖습니다(동일한 keypair를 재사용하는 경우 제외). 애플리케이션 설정에 있는 모든 참조를 업데이트하세요. 프로그램 keypair는 안전한 곳에 보관하세요(`cargo clean`을 실행하면 프로그램 keypair가 삭제될 수 있습니다).
- **계정 초기화:** 프로그램에 관리자 계정, PDA 또는 기타 상태 계정이 필요한 경우, 사용자가 애플리케이션을 사용하기 전에 메인넷에 해당 계정들을 미리 생성해 두세요. 프로그램에 필요한 associated token account(ATA)도 마찬가지입니다.

## 배포 과정

- **버퍼 계정:** 용량이 큰 프로그램은 버퍼 계정을 통해 배포됩니다. `solana program deploy` 명령어가 이를 자동으로 처리하지만, 배포는 원자적(atomic)으로 이루어지지 않는다는 점을 알아 두세요. 중단되면 버퍼 계정을 복구하거나 닫아야 할 수 있습니다.
- **업그레이드 권한:** [멀티시그](https://docs.squads.so/main/basics/what-is-a-multisig)를 생성하고 이를 [Solana 프로그램의 업그레이드 권한](https://docs.squads.so/main/navigating-your-squad/developers-assets/programs)으로 지정하세요.
- **렌트:** 배포용 지갑에 모든 program account의 렌트 면제 최소 금액을 충당할 수 있는 충분한 SOL이 있는지 확인하세요.
- **검증:** 프로그램을 [검증](https://solana.com/docs/programs/verified-builds)하여 Solana 네트워크에 배포하는 실행 프로그램이 저장소의 소스 코드와 일치하는지 확인하세요.
