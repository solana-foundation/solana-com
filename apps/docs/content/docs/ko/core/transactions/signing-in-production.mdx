트랜잭션은 필요한 모든 서명자의 유효한
[서명](/docs/core/transactions/transaction-structure#signatures)이 포함되어 있어야만 실행됩니다. 로컬 개발 중에는 보통 해당 키를
[`Keypair`](/developers/cookbook/wallets/create-keypair)로 보관하고 직접 서명합니다. 프로덕션에서는
중요한 질문이 달라집니다. **개인 키는 어디에 보관되며, 누가 그 키로 서명을 승인할 수 있는가?**

<Callout type="warn">
  개인 키를 클라이언트 측 코드에 포함하거나, 프론트엔드에 번들로 넣거나,
  소스 관리에 커밋해서는 안 됩니다. 키를 획득한 사람은 누구든 해당 계정의 자금을 완전히 장악할 수 있습니다.
</Callout>

## 서명 방식

| 방식                  | 키가 보관되는 위치                                     | 서명 주체                                          | 적합한 용도                                                      |
| ------------------------- | ------------------------------------------------------- | -------------------------------------------------- | ------------------------------------------------------------- |
| **로컬 keypair**         | 머신의 파일 또는 환경 변수           | 사용자의 코드가 직접 서명                                | 로컬 개발, 테스트, CI                                  |
| **브라우저 지갑**        | 최종 사용자의 지갑 (예: Phantom, Solflare)          | 최종 사용자가 트랜잭션마다 서명                      | 사용자가 자신의 트랜잭션에 직접 서명하는 프론트엔드 dApp        |
| **클라우드 KMS / HSM**       | 하드웨어 기반 키 서비스 (AWS KMS, GCP KMS, Vault) | 백엔드가 서비스에 서명을 요청 | 백엔드 서비스, 트레저리 운영, 규제 환경 |
| **관리형 / MPC 지갑** | 제공업체의 인프라에 분할 또는 수탁되어 보관   | 제공업체가 사용자의 정책에 따라 공동 서명     | 임베디드 지갑, 승인 워크플로, 기관 수탁   |

로컬 keypair는 원본 키 자료를 애플리케이션 내부에 두는 유일한 방식입니다.
모든 프로덕션 방식은 키를 전용 인프라에 보관하고, 해당 인프라가 사용자를 대신해 서명하도록 요청합니다.

## 백엔드 서명

서버가 서명해야 하는 경우(수수료 지불, 프로그램 트랜잭션 전송, 트레저리 운영 등)에는
원본 keypair 대신 전용 키 관리 백엔드를 사용하세요. Solana Foundation은
[Keychain](/docs/tools/keychain)을 관리하고 있습니다. Keychain은 통합 서명 라이브러리(Rust, TypeScript, Python, Go)로, 위 표의 모든 백엔드(Memory,
HashiCorp Vault, AWS KMS, GCP KMS, Fireblocks, Privy, Turnkey, CDP, Crossmint,
Dfns, Para, Openfort, Utila, Fordefi)에 대해 하나의 `SolanaSigner` 인터페이스를 제공합니다.

인터페이스가 모든 백엔드에서 공유되므로, 로컬에서는 인메모리 키로 개발하고 구성만 변경하여 프로덕션 백엔드로 전환할 수 있으며,
애플리케이션 코드를 다시 작성할 필요가 없습니다(Crossmint처럼 대신 브로드캐스트해 주는 백엔드는
대신 서명 후 전송(sign-and-send) 경로로 호출합니다). Keychain은
[`@solana/kit`](/docs/clients/official/javascript), 
[Rust SDK](/docs/clients/official/rust), `solders`(Python), `solana-go` v2
(Go)와 호환됩니다.
