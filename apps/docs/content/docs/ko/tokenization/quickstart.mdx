## devnet을 대상으로 지정하기

RPC URL을 devnet용으로 교체하고 [faucet](/developers/cookbook/development/airdrops-and-faucets)에서 payer에 자금을 공급하세요:

```ts
solanaRpc({
  rpcUrl: "https://api.devnet.solana.com",
  rpcSubscriptionsUrl: "wss://api.devnet.solana.com"
});
```

그 외에는 모두 동일합니다. mainnet에서 동일한 구성을 사용하기 전에, 해당 자산의 권한 관리, 컴플라이언스 운영, 모니터링을 계획하세요.
