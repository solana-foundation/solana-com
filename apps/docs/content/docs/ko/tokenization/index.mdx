Solana는 토큰화된 자산을 대규모로 발행하고 운영하기 위해 특별히 설계되었습니다:
1초 미만의 최종 확정성, $0.001 미만의 수수료, 그리고 다른 체인에서는 커스텀 스마트 컨트랙트가 필요한 기본 컴플라이언스 제어 기능 - 전송 제한, 일시 중지 기능, 기밀 전송, 영구 위임 - 을 갖춘 토큰 표준을 제공합니다.

## 통합 구조

Solana의 토큰화된 자산은 [Token-2022 program](/docs/tokens)과 그 [확장 기능](/docs/tokens/extensions)을 기반으로 구축됩니다 - 핵심 문서에 설명된 동일한 기본 요소입니다. 이 섹션은 워크플로우 중심으로 구성되어 있으며, 각 페이지는 작업을 처음부터 끝까지 안내하고 전체 API 표면이 필요할 때 기본 확장 기능 레퍼런스로 연결됩니다.
