---
title: "빠른 시작: CLI로 토큰 만들기"
description:
  Create a token, open a token account, mint supply, and transfer tokens using
  the SPL Token CLI on devnet.
---

이 빠른 시작 가이드는 _sh`spl-token`_ CLI를 사용하여 토큰의 전체 생명주기를 안내합니다. mint account를 생성하고, 토큰을 보관할 수 있는 계정을 만들고, 토큰 100개를 발행한 후 일부를 다른 지갑으로 전송합니다.

[Solana Playground](https://beta.solpg.io/)에서 브라우저로 명령어를 실행하거나, `cargo install spl-token-cli`로 CLI를 로컬에 설치하세요. 출력에 표시되는 주소는 아래 예시와 다를 수 있습니다.

## 1. 데브넷 연결

Solana Playground에서 지갑을 생성하거나 연결한 후, 데브넷을 선택하고 계정 보증금 및 트랜잭션 수수료를 위한 SOL을 요청하세요:

```terminal
$ solana config set --url devnet
$ solana airdrop 2
```

데브넷 토큰은 테스트 목적으로만 사용하세요. 실제 금전적 가치는 없습니다.

## 2. 토큰 생성

토큰을 식별하는 mint account를 생성합니다:

```terminal
$ spl-token create-token
```

출력에서 토큰 주소를 복사하세요. 이것이 이후 명령어에서 사용할 민트 주소입니다. 새로운 민트는 공급량 0으로 시작합니다.

```terminal
$ spl-token supply <MINT_ADDRESS>
```

## 3. token account 생성

잔액을 보유하려면 지갑에 해당 민트에 대한 token account가 필요합니다:

```terminal
$ spl-token create-account <MINT_ADDRESS>
```

이 명령어는 지갑 주소와 민트에서 파생된 주소를 가진
[associated token account](/docs/tokens#associated-token-account)를 생성합니다.

## 4. 토큰 발행

associated token account에 토큰 100개를 발행합니다:

```terminal
$ spl-token mint <MINT_ADDRESS> 100
$ spl-token balance <MINT_ADDRESS>
```

이 작업에는 민트 권한자의 서명이 필요합니다. 발행 시 token account 잔액과 민트에 기록된 총 공급량이 모두 증가합니다.

## 5. 토큰 전송

다른 데브넷 지갑으로 토큰 10개를 전송합니다. _sh`--fund-recipient`_ 옵션은 수신자의 associated token account가 없을 경우 자동으로 생성합니다:

```terminal
$ spl-token transfer <MINT_ADDRESS> 10 <RECIPIENT_WALLET_ADDRESS> --fund-recipient
```

전송은 발신자와 수신자의 token account 잔액을 변경하며, 민트의 총 공급량은 변경되지 않습니다.

## 선택 사항: Token-2022 메타데이터 추가

새로운 Token-2022 민트에 이름, 심볼, URI를 직접 저장하려면 메타데이터 확장 기능을 활성화하여 생성하세요:

```terminal
$ spl-token create-token \
  --program-id TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb \
  --enable-metadata
```

그런 다음 해당 명령어로 출력된 새 민트 주소를 사용하세요:

```terminal
$ spl-token initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  "EXAMPLE" \
  "https://example.com/token.json"
```

URI는 공개 JSON 메타데이터 문서를 반환해야 합니다. 계정 모델과 코드 예시는
[Token-2022 metadata](/docs/tokens/extensions/metadata)를 참고하세요.
