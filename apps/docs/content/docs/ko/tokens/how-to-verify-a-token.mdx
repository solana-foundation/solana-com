# 토큰을 검증하고 Solana Explorer에 표시되게 하는 방법

토큰 생성자들이 자주 묻는 질문은 다음과 같습니다. _"Solana Explorer에서 검색해도 내 토큰이 표시되지 않는 이유는 무엇이며, 어떻게 검증받을 수 있나요?"_

간단히 말하면, Solana Explorer는 자체적인 단일 검증 프로세스를 운영하지 않습니다. 대신 **여러 독립 검증 제공업체를 집계**합니다. 토큰이 이러한 제공업체 중 **어느 하나**를 통해 검증되면 Explorer 검색 결과에 표시되고 검증 정보가 나타납니다.

이 가이드에서는 각 제공업체, "검증됨"이 의미하는 것과 의미하지 않는 것, 그리고 토큰을 검증받는 방법을 설명합니다.

## "검증됨"의 의미(그리고 의미하지 않는 것)

검증은 특정 이름, 심볼, 민트 주소에 대해 해당 토큰이 **정식/올바른 토큰**임을 확인합니다. Solana에서는 누구나 어떤 이름으로든 토큰을 민트할 수 있으므로, 사용자가 사칭 토큰과 중복 토큰을 피하는 데 도움이 됩니다.

검증은 프로젝트에 대한 보증이 **아니며**, 토큰의 가치, 안전성 또는 적법성에 대한 보장도 **아닙니다**. 항상 직접 조사하세요.

## Solana Explorer 뒤의 검증 제공업체

Solana Explorer는 다음과 같은 독립 검증자를 확인합니다. 이들 중 어느 곳에든 등록되면(RugCheck는 자동이며, 나머지는 조치가 필요함) 토큰이 Explorer 검색에 표시됩니다.

### 1. RugCheck(자동)

[RugCheck](https://rugcheck.xyz)는 자동 온체인 분석을 수행하고 토큰을 자동으로 추적합니다. 자동으로 이루어지므로 일반적으로 별도로 제출할 필요가 없습니다. RugCheck는 온체인 위험 신호(민트/동결 권한, 보유자 분포, 유동성 등)를 평가하고 자체적으로 토큰을 추적합니다.

특정 스테이블코인에는 특별 처리가 적용되며, 프로젝트는 적절한 처리를 위해 RugCheck 팀에 직접 문의할 수 있습니다.

예시 토큰 페이지:
[`rugcheck.xyz/tokens/<mint>`](https://rugcheck.xyz/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 2. Jupiter

[Jupiter](https://jup.ag)는 Solana 생태계 전반(DEX, 지갑, 스크리너)에 널리 통합된 검증 토큰 목록(VRFD)을 유지합니다. 검증된 토큰은 Jupiter 제품과 파트너 플랫폼 전반에서 초록색 체크 표시를 받습니다.

검증을 받으려면 토큰을 제출하여 검토를 받으세요.

- [verified.jup.ag/tokens](https://verified.jup.ag/tokens)에서 제출
- 누구나 토큰을 제출할 수 있습니다(프로젝트 팀만 가능한 것은 아님).
- 선택적으로 프로젝트의 X 계정을 연결하여 토큰의 민트 주소를 특정 계정과 연결할 수 있습니다.
- Jupiter는 단일 지표를 확인하는 대신 유동성, 메타데이터 표준 준수 여부 및 기타 신호를 종합적으로 검토합니다.

예시 토큰 페이지:
[`jup.ag/tokens/<mint>`](https://jup.ag/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 3. CoinGecko

[CoinGecko](https://www.coingecko.com) 검증은 토큰을 시장 데이터와 함께 등록합니다. CoinGecko에서 검증할 때는 다운스트림 통합에서 가격을 올바르게 확인할 수 있도록 토큰의 **민트 주소**(CoinGecko 양식에서는 이를 "컨트랙트 주소"라고 표시)를 반드시 포함하세요.

공식 CoinGecko 등록/업데이트 가이드를 따르세요.

- [CoinGecko 등록 및 업데이트 요청을 위한 검증 가이드](https://support.coingecko.com/hc/en-us/articles/23725417857817-Verification-Guide-for-Listing-Update-Requests-on-CoinGecko)

예시 코인 페이지:
[`coingecko.com/en/coins/<token>`](https://www.coingecko.com/en/coins/usdc)

### 4. Solflare

[Solflare](https://solflare.com)는 Solana Explorer의 검증 프레임워크에서 독립 validator입니다. 실제로 Solflare의 토큰 등록 기준은 Jupiter의 기준과 크게 겹치는데, Solflare의 인앱 스왑 목록이 Jupiter 애그리게이터를 기반으로 하기 때문입니다. 새 토큰이 표시되려면 일반적으로 다음 조건을 충족해야 합니다.

- Metaplex Token Metadata 표준을 따르는 메타데이터가 있는 Solana 블록체인의 유효한 토큰이어야 합니다.
- 충분한 유동성(거래에 사용할 수 있는 토큰의 최소 USD 가치)이 있어야 합니다.
- 일반적인 스왑에서 가격 영향을 허용 가능한 한도 내로 유지해야 합니다.

이러한 중복성 때문에 Jupiter 검증을 완료한 토큰은 별도 제출 없이도 Solflare에서 이미 자격을 갖추는 경우가 많습니다. 따라서 일반적으로 Solflare를 추가 수동 단계로 다룰 필요는 없습니다. 기준이 충족되면 토큰은 보통 몇 분 내에 표시됩니다. 참고:

- [Solflare에서 토큰을 찾을 수 없습니다](https://help.solflare.com/en/articles/9260147-i-cannot-find-a-token-in-solflare)

예시 토큰 페이지:
[`solflare.com/prices/<name>/<mint>`](https://www.solflare.com/prices/usd-coin/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/)

### 5. Bluprynt(향상된 KYC)

[Bluprynt](https://app.bluprynt.com/register/account)는 KYC 프로토콜을 통한 향상된 검증 경로를 제공합니다. 이는 더 강력한 검증 신호를 원하는 프로젝트에 적합한, 더 엄격하고 신원 기반의 프로세스입니다.

- [Solana Explorer용 Bluprynt 온보딩](https://app.bluprynt.com/register/account)을 통해 등록

예시 검증 자산 페이지:
[`verified.bluprynt.com/verified-assets/<mint>/solana`](https://verified.bluprynt.com/verified-assets/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/solana)

## 전체 과정이 함께 작동하는 방식

- **RugCheck**는 온체인 분석을 통해 자동으로 이루어지므로 제출이 필요 없습니다.
- **Jupiter, CoinGecko, Solflare, Bluprynt**는 각각 해당 프로세스를 제출/완료해야 합니다.
- 토큰이 이러한 제공업체 중 **최소 하나**에서 검증되는 즉시 **Solana Explorer** 검색에 표시되고 검증 세부 정보가 나타납니다.

토큰이 아직 Explorer 검색에 표시되지 않는다면, 가장 빠른 방법은 일반적으로 Jupiter 검증에 제출하거나 CoinGecko 등록을 완료하는 것입니다. 두 서비스 모두 생태계 전반에 널리 통합되어 있기 때문입니다.

## 검증 성공 가능성을 높이는 사전 요건

제공업체와 관계없이, 다음과 같은 온체인 기본 요소가 갖춰져 있으면 검증 성공 가능성이 훨씬 높아집니다.

- **유효한 메타데이터**: 토큰에는 Metaplex Token Metadata 표준(이름, 심볼, 로고 URI)을 따르는 온체인 메타데이터가 있어야 합니다.
- **유동성**: 토큰이 거래되고 평가될 수 있도록 지원되는 DEX에 충분한 유동성을 제공하세요.
- **올바른 민트 주소**: 제공업체에 제출할 때는 항상 토큰의 **민트 주소**를 사용하세요(일부 제공업체 양식에서는 "컨트랙트 주소"라고 표시됨).

## 요약

Solana Explorer는 여러 독립 검증자, 즉 **RugCheck**(자동), **Jupiter**, **CoinGecko**, **Solflare**, **Bluprynt**(KYC)를 집계합니다. 이들 중 어느 하나를 통해 검증되면 토큰을 Explorer 검색에서 찾을 수 있습니다. 검증은 정식 토큰 신원을 확인하는 것이며 보증이 아니므로, 사용자는 항상 직접 조사해야 합니다.
