Als je afkomstig bent van `@solana/web3.js` (legacy), `@solana/wallet-adapter-*`,
of de eerdere framework-kit-pakketten (`@solana/client`, `@solana/react-hooks`,
`@solana/web3-compat`), raden we je aan te migreren naar `@solana/kit`-plugins of
`@solana/web3.js` v3 (of hoger).

Deze pagina koppelt de concepten die je al kent aan hun Kit-equivalenten.

## Conceptmapping

| web3.js (legacy) / wallet-adapter      | Kit                                                                  |
| -------------------------------------- | -------------------------------------------------------------------- |
| `new Connection(url)`                  | `createSolanaRpc(url)`, of `.use(solanaRpc({ rpcUrl }))` op een client |
| `PublicKey`                            | `Address` — converteer een string met `address("...")`                    |
| `Keypair`                              | `generateKeyPairSigner()` of de `@solana/kit-plugin-signer`-plugins |
| `SystemProgram.transfer(...)`          | `getTransferSolInstruction(...)` van `@solana-program/system`       |
| `LAMPORTS_PER_SOL` rekenkunde                | `lamports(...)` van `@solana/kit`                                   |
| `Transaction` / `VersionedTransaction` | Transactieberichten gebouwd en samengesteld door de transactieplanner     |
| `sendAndConfirmTransaction(...)`       | `client.sendTransaction([...])` (planner ondertekent, verstuurt en bevestigt) |
| `@solana/wallet-adapter-*`             | `@solana/kit-plugin-wallet` + Wallet Standard-detectie              |

web3.js v3 behoudt de hierboven genoemde klassegebaseerde namen — `Connection`, `Keypair`,
`Transaction`, `PublicKey` — als dunne wrappers rond de interne onderdelen van Kit, dus de Kit-
kolom beschrijft ook wat die klassen in v3 onder de motorkap doen.

## Afkomstig van web3.js?

Als je een grote `@solana/web3.js` (legacy) codebase onderhoudt en een volledige herschrijving
naar Kit niet haalbaar is, vormt web3.js v3 de brug. Installeer het met
`@solana/web3.js@3`. Het bouwt de klassieke klassegebaseerde API — `Connection`,
`Keypair`, `Transaction`, `PublicKey` — opnieuw op bovenop de interne onderdelen van `@solana/kit`.
Omdat het op Kit draait, is de interoperabiliteit hecht: `PublicKey` is het primaire adrestype
en de methode `.toBase58()` geeft Kits branded `Address`-string terug, en een v3
`Keypair` implementeert Kits `KeyPairSigner`, zodat je die rechtstreeks kunt doorgeven aan Kit-
API's, plugins en door Codama gegenereerde clients.

<Callout type="warn" title="v1-transacties en web3.js (legacy)">
  Als je v1-transacties verstuurt met web3.js, moet je v3 of hoger gebruiken.
</Callout>

Voor de migratie zelf verwijzen we naar de officiële
[migratiegids van web3.js v1 → v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md).

## Wallets

Kit gebruikt geen wallet-adapter. `@solana/kit-plugin-wallet` ontdekt Wallet
Standard-wallets en stelt ze beschikbaar via `client.wallet` en de
[React hooks](/docs/frontend/react-hooks). Moderne wallets (Phantom, Solflare,
Backpack en anderen) melden zichzelf aan via Wallet Standard, dus er is geen
per-wallet adapterpakket vereist.

Je kunt ook vooraf gebouwde tools gebruiken zoals
[@solana/connector](https://www.npmjs.com/package/@solana/connector), die
Kit-primitieven rechtstreeks gebruikt om verbinding te maken met wallets.

<Callout type="info" title="Nog op wallet-adapter?">
  Als je een app onderhoudt die gebouwd is op `@solana/wallet-adapter-*` en nog
  niet klaar bent om te migreren, blijft de [wallet-adapter
  repository](https://github.com/anza-xyz/wallet-adapter) de referentie voor dat
  stack. Voor alles wat nieuw is, geef de voorkeur aan de Kit wallet-plugin.
</Callout>
