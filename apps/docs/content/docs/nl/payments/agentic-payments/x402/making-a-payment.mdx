Gebruik [Pay](https://pay.sh) om een x402 V2-API uit te voeren en Claude Code een
betalingsbewuste HTTP-client te geven. De API, de payer-wallet en de settlement maken allemaal gebruik van de
Solana-sandbox, dus voor deze walkthrough heb je geen account of echte middelen nodig.

Je hebt een terminal nodig, plus Pay en Claude Code geïnstalleerd.

## 1. Pay installeren

Installeer op macOS het vooraf gebouwde binaire bestand:

```bash
brew install pay
pay --version
```

Installeer op andere platforms het npm-pakket:

```bash
npm install --global @solana/pay
pay --version
```

## 2. Een x402-sandbox-API starten

Maak `x402-demo.yaml` aan:

```yaml filename=x402-demo.yaml
name: x402-demo
subdomain: x402-demo
title: "x402 Demo"
description: "Minimal x402 V2 sandbox endpoint."
category: devtools
version: v1
routing:
  type: respond
operator:
  currencies:
    usd: ["USDC"]
  network: "localnet"
  fee_payer: true
endpoints:
  - method: GET
    path: "report"
    description: "Return a sandbox report."
    metering:
      schemes: [x402-exact]
      dimensions:
        - direction: usage
          unit: requests
          scale: 1
          tiers:
            - price_usd: 0.001
```

Start de API en laat deze draaien:

```bash
pay --sandbox server start x402-demo.yaml --bind 127.0.0.1:1402
```

Door het `x402-exact`-schema wordt dit een endpoint dat uitsluitend x402 ondersteunt. De sandbox-modus maakt
tijdelijke operator- en payer-accounts automatisch aan en voorziet ze van saldo.

## 3. De agent starten met Pay

Start in een andere terminal Claude Code in sandbox-modus:

```bash
pay --sandbox claude
```

Pay koppelt zijn lokale MCP-tools aan de agentsessie. De agent ontvangt geen
privésleutel.

## 4. Eén x402-verzoek uitvoeren

Plak deze prompt in de agent:

```text
Use Pay to make exactly one sandbox x402 API request to
http://127.0.0.1:1402/report.

Before paying, show me the amount and ask for approval. Then return the API
result and payment receipt. Do not make any other paid requests.
```

Het verzoek doorloopt één volledige x402 V2-betalingscyclus:

1. De API retourneert `402 Payment Required` met een `PAYMENT-REQUIRED`-challenge.
2. Pay valideert de x402-vereisten en toont de betalingsvoorwaarden.
3. Na goedkeuring ondertekent de sandbox-wallet en probeert Pay het verzoek opnieuw met
   `PAYMENT-SIGNATURE`.
4. De API retourneert het resultaat met een `PAYMENT-RESPONSE`-bevestiging.

Er worden geen echte middelen verplaatst. Als je de goedkeuring weigert, wordt het verzoek gestopt.

Ga verder met [x402 op Solana](/docs/payments/agentic-payments/x402) om een
x402 V2-client en resourceserver te bouwen, of
[word een x402-facilitator](/docs/tools/x402-facilitator).
