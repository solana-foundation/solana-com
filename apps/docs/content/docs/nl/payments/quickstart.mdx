Je eindigt met een React-component die een Solana Pay-QR-code toont voor een USDC-betaling, wacht tot de betaling binnenkomt en controleert of die overeenkomt met wat je hebt gevraagd. Je hebt Node.js 20+, een React- of Next.js-app (een nieuwe `create-next-app` volstaat) en een mobiele wallet die is ingesteld op devnet nodig. Vul die aan met devnet-USDC van [faucet.circle.com](https://faucet.circle.com) en devnet-SOL van [faucet.solana.com](https://faucet.solana.com) om de transactiekosten te dekken.

<Callout type="caution">
  `@solana/pay` is momenteel in beta. API's kunnen veranderen vóór de stabiele release.
</Callout>

## 1. Installeer Solana Pay

```bash
pnpm add @solana/pay@beta @solana/kit
```

## 2. Voeg de betaal-QR-code toe

De component maakt een unieke referentie voor de bestelling aan, codeert die in een [transfer request](/docs/tools/solana-pay/quickstart/transfer-requests)-URL en rendert de URL als QR-code. Daarna wacht de component op een transactie die de referentie bevat en valideert die de ontvanger, het bedrag en het token voordat de bestelling als betaald wordt gemarkeerd. Stel `MERCHANT_WALLET` in op een adres dat je zelf beheert:

```tsx
"use client";

import { useEffect, useRef, useState } from "react";
import {
  address,
  createSolanaRpc,
  createSolanaRpcSubscriptions,
  generateKeyPair,
  getAddressFromPublicKey
} from "@solana/kit";
import {
  createQR,
  encodeURL,
  validateTransfer,
  watchReference
} from "@solana/pay";

const MERCHANT_WALLET = address("your-wallet-address");
const USDC_DEVNET = address("4zMMC9srt5Ri5X14GAgXhaHii3GnPAEERYPJgZJDncDU");
const AMOUNT = 1;

const rpc = createSolanaRpc("https://api.devnet.solana.com");
const rpcSubscriptions = createSolanaRpcSubscriptions(
  "wss://api.devnet.solana.com"
);

export function Checkout() {
  const qrRef = useRef<HTMLDivElement>(null);
  const [signature, setSignature] = useState<string | null>(null);

  useEffect(() => {
    const abortController = new AbortController();

    async function startPayment() {
      const keyPair = await generateKeyPair();
      const reference = await getAddressFromPublicKey(keyPair.publicKey);

      const url = encodeURL({
        recipient: MERCHANT_WALLET,
        amount: AMOUNT,
        splToken: USDC_DEVNET,
        reference,
        label: "My Store",
        message: "Order #1001"
      });

      if (abortController.signal.aborted) return;

      if (qrRef.current) {
        qrRef.current.innerHTML = "";
        createQR(url, 300).append(qrRef.current);
      }

      const result = await watchReference(rpcSubscriptions, reference, {
        abortSignal: abortController.signal
      });
      if (result.err) throw new Error("Payment transaction failed");

      await validateTransfer(rpc, result.signature, {
        recipient: MERCHANT_WALLET,
        amount: AMOUNT,
        splToken: USDC_DEVNET,
        reference
      });
      setSignature(result.signature);
    }

    startPayment().catch((error) => {
      if (!abortController.signal.aborted) console.error(error);
    });

    return () => abortController.abort();
  }, []);

  if (signature) return <p>Payment confirmed: {signature}</p>;
  return <div ref={qrRef} />;
}
```

`amount` is in tokeneenheden, dus `1` vraagt 1 USDC aan. Laat `splToken` weg om in plaats daarvan SOL aan te vragen.

## 3. Ontvang een betaling

Start je app, scan de QR-code met je wallet en keur de betaling goed. Zodra de transactie is bevestigd en de validatie doorstaat, toont de component de transactiehandtekening. Die handtekening is je bewijs van betaling: zoek hem op met [getTransaction](/docs/rpc/http/gettransaction) of in een willekeurige explorer.

<Callout type="warn">
  Validatie in de browser is prima voor een demo. Valideer betalingen op je server voordat je echte bestellingen afhandelt. Zie [betalingen verifiëren](/docs/payments/accept-payments/verification-tools).
</Callout>
