## Verbinden met devnet

Vervang de RPC-URL's door die van devnet en financier de betaler via een
[faucet](/developers/cookbook/development/airdrops-and-faucets):

```ts
solanaRpc({
  rpcUrl: "https://api.devnet.solana.com",
  rpcSubscriptionsUrl: "wss://api.devnet.solana.com"
});
```

Al het overige blijft ongewijzigd. Voordat je dezelfde configuratie op het mainnet gebruikt, dien je het beheer van bevoegdheden, nalevingsoperaties en monitoring voor het asset te plannen.
