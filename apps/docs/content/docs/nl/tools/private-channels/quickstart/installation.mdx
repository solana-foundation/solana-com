## Vereisten

- Rust 1.91+
- Solana CLI 3.1.13 (Agave):
  `sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.13/install)"`
- Node.js 24.7.0+
- pnpm 10.15.1+: `npm install -g pnpm@10.15.1`

## De repository klonen

```bash
git clone https://github.com/solana-foundation/solana-private-channels.git
cd solana-private-channels
```

## TypeScript-clients genereren

De TypeScript-clients worden **niet** gepubliceerd op npm. Ze moeten worden gegenereerd vanuit
de IDL met behulp van Codama.

```bash
# Escrow program client
cd private-channel-escrow-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..

# Withdraw program client
cd private-channel-withdraw-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..
```

Gegenereerde clients komen terecht in:

- `private-channel-escrow-program/clients/typescript/src/generated/`
- `private-channel-withdraw-program/clients/typescript/src/generated/`

Importeer vanuit deze lokale paden in je applicatie; er is geen
`@private-channels/client`-pakket op npm. Codevoorbeelden in dit gedeelte gebruiken een
relatief pad (`../private-channel-escrow-program/...`) dat ervan uitgaat dat je code
naast de gekloonde repository staat; pas het aan zodat het overeenkomt met de locatie waarvan je
werkelijk importeert in je eigen project.
