---
title: SMT Root resetten
description:
  Roteert de Sparse Merkle Tree en reset de opnameboom voor een nieuwe boomepoch
---

Operator-only instructie die de Sparse Merkle Tree roteert door
`Instance.current_tree_index` te verhogen en de opnamewortel te resetten, waardoor een nieuwe
epoch van 65.536 opnames mogelijk wordt.

<Callout type="info">
  Het escrow-programma migreert van dit Sparse Merkle Tree-ontwerp naar een
  on-chain nonce-bitmap (upstream bijgehouden), waarbij deze instructie
  `RotateBitmap` wordt. Deze pagina is accuraat voor het huidige escrow-programma en
  wordt herzien zodra die wijziging van kracht wordt.
</Callout>

## Accounts

| Account                          | Beschrijfbaar | Ondertekenaar | Beschrijving                                            |
| -------------------------------- | -------- | ------ | ------------------------------------------------------ |
| `payer`                          | ✓        | ✓      | Vergoedingsbetaler                                              |
| `operator`                       |          | ✓      | Operator-ondertekenaar                                        |
| `instance`                       | ✓        |        | Escrow-instantie PDA (`current_tree_index` verhoogd) |
| `operator_pda`                   |          |        | Operator PDA die bewijst dat de ondertekenaar is ingericht         |
| `event_authority`                |          |        | Event-autoriteit PDA voor `EmitEvent` CPI                |
| `private_channel_escrow_program` |          |        | Escrow-programma (zelfverwijzing voor CPI)                |

## Parameters

| Parameter                     | Type  | Beschrijving                                                              |
| ----------------------------- | ----- | ------------------------------------------------------------------------ |
| `expected_current_tree_index` | `u64` | Replay-beveiliging; moet overeenkomen met `Instance.current_tree_index`, anders mislukt de aanroep |

## Retourwaarde

Retourneert een `TransactionBuilder` die kan worden gebruikt om de
transactie te bouwen en te verzenden.

## Voorbeeld

```typescript
import { getResetSmtRootInstruction } from "../private-channel-escrow-program/clients/typescript/src/generated";

const resetIx = getResetSmtRootInstruction({
  payer: operatorPayerSigner,
  operator: operatorSigner,
  instance: instancePda,
  operatorPda: operatorPdaAddress,
  eventAuthority: eventAuthorityPda,
  privateChannelEscrowProgram: ESCROW_PROGRAM_ID,
  expectedCurrentTreeIndex: currentTreeIndex // u64
});
```

## Belangrijke opmerkingen

- Alleen voor operators: vereist een geldige `operator_pda`; geeft anders `InvalidOperatorPda`
  terug
- `expected_current_tree_index` moet gelijk zijn aan `Instance.current_tree_index` op het moment van aanroep;
  een verouderde waarde geeft `UnexpectedTreeIndex` terug, als beveiliging tegen het opnieuw uitvoeren van een
  reset die al heeft plaatsgevonden
- Verhoogt `Instance.current_tree_index`; nonces die geldig waren in de vorige boomepoch worden ongeldig na rotatie
- De `operator-private-channel`-service roept dit automatisch aan wanneer
  `transaction_nonce % 65536 == 0` (en `nonce > 0`), wat het begin van een
  nieuwe epoch signaleert; dit hoeft onder normale omstandigheden niet handmatig te worden aangeroepen
- Na rotatie wordt de opnamewortel teruggezet naar de lege boom, zodat nieuwe
  opnames beginnen vanuit een nieuwe SMT
- Verzendt een event via `EmitEvent` CPI
