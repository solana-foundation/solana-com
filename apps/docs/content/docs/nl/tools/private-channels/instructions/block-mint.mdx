Verwijdert een eerder toegestane mint uit de instantie, waardoor nieuwe stortingen voor
die mint worden voorkomen. Bestaande stortingen blijven onaangetast.

## Accounts

| Account                          | Schrijfbaar | Ondertekenaar | Beschrijving                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | Betaler van kosten                                    |
| `admin`                          |          | ✓      | Instantiebeheerder                               |
| `instance`                       |          |        | Instantie PDA                                 |
| `mint`                           |          |        | SPL-token mint om te blokkeren                      |
| `allowed_mint`                   | ✓        |        | AllowedMint PDA (gesloten door deze instructie) |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | Event authority PDA                          |
| `private_channel_escrow_program` |          |        | Escrow-programma                               |

Deze instructie vereist geen parameters.

## Belangrijke opmerkingen

- Sluit de `allowed_mint` PDA: nieuwe `Deposit`-aanroepen voor deze mint zullen mislukken
  met `InvalidAllowedMint`
- Bestaande kanaalsaldi voor deze mint blijven onaangetast
- Verzendt een gebeurtenis via `EmitEvent` CPI
