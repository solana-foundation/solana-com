---
title: AllowMint
description:
  Staat een SPL-token mint toe op de instantie en maakt de escrow ATA aan voor die mint
---

Staat een SPL-token mint toe op de instantie en maakt de associated
token account van de escrow aan voor die mint. Stortingen voor deze mint worden mogelijk na deze
aanroep.

## Accounts

| Account                          | Schrijfbaar | Ondertekenaar | Beschrijving                                                                   |
| -------------------------------- | -------- | ------ | ----------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Betaler van de vergoeding                                                                     |
| `admin`                          |          | ✓      | Instantiebeheerder                                                                |
| `instance`                       |          |        | Instantie-PDA                                                                  |
| `mint`                           |          |        | SPL-token mint om toe te staan                                                       |
| `allowed_mint`                   | ✓        |        | AllowedMint PDA (aangemaakt door deze instructie)                                 |
| `instance_ata`                   | ✓        |        | Associated token account van de escrow voor deze mint (aangemaakt door deze instructie) |
| `system_program`                 |          |        | System Program                                                                |
| `token_program`                  |          |        | SPL Token Program                                                             |
| `associated_token_program`       |          |        | Associated Token Program                                                      |
| `event_authority`                |          |        | PDA van de event-autoriteit                                                           |
| `private_channel_escrow_program` |          |        | Escrow-programma                                                                |

## Parameters

| Parameter | Type | Beschrijving                                                                                   |
| --------- | ---- | --------------------------------------------------------------------------------------------- |
| `bump`    | `u8` | Bump seed voor de `allowed_mint` PDA. Optioneel: de `Async`-client leidt deze automatisch af als weggelaten |

> De IDL bevat een `discriminator: u8`-argument (waarde `1`) dat automatisch wordt ingesteld
> door de gegenereerde client en niet handmatig doorgegeven mag worden.

## Belangrijke opmerkingen

- Gebruik `getAllowMintInstructionAsync`; deze leidt `bump`, `allowed_mint`,
  en `instance_ata` automatisch af wanneer ze niet zijn opgegeven. Geef uw eigen `bump` alleen door als
  u deze al hebt berekend via
  `Pubkey::find_program_address(&[b"allowed_mint", instance_pda, mint], &PROGRAM_ID)`
- Maakt ook `instance_ata` aan, de ATA van de escrow voor deze mint
- Mints met een transfer hook-extensie zijn expliciet geblokkeerd: een poging om
  zo'n mint toe te staan geeft `TransferHookNotAllowed`
- Verstuurt een event via `EmitEvent` CPI
