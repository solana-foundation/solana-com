---
title: AddOperator
description: Registreert een nieuwe operator door hun Operator PDA aan te maken
---

Registreert een nieuwe operator door hun `Operator` PDA aan te maken. Na deze aanroep kan de
`operator`-wallet `ReleaseFunds` en `ResetSmtRoot` aanroepen.

## Accounts

| Account                          | Schrijfbaar | Ondertekenaar | Beschrijving                                                         |
| -------------------------------- | -------- | ------ | ------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Betaler van kosten                                                           |
| `admin`                          |          | ✓      | Instantiebeheerder                                                      |
| `instance`                       |          |        | Instantie PDA                                                        |
| `operator`                       |          |        | Operator-wallet om te registreren                                        |
| `operator_pda`                   | ✓        |        | Operator PDA - automatisch afgeleid van `["operator", instance, operator]` |
| `system_program`                 |          |        | System Program                                                      |
| `event_authority`                |          |        | Event authority PDA                                                 |
| `private_channel_escrow_program` |          |        | Escrow Program                                                      |

## Parameters

| Parameter | Type | Beschrijving                                                                               |
| --------- | ---- | ----------------------------------------------------------------------------------------- |
| `bump`    | `u8` | Bump seed voor de `operator_pda`. Optioneel: de `Async`-client leidt dit automatisch af indien weggelaten |

> De IDL bevat een argument `discriminator: u8` (waarde `3`) dat automatisch wordt ingesteld
> door de gegenereerde client en niet handmatig doorgegeven mag worden.

## Belangrijke opmerkingen

- Gebruik `getAddOperatorInstructionAsync`; dit leidt `bump` en
  `operator_pda` automatisch af wanneer ze niet zijn opgegeven. Een synchrone
  variant `getAddOperatorInstruction` bestaat ook als u `bump` al zelf heeft berekend
- Na deze aanroep kan de `operator`-wallet `ReleaseFunds` en
  `ResetSmtRoot` aanroepen
- Verzendt een event via `EmitEvent` CPI
