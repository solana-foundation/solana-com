---
title: RemoveOperator
description: Trekt een operator in door hun Operator PDA te sluiten
---

Trekt een operator in door hun `Operator` PDA te sluiten. De ingetrokken wallet kan niet langer `ReleaseFunds` of `ResetSmtRoot` aanroepen.

## Accounts

| Account                          | Schrijfbaar | Ondertekenaar | Beschrijving                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | Betaler van de transactiekosten                                 |
| `admin`                          |          | ✓      | Instantiebeheerder                            |
| `instance`                       |          |        | Instantie PDA                              |
| `operator`                       |          |        | Operator wallet om in te trekken                 |
| `operator_pda`                   | ✓        |        | Operator PDA (gesloten door deze instructie) |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | Gebeurtenisautoriteit PDA                       |
| `private_channel_escrow_program` |          |        | Escrow-programma                            |

Deze instructie heeft geen parameters.

## Belangrijke opmerkingen

- Sluit de `operator_pda`; de ingetrokken wallet kan niet langer
  `ReleaseFunds` of `ResetSmtRoot` aanroepen
- Lopende operatortransacties zullen mislukken met `InvalidOperatorPda` na
  deze aanroep
- Verstuurt een gebeurtenis via `EmitEvent` CPI
