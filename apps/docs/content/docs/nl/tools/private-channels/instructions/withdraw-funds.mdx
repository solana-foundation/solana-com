---
title: Fondsen Opnemen
description:
  Verbrandt tokens aan de kanaalzijde om een opname terug naar de Solana mainnet escrow te initiëren
---

Verbrandt het channel-side tokensaldo van een gebruiker op het Withdraw Program om een
ausstehende opname te signaleren; een operator moet vervolgens `ReleaseFunds` aanroepen op het
Escrow Program om de afwikkeling te voltooien.

## Accounts

| Account                    | Schrijfbaar | Ondertekenaar | Beschrijving                                |
| -------------------------- | -------- | ------ | ------------------------------------------ |
| `user`                     |          | ✓      | Token-eigenaar die de opname initieert      |
| `mint`                     | ✓        |        | SPL token mint (tegen verbrand)            |
| `token_account`            | ✓        |        | Channel-side token account van de gebruiker (bron) |
| `token_program`            |          |        | SPL Token Program                          |
| `associated_token_program` |          |        | Associated Token Program                   |

## Parameters

| Parameter     | Type             | Beschrijving                                                          |
| ------------- | ---------------- | -------------------------------------------------------------------- |
| `amount`      | `u64`            | Hoeveelheid tokens om op te nemen, in de kleinste eenheid van de token           |
| `destination` | `Option<Pubkey>` | Doelwallet op Mainnet; indien `None`, wordt standaard de wallet van de ondertekenaar gebruikt |

## Geeft Terug

Geeft een `TransactionBuilder` terug die kan worden gebruikt om de
transactie te bouwen en te verzenden.

## Voorbeeld

```typescript
import { getWithdrawFundsInstruction } from "../private-channel-withdraw-program/clients/typescript/src/generated";

const withdrawIx = getWithdrawFundsInstruction({
  user: userSigner,
  mint: mintAddress,
  tokenAccount: channelTokenAccount,
  tokenProgram: TOKEN_PROGRAM_ID,
  associatedTokenProgram: ASSOCIATED_TOKEN_PROGRAM_ID,
  amount: 1_000_000n,
  destination: null // null = release to signer's Mainnet wallet
});
```

## Belangrijke Opmerkingen

- Deze instructie bevindt zich op het **Withdraw Program**
  (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi` devnet), niet op het Escrow
  Program
- Het verbranden van tokens aan de kanaalzijde **geeft** fondsen op
  Mainnet **niet** automatisch vrij; een operator moet vervolgens `ReleaseFunds` aanroepen op het Escrow
  Program met een geldig SMT-uitsluitingsbewijs
- `ZeroAmount`-fout wordt gegenereerd als `amount` 0 is
- Als `destination` `None` is, zal de `ReleaseFunds`-aanroep van de operator
  fondsen vrijgeven naar de wallet van de ondertekenaar

Voor de volledige foutcodereferentie voor beide programma's, zie
[Instructies -> Foutcodes](/docs/tools/private-channels/instructions#error-codes).
