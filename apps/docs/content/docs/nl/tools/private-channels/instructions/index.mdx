Dit gedeelte is de on-chain instructiereferentie. De meeste ontwikkelaars roepen deze
instructies aan via de gegenereerde TypeScript-clients; u hebt dit alleen nodig als u
operatortooling bouwt, aangepaste integraties schrijft of fouten op instructieniveau
opspoort.

**Escrow-programma** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) - beheert
stortingen, operatorinrichting en Mainnet-afwikkeling:

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) -
  initialiseer de escrow-instantie PDA
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) - voeg een
  SPL-token mint toe aan de allowlist
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) - verwijder een
  mint van de allowlist
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) -
  richt een operator in
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) -
  trek een operator in
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) -
  draag beheerdersrechten over
- [Deposit](/docs/tools/private-channels/instructions/deposit) - verplaats SPL-tokens
  naar de escrow
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) -
  operator verwerkt een opname naar Mainnet
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) -
  operator roteert de Sparse Merkle Tree

**Withdraw-programma** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) - wordt uitgevoerd op
het private channel-netwerk:

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) -
  verbrand het channel-side saldo om een opname te initiëren

## Foutcodes

**Escrow-programma - `PrivateChannelEscrowProgramError`**

| Code                                         | Bericht                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | Ongeldige event-autoriteit opgegeven                 |
| `InvalidAta`                                 | Ongeldig ATA opgegeven                             |
| `InvalidMint`                                | Ongeldige mint opgegeven                            |
| `InvalidInstanceId`                          | Instantie-ID ongeldig of voldoet niet aan de regels    |
| `InvalidInstance`                            | Ongeldige instantie opgegeven                        |
| `InvalidAdmin`                               | Ongeldige beheerder opgegeven                           |
| `TransferHookNotAllowed`                     | Transfer hook-extensie niet toegestaan              |
| `InvalidOperatorPda`                         | Ongeldige operator-PDA opgegeven                    |
| `InvalidTokenAccount`                        | Ongeldig token account opgegeven                   |
| `InvalidEscrowBalance`                       | Ongeldig escrow-saldo                           |
| `InvalidAllowedMint`                         | Ongeldige toegestane mint                             |
| `InvalidSmtProof`                            | Ongeldig SMT-bewijs opgegeven                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | Ongeldige transactienonce voor huidige boomindex |
| `UnexpectedTreeIndex`                        | Onverwachte huidige boomindex voor SMT-root-reset |

**Withdraw-programma - `PrivateChannelWithdrawProgramError`**

| Code          | Bericht                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | Ongeldige mint opgegeven                       |
| `ZeroAmount`  | Het opnamebedrag moet groter zijn dan nul |
