Draagt beheerdersrechten over aan een nieuwe wallet.

## Accounts

| Account                          | Beschrijfbaar | Ondertekenaar | Beschrijving                        |
| -------------------------------- | -------- | ------ | ---------------------------------- |
| `payer`                          | ✓        | ✓      | Betaler van transactiekosten                          |
| `current_admin`                  |          | ✓      | Huidige beheerder (moet ondertekenen)          |
| `instance`                       | ✓        |        | Instantie-PDA (beheerderveld bijgewerkt) |
| `new_admin`                      |          | ✓      | Wallet die beheerdersrechten ontvangt     |
| `event_authority`                |          |        | Event authority PDA                |
| `private_channel_escrow_program` |          |        | Escrow-programma                     |

Deze instructie heeft geen parameters.

## Belangrijke opmerkingen

- **Onomkeerbaar in één stap**: de huidige beheerder kan de rol niet terugclaimen
  zonder dat de nieuwe beheerder opnieuw `SetNewAdmin` aanroept
- Controleer het doeladres voordat u de instructie aanroept; er is geen ongedaan maken mogelijk
- Verstuurt een event via `EmitEvent` CPI
