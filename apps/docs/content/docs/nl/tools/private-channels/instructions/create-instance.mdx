title: CreateInstance

---

Maakt de `Instance` PDA aan die de escrow verankert. Moet worden aangeroepen vóór elke
andere bewerking.

## PDA Seeds

```
instance        -> ["instance", instance_seed: Pubkey]
allowed_mint    -> ["allowed_mint", instance_pda: Pubkey, mint: Pubkey]
operator        -> ["operator", instance_pda: Pubkey, operator: Pubkey]
event_authority -> ["event_authority"]
```

## Accounts

| Account                          | Schrijfbaar | Ondertekenaar | Beschrijving                                                                 |
| -------------------------------- | -------- | ------ | --------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Betaler van kosten en rent                                                    |
| `admin`                          |          | ✓      | Initiële beheerder van de instantie                                               |
| `instance_seed`                  |          | ✓      | Wegwerp-keypair uitsluitend gebruikt voor PDA-afleiding; zijn pubkey wordt de seed |
| `instance`                       | ✓        |        | Instance PDA (afgeleid van `["instance", instance_seed.pubkey]`)            |
| `system_program`                 |          |        | System Program                                                              |
| `event_authority`                |          |        | Event authority PDA                                                         |
| `private_channel_escrow_program` |          |        | Escrow Program                                                              |

## Parameters

| Parameter | Type | Beschrijving                                                                             |
| --------- | ---- | --------------------------------------------------------------------------------------- |
| `bump`    | `u8` | bump seed voor de instance PDA. Optioneel: de `Async`-client leidt deze automatisch af indien weggelaten |

> De IDL bevat een `discriminator: u8`-argument (waarde `0`) dat automatisch wordt ingesteld
> door de gegenereerde client en niet handmatig doorgegeven dient te worden.

## Belangrijke opmerkingen

- `instance_seed` is een wegwerp-keypair, uitsluitend gebruikt om de `Instance`
  PDA af te leiden. De pubkey ervan wordt de seed; het keypair zelf wordt niet opgeslagen of hergebruikt.
- Gebruik `getCreateInstanceInstructionAsync`; dit leidt automatisch `bump` en `instance`
  af van `instance_seed` wanneer deze niet worden opgegeven. Geef uw eigen `bump` alleen door als
  u deze al heeft berekend via
  `Pubkey::find_program_address(&[b"instance", instance_seed_pubkey.as_ref()], &PROGRAM_ID)`
- Genereert een event via `EmitEvent` CPI
