  productiegebruik met echte fondsen zonder een grondige beveiligingsbeoordeling.
</Callout>

**Private Channels is een enterprise-laag voor internet-kapitaalmarkten op
Solana.** Het biedt een configureerbare app-laag voor privé, directe, gratis
overdrachten binnen betaalkanalen: gebruikers storten SPL-tokens in een on-chain
escrow-programma, voeren transacties uit off-chain via een gateway, en rekenen af op Mainnet
via een Sparse Merkle Tree-bewijs, waardoor app-ontwikkelaars directe, gratis, privé
overdrachten krijgen zonder het Solana-ecosysteem te verlaten.

### Waarom Private Channels?

- **Directe overdrachten**: off-chain doorvoer voorbij Solana's native TPS;
  overdrachten worden bevestigd wanneer de sequencer ze verwerkt, niet wanneer een blok wordt bevestigd
- **Geen kosten per overdracht**: geen gaskosten bij individuele kanaaloverdrachten; gebruikers
  betalen alleen voor on-chain stortingen en opnames
- **Privacy**: overdrachten tussen kanaaldeelnemers worden niet geregistreerd op Solana
  Mainnet
- **Beperkte toegang**: RBAC met JWT-authenticatie geeft u controle over wie kan
  verzenden en ontvangen
- **Mainnet-afrekening**: fondsen zijn altijd inwisselbaar naar Solana via een Sparse
  Merkle Tree-uitsluitingsbewijs, dat het escrow-programma on-chain afdwingt

Zie het **[Overzicht](/docs/tools/private-channels/overview)** voor de volledige
architectuur, gegevensstroomdiagram en beveiligingsmodel.

## Snel starten

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n, // 1 USDC
  recipient: null
});
// send via your preferred Solana client
```

TypeScript-clients worden gegenereerd vanuit de IDL; zie Installatie. Voor Token-2022
mints, geef `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS` expliciet mee, omdat het
standaard de standaard SPL Token Program gebruikt.

## Gebruiksscenario's

- **Institutionele bilaterale betalingen** - banken en instellingen die behoefte hebben aan
  grootschalige, privé USDC-stromen zonder dat elke overdracht on-chain zichtbaar is
- **Hoogfrequente app-laag overdrachten** - gaming-, loyaliteits- en consumenten-apps
  die sub-seconde, gratis overdrachten op schaal nodig hebben die de native Solana TPS overstijgen
- **Privacybeschermende tokenstromen** - elk gebruiksscenario waarbij privacy van tegenpartij en
  bedrag een productvereiste is
