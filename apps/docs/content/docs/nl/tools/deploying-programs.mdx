---
title: Programma's deployen
description: Best practices voor het deployen van programma's op Mainnet
---

Als je een aangepast Solana-programma deployt als onderdeel van je betalingsinfrastructuur, zijn er aanvullende overwegingen.

## Vóór de deployment

- **Solana CLI-versie:** Zorg ervoor dat je de nieuwste versie van de
  [Solana CLI](https://solana.com/docs/intro/installation) gebruikt.
- **Programma-keypair:** Je programma heeft op mainnet een ander adres
  dan op devnet (tenzij je dezelfde keypair hergebruikt). Werk alle verwijzingen in
  de configuratie van je applicatie bij. Bewaar de keypair van je programma op een veilige locatie (let op:
  `cargo clean` verwijdert je programma-keypair waarschijnlijk).
- **Accounts initialiseren:** Als je programma admin-accounts, PDA's of
  andere state-accounts nodig heeft, zorg er dan voor dat deze op mainnet zijn aangemaakt voordat gebruikers
  met je applicatie werken. Hetzelfde geldt voor alle Associated Token Accounts (ATAs)
  die je programma nodig heeft.

## Deploymentproces

- **Buffer accounts:** Grote programma's worden gedeployd via buffer accounts. Het
  commando `solana program deploy` regelt dit automatisch, maar houd er rekening mee
  dat deployment niet atomair is: bij een onderbreking moet je buffer accounts mogelijk herstellen of
  sluiten.
- **Upgrade authority:** Maak een
  [multisig](https://docs.squads.so/main/basics/what-is-a-multisig) aan en wijs deze
  toe als de
  [upgrade authority van je Solana-programma](https://docs.squads.so/main/navigating-your-squad/developers-assets/programs).
- **Rent:** Zorg ervoor dat je deployment-wallet genoeg SOL heeft om de rent-exempt
  minimumbedragen voor alle program accounts te dekken.
- **Verificatie:** [Verifieer](https://solana.com/docs/programs/verified-builds)
  je programma om te garanderen dat het uitvoerbare programma dat je naar het netwerk van Solana deployt
  overeenkomt met de broncode in je repository
