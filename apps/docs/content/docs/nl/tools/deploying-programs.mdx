---
title: Programma's deployen
description: Best practices voor het deployen van programma's op Mainnet
---

Als je een aangepast Solana-programma deployt als onderdeel van je betalingsinfrastructuur, zijn er aanvullende aandachtspunten.

## Voor de deployment

- **Solana CLI-versie:** Zorg ervoor dat je de nieuwste versie van de
  [Solana CLI](https://solana.com/docs/intro/installation) gebruikt.
- **Programma-keypair:** Je programma heeft op mainnet een ander adres dan op devnet (tenzij je hetzelfde keypair hergebruikt). Werk alle verwijzingen in je applicatieconfiguratie bij. Bewaar je programma-keypair op een veilige plek (let op: het uitvoeren van `cargo clean` verwijdert je programma-keypair waarschijnlijk).
- **Accounts initialiseren:** Als je programma admin-accounts, PDA's of andere state-accounts nodig heeft, zorg er dan voor dat deze op mainnet zijn aangemaakt voordat gebruikers met je applicatie communiceren. Hetzelfde geldt voor alle Associated Token Accounts (ATA's) die je programma nodig heeft.

## Deploymentproces

- **Buffer-accounts:** Grote programma's worden gedeployd via buffer-accounts. Het commando `solana program deploy` regelt dit automatisch, maar houd er rekening mee dat deployment niet atomair is: als het wordt onderbroken, moet je mogelijk buffer-accounts herstellen of sluiten.
- **Upgrade authority:** Maak een
  [multisig](https://docs.squads.so/main/basics/what-is-a-multisig) aan en wijs deze toe als de
  [upgrade authority van je Solana-programma](https://docs.squads.so/main/navigating-your-squad/developers-assets/programs).
- **Rent:** Zorg ervoor dat je deployment-wallet voldoende SOL bevat om de rent-exempt-minimumbedragen voor alle programma-accounts te dekken.
- **Verificatie:** [Verifieer](https://solana.com/docs/programs/verified-builds)
  je programma om te garanderen dat het uitvoerbare programma dat je op het netwerk van Solana deployt overeenkomt met de broncode in je repository
