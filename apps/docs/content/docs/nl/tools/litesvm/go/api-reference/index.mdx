## Snelle referentie

### Handle-configuratie

```go
import (
    litesvm "github.com/LiteSVM/litesvm-go"
    solana "github.com/gagliardetto/solana-go"
)

svm, err := litesvm.New()
if err != nil {
    // handle error
}
defer svm.Close()
```

### Accountbeheer

| Methode                                                                       | Beschrijving                                          |
| ---------------------------------------------------------------------------- | ---------------------------------------------------- |
| `Airdrop(pubkey, lamports) error`                                            | Een account financieren                                      |
| `Balance(pubkey) (uint64, bool, error)`                                      | SOL-saldo; bool geeft aan of het account bestaat |
| `GetAccount(pubkey) *Account`                                                | Haal een account-handle op (nil indien niet gevonden)          |
| `SetAccount(pubkey, *Account) error`                                         | Accountstatus rechtstreeks opslaan                         |
| `MinimumBalanceForRentExemption(dataLen int) (uint64, error)`                | Bereken het rent-vrije minimum                          |
| `NewAccount(lamports, data, owner, executable, rentEpoch) (*Account, error)` | Bouw een Account-handle voor SetAccount               |

### Programmabeheeer

| Methode                                                   | Beschrijving                             |
| -------------------------------------------------------- | --------------------------------------- |
| `AddProgram(programID, bytes) error`                     | Programma laden vanuit bytes                 |
| `AddProgramFromFile(programID, path) error`              | Programma laden vanuit `.so`-bestand            |
| `AddProgramWithLoader(programID, bytes, loaderID) error` | Laden met een specifieke loader (geavanceerd) |

### Transacties

| Methode                                                                        | Beschrijving                                                                     |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| `SendLegacyTransaction(txBytes) (*TxOutcome, error)`                          | Voer een legacy-transactie uit                                                    |
| `SendVersionedTransaction(txBytes) (*TxOutcome, error)`                       | Voer een v0+-transactie uit                                                       |
| `SimulateLegacyTransaction(txBytes) (*TxOutcome, error)`                      | Simuleer zonder statuswijzigingen                                                  |
| `SimulateVersionedTransaction(txBytes) (*TxOutcome, error)`                   | Simuleer v0+ zonder statuswijzigingen                                              |
| `LatestBlockhash() (solana.Hash, error)`                                      | Huidige blockhash                                                               |
| `ExpireBlockhash() error`                                                     | Overschakelen naar een nieuwe blockhash                                                      |
| `GetTransaction(signature) *TxOutcome`                                        | Transactie opzoeken in geschiedenis (nil indien afwezig)                                  |
| `litesvm.BuildTransferTx(payerSeed, to, lamports, blockhash) ([]byte, error)` | Testhulpfunctie die een ondertekende legacy-overdracht opbouwt zonder `solana-go` te importeren |

### Configuratie

| Methode                                         | Beschrijving                                             |
| ---------------------------------------------- | ------------------------------------------------------- |
| `SetSigverify(bool) error`                     | Handtekeningverificatie in- / uitschakelen                 |
| `Sigverify() (bool, error)`                    | Huidige instelling uitlezen                                |
| `SetBlockhashCheck(bool) error`                | Blockhash-validatie in- / uitschakelen                   |
| `SetTransactionHistory(int) error`             | Capaciteit van de in-memory tx-geschiedenis (0 schakelt uit)           |
| `SetLogBytesLimit(int) error`                  | Logbyte-limiet per transactie (negatief = onbeperkt)              |
| `SetLamports(uint64) error`                    | Standaard lamports voor nieuwe airdrop-pool-accounts          |
| `SetSysvars() error`                           | Sysvars terugzetten naar standaardwaarden                               |
| `SetBuiltins() error`                          | Ingebouwde programma's herladen                                |
| `SetDefaultPrograms() error`                   | SPL Token, Memo, enz. herladen                            |
| `SetPrecompiles() error`                       | ed25519 / secp256k1-precompiles inschakelen                  |
| `WithNativeMints() error`                      | seed wrapped-SOL mint                                   |
| `SetFeatureSet(*FeatureSet) error`             | Een feature-gate-set installeren                              |
| `SetComputeBudget(ComputeBudget) error`        | Een rekenbudget toepassen                                  |
| `ComputeBudget() (ComputeBudget, bool, error)` | Huidig budget uitlezen (bool geeft aan of het expliciet is ingesteld) |
