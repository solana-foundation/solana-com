Methoden voor het financieren, lezen en schrijven van accounts.

## Airdrop

```go
func (s *LiteSVM) Airdrop(pubkey solana.PublicKey, lamports uint64) error
```

Financier een account met lamports. Geïmplementeerd als een echte System Program-overdracht
vanuit de interne faucet, dus de ontvanger moet het resulterende
saldo kunnen aanhouden.

```go
priv, err := solana.NewRandomPrivateKey()
if err != nil {
    t.Fatal(err)
}
payer := priv.PublicKey()

// Airdrop 5 SOL
if err := svm.Airdrop(payer, 5_000_000_000); err != nil {
    t.Fatal(err)
}
```

## Saldo

```go
func (s *LiteSVM) Balance(pubkey solana.PublicKey) (uint64, bool, error)
```

Geeft het SOL-saldo van het account terug. De tweede waarde is `false` wanneer het account
niet bestaat — dit verschilt van "account bestaat met nul lamports".

```go
lamports, ok, err := svm.Balance(payer)
if err != nil {
    t.Fatal(err)
}
if !ok {
    t.Log("account does not exist")
} else {
    t.Logf("balance: %d lamports (%.3f SOL)", lamports, float64(lamports)/1e9)
}
```

## GetAccount

```go
func (s *LiteSVM) GetAccount(pubkey solana.PublicKey) *Account
```

Haal een ondoorzichtig account-handle op, of `nil` als het account niet bestaat.
Sluit altijd het handle met `Close` (of vertrouw op de finalizer).

```go
acct := svm.GetAccount(payer)
if acct == nil {
    t.Fatal("account missing")
}
defer acct.Close()

_ = acct.Lamports()    // uint64
_ = acct.Owner()       // solana.PublicKey
_ = acct.Executable()  // bool
_ = acct.RentEpoch()   // uint64
_ = acct.Data()        // []byte (copy)
```

### Accountmethoden

| Methode         | Retourneert            | Beschrijving                        |
| -------------- | ------------------ | ---------------------------------- |
| `Lamports()`   | `uint64`           | SOL-saldo                        |
| `Owner()`      | `solana.PublicKey` | Eigenaarsprogramma                     |
| `Executable()` | `bool`             | Of het account uitvoerbaar is  |
| `RentEpoch()`  | `uint64`           | Rent epoch                         |
| `Data()`       | `[]byte`           | Kopie van de accountgegevens           |
| `Close()`      | -                  | Geeft het onderliggende Rust-handle vrij |

## NewAccount

```go
func NewAccount(lamports uint64, data []byte, owner solana.PublicKey, executable bool, rentEpoch uint64) (*Account, error)
```

Construeer een `Account`-waarde om door te geven aan `SetAccount`. De aanroeper behoudt eigendom van
het geretourneerde handle en moet het sluiten met `Close`.

```go
payload := []byte{1, 2, 3, 4}
rent, err := svm.MinimumBalanceForRentExemption(len(payload))
if err != nil {
    t.Fatal(err)
}

acct, err := litesvm.NewAccount(rent, payload, ownerProgramID, false, 0)
if err != nil {
    t.Fatal(err)
}
defer acct.Close()
```

## SetAccount

```go
func (s *LiteSVM) SetAccount(pubkey solana.PublicKey, acct *Account) error
```

Sla een kopie van `acct` op bij `pubkey`. De SVM bewaart zijn eigen kopie; de aanroeper behoudt
eighendom van `acct` en moet het sluiten met `Close`.

```go
if err := svm.SetAccount(targetAddr, acct); err != nil {
    t.Fatal(err)
}
```

<Callout type="info">
  `SetAccount` is aanzienlijk sneller dan het uitvoeren van transacties wanneer je alleen
  veel accounts wilt seed voor een test. Zorg ervoor dat de lamports-waarde minimaal
  de rent-vrijgestelde minimum is voor de gegevensgrootte.
</Callout>

## MinimumBalanceForRentExemption

```go
func (s *LiteSVM) MinimumBalanceForRentExemption(dataLen int) (uint64, error)
```

Bereken het aantal lamports dat vereist is om een account met de opgegeven gegevenslengte
rent-vrijgesteld te maken.

```go
for _, size := range []int{0, 100, 1024} {
    min, err := svm.MinimumBalanceForRentExemption(size)
    if err != nil {
        t.Fatal(err)
    }
    t.Logf("%4d bytes -> %d lamports", size, min)
}
```

## Programmabeeer

### AddProgram

```go
func (s *LiteSVM) AddProgram(programID solana.PublicKey, bytes []byte) error
```

Laad een SBF-programma vanuit bytes in het geheugen.

```go
bytes, err := os.ReadFile("./target/deploy/my_program.so")
if err != nil {
    t.Fatal(err)
}
if err := svm.AddProgram(programID, bytes); err != nil {
    t.Fatal(err)
}
```

### AddProgramFromFile

```go
func (s *LiteSVM) AddProgramFromFile(programID solana.PublicKey, path string) error
```

Laad een SBF-programma vanuit een `.so`-bestandspad.

```go
if err := svm.AddProgramFromFile(programID, "./target/deploy/my_program.so"); err != nil {
    t.Fatal(err)
}
```

### AddProgramWithLoader

```go
func (s *LiteSVM) AddProgramWithLoader(programID solana.PublicKey, bytes []byte, loaderID solana.PublicKey) error
```

Laad een SBF-programma met een specifieke loader. Nuttig bij het testen met een
niet-standaard BPF loader-versie.

## Batch accountinstelling

Voor tests die veel geseedde accounts nodig hebben, loop over `SetAccount`:

```go
const N = 10
for i := 0; i < N; i++ {
    pk := solana.NewWallet().PublicKey()
    data := []byte{byte(i)}
    rent, err := svm.MinimumBalanceForRentExemption(len(data))
    if err != nil {
        t.Fatal(err)
    }

    acct, err := litesvm.NewAccount(rent, data, owner, false, 0)
    if err != nil {
        t.Fatal(err)
    }
    if err := svm.SetAccount(pk, acct); err != nil {
        acct.Close()
        t.Fatal(err)
    }
    acct.Close()
}
```

<Callout type="info">
  Sluit altijd het `*Account` dat door `NewAccount` wordt geretourneerd met `Close` zodra de SVM
  zijn kopie heeft opgeslagen via `SetAccount` — de SVM neemt geen eigendom over van het handle.
</Callout>
