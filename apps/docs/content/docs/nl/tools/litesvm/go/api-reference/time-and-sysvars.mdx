Methoden voor het manipuleren van tijd en het raadplegen van systeemvariabelen. Elke sysvar-getter heeft een bijbehorende setter; de structs zijn eenvoudige Go-spiegelingen van de Solana-broncode.

## Klokmanipulatie

### WarpToSlot

```go
func (s *LiteSVM) WarpToSlot(slot uint64) error
```

Zet de interne klok vooruit naar een specifieke slot.

```go
before, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("current slot: %d", before.Slot)

if err := svm.WarpToSlot(10_000_000); err != nil {
    t.Fatal(err)
}

after, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("new slot:     %d", after.Slot)
```

### Clock

```go
type Clock struct {
    Slot                uint64
    EpochStartTimestamp int64
    Epoch               uint64
    LeaderScheduleEpoch uint64
    UnixTimestamp       int64
}

func (s *LiteSVM) Clock() (Clock, error)
```

Lees de Clock-sysvar.

```go
c, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("slot=%d epoch=%d unix=%d", c.Slot, c.Epoch, c.UnixTimestamp)
```

### SetClock

```go
func (s *LiteSVM) SetClock(c Clock) error
```

Overschrijf de Clock-sysvar. Lees hem uit, pas velden aan en schrijf hem terug wanneer je controle nodig hebt over `Epoch` of `UnixTimestamp` (die `WarpToSlot` niet bijwerkt).

```go
c, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
c.Slot = 1_000
c.Epoch = 10
c.UnixTimestamp = 1_735_689_600
if err := svm.SetClock(c); err != nil {
    t.Fatal(err)
}
```

<Callout type="info">
  `WarpToSlot` werkt alleen `Slot` bij. Gebruik `SetClock` wanneer je programma
  `Epoch` of `UnixTimestamp` uit de Clock-sysvar leest.
</Callout>

## Epoch Rewards

```go
type EpochRewards struct {
    DistributionStartingBlockHeight uint64
    NumPartitions                   uint64
    ParentBlockhash                 solana.Hash
    TotalPointsLo                   uint64 // low 64 bits of the u128 total_points
    TotalPointsHi                   uint64 // high 64 bits
    TotalRewards                    uint64
    DistributedRewards              uint64
    Active                          bool
}

func (s *LiteSVM) EpochRewards() (EpochRewards, error)
func (s *LiteSVM) SetEpochRewards(e EpochRewards) error
```

`total_points` is een `u128` aan de Solana-kant; `litesvm-go` stelt beide helften
expliciet beschikbaar zodat Go-aanroepers geen u128-bibliotheek nodig hebben. Voor waarden die in 64 bits passen, is `TotalPointsHi` gelijk aan `0` en is `TotalPointsLo` de waarde.

### SlotHistory

`SlotHistory` is een bitvec van ~128 KB; `litesvm-go` stelt het bloot als een handle in plaats van een slice.

```go
sh, err := litesvm.NewSlotHistory()
if err != nil {
    t.Fatal(err)
}
defer sh.Close()

sh.Add(42)

switch sh.Check(42) {
case litesvm.SlotHistoryFound:
    // ...
case litesvm.SlotHistoryNotFound:
    // ...
case litesvm.SlotHistoryTooOld:
    // ...
case litesvm.SlotHistoryFuture:
    // ...
}

if err := svm.SetSlotHistory(sh); err != nil {
    t.Fatal(err)
}
```

| Methode                                           | Beschrijving                                |
| ------------------------------------------------ | ------------------------------------------ |
| `litesvm.NewSlotHistory() (*SlotHistory, error)` | Lege handle                               |
| `sh.Add(slot uint64)`                            | Een slot registreren                              |
| `sh.Check(slot uint64) SlotHistoryCheck`         | `Future` / `TooOld` / `Found` / `NotFound` |
| `sh.Oldest() uint64`                             | Oudste bijgehouden slot                        |
| `sh.Newest() uint64`                             | Nieuwste bijgehouden slot                        |
| `sh.NextSlot() uint64`                           | Volgende te registreren slot                        |
| `sh.SetNextSlot(slot uint64) error`              | De volgende-slot-markering overschrijven              |
| `sh.Close()`                                     | De handle vrijgeven                         |
| `svm.SlotHistory() (*SlotHistory, error)`        | Inlezen in een nieuwe handle                   |
| `svm.SetSlotHistory(*SlotHistory) error`         | Installeren op de SVM                         |

## Tijdsafhankelijke logica testen

Gebruik `WarpToSlot` voor eenvoudige slot-gebaseerde vooruitgang, `SetClock` voor volledige controle:

```go
func TestTimeLockedVault(t *testing.T) {
    svm, err := litesvm.New()
    if err != nil {
        t.Fatal(err)
    }
    defer svm.Close()

    const unlockSlot = uint64(10_000)

    // Setup: create the time-locked account ...

    // Test 1: Try to withdraw before unlock (should fail)
    before, err := svm.Clock()
    if err != nil {
        t.Fatal(err)
    }
    t.Logf("current slot: %d", before.Slot)
    // ... attempt withdrawal, expect failure ...

    // Warp time forward past unlock slot
    if err := svm.WarpToSlot(unlockSlot + 1); err != nil {
        t.Fatal(err)
    }

    // Test 2: Try to withdraw after unlock (should succeed)
    after, err := svm.Clock()
    if err != nil {
        t.Fatal(err)
    }
    t.Logf("new slot: %d", after.Slot)
    // ... attempt withdrawal, expect success ...
}
```
