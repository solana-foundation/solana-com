# Hoe je een token verifieert en zichtbaar maakt in Solana Explorer

Een veelgestelde vraag van tokencreators is: _"Waarom verschijnt mijn token niet wanneer ik
er op Solana Explorer naar zoek, en hoe krijg ik het geverifieerd?"_

Het korte antwoord: Solana Explorer voert geen eigen verificatieproces uit.
In plaats daarvan **aggregeert het meerdere onafhankelijke verificatieproviders**.
Als je token geverifieerd wordt via **één van** deze providers, verschijnt het
in de zoekresultaten van Explorer en worden de verificatiegegevens weergegeven.

Deze gids legt elke provider uit, wat "geverifieerd" wel (en niet) betekent, en
hoe je je token kunt laten verifiëren.

## Wat "geverifieerd" betekent (en wat niet)

Verificatie bevestigt dat een token het **canonieke / correcte token** is voor een
gegeven naam, symbool en mint-adres. Het helpt gebruikers imitators en
duplicate tokens te vermijden, aangezien iedereen een token met willekeurige naam op Solana kan minten.

Verificatie is **geen** goedkeuring van een project, en het is **geen**
guarantie voor de waarde, veiligheid of legitimiteit van een token. Doe altijd je eigen
onderzoek.

## De verificatieproviders achter Solana Explorer

Solana Explorer raadpleegt de volgende onafhankelijke verificateurs. Zodra je token wordt opgepikt door
een van hen (RugCheck is automatisch; de overige vereisen actie), verschijnt je token
in de Explorer-zoekresultaten.

### 1. RugCheck (automatisch)

[RugCheck](https://rugcheck.xyz) voert geautomatiseerde on-chain analyse uit en
volgt tokens automatisch. Omdat het automatisch werkt, hoef je over het algemeen niets
in te dienen — RugCheck evalueert on-chain risicosignalen (mint/freeze-autoriteit,
houderdistributie, liquiditeit, etc.) en volgt het token zelfstandig.

Er is speciale behandeling voor bepaalde stablecoins, waarbij projecten rechtstreeks contact
kunnen opnemen met het RugCheck-team voor de juiste verwerking.

Voorbeeld tokenpagina:
[`rugcheck.xyz/tokens/<mint>`](https://rugcheck.xyz/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 2. Jupiter

[Jupiter](https://jup.ag) onderhoudt een geverifieerde tokenlijst (VRFD) die breed
geïntegreerd is in het Solana-ecosysteem — DEX'en, wallets en screeners. Een
geverifieerd token ontvangt een groen vinkje in Jupiter-producten en partnerplatformen.

Om geverifieerd te worden, dien je je token in voor beoordeling:

- Indienen via [verified.jup.ag/tokens](https://verified.jup.ag/tokens)
- Iedereen kan een token indienen (niet alleen het projectteam)
- Je kunt optioneel het X-account van het project koppelen om het mint-adres van het token
  te verbinden aan een specifiek account
- Jupiter voert een holistische beoordeling uit (liquiditeit, naleving van metadatastandaarden en
  andere signalen) in plaats van één enkele meetwaarde te controleren

Voorbeeld tokenpagina:
[`jup.ag/tokens/<mint>`](https://jup.ag/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 3. CoinGecko

[CoinGecko](https://www.coingecko.com)-verificatie plaatst je token op de lijst met
marktgegevens. Zorg er bij verificatie via CoinGecko voor dat je het **mint-adres** van het token
opneemt (CoinGecko's formulier noemt dit het "contractadres") zodat downstream-integraties
prijzen correct kunnen ophalen.

Volg de officiële CoinGecko-gids voor vermelding/bijwerking:

- [Verificatiegids voor vermeldings- en updateverzoeken op CoinGecko](https://support.coingecko.com/hc/en-us/articles/23725417857817-Verification-Guide-for-Listing-Update-Requests-on-CoinGecko)

Voorbeeld muntpagina:
[`coingecko.com/en/coins/<token>`](https://www.coingecko.com/en/coins/usdc)

### 4. Solflare

[Solflare](https://solflare.com) is een onafhankelijke validator in het verificatieraamwerk van Solana
Explorer. In de praktijk overlappen de tokenlijstcriteria sterk met die van Jupiter, omdat Solflare's
in-app swaplijst wordt aangedreven door de Jupiter-aggregator. Voor een nieuw token om te verschijnen, moet het doorgaans:

- Een geldig token zijn op de Solana-blockchain met metadata die voldoet aan
  de Metaplex Token Metadata-standaard
- Voldoende liquiditeit hebben (een minimale USD-waarde van het token beschikbaar voor
  handel)
- De prijsimpact binnen aanvaardbare limieten houden voor gebruikelijke swaps

Vanwege deze overlap zijn tokens die Jupiter-verificatie voltooien vaak
al in aanmerking voor Solflare zonder afzonderlijke indiening — doorgaans hoef je Solflare
niet als extra handmatige stap te behandelen. Zodra aan de criteria is voldaan,
verschijnen tokens doorgaans binnen enkele minuten. Zie:

- [Ik kan een token niet vinden in Solflare](https://help.solflare.com/en/articles/9260147-i-cannot-find-a-token-in-solflare)

Voorbeeld tokenpagina:
[`solflare.com/prices/<name>/<mint>`](https://www.solflare.com/prices/usd-coin/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/)

### 5. Bluprynt (uitgebreide KYC)

[Bluprynt](https://app.bluprynt.com/register/account) biedt een uitgebreid
verificatietraject met een KYC-protocol. Dit is een strenger, identiteitsgedragen
proces dat geschikt is voor projecten die een sterkere verificatiesignaal wensen.

- Registreer via de
  [Bluprynt-onboarding voor Solana Explorer](https://app.bluprynt.com/register/account)

Voorbeeld geverifieerde activapagina:
[`verified.bluprynt.com/verified-assets/<mint>/solana`](https://verified.bluprynt.com/verified-assets/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/solana)

## Hoe het allemaal samenkomt

- **RugCheck** verloopt automatisch via on-chain analyse — geen indiening
  vereist.
- **Jupiter, CoinGecko, Solflare en Bluprynt** vereisen elk dat je hun
  respectieve proces indient of doorloopt.
- Zodra je token geverifieerd is door **ten minste één** van deze providers, verschijnt het
  in **Solana Explorer**-zoekresultaten en worden verificatiegegevens weergegeven.

Als je token nog niet verschijnt in de Explorer-zoekresultaten, is de snelste weg
doorgaans het indienen voor Jupiter-verificatie en/of het voltooien van een CoinGecko-vermelding,
aangezien beide breed geïntegreerd zijn in het ecosysteem.

## Vereisten die verificatie helpen slagen

Ongeacht de provider vergroten deze on-chain fundamentals de kans op
geslaagde verificatie aanzienlijk:

- **Geldige metadata**: je token moet on-chain metadata hebben die voldoet aan
  de Metaplex Token Metadata-standaard (naam, symbool, logo-URI).
- **Liquiditeit**: zorg voor voldoende liquiditeit op een ondersteunde DEX zodat het token
  verhandeld en geëvalueerd kan worden.
- **Correct mint-adres**: gebruik bij indiening bij een provider altijd het
  **mint-adres** van je token (in sommige providerformulieren aangeduid als "contractadres").

## Samenvatting

Solana Explorer aggregeert meerdere onafhankelijke verificateurs — **RugCheck**
(automatisch), **Jupiter**, **CoinGecko**, **Solflare** en **Bluprynt** (KYC).
Verificatie via een van hen maakt je token vindbaar in de Explorer-zoekresultaten.
Verificatie bevestigt de canonieke tokenidentiteit; het is geen goedkeuring,
zodanig dat gebruikers altijd hun eigen onderzoek moeten doen.
