---
title: "Quickstart: maak een token aan met de CLI"
description:
  Create a token, open a token account, mint supply, and transfer tokens using
  the SPL Token CLI on devnet.
---

Deze quickstart doorloopt de volledige levenscyclus van een token met de
_sh`spl-token`_ CLI. Je maakt een mint aan, maakt een account aan dat het
token kan bevatten, mint 100 tokens en stuurt een deel naar een andere wallet.

Gebruik [Solana Playground](https://beta.solpg.io/) om de opdrachten in je
browser uit te voeren, of installeer de CLI lokaal met `cargo install spl-token-cli`. De
adressen in jouw uitvoer zullen afwijken van de onderstaande voorbeelden.

## 1. Verbinding maken met devnet

Maak een wallet aan of verbind er een in Solana Playground, selecteer vervolgens devnet en vraag
SOL aan voor stortingen op accounts en transactiekosten:

```terminal
$ solana config set --url devnet
$ solana airdrop 2
```

Gebruik devnet-tokens alleen voor testdoeleinden. Ze hebben geen financiële waarde.

## 2. Een token aanmaken

Maak het mint account aan dat jouw token identificeert:

```terminal
$ spl-token create-token
```

Kopieer het tokenadres uit de uitvoer. Dit is het mint-adres dat je gebruikt in
de overige opdrachten. Een nieuwe mint begint met een aanbod van nul.

```terminal
$ spl-token supply <MINT_ADDRESS>
```

## 3. Een token account aanmaken

Je wallet heeft een token account nodig voor deze mint voordat het een saldo kan bevatten:

```terminal
$ spl-token create-account <MINT_ADDRESS>
```

Dit maakt jouw
[associated token account](/docs/tokens#associated-token-account) aan, waarvan het adres
wordt afgeleid van jouw wallet en de mint.

## 4. Tokens minten

Mint 100 tokens in jouw associated token account:

```terminal
$ spl-token mint <MINT_ADDRESS> 100
$ spl-token balance <MINT_ADDRESS>
```

De mint-autoriteit moet deze handeling ondertekenen. Minting verhoogt zowel het saldo van jouw token account als het totale aanbod dat door de mint wordt bijgehouden.

## 5. Tokens overdragen

Stuur 10 tokens naar een andere devnet-wallet. De optie _sh`--fund-recipient`_
maakt het associated token account van de ontvanger aan als dit nog niet bestaat:

```terminal
$ spl-token transfer <MINT_ADDRESS> 10 <RECIPIENT_WALLET_ADDRESS> --fund-recipient
```

De overdracht wijzigt de saldi in de token accounts van de verzender en ontvanger; het
wijzigt het totale aanbod van de mint niet.

## Optioneel: Token-2022-metadata toevoegen

Om een naam, symbool en URI rechtstreeks op een nieuwe Token-2022-mint op te slaan, maak je deze aan
met de metadata-extensie ingeschakeld:

```terminal
$ spl-token create-token \
  --program-id TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb \
  --enable-metadata
```

Gebruik vervolgens het nieuwe mint-adres dat door die opdracht wordt afgedrukt:

```terminal
$ spl-token initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  "EXAMPLE" \
  "https://example.com/token.json"
```

De URI moet een openbaar JSON-metadatadocument retourneren. Zie
[Token-2022 metadata](/docs/tokens/extensions/metadata) voor het accountmodel
en codevoorbeelden.
