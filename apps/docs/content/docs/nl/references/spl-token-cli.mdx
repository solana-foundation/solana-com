De `spl-token`-opdrachtregelinterface maakt en beheert mints, token accounts, autoriteiten, transfers en Token-2022-extensies.

Deze referentie volgt
[`spl-token-cli` v5.6.1](https://github.com/solana-program/token-2022/releases/tag/cli%40v5.6.1),
de versie die met Agave v4.2.1 wordt meegeleverd. Voer `spl-token --version` uit en gebruik
`<command> --help` voor de exacte opties die beschikbaar zijn in je geïnstalleerde versie.

<Callout type="warn">
  Het aanmaken van een mint, transfers, wijzigingen van autoriteiten, burns, freezes en het sluiten van accounts verzenden transacties. Controleer het cluster, het Token Program, de ondertekenaar en de adressen voordat je een opdracht uitvoert. Op Mainnet werk je met echte assets.
</Callout>

## Installeren en hulp opvragen

De Agave CLI-releasebundel bevat `spl-token`. Als het niet is geïnstalleerd, gebruik dan de gepubliceerde Rust-crate:

```shell
cargo install spl-token-cli --version 5.6.1
spl-token --version
```

Bekijk de hulp op rootniveau of opdrachtniveau:

```shell
spl-token --help
spl-token create-token --help
spl-token transfer --help
```

## Globale opties

Plaats globale opties vóór de opdracht.

| Optie                                       | Doel                                                                   |
| -------------------------------------------- | ------------------------------------------------------------------------- |
| `-u, --url <URL_OR_MONIKER>`                 | Selecteer een RPC-URL of `mainnet-beta`, `testnet`, `devnet` of `localhost`. |
| `-C, --config <PATH>`                        | Gebruik een ander configuratiebestand van de Solana CLI.                            |
| `--fee-payer <KEYPAIR>`                      | Selecteer het account dat de transactiekosten betaalt.                            |
| `-p, --program-id <ADDRESS>`                 | Gebruik een expliciete Token Program-ID.                                         |
| `--program-2022`                             | Gebruik Token-2022 (`TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb`).           |
| `--output <FORMAT>`                          | Geef `json` of `json-compact` terug waar dit wordt ondersteund.                          |
| `--with-compute-unit-limit <UNITS>`          | Stel de limiet voor compute units van de transactie in.                                   |
| `--with-compute-unit-price <MICRO_LAMPORTS>` | Stel de prioriteitsprijs per compute unit in.                                  |
| `-v, --verbose`                              | Toon aanvullende uitvoer.                                                   |
| `-V, --version`                              | Toon de geïnstalleerde CLI-versie.                                          |

Het standaardprogramma is het oorspronkelijke Token Program. Gebruik `--program-2022` voor een Token-2022-mint of -account, ook wanneer je deze alleen uitleest. Een opdracht mislukt als het geselecteerde programma niet de eigenaar is van het opgegeven adres.

## Een token aanmaken en gebruiken

De opdrachten tonen de aangemaakte adressen. Bewaar het mint-adres dat `create-token` teruggeeft voor de volgende opdrachten.

```shell
# Create a six-decimal mint under the original Token Program.
spl-token --url devnet create-token --decimals 6

# Create the default signer's associated token account for the mint.
spl-token --url devnet create-account <MINT_ADDRESS>

# Mint 100 tokens to that associated token account.
spl-token --url devnet mint <MINT_ADDRESS> 100

# Read supply, balance, and complete mint or account details.
spl-token --url devnet supply <MINT_ADDRESS>
spl-token --url devnet balance <MINT_ADDRESS>
spl-token --url devnet display <MINT_OR_TOKEN_ACCOUNT_ADDRESS>

# Transfer tokens to a wallet and create its associated account if needed.
spl-token --url devnet transfer \
  <MINT_ADDRESS> \
  10 \
  <RECIPIENT_WALLET_ADDRESS> \
  --fund-recipient
```

Bedragen zijn UI-tokenbedragen, aangepast aan de decimalen van de mint. Opdrachten zoals `transfer`, `burn` en `unwrap-sol` accepteren `ALL` waar dit in hun hulp wordt vermeld.

## Een Token-2022-mint aanmaken

Extensies reserveren extra mint- of accountstatus en moeten meestal worden gekozen bij het aanmaken van de mint. Dit voorbeeld maakt een mint met zes decimalen aan met ondersteuning voor ingebedde metadata:

```shell
spl-token --program-2022 create-token \
  --decimals 6 \
  --enable-metadata

spl-token --program-2022 initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  EXAMPLE \
  https://example.com/token.json
```

Veelgebruikte extensieopties van `create-token` zijn onder andere:

- `--enable-close`
- `--enable-confidential-transfers auto|manual`
- `--enable-freeze`
- `--enable-group` en `--enable-member`
- `--enable-metadata`
- `--enable-non-transferable`
- `--enable-pause`
- `--enable-permanent-delegate`
- `--enable-permissioned-burn`
- `--enable-transfer-hook` of `--transfer-hook <PROGRAM_ID>`
- `--interest-rate <BASIS_POINTS>`
- `--transfer-fee-basis-points <BASIS_POINTS>` met
  `--transfer-fee-maximum-fee <AMOUNT>`
- `--ui-amount-multiplier <MULTIPLIER>`

Combineer alleen extensies die het Token-2022-programma samen toestaat. Raadpleeg de relevante [Token-2022-extensiegids](/docs/tokens/extensions) voordat je een onomkeerbare mint-configuratie aanmaakt.

## Autoriteiten en delegates beheren

```shell
# Change the mint authority.
spl-token authorize <MINT_ADDRESS> mint <NEW_AUTHORITY_ADDRESS>

# Permanently remove the mint authority.
spl-token authorize <MINT_ADDRESS> mint --disable

# Let a delegate spend up to 25 tokens from one token account.
spl-token approve \
  <TOKEN_ACCOUNT_ADDRESS> \
  25 \
  <DELEGATE_ADDRESS>

# Remove the current delegate.
spl-token revoke <TOKEN_ACCOUNT_ADDRESS>
```

`authorize` ondersteunt autoriteitstypen voor mint, freeze, owner, close en extensiespecifieke autoriteiten. Het verwijderen van een autoriteit met `--disable` is permanent als geen ander programmamechanisme deze kan herstellen.

## Bevriezen, burnen en sluiten

```shell
spl-token freeze <TOKEN_ACCOUNT_ADDRESS>
spl-token thaw <TOKEN_ACCOUNT_ADDRESS>

spl-token burn <TOKEN_ACCOUNT_ADDRESS> 5

# A token account must normally have a zero token balance before closing.
spl-token close --address <TOKEN_ACCOUNT_ADDRESS>
```

`burn` verlaagt zowel het accountsaldo als de totale supply. `close` stuurt de resterende lamports van het account naar de geconfigureerde ontvanger; het herstelt geen geburnde tokens.

## SOL wrappen en unwrappen

```shell
# Create or fund the owner's wrapped SOL token account.
spl-token wrap 1

# Unwrap part of the wrapped SOL balance.
spl-token unwrap-sol 0.25

# Close the wrapped SOL account and return its full lamport balance.
spl-token unwrap
```

Gebruik `sync-native` nadat je lamports rechtstreeks hebt overgemaakt naar een gewrapt SOL token account, zodat het tokenbedrag overeenkomt met de onderliggende lamports.

## Multisig-ondertekening

Maak een M-of-N Token Program-multisig aan met maximaal 11 leden:

```shell
spl-token create-multisig \
  2 \
  <MEMBER_1_ADDRESS> \
  <MEMBER_2_ADDRESS> \
  <MEMBER_3_ADDRESS>
```

Geef voor een transactie die door die multisig wordt beheerd het multisig-adres door als de relevante autoriteit en geef de keypairs van de leden op via herhaalde `--multisig-signer`-waarden. Raadpleeg de hulp van de betreffende opdracht, want de vlag voor de primaire autoriteit verschilt per bewerking.

## Vertrouwelijke saldi

Opdrachten voor vertrouwelijke saldi vereisen een Token-2022-mint die is geconfigureerd voor vertrouwelijke transfers en een geconfigureerd ontvangeraccount.

```shell
spl-token --program-2022 configure-confidential-transfer-account \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 deposit-confidential-tokens \
  <MINT_ADDRESS> \
  10 \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 apply-pending-balance \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 withdraw-confidential-tokens \
  <MINT_ADDRESS> \
  5 \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 transfer \
  <MINT_ADDRESS> \
  1 \
  <RECIPIENT_ADDRESS> \
  --confidential
```

Geef bij `configure-confidential-transfer-account` en `apply-pending-balance` óf `--address <TOKEN_ACCOUNT_ADDRESS>` óf een positioneel `<MINT_ADDRESS>` op, niet beide. De positionele vorm gebruikt het associated token account van de eigenaar. Storten en opnemen vereisen altijd de mint en accepteren `--address` om dat standaardaccount te overschrijven.

Gebruik `enable-confidential-credits`, `disable-confidential-credits`, `enable-non-confidential-credits` en `disable-non-confidential-credits` om te bepalen welke stortingen het account accepteert. Deze instellingen beïnvloeden de privacy van het account en de compatibiliteit van betalingen; controleer het account voordat je ze wijzigt.

## Gestructureerd en offline ondertekenen

Gebruik gestructureerde uitvoer in plaats van weergavetekst te parsen:

```shell
spl-token accounts --output json
spl-token display <MINT_ADDRESS> --output json-compact
```

Opdrachten die transacties produceren ondersteunen doorgaans `--sign-only`, `--blockhash`, `--signer <PUBKEY=SIGNATURE>`, `--nonce` en `--nonce-authority`. De exacte offline invoer hangt af van de opdracht, de decimalen van de mint en de autoriteitsconfiguratie. Genereer daarom het niet-ondertekende bericht volgens de `--help`-instructies van die opdracht en controleer elk adres voordat je handtekeningen verzamelt.
