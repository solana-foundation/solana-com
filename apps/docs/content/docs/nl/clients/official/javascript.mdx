## Solana Kit

`@solana/kit` is de aanbevolen TypeScript SDK voor het bouwen op Solana. Je
stelt een client samen uit composeerbare plugins, voegt React-bindingen toe
wanneer je ze nodig hebt, en integreert gegenereerde programmaclients voor de
on-chain programma's die je aanroept.

| Package                   | Beschrijving                                  | GitHub                                                                                 |
| ------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------- |
| @solana/kit               | Kern-SDK: RPC, transacties, codecs, signers | [Bron](https://github.com/anza-xyz/kit)                                              |
| @solana/react             | React-bindingen: `ClientProvider` en hooks   | [Bron](https://github.com/anza-xyz/kit/tree/main/packages/react)                     |
| @solana/kit-plugin-rpc    | RPC-verbinding + transacties verzenden         | [Bron](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-rpc)    |
| @solana/kit-plugin-signer | Fee payer, identiteit en signer-plugins      | [Bron](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-signer) |
| @solana/kit-plugin-wallet | Wallet Standard-verbinding + React-hooks     | [Bron](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-wallet) |

## Solana Web3.js v3

`@solana/web3.js` v3 is de aanbevolen versie van web3.js. Het bouwt de
klassieke klassegebaseerde API — `Connection`, `Keypair`, `Transaction`, `PublicKey` —
opnieuw op met de interne onderdelen van `@solana/kit`, zodat het werkt met Kit-primitieven en de
hierboven genoemde programma-clients. Gebruik het als je een bestaande web3.js-app upgradet of
liever de klassegebaseerde API gebruikt.

De meeste methoden die in de legacy SDK synchroon waren, zoals
`Keypair.generate()` en `transaction.sign()`, zijn nu async.

```bash
npm install @solana/web3.js@3
```

| Package         | Beschrijving | GitHub                                                        |
| --------------- | ----------- | ------------------------------------------------------------- |
| @solana/web3.js | Kern SDK    | [Bron](https://github.com/solana-foundation/solana-web3.js) |

`@solana/spl-token` is afhankelijk van `@solana/web3.js` (legacy) en werkt niet met
v3. Gebruik in plaats daarvan `@solana-program/token` of `@solana-program/token-2022`; de bijbehorende
gegenereerde instructies en instructieplannen werken rechtstreeks met
`Transaction.add()` van v3.

- [Migratiegids web3.js v1 → v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
- [Migratiegids spl-token](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-spl-token-migration.md)

## Solana Web3.js (legacy)

`@solana/web3.js` (legacy, `1.x`) is de oorspronkelijke TypeScript-SDK voor Solana. Deze
bevindt zich in de onderhoudsmodus en ontvangt alleen kritieke fixes. Bestaande codebases kunnen
[upgraden naar web3.js v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
of [migreren naar Kit](/docs/frontend/web3-compat).
