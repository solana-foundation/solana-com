Deze sectie biedt enkele veelvoorkomende commando's en voorbeelden om je te
helpen bij het gebruik van de [Anchor CLI](https://www.anchor-lang.com/docs).

<Steps>
<Step>

### Het project initialiseren

Maak een nieuw Anchor-project aan door onderstaand commando uit te voeren. Er wordt
een nieuwe map met de projectnaam aangemaakt, die vervolgens wordt gebruikt om een nieuw Anchor-
project te initialiseren.

```terminal
$ anchor init <project-name>
```

Met het onderstaande commando maak je bijvoorbeeld een project aan met de naam `my-project`. De
map `my-project` bevat een modulair Rust-programma en een Rust-testtemplate
dat gebruikmaakt van LiteSVM.

```terminal
$ anchor init my-project
```

Wil je in plaats daarvan een TypeScript-testtemplate genereren, kies er dan expliciet een. Gebruik
bijvoorbeeld de Mocha-template:

```terminal
$ anchor init my-project --test-template mocha
```

Voor TypeScript-testtemplates zijn Node.js en een JavaScript-pakketbeheerder vereist.

Navigeer vervolgens naar de projectmap:

```terminal
$ cd <project-name>
```

Zie de [bestandsstructuur van een project](https://www.anchor-lang.com/docs/quickstart/local#project-file-structure) in Anchor.

</Step>
<Step>

### Bouw het programma

Om je project te bouwen, voer je het volgende commando uit:

```terminal
$ anchor build
```

Je vindt het gecompileerde programma in de `/target/deploy` map.

<Callout type="warn" title="Installatie van platformtools mislukt">
  Als de build een ongeldige platform-tools-map meldt, installeer dan de SBF-
  buildtools opnieuw en probeer de build vervolgens nogmaals:

```terminal
$ cargo build-sbf --force-tools-install
$ anchor build
```

</Callout>

</Step>
<Step>

### Deploy het programma

Om je project te deployen, voer het volgende commando uit:

```terminal
$ anchor deploy
```

Dit commando deployt je programma naar het `cluster` dat is opgegeven in het
[`Anchor.toml`](https://www.anchor-lang.com/docs/references/anchor-toml)-bestand.

</Step>
<Step>

### Test het programma

Om je project te testen, voer het volgende commando uit:

```terminal
$ anchor test
```

Dit commando bouwt, deployt en voert de tests voor je project uit.

<Callout>
  Bij gebruik van het `localnet`-cluster start Anchor automatisch een lokale
  validator, deployt het programma, voert tests uit en stopt vervolgens de
  validator.
</Callout>

<Callout type="warn" title="Fouten in de JavaScript-testrunner">

Als je een JavaScript- of TypeScript-testtemplate hebt geselecteerd, kan een van de
volgende fouten erop wijzen dat Node.js of de geconfigureerde pakketbeheerder
niet is geïnstalleerd:

```
Permission denied (os error 13)
```

```
No such file or directory (os error 2)
```

</Callout>

</Step>
</Steps>
