Stel een lokale Solana-ontwikkelomgeving in met de geautomatiseerde installer. Deze
installeert Rust, de Solana CLI, Anchor CLI, Surfpool CLI, Node.js en Yarn op
macOS, Linux of Windows via WSL.

<Callout type="info" title="Windows vereist WSL">
  Voer in Windows PowerShell `wsl --install` uit, start Windows opnieuw op als daarom wordt gevraagd en voer vervolgens
  de onderstaande installatiecommando's uit in de Ubuntu-terminal. Zie de [handleiding voor handmatige
  installatie](/docs/intro/installation/dependencies) voor de volledige
  WSL-configuratie.
</Callout>

## Snelle installatie

1. Voer de installer uit in een macOS-, Linux- of WSL-terminal:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
```

Je kunt
[de broncode van de installer bekijken](https://github.com/solana-developers/solana-install/blob/main/install.sh)
voordat je deze uitvoert. De installer detecteert ondersteunde Linux-pakketbeheerders en
installeert de bijbehorende systeemafhankelijkheden automatisch.

2. Start je terminal opnieuw op, zodat de nieuwe commando's beschikbaar zijn in je `PATH`.

3. Controleer elke tool:

```terminal
$ rustc --version
$ solana --version
$ anchor --version
$ surfpool --version
$ node --version
$ yarn --version
```

Een geslaagde installatie geeft uitvoer in deze vorm (versienummers veranderen naarmate
tools worden uitgebracht):

```txt title="Example output"
Installed Versions:
Rust: rustc x.y.z (...)
Solana CLI: solana-cli x.y.z (..., client:Agave)
Anchor CLI: anchor-cli x.y.z
Surfpool CLI: surfpool x.y.z
Node.js: vx.y.z
Yarn: x.y.z
```

<Callout type="warn" title="Installer mislukt of een commando ontbreekt">
  Volg de [handleiding voor handmatige installatie](/docs/intro/installation/dependencies)
  om elke afhankelijkheid afzonderlijk te installeren of problemen op te lossen.
</Callout>
