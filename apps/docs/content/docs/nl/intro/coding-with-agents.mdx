## Solana MCP gebruiken

De krachtigste manier om AI in te zetten voor Solana-ontwikkeling is via het
[Solana Developer MCP](https://mcp.solana.com/) (Model Context Protocol). Deze
integratie brengt gespecialiseerde Solana-kennis rechtstreeks in je IDE, waardoor
je agents toegang krijgen tot actuele Solana-documentatie en de ontwikkeling
sneller en efficiënter verloopt.

## Wat is Solana MCP?

Solana MCP is een gespecialiseerde AI-assistent die direct integreert in
AI-ondersteunde IDE's zoals Cursor en Windsurf. Wanneer je Solana-specifieke
vragen stelt, bevraagt het automatisch de MCP-server om nauwkeurige,
actuele informatie te bieden vanuit:

- De [Solana-documentatie](/docs)
- De [Anchor Framework-documentatie](https://www.anchor-lang.com/docs)
- Solana
  [Programmavoorbeelden](https://github.com/solana-developers/program-examples)
- [Solana Stack Exchange](https://solana.stackexchange.com/)-vragen en
  -antwoorden

## Voorbeelden van gebruikssituaties

Je kunt MCP gebruiken om:

- Vragen te stellen over Solana-concepten
- Programmafouten te debuggen
- Aanbevelingen voor best practices te ontvangen
- Te leren van voorbeelden van experts
- Sneller te ontwikkelen met de hulp van een expert

## Solana MCP instellen

Vind een gedetailleerde installatie- en startgids op de
[Solana MCP-website](https://mcp.solana.com/).

## Liever een skill gebruiken?

Als je liever een skill gebruikt, installeer dan de officiële Solana-skill met:

```bash
npx skills add https://github.com/solana-foundation/solana-dev-skill
```

Bekijk meer herbruikbare workflows in de [Solana Agent Skills-bibliotheek](/skills).
