## Solana Kit

`@solana/kit` ist das empfohlene TypeScript-SDK für die Entwicklung auf Solana.
Sie stellen einen Client aus kombinierbaren Plugins zusammen, fügen bei Bedarf
React-Bindungen hinzu und binden generierte Programmclients für die von Ihnen
aufgerufenen On-Chain-Programme ein.

| Paket                   | Beschreibung                                  | GitHub                                                                                 |
| ------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------- |
| @solana/kit               | Kern-SDK: RPC, Transaktionen, Codecs, Signer | [Quelle](https://github.com/anza-xyz/kit)                                              |
| @solana/react             | React-Bindungen: `ClientProvider` und Hooks   | [Quelle](https://github.com/anza-xyz/kit/tree/main/packages/react)                     |
| @solana/kit-plugin-rpc    | RPC-Verbindung + Transaktionsversand         | [Quelle](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-rpc)    |
| @solana/kit-plugin-signer | Gebührenzahler-, Identitäts- und Signer-Plugins      | [Quelle](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-signer) |
| @solana/kit-plugin-wallet | Wallet-Standard-Verbindung + React-Hooks     | [Quelle](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-wallet) |

## Solana Web3.js v3

`@solana/web3.js` v3 ist die empfohlene Version von web3.js. Sie baut die
klassische klassenbasierte API – `Connection`, `Keypair`, `Transaction`, `PublicKey` –
auf den Interna von `@solana/kit` neu auf und funktioniert daher mit Kit-Primitiven und den
oben genannten Programm-Clients. Verwenden Sie sie, wenn Sie eine bestehende web3.js-App aktualisieren oder
die klassenbasierte API bevorzugen.

Die meisten Methoden, die im Legacy-SDK synchron waren, wie
`Keypair.generate()` und `transaction.sign()`, sind jetzt asynchron.

```bash
npm install @solana/web3.js@3
```

| Paket         | Beschreibung | GitHub                                                        |
| --------------- | ----------- | ------------------------------------------------------------- |
| @solana/web3.js | Kern-SDK    | [Quelle](https://github.com/solana-foundation/solana-web3.js) |

`@solana/spl-token` hängt von `@solana/web3.js` (Legacy) ab und läuft nicht mit
v3. Verwenden Sie stattdessen `@solana-program/token` oder `@solana-program/token-2022`; deren
generierte Anweisungen und Anweisungspläne funktionieren direkt mit
`Transaction.add()` von v3.

- [Migrationsleitfaden von web3.js v1 → v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
- [spl-token-Migrationsleitfaden](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-spl-token-migration.md)

## Solana Web3.js (Legacy)

`@solana/web3.js` (Legacy, `1.x`) ist das ursprüngliche TypeScript-SDK für Solana. Es
befindet sich im Wartungsmodus und erhält nur noch kritische Fixes. Bestehende Codebasen können
[auf web3.js v3 aktualisieren](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
oder [zu Kit migrieren](/docs/frontend/web3-compat).
