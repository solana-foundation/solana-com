## Mit Devnet verbinden

Ersetzen Sie die RPC-URLs für Devnet und laden Sie das Zahlerkonto über einen
[Faucet](/developers/cookbook/development/airdrops-and-faucets) auf:

```ts
solanaRpc({
  rpcUrl: "https://api.devnet.solana.com",
  rpcSubscriptionsUrl: "wss://api.devnet.solana.com"
});
```

Alles andere bleibt unverändert. Bevor Sie dieselbe Konfiguration im Mainnet verwenden, planen Sie die Verwaltung der Autoritäten, Compliance-Vorgänge und das Monitoring des Assets.
