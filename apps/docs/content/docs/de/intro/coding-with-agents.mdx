## Solana MCP verwenden

Die leistungsstärkste Methode, KI für die Solana-Entwicklung zu nutzen, ist das
[Solana Developer MCP](https://mcp.solana.com/) (Model Context Protocol). Diese
Integration bringt spezialisiertes Solana-Wissen direkt in deine IDE und gibt
deinen Agenten Zugang zu aktueller Solana-Dokumentation – für eine schnellere
und effizientere Entwicklung.

## Was ist Solana MCP?

Solana MCP ist ein spezialisierter KI-Assistent, der sich direkt in
KI-unterstützte IDEs wie Cursor und Windsurf integriert. Bei Solana-spezifischen
Fragen fragt er automatisch den MCP-Server ab und liefert genaue,
aktuellen Informationen aus:

- Der [Solana-Dokumentation](/docs)
- Der [Anchor Framework-Dokumentation](https://www.anchor-lang.com/docs)
- Solana
  [Programmbeispielen](https://github.com/solana-developers/program-examples)
- Fragen und Antworten auf dem [Solana Stack Exchange](https://solana.stackexchange.com/)

## Beispielanwendungsfälle

Du kannst MCP verwenden, um:

- Solana-Konzepte zu verstehen
- Programmfehler zu debuggen
- Empfehlungen für Best Practices zu erhalten
- Von Expertenbeispielen zu lernen
- Mit der Unterstützung eines Experten schneller zu entwickeln

## Solana MCP einrichten

Eine ausführliche Anleitung zur Einrichtung und zum Einstieg findest du auf der
[Solana MCP-Website](https://mcp.solana.com/).

## Lieber eine Skill verwenden?

Wenn du lieber eine Skill verwendest, installiere die offizielle Solana-Skill mit:

```bash
npx skills add https://github.com/solana-foundation/solana-dev-skill
```

Weitere wiederverwendbare Workflows findest du in der [Solana Agent Skills-Bibliothek](/skills).
