Richte mit dem automatischen Installer eine lokale Solana-Entwicklungsumgebung ein. Er
installiert Rust, die Solana CLI, Anchor CLI, Surfpool CLI, Node.js und Yarn unter
macOS, Linux oder Windows über WSL.

<Callout type="info" title="Windows erfordert WSL">
  Führe in der Windows PowerShell `wsl --install` aus, starte Windows bei Aufforderung neu und
  führe anschließend die unten stehenden Installationsbefehle im Ubuntu-Terminal aus. Die vollständige
  WSL-Einrichtung findest du in der [manuellen
  Installationsanleitung](/docs/intro/installation/dependencies).
</Callout>

## Schnellinstallation

1. Führe den Installer in einem Terminal unter macOS, Linux oder WSL aus:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
```

Du kannst
[den Quellcode des Installers prüfen](https://github.com/solana-developers/solana-install/blob/main/install.sh),
bevor du ihn ausführst. Der Installer erkennt unterstützte Linux-Paketmanager und
installiert deren Systemabhängigkeiten automatisch.

2. Starte dein Terminal neu, damit die neuen Befehle in deinem `PATH` verfügbar sind.

3. Überprüfe jedes Tool:

```terminal
$ rustc --version
$ solana --version
$ anchor --version
$ surfpool --version
$ node --version
$ yarn --version
```

Eine erfolgreiche Installation liefert eine Ausgabe in dieser Form (die Versionsnummern ändern sich, sobald
neue Versionen der Tools veröffentlicht werden):

```txt title="Example output"
Installed Versions:
Rust: rustc x.y.z (...)
Solana CLI: solana-cli x.y.z (..., client:Agave)
Anchor CLI: anchor-cli x.y.z
Surfpool CLI: surfpool x.y.z
Node.js: vx.y.z
Yarn: x.y.z
```

<Callout type="warn" title="Installer fehlgeschlagen oder ein Befehl fehlt">
  Folge der [manuellen Installationsanleitung](/docs/intro/installation/dependencies),
  um jede Abhängigkeit einzeln zu installieren oder Fehler zu beheben.
</Callout>
