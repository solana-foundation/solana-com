Dieser Abschnitt bietet einige gängige Befehle und Beispiele, um Ihnen den
Einstieg in die Verwendung der [Anchor CLI](https://www.anchor-lang.com/docs) zu
erleichtern.

<Steps>
<Step>

### Projekt initialisieren

Erstelle ein neues Anchor-Projekt, indem du den unten gezeigten Befehl ausführst. Dadurch wird ein
neues Verzeichnis mit dem Projektnamen angelegt und verwendet, um ein neues Anchor-
Projekt zu initialisieren.

```terminal
$ anchor init <project-name>
```

Der folgende Befehl erstellt zum Beispiel ein Projekt namens `my-project`. Das
Verzeichnis `my-project` enthält ein modulares Rust-Programm und eine Rust-Test-
Vorlage, die LiteSVM verwendet.

```terminal
$ anchor init my-project
```

Um stattdessen eine TypeScript-Testvorlage zu generieren, wähle explizit eine aus. Verwende
zum Beispiel die Mocha-Vorlage:

```terminal
$ anchor init my-project --test-template mocha
```

TypeScript-Testvorlagen erfordern Node.js und einen JavaScript-Paketmanager.

Wechsle anschließend in das Projektverzeichnis:

```terminal
$ cd <project-name>
```

Siehe die
[Dateistruktur von Anchor-Projekten](https://www.anchor-lang.com/docs/quickstart/local#project-file-structure).

</Step>
<Step>

### Programm erstellen

Um Ihr Projekt zu erstellen, führen Sie folgenden Befehl aus:

```terminal
$ anchor build
```

Das kompilierte Programm finden Sie im `/target/deploy`-Verzeichnis.

<Callout type="warn" title="Installation der Plattform-Tools fehlgeschlagen">
  Wenn beim Build ein ungültiges Platform-Tools-Verzeichnis gemeldet wird, installiere die SBF-
  Build-Tools neu und wiederhole anschließend den Build:

```terminal
$ cargo build-sbf --force-tools-install
$ anchor build
```

</Callout>

</Step>
<Step>

### Programm bereitstellen

Um Ihr Projekt bereitzustellen, führen Sie den folgenden Befehl aus:

```terminal
$ anchor deploy
```

Dieser Befehl stellt Ihr Programm auf dem `cluster` bereit, der in der
[`Anchor.toml`](https://www.anchor-lang.com/docs/references/anchor-toml)-Datei
angegeben ist.

</Step>
<Step>

### Programm testen

Um Ihr Projekt zu testen, führen Sie den folgenden Befehl aus:

```terminal
$ anchor test
```

Dieser Befehl baut, stellt bereit und führt die Tests für Ihr Projekt aus.

<Callout>
  Bei Verwendung des `localnet`-Clusters startet Anchor automatisch einen
  lokalen Validator, stellt das Programm bereit, führt Tests aus und stoppt dann
  den Validator.
</Callout>

<Callout type="warn" title="Fehler beim JavaScript-Test-Runner">

Wenn du eine JavaScript- oder TypeScript-Testvorlage ausgewählt hast, kann einer der
folgenden Fehler darauf hinweisen, dass Node.js oder der konfigurierte Paketmanager
nicht installiert ist:

```
Permission denied (os error 13)
```

```
No such file or directory (os error 2)
```

</Callout>

</Step>
</Steps>
