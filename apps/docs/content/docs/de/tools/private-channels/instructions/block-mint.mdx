title: BlockMint
description:
  Entfernt eine zuvor erlaubte Mint aus der Instanz und verhindert neue Einzahlungen für diese Mint
---

Entfernt eine zuvor erlaubte Mint aus der Instanz und verhindert neue Einzahlungen für
diese Mint. Bestehende Einzahlungen sind nicht betroffen.

## Konten

| Konten                          | Schreibbar | Signer | Beschreibung                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | Gebührenzahler                                    |
| `admin`                          |          | ✓      | Instanz-Administrator                               |
| `instance`                       |          |        | Instanz-PDA                                 |
| `mint`                           |          |        | Zu blockierende SPL-Token-Mint                      |
| `allowed_mint`                   | ✓        |        | AllowedMint-PDA (durch diese Anweisungen geschlossen) |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | Event-Autorität-PDA                          |
| `private_channel_escrow_program` |          |        | Escrow-Programm                               |

Diese Anweisungen haben keine Parameter.

## Wichtige Hinweise

- Schließt die `allowed_mint`-PDA: neue `Deposit`-Aufrufe für diese Mint schlagen
  mit `InvalidAllowedMint` fehl
- Bestehende Kanalguthaben für diese Mint sind nicht betroffen
- Sendet ein Ereignis über `EmitEvent`-CPI
