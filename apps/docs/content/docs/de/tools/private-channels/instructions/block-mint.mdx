title: BlockMint
description:
  Entfernt einen zuvor erlaubten Mint aus der Instanz und verhindert neue Einzahlungen für diesen Mint
---

Entfernt einen zuvor erlaubten Mint aus der Instanz und verhindert neue Einzahlungen für
diesen Mint. Bestehende Einzahlungen sind davon nicht betroffen.

## Konten

| Konten                          | Beschreibbar | Signer | Beschreibung                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | Gebührenzahler                                    |
| `admin`                          |          | ✓      | Instanz-Administrator                               |
| `instance`                       |          |        | Instanz-PDA                                 |
| `mint`                           |          |        | SPL-Token-Mint zum Blockieren                      |
| `allowed_mint`                   | ✓        |        | AllowedMint-PDA (durch diese Anweisungen geschlossen) |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | Ereignisbehörde-PDA                          |
| `private_channel_escrow_program` |          |        | Escrow-Programm                               |

Diese Anweisungen benötigen keine Parameter.

## Wichtige Hinweise

- Schließt die `allowed_mint`-PDA: Neue `Deposit`-Aufrufe für diesen Mint schlagen
  mit `InvalidAllowedMint` fehl
- Bestehende Kanalguthaben für diesen Mint sind davon nicht betroffen
- Gibt ein Ereignis über `EmitEvent`-CPI aus
