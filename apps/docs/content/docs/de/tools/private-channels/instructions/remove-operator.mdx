---
title: RemoveOperator
description: Widerruft einen Operator, indem dessen Operator-PDA geschlossen wird
---

Widerruft einen Operator, indem dessen `Operator`-PDA geschlossen wird. Das widerrufene Wallet kann nicht mehr `ReleaseFunds` oder `ResetSmtRoot` aufrufen.

## Konten

| Konten                          | Schreibbar | Signer | Beschreibung                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | Gebührenzahler                                 |
| `admin`                          |          | ✓      | Instanz-Administrator                            |
| `instance`                       |          |        | Instanz-PDA                              |
| `operator`                       |          |        | Zu widerrufendes Operator-Wallet                 |
| `operator_pda`                   | ✓        |        | Operator-PDA (durch diese Anweisungen geschlossen) |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | Ereignisautoritäts-PDA                       |
| `private_channel_escrow_program` |          |        | Escrow-Programm                            |

Diese Anweisungen benötigen keine Parameter.

## Wichtige Hinweise

- Schließt die `operator_pda`; das widerrufene Wallet kann nicht mehr
  `ReleaseFunds` oder `ResetSmtRoot` aufrufen
- Alle laufenden Operator-Transaktionen schlagen nach diesem Aufruf mit `InvalidOperatorPda` fehl
- Gibt ein Ereignis über `EmitEvent`-CPI aus
