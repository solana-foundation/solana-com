Überträgt Administratorrechte auf eine neue Wallet.

## Konten

| Konten                          | Schreibbar | Signer | Beschreibung                        |
| -------------------------------- | -------- | ------ | ---------------------------------- |
| `payer`                          | ✓        | ✓      | Gebührenzahler                          |
| `current_admin`                  |          | ✓      | Aktueller Administrator (muss unterzeichnen)          |
| `instance`                       | ✓        |        | Instanz-PDA (Admin-Feld aktualisiert) |
| `new_admin`                      |          | ✓      | Wallet, die Administratorrechte erhält     |
| `event_authority`                |          |        | Ereignisautorität-PDA                |
| `private_channel_escrow_program` |          |        | Escrow-Programm                     |

Diese Anweisung hat keine Parameter.

## Wichtige Hinweise

- **Nicht rückgängig in einem Schritt**: Der aktuelle Administrator kann die Rolle nicht zurückfordern,
  ohne dass der neue Administrator erneut `SetNewAdmin` aufruft
- Überprüfen Sie die Zieladresse vor dem Aufruf; es gibt keine Rückgängig-Funktion
- Gibt ein Ereignis über `EmitEvent` CPI aus
