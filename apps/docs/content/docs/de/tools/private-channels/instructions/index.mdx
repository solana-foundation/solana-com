  On-Chain- Anweisungen Referenz für die Private Channels Escrow- und Withdraw-Programme

Dieser Abschnitt ist die On-Chain- Anweisungen Referenz. Die meisten Entwickler rufen diese
 Anweisungen über die generierten TypeScript-Clients auf; Sie benötigen dies nur, wenn Sie
Operator-Tooling entwickeln, benutzerdefinierte Integrationen schreiben oder
Fehler auf  Anweisungen-Ebene debuggen.

**Escrow-Programm** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) – verwaltet
Einzahlungen, Operator-Bereitstellung und Mainnet-Abrechnung:

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) –
  Escrow-Instanz-PDA initialisieren
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) – ein
  SPL-Token-Mint auf die Whitelist setzen
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) – einen
  Mint von der Allowlist entfernen
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) –
  einen Operator bereitstellen
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) –
  einen Operator widerrufen
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) –
  Admin-Rechte übertragen
- [Deposit](/docs/tools/private-channels/instructions/deposit) – SPL-Token
  in den Escrow verschieben
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) –
  Operator rechnet eine Auszahlung auf Mainnet ab
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) –
  Operator rotiert den Sparse Merkle Tree

**Withdraw-Programm** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) – läuft auf
dem privaten Kanalnetzwerk:

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) –
  Kanal-seitiges Guthaben verbrennen, um eine Auszahlung einzuleiten

## Fehlercodes

**Escrow-Programm – `PrivateChannelEscrowProgramError`**

| Code                                         | Nachricht                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | Ungültige Ereignisberechtigung angegeben                 |
| `InvalidAta`                                 | Ungültige ATA angegeben                             |
| `InvalidMint`                                | Ungültiger Mint angegeben                            |
| `InvalidInstanceId`                          | Instanz-ID ungültig oder entspricht nicht den Regeln    |
| `InvalidInstance`                            | Ungültige Instanz angegeben                        |
| `InvalidAdmin`                               | Ungültiger Admin angegeben                           |
| `TransferHookNotAllowed`                     | Transfer-Hook-Erweiterung nicht erlaubt              |
| `InvalidOperatorPda`                         | Ungültige Operator-PDA angegeben                    |
| `InvalidTokenAccount`                        | Ungültiges token account angegeben                   |
| `InvalidEscrowBalance`                       | Ungültiges Escrow-Guthaben                           |
| `InvalidAllowedMint`                         | Ungültiger erlaubter Mint                             |
| `InvalidSmtProof`                            | Ungültiger SMT-Beweis angegeben                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | Ungültiger Transaktions-Nonce für den aktuellen Baumindex |
| `UnexpectedTreeIndex`                        | Unerwarteter aktueller Baumindex für SMT-Root-Zurücksetzung |

**Withdraw-Programm – `PrivateChannelWithdrawProgramError`**

| Code          | Nachricht                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | Ungültiger Mint angegeben                       |
| `ZeroAmount`  | Der Auszahlungsbetrag muss größer als null sein |
