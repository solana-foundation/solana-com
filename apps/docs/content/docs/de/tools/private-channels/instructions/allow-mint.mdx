---
title: AllowMint
description:
  Erlaubt einen SPL-Token-Mint auf der Instanz und erstellt das Escrow-ATA für diesen Mint
---

Erlaubt einen SPL-Token-Mint auf der Instanz und erstellt das associated
token account des Escrows für diesen Mint. Einzahlungen für diesen Mint werden nach diesem
Aufruf möglich.

## Konten

| Konten                          | Schreibbar | Signer | Beschreibung                                                                   |
| -------------------------------- | -------- | ------ | ----------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Gebührenzahler                                                                     |
| `admin`                          |          | ✓      | Instanz-Administrator                                                                |
| `instance`                       |          |        | Instanz-PDA                                                                  |
| `mint`                           |          |        | Zu erlaubender SPL-Token-Mint                                                       |
| `allowed_mint`                   | ✓        |        | AllowedMint-PDA (durch diese Anweisung erstellt)                                 |
| `instance_ata`                   | ✓        |        | Associated token account des Escrows für diesen Mint (durch diese Anweisung erstellt) |
| `system_program`                 |          |        | System Program                                                                |
| `token_program`                  |          |        | SPL Token Program                                                             |
| `associated_token_program`       |          |        | Associated Token Program                                                      |
| `event_authority`                |          |        | Event-Authority-PDA                                                           |
| `private_channel_escrow_program` |          |        | Escrow-Programm                                                                |

## Parameter

| Parameter | Typ | Beschreibung                                                                                   |
| --------- | ---- | --------------------------------------------------------------------------------------------- |
| `bump`    | `u8` | bump seed für den `allowed_mint`-PDA. Optional: Der `Async`-Client leitet ihn automatisch ab, wenn er nicht angegeben wird |

> Das IDL enthält ein `discriminator: u8`-Argument (Wert `1`), das automatisch
> vom generierten Client gesetzt wird und nicht manuell übergeben werden sollte.

## Wichtige Hinweise

- Verwende `getAllowMintInstructionAsync`; es leitet `bump`, `allowed_mint`,
  und `instance_ata` automatisch ab, wenn sie nicht angegeben werden. Übergib einen eigenen `bump` nur, wenn
  du ihn bereits über
  `Pubkey::find_program_address(&[b"allowed_mint", instance_pda, mint], &PROGRAM_ID)` berechnet hast
- Erstellt außerdem `instance_ata`, das ATA des Escrows für diesen Mint
- Mints mit einer Transfer-Hook-Erweiterung sind ausdrücklich blockiert: Der Versuch,
  einen solchen Mint zu erlauben, wirft `TransferHookNotAllowed`
- Sendet ein Event via `EmitEvent`-CPI
