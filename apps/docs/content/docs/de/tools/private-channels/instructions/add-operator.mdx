---
title: AddOperator
description: Richtet einen neuen Operator ein, indem dessen Operator PDA erstellt wird
---

Richtet einen neuen Operator ein, indem dessen `Operator` PDA erstellt wird. Nach diesem Aufruf kann das
`operator`-Wallet `ReleaseFunds` und `ResetSmtRoot` aufrufen.

## Konten

| Konten                          | Beschreibbar | Signer | Beschreibung                                                         |
| -------------------------------- | -------- | ------ | ------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Gebührenzahler                                                           |
| `admin`                          |          | ✓      | Instanz-Admin                                                      |
| `instance`                       |          |        | Instanz-PDA                                                        |
| `operator`                       |          |        | Einzurichtendes Operator-Wallet                                        |
| `operator_pda`                   | ✓        |        | Operator PDA – automatisch abgeleitet aus `["operator", instance, operator]` |
| `system_program`                 |          |        | System Program                                                      |
| `event_authority`                |          |        | Event-Authority-PDA                                                 |
| `private_channel_escrow_program` |          |        | Escrow-Programm                                                      |

## Parameter

| Parameter | Typ | Beschreibung                                                                               |
| --------- | ---- | ----------------------------------------------------------------------------------------- |
| `bump`    | `u8` | bump seed für die `operator_pda`. Optional: Der `Async`-Client leitet ihn automatisch ab, wenn er nicht angegeben wird |

> Die IDL enthält ein `discriminator: u8`-Argument (Wert `3`), das automatisch
> vom generierten Client gesetzt wird und nicht manuell übergeben werden sollte.

## Wichtige Hinweise

- Verwende `getAddOperatorInstructionAsync`; es leitet `bump` und
  `operator_pda` automatisch ab, wenn sie nicht angegeben werden. Eine synchrone
  Variante `getAddOperatorInstruction` ist ebenfalls verfügbar, wenn `bump`
  bereits selbst berechnet wurde
- Nach diesem Aufruf kann das `operator`-Wallet `ReleaseFunds` und
  `ResetSmtRoot` aufrufen
- Gibt ein Ereignis über `EmitEvent` CPI aus
