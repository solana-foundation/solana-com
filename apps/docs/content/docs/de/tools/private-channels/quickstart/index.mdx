---
title: Schnellstart
description:
  Einzahlen, übertragen und abheben im Solana Devnet in unter 30 Minuten
---

Dieser Schnellstart führt Sie durch den vollständigen Private Channels-Ablauf im Solana Devnet:
Richten Sie die Client-Umgebung ein, zahlen Sie SPL-Token in das Escrow ein, senden Sie eine
Off-Chain-Übertragung zwischen zwei Wallets und heben Sie Guthaben zurück in Ihre Solana-Wallet ab.

Am Ende werden Sie den vollständigen Zyklus aus Einzahlung -> Off-Chain-Übertragung ->
Auszahlung verstehen und funktionierenden TypeScript-Code für jeden Schritt besitzen.

<Callout type="info">
  Dieser Schnellstart setzt voraus, dass eine Private Channels-Instanz bereits deployed und
  im Devnet mit Ihrer Mint auf der Allowlist läuft. Falls Sie zunächst eine deployen müssen,
  deckt der [Operators-Leitfaden](/docs/tools/private-channels/operators) das
  vollständige Setup ab; rechnen Sie mit 30–60 Minuten für den initialen Docker-Build.
</Callout>

## Schritte

1. **[Installation](/docs/tools/private-channels/quickstart/installation)** –
   Repository klonen und die TypeScript-Clients generieren (5 Minuten)
2. **[Token einzahlen](/docs/tools/private-channels/quickstart/deposit)** –
   SPL-Token in das Escrow einzahlen; ca. 15 Sekunden warten, bis der Indexer
   Ihr Channel-Guthaben gutschreibt
3. **[Übertragung senden](/docs/tools/private-channels/quickstart/transfer)** –
   eine Off-Chain-Übertragung über das Gateway senden; Bestätigung in unter einer Sekunde,
   berührt nie das Mainnet
4. **[Guthaben abheben](/docs/tools/private-channels/quickstart/withdraw)** – verbrennen
   Sie Ihr kanalseitiges Guthaben; der Operator überweist die Mittel innerhalb weniger Sekunden an Ihre Mainnet-Wallet
