## Voraussetzungen

- Rust 1.91+
- Solana CLI 3.1.13 (Agave):
  `sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.13/install)"`
- Node.js 24.7.0+
- pnpm 10.15.1+: `npm install -g pnpm@10.15.1`

## Repository klonen

```bash
git clone https://github.com/solana-foundation/solana-private-channels.git
cd solana-private-channels
```

## TypeScript-Clients generieren

Die TypeScript-Clients werden **nicht** auf npm veröffentlicht. Sie müssen aus
der IDL mithilfe von Codama generiert werden.

```bash
# Escrow program client
cd private-channel-escrow-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..

# Withdraw program client
cd private-channel-withdraw-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..
```

Generierte Clients befinden sich in:

- `private-channel-escrow-program/clients/typescript/src/generated/`
- `private-channel-withdraw-program/clients/typescript/src/generated/`

Importieren Sie aus diesen lokalen Pfaden in Ihrer Anwendung; es gibt kein
`@private-channels/client`-Paket auf npm. Die Codebeispiele in diesem Abschnitt verwenden einen
relativen Pfad (`../private-channel-escrow-program/...`), der davon ausgeht, dass sich Ihr Code
neben dem geklonten Repository befindet; passen Sie ihn an den tatsächlichen
Importpfad in Ihrem eigenen Projekt an.
