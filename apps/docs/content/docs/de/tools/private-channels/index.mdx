**Private Channels ist eine Enterprise-Schicht für Internet-Kapitalmärkte auf
Solana.** Sie bietet eine konfigurierbare App-Schicht für private, sofortige und gebührenfreie
Transfers innerhalb von Zahlungskanälen: Nutzer hinterlegen SPL-Token in einem On-Chain-
Escrow-Programm, wickeln Transaktionen off-chain über ein Gateway ab und rechnen über einen Sparse-Merkle-Tree-Beweis zurück auf dem Mainnet ab – und ermöglichen so App-Entwicklern sofortige, gebührenfreie und private Transfers, ohne das Solana-Ökosystem zu verlassen.

### Warum Private Channels?

- **Sofortige Transfers**: Off-Chain-Durchsatz jenseits von Solanas nativem TPS;
  Transfers werden bestätigt, sobald der Sequencer sie verarbeitet, nicht erst wenn ein Block bestätigt wird
- **Keine transferbezogenen Gebühren**: keine Gaskosten für einzelne Kanal-Transfers; Nutzer
  zahlen nur für On-Chain-Einzahlungen und -Auszahlungen
- **Datenschutz**: Transfers zwischen Kanalteilnehmern werden nicht auf dem Solana
  Mainnet aufgezeichnet
- **Kontrollierter Zugang**: RBAC mit JWT-Authentifizierung ermöglicht die Kontrolle darüber, wer
  senden und empfangen kann
- **Mainnet-Abrechnung**: Guthaben sind über einen Sparse-Merkle-Tree-Ausschlussbeweis jederzeit auf Solana einlösbar, den das Escrow-Programm on-chain durchsetzt

Siehe die **[Übersicht](/docs/tools/private-channels/overview)** für die vollständige
Architektur, das DatenflussDiagramm und das Sicherheitsmodell.

## Schnellstart

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n, // 1 USDC
  recipient: null
});
// send via your preferred Solana client
```

TypeScript-Clients werden aus der IDL generiert; siehe Installation. Für Token-2022-
Mints übergeben Sie `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS` explizit, da
standardmäßig das SPL Token Program verwendet wird.

## Anwendungsfälle

- **Institutionelle bilaterale Zahlungen** – Banken und Institutionen, die
  hochvolumige, private USDC-Transaktionen benötigen, ohne dass jeder Transfer on-chain erscheint
- **Hochfrequente App-Schicht-Transfers** – Gaming-, Loyalty- und Consumer-Apps,
  die sekundenschnelle, gebührenfreie Transfers in großem Maßstab jenseits des nativen Solana-TPS benötigen
- **Datenschutzwahrende Token-Flüsse** – alle Anwendungsfälle, bei denen die
  Vertraulichkeit von Gegenpartei und Betrag eine Produktanforderung ist

**[Wann stattdessen native SPL-Transfers verwendet werden sollten](/docs/tools/private-channels/concepts/channels#when-to-use-private-channels)**
