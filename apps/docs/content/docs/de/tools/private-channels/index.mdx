**Private Channels ist eine Enterprise-Schicht für Internet-Kapitalmärkte auf
Solana.** Es bietet eine konfigurierbare App-Schicht für private, sofortige, gebührenfreie
Transfers innerhalb von Zahlungskanälen: Nutzer hinterlegen SPL-Token in einem On-Chain-
Escrow-Programm, führen Transaktionen Off-Chain über ein Gateway durch und rechnen über einen Sparse Merkle Tree Beweis mit dem Mainnet ab – und bieten App-Entwicklern so sofortige, gebührenfreie, private Transfers, ohne das Solana-Ökosystem zu verlassen.

### Warum Private Channels?

- **Sofortige Transfers**: Off-Chain-Durchsatz jenseits von Solanas nativem TPS;
  Transfers werden bestätigt, sobald der Sequenzer sie verarbeitet, nicht wenn ein Block bestätigt wird
- **Keine Gebühren pro Transfer**: keine Gaskosten für einzelne Kanal-Transfers; Nutzer
  zahlen nur für On-Chain-Einzahlungen und -Abhebungen
- **Datenschutz**: Transfers zwischen Kanal-Teilnehmern werden nicht im Solana
  Mainnet aufgezeichnet
- **Zugangskontrolle**: RBAC mit JWT-Authentifizierung ermöglicht die Kontrolle darüber, wer
  senden und empfangen kann
- **Mainnet-Abrechnung**: Guthaben sind über einen Sparse Merkle Tree Exclusion Proof jederzeit auf Solana einlösbar, der vom Escrow-Programm On-Chain durchgesetzt wird

Weitere Informationen zur vollständigen Architektur, zum Datenflussdiagramm und zum Sicherheitsmodell finden Sie in der **[Übersicht](/docs/tools/private-channels/overview)**.

## Schnellstart

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n, // 1 USDC
  recipient: null
});
// send via your preferred Solana client
```

TypeScript-Clients werden aus der IDL generiert; siehe Installation. Für Token-2022-
Mints übergeben Sie `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS` explizit, da standardmäßig
das Standard-SPL Token Program verwendet wird.

## Anwendungsfälle

- **Institutionelle bilaterale Zahlungen** – Banken und Institutionen, die
  hochvolumige, private USDC-Transaktionen benötigen, ohne dass jeder Transfer On-Chain erscheint
- **Hochfrequente App-Schicht-Transfers** – Gaming-, Loyalty- und Consumer-Apps,
  die sekundenschnelle, gebührenfreie Transfers in großem Maßstab jenseits des nativen Solana-TPS benötigen
- **Datenschutzwahrende Token-Flows** – alle Anwendungsfälle, bei denen die Privatsphäre
  von Gegenpartei und Betrag eine Produktanforderung ist

**[Wann stattdessen native SPL-Transfers verwendet werden sollten](/docs/tools/private-channels/concepts/channels#when-to-use-private-channels)**
