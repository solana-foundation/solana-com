---
title: Deployment von Programmen
description: Best Practices für das Deployment von Programmen im Mainnet
---

Wenn du ein benutzerdefiniertes Solana-Programm als Teil deiner Zahlungsinfrastruktur deployst,
gibt es zusätzliche Aspekte zu beachten.

## Vor dem Deployment

- **Solana-CLI-Version:** Stelle sicher, dass du die neueste Version der
  [Solana CLI](https://solana.com/docs/intro/installation) verwendest.
- **Programm-keypair:** Dein Programm hat im Mainnet eine andere Adresse
  als im Devnet (es sei denn, du verwendest dasselbe keypair erneut). Aktualisiere alle Referenzen in
  deiner Anwendungskonfiguration. Bewahre dein Programm-keypair an einem sicheren Ort auf (beachte,
  dass `cargo clean` dein Programm-keypair wahrscheinlich löscht).
- **Konten initialisieren:** Wenn dein Programm Admin-Konten, PDAs oder
  andere State-Konten benötigt, stelle sicher, dass diese im Mainnet erstellt werden, bevor Nutzer
  mit deiner Anwendung interagieren. Dasselbe gilt für alle Associated Token Accounts (ATAs),
  die dein Programm benötigt.

## Deployment-Prozess

- **Buffer-Accounts:** Große Programme werden über Buffer-Accounts deployt. Der Befehl
  `solana program deploy` übernimmt dies automatisch, aber beachte,
  dass das Deployment nicht atomar ist – bei einer Unterbrechung musst du Buffer-Accounts
  eventuell wiederherstellen oder schließen.
- **Upgrade-Authority:** Erstelle ein
  [Multisig](https://docs.squads.so/main/basics/what-is-a-multisig) und weise es
  als
  [Upgrade-Authority deines Solana-Programms](https://docs.squads.so/main/navigating-your-squad/developers-assets/programs) zu.
- **Rent:** Stelle sicher, dass deine Deployment-Wallet genug SOL hat, um die Rent-Exempt-Mindestbeträge
  für alle program accounts abzudecken.
- **Verifizierung:** [Verifiziere](https://solana.com/docs/programs/verified-builds)
  dein Programm, um sicherzustellen, dass das ausführbare Programm, das du im Netzwerk von Solana deployst,
  mit dem Quellcode in deinem Repository übereinstimmt
