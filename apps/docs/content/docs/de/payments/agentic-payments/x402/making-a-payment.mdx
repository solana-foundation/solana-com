  Starte einen Agenten mit Pay und schließe eine x402-V2-Zahlung über eine lokale Sandbox-API ab, ohne echte Gelder zu bewegen.
---

Verwende [Pay](https://pay.sh), um eine x402-V2-API auszuführen und Claude Code einen
zahlungsfähigen HTTP-Client zur Verfügung zu stellen. API, Payer-Wallet und Settlement nutzen
alle die Solana-Sandbox, daher erfordert diese Anleitung weder Konten noch echte Gelder.

Du benötigst ein Terminal sowie installierte Versionen von Pay und Claude Code.

## 1. Pay installieren

Installiere unter macOS die vorkompilierte Binärdatei:

```bash
brew install pay
pay --version
```

Installiere auf anderen Plattformen das npm-Paket:

```bash
npm install --global @solana/pay
pay --version
```

## 2. Eine x402-Sandbox-API starten

Erstelle `x402-demo.yaml`:

```yaml filename=x402-demo.yaml
name: x402-demo
subdomain: x402-demo
title: "x402 Demo"
description: "Minimal x402 V2 sandbox endpoint."
category: devtools
version: v1
routing:
  type: respond
operator:
  currencies:
    usd: ["USDC"]
  network: "localnet"
  fee_payer: true
endpoints:
  - method: GET
    path: "report"
    description: "Return a sandbox report."
    metering:
      schemes: [x402-exact]
      dimensions:
        - direction: usage
          unit: requests
          scale: 1
          tiers:
            - price_usd: 0.001
```

Starte die API und lass sie laufen:

```bash
pay --sandbox server start x402-demo.yaml --bind 127.0.0.1:1402
```

Das Schema `x402-exact` macht diesen Endpunkt zu einem reinen x402-Endpunkt. Der Sandbox-Modus erstellt
und finanziert automatisch temporäre Operator- und Payer-Konten.

## 3. Den Agenten mit Pay starten

Starte in einem anderen Terminal Claude Code im Sandbox-Modus:

```bash
pay --sandbox claude
```

Pay hängt seine lokalen MCP-Tools an die Agentensitzung an. Der Agent erhält
keinen privaten Schlüssel.

## 4. Eine x402-Anfrage senden

Füge diesen Prompt in den Agenten ein:

```text
Use Pay to make exactly one sandbox x402 API request to
http://127.0.0.1:1402/report.

Before paying, show me the amount and ask for approval. Then return the API
result and payment receipt. Do not make any other paid requests.
```

Die Anfrage durchläuft einen vollständigen x402-V2-Zahlungsablauf:

1. Die API antwortet mit `402 Payment Required` und einer `PAYMENT-REQUIRED`-Challenge.
2. Pay validiert die x402-Anforderungen und zeigt die Zahlungsbedingungen an.
3. Nach der Genehmigung signiert die Sandbox-Wallet, und Pay wiederholt die Anfrage mit
   `PAYMENT-SIGNATURE`.
4. Die API liefert das Ergebnis mit einem `PAYMENT-RESPONSE`-Beleg zurück.

Es werden keine echten Gelder bewegt. Wenn du die Genehmigung ablehnst, wird die Anfrage abgebrochen.

Weiter geht es mit [x402 auf Solana](/docs/payments/agentic-payments/x402), um einen
x402-V2-Client und -Resource-Server zu erstellen, oder
[werde x402-Facilitator](/docs/tools/x402-facilitator).
