---
title: "Quickstart: Token mit der CLI erstellen"
description:
  Create a token, open a token account, mint supply, and transfer tokens using
  the SPL Token CLI on devnet.
---

Dieser Quickstart führt durch den vollständigen Token-Lebenszyklus mit der
_sh`spl-token`_ CLI. Sie erstellen einen Mint, legen ein Konten an, das den
Token halten kann, prägen 100 Token und übertragen einige an eine andere Wallet.

Verwenden Sie [Solana Playground](https://beta.solpg.io/), um die Befehle in Ihrem
Browser auszuführen, oder installieren Sie die CLI lokal mit `cargo install spl-token-cli`. Die
Adressen in Ihrer Ausgabe werden von den folgenden Beispielen abweichen.

## 1. Mit Devnet verbinden

Erstellen oder verbinden Sie eine Wallet in Solana Playground, wählen Sie dann Devnet aus und fordern Sie
SOL für Konten-Einzahlungen und Transaktions-Fee an:

```terminal
$ solana config set --url devnet
$ solana airdrop 2
```

Verwenden Sie Devnet-Token nur zum Testen. Sie haben keinen finanziellen Wert.

## 2. Token erstellen

Erstellen Sie den mint account, der Ihren Token identifiziert:

```terminal
$ spl-token create-token
```

Kopieren Sie die Token-Adresse aus der Ausgabe. Dies ist die Mint-Adresse, die Sie in
den verbleibenden Befehlen verwenden werden. Ein neuer Mint startet mit einem Vorrat von null.

```terminal
$ spl-token supply <MINT_ADDRESS>
```

## 3. Token-Konten erstellen

Ihre Wallet benötigt ein token account für diesen Mint, bevor sie ein Guthaben halten kann:

```terminal
$ spl-token create-account <MINT_ADDRESS>
```

Dies erstellt Ihr
[associated token account](/docs/tokens#associated-token-account), dessen Adresse
aus Ihrer Wallet und dem Mint abgeleitet wird.

## 4. Token prägen

Prägen Sie 100 Token in Ihr associated token account:

```terminal
$ spl-token mint <MINT_ADDRESS> 100
$ spl-token balance <MINT_ADDRESS>
```

Die Mint-Autorität muss diesen Vorgang signieren. Das Prägen erhöht sowohl Ihr token account-Guthaben als auch den vom Mint erfassten Gesamtvorrat.

## 5. Token übertragen

Senden Sie 10 Token an eine andere Devnet-Wallet. Die Option _sh`--fund-recipient`_
erstellt das associated token account des Empfängers, falls es nicht existiert:

```terminal
$ spl-token transfer <MINT_ADDRESS> 10 <RECIPIENT_WALLET_ADDRESS> --fund-recipient
```

Die Übertragung ändert die Guthaben in den token accounts von Sender und Empfänger;
sie ändert nicht den Gesamtvorrat des Mints.

## Optional: Token-2022-Metadaten hinzufügen

Um einen Namen, ein Symbol und einen URI direkt auf einem neuen Token-2022-Mint zu speichern, erstellen Sie diesen
mit aktivierter Metadaten-Erweiterung:

```terminal
$ spl-token create-token \
  --program-id TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb \
  --enable-metadata
```

Verwenden Sie dann die von diesem Befehl ausgegebene neue Mint-Adresse:

```terminal
$ spl-token initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  "EXAMPLE" \
  "https://example.com/token.json"
```

Der URI sollte ein öffentliches JSON-Metadatendokument zurückgeben. Siehe
[Token-2022-Metadaten](/docs/tokens/extensions/metadata) für das Konten-Modell
und Code-Beispiele.
