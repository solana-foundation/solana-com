# Wie man einen Token verifiziert und ihn im Solana Explorer anzeigen lässt

Eine häufige Frage von Token-Erstellern lautet: _"Warum wird mein Token nicht angezeigt, wenn
ich ihn im Solana Explorer suche, und wie bekomme ich ihn verifiziert?"_

Die kurze Antwort: Der Solana Explorer betreibt keinen eigenen einheitlichen Verifizierungsprozess. Stattdessen **aggregiert er mehrere unabhängige Verifizierungsanbieter**.
Wird dein Token durch **einen** dieser Anbieter verifiziert, erscheint er in den Suchergebnissen des Explorers und zeigt Verifizierungsinformationen an.

Diese Anleitung erklärt jeden Anbieter, was "verifiziert" bedeutet (und was nicht), und
wie du deinen Token verifizieren lassen kannst.

## Was "verifiziert" bedeutet (und was nicht)

Die Verifizierung bestätigt, dass ein Token der **kanonische / korrekte Token** für einen
bestimmten Namen, ein Symbol und eine Mint-Adresse ist. Sie hilft Nutzern, Imitatoren und
doppelte Token zu vermeiden, da jeder auf Solana einen Token mit beliebigem Namen erstellen kann.

Verifizierung ist **keine** Empfehlung eines Projekts und **keine**
Garantie für den Wert, die Sicherheit oder die Legitimität eines Tokens. Führe stets deine eigene
Recherche durch.

## Die Verifizierungsanbieter hinter dem Solana Explorer

Der Solana Explorer prüft die folgenden unabhängigen Verifizierungsdienste. Wird dein Token von
einem davon erfasst (RugCheck ist automatisch; die anderen erfordern eine Aktion), erscheint dein Token
in der Explorer-Suche.

### 1. RugCheck (automatisch)

[RugCheck](https://rugcheck.xyz) führt automatisierte On-Chain-Analysen durch und
verfolgt Token automatisch. Da der Prozess automatisch abläuft, musst du in der Regel nichts einreichen — RugCheck wertet On-Chain-Risikosignale aus (Mint-/Freeze-Autorität, Inhaberverteilung, Liquidität usw.) und verfolgt den Token eigenständig.

Für bestimmte Stablecoins gibt es eine Sonderbehandlung, bei der Projekte das RugCheck-Team direkt für eine angemessene Behandlung kontaktieren können.

Beispiel-Token-Seite:
[`rugcheck.xyz/tokens/<mint>`](https://rugcheck.xyz/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 2. Jupiter

[Jupiter](https://jup.ag) pflegt eine verifizierte Token-Liste (VRFD), die im gesamten
Solana-Ökosystem weit verbreitet ist — DEXes, Wallets und Screener. Ein
verifizierter Token erhält ein grünes Häkchen auf Jupiter-Produkten und Partnerplattformen.

Um verifiziert zu werden, reiche deinen Token zur Prüfung ein:

- Einreichen unter [verified.jup.ag/tokens](https://verified.jup.ag/tokens)
- Jeder kann einen Token einreichen (nicht nur das Projektteam)
- Du kannst optional das X-Konto des Projekts verbinden, um die Mint-Adresse des Tokens
  mit einem bestimmten Konten zu verknüpfen
- Jupiter führt eine ganzheitliche Prüfung durch (Liquidität, Einhaltung von Metadatenstandards und
  andere Signale), anstatt eine einzelne Kennzahl zu prüfen

Beispiel-Token-Seite:
[`jup.ag/tokens/<mint>`](https://jup.ag/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 3. CoinGecko

Die [CoinGecko](https://www.coingecko.com)-Verifizierung listet deinen Token mit Marktdaten. Stelle bei der Verifizierung mit CoinGecko sicher, dass du die **Mint-Adresse** des Tokens angibst (CoinGecko bezeichnet dies im Formular als „Vertragsadresse“), damit nachgelagerte Integrationen Preise korrekt auflösen können.

Folge der offiziellen CoinGecko-Anleitung für Listing/Update-Anfragen:

- [Verifizierungsanleitung für Listing- und Update-Anfragen auf CoinGecko](https://support.coingecko.com/hc/en-us/articles/23725417857817-Verification-Guide-for-Listing-Update-Requests-on-CoinGecko)

Beispiel-Coin-Seite:
[`coingecko.com/en/coins/<token>`](https://www.coingecko.com/en/coins/usdc)

### 4. Solflare

[Solflare](https://solflare.com) ist ein unabhängiger Validator im Verifizierungs-Framework des Solana
Explorers. In der Praxis überschneiden sich die Token-Listing-Kriterien stark mit denen von Jupiter, da Solflares In-App-Swap-Liste vom Jupiter-Aggregator betrieben wird. Damit ein neuer Token erscheint, muss er in der Regel:

- Ein gültiger Token auf der Solana-Blockchain sein, dessen Metadaten dem
  Metaplex Token Metadata-Standard entsprechen
- Ausreichend Liquidität aufweisen (ein Mindest-USD-Wert des Tokens muss für den
  Handel verfügbar sein)
- Den Preiseinfluss innerhalb akzeptabler Grenzen für typische Swaps halten

Aufgrund dieser Überschneidung sind Token, die die Jupiter-Verifizierung abgeschlossen haben, häufig
bereits ohne separate Einreichung für Solflare qualifiziert — daher musst du Solflare in der Regel nicht als zusätzlichen manuellen Schritt behandeln. Sobald die Kriterien erfüllt sind,
erscheinen Token normalerweise innerhalb weniger Minuten. Siehe:

- [Ich kann einen Token in Solflare nicht finden](https://help.solflare.com/en/articles/9260147-i-cannot-find-a-token-in-solflare)

Beispiel-Token-Seite:
[`solflare.com/prices/<name>/<mint>`](https://www.solflare.com/prices/usd-coin/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/)

### 5. Bluprynt (erweitertes KYC)

[Bluprynt](https://app.bluprynt.com/register/account) bietet einen erweiterten
Verifizierungsweg mit einem KYC-Protokoll. Dies ist ein strengerer, identitätsgestützter
Prozess, der für Projekte geeignet ist, die ein stärkeres Verifizierungssignal wünschen.

- Registriere dich über das
  [Bluprynt-Onboarding für den Solana Explorer](https://app.bluprynt.com/register/account)

Beispielseite für verifizierte Assets:
[`verified.bluprynt.com/verified-assets/<mint>/solana`](https://verified.bluprynt.com/verified-assets/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/solana)

## So greift alles ineinander

- **RugCheck** erfolgt automatisch durch On-Chain-Analyse — keine Einreichung
  erforderlich.
- **Jupiter, CoinGecko, Solflare und Bluprynt** erfordern jeweils eine Einreichung /
  den Abschluss ihres jeweiligen Prozesses.
- Sobald dein Token von **mindestens einem** dieser Anbieter verifiziert wurde, erscheint er
  in der **Solana Explorer**-Suche und zeigt Verifizierungsdetails an.

Wenn dein Token noch nicht in der Explorer-Suche erscheint, ist der schnellste Weg in der Regel
die Einreichung zur Jupiter-Verifizierung und/oder die Erstellung eines CoinGecko-Listings,
da beide im gesamten Ökosystem weit verbreitet sind.

## Voraussetzungen, die eine erfolgreiche Verifizierung begünstigen

Unabhängig vom Anbieter erhöhen diese On-Chain-Grundlagen die Wahrscheinlichkeit einer
erfolgreichen Verifizierung erheblich:

- **Gültige Metadaten**: Dein Token sollte On-Chain-Metadaten haben, die dem
  Metaplex Token Metadata-Standard entsprechen (Name, Symbol, Logo-URI).
- **Liquidität**: Stelle ausreichend Liquidität auf einem unterstützten DEX bereit, damit der Token gehandelt und bewertet werden kann.
- **Korrekte Mint-Adresse**: Verwende bei der Einreichung bei einem Anbieter immer die
  **Mint-Adresse** deines Tokens (in manchen Anbieterformularen als „Vertragsadresse“ bezeichnet).

## Zusammenfassung

Der Solana Explorer aggregiert mehrere unabhängige Verifizierungsdienste — **RugCheck**
(automatisch), **Jupiter**, **CoinGecko**, **Solflare** und **Bluprynt** (KYC).
Die Verifizierung durch einen davon macht deinen Token in der Explorer-Suche auffindbar. Die Verifizierung bestätigt die kanonische Token-Identität; sie ist keine
Empfehlung, daher sollten Nutzer stets ihre eigene Recherche durchführen.
