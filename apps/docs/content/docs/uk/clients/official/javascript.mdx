## Solana Kit

`@solana/kit` — рекомендований TypeScript SDK для розробки на Solana. Ви
збираєте клієнт із композованих плагінів, додаєте React-байдинги за потреби та
підключаєте згенеровані клієнти програм для викликів ончейн-програм.

| Пакет                   | Опис                                  | GitHub                                                                                 |
| ------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------- |
| @solana/kit               | Основний SDK: RPC, транзакції, кодеки, підписувачі | [Джерело](https://github.com/anza-xyz/kit)                                              |
| @solana/react             | React-байдинги: `ClientProvider` та хуки   | [Джерело](https://github.com/anza-xyz/kit/tree/main/packages/react)                     |
| @solana/kit-plugin-rpc    | RPC-з'єднання + надсилання транзакцій         | [Джерело](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-rpc)    |
| @solana/kit-plugin-signer | Плагіни платника комісії, ідентифікації та підпису      | [Джерело](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-signer) |
| @solana/kit-plugin-wallet | Підключення Wallet Standard + React-хуки     | [Джерело](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-wallet) |

## Solana Web3.js v3

`@solana/web3.js` v3 — це рекомендована версія web3.js. Вона перебудовує
класичний API на основі класів — `Connection`, `Keypair`, `Transaction`, `PublicKey` —
на базі внутрішніх компонентів `@solana/kit`, тому працює з примітивами Kit і
клієнтами програм, наведеними вище. Використовуйте її, якщо ви оновлюєте наявний застосунок на web3.js або
віддаєте перевагу API на основі класів.

Більшість методів, які були синхронними в застарілому SDK, як-от
`Keypair.generate()` та `transaction.sign()`, тепер асинхронні.

```bash
npm install @solana/web3.js@3
```

| Пакет         | Опис | GitHub                                                        |
| --------------- | ----------- | ------------------------------------------------------------- |
| @solana/web3.js | Основний SDK    | [Джерело](https://github.com/solana-foundation/solana-web3.js) |

`@solana/spl-token` залежить від `@solana/web3.js` (legacy) і не працює на
v3. Натомість використовуйте `@solana-program/token` або `@solana-program/token-2022`; їхні
згенеровані інструкції та плани інструкцій працюють безпосередньо з
`Transaction.add()` у v3.

- [Посібник із міграції з web3.js v1 на v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
- [Посібник із міграції spl-token](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-spl-token-migration.md)

## Solana Web3.js (legacy)

`@solana/web3.js` (legacy, `1.x`) — це оригінальний TypeScript SDK для Solana. Він
перебуває в режимі підтримки й отримує лише критичні виправлення. Наявні кодові бази можуть
[оновитися до web3.js v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
або [мігрувати на Kit](/docs/frontend/web3-compat).
