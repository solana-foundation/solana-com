title: "Швидкий старт: створення токена за допомогою CLI"

  Create a token, open a token account, mint supply, and transfer tokens using
  the SPL Token CLI on devnet.
---

Цей швидкий старт охоплює повний життєвий цикл токена за допомогою CLI _sh`spl-token`_. Ви створите mint, створите account для зберігання токена, відкарбуєте 100 токенів і перекажете частину на інший гаманець.

Використовуйте [Solana Playground](https://beta.solpg.io/), щоб виконувати команди у браузері, або встановіть CLI локально за допомогою `cargo install spl-token-cli`. Адреси у вашому виводі відрізнятимуться від наведених нижче прикладів.

## 1. Підключення до devnet

Створіть або підключіть гаманець у Solana Playground, потім виберіть devnet і запросіть SOL для поповнення account і сплати комісій за транзакції:

```terminal
$ solana config set --url devnet
$ solana airdrop 2
```

Використовуйте токени devnet лише для тестування. Вони не мають фінансової цінності.

## 2. Створення токена

Створіть mint account, що ідентифікує ваш токен:

```terminal
$ spl-token create-token
```

Скопіюйте адресу токена з виводу. Це mint-адреса, яку ви використовуватимете в решті команд. Новий mint починається з нульовим постачанням.

```terminal
$ spl-token supply <MINT_ADDRESS>
```

## 3. Створення token account

Вашому гаманцю потрібен token account для цього mint, перш ніж він зможе зберігати баланс:

```terminal
$ spl-token create-account <MINT_ADDRESS>
```

Це створює ваш [associated token account](/docs/tokens#associated-token-account), адреса якого виводиться з вашого гаманця та mint.

## 4. Карбування токенів

Відкарбуйте 100 токенів на ваш associated token account:

```terminal
$ spl-token mint <MINT_ADDRESS> 100
$ spl-token balance <MINT_ADDRESS>
```

Повноваження mint повинні підписати цю операцію. Карбування збільшує як баланс вашого token account, так і загальне постачання, зафіксоване у mint.

## 5. Переказ токенів

Надішліть 10 токенів на інший гаманець у devnet. Опція _sh`--fund-recipient`_ створює associated token account отримувача, якщо він не існує:

```terminal
$ spl-token transfer <MINT_ADDRESS> 10 <RECIPIENT_WALLET_ADDRESS> --fund-recipient
```

Переказ змінює баланси token account відправника та отримувача; він не змінює загальне постачання mint.

## Додатково: додавання метаданих Token-2022

Щоб зберегти назву, символ і URI безпосередньо на новому mint Token-2022, створіть його з увімкненим розширенням метаданих:

```terminal
$ spl-token create-token \
  --program-id TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb \
  --enable-metadata
```

Потім використовуйте нову mint-адресу, виведену цією командою:

```terminal
$ spl-token initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  "EXAMPLE" \
  "https://example.com/token.json"
```

URI повинен повертати публічний документ метаданих JSON. Дивіться [Token-2022 metadata](/docs/tokens/extensions/metadata) для моделі account та прикладів коду.
