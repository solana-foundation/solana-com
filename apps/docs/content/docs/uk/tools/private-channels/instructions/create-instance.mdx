Створює `Instance` PDA, що закріплює ескроу. Має бути викликано перед будь-якою
іншою операцією.

## Seeds PDA

```
instance        -> ["instance", instance_seed: Pubkey]
allowed_mint    -> ["allowed_mint", instance_pda: Pubkey, mint: Pubkey]
operator        -> ["operator", instance_pda: Pubkey, operator: Pubkey]
event_authority -> ["event_authority"]
```

## Акаунти

| Акаунт                          | Записуваний | Підписант | Опис                                                                 |
| -------------------------------- | -------- | ------ | --------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Платник комісії та rent                                                    |
| `admin`                          |          | ✓      | Початковий адміністратор інстансу                                               |
| `instance_seed`                  |          | ✓      | Одноразовий keypair, що використовується лише для виведення PDA; його pubkey стає seed |
| `instance`                       | ✓        |        | Instance PDA (виведено з `["instance", instance_seed.pubkey]`)            |
| `system_program`                 |          |        | System Program                                                              |
| `event_authority`                |          |        | PDA авторитету подій                                                         |
| `private_channel_escrow_program` |          |        | Програма ескроу                                                              |

## Параметри

| Параметр | Тип | Опис                                                                             |
| --------- | ---- | --------------------------------------------------------------------------------------- |
| `bump`    | `u8` | bump seed для Instance PDA. Необов'язково: клієнт `Async` автоматично виводить його, якщо не вказано |

> IDL містить аргумент `discriminator: u8` (значення `0`), який автоматично встановлюється
> згенерованим клієнтом і не повинен передаватися вручну.

## Важливі примітки

- `instance_seed` — це одноразовий keypair, що використовується лише для виведення `Instance`
  PDA. Його pubkey стає seed; сам keypair не зберігається і не використовується повторно.
- Використовуйте `getCreateInstanceInstructionAsync`; він автоматично виводить `bump` та `instance`
  з `instance_seed`, якщо вони не надані. Передавайте власний `bump` лише якщо
  ви вже обчислили його через
  `Pubkey::find_program_address(&[b"instance", instance_seed_pubkey.as_ref()], &PROGRAM_ID)`
- Генерує подію через `EmitEvent` CPI
