---
title: AddOperator
description: Реєструє нового оператора, створюючи його Operator PDA
---

Реєструє нового оператора, створюючи його `Operator` PDA. Після цього виклику
гаманець `operator` може викликати `ReleaseFunds` і `ResetSmtRoot`.

## Акаунти

| Акаунт                          | Записуваний | Підписант | Опис                                                         |
| -------------------------------- | -------- | ------ | ------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Платник комісії                                                           |
| `admin`                          |          | ✓      | Адміністратор інстансу                                                      |
| `instance`                       |          |        | Instance PDA                                                        |
| `operator`                       |          |        | Гаманець оператора для реєстрації                                        |
| `operator_pda`                   | ✓        |        | Operator PDA — автоматично виводиться з `["operator", instance, operator]` |
| `system_program`                 |          |        | System Program                                                      |
| `event_authority`                |          |        | PDA авторитету подій                                                 |
| `private_channel_escrow_program` |          |        | Escrow Program                                                      |

## Параметри

| Параметр | Тип | Опис                                                                               |
| --------- | ---- | ----------------------------------------------------------------------------------------- |
| `bump`    | `u8` | bump seed для `operator_pda`. Необов'язковий: клієнт `Async` автоматично виводить його, якщо не вказано |

> IDL містить аргумент `discriminator: u8` (значення `3`), який автоматично встановлюється
> згенерованим клієнтом і не повинен передаватися вручну.

## Важливі примітки

- Використовуйте `getAddOperatorInstructionAsync` — він автоматично виводить `bump` і
  `operator_pda`, якщо вони не надані. Також існує синхронний варіант
  `getAddOperatorInstruction`, якщо ви вже обчислили `bump`
  самостійно
- Після цього виклику гаманець `operator` може викликати `ReleaseFunds` і
  `ResetSmtRoot`
- Генерує подію через `EmitEvent` CPI
