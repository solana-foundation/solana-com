---
title: AddOperator
description: Надає нового оператора шляхом створення його Operator PDA
---

Надає нового оператора шляхом створення його `Operator` PDA. Після цього виклику
гаманець `operator` може викликати `ReleaseFunds` і `ResetSmtRoot`.

## Акаунти

| Акаунт                          | Записуваний | Підписант | Опис                                                         |
| -------------------------------- | -------- | ------ | ------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Платник комісії                                                           |
| `admin`                          |          | ✓      | Адміністратор екземпляра                                                      |
| `instance`                       |          |        | Instance PDA                                                        |
| `operator`                       |          |        | Гаманець оператора для надання                                        |
| `operator_pda`                   | ✓        |        | Operator PDA — автоматично похідний від `["operator", instance, operator]` |
| `system_program`                 |          |        | System Program                                                      |
| `event_authority`                |          |        | PDA авторитету подій                                                 |
| `private_channel_escrow_program` |          |        | Програма ескроу                                                      |

## Параметри

| Параметр | Тип | Опис                                                                               |
| --------- | ---- | ----------------------------------------------------------------------------------------- |
| `bump`    | `u8` | bump seed для `operator_pda`. Необов'язковий: клієнт `Async` автоматично похідний, якщо не вказано |

> IDL містить аргумент `discriminator: u8` (значення `3`), який автоматично встановлюється
> згенерованим клієнтом і не повинен передаватися вручну.

## Важливі примітки

- Використовуйте `getAddOperatorInstructionAsync`; він автоматично визначає `bump` і
  `operator_pda`, якщо вони не надані. Синхронний варіант
  `getAddOperatorInstruction` також існує, якщо ви вже самостійно обчислили `bump`
- Після цього виклику гаманець `operator` може викликати `ReleaseFunds` і
  `ResetSmtRoot`
- Генерує подію через `EmitEvent` CPI
