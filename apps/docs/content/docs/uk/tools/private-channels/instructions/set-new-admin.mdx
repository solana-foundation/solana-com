Передає права адміністратора новому гаманцю.

## Акаунти

| Акаунт                          | Записуваний | Підписувач | Опис                        |
| -------------------------------- | -------- | ------ | ---------------------------------- |
| `payer`                          | ✓        | ✓      | Платник комісії                          |
| `current_admin`                  |          | ✓      | Поточний адміністратор (має підписати)          |
| `instance`                       | ✓        |        | Instance PDA (поле адміністратора оновлено) |
| `new_admin`                      |          | ✓      | Гаманець для отримання прав адміністратора     |
| `event_authority`                |          |        | PDA авторитету подій                |
| `private_channel_escrow_program` |          |        | Програма ескроу                     |

Ця інструкція не приймає жодних параметрів.

## Важливі примітки

- **Незворотно за один крок**: поточний адміністратор не може повернути собі роль
  без того, щоб новий адміністратор знову викликав `SetNewAdmin`
- Перевірте цільову адресу перед викликом; скасування неможливе
- Генерує подію через `EmitEvent` CPI
