Видаляє раніше дозволений mint з екземпляра, запобігаючи новим депозитам для
цього mint. Наявні депозити не зачіпаються.

## Акаунти

| Акаунт                          | Записуваний | Підписант | Опис                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | Платник комісії                                    |
| `admin`                          |          | ✓      | Адміністратор екземпляра                               |
| `instance`                       |          |        | PDA екземпляра                                 |
| `mint`                           |          |        | SPL token mint для блокування                      |
| `allowed_mint`                   | ✓        |        | AllowedMint PDA (закривається цією інструкцією) |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | PDA авторизації подій                          |
| `private_channel_escrow_program` |          |        | Програма ескроу                               |

Ця інструкція не приймає параметрів.

## Важливі примітки

- Закриває `allowed_mint` PDA: нові виклики `Deposit` для цього mint завершаться
  помилкою `InvalidAllowedMint`
- Наявні баланси каналів для цього mint не зачіпаються
- Генерує подію через `EmitEvent` CPI
