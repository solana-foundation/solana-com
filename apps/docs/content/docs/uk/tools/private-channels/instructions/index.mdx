  Довідник інструкцій на блокчейні для програм Escrow та Withdraw приватних каналів
---

Цей розділ є довідником інструкцій на блокчейні. Більшість розробників викликають ці
інструкції через згенеровані клієнти TypeScript; цей матеріал потрібен лише тоді, коли ви
створюєте інструментарій оператора, пишете власні інтеграції або відлагоджуєте
помилки на рівні інструкцій.

**Програма Escrow** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) — керує
депозитами, підготовкою операторів та розрахунками в основній мережі:

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) —
  ініціалізація PDA екземпляра escrow
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) — додати
  монетний двір SPL-токена до білого списку
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) — видалити
  монетний двір зі списку дозволених
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) —
  підключити оператора
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) —
  відкликати оператора
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) —
  передати права адміністратора
- [Deposit](/docs/tools/private-channels/instructions/deposit) — перемістити SPL-токени
  до escrow
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) —
  оператор виконує розрахунок виведення коштів до основної мережі
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) —
  оператор оновлює корінь розрідженого дерева Меркла

**Програма Withdraw** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) — працює в
мережі приватних каналів:

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) —
  спалити баланс на стороні каналу для ініціювання виведення коштів

## Коди помилок

**Програма Escrow — `PrivateChannelEscrowProgramError`**

| Код                                         | Повідомлення                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | Надано недійсний орган події                 |
| `InvalidAta`                                 | Надано недійсний ATA                             |
| `InvalidMint`                                | Надано недійсний монетний двір                            |
| `InvalidInstanceId`                          | Ідентифікатор екземпляра недійсний або не відповідає правилам    |
| `InvalidInstance`                            | Надано недійсний екземпляр                        |
| `InvalidAdmin`                               | Надано недійсного адміністратора                           |
| `TransferHookNotAllowed`                     | Розширення хука передачі не дозволено              |
| `InvalidOperatorPda`                         | Надано недійсний PDA оператора                    |
| `InvalidTokenAccount`                        | Надано недійсний token account                   |
| `InvalidEscrowBalance`                       | Недійсний баланс escrow                           |
| `InvalidAllowedMint`                         | Недійсний дозволений монетний двір                             |
| `InvalidSmtProof`                            | Надано недійсний SMT-доказ                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | Недійсний одноразовий номер транзакції для поточного індексу дерева |
| `UnexpectedTreeIndex`                        | Неочікуваний поточний індекс дерева під час скидання кореня SMT |

**Програма Withdraw — `PrivateChannelWithdrawProgramError`**

| Код          | Повідомлення                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | Надано недійсний монетний двір                       |
| `ZeroAmount`  | Сума виведення має бути більшою за нуль |
