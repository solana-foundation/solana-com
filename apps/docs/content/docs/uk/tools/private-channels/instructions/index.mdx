Цей розділ є довідником on-chain інструкцій. Більшість розробників викликають ці
інструкції через згенеровані TypeScript-клієнти; він потрібен лише тоді, коли ви
розробляєте операторський інструментарій, пишете власні інтеграції або налагоджуєте
помилки на рівні інструкцій.

**Escrow Program** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) — керує
депозитами, підготовкою операторів і розрахунками в Mainnet:

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) —
  ініціалізувати PDA екземпляра escrow
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) — додати
  мінт SPL-токена до білого списку
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) — видалити
  мінт зі списку дозволених
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) —
  підготувати оператора
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) —
  відкликати оператора
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) —
  передати права адміністратора
- [Deposit](/docs/tools/private-channels/instructions/deposit) — перемістити SPL-токени
  до escrow
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) —
  оператор виконує розрахунок виведення коштів до Mainnet
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) —
  оператор ротує корінь Sparse Merkle Tree

**Withdraw Program** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) — працює в
мережі приватних каналів:

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) —
  спалити баланс на стороні каналу для ініціювання виведення коштів

## Коди помилок

**Escrow Program — `PrivateChannelEscrowProgramError`**

| Код                                         | Повідомлення                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | Надано недійсний авторитет події                 |
| `InvalidAta`                                 | Надано недійсний ATA                             |
| `InvalidMint`                                | Надано недійсний мінт                            |
| `InvalidInstanceId`                          | ID екземпляра недійсний або не відповідає правилам    |
| `InvalidInstance`                            | Надано недійсний екземпляр                        |
| `InvalidAdmin`                               | Надано недійсного адміністратора                           |
| `TransferHookNotAllowed`                     | Розширення transfer hook не дозволено              |
| `InvalidOperatorPda`                         | Надано недійсний PDA оператора                    |
| `InvalidTokenAccount`                        | Надано недійсний token account                   |
| `InvalidEscrowBalance`                       | Недійсний баланс escrow                           |
| `InvalidAllowedMint`                         | Недійсний дозволений мінт                             |
| `InvalidSmtProof`                            | Надано недійсний SMT-доказ                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | Недійсний nonce транзакції для поточного індексу дерева |
| `UnexpectedTreeIndex`                        | Неочікуваний поточний індекс дерева для скидання кореня SMT |

**Withdraw Program — `PrivateChannelWithdrawProgramError`**

| Код          | Повідомлення                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | Надано недійсний мінт                       |
| `ZeroAmount`  | Сума виведення має бути більшою за нуль |
