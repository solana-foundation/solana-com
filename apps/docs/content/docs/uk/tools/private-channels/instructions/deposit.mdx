---
title: Депозит
description:
  Переказує SPL-токени з гаманця користувача до ескроу Private Channels
---

Переказує SPL-токени з associated token account користувача до
associated token account ескроу, зараховуючи баланс каналу користувача, який здійснює депозит (або
баланс необов'язкового одержувача).

## Акаунти

| Акаунт                          | Записуваний | Підписант | Опис                                          |
| -------------------------------- | -------- | ------ | ---------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Платник комісії за транзакцію                        |
| `user`                           |          | ✓      | Власник токенів, який здійснює депозит                       |
| `instance`                       |          |        | PDA екземпляра ескроу                                  |
| `mint`                           |          |        | Мінт SPL-токена                                       |
| `allowed_mint`                   |          |        | PDA, що підтверджує дозвіл мінту на цьому екземплярі |
| `user_ata`                       | ✓        |        | Associated token account користувача (джерело)             |
| `instance_ata`                   | ✓        |        | Associated token account ескроу (призначення)      |
| `system_program`                 |          |        | System Program                                       |
| `token_program`                  |          |        | SPL Token Program                                    |
| `associated_token_program`       |          |        | Associated Token Program                             |
| `event_authority`                |          |        | PDA авторитету подій для CPI `EmitEvent`              |
| `private_channel_escrow_program` |          |        | Програма ескроу (самопосилання для CPI)              |

## Параметри

| Параметр   | Тип             | Опис                                                                           |
| ----------- | ---------------- | ------------------------------------------------------------------------------------- |
| `amount`    | `u64`            | Кількість токенів для депозиту в найменшій одиниці токена                             |
| `recipient` | `Option<Pubkey>` | Необов'язковий одержувач у мережі; якщо `None`, зараховується баланс каналу користувача, який здійснює депозит |

## Повертає

Повертає `TransactionBuilder`, який можна використовувати для побудови та надсилання
транзакції.

## Приклад

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

// allowedMint and instanceAta are auto-derived from mint and instance
const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n,
  recipient: null
});
```

## Важливі примітки

- ID програми: `9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`
- Для мінтів Token-2022 явно передайте `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS`,
  оскільки за замовчуванням використовується стандартний SPL Token Program
- PDA `allowed_mint` має існувати (створений через `AllowMint`); спроба депозиту
  незареєстрованого мінту спричинить помилку `InvalidAllowedMint`
- Якщо `recipient` має значення `None`, зараховується баланс каналу користувача, який здійснює депозит;
  якщо вказано, натомість зараховується баланс зазначеного гаманця
- Як `payer`, так і `user` мають підписати транзакцію
- Акаунт `instance_ata` має вже існувати (створений через `AllowMint` для цього мінту)
