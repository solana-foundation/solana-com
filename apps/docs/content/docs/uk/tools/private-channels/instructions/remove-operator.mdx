---
title: RemoveOperator
description: Відкликає оператора, закриваючи його Operator PDA
---

Відкликає оператора, закриваючи його `Operator` PDA. Відкликаний гаманець більше не
зможе викликати `ReleaseFunds` або `ResetSmtRoot`.

## Акаунти

| Акаунт                          | Записуваний | Підписант | Опис                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | Платник комісії                                 |
| `admin`                          |          | ✓      | Адміністратор інстансу                            |
| `instance`                       |          |        | PDA інстансу                              |
| `operator`                       |          |        | Гаманець оператора для відкликання                 |
| `operator_pda`                   | ✓        |        | Operator PDA (закривається цією інструкцією) |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | PDA авторитету подій                       |
| `private_channel_escrow_program` |          |        | Програма ескроу                            |

Ця інструкція не приймає жодних параметрів.

## Важливі примітки

- Закриває `operator_pda`; відкликаний гаманець більше не може викликати
  `ReleaseFunds` або `ResetSmtRoot`
- Будь-які транзакції оператора, що виконуються, завершаться помилкою `InvalidOperatorPda` після
  цього виклику
- Генерує подію через `EmitEvent` CPI
