title: AllowMint

  Дозволяє карбування SPL-токена на екземплярі та створює escrow ATA для цього монетного двору
---

Дозволяє карбування SPL-токена на екземплярі та створює associated
token account ескроу для цього монетного двору. Після цього
виклику стають можливими депозити для цього монетного двору.

## Акаунти

| Акаунт                          | Записуваний | Підписант | Опис                                                                   |
| -------------------------------- | -------- | ------ | ----------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Платник комісії                                                                     |
| `admin`                          |          | ✓      | Адміністратор екземпляра                                                                |
| `instance`                       |          |        | PDA екземпляра                                                                  |
| `mint`                           |          |        | Монетний двір SPL-токена для дозволу                                                       |
| `allowed_mint`                   | ✓        |        | PDA AllowedMint (створюється цією інструкцією)                                 |
| `instance_ata`                   | ✓        |        | Associated token account ескроу для цього монетного двору (створюється цією інструкцією) |
| `system_program`                 |          |        | System Program                                                                |
| `token_program`                  |          |        | SPL Token Program                                                             |
| `associated_token_program`       |          |        | Associated Token Program                                                      |
| `event_authority`                |          |        | PDA авторитету подій                                                           |
| `private_channel_escrow_program` |          |        | Програма ескроу                                                                |

## Параметри

| Параметр | Тип | Опис                                                                                   |
| --------- | ---- | --------------------------------------------------------------------------------------------- |
| `bump`    | `u8` | Bump seed для PDA `allowed_mint`. Необов'язково: клієнт `Async` автоматично визначає його, якщо не вказано |

> IDL містить аргумент `discriminator: u8` (значення `1`), який автоматично встановлюється
> згенерованим клієнтом і не повинен передаватися вручну.

## Важливі примітки

- Використовуйте `getAllowMintInstructionAsync` — він автоматично визначає `bump`, `allowed_mint`
  та `instance_ata`, якщо вони не надані. Передавайте власний `bump` лише тоді, якщо
  ви вже обчислили його через
  `Pubkey::find_program_address(&[b"allowed_mint", instance_pda, mint], &PROGRAM_ID)`
- Також створює `instance_ata` — ATA ескроу для цього монетного двору
- Монетні двори з розширенням transfer hook явно заблоковані: спроба дозволити такий монетний двір викликає помилку `TransferHookNotAllowed`
- Генерує подію через CPI `EmitEvent`
