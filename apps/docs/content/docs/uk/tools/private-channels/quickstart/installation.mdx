## Передумови

- Rust 1.91+
- Solana CLI 3.1.13 (Agave):
  `sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.13/install)"`
- Node.js 24.7.0+
- pnpm 10.15.1+: `npm install -g pnpm@10.15.1`

## Клонування репозиторію

```bash
git clone https://github.com/solana-foundation/solana-private-channels.git
cd solana-private-channels
```

## Генерація TypeScript-клієнтів

TypeScript-клієнти **не** публікуються в npm. Їх необхідно згенерувати з
IDL за допомогою Codama.

```bash
# Escrow program client
cd private-channel-escrow-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..

# Withdraw program client
cd private-channel-withdraw-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..
```

Згенеровані клієнти розміщуються в:

- `private-channel-escrow-program/clients/typescript/src/generated/`
- `private-channel-withdraw-program/clients/typescript/src/generated/`

Імпортуйте з цих локальних шляхів у своєму застосунку; пакету
`@private-channels/client` в npm не існує. Приклади коду в цьому розділі використовують
відносний шлях (`../private-channel-escrow-program/...`), який передбачає, що ваш код
розташований поряд із клонованим репозиторієм; скоригуйте його відповідно до того, звідки ви
фактично імпортуєте у своєму проєкті.
