---

Цей посібник із швидкого старту охоплює повний процес роботи з Private Channels у мережі Solana devnet:
налаштування клієнтського середовища, внесення SPL-токенів на ескроу, надсилання
позамережевого переказу між двома гаманцями та виведення коштів назад до вашого гаманця Solana.

Після завершення ви зрозумієте повний цикл: поповнення -> позамережевий переказ ->
виведення коштів — і матимете готовий код на TypeScript для кожного кроку.

<Callout type="info">
  Цей посібник із швидкого старту передбачає, що екземпляр Private Channels вже розгорнуто та
  запущено в мережі devnet із вашим монетним двором у списку дозволених. Якщо вам потрібно спочатку розгорнути його,
  [Посібник для операторів](/docs/tools/private-channels/operators) охоплює
  повне налаштування; очікуйте 30–60 хвилин на початкове складання Docker-образу.
</Callout>

## Кроки

1. **[Встановлення](/docs/tools/private-channels/quickstart/installation)** —
   клонуйте репозиторій і згенеруйте TypeScript-клієнти (5 хвилин)
2. **[Поповнення токенів](/docs/tools/private-channels/quickstart/deposit)** —
   внесіть SPL-токени на ескроу; зачекайте ~15 секунд, поки індексатор
   зарахує баланс на ваш канал
3. **[Надіслати переказ](/docs/tools/private-channels/quickstart/transfer)** —
   надішліть позамережевий переказ через шлюз; підтверджується менш ніж за секунду,
   ніколи не потрапляє до Mainnet
4. **[Вивести кошти](/docs/tools/private-channels/quickstart/withdraw)** — спаліть
   баланс на стороні каналу; оператор переводить кошти до вашого гаманця Mainnet
   протягом кількох секунд
