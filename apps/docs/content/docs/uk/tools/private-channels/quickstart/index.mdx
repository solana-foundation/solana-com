Цей посібник швидкого старту охоплює повний процес Private Channels у Solana devnet:
налаштування клієнтського середовища, поповнення ескроу токенами SPL, надсилання
позамережевого переказу між двома гаманцями та виведення коштів назад до вашого гаманця
Solana.

Після завершення ви розумітимете повний цикл поповнення -> позамережевого переказу ->
виведення коштів і матимете готовий код на TypeScript для кожного кроку.

<Callout type="info">
  Цей посібник швидкого старту передбачає, що екземпляр Private Channels вже розгорнуто та
  запущено у devnet з вашим монетним двором у списку дозволених. Якщо вам спочатку потрібно
  розгорнути його, [посібник операторів](/docs/tools/private-channels/operators) охоплює
  повне налаштування; очікуйте 30–60 хвилин на початкову збірку Docker.
</Callout>

## Кроки

1. **[Встановлення](/docs/tools/private-channels/quickstart/installation)** —
   клонуйте репозиторій та згенеруйте TypeScript-клієнти (5 хвилин)
2. **[Поповнення токенів](/docs/tools/private-channels/quickstart/deposit)** —
   поповніть ескроу токенами SPL; дозвольте ~15 секунд для індексатора,
   щоб зарахувати баланс вашого каналу
3. **[Надіслати переказ](/docs/tools/private-channels/quickstart/transfer)** —
   надішліть позамережевий переказ через шлюз; підтверджується менш ніж за секунду,
   ніколи не торкається Mainnet
4. **[Вивести кошти](/docs/tools/private-channels/quickstart/withdraw)** — спаліть
   баланс на стороні каналу; оператор розраховується з коштами на вашому гаманці Mainnet
   протягом кількох секунд
