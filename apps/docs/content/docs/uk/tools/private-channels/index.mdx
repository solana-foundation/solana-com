<Callout type="warning">
  Private Channels не пройшов аудит безпеки та не рекомендується для
  використання у виробничому середовищі з реальними коштами без ретельної перевірки безпеки.
</Callout>

**Private Channels — це корпоративний рівень для інтернет-ринків капіталу на
Solana.** Він забезпечує налаштовуваний рівень застосунків для приватних, миттєвих переказів
без комісій усередині платіжних каналів: користувачі вносять SPL-токени до програми
ескроу на блокчейні, здійснюють транзакції поза мережею через шлюз і виконують
розрахунок назад у Mainnet через доказ на основі розрідженого дерева Меркла, надаючи
розробникам застосунків миттєві, безкоштовні та приватні перекази без виходу з
екосистеми Solana.

### Чому Private Channels?

- **Миттєві перекази**: пропускна здатність поза мережею перевищує нативний TPS Solana;
  перекази підтверджуються, коли їх обробляє секвенсер, а не коли підтверджується блок
- **Нульові комісії за переказ**: жодних витрат на газ для окремих переказів у каналі;
  користувачі платять лише за внески та виведення коштів на блокчейні
- **Конфіденційність**: перекази між учасниками каналу не реєструються в
  Solana Mainnet
- **Контрольований доступ**: RBAC з автентифікацією JWT дозволяє контролювати,
  хто може надсилати та отримувати кошти
- **Розрахунок у Mainnet**: кошти завжди можна вивести до Solana за допомогою
  доказу виключення розрідженого дерева Меркла, який програма ескроу перевіряє на блокчейні

Дивіться **[Огляд](/docs/tools/private-channels/overview)** для ознайомлення з повною
архітектурою, діаграмою потоку даних і моделлю безпеки.

## Швидкий старт

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n, // 1 USDC
  recipient: null
});
// send via your preferred Solana client
```

TypeScript-клієнти генеруються з IDL; див. розділ «Встановлення». Для мінтів Token-2022
передайте `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS` явно, оскільки за замовчуванням
використовується стандартний SPL Token Program.

**[Повний посібник із швидкого старту](/docs/tools/private-channels/quickstart/installation)** —
налаштування середовища та генерація клієнтів

**[Огляд](/docs/tools/private-channels/overview)** — архітектура та потік
даних

## Сценарії використання

- **Інституційні двосторонні платежі** — банки та установи, яким потрібні
  великі обсяги приватних потоків USDC без відображення кожного переказу на блокчейні
- **Високочастотні перекази на рівні застосунків** — ігри, програми лояльності та
  споживчі застосунки, яким потрібні субсекундні перекази без комісій у масштабі, що перевищує нативний TPS Solana
- **Потоки токенів із збереженням конфіденційності** — будь-який сценарій,
  де конфіденційність контрагента та суми є вимогою продукту

**[Коли натомість використовувати нативні SPL-перекази](/docs/tools/private-channels/concepts/channels#when-to-use-private-channels)**
