<Callout type="warning">
  Private Channels не пройшов аудит безпеки та не рекомендується для
  використання у продакшені з реальними коштами без ретельної перевірки безпеки.
</Callout>

**Private Channels — це корпоративний рівень для інтернет-ринків капіталу на
Solana.** Він надає налаштовуваний прикладний рівень для приватних, миттєвих переказів
без комісій у платіжних каналах: користувачі вносять SPL-токени в ескроу-програму в мережі,
здійснюють транзакції поза мережею через шлюз і розраховуються назад у Mainnet
за допомогою доказу Sparse Merkle Tree, надаючи розробникам додатків миттєві, безкоштовні, приватні
перекази без виходу з екосистеми Solana.

### Навіщо Private Channels?

- **Миттєві перекази**: пропускна здатність поза мережею перевищує нативний TPS Solana;
  перекази підтверджуються, коли їх обробляє секвенсор, а не коли підтверджується блок
- **Нульова комісія за переказ**: відсутність витрат на газ для окремих переказів у каналі; користувачі
  платять лише за депозити та виведення коштів у мережі
- **Конфіденційність**: перекази між учасниками каналу не записуються в
  Solana Mainnet
- **Контрольований доступ**: RBAC з JWT-аутентифікацією дозволяє контролювати, хто може
  надсилати та отримувати кошти
- **Розрахунок у Mainnet**: кошти завжди можна вивести в Solana за допомогою доказу
  виключення Sparse Merkle Tree, який ескроу-програма перевіряє в мережі

Дивіться **[Огляд](/docs/tools/private-channels/overview)** для ознайомлення з повною
архітектурою, схемою потоку даних і моделлю безпеки.

## Швидкий старт

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n, // 1 USDC
  recipient: null
});
// send via your preferred Solana client
```

TypeScript-клієнти генеруються з IDL; дивіться розділ «Встановлення». Для мінтів Token-2022
передайте `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS` явно, оскільки
за замовчуванням використовується стандартний SPL Token Program.

**[Повний посібник із швидкого старту](/docs/tools/private-channels/quickstart/installation)** —
налаштування середовища та генерація клієнтів

**[Огляд](/docs/tools/private-channels/overview)** — архітектура та потік
даних

## Сценарії використання

- **Інституційні двосторонні платежі** — банки та установи, яким потрібні
  великі обсяги приватних потоків USDC без відображення кожного переказу в мережі
- **Високочастотні перекази на прикладному рівні** — ігрові, програми лояльності та споживчі додатки,
  яким потрібні субсекундні перекази без комісій у масштабі, що перевищує нативний TPS Solana
- **Конфіденційні потоки токенів** — будь-які сценарії, де конфіденційність контрагента та
  суми є продуктовою вимогою

**[Коли натомість використовувати нативні SPL-перекази](/docs/tools/private-channels/concepts/channels#when-to-use-private-channels)**
