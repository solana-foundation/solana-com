**Solana Keychain надає єдиний інтерфейс для підписання транзакцій Solana
через різні бекенди керування ключами.** Розробляйте локально з ключем у пам’яті,
а потім переходьте на корпоративне керування ключами, хмарні HSM або керовані
сервіси гаманців у продакшені — без переписування коду підписання.

### Чому Keychain?

- **Єдиний інтерфейс**: один базовий інтерфейс `SolanaSigner` для всіх бекендів
  плюс одна можливість на бекенд: підписання, переписування з підписанням або підписання з розсиланням
- **Заміна бекендів**: змінюйте провайдерів керування ключами через конфігурацію;
  місця виклику змінюються, лише якщо новий бекенд має іншу можливість (нативні
  режими Crossmint і Fordefi)
- **Платіть лише за те, що використовуєте**: прапорці функцій Rust, окремі npm-пакети для кожного бекенду, додаткові
  пакети (extras) Python і окремі Go-модулі для кожного бекенду містять лише потрібні вам бекенди
- **Аудит пройдено**: Rust, TypeScript, Python і Go пройшли аудит
  [OtterSec](https://osec.io) (опціональний бекенд Ledger не входив до обсягу аудиту); раніший
  аудит [Accretion](https://accretion.xyz) охоплював Rust і TypeScript.
  Див.
  [статус аудиту](https://github.com/solana-foundation/solana-keychain/blob/main/audits/AUDIT_STATUS.md).

### Архітектура

- **Мови**: Rust, TypeScript, Python і Go, з однаковими можливостями (бекенд Ledger
  доступний лише для Rust)
- **Інтерфейс**: базовий `SolanaSigner` (`pubkey`, `sign_message`, `is_available`)
  плюс рівно одна можливість на бекенд: `TransactionSigner`,
  `ModifyingSigner` або `SendingSigner`
- **Бекенди**: Memory, Vault, AWS KMS, GCP KMS, Privy, Turnkey, Fireblocks,
  CDP, Crossmint, Dfns, Openfort, Para, Utila, Fordefi, Ledger (лише Rust,
  опціонально, без аудиту)
- **Сумісність**: `@solana/kit` і `@solana/signers` 8.1+ (TypeScript) |
  `solana-sdk` 2.x, 3.x або 4.x через функції `sdk-v2` / `sdk-v3` / `sdk-v4`
  (Rust; транзакції v1 потребують `sdk-v4`) | `solders` (Python) | `solana-go` v2
  (Go)

### Підтримувані бекенди

Бекенди охоплюють локальну розробку, самостійне та хмарне управління ключами, а
також керовані сервіси та MPC-гаманці. Перегляньте
[Вибір бекенду](/docs/tools/keychain/choosing-a-backend), щоб порівняти моделі
зберігання та обрати відповідну.

| Бекенд         | Сценарій використання                            | Rust | TypeScript | Python | Go  |
| --------------- | ----------------------------------- | ---- | ---------- | ------ | --- |
| Memory          | Розробка, тестування                | ✓    | ✓          | ✓      | ✓   |
| HashiCorp Vault | Самостійне управління ключами          | ✓    | ✓          | ✓      | ✓   |
| AWS KMS         | Хмарний (AWS)                  | ✓    | ✓          | ✓      | ✓   |
| GCP KMS         | Хмарний (GCP)                  | ✓    | ✓          | ✓      | ✓   |
| Privy           | Вбудовані гаманці                    | ✓    | ✓          | ✓      | ✓   |
| Turnkey         | Некастодіальне управління        | ✓    | ✓          | ✓      | ✓   |
| Fireblocks      | Інституційне зберігання               | ✓    | ✓          | ✓      | ✓   |
| CDP             | Coinbase Developer Platform         | ✓    | ✓          | ✓      | ✓   |
| Crossmint       | Керовані гаманці Crossmint           | ✓    | ✓          | ✓      | ✓   |
| Dfns            | Інфраструктура гаманців Dfns          | ✓    | ✓          | ✓      | ✓   |
| Openfort        | Бекенд-гаманці Openfort            | ✓    | ✓          | ✓      | ✓   |
| Para            | MPC-гаманці Para                    | ✓    | ✓          | ✓      | ✓   |
| Utila           | MPC-зберігання Utila                   | ✓    | ✓          | ✓      | ✓   |
| Fordefi         | Fordefi MPC custody                 | ✓    | ✓          | ✓      | ✓   |
| Ledger          | Апаратний гаманець (опціонально, без аудиту) | ✓    |            |        |     |

## Швидкий старт

### Rust

Встановіть крейт Rust:

```bash
cargo add solana-keychain
```

Базове використання:

```rust
use solana_keychain::{Signer, SolanaSigner};

// Create a signer from any backend
let signer = Signer::from_memory("base58_private_key")?;
let pubkey = signer.pubkey();

// Transaction signing is a capability; `tx` is a VersionedTransaction
if let Some(tx_signer) = signer.as_transaction_signer() {
    let result = tx_signer.sign_transaction(&mut tx).await?;
}

// Or let the umbrella route any backend shape and supply the RPC hop yourself
let signature = signer
    .sign_and_send(&mut tx, |encoded| async move { broadcast(encoded).await })
    .await?;
```

- [Посібник з Rust](/docs/tools/keychain/getting-started/rust) - Повна
  інсталяція та налаштування бекенду
- [Crates.io](https://crates.io/crates/solana-keychain) - Rust crate

### TypeScript

Встановіть пакет TypeScript:

```bash
pnpm add @solana/keychain
```

Базове використання:

```typescript
import { createKeychainSigner } from "@solana/keychain";
import { signTransactionWithSigners } from "@solana/signers";

// Create any signer via the unified factory
const signer = await createKeychainSigner({
  backend: "vault",
  vaultAddr: "https://vault.example.com:8200",
  vaultToken: "hvs.xxxxx",
  keyName: "my-solana-key",
  publicKey: "base58_public_key"
});

// Sign an already-compiled transaction
const signedTx = await signTransactionWithSigners(
  [signer],
  compiledTransaction
);
```

- [Посібник з TypeScript](/docs/tools/keychain/getting-started/typescript) -
  пакети `@solana/keychain`
- [npm Package](https://www.npmjs.com/package/@solana/keychain) - npm пакет

Щоб встановити підписувач Keychain на клієнт [Kit](https://github.com/anza-xyz/kit)
як його `payer` або `identity`, використовуйте `@solana/keychain-kit-plugin` (нативні режими Crossmint і
Fordefi виключено, оскільки вони переписують транзакції).

### Python

Встановіть пакет (важчі бекенди постачаються як додаткові пакети (extras), наприклад
`solana-keychain[aws-kms]`):

```bash
pip install solana-keychain
```

Базове використання:

```python
import os

from solana_keychain import VaultSignerConfig, create_vault_signer

signer = await create_vault_signer(
    VaultSignerConfig(
        api_base_url="https://vault.example.com:8200",
        token=os.environ["VAULT_TOKEN"],
        key_name="my-solana-key",
        public_key="base58_public_key",
    )
)

# tx is a solders VersionedTransaction
result = await signer.sign_transaction(tx)
```

- [Посібник із Python](/docs/tools/keychain/getting-started/python) — повні відомості про
  встановлення, extras і конфігурацію бекендів
- [PyPI](https://pypi.org/project/solana-keychain/) — пакет Python

### Go

Кожен бекенд — це окремий Go-модуль, тож ви підтягуєте лише ті бекенди, які імпортуєте:

```bash
go get github.com/solana-foundation/solana-keychain/go/signers/vault/v2@latest
```

Базове використання:

```go
import "github.com/solana-foundation/solana-keychain/go/signers/vault/v2"

signer, err := vault.New(vault.Config{
	VaultAddr: "https://vault.example.com:8200",
	Token:     os.Getenv("VAULT_TOKEN"),
	KeyName:   "my-solana-key",
	Pubkey:    "base58_public_key",
})
if err != nil {
	return err
}

// tx is a *solana.Transaction from solana-go v2
res, err := signer.SignTransaction(ctx, tx)
```

- [Посібник із Go](/docs/tools/keychain/getting-started/go) — модулі, можливості
  та конфігурація бекендів
- [pkg.go.dev](https://pkg.go.dev/github.com/solana-foundation/solana-keychain/go/core/v2) —
  довідник Go
