---
title: Розгортання програм
description: Найкращі практики розгортання програм у Mainnet
---

Якщо ви розгортаєте власну програму Solana як частину своєї платіжної
інфраструктури, слід врахувати додаткові аспекти.

## Перед розгортанням

- **Версія Solana CLI:** Переконайтеся, що ви використовуєте останню версію
  [Solana CLI](https://solana.com/docs/intro/installation).
- **Program keypair:** Ваша програма матиме в mainnet іншу адресу, ніж у devnet (якщо ви не використовуєте повторно той самий keypair). Оновіть усі посилання в конфігурації вашого застосунку. Зберігайте program keypair у безпечному місці (зауважте, що виконання `cargo clean`, імовірно, видалить program keypair вашої програми).
- **Ініціалізуйте акаунти:** Якщо вашій програмі потрібні адміністративні акаунти, PDA або
  інші акаунти стану, переконайтеся, що їх створено в mainnet до того, як користувачі почнуть
  взаємодіяти з вашим застосунком. Те саме стосується будь-яких Associated Token Accounts (ATAs),
  потрібних вашій програмі.

## Процес розгортання

- **Буферні акаунти:** Великі програми розгортаються через буферні акаунти. Команда
  `solana program deploy` виконує це автоматично, але майте на увазі,
  що розгортання не є атомарним — у разі переривання вам може знадобитися відновити або закрити
  буферні акаунти.
- **Повноваження на оновлення:** Створіть
  [multisig](https://docs.squads.so/main/basics/what-is-a-multisig) і призначте його
  як
  [повноваження на оновлення вашої програми Solana](https://docs.squads.so/main/navigating-your-squad/developers-assets/programs).
- **Рента:** Переконайтеся, що на вашому гаманці для розгортання достатньо SOL, щоб покрити мінімальні суми для звільнення від ренти
  для всіх program accounts.
- **Верифікація:** [Верифікуйте](https://solana.com/docs/programs/verified-builds)
  свою програму, щоб переконатися, що виконуваний файл програми, який ви розгортаєте в
  мережі Solana, відповідає вихідному коду у вашому репозиторії
