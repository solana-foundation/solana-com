---
title: Розгортання програм
description: Найкращі практики розгортання програм у Mainnet
---

Якщо ви розгортаєте власну програму Solana як частину своєї платіжної
інфраструктури, потрібно врахувати додаткові аспекти.

## Перед розгортанням

- **Версія Solana CLI:** переконайтеся, що ви використовуєте найновішу версію
  [Solana CLI](https://solana.com/docs/intro/installation).
- **Keypair програми:** ваша програма матиме іншу адресу в mainnet,
  ніж у devnet (якщо ви не використовуєте повторно той самий keypair). Оновіть усі посилання в
  конфігурації вашого застосунку. Зберігайте keypair програми в безпечному місці (зверніть увагу,
  що виконання `cargo clean`, імовірно, видалить keypair вашої програми).
- **Ініціалізація акаунтів:** якщо вашій програмі потрібні акаунти адміністратора, PDA або
  інші акаунти стану, переконайтеся, що їх створено в mainnet до того, як користувачі
  почнуть взаємодіяти з вашим застосунком. Те саме стосується будь-яких Associated Token Accounts (ATA),
  потрібних вашій програмі.

## Процес розгортання

- **Буферні акаунти:** великі програми розгортаються через буферні акаунти.
  Команда `solana program deploy` виконує це автоматично, але майте на увазі,
  що розгортання не є атомарним — якщо його перервано, можливо, доведеться відновити або закрити
  буферні акаунти.
- **Upgrade authority:** створіть
  [мультипідпис](https://docs.squads.so/main/basics/what-is-a-multisig) і призначте
  його як
  [upgrade authority вашої програми Solana](https://docs.squads.so/main/navigating-your-squad/developers-assets/programs).
- **Рента:** переконайтеся, що на гаманці для розгортання достатньо SOL для покриття мінімальних сум, що звільняють від ренти,
  для всіх акаунтів програми.
- **Верифікація:** [верифікуйте](https://solana.com/docs/programs/verified-builds)
  свою програму, щоб переконатися, що виконуваний файл програми, який ви розгортаєте в мережі
  Solana, відповідає вихідному коду у вашому репозиторії
