## Інструменти

<Cards>
  <Card title="Kora" href="/docs/tools/kora">
    Створюйте потоки транзакцій без комісії та з оплатою токенами за допомогою
    paymaster Kora.
  </Card>
  <Card title="Keychain" href="/docs/tools/keychain">
    Використовуйте єдиний інтерфейс підписання для локальних ключів, KMS, HSM та
    гаманців.
  </Card>
  <Card title="Commerce Kit" href="/docs/tools/commerce-kit">
    Додайте компоненти оплати Solana та комерційні потоки до свого застосунку.
  </Card>
  <Card title="Solana Pay" href="/docs/tools/solana-pay">
    Реалізуйте потоки переказів та транзакційних запитів Solana Pay.
  </Card>
  <Card title="Attestations" href="/docs/tools/attestations">
    Створюйте облікові дані, схеми та підтвердження для офчейн-даних, пов'язаних
    з ончейн-акаунтами.
  </Card>
  <Card title="Private Channels" href="/docs/tools/private-channels">
    Перегляньте матеріали про приватні канали та ресурси для інтеграції.
  </Card>
  <Card title="Surfpool" href="/docs/tools/surfpool">
    Замінник solana-test-validator для локальної розробки, тестування та
    розгортання Infrastructure-as-Code.
  </Card>
  <Card title="LiteSVM" href="/docs/tools/litesvm">
    Тестуйте програми Solana у швидкій внутрішньопроцесній VM без validator — на
    Rust та TypeScript.
  </Card>
  <Card title="Actions and Blinks" href="/docs/tools/actions">
    Перетворіть будь-яку транзакцію Solana на посилання, яким можна поділитися, з багатим метаданими.
  </Card>
  <Card title="Інструменти ШІ" href="/docs/tools/ai">
    Використовуйте ШІ-помічники для написання коду та фреймворки агентів разом із Solana.
  </Card>
</Cards>
