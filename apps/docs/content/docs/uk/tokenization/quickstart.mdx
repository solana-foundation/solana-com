## Підключення до devnet

Замініть URL-адреси RPC на devnet і поповніть рахунок платника через [faucet](/developers/cookbook/development/airdrops-and-faucets):

```ts
solanaRpc({
  rpcUrl: "https://api.devnet.solana.com",
  rpcSubscriptionsUrl: "wss://api.devnet.solana.com"
});
```

Все інше залишається без змін. Перед використанням тієї самої конфігурації в mainnet сплануйте управління правами, операції з дотримання нормативних вимог і моніторинг активу.
