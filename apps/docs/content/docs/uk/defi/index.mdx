Єдиний глобальний стан Solana, час формування блоків ~400 мс і комісії менше цента роблять її домівкою онлайн-фінансів та DeFi: кожна програма — DEX, ринки кредитування, оракули, безстрокові контракти — є композованою в рамках однієї атомарної транзакції. Цей розділ є рівнем робочого процесу для створення фінансових застосунків; він посилається на
[Основні концепції](/docs/core/transactions) та
[кулінарну книгу](/developers/cookbook) для ознайомлення з базовою механікою.
