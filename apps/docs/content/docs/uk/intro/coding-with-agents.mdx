## Використання Solana MCP

Найефективніший спосіб використовувати ШІ для розробки на Solana — це
[Solana Developer MCP](https://mcp.solana.com/) (Model Context Protocol). Ця
інтеграція привносить спеціалізовані знання про Solana безпосередньо у ваше IDE, надаючи
вашим агентам доступ до актуальної документації Solana та роблячи розробку
швидшою та ефективнішою.

## Що таке Solana MCP?

Solana MCP — це спеціалізований ШІ-асистент, який інтегрується безпосередньо в
IDE з підтримкою ШІ, такі як Cursor та Windsurf. Коли ви ставите запитання,
пов'язані з Solana, він автоматично звертається до MCP-сервера, щоб надати точну
та актуальну інформацію з:

- [Документації Solana](/docs)
- [Документації фреймворку Anchor](https://www.anchor-lang.com/docs)
- [Прикладів програм](https://github.com/solana-developers/program-examples)
  Solana
- Запитань та відповідей
  [Solana Stack Exchange](https://solana.stackexchange.com/)

## Приклади використання

За допомогою MCP ви можете:

- Ставити запитання про концепції Solana
- Налагоджувати помилки програм
- Отримувати рекомендації щодо найкращих практик
- Навчатися на прикладах від експертів
- Розробляти швидше за допомогою експерта

## Налаштування Solana MCP

Детальний посібник із налаштування та початку роботи можна знайти на
[сайті Solana MCP](https://mcp.solana.com/).

## Бажаєте використовувати навичку?

Якщо ви надаєте перевагу навичці, встановіть офіційну навичку Solana за допомогою:

```bash
npx skills add https://github.com/solana-foundation/solana-dev-skill
```

Переглядайте більше готових робочих процесів у [бібліотеці навичок Solana Agent](/skills).
