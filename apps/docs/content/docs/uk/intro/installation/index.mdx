Налаштуйте локальне середовище розробки Solana за допомогою автоматичного інсталятора. Він
встановлює Rust, Solana CLI, Anchor CLI, Surfpool CLI, Node.js і Yarn у
macOS, Linux або Windows через WSL.

<Callout type="info" title="Windows потребує WSL">
  У Windows PowerShell виконайте `wsl --install`, за потреби перезапустіть Windows, а потім
  виконайте наведені нижче команди встановлення в терміналі Ubuntu. Повну інструкцію з налаштування
  WSL дивіться в [посібнику з ручного
  встановлення](/docs/intro/installation/dependencies).
</Callout>

## Швидке встановлення

1. Запустіть інсталятор у терміналі macOS, Linux або WSL:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
```

Перед запуском ви можете
[переглянути вихідний код інсталятора](https://github.com/solana-developers/solana-install/blob/main/install.sh).
Інсталятор визначає підтримувані менеджери пакетів Linux і
автоматично встановлює їхні системні залежності.

2. Перезапустіть термінал, щоб нові команди стали доступні у вашому `PATH`.

3. Перевірте кожен інструмент:

```terminal
$ rustc --version
$ solana --version
$ anchor --version
$ surfpool --version
$ node --version
$ yarn --version
```

Успішне встановлення повертає вивід у такому форматі (номери версій змінюються з
виходом нових версій інструментів):

```txt title="Example output"
Installed Versions:
Rust: rustc x.y.z (...)
Solana CLI: solana-cli x.y.z (..., client:Agave)
Anchor CLI: anchor-cli x.y.z
Surfpool CLI: surfpool x.y.z
Node.js: vx.y.z
Yarn: x.y.z
```

<Callout type="warn" title="Інсталятор не спрацював або якоїсь команди бракує">
  Скористайтеся [посібником з ручного встановлення](/docs/intro/installation/dependencies),
  щоб встановити кожну залежність окремо або усунути пов’язані з нею проблеми.
</Callout>
