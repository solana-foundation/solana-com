Установлюйте кожну залежність окремо, коли потрібна певна версія або коли
[швидке встановлення](/docs/intro/installation) не завершується успішно.
Для нового середовища виконуйте розділи по порядку або одразу переходьте до інструмента,
який потрібно встановити чи налагодити.

## Передумови

<Accordions>
<Accordion title="Windows">

Для розробки програм Solana на Windows ви **повинні** використовувати
[Windows Subsystem for Linux](https://learn.microsoft.com/en-us/windows/wsl/install)
(WSL). Після встановлення WSL всі інші залежності встановлюватимуться через
термінал Linux.

Щоб встановити WSL, виконайте наступну команду в Windows PowerShell:

```terminal
$ wsl --install
```

Процес встановлення запропонує вам створити обліковий запис користувача за
замовчуванням.

![Встановлення WSL](/assets/docs/intro/installation/wsl-install.png)

За замовчуванням WSL встановлює Ubuntu. Ви можете відкрити термінал Linux,
шукаючи "Ubuntu" у рядку пошуку.

![WSL Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-search.png)

Якщо ваш термінал Ubuntu виглядає як на зображенні нижче, ви можете зіткнутися з
проблемою, коли `ctrl + v` (комбінація клавіш для вставки) не працює в
терміналі.

![Термінал Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-terminal-1.png)

Якщо ви зіткнулися з цією проблемою, відкрийте Windows Terminal, шукаючи
"Terminal" у рядку пошуку.

![Windows Terminal](/assets/docs/intro/installation/wsl-windows-terminal.png)

Далі закрийте Windows Terminal і знову відкрийте термінал Linux, знову шукаючи
Ubuntu. Тепер термінал повинен виглядати як на зображенні нижче, де `ctrl + v`
(комбінація клавіш для вставки) працює.

![Термінал Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-terminal-2.png)

Якщо ви використовуєте VS Code,
[розширення WSL](https://code.visualstudio.com/docs/remote/wsl-tutorial)
дозволяє вам використовувати WSL та VS Code разом.

![Налаштування WSL у VS Code](/assets/docs/intro/installation/wsl-vscode.png)

Ви побачите наступне в рядку стану VS Code:

![WSL: Ubuntu](/assets/docs/intro/installation/wsl-vscode-ubuntu.png)

Після налаштування WSL ви готові або:

- Завершити [швидке встановлення](/docs/intro/installation), використовуючи
  термінал Ubuntu (Linux)
- Встановити [Rust](#install-rust), [Solana CLI](#install-solana-cli) та
  [Anchor CLI](#install-anchor-cli) окремо, як описано нижче

</Accordion>
<Accordion title="Linux">

<Tabs items={[".deb", ".rpm"]}>
<Tab value=".deb" >
У Debian або дистрибутиві на основі Debian, як-от Ubuntu чи Mint:

1. Оновіть списки пакетів, щоб переконатися, що всі пакети актуальні:

```terminal
$ sudo apt-get update
```

2. Встановіть наступні залежності:

```terminal
$ sudo apt-get install -y \
    build-essential \
    pkg-config \
    libudev-dev llvm libclang-dev \
    protobuf-compiler libssl-dev
```

<Callout>
Якщо під час встановлення `protobuf-compiler` виникає така помилка, виконайте
`sudo apt-get update` перед повторною спробою виконати команду встановлення.

```
Package protobuf-compiler is not available, but is referred to by another package.
This may mean that the package is missing, has been obsoleted, or
is only available from another source
```

</Callout>

  </Tab>

    <Tab value=".rpm" >
    У дистрибутиві на основі RPM, як-от Fedora або Red Hat Enterprise Linux:

Оновіть установлені пакети:

```terminal
$ sudo dnf upgrade --refresh
```

Встановіть залежності для розробки:

```terminal
$ sudo dnf group install c-development development-tools \
&& sudo dnf install pkg-config openssl-devel
```

### Встановлення Rust

Розробники створюють програми Solana, використовуючи мову програмування
[Rust](https://www.rust-lang.org/).

1. Встановіть Rust за допомогою
   [rustup](https://www.rust-lang.org/tools/install), ввівши наступну команду у
   вашому терміналі:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
```

Після успішного встановлення ви побачите таке повідомлення:

<Accordions>
<Accordion title="Повідомлення про успішне встановлення Rust">

```
Rust is installed now. Great!

To get started you may need to restart your current shell.
This would reload your PATH environment variable to include
Cargo's bin directory ($HOME/.cargo/bin).

To configure your current shell, you need to source
the corresponding env file under $HOME/.cargo.

This is usually done by running one of the following (note the leading DOT):
. "$HOME/.cargo/env"            # For sh/bash/zsh/ash/dash/pdksh
source "$HOME/.cargo/env.fish"  # For fish
```

</Accordion>
</Accordions>

2. Перезавантажте змінну середовища PATH, щоб включити директорію bin
   [Cargo](https://github.com/rust-lang/cargo):

```terminal
$ . "$HOME/.cargo/env"
```

3. Переконайтеся, що встановлення пройшло успішно.

```terminal
$ rustc --version
```

Команда виводить установлену версію Rust, наприклад:

```
rustc x.y.z (...)
```

</Step>

### Встановлення Solana CLI

Solana CLI надає всі інструменти, необхідні для створення та розгортання програм
Solana.

1. Встановіть набір інструментів Solana CLI за допомогою офіційної команди
   встановлення:

```terminal
$ sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

<Callout>
  Ви можете замінити `stable` на тег певного релізу Agave або на канал випусків `beta`
  чи `edge`.
</Callout>

2. Зробіть Solana CLI доступним у вашому поточному терміналі.

Інсталятор оновлює конфігурацію вашої оболонки та виводить команду, потрібну
для оновлення поточного сеансу. Зазвичай це така команда:

```terminal
$ export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"
```

Якщо `solana` усе ще недоступна, перезапустіть термінал. Щоб дізнатися, який файл
конфігурації оболонки оновив інсталятор, перевірте вашу поточну оболонку:

```terminal
$ echo $SHELL
```

- Якщо вивід містить `/bash`, перезапустіть термінал або виконайте
  `source ~/.bashrc`.
- Якщо вивід містить `/zsh`, перезапустіть термінал або виконайте `source ~/.zshrc`.

3. Переконайтеся, що встановлення пройшло успішно:

```terminal
$ solana --version
```

Команда виводить установлену версію Solana CLI, наприклад:

```
solana-cli x.y.z (..., client:Agave)
```

<Callout>

Усі доступні версії можна переглянути в
[репозиторії Agave на GitHub](https://github.com/anza-xyz/agave/releases). Agave — це
клієнт validator від [Anza](https://www.anza.xyz/), раніше відомий як
клієнт validator від Solana Labs.

</Callout>

4. Щоб пізніше оновити Solana CLI, виконайте:

```terminal
$ agave-install update
```

</Step>

### Встановлення Anchor CLI

[Anchor](https://www.anchor-lang.com/) — це фреймворк для розробки програм
Solana. Фреймворк Anchor використовує макроси Rust для спрощення процесу
написання програм Solana.

#### Передумови

Node.js і менеджер пакетів JavaScript потрібні лише тоді, коли ви обираєте
шаблон тестів на TypeScript, як-от Mocha або Jest. Типовий шаблон тестів LiteSVM
виконується на Rust і не потребує інструментів Node.js.

<Accordions>
<Accordion title="Встановлення Node">

1. Установіть Node за допомогою
   [Node Version Manager (nvm)](https://github.com/nvm-sh/nvm), виконавши
   таку команду:

```terminal
$ curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```

2. Перезапустіть термінал і переконайтеся, що команда `nvm` виконується успішно:

```terminal
$ command -v nvm
```

3. Установіть Node за допомогою `nvm`:

```terminal
$ nvm install --lts
```

4. Переконайтеся, що встановлення пройшло успішно, перевіривши версію Node:

```terminal
$ node --version
```

Команда виводить установлену версію Node.js, наприклад:

```
vx.y.z
```

</Accordion>
<Accordion title="Встановлення Yarn">

1. Установіть Yarn:

```terminal
$ npm install --global yarn
```

2. Переконайтеся, що встановлення пройшло успішно, перевіривши версію Yarn:

```terminal
$ yarn --version
```

Команда виводить установлену версію Yarn, наприклад:

```
x.y.z
```

</Accordion>
</Accordions>

#### Встановлення

Ви можете встановити Anchor CLI та інструменти двома способами:

- Anchor Version Manager (AVM) — рекомендований спосіб встановлення
- Без AVM — встановлення безпосередньо з GitHub

<Tabs groupId="anchor" items={["AVM", "Without AVM"]}>
<Tab value="AVM">

Anchor Version Manager (AVM) дозволяє встановлювати та керувати різними версіями
Anchor у вашій системі та легко оновлювати версії Anchor у майбутньому. Щоб
встановити Anchor за допомогою AVM, виконайте наступні кроки:

1. Встановіть AVM за допомогою наступної команди:

```terminal
$ curl -sSfL https://raw.githubusercontent.com/otter-sec/anchor/master/avm/install | sh
```

2.  Підтвердьте успішне встановлення AVM:

```terminal
$ avm --version
```

3. Встановіть Anchor CLI за допомогою AVM:

Щоб встановити останню версію:

```terminal
$ avm install latest
$ avm use latest
```

Щоб встановити конкретну версію, вкажіть номер версії:

```terminal
$ avm install 1.1.2
$ avm use 1.1.2
```

<Callout type="warn">

Під час встановлення Anchor CLI на Linux або WSL ви можете зіткнутися з такою помилкою:

```
error: could not exec the linker cc = note: Permission denied (os error 13)
```

Якщо ви бачите це повідомлення про помилку, виконайте такі кроки:

1. Встановіть залежності, перелічені в розділі
   [Linux](/docs/intro/installation/dependencies) на початку цієї
   сторінки.
2. Повторіть спробу встановлення Anchor CLI.

</Callout>

4. Перевірте успішність встановлення, перевіривши версію Anchor CLI:

```terminal
$ anchor --version
```

Команда виводить активну версію Anchor CLI, наприклад:

```
anchor-cli 1.1.2
```

<Callout type="info">

Виконайте `avm use`, щоб вибрати версію Anchor CLI для вашої системи.

- Якщо ви встановили найновішу версію, виконайте `avm use latest`.
- Якщо ви встановили версію `1.1.2`, виконайте `avm use 1.1.2`.

</Callout>

</Tab>

<Tab value="Without AVM">

1. Установіть певну версію Anchor CLI за допомогою такої команди:

```terminal
$ cargo install --git https://github.com/solana-foundation/anchor --tag v1.1.2 anchor-cli --locked
```

2. Переконайтеся, що встановлення пройшло успішно, перевіривши версію Anchor CLI:

```terminal
$ anchor --version
```

Команда виводить установлену версію Anchor CLI, наприклад:

```
anchor-cli 1.1.2
```

</Tab>

### Установіть Surfpool CLI

[Surfpool](/docs/tools/surfpool) — це інструмент для локальної розробки та покращена
заміна для `solana-test-validator`.

1. Установіть Surfpool за допомогою такої команди:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://run.surfpool.run/ | bash
```

2. Переконайтеся, що встановлення пройшло успішно, перевіривши версію
   Surfpool CLI:

```terminal
$ surfpool --version
```

Команда виводить установлену версію Surfpool CLI, наприклад:

```
surfpool x.y.z
```
