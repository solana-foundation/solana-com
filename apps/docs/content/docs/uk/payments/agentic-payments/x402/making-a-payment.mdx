Використовуйте [Pay](https://pay.sh), щоб запустити API x402 V2 і надати Claude Code
HTTP-клієнт з підтримкою платежів. API, гаманець платника та розрахунки працюють
у sandbox-середовищі Solana, тому для цього покрокового посібника не потрібні
ні обліковий запис, ні реальні кошти.

Вам знадобляться термінал, Pay та встановлений Claude Code.

## 1. Встановіть Pay

У macOS встановіть попередньо зібраний бінарний файл:

```bash
brew install pay
pay --version
```

На інших платформах встановіть пакет npm:

```bash
npm install --global @solana/pay
pay --version
```

## 2. Запустіть sandbox API x402

Створіть файл `x402-demo.yaml`:

```yaml filename=x402-demo.yaml
name: x402-demo
subdomain: x402-demo
title: "x402 Demo"
description: "Minimal x402 V2 sandbox endpoint."
category: devtools
version: v1
routing:
  type: respond
operator:
  currencies:
    usd: ["USDC"]
  network: "localnet"
  fee_payer: true
endpoints:
  - method: GET
    path: "report"
    description: "Return a sandbox report."
    metering:
      schemes: [x402-exact]
      dimensions:
        - direction: usage
          unit: requests
          scale: 1
          tiers:
            - price_usd: 0.001
```

Запустіть API і залиште його працювати:

```bash
pay --sandbox server start x402-demo.yaml --bind 127.0.0.1:1402
```

Схема `x402-exact` робить цю кінцеву точку доступною лише для x402. Режим sandbox
автоматично створює та поповнює тимчасові облікові записи оператора й платника.

## 3. Запустіть агента з Pay

В іншому терміналі запустіть Claude Code у режимі sandbox:

```bash
pay --sandbox claude
```

Pay підключає свої локальні інструменти MCP до сесії агента. Агент не
отримує приватний ключ.

## 4. Виконайте один запит x402

Вставте цей промпт в агента:

```text
Use Pay to make exactly one sandbox x402 API request to
http://127.0.0.1:1402/report.

Before paying, show me the amount and ask for approval. Then return the API
result and payment receipt. Do not make any other paid requests.
```

Запит проходить повний цикл платежу x402 V2:

1. API повертає `402 Payment Required` із запитом `PAYMENT-REQUIRED`.
2. Pay перевіряє вимоги x402 і показує умови платежу.
3. Після підтвердження sandbox-гаманець підписує транзакцію, а Pay повторює запит із
   `PAYMENT-SIGNATURE`.
4. API повертає результат разом із квитанцією `PAYMENT-RESPONSE`.

Реальні кошти не переказуються. Якщо відхилити підтвердження, запит буде зупинено.

Продовжте з [x402 у Solana](/docs/payments/agentic-payments/x402), щоб створити
клієнт і сервер ресурсів x402 V2, або
[стати фасилітатором x402](/docs/tools/x402-facilitator).
