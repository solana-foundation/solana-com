### Фреймворки для ШІ-агентів

ШІ-агенти можуть автономно виконувати платіжні транзакції в Solana. Ці
фреймворки дають змогу створювати агентів, які обробляють платежі, відстежують транзакції
та автоматизують платіжні процеси:

| Фреймворк        | Опис                                                                        | Посилання                                                                                     |
| ---------------- | ---------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Solana Agent Kit | Інструменти для створення агентів, здатних виконувати платежі; сумісні з LangChain і Vercel AI | [GitHub](https://github.com/sendaifun/solana-agent-kit) • [Документація](https://kit.sendai.fun/) |
| Send AI Skills   | Колекція готових навичок для створення агентів у Solana                     | [GitHub](https://github.com/sendaifun/skills)                                             |
| Eliza Framework  | Багатоплатформний фреймворк для агентів із плагіном Solana для ботів у X, Telegram, Discord    | [GitHub](https://github.com/elizaOS/eliza) • [Документація](https://docs.elizaos.ai/)             |
| GOAT Toolkit     | Кросчейн-набір інструментів із платіжними діями Solana                                    | [GitHub](https://github.com/goat-sdk/goat)                                                |
