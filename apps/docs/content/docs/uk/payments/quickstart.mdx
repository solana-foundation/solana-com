У результаті ви отримаєте React-компонент, який показує QR-код Solana Pay для платежу в USDC, очікує надходження платежу та перевіряє, чи він збігається із запитаним. Вам знадобляться Node.js 20+, додаток на React або Next.js (щойно створений
`create-next-app` підійде) і мобільний гаманець, налаштований на devnet. Поповніть його
tестовими USDC із [faucet.circle.com](https://faucet.circle.com) та тестовими SOL
із [faucet.solana.com](https://faucet.solana.com), щоб покрити комісії за транзакції.

<Callout type="caution">
  `@solana/pay` наразі перебуває в бета-версії. API може змінитися до стабільного релізу.
</Callout>

## 1. Встановіть Solana Pay

```bash
pnpm add @solana/pay@beta @solana/kit
```

## 2. Додайте QR-код для оплати

Компонент створює унікальний референс для замовлення, кодує його в URL
[запиту на переказ](/docs/tools/solana-pay/quickstart/transfer-requests) і
відображає цей URL як QR-код. Потім він відстежує транзакцію, що містить
референс, і перевіряє одержувача, суму та токен, перш ніж позначити
замовлення як оплачене. Укажіть у `MERCHANT_WALLET` адресу, яку ви контролюєте:

```tsx
"use client";

import { useEffect, useRef, useState } from "react";
import {
  address,
  createSolanaRpc,
  createSolanaRpcSubscriptions,
  generateKeyPair,
  getAddressFromPublicKey
} from "@solana/kit";
import {
  createQR,
  encodeURL,
  validateTransfer,
  watchReference
} from "@solana/pay";

const MERCHANT_WALLET = address("your-wallet-address");
const USDC_DEVNET = address("4zMMC9srt5Ri5X14GAgXhaHii3GnPAEERYPJgZJDncDU");
const AMOUNT = 1;

const rpc = createSolanaRpc("https://api.devnet.solana.com");
const rpcSubscriptions = createSolanaRpcSubscriptions(
  "wss://api.devnet.solana.com"
);

export function Checkout() {
  const qrRef = useRef<HTMLDivElement>(null);
  const [signature, setSignature] = useState<string | null>(null);

  useEffect(() => {
    const abortController = new AbortController();

    async function startPayment() {
      const keyPair = await generateKeyPair();
      const reference = await getAddressFromPublicKey(keyPair.publicKey);

      const url = encodeURL({
        recipient: MERCHANT_WALLET,
        amount: AMOUNT,
        splToken: USDC_DEVNET,
        reference,
        label: "My Store",
        message: "Order #1001"
      });

      if (abortController.signal.aborted) return;

      if (qrRef.current) {
        qrRef.current.innerHTML = "";
        createQR(url, 300).append(qrRef.current);
      }

      const result = await watchReference(rpcSubscriptions, reference, {
        abortSignal: abortController.signal
      });
      if (result.err) throw new Error("Payment transaction failed");

      await validateTransfer(rpc, result.signature, {
        recipient: MERCHANT_WALLET,
        amount: AMOUNT,
        splToken: USDC_DEVNET,
        reference
      });
      setSignature(result.signature);
    }

    startPayment().catch((error) => {
      if (!abortController.signal.aborted) console.error(error);
    });

    return () => abortController.abort();
  }, []);

  if (signature) return <p>Payment confirmed: {signature}</p>;
  return <div ref={qrRef} />;
}
```

`amount` указується в одиницях токена, тож `1` означає запит на 1 USDC. Якщо не вказувати `splToken`,
буде запит на SOL.

## 3. Прийміть платіж

Запустіть додаток, відскануйте QR-код гаманцем і підтвердьте платіж. Щойно
транзакцію підтверджено та вона пройшла перевірку, компонент показує
підпис транзакції. Цей підпис — ваша квитанція: знайдіть її за допомогою
[getTransaction](/docs/rpc/http/gettransaction) або в будь-якому провіднику.

<Callout type="warn">
  Перевірка в браузері підходить для демо. Перш ніж виконувати реальні замовлення,
  перевіряйте платежі на своєму сервері. Див. [перевірка
  платежів](/docs/payments/accept-payments/verification-tools).
</Callout>
