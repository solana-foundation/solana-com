## Emisja i zarządzanie zasobami

Jeśli tworzysz zasób od podstaw, a nie integrujesz już istniejącego,
przejdź do [Emisji i Tokenizacji](/docs/tokenization). Obejmuje ona tworzenie tokenów,
kontrole dostępu, rozliczenia dostawa-za-płatność oraz operacje funduszowe.
