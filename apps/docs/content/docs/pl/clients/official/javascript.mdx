## Solana Kit

`@solana/kit` to zalecane SDK TypeScript do budowania na Solanie. Składasz
klienta z kompozytowalnych wtyczek, dodajesz powiązania React gdy ich
potrzebujesz i dołączasz wygenerowane klienty programów dla programów on-chain,
które wywołujesz.

| Pakiet                   | Opis                                  | GitHub                                                                                 |
| ------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------- |
| @solana/kit               | Podstawowe SDK: RPC, transakcje, kodeki, podpisujący | [Źródło](https://github.com/anza-xyz/kit)                                              |
| @solana/react             | Powiązania React: `ClientProvider` i hooki   | [Źródło](https://github.com/anza-xyz/kit/tree/main/packages/react)                     |
| @solana/kit-plugin-rpc    | Połączenie RPC + wysyłanie transakcji         | [Źródło](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-rpc)    |
| @solana/kit-plugin-signer | Wtyczki płatnika opłat, tożsamości i podpisującego      | [Źródło](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-signer) |
| @solana/kit-plugin-wallet | Połączenie Wallet Standard + hooki React     | [Źródło](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-wallet) |

## Solana Web3.js v3

`@solana/web3.js` v3 to zalecana wersja web3.js. Odtwarza klasyczne API oparte na
klasach — `Connection`, `Keypair`, `Transaction`, `PublicKey` —
na bazie wewnętrznych mechanizmów `@solana/kit`, dzięki czemu współpracuje z prymitywami Kit oraz
klientami programów wymienionymi powyżej. Użyj jej, jeśli aktualizujesz istniejącą aplikację web3.js lub
preferujesz API oparte na klasach.

Większość metod, które w starszym SDK były synchroniczne, takich jak
`Keypair.generate()` i `transaction.sign()`, jest teraz asynchroniczna.

```bash
npm install @solana/web3.js@3
```

| Pakiet         | Opis | GitHub                                                        |
| --------------- | ----------- | ------------------------------------------------------------- |
| @solana/web3.js | Podstawowe SDK    | [Źródło](https://github.com/solana-foundation/solana-web3.js) |

`@solana/spl-token` zależy od `@solana/web3.js` (legacy) i nie działa na
v3. Zamiast tego użyj `@solana-program/token` lub `@solana-program/token-2022`; ich
wygenerowane instrukcje i plany instrukcji działają bezpośrednio z
`Transaction.add()` w wersji v3.

- [Przewodnik migracji z web3.js v1 do v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
- [Przewodnik migracji spl-token](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-spl-token-migration.md)

## Solana Web3.js (legacy)

`@solana/web3.js` (legacy, `1.x`) to oryginalne SDK Solany dla TypeScriptu. Jest
w trybie konserwacji i otrzymuje wyłącznie poprawki krytyczne. Istniejące bazy kodu mogą
[przejść na web3.js v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
lub [zmigrować do Kit](/docs/frontend/web3-compat).
