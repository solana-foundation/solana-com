Metody do manipulowania czasem i uzyskiwania dostępu do zmiennych systemowych. Każdy getter sysvara ma odpowiadający mu setter; struktury są zwykłymi lustrzanymi odpowiednikami źródła Solany w Go.

## Manipulacja Zegarem

### WarpToSlot

```go
func (s *LiteSVM) WarpToSlot(slot uint64) error
```

Przesuń wewnętrzny zegar do określonego slot.

```go
before, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("current slot: %d", before.Slot)

if err := svm.WarpToSlot(10_000_000); err != nil {
    t.Fatal(err)
}

after, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("new slot:     %d", after.Slot)
```

### Clock

```go
type Clock struct {
    Slot                uint64
    EpochStartTimestamp int64
    Epoch               uint64
    LeaderScheduleEpoch uint64
    UnixTimestamp       int64
}

func (s *LiteSVM) Clock() (Clock, error)
```

Odczytaj sysvar Clock.

```go
c, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("slot=%d epoch=%d unix=%d", c.Slot, c.Epoch, c.UnixTimestamp)
```

### SetClock

```go
func (s *LiteSVM) SetClock(c Clock) error
```

Nadpisz sysvar Clock. Odczytaj go, zmień pola i zapisz z powrotem, gdy potrzebujesz kontroli nad `Epoch` lub `UnixTimestamp` (których `WarpToSlot` nie aktualizuje).

```go
c, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
c.Slot = 1_000
c.Epoch = 10
c.UnixTimestamp = 1_735_689_600
if err := svm.SetClock(c); err != nil {
    t.Fatal(err)
}
```

<Callout type="info">
  `WarpToSlot` aktualizuje tylko `Slot`. Używaj `SetClock`, gdy Twój program odczytuje
  `Epoch` lub `UnixTimestamp` z sysvara Clock.
</Callout>

## Nagrody Epoch

```go
type EpochRewards struct {
    DistributionStartingBlockHeight uint64
    NumPartitions                   uint64
    ParentBlockhash                 solana.Hash
    TotalPointsLo                   uint64 // low 64 bits of the u128 total_points
    TotalPointsHi                   uint64 // high 64 bits
    TotalRewards                    uint64
    DistributedRewards              uint64
    Active                          bool
}

func (s *LiteSVM) EpochRewards() (EpochRewards, error)
func (s *LiteSVM) SetEpochRewards(e EpochRewards) error
```

`total_points` jest typu `u128` po stronie Solany; `litesvm-go` udostępnia obie połówki
explicitnie, aby wywołujący w Go nie potrzebowali biblioteki u128. Dla wartości mieszczących się w 64
bitach, `TotalPointsHi` wynosi `0`, a `TotalPointsLo` jest wartością.

### SlotHistory

`SlotHistory` to bitvec o rozmiarze ~128 KB; `litesvm-go` udostępnia go jako uchwyt zamiast
wycinka (slice).

```go
sh, err := litesvm.NewSlotHistory()
if err != nil {
    t.Fatal(err)
}
defer sh.Close()

sh.Add(42)

switch sh.Check(42) {
case litesvm.SlotHistoryFound:
    // ...
case litesvm.SlotHistoryNotFound:
    // ...
case litesvm.SlotHistoryTooOld:
    // ...
case litesvm.SlotHistoryFuture:
    // ...
}

if err := svm.SetSlotHistory(sh); err != nil {
    t.Fatal(err)
}
```

| Metoda                                           | Opis                                |
| ------------------------------------------------ | ------------------------------------------ |
| `litesvm.NewSlotHistory() (*SlotHistory, error)` | Pusty uchwyt                               |
| `sh.Add(slot uint64)`                            | Zapisz slot                              |
| `sh.Check(slot uint64) SlotHistoryCheck`         | `Future` / `TooOld` / `Found` / `NotFound` |
| `sh.Oldest() uint64`                             | Najstarszy śledzony slot                        |
| `sh.Newest() uint64`                             | Najnowszy śledzony slot                        |
| `sh.NextSlot() uint64`                           | Następny slot do zapisania                        |
| `sh.SetNextSlot(slot uint64) error`              | Nadpisz znacznik następnego slot              |
| `sh.Close()`                                     | Zwolnij uchwyt                         |
| `svm.SlotHistory() (*SlotHistory, error)`        | Odczytaj do nowego uchwytu                   |
| `svm.SetSlotHistory(*SlotHistory) error`         | Zainstaluj na SVM                         |

## Testowanie Logiki Zależnej od Czasu

Używaj `WarpToSlot` do prostego przesuwania opartego na slot, `SetClock` dla pełnej kontroli:

```go
func TestTimeLockedVault(t *testing.T) {
    svm, err := litesvm.New()
    if err != nil {
        t.Fatal(err)
    }
    defer svm.Close()

    const unlockSlot = uint64(10_000)

    // Setup: create the time-locked account ...

    // Test 1: Try to withdraw before unlock (should fail)
    before, err := svm.Clock()
    if err != nil {
        t.Fatal(err)
    }
    t.Logf("current slot: %d", before.Slot)
    // ... attempt withdrawal, expect failure ...

    // Warp time forward past unlock slot
    if err := svm.WarpToSlot(unlockSlot + 1); err != nil {
        t.Fatal(err)
    }

    // Test 2: Try to withdraw after unlock (should succeed)
    after, err := svm.Clock()
    if err != nil {
        t.Fatal(err)
    }
    t.Logf("new slot: %d", after.Slot)
    // ... attempt withdrawal, expect success ...
}
```
