title: Konfiguracja
description: Metody setter do konfigurowania LiteSVM w Go
---

Każdy setter odpowiada metodzie builder na typie Rust `LiteSVM`.
Wywołania są stosowane natychmiast i zwracają `error`.

## Typowa konfiguracja testu

```go
svm, err := litesvm.New()
if err != nil {
    t.Fatal(err)
}
defer svm.Close()

// Each setter returns an error. The calls below are infallible in practice,
// so the docs use _ = ... for brevity; check the error in production code.
_ = svm.SetSigverify(false)        // skip signature verification (faster)
_ = svm.SetBlockhashCheck(false)   // skip blockhash validation (simpler)
_ = svm.SetSysvars()               // reset Clock, Rent, etc. to defaults
_ = svm.SetBuiltins()              // reload built-in programs
_ = svm.SetTransactionHistory(100) // keep the last 100 transactions
```

## Podpis i Blockhash

### SetSigverify

```go
func (s *LiteSVM) SetSigverify(enabled bool) error
```

Przełącz weryfikację podpisów transakcji.

```go
if err := svm.SetSigverify(false); err != nil { // accept unsigned / badly-signed txs
    t.Fatal(err)
}
if err := svm.SetSigverify(true); err != nil {  // restore production-like behavior
    t.Fatal(err)
}
```

<Callout type="info">
  Wyłączenie weryfikacji podpisów przyspiesza testy, ale czyni je mniej realistycznymi.
</Callout>

### Sigverify

```go
func (s *LiteSVM) Sigverify() (bool, error)
```

Odczytaj bieżące ustawienie.

### SetBlockhashCheck

```go
func (s *LiteSVM) SetBlockhashCheck(enabled bool) error
```

Przełącz sprawdzanie recent-blockhash dla przesyłanych transakcji.

```go
if err := svm.SetBlockhashCheck(false); err != nil { // accept any blockhash
    t.Fatal(err)
}
```

## Programy i Sysvars

### SetSysvars

```go
func (s *LiteSVM) SetSysvars() error
```

Ponownie zainicjuj wbudowane sysvary (Clock, Rent, EpochSchedule, ...) do ich
domyślnych wartości.

### SetBuiltins

```go
func (s *LiteSVM) SetBuiltins() error
```

Załaduj domyślny zestaw wbudowanych programów.

### SetDefaultPrograms

```go
func (s *LiteSVM) SetDefaultPrograms() error
```

Załaduj standardowe programy SPL (System Program, SPL Token, Memo, ...).

### SetPrecompiles

```go
func (s *LiteSVM) SetPrecompiles() error
```

Włącz prekompilowane programy ed25519 / secp256k1.

### WithNativeMints

```go
func (s *LiteSVM) WithNativeMints() error
```

Zasil konta natywnego mintu SPL Token / Token-2022 (opakowany SOL) przez seed. Brak efektu, jeśli odpowiedni program nie jest załadowany — wywołaj najpierw `SetDefaultPrograms`, jeśli chcesz mieć oba.

## Limity zasobów

### SetLamports

```go
func (s *LiteSVM) SetLamports(lamports uint64) error
```

Ustaw domyślne saldo lamport wewnętrznego konta puli airdrop.

```go
if err := svm.SetLamports(1 << 40); err != nil { // ~1.1 trillion lamports (~1,100 SOL)
    t.Fatal(err)
}
```

### SetLogBytesLimit

```go
func (s *LiteSVM) SetLogBytesLimit(limit int) error
```

Ogranicz łączną liczbę bajtów logów przechwytywanych na transakcję. Przekaż wartość ujemną, aby usunąć limit.

```go
if err := svm.SetLogBytesLimit(10_000); err != nil { // 10 KB cap
    t.Fatal(err)
}
if err := svm.SetLogBytesLimit(-1); err != nil {     // unlimited
    t.Fatal(err)
}
```

### SetTransactionHistory

```go
func (s *LiteSVM) SetTransactionHistory(capacity int) error
```

Ustaw pojemność historii transakcji przechowywanej w pamięci. Przekaż `0`, aby wyłączyć deduplicję i zezwolić na ponowne odtwarzanie identycznych transakcji.

```go
if err := svm.SetTransactionHistory(100); err != nil { // cap at 100 entries
    t.Fatal(err)
}
if err := svm.SetTransactionHistory(0); err != nil {   // disable dedup entirely
    t.Fatal(err)
}
```

## Budżet obliczeniowy

```go
type ComputeBudget struct {
    // See litesvm-go/litesvm.go for the full field list.
    // usize fields are normalized to uint64; HeapSize stays uint32.
    ComputeUnitLimit uint64
    HeapSize         uint32
    // ...
}
```

### ComputeBudget

```go
func (s *LiteSVM) ComputeBudget() (ComputeBudget, bool, error)
```

Odczytaj bieżący budżet obliczeniowy. Druga zwracana wartość informuje, czy budżet został jawnie ustawiony; jeśli `false`, struktura zawiera domyślne wartości, które zostaną użyte.

```go
budget, set, err := svm.ComputeBudget()
if err != nil {
    t.Fatal(err)
}
if !set {
    budget.ComputeUnitLimit = 1_400_000
}
if err := svm.SetComputeBudget(budget); err != nil {
    t.Fatal(err)
}
```

### SetComputeBudget

```go
func (s *LiteSVM) SetComputeBudget(b ComputeBudget) error
```

Zainstaluj budżet obliczeniowy dla kolejnych transakcji.

## Zestawy funkcji

`FeatureSet` to nieprzezroczysty uchwyt — utwórz go, modyfikuj za pomocą `Activate` /
`Deactivate`, a następnie zainstaluj przy użyciu `SetFeatureSet`. Zamknij uchwyty, które tworzysz.

```go
// Start with all features off, then activate what you care about.
fs, err := litesvm.NewFeatureSet()
if err != nil {
    t.Fatal(err)
}
defer fs.Close()
if err := fs.Activate(featureID, 0); err != nil {
    t.Fatal(err)
}

// Or start from "everything enabled" and flip specific features off.
fs2, err := litesvm.NewFeatureSetAllEnabled()
if err != nil {
    t.Fatal(err)
}
defer fs2.Close()
if err := fs2.Deactivate(featureID); err != nil {
    t.Fatal(err)
}

if err := svm.SetFeatureSet(fs); err != nil {
    t.Fatal(err)
}
```

| Metoda                                                   | Opis                       |
| -------------------------------------------------------- | --------------------------------- |
| `litesvm.NewFeatureSet() (*FeatureSet, error)`           | Pusty zestaw (wszystkie funkcje nieaktywne) |
| `litesvm.NewFeatureSetAllEnabled() (*FeatureSet, error)` | Wszystkie funkcje aktywne               |
| `fs.Activate(featureID, slot) error`                     | Oznacz funkcję jako aktywną w slot       |
| `fs.Deactivate(featureID) error`                         | Oznacz funkcję jako nieaktywną             |
| `fs.IsActive(featureID) bool`                            | Sprawdzenie aktywności                      |
| `fs.ActivatedSlot(featureID) (uint64, bool)`             | slot, w którym funkcja została aktywowana   |
| `fs.ActiveCount() int`                                   | Liczba aktywnych funkcji              |
| `fs.InactiveCount() int`                                 | Liczba nieaktywnych funkcji            |
| `fs.ActiveFeatures() []solana.PublicKey`                 | Lista aktywnych identyfikatorów funkcji           |
| `fs.InactiveFeatures() []solana.PublicKey`               | Lista nieaktywnych identyfikatorów funkcji         |
| `fs.Close()`                                             | Zwolnij uchwyt                |
| `svm.SetFeatureSet(*FeatureSet) error`                   | Zainstaluj na SVM                |

<Callout type="info">
  Użyj bramkowania funkcji, aby przetestować zachowanie programów w konkretnej wersji Solana
  — aktywuj funkcje dostarczone wraz z docelową wersją, a następnie
  dezaktywuj te, które pojawiły się później.
</Callout>
