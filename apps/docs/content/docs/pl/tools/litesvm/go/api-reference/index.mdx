## Skrócony przewodnik

### Konfiguracja uchwytu

```go
import (
    litesvm "github.com/LiteSVM/litesvm-go"
    solana "github.com/gagliardetto/solana-go"
)

svm, err := litesvm.New()
if err != nil {
    // handle error
}
defer svm.Close()
```

### Zarządzanie kontami

| Metoda                                                                       | Opis                                          |
| ---------------------------------------------------------------------------- | ---------------------------------------------------- |
| `Airdrop(pubkey, lamports) error`                                            | Zasilenie konta środkami                                      |
| `Balance(pubkey) (uint64, bool, error)`                                      | Saldo SOL; bool informuje, czy konto istnieje |
| `GetAccount(pubkey) *Account`                                                | Pobierz uchwyt konta (nil jeśli brak)          |
| `SetAccount(pubkey, *Account) error`                                         | Bezpośrednie zapisanie stanu konta                         |
| `MinimumBalanceForRentExemption(dataLen int) (uint64, error)`                | Oblicz minimalną kwotę zwalniającą z rent                          |
| `NewAccount(lamports, data, owner, executable, rentEpoch) (*Account, error)` | Utwórz uchwyt Account na potrzeby SetAccount               |

### Zarządzanie programami

| Metoda                                                   | Opis                             |
| -------------------------------------------------------- | --------------------------------------- |
| `AddProgram(programID, bytes) error`                     | Załaduj program z bajtów                 |
| `AddProgramFromFile(programID, path) error`              | Załaduj program z pliku `.so`            |
| `AddProgramWithLoader(programID, bytes, loaderID) error` | Załaduj przy użyciu określonego loadera (zaawansowane) |

### Transakcje

| Metoda                                                                        | Opis                                                                     |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| `SendLegacyTransaction(txBytes) (*TxOutcome, error)`                          | Wykonaj transakcję legacy                                                    |
| `SendVersionedTransaction(txBytes) (*TxOutcome, error)`                       | Wykonaj transakcję v0+                                                       |
| `SimulateLegacyTransaction(txBytes) (*TxOutcome, error)`                      | Symuluj bez wprowadzania zmian stanu                                                  |
| `SimulateVersionedTransaction(txBytes) (*TxOutcome, error)`                   | Symuluj v0+ bez wprowadzania zmian stanu                                              |
| `LatestBlockhash() (solana.Hash, error)`                                      | Bieżący blockhash                                                               |
| `ExpireBlockhash() error`                                                     | Przejdź do nowego blockhasha                                                      |
| `GetTransaction(signature) *TxOutcome`                                        | Wyszukaj transakcję w historii (nil jeśli brak)                                  |
| `litesvm.BuildTransferTx(payerSeed, to, lamports, blockhash) ([]byte, error)` | Pomocnik testowy budujący podpisaną transakcję legacy przelewu bez importowania `solana-go` |

### Konfiguracja

| Metoda                                         | Opis                                             |
| ---------------------------------------------- | ------------------------------------------------------- |
| `SetSigverify(bool) error`                     | Włącz / wyłącz weryfikację podpisów                 |
| `Sigverify() (bool, error)`                    | Odczytaj bieżące ustawienie                                |
| `SetBlockhashCheck(bool) error`                | Włącz / wyłącz walidację blockhasha                   |
| `SetTransactionHistory(int) error`             | Pojemność historii transakcji w pamięci (0 wyłącza)           |
| `SetLogBytesLimit(int) error`                  | Limit bajtów logów na transakcję (ujemna = bez limitu)              |
| `SetLamports(uint64) error`                    | Domyślna liczba lamportów dla nowych kont puli airdrop          |
| `SetSysvars() error`                           | Zresetuj sysvary do wartości domyślnych                               |
| `SetBuiltins() error`                          | Przeładuj wbudowane programy                                |
| `SetDefaultPrograms() error`                   | Przeładuj SPL Token, Memo itp.                            |
| `SetPrecompiles() error`                       | Włącz prekompilacje ed25519 / secp256k1                  |
| `WithNativeMints() error`                      | seed mintu zapakowanego SOL                                   |
| `SetFeatureSet(*FeatureSet) error`             | Zainstaluj zestaw flag funkcji                              |
| `SetComputeBudget(ComputeBudget) error`        | Zastosuj budżet obliczeniowy                                  |
| `ComputeBudget() (ComputeBudget, bool, error)` | Odczytaj bieżący budżet (bool informuje o "jawnym ustawieniu") |

### Czas i sysvary

| Metoda                                       | Opis                          |
| -------------------------------------------- | ------------------------------------ |
| `WarpToSlot(slot uint64) error`              | Przeskocz do określonego slot              |
| `Clock() (Clock, error)`                     | Odczytaj sysvar Clock                |
| `SetClock(Clock) error`                      | Nadpisz sysvar Clock           |
| `Rent() (Rent, error)`                       | Odczytaj sysvar Rent                 |
| `SetRent(Rent) error`                        | Nadpisz sysvar Rent            |
| `EpochSchedule() (EpochSchedule, error)`     | Odczytaj sysvar EpochSchedule        |
| `SetEpochSchedule(EpochSchedule) error`      | Nadpisz sysvar EpochSchedule   |
| `EpochRewards() (EpochRewards, error)`       | Odczytaj sysvar EpochRewards         |
| `SetEpochRewards(EpochRewards) error`        | Nadpisz sysvar EpochRewards    |
| `LastRestartSlot() (uint64, error)`          | Odczytaj last-restart-slot               |
| `SetLastRestartSlot(uint64) error`           | Ustaw last-restart-slot                |
| `SlotHashes() ([]SlotHash, error)`           | Odczytaj sysvar SlotHashes           |
| `SetSlotHashes([]SlotHash) error`            | Nadpisz sysvar SlotHashes      |
| `SlotHistory() (*SlotHistory, error)`        | Odczytaj sysvar SlotHistory (uchwyt) |
| `SetSlotHistory(*SlotHistory) error`         | Nadpisz sysvar SlotHistory     |
| `StakeHistory() ([]StakeHistoryItem, error)` | Odczytaj sysvar StakeHistory         |
| `SetStakeHistory([]StakeHistoryItem) error`  | Nadpisz sysvar StakeHistory    |

### Narzędzia pomocnicze
