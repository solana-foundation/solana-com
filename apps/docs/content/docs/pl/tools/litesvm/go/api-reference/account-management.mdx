Metody finansowania, odczytu i zapisu kont.

## Airdrop

```go
func (s *LiteSVM) Airdrop(pubkey solana.PublicKey, lamports uint64) error
```

Zasilenie konta w lamport. Zaimplementowane jako rzeczywisty transfer przez System Program
z wewnętrznego fauceta, dlatego odbiorca musi być w stanie przechowywać wynikowe
saldo.

```go
priv, err := solana.NewRandomPrivateKey()
if err != nil {
    t.Fatal(err)
}
payer := priv.PublicKey()

// Airdrop 5 SOL
if err := svm.Airdrop(payer, 5_000_000_000); err != nil {
    t.Fatal(err)
}
```

## Balance

```go
func (s *LiteSVM) Balance(pubkey solana.PublicKey) (uint64, bool, error)
```

Zwraca saldo SOL konta. Druga wartość wynosi `false`, gdy konto
nie istnieje – co różni się od sytuacji "konto istnieje z zerową liczbą lamport".

```go
lamports, ok, err := svm.Balance(payer)
if err != nil {
    t.Fatal(err)
}
if !ok {
    t.Log("account does not exist")
} else {
    t.Logf("balance: %d lamports (%.3f SOL)", lamports, float64(lamports)/1e9)
}
```

## GetAccount

```go
func (s *LiteSVM) GetAccount(pubkey solana.PublicKey) *Account
```

Pobiera nieprzezroczysty uchwyt konta lub `nil`, jeśli konto nie istnieje.
Zawsze wywołuj `Close` na uchwycie (lub polegaj na finalizatorze).

```go
acct := svm.GetAccount(payer)
if acct == nil {
    t.Fatal("account missing")
}
defer acct.Close()

_ = acct.Lamports()    // uint64
_ = acct.Owner()       // solana.PublicKey
_ = acct.Executable()  // bool
_ = acct.RentEpoch()   // uint64
_ = acct.Data()        // []byte (copy)
```

### Metody konta

| Metoda         | Zwraca            | Opis                        |
| -------------- | ------------------ | ---------------------------------- |
| `Lamports()`   | `uint64`           | Saldo SOL                        |
| `Owner()`      | `solana.PublicKey` | Program właściciela                     |
| `Executable()` | `bool`             | Czy konto jest wykonywalne  |
| `RentEpoch()`  | `uint64`           | epoch rent                         |
| `Data()`       | `[]byte`           | Kopia danych konta           |
| `Close()`      | -                  | Zwolnienie bazowego uchwytu Rust |

## NewAccount

```go
func NewAccount(lamports uint64, data []byte, owner solana.PublicKey, executable bool, rentEpoch uint64) (*Account, error)
```

Tworzy wartość `Account` do przekazania do `SetAccount`. Wywołujący nadal jest właścicielem
zwróconego uchwytu i musi wywołać na nim `Close`.

```go
payload := []byte{1, 2, 3, 4}
rent, err := svm.MinimumBalanceForRentExemption(len(payload))
if err != nil {
    t.Fatal(err)
}

acct, err := litesvm.NewAccount(rent, payload, ownerProgramID, false, 0)
if err != nil {
    t.Fatal(err)
}
defer acct.Close()
```

## SetAccount

```go
func (s *LiteSVM) SetAccount(pubkey solana.PublicKey, acct *Account) error
```

Zapisuje kopię `acct` pod kluczem `pubkey`. SVM przechowuje własną kopię; wywołujący nadal
jest właścicielem `acct` i musi wywołać na nim `Close`.

```go
if err := svm.SetAccount(targetAddr, acct); err != nil {
    t.Fatal(err)
}
```

<Callout type="info">
  `SetAccount` jest znacznie szybsze niż wykonywanie transakcji, gdy chcesz jedynie
  seed wiele kont na potrzeby testu. Upewnij się, że wartość lamport wynosi co najmniej
  minimum wymagane do zwolnienia z rent dla danego rozmiaru danych.
</Callout>

## MinimumBalanceForRentExemption

```go
func (s *LiteSVM) MinimumBalanceForRentExemption(dataLen int) (uint64, error)
```

Oblicza liczbę lamport wymaganą, aby konto o podanej długości danych było
zwolnione z rent.

```go
for _, size := range []int{0, 100, 1024} {
    min, err := svm.MinimumBalanceForRentExemption(size)
    if err != nil {
        t.Fatal(err)
    }
    t.Logf("%4d bytes -> %d lamports", size, min)
}
```

## Zarządzanie programami

### AddProgram

```go
func (s *LiteSVM) AddProgram(programID solana.PublicKey, bytes []byte) error
```

Ładuje program SBF z bajtów w pamięci.

```go
bytes, err := os.ReadFile("./target/deploy/my_program.so")
if err != nil {
    t.Fatal(err)
}
if err := svm.AddProgram(programID, bytes); err != nil {
    t.Fatal(err)
}
```

### AddProgramFromFile

```go
func (s *LiteSVM) AddProgramFromFile(programID solana.PublicKey, path string) error
```

Ładuje program SBF ze ścieżki pliku `.so`.

```go
if err := svm.AddProgramFromFile(programID, "./target/deploy/my_program.so"); err != nil {
    t.Fatal(err)
}
```

### AddProgramWithLoader

```go
func (s *LiteSVM) AddProgramWithLoader(programID solana.PublicKey, bytes []byte, loaderID solana.PublicKey) error
```

Ładuje program SBF przy użyciu określonego loadera. Przydatne podczas testowania z
niedomyślną wersją loadera BPF.

## Wsadowa konfiguracja kont

W przypadku testów wymagających wielu kont z seed, użyj pętli po `SetAccount`:

```go
const N = 10
for i := 0; i < N; i++ {
    pk := solana.NewWallet().PublicKey()
    data := []byte{byte(i)}
    rent, err := svm.MinimumBalanceForRentExemption(len(data))
    if err != nil {
        t.Fatal(err)
    }

    acct, err := litesvm.NewAccount(rent, data, owner, false, 0)
    if err != nil {
        t.Fatal(err)
    }
    if err := svm.SetAccount(pk, acct); err != nil {
        acct.Close()
        t.Fatal(err)
    }
    acct.Close()
}
```

<Callout type="info">
  Zawsze wywołuj `Close` na `*Account` zwróconym przez `NewAccount`, gdy SVM zapisał już
  swoją kopię poprzez `SetAccount` – SVM nie przejmuje własności uchwytu.
</Callout>
