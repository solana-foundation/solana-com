**Private Channels to warstwa enterprise dla internetowych rynków kapitałowych na
Solanie.** Zapewnia konfigurowalną warstwę aplikacji umożliwiającą prywatne, natychmiastowe transfery bez opłat
wewnątrz kanałów płatniczych: użytkownicy deponują tokeny SPL do programu escrow on-chain,
dokonują transakcji off-chain przez bramkę i rozliczają się z powrotem na Mainnecie
za pomocą dowodu Sparse Merkle Tree, dając deweloperom aplikacji natychmiastowe, bezpłatne, prywatne
transfery bez opuszczania ekosystemu Solany.

- **[Strona produktu](https://launch.solana.com/products/private-channels)**

### Dlaczego Private Channels?

- **Natychmiastowe transfery**: przepustowość off-chain przekraczająca natywne TPS Solany;
  transfery potwierdzają się w momencie przetworzenia przez sekwencer, a nie po potwierdzeniu bloku
- **Zero opłat za transfer**: brak kosztów gazu przy indywidualnych transferach kanałowych; użytkownicy
  płacą wyłącznie za depozyty i wypłaty on-chain
- **Prywatność**: transfery między uczestnikami kanału nie są rejestrowane na Solana
  Mainnecie
- **Dostęp z uprawnieniami**: RBAC z uwierzytelnianiem JWT pozwala kontrolować, kto może
  wysyłać i odbierać
- **Rozliczenie na Mainnecie**: środki są zawsze możliwe do zrealizowania na Solanie za pomocą dowodu
  wykluczenia Sparse Merkle Tree, który program escrow egzekwuje on-chain

Zobacz **[Przegląd](/docs/tools/private-channels/overview)**, aby zapoznać się z pełną
architekturą, diagramem przepływu danych i modelem bezpieczeństwa.

## Szybki Start

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n, // 1 USDC
  recipient: null
});
// send via your preferred Solana client
```

Klienty TypeScript są generowane z IDL; zobacz Instalację. W przypadku mintów Token-2022
przekaż jawnie `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS`, ponieważ
domyślnie używany jest standardowy SPL Token Program.

## Przypadki Użycia

- **Instytucjonalne płatności dwustronne** - banki i instytucje potrzebujące
  dużych wolumenów prywatnych przepływów USDC bez rejestrowania każdego transferu on-chain
- **Transfery w warstwie aplikacji o wysokiej częstotliwości** - aplikacje do gier, lojalnościowe i konsumenckie
  wymagające transferów w czasie poniżej sekundy, bez opłat i w skali przekraczającej natywne TPS Solany
- **Przepływy tokenów z zachowaniem prywatności** - każdy przypadek użycia, w którym prywatność
  kontrahenta i kwoty jest wymaganiem produktowym

**[Kiedy zamiast tego używać natywnych transferów SPL](/docs/tools/private-channels/concepts/channels#when-to-use-private-channels)**
