**Private Channels to warstwa aplikacyjna dla przedsiębiorstw obsługująca internetowe rynki kapitałowe na
Solanie.** Zapewnia konfigurowalną warstwę aplikacyjną dla prywatnych, natychmiastowych transferów bez opłat
wewnątrz kanałów płatniczych: użytkownicy deponują tokeny SPL do programu escrow on-chain,
dokonują transakcji off-chain przez bramę i rozliczają się z powrotem do Mainnet
za pomocą dowodu Sparse Merkle Tree, dając deweloperom aplikacji natychmiastowe, bezpłatne, prywatne
transfery bez opuszczania ekosystemu Solany.

### Dlaczego Private Channels?

- **Natychmiastowe transfery**: przepustowość off-chain wykraczająca poza natywny TPS Solany;
  transfery są potwierdzane w momencie przetworzenia przez sekwencer, a nie po potwierdzeniu bloku
- **Zero opłat za transfer**: brak kosztów gazu przy indywidualnych transferach w kanale; użytkownicy
  płacą wyłącznie za depozyty i wypłaty on-chain
- **Prywatność**: transfery między uczestnikami kanału nie są rejestrowane w Solana
  Mainnet
- **Kontrola dostępu**: RBAC z uwierzytelnianiem JWT pozwala kontrolować, kto może
  wysyłać i odbierać
- **Rozliczenie na Mainnet**: środki są zawsze wymienialne na Solanie za pomocą dowodu wykluczenia
  Sparse Merkle Tree, który program escrow egzekwuje on-chain

Zobacz **[Przegląd](/docs/tools/private-channels/overview)**, aby poznać pełną
architekturę, diagram przepływu danych i model bezpieczeństwa.

## Szybki Start

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n, // 1 USDC
  recipient: null
});
// send via your preferred Solana client
```

Klienci TypeScript są generowani z IDL; zobacz Instalację. W przypadku mintów Token-2022
przekaż `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS` jawnie, ponieważ domyślnie
używany jest standardowy SPL Token Program.

## Przypadki Użycia

- **Instytucjonalne płatności dwustronne** – banki i instytucje potrzebujące
  dużych, prywatnych przepływów USDC bez widoczności każdego transferu on-chain
- **Wysokoczęstotliwościowe transfery na warstwie aplikacyjnej** – gry, programy lojalnościowe i aplikacje konsumenckie
  wymagające transferów poniżej sekundy, bez opłat i w skali przekraczającej natywny TPS Solany
- **Prywatne przepływy tokenów** – każdy przypadek użycia, w którym prywatność kontrahenta i
  kwoty jest wymaganiem produktowym

**[Kiedy zamiast tego używać natywnych transferów SPL](/docs/tools/private-channels/concepts/channels#when-to-use-private-channels)**
