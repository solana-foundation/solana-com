## Wymagania wstępne

- Rust 1.91+
- Solana CLI 3.1.13 (Agave):
  `sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.13/install)"`
- Node.js 24.7.0+
- pnpm 10.15.1+: `npm install -g pnpm@10.15.1`

## Sklonuj repozytorium

```bash
git clone https://github.com/solana-foundation/solana-private-channels.git
cd solana-private-channels
```

## Generowanie klientów TypeScript

Klienci TypeScript **nie** są publikowani w npm. Muszą zostać wygenerowani z
IDL przy użyciu Codama.

```bash
# Escrow program client
cd private-channel-escrow-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..

# Withdraw program client
cd private-channel-withdraw-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..
```

Wygenerowani klienci trafiają do:

- `private-channel-escrow-program/clients/typescript/src/generated/`
- `private-channel-withdraw-program/clients/typescript/src/generated/`

Importuj z tych lokalnych ścieżek w swojej aplikacji; nie istnieje żaden
paket `@private-channels/client` w npm. Przykłady kodu w tej sekcji używają
ścieżki względnej (`../private-channel-escrow-program/...`), która zakłada, że Twój kod
znajduje się obok sklonowanego repozytorium; dostosuj ją do miejsca, z którego faktycznie
importujesz w swoim projekcie.
