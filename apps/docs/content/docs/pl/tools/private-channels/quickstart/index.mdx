Ten przewodnik szybkiego startu przeprowadza przez pełny przepływ Private Channels w sieci devnet Solany:
skonfiguruj środowisko klienta, wpłać tokeny SPL do depozytu escrow, wyślij
transfer off-chain między dwoma portfelami i wypłać środki z powrotem do swojego portfela
Solana.

Po zakończeniu zrozumiesz pełny cykl wpłata -> transfer off-chain ->
wypłata i będziesz dysponować działającym kodem TypeScript dla każdego kroku.

<Callout type="info">
  Ten przewodnik szybkiego startu zakłada, że instancja Private Channels jest już wdrożona i
  działa w sieci devnet z Twoim mintem na liście dozwolonych. Jeśli najpierw musisz ją wdrożyć,
  [przewodnik dla operatorów](/docs/tools/private-channels/operators) opisuje
  pełną konfigurację; wstępna kompilacja Docker zajmuje od 30 do 60 minut.
</Callout>

## Kroki

1. **[Instalacja](/docs/tools/private-channels/quickstart/installation)** -
   sklonuj repozytorium i wygeneruj klientów TypeScript (5 minut)
2. **[Wpłata tokenów](/docs/tools/private-channels/quickstart/deposit)** -
   wpłać tokeny SPL do depozytu escrow; poczekaj ~15 sekund, aż indekser
   zakredytuje saldo Twojego kanału
3. **[Wyślij transfer](/docs/tools/private-channels/quickstart/transfer)** -
   wyślij transfer off-chain przez bramę; potwierdzenie zajmuje poniżej sekundy
   i nigdy nie dotyka sieci Mainnet
4. **[Wypłata środków](/docs/tools/private-channels/quickstart/withdraw)** - spał
   saldo po stronie kanału; operator rozlicza środki na Twój portfel Mainnet
   w ciągu kilku sekund
