---
title: RemoveOperator
description: Odbiera uprawnienia operatora poprzez zamknięcie jego Operator PDA
---

Odbiera uprawnienia operatora poprzez zamknięcie jego `Operator` PDA. Odwołany portfel nie może już wywoływać `ReleaseFunds` ani `ResetSmtRoot`.

## Konta

| Konto                          | Zapisywalne | Podpisujący | Opis                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | Płatnik opłat                                 |
| `admin`                          |          | ✓      | Administrator instancji                            |
| `instance`                       |          |        | Instancja PDA                              |
| `operator`                       |          |        | Portfel operatora do odwołania                 |
| `operator_pda`                   | ✓        |        | Operator PDA (zamykany przez tę instrukcję) |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | PDA autorytetu zdarzeń                       |
| `private_channel_escrow_program` |          |        | Program Escrow                            |

Ta instrukcja nie przyjmuje żadnych parametrów.

## Ważne uwagi

- Zamyka `operator_pda`; odwołany portfel nie może już wywoływać
  `ReleaseFunds` ani `ResetSmtRoot`
- Wszelkie będące w toku transakcje operatora zakończą się błędem `InvalidOperatorPda` po
  tym wywołaniu
- Emituje zdarzenie za pośrednictwem CPI `EmitEvent`
