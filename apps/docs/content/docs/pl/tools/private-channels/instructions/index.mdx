Ta sekcja stanowi dokumentację instrukcji on-chain. Większość deweloperów wywołuje te
instrukcje za pośrednictwem wygenerowanych klientów TypeScript; ta sekcja jest potrzebna tylko wtedy, gdy
budujesz narzędzia operatorskie, piszesz niestandardowe integracje lub debugujesz
błędy na poziomie instrukcji.

**Program Escrow** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) - zarządza
depozytami, provisioningiem operatorów oraz rozliczeniami w sieci Mainnet:

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) -
  inicjalizuje PDA instancji escrow
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) - dodaje
  mint tokenu SPL do listy dozwolonych
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) - usuwa
  mint z listy dozwolonych
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) -
  dodaje operatora
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) -
  odwołuje operatora
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) -
  przekazuje uprawnienia administratora
- [Deposit](/docs/tools/private-channels/instructions/deposit) - przenosi tokeny SPL
  do escrow
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) -
  operator rozlicza wypłatę do sieci Mainnet
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) -
  operator rotuje korzeń Sparse Merkle Tree

**Program Withdraw** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) - działa w
sieci prywatnych kanałów:

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) -
  spala saldo po stronie kanału w celu zainicjowania wypłaty

## Kody błędów

**Program Escrow - `PrivateChannelEscrowProgramError`**

| Kod                                         | Komunikat                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | Podano nieprawidłowy autorytet zdarzenia                 |
| `InvalidAta`                                 | Podano nieprawidłowy ATA                             |
| `InvalidMint`                                | Podano nieprawidłowy mint                            |
| `InvalidInstanceId`                          | ID instancji jest nieprawidłowy lub nie spełnia wymaganych reguł    |
| `InvalidInstance`                            | Podano nieprawidłową instancję                        |
| `InvalidAdmin`                               | Podano nieprawidłowego administratora                           |
| `TransferHookNotAllowed`                     | Rozszerzenie transfer hook jest niedozwolone              |
| `InvalidOperatorPda`                         | Podano nieprawidłowy PDA operatora                    |
| `InvalidTokenAccount`                        | Podano nieprawidłowy token account                   |
| `InvalidEscrowBalance`                       | Nieprawidłowe saldo escrow                           |
| `InvalidAllowedMint`                         | Nieprawidłowy dozwolony mint                             |
| `InvalidSmtProof`                            | Podano nieprawidłowy dowód SMT                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | Nieprawidłowy nonce transakcji dla bieżącego indeksu drzewa |
| `UnexpectedTreeIndex`                        | Nieoczekiwany bieżący indeks drzewa podczas resetowania korzenia SMT |

**Program Withdraw - `PrivateChannelWithdrawProgramError`**

| Kod          | Komunikat                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | Podano nieprawidłowy mint                       |
| `ZeroAmount`  | Kwota wypłaty musi być większa niż zero |
