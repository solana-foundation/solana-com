  Zezwala na mint tokenu SPL w instancji i tworzy escrow ATA dla tego mintu
---

Zezwala na mint tokenu SPL w instancji i tworzy associated
token account escrow dla tego mintu. Depozyty dla tego mintu stają się możliwe po tym
wywołaniu.

## Konta

| Konto                          | Zapisywalne | Podpisujący | Opis                                                                   |
| -------------------------------- | -------- | ------ | ----------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Płatnik opłat                                                                     |
| `admin`                          |          | ✓      | Administrator instancji                                                                |
| `instance`                       |          |        | PDA instancji                                                                  |
| `mint`                           |          |        | Mint tokenu SPL do zezwolenia                                                       |
| `allowed_mint`                   | ✓        |        | PDA AllowedMint (tworzony przez tę instrukcję)                                 |
| `instance_ata`                   | ✓        |        | Associated token account escrow dla tego mintu (tworzony przez tę instrukcję) |
| `system_program`                 |          |        | System Program                                                                |
| `token_program`                  |          |        | SPL Token Program                                                             |
| `associated_token_program`       |          |        | Associated Token Program                                                      |
| `event_authority`                |          |        | PDA autorytetu zdarzeń                                                           |
| `private_channel_escrow_program` |          |        | Program Escrow                                                                |

## Parametry

| Parametr | Typ | Opis                                                                                   |
| --------- | ---- | --------------------------------------------------------------------------------------------- |
| `bump`    | `u8` | Bump seed dla PDA `allowed_mint`. Opcjonalny: klient `Async` wywodzi go automatycznie, jeśli zostanie pominięty |

> IDL zawiera argument `discriminator: u8` (wartość `1`), który jest automatycznie ustawiany
> przez wygenerowanego klienta i nie powinien być przekazywany ręcznie.

## Ważne uwagi

- Używaj `getAllowMintInstructionAsync`; automatycznie wywodzi `bump`, `allowed_mint`
  oraz `instance_ata`, gdy nie zostały podane. Przekaż własny `bump` tylko wtedy, gdy
  już go wyliczyłeś za pomocą
  `Pubkey::find_program_address(&[b"allowed_mint", instance_pda, mint], &PROGRAM_ID)`
- Tworzy również `instance_ata`, ATA escrow dla tego mintu
- Minty z rozszerzeniem transfer hook są jawnie blokowane: próba zezwolenia na taki mint
  zgłasza błąd `TransferHookNotAllowed`
- Emituje zdarzenie poprzez CPI `EmitEvent`
