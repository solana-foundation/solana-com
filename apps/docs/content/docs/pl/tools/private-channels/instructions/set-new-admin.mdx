Przenosi prawa administratora do nowego portfela.

## Konta

| Konto                          | Zapisywalne | Podpisujący | Opis                        |
| -------------------------------- | -------- | ------ | ---------------------------------- |
| `payer`                          | ✓        | ✓      | Płatnik opłat                          |
| `current_admin`                  |          | ✓      | Obecny administrator (musi podpisać)          |
| `instance`                       | ✓        |        | PDA instancji (pole administratora zaktualizowane) |
| `new_admin`                      |          | ✓      | Portfel, który otrzyma prawa administratora     |
| `event_authority`                |          |        | PDA autorytetu zdarzeń                |
| `private_channel_escrow_program` |          |        | Program Escrow                     |

Ta instrukcja nie przyjmuje żadnych parametrów.

## Ważne uwagi

- **Nieodwracalne w jednym kroku**: obecny administrator nie może odzyskać roli
  bez ponownego wywołania `SetNewAdmin` przez nowego administratora
- Zweryfikuj adres docelowy przed wywołaniem; nie ma możliwości cofnięcia
- Emituje zdarzenie przez CPI `EmitEvent`
