---
title: AddOperator
description: Tworzy nowego operatora poprzez utworzenie jego Operator PDA
---

Tworzy nowego operatora poprzez utworzenie jego `Operator` PDA. Po tym wywołaniu
portfel `operator` może wywoływać `ReleaseFunds` i `ResetSmtRoot`.

## Konta

| Konto                          | Zapisywalne | Podpisujący | Opis                                                         |
| -------------------------------- | -------- | ------ | ------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Płatnik opłat                                                           |
| `admin`                          |          | ✓      | Administrator instancji                                                      |
| `instance`                       |          |        | Instancja PDA                                                        |
| `operator`                       |          |        | Portfel operatora do skonfigurowania                                        |
| `operator_pda`                   | ✓        |        | Operator PDA – automatycznie wyprowadzany z `["operator", instance, operator]` |
| `system_program`                 |          |        | System Program                                                      |
| `event_authority`                |          |        | PDA autorytetu zdarzeń                                                 |
| `private_channel_escrow_program` |          |        | Program Escrow                                                      |

## Parametry

| Parametr | Typ | Opis                                                                               |
| --------- | ---- | ----------------------------------------------------------------------------------------- |
| `bump`    | `u8` | Bump seed dla `operator_pda`. Opcjonalny: klient `Async` wyprowadza go automatycznie, jeśli zostanie pominięty |

> IDL zawiera argument `discriminator: u8` (wartość `3`), który jest ustawiany automatycznie
> przez wygenerowanego klienta i nie powinien być przekazywany ręcznie.

## Ważne uwagi

- Używaj `getAddOperatorInstructionAsync`; automatycznie wyprowadza `bump` i
  `operator_pda`, gdy nie zostały podane. Istnieje również synchroniczny
  wariant `getAddOperatorInstruction`, jeśli `bump` zostało już wcześniej obliczone
- Po tym wywołaniu portfel `operator` może wywoływać `ReleaseFunds` i
  `ResetSmtRoot`
- Emituje zdarzenie za pośrednictwem `EmitEvent` CPI
