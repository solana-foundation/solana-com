Usuwa wcześniej dozwolony mint z instancji, uniemożliwiając nowe depozyty dla
tego minta. Istniejące depozyty pozostają niezmienione.

## Konta

| Konto                          | Zapisywalne | Podpisujący | Opis                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | Płatnik opłat                                    |
| `admin`                          |          | ✓      | Administrator instancji                               |
| `instance`                       |          |        | PDA instancji                                 |
| `mint`                           |          |        | Mint tokena SPL do zablokowania                      |
| `allowed_mint`                   | ✓        |        | PDA AllowedMint (zamknięty przez tę instrukcję) |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | PDA autorytetu zdarzeń                          |
| `private_channel_escrow_program` |          |        | Program Escrow                               |

Ta instrukcja nie przyjmuje żadnych parametrów.

## Ważne uwagi

- Zamyka PDA `allowed_mint`: nowe wywołania `Deposit` dla tego minta zakończą się
  błędem `InvalidAllowedMint`
- Istniejące salda kanałów dla tego minta pozostają niezmienione
- Emituje zdarzenie za pośrednictwem CPI `EmitEvent`
