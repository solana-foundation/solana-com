Usuwa wcześniej dozwolony mint z instancji, uniemożliwiając nowe depozyty dla
tego mintu. Istniejące depozyty nie są naruszane.

## Konta

| Konto                          | Zapisywalne | Sygnatariusz | Opis                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | Płatnik opłat                                    |
| `admin`                          |          | ✓      | Administrator instancji                               |
| `instance`                       |          |        | PDA instancji                                 |
| `mint`                           |          |        | Mint tokenu SPL do zablokowania                      |
| `allowed_mint`                   | ✓        |        | PDA AllowedMint (zamykany przez tę instrukcję) |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | PDA autorytetu zdarzeń                          |
| `private_channel_escrow_program` |          |        | Program Escrow                               |

Ta instrukcja nie przyjmuje żadnych parametrów.

## Ważne uwagi

- Zamyka PDA `allowed_mint`: nowe wywołania `Deposit` dla tego mintu będą kończyć się niepowodzeniem
  z błędem `InvalidAllowedMint`
- Istniejące salda kanałów dla tego mintu nie są naruszane
- Emituje zdarzenie poprzez CPI `EmitEvent`
