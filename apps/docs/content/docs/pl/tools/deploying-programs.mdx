---
title: Wdrażanie programów
description: Najlepsze praktyki wdrażania programów w sieci Mainnet
---

Jeśli wdrażasz własny program Solana jako część swojej infrastruktury
płatniczej, należy wziąć pod uwagę dodatkowe kwestie.

## Przed wdrożeniem

- **Wersja Solana CLI:** Upewnij się, że używasz najnowszej wersji
  [Solana CLI](https://solana.com/docs/intro/installation).
- **Keypair programu:** Twój program będzie miał w sieci mainnet inny adres
  niż w devnecie (chyba że używasz ponownie tego samego keypair). Zaktualizuj
  wszystkie odwołania w konfiguracji aplikacji. Przechowuj keypair programu w
  bezpiecznym miejscu (pamiętaj, że uruchomienie `cargo clean` prawdopodobnie
  usunie keypair Twojego programu).
- **Zainicjuj konta:** Jeśli Twój program wymaga kont administratora, PDA lub
  innych kont stanu, upewnij się, że zostały one utworzone w sieci mainnet,
  zanim użytkownicy zaczną korzystać z Twojej aplikacji. To samo dotyczy
  wszystkich Associated Token Accounts (ATA), których potrzebuje Twój program.

## Proces wdrażania

- **Konta bufora:** Duże programy są wdrażane za pośrednictwem kont bufora.
  Polecenie `solana program deploy` robi to automatycznie, ale pamiętaj, że
  wdrożenie nie jest atomowe — w przypadku przerwania może być konieczne
  odzyskanie lub zamknięcie kont bufora.
- **Uprawnienia do aktualizacji (upgrade authority):** Utwórz
  [multisig](https://docs.squads.so/main/basics/what-is-a-multisig) i przypisz
  go jako
  [upgrade authority swojego programu Solana](https://docs.squads.so/main/navigating-your-squad/developers-assets/programs).
- **Rent:** Upewnij się, że portfel używany do wdrożenia ma wystarczającą ilość
  SOL, aby pokryć minimalne salda zwalniające z opłaty rent dla wszystkich kont
  programu.
- **Weryfikacja:** [Zweryfikuj](https://solana.com/docs/programs/verified-builds)
  swój program, aby upewnić się, że wykonywalny program wdrażany w sieci Solana
  odpowiada kodowi źródłowemu w Twoim repozytorium
