Skonfiguruj lokalne środowisko programistyczne Solana za pomocą automatycznego instalatora. Instaluje on Rust, Solana CLI, Anchor CLI, Surfpool CLI, Node.js oraz Yarn w systemie macOS, Linux lub Windows przez WSL.

<Callout type="info" title="Windows wymaga WSL">
  W Windows PowerShell uruchom `wsl --install`, w razie potrzeby uruchom ponownie system Windows, a następnie wykonaj poniższe polecenia instalacyjne w terminalu Ubuntu. Pełną konfigurację WSL znajdziesz w [podręczniku instalacji ręcznej](/docs/intro/installation/dependencies).
</Callout>

## Szybka instalacja

1. Uruchom instalator w terminalu macOS, Linux lub WSL:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
```

Przed uruchomieniem możesz
[przejrzeć kod źródłowy instalatora](https://github.com/solana-developers/solana-install/blob/main/install.sh).
Instalator wykrywa obsługiwane menedżery pakietów w systemie Linux i automatycznie instaluje wymagane zależności systemowe.

2. Uruchom ponownie terminal, aby nowe polecenia były dostępne w zmiennej `PATH`.

3. Sprawdź każde narzędzie:

```terminal
$ rustc --version
$ solana --version
$ anchor --version
$ surfpool --version
$ node --version
$ yarn --version
```

Pomyślna instalacja zwraca dane wyjściowe w następującej postaci (numery wersji zmieniają się wraz z wydawaniem nowych wersji narzędzi):

```txt title="Example output"
Installed Versions:
Rust: rustc x.y.z (...)
Solana CLI: solana-cli x.y.z (..., client:Agave)
Anchor CLI: anchor-cli x.y.z
Surfpool CLI: surfpool x.y.z
Node.js: vx.y.z
Yarn: x.y.z
```

<Callout type="warn" title="Instalator zakończył się błędem lub brakuje polecenia">
  Skorzystaj z [podręcznika instalacji ręcznej](/docs/intro/installation/dependencies),
  aby zainstalować każdą zależność osobno lub rozwiązać związane z nią problemy.
</Callout>
