Zainstaluj każdą zależność osobno, gdy potrzebujesz konkretnej wersji lub gdy
[szybka instalacja](/docs/intro/installation) nie zakończy się powodzeniem.
W przypadku nowego środowiska przechodź przez sekcje po kolei albo przejdź od razu do narzędzia,
które chcesz zainstalować lub którego problemy chcesz rozwiązać.

## Wymagania wstępne

<Accordions>
<Accordion title="Windows">

Aby rozwijać programy Solana na Windows, **musisz** użyć
[Windows Subsystem for Linux](https://learn.microsoft.com/en-us/windows/wsl/install)
(WSL). Po zainstalowaniu WSL wszystkie pozostałe zależności będą instalowane
przez terminal Linuksa.

Aby zainstalować WSL, uruchom poniższe polecenie w Windows PowerShell:

```terminal
$ wsl --install
```

Podczas instalacji zostaniesz poproszony o utworzenie domyślnego konta
użytkownika.

![Instalacja WSL](/assets/docs/intro/installation/wsl-install.png)

Domyślnie WSL instaluje Ubuntu. Możesz otworzyć terminal Linuksa, wyszukując
"Ubuntu" na pasku wyszukiwania.

![WSL Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-search.png)

Jeśli Twój terminal Ubuntu wygląda jak na poniższym obrazku, możesz napotkać
problem, w którym `ctrl + v` (skrót klawiszowy wklejania) nie działa w
terminalu.

![Terminal Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-terminal-1.png)

Jeśli napotkasz ten problem, otwórz Windows Terminal, wyszukując "Terminal" na
pasku wyszukiwania.

![Windows Terminal](/assets/docs/intro/installation/wsl-windows-terminal.png)

Następnie zamknij Windows Terminal i ponownie otwórz terminal Linuksa,
wyszukując ponownie Ubuntu. Terminal powinien teraz wyglądać jak na poniższym
obrazku, gdzie `ctrl + v` (skrót klawiszowy wklejania) działa.

![Terminal Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-terminal-2.png)

Jeśli korzystasz z VS Code,
[rozszerzenie WSL](https://code.visualstudio.com/docs/remote/wsl-tutorial)
umożliwia używanie WSL i VS Code razem.

![Konfiguracja WSL w VS Code](/assets/docs/intro/installation/wsl-vscode.png)

W pasku stanu VS Code zobaczysz następującą informację:

![WSL: Ubuntu](/assets/docs/intro/installation/wsl-vscode-ubuntu.png)

Gdy WSL jest już skonfigurowany, możesz przejść do:

- Szybkiej [instalacji](/docs/intro/installation) przy użyciu terminala Ubuntu
  (Linux)
- Instalacji [Rust](#install-rust), [Solana CLI](#install-solana-cli) oraz
  [Anchor CLI](#install-anchor-cli) osobno, zgodnie z poniższym opisem

</Accordion>
<Accordion title="Linux">

<Tabs items={[".deb", ".rpm"]}>
<Tab value=".deb" >
W dystrybucji Debian lub dystrybucji opartej na Debianie, takiej jak Ubuntu lub Mint:

1. Zaktualizuj listy pakietów, aby mieć pewność, że wszystkie pakiety są
   aktualne:

```terminal
$ sudo apt-get update
```

2. Zainstaluj następujące zależności:

```terminal
$ sudo apt-get install -y \
    build-essential \
    pkg-config \
    libudev-dev llvm libclang-dev \
    protobuf-compiler libssl-dev
```

<Callout>
Jeśli podczas instalacji `protobuf-compiler` pojawi się poniższy błąd, uruchom
`sudo apt-get update`, a następnie ponów polecenie instalacji.

```
Package protobuf-compiler is not available, but is referred to by another package.
This may mean that the package is missing, has been obsoleted, or
is only available from another source
```

</Callout>

  </Tab>

    <Tab value=".rpm" >
    W dystrybucji opartej na RPM, takiej jak Fedora lub Red Hat Enterprise Linux:

Zaktualizuj zainstalowane pakiety:

```terminal
$ sudo dnf upgrade --refresh
```

Zainstaluj zależności deweloperskie:

```terminal
$ sudo dnf group install c-development development-tools \
&& sudo dnf install pkg-config openssl-devel
```

### Instalacja Rust

Deweloperzy tworzą programy Solana w języku programowania
[Rust](https://www.rust-lang.org/).

1. Zainstaluj Rust za pomocą [rustup](https://www.rust-lang.org/tools/install),
   wpisując poniższe polecenie w terminalu:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
```

Po pomyślnej instalacji zobaczysz następujący komunikat:

<Accordions>
<Accordion title="Komunikat o pomyślnej instalacji Rust">

```
Rust is installed now. Great!

To get started you may need to restart your current shell.
This would reload your PATH environment variable to include
Cargo's bin directory ($HOME/.cargo/bin).

To configure your current shell, you need to source
the corresponding env file under $HOME/.cargo.

This is usually done by running one of the following (note the leading DOT):
. "$HOME/.cargo/env"            # For sh/bash/zsh/ash/dash/pdksh
source "$HOME/.cargo/env.fish"  # For fish
```

</Accordion>
</Accordions>

2. Przeładuj zmienną środowiskową PATH, aby dodać katalog bin
   [Cargo](https://github.com/rust-lang/cargo):

```terminal
$ . "$HOME/.cargo/env"
```

3. Zweryfikuj, czy instalacja przebiegła pomyślnie.

```terminal
$ rustc --version
```

Polecenie wyświetla zainstalowaną wersję Rusta, na przykład:

```
rustc x.y.z (...)
```

</Step>

### Instalacja Solana CLI

Solana CLI udostępnia wszystkie narzędzia potrzebne do budowania i wdrażania
programów na Solanie.

1. Zainstaluj pakiet narzędzi Solana CLI, używając oficjalnego polecenia
   instalacyjnego:

```terminal
$ sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

<Callout>
  Możesz zastąpić `stable` konkretnym tagiem wydania Agave albo kanałem wydań `beta`
  lub `edge`.
</Callout>

2. Udostępnij Solana CLI w bieżącym terminalu.

Instalator aktualizuje konfigurację powłoki i wyświetla polecenie potrzebne
do zaktualizowania bieżącej sesji. Zazwyczaj jest to polecenie:

```terminal
$ export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"
```

Jeśli `solana` nadal jest niedostępne, uruchom terminal ponownie. Aby sprawdzić, który plik
konfiguracyjny powłoki został zaktualizowany przez instalator, sprawdź swoją bieżącą powłokę:

```terminal
$ echo $SHELL
```

- Jeśli wynik zawiera `/bash`, uruchom terminal ponownie lub wykonaj
  `source ~/.bashrc`.
- Jeśli wynik zawiera `/zsh`, uruchom terminal ponownie lub wykonaj `source ~/.zshrc`.

3. Sprawdź, czy instalacja zakończyła się powodzeniem:

```terminal
$ solana --version
```

Polecenie wyświetla zainstalowaną wersję Solana CLI, na przykład:

```
solana-cli x.y.z (..., client:Agave)
```

<Callout>

Wszystkie dostępne wersje znajdziesz w
[repozytorium Agave na GitHubie](https://github.com/anza-xyz/agave/releases). Agave to
klient validator od [Anza](https://www.anza.xyz/), dawniej znany jako
klient validator Solana Labs.

</Callout>

4. Aby później zaktualizować Solana CLI, uruchom:

```terminal
$ agave-install update
```

</Step>

### Instalacja Anchor CLI

[Anchor](https://www.anchor-lang.com/) to framework do tworzenia programów na
Solanie. Framework Anchor wykorzystuje makra Rust, aby uprościć proces pisania
programów na Solanę.

#### Wymagania wstępne

Node.js i menedżer pakietów JavaScript są wymagane tylko wtedy, gdy wybierzesz
szablon testów w TypeScript, taki jak Mocha lub Jest. Domyślny szablon testów LiteSVM
działa w Rust i nie wymaga narzędzi Node.js.

<Accordions>
<Accordion title="Instalacja Node">

1. Zainstaluj Node za pomocą
   [Node Version Manager (nvm)](https://github.com/nvm-sh/nvm), uruchamiając
   następujące polecenie:

```terminal
$ curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```

2. Uruchom terminal ponownie i sprawdź, czy polecenie `nvm` działa poprawnie:

```terminal
$ command -v nvm
```

3. Zainstaluj Node za pomocą `nvm`:

```terminal
$ nvm install --lts
```

4. Sprawdź, czy instalacja zakończyła się powodzeniem, weryfikując wersję Node:

```terminal
$ node --version
```

Polecenie wyświetla zainstalowaną wersję Node.js, na przykład:

```
vx.y.z
```

</Accordion>
<Accordion title="Instalacja Yarn">

1. Zainstaluj Yarn:

```terminal
$ npm install --global yarn
```

2. Sprawdź, czy instalacja zakończyła się powodzeniem, weryfikując wersję Yarn:

```terminal
$ yarn --version
```

Polecenie wyświetla zainstalowaną wersję Yarn, na przykład:

```
x.y.z
```

</Accordion>
</Accordions>

#### Instalacja

Możesz zainstalować Anchor CLI i narzędzia na dwa sposoby:

- Anchor Version Manager (AVM) — zalecana metoda instalacji
- Bez AVM — instalacja bezpośrednio z GitHub

<Tabs groupId="anchor" items={["AVM", "Without AVM"]}>
<Tab value="AVM">

Anchor Version Manager (AVM) umożliwia instalowanie i zarządzanie różnymi
wersjami Anchor na Twoim systemie oraz łatwą aktualizację wersji Anchor w
przyszłości. Aby zainstalować Anchor za pomocą AVM, wykonaj poniższe kroki:

1. Zainstaluj AVM za pomocą następującego polecenia:

```terminal
$ curl -sSfL https://raw.githubusercontent.com/otter-sec/anchor/master/avm/install | sh
```

2.  Potwierdź, że AVM został poprawnie zainstalowany:

```terminal
$ avm --version
```

3. Zainstaluj Anchor CLI używając AVM:

Aby zainstalować najnowszą wersję:

```terminal
$ avm install latest
$ avm use latest
```

Aby zainstalować konkretną wersję, podaj jej numer:

```terminal
$ avm install 1.1.2
$ avm use 1.1.2
```

<Callout type="warn">

Podczas instalacji Anchor CLI na Linuksie lub WSL możesz napotkać następujący błąd:

```
error: could not exec the linker cc = note: Permission denied (os error 13)
```

Jeśli widzisz ten komunikat o błędzie, wykonaj następujące kroki:

1. Zainstaluj zależności wymienione w sekcji
   [Linux](/docs/intro/installation/dependencies) na górze tej
   strony.
2. Ponów próbę instalacji Anchor CLI.

</Callout>

4. Zweryfikuj, czy instalacja zakończyła się sukcesem, sprawdzając wersję Anchor
   CLI:

```terminal
$ anchor --version
```

Polecenie wyświetla aktywną wersję Anchor CLI, na przykład:

```
anchor-cli 1.1.2
```

<Callout type="info">

Uruchom `avm use`, aby wybrać wersję Anchor CLI dla swojego systemu.

- Jeśli została zainstalowana najnowsza wersja, uruchom `avm use latest`.
- Jeśli została zainstalowana wersja `1.1.2`, uruchom `avm use 1.1.2`.

</Callout>

</Tab>

<Tab value="Without AVM">

1. Zainstaluj konkretną wersję Anchor CLI za pomocą następującego polecenia:

```terminal
$ cargo install --git https://github.com/solana-foundation/anchor --tag v1.1.2 anchor-cli --locked
```

2. Sprawdź, czy instalacja zakończyła się powodzeniem, weryfikując wersję Anchor CLI:

```terminal
$ anchor --version
```

Polecenie wyświetla zainstalowaną wersję Anchor CLI, na przykład:

```
anchor-cli 1.1.2
```

</Tab>

### Instalacja Surfpool CLI

[Surfpool](/docs/tools/surfpool) to narzędzie do lokalnego programowania i ulepszony
zamiennik `solana-test-validator`.

1. Zainstaluj Surfpool za pomocą następującego polecenia:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://run.surfpool.run/ | bash
```

2. Sprawdź, czy instalacja zakończyła się powodzeniem, weryfikując wersję Surfpool CLI:

```terminal
$ surfpool --version
```

Polecenie wyświetla zainstalowaną wersję Surfpool CLI, na przykład:

```
surfpool x.y.z
```
