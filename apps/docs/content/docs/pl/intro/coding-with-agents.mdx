## Używanie Solana MCP

Najpotężniejszym sposobem wykorzystania AI do tworzenia aplikacji na Solanie jest
[Solana Developer MCP](https://mcp.solana.com/) (Model Context Protocol). Ta
integracja wprowadza specjalistyczną wiedzę o Solanie bezpośrednio do Twojego IDE, dając
Twoim agentom dostęp do aktualnej dokumentacji Solany i sprawiając, że rozwój
jest szybszy i bardziej wydajny.

## Czym jest Solana MCP?

Solana MCP to wyspecjalizowany asystent AI, który integruje się bezpośrednio z
IDE obsługującymi AI, takimi jak Cursor i Windsurf. Gdy zadajesz pytania dotyczące
Solany, automatycznie wysyła zapytania do serwera MCP, aby dostarczyć dokładnych,
aktualne informacje z:

- [Dokumentacji Solany](/docs)
- [Dokumentacji Anchor Framework](https://www.anchor-lang.com/docs)
- [Przykładów programów](https://github.com/solana-developers/program-examples)
  Solany
- Pytań i odpowiedzi na
  [Solana Stack Exchange](https://solana.stackexchange.com/)

## Przykładowe przypadki użycia

Możesz używać MCP, aby:

- Pytać o koncepcje Solany
- Debugować błędy programów
- Otrzymywać rekomendacje dotyczące najlepszych praktyk
- Uczyć się z przykładów ekspertów
- Rozwijać się szybciej z pomocą eksperta

## Konfiguracja Solana MCP

Szczegółowy przewodnik po konfiguracji i rozpoczęciu pracy znajdziesz na
[stronie Solana MCP](https://mcp.solana.com/).

## Wolisz używać umiejętności?

Jeśli wolisz skorzystać z umiejętności, zainstaluj oficjalną umiejętność Solany za pomocą:

```bash
npx skills add https://github.com/solana-foundation/solana-dev-skill
```

Przeglądaj więcej gotowych do użycia przepływów pracy w [bibliotece Solana Agent Skills](/skills).
