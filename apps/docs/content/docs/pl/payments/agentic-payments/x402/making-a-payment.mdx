Użyj [Pay](https://pay.sh), aby uruchomić API x402 V2 i udostępnić Claude Code klienta HTTP obsługującego płatności. API, portfel płatnika i rozliczenie korzystają z sandboxa Solany, więc ten przewodnik nie wymaga konta ani prawdziwych środków.

Potrzebujesz terminala oraz zainstalowanych Pay i Claude Code.

## 1. Zainstaluj Pay

W systemie macOS zainstaluj gotowy plik binarny:

```bash
brew install pay
pay --version
```

Na innych platformach zainstaluj pakiet npm:

```bash
npm install --global @solana/pay
pay --version
```

## 2. Uruchom API sandbox x402

Utwórz plik `x402-demo.yaml`:

```yaml filename=x402-demo.yaml
name: x402-demo
subdomain: x402-demo
title: "x402 Demo"
description: "Minimal x402 V2 sandbox endpoint."
category: devtools
version: v1
routing:
  type: respond
operator:
  currencies:
    usd: ["USDC"]
  network: "localnet"
  fee_payer: true
endpoints:
  - method: GET
    path: "report"
    description: "Return a sandbox report."
    metering:
      schemes: [x402-exact]
      dimensions:
        - direction: usage
          unit: requests
          scale: 1
          tiers:
            - price_usd: 0.001
```

Uruchom API i pozostaw je włączone:

```bash
pay --sandbox server start x402-demo.yaml --bind 127.0.0.1:1402
```

Schemat `x402-exact` sprawia, że jest to endpoint obsługujący wyłącznie x402. Tryb sandbox automatycznie tworzy i zasila tymczasowe konta operatora oraz płatnika.

## 3. Uruchom agenta z Pay

W innym terminalu uruchom Claude Code w trybie sandbox:

```bash
pay --sandbox claude
```

Pay dołącza swoje lokalne narzędzia MCP do sesji agenta. Agent nie otrzymuje klucza prywatnego.

## 4. Wykonaj jedno żądanie x402

Wklej ten prompt do agenta:

```text
Use Pay to make exactly one sandbox x402 API request to
http://127.0.0.1:1402/report.

Before paying, show me the amount and ask for approval. Then return the API
result and payment receipt. Do not make any other paid requests.
```

To żądanie przechodzi przez pełną pętlę płatności x402 V2:

1. API zwraca `402 Payment Required` wraz z wyzwaniem `PAYMENT-REQUIRED`.
2. Pay weryfikuje wymagania x402 i wyświetla warunki płatności.
3. Po zatwierdzeniu portfel sandbox podpisuje transakcję, a Pay ponawia żądanie z nagłówkiem `PAYMENT-SIGNATURE`.
4. API zwraca wynik wraz z potwierdzeniem `PAYMENT-RESPONSE`.

Żadne prawdziwe środki nie są przenoszone. Odrzucenie zatwierdzenia zatrzymuje żądanie.

Przejdź do [x402 na Solanie](/docs/payments/agentic-payments/x402), aby zbudować klienta i serwer zasobów x402 V2, lub [zostań facilitatorem x402](/docs/tools/x402-facilitator).
