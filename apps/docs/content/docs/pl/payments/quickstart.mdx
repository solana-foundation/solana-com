W rezultacie otrzymasz komponent React, który wyświetla kod QR Solana Pay do płatności w USDC, czeka na zaksięgowanie płatności i sprawdza, czy zgadza się ona z zamówieniem. Potrzebujesz Node.js 20+, aplikacji React lub Next.js (świeży projekt `create-next-app` wystarczy) oraz portfela mobilnego ustawionego na devnet. Zasil go USDC z devnetu z [faucet.circle.com](https://faucet.circle.com) oraz SOL z devnetu z [faucet.solana.com](https://faucet.solana.com), aby pokryć opłaty transakcyjne.

<Callout type="caution">
  `@solana/pay` jest obecnie w fazie beta. Interfejsy API mogą ulec zmianie przed stabilną wersją.
</Callout>

## 1. Zainstaluj Solana Pay

```bash
pnpm add @solana/pay@beta @solana/kit
```

## 2. Dodaj kod QR płatności

Komponent tworzy unikalny identyfikator referencyjny zamówienia, koduje go w adresie URL [żądania transferu](/docs/tools/solana-pay/quickstart/transfer-requests) i renderuje ten adres jako kod QR. Następnie czeka na transakcję zawierającą ten identyfikator referencyjny i przed oznaczeniem zamówienia jako opłaconego weryfikuje odbiorcę, kwotę i token. Ustaw `MERCHANT_WALLET` na adres, który kontrolujesz:

```tsx
"use client";

import { useEffect, useRef, useState } from "react";
import {
  address,
  createSolanaRpc,
  createSolanaRpcSubscriptions,
  generateKeyPair,
  getAddressFromPublicKey
} from "@solana/kit";
import {
  createQR,
  encodeURL,
  validateTransfer,
  watchReference
} from "@solana/pay";

const MERCHANT_WALLET = address("your-wallet-address");
const USDC_DEVNET = address("4zMMC9srt5Ri5X14GAgXhaHii3GnPAEERYPJgZJDncDU");
const AMOUNT = 1;

const rpc = createSolanaRpc("https://api.devnet.solana.com");
const rpcSubscriptions = createSolanaRpcSubscriptions(
  "wss://api.devnet.solana.com"
);

export function Checkout() {
  const qrRef = useRef<HTMLDivElement>(null);
  const [signature, setSignature] = useState<string | null>(null);

  useEffect(() => {
    const abortController = new AbortController();

    async function startPayment() {
      const keyPair = await generateKeyPair();
      const reference = await getAddressFromPublicKey(keyPair.publicKey);

      const url = encodeURL({
        recipient: MERCHANT_WALLET,
        amount: AMOUNT,
        splToken: USDC_DEVNET,
        reference,
        label: "My Store",
        message: "Order #1001"
      });

      if (abortController.signal.aborted) return;

      if (qrRef.current) {
        qrRef.current.innerHTML = "";
        createQR(url, 300).append(qrRef.current);
      }

      const result = await watchReference(rpcSubscriptions, reference, {
        abortSignal: abortController.signal
      });
      if (result.err) throw new Error("Payment transaction failed");

      await validateTransfer(rpc, result.signature, {
        recipient: MERCHANT_WALLET,
        amount: AMOUNT,
        splToken: USDC_DEVNET,
        reference
      });
      setSignature(result.signature);
    }

    startPayment().catch((error) => {
      if (!abortController.signal.aborted) console.error(error);
    });

    return () => abortController.abort();
  }, []);

  if (signature) return <p>Payment confirmed: {signature}</p>;
  return <div ref={qrRef} />;
}
```

`amount` podaje się w jednostkach tokena, więc `1` oznacza żądanie 1 USDC. Pomiń `splToken`, aby zamiast tego zażądać SOL.

## 3. Przyjmij płatność

Uruchom aplikację, zeskanuj kod QR portfelem i zatwierdź płatność. Gdy transakcja zostanie potwierdzona i przejdzie walidację, komponent wyświetli sygnaturę transakcji. Ta sygnatura jest Twoim potwierdzeniem: wyszukaj ją za pomocą [getTransaction](/docs/rpc/http/gettransaction) lub w dowolnym eksploratorze.

<Callout type="warn">
  Walidacja w przeglądarce wystarczy na potrzeby dema. Zanim zaczniesz realizować prawdziwe zamówienia, weryfikuj płatności na serwerze. Zobacz [weryfikowanie płatności](/docs/payments/accept-payments/verification-tools).
</Callout>
