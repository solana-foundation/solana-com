---
title: "Quickstart: tworzenie tokena za pomocą CLI"
description:
  Create a token, open a token account, mint supply, and transfer tokens using
  the SPL Token CLI on devnet.
---

Ten quickstart przeprowadza przez kompletny cykl życia tokena przy użyciu CLI
_sh`spl-token`_. Utworzysz mint, stworzysz konto mogące przechowywać token,
wybitujesz 100 tokenów i prześlesz część do innego portfela.

Użyj [Solana Playground](https://beta.solpg.io/), aby uruchamiać polecenia w przeglądarce,
lub zainstaluj CLI lokalnie za pomocą `cargo install spl-token-cli`.
Adresy w Twoich wynikach będą się różnić od poniższych przykładów.

## 1. Połącz się z devnet

Utwórz lub podłącz portfel w Solana Playground, następnie wybierz devnet
i zażądaj SOL na depozyty kont oraz opłaty transakcyjne:

```terminal
$ solana config set --url devnet
$ solana airdrop 2
```

Używaj tokenów devnet wyłącznie do testowania. Nie mają one żadnej wartości finansowej.

## 2. Utwórz token

Utwórz mint account identyfikujące Twój token:

```terminal
$ spl-token create-token
```

Skopiuj adres tokena z danych wyjściowych. To jest adres mint, którego użyjesz
w pozostałych poleceniach. Nowy mint startuje z zerową podażą.

```terminal
$ spl-token supply <MINT_ADDRESS>
```

## 3. Utwórz token account

Twój portfel potrzebuje token account dla tego mint, zanim będzie mógł przechowywać saldo:

```terminal
$ spl-token create-account <MINT_ADDRESS>
```

Tworzy to Twoje
[associated token account](/docs/tokens#associated-token-account), którego adres
jest pochodną Twojego portfela i mint.

## 4. Wybijaj tokeny

Wybij 100 tokenów na swoje associated token account:

```terminal
$ spl-token mint <MINT_ADDRESS> 100
$ spl-token balance <MINT_ADDRESS>
```

Autoritet mint musi podpisać tę operację. Wybijanie zwiększa zarówno saldo
Twojego token account, jak i całkowitą podaż rejestrowaną przez mint.

## 5. Prześlij tokeny

Wyślij 10 tokenów do innego portfela devnet. Opcja _sh`--fund-recipient`_
tworzy associated token account odbiorcy, jeśli jeszcze nie istnieje:

```terminal
$ spl-token transfer <MINT_ADDRESS> 10 <RECIPIENT_WALLET_ADDRESS> --fund-recipient
```

Transfer zmienia salda w token accounts nadawcy i odbiorcy;
nie zmienia całkowitej podaży mint.

## Opcjonalnie: dodaj metadane Token-2022

Aby zapisać nazwę, symbol i URI bezpośrednio w nowym mint Token-2022, utwórz go
z włączonym rozszerzeniem metadanych:

```terminal
$ spl-token create-token \
  --program-id TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb \
  --enable-metadata
```

Następnie użyj nowego adresu mint wydrukowanego przez to polecenie:

```terminal
$ spl-token initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  "EXAMPLE" \
  "https://example.com/token.json"
```

URI powinien zwracać publiczny dokument metadanych JSON. Zobacz
[Token-2022 metadata](/docs/tokens/extensions/metadata), aby zapoznać się z modelem konta
i przykładami kodu.
