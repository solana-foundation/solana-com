## Skieruj na devnet

Zamień adresy URL RPC na devnet i zasil płatnika z
[faucet](/developers/cookbook/development/airdrops-and-faucets):

```ts
solanaRpc({
  rpcUrl: "https://api.devnet.solana.com",
  rpcSubscriptionsUrl: "wss://api.devnet.solana.com"
});
```

Wszystko inne pozostaje bez zmian. Przed użyciem tej samej konfiguracji w sieci mainnet
zaplanuj zarządzanie uprawnieniami, operacje compliance oraz monitoring zasobu.
