---
title: "Démarrage rapide : créer un token avec le CLI"
description:
  Create a token, open a token account, mint supply, and transfer tokens using
  the SPL Token CLI on devnet.
---

Ce démarrage rapide parcourt l'ensemble du cycle de vie d'un token avec le CLI
_sh`spl-token`_. Vous allez créer un mint, créer un compte capable de détenir le
token, émettre 100 tokens et en transférer une partie vers un autre portefeuille.

Utilisez [Solana Playground](https://beta.solpg.io/) pour exécuter les commandes dans votre
navigateur, ou installez le CLI localement avec `cargo install spl-token-cli`. Les
adresses affichées dans votre sortie seront différentes des exemples ci-dessous.

## 1. Se connecter au devnet

Créez ou connectez un portefeuille dans Solana Playground, puis sélectionnez le devnet et demandez
des SOL pour les dépôts de comptes et les frais de transaction :

```terminal
$ solana config set --url devnet
$ solana airdrop 2
```

Utilisez les tokens du devnet uniquement à des fins de test. Ils n'ont aucune valeur financière.

## 2. Créer un token

Créez le mint account qui identifie votre token :

```terminal
$ spl-token create-token
```

Copiez l'adresse du token depuis la sortie. Il s'agit de l'adresse de mint que vous utiliserez dans
les commandes suivantes. Un nouveau mint démarre avec un approvisionnement de zéro.

```terminal
$ spl-token supply <MINT_ADDRESS>
```

## 3. Créer un token account

Votre portefeuille a besoin d'un token account pour ce mint avant de pouvoir détenir un solde :

```terminal
$ spl-token create-account <MINT_ADDRESS>
```

Cela crée votre
[associated token account](/docs/tokens#associated-token-account), dont l'adresse
est dérivée de votre portefeuille et du mint.

## 4. Émettre des tokens

Émettez 100 tokens dans votre associated token account :

```terminal
$ spl-token mint <MINT_ADDRESS> 100
$ spl-token balance <MINT_ADDRESS>
```

L'autorité de mint doit signer cette opération. L'émission augmente à la fois le
solde de votre token account et l'approvisionnement total enregistré par le mint.

## 5. Transférer des tokens

Envoyez 10 tokens à un autre portefeuille du devnet. L'option _sh`--fund-recipient`_
crée l'associated token account du destinataire s'il n'existe pas :

```terminal
$ spl-token transfer <MINT_ADDRESS> 10 <RECIPIENT_WALLET_ADDRESS> --fund-recipient
```

Le transfert modifie les soldes des token accounts de l'expéditeur et du destinataire ; il
ne modifie pas l'approvisionnement total du mint.

## Facultatif : ajouter des métadonnées Token-2022

Pour stocker un nom, un symbole et un URI directement sur un nouveau mint Token-2022, créez-le
avec l'extension de métadonnées activée :

```terminal
$ spl-token create-token \
  --program-id TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb \
  --enable-metadata
```

Utilisez ensuite la nouvelle adresse de mint affichée par cette commande :

```terminal
$ spl-token initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  "EXAMPLE" \
  "https://example.com/token.json"
```

L'URI doit retourner un document de métadonnées JSON public. Consultez
[Token-2022 metadata](/docs/tokens/extensions/metadata) pour le modèle de compte
et des exemples de code.
