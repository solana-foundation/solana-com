# Comment vérifier un token et le faire apparaître dans Solana Explorer

Une question fréquente des créateurs de tokens est : _"Pourquoi mon token n'apparaît-il pas lorsque je le recherche sur Solana Explorer, et comment le faire vérifier ?"_

La réponse courte : Solana Explorer ne gère pas son propre processus de vérification unique. Il **agrège plusieurs fournisseurs de vérification indépendants**. Si votre token est vérifié par **l'un** de ces fournisseurs, il apparaîtra dans les résultats de recherche d'Explorer et affichera les informations de vérification.

Ce guide explique chaque fournisseur, ce que « vérifié » signifie (et ne signifie pas), et comment faire vérifier votre token.

## Ce que « vérifié » signifie (et ce que cela ne signifie pas)

La vérification confirme qu'un token est le **token canonique / correct** pour un nom, un symbole et une adresse de mint donnés. Elle aide les utilisateurs à éviter les usurpateurs et les tokens dupliqués, puisque n'importe qui peut créer un token avec n'importe quel nom sur Solana.

La vérification n'est **pas** une approbation d'un projet, et elle ne constitue **pas** une garantie de la valeur, de la sécurité ou de la légitimité d'un token. Faites toujours vos propres recherches.

## Les fournisseurs de vérification derrière Solana Explorer

Solana Explorer consulte les vérificateurs indépendants suivants. Être référencé par l'un d'eux (RugCheck est automatique ; les autres nécessitent une action) fait apparaître votre token dans la recherche Explorer.

### 1. RugCheck (automatique)

[RugCheck](https://rugcheck.xyz) effectue une analyse automatisée on-chain et suit les tokens automatiquement. Étant automatique, vous n'avez généralement rien à soumettre — RugCheck évalue les signaux de risque on-chain (autorité de mint/gel, distribution des détenteurs, liquidité, etc.) et suit le token de lui-même.

Un traitement spécial est prévu pour certains stablecoins, où les projets peuvent contacter directement l'équipe RugCheck pour un traitement approprié.

Exemple de page de token :
[`rugcheck.xyz/tokens/<mint>`](https://rugcheck.xyz/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 2. Jupiter

[Jupiter](https://jup.ag) maintient une liste de tokens vérifiés (VRFD) largement intégrée dans l'écosystème Solana — DEX, portefeuilles et outils d'analyse. Un token vérifié reçoit une coche verte sur les produits Jupiter et les plateformes partenaires.

Pour obtenir la vérification, soumettez votre token pour examen :

- Soumettre sur [verified.jup.ag/tokens](https://verified.jup.ag/tokens)
- N'importe qui peut soumettre un token (pas seulement l'équipe du projet)
- Vous pouvez optionnellement connecter le compte X du projet pour lier l'adresse de mint du token
  à un compte spécifique
- Jupiter effectue une revue globale (liquidité, conformité aux standards de métadonnées et
  autres signaux) plutôt que de vérifier une seule métrique

Exemple de page de token :
[`jup.ag/tokens/<mint>`](https://jup.ag/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 3. CoinGecko

La vérification [CoinGecko](https://www.coingecko.com) référence votre token avec des données de marché. Lors de la vérification avec CoinGecko, veillez à inclure l'**adresse de mint** du token (que le formulaire CoinGecko appelle « adresse de contrat ») afin que les intégrations en aval puissent résoudre les prix correctement.

Suivez le guide officiel de référencement/mise à jour de CoinGecko :

- [Guide de vérification pour les demandes de référencement et de mise à jour sur CoinGecko](https://support.coingecko.com/hc/en-us/articles/23725417857817-Verification-Guide-for-Listing-Update-Requests-on-CoinGecko)

Exemple de page de coin :
[`coingecko.com/en/coins/<token>`](https://www.coingecko.com/en/coins/usdc)

### 4. Solflare

[Solflare](https://solflare.com) est un validator indépendant dans le cadre de vérification de Solana Explorer. En pratique, ses critères de référencement des tokens recoupent largement ceux de Jupiter, car la liste de swaps intégrée à Solflare est alimentée par l'agrégateur Jupiter. Pour qu'un nouveau token apparaisse, il doit généralement :

- Être un token valide sur la blockchain Solana avec des métadonnées conformes au standard Metaplex Token Metadata
- Disposer d'une liquidité suffisante (une valeur minimale en USD du token disponible pour le trading)
- Maintenir l'impact sur le prix dans des limites acceptables pour les swaps habituels

En raison de ce recoupement, les tokens ayant complété la vérification Jupiter sont souvent déjà éligibles sur Solflare sans soumission séparée — vous n'avez donc généralement pas besoin de traiter Solflare comme une étape manuelle supplémentaire. Une fois les critères remplis, les tokens apparaissent généralement en quelques minutes. Voir :

- [Je ne trouve pas un token dans Solflare](https://help.solflare.com/en/articles/9260147-i-cannot-find-a-token-in-solflare)

Exemple de page de token :
[`solflare.com/prices/<name>/<mint>`](https://www.solflare.com/prices/usd-coin/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/)

### 5. Bluprynt (KYC renforcé)

[Bluprynt](https://app.bluprynt.com/register/account) propose un parcours de vérification renforcé avec un protocole KYC. Il s'agit d'un processus plus rigoureux, adossé à une vérification d'identité, adapté aux projets souhaitant un signal de vérification plus solide.

- Inscrivez-vous via
  [l'intégration Bluprynt pour Solana Explorer](https://app.bluprynt.com/register/account)

Exemple de page d'actif vérifié :
[`verified.bluprynt.com/verified-assets/<mint>/solana`](https://verified.bluprynt.com/verified-assets/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/solana)

## Comment tout cela s'articule

- **RugCheck** se fait automatiquement via l'analyse on-chain — aucune soumission nécessaire.
- **Jupiter, CoinGecko, Solflare et Bluprynt** requièrent chacun que vous soumettiez /
  complétiez leur processus respectif.
- Dès que votre token est vérifié par **au moins un** de ces fournisseurs, il
  apparaîtra dans la recherche **Solana Explorer** et affichera les détails de vérification.

Si votre token n'apparaît pas encore dans la recherche Explorer, le chemin le plus rapide est généralement de soumettre pour la vérification Jupiter et/ou de compléter un référencement CoinGecko, car les deux sont largement intégrés dans l'écosystème.

## Prérequis qui favorisent la réussite de la vérification

Quel que soit le fournisseur, ces fondamentaux on-chain augmentent considérablement les chances de succès de la vérification :

- **Métadonnées valides** : votre token doit disposer de métadonnées on-chain conformes au standard Metaplex Token Metadata (nom, symbole, URI du logo).
- **Liquidité** : fournissez suffisamment de liquidité sur un DEX supporté afin que le token puisse être échangé et évalué.
- **Adresse de mint correcte** : lors de toute soumission à un fournisseur, utilisez toujours l'**adresse de mint** de votre token (appelée « adresse de contrat » dans certains formulaires de fournisseurs).

## Résumé

Solana Explorer agrège plusieurs vérificateurs indépendants — **RugCheck** (automatique), **Jupiter**, **CoinGecko**, **Solflare** et **Bluprynt** (KYC). La vérification par l'un d'eux rend votre token découvrable dans la recherche Explorer. La vérification confirme l'identité canonique du token ; elle ne constitue pas une approbation, les utilisateurs doivent donc toujours effectuer leurs propres recherches.
