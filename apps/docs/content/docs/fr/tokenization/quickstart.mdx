## Le pointer vers le devnet

Remplacez les URL RPC par celles du devnet et alimentez le payeur depuis un [faucet](/developers/cookbook/development/airdrops-and-faucets) :

```ts
solanaRpc({
  rpcUrl: "https://api.devnet.solana.com",
  rpcSubscriptionsUrl: "wss://api.devnet.solana.com"
});
```

Tout le reste est inchangé. Avant d'utiliser la même configuration sur le mainnet, planifiez la gestion des autorités, les opérations de conformité et la surveillance de l'actif.
