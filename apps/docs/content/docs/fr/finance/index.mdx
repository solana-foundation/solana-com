## Émission et gestion d'actifs

Si vous créez l'actif plutôt que d'en intégrer un existant, consultez [Émission & Tokenisation](/docs/tokenization). Ce guide couvre la création de tokens, les contrôles d'accès, le règlement livraison contre paiement et les opérations de fonds.
