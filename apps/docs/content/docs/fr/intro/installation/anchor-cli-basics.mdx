Cette section fournit quelques commandes et exemples courants pour vous aider à
démarrer avec
l'[interface en ligne de commande Anchor](https://www.anchor-lang.com/docs).

<Steps>
<Step>

### Initialiser le projet

Créez un nouveau projet Anchor en exécutant la commande ci-dessous. Elle créera un
nouveau répertoire portant le nom du projet et l'utilisera pour initialiser un nouveau projet
Anchor.

```terminal
$ anchor init <project-name>
```

Par exemple, la commande ci-dessous créera un projet appelé `my-project`. Le
répertoire `my-project` contiendra un programme Rust modulaire et un modèle de test
Rust qui utilise LiteSVM.

```terminal
$ anchor init my-project
```

Pour générer plutôt un modèle de test TypeScript, choisissez-en un explicitement. Par
exemple, utilisez le modèle Mocha :

```terminal
$ anchor init my-project --test-template mocha
```

Les modèles de test TypeScript nécessitent Node.js et un gestionnaire de paquets JavaScript.

Accédez ensuite au répertoire du projet :

```terminal
$ cd <project-name>
```

Consultez la [structure des fichiers d'un projet](https://www.anchor-lang.com/docs/quickstart/local#project-file-structure) Anchor.

</Step>
<Step>

### Compiler le programme

Pour compiler votre projet, exécutez la commande suivante :

```terminal
$ anchor build
```

Vous trouverez le programme compilé dans le répertoire `/target/deploy`.

<Callout type="warn" title="Échec de l'installation des outils de plateforme">
  Si la compilation signale un répertoire platform-tools non valide, réinstallez les
  outils de compilation SBF, puis relancez la compilation :

```terminal
$ cargo build-sbf --force-tools-install
$ anchor build
```

</Callout>

</Step>
<Step>

### Déployer le programme

Pour déployer votre projet, exécutez la commande suivante :

```terminal
$ anchor deploy
```

Cette commande déploie votre programme sur le `cluster` spécifié dans le fichier
[`Anchor.toml`](https://www.anchor-lang.com/docs/references/anchor-toml).

</Step>
<Step>

### Tester le programme

Pour tester votre projet, exécutez la commande suivante :

```terminal
$ anchor test
```

Cette commande compile, déploie et exécute les tests de votre projet.

<Callout>
  Lors de l'utilisation du cluster `localnet`, Anchor démarre automatiquement un
  validateur local, déploie le programme, exécute les tests, puis arrête le
  validateur.
</Callout>

<Callout type="warn" title="Erreurs de l'exécuteur de tests JavaScript">

Si vous avez sélectionné un modèle de test JavaScript ou TypeScript, l'une des
erreurs suivantes peut indiquer que Node.js ou le gestionnaire de paquets configuré n'est
pas installé :

```
Permission denied (os error 13)
```

```
No such file or directory (os error 2)
```

</Callout>

</Step>
</Steps>
