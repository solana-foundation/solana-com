Installez chaque dépendance séparément lorsque vous avez besoin d'une version spécifique ou lorsque l'[installation rapide](/docs/intro/installation) ne se termine pas correctement.
Suivez les sections dans l'ordre pour un nouvel environnement, ou accédez directement à l'outil
que vous devez installer ou dépanner.

## Prérequis

<Accordions>
<Accordion title="Windows">

Pour développer des programmes Solana sur Windows, vous **devez** utiliser
[Windows Subsystem for Linux](https://learn.microsoft.com/en-us/windows/wsl/install)
(WSL). Après avoir installé WSL, toutes les autres dépendances seront installées
via le terminal Linux.

Pour installer WSL, exécutez la commande suivante dans Windows PowerShell :

```terminal
$ wsl --install
```

Le processus d'installation vous invitera à créer un compte utilisateur par
défaut.

![Installation WSL](/assets/docs/intro/installation/wsl-install.png)

Par défaut, WSL installe Ubuntu. Vous pouvez ouvrir un terminal Linux en
recherchant « Ubuntu » dans la barre de recherche.

![WSL Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-search.png)

Si votre terminal Ubuntu ressemble à l'image ci-dessous, vous pourriez
rencontrer un problème où `ctrl + v` (raccourci clavier pour coller) ne
fonctionne pas dans le terminal.

![Terminal Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-terminal-1.png)

Si vous rencontrez ce problème, ouvrez Windows Terminal en recherchant «
Terminal » dans la barre de recherche.

![Windows Terminal](/assets/docs/intro/installation/wsl-windows-terminal.png)

Ensuite, fermez Windows Terminal et rouvrez un terminal Linux en recherchant à
nouveau Ubuntu. Le terminal devrait maintenant ressembler à l'image ci-dessous,
où `ctrl + v` (raccourci clavier pour coller) fonctionne.

![Terminal Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-terminal-2.png)

Si vous utilisez VS Code,
l'[extension WSL](https://code.visualstudio.com/docs/remote/wsl-tutorial) vous
permet d'utiliser WSL et VS Code ensemble.

![Configuration WSL dans VS Code](/assets/docs/intro/installation/wsl-vscode.png)

Vous verrez ce qui suit dans la barre d'état de VS Code :

![WSL: Ubuntu](/assets/docs/intro/installation/wsl-vscode-ubuntu.png)

Une fois WSL configuré, vous êtes prêt à :

- Effectuer l'[installation rapide](/docs/intro/installation) en utilisant le
  terminal Ubuntu (Linux)
- Installer [Rust](#install-rust), la [CLI Solana](#install-solana-cli) et la
  [CLI Anchor](#install-anchor-cli) individuellement, comme décrit ci-dessous

<Tabs items={[".deb", ".rpm"]}>
<Tab value=".deb" >
Sur Debian ou une distribution dérivée de Debian comme Ubuntu ou Mint :

1. Mettez à jour les listes de paquets pour vous assurer que tous les paquets
   sont à jour :

```terminal
$ sudo apt-get update
```

2. Installez les dépendances suivantes :

```terminal
$ sudo apt-get install -y \
    build-essential \
    pkg-config \
    libudev-dev llvm libclang-dev \
    protobuf-compiler libssl-dev
```

<Callout>
Si vous rencontrez l'erreur suivante lors de l'installation de `protobuf-compiler`, exécutez
`sudo apt-get update` avant de relancer la commande d'installation.

```
Package protobuf-compiler is not available, but is referred to by another package.
This may mean that the package is missing, has been obsoleted, or
is only available from another source
```

</Callout>

    <Tab value=".rpm" >
    Sur une distribution basée sur RPM comme Fedora ou Red Hat Enterprise Linux :

Mettez à jour les paquets installés :

```terminal
$ sudo dnf upgrade --refresh
```

Installez les dépendances de développement :

```terminal
$ sudo dnf group install c-development development-tools \
&& sudo dnf install pkg-config openssl-devel
```

### Installer Rust

Les développeurs créent des programmes Solana en utilisant le langage de
programmation [Rust](https://www.rust-lang.org/).

1. Installez Rust en utilisant [rustup](https://www.rust-lang.org/tools/install)
   en saisissant la commande suivante dans votre terminal :

```terminal
$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
```

Après une installation réussie, vous verrez le message suivant :

<Accordions>
<Accordion title="Message d'installation réussie de Rust">

```
Rust is installed now. Great!

To get started you may need to restart your current shell.
This would reload your PATH environment variable to include
Cargo's bin directory ($HOME/.cargo/bin).

To configure your current shell, you need to source
the corresponding env file under $HOME/.cargo.

This is usually done by running one of the following (note the leading DOT):
. "$HOME/.cargo/env"            # For sh/bash/zsh/ash/dash/pdksh
source "$HOME/.cargo/env.fish"  # For fish
```

</Accordion>
</Accordions>

2. Rechargez votre variable d'environnement PATH pour inclure le répertoire bin
   de [Cargo](https://github.com/rust-lang/cargo) :

```terminal
$ . "$HOME/.cargo/env"
```

3. Vérifiez que l'installation a réussi.

```terminal
$ rustc --version
```

La commande affiche la version de Rust installée, par exemple :

```
rustc x.y.z (...)
```

</Step>

### Installer Solana CLI

Solana CLI fournit tous les outils nécessaires pour créer et déployer des
programmes Solana.

1. Installez la suite d'outils Solana CLI en utilisant la commande
   d'installation officielle :

```terminal
$ sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

<Callout>
  Vous pouvez remplacer `stable` par un tag de version Agave spécifique ou par le canal de publication `beta`
  ou `edge`.
</Callout>

2. Rendez la CLI Solana disponible dans votre terminal actuel.

Le programme d'installation met à jour la configuration de votre shell et affiche la commande nécessaire
pour mettre à jour la session en cours. La commande est généralement :

```terminal
$ export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"
```

Si `solana` reste indisponible, redémarrez votre terminal. Pour confirmer quel fichier de configuration
du shell a été mis à jour par le programme d'installation, vérifiez votre shell actuel :

```terminal
$ echo $SHELL
```

- Si la sortie contient `/bash`, redémarrez le terminal ou exécutez
  `source ~/.bashrc`.
- Si la sortie contient `/zsh`, redémarrez le terminal ou exécutez `source ~/.zshrc`.

3. Vérifiez que l'installation a réussi :

```terminal
$ solana --version
```

La commande affiche la version de la CLI Solana installée, par exemple :

```
solana-cli x.y.z (..., client:Agave)
```

<Callout>

Vous pouvez consulter toutes les versions disponibles sur le
[dépôt GitHub d'Agave](https://github.com/anza-xyz/agave/releases). Agave est
le client validator d'[Anza](https://www.anza.xyz/), anciennement connu sous le nom de
client validator de Solana Labs.

</Callout>

4. Pour mettre à jour la CLI Solana ultérieurement, exécutez :

```terminal
$ agave-install update
```

</Step>

### Installer l'interface de ligne de commande Anchor

[Anchor](https://www.anchor-lang.com/) est un framework de développement de
programmes Solana. Le framework Anchor exploite les macros Rust pour simplifier
le processus d'écriture de programmes Solana.

#### Prérequis

Node.js et un gestionnaire de paquets JavaScript ne sont requis que lorsque vous sélectionnez un
modèle de test TypeScript tel que Mocha ou Jest. Le modèle de test LiteSVM par défaut
s'exécute en Rust et ne nécessite pas d'outils Node.js.

<Accordions>
<Accordion title="Installation de Node">

1. Installez Node à l'aide de
   [Node Version Manager (nvm)](https://github.com/nvm-sh/nvm) en exécutant la
   commande suivante :

```terminal
$ curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```

2. Redémarrez votre terminal et vérifiez que la commande `nvm` s'exécute correctement :

```terminal
$ command -v nvm
```

3. Utilisez `nvm` pour installer Node :

```terminal
$ nvm install --lts
```

4. Vérifiez que l'installation a réussi en consultant la version de Node :

```terminal
$ node --version
```

La commande affiche la version de Node.js installée, par exemple :

```
vx.y.z
```

</Accordion>
<Accordion title="Installation de Yarn">

1. Installez Yarn :

```terminal
$ npm install --global yarn
```

2. Vérifiez que l'installation a réussi en consultant la version de Yarn :

```terminal
$ yarn --version
```

La commande affiche la version de Yarn installée, par exemple :

```
x.y.z
```

</Accordion>
</Accordions>

#### Installation

Vous pouvez installer l'interface en ligne de commande (CLI) et les outils
Anchor de deux manières :

- Anchor Version Manager (AVM) — méthode d'installation recommandée
- Sans AVM — installation directe depuis GitHub

<Tabs groupId="anchor" items={["AVM", "Without AVM"]}>
<Tab value="AVM">

Le gestionnaire de versions Anchor (AVM) vous permet d'installer et de gérer
différentes versions d'Anchor sur votre système et de mettre à jour facilement
les versions d'Anchor à l'avenir. Pour installer Anchor à l'aide d'AVM, suivez
les étapes ci-dessous :

1. Installez AVM avec la commande suivante :

```terminal
$ curl -sSfL https://raw.githubusercontent.com/otter-sec/anchor/master/avm/install | sh
```

2.  Confirmez qu'AVM s'est installé avec succès :

```terminal
$ avm --version
```

3. Installez l'interface de ligne de commande Anchor à l'aide d'AVM :

Pour installer la dernière version :

```terminal
$ avm install latest
$ avm use latest
```

Pour installer une version spécifique, spécifiez le numéro de version :

```terminal
$ avm install 1.1.2
$ avm use 1.1.2
```

<Callout type="warn">

Lors de l'installation de l'Anchor CLI sur Linux ou WSL, vous pouvez rencontrer cette erreur :

```
error: could not exec the linker cc = note: Permission denied (os error 13)
```

Si vous voyez ce message d'erreur, suivez ces étapes :

1. Installez les dépendances listées dans la section
   [Linux](/docs/intro/installation/dependencies) en haut de cette
   page.
2. Réessayez d'installer l'Anchor CLI.

</Callout>

4. Vérifiez que l'installation a réussi en contrôlant la version de l'interface
   de ligne de commande Anchor :

```terminal
$ anchor --version
```

La commande affiche la version active de la CLI Anchor, par exemple :

```
anchor-cli 1.1.2
```

<Callout type="info">

Exécutez `avm use` pour sélectionner la version de la CLI Anchor pour votre système.

- Si vous avez installé la dernière version, exécutez `avm use latest`.
- Si vous avez installé la version `1.1.2`, exécutez `avm use 1.1.2`.

</Callout>

</Tab>

<Tab value="Without AVM">

1. Installez une version spécifique de la CLI Anchor avec la commande suivante :

```terminal
$ cargo install --git https://github.com/solana-foundation/anchor --tag v1.1.2 anchor-cli --locked
```

2. Vérifiez que l'installation a réussi en consultant la version de la CLI Anchor :

```terminal
$ anchor --version
```

La commande affiche la version de la CLI Anchor installée, par exemple :

```
anchor-cli 1.1.2
```

</Tab>

### Installer la CLI Surfpool

[Surfpool](/docs/tools/surfpool) est un outil de développement local et un remplaçant amélioré
de `solana-test-validator`.

1. Installez Surfpool avec la commande suivante :

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://run.surfpool.run/ | bash
```

2. Vérifiez que l'installation a réussi en consultant la version de la CLI
   Surfpool :

```terminal
$ surfpool --version
```

La commande affiche la version de la CLI Surfpool installée, par exemple :

```
surfpool x.y.z
```

</Step>
