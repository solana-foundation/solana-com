Configurez un environnement de développement Solana local avec l'installateur automatisé. Il
installe Rust, la CLI Solana, la CLI Anchor, la CLI Surfpool, Node.js et Yarn sur
macOS, Linux ou Windows via WSL.

<Callout type="info" title="Windows nécessite WSL">
  Dans Windows PowerShell, exécutez `wsl --install`, redémarrez Windows si vous y êtes invité, puis
  exécutez les commandes d'installation ci-dessous dans le terminal Ubuntu. Consultez le [guide d'installation
  manuelle](/docs/intro/installation/dependencies) pour la configuration
  complète de WSL.
</Callout>

## Installation rapide

1. Exécutez l'installateur dans un terminal macOS, Linux ou WSL :

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
```

Vous pouvez
[consulter le code source de l'installateur](https://github.com/solana-developers/solana-install/blob/main/install.sh)
avant de l'exécuter. L'installateur détecte les gestionnaires de paquets Linux pris en charge et
installe automatiquement leurs dépendances système.

2. Redémarrez votre terminal afin que les nouvelles commandes soient disponibles dans votre `PATH`.

3. Vérifiez chaque outil :

```terminal
$ rustc --version
$ solana --version
$ anchor --version
$ surfpool --version
$ node --version
$ yarn --version
```

Une installation réussie renvoie une sortie de la forme suivante (les numéros de version changent au fil des
versions des outils) :

```txt title="Example output"
Installed Versions:
Rust: rustc x.y.z (...)
Solana CLI: solana-cli x.y.z (..., client:Agave)
Anchor CLI: anchor-cli x.y.z
Surfpool CLI: surfpool x.y.z
Node.js: vx.y.z
Yarn: x.y.z
```

<Callout type="warn" title="L'installateur a échoué ou une commande est introuvable">
  Suivez le [guide d'installation manuelle](/docs/intro/installation/dependencies)
  pour installer ou dépanner chaque dépendance individuellement.
</Callout>
