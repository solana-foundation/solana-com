## Utiliser Solana MCP

La façon la plus efficace de tirer parti de l'IA pour le développement sur Solana est d'utiliser le
[Solana Developer MCP](https://mcp.solana.com/) (Model Context Protocol). Cette
intégration apporte des connaissances spécialisées sur Solana directement dans votre IDE, offrant
à vos agents un accès à une documentation Solana à jour et rendant le développement
plus rapide et plus efficace.

## Qu'est-ce que Solana MCP ?

Solana MCP est un assistant IA spécialisé qui s'intègre directement dans
les IDE compatibles avec l'IA comme Cursor et Windsurf. Lorsque vous posez des
questions spécifiques à Solana, il interroge automatiquement le serveur MCP pour fournir des informations
précises et à jour provenant de :

- La [documentation Solana](/docs)
- La [documentation du framework Anchor](https://www.anchor-lang.com/docs)
- Les
  [exemples de programmes](https://github.com/solana-developers/program-examples) Solana
- Les questions et
  réponses de [Solana Stack Exchange](https://solana.stackexchange.com/)

## Exemples de cas d'utilisation

Vous pouvez utiliser MCP pour :

- Poser des questions sur les concepts Solana
- Déboguer les erreurs de programme
- Obtenir des recommandations de bonnes pratiques
- Apprendre à partir d'exemples d'experts
- Développer plus rapidement avec l'aide d'un expert

## Configurer Solana MCP

Retrouvez un guide de configuration et de démarrage détaillé sur le
[site web de Solana MCP](https://mcp.solana.com/).

## Vous préférez utiliser une compétence ?

Si vous préférez utiliser une compétence, installez la compétence Solana officielle avec :

```bash
npx skills add https://github.com/solana-foundation/solana-dev-skill
```

Parcourez d'autres workflows réutilisables dans la [bibliothèque Solana Agent Skills](/skills).
