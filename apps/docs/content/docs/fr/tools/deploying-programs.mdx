---
title: Déployer des programmes
description: Bonnes pratiques pour déployer des programmes sur le Mainnet
---

Si vous déployez un programme Solana personnalisé dans le cadre de votre infrastructure de paiement,
des points supplémentaires sont à prendre en compte.

## Avant le déploiement

- **Version de la CLI Solana :** Assurez-vous d'utiliser la dernière version de la
  [CLI Solana](https://solana.com/docs/intro/installation).
- **Keypair du programme :** Votre programme aura une adresse différente sur le mainnet
  et sur le devnet (sauf si vous réutilisez le même keypair). Mettez à jour toutes les références dans
  la configuration de votre application. Conservez le keypair de votre programme dans un emplacement sécurisé (notez
  que l'exécution de `cargo clean` supprimera probablement le keypair de votre programme).
- **Initialiser les comptes :** Si votre programme nécessite des comptes d'administration, des PDA ou
  d'autres comptes d'état, assurez-vous qu'ils sont créés sur le mainnet avant que les utilisateurs
  n'interagissent avec votre application. Il en va de même pour tous les associated token accounts (ATA)
  dont votre programme a besoin.

## Processus de déploiement

- **Buffer accounts :** Les programmes volumineux sont déployés via des buffer accounts. La
  commande `solana program deploy` gère cela automatiquement, mais sachez
  que le déploiement n'est pas atomique : en cas d'interruption, vous devrez peut-être récupérer ou fermer
  les buffer accounts.
- **Autorité de mise à niveau :** Créez un
  [multisig](https://docs.squads.so/main/basics/what-is-a-multisig) et attribuez-le
  comme
  [autorité de mise à niveau de votre programme Solana](https://docs.squads.so/main/navigating-your-squad/developers-assets/programs).
- **Rent :** Assurez-vous que votre portefeuille de déploiement dispose de suffisamment de SOL pour couvrir les minimums d'exonération de rent
  pour tous les comptes du programme.
- **Vérification :** [Vérifiez](https://solana.com/docs/programs/verified-builds)
  votre programme afin de vous assurer que le programme exécutable que vous déployez sur le réseau
  de Solana correspond au code source de votre dépôt
