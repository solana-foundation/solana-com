---
title: AllowMint
description:
  Autorise un mint de token SPL sur l'instance et crée l'ATA d'entiercement pour ce mint
---

Autorise un mint de token SPL sur l'instance et crée l'associated
token account de l'entiercement pour ce mint. Les dépôts pour ce mint deviennent possibles après
cet appel.

## Comptes

| Compte                          | Modifiable | Signataire | Description                                                                   |
| -------------------------------- | -------- | ------ | ----------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Payeur des frais                                                                     |
| `admin`                          |          | ✓      | Administrateur de l'instance                                                                |
| `instance`                       |          |        | PDA de l'instance                                                                  |
| `mint`                           |          |        | Mint de token SPL à autoriser                                                       |
| `allowed_mint`                   | ✓        |        | PDA AllowedMint (créé par cette instruction)                                 |
| `instance_ata`                   | ✓        |        | Associated token account de l'entiercement pour ce mint (créé par cette instruction) |
| `system_program`                 |          |        | System Program                                                                |
| `token_program`                  |          |        | SPL Token Program                                                             |
| `associated_token_program`       |          |        | Associated Token Program                                                      |
| `event_authority`                |          |        | PDA de l'autorité d'événement                                                           |
| `private_channel_escrow_program` |          |        | Programme d'entiercement                                                                |

## Paramètres

| Paramètre | Type | Description                                                                                   |
| --------- | ---- | --------------------------------------------------------------------------------------------- |
| `bump`    | `u8` | Bump seed pour le PDA `allowed_mint`. Optionnel : le client `Async` le dérive automatiquement si omis |

> L'IDL contient un argument `discriminator: u8` (valeur `1`) qui est défini automatiquement
> par le client généré et ne doit pas être passé manuellement.

## Notes importantes

- Utilisez `getAllowMintInstructionAsync` ; il dérive automatiquement `bump`, `allowed_mint`,
  et `instance_ata` lorsqu'ils ne sont pas fournis. Passez votre propre `bump` uniquement si
  vous l'avez déjà calculé via
  `Pubkey::find_program_address(&[b"allowed_mint", instance_pda, mint], &PROGRAM_ID)`
- Crée également `instance_ata`, l'ATA de l'entiercement pour ce mint
- Les mints avec une extension de hook de transfert sont explicitement bloqués : tenter d'autoriser
  un tel mint lève l'erreur `TransferHookNotAllowed`
- Émet un événement via le CPI `EmitEvent`
