Cette section constitue la référence des instructions on-chain. La plupart des développeurs appellent ces instructions via les clients TypeScript générés ; vous n'avez besoin de cette section que si vous construisez des outils d'opérateur, écrivez des intégrations personnalisées ou déboguez des erreurs au niveau des instructions.

**Programme Escrow** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) - gère
les dépôts, le provisionnement des opérateurs et le règlement sur le Mainnet :

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) -
  initialiser le PDA de l'instance escrow
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) - mettre
  sur liste blanche un mint de token SPL
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) - retirer
  un mint de la liste blanche
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) -
  provisionner un opérateur
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) -
  révoquer un opérateur
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) -
  transférer les droits d'administration
- [Deposit](/docs/tools/private-channels/instructions/deposit) - déplacer des tokens SPL
  vers l'escrow
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) -
  l'opérateur règle un retrait vers le Mainnet
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) -
  l'opérateur effectue une rotation de la racine du Sparse Merkle Tree

**Programme Withdraw** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) - fonctionne sur
le réseau de canaux privés :

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) -
  brûler le solde côté canal pour initier un retrait

## Codes d'erreur

**Programme Escrow - `PrivateChannelEscrowProgramError`**

| Code                                         | Message                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | Autorité d'événement fournie invalide                 |
| `InvalidAta`                                 | ATA fourni invalide                             |
| `InvalidMint`                                | Mint fourni invalide                            |
| `InvalidInstanceId`                          | ID d'instance invalide ou ne respectant pas les règles    |
| `InvalidInstance`                            | Instance fournie invalide                        |
| `InvalidAdmin`                               | Administrateur fourni invalide                           |
| `TransferHookNotAllowed`                     | Extension transfer hook non autorisée              |
| `InvalidOperatorPda`                         | PDA d'opérateur fourni invalide                    |
| `InvalidTokenAccount`                        | token account fourni invalide                   |
| `InvalidEscrowBalance`                       | Solde escrow invalide                           |
| `InvalidAllowedMint`                         | Mint autorisé invalide                             |
| `InvalidSmtProof`                            | Preuve SMT fournie invalide                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | Nonce de transaction invalide pour l'index d'arbre actuel |
| `UnexpectedTreeIndex`                        | Index d'arbre actuel inattendu lors de la réinitialisation de la racine SMT |

**Programme Withdraw - `PrivateChannelWithdrawProgramError`**

| Code          | Message                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | Mint fourni invalide                       |
| `ZeroAmount`  | Le montant du retrait doit être supérieur à zéro |
