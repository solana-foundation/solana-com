Supprime un mint précédemment autorisé de l'instance, empêchant tout nouveau dépôt pour
ce mint. Les dépôts existants ne sont pas affectés.

## Comptes

| Compte                          | Accessible en écriture | Signataire | Description                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | Payeur des frais                                    |
| `admin`                          |          | ✓      | Administrateur de l'instance                               |
| `instance`                       |          |        | PDA de l'instance                                 |
| `mint`                           |          |        | Mint de token SPL à bloquer                      |
| `allowed_mint`                   | ✓        |        | PDA AllowedMint (fermé par cette instruction) |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | PDA de l'autorité d'événement                          |
| `private_channel_escrow_program` |          |        | Programme d'escrow                               |

Cette instruction ne prend aucun paramètre.

## Notes importantes

- Ferme le PDA `allowed_mint` : les nouveaux appels `Deposit` pour ce mint échoueront
  avec `InvalidAllowedMint`
- Les soldes de canal existants pour ce mint ne sont pas affectés
- Émet un événement via le CPI `EmitEvent`
