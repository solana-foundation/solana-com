Transfère les droits d'administration à un nouveau portefeuille.

## Comptes

| Compte                          | Modifiable | Signataire | Description                        |
| -------------------------------- | -------- | ------ | ---------------------------------- |
| `payer`                          | ✓        | ✓      | Payeur des frais                          |
| `current_admin`                  |          | ✓      | Administrateur actuel (doit signer)          |
| `instance`                       | ✓        |        | PDA d'instance (champ admin mis à jour) |
| `new_admin`                      |          | ✓      | Portefeuille destiné à recevoir les droits d'administration     |
| `event_authority`                |          |        | PDA de l'autorité d'événement                |
| `private_channel_escrow_program` |          |        | Programme d'entiercement                     |

Cette instruction ne prend aucun paramètre.

## Remarques importantes

- **Irréversible en une seule étape** : l'administrateur actuel ne peut pas récupérer le rôle
  sans que le nouvel administrateur appelle à nouveau `SetNewAdmin`
- Vérifiez l'adresse cible avant d'appeler cette instruction ; aucune annulation n'est possible
- Émet un événement via le CPI `EmitEvent`
