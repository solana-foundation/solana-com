---
title: Dépôt
description:
  Transfère des tokens SPL depuis le portefeuille d'un utilisateur vers l'escrow de Private Channels
---

Transfère des tokens SPL depuis l'associated token account d'un utilisateur vers l'associated token account de l'escrow, en créditant le solde du canal de l'utilisateur effectuant le dépôt (ou le solde d'un destinataire facultatif).

## Comptes

| Compte                          | Accessible en écriture | Signataire | Description                                          |
| -------------------------------- | -------- | ------ | ---------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Payeur des frais de transaction                        |
| `user`                           |          | ✓      | Propriétaire du token effectuant le dépôt                       |
| `instance`                       |          |        | PDA de l'instance d'escrow                                  |
| `mint`                           |          |        | Mint du token SPL                                       |
| `allowed_mint`                   |          |        | PDA vérifiant que le mint est autorisé sur cette instance |
| `user_ata`                       | ✓        |        | Associated token account de l'utilisateur (source)             |
| `instance_ata`                   | ✓        |        | Associated token account de l'escrow (destination)      |
| `system_program`                 |          |        | System Program                                       |
| `token_program`                  |          |        | SPL Token Program                                    |
| `associated_token_program`       |          |        | Associated Token Program                             |
| `event_authority`                |          |        | PDA d'autorité d'événement pour le CPI `EmitEvent`              |
| `private_channel_escrow_program` |          |        | Programme d'escrow (auto-référence pour CPI)              |

## Paramètres

| Paramètre   | Type             | Description                                                                           |
| ----------- | ---------------- | ------------------------------------------------------------------------------------- |
| `amount`    | `u64`            | Montant de tokens à déposer, dans la plus petite unité du token                             |
| `recipient` | `Option<Pubkey>` | Destinataire on-chain facultatif ; si `None`, crédite le solde du canal de l'utilisateur effectuant le dépôt |

## Retours

Retourne un `TransactionBuilder` pouvant être utilisé pour construire et envoyer la transaction.

## Exemple

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

// allowedMint and instanceAta are auto-derived from mint and instance
const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n,
  recipient: null
});
```

## Remarques importantes

- ID du programme : `9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`
- Pour les mints Token-2022, passez `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS`
  explicitement, car il utilise par défaut le SPL Token Program standard
- Le PDA `allowed_mint` doit exister (créé par `AllowMint`) ; déposer un
  mint non répertorié lève l'erreur `InvalidAllowedMint`
- Lorsque `recipient` est `None`, le solde du canal de l'utilisateur effectuant le dépôt est crédité ;
  lorsqu'il est fourni, le solde du portefeuille spécifié est crédité à la place
- `payer` et `user` doivent tous deux signer la transaction
- L'`instance_ata` doit déjà exister (créée par `AllowMint` pour ce mint)
