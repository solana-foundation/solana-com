---
title: RemoveOperator
description: Révoque un opérateur en fermant son PDA Opérateur
---

Révoque un opérateur en fermant son PDA `Operator`. Le portefeuille révoqué ne peut plus
appeler `ReleaseFunds` ni `ResetSmtRoot`.

## Comptes

| Compte                          | Modifiable | Signataire | Description                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | Payeur des frais                                 |
| `admin`                          |          | ✓      | Administrateur de l'instance                            |
| `instance`                       |          |        | PDA de l'instance                              |
| `operator`                       |          |        | Portefeuille opérateur à révoquer                 |
| `operator_pda`                   | ✓        |        | PDA Opérateur (fermé par cette instruction) |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | PDA d'autorité d'événement                       |
| `private_channel_escrow_program` |          |        | Programme d'entiercement                            |

Cette instruction ne prend aucun paramètre.

## Remarques importantes

- Ferme le `operator_pda` ; le portefeuille révoqué ne peut plus appeler
  `ReleaseFunds` ni `ResetSmtRoot`
- Toutes les transactions opérateur en cours échoueront avec `InvalidOperatorPda` après
  cet appel
- Émet un événement via le CPI `EmitEvent`
