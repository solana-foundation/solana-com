---
title: Retirer des fonds
description:
  Brûle les tokens côté canal pour initier un retrait vers l'escrow du mainnet Solana
---

Brûle le solde de tokens côté canal d'un utilisateur sur le Withdraw Program pour signaler un
retrait en attente ; un opérateur doit ensuite appeler `ReleaseFunds` sur le
Escrow Program pour finaliser le règlement.

## Comptes

| Compte                    | Inscriptible | Signataire | Description                                |
| -------------------------- | -------- | ------ | ------------------------------------------ |
| `user`                     |          | ✓      | Propriétaire du token initiant le retrait      |
| `mint`                     | ✓        |        | Mint du token SPL (utilisé pour le burn)            |
| `token_account`            | ✓        |        | token account côté canal de l'utilisateur (source) |
| `token_program`            |          |        | SPL Token Program                          |
| `associated_token_program` |          |        | Associated Token Program                   |

## Paramètres

| Paramètre     | Type             | Description                                                          |
| ------------- | ---------------- | -------------------------------------------------------------------- |
| `amount`      | `u64`            | Montant de tokens à retirer, dans la plus petite unité du token           |
| `destination` | `Option<Pubkey>` | Portefeuille cible sur le Mainnet ; si `None`, correspond par défaut au portefeuille du signataire |

## Retours

Retourne un `TransactionBuilder` pouvant être utilisé pour construire et envoyer la
transaction.

## Exemple

```typescript
import { getWithdrawFundsInstruction } from "../private-channel-withdraw-program/clients/typescript/src/generated";

const withdrawIx = getWithdrawFundsInstruction({
  user: userSigner,
  mint: mintAddress,
  tokenAccount: channelTokenAccount,
  tokenProgram: TOKEN_PROGRAM_ID,
  associatedTokenProgram: ASSOCIATED_TOKEN_PROGRAM_ID,
  amount: 1_000_000n,
  destination: null // null = release to signer's Mainnet wallet
});
```

## Remarques importantes

- Cette instruction se trouve sur le **Withdraw Program**
  (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi` devnet), et non sur le Escrow
  Program
- Le burn de tokens côté canal ne libère **pas** automatiquement les fonds sur
  le Mainnet ; un opérateur doit ensuite appeler `ReleaseFunds` sur le Escrow
  Program avec une preuve d'exclusion SMT valide
- L'erreur `ZeroAmount` est levée si `amount` vaut 0
- Si `destination` est `None`, l'appel `ReleaseFunds` de l'opérateur libérera
  les fonds vers le portefeuille du signataire

Pour la référence complète des codes d'erreur des deux programmes, voir
[Instructions -> Error Codes](/docs/tools/private-channels/instructions#error-codes).
