title: AddOperator
description: Provisionne un nouvel opérateur en créant son PDA Operator
---

Provisionne un nouvel opérateur en créant son PDA `Operator`. Après cet appel, le
portefeuille `operator` peut appeler `ReleaseFunds` et `ResetSmtRoot`.

## Comptes

| Compte                          | Modifiable | Signataire | Description                                                         |
| -------------------------------- | -------- | ------ | ------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Payeur des frais                                                           |
| `admin`                          |          | ✓      | Administrateur de l'instance                                                      |
| `instance`                       |          |        | PDA de l'instance                                                        |
| `operator`                       |          |        | Portefeuille opérateur à provisionner                                        |
| `operator_pda`                   | ✓        |        | PDA de l'opérateur — dérivé automatiquement depuis `["operator", instance, operator]` |
| `system_program`                 |          |        | System Program                                                      |
| `event_authority`                |          |        | PDA de l'autorité d'événement                                                 |
| `private_channel_escrow_program` |          |        | Programme d'escrow                                                      |

## Paramètres

| Paramètre | Type | Description                                                                               |
| --------- | ---- | ----------------------------------------------------------------------------------------- |
| `bump`    | `u8` | bump seed pour le `operator_pda`. Optionnel : le client `Async` le dérive automatiquement s'il est omis |

> L'IDL contient un argument `discriminator: u8` (valeur `3`) qui est défini automatiquement
> par le client généré et ne doit pas être passé manuellement.

## Notes importantes

- Utilisez `getAddOperatorInstructionAsync` ; il dérive automatiquement `bump` et
  `operator_pda` lorsqu'ils ne sont pas fournis. Une variante synchrone
  `getAddOperatorInstruction` existe également si vous avez déjà calculé `bump`
  vous-même
- Après cet appel, le portefeuille `operator` peut appeler `ReleaseFunds` et
  `ResetSmtRoot`
- Émet un événement via le CPI `EmitEvent`
