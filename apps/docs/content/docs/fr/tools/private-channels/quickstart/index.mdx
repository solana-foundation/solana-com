---
title: Démarrage rapide
description:
  Déposez, transférez et retirez des fonds sur le devnet Solana en moins de 30 minutes
---

Ce guide de démarrage rapide présente l'intégralité du flux Private Channels sur le devnet Solana :
configurez l'environnement client, déposez des tokens SPL dans l'escrow, envoyez un
transfert hors chaîne entre deux portefeuilles et retirez des fonds vers votre portefeuille
Solana.

À la fin, vous comprendrez l'intégralité du cycle dépôt -> transfert hors chaîne ->
retrait et disposerez d'un code TypeScript fonctionnel pour chaque étape.

<Callout type="info">
  Ce guide de démarrage rapide suppose qu'une instance Private Channels est déjà déployée et
  opérationnelle sur le devnet avec votre mint sur la liste d'autorisation. Si vous devez en déployer une
  d'abord, le [guide des opérateurs](/docs/tools/private-channels/operators) couvre
  la configuration complète ; prévoyez 30 à 60 minutes pour la compilation Docker initiale.
</Callout>

## Étapes

1. **[Installation](/docs/tools/private-channels/quickstart/installation)** -
   clonez le dépôt et générez les clients TypeScript (5 minutes)
2. **[Déposer des tokens](/docs/tools/private-channels/quickstart/deposit)** -
   déposez des tokens SPL dans l'escrow ; accordez ~15 secondes à l'indexeur pour
   créditer le solde de votre canal
3. **[Envoyer un transfert](/docs/tools/private-channels/quickstart/transfer)** -
   envoyez un transfert hors chaîne via la passerelle ; confirmation en moins d'une seconde,
   sans jamais toucher au Mainnet
4. **[Retirer des fonds](/docs/tools/private-channels/quickstart/withdraw)** - brûlez
   votre solde côté canal ; l'opérateur règle les fonds sur votre portefeuille Mainnet
   en quelques secondes
