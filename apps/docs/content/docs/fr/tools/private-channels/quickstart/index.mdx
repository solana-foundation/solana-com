---
title: Démarrage rapide
description:
  Déposez, transférez et retirez des fonds sur le devnet Solana en moins de 30 minutes
---

Ce guide de démarrage rapide présente le flux complet des Canaux Privés sur le devnet Solana :
configurer l'environnement client, déposer des tokens SPL dans l'escrow, envoyer un
transfert hors chaîne entre deux portefeuilles et retirer des fonds vers votre portefeuille
Solana.

À la fin, vous comprendrez le cycle complet dépôt -> transfert hors chaîne ->
retrait et disposerez d'un code TypeScript fonctionnel pour chaque étape.

<Callout type="info">
  Ce guide de démarrage rapide suppose qu'une instance de Canaux Privés est déjà déployée et
  en cours d'exécution sur le devnet avec votre mint sur la liste d'autorisation. Si vous devez d'abord en déployer une,
  le [guide des Opérateurs](/docs/tools/private-channels/operators) couvre
  la configuration complète ; prévoyez 30 à 60 minutes pour la compilation Docker initiale.
</Callout>

## Étapes

1. **[Installation](/docs/tools/private-channels/quickstart/installation)** -
   clonez le dépôt et générez les clients TypeScript (5 minutes)
2. **[Déposer des tokens](/docs/tools/private-channels/quickstart/deposit)** -
   déposez des tokens SPL dans l'escrow ; comptez ~15 secondes pour que l'indexeur
   crédite le solde de votre canal
3. **[Envoyer un transfert](/docs/tools/private-channels/quickstart/transfer)** -
   envoyez un transfert hors chaîne via la passerelle ; la confirmation prend moins d'une seconde
   et ne touche jamais le Mainnet
4. **[Retirer des fonds](/docs/tools/private-channels/quickstart/withdraw)** - brûlez
   le solde de votre côté du canal ; l'opérateur règle les fonds sur votre portefeuille Mainnet
   en quelques secondes
