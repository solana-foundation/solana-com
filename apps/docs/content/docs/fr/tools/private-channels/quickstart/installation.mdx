## Prérequis

- Rust 1.91+
- Solana CLI 3.1.13 (Agave) :
  `sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.13/install)"`
- Node.js 24.7.0+
- pnpm 10.15.1+ : `npm install -g pnpm@10.15.1`

## Cloner le dépôt

```bash
git clone https://github.com/solana-foundation/solana-private-channels.git
cd solana-private-channels
```

## Générer les clients TypeScript

Les clients TypeScript ne sont **pas** publiés sur npm. Ils doivent être générés à partir
de l'IDL à l'aide de Codama.

```bash
# Escrow program client
cd private-channel-escrow-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..

# Withdraw program client
cd private-channel-withdraw-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..
```

Les clients générés se trouvent dans :

- `private-channel-escrow-program/clients/typescript/src/generated/`
- `private-channel-withdraw-program/clients/typescript/src/generated/`

Importez depuis ces chemins locaux dans votre application ; il n'existe pas de
package `@private-channels/client` sur npm. Les exemples de code de cette section utilisent un
chemin relatif (`../private-channel-escrow-program/...`) qui suppose que votre code
se trouve à côté du dépôt cloné ; adaptez-le selon l'emplacement réel de vos
importations dans votre projet.
