**Private Channels est une couche d'entreprise pour les marchés de capitaux sur internet via
Solana.** Elle fournit une couche applicative configurable pour des transferts privés, instantanés et sans frais
au sein de canaux de paiement : les utilisateurs déposent des tokens SPL dans un programme d'entiercement on-chain,
effectuent des transactions off-chain via une passerelle, et règlent sur le Mainnet
via une preuve d'arbre de Merkle creux, offrant aux développeurs d'applications des transferts instantanés, sans frais et privés
sans quitter l'écosystème Solana.

### Pourquoi Private Channels ?

- **Transferts instantanés** : débit off-chain supérieur au TPS natif de Solana ;
  les transferts sont confirmés dès que le séquenceur les traite, et non lors de la confirmation d'un bloc
- **Zéro frais par transfert** : aucun coût de gas sur les transferts individuels dans le canal ; les utilisateurs
  ne paient que pour les dépôts et retraits on-chain
- **Confidentialité** : les transferts entre participants du canal ne sont pas enregistrés sur le
  Mainnet de Solana
- **Accès restreint** : le RBAC avec authentification JWT vous permet de contrôler qui peut
  envoyer et recevoir
- **Règlement sur le Mainnet** : les fonds sont toujours remboursables sur Solana via une preuve d'exclusion par arbre de Merkle creux, que le programme d'entiercement applique on-chain

Consultez la **[Vue d'ensemble](/docs/tools/private-channels/overview)** pour l'architecture complète,
le diagramme de flux de données et le modèle de sécurité.

## Démarrage rapide

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n, // 1 USDC
  recipient: null
});
// send via your preferred Solana client
```

Les clients TypeScript sont générés à partir de l'IDL ; voir Installation. Pour les
mints Token-2022, passez explicitement `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS`, car
la valeur par défaut est le Token Program SPL standard.

## Cas d'utilisation

- **Paiements bilatéraux institutionnels** - banques et institutions ayant besoin
  de flux USDC privés et à fort volume sans que chaque transfert apparaisse on-chain
- **Transferts applicatifs à haute fréquence** - jeux, fidélité et applications grand public
  nécessitant des transferts sub-seconde, sans frais et à grande échelle au-delà du TPS natif de Solana
- **Flux de tokens préservant la confidentialité** - tout cas d'usage où la confidentialité de la contrepartie et
  du montant est une exigence produit

**[Quand utiliser les transferts SPL natifs à la place](/docs/tools/private-channels/concepts/channels#when-to-use-private-channels)**
