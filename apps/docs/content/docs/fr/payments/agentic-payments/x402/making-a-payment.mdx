  Lancez un agent avec Pay et effectuez un paiement x402 V2 sur une API sandbox locale, sans transférer de fonds réels.
---

Utilisez [Pay](https://pay.sh) pour exécuter une API x402 V2 et donner à Claude Code un client HTTP
capable de gérer les paiements. L'API, le portefeuille du payeur et le règlement utilisent tous le
sandbox Solana : ce tutoriel ne nécessite donc ni compte ni fonds réels.

Vous avez besoin d'un terminal, de Pay et de Claude Code installés.

## 1. Installer Pay

Sur macOS, installez le binaire précompilé :

```bash
brew install pay
pay --version
```

Sur les autres plateformes, installez le package npm :

```bash
npm install --global @solana/pay
pay --version
```

## 2. Démarrer une API sandbox x402

Créez `x402-demo.yaml` :

```yaml filename=x402-demo.yaml
name: x402-demo
subdomain: x402-demo
title: "x402 Demo"
description: "Minimal x402 V2 sandbox endpoint."
category: devtools
version: v1
routing:
  type: respond
operator:
  currencies:
    usd: ["USDC"]
  network: "localnet"
  fee_payer: true
endpoints:
  - method: GET
    path: "report"
    description: "Return a sandbox report."
    metering:
      schemes: [x402-exact]
      dimensions:
        - direction: usage
          unit: requests
          scale: 1
          tiers:
            - price_usd: 0.001
```

Démarrez l'API et laissez-la en cours d'exécution :

```bash
pay --sandbox server start x402-demo.yaml --bind 127.0.0.1:1402
```

Le schéma `x402-exact` fait de ceci un endpoint exclusivement x402. Le mode sandbox crée
et alimente automatiquement des comptes temporaires d'opérateur et de payeur.

## 3. Lancer l'agent avec Pay

Dans un autre terminal, démarrez Claude Code en mode sandbox :

```bash
pay --sandbox claude
```

Pay associe ses outils MCP locaux à la session de l'agent. L'agent ne
reçoit aucune clé privée.

## 4. Effectuer une requête x402

Collez ce prompt dans l'agent :

```text
Use Pay to make exactly one sandbox x402 API request to
http://127.0.0.1:1402/report.

Before paying, show me the amount and ask for approval. Then return the API
result and payment receipt. Do not make any other paid requests.
```

La requête suit une boucle de paiement x402 V2 complète :

1. L'API renvoie `402 Payment Required` avec un défi `PAYMENT-REQUIRED`.
2. Pay valide les exigences x402 et affiche les conditions de paiement.
3. Après approbation, le portefeuille sandbox signe et Pay relance la requête avec
   `PAYMENT-SIGNATURE`.
4. L'API renvoie le résultat avec un reçu `PAYMENT-RESPONSE`.

Aucun fonds réel n'est transféré. Refuser l'approbation interrompt la requête.

Poursuivez avec [x402 sur Solana](/docs/payments/agentic-payments/x402) pour créer un
client x402 V2 et un serveur de ressources, ou
[devenez un facilitateur x402](/docs/tools/x402-facilitator).
