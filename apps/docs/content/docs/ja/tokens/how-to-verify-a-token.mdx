# トークンを認証してSolana Explorerに表示させる方法

トークン作成者からよくある質問があります：_「Solana Explorerで検索してもトークンが表示されないのはなぜですか？認証を受けるにはどうすればよいですか？」_

簡単に答えると：Solana Explorer は独自の単一認証プロセスを運営していません。代わりに、**複数の独立した認証プロバイダーを集約**しています。
トークンがこれらのプロバイダーの**いずれか一つ**で認証されると、Explorerの検索結果に表示され、認証情報が表示されます。

このガイドでは、各プロバイダーの説明、「認証済み」が意味すること（および意味しないこと）、そしてトークンを認証する方法を解説します。

## 「認証済み」が意味すること（と意味しないこと）

認証は、特定の名前、シンボル、およびミントアドレスに対してトークンが**正規の／正しいトークン**であることを確認します。Solana上では誰でも任意の名前でトークンをミントできるため、なりすましや重複トークンを避けるのに役立ちます。

認証はプロジェクトの**推薦ではなく**、トークンの価値、安全性、または正当性の**保証でもありません**。常にご自身で調査を行ってください。

## Solana Explorerの認証プロバイダー

Solana Explorerは以下の独立した認証機関を確認しています。これらのいずれか（RugCheckは自動；それ以外は手動での対応が必要）に認証されると、トークンがExplorerの検索に表示されます。

### 1. RugCheck（自動）

[RugCheck](https://rugcheck.xyz)は自動化されたオンチェーン分析を実行し、トークンを自動的に追跡します。自動処理のため、通常は何も提出する必要はありません。RugCheckはオンチェーンのリスクシグナル（ミント／フリーズ権限、ホルダー分布、流動性など）を評価し、独自にトークンを追跡します。

一部のステーブルコインには特別な対応があり、プロジェクトはRugCheckチームに直接連絡して適切な処理を依頼できます。

トークンページの例：
[`rugcheck.xyz/tokens/<mint>`](https://rugcheck.xyz/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 2. Jupiter

[Jupiter](https://jup.ag)は、Solanaエコシステム全体で広く統合されている認証済みトークンリスト（VRFD）を管理しています。DEX、ウォレット、スクリーナーなどで利用されており、認証済みトークンはJupiterのプロダクトおよびパートナープラットフォームでグリーンのチェックマークを受け取ります。

認証を受けるには、トークンをレビュー用に提出してください：

- [verified.jup.ag/tokens](https://verified.jup.ag/tokens) から提出する
- 誰でもトークンを提出できます（プロジェクトチームに限らない）
- プロジェクトのXアカウントを任意で連携し、トークンのミントアドレスを特定のアカウントにリンクすることができます
- Jupiterは単一の指標ではなく、流動性、メタデータ標準への準拠、その他のシグナルを総合的にレビューします

トークンページの例：
[`jup.ag/tokens/<mint>`](https://jup.ag/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 3. CoinGecko

[CoinGecko](https://www.coingecko.com)の認証により、トークンが市場データとともにリストされます。CoinGeckoで認証する際は、ダウンストリームの統合が正しく価格を解決できるよう、トークンの**ミントアドレス**（CoinGeckoのフォームでは「コントラクトアドレス」と表示）を必ず含めてください。

公式のCoinGeckoリスティング／更新ガイドに従ってください：

- [CoinGeckoのリスティング＆更新リクエストに関する認証ガイド](https://support.coingecko.com/hc/en-us/articles/23725417857817-Verification-Guide-for-Listing-Update-Requests-on-CoinGecko)

コインページの例：
[`coingecko.com/en/coins/<token>`](https://www.coingecko.com/en/coins/usdc)

### 4. Solflare

[Solflare](https://solflare.com)はSolana Explorerの認証フレームワークにおける独立したvalidatorです。実際には、SolflareのアプリはJupiterアグリゲーターを利用しているため、トークンリストの基準はJupiterと大きく重なっています。新しいトークンが表示されるためには、通常以下が必要です：

- Metaplex Token Metadataスタンダードに準拠したメタデータ（名前、シンボル、ロゴURI）を持つ、Solanaブロックチェーン上の有効なトークンであること
- 取引および評価が可能な十分な流動性（最低USD相当額のトークンが取引可能な状態）があること
- 一般的なスワップに対して、価格インパクトが許容範囲内に収まっていること

この重複があるため、Jupiterの認証を完了したトークンは、別途提出することなくSolflareでも対象となることがほとんどです。そのため、通常Solflareを追加の手動ステップとして扱う必要はありません。基準を満たすと、トークンは通常数分以内に表示されます。詳細はこちら：

- [Solflareでトークンが見つからない場合](https://help.solflare.com/en/articles/9260147-i-cannot-find-a-token-in-solflare)

トークンページの例：
[`solflare.com/prices/<name>/<mint>`](https://www.solflare.com/prices/usd-coin/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/)

### 5. Bluprynt（強化KYC）

[Bluprynt](https://app.bluprynt.com/register/account)は、KYCプロトコルを用いた強化された認証パスを提供しています。これはより厳格な本人確認に基づくプロセスであり、より強力な認証シグナルを求めるプロジェクトに適しています。

- [Solana Explorer向けBluprynt オンボーディング](https://app.bluprynt.com/register/account)から登録する

認証済みアセットページの例：
[`verified.bluprynt.com/verified-assets/<mint>/solana`](https://verified.bluprynt.com/verified-assets/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/solana)

## すべてが組み合わさる仕組み

- **RugCheck**はオンチェーン分析によって自動的に処理されます。提出は不要です。
- **Jupiter、CoinGecko、Solflare、およびBluprynt**はそれぞれのプロセスを提出／完了する必要があります。
- これらのプロバイダーの**少なくとも一つ**でトークンが認証されると、**Solana Explorer**の検索に表示され、認証の詳細が表示されます。

トークンがまだExplorerの検索に表示されていない場合、JupiterへのVerification申請やCoinGeckoのリスティング完了が最も早い方法です。どちらもエコシステム全体で広く統合されています。

## 認証を成功させるための前提条件

プロバイダーに関わらず、以下のオンチェーンの基本事項が整っていると、認証が成功する可能性が大幅に高まります：

- **有効なメタデータ**：トークンにはMetaplex Token Metadataスタンダードに準拠したオンチェーンメタデータ（名前、シンボル、ロゴURI）が必要です。
- **流動性**：対応するDEXに十分な流動性を提供し、トークンが取引・評価できる状態にしてください。
- **正しいミントアドレス**：プロバイダーに提出する際は、常にトークンの**ミントアドレス**（一部のプロバイダーフォームでは「コントラクトアドレス」と表示）を使用してください。

## まとめ

Solana Explorerは複数の独立した認証機関を集約しています。**RugCheck**（自動）、**Jupiter**、**CoinGecko**、**Solflare**、および**Bluprynt**（KYC）です。これらのいずれか一つで認証されると、トークンがExplorerの検索で発見可能になります。認証は正規のトークンであることを確認するものであり、推薦ではないため、ユーザーは常にご自身で調査を行ってください。
