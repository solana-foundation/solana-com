## devnetに接続する

RPCのURLをdevnet用に切り替え、[フォーセット](/developers/cookbook/development/airdrops-and-faucets)から支払者にSOLを補充してください：

```ts
solanaRpc({
  rpcUrl: "https://api.devnet.solana.com",
  rpcSubscriptionsUrl: "wss://api.devnet.solana.com"
});
```

その他の設定は変わりません。同じ設定をメインネットで使用する前に、権限管理、コンプライアンス運用、およびアセットの監視を計画してください。
