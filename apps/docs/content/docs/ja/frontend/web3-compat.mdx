`@solana/web3.js`(レガシー)、`@solana/wallet-adapter-*`、または以前のframework-kitパッケージ(`@solana/client`、`@solana/react-hooks`、
`@solana/web3-compat`)をお使いの場合は、`@solana/kit`プラグインまたは
`@solana/web3.js` v3(以降)への移行をおすすめします。

このページでは、既にご存じの概念をKitの対応する機能に対応付けて紹介します。

## 概念の対応表

| web3.js(レガシー)/ wallet-adapter      | Kit                                                                  |
| -------------------------------------- | -------------------------------------------------------------------- |
| `new Connection(url)`                  | `createSolanaRpc(url)`、またはクライアント上の`.use(solanaRpc({ rpcUrl }))` |
| `PublicKey`                            | `Address` — `address("...")`で文字列を変換                    |
| `Keypair`                              | `generateKeyPairSigner()` または`@solana/kit-plugin-signer`プラグイン |
| `SystemProgram.transfer(...)`          | `@solana-program/system`の`getTransferSolInstruction(...)`       |
| `LAMPORTS_PER_SOL` 演算                | `@solana/kit`の`lamports(...)`                                   |
| `Transaction` / `VersionedTransaction` | トランザクションプランナーによって構築・パックされるトランザクションメッセージ     |
| `sendAndConfirmTransaction(...)`       | `client.sendTransaction([...])`（プランナーが署名・送信・確認を行う） |
| `@solana/wallet-adapter-*`             | `@solana/kit-plugin-wallet` + Wallet Standard検出              |

web3.js v3では、上記のクラスベースの名前(`Connection`、`Keypair`、
`Transaction`、`PublicKey`)がそのまま維持されており、Kit内部の薄いラッパーとして動作します。そのため、Kitの列は、v3でこれらのクラスが内部的に行っている処理も表しています。

## web3.jsからの移行

大規模な`@solana/web3.js`(レガシー)のコードベースを保守していて、Kitへの全面的な書き換えが現実的でない場合、web3.js v3が橋渡し役になります。
`@solana/web3.js@3`でインストールしてください。従来のクラスベースAPI(`Connection`、
`Keypair`、`Transaction`、`PublicKey`)を`@solana/kit`の内部機能の上に再構築したものです。
Kitをベースにしているため相互運用性が高く、`PublicKey`は主要なアドレス型であり、その`.toBase58()`はKitのブランド型`Address`文字列を返します。また、v3の`Keypair`はKitの`KeyPairSigner`を実装しているため、Kit APIやプラグイン、Codamaで生成されたクライアントにそのまま渡せます。

<Callout type="warn" title="v1トランザクションとweb3.js(レガシー)">
  web3.jsでv1トランザクションを送信する場合は、v3以降を使用する必要があります。
</Callout>

移行の手順については、公式の[web3.js v1 → v3 移行ガイド](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)をご覧ください。

## ウォレット

Kitはwallet-adapterを使用しません。`@solana/kit-plugin-wallet`はWallet
Standardウォレットを検出し、`client.wallet`と
[Reactフック](/docs/frontend/react-hooks)を通じて公開します。最新のウォレット（Phantom、Solflare、Backpack、その他）はWallet
Standardを通じて自身を通知するため、ウォレットごとのアダプターパッケージは不要です。

[@solana/connector](https://www.npmjs.com/package/@solana/connector)のような既成ツールを使用することもできます。このツールはKitのプリミティブを直接使用してウォレットに接続します。

<Callout type="info" title="まだwallet-adapterをお使いですか?">
  `@solana/wallet-adapter-*`で構築されたアプリを管理しており、まだ移行の準備ができていない場合は、[wallet-adapter
  リポジトリ](https://github.com/anza-xyz/wallet-adapter)がそのスタックのリファレンスとして引き続き利用できます。新しいものにはKitウォレットプラグインをお勧めします。
</Callout>
