自動インストーラーを使って、ローカルのSolana開発環境をセットアップしましょう。macOS、Linux、またはWSL経由のWindowsに、Rust、Solana CLI、Anchor CLI、Surfpool CLI、Node.js、Yarnをインストールします。

<Callout type="info" title="WindowsではWSLが必要です">
  Windows PowerShellで `wsl --install` を実行し、再起動を求められた場合はWindowsを再起動してから、Ubuntuターミナルで以下のインストールコマンドを実行してください。WSLの完全なセットアップ手順については、[手動インストールガイド](/docs/intro/installation/dependencies)をご覧ください。
</Callout>

## クイックインストール

1. macOS、Linux、またはWSLのターミナルでインストーラーを実行します。

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
```

実行前に[インストーラーのソースを確認](https://github.com/solana-developers/solana-install/blob/main/install.sh)することもできます。インストーラーは、サポートされているLinuxのパッケージマネージャーを検出し、必要なシステム依存関係を自動的にインストールします。

2. 新しいコマンドを使用できるように、ターミナルを再起動して `PATH` を反映させます。

3. すべてのツールを確認します。

```terminal
$ rustc --version
$ solana --version
$ anchor --version
$ surfpool --version
$ node --version
$ yarn --version
```

インストールが成功すると、次の形式で出力されます(バージョン番号はツールのリリースに応じて変わります)。

```txt title="Example output"
Installed Versions:
Rust: rustc x.y.z (...)
Solana CLI: solana-cli x.y.z (..., client:Agave)
Anchor CLI: anchor-cli x.y.z
Surfpool CLI: surfpool x.y.z
Node.js: vx.y.z
Yarn: x.y.z
```

<Callout type="warn" title="インストーラーが失敗した、またはコマンドが見つからない場合">
  [手動インストールガイド](/docs/intro/installation/dependencies)に従って、各依存関係を個別にインストールまたはトラブルシューティングしてください。
</Callout>
