このセクションでは、[Anchor CLI](https://www.anchor-lang.com/docs)の使用を開始するための一般的なコマンドと例を紹介します。

<Steps>
<Step>

### プロジェクトを初期化する

以下のコマンドを実行して、新しい Anchor プロジェクトを作成します。プロジェクト名のディレクトリが新規作成され、そのディレクトリを使って新しい Anchor プロジェクトが初期化されます。

```terminal
$ anchor init <project-name>
```

たとえば、以下のコマンドは `my-project` という名前のプロジェクトを作成します。`my-project` ディレクトリには、モジュール化された Rust プログラムと、LiteSVM を使用する Rust テストテンプレートが含まれます。

```terminal
$ anchor init my-project
```

代わりに TypeScript テストテンプレートを生成するには、明示的にテンプレートを指定します。たとえば、Mocha テンプレートを使用する場合は次のようにします。

```terminal
$ anchor init my-project --test-template mocha
```

TypeScript テストテンプレートを使用するには、Node.js と JavaScript パッケージマネージャーが必要です。

次に、プロジェクトのディレクトリに移動します。

```terminal
$ cd <project-name>
```

Anchor の[プロジェクトファイル構成](https://www.anchor-lang.com/docs/quickstart/local#project-file-structure)も参照してください。

</Step>
<Step>

### プログラムのビルド

プロジェクトをビルドするには、次のコマンドを実行します：

```terminal
$ anchor build
```

コンパイルされたプログラムは`/target/deploy`ディレクトリにあります。

<Callout type="warn" title="プラットフォームツールのインストールに失敗しました">
  ビルド時に platform-tools ディレクトリが無効であると報告された場合は、SBF ビルドツールを再インストールしてから、ビルドをもう一度実行してください。

```terminal
$ cargo build-sbf --force-tools-install
$ anchor build
```

</Callout>

</Step>
<Step>

### プログラムをデプロイする

プロジェクトをデプロイするには、次のコマンドを実行します：

```terminal
$ anchor deploy
```

このコマンドは、[`Anchor.toml`](https://www.anchor-lang.com/docs/references/anchor-toml)ファイルで指定された`cluster`にプログラムをデプロイします。

</Step>
<Step>

### プログラムをテストする

プロジェクトをテストするには、次のコマンドを実行します：

```terminal
$ anchor test
```

このコマンドは、プロジェクトのビルド、デプロイ、テストの実行を行います。

<Callout>
  `localnet`クラスターを使用する場合、Anchorは自動的にローカルvalidatorを起動し、プログラムをデプロイし、テストを実行してから、validatorを停止します。
</Callout>

<Callout type="warn" title="JavaScript テストランナーのエラー">

JavaScript または TypeScript のテストテンプレートを選択した場合、次のいずれかのエラーが表示されたときは、Node.js または設定済みのパッケージマネージャーがインストールされていない可能性があります。

```
Permission denied (os error 13)
```

```
No such file or directory (os error 2)
```

</Callout>

</Step>
</Steps>
