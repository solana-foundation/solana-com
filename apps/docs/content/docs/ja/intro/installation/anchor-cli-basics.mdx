このセクションでは、[Anchor CLI](https://www.anchor-lang.com/docs)の使用を開始するための一般的なコマンドと例を紹介します。

<Steps>
<Step>

### プロジェクトを初期化する

以下のコマンドを実行して、新しいAnchorプロジェクトを作成します。プロジェクト名のディレクトリが新規に作成され、そこで新しいAnchorプロジェクトが初期化されます。

```terminal
$ anchor init <project-name>
```

たとえば、以下のコマンドは `my-project` というプロジェクトを作成します。`my-project` ディレクトリには、モジュール化されたRustプログラムと、LiteSVMを使用するRustテストテンプレートが含まれます。

```terminal
$ anchor init my-project
```

代わりにTypeScriptのテストテンプレートを生成するには、明示的に指定します。たとえば、Mochaテンプレートを使用する場合は次のようにします。

```terminal
$ anchor init my-project --test-template mocha
```

TypeScriptのテストテンプレートには、Node.jsとJavaScriptパッケージマネージャーが必要です。

続いて、プロジェクトのディレクトリに移動します。

```terminal
$ cd <project-name>
```

Anchorの[プロジェクトファイル構造](https://www.anchor-lang.com/docs/quickstart/local#project-file-structure)も参照してください。

</Step>
<Step>

### プログラムのビルド

プロジェクトをビルドするには、次のコマンドを実行します：

```terminal
$ anchor build
```

コンパイルされたプログラムは`/target/deploy`ディレクトリにあります。

<Callout type="warn" title="プラットフォームツールのインストールに失敗しました">
  ビルド時に無効なplatform-toolsディレクトリが報告された場合は、SBFビルドツールを再インストールしてから、ビルドをやり直してください。

```terminal
$ cargo build-sbf --force-tools-install
$ anchor build
```

</Callout>

</Step>
<Step>

### プログラムをデプロイする

プロジェクトをデプロイするには、次のコマンドを実行します：

```terminal
$ anchor deploy
```

このコマンドは、[`Anchor.toml`](https://www.anchor-lang.com/docs/references/anchor-toml)ファイルで指定された`cluster`にプログラムをデプロイします。

</Step>
<Step>

### プログラムをテストする

プロジェクトをテストするには、次のコマンドを実行します：

```terminal
$ anchor test
```

このコマンドは、プロジェクトのビルド、デプロイ、テストの実行を行います。

<Callout>
  `localnet`クラスターを使用する場合、Anchorは自動的にローカルvalidatorを起動し、プログラムをデプロイし、テストを実行してから、validatorを停止します。
</Callout>

<Callout type="warn" title="JavaScriptテストランナーのエラー">

JavaScriptまたはTypeScriptのテストテンプレートを選択した場合、次のいずれかのエラーが表示されたときは、Node.jsまたは設定済みのパッケージマネージャーがインストールされていない可能性があります。

```
Permission denied (os error 13)
```

```
No such file or directory (os error 2)
```

</Callout>

</Step>
</Steps>
