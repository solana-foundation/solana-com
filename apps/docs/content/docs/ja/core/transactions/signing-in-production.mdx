トランザクションは、必要なすべての署名者からの有効な[署名](/docs/core/transactions/transaction-structure#signatures)が含まれている場合にのみ実行されます。ローカル開発では通常、その鍵を[`Keypair`](/developers/cookbook/wallets/create-keypair)として保持し、直接署名します。本番環境で重要になる問いは異なります。**秘密鍵はどこに置かれ、誰がその鍵による署名を承認できるのか?**

<Callout type="warn">
  秘密鍵をクライアントサイドのコードに埋め込んだり、フロントエンドにバンドルしたり、ソース管理にコミットしたりしないでください。鍵を入手した人は誰でも、そのアカウントの資金を完全に掌握できます。
</Callout>

## 署名方式

| 方式                  | 鍵の保管場所                                     | 署名者                                          | 最適な用途                                                      |
| ------------------------- | ------------------------------------------------------- | -------------------------------------------------- | ------------------------------------------------------------- |
| **ローカル keypair**         | マシン上のファイルまたは環境変数           | お客様のコードが直接署名                                | ローカル開発、テスト、CI                                  |
| **ブラウザウォレット**        | エンドユーザーのウォレット(例:Phantom、Solflare)          | エンドユーザー(トランザクションごと)                      | ユーザー自身がトランザクションに署名するフロントエンド dApp        |
| **クラウド KMS / HSM**       | ハードウェアベースの鍵管理サービス(AWS KMS、GCP KMS、Vault) | バックエンドがサービスに署名をリクエスト | バックエンドサービス、トレジャリー運用、規制対象環境 |
| **マネージド / MPC ウォレット** | プロバイダーのインフラ全体に分割、またはカストディされる   | ポリシーに従ってプロバイダーが共同署名     | 組み込みウォレット、承認ワークフロー、機関投資家向けカストディ   |

ローカル keypair は、生の鍵情報をアプリケーション内部に置く唯一の方式です。本番向けの方式はいずれも、鍵を専用のインフラに保持し、そのインフラに代理で署名を依頼します。

## バックエンドでの署名

サーバーが署名する必要がある場合(手数料の支払い、プログラムトランザクションの送信、トレジャリーの運用など)は、生の keypair ではなく、専用の鍵管理バックエンドを使用してください。Solana Foundation は、統合署名ライブラリ [Keychain](/docs/tools/keychain) を保守しています(Rust、TypeScript、Python、Go に対応)。上の表にあるすべてのバックエンド(Memory、HashiCorp Vault、AWS KMS、GCP KMS、Fireblocks、Privy、Turnkey、CDP、Crossmint、Dfns、Para、Openfort、Utila、Fordefi)に対して、単一の `SolanaSigner` インターフェースを提供します。

インターフェースがバックエンド間で共通のため、ローカルではインメモリの鍵で開発し、設定の変更だけで本番バックエンドに切り替えられ、アプリケーションコードを書き直す必要はありません(Crossmint のようにブロードキャストまで行うバックエンドは、代わりに署名・送信のパスで呼び出します)。Keychain は [`@solana/kit`](/docs/clients/official/javascript)、[Rust SDK](/docs/clients/official/rust)、`solders`(Python)、`solana-go` v2(Go)と互換性があります。
