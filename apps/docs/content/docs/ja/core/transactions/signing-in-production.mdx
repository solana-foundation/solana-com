トランザクションは、すべての必須署名者から有効な
[署名](/docs/core/transactions/transaction-structure#signatures)を受け取った場合にのみ実行されます。ローカル開発時は通常、
[`Keypair`](/developers/cookbook/wallets/create-keypair)として鍵を保持し、直接署名します。本番環境では、重要な問いは異なります：**秘密鍵はどこに保管され、誰がその鍵で署名を承認できるのか？**

<Callout type="warn">
  秘密鍵をクライアントサイドのコードに埋め込んだり、フロントエンドにバンドルしたり、
  ソース管理にコミットしたりしないでください。鍵を入手した者は誰でも、
  そのアカウントの資金を完全に制御できます。
</Callout>

## 署名のアプローチ

| アプローチ                  | 鍵の保管場所                                     | 署名者                                          | 最適な用途                                                      |
| ------------------------- | ------------------------------------------------------- | -------------------------------------------------- | ------------------------------------------------------------- |
| **ローカルkeypair**         | マシン上のファイルまたは環境変数           | コードが直接署名                                | ローカル開発、テスト、CI                                  |
| **ブラウザウォレット**        | エンドユーザーのウォレット（例：Phantom、Solflare）          | エンドユーザーがトランザクションごとに署名                      | ユーザーが自分のトランザクションに署名するフロントエンドdApp        |
| **クラウドKMS / HSM**       | ハードウェアバックの鍵サービス（AWS KMS、GCP KMS、Vault） | バックエンドがサービスに署名を要求 | バックエンドサービス、トレジャリー運用、規制環境 |
| **マネージド / MPCウォレット** | プロバイダーのインフラ全体で分割または管理   | プロバイダーがポリシーに従って共同署名     | 組み込みウォレット、承認ワークフロー、機関向けカストディ   |

ローカルkeypairは、生の鍵マテリアルをアプリケーション内に置く唯一のアプローチです。本番環境のすべてのアプローチでは、鍵を専用インフラに保管し、そのインフラに代わりに署名を依頼します。

## バックエンド署名

サーバーが署名を行う必要がある場合(手数料の支払い、プログラムトランザクションの送信、またはトレジャリーの運用など)は、生の
keypairではなく、専用の鍵管理バックエンドを使用してください。Solana Foundationは、[Keychain](/docs/tools/keychain)を管理しています。これは、
統合署名ライブラリ(Rust、TypeScript、Python、Go対応)で、上記の表にあるすべてのバックエンド(Memory、
HashiCorp Vault、AWS KMS、GCP KMS、Fireblocks、Privy、Turnkey、CDP、Crossmint、
Dfns、Para、Openfort、Utila、Fordefi)に対して、単一の`SolanaSigner`インターフェースを提供します。

このインターフェースはバックエンド間で共通であるため、ローカルではインメモリキーで開発し、
アプリケーションコードを書き換えることなく、設定の変更だけで本番用バックエンドに切り替えることができます(Crossmintのようにブロードキャストを代行するバックエンドは、代わりに署名と送信を一括で行うパスを通じて呼び出します)。Keychainは、
[`@solana/kit`](/docs/clients/official/javascript)、
[Rust SDK](/docs/clients/official/rust)、`solders`(Python)、および`solana-go` v2
(Go)と互換性があります。
