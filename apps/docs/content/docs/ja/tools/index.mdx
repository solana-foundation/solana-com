## ツール

<Cards>
  <Card title="Kora" href="/docs/tools/kora">
    Koraペイマスターを使用して、ガスレスおよびトークン決済のトランザクションフローを構築します。
  </Card>
  <Card title="Keychain" href="/docs/tools/keychain">
    ローカルキー、KMS、HSM、ウォレットバックエンドにわたって統一された署名インターフェースを使用します。
  </Card>
  <Card title="Commerce Kit" href="/docs/tools/commerce-kit">
    Solana決済コンポーネントとコマースフローをアプリに追加します。
  </Card>
  <Card title="Solana Pay" href="/docs/tools/solana-pay">
    Solana Payの送金およびトランザクションリクエストフローを実装します。
  </Card>
  <Card title="Attestations" href="/docs/tools/attestations">
    オンチェーンアカウントにリンクされたオフチェーンデータの資格情報、スキーマ、および
    attestation を作成します。
  </Card>
  <Card title="Private Channels" href="/docs/tools/private-channels">
    プライベートチャネルの製品資料と統合リソースを確認します。
  </Card>
  <Card title="Surfpool" href="/docs/tools/surfpool">
    ローカル開発、テスト、およびInfrastructure-as-Codeデプロイ向けの、solana-test-validatorのドロップイン代替ツールです。
  </Card>
  <Card title="LiteSVM" href="/docs/tools/litesvm">
    validator
    なしで、RustおよびTypeScriptを使用して、高速なインプロセスVMでSolanaプログラムをテストします。
  </Card>
  <Card title="アクションとBlinks" href="/docs/tools/actions">
    任意のSolanaトランザクションを、共有可能なメタデータ付きリンクに変換する。
  </Card>
  <Card title="AIツール" href="/docs/tools/ai">
    AIコーディングアシスタントおよびエージェントフレームワークをSolanaで活用する。
  </Card>
</Cards>
