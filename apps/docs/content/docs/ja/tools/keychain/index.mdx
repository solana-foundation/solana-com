**Solana Keychainは、複数のキー管理バックエンドにわたってSolanaトランザクションに署名するための統一インターフェースを提供します。**
インメモリキーを使用してローカルで開発し、署名コードを書き直すことなく、本番環境ではエンタープライズキー管理、クラウドHSM、またはマネージドウォレットサービスに切り替えることができます。

### なぜKeychainなのか？

- **単一インターフェース**: すべてのバックエンドに共通の `SolanaSigner`
  基本インターフェースに加え、バックエンドごとに1つの機能（署名、書き換えて署名、署名してブロードキャスト）を提供
- **バックエンドの切り替え**: コードではなく設定によってキー管理プロバイダーを変更できます。
  呼び出し側の変更が必要になるのは、新しいバックエンドの機能が異なる場合（CrossmintおよびFordefiのネイティブモード）のみです
- **必要な分だけ利用**: Rustのフィーチャーフラグ、バックエンドごとのnpmパッケージ、Pythonのextras、バックエンドごとのGoモジュールにより、必要なバックエンドだけを含められます
- **監査済み**: Rust、TypeScript、Python、Goは
  [OtterSec](https://osec.io)による監査を受けています（オプトインのLedgerバックエンドは対象外）。以前の[Accretion](https://accretion.xyz)による監査では、RustとTypeScriptが対象でした。
  詳細は
  [監査状況](https://github.com/solana-foundation/solana-keychain/blob/main/audits/AUDIT_STATUS.md)をご覧ください。

### アーキテクチャ

- **言語**: Rust、TypeScript、Python、Go（機能は同等。LedgerバックエンドはRust専用）
- **インターフェース**: `SolanaSigner` 基本インターフェース（`pubkey`、`sign_message`、`is_available`）に加え、
  バックエンドごとに `TransactionSigner`、`ModifyingSigner`、`SendingSigner` のいずれか1つ
- **バックエンド**: Memory、Vault、AWS KMS、GCP KMS、Privy、Turnkey、Fireblocks、
  CDP、Crossmint、Dfns、Openfort、Para、Utila、Fordefi、Ledger（Rustのみ、
  オプトイン、未監査）
- **互換性**: `@solana/kit` および `@solana/signers` 8.1以上（TypeScript）|
  `sdk-v2` / `sdk-v3` / `sdk-v4` フィーチャー経由で `solana-sdk` 2.x、3.x、4.x に対応
  （Rust。v1トランザクションには `sdk-v4` が必要）| `solders`（Python）| `solana-go` v2
  （Go）

## クイックスタート

### Rust

Rust クレートをインストールします：

```bash
cargo add solana-keychain
```

基本的な使い方：

```rust
use solana_keychain::{Signer, SolanaSigner};

// Create a signer from any backend
let signer = Signer::from_memory("base58_private_key")?;
let pubkey = signer.pubkey();

// Transaction signing is a capability; `tx` is a VersionedTransaction
if let Some(tx_signer) = signer.as_transaction_signer() {
    let result = tx_signer.sign_transaction(&mut tx).await?;
}

// Or let the umbrella route any backend shape and supply the RPC hop yourself
let signature = signer
    .sign_and_send(&mut tx, |encoded| async move { broadcast(encoded).await })
    .await?;
```

- [Rust ガイド](/docs/tools/keychain/getting-started/rust) - 完全なインストールとバックエンド設定
- [Crates.io](https://crates.io/crates/solana-keychain) - Rust クレート

### TypeScript

TypeScript パッケージをインストールします：

```bash
pnpm add @solana/keychain
```

基本的な使い方：

```typescript
import { createKeychainSigner } from "@solana/keychain";
import { signTransactionWithSigners } from "@solana/signers";

// Create any signer via the unified factory
const signer = await createKeychainSigner({
  backend: "vault",
  vaultAddr: "https://vault.example.com:8200",
  vaultToken: "hvs.xxxxx",
  keyName: "my-solana-key",
  publicKey: "base58_public_key"
});

// Sign an already-compiled transaction
const signedTx = await signTransactionWithSigners(
  [signer],
  compiledTransaction
);
```

- [TypeScript ガイド](/docs/tools/keychain/getting-started/typescript) -
  `@solana/keychain` パッケージ
- [npm パッケージ](https://www.npmjs.com/package/@solana/keychain) -
  npm パッケージ

[Kit](https://github.com/anza-xyz/kit) クライアントに Keychain シグナーを
`payer` または `identity` としてインストールするには、`@solana/keychain-kit-plugin` を使用します（Crossmint と
Fordefi のネイティブモードは、トランザクションを書き換えるため対象外です）。

### Python

パッケージをインストールします（重めのバックエンドはextrasとして提供されます。例:
`solana-keychain[aws-kms]`）:

```bash
pip install solana-keychain
```

基本的な使い方：

```python
import os

from solana_keychain import VaultSignerConfig, create_vault_signer

signer = await create_vault_signer(
    VaultSignerConfig(
        api_base_url="https://vault.example.com:8200",
        token=os.environ["VAULT_TOKEN"],
        key_name="my-solana-key",
        public_key="base58_public_key",
    )
)

# tx is a solders VersionedTransaction
result = await signer.sign_transaction(tx)
```

- [Python ガイド](/docs/tools/keychain/getting-started/python) - 完全なインストール、
  extras、バックエンド設定
- [PyPI](https://pypi.org/project/solana-keychain/) - Pythonパッケージ

### Go

各バックエンドは独立したGoモジュールなので、インポートしたバックエンドのみを取り込めます:

```bash
go get github.com/solana-foundation/solana-keychain/go/signers/vault/v2@latest
```

基本的な使い方：

```go
import "github.com/solana-foundation/solana-keychain/go/signers/vault/v2"

signer, err := vault.New(vault.Config{
	VaultAddr: "https://vault.example.com:8200",
	Token:     os.Getenv("VAULT_TOKEN"),
	KeyName:   "my-solana-key",
	Pubkey:    "base58_public_key",
})
if err != nil {
	return err
}

// tx is a *solana.Transaction from solana-go v2
res, err := signer.SignTransaction(ctx, tx)
```

- [Go ガイド](/docs/tools/keychain/getting-started/go) - モジュール、機能、
  バックエンド設定
- [pkg.go.dev](https://pkg.go.dev/github.com/solana-foundation/solana-keychain/go/core/v2) -
  Goリファレンス
