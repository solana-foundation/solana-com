title: プログラムのデプロイ

---

決済インフラの一部としてカスタムSolanaプログラムをデプロイする場合は、追加で考慮すべき点があります。

## デプロイ前の準備

- **Solana CLIのバージョン:** 必ず最新バージョンの[Solana CLI](https://solana.com/docs/intro/installation)を使用してください。
- **プログラムのkeypair:** プログラムのアドレスは、(同じkeypairを再利用する場合を除き) メインネットとdevnetで異なります。アプリケーション設定内の参照をすべて更新してください。プログラムのkeypairは安全な場所に保管してください (`cargo clean`を実行すると、プログラムのkeypairが削除される可能性が高い点にご注意ください)。
- **アカウントの初期化:** プログラムが管理者アカウント、PDA、その他のステートアカウントを必要とする場合は、ユーザーがアプリケーションを操作する前に、メインネット上でこれらを作成しておいてください。プログラムが必要とするAssociated Token Accounts (ATA) についても同様です。

## デプロイの手順

- **バッファアカウント:** 大規模なプログラムはバッファアカウント経由でデプロイされます。`solana program deploy`コマンドがこれを自動的に処理しますが、デプロイはアトミックではないため、中断された場合はバッファアカウントの復旧やクローズが必要になることがあります。
- **アップグレード権限:** [マルチシグ](https://docs.squads.so/main/basics/what-is-a-multisig)を作成し、それを[Solanaプログラムのアップグレード権限](https://docs.squads.so/main/navigating-your-squad/developers-assets/programs)として割り当ててください。
- **レント:** デプロイ用ウォレットに、すべてのprogram accountのレント免除の最低額をまかなえるだけのSOLがあることを確認してください。
- **検証:** [プログラムを検証](https://solana.com/docs/programs/verified-builds)し、Solanaのネットワークにデプロイする実行可能プログラムが、リポジトリ内のソースコードと一致していることを確認してください。
