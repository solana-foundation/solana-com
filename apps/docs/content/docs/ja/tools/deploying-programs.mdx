---
title: プログラムのデプロイ
description: メインネットでプログラムをデプロイするためのベストプラクティス
---

決済インフラの一部としてカスタム Solana プログラムをデプロイする場合は、
いくつか追加で考慮すべき点があります。

## デプロイ前の準備

- **Solana CLI のバージョン:** 必ず最新バージョンの
  [Solana CLI](https://solana.com/docs/intro/installation) を使用してください。
- **プログラムの keypair:** プログラムのアドレスは、メインネットと devnet で異なります(同じ keypair を再利用する場合を除く)。アプリケーションの設定内にあるすべての参照を更新してください。プログラムの keypair は安全な場所に保管してください(`cargo clean` を実行すると、プログラムの keypair が削除される可能性が高い点に注意してください)。
- **アカウントの初期化:** プログラムに管理者アカウント、PDA、その他のステートアカウントが必要な場合は、ユーザーがアプリケーションを利用する前に、メインネット上でこれらを作成しておいてください。プログラムが必要とする Associated Token Account(ATA)も同様です。

## デプロイの手順

- **バッファアカウント:** 大規模なプログラムはバッファアカウントを介してデプロイされます。`solana program deploy` コマンドがこれを自動的に処理しますが、デプロイはアトミックではない点に注意してください。中断された場合は、バッファアカウントの復旧またはクローズが必要になることがあります。
- **アップグレード権限:** [マルチシグ](https://docs.squads.so/main/basics/what-is-a-multisig)を作成し、
  それを
  [Solana プログラムのアップグレード権限](https://docs.squads.so/main/navigating-your-squad/developers-assets/programs)として割り当ててください。
- **レント:** デプロイ用ウォレットに、すべてのプログラムアカウントのレント免除に必要な最小額を
  カバーできるだけの SOL があることを確認してください。
- **検証:** プログラムを[検証](https://solana.com/docs/programs/verified-builds)して、
  Solana ネットワークにデプロイする実行可能プログラムが、リポジトリ内のソースコードと
  一致していることを確認してください。
