## クロックのセマンティクス

<Callout
  type="warn"
  title="タイムスタンプはミリ秒単位。クロックは秒単位で報告する"
>
  `surfnet_timeTravel` の `absoluteTimestamp` は、JavaScriptの `Date.now()` と同様に**ミリ秒**単位ですが、プログラムが読み取る `Clock` sysvar は**秒**単位で報告します。クロックから取得した値をそのままチートコードに渡すと、1970年代初頭の時刻になってしまいます。クロックは前にしか進まないため、その呼び出しは無視されるのではなく拒否されます。必ず1000を掛けてから渡してください。
</Callout>

クロックチートコードに対応するSDKレベルの同等機能については、[タイムトラベル](/docs/tools/surfpool/sdk/time-travel)を参照してください。
