# SolanaでのLLMとエージェントの活用

具体的なツールに入る前に、AI開発スタックの主要コンポーネントを理解しましょう：

## AIスタックの理解

1. **大規模言語モデル（LLM）**
   - 基盤となるAIモデル（GPT-4、Claude、Llamaなど）
   - 自然言語の処理と生成
   - 生の知性と推論能力の提供
   - 例：OpenAIのGPT-4、AnthropicのClaude、MetaのLlama

2. **エージェントフレームワーク（Elizaなど）**
   - LLMの上に構築され、自律エージェントを作成
   - エージェントのパーソナリティと動作を管理
   - メモリとコンテキストの処理
   - マルチプラットフォーム統合の提供
   - 例：Eliza、LangChain、AutoGPT、Vercel AI

3. **ドメイン特化型エージェントキット（Solana Agent Kitなど）**
   - 特定のユースケース向けに構築（例：ブロックチェーン操作）
   - 事前構築済みのツールと統合機能を提供
   - 技術的な複雑さを抽象化
   - すぐに使えるブロックチェーン機能
   - 例：Solana Agent Kit、GOAT Toolkit

次のようにイメージしてください：

- LLMは言語を理解・生成できる「頭脳」
- エージェントフレームワークはAIの動作を管理する「オペレーティングシステム」
- ドメイン特化型キットはAIに特定の能力を与える「アプリ」

# Solana向けAIエージェントの構築

このガイドでは以下の方法を説明します：

- SendAIのSolana Agent Kitを使った基本的なAIエージェントの構築

- オンチェーンAI統合オプションの理解

## SolanaのAIエージェント入門

SolanaのAIエージェントは、自然言語処理と機械学習を使ってブロックチェーンと対話できる自律プログラムです。以下のことが可能です：

- トランザクションの実行
- ブロックチェーンアクティビティの監視
- スマートコントラクトとのインタラクション
- ユーザーサポートの提供
- 複雑なワークフローの自動化

## 利用可能なフレームワーク

Solana上でAIエージェントを構築するためのフレームワークワークがいくつか利用できます：

1. **SendAIのSolana Agent Kit**

- Solana上でエージェントを構築するためのツールコレクション
- Eliza、Langchain、Vercel AI SDKと互換性あり
- Solana組み込みツールとユーティリティ
- 自然言語処理機能
- [Solana Agent Kit](https://github.com/sendaifun/solana-agent-kit)
- [ドキュメント](https://docs.solanaagentkit.xyz/)

2. **Eliza フレームワーク**

- データレイヤー、LLM、エージェントを組み合わせ、専用のSolanaプラグインを備えています
- 拡張可能なエージェントアーキテクチャ
- 既存プロジェクトへの簡単な統合が可能で、Twitter (X)、Telegram、Discordボットなどに活用できます
- [GitHubリポジトリ](https://github.com/elizaOS/eliza)

3. **GOAT Toolkit**

- 包括的な開発ツールキット
- クロスチェーン互換性
- [GitHubリポジトリ](https://github.com/goat-sdk/goat)

4. **Rig フレームワーク**

- ネイティブRust実装
- 高性能トレーディングボットに最適
- Listen.rsツールキットと組み合わせることで、Solana統合、トランザクション監視、Jitoバンドルを使ったトランザクション送信などが可能です
- [GitHubリポジトリ](https://github.com/0xPlaygrounds/rig)
- [Listen.rsリポジトリ](https://github.com/piotrostr/listen)

AIフレームワークを構築している場合は、PRを開いてフレームワークをリストに追加してください

### エージェントスクリプトの作成

以下の内容で`agent.ts`という新しいファイルを作成してください：

```typescript filename=agent.ts
import { SolanaAgentKit, createSolanaTools } from "solana-agent-kit";
import { HumanMessage } from "@langchain/core/messages";
import { ChatOpenAI } from "@langchain/openai";
import { createReactAgent } from "@langchain/langgraph/prebuilt";
import { MemorySaver } from "@langchain/langgraph";
import * as dotenv from "dotenv";
import bs58 from "bs58";
import * as readline from "readline";

dotenv.config();

async function initializeAgent() {
  const llm = new ChatOpenAI({
    modelName: "gpt-4-turbo-preview",
    temperature: 0.7
  });

  // Convert array string to actual array, then to Uint8Array, then to base58
  const privateKeyArray = JSON.parse(process.env.SOLANA_PRIVATE_KEY!);
  const privateKeyUint8 = new Uint8Array(privateKeyArray);
  const privateKeyBase58 = bs58.encode(privateKeyUint8);

  const solanaKit = new SolanaAgentKit(privateKeyBase58, process.env.RPC_URL!, {
    OPENAI_API_KEY: process.env.OPENAI_API_KEY!
  });

  const tools = createSolanaTools(solanaKit);
  const memory = new MemorySaver();

  return createReactAgent({
    llm,
    tools,
    checkpointSaver: memory
  });
}

async function runInteractiveChat() {
  const agent = await initializeAgent();
  const config = { configurable: { thread_id: "Solana Agent Kit!" } };
  const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout
  });

  // Clear console and start chat with a small delay
  setTimeout(() => {
    console.clear(); // Clear any initialization messages
    console.log("Chat with Solana Agent (type 'exit' to quit)");
    console.log("--------------------------------------------");
    askQuestion();
  }, 100);

  const askQuestion = () => {
    rl.question("You: ", async (input) => {
      if (input.toLowerCase() === "exit") {
        rl.close();
        return;
      }

      const stream = await agent.stream(
        {
          messages: [new HumanMessage(input)]
        },
        config
      );

      process.stdout.write("Agent: ");
      for await (const chunk of stream) {
        if ("agent" in chunk) {
          process.stdout.write(chunk.agent.messages[0].content);
        } else if ("tools" in chunk) {
          process.stdout.write(chunk.tools.messages[0].content);
        }
      }
      console.log("\n--------------------------------------------");

      askQuestion(); // Continue the conversation
    });
  };
}

runInteractiveChat().catch(console.error);
```

</Step>

## Eliza フレームワークでの構築

[ElizaOS](https://github.com/elizaOS/eliza)（旧称Ai16z）はAIフレームワークです。複数のアプリケーションを一つにまとめ、それらのインタラクションを整理します。以下を組み合わせています：

1. ユーザーを理解するための各種LLM
2. NFTのミントなど様々なアクションを持つブロックチェーンエージェント
3. Redis、PostgreSQL DB、ローカルストレージなどを使用してアクション間のキャラクター状態を保存するデータレイヤー
4. X、Telegram、Discordなど各種クライアント

これらすべてをまとめ、ユーザーと対話したり自律的に動作したりできる「キャラクター」を作成できます。キャラクターはJSONファイルで定義され、実行可能なアクション、使用するLLM、キャラクターの振る舞いを定義するプロンプトが指定されます。

```ts filename=encode58.ts
const bs58 = require('bs58');
console.log(bs58.encode(new Uint8Array([213,29,143,...])));
```

### キャラクター設定の作成

新しいキャラクターを作成するには、character.jsonファイルを作成する必要があります。Elizaプロジェクトのcharactersフォルダにプリセットキャラクターが用意されています。新しいキャラクターを作成するには、既存のキャラクターをコピーして変更するか、[CursorのComposer機能](https://docs.cursor.com/composer/overview)を使って作りたいキャラクターの種類を指示することができます。

```json filename=characters/sol.character.json
{
    "name": "Sol",
    "clients": ["twitter"],
    "modelProvider": "openai",
    "settings": {
        "voice": {
            "model": "en_US-neural"
        },
        ...
```

重要なのはclientsとmodelProviderの設定です。今回は`.env`ファイルでシークレットを設定したため、クライアントとしてtwitterを、モデルプロバイダーとしてopenaiを使用します。

### エージェントの実行

設定が完了したら、キャラクターを実行します：

```bash
pnpm start --character="characters/sol.character.json"
```

エージェントが起動し、Twitterで対話できるようになります。キャラクターは数時間ごとに自動的にツイートを投稿し、対話するとNFTのミントなどのSolanaアクションを実行できます。

[キャラクターの実際の動作](https://x.com/solanadevhelper/status/1882222232656847143)をこちらで確認できます。

以下のコマンドを使ってキャラクターとローカルで対話することもできます。ポート3000を解放し、`--host`フラグを付けてキャラクターを起動する必要があるかもしれません。

```bash
pnpm start --character="characters/sol.character.json" --host
pnpm start:client
```

クライアントが接続しない場合は、`--host`フラグを付けてエージェントを実行し、クライアント起動時にポート3000が使用されていないことを確認してください。

詳細については[Elizaの公式ドキュメント](https://elizaos.github.io/eliza/docs/quickstart/)を参照してください

## GOAT Toolkitの活用

[GOAT](https://github.com/goat-sdk/goat)はSolana Agent Kitと同様に、Solanaアクションやほかのチェーンもサポートするさまざまなブロックチェーンツールのコレクションです。Elizaフレームワークへの統合も可能で、多くのウォレット、フレームワーク、ブロックチェーンに対応しています。この[サンプル](https://github.com/goat-sdk/goat/tree/main/typescript/examples/by-use-case/solana-purchase-on-amazon)では、[Windsurf コードエディター](https://codeium.com/windsurf)内で[Crossmint](https://www.crossmint.com/)を直接使用してAmazonで商品を購入する方法を紹介しています。[デモ動画](https://x.com/windsurf_ai/status/1903118960633188485)もご覧いただけます。

## オンチェーンプログラムエージェント統合

Solanaプログラム内でエージェントの返信を使用したい場合は、返信データをプログラムが読み取れるアカウントに書き込むオラクルを使用する必要があります。質問に正解したユーザーにトークンを転送するLLMの例はこちらで確認できます：

[オンチェーンプログラムとLLMのインタラクション](https://github.com/GabrielePicco/super-smart-contracts)

これは、LLM（AI）オラクルと統合して「Mar1o」という名前のインタラクティブなトークン配布エージェントを作成するオンチェーンプログラムの例です。

### 主な機能

1. **AIエージェントとのインタラクション**
   - ユーザーはMar1oとチャットしてトークンを獲得できます
   - エージェントはユーザーのSolana知識を評価してトークン量を決定します
   - レスポンスは返信テキストとトークン量を含むJSON形式です

2. **トークン管理**
   - メタデータ付きのMAR1Oトークンを作成します
   - AIの返答に基づいて0〜10,000トークンをミントできます
   - トークン管理にPDAを使用します

### プログラムフローの説明

このプログラムの動作の仕組みは以下の通りです：

```rust
// Initialize the AI agent with personality
const AGENT_DESC: &str = "You are an AI agent called Mar1o which can dispense MAR1O tokens...";

// User interaction flow:
// 1. User sends message to agent
// 2. Oracle processes with LLM
// 3. Agent responds with JSON containing reply and amount
// 4. If amount > 0, tokens are minted to user

// Example response:
{
    "reply": "Great answer! Here's a reward.",
    "amount": 1000
}
```

これは、AIの機能とオンチェーンのトークンメカニズムを組み合わせてインタラクティブなブロックチェーン体験を生み出す方法を示しています。エージェントにトークンを転送させるよう説得を試みることができる[ライブデモ](https://mar1o.xyz/)はこちらです。

## アルゴリズム取引向け高度なRustエージェント

RustでエージェントをAIを書きたい場合は、[Rigフレームワーク](https://github.com/0xPlaygrounds/rig)と[Listen.rs](https://github.com/piotrostr/listen)ライブラリを使用できます。

この2つは相性が良く、Rigフレームワークを使えばLLMへの接続が簡単になる一方、Listen.rsツールキットはJitoバンドルを使用したトランザクションの監視・送信などのSolana統合機能を提供します。

## ベストプラクティス

- エージェントは秘密鍵を持っているため、ウォレット内の資金にアクセスできることを認識してください。たとえば、誰かがエージェントとチャットでき、転送アクションが設定されている場合、ユーザーが資金を転送させてしまう可能性があります。
- 有料の[RPCエンドポイント](https://solana.com/rpc)を使用してください。パブリックエンドポイントは通常レート制限がかかります
- エージェントの活動を監視し、悪意のある行動をしていないか、またはユーザーにそのような行動を誘導されていないかを確認してください
- ネットワークが混雑している場合でもエージェントのアクションが実行されるよう、優先手数料とトランザクションの再試行を実装してください
- 可能であれば、メインネットにデプロイする前にdevnetでテストしてください。多くのエージェントはRPC URLを入力として受け取るため、メインネットの準備が整うまでdevnetのものを使用できます。ただし、devnetではすべてのアクションが実行できるわけではありません。
- 独自のアクションを作成する際は、プログラムやAPIの変更によって失敗しているアクションをフレームワークが監視できるよう、インテグレーションテストを追加してください

## まとめ

SolanaのAIエージェントは、ブロックチェーンとの自動化およびインタラクションに新たな可能性をもたらします。すべてのインテグレーションがまだ完璧ではありませんが、急速に開発が進んでおり、コントリビューションの機会が多く、独自のインテグレーションを追加する柔軟性も非常に高いです。
