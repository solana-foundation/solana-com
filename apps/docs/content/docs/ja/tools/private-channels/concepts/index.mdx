これらのページでは、プライベートチャネルの内部的な仕組みについて説明します。既存のインスタンスに統合する開発者は、まず**チャネルライフサイクル**をお読みください。オペレーターおよびオペレーターツールを構築するすべての方は、**スパースマークルツリー**のリファレンスもお読みください。

- **[チャネルライフサイクル](/docs/tools/private-channels/concepts/channels)** -
  参加者、役割、および入金から出金までのフロー
- **[スパースマークルツリー](/docs/tools/private-channels/concepts/smt)** -
  二重支払いを防止するためにオンチェーンで出金証明を検証する方法
- **[認証と役割](/docs/tools/private-channels/concepts/auth)** - JWT
  認証、RBAC、およびウォレット検証
