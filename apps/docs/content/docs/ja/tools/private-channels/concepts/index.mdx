これらのページでは、プライベートチャネルの内部動作について説明します。既存のインスタンスに統合する開発者は、まず**チャネルライフサイクル**をお読みください。オペレーターおよびオペレーターツールを構築するすべての方は、**スパースマークルツリー**のリファレンスもご参照ください。

- **[チャネルライフサイクル](/docs/tools/private-channels/concepts/channels)** -
  参加者、役割、およびデポジットから引き出しまでのフロー
- **[スパースマークルツリー](/docs/tools/private-channels/concepts/smt)** -
  二重支払いを防ぐためにオンチェーンで引き出し証明を検証する仕組み
- **[認証とロール](/docs/tools/private-channels/concepts/auth)** - JWT
  認証、RBAC、およびウォレット検証
