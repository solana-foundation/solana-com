title: クイックスタート
description:
  30分以内にSolana devnetでの入金、送金、出金を体験する
---

このクイックスタートでは、Solana devnet上でのPrivate Channelsの一連のフローを解説します：
クライアント環境のセットアップ、エスクローへのSPLトークンの入金、2つのウォレット間での
オフチェーン送金、そしてSolanaウォレットへの出金。

このガイドを最後まで読むことで、入金 -> オフチェーン送金 ->
出金のサイクル全体を理解し、各ステップの動作するTypeScriptコードを手に入れられます。

<Callout type="info">
  このクイックスタートは、Private Channelsのインスタンスがすでにdevnetにデプロイされ、
  あなたのミントがアローリストに登録された状態で稼働していることを前提としています。先にデプロイが必要な場合は、
  [オペレーターガイド](/docs/tools/private-channels/operators)で
  セットアップの全手順を確認してください。初回のDockerビルドには30〜60分ほどかかります。
</Callout>

## ステップ

1. **[インストール](/docs/tools/private-channels/quickstart/installation)** -
   リポジトリをクローンしてTypeScriptクライアントを生成する（約5分）
2. **[トークンの入金](/docs/tools/private-channels/quickstart/deposit)** -
   SPLトークンをエスクローに入金する。インデクサーがチャンネル残高に反映するまで約15秒かかります
3. **[送金](/docs/tools/private-channels/quickstart/transfer)** -
   ゲートウェイ経由でオフチェーン送金を実行する。1秒未満で確定し、
   Mainnetには一切触れません
4. **[資金の出金](/docs/tools/private-channels/quickstart/withdraw)** - 
   チャンネル側の残高をバーンする。オペレーターが数秒以内にMainnetウォレットへ資金を決済します
