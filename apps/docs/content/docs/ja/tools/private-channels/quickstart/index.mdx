title: クイックスタート
description:
  30分以内にSolana devnetでの入金、送金、出金を体験する
---

このクイックスタートでは、Solana devnet上でのPrivate Channelsの一連のフローを順を追って説明します：
クライアント環境のセットアップ、エスクローへのSPLトークンの入金、2つのウォレット間でのオフチェーン送金、そしてSolanaウォレットへの出金。

このガイドを最後まで進めることで、入金 → オフチェーン送金 →
出金の一連のサイクルを理解し、各ステップで動作するTypeScriptコードを手に入れることができます。

<Callout type="info">
  このクイックスタートは、Private Channelsのインスタンスがすでにdevnetにデプロイされ、
  あなたのミントがアローリストに登録された状態で稼働していることを前提としています。先にデプロイが必要な場合は、[オペレーターガイド](/docs/tools/private-channels/operators)に
  完全なセットアップ手順が記載されています。初回のDockerビルドには30〜60分ほどかかる場合があります。
</Callout>

## 手順

1. **[インストール](/docs/tools/private-channels/quickstart/installation)** -
   リポジトリをクローンしてTypeScriptクライアントを生成する（5分）
2. **[トークンの入金](/docs/tools/private-channels/quickstart/deposit)** -
   SPLトークンをエスクローに入金する。インデクサーがチャンネル残高に反映するまで約15秒かかる場合があります
3. **[送金を実行する](/docs/tools/private-channels/quickstart/transfer)** -
   ゲートウェイを通じてオフチェーン送金を送信する。1秒未満で確定し、
   Mainnetには一切接触しません
4. **[資金の出金](/docs/tools/private-channels/quickstart/withdraw)** - チャンネル側の残高をバーンする。オペレーターが数秒以内にMainnetウォレットへ資金を決済します
