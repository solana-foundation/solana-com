title: CreateInstance

エスクローをアンカーする`Instance` PDAを作成します。他のいかなる操作よりも先に呼び出す必要があります。

## PDA Seeds

```
instance        -> ["instance", instance_seed: Pubkey]
allowed_mint    -> ["allowed_mint", instance_pda: Pubkey, mint: Pubkey]
operator        -> ["operator", instance_pda: Pubkey, operator: Pubkey]
event_authority -> ["event_authority"]
```

## アカウント

| アカウント                          | 書き込み可能 | 署名者 | 説明                                                                 |
| -------------------------------- | -------- | ------ | --------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | 手数料支払者およびrent支払者                                                    |
| `admin`                          |          | ✓      | インスタンスの初期管理者                                               |
| `instance_seed`                  |          | ✓      | PDA導出のみに使用される使い捨てのkeypair。そのpubkeyがseedになります |
| `instance`                       | ✓        |        | Instance PDA（`["instance", instance_seed.pubkey]`から導出）            |
| `system_program`                 |          |        | System Program                                                              |
| `event_authority`                |          |        | イベントオーソリティPDA                                                         |
| `private_channel_escrow_program` |          |        | エスクロープログラム                                                              |

## パラメータ

| パラメータ | 型 | 説明                                                                             |
| --------- | ---- | --------------------------------------------------------------------------------------- |
| `bump`    | `u8` | インスタンスPDAのbump seed。省略可能：`Async`クライアントは省略時に自動導出します |

> IDLには`discriminator: u8`引数（値`0`）が含まれており、生成されたクライアントによって自動設定されるため、手動で渡さないでください。

## 重要な注意事項

- `instance_seed`は使い捨てのkeypairであり、`Instance` PDAの導出のみに使用されます。そのpubkeyがseedになりますが、keypair自体は保存も再利用もされません。
- `getCreateInstanceInstructionAsync`を使用してください。`instance_seed`から`bump`と`instance`が未指定の場合に自動導出されます。`bump`を独自に渡すのは、`Pubkey::find_program_address(&[b"instance", instance_seed_pubkey.as_ref()], &PROGRAM_ID)`で既に計算済みの場合のみにしてください。
- `EmitEvent` CPIを通じてイベントを発行します
