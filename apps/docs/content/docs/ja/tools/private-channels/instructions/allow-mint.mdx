---
title: AllowMint
description:
  インスタンス上のSPLトークンミントを許可し、そのミント用のエスクローATAを作成します
---

インスタンス上のSPLトークンミントを許可し、そのミント用のエスクローのassociated
token accountを作成します。この呼び出し後、当該ミントへのデポジットが可能になります。

## アカウント

| アカウント                          | 書き込み可能 | 署名者 | 説明                                                                   |
| -------------------------------- | -------- | ------ | ----------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | 手数料支払者                                                                     |
| `admin`                          |          | ✓      | インスタンス管理者                                                                |
| `instance`                       |          |        | インスタンスPDA                                                                  |
| `mint`                           |          |        | 許可するSPLトークンミント                                                       |
| `allowed_mint`                   | ✓        |        | AllowedMint PDA（このinstructionにより作成）                                 |
| `instance_ata`                   | ✓        |        | このミント用エスクローのassociated token account（このinstructionにより作成） |
| `system_program`                 |          |        | System Program                                                                |
| `token_program`                  |          |        | SPL Token Program                                                             |
| `associated_token_program`       |          |        | Associated Token Program                                                      |
| `event_authority`                |          |        | イベント権限PDA                                                           |
| `private_channel_escrow_program` |          |        | エスクロープログラム                                                                |

## パラメータ

| パラメータ | 型 | 説明                                                                                   |
| --------- | ---- | --------------------------------------------------------------------------------------------- |
| `bump`    | `u8` | `allowed_mint` PDAのbump seed。省略可能：`Async`クライアントは省略時に自動導出します |

> IDLには`discriminator: u8`引数（値`1`）が含まれており、生成されたクライアントによって自動設定されます。手動で渡す必要はありません。

## 重要な注意事項

- `getAllowMintInstructionAsync`を使用してください。`bump`、`allowed_mint`、および`instance_ata`が指定されていない場合に自動導出します。`bump`を独自に渡す場合は、`Pubkey::find_program_address(&[b"allowed_mint", instance_pda, mint], &PROGRAM_ID)`で事前に計算した値のみを渡してください。
- このミント用エスクローのATA（`instance_ata`）も同時に作成します
- トランスファーフック拡張を持つミントは明示的にブロックされます。そのようなミントを許可しようとすると`TransferHookNotAllowed`がスローされます
- `EmitEvent` CPIを通じてイベントを発行します
