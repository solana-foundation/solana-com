---
title: AllowMint
description:
  インスタンス上でSPLトークンのミントを許可し、そのミント用のエスクローATAを作成します
---

インスタンス上でSPLトークンのミントを許可し、そのミント用のエスクローのassociated
token accountを作成します。この呼び出し後、このミントへの入金が可能になります。

## アカウント

| アカウント                          | 書き込み可能 | 署名者 | 説明                                                                   |
| -------------------------------- | -------- | ------ | ----------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | 手数料支払者                                                                     |
| `admin`                          |          | ✓      | インスタンス管理者                                                                |
| `instance`                       |          |        | インスタンスPDA                                                                  |
| `mint`                           |          |        | 許可するSPLトークンのミント                                                       |
| `allowed_mint`                   | ✓        |        | AllowedMint PDA（このinstructionsにより作成）                                 |
| `instance_ata`                   | ✓        |        | このミント用エスクローのassociated token account（このinstructionsにより作成） |
| `system_program`                 |          |        | System Program                                                                |
| `token_program`                  |          |        | SPL Token Program                                                             |
| `associated_token_program`       |          |        | Associated Token Program                                                      |
| `event_authority`                |          |        | イベント権限PDA                                                           |
| `private_channel_escrow_program` |          |        | エスクロープログラム                                                                |

## パラメータ

| パラメータ | 型 | 説明                                                                                   |
| --------- | ---- | --------------------------------------------------------------------------------------------- |
| `bump`    | `u8` | `allowed_mint` PDA用のbump seed。省略可能：省略した場合、`Async`クライアントが自動導出します |

> IDLには`discriminator: u8`引数（値`1`）が含まれており、生成されたクライアントによって自動設定されます。
> 手動で渡さないでください。

## 重要な注意事項

- `getAllowMintInstructionAsync`を使用してください。`bump`、`allowed_mint`、
  および`instance_ata`が指定されていない場合、自動的に導出します。独自の`bump`を渡すのは、
  `Pubkey::find_program_address(&[b"allowed_mint", instance_pda, mint], &PROGRAM_ID)`
  によってすでに計算済みの場合のみにしてください。
- `instance_ata`（このミント用エスクローのATA）も同時に作成します
- 転送フック拡張を持つミントは明示的にブロックされます。そのようなミントを許可しようとすると、`TransferHookNotAllowed`がスローされます
- `EmitEvent` CPIを通じてイベントを発行します
