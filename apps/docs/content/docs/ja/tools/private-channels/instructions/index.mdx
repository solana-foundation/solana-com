このセクションは、オンチェーンinstructionsのリファレンスです。ほとんどの開発者は、生成されたTypeScriptクライアントを通じてこれらのinstructionsを呼び出します。このセクションが必要になるのは、オペレータツールの構築、カスタム統合の実装、またはinstruction レベルのエラーのデバッグを行う場合のみです。

**エスクロープログラム** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) - デポジット、オペレータのプロビジョニング、およびメインネットの決済を管理します：

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) -
  エスクローインスタンスPDAを初期化する
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) - SPLトークンミントを
  ホワイトリストに追加する
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) - ミントを
  許可リストから削除する
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) -
  オペレータをプロビジョニングする
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) -
  オペレータの権限を取り消す
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) -
  管理者権限を移譲する
- [Deposit](/docs/tools/private-channels/instructions/deposit) - SPLトークンを
  エスクローに移動する
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) -
  オペレータがメインネットへの出金を決済する
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) -
  オペレータがスパースマークルツリーをローテーションする

**出金プログラム** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) - プライベートチャネルネットワーク上で動作します：

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) -
  チャネル側の残高をバーンして出金を開始する

## エラーコード

**エスクロープログラム - `PrivateChannelEscrowProgramError`**

| コード                                         | メッセージ                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | 無効なイベント権限が指定されました                 |
| `InvalidAta`                                 | 無効なATAが指定されました                             |
| `InvalidMint`                                | 無効なミントが指定されました                            |
| `InvalidInstanceId`                          | インスタンスIDが無効またはルールに適合していません    |
| `InvalidInstance`                            | 無効なインスタンスが指定されました                        |
| `InvalidAdmin`                               | 無効な管理者が指定されました                           |
| `TransferHookNotAllowed`                     | 転送フック拡張は許可されていません              |
| `InvalidOperatorPda`                         | 無効なオペレータPDAが指定されました                    |
| `InvalidTokenAccount`                        | 無効な token account が指定されました                   |
| `InvalidEscrowBalance`                       | エスクロー残高が無効です                           |
| `InvalidAllowedMint`                         | 許可されたミントが無効です                             |
| `InvalidSmtProof`                            | 無効なSMT証明が指定されました                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | 現在のツリーインデックスに対するトランザクションナンスが無効です |
| `UnexpectedTreeIndex`                        | SMTルートのリセットに対する現在のツリーインデックスが予期しない値です |

**出金プログラム - `PrivateChannelWithdrawProgramError`**

| コード          | メッセージ                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | 無効なミントが指定されました                       |
| `ZeroAmount`  | 出金額はゼロより大きい必要があります |
