このセクションはオンチェーンinstructionsリファレンスです。ほとんどの開発者は生成されたTypeScriptクライアントを通じてこれらのinstructionsを呼び出します。このリファレンスが必要なのは、オペレーターツールの構築、カスタム統合の実装、またはinstruction レベルのエラーのデバッグを行う場合に限られます。

**Escrowプログラム** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) - デポジット、オペレータープロビジョニング、およびメインネット決済を管理します：

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) -
  エスクローインスタンスPDAを初期化する
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) - SPLトークンミントをホワイトリストに追加する
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) - ミントをアローリストから削除する
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) -
  オペレーターをプロビジョニングする
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) -
  オペレーターの権限を剥奪する
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) -
  管理者権限を移譲する
- [Deposit](/docs/tools/private-channels/instructions/deposit) - SPLトークンをエスクローに移動する
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) -
  オペレーターがメインネットへの引き出しを決済する
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) -
  オペレーターがスパースマークルツリーをローテーションする

**Withdrawプログラム** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) - プライベートチャネルネットワーク上で動作します：

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) -
  引き出しを開始するためにチャネル側の残高をバーンする

## エラーコード

**Escrowプログラム - `PrivateChannelEscrowProgramError`**

| コード                                         | メッセージ                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | 無効なイベント権限が指定されました                 |
| `InvalidAta`                                 | 無効なATAが指定されました                             |
| `InvalidMint`                                | 無効なミントが指定されました                            |
| `InvalidInstanceId`                          | インスタンスIDが無効またはルールに準拠していません    |
| `InvalidInstance`                            | 無効なインスタンスが指定されました                        |
| `InvalidAdmin`                               | 無効な管理者が指定されました                           |
| `TransferHookNotAllowed`                     | 転送フック拡張は許可されていません              |
| `InvalidOperatorPda`                         | 無効なオペレーターPDAが指定されました                    |
| `InvalidTokenAccount`                        | 無効な token account が指定されました                   |
| `InvalidEscrowBalance`                       | エスクロー残高が無効です                           |
| `InvalidAllowedMint`                         | 許可されたミントが無効です                             |
| `InvalidSmtProof`                            | 無効なSMTプルーフが指定されました                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | 現在のツリーインデックスに対するトランザクションナンスが無効です |
| `UnexpectedTreeIndex`                        | SMTルートリセットに対して予期しない現在のツリーインデックスです |

**Withdrawプログラム - `PrivateChannelWithdrawProgramError`**

| コード          | メッセージ                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | 無効なミントが指定されました                       |
| `ZeroAmount`  | 引き出し金額はゼロより大きくなければなりません |
