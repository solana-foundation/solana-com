title: BlockMint

  インスタンスから以前に許可されたミントを削除し、そのミントへの新規デポジットを禁止します
---

インスタンスから以前に許可されたミントを削除し、そのミントへの新規デポジットを禁止します。
既存のデポジットには影響しません。

## アカウント

| アカウント                          | 書き込み可能 | 署名者 | 説明                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | 手数料支払者                                    |
| `admin`                          |          | ✓      | インスタンス管理者                               |
| `instance`                       |          |        | インスタンス PDA                                 |
| `mint`                           |          |        | ブロック対象の SPL トークンミント                      |
| `allowed_mint`                   | ✓        |        | AllowedMint PDA（この instructions によってクローズされます） |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | イベント認証 PDA                          |
| `private_channel_escrow_program` |          |        | エスクロープログラム                               |

この instructions はパラメーターを取りません。

## 重要な注意事項

- `allowed_mint` PDA をクローズします：このミントへの新規 `Deposit` 呼び出しは
  `InvalidAllowedMint` で失敗します
- このミントの既存のチャネル残高には影響しません
- `EmitEvent` CPI を介してイベントを発行します
