以前に許可されたミントをインスタンスから削除し、そのミントへの新規デポジットを
防止します。既存のデポジットには影響しません。

## アカウント

| アカウント                          | 書き込み可能 | 署名者 | 説明                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | 手数料支払者                                    |
| `admin`                          |          | ✓      | インスタンス管理者                               |
| `instance`                       |          |        | インスタンス PDA                                 |
| `mint`                           |          |        | ブロック対象の SPL トークンミント                      |
| `allowed_mint`                   | ✓        |        | AllowedMint PDA（この instructions によってクローズされます） |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | イベント認証 PDA                          |
| `private_channel_escrow_program` |          |        | エスクロープログラム                               |

この instructions にはパラメーターがありません。

## 重要事項

- `allowed_mint` PDA をクローズします。このミントに対する新規の `Deposit` 呼び出しは
  `InvalidAllowedMint` で失敗します
- このミントの既存チャネル残高には影響しません
- `EmitEvent` CPI 経由でイベントを発行します
