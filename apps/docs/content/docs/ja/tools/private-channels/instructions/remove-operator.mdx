---
title: RemoveOperator
description: オペレーターのPDAをクローズすることでオペレーターを失効させます
---

オペレーターの`Operator` PDAをクローズすることで、そのオペレーターを失効させます。失効したウォレットは`ReleaseFunds`や`ResetSmtRoot`を呼び出せなくなります。

## アカウント

| アカウント                          | 書き込み可能 | 署名者 | 説明                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | 手数料支払者                                 |
| `admin`                          |          | ✓      | インスタンス管理者                            |
| `instance`                       |          |        | インスタンスPDA                              |
| `operator`                       |          |        | 失効対象のオペレーターウォレット                 |
| `operator_pda`                   | ✓        |        | オペレーターPDA（このinstructionによってクローズされます） |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | イベントオーソリティPDA                       |
| `private_channel_escrow_program` |          |        | エスクロープログラム                            |

このinstructionはパラメーターを受け取りません。

## 重要な注意事項

- `operator_pda`をクローズします。失効したウォレットは`ReleaseFunds`や`ResetSmtRoot`を呼び出せなくなります
- この呼び出し以降、処理中のオペレータートランザクションは`InvalidOperatorPda`で失敗します
- `EmitEvent` CPIを通じてイベントを発行します
