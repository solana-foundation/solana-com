---
title: RemoveOperator
description: オペレーターのPDAを閉じることでオペレーターを失効させます
---

オペレーターの`Operator` PDAを閉じることで、そのオペレーターを失効させます。失効したウォレットは`ReleaseFunds`または`ResetSmtRoot`を呼び出すことができなくなります。

## アカウント

| アカウント                          | 書き込み可能 | 署名者 | 説明                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | 手数料支払者                                 |
| `admin`                          |          | ✓      | インスタンス管理者                            |
| `instance`                       |          |        | インスタンスPDA                              |
| `operator`                       |          |        | 失効させるオペレーターウォレット                 |
| `operator_pda`                   | ✓        |        | オペレーターPDA（このinstructionにより閉じられます） |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | イベント認可PDA                       |
| `private_channel_escrow_program` |          |        | エスクロープログラム                            |

このinstructionはパラメーターを取りません。

## 重要な注意事項

- `operator_pda`を閉じます。失効したウォレットは`ReleaseFunds`または`ResetSmtRoot`を呼び出すことができなくなります
- このコール後、処理中のオペレータートランザクションはすべて`InvalidOperatorPda`で失敗します
- `EmitEvent` CPIを通じてイベントを発行します
