新しいウォレットに管理者権限を移譲します。

## アカウント

| アカウント                          | 書き込み可能 | 署名者 | 説明                        |
| -------------------------------- | -------- | ------ | ---------------------------------- |
| `payer`                          | ✓        | ✓      | 手数料支払者                          |
| `current_admin`                  |          | ✓      | 現在の管理者（署名必須）          |
| `instance`                       | ✓        |        | インスタンスPDA（adminフィールドが更新されます） |
| `new_admin`                      |          | ✓      | 管理者権限を受け取るウォレット     |
| `event_authority`                |          |        | イベント権限PDA                |
| `private_channel_escrow_program` |          |        | エスクロープログラム                     |

このinstructionsにはパラメーターがありません。

## 重要な注意事項

- **元に戻せない操作**: 現在の管理者は、新しい管理者が再度`SetNewAdmin`を呼び出さない限り、役割を取り戻すことはできません
- 呼び出す前に対象アドレスを確認してください。取り消しはできません
- `EmitEvent` CPIを通じてイベントを発行します
