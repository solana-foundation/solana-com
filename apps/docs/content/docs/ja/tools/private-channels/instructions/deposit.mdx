---
title: デポジット
description:
  ユーザーのウォレットからPrivate ChannelsエスクローへSPLトークンを転送します
---

ユーザーのassociated token accountからエスクローの
associated token accountへSPLトークンを転送し、デポジットを行ったユーザーのチャンネル残高（または
オプションで指定した受取人の残高）に反映します。

## アカウント

| アカウント                          | 書き込み可能 | 署名者 | 説明                                          |
| -------------------------------- | -------- | ------ | ---------------------------------------------------- |
| `payer`                          | ✓        | ✓      | トランザクションの手数料支払者                        |
| `user`                           |          | ✓      | デポジットを行うトークンオーナー                       |
| `instance`                       |          |        | エスクローインスタンスのPDA                                  |
| `mint`                           |          |        | SPLトークンのミント                                       |
| `allowed_mint`                   |          |        | このインスタンスでミントが許可されていることを検証するPDA |
| `user_ata`                       | ✓        |        | ユーザーのassociated token account（送金元）             |
| `instance_ata`                   | ✓        |        | エスクローのassociated token account（送金先）      |
| `system_program`                 |          |        | System Program                                       |
| `token_program`                  |          |        | SPL Token Program                                    |
| `associated_token_program`       |          |        | Associated Token Program                             |
| `event_authority`                |          |        | `EmitEvent` CPI用のイベント権限PDA              |
| `private_channel_escrow_program` |          |        | エスクロープログラム（CPI用の自己参照）              |

## パラメータ

| パラメータ   | 型             | 説明                                                                           |
| ----------- | ---------------- | ------------------------------------------------------------------------------------- |
| `amount`    | `u64`            | デポジットするトークン量（トークンの最小単位で指定）                             |
| `recipient` | `Option<Pubkey>` | オプションのオンチェーン受取人。`None`の場合、デポジットを行ったユーザーのチャンネル残高に反映されます |

## 戻り値

トランザクションのビルドおよび送信に使用できる`TransactionBuilder`を返します。

## 使用例

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

// allowedMint and instanceAta are auto-derived from mint and instance
const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n,
  recipient: null
});
```

## 重要事項

- プログラムID: `9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`
- Token-2022のミントの場合、標準のSPL Token Programがデフォルトとなるため、`tokenProgram: TOKEN_2022_PROGRAM_ADDRESS`を明示的に指定してください
- `allowed_mint` PDAが存在している必要があります（`AllowMint`によって作成）。未登録のミントをデポジットしようとすると`InvalidAllowedMint`がスローされます
- `recipient`が`None`の場合、デポジットを行ったユーザーのチャンネル残高に反映されます。指定した場合は、指定されたウォレットの残高に反映されます
- `payer`と`user`の両方がトランザクションに署名する必要があります
- `instance_ata`はあらかじめ存在している必要があります（このミントのために`AllowMint`によって作成）
