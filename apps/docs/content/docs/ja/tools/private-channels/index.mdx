<Callout type="warning">
  Private Channelsはセキュリティ監査を受けておらず、十分なセキュリティレビューなしに実際の資金を使った本番環境での使用は推奨されません。
</Callout>

**Private ChannelsはSolana上のインターネット資本市場向けエンタープライズ層です。** 決済チャネル内でのプライベート・即時・手数料ゼロの転送に対応した設定可能なアプリ層を提供します。ユーザーはSPLトークンをオンチェーンのエスクロープログラムに預け入れ、ゲートウェイを通じてオフチェーンで取引し、Sparse Merkle Treeプルーフを使ってMainnetに決済します。これにより、アプリ開発者はSolanaエコシステムを離れることなく、即時・手数料ゼロ・プライベートな転送を実現できます。

### なぜPrivate Channelsなのか？

- **即時転送**: SolanaネイティブTPSを超えるオフチェーンスループット。転送はブロックの確認を待たず、シーケンサーが処理した時点で確定します
- **転送ごとの手数料ゼロ**: チャネル内の個別転送にガスコストは発生しません。ユーザーが負担するのはオンチェーンの入出金のみです
- **プライバシー**: チャネル参加者間の転送はSolana Mainnetに記録されません
- **許可制アクセス**: JWT認証を用いたRBACにより、送受信できるユーザーを制御できます
- **Mainnet決済**: 資金はSparse Merkle Tree除外プルーフによって常にSolanaへ償還可能であり、エスクロープログラムがオンチェーンで強制します

完全なアーキテクチャ、データフロー図、セキュリティモデルについては**[概要](/docs/tools/private-channels/overview)**をご覧ください。

## クイックスタート

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n, // 1 USDC
  recipient: null
});
// send via your preferred Solana client
```

TypeScriptクライアントはIDLから生成されます。詳細はインストールをご覧ください。Token-2022のmintを使用する場合は、標準のSPL Token Programがデフォルトになっているため、`tokenProgram: TOKEN_2022_PROGRAM_ADDRESS`を明示的に指定してください。

## ユースケース

- **機関間の二者間決済** - すべての転送をオンチェーンに記録せずに、大量のプライベートUSDCフローを必要とする銀行や金融機関向け
- **高頻度アプリ層転送** - ネイティブSolana TPSを超えるスケールで、サブ秒・手数料ゼロの転送を必要とするゲーム・ロイヤリティ・コンシューマーアプリ向け
- **プライバシー保護トークンフロー** - 取引相手と金額のプライバシーがプロダクト要件となるあらゆるユースケース向け

**[ネイティブSPL転送を使うべき場合](/docs/tools/private-channels/concepts/channels#when-to-use-private-channels)**
