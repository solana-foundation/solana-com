<Callout type="warning">
  Private Channelsはセキュリティ監査を受けておらず、十分なセキュリティレビューなしに実際の資金を使った本番環境での利用は推奨されません。
</Callout>

**Private ChannelsはSolana上のインターネット資本市場向けエンタープライズ層です。**
ペイメントチャネル内でのプライベート・即時・無料送金を実現する設定可能なアプリ層を提供します。ユーザーはSPLトークンをオンチェーンのエスクロープログラムにデポジットし、ゲートウェイを通じてオフチェーンで取引を行い、スパースマークルツリー証明によってメインネットに決済します。これにより、アプリ開発者はSolanaエコシステムを離れることなく、即時・無料・プライベートな送金を実現できます。

### なぜPrivate Channelsなのか？

- **即時送金**：SolanaネイティブTPSを超えるオフチェーンスループット。送金はブロックの確認を待たず、シーケンサーが処理した時点で確定します
- **送金手数料ゼロ**：チャネル内個別送金にガスコストなし。ユーザーはオンチェーンのデポジットと引き出しのみ費用が発生します
- **プライバシー**：チャネル参加者間の送金はSolanaメインネットに記録されません
- **許可制アクセス**：JWT認証を用いたRBACにより、送受信者を制御できます
- **メインネット決済**：資金はスパースマークルツリー排除証明によっていつでもSolanaに償還可能で、エスクロープログラムがオンチェーンで強制します

完全なアーキテクチャ、データフロー図、セキュリティモデルについては**[概要](/docs/tools/private-channels/overview)**をご覧ください。

## クイックスタート

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n, // 1 USDC
  recipient: null
});
// send via your preferred Solana client
```

TypeScriptクライアントはIDLから生成されます。インストールをご参照ください。Token-2022ミントの場合、標準のSPL Token Programがデフォルトとなるため、`tokenProgram: TOKEN_2022_PROGRAM_ADDRESS`を明示的に指定してください。

## ユースケース

- **機関間双方向決済** - 高ボリュームなプライベートUSDCフローを必要とし、すべての送金をオンチェーンに残したくない銀行や金融機関向け
- **高頻度アプリ層送金** - ネイティブSolana TPSを超えるスケールでサブ秒・無料送金を必要とするゲーム、ロイヤルティ、コンシューマーアプリ向け
- **プライバシー保護トークンフロー** - 取引相手と金額のプライバシーが製品要件となるあらゆるユースケース
