title: 時間とSysvar
description: GoにおけるClockの操作とsysvarへのアクセス

時間の操作およびシステム変数へのアクセスのためのメソッド群です。すべてのsysvarゲッターには対応するセッターがあり、各構造体はSolanaソースのGoミラーです。

## Clock操作

### WarpToSlot

```go
func (s *LiteSVM) WarpToSlot(slot uint64) error
```

内部Clockを特定のslotへ進めます。

```go
before, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("current slot: %d", before.Slot)

if err := svm.WarpToSlot(10_000_000); err != nil {
    t.Fatal(err)
}

after, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("new slot:     %d", after.Slot)
```

### Clock

```go
type Clock struct {
    Slot                uint64
    EpochStartTimestamp int64
    Epoch               uint64
    LeaderScheduleEpoch uint64
    UnixTimestamp       int64
}

func (s *LiteSVM) Clock() (Clock, error)
```

Clock sysvarを読み取ります。

```go
c, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("slot=%d epoch=%d unix=%d", c.Slot, c.Epoch, c.UnixTimestamp)
```

### SetClock

```go
func (s *LiteSVM) SetClock(c Clock) error
```

Clock sysvarを上書きします。`WarpToSlot`が更新しない`Epoch`や`UnixTimestamp`を制御する必要がある場合は、Clock sysvarを読み取り、フィールドを変更してから書き戻してください。

```go
c, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
c.Slot = 1_000
c.Epoch = 10
c.UnixTimestamp = 1_735_689_600
if err := svm.SetClock(c); err != nil {
    t.Fatal(err)
}
```

<Callout type="info">
  `WarpToSlot`は`Slot`のみを更新します。プログラムがClock sysvarから`Epoch`または`UnixTimestamp`を読み取る場合は`SetClock`を使用してください。
</Callout>

## Epoch Rewards

```go
type EpochRewards struct {
    DistributionStartingBlockHeight uint64
    NumPartitions                   uint64
    ParentBlockhash                 solana.Hash
    TotalPointsLo                   uint64 // low 64 bits of the u128 total_points
    TotalPointsHi                   uint64 // high 64 bits
    TotalRewards                    uint64
    DistributedRewards              uint64
    Active                          bool
}

func (s *LiteSVM) EpochRewards() (EpochRewards, error)
func (s *LiteSVM) SetEpochRewards(e EpochRewards) error
```

`total_points`はSolana側では`u128`ですが、`litesvm-go`はGoの呼び出し元がu128ライブラリを必要としないよう、上位・下位の両半分を明示的に公開しています。64ビットに収まる値の場合、`TotalPointsHi`は`0`、`TotalPointsLo`がその値になります。

### SlotHistory

`SlotHistory`は約128KBのビットベクタです。`litesvm-go`はスライスではなくハンドルとして公開しています。

```go
sh, err := litesvm.NewSlotHistory()
if err != nil {
    t.Fatal(err)
}
defer sh.Close()

sh.Add(42)

switch sh.Check(42) {
case litesvm.SlotHistoryFound:
    // ...
case litesvm.SlotHistoryNotFound:
    // ...
case litesvm.SlotHistoryTooOld:
    // ...
case litesvm.SlotHistoryFuture:
    // ...
}

if err := svm.SetSlotHistory(sh); err != nil {
    t.Fatal(err)
}
```

| メソッド                                           | 説明                                |
| ------------------------------------------------ | ------------------------------------------ |
| `litesvm.NewSlotHistory() (*SlotHistory, error)` | 空のハンドル                               |
| `sh.Add(slot uint64)`                            | slotを記録する                              |
| `sh.Check(slot uint64) SlotHistoryCheck`         | `Future` / `TooOld` / `Found` / `NotFound` |
| `sh.Oldest() uint64`                             | 追跡中の最古のslot                        |
| `sh.Newest() uint64`                             | 追跡中の最新のslot                        |
| `sh.NextSlot() uint64`                           | 次に記録するslot                        |
| `sh.SetNextSlot(slot uint64) error`              | 次slotマーカーを上書きする              |
| `sh.Close()`                                     | ハンドルを解放する                         |
| `svm.SlotHistory() (*SlotHistory, error)`        | 新しいハンドルに読み込む                   |
| `svm.SetSlotHistory(*SlotHistory) error`         | SVMにインストールする                         |

## 時間依存ロジックのテスト

単純なslotベースの進行には`WarpToSlot`を、完全な制御には`SetClock`を使用してください：

```go
func TestTimeLockedVault(t *testing.T) {
    svm, err := litesvm.New()
    if err != nil {
        t.Fatal(err)
    }
    defer svm.Close()

    const unlockSlot = uint64(10_000)

    // Setup: create the time-locked account ...

    // Test 1: Try to withdraw before unlock (should fail)
    before, err := svm.Clock()
    if err != nil {
        t.Fatal(err)
    }
    t.Logf("current slot: %d", before.Slot)
    // ... attempt withdrawal, expect failure ...

    // Warp time forward past unlock slot
    if err := svm.WarpToSlot(unlockSlot + 1); err != nil {
        t.Fatal(err)
    }

    // Test 2: Try to withdraw after unlock (should succeed)
    after, err := svm.Clock()
    if err != nil {
        t.Fatal(err)
    }
    t.Logf("new slot: %d", after.Slot)
    // ... attempt withdrawal, expect success ...
}
```
