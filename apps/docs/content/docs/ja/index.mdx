### Solanaを試す：2048をプレイ

Solana上で2048をプレイしましょう。すべての動きがトランザクションを送信します。「プレイ」をクリックして資金が入ったDevnetウォレットで開始し、矢印キーまたはモバイルでのスワイプを使用します。
