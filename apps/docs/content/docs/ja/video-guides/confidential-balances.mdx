Confidential Balancesは、token accountのアドレスは公開したまま、送金額と残高をSolana上で暗号化して保護するToken-2022拡張機能です。この動画では、その仕組みと、給与支払い、トレーディング、日常の決済においてなぜ重要なのかを解説します。[Confidential Balancesガイド](/docs/tokens/extensions/confidential-transfer)と併せてご覧ください。
