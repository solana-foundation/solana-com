## Solana Kit

`@solana/kit` は、Solana 上で開発するための推奨 TypeScript
SDK です。コンポーザブルなプラグインからクライアントを組み立て、必要に応じて React バインディングを追加し、呼び出すオンチェーンプログラム用に生成されたプログラムクライアントを取り込みます。

| パッケージ                   | 説明                                  | GitHub                                                                                 |
| ------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------- |
| @solana/kit               | コア SDK：RPC、トランザクション、コーデック、署名者 | [ソース](https://github.com/anza-xyz/kit)                                              |
| @solana/react             | React バインディング：`ClientProvider` とフック   | [ソース](https://github.com/anza-xyz/kit/tree/main/packages/react)                     |
| @solana/kit-plugin-rpc    | RPC 接続 + トランザクション送信         | [ソース](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-rpc)    |
| @solana/kit-plugin-signer | 手数料支払者、ID、署名者プラグイン      | [ソース](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-signer) |
| @solana/kit-plugin-wallet | Wallet Standard 接続 + React フック     | [ソース](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-wallet) |

## Solana Web3.js v3

`@solana/web3.js` v3 は web3.js の推奨バージョンです。従来のクラスベースAPI(`Connection`、`Keypair`、`Transaction`、`PublicKey`)を `@solana/kit` の内部実装の上に再構築しているため、Kit のプリミティブや上記のプログラムクライアントと連携して動作します。既存の web3.js アプリをアップグレードする場合や、クラスベースAPIを好む場合にご利用ください。

従来のSDKで同期処理だったほとんどのメソッド(`Keypair.generate()` や `transaction.sign()` など)は、非同期になりました。

```bash
npm install @solana/web3.js@3
```

| パッケージ         | 説明 | GitHub                                                        |
| --------------- | ----------- | ------------------------------------------------------------- |
| @solana/web3.js | コアSDK    | [ソース](https://github.com/solana-foundation/solana-web3.js) |

`@solana/spl-token` は `@solana/web3.js`(レガシー)に依存しており、v3 では動作しません。代わりに `@solana-program/token` または `@solana-program/token-2022` を使用してください。これらが生成する instructions と instruction plans は、v3 の `Transaction.add()` でそのまま利用できます。

- [web3.js v1 → v3 移行ガイド](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
- [spl-token 移行ガイド](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-spl-token-migration.md)

## Solana Web3.js(レガシー)

`@solana/web3.js`(レガシー、`1.x`)は、Solana 向けの最初の TypeScript SDK です。現在はメンテナンスモードであり、重大な修正のみが提供されます。既存のコードベースは[web3.js v3 にアップグレード](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)するか、[Kit に移行](/docs/frontend/web3-compat)できます。
