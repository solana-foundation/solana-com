[Pay](https://pay.sh)を使って、x402 V2 APIを実行し、Claude Codeに決済対応のHTTPクライアントを提供します。API、支払い用ウォレット、決済処理はすべてSolanaのサンドボックスを使用するため、このチュートリアルではアカウントも実際の資金も必要ありません。

ターミナル、Pay、Claude Codeがインストールされている必要があります。

## 1. Payをインストールする

macOSでは、ビルド済みのバイナリをインストールします。

```bash
brew install pay
pay --version
```

その他のプラットフォームでは、npmパッケージをインストールします。

```bash
npm install --global @solana/pay
pay --version
```

## 2. x402サンドボックスAPIを起動する

`x402-demo.yaml`を作成します。

```yaml filename=x402-demo.yaml
name: x402-demo
subdomain: x402-demo
title: "x402 Demo"
description: "Minimal x402 V2 sandbox endpoint."
category: devtools
version: v1
routing:
  type: respond
operator:
  currencies:
    usd: ["USDC"]
  network: "localnet"
  fee_payer: true
endpoints:
  - method: GET
    path: "report"
    description: "Return a sandbox report."
    metering:
      schemes: [x402-exact]
      dimensions:
        - direction: usage
          unit: requests
          scale: 1
          tiers:
            - price_usd: 0.001
```

APIを起動し、そのまま実行し続けます。

```bash
pay --sandbox server start x402-demo.yaml --bind 127.0.0.1:1402
```

`x402-exact`スキームにより、このエンドポイントはx402専用になります。サンドボックスモードでは、一時的なオペレーターアカウントと支払い用アカウントが自動的に作成され、資金が補充されます。

## 3. Payでエージェントを起動する

別のターミナルで、サンドボックスモードでClaude Codeを起動します。

```bash
pay --sandbox claude
```

Payは、ローカルのMCPツールをエージェントのセッションに接続します。エージェントが秘密鍵を受け取ることはありません。

## 4. x402リクエストを1回実行する

次のプロンプトをエージェントに貼り付けます。

```text
Use Pay to make exactly one sandbox x402 API request to
http://127.0.0.1:1402/report.

Before paying, show me the amount and ask for approval. Then return the API
result and payment receipt. Do not make any other paid requests.
```

このリクエストは、x402 V2決済の一連のループを1回分完結させます。

1. APIは`402 Payment Required`と`PAYMENT-REQUIRED`チャレンジを返します。
2. Payはx402の要件を検証し、支払い条件を表示します。
3. 承認後、サンドボックスウォレットが署名し、Payは`PAYMENT-SIGNATURE`を付けてリクエストを再試行します。
4. APIは結果と`PAYMENT-RESPONSE`レシートを返します。

実際の資金は動きません。承認を拒否すると、リクエストは中止されます。

次は[SolanaでのX402](/docs/payments/agentic-payments/x402)に進んでx402 V2のクライアントとリソースサーバーを構築するか、[x402ファシリテーターになる](/docs/tools/x402-facilitator)方法をご覧ください。
