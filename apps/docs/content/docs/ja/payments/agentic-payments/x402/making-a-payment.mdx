[Pay](https://pay.sh)を使用して、x402 V2 APIを実行し、Claude Codeにペイメント対応のHTTPクライアントを提供します。API、支払いウォレット、決済はすべてSolanaサンドボックスを使用するため、このチュートリアルではアカウントや実際の資金は必要ありません。

ターミナル、Pay、Claude Codeがインストールされている必要があります。

## 1. Payをインストールする

macOSでは、ビルド済みバイナリをインストールします:

```bash
brew install pay
pay --version
```

その他のプラットフォームでは、npmパッケージをインストールします:

```bash
npm install --global @solana/pay
pay --version
```

## 2. x402サンドボックスAPIを起動する

`x402-demo.yaml`を作成します:

```yaml filename=x402-demo.yaml
name: x402-demo
subdomain: x402-demo
title: "x402 Demo"
description: "Minimal x402 V2 sandbox endpoint."
category: devtools
version: v1
routing:
  type: respond
operator:
  currencies:
    usd: ["USDC"]
  network: "localnet"
  fee_payer: true
endpoints:
  - method: GET
    path: "report"
    description: "Return a sandbox report."
    metering:
      schemes: [x402-exact]
      dimensions:
        - direction: usage
          unit: requests
          scale: 1
          tiers:
            - price_usd: 0.001
```

APIを起動し、そのまま実行し続けます:

```bash
pay --sandbox server start x402-demo.yaml --bind 127.0.0.1:1402
```

`x402-exact`スキームにより、これはx402専用のエンドポイントになります。サンドボックスモードでは、一時的なオペレーターアカウントと支払いアカウントが自動的に作成され、資金が補充されます。

## 3. Payでエージェントを起動する

別のターミナルで、サンドボックスモードでClaude Codeを起動します:

```bash
pay --sandbox claude
```

Payは、ローカルのMCPツールをエージェントセッションに接続します。エージェントが秘密鍵を受け取ることはありません。

## 4. x402リクエストを1回実行する

次のプロンプトをエージェントに貼り付けます:

```text
Use Pay to make exactly one sandbox x402 API request to
http://127.0.0.1:1402/report.

Before paying, show me the amount and ask for approval. Then return the API
result and payment receipt. Do not make any other paid requests.
```

このリクエストは、x402 V2の完全なペイメントループを1回たどります:

1. APIは、`PAYMENT-REQUIRED`チャレンジとともに`402 Payment Required`を返します。
2. Payはx402の要件を検証し、支払い条件を表示します。
3. 承認後、サンドボックスウォレットが署名し、Payは`PAYMENT-SIGNATURE`を付けてリクエストを再試行します。
4. APIは、`PAYMENT-RESPONSE`レシートとともに結果を返します。

実際の資金は動きません。承認を拒否すると、リクエストは停止します。
