Tujuh konsep membentuk fondasi pengembangan Solana. Mulailah dengan Akun
dan Program, lalu ikuti bagaimana Instruksi menjadi Transaksi. PDA, CPI, dan
Biaya dibangun di atas model eksekusi tersebut.

<DocsDiagram
  src="/assets/docs/diagrams/core-concepts.svg"
  alt="Solana core concepts, ordered from accounts and programs through instructions and transactions, with PDAs, CPIs, and fees"
/>

<Cards>
  <Card title="Akun" href="/docs/core/accounts">
    Solana menyimpan semua status dalam akun, sebuah penyimpanan nilai-kunci yang diindeks
    dengan alamat 32-byte. Setiap akun memiliki lima field: lamports, data, owner, executable,
    dan rent_epoch.
  </Card>
  <Card title="Program" href="/docs/core/programs">
    Smart contract Solana, dikompilasi ke sBPF. Program bersifat stateless dan semua
    status yang dapat diubah berada di akun data terpisah yang diteruskan melalui instruksi.
  </Card>
  <Card title="Instruksi" href="/docs/core/instructions">
    Permintaan untuk mengeksekusi satu program, berisi ID program, daftar akun,
    dan byte data buram. Beberapa instruksi dapat disusun menjadi satu
    transaksi.
  </Card>
  <Card title="Transaksi" href="/docs/core/transactions">
    Unit eksekusi atomik di Solana. Berisi tanda tangan dan pesan
    (alamat akun, blockhash terbaru, dan instruksi yang telah dikompilasi). Maksimal 1232
    byte, atau 4096 dengan format v1.
  </Card>
  <Card title="Biaya" href="/docs/core/fees">
    Biaya dasar 5.000 lamports per tanda tangan, ditambah biaya prioritas opsional
    berdasarkan compute unit yang diminta. Maksimal 1,4 juta compute unit per transaksi.
  </Card>
  <Card title="Program Derived Addresses (PDA)" href="/docs/core/pda">
    Alamat deterministik yang diturunkan dari ID program dan seed. Hanya program
    pemilik yang dapat menandatangani atas nama PDA melalui invoke_signed.
  </Card>
  <Card title="Cross-Program Invocations (CPI)" href="/docs/core/cpi">
    Satu program memanggil program lain melalui invoke atau invoke_signed. Hak istimewa
    penanda tangan dan writable diteruskan ke callee. Kedalaman tumpukan instruksi maksimal 5 (tingkat
    atas ditambah CPI).
  </Card>
</Cards>
