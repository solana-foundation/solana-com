## Arahkan ke devnet

Ganti URL RPC dengan devnet dan danai payer dari
[faucet](/developers/cookbook/development/airdrops-and-faucets):

```ts
solanaRpc({
  rpcUrl: "https://api.devnet.solana.com",
  rpcSubscriptionsUrl: "wss://api.devnet.solana.com"
});
```

Semua lainnya tidak berubah. Sebelum menggunakan konfigurasi yang sama di mainnet,
rencanakan manajemen otoritas, operasi kepatuhan, dan pemantauan untuk aset tersebut.
