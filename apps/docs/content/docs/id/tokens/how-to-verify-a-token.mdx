# Cara memverifikasi token dan membuatnya muncul di Solana Explorer

Pertanyaan umum dari para pembuat token adalah: _"Mengapa token saya tidak muncul saat
saya mencarinya di Solana Explorer, dan bagaimana cara mendapatkan verifikasinya?"_

Jawaban singkatnya: Solana Explorer tidak menjalankan proses verifikasi tunggal
miliknya sendiri. Sebaliknya, ia **mengagregasi beberapa penyedia verifikasi independen**.
Jika token Anda diverifikasi melalui **salah satu** dari penyedia ini, token tersebut akan
muncul di hasil pencarian Explorer dan menampilkan informasi verifikasi.

Panduan ini menjelaskan setiap penyedia, apa yang "terverifikasi" berarti (dan tidak berarti), serta
bagaimana cara mendapatkan token Anda diverifikasi.

## Apa yang dimaksud dengan "terverifikasi" (dan apa yang tidak)

Verifikasi mengonfirmasi bahwa suatu token adalah **token kanonik / yang benar** untuk
nama, simbol, dan alamat mint tertentu. Ini membantu pengguna menghindari peniru dan
token duplikat, karena siapa pun dapat mencetak token dengan nama apa pun di Solana.

Verifikasi **bukan** merupakan dukungan terhadap suatu proyek, dan **bukan** merupakan
jaminan atas nilai, keamanan, atau legitimasi token. Selalu lakukan riset Anda sendiri.

## Penyedia verifikasi di balik Solana Explorer

Solana Explorer memeriksa verifikator independen berikut. Jika token Anda terdaftar di
salah satunya (RugCheck bersifat otomatis; yang lain memerlukan tindakan), token Anda
akan muncul di pencarian Explorer.

### 1. RugCheck (otomatis)

[RugCheck](https://rugcheck.xyz) melakukan analisis on-chain secara otomatis dan
secara otomatis melacak token. Karena bersifat otomatis, Anda umumnya tidak perlu
mengirimkan apa pun — RugCheck mengevaluasi sinyal risiko on-chain (otoritas mint/freeze,
distribusi pemegang, likuiditas, dll.) dan melacak token secara mandiri.

Ada penanganan khusus untuk stablecoin tertentu, di mana proyek dapat menghubungi
tim RugCheck secara langsung untuk penanganan yang sesuai.

Contoh halaman token:
[`rugcheck.xyz/tokens/<mint>`](https://rugcheck.xyz/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 2. Jupiter

[Jupiter](https://jup.ag) memelihara daftar token terverifikasi (VRFD) yang terintegrasi
secara luas di seluruh ekosistem Solana — DEX, dompet, dan screener. Token
terverifikasi mendapatkan tanda centang hijau di seluruh produk Jupiter dan platform
mitra.

Untuk mendapatkan verifikasi, ajukan token Anda untuk ditinjau:

- Ajukan di [verified.jup.ag/tokens](https://verified.jup.ag/tokens)
- Siapa pun dapat mengajukan token (tidak hanya tim proyek)
- Anda dapat secara opsional menghubungkan akun X proyek untuk mengaitkan alamat mint
  token ke akun tertentu
- Jupiter menjalankan tinjauan holistik (likuiditas, kepatuhan standar metadata, dan
  sinyal lainnya) daripada hanya memeriksa satu metrik

Contoh halaman token:
[`jup.ag/tokens/<mint>`](https://jup.ag/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 3. CoinGecko

Verifikasi [CoinGecko](https://www.coingecko.com) mendaftarkan token Anda beserta data pasar.
Saat memverifikasi dengan CoinGecko, pastikan untuk menyertakan **alamat mint** token
(formulir CoinGecko menyebutnya "contract address") agar integrasi hilir dapat
menyelesaikan harga dengan benar.

Ikuti panduan resmi listing/pembaruan CoinGecko:

- [Panduan verifikasi untuk permintaan listing & pembaruan di CoinGecko](https://support.coingecko.com/hc/en-us/articles/23725417857817-Verification-Guide-for-Listing-Update-Requests-on-CoinGecko)

Contoh halaman koin:
[`coingecko.com/en/coins/<token>`](https://www.coingecko.com/en/coins/usdc)

### 4. Solflare

[Solflare](https://solflare.com) adalah validator independen dalam kerangka verifikasi
Solana Explorer. Dalam praktiknya, kriteria listing token-nya sangat tumpang tindih
dengan Jupiter, karena daftar swap dalam aplikasi Solflare didukung oleh agregator
Jupiter. Agar token baru dapat muncul, biasanya token tersebut harus:

- Merupakan token yang valid di blockchain Solana dengan metadata yang mengikuti
  standar Metaplex Token Metadata
- Memiliki likuiditas yang cukup (nilai minimum USD dari token yang tersedia untuk
  diperdagangkan)
- Menjaga dampak harga dalam batas yang dapat diterima untuk swap tipikal

Karena tumpang tindih ini, token yang telah menyelesaikan verifikasi Jupiter sering kali
sudah memenuhi syarat di Solflare tanpa pengajuan terpisah — sehingga biasanya Anda
tidak perlu memperlakukan Solflare sebagai langkah manual tambahan. Setelah kriteria
terpenuhi, token biasanya muncul dalam beberapa menit. Lihat:

- [Saya tidak dapat menemukan token di Solflare](https://help.solflare.com/en/articles/9260147-i-cannot-find-a-token-in-solflare)

Contoh halaman token:
[`solflare.com/prices/<name>/<mint>`](https://www.solflare.com/prices/usd-coin/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/)

### 5. Bluprynt (KYC yang ditingkatkan)

[Bluprynt](https://app.bluprynt.com/register/account) menawarkan jalur verifikasi yang ditingkatkan
dengan protokol KYC. Ini adalah proses yang lebih ketat dan berbasis identitas, cocok
untuk proyek yang menginginkan sinyal verifikasi yang lebih kuat.

- Daftar melalui
  [Bluprynt onboarding untuk Solana Explorer](https://app.bluprynt.com/register/account)

Contoh halaman aset terverifikasi:
[`verified.bluprynt.com/verified-assets/<mint>/solana`](https://verified.bluprynt.com/verified-assets/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/solana)

## Bagaimana semuanya bersatu

- **RugCheck** berjalan secara otomatis melalui analisis on-chain — tidak perlu
  pengajuan.
- **Jupiter, CoinGecko, Solflare, dan Bluprynt** masing-masing mengharuskan Anda untuk
  mengajukan / menyelesaikan proses mereka masing-masing.
- Segera setelah token Anda diverifikasi oleh **setidaknya satu** dari penyedia ini,
  token akan muncul di pencarian **Solana Explorer** dan menampilkan detail verifikasi.

Jika token Anda belum muncul di pencarian Explorer, jalur tercepat biasanya adalah
mengajukan untuk verifikasi Jupiter dan/atau menyelesaikan listing CoinGecko,
karena keduanya terintegrasi secara luas di seluruh ekosistem.

## Prasyarat yang membantu verifikasi berhasil

Terlepas dari penyedianya, fondasi on-chain berikut membuat verifikasi jauh
lebih mungkin berhasil:

- **Metadata yang valid**: token Anda harus memiliki metadata on-chain yang mengikuti
  standar Metaplex Token Metadata (nama, simbol, URI logo).
- **Likuiditas**: sediakan likuiditas yang cukup di DEX yang didukung agar token dapat
  diperdagangkan dan dievaluasi.
- **Alamat mint yang benar**: setiap kali Anda mengajukan ke penyedia, selalu gunakan
  **alamat mint** token Anda (disebut "contract address" di beberapa formulir penyedia).

## Ringkasan

Solana Explorer mengagregasi beberapa verifikator independen — **RugCheck**
(otomatis), **Jupiter**, **CoinGecko**, **Solflare**, dan **Bluprynt** (KYC).
Verifikasi melalui salah satu dari mereka membuat token Anda dapat ditemukan di
pencarian Explorer. Verifikasi mengonfirmasi identitas token kanonik; ini bukan
dukungan, sehingga pengguna harus selalu melakukan riset mereka sendiri.
