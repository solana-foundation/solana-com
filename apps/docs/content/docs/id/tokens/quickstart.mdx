---
title: "Quickstart: buat token dengan CLI"
description:
  Create a token, open a token account, mint supply, and transfer tokens using
  the SPL Token CLI on devnet.
---

Quickstart ini memandu Anda melalui siklus hidup token secara lengkap menggunakan CLI _sh`spl-token`_. Anda akan membuat mint, membuat akun yang dapat menyimpan token, mencetak 100 token, dan mentransfer sebagian ke dompet lain.

Gunakan [Solana Playground](https://beta.solpg.io/) untuk menjalankan perintah di browser Anda, atau instal CLI secara lokal dengan `cargo install spl-token-cli`. Alamat dalam output Anda akan berbeda dari contoh di bawah ini.

## 1. Hubungkan ke devnet

Buat atau hubungkan dompet di Solana Playground, lalu pilih devnet dan minta SOL untuk deposit akun dan biaya transaksi:

```terminal
$ solana config set --url devnet
$ solana airdrop 2
```

Gunakan token devnet hanya untuk pengujian. Token ini tidak memiliki nilai finansial.

## 2. Buat token

Buat mint account yang mengidentifikasi token Anda:

```terminal
$ spl-token create-token
```

Salin alamat token dari output. Ini adalah alamat mint yang akan Anda gunakan dalam perintah-perintah selanjutnya. Mint baru dimulai dengan pasokan nol.

```terminal
$ spl-token supply <MINT_ADDRESS>
```

## 3. Buat token account

Dompet Anda memerlukan token account untuk mint ini sebelum dapat menyimpan saldo:

```terminal
$ spl-token create-account <MINT_ADDRESS>
```

Ini membuat [associated token account](/docs/tokens#associated-token-account) Anda, yang alamatnya diturunkan dari dompet dan mint Anda.

## 4. Cetak token

Cetak 100 token ke associated token account Anda:

```terminal
$ spl-token mint <MINT_ADDRESS> 100
$ spl-token balance <MINT_ADDRESS>
```

Otoritas mint harus menandatangani operasi ini. Pencetakan meningkatkan saldo token account Anda maupun total pasokan yang dicatat oleh mint.

## 5. Transfer token

Kirim 10 token ke dompet devnet lain. Opsi _sh`--fund-recipient`_ akan membuat associated token account penerima jika belum ada:

```terminal
$ spl-token transfer <MINT_ADDRESS> 10 <RECIPIENT_WALLET_ADDRESS> --fund-recipient
```

Transfer mengubah saldo pada token account pengirim dan penerima; transfer tidak mengubah total pasokan mint.

## Opsional: tambahkan metadata Token-2022

Untuk menyimpan nama, simbol, dan URI langsung pada mint Token-2022 baru, buat dengan ekstensi metadata yang diaktifkan:

```terminal
$ spl-token create-token \
  --program-id TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb \
  --enable-metadata
```

Kemudian gunakan alamat mint baru yang dicetak oleh perintah tersebut:

```terminal
$ spl-token initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  "EXAMPLE" \
  "https://example.com/token.json"
```

URI harus mengembalikan dokumen metadata JSON publik. Lihat [Token-2022 metadata](/docs/tokens/extensions/metadata) untuk model akun dan contoh kode.
