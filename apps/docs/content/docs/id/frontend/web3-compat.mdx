title: Migrasi ke Kit
description:
  Bagaimana konsep @solana/web3.js dan wallet-adapter dipetakan ke @solana/kit.
---

Jika Anda beralih dari `@solana/web3.js` (legacy), `@solana/wallet-adapter-*`,
atau paket framework-kit sebelumnya (`@solana/client`, `@solana/react-hooks`,
`@solana/web3-compat`), kami menyarankan Anda bermigrasi ke plugin `@solana/kit` atau
`@solana/web3.js` v3 (atau yang lebih baru).

Halaman ini memetakan konsep yang sudah Anda kenal ke padanannya di Kit.

## Pemetaan konsep

| web3.js (legacy) / wallet-adapter      | Kit                                                                  |
| -------------------------------------- | -------------------------------------------------------------------- |
| `new Connection(url)`                  | `createSolanaRpc(url)`, atau `.use(solanaRpc({ rpcUrl }))` pada klien |
| `PublicKey`                            | `Address` — konversi string dengan `address("...")`                    |
| `Keypair`                              | `generateKeyPairSigner()` atau plugin `@solana/kit-plugin-signer` |
| `SystemProgram.transfer(...)`          | `getTransferSolInstruction(...)` dari `@solana-program/system`       |
| `LAMPORTS_PER_SOL` math                | `lamports(...)` dari `@solana/kit`                                   |
| `Transaction` / `VersionedTransaction` | Pesan transaksi yang dibangun dan dikemas oleh perencana transaksi     |
| `sendAndConfirmTransaction(...)`       | `client.sendTransaction([...])` (perencana menandatangani, mengirim, dan mengonfirmasi) |
| `@solana/wallet-adapter-*`             | `@solana/kit-plugin-wallet` + penemuan Wallet Standard              |

web3.js v3 mempertahankan nama berbasis class di atas — `Connection`, `Keypair`,
`Transaction`, `PublicKey` — sebagai wrapper tipis di atas internal Kit, sehingga kolom
Kit juga menjelaskan apa yang dilakukan class-class tersebut di balik layar pada v3.

## Berasal dari web3.js?

Jika Anda memelihara codebase `@solana/web3.js` (legacy) yang besar dan penulisan ulang
sepenuhnya ke Kit tidak praktis, web3.js v3 adalah jembatannya. Instal dengan
`@solana/web3.js@3`. Library ini membangun ulang API klasik berbasis class — `Connection`,
`Keypair`, `Transaction`, `PublicKey` — di atas internal `@solana/kit`.
Karena berjalan di atas Kit, interoperabilitasnya sangat erat: `PublicKey` adalah tipe
alamat utama dan `.toBase58()`-nya mengembalikan string `Address` bermerek milik Kit, dan
`Keypair` v3 mengimplementasikan `KeyPairSigner` milik Kit, sehingga Anda dapat langsung meneruskannya ke
API Kit, plugin, dan klien yang dihasilkan Codama.

<Callout type="warn" title="Transaksi v1 dan web3.js (legacy)">
  Jika Anda mengirim transaksi v1 dengan web3.js, Anda harus menggunakan v3+.
</Callout>

Untuk proses migrasinya, lihat
[panduan migrasi web3.js v1 → v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md) resmi.

## Dompet

Kit tidak menggunakan wallet-adapter. `@solana/kit-plugin-wallet` menemukan
dompet Wallet Standard dan mengeksposnya melalui `client.wallet` dan
[React hooks](/docs/frontend/react-hooks). Dompet modern (Phantom, Solflare,
Backpack, dan lainnya) mengiklankan diri mereka melalui Wallet Standard,
sehingga tidak diperlukan paket adapter per-dompet.

Anda juga dapat menggunakan alat bawaan seperti
[@solana/connector](https://www.npmjs.com/package/@solana/connector), yang
menggunakan primitif Kit secara langsung untuk terhubung ke dompet.

<Callout type="info" title="Masih menggunakan wallet-adapter?">
  Jika Anda mengelola aplikasi yang dibangun di atas `@solana/wallet-adapter-*`
  dan belum siap untuk bermigrasi, [repositori wallet-adapter
](https://github.com/anza-xyz/wallet-adapter) tetap menjadi referensi untuk
  stack tersebut. Untuk proyek baru, gunakan plugin dompet Kit.
</Callout>
