Antarmuka baris perintah `solana` mengonfigurasi koneksi cluster, membaca
status jaringan, mengirim SOL, mengelola durable nonce, men-deploy program, dan mengoperasikan
akun stake dan vote.

Referensi ini mengikuti
[Agave v4.2.1](https://github.com/anza-xyz/agave/releases/tag/v4.2.1). Jalankan
`solana --version` untuk memeriksa rilis yang terpasang dan gunakan `--help` untuk opsi yang tepat
yang tersedia pada versi tersebut.

<Callout type="warn">
  Perintah yang membuat, mentransfer, mengotorisasi, menarik, atau men-deploy akan mengirimkan
  transaksi. Konfirmasikan cluster dan penandatangan yang dikonfigurasi sebelum menjalankannya.
  Token Devnet dan Testnet tidak bernilai; perintah Mainnet menggunakan SOL sungguhan.
</Callout>

## Struktur perintah

```text
solana [GLOBAL_OPTIONS] <COMMAND> [COMMAND_OPTIONS]
```

Dapatkan bantuan di setiap tingkat:

```shell
solana --help
solana transfer --help
solana address-lookup-table extend --help
```

## Opsi global

Opsi global dapat ditempatkan sebelum perintah. Bantuan khusus perintah mengulang
opsi yang berlaku untuk perintah tersebut.

| Opsi                          | Fungsi                                                                        |
| ------------------------------- | ------------------------------------------------------------------------------ |
| `-u, --url <URL_OR_MONIKER>`    | Pilih URL RPC atau `mainnet-beta`, `testnet`, `devnet`, atau `localhost`.      |
| `--ws <URL>`                    | Ganti endpoint WebSocket.                                               |
| `-k, --keypair <KEYPAIR>`       | Pilih file keypair, `ASK`, stdin (`-`), atau URL penandatangan yang didukung.          |
| `-C, --config <FILEPATH>`       | Gunakan file konfigurasi CLI yang berbeda.                                        |
| `--commitment <LEVEL>`          | Baca pada tingkat commitment `processed`, `confirmed`, atau `finalized`.                   |
| `--output <FORMAT>`             | Kembalikan `json` atau `json-compact` jika didukung.                               |
| `--skip-preflight`              | Kirim tanpa simulasi RPC. Gunakan hanya jika Anda memahami trade-off kegagalannya. |
| `--use-tpu-client`              | Kirim transaksi melalui klien TPU.                                      |
| `--no-address-labels`           | Tampilkan alamat tanpa label lokal.                                          |
| `--skip-seed-phrase-validation` | Izinkan frasa pemulihan di luar daftar bahasa Inggris BIP39.                       |
| `-v, --verbose`                 | Tampilkan output perintah tambahan.                                                |
| `-V, --version`                 | Cetak versi CLI yang terpasang.                                               |

## Konfigurasi CLI

```shell
# Inspect the effective configuration.
solana config get

# Use Devnet and a specific signer by default.
solana config set --url devnet
solana config set --keypair ./devnet-keypair.json

# Override defaults for one command.
solana --url mainnet-beta --keypair usb://ledger address
```

Konfigurasi berisi URL RPC, URL WebSocket, penandatangan default, dan
commitment. Opsi baris perintah menimpa nilai yang tersimpan untuk pemanggilan tersebut.

## Alur kerja akun dan transaksi umum

```shell
# Print the default signer's address and balance.
solana address
solana balance

# Read an account as JSON.
solana account <ACCOUNT_ADDRESS> --output json

# Request Devnet SOL.
solana airdrop 1 --url devnet

# Send SOL and then confirm the returned signature.
solana transfer <RECIPIENT_ADDRESS> 0.1 --allow-unfunded-recipient
solana confirm <TRANSACTION_SIGNATURE>

# Inspect recent activity and stream logs mentioning an address.
solana transaction-history <ADDRESS> --limit 20
solana logs <ADDRESS>
```

`transfer` menerima SOL secara default. Gunakan `ALL` sebagai jumlah untuk memindahkan saldo
tersedia setelah biaya. Untuk contoh token, lihat
[panduan singkat token](/docs/tokens/quickstart).

## Alur kerja program

```shell
# Deploy or upgrade an SBF program.
solana program deploy ./target/deploy/my_program.so

# Inspect the deployed program and list programs controlled by the signer.
solana program show <PROGRAM_ID>
solana program show --programs

# Close a program buffer and recover its lamports.
solana program close <BUFFER_ADDRESS>
```

Berikan `--program-id <KEYPAIR_OR_ADDRESS>` saat deployment harus menggunakan
ID program yang sudah diketahui. `--final` membuat deployment baru menjadi immutable; baca bantuannya dengan cermat
sebelum menggunakannya karena upgrade authority tidak dapat dipulihkan.

## Alur kerja durable nonce

```shell
solana-keygen new --outfile nonce-account.json
solana create-nonce-account nonce-account.json 0.1
solana nonce nonce-account.json
solana new-nonce nonce-account.json
solana withdraw-from-nonce-account nonce-account.json <RECIPIENT_ADDRESS> ALL
```

Gunakan `authorize-nonce-account` untuk mengubah otoritas nonce dan `nonce-account`
untuk memeriksa status akun secara lengkap. Transaksi yang menggunakan nonce juga menerima
`--nonce` dan `--nonce-authority` pada perintah yang didukung.

## Alur kerja stake

```shell
solana-keygen new --outfile stake-account.json
solana create-stake-account stake-account.json 1
solana delegate-stake stake-account.json <VOTE_ACCOUNT_ADDRESS>
solana stake-account stake-account.json

solana deactivate-stake stake-account.json
solana withdraw-stake stake-account.json <RECIPIENT_ADDRESS> ALL
```

Deaktivasi selesai pada batas epoch dan bisa memakan waktu lebih dari satu epoch.
Gunakan `stakes`, `validators`, `stake-history`, dan `stake-minimum-delegation` untuk
memeriksa status cluster dan delegasi sebelum mengirimkan perubahan.

## Utilitas alamat

```shell
# Derive a PDA from typed seeds.
solana find-program-derived-address \
  <PROGRAM_ID> \
  string:profile \
  pubkey:<OWNER_ADDRESS>

# Create and extend an address lookup table.
solana address-lookup-table create
solana address-lookup-table extend \
  <LOOKUP_TABLE_ADDRESS> \
  --addresses <ADDRESS_1>,<ADDRESS_2>
```

Seed PDA menggunakan format `PREFIX:VALUE`. Prefiks yang didukung meliputi `string`, `pubkey`,
`hex`, `u8`, dan encoding integer bertanda atau tidak bertanda dengan lebar tetap seperti
`u64le`.

## Pesan off-chain dan shell completion

```shell
solana sign-offchain-message "terms accepted"
solana verify-offchain-signature \
  "terms accepted" \
  <SIGNATURE> \
  --signer <SIGNER_ADDRESS>

# Print a completion script for the current shell.
solana completion --shell zsh
```

## Output skrip

Gunakan `--output json` atau `--output json-compact` jika didukung, alih-alih
mem-parsing output yang dapat dibaca manusia:

```shell
solana epoch-info --output json
solana account <ACCOUNT_ADDRESS> --output json-compact
solana validators --output json > validators.json
```

Tidak semua perintah mendukung output terstruktur. Periksa bantuan perintah sebelum
mengandalkannya dalam otomatisasi, dan anggap status keluar bukan nol sebagai kegagalan.
