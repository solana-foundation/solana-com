---
title: Pemrograman Staking
---

Untuk memaksimalkan distribusi stake, desentralisasi, dan ketahanan terhadap
sensor di jaringan Solana, staking dapat dilakukan secara terprogram. Tim dan
komunitas telah mengembangkan beberapa program onchain dan offchain untuk
membuat pengelolaan stake menjadi lebih mudah.

### Program Delegasi Solana Foundation

[Program Delegasi Solana Foundation](https://solana.org/delegation-program)
dirancang untuk melayani kebutuhan jaringan dengan menargetkan tujuan-tujuan
berikut:

1. Memaksimalkan desentralisasi, keandalan, dan performa Solana
2. Memaksimalkan jumlah validator yang memiliki sumber stake yang beragam
3. Mempertahankan testnet yang besar dan representatif

### Stake Pools

Program onchain ini menggabungkan SOL untuk di-stake oleh seorang manajer, sehingga pemegang SOL
dapat melakukan staking dan memperoleh reward tanpa perlu mengelola stake sendiri. Pengguna menyetorkan SOL sebagai
imbalan token SPL (derivatif staking) yang mewakili kepemilikan mereka di
stake pool. Manajer pool melakukan staking atas SOL yang disetor sesuai dengan
strateginya, mungkin dengan menggunakan varian bot auto-delegation seperti yang dijelaskan di atas.
Seiring stake menghasilkan reward, nilai pool dan token pool bertambah secara proporsional.
Terakhir, pemegang token pool dapat mengirimkan token SPL kembali ke stake pool untuk menukarkannya dengan
SOL, sehingga dapat berpartisipasi dalam desentralisasi dengan usaha yang jauh lebih sedikit.
Informasi lebih lanjut dapat ditemukan di
[dokumentasi Stake Pool](https://www.solana-program.com/docs/stake-pool).
