  Jalankan agen dengan Pay dan selesaikan satu pembayaran x402 V2 pada API sandbox lokal tanpa memindahkan dana sungguhan.
---

Gunakan [Pay](https://pay.sh) untuk menjalankan API x402 V2 dan memberi Claude Code klien HTTP yang mendukung pembayaran. API, dompet pembayar, dan penyelesaian transaksi semuanya menggunakan sandbox Solana, sehingga panduan ini tidak memerlukan akun atau dana sungguhan.

Anda memerlukan terminal, Pay, dan Claude Code yang sudah terpasang.

## 1. Instal Pay

Di macOS, instal biner yang sudah dikompilasi:

```bash
brew install pay
pay --version
```

Di platform lain, instal paket npm:

```bash
npm install --global @solana/pay
pay --version
```

## 2. Jalankan API sandbox x402

Buat `x402-demo.yaml`:

```yaml filename=x402-demo.yaml
name: x402-demo
subdomain: x402-demo
title: "x402 Demo"
description: "Minimal x402 V2 sandbox endpoint."
category: devtools
version: v1
routing:
  type: respond
operator:
  currencies:
    usd: ["USDC"]
  network: "localnet"
  fee_payer: true
endpoints:
  - method: GET
    path: "report"
    description: "Return a sandbox report."
    metering:
      schemes: [x402-exact]
      dimensions:
        - direction: usage
          unit: requests
          scale: 1
          tiers:
            - price_usd: 0.001
```

Jalankan API dan biarkan tetap berjalan:

```bash
pay --sandbox server start x402-demo.yaml --bind 127.0.0.1:1402
```

Skema `x402-exact` menjadikan ini endpoint khusus x402. Mode sandbox membuat dan mendanai akun operator dan pembayar sementara secara otomatis.

## 3. Jalankan agen dengan Pay

Di terminal lain, jalankan Claude Code dalam mode sandbox:

```bash
pay --sandbox claude
```

Pay menyematkan alat MCP lokalnya ke sesi agen. Agen tidak menerima kunci privat.

## 4. Buat satu permintaan x402

Tempel prompt ini ke agen:

```text
Use Pay to make exactly one sandbox x402 API request to
http://127.0.0.1:1402/report.

Before paying, show me the amount and ask for approval. Then return the API
result and payment receipt. Do not make any other paid requests.
```

Permintaan ini mengikuti satu alur pembayaran x402 V2 yang lengkap:

1. API mengembalikan `402 Payment Required` beserta tantangan `PAYMENT-REQUIRED`.
2. Pay memvalidasi persyaratan x402 dan menampilkan ketentuan pembayaran.
3. Setelah disetujui, dompet sandbox menandatangani dan Pay mengulang permintaan dengan
   `PAYMENT-SIGNATURE`.
4. API mengembalikan hasilnya beserta tanda terima `PAYMENT-RESPONSE`.

Tidak ada dana sungguhan yang berpindah. Menolak persetujuan akan menghentikan permintaan.

Lanjutkan dengan [x402 di Solana](/docs/payments/agentic-payments/x402) untuk membangun klien dan server resource x402 V2, atau [menjadi fasilitator x402](/docs/tools/x402-facilitator).
