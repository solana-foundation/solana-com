---
title: Men-deploy Program
description: Praktik terbaik untuk men-deploy program di Mainnet
---

Jika Anda men-deploy program Solana kustom sebagai bagian dari infrastruktur
pembayaran Anda, ada beberapa pertimbangan tambahan.

## Sebelum Deployment

- **Versi Solana CLI:** Pastikan Anda menggunakan versi terbaru dari
  [Solana CLI](https://solana.com/docs/intro/installation).
- **Keypair program:** Program Anda akan memiliki alamat yang berbeda di mainnet
  dibandingkan di devnet (kecuali Anda menggunakan ulang keypair yang sama). Perbarui semua referensi di
  konfigurasi aplikasi Anda. Simpan keypair program Anda di lokasi yang aman (perhatikan
  bahwa menjalankan `cargo clean` kemungkinan besar akan menghapus keypair program Anda).
- **Inisialisasi akun:** Jika program Anda memerlukan akun admin, PDA, atau
  akun state lainnya, pastikan semuanya dibuat di mainnet sebelum pengguna
  berinteraksi dengan aplikasi Anda. Hal yang sama berlaku untuk setiap Associated Token Account (ATA)
  yang dibutuhkan program Anda.

## Proses Deployment

- **Akun buffer:** Program berukuran besar di-deploy melalui akun buffer. Perintah
  `solana program deploy` menangani hal ini secara otomatis, tetapi perlu dipahami
  bahwa deployment tidak bersifat atomik—jika terputus, Anda mungkin perlu memulihkan atau menutup
  akun buffer.
- **Upgrade authority:** Buat
  [multisig](https://docs.squads.so/main/basics/what-is-a-multisig) dan tetapkan
  sebagai
  [upgrade authority dari program Solana Anda](https://docs.squads.so/main/navigating-your-squad/developers-assets/programs).
- **Rent:** Pastikan wallet deployment Anda memiliki cukup SOL untuk menutup
  minimum rent-exempt bagi semua akun program.
- **Verifikasi:** [Verifikasi](https://solana.com/docs/programs/verified-builds)
  program Anda untuk memastikan bahwa program yang dapat dieksekusi yang Anda deploy ke
  jaringan Solana sesuai dengan kode sumber di repositori Anda
