## Semantik Clock

<Callout
  type="warn"
  title="Timestamp dalam milidetik; clock melaporkan dalam detik"
>
  `surfnet_timeTravel`'s `absoluteTimestamp` dalam **milidetik**, seperti
  `Date.now()` JavaScript, tetapi sysvar `Clock` yang dibaca program melaporkan
  **detik**. Memasukkan nilai langsung dari clock ke dalam cheatcode
  akan mendarat di awal tahun 1970 — dan karena clock hanya bergerak maju, panggilan tersebut
  ditolak bukan diabaikan. Kalikan dengan 1000 terlebih dahulu.
</Callout>

Untuk padanan cheatcode clock di tingkat SDK, lihat
[Time Travel](/docs/tools/surfpool/sdk/time-travel).
