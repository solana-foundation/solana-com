Metode untuk memanipulasi waktu dan mengakses variabel sistem. Setiap getter sysvar
memiliki setter yang sesuai; struct-nya adalah cerminan Go biasa dari sumber
Solana.

## Manipulasi Clock

### WarpToSlot

```go
func (s *LiteSVM) WarpToSlot(slot uint64) error
```

Maju ke slot tertentu pada jam internal.

```go
before, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("current slot: %d", before.Slot)

if err := svm.WarpToSlot(10_000_000); err != nil {
    t.Fatal(err)
}

after, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("new slot:     %d", after.Slot)
```

### Clock

```go
type Clock struct {
    Slot                uint64
    EpochStartTimestamp int64
    Epoch               uint64
    LeaderScheduleEpoch uint64
    UnixTimestamp       int64
}

func (s *LiteSVM) Clock() (Clock, error)
```

Membaca sysvar Clock.

```go
c, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("slot=%d epoch=%d unix=%d", c.Slot, c.Epoch, c.UnixTimestamp)
```

### SetClock

```go
func (s *LiteSVM) SetClock(c Clock) error
```

Menimpa sysvar Clock. Baca, ubah field, lalu tulis kembali saat Anda memerlukan
kontrol atas `Epoch` atau `UnixTimestamp` (yang tidak diperbarui oleh `WarpToSlot`).

```go
c, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
c.Slot = 1_000
c.Epoch = 10
c.UnixTimestamp = 1_735_689_600
if err := svm.SetClock(c); err != nil {
    t.Fatal(err)
}
```

<Callout type="info">
  `WarpToSlot` hanya memperbarui `Slot`. Gunakan `SetClock` saat program Anda membaca
  `Epoch` atau `UnixTimestamp` dari sysvar Clock.
</Callout>

## Epoch Rewards

```go
type EpochRewards struct {
    DistributionStartingBlockHeight uint64
    NumPartitions                   uint64
    ParentBlockhash                 solana.Hash
    TotalPointsLo                   uint64 // low 64 bits of the u128 total_points
    TotalPointsHi                   uint64 // high 64 bits
    TotalRewards                    uint64
    DistributedRewards              uint64
    Active                          bool
}

func (s *LiteSVM) EpochRewards() (EpochRewards, error)
func (s *LiteSVM) SetEpochRewards(e EpochRewards) error
```

`total_points` adalah `u128` di sisi Solana; `litesvm-go` menampilkan kedua bagiannya
secara eksplisit sehingga pemanggil Go tidak memerlukan library u128. Untuk nilai yang muat dalam 64
bit, `TotalPointsHi` adalah `0` dan `TotalPointsLo` adalah nilainya.

### SlotHistory

`SlotHistory` adalah bitvec ~128 KB; `litesvm-go` mengeksposnya sebagai handle daripada
sebuah slice.

```go
sh, err := litesvm.NewSlotHistory()
if err != nil {
    t.Fatal(err)
}
defer sh.Close()

sh.Add(42)

switch sh.Check(42) {
case litesvm.SlotHistoryFound:
    // ...
case litesvm.SlotHistoryNotFound:
    // ...
case litesvm.SlotHistoryTooOld:
    // ...
case litesvm.SlotHistoryFuture:
    // ...
}

if err := svm.SetSlotHistory(sh); err != nil {
    t.Fatal(err)
}
```

| Metode                                           | Deskripsi                                |
| ------------------------------------------------ | ------------------------------------------ |
| `litesvm.NewSlotHistory() (*SlotHistory, error)` | Handle kosong                               |
| `sh.Add(slot uint64)`                            | Mencatat sebuah slot                              |
| `sh.Check(slot uint64) SlotHistoryCheck`         | `Future` / `TooOld` / `Found` / `NotFound` |
| `sh.Oldest() uint64`                             | Slot terlama yang dilacak                        |
| `sh.Newest() uint64`                             | Slot terbaru yang dilacak                        |
| `sh.NextSlot() uint64`                           | Slot berikutnya untuk dicatat                        |
| `sh.SetNextSlot(slot uint64) error`              | Menimpa penanda slot berikutnya              |
| `sh.Close()`                                     | Melepaskan handle                         |
| `svm.SlotHistory() (*SlotHistory, error)`        | Membaca ke dalam handle baru                   |
| `svm.SetSlotHistory(*SlotHistory) error`         | Memasang pada SVM                         |

## Menguji Logika yang Bergantung pada Waktu

Gunakan `WarpToSlot` untuk kemajuan berbasis slot biasa, `SetClock` untuk kontrol penuh:

```go
func TestTimeLockedVault(t *testing.T) {
    svm, err := litesvm.New()
    if err != nil {
        t.Fatal(err)
    }
    defer svm.Close()

    const unlockSlot = uint64(10_000)

    // Setup: create the time-locked account ...

    // Test 1: Try to withdraw before unlock (should fail)
    before, err := svm.Clock()
    if err != nil {
        t.Fatal(err)
    }
    t.Logf("current slot: %d", before.Slot)
    // ... attempt withdrawal, expect failure ...

    // Warp time forward past unlock slot
    if err := svm.WarpToSlot(unlockSlot + 1); err != nil {
        t.Fatal(err)
    }

    // Test 2: Try to withdraw after unlock (should succeed)
    after, err := svm.Clock()
    if err != nil {
        t.Fatal(err)
    }
    t.Logf("new slot: %d", after.Slot)
    // ... attempt withdrawal, expect success ...
}
```
