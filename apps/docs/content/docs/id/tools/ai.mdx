# Bekerja dengan LLM dan Agen di Solana

Sebelum menyelami alat-alat tertentu, mari kita pahami komponen utama dalam
stack pengembangan AI:

## Memahami Stack AI

1. **Large Language Models (LLM)**
   - Model AI dasar (seperti GPT-4, Claude, atau Llama)
   - Memproses dan menghasilkan bahasa alami
   - Menyediakan kecerdasan dan kemampuan penalaran mentah
   - Contoh: GPT-4 dari OpenAI, Claude dari Anthropic, Llama dari Meta

2. **Framework Agen (seperti Eliza)**
   - Dibangun di atas LLM untuk membuat agen otonom
   - Mengelola kepribadian dan perilaku agen
   - Menangani memori dan konteks
   - Menyediakan integrasi multi-platform
   - Contoh: Eliza, LangChain, AutoGPT, Vercel AI

3. **Kit Agen Domain-Spesifik (seperti Solana Agent Kit)**
   - Dibangun untuk kasus penggunaan tertentu (misalnya, operasi blockchain)
   - Menyediakan alat dan integrasi bawaan
   - Menyederhanakan kompleksitas teknis
   - Fungsi blockchain yang siap digunakan
   - Contoh: Solana Agent Kit, GOAT Toolkit

Bayangkan seperti ini:

- LLM adalah "otak" yang dapat memahami dan menghasilkan bahasa
- Framework agen adalah "sistem operasi" yang mengelola perilaku AI
- Kit domain-spesifik adalah "aplikasi" yang memberikan kemampuan khusus kepada AI

# Membangun Agen AI untuk Solana

Panduan ini akan menunjukkan cara:

- Membangun agen AI dasar menggunakan Solana Agent Kit dari SendAI
- Membuat bot Twitter dengan Eliza Framework
- Memahami opsi integrasi AI onchain
- Pilihan cara membangun bot trading canggih

## Pengenalan Agen AI di Solana

Agen AI di Solana adalah program otonom yang dapat berinteraksi dengan
blockchain menggunakan pemrosesan bahasa alami dan machine learning. Mereka dapat:

- Mengeksekusi transaksi
- Memantau aktivitas blockchain
- Berinteraksi dengan smart contract
- Memberikan bantuan kepada pengguna
- Mengotomatiskan alur kerja yang kompleks

## Framework yang Tersedia

Beberapa framework tersedia untuk membangun agen AI di Solana:

1. **Solana Agent Kit dari SendAI**

- Kumpulan alat untuk membangun agen di Solana
- Kompatibel dengan Eliza, Langchain, dan Vercel AI SDK
- Alat dan utilitas Solana bawaan
- Kemampuan pemrosesan bahasa alami
- [Solana Agent Kit](https://github.com/sendaifun/solana-agent-kit)
- [Dokumentasi](https://docs.solanaagentkit.xyz/)

2. **Eliza Framework**

- Menggabungkan datalayer, llm, dan agen serta memiliki plugin Solana khusus
- Arsitektur agen yang dapat diperluas
- Integrasi mudah dengan proyek yang sudah ada dan dapat digunakan misalnya untuk
  bot Twitter (X), Telegram, atau Discord
- [Repositori GitHub](https://github.com/elizaOS/eliza)

3. **GOAT Toolkit**

- Toolkit pengembangan yang komprehensif
- Kompatibilitas lintas rantai
- [Repositori GitHub](https://github.com/goat-sdk/goat)

4. **Rig Framework**

- Implementasi Rust asli
- Cocok untuk bot trading berkinerja tinggi
- Dapat dikombinasikan dengan toolkit Listen.rs untuk integrasi Solana, pemantauan
  transaksi, dan pengiriman transaksi menggunakan Jito bundles misalnya
- [Repositori GitHub](https://github.com/0xPlaygrounds/rig)
- [Repositori Listen.rs](https://github.com/piotrostr/listen)

Jika Anda sedang membangun framework AI, silakan buka PR untuk menambahkan framework Anda
ke daftar ini

### Buat skrip agen

Buat file baru bernama `agent.ts` dengan konten berikut:

```typescript filename=agent.ts
import { SolanaAgentKit, createSolanaTools } from "solana-agent-kit";
import { HumanMessage } from "@langchain/core/messages";
import { ChatOpenAI } from "@langchain/openai";
import { createReactAgent } from "@langchain/langgraph/prebuilt";
import { MemorySaver } from "@langchain/langgraph";
import * as dotenv from "dotenv";
import bs58 from "bs58";
import * as readline from "readline";

dotenv.config();

async function initializeAgent() {
  const llm = new ChatOpenAI({
    modelName: "gpt-4-turbo-preview",
    temperature: 0.7
  });

  // Convert array string to actual array, then to Uint8Array, then to base58
  const privateKeyArray = JSON.parse(process.env.SOLANA_PRIVATE_KEY!);
  const privateKeyUint8 = new Uint8Array(privateKeyArray);
  const privateKeyBase58 = bs58.encode(privateKeyUint8);

  const solanaKit = new SolanaAgentKit(privateKeyBase58, process.env.RPC_URL!, {
    OPENAI_API_KEY: process.env.OPENAI_API_KEY!
  });

  const tools = createSolanaTools(solanaKit);
  const memory = new MemorySaver();

  return createReactAgent({
    llm,
    tools,
    checkpointSaver: memory
  });
}

async function runInteractiveChat() {
  const agent = await initializeAgent();
  const config = { configurable: { thread_id: "Solana Agent Kit!" } };
  const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout
  });

  // Clear console and start chat with a small delay
  setTimeout(() => {
    console.clear(); // Clear any initialization messages
    console.log("Chat with Solana Agent (type 'exit' to quit)");
    console.log("--------------------------------------------");
    askQuestion();
  }, 100);

  const askQuestion = () => {
    rl.question("You: ", async (input) => {
      if (input.toLowerCase() === "exit") {
        rl.close();
        return;
      }

      const stream = await agent.stream(
        {
          messages: [new HumanMessage(input)]
        },
        config
      );

      process.stdout.write("Agent: ");
      for await (const chunk of stream) {
        if ("agent" in chunk) {
          process.stdout.write(chunk.agent.messages[0].content);
        } else if ("tools" in chunk) {
          process.stdout.write(chunk.tools.messages[0].content);
        }
      }
      console.log("\n--------------------------------------------");

      askQuestion(); // Continue the conversation
    });
  };
}

runInteractiveChat().catch(console.error);
```

</Step>

## Membangun dengan Eliza Framework

[ElizaOS](https://github.com/elizaOS/eliza) (sebelumnya dikenal sebagai Ai16z) adalah sebuah
framework AI. Artinya, ia menggabungkan beberapa aplikasi menjadi satu dan
mengorganisir interaksi di antara mereka. Framework ini menggabungkan:

1. Berbagai LLM untuk memahami pengguna
2. Agen blockchain dengan berbagai aksi (seperti minting NFT misalnya)
3. Datalayer untuk menyimpan status karakter antar aksi menggunakan misalnya
   Redis, PostgreSQL DB, atau penyimpanan lokal
4. Berbagai klien seperti X, Telegram, Discord, dll.

Framework ini mengambil semua hal tersebut dan menyatukannya sehingga Anda dapat membuat
"Karakter" yang dapat berinteraksi dengan pengguna atau secara otonom. Karakter-karakter ini
didefinisikan dalam file JSON yang menentukan aksi apa yang dapat dilakukannya, LLM mana
yang harus digunakan, dan berbagai prompt yang mendefinisikan perilaku karakter tersebut.

## Integrasi agen program onchain

Jika Anda ingin menggunakan balasan agen dalam program solana, Anda perlu menggunakan
oracle yang menulis data balasan ke dalam akun yang dapat dibaca oleh program Anda.
Anda dapat menemukan contoh LLM yang akan mentransfer token ke pengguna mana pun yang
menjawab pertanyaan dengan benar di sini:

[Interaksi LLM program on chain](https://github.com/GabrielePicco/super-smart-contracts)

Ini adalah contoh program onchain yang berintegrasi dengan oracle LLM (AI)
untuk membuat agen pembagi token interaktif bernama "Mar1o".

### Fitur Utama

1. **Interaksi Agen AI**
   - Pengguna dapat mengobrol dengan Mar1o untuk mencoba mendapatkan token
   - Agen mengevaluasi pengetahuan Solana pengguna untuk menentukan jumlah token
   - Respons dalam format JSON dengan teks balasan dan jumlah token

2. **Manajemen Token**
   - Membuat token MAR1O beserta metadatanya
   - Dapat mencetak antara 0-10.000 token berdasarkan respons AI
   - Menggunakan PDA untuk manajemen token

### Penjelasan alur program

Berikut cara kerja program ini:

```rust
// Initialize the AI agent with personality
const AGENT_DESC: &str = "You are an AI agent called Mar1o which can dispense MAR1O tokens...";

// User interaction flow:
// 1. User sends message to agent
// 2. Oracle processes with LLM
// 3. Agent responds with JSON containing reply and amount
// 4. If amount > 0, tokens are minted to user

// Example response:
{
    "reply": "Great answer! Here's a reward.",
    "amount": 1000
}
```

Ini menunjukkan cara menggabungkan kemampuan AI dengan mekanisme token onchain untuk
menciptakan pengalaman blockchain yang interaktif. Berikut adalah
[contoh langsung](https://mar1o.xyz/) di mana Anda dapat mencoba meyakinkan Agen untuk
mentransfer beberapa token kepada Anda.

## Agen Rust tingkat lanjut untuk perdagangan algoritmik

Jika Anda ingin menulis agen dalam Rust, Anda dapat menggunakan
[framework Rig](https://github.com/0xPlaygrounds/rig) dan

Keduanya bekerja dengan baik bersama-sama. Sementara framework Rig memberi Anda cara mudah untuk

## Praktik Terbaik

- Ketahuilah bahwa agen Anda memiliki kunci privat sehingga dapat mengakses dana di
  dompet Anda. Jika seseorang dapat mengobrol dengan agen Anda dan agen tersebut memiliki aksi transfer
  misalnya, pengguna kemungkinan bisa membuatnya mentransfer dana Anda.
- Gunakan [endpoint RPC](https://solana.com/rpc) berbayar. Endpoint publik
  biasanya dibatasi kecepatannya
- Pantau aktivitas agen dan pastikan mereka tidak melakukan hal-hal yang berbahaya
  atau tertipu oleh pengguna yang berinteraksi dengan mereka
- Terapkan biaya prioritas dan percobaan ulang transaksi pada aksi agen Anda agar
  transaksi tetap berhasil saat terjadi kemacetan jaringan
- Jika memungkinkan, uji terlebih dahulu di devnet sebelum Anda deploy ke mainnet. Sebagian besar agen
  hanya mengambil URL RPC sebagai input dan Anda dapat menggunakan devnet hingga Anda siap
  untuk mainnet. Namun tidak semua aksi mungkin bisa dilakukan di devnet.
- Saat menulis aksi Anda sendiri, tambahkan tes integrasi agar
  framework dapat memantau aksi mana yang gagal akibat perubahan program atau
  API

Agen AI di Solana membuka peluang baru untuk otomasi dan interaksi
dengan blockchain. Meskipun belum semua integrasi sempurna, pengembangannya berlangsung
