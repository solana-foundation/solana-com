---
title: AllowMint
description:
  Mengizinkan mint token SPL pada instance dan membuat escrow ATA untuk mint tersebut
---

Mengizinkan mint token SPL pada instance dan membuat associated
token account escrow untuk mint tersebut. Deposit untuk mint ini menjadi
mungkin dilakukan setelah pemanggilan ini.

## Akun

| Akun                          | Dapat Ditulis | Penanda Tangan | Deskripsi                                                                   |
| -------------------------------- | -------- | ------ | ----------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Pembayar biaya                                                                     |
| `admin`                          |          | ✓      | Admin instance                                                                |
| `instance`                       |          |        | PDA instance                                                                  |
| `mint`                           |          |        | Mint token SPL yang akan diizinkan                                                       |
| `allowed_mint`                   | ✓        |        | PDA AllowedMint (dibuat oleh instruksi ini)                                 |
| `instance_ata`                   | ✓        |        | Associated token account escrow untuk mint ini (dibuat oleh instruksi ini) |
| `system_program`                 |          |        | System Program                                                                |
| `token_program`                  |          |        | SPL Token Program                                                             |
| `associated_token_program`       |          |        | Associated Token Program                                                      |
| `event_authority`                |          |        | PDA otoritas event                                                           |
| `private_channel_escrow_program` |          |        | Program Escrow                                                                |

## Parameter

| Parameter | Tipe | Deskripsi                                                                                   |
| --------- | ---- | --------------------------------------------------------------------------------------------- |
| `bump`    | `u8` | Bump seed untuk PDA `allowed_mint`. Opsional: klien `Async` menurunkannya secara otomatis jika dihilangkan |

> IDL memuat argumen `discriminator: u8` (nilai `1`) yang diatur secara otomatis
> oleh klien yang dihasilkan dan tidak boleh dimasukkan secara manual.

## Catatan Penting

- Gunakan `getAllowMintInstructionAsync`; fungsi ini secara otomatis menurunkan `bump`, `allowed_mint`,
  dan `instance_ata` jika tidak disediakan. Masukkan `bump` Anda sendiri hanya jika
  Anda sudah menghitungnya melalui
  `Pubkey::find_program_address(&[b"allowed_mint", instance_pda, mint], &PROGRAM_ID)`
- Juga membuat `instance_ata`, ATA escrow untuk mint ini
- Mint dengan ekstensi transfer hook secara eksplisit diblokir: mencoba
  mengizinkan mint semacam itu akan memunculkan `TransferHookNotAllowed`
- Memancarkan event melalui CPI `EmitEvent`
