Mentransfer hak admin ke dompet baru.

## Akun

| Akun                          | Dapat Ditulis | Penanda Tangan | Deskripsi                        |
| -------------------------------- | -------- | ------ | ---------------------------------- |
| `payer`                          | ✓        | ✓      | Pembayar biaya                          |
| `current_admin`                  |          | ✓      | Admin saat ini (harus menandatangani)          |
| `instance`                       | ✓        |        | Instance PDA (kolom admin diperbarui) |
| `new_admin`                      |          | ✓      | Dompet yang menerima hak admin     |
| `event_authority`                |          |        | PDA otoritas acara                |
| `private_channel_escrow_program` |          |        | Program Escrow                     |

Instruksi ini tidak memerlukan parameter.

## Catatan Penting

- **Tidak dapat dibalik dalam satu langkah**: admin saat ini tidak dapat mengklaim kembali peran tersebut
  tanpa admin baru memanggil `SetNewAdmin` lagi
- Verifikasi alamat target sebelum memanggil; tidak ada pembatalan
- Memancarkan sebuah acara melalui `EmitEvent` CPI
