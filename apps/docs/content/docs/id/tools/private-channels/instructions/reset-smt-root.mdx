---
title: Reset SMT Root
description:
  Merotasi Sparse Merkle Tree, mereset withdrawal root untuk epoch pohon baru
---

Instruksi khusus operator yang merotasi Sparse Merkle Tree dengan menambahkan
`Instance.current_tree_index` dan mereset withdrawal root, memungkinkan
epoch baru sebanyak 65.536 penarikan.

<Callout type="info">
  Program escrow sedang bermigrasi dari desain Sparse Merkle Tree ini ke
  nonce bitmap on-chain (dilacak di upstream), di mana instruksi ini menjadi
  `RotateBitmap`. Halaman ini akurat terhadap program escrow saat ini dan
  akan diperbarui setelah perubahan tersebut diterapkan.
</Callout>

## Akun

| Akun                          | Dapat Ditulis | Penanda Tangan | Deskripsi                                            |
| -------------------------------- | -------- | ------ | ------------------------------------------------------ |
| `payer`                          | ✓        | ✓      | Pembayar biaya                                              |
| `operator`                       |          | ✓      | Penanda tangan operator                                        |
| `instance`                       | ✓        |        | PDA instance escrow (`current_tree_index` ditambahkan) |
| `operator_pda`                   |          |        | PDA operator yang membuktikan penanda tangan telah disediakan         |
| `event_authority`                |          |        | PDA event authority untuk CPI `EmitEvent`                |
| `private_channel_escrow_program` |          |        | Program Escrow (referensi diri untuk CPI)                |

## Parameter

| Parameter                     | Tipe  | Deskripsi                                                              |
| ----------------------------- | ----- | ------------------------------------------------------------------------ |
| `expected_current_tree_index` | `u64` | Pengaman replay; harus cocok dengan `Instance.current_tree_index` atau panggilan akan gagal |

## Nilai Kembalian

Mengembalikan `TransactionBuilder` yang dapat digunakan untuk membangun dan mengirim
transaksi.

## Contoh

```typescript
import { getResetSmtRootInstruction } from "../private-channel-escrow-program/clients/typescript/src/generated";

const resetIx = getResetSmtRootInstruction({
  payer: operatorPayerSigner,
  operator: operatorSigner,
  instance: instancePda,
  operatorPda: operatorPdaAddress,
  eventAuthority: eventAuthorityPda,
  privateChannelEscrowProgram: ESCROW_PROGRAM_ID,
  expectedCurrentTreeIndex: currentTreeIndex // u64
});
```

## Catatan Penting

- Khusus operator: memerlukan `operator_pda` yang valid; melempar `InvalidOperatorPda`
  jika tidak
- `expected_current_tree_index` harus sama dengan `Instance.current_tree_index` pada saat
  pemanggilan; nilai yang usang akan melempar `UnexpectedTreeIndex`, yang melindungi dari pemutaran ulang
  reset yang sudah diterapkan
- Menambahkan `Instance.current_tree_index`; nonce yang valid di epoch pohon sebelumnya
  akan dibatalkan setelah rotasi
- Layanan `operator-private-channel` memanggil ini secara otomatis ketika
  `transaction_nonce % 65536 == 0` (dan `nonce > 0`), menandai dimulainya
  epoch baru; instruksi ini seharusnya tidak perlu dipanggil secara manual dalam operasi normal
- Setelah rotasi, withdrawal root direset ke pohon kosong, sehingga penarikan
  baru dimulai dari SMT yang baru
- Memancarkan event melalui CPI `EmitEvent`
