---
title: Deposit
description:
  Mentransfer token SPL dari dompet pengguna ke escrow Private Channels
---

Mentransfer token SPL dari associated token account pengguna ke associated token account escrow,
mengkreditkan saldo channel pengguna yang melakukan deposit (atau saldo
penerima opsional).

## Akun

| Akun                          | Dapat Ditulis | Penanda Tangan | Deskripsi                                          |
| -------------------------------- | -------- | ------ | ---------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Pembayar biaya untuk transaksi                        |
| `user`                           |          | ✓      | Pemilik token yang melakukan deposit                       |
| `instance`                       |          |        | PDA instance escrow                                  |
| `mint`                           |          |        | Mint token SPL                                       |
| `allowed_mint`                   |          |        | PDA yang memverifikasi bahwa mint diizinkan pada instance ini |
| `user_ata`                       | ✓        |        | Associated token account pengguna (sumber)             |
| `instance_ata`                   | ✓        |        | Associated token account escrow (tujuan)      |
| `system_program`                 |          |        | System Program                                       |
| `token_program`                  |          |        | SPL Token Program                                    |
| `associated_token_program`       |          |        | Associated Token Program                             |
| `event_authority`                |          |        | PDA otoritas event untuk CPI `EmitEvent`              |
| `private_channel_escrow_program` |          |        | Program Escrow (referensi-diri untuk CPI)              |

## Parameter

| Parameter   | Tipe             | Deskripsi                                                                           |
| ----------- | ---------------- | ------------------------------------------------------------------------------------- |
| `amount`    | `u64`            | Jumlah token yang akan didepositkan, dalam satuan terkecil token                             |
| `recipient` | `Option<Pubkey>` | Penerima on-chain opsional; jika `None`, mengkreditkan saldo channel pengguna yang melakukan deposit |

## Nilai Kembalian

Mengembalikan `TransactionBuilder` yang dapat digunakan untuk membangun dan mengirim
transaksi.

## Contoh

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

// allowedMint and instanceAta are auto-derived from mint and instance
const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n,
  recipient: null
});
```

## Catatan Penting

- ID Program: `9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`
- Untuk mint Token-2022, sertakan `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS`
  secara eksplisit, karena defaultnya adalah SPL Token Program standar
- PDA `allowed_mint` harus sudah ada (dibuat oleh `AllowMint`); mendepositkan
  mint yang tidak terdaftar akan memunculkan error `InvalidAllowedMint`
- Jika `recipient` bernilai `None`, saldo channel pengguna yang melakukan deposit akan dikreditkan;
  jika disertakan, saldo dompet yang ditentukan akan dikreditkan
- Baik `payer` maupun `user` harus menandatangani transaksi
- `instance_ata` harus sudah ada (dibuat oleh `AllowMint` untuk mint ini)
