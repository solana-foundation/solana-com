Membuat `Instance` PDA yang menjangkar escrow. Harus dipanggil sebelum operasi
lainnya.

## Seed PDA

```
instance        -> ["instance", instance_seed: Pubkey]
allowed_mint    -> ["allowed_mint", instance_pda: Pubkey, mint: Pubkey]
operator        -> ["operator", instance_pda: Pubkey, operator: Pubkey]
event_authority -> ["event_authority"]
```

## Akun

| Akun                          | Dapat Ditulis | Penandatangan | Deskripsi                                                                 |
| -------------------------------- | -------- | ------ | --------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Pembayar biaya dan pembayar rent                                                    |
| `admin`                          |          | ✓      | Admin awal dari instance                                               |
| `instance_seed`                  |          | ✓      | keypair sekali pakai yang hanya digunakan untuk derivasi PDA; pubkey-nya menjadi seed |
| `instance`                       | ✓        |        | Instance PDA (diturunkan dari `["instance", instance_seed.pubkey]`)            |
| `system_program`                 |          |        | System Program                                                              |
| `event_authority`                |          |        | PDA otoritas event                                                         |
| `private_channel_escrow_program` |          |        | Program Escrow                                                              |

## Parameter

| Parameter | Tipe | Deskripsi                                                                             |
| --------- | ---- | --------------------------------------------------------------------------------------- |
| `bump`    | `u8` | bump seed untuk instance PDA. Opsional: klien `Async` akan menurunkannya secara otomatis jika tidak diberikan |

> IDL berisi argumen `discriminator: u8` (nilai `0`) yang disetel otomatis
> oleh klien yang dihasilkan dan tidak boleh diisi secara manual.

## Catatan Penting

- `instance_seed` adalah keypair sekali pakai, hanya digunakan untuk menurunkan `Instance`
  PDA. pubkey-nya menjadi seed; keypair itu sendiri tidak disimpan atau digunakan kembali.
- Gunakan `getCreateInstanceInstructionAsync`; fungsi ini akan menurunkan `bump` dan `instance`
  secara otomatis dari `instance_seed` jika tidak disediakan. Berikan `bump` Anda sendiri hanya jika
  Anda sudah menghitungnya melalui
  `Pubkey::find_program_address(&[b"instance", instance_seed_pubkey.as_ref()], &PROGRAM_ID)`
- Memancarkan event melalui CPI `EmitEvent`
