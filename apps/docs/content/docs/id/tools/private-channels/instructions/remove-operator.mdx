---
title: RemoveOperator
description: Mencabut operator dengan menutup Operator PDA mereka
---

Mencabut operator dengan menutup `Operator` PDA mereka. Wallet yang dicabut tidak
lagi dapat memanggil `ReleaseFunds` atau `ResetSmtRoot`.

## Akun

| Akun                          | Dapat Ditulis | Penanda Tangan | Deskripsi                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | Pembayar biaya                                 |
| `admin`                          |          | ✓      | Admin instance                            |
| `instance`                       |          |        | Instance PDA                              |
| `operator`                       |          |        | Wallet operator yang akan dicabut                 |
| `operator_pda`                   | ✓        |        | Operator PDA (ditutup oleh instruksi ini) |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | PDA otoritas event                       |
| `private_channel_escrow_program` |          |        | Program Escrow                            |

Instruksi ini tidak memerlukan parameter.

## Catatan Penting

- Menutup `operator_pda`; wallet yang dicabut tidak lagi dapat memanggil
  `ReleaseFunds` atau `ResetSmtRoot`
- Setiap transaksi operator yang sedang berlangsung akan gagal dengan `InvalidOperatorPda` setelah
  pemanggilan ini
- Memancarkan event melalui CPI `EmitEvent`
