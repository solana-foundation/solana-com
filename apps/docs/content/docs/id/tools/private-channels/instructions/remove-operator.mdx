---
title: RemoveOperator
description: Mencabut operator dengan menutup Operator PDA mereka
---

Mencabut operator dengan menutup `Operator` PDA mereka. Dompet yang dicabut tidak lagi
dapat memanggil `ReleaseFunds` atau `ResetSmtRoot`.

## Akun

| Akun                          | Dapat Ditulis | Penandatangan | Deskripsi                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | Pembayar biaya                                 |
| `admin`                          |          | ✓      | Admin instance                            |
| `instance`                       |          |        | Instance PDA                              |
| `operator`                       |          |        | Dompet operator yang akan dicabut                 |
| `operator_pda`                   | ✓        |        | Operator PDA (ditutup oleh instruksi ini) |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | Event authority PDA                       |
| `private_channel_escrow_program` |          |        | Program Escrow                            |

Instruksi ini tidak memerlukan parameter.

## Catatan Penting

- Menutup `operator_pda`; dompet yang dicabut tidak lagi dapat memanggil
  `ReleaseFunds` atau `ResetSmtRoot`
- Setiap transaksi operator yang sedang berjalan akan gagal dengan `InvalidOperatorPda` setelah
  panggilan ini
- Memancarkan event melalui `EmitEvent` CPI
