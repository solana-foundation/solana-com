Bagian ini adalah referensi instruksi on-chain. Sebagian besar pengembang memanggil instruksi-instruksi ini melalui klien TypeScript yang telah dibuat; Anda hanya memerlukan ini jika Anda sedang membangun alat operator, menulis integrasi kustom, atau melakukan debug kesalahan pada level instruksi.

**Escrow Program** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) - mengelola
deposit, provisi operator, dan penyelesaian Mainnet:

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) -
  inisialisasi PDA instans escrow
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) - whitelist
  mint token SPL
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) - hapus
  mint dari allowlist
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) -
  provisi operator
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) -
  cabut operator
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) -
  transfer hak admin
- [Deposit](/docs/tools/private-channels/instructions/deposit) - pindahkan token SPL
  ke dalam escrow
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) -
  operator menyelesaikan penarikan ke Mainnet
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) -
  operator merotasi Sparse Merkle Tree

**Withdraw Program** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) - berjalan di
jaringan private channel:

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) -
  bakar saldo sisi channel untuk memulai penarikan

## Kode Kesalahan

**Escrow Program - `PrivateChannelEscrowProgramError`**

| Kode                                         | Pesan                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | Otoritas event tidak valid yang diberikan                 |
| `InvalidAta`                                 | ATA tidak valid yang diberikan                             |
| `InvalidMint`                                | Mint tidak valid yang diberikan                            |
| `InvalidInstanceId`                          | ID instans tidak valid atau tidak memenuhi aturan    |
| `InvalidInstance`                            | Instans tidak valid yang diberikan                        |
| `InvalidAdmin`                               | Admin tidak valid yang diberikan                           |
| `TransferHookNotAllowed`                     | Ekstensi transfer hook tidak diizinkan              |
| `InvalidOperatorPda`                         | PDA operator tidak valid yang diberikan                    |
| `InvalidTokenAccount`                        | token account tidak valid yang diberikan                   |
| `InvalidEscrowBalance`                       | Saldo escrow tidak valid                           |
| `InvalidAllowedMint`                         | Mint yang diizinkan tidak valid                             |
| `InvalidSmtProof`                            | Bukti SMT tidak valid yang diberikan                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | Nonce transaksi tidak valid untuk indeks pohon saat ini |
| `UnexpectedTreeIndex`                        | Indeks pohon saat ini tidak terduga untuk reset root SMT |

**Withdraw Program - `PrivateChannelWithdrawProgramError`**

| Kode          | Pesan                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | Mint tidak valid yang diberikan                       |
| `ZeroAmount`  | Jumlah penarikan harus lebih besar dari nol |
