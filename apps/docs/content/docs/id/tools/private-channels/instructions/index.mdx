Bagian ini adalah referensi instruksi on-chain. Sebagian besar developer memanggil instruksi-instruksi ini melalui klien TypeScript yang telah dibuat; Anda hanya memerlukan ini jika Anda sedang membangun alat operator, menulis integrasi kustom, atau melakukan debug pada kesalahan di tingkat instruksi.

**Escrow Program** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) - mengelola
deposit, penyediaan operator, dan penyelesaian Mainnet:

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) -
  inisialisasi PDA instance escrow
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) - masukkan
  mint token SPL ke dalam whitelist
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) - hapus
  mint dari allowlist
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) -
  sediakan operator
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) -
  cabut akses operator
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) -
  transfer hak admin
- [Deposit](/docs/tools/private-channels/instructions/deposit) - pindahkan token SPL
  ke dalam escrow
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) -
  operator menyelesaikan penarikan ke Mainnet
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) -
  operator merotasi Sparse Merkle Tree

**Withdraw Program** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) - berjalan di
jaringan private channel:

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) -
  burn saldo sisi channel untuk memulai penarikan

## Kode Error

**Escrow Program - `PrivateChannelEscrowProgramError`**

| Kode                                         | Pesan                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | Otoritas event tidak valid                 |
| `InvalidAta`                                 | ATA yang diberikan tidak valid                             |
| `InvalidMint`                                | Mint yang diberikan tidak valid                            |
| `InvalidInstanceId`                          | ID instance tidak valid atau tidak memenuhi aturan    |
| `InvalidInstance`                            | Instance yang diberikan tidak valid                        |
| `InvalidAdmin`                               | Admin yang diberikan tidak valid                           |
| `TransferHookNotAllowed`                     | Ekstensi transfer hook tidak diizinkan              |
| `InvalidOperatorPda`                         | PDA operator yang diberikan tidak valid                    |
| `InvalidTokenAccount`                        | token account yang diberikan tidak valid                   |
| `InvalidEscrowBalance`                       | Saldo escrow tidak valid                           |
| `InvalidAllowedMint`                         | Mint yang diizinkan tidak valid                             |
| `InvalidSmtProof`                            | Bukti SMT yang diberikan tidak valid                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | Nonce transaksi tidak valid untuk indeks tree saat ini |
| `UnexpectedTreeIndex`                        | Indeks tree saat ini tidak terduga untuk reset SMT root |

**Withdraw Program - `PrivateChannelWithdrawProgramError`**

| Kode          | Pesan                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | Mint yang diberikan tidak valid                       |
| `ZeroAmount`  | Jumlah penarikan harus lebih besar dari nol |
