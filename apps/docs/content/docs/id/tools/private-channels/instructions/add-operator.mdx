---
title: AddOperator
description: Menyediakan operator baru dengan membuat Operator PDA mereka
---

Menyediakan operator baru dengan membuat `Operator` PDA mereka. Setelah pemanggilan ini,
dompet `operator` dapat memanggil `ReleaseFunds` dan `ResetSmtRoot`.

## Akun

| Akun                          | Dapat Ditulis | Penanda Tangan | Deskripsi                                                         |
| -------------------------------- | -------- | ------ | ------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Pembayar biaya                                                           |
| `admin`                          |          | ✓      | Admin instance                                                      |
| `instance`                       |          |        | Instance PDA                                                        |
| `operator`                       |          |        | Dompet operator yang akan disediakan                                        |
| `operator_pda`                   | ✓        |        | Operator PDA - diturunkan otomatis dari `["operator", instance, operator]` |
| `system_program`                 |          |        | System Program                                                      |
| `event_authority`                |          |        | Event authority PDA                                                 |
| `private_channel_escrow_program` |          |        | Escrow Program                                                      |

## Parameter

| Parameter | Tipe | Deskripsi                                                                               |
| --------- | ---- | ----------------------------------------------------------------------------------------- |
| `bump`    | `u8` | Bump seed untuk `operator_pda`. Opsional: klien `Async` menurunkannya secara otomatis jika dihilangkan |

> IDL memuat argumen `discriminator: u8` (nilai `3`) yang diatur secara otomatis
> oleh klien yang dihasilkan dan tidak boleh dimasukkan secara manual.

## Catatan Penting

- Gunakan `getAddOperatorInstructionAsync`; fungsi ini menurunkan `bump` dan
  `operator_pda` secara otomatis jika tidak disediakan. Varian sinkron
  `getAddOperatorInstruction` juga tersedia jika Anda telah menghitung `bump`
  sendiri
- Setelah pemanggilan ini, dompet `operator` dapat memanggil `ReleaseFunds` dan
  `ResetSmtRoot`
- Memancarkan event melalui CPI `EmitEvent`
