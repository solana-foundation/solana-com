Menghapus mint yang sebelumnya diizinkan dari instance, mencegah deposit baru untuk
mint tersebut. Deposit yang sudah ada tidak terpengaruh.

## Akun

| Akun                          | Dapat Ditulis | Penanda Tangan | Deskripsi                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | Pembayar biaya                                    |
| `admin`                          |          | ✓      | Admin instance                               |
| `instance`                       |          |        | PDA instance                                 |
| `mint`                           |          |        | Mint token SPL yang akan diblokir                      |
| `allowed_mint`                   | ✓        |        | PDA AllowedMint (ditutup oleh instruksi ini) |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | PDA otoritas event                          |
| `private_channel_escrow_program` |          |        | Program Escrow                               |

Instruksi ini tidak memerlukan parameter.

## Catatan Penting

- Menutup PDA `allowed_mint`: panggilan `Deposit` baru untuk mint ini akan gagal
  dengan `InvalidAllowedMint`
- Saldo channel yang sudah ada untuk mint ini tidak terpengaruh
- Mengirimkan event melalui CPI `EmitEvent`
