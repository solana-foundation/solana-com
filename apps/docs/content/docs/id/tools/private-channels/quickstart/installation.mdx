## Prasyarat

- Rust 1.91+
- Solana CLI 3.1.13 (Agave):
  `sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.13/install)"`
- Node.js 24.7.0+
- pnpm 10.15.1+: `npm install -g pnpm@10.15.1`

## Clone Repositori

```bash
git clone https://github.com/solana-foundation/solana-private-channels.git
cd solana-private-channels
```

## Buat Klien TypeScript

Klien TypeScript **tidak** dipublikasikan ke npm. Klien harus dibuat dari
IDL menggunakan Codama.

```bash
# Escrow program client
cd private-channel-escrow-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..

# Withdraw program client
cd private-channel-withdraw-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..
```

Klien yang dihasilkan berada di:

- `private-channel-escrow-program/clients/typescript/src/generated/`
- `private-channel-withdraw-program/clients/typescript/src/generated/`

Impor dari jalur lokal ini di aplikasi Anda; tidak ada
paket `@private-channels/client` di npm. Contoh kode di bagian ini menggunakan
jalur relatif (`../private-channel-escrow-program/...`) yang mengasumsikan kode Anda
berada berdampingan dengan repositori yang telah di-clone; sesuaikan dengan lokasi
impor Anda yang sebenarnya dalam proyek Anda sendiri.
