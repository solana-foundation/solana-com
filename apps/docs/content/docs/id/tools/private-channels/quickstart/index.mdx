  Deposit, transfer, dan penarikan di Solana devnet dalam waktu kurang dari 30 menit
---

Panduan mulai cepat ini membahas alur lengkap Private Channels di Solana devnet:
siapkan lingkungan klien, deposit token SPL ke dalam escrow, kirim transfer
off-chain antara dua dompet, dan tarik dana kembali ke dompet Solana Anda.

Di akhir panduan ini, Anda akan memahami siklus lengkap deposit -> transfer off-chain ->
penarikan dan memiliki kode TypeScript yang berfungsi untuk setiap langkah.

<Callout type="info">
  Panduan mulai cepat ini mengasumsikan bahwa instance Private Channels sudah di-deploy dan
  berjalan di devnet dengan mint Anda ada di allowlist. Jika Anda perlu men-deploy terlebih dahulu,
  [panduan Operator](/docs/tools/private-channels/operators) mencakup
  setup lengkap; perkirakan 30-60 menit untuk build Docker awal.
</Callout>

## Langkah-Langkah

1. **[Instalasi](/docs/tools/private-channels/quickstart/installation)** -
   clone repositori dan buat klien TypeScript (5 menit)
2. **[Deposit Token](/docs/tools/private-channels/quickstart/deposit)** -
   deposit token SPL ke dalam escrow; tunggu ~15 detik agar pengindeks
   mengkredit saldo channel Anda
3. **[Kirim Transfer](/docs/tools/private-channels/quickstart/transfer)** -
   kirim transfer off-chain melalui gateway; dikonfirmasi dalam waktu kurang dari satu detik,
   tidak pernah menyentuh Mainnet
4. **[Tarik Dana](/docs/tools/private-channels/quickstart/withdraw)** - burn
   saldo sisi channel Anda; operator menyelesaikan dana ke dompet Mainnet Anda
   dalam beberapa detik
