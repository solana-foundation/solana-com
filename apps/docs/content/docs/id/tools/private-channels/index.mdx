**Private Channels adalah lapisan enterprise untuk pasar modal internet di
Solana.** Ini menyediakan lapisan aplikasi yang dapat dikonfigurasi untuk transfer
privat, instan, dan tanpa biaya di dalam saluran pembayaran: pengguna menyetor token SPL ke dalam
program escrow on-chain, bertransaksi secara off-chain melalui gateway, dan menyelesaikan kembali ke Mainnet
melalui bukti Sparse Merkle Tree, memberikan developer aplikasi transfer yang instan, tanpa biaya, dan privat
tanpa meninggalkan ekosistem Solana.

### Mengapa Private Channels?

- **Transfer instan**: throughput off-chain melampaui TPS native Solana;
  transfer dikonfirmasi saat sequencer memprosesnya, bukan saat blok dikonfirmasi
- **Tanpa biaya per transfer**: tidak ada biaya gas pada transfer saluran individual; pengguna
  hanya membayar untuk deposit dan penarikan on-chain
- **Privasi**: transfer antara peserta saluran tidak dicatat di Solana
  Mainnet
- **Akses terotorisasi**: RBAC dengan autentikasi JWT memungkinkan Anda mengontrol siapa yang dapat
  mengirim dan menerima
- **Penyelesaian Mainnet**: dana selalu dapat ditukarkan ke Solana melalui bukti
  eksklusi Sparse Merkle Tree, yang diberlakukan oleh program escrow secara on-chain

Lihat **[Ikhtisar](/docs/tools/private-channels/overview)** untuk arsitektur lengkap,
diagram aliran data, dan model keamanan.

## Mulai Cepat

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n, // 1 USDC
  recipient: null
});
// send via your preferred Solana client
```

Klien TypeScript dibuat dari IDL; lihat Instalasi. Untuk mint Token-2022,
berikan `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS` secara eksplisit, karena secara
default menggunakan Token Program SPL standar.

## Kasus Penggunaan

- **Pembayaran bilateral institusional** - bank dan institusi yang membutuhkan
  aliran USDC volume tinggi dan privat tanpa setiap transfer muncul secara on-chain
- **Transfer lapisan aplikasi frekuensi tinggi** - game, loyalitas, dan aplikasi konsumen
  yang membutuhkan transfer sub-detik tanpa biaya dalam skala melampaui TPS native Solana
- **Aliran token dengan privasi terjaga** - kasus penggunaan apa pun di mana privasi pihak lawan dan
  jumlah merupakan persyaratan produk

**[Kapan menggunakan transfer SPL native sebagai gantinya](/docs/tools/private-channels/concepts/channels#when-to-use-private-channels)**
