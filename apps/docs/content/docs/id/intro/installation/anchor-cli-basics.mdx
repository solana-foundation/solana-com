Bagian ini menyediakan beberapa perintah dan contoh umum untuk membantu Anda
memulai menggunakan [Anchor CLI](https://www.anchor-lang.com/docs).

<Steps>
<Step>

### Inisialisasi proyek

Buat proyek Anchor baru dengan menjalankan perintah di bawah ini. Perintah ini akan membuat
direktori baru dengan nama proyek dan menggunakannya untuk menginisialisasi proyek
Anchor baru.

```terminal
$ anchor init <project-name>
```

Misalnya, perintah di bawah ini akan membuat proyek bernama `my-project`. Direktori
`my-project` akan berisi program Rust modular dan templat pengujian Rust
yang menggunakan LiteSVM.

```terminal
$ anchor init my-project
```

Untuk membuat templat pengujian TypeScript, pilih secara eksplisit. Misalnya,
gunakan templat Mocha:

```terminal
$ anchor init my-project --test-template mocha
```

Templat pengujian TypeScript memerlukan Node.js dan pengelola paket JavaScript.

Kemudian buka direktori proyek:

```terminal
$ cd <project-name>
```

Lihat [struktur file proyek](https://www.anchor-lang.com/docs/quickstart/local#project-file-structure) Anchor.

</Step>
<Step>

### Build program

Untuk mem-build proyek Anda, jalankan perintah berikut:

```terminal
$ anchor build
```

Anda dapat menemukan program yang telah dikompilasi di direktori
`/target/deploy`.

<Callout type="warn" title="Platform tools gagal diinstal">
  Jika proses build melaporkan direktori platform-tools tidak valid, instal ulang SBF
  build tools, lalu coba build kembali:

```terminal
$ cargo build-sbf --force-tools-install
$ anchor build
```

</Callout>

</Step>
<Step>

### Deploy program

Untuk men-deploy proyek Anda, jalankan perintah berikut:

```terminal
$ anchor deploy
```

Perintah ini men-deploy program Anda ke `cluster` yang ditentukan dalam file
[`Anchor.toml`](https://www.anchor-lang.com/docs/references/anchor-toml).

</Step>
<Step>

### Test program

Untuk menguji proyek Anda, jalankan perintah berikut:

```terminal
$ anchor test
```

Perintah ini mem-build, men-deploy, dan menjalankan test untuk proyek Anda.

<Callout>
  Saat menggunakan cluster `localnet`, Anchor secara otomatis memulai validator
  lokal, men-deploy program, menjalankan test, kemudian menghentikan validator.
</Callout>

<Callout type="warn" title="Error test runner JavaScript">

Jika Anda memilih templat pengujian JavaScript atau TypeScript, salah satu
error berikut mungkin menandakan bahwa Node.js atau pengelola paket yang dikonfigurasi
belum terinstal:

```
Permission denied (os error 13)
```

```
No such file or directory (os error 2)
```

</Callout>

</Step>
</Steps>
