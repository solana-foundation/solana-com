Siapkan lingkungan pengembangan Solana lokal dengan installer otomatis. Installer ini
memasang Rust, Solana CLI, Anchor CLI, Surfpool CLI, Node.js, dan Yarn di
macOS, Linux, atau Windows melalui WSL.

<Callout type="info" title="Windows memerlukan WSL">
  Di Windows PowerShell, jalankan `wsl --install`, mulai ulang Windows jika diminta, lalu
  jalankan perintah instalasi di bawah ini di terminal Ubuntu. Lihat [panduan
  instalasi manual](/docs/intro/installation/dependencies) untuk pengaturan
  WSL yang lengkap.
</Callout>

## Instalasi cepat

1. Jalankan installer di terminal macOS, Linux, atau WSL:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
```

Anda dapat
[meninjau sumber installer](https://github.com/solana-developers/solana-install/blob/main/install.sh)
sebelum menjalankannya. Installer ini mendeteksi package manager Linux yang didukung dan
memasang dependensi sistemnya secara otomatis.

2. Mulai ulang terminal Anda agar perintah-perintah baru tersedia di `PATH` Anda.

3. Verifikasi setiap tool:

```terminal
$ rustc --version
$ solana --version
$ anchor --version
$ surfpool --version
$ node --version
$ yarn --version
```

Instalasi yang berhasil akan menampilkan output dalam format berikut (nomor versi berubah seiring
rilis tool):

```txt title="Example output"
Installed Versions:
Rust: rustc x.y.z (...)
Solana CLI: solana-cli x.y.z (..., client:Agave)
Anchor CLI: anchor-cli x.y.z
Surfpool CLI: surfpool x.y.z
Node.js: vx.y.z
Yarn: x.y.z
```

<Callout type="warn" title="Installer gagal atau ada perintah yang tidak ditemukan">
  Ikuti [panduan instalasi manual](/docs/intro/installation/dependencies)
  untuk memasang atau memecahkan masalah setiap dependensi satu per satu.
</Callout>
