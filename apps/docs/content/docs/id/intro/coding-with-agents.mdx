## Menggunakan Solana MCP

Cara paling efektif untuk memanfaatkan AI dalam pengembangan Solana adalah melalui
[Solana Developer MCP](https://mcp.solana.com/) (Model Context Protocol). Integrasi ini
menghadirkan pengetahuan Solana yang terkhususkan langsung ke dalam IDE Anda, memberikan
akses kepada agen Anda ke dokumentasi Solana terkini dan membuat pengembangan
lebih cepat dan lebih efisien.

## Apa itu Solana MCP?

Solana MCP adalah asisten AI khusus yang terintegrasi langsung ke dalam
IDE bertenaga AI seperti Cursor dan Windsurf. Ketika Anda mengajukan
pertanyaan spesifik tentang Solana, MCP server secara otomatis akan dikueri untuk memberikan informasi
yang akurat dan terkini dari:

- [Dokumentasi Solana](/docs)
- [Dokumentasi Anchor Framework](https://www.anchor-lang.com/docs)
- [Contoh Program](https://github.com/solana-developers/program-examples)
  Solana
- Pertanyaan dan jawaban
  [Solana Stack Exchange](https://solana.stackexchange.com/)

## Contoh kasus penggunaan

Anda dapat menggunakan MCP untuk:

- Bertanya tentang konsep Solana
- Men-debug kesalahan program
- Mendapatkan rekomendasi praktik terbaik
- Belajar dari contoh para ahli
- Mengembangkan lebih cepat dengan bantuan seorang ahli

## Menyiapkan Solana MCP

Temukan panduan pengaturan dan memulai yang terperinci di
[situs web Solana MCP](https://mcp.solana.com/).

## Lebih suka menggunakan skill?

Jika Anda lebih memilih menggunakan skill, instal skill Solana resmi dengan:

```bash
npx skills add https://github.com/solana-foundation/solana-dev-skill
```

Jelajahi lebih banyak alur kerja yang dapat digunakan kembali di [perpustakaan Solana Agent Skills](/skills).
