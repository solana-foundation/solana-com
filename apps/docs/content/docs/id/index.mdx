### Coba Solana: Main 2048

Mainkan 2048 di Solana, tempat setiap gerakan mengirim transaksi. Klik "Main"
untuk memulai dengan wallet Devnet yang didanai, lalu gunakan tombol panah atau
geser di perangkat seluler.
