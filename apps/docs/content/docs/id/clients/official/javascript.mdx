## Solana Kit

`@solana/kit` adalah TypeScript SDK yang direkomendasikan untuk membangun di
Solana. Anda merakit klien dari plugin-plugin yang dapat dikombinasikan,
menambahkan binding React saat dibutuhkan, dan mengintegrasikan klien program
yang telah dibuat untuk program on-chain yang Anda panggil.

| Package                   | Deskripsi                                  | GitHub                                                                                 |
| ------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------- |
| @solana/kit               | SDK Inti: RPC, transaksi, codec, penanda tangan | [Sumber](https://github.com/anza-xyz/kit)                                              |
| @solana/react             | Binding React: `ClientProvider` dan hooks   | [Sumber](https://github.com/anza-xyz/kit/tree/main/packages/react)                     |
| @solana/kit-plugin-rpc    | Koneksi RPC + pengiriman transaksi         | [Sumber](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-rpc)    |
| @solana/kit-plugin-signer | Plugin pembayar biaya, identitas, dan penanda tangan      | [Sumber](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-signer) |
| @solana/kit-plugin-wallet | Koneksi Wallet Standard + React hooks     | [Sumber](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-wallet) |

## Solana Web3.js v3

`@solana/web3.js` v3 adalah versi web3.js yang direkomendasikan. Versi ini membangun ulang
API klasik berbasis kelas — `Connection`, `Keypair`, `Transaction`, `PublicKey` —
di atas internal `@solana/kit`, sehingga dapat bekerja dengan primitif Kit dan
klien program di atas. Gunakan versi ini jika Anda ingin meningkatkan aplikasi web3.js yang sudah ada atau
lebih menyukai API berbasis kelas.

Sebagian besar metode yang sebelumnya sinkron di SDK lama, seperti
`Keypair.generate()` dan `transaction.sign()`, kini bersifat asinkron.

```bash
npm install @solana/web3.js@3
```

| Package         | Deskripsi | GitHub                                                        |
| --------------- | ----------- | ------------------------------------------------------------- |
| @solana/web3.js | SDK Inti    | [Sumber](https://github.com/solana-foundation/solana-web3.js) |

`@solana/spl-token` bergantung pada `@solana/web3.js` (legacy) dan tidak berjalan di
v3. Gunakan `@solana-program/token` atau `@solana-program/token-2022` sebagai gantinya; instruksi
yang dihasilkan dan rencana instruksinya dapat langsung digunakan dengan
`Transaction.add()` milik v3.

- [Panduan migrasi web3.js v1 → v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
- [Panduan migrasi spl-token](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-spl-token-migration.md)

## Solana Web3.js (legacy)

`@solana/web3.js` (legacy, `1.x`) adalah SDK TypeScript asli untuk Solana. SDK ini
berada dalam mode pemeliharaan dan hanya menerima perbaikan penting. Basis kode yang sudah ada dapat
[meningkatkan ke web3.js v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
atau [bermigrasi ke Kit](/docs/frontend/web3-compat).
