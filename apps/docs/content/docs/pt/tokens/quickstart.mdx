---
title: "Início rápido: criar um token com a CLI"
description:
  Create a token, open a token account, mint supply, and transfer tokens using
  the SPL Token CLI on devnet.
---

Este início rápido percorre o ciclo de vida completo de um token com a CLI _sh`spl-token`_. Você irá criar um mint, criar uma conta que pode guardar o token, emitir 100 tokens e transferir alguns para outra carteira.

Use o [Solana Playground](https://beta.solpg.io/) para executar os comandos no seu navegador, ou instale a CLI localmente com `cargo install spl-token-cli`. Os endereços na sua saída serão diferentes dos exemplos abaixo.

## 1. Conectar à devnet

Crie ou conecte uma carteira no Solana Playground, selecione a devnet e solicite SOL para depósitos em conta e taxas de transação:

```terminal
$ solana config set --url devnet
$ solana airdrop 2
```

Use tokens da devnet apenas para testes. Eles não têm valor financeiro.

## 2. Criar um token

Crie o mint account que identifica o seu token:

```terminal
$ spl-token create-token
```

Copie o endereço do token da saída. Este é o endereço do mint que você usará nos comandos restantes. Um novo mint começa com um fornecimento de zero.

```terminal
$ spl-token supply <MINT_ADDRESS>
```

## 3. Criar um token account

A sua carteira precisa de um token account para este mint antes de poder ter um saldo:

```terminal
$ spl-token create-account <MINT_ADDRESS>
```

Isto cria o seu [associated token account](/docs/tokens#associated-token-account), cujo endereço é derivado da sua carteira e do mint.

## 4. Emitir tokens

Emita 100 tokens para o seu associated token account:

```terminal
$ spl-token mint <MINT_ADDRESS> 100
$ spl-token balance <MINT_ADDRESS>
```

A autoridade de mint deve assinar esta operação. A emissão aumenta tanto o saldo do seu token account quanto o fornecimento total registado pelo mint.

## 5. Transferir tokens

Envie 10 tokens para outra carteira na devnet. A opção _sh`--fund-recipient`_ cria o associated token account do destinatário caso ele não exista:

```terminal
$ spl-token transfer <MINT_ADDRESS> 10 <RECIPIENT_WALLET_ADDRESS> --fund-recipient
```

A transferência altera os saldos nos token accounts do remetente e do destinatário; não altera o fornecimento total do mint.

## Opcional: adicionar metadados Token-2022

Para armazenar um nome, símbolo e URI diretamente num novo mint Token-2022, crie-o com a extensão de metadados ativada:

```terminal
$ spl-token create-token \
  --program-id TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb \
  --enable-metadata
```

Em seguida, use o novo endereço do mint impresso por esse comando:

```terminal
$ spl-token initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  "EXAMPLE" \
  "https://example.com/token.json"
```

O URI deve retornar um documento de metadados JSON público. Consulte [Token-2022 metadata](/docs/tokens/extensions/metadata) para o modelo de conta e exemplos de código.
