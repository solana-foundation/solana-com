# Como verificar um token e fazê-lo aparecer no Solana Explorer

Uma dúvida comum entre criadores de tokens é: _"Por que meu token não aparece quando
pesquiso no Solana Explorer, e como faço para verificá-lo?"_

A resposta resumida: o Solana Explorer não possui um processo único de verificação
próprio. Em vez disso, ele **agrega vários provedores de verificação independentes**.
Se o seu token for verificado por **qualquer um** desses provedores, ele aparecerá
nos resultados de pesquisa do Explorer e exibirá as informações de verificação.

Este guia explica cada provedor, o que "verificado" significa (e o que não significa), e
como verificar o seu token.

## O que "verificado" significa (e o que não significa)

A verificação confirma que um token é o **token canônico / correto** para um
determinado nome, símbolo e endereço de mint. Ela ajuda os usuários a evitar
impostores e tokens duplicados, já que qualquer pessoa pode criar um token com
qualquer nome na Solana.

A verificação **não** é um endosso de um projeto e **não** é uma
garantia do valor, segurança ou legitimidade de um token. Faça sempre sua própria
pesquisa.

## Os provedores de verificação por trás do Solana Explorer

O Solana Explorer consulta os seguintes verificadores independentes. Ser reconhecido
por qualquer um deles (o RugCheck é automático; os demais exigem uma ação) faz com
que seu token apareça na pesquisa do Explorer.

### 1. RugCheck (automático)

[RugCheck](https://rugcheck.xyz) realiza análises automatizadas on-chain e
rastreia tokens automaticamente. Por ser automático, geralmente não é necessário
enviar nada — o RugCheck avalia sinais de risco on-chain (autoridade de mint/freeze,
distribuição de holders, liquidez, etc.) e rastreia o token por conta própria.

Há um tratamento especial para determinadas stablecoins, em que os projetos podem
entrar em contato diretamente com a equipe do RugCheck para um tratamento adequado.

Exemplo de página de token:
[`rugcheck.xyz/tokens/<mint>`](https://rugcheck.xyz/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 2. Jupiter

[Jupiter](https://jup.ag) mantém uma lista de tokens verificados (VRFD) amplamente
integrada em todo o ecossistema Solana — DEXes, carteiras e screeners. Um
token verificado recebe um selo de verificação verde nos produtos Jupiter e nas
plataformas parceiras.

Para ser verificado, envie seu token para análise:

- Envie em [verified.jup.ag/tokens](https://verified.jup.ag/tokens)
- Qualquer pessoa pode enviar um token (não apenas a equipe do projeto)
- Você pode, opcionalmente, conectar a conta X do projeto para vincular o endereço
  de mint do token a uma conta específica
- O Jupiter realiza uma análise holística (liquidez, conformidade com padrões de
  metadados e outros sinais) em vez de verificar uma única métrica

Exemplo de página de token:
[`jup.ag/tokens/<mint>`](https://jup.ag/tokens/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)

### 3. CoinGecko

A verificação pela [CoinGecko](https://www.coingecko.com) lista seu token com dados de
mercado. Ao verificar com a CoinGecko, certifique-se de incluir o **endereço de
mint** do token (o formulário da CoinGecko denomina isso como "endereço do contrato")
para que as integrações downstream possam resolver os preços corretamente.

Siga o guia oficial de listagem/atualização da CoinGecko:

- [Guia de verificação para solicitações de listagem e atualização na CoinGecko](https://support.coingecko.com/hc/en-us/articles/23725417857817-Verification-Guide-for-Listing-Update-Requests-on-CoinGecko)

Exemplo de página de moeda:
[`coingecko.com/en/coins/<token>`](https://www.coingecko.com/en/coins/usdc)

### 4. Solflare

[Solflare](https://solflare.com) é um validator independente no framework de
verificação do Solana Explorer. Na prática, seus critérios de listagem de tokens
se sobrepõem amplamente aos do Jupiter, pois a lista de swaps integrada ao Solflare
é alimentada pelo agregador Jupiter. Para que um novo token apareça, ele normalmente deve:

- Ser um token válido na blockchain Solana com metadados que seguem o
  padrão Metaplex Token Metadata
- Ter liquidez suficiente (um valor mínimo em USD do token disponível para
  negociação)
- Manter o impacto no preço dentro de limites aceitáveis para swaps típicos

Devido a essa sobreposição, tokens que concluem a verificação pelo Jupiter
geralmente já são elegíveis no Solflare sem um envio separado — portanto, normalmente
não é necessário tratar o Solflare como uma etapa manual adicional. Uma vez
atendidos os critérios, os tokens geralmente aparecem em poucos minutos. Veja:

- [Não consigo encontrar um token no Solflare](https://help.solflare.com/en/articles/9260147-i-cannot-find-a-token-in-solflare)

Exemplo de página de token:
[`solflare.com/prices/<name>/<mint>`](https://www.solflare.com/prices/usd-coin/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/)

### 5. Bluprynt (KYC aprimorado)

[Bluprynt](https://app.bluprynt.com/register/account) oferece um caminho de verificação
aprimorado com um protocolo KYC. Trata-se de um processo mais rigoroso, com
respaldo de identidade, adequado para projetos que desejam um sinal de verificação
mais robusto.

- Registre-se pelo
  [onboarding da Bluprynt para o Solana Explorer](https://app.bluprynt.com/register/account)

Exemplo de página de ativo verificado:
[`verified.bluprynt.com/verified-assets/<mint>/solana`](https://verified.bluprynt.com/verified-assets/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v/solana)

## Como tudo se encaixa

- **RugCheck** acontece automaticamente via análise on-chain — nenhum envio
  necessário.
- **Jupiter, CoinGecko, Solflare e Bluprynt** exigem que você envie /
  conclua seus respectivos processos.
- Assim que seu token for verificado por **pelo menos um** desses provedores, ele
  aparecerá na pesquisa do **Solana Explorer** e exibirá os detalhes de verificação.

Se o seu token ainda não está aparecendo na pesquisa do Explorer, o caminho mais
rápido geralmente é enviar para verificação pelo Jupiter e/ou concluir uma listagem
na CoinGecko, já que ambos são amplamente integrados em todo o ecossistema.

## Pré-requisitos que ajudam a verificação a ser bem-sucedida

Independentemente do provedor, esses fundamentos on-chain aumentam muito a
probabilidade de a verificação ser bem-sucedida:

- **Metadados válidos**: seu token deve ter metadados on-chain que seguem o
  padrão Metaplex Token Metadata (nome, símbolo, URI do logotipo).
- **Liquidez**: forneça liquidez suficiente em uma DEX compatível para que o token
  possa ser negociado e avaliado.
- **Endereço de mint correto**: sempre que enviar para um provedor, use sempre o
  **endereço de mint** do seu token (denominado "endereço do contrato" em alguns
  formulários de provedores).

## Resumo

O Solana Explorer agrega múltiplos verificadores independentes — **RugCheck**
(automático), **Jupiter**, **CoinGecko**, **Solflare** e **Bluprynt** (KYC).
A verificação por qualquer um deles torna seu token pesquisável no Explorer.
A verificação confirma a identidade canônica do token; não é um endosso,
portanto os usuários devem sempre fazer sua própria pesquisa.
