## Apontar para a devnet

Substitua as URLs de RPC pela devnet e financie o pagador a partir de uma [faucet](/developers/cookbook/development/airdrops-and-faucets):

```ts
solanaRpc({
  rpcUrl: "https://api.devnet.solana.com",
  rpcSubscriptionsUrl: "wss://api.devnet.solana.com"
});
```

Todo o resto permanece inalterado. Antes de usar a mesma configuração na mainnet, planeje o gerenciamento de autoridades, as operações de conformidade e o monitoramento do ativo.
