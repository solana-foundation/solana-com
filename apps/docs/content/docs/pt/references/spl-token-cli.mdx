A interface de linha de comando `spl-token` cria e gerencia mints, token
accounts, autoridades, transferências e extensões do Token-2022.

Esta referência acompanha o
[`spl-token-cli` v5.6.1](https://github.com/solana-program/token-2022/releases/tag/cli%40v5.6.1),
a versão incluída no Agave v4.2.1. Execute `spl-token --version` e use
`<command> --help` para ver as opções exatas disponíveis na sua versão instalada.

<Callout type="warn">
  Criação de mints, transferências, alterações de autoridade, burns, congelamentos e
  fechamento de contas enviam transações. Confirme o cluster, o token program, o signatário e
  os endereços antes de executar um comando. Alterações na mainnet usam ativos reais.
</Callout>

## Instalação e ajuda

O pacote de lançamento da CLI do Agave inclui o `spl-token`. Se ele não estiver instalado, use
o crate Rust publicado:

```shell
cargo install spl-token-cli --version 5.6.1
spl-token --version
```

Consulte a ajuda na raiz ou no nível de um comando:

```shell
spl-token --help
spl-token create-token --help
spl-token transfer --help
```

## Opções globais

Coloque as opções globais antes do comando.

| Opção                                       | Finalidade                                                                   |
| -------------------------------------------- | ------------------------------------------------------------------------- |
| `-u, --url <URL_OR_MONIKER>`                 | Seleciona uma URL de RPC ou `mainnet-beta`, `testnet`, `devnet` ou `localhost`. |
| `-C, --config <PATH>`                        | Usa um arquivo de configuração diferente da Solana CLI.                            |
| `--fee-payer <KEYPAIR>`                      | Seleciona a conta que paga as taxas de transação.                            |
| `-p, --program-id <ADDRESS>`                 | Usa um ID explícito de Token Program.                                         |
| `--program-2022`                             | Usa o Token-2022 (`TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb`).           |
| `--output <FORMAT>`                          | Retorna `json` ou `json-compact` quando houver suporte.                          |
| `--with-compute-unit-limit <UNITS>`          | Define o limite de unidades de computação da transação.                                   |
| `--with-compute-unit-price <MICRO_LAMPORTS>` | Define o preço de prioridade por unidade de computação.                                  |
| `-v, --verbose`                              | Exibe saída adicional.                                                   |
| `-V, --version`                              | Imprime a versão instalada da CLI.                                          |

O programa padrão é o Token Program original. Use `--program-2022` para um
mint ou uma conta do Token-2022, inclusive ao lê-los. Um comando falha se o
programa selecionado não for o proprietário do endereço informado.

## Criar e usar um token

Os comandos imprimem os endereços criados. Salve o endereço do mint retornado por
`create-token` para os comandos seguintes.

```shell
# Create a six-decimal mint under the original Token Program.
spl-token --url devnet create-token --decimals 6

# Create the default signer's associated token account for the mint.
spl-token --url devnet create-account <MINT_ADDRESS>

# Mint 100 tokens to that associated token account.
spl-token --url devnet mint <MINT_ADDRESS> 100

# Read supply, balance, and complete mint or account details.
spl-token --url devnet supply <MINT_ADDRESS>
spl-token --url devnet balance <MINT_ADDRESS>
spl-token --url devnet display <MINT_OR_TOKEN_ACCOUNT_ADDRESS>

# Transfer tokens to a wallet and create its associated account if needed.
spl-token --url devnet transfer \
  <MINT_ADDRESS> \
  10 \
  <RECIPIENT_WALLET_ADDRESS> \
  --fund-recipient
```

Os valores são quantidades de token em formato de interface (UI), ajustadas pelas casas decimais do mint. Comandos como
`transfer`, `burn` e `unwrap-sol` aceitam `ALL` quando indicado em sua ajuda.

## Criar um mint do Token-2022

As extensões alocam estado extra no mint ou na conta e, em geral, precisam ser escolhidas quando
o mint é criado. Este exemplo cria um mint com seis casas decimais e suporte a
metadados incorporados:

```shell
spl-token --program-2022 create-token \
  --decimals 6 \
  --enable-metadata

spl-token --program-2022 initialize-metadata \
  <MINT_ADDRESS> \
  "Example Token" \
  EXAMPLE \
  https://example.com/token.json
```

As opções de extensão mais comuns de `create-token` incluem:

- `--enable-close`
- `--enable-confidential-transfers auto|manual`
- `--enable-freeze`
- `--enable-group` e `--enable-member`
- `--enable-metadata`
- `--enable-non-transferable`
- `--enable-pause`
- `--enable-permanent-delegate`
- `--enable-permissioned-burn`
- `--enable-transfer-hook` ou `--transfer-hook <PROGRAM_ID>`
- `--interest-rate <BASIS_POINTS>`
- `--transfer-fee-basis-points <BASIS_POINTS>` com
  `--transfer-fee-maximum-fee <AMOUNT>`
- `--ui-amount-multiplier <MULTIPLIER>`

Combine apenas extensões que o programa Token-2022 permita usar em conjunto. Revise o
[guia de extensões do Token-2022](/docs/tokens/extensions) relevante antes de criar
uma configuração de mint irreversível.

## Gerenciar autoridades e delegados

```shell
# Change the mint authority.
spl-token authorize <MINT_ADDRESS> mint <NEW_AUTHORITY_ADDRESS>

# Permanently remove the mint authority.
spl-token authorize <MINT_ADDRESS> mint --disable

# Let a delegate spend up to 25 tokens from one token account.
spl-token approve \
  <TOKEN_ACCOUNT_ADDRESS> \
  25 \
  <DELEGATE_ADDRESS>

# Remove the current delegate.
spl-token revoke <TOKEN_ACCOUNT_ADDRESS>
```

`authorize` oferece suporte aos tipos de autoridade mint, freeze, owner, close e
específicos de extensões. Remover uma autoridade com `--disable` é permanente quando nenhum
outro mecanismo do programa puder restaurá-la.

## Congelar, queimar e fechar

```shell
spl-token freeze <TOKEN_ACCOUNT_ADDRESS>
spl-token thaw <TOKEN_ACCOUNT_ADDRESS>

spl-token burn <TOKEN_ACCOUNT_ADDRESS> 5

# A token account must normally have a zero token balance before closing.
spl-token close --address <TOKEN_ACCOUNT_ADDRESS>
```

`burn` reduz tanto o saldo da conta quanto o fornecimento total. `close` devolve os
lamports restantes da conta ao destinatário configurado; ele não recupera os
tokens queimados.

## Wrap e unwrap de SOL

```shell
# Create or fund the owner's wrapped SOL token account.
spl-token wrap 1

# Unwrap part of the wrapped SOL balance.
spl-token unwrap-sol 0.25

# Close the wrapped SOL account and return its full lamport balance.
spl-token unwrap
```

Use `sync-native` após transferir lamports diretamente para uma token
account de wrapped SOL, para que a quantidade de tokens corresponda aos lamports subjacentes.

## Assinatura multisig

Crie uma multisig M-de-N do Token Program com até 11 membros:

```shell
spl-token create-multisig \
  2 \
  <MEMBER_1_ADDRESS> \
  <MEMBER_2_ADDRESS> \
  <MEMBER_3_ADDRESS>
```

Para uma transação controlada por essa multisig, informe o endereço da multisig como a
autoridade relevante e forneça os keypairs dos membros por meio de valores
`--multisig-signer` repetidos. Consulte a ajuda do comando de destino, pois a flag de
autoridade principal varia conforme a operação.

## Saldos confidenciais

Os comandos de saldo confidencial exigem um mint do Token-2022 configurado para
transferências confidenciais e uma conta de destino configurada.

```shell
spl-token --program-2022 configure-confidential-transfer-account \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 deposit-confidential-tokens \
  <MINT_ADDRESS> \
  10 \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 apply-pending-balance \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 withdraw-confidential-tokens \
  <MINT_ADDRESS> \
  5 \
  --address <TOKEN_ACCOUNT_ADDRESS>

spl-token --program-2022 transfer \
  <MINT_ADDRESS> \
  1 \
  <RECIPIENT_ADDRESS> \
  --confidential
```

Para `configure-confidential-transfer-account` e `apply-pending-balance`, informe
`--address <TOKEN_ACCOUNT_ADDRESS>` ou um `<MINT_ADDRESS>` posicional, não
os dois. A forma posicional usa a associated token account do proprietário. Depósito e
saque sempre recebem o mint e aceitam `--address` para substituir essa conta
padrão.

Use `enable-confidential-credits`, `disable-confidential-credits`,
`enable-non-confidential-credits` e `disable-non-confidential-credits` para
controlar quais depósitos a conta aceita. Essas configurações afetam a privacidade da
conta e a compatibilidade de pagamentos; inspecione a conta antes de alterá-las.

## Assinatura estruturada e offline

Use a saída estruturada em vez de analisar o texto exibido:

```shell
spl-token accounts --output json
spl-token display <MINT_ADDRESS> --output json-compact
```

Os comandos que produzem transações geralmente oferecem suporte a `--sign-only`, `--blockhash`,
`--signer <PUBKEY=SIGNATURE>`, `--nonce` e `--nonce-authority`. As entradas
offline exatas dependem do comando, das casas decimais do mint e do arranjo de autoridades;
portanto, gere a mensagem não assinada seguindo as instruções de `--help` desse comando e
verifique cada endereço antes de coletar assinaturas.
