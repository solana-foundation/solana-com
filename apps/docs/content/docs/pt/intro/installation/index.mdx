Configure um ambiente local de desenvolvimento Solana com o instalador automatizado. Ele
instala Rust, a Solana CLI, a Anchor CLI, a Surfpool CLI, Node.js e Yarn no
macOS, Linux ou Windows por meio do WSL.

<Callout type="info" title="O Windows requer o WSL">
  No Windows PowerShell, execute `wsl --install`, reinicie o Windows se solicitado e depois
  execute os comandos de instalação abaixo no terminal do Ubuntu. Consulte o [guia de
  instalação manual](/docs/intro/installation/dependencies) para ver a configuração
  completa do WSL.
</Callout>

## Instalação rápida

1. Execute o instalador em um terminal macOS, Linux ou WSL:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
```

Você pode
[revisar o código-fonte do instalador](https://github.com/solana-developers/solana-install/blob/main/install.sh)
antes de executá-lo. O instalador detecta os gerenciadores de pacotes Linux compatíveis e
instala automaticamente as dependências do sistema.

2. Reinicie o terminal para que os novos comandos fiquem disponíveis no seu `PATH`.

3. Verifique todas as ferramentas:

```terminal
$ rustc --version
$ solana --version
$ anchor --version
$ surfpool --version
$ node --version
$ yarn --version
```

Uma instalação bem-sucedida retorna uma saída neste formato (os números de versão mudam à medida que
as ferramentas são lançadas):

```txt title="Example output"
Installed Versions:
Rust: rustc x.y.z (...)
Solana CLI: solana-cli x.y.z (..., client:Agave)
Anchor CLI: anchor-cli x.y.z
Surfpool CLI: surfpool x.y.z
Node.js: vx.y.z
Yarn: x.y.z
```

<Callout type="warn" title="O instalador falhou ou um comando está ausente">
  Siga o [guia de instalação manual](/docs/intro/installation/dependencies)
  para instalar ou solucionar problemas de cada dependência individualmente.
</Callout>
