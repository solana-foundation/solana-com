Instale cada dependência separadamente quando precisar de uma versão específica ou quando a
[instalação rápida](/docs/intro/installation) não for concluída com sucesso.
Siga as seções na ordem para configurar um novo ambiente ou vá diretamente à ferramenta
que você precisa instalar ou cujos problemas deseja resolver.

## Pré-requisitos

<Accordions>
<Accordion title="Windows">

Para desenvolver programas Solana no Windows, **deve** usar o
[Windows Subsystem for Linux](https://learn.microsoft.com/en-us/windows/wsl/install)
(WSL). Após instalar o WSL, todas as outras dependências serão instaladas
através do terminal Linux.

Para instalar o WSL, execute o seguinte comando no Windows PowerShell:

```terminal
$ wsl --install
```

O processo de instalação irá solicitar que crie uma conta de utilizador
predefinida.

![Instalação do WSL](/assets/docs/intro/installation/wsl-install.png)

Por predefinição, o WSL instala o Ubuntu. Pode abrir um terminal Linux
procurando "Ubuntu" na barra de pesquisa.

![WSL Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-search.png)

Se o seu terminal Ubuntu se parecer com a imagem abaixo, poderá encontrar um
problema em que `ctrl + v` (atalho de teclado para colar) não funciona no
terminal.

![Terminal Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-terminal-1.png)

Se encontrar este problema, abra o Windows Terminal procurando "Terminal" na
barra de pesquisa.

![Windows Terminal](/assets/docs/intro/installation/wsl-windows-terminal.png)

Em seguida, feche o Windows Terminal e reabra um terminal Linux procurando
Ubuntu novamente. O terminal deverá agora parecer-se com a imagem abaixo, onde
`ctrl + v` (atalho de teclado para colar) funciona.

![Terminal Ubuntu](/assets/docs/intro/installation/wsl-ubuntu-terminal-2.png)

Se usar o VS Code, a
[extensão WSL](https://code.visualstudio.com/docs/remote/wsl-tutorial)
permite-lhe usar o WSL e o VS Code em conjunto.

![Configuração do WSL no VS Code](/assets/docs/intro/installation/wsl-vscode.png)

Você verá o seguinte na barra de status do VS Code:

![WSL: Ubuntu](/assets/docs/intro/installation/wsl-vscode-ubuntu.png)

Depois de configurar o WSL, você está pronto para:

- Concluir a [instalação rápida](/docs/intro/installation) usando o terminal
  Ubuntu (Linux)
- Instalar o [Rust](#install-rust), a [CLI do Solana](#install-solana-cli) e a
  [CLI do Anchor](#install-anchor-cli) individualmente, conforme descrito abaixo

<Accordion title="Linux">

<Tabs items={[".deb", ".rpm"]}>
<Tab value=".deb" >
No Debian ou em uma distribuição derivada do Debian, como Ubuntu ou Mint:

1. Atualize as listas de pacotes para garantir que todos os pacotes estejam
   atualizados:

```terminal
$ sudo apt-get update
```

2. Instale as seguintes dependências:

```terminal
$ sudo apt-get install -y \
    build-essential \
    pkg-config \
    libudev-dev llvm libclang-dev \
    protobuf-compiler libssl-dev
```

<Callout>
Se você encontrar o seguinte erro ao instalar o `protobuf-compiler`, execute
`sudo apt-get update` antes de tentar novamente o comando de instalação.

```
Package protobuf-compiler is not available, but is referred to by another package.
This may mean that the package is missing, has been obsoleted, or
is only available from another source
```

</Callout>

  </Tab>

    <Tab value=".rpm" >
    Em uma distribuição baseada em RPM, como Fedora ou Red Hat Enterprise Linux:

Atualize os pacotes instalados:

```terminal
$ sudo dnf upgrade --refresh
```

Instale as dependências de desenvolvimento:

```terminal
$ sudo dnf group install c-development development-tools \
&& sudo dnf install pkg-config openssl-devel
```

### Instalar o Rust

Os desenvolvedores criam programas Solana usando a linguagem de programação
[Rust](https://www.rust-lang.org/).

1. Instale o Rust usando [rustup](https://www.rust-lang.org/tools/install)
   digitando o seguinte comando no seu terminal:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
```

Após uma instalação bem-sucedida, você verá a seguinte mensagem:

<Accordions>
<Accordion title="Mensagem de instalação bem-sucedida do Rust">

```
Rust is installed now. Great!

To get started you may need to restart your current shell.
This would reload your PATH environment variable to include
Cargo's bin directory ($HOME/.cargo/bin).

To configure your current shell, you need to source
the corresponding env file under $HOME/.cargo.

This is usually done by running one of the following (note the leading DOT):
. "$HOME/.cargo/env"            # For sh/bash/zsh/ash/dash/pdksh
source "$HOME/.cargo/env.fish"  # For fish
```

</Accordion>
</Accordions>

2. Recarregue a sua variável de ambiente PATH para incluir o diretório bin do
   [Cargo](https://github.com/rust-lang/cargo):

```terminal
$ . "$HOME/.cargo/env"
```

3. Verifique se a instalação foi bem-sucedida.

```terminal
$ rustc --version
```

O comando exibe a versão instalada do Rust, por exemplo:

```
rustc x.y.z (...)
```

</Step>

### Instalar Solana CLI

A Solana CLI fornece todas as ferramentas necessárias para construir e
implementar programas Solana.

1. Instale o conjunto de ferramentas Solana CLI usando o comando de instalação
   oficial:

```terminal
$ sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

<Callout>
  Você pode substituir `stable` por uma tag de versão específica do Agave ou pelo canal de versões `beta`
  ou `edge`.
</Callout>

2. Disponibilize a Solana CLI no terminal atual.

O instalador atualiza a configuração do seu shell e exibe o comando necessário
para atualizar a sessão atual. Normalmente, o comando é:

```terminal
$ export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"
```

Se `solana` ainda não estiver disponível, reinicie o terminal. Para confirmar qual arquivo de
configuração do shell foi atualizado pelo instalador, verifique o shell atual:

```terminal
$ echo $SHELL
```

- Se a saída contiver `/bash`, reinicie o terminal ou execute
  `source ~/.bashrc`.
- Se a saída contiver `/zsh`, reinicie o terminal ou execute `source ~/.zshrc`.

3. Verifique se a instalação foi bem-sucedida:

```terminal
$ solana --version
```

O comando exibe a versão instalada da Solana CLI, por exemplo:

```
solana-cli x.y.z (..., client:Agave)
```

<Callout>

Você pode ver todas as versões disponíveis no
[repositório do Agave no GitHub](https://github.com/anza-xyz/agave/releases). O Agave é
o cliente validator da [Anza](https://www.anza.xyz/), anteriormente conhecido como
cliente validator da Solana Labs.

</Callout>

4. Para atualizar a Solana CLI posteriormente, execute:

```terminal
$ agave-install update
```

</Step>

### Instalar Anchor CLI

[Anchor](https://www.anchor-lang.com/) é uma framework para desenvolver
programas Solana. A framework Anchor utiliza macros Rust para simplificar o
processo de escrever programas Solana.

#### Pré-requisitos

O Node.js e um gerenciador de pacotes JavaScript só são necessários quando você seleciona um
modelo de teste em TypeScript, como Mocha ou Jest. O modelo de teste padrão do LiteSVM
é executado em Rust e não requer ferramentas do Node.js.

<Accordions>
<Accordion title="Instalação do Node">

1. Instale o Node usando o
   [Node Version Manager (nvm)](https://github.com/nvm-sh/nvm) executando o
   seguinte comando:

```terminal
$ curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```

2. Reinicie o terminal e confirme que o comando `nvm` é executado com sucesso:

```terminal
$ command -v nvm
```

3. Use o `nvm` para instalar o Node:

```terminal
$ nvm install --lts
```

4. Verifique se a instalação foi bem-sucedida conferindo a versão do Node:

```terminal
$ node --version
```

O comando exibe a versão instalada do Node.js, por exemplo:

```
vx.y.z
```

</Accordion>
<Accordion title="Instalação do Yarn">

1. Instale o Yarn:

```terminal
$ npm install --global yarn
```

2. Verifique se a instalação foi bem-sucedida conferindo a versão do Yarn:

```terminal
$ yarn --version
```

O comando exibe a versão instalada do Yarn, por exemplo:

```
x.y.z
```

</Accordion>
</Accordions>

#### Instalação

Você pode instalar a CLI e as ferramentas do Anchor de duas formas:

- Anchor Version Manager (AVM) — Método de instalação recomendado
- Sem AVM — Instalar diretamente do GitHub

<Tabs groupId="anchor" items={["AVM", "Without AVM"]}>
<Tab value="AVM">

O Anchor Version Manager (AVM) permite instalar e gerir diferentes versões do
Anchor no seu sistema e atualizar facilmente as versões do Anchor no futuro.
Para instalar o Anchor usando o AVM, siga os passos abaixo:

1. Instale o AVM com o seguinte comando:

```terminal
$ curl -sSfL https://raw.githubusercontent.com/otter-sec/anchor/master/avm/install | sh
```

2.  Confirme que o AVM foi instalado com sucesso:

```terminal
$ avm --version
```

3. Instale o Anchor CLI usando o AVM:

Para instalar a versão mais recente:

```terminal
$ avm install latest
$ avm use latest
```

Para instalar uma versão específica, especifique o número da versão:

```terminal
$ avm install 1.1.2
$ avm use 1.1.2
```

<Callout type="warn">

Ao instalar o Anchor CLI no Linux ou WSL, você pode encontrar este erro:

```
error: could not exec the linker cc = note: Permission denied (os error 13)
```

Se você vir esta mensagem de erro, siga estas etapas:

1. Instale as dependências listadas na
   seção [Linux](/docs/intro/installation/dependencies) no topo desta
   página.
2. Tente instalar o Anchor CLI novamente.

</Callout>

4. Verifique se a instalação foi bem-sucedida, verificando a versão do Anchor
   CLI:

```terminal
$ anchor --version
```

O comando exibe a versão ativa da Anchor CLI, por exemplo:

```
anchor-cli 1.1.2
```

<Callout type="info">

Execute `avm use` para selecionar a versão da Anchor CLI para o seu sistema.

- Se você instalou a versão mais recente, execute `avm use latest`.
- Se você instalou a versão `1.1.2`, execute `avm use 1.1.2`.

</Callout>

</Tab>

<Tab value="Without AVM">

1. Instale uma versão específica da Anchor CLI com o seguinte comando:

```terminal
$ cargo install --git https://github.com/solana-foundation/anchor --tag v1.1.2 anchor-cli --locked
```

2. Verifique se a instalação foi bem-sucedida conferindo a versão da Anchor CLI:

```terminal
$ anchor --version
```

O comando exibe a versão instalada da Anchor CLI, por exemplo:

```
anchor-cli 1.1.2
```

</Tab>

### Instalar a Surfpool CLI

O [Surfpool](/docs/tools/surfpool) é uma ferramenta para desenvolvimento local e um substituto
aprimorado para o `solana-test-validator`.

1. Instale o Surfpool com o seguinte comando:

```terminal
$ curl --proto '=https' --tlsv1.2 -sSfL https://run.surfpool.run/ | bash
```

2. Verifique se a instalação foi bem-sucedida conferindo a versão da Surfpool
   CLI:

```terminal
$ surfpool --version
```

O comando exibe a versão instalada da Surfpool CLI, por exemplo:

```
surfpool x.y.z
```

</Step>
