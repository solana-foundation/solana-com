## Usando o Solana MCP

A maneira mais poderosa de aproveitar a IA para o desenvolvimento em Solana é através do
[Solana Developer MCP](https://mcp.solana.com/) (Model Context Protocol). Esta
integração traz conhecimento especializado em Solana diretamente para o seu IDE, dando
aos seus agentes acesso à documentação atualizada do Solana e tornando o desenvolvimento
mais rápido e eficiente.

## O que é o Solana MCP?

O Solana MCP é um assistente de IA especializado que se integra diretamente em
IDEs com suporte a IA, como Cursor e Windsurf. Quando você faz perguntas
específicas sobre Solana, ele consulta automaticamente o servidor MCP para fornecer
informações precisas e atualizadas provenientes de:

- A [documentação do Solana](/docs)
- A [documentação do Framework Anchor](https://www.anchor-lang.com/docs)
- [Exemplos de Programas](https://github.com/solana-developers/program-examples) do Solana
- Perguntas e respostas do [Solana Stack Exchange](https://solana.stackexchange.com/)

## Exemplos de casos de uso

Você pode usar o MCP para:

- Perguntar sobre conceitos do Solana
- Depurar erros de programas
- Obter recomendações de boas práticas
- Aprender com exemplos de especialistas
- Desenvolver mais rapidamente com a ajuda de um especialista

## Configurar o Solana MCP

Encontre um guia detalhado de configuração e primeiros passos no
[site do Solana MCP](https://mcp.solana.com/).

## Prefere usar uma skill?

Se preferir usar uma skill, instale a skill oficial do Solana com:

```bash
npx skills add https://github.com/solana-foundation/solana-dev-skill
```

Explore mais fluxos de trabalho reutilizáveis na [biblioteca de Solana Agent Skills](/skills).
