## Pré-requisitos

- Rust 1.91+
- Solana CLI 3.1.13 (Agave):
  `sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.13/install)"`
- Node.js 24.7.0+
- pnpm 10.15.1+: `npm install -g pnpm@10.15.1`

## Clonar o Repositório

```bash
git clone https://github.com/solana-foundation/solana-private-channels.git
cd solana-private-channels
```

## Gerar Clientes TypeScript

Os clientes TypeScript **não** são publicados no npm. Eles devem ser gerados a partir
do IDL usando o Codama.

```bash
# Escrow program client
cd private-channel-escrow-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..

# Withdraw program client
cd private-channel-withdraw-program
pnpm install --frozen-lockfile
pnpm run generate-clients
cd ..
```

Os clientes gerados ficam em:

- `private-channel-escrow-program/clients/typescript/src/generated/`
- `private-channel-withdraw-program/clients/typescript/src/generated/`

Importe a partir desses caminhos locais em sua aplicação; não existe
nenhum pacote `@private-channels/client` no npm. Os exemplos de código nesta seção usam um
caminho relativo (`../private-channel-escrow-program/...`) que pressupõe que seu código
esteja junto ao repositório clonado; ajuste-o para corresponder ao local de onde você realmente
importa em seu próprio projeto.
