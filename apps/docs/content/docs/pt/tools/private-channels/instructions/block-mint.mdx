title: BlockMint
description:
  Remove um mint anteriormente permitido da instância, impedindo novos depósitos para esse mint
---

Remove um mint anteriormente permitido da instância, impedindo novos depósitos para
esse mint. Os depósitos existentes não são afetados.

## Contas

| Conta                          | Gravável | Signatário | Descrição                                  |
| -------------------------------- | -------- | ------ | -------------------------------------------- |
| `payer`                          | ✓        | ✓      | Pagador de taxas                                    |
| `admin`                          |          | ✓      | Administrador da instância                               |
| `instance`                       |          |        | PDA da instância                                 |
| `mint`                           |          |        | Mint de token SPL a bloquear                      |
| `allowed_mint`                   | ✓        |        | PDA AllowedMint (encerrado por esta instrução) |
| `system_program`                 |          |        | System Program                               |
| `event_authority`                |          |        | PDA de autoridade de eventos                          |
| `private_channel_escrow_program` |          |        | Programa de Escrow                               |

Esta instrução não recebe parâmetros.

## Notas Importantes

- Encerra o PDA `allowed_mint`: novas chamadas `Deposit` para este mint falharão
  com `InvalidAllowedMint`
- Os saldos de canal existentes para este mint não são afetados
- Emite um evento via CPI `EmitEvent`
