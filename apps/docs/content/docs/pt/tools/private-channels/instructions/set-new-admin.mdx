Transfere os direitos de administrador para uma nova carteira.

## Contas

| Conta                          | Gravável | Assinante | Descrição                        |
| -------------------------------- | -------- | ------ | ---------------------------------- |
| `payer`                          | ✓        | ✓      | Pagador de taxas                          |
| `current_admin`                  |          | ✓      | Administrador atual (deve assinar)          |
| `instance`                       | ✓        |        | PDA da instância (campo de administrador atualizado) |
| `new_admin`                      |          | ✓      | Carteira que receberá os direitos de administrador     |
| `event_authority`                |          |        | PDA de autoridade de eventos                |
| `private_channel_escrow_program` |          |        | Programa de Escrow                     |

Esta instrução não recebe parâmetros.

## Notas Importantes

- **Irreversível em uma etapa**: o administrador atual não pode recuperar o papel
  sem que o novo administrador chame `SetNewAdmin` novamente
- Verifique o endereço de destino antes de chamar; não há desfazer
- Emite um evento via CPI `EmitEvent`
