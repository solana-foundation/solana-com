---
title: Retirar Fundos
description:
  Queima tokens do lado do canal para iniciar uma retirada de volta ao escrow da mainnet Solana
---

Queima o saldo de tokens do lado do canal de um utilizador no Programa de Retirada para sinalizar uma
retirada pendente; um operador deve posteriormente chamar `ReleaseFunds` no
Programa de Escrow para concluir a liquidação.

## Contas

| Conta                    | Gravável | Assinante | Descrição                                |
| -------------------------- | -------- | ------ | ------------------------------------------ |
| `user`                     |          | ✓      | Proprietário do token que inicia a retirada      |
| `mint`                     | ✓        |        | Mint do token SPL (usado na queima)            |
| `token_account`            | ✓        |        | token account do canal do utilizador (origem) |
| `token_program`            |          |        | Token Program SPL                          |
| `associated_token_program` |          |        | Associated Token Program                   |

## Parâmetros

| Parâmetro     | Tipo             | Descrição                                                          |
| ------------- | ---------------- | -------------------------------------------------------------------- |
| `amount`      | `u64`            | Quantidade de tokens a retirar, na menor unidade do token           |
| `destination` | `Option<Pubkey>` | Carteira de destino na Mainnet; se `None`, assume por defeito a carteira do assinante |

## Retorna

Retorna um `TransactionBuilder` que pode ser utilizado para construir e enviar a
transação.

## Exemplo

```typescript
import { getWithdrawFundsInstruction } from "../private-channel-withdraw-program/clients/typescript/src/generated";

const withdrawIx = getWithdrawFundsInstruction({
  user: userSigner,
  mint: mintAddress,
  tokenAccount: channelTokenAccount,
  tokenProgram: TOKEN_PROGRAM_ID,
  associatedTokenProgram: ASSOCIATED_TOKEN_PROGRAM_ID,
  amount: 1_000_000n,
  destination: null // null = release to signer's Mainnet wallet
});
```

## Notas Importantes

- Esta instrução encontra-se no **Programa de Retirada**
  (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi` devnet), não no Programa de
  Escrow
- A queima de tokens do lado do canal **não** liberta automaticamente os fundos na
  Mainnet; um operador deve posteriormente chamar `ReleaseFunds` no Programa de
  Escrow com uma prova de exclusão SMT válida
- O erro `ZeroAmount` é lançado se `amount` for 0
- Se `destination` for `None`, a chamada `ReleaseFunds` do operador libertará
  os fundos para a carteira do assinante

Para a referência completa de códigos de erro de ambos os programas, consulte
[Instruções -> Códigos de Erro](/docs/tools/private-channels/instructions#error-codes).
