Esta seção é a referência de instruções on-chain. A maioria dos desenvolvedores chama essas
instruções por meio dos clientes TypeScript gerados; você só precisa disto se estiver
construindo ferramentas de operador, escrevendo integrações personalizadas ou depurando
erros no nível de instrução.

**Programa Escrow** (`9tgHa1DcnaSSUtmMsst8ovKTe1Gfxzezn27KnH9xXYeU`) - gerencia
depósitos, provisionamento de operadores e liquidação na Mainnet:

- [CreateInstance](/docs/tools/private-channels/instructions/create-instance) -
  inicializar o PDA da instância de escrow
- [AllowMint](/docs/tools/private-channels/instructions/allow-mint) - adicionar
  um mint de token SPL à lista de permissões
- [BlockMint](/docs/tools/private-channels/instructions/block-mint) - remover um
  mint da lista de permissões
- [AddOperator](/docs/tools/private-channels/instructions/add-operator) -
  provisionar um operador
- [RemoveOperator](/docs/tools/private-channels/instructions/remove-operator) -
  revogar um operador
- [SetNewAdmin](/docs/tools/private-channels/instructions/set-new-admin) -
  transferir direitos de administrador
- [Deposit](/docs/tools/private-channels/instructions/deposit) - mover tokens SPL
  para o escrow
- [Release Funds](/docs/tools/private-channels/instructions/release-funds) -
  operador liquida um saque para a Mainnet
- [Reset SMT Root](/docs/tools/private-channels/instructions/reset-smt-root) -
  operador rotaciona a Sparse Merkle Tree

**Programa Withdraw** (`J231K9UEpS4y4KAPwGc4gsMNCjKFRMYcQBcjVW7vBhVi`) - executado na
rede de canais privados:

- [Withdraw Funds](/docs/tools/private-channels/instructions/withdraw-funds) -
  queimar saldo do lado do canal para iniciar um saque

## Códigos de Erro

**Programa Escrow - `PrivateChannelEscrowProgramError`**

| Código                                         | Mensagem                                          |
| -------------------------------------------- | ------------------------------------------------ |
| `InvalidEventAuthority`                      | Autoridade de evento inválida fornecida                 |
| `InvalidAta`                                 | ATA inválida fornecida                             |
| `InvalidMint`                                | Mint inválido fornecido                            |
| `InvalidInstanceId`                          | ID de instância inválido ou não respeita as regras    |
| `InvalidInstance`                            | Instância inválida fornecida                        |
| `InvalidAdmin`                               | Administrador inválido fornecido                           |
| `TransferHookNotAllowed`                     | Extensão de transfer hook não permitida              |
| `InvalidOperatorPda`                         | PDA de operador inválido fornecido                    |
| `InvalidTokenAccount`                        | token account inválida fornecida                   |
| `InvalidEscrowBalance`                       | Saldo de escrow inválido                           |
| `InvalidAllowedMint`                         | Mint permitido inválido                             |
| `InvalidSmtProof`                            | Prova SMT inválida fornecida                       |
| `InvalidTransactionNonceForCurrentTreeIndex` | Nonce de transação inválido para o índice de árvore atual |
| `UnexpectedTreeIndex`                        | Índice de árvore atual inesperado para redefinição da raiz SMT |

**Programa Withdraw - `PrivateChannelWithdrawProgramError`**

| Código          | Mensagem                                     |
| ------------- | ------------------------------------------- |
| `InvalidMint` | Mint inválido fornecido                       |
| `ZeroAmount`  | O valor do saque deve ser maior que zero |
