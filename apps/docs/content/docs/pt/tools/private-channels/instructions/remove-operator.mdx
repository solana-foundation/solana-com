---
title: RemoveOperator
description: Revoga um operador encerrando seu PDA de Operador
---

Revoga um operador encerrando seu PDA `Operator`. A carteira revogada não
pode mais chamar `ReleaseFunds` ou `ResetSmtRoot`.

## Contas

| Conta                          | Gravável | Assinante | Descrição                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | Pagador de taxas                                 |
| `admin`                          |          | ✓      | Administrador da instância                            |
| `instance`                       |          |        | PDA da instância                              |
| `operator`                       |          |        | Carteira do operador a ser revogada                 |
| `operator_pda`                   | ✓        |        | PDA do Operador (encerrado por esta instrução) |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | PDA de autoridade de eventos                       |
| `private_channel_escrow_program` |          |        | Programa de Escrow                            |

Esta instrução não aceita parâmetros.

## Notas Importantes

- Encerra o `operator_pda`; a carteira revogada não pode mais chamar
  `ReleaseFunds` ou `ResetSmtRoot`
- Quaisquer transações de operador em andamento falharão com `InvalidOperatorPda` após
  esta chamada
- Emite um evento via CPI `EmitEvent`
