---
title: RemoveOperator
description: Revoga um operador ao fechar o seu PDA de Operador
---

Revoga um operador ao fechar o seu PDA `Operator`. A carteira revogada não
pode mais chamar `ReleaseFunds` ou `ResetSmtRoot`.

## Contas

| Conta                          | Gravável | Signatário | Descrição                               |
| -------------------------------- | -------- | ------ | ----------------------------------------- |
| `payer`                          | ✓        | ✓      | Pagador de taxa                                 |
| `admin`                          |          | ✓      | Administrador da instância                            |
| `instance`                       |          |        | PDA de instância                              |
| `operator`                       |          |        | Carteira do operador a revogar                 |
| `operator_pda`                   | ✓        |        | PDA do Operador (fechado por esta instrução) |
| `system_program`                 |          |        | System Program                            |
| `event_authority`                |          |        | PDA de autoridade de evento                       |
| `private_channel_escrow_program` |          |        | Programa de Escrow                            |

Esta instrução não recebe parâmetros.

## Notas Importantes

- Fecha o `operator_pda`; a carteira revogada não pode mais chamar
  `ReleaseFunds` ou `ResetSmtRoot`
- Quaisquer transações de operador em curso falharão com `InvalidOperatorPda` após
  esta chamada
- Emite um evento via CPI `EmitEvent`
