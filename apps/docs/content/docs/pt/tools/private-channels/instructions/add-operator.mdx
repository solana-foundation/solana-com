---
title: AddOperator
description: Provisiona um novo operador criando seu Operator PDA
---

Provisiona um novo operador criando seu PDA `Operator`. Após esta chamada, a
carteira `operator` pode chamar `ReleaseFunds` e `ResetSmtRoot`.

## Contas

| Conta                          | Gravável | Signatário | Descrição                                                         |
| -------------------------------- | -------- | ------ | ------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Pagador de taxas                                                           |
| `admin`                          |          | ✓      | Administrador da instância                                                      |
| `instance`                       |          |        | PDA da instância                                                        |
| `operator`                       |          |        | Carteira do operador a provisionar                                        |
| `operator_pda`                   | ✓        |        | PDA do operador - derivado automaticamente de `["operator", instance, operator]` |
| `system_program`                 |          |        | System Program                                                      |
| `event_authority`                |          |        | PDA de autoridade de eventos                                                 |
| `private_channel_escrow_program` |          |        | Programa de Escrow                                                      |

## Parâmetros

| Parâmetro | Tipo | Descrição                                                                               |
| --------- | ---- | ----------------------------------------------------------------------------------------- |
| `bump`    | `u8` | bump seed para o `operator_pda`. Opcional: o cliente `Async` o deriva automaticamente se omitido |

> O IDL contém um argumento `discriminator: u8` (valor `3`) que é definido automaticamente
> pelo cliente gerado e não deve ser passado manualmente.

## Notas Importantes

- Use `getAddOperatorInstructionAsync`; ele deriva automaticamente `bump` e
  `operator_pda` quando não fornecidos. Uma variante síncrona
  `getAddOperatorInstruction` também existe caso você já tenha calculado o `bump`
  por conta própria
- Após esta chamada, a carteira `operator` pode chamar `ReleaseFunds` e
  `ResetSmtRoot`
- Emite um evento via CPI `EmitEvent`
