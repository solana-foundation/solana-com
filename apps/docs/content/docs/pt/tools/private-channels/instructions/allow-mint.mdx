---
title: AllowMint
description:
  Permite um mint de token SPL na instância e cria o ATA de custódia para esse mint
---

Permite um mint de token SPL na instância e cria o associated
token account de custódia para esse mint. Os depósitos para este mint tornam-se possíveis após esta
chamada.

## Contas

| Conta                          | Gravável | Assinante | Descrição                                                                   |
| -------------------------------- | -------- | ------ | ----------------------------------------------------------------------------- |
| `payer`                          | ✓        | ✓      | Pagador de taxas                                                                     |
| `admin`                          |          | ✓      | Administrador da instância                                                                |
| `instance`                       |          |        | PDA da instância                                                                  |
| `mint`                           |          |        | Mint de token SPL a permitir                                                       |
| `allowed_mint`                   | ✓        |        | PDA AllowedMint (criado por esta instrução)                                 |
| `instance_ata`                   | ✓        |        | associated token account de custódia para este mint (criado por esta instrução) |
| `system_program`                 |          |        | System Program                                                                |
| `token_program`                  |          |        | SPL Token Program                                                             |
| `associated_token_program`       |          |        | Associated Token Program                                                      |
| `event_authority`                |          |        | PDA de autoridade de eventos                                                           |
| `private_channel_escrow_program` |          |        | Programa de Custódia                                                                |

## Parâmetros

| Parâmetro | Tipo | Descrição                                                                                   |
| --------- | ---- | --------------------------------------------------------------------------------------------- |
| `bump`    | `u8` | Bump seed para o PDA `allowed_mint`. Opcional: o cliente `Async` deriva-o automaticamente se omitido |

> O IDL contém um argumento `discriminator: u8` (valor `1`) que é definido automaticamente
> pelo cliente gerado e não deve ser passado manualmente.

## Notas Importantes

- Use `getAllowMintInstructionAsync`; ele deriva automaticamente `bump`, `allowed_mint`,
  e `instance_ata` quando não são fornecidos. Passe o seu próprio `bump` apenas se
  já o calculou via
  `Pubkey::find_program_address(&[b"allowed_mint", instance_pda, mint], &PROGRAM_ID)`
- Também cria `instance_ata`, o ATA de custódia para este mint
- Mints com extensão de transfer hook são explicitamente bloqueados: tentar
  permitir tal mint lança `TransferHookNotAllowed`
- Emite um evento via CPI `EmitEvent`
