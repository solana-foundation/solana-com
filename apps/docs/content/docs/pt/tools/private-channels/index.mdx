**Private Channels é uma camada empresarial para mercados de capitais na internet sobre
Solana.** Oferece uma camada de aplicação configurável para transferências privadas, instantâneas e sem taxas
dentro de canais de pagamento: os utilizadores depositam tokens SPL num programa de
escrow on-chain, realizam transações off-chain através de um gateway e liquidam de volta à Mainnet
via uma prova de Sparse Merkle Tree, proporcionando aos programadores de aplicações transferências instantâneas, sem taxas e privadas
sem sair do ecossistema Solana.

### Por que Private Channels?

- **Transferências instantâneas**: throughput off-chain além do TPS nativo da Solana;
  as transferências confirmam quando o sequenciador as processa, não quando um bloco é confirmado
- **Zero taxas por transferência**: sem custo de gas em transferências individuais de canal; os utilizadores
  pagam apenas por depósitos e levantamentos on-chain
- **Privacidade**: as transferências entre participantes do canal não são registadas na
  Mainnet da Solana
- **Acesso permissionado**: RBAC com autenticação JWT permite controlar quem pode
  enviar e receber
- **Liquidação na Mainnet**: os fundos são sempre resgatáveis para a Solana via uma prova de exclusão de Sparse
  Merkle Tree, que o programa de escrow aplica on-chain

Consulte a **[Visão Geral](/docs/tools/private-channels/overview)** para a arquitetura completa,
diagrama de fluxo de dados e modelo de segurança.

## Início Rápido

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n, // 1 USDC
  recipient: null
});
// send via your preferred Solana client
```

Os clientes TypeScript são gerados a partir do IDL; consulte Instalação. Para cunhagens Token-2022,
passe `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS` explicitamente, pois o padrão
é o SPL Token Program padrão.

## Casos de Uso

- **Pagamentos bilaterais institucionais** - bancos e instituições que precisam
  de fluxos de USDC privados e de alto volume sem que cada transferência apareça on-chain
- **Transferências de camada de aplicação de alta frequência** - jogos, fidelização e aplicações de consumo
  que precisam de transferências sub-segundo e sem taxas em escala além do TPS nativo da Solana
- **Fluxos de tokens com preservação de privacidade** - qualquer caso de uso em que a privacidade da contraparte e
  do valor seja um requisito do produto

**[Quando usar transferências SPL nativas em vez disso](/docs/tools/private-channels/concepts/channels#when-to-use-private-channels)**
