**Os Canais Privados são uma camada empresarial para mercados de capitais na internet sobre
Solana.** Fornece uma camada de aplicação configurável para transferências privadas, instantâneas e sem taxas
dentro de canais de pagamento: os utilizadores depositam tokens SPL num programa de
custódia on-chain, realizam transações off-chain através de um gateway e liquidam de volta para a Mainnet
via uma prova de Sparse Merkle Tree, proporcionando aos programadores de aplicações transferências instantâneas, sem taxas e privadas
sem sair do ecossistema Solana.

### Por que Canais Privados?

- **Transferências instantâneas**: débito off-chain além do TPS nativo da Solana;
  as transferências são confirmadas quando o sequenciador as processa, e não quando um bloco é confirmado
- **Zero taxas por transferência**: sem custo de gas em transferências individuais no canal; os utilizadores
  pagam apenas pelos depósitos e levantamentos on-chain
- **Privacidade**: as transferências entre participantes do canal não são registadas na
  Mainnet da Solana
- **Acesso permissionado**: RBAC com autenticação JWT permite controlar quem pode
  enviar e receber
- **Liquidação na Mainnet**: os fundos são sempre resgatáveis para a Solana via uma prova de exclusão de Sparse
  Merkle Tree, que o programa de custódia aplica on-chain

Consulte a **[Visão Geral](/docs/tools/private-channels/overview)** para a arquitetura completa,
o diagrama de fluxo de dados e o modelo de segurança.

## Início Rápido

```typescript
import { getDepositInstructionAsync } from "../private-channel-escrow-program/clients/typescript/src/generated";

const depositIx = await getDepositInstructionAsync({
  payer: payerSigner,
  user: userSigner,
  instance: instancePda,
  mint: mintAddress,
  userAta: userAtaAddress,
  amount: 1_000_000n, // 1 USDC
  recipient: null
});
// send via your preferred Solana client
```

Os clientes TypeScript são gerados a partir do IDL; consulte a Instalação. Para cunhagens Token-2022,
passe `tokenProgram: TOKEN_2022_PROGRAM_ADDRESS` explicitamente, pois o padrão é o
SPL Token Program padrão.

## Casos de Uso

- **Pagamentos bilaterais institucionais** - bancos e instituições que necessitam
  de fluxos de USDC privados e de alto volume sem que cada transferência apareça on-chain
- **Transferências de camada de aplicação de alta frequência** - jogos, fidelização e aplicações de consumo
  que necessitam de transferências sub-segundo e sem taxas em escala além do TPS nativo da Solana
- **Fluxos de tokens com preservação de privacidade** - qualquer caso de uso em que a privacidade da contraparte e
  do montante seja um requisito do produto

**[Quando usar transferências SPL nativas em vez disso](/docs/tools/private-channels/concepts/channels#when-to-use-private-channels)**
