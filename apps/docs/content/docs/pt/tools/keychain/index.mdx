title: Keychain

**O Solana Keychain oferece uma interface unificada para assinar transações Solana
em vários backends de gerenciamento de chaves.** Desenvolva localmente com uma chave
em memória e, em produção, passe para gerenciamento de chaves corporativo, HSMs na nuvem ou serviços de carteira
gerenciados, sem reescrever seu código de assinatura.

### Por que Keychain?

- **Interface única**: Uma interface base `SolanaSigner` para todos os backends,
  mais uma capacidade por backend: assinar, reescrever e assinar, ou assinar e transmitir
- **Troque de backend**: Mude de provedor de gerenciamento de chaves por meio de configuração; os
  pontos de chamada só mudam quando o novo backend tem uma capacidade diferente (modos nativos da Crossmint
  e da Fordefi)
- **Pague apenas pelo que usar**: Feature flags do Rust, pacotes npm por backend, extras do Python
  e módulos Go por backend incluem apenas os backends de que você precisa
- **Auditado**: Rust, TypeScript, Python e Go auditados pela
  [OtterSec](https://osec.io) (o backend opcional da Ledger ficou fora do escopo); uma
  auditoria anterior da [Accretion](https://accretion.xyz) cobriu Rust e TypeScript.
  Consulte o
  [status das auditorias](https://github.com/solana-foundation/solana-keychain/blob/main/audits/AUDIT_STATUS.md).

### Arquitetura

- **Linguagens**: Rust, TypeScript, Python e Go, em paridade (o backend Ledger
  existe apenas em Rust)
- **Interface**: base `SolanaSigner` (`pubkey`, `sign_message`, `is_available`)
  mais exatamente uma capacidade por backend: `TransactionSigner`,
  `ModifyingSigner` ou `SendingSigner`
- **Backends**: Memory, Vault, AWS KMS, GCP KMS, Privy, Turnkey, Fireblocks,
  CDP, Crossmint, Dfns, Openfort, Para, Utila, Fordefi, Ledger (somente Rust,
  opcional, não auditado)
- **Compatibilidade**: `@solana/kit` e `@solana/signers` 8.1+ (TypeScript) |
  `solana-sdk` 2.x, 3.x ou 4.x por meio dos recursos `sdk-v2` / `sdk-v3` / `sdk-v4`
  (Rust; transações v1 exigem `sdk-v4`) | `solders` (Python) | `solana-go` v2
  (Go)

### Backends Suportados

Os backends abrangem desenvolvimento local, gerenciamento de chaves
auto-hospedado e em nuvem, e serviços de carteira gerenciada ou MPC. Consulte
[Como escolher um backend](/docs/tools/keychain/choosing-a-backend) para
comparar os modelos de custódia e escolher o mais adequado.

| Backend         | Caso de Uso                            | Rust | TypeScript | Python | Go  |
| --------------- | ----------------------------------- | ---- | ---------- | ------ | --- |
| Memory          | Desenvolvimento, testes                | ✓    | ✓          | ✓      | ✓   |
| HashiCorp Vault | Gerenciamento de chaves próprio          | ✓    | ✓          | ✓      | ✓   |
| AWS KMS         | Nativo em nuvem (AWS)                  | ✓    | ✓          | ✓      | ✓   |
| GCP KMS         | Nativo em nuvem (GCP)                  | ✓    | ✓          | ✓      | ✓   |
| Privy           | Carteiras integradas                    | ✓    | ✓          | ✓      | ✓   |
| Turnkey         | Gerenciamento de chaves sem custódia        | ✓    | ✓          | ✓      | ✓   |
| Fireblocks      | Custódia institucional               | ✓    | ✓          | ✓      | ✓   |
| CDP             | Coinbase Developer Platform         | ✓    | ✓          | ✓      | ✓   |
| Crossmint       | Carteiras gerenciadas Crossmint           | ✓    | ✓          | ✓      | ✓   |
| Dfns            | Infraestrutura de carteiras Dfns          | ✓    | ✓          | ✓      | ✓   |
| Openfort        | Carteiras backend Openfort            | ✓    | ✓          | ✓      | ✓   |
| Para            | Carteiras MPC Para                    | ✓    | ✓          | ✓      | ✓   |

| Fordefi         | Custódia MPC Fordefi                 | ✓    | ✓          | ✓      | ✓   |

## Início Rápido

### Rust

Instale o crate Rust:

```bash
cargo add solana-keychain
```

Uso básico:

```rust
use solana_keychain::{Signer, SolanaSigner};

// Create a signer from any backend
let signer = Signer::from_memory("base58_private_key")?;
let pubkey = signer.pubkey();

// Transaction signing is a capability; `tx` is a VersionedTransaction
if let Some(tx_signer) = signer.as_transaction_signer() {
    let result = tx_signer.sign_transaction(&mut tx).await?;
}

// Or let the umbrella route any backend shape and supply the RPC hop yourself
let signature = signer
    .sign_and_send(&mut tx, |encoded| async move { broadcast(encoded).await })
    .await?;
```

- [Guia Rust](/docs/tools/keychain/getting-started/rust) - Instalação completa e
  configuração de backend
- [Crates.io](https://crates.io/crates/solana-keychain) - Crate Rust

### TypeScript

Instale o pacote TypeScript:

```bash
pnpm add @solana/keychain
```

Uso básico:

```typescript
import { createKeychainSigner } from "@solana/keychain";
import { signTransactionWithSigners } from "@solana/signers";

// Create any signer via the unified factory
const signer = await createKeychainSigner({
  backend: "vault",
  vaultAddr: "https://vault.example.com:8200",
  vaultToken: "hvs.xxxxx",
  keyName: "my-solana-key",
  publicKey: "base58_public_key"
});

// Sign an already-compiled transaction
const signedTx = await signTransactionWithSigners(
  [signer],
  compiledTransaction
);
```

- [Guia TypeScript](/docs/tools/keychain/getting-started/typescript) - Pacotes
  `@solana/keychain`
- [Pacote npm](https://www.npmjs.com/package/@solana/keychain) - Pacote npm

Para instalar um signer do Keychain em um cliente [Kit](https://github.com/anza-xyz/kit)
como `payer` ou `identity`, use `@solana/keychain-kit-plugin` (os modos nativos da Crossmint e
da Fordefi são excluídos, pois reescrevem transações).

### Python

Instale o pacote (os backends mais pesados são distribuídos como extras, por exemplo
`solana-keychain[aws-kms]`):

```bash
pip install solana-keychain
```

Uso básico:

```python
import os

from solana_keychain import VaultSignerConfig, create_vault_signer

signer = await create_vault_signer(
    VaultSignerConfig(
        api_base_url="https://vault.example.com:8200",
        token=os.environ["VAULT_TOKEN"],
        key_name="my-solana-key",
        public_key="base58_public_key",
    )
)

# tx is a solders VersionedTransaction
result = await signer.sign_transaction(tx)
```

- [Guia de Python](/docs/tools/keychain/getting-started/python) - Instalação
  completa, extras e configuração de backends
- [PyPI](https://pypi.org/project/solana-keychain/) - Pacote Python

### Go

Cada backend é um módulo Go independente, então você só baixa os backends que importar:

```bash
go get github.com/solana-foundation/solana-keychain/go/signers/vault/v2@latest
```

Uso básico:

```go
import "github.com/solana-foundation/solana-keychain/go/signers/vault/v2"

signer, err := vault.New(vault.Config{
	VaultAddr: "https://vault.example.com:8200",
	Token:     os.Getenv("VAULT_TOKEN"),
	KeyName:   "my-solana-key",
	Pubkey:    "base58_public_key",
})
if err != nil {
	return err
}

// tx is a *solana.Transaction from solana-go v2
res, err := signer.SignTransaction(ctx, tx)
```

- [Guia de Go](/docs/tools/keychain/getting-started/go) - Módulos, capacidades
  e configuração de backends
- [pkg.go.dev](https://pkg.go.dev/github.com/solana-foundation/solana-keychain/go/core/v2) -
  Referência de Go
