## Solana Kit

`@solana/kit` é o SDK TypeScript recomendado para desenvolver na Solana. Você
monta um cliente a partir de plugins combináveis, adiciona bindings React quando
necessário e importa clientes de programa gerados para os programas on-chain que
você utiliza.

| Pacote                   | Descrição                                  | GitHub                                                                                 |
| ------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------- |
| @solana/kit               | SDK principal: RPC, transações, codecs, signatários | [Fonte](https://github.com/anza-xyz/kit)                                              |
| @solana/react             | Bindings React: `ClientProvider` e hooks   | [Fonte](https://github.com/anza-xyz/kit/tree/main/packages/react)                     |
| @solana/kit-plugin-rpc    | Conexão RPC + envio de transações         | [Fonte](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-rpc)    |
| @solana/kit-plugin-signer | Plugins de pagador de taxas, identidade e signatário      | [Fonte](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-signer) |
| @solana/kit-plugin-wallet | Conexão Wallet Standard + hooks React     | [Fonte](https://github.com/anza-xyz/kit-plugins/tree/main/packages/kit-plugin-wallet) |

## Solana Web3.js v3

`@solana/web3.js` v3 é a versão recomendada do web3.js. Ela reconstrói a
API clássica baseada em classes — `Connection`, `Keypair`, `Transaction`, `PublicKey` —
sobre os componentes internos do `@solana/kit`, de modo que funciona com as primitivas do Kit e com os
clientes de programas acima. Use-a se estiver atualizando um aplicativo web3.js existente ou
preferir a API baseada em classes.

A maioria dos métodos que eram síncronos no SDK legado, como
`Keypair.generate()` e `transaction.sign()`, agora são assíncronos.

```bash
npm install @solana/web3.js@3
```

| Pacote         | Descrição | GitHub                                                        |
| --------------- | ----------- | ------------------------------------------------------------- |
| @solana/web3.js | SDK principal    | [Fonte](https://github.com/solana-foundation/solana-web3.js) |

O `@solana/spl-token` depende do `@solana/web3.js` (legado) e não funciona na
v3. Use `@solana-program/token` ou `@solana-program/token-2022`; as
instruções geradas e os planos de instruções deles funcionam diretamente com o
`Transaction.add()` da v3.

- [Guia de migração do web3.js v1 para o v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
- [Guia de migração do spl-token](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-spl-token-migration.md)

## Solana Web3.js (legado)

`@solana/web3.js` (legado, `1.x`) é o SDK original em TypeScript para a Solana. Ele
está em modo de manutenção e recebe apenas correções críticas. As bases de código existentes podem
[atualizar para o web3.js v3](https://github.com/solana-foundation/solana-web3.js/blob/main/docs/web3js-v1-to-v3-migration.md)
ou [migrar para o Kit](/docs/frontend/web3-compat).
