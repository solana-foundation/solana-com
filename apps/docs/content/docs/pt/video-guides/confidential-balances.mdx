Os Saldos Confidenciais são uma extensão do Token-2022 que mantém os valores das transferências e
os saldos criptografados na Solana, enquanto os endereços das token account permanecem públicos.
Este vídeo explica como funciona e por que isso é importante para folhas de pagamento, negociação e
pagamentos do dia a dia. Combine-o com o
[guia de Saldos Confidenciais](/docs/tokens/extensions/confidential-transfer).
