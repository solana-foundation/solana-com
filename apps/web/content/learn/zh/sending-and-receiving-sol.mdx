# 发送和接收 SOL

能够发送和接收 SOL 是你在 Solana 上的第一项实用技能。SOL 是 Solana 网络的原生代币，用于交易、质押以及与应用交互。在本章中，你将了解转账的工作原理，并实践完成你的第一笔交易。

## 你将学到什么

学完本章后，你将能够：

- 了解你的钱包地址以及如何安全地分享它
- 向其他钱包发送 SOL
- 接收他人发来的 SOL
- 查看交易状态
- 了解转账过程中发生了什么

## 了解你的钱包地址

你的钱包地址就像你在 Solana 上的账号。它具有以下特点：

- **公开**：接收资金时可以放心分享
- **唯一**：不会有两个钱包拥有相同的地址
- **永久**：不会更改，也不会过期

示例地址：`7xKXtg2CW87d8V6zXKBq7cM8Y2FPHwzaAkxqEqD7x4rH`

### 分享你的地址

你可以通过以下方式分享地址：

- **复制/粘贴**：点击钱包中的复制按钮
- **二维码**：让他人用手机扫描
- **ENS/域名**：便于人类阅读的名称（例如 `yourname.sol`）

## 接收 SOL

![接收 SOL 的四步流程：打开钱包、找到地址、分享地址、查看新余额](/images/learn/receiving_sol.webp)

接收 SOL 非常简单：

1. **打开你的钱包**
2. **找到你的地址**（通常显示在顶部）
3. **将地址分享**给发送方
4. **等待几秒钟**，交易即可完成
5. **查看你的新余额**，余额会自动更新

### 发送方需要什么

当有人向你发送 SOL 时，他们只需要：

- 你的钱包地址
- 发送金额

他们不需要你的姓名、位置或任何个人信息。

## 发送 SOL

![发送 SOL 的三步流程：获取收款方地址、发起转账、确认并发送](/images/learn/sending_sol.webp)

以下是向他人发送 SOL 的方法：

### 第 1 步：获取收款方地址

- 请对方分享其 Solana 钱包地址
- 仔细核对你获得的地址是否正确
- 请记住：交易无法撤销

### 第 2 步：发起转账

1. 点击钱包中的“发送”
2. 粘贴收款方地址
3. 输入 SOL 金额
4. 查看交易手续费（通常低于 0.001 美元）

### 第 3 步：确认并发送

1. 仔细核对所有详情
2. 确认交易
3. 等待 1-2 秒即可完成
4. 保存交易 ID 以便日后查阅

## 了解交易详情

每笔交易都会生成一条记录，包含：

- **签名**：唯一的交易标识符
- **发送方/接收方**：发送方和接收方地址
- **金额**：转账的 SOL 数量
- **手续费**：已支付的网络费用（以 SOL 计）
- **时间戳**：交易发生的时间
- **状态**：成功或失败

你可以在 Solscan 或 Solana Explorer 等区块浏览器上查看任意交易。

## 常见问题

### 转账需要多长时间？

通常需要 1-2 秒。与传统银行相比，Solana 处理交易的速度非常快。

### 如果我发送到了错误的地址怎么办？

交易是永久性的，无法撤销。发送前务必仔细核对地址。

### 为什么我需要 SOL 来支付手续费？

每笔交易都需要支付少量费用，用于补偿处理交易的网络 validator：每个签名收取 0.000005 SOL 的基础费用，网络繁忙时还可额外支付可选的优先费用。

### 除了 SOL，我还可以发送其他代币吗？

可以，但即使发送其他代币，你也始终需要少量 SOL 来支付交易手续费。

## 实践练习

准备好尝试你的第一笔交易了吗？下面是一种安全的练习方式：

1. **发送极小金额**（例如 0.001 SOL）给朋友
2. **让对方转回给你**
3. **在区块浏览器上查询该交易**
4. **记下手续费**和确认时间

这样你就可以用极小的金额熟悉整个流程。

## 交易最佳实践

- 向新地址转账时，**先从小额开始**
- **将重要地址保存**到钱包的地址簿中
- **保留交易记录**，以便报税或个人追踪
- **仔细核对地址**——尤其是前 4 位和后 4 位字符
- 发送时**留意当前 SOL 的价格**
