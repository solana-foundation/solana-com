# Αποστολή και λήψη SOL

Η δυνατότητα αποστολής και λήψης SOL είναι η πρώτη σας πρακτική δεξιότητα στο Solana. Το SOL
είναι το εγγενές token του δικτύου Solana και χρησιμοποιείται για συναλλαγές, staking και
αλληλεπίδραση με εφαρμογές. Σε αυτό το κεφάλαιο, θα μάθετε πώς λειτουργούν οι μεταφορές
και θα εξασκηθείτε κάνοντας την πρώτη σας συναλλαγή.

## Τι θα μάθετε

Μέχρι το τέλος αυτού του κεφαλαίου, θα είστε σε θέση να:

- Κατανοείτε τη διεύθυνση του πορτοφολιού σας και πώς να την μοιράζεστε με ασφάλεια
- Στέλνετε SOL σε ένα άλλο πορτοφόλι
- Λαμβάνετε SOL από άλλους
- Ελέγχετε την κατάσταση μιας συναλλαγής
- Κατανοείτε τι συμβαίνει κατά τη διάρκεια μιας μεταφοράς

## Κατανοώντας τη διεύθυνση του πορτοφολιού σας

Η διεύθυνση του πορτοφολιού σας είναι σαν τον αριθμό λογαριασμού σας στο Solana. Είναι:

- **Δημόσια**: Ασφαλής για κοινοποίηση όταν λαμβάνετε κεφάλαια
- **Μοναδική**: Δύο πορτοφόλια δεν έχουν ποτέ την ίδια διεύθυνση
- **Μόνιμη**: Δεν αλλάζει και δεν λήγει

Παράδειγμα διεύθυνσης: `7xKXtg2CW87d8V6zXKBq7cM8Y2FPHwzaAkxqEqD7x4rH`

### Κοινοποίηση της διεύθυνσής σας

Μπορείτε να μοιραστείτε τη διεύθυνσή σας μέσω:

- **Αντιγραφής/Επικόλλησης**: Πατήστε το κουμπί αντιγραφής στο πορτοφόλι σας
- **Κωδικού QR**: Αφήστε τους άλλους να τον σαρώσουν με το κινητό τους
- **ENS/Ονομάτων τομέα**: Ονόματα εύκολα στην ανάγνωση (όπως `yourname.sol`)

## Λήψη SOL

![Διαδικασία τεσσάρων βημάτων για τη λήψη SOL: Ανοίξτε το πορτοφόλι, βρείτε τη διεύθυνση, μοιραστείτε τη διεύθυνση, δείτε το νέο υπόλοιπο](/images/learn/receiving_sol.webp)

Η λήψη SOL είναι απλή:

1. **Ανοίξτε το πορτοφόλι σας**
2. **Βρείτε τη διεύθυνσή σας** (συνήθως εμφανίζεται στην κορυφή)
3. **Μοιραστείτε την** με τον αποστολέα
4. **Περιμένετε μερικά δευτερόλεπτα** για την ολοκλήρωση της συναλλαγής
5. **Δείτε το νέο σας υπόλοιπο** να ενημερώνεται αυτόματα

### Τι χρειάζονται οι αποστολείς

Όταν κάποιος σας στέλνει SOL, χρειάζεται μόνο:

- Τη διεύθυνση του πορτοφολιού σας
- Το ποσό που θα αποστείλει

Δεν χρειάζονται το όνομά σας, την τοποθεσία σας ή οποιαδήποτε προσωπική πληροφορία.

## Αποστολή SOL

![Διαδικασία τριών βημάτων για την αποστολή SOL: Λάβετε τη διεύθυνση του παραλήπτη, ξεκινήστε τη μεταφορά, επιβεβαιώστε και στείλτε](/images/learn/sending_sol.webp)

Δείτε πώς μπορείτε να στείλετε SOL σε κάποιον άλλον:

### Βήμα 1: Λάβετε τη διεύθυνση του παραλήπτη

- Ζητήστε του να μοιραστεί τη διεύθυνση του πορτοφολιού του στο Solana
- Ελέγξτε διπλά ότι έχετε τη σωστή διεύθυνση
- Θυμηθείτε: οι συναλλαγές δεν μπορούν να αντιστραφούν

### Βήμα 2: Ξεκινήστε τη μεταφορά

1. Πατήστε «Αποστολή» στο πορτοφόλι σας
2. Επικολλήστε τη διεύθυνση του παραλήπτη
3. Εισαγάγετε το ποσό σε SOL
4. Ελέγξτε την προμήθεια συναλλαγής (συνήθως < $0.001)

### Βήμα 3: Επιβεβαιώστε και στείλτε

1. Ελέγξτε προσεκτικά όλα τα στοιχεία
2. Επιβεβαιώστε τη συναλλαγή
3. Περιμένετε 1-2 δευτερόλεπτα για την ολοκλήρωση
4. Αποθηκεύστε το αναγνωριστικό της συναλλαγής για τα αρχεία σας

## Κατανοώντας τις λεπτομέρειες μιας συναλλαγής

Κάθε συναλλαγή δημιουργεί μια εγγραφή που περιέχει:

- **Υπογραφή**: Μοναδικό αναγνωριστικό συναλλαγής
- **Από/Προς**: Διευθύνσεις αποστολέα και παραλήπτη
- **Ποσό**: Πόσα SOL μεταφέρθηκαν
- **Προμήθεια**: Η προμήθεια δικτύου που πληρώθηκε (σε SOL)
- **Χρονοσήμανση**: Πότε πραγματοποιήθηκε
- **Κατάσταση**: Επιτυχία ή αποτυχία

Μπορείτε να δείτε οποιαδήποτε συναλλαγή σε έναν block explorer, όπως το Solscan ή το Solana
Explorer.

## Συχνές ερωτήσεις

### Πόσο διαρκούν οι μεταφορές;

Συνήθως 1-2 δευτερόλεπτα. Το Solana επεξεργάζεται τις συναλλαγές πολύ γρήγορα σε σύγκριση
με τις παραδοσιακές τράπεζες.

### Τι γίνεται αν στείλω σε λάθος διεύθυνση;

Οι συναλλαγές είναι μόνιμες και δεν μπορούν να αντιστραφούν. Να ελέγχετε πάντα διπλά τις διευθύνσεις
πριν από την αποστολή.

### Γιατί χρειάζομαι SOL για τις προμήθειες;

Κάθε συναλλαγή απαιτεί μια μικρή προμήθεια για την αποζημίωση των validators του δικτύου που
την επεξεργάζονται: μια βασική προμήθεια 0.000005 SOL ανά υπογραφή, συν μια προαιρετική
προμήθεια προτεραιότητας όταν το δίκτυο έχει φόρτο.

### Μπορώ να στείλω και άλλα tokens εκτός από SOL;

Ναι, αλλά θα χρειάζεστε πάντα μια μικρή ποσότητα SOL για τις προμήθειες συναλλαγών, ακόμη
και όταν στέλνετε άλλα tokens.

## Άσκηση εξάσκησης

Είστε έτοιμοι να δοκιμάσετε την πρώτη σας συναλλαγή; Ακολουθεί ένας ασφαλής τρόπος εξάσκησης:

1. **Στείλτε ένα πολύ μικρό ποσό** (π.χ. 0.001 SOL) σε έναν φίλο
2. **Ζητήστε του να σας το στείλει πίσω**
3. **Αναζητήστε τη συναλλαγή** σε έναν block explorer
4. **Σημειώστε την προμήθεια** και τον χρόνο επιβεβαίωσης

Αυτό σας βοηθά να νιώσετε άνετα με τη διαδικασία χρησιμοποιώντας ελάχιστα ποσά.

## Βέλτιστες πρακτικές για συναλλαγές

- **Ξεκινήστε με μικρό ποσό** όταν στέλνετε σε μια νέα διεύθυνση
- **Αποθηκεύστε τις σημαντικές διευθύνσεις** στο βιβλίο διευθύνσεων του πορτοφολιού σας
- **Κρατήστε αρχεία συναλλαγών** για φορολογική ή προσωπική παρακολούθηση
- **Ελέγχετε διπλά τις διευθύνσεις** - ειδικά τους πρώτους και τους τελευταίους 4 χαρακτήρες
- **Να γνωρίζετε την τρέχουσα τιμή του SOL** όταν στέλνετε

## Τα επόμενα βήματα

Τώρα που μπορείτε να στέλνετε και να λαμβάνετε SOL, είστε έτοιμοι να εξερευνήσετε πιο προηγμένες
λειτουργίες. Στο επόμενο κεφάλαιο, θα μάθουμε για το staking - έναν τρόπο να κερδίζετε ανταμοιβές
βοηθώντας στην ασφάλεια του δικτύου Solana.

Θυμηθείτε: κάθε ειδικός ήταν κάποτε αρχάριος. Πάρτε τον χρόνο σας, ξεκινήστε με μικρά
ποσά και χτίστε αυτοπεποίθηση μέσα από την εξάσκηση.
