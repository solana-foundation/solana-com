# Account Setup Quickstart

Set up access to author Solana Media posts in Keystatic.

1. Create and verify a [GitHub account](https://github.com/join), if needed.
2. Ask a Solana Media admin for **Write** access to
   `solana-foundation/solana-com` and access to the Solana Media Keystatic
   GitHub App. Accept the GitHub invitation.
3. Open [Keystatic](https://solana-com-media.vercel.app/keystatic), select **Log
   in with GitHub**, and approve the authorization prompt.

![Log in with GitHub](screenshots/16-keystatic-login.webp)

You are ready when the Keystatic dashboard loads. If it does not, ask an admin
to confirm your repository and GitHub App access.
