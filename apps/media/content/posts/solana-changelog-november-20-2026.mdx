## Ecosystem work

### SIMDs

- [Entry timestamps similar to Market Tick](https://github.com/solana-foundation/solana-improvement-documents/pull/732) are being planned

### Validator clients (Agave, Firedancer, Mithril)

- Agave is exploring [adding wincode configurations to each snapshot file](https://github.com/anza-xyz/agave/pull/16946) it exports
- Agave is improving memory allocation for runtime initialization with [well-defined preallocations](https://github.com/anza-xyz/agave/pull/16929) and [reduced overhead](https://github.com/anza-xyz/agave/pull/16936)
- Mithril implemented an experimental service called [FRODO](https://github.com/Overclock-Validator/mithril/pull/356), which predicts whether transactions will fail or leave account state unchanged so they can run later in the queue

### RPC 2.0

- Superbank is improving the performance of its [disk-cache partition reads](https://github.com/solana-rpc/superbank/pull/137)

### Solana Program Library (SPL) and Core BPF

- The Subscriptions Program will [allow clear signing](https://github.com/solana-foundation/subscriptions/pull/281)

### Solana program frameworks (Anchor, Pinocchio, Quasar)

- Anchor is working to [minimize heap allocations](https://github.com/otter-sec/anchor/pull/5284) in its v2 release
- Quasar is implementing a [shared-accounts feature](https://github.com/blueshift-gg/quasar/pull/523) that supports variable numbers of accounts, duplicate accounts, and other behaviors
