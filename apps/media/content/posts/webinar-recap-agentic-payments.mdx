## Why agentic payments, why now

Stablecoins on Solana have grown quickly across cross-border payments, remittances, and store of value. The network now has over $15 billion in circulating stablecoins and has processed roughly $10 trillion in transfers to date, supported by 400-millisecond block times and fees of a thousandth of a cent.

The next frontier is programmable money for a web increasingly navigated by agents rather than people. As agents running in tools like Claude Code, Codex, and OpenClaw become more capable, they still need a scalable way to pay for the resources they use.

X402 is filling that gap with roughly 200 million transactions, $50 billion in volume, and about 150,000 merchant endpoints. Most transactions are under 50 cents — a scale of micropayment activity traditional card networks do not support.

## How X402 uses HTTP 402

HTTP has always included an unused 402 status code: “Payment Required.” X402 brings that status code into use as a native, per-request payment pattern for the web.

With X402, agents can receive real-time pricing, reason about whether a resource fits a budget, and pay on the spot for a website, article, or API call. Payments settle in stablecoins like USDC, turning access to web resources into something agents can handle directly rather than relying on a human to provision accounts, enter card details, or manage API keys.

## What agents can do with native payments

X402 addresses three core problems that emerge when agents need to operate across paid resources on the internet. The protocol makes payment and access part of the same runtime.

- **Open tool discovery:** X402 replaces API keys with the wallet itself as an agent’s identity, allowing agents to access HTTP resources without a human configuring each tool call.
- **Economic reasoning:** X402 embeds pricing directly into an agent’s context window, so an agent can compare a ten-cent tool with a one-dollar tool and stay within a budget.
- **Earning and spending in one runtime:** A simple wallet lets agents both earn and spend with real-time settlement, enabling autonomous loops where earnings fund further agent activity.

## An open standard gaining distribution

X402 is an open standard hosted by the Linux Foundation. Speakers compared its path to Kubernetes: incubated by one company, but built for broad, cross-industry use rather than a single walled garden.

Since launching about a year ago, X402 has processed over 180 million transactions and is now referenced in the docs and workflows of Cloudflare, Stripe, and AWS, where it is built natively into Agent Core Payments. AI-native services including Browserbase and Exa also reference the standard.

## Live demos: pay.sh and AWOL

The webinar closed with live demos showing how little friction remains once X402 is wired into an agent workflow. Both demos centered on agents discovering and paying for tools directly from a wallet-based runtime.

- **pay.sh:** [Using pay.sh](https://pay.sh/), a Solana-built CLI directory of X402-payable endpoints, an agent was asked for the day’s top tokens by trading volume. It found the right endpoint, paid a one-cent fee, and returned live rankings without requiring an API key.
- **AWOL:** [Using AWOL](https://docs.cdp.coinbase.com/agentic-wallet/welcome), Coinbase’s comparable wallet-based client, an agent chained multiple paid tool calls together live. It pulled trending social content, fed it into a video-generation endpoint, and produced a short market recap clip, with the agent funding and paying for the workflow autonomously.

Manually provisioning the same API keys the old way can take 30 minutes to an hour. With X402, the payment and access flow can happen inside a single session.

## Explore X402

Developers can visit [x402.org](https://x402.org) for protocol documentation. Teams interested in experimenting with pay.sh and AWOL can reach out to the Solana Foundation.
